# ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ LLM ಕ್ಲೈಂಟ್

ಲಾಂಚೈನ್4j ಅನ್ನು ಬಳಸಿಕೊಂಡು ಮಿನಿಮ್ಯಾಕ್ಸ್ ಓಪನ್ಎಐ-ಹೊಂದಾಣಿಕೆಯ ಎಪಿಐ ಮೂಲಕ MCP (ಮೋಡಲ್ ಕಂಟೆಕ್ಸ್ಟ್ ಪ್ರೊಟೋಕಾಲ್) ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆಗೆ ಸಂಪರ್ಕ ಮಾಡುವುದು ಹೇಗೆ ಎಂದು ತೋರಿಸುವ ಜಾವಾ ಅಪ್ಲಿಕೇಶನ್.

## ಅಗತ್ಯ precededಿಕೆಗಳು

- ಜಾವಾ 21 ಅಥವಾ ಮೇಲು
- ಮೇವನ್ 3.6+ (ಅಥವಾ ಒಳಗೊಂಡಿರುವ ಮೇವನ್ ರ್ಯಾಪರ್ ಬಳಸಿ)
- ಮಿನಿಮ್ಯಾಕ್ಸ್ API ಕೀ
- `http://localhost:8080` ನಲ್ಲಿ ಕಾರ್ಯಗತವಾಗಿರುವ MCP ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆ

## API ಕೀ ಪಡೆಯುವುದು

ಈ ಅಪ್ಲಿಕೇಶನ್ ಮಿನಿಮ್ಯಾಕ್ಸ್ ಓಪನ್ಎಐ-ಹೊಂದಾಣಿಕೆಯ ಎಪಿಐ ಬಳಿಸುತ್ತದೆ. ನಿಮ್ಮ ಕೀ ಮತ್ತು ಎಂಡ್‌ಪಾಯಿಂಟ್ ಪಡೆಯಲು ಈ ಹಂತಗಳನ್ನು ಅನುಸರಿಸಿ:

### 1. ಒಂದು ಎಂಡ್‌ಪಾಯಿಂಟ್ ಆಯ್ಕೆಮಾಡಿ
1. ಪ್ರಪಂಚದೆ ಲಗ್ಗೆಗಾಗಿ `https://api.minimax.io/v1` ಬಳಸಿ
2. ಚೀನಾದ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಗೆ`https://api.minimaxi.com/v1` ಬಳಸಿ

### 2. API ಕೀ ರಚಿಸಿ
1. ನಿಮ್ಮ ಮಿನಿಮ್ಯಾಕ್ಸ್ ಖಾತೆಯಿಂದ ಮಿನಿಮ್ಯಾಕ್ಸ್ API ಕೀ ರಚಿಸಿ
2. ಕೀನನ್ನು ಸುರಕ್ಷಿತವಾಗಿ ಇಡಿ

### 3. ಪರಿಸರಚರಗಳನ್ನು ಸೆಟ್ ಮಾಡಿ

#### ವಿಂಡೋಸ್‌ನಲ್ಲಿ (ಕಮಾಂಡ್ ಪ್ರಾಂಪ್ಟ್):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### ವಿಂಡೋಸ್‌ನಲ್ಲಿ (ಪವರ್ ಶೆಲ್):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### macOS/Linux ನಲ್ಲಿ:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## ಸೆಟಪ್ ಮತ್ತು ಸ್ಥಾಪನೆ

1. **ಪ್ರಾಜೆಕ್ಟ್ ಡೈರೆಕ್ಟರಿಗೆ ಕ್ಲೋನ್ ಅಥವಾ ನ್ಯಾವಿಗೇಟ್ ಮಾಡಿ**

2. **ನಿರ್ಭರತೆಗಳನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ**:
   ```cmd
   mvnw clean install
   ```
   ಅಥವಾ ನೀವು ಮೇವನ್ ಅನ್ನು ಗ್ಲೋಬಲ್ ಆಗಿ ಸ್ಥಾಪಿಸಿರುವರೆ:
   ```cmd
   mvn clean install
   ```

3. **ಪರಿಸರಚರಗಳನ್ನು ಸೆಟ್ ಮಾಡಿ** ("API ಕೀ ಪಡೆಯುವುದು" ವಿಭಾಗ ನೋಡಿ)

4. **MCP ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆಯನ್ನು ಪ್ರಾರಂಭಿಸಿ**:
   ಅಧ್ಯಾಯ 1 ರ MCP ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆಯು `http://localhost:8080/sse` ನಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿರಲು ಖಚಿತಪಡಿಸಿ. ಇದು ಕ್ಲೈಂಟ್ ಪ್ರಾರಂಭಿಸುವ ಮುನ್ನ ಕಾರ್ಯನಿರ್ವಹಿಸಿರಬೇಕು.

## ಅಪ್ಲಿಕೇಶನ್ ಚಾಲನೆ

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## ಅಪ್ಲಿಕೇಶನ್ ಮಾಡುವುದೇನು

ಅಪ್ಲಿಕೇಶನ್ ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆಯೊಂದಿಗೆ ಮೂವರು ಮುಖ್ಯ ಕ್ರಿಯೆಗಳನ್ನು ತೋರಿಸುತ್ತದೆ:

1. **ಯೋಜನೆ**: 24.5 ಮತ್ತು 17.3 ರ ಮೊತ್ತವನ್ನು ಲೆಕ್ಕಹಾಕುತ್ತದೆ
2. **ವರಗ ಮೂಲ**: 144 ರವರಗ ಮೂಲವನ್ನು ಲೆಕ್ಕಹಾಕುತ್ತದೆ
3. **ಸಹಾಯ**: ಲಭ್ಯವಿರುವ ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ფუნქ್ಷನ್ ಗಳನ್ನು ತೋರಿಸುತ್ತದೆ

## ನಿರೀಕ್ಷಿತ ಔಟ್‌ಪುಟ್

ಯಶಸ್ವಿಯಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸಿದಾಗ, ನೀವು ಕೆಳಗಿನಂತ_Output_ನನ್ನವರನ್ನು ಕಾಣಬೇಕು:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## ದೋಷ ಪರಿಹಾರ

### ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

1. **"OPENAI_API_KEY ಪರಿಸರಚರ ಹೊಂದಾಣಿಕೆ ಮಾಡಿಲ್ಲ"**
   - ನೀವು `OPENAI_API_KEY` ಪರಿಸರಚರವನ್ನು ಹೊಂದಿಸಿರಲು ಖಚಿತವಾಗಿರಿ
   - ಪರಿಶೀಲನೆಗಾಗಿ ನಿಮ್ಮ ಟರ್ಮಿನಲ್/ಕಮಾಂಡ್ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಪುನರಾರಂಭಿಸಿ

2. **"localhost:8080 ಗೆ ಸಂಪರ್ಕ ನಿರಾಕರಿಸಲಾಗಿದೆ"**
   - MCP ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆ 8080 ಪೋರ್ಟ್ ನಲ್ಲಿ ನಡೆಯುತ್ತಿದೆಯೆಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ
   - ಬೇರೊಂದು ಸೇವೆ ಪೋರ್ಟ್ 8080 ಬಳಸುತ್ತಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ

3. **"ಪ್ರಾಮಾಣೀಕರಣ ವಿಫಲವಾಗಿದೆ"**
   - ನಿಮ್ಮ API ಕೀ ಮಾನ್ಯವಾಗಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ
   - ನೀವು ಬಳಸಿ ನಿರೀಕ್ಷಿಸಿದ ಎಂಡ್‌ಪಾಯಿಂಟ್ ಗೆ `OPENAI_BASE_URL` ಹೊಂದಿಕೊಂಡಿದೆಯೇ ಎಂದು ಚೆಕ್ ಮಾಡಿ

4. **ಮೇವನ್ ನಿರ್ಮಾಣ ದೋಷಗಳು**
   - ನೀವು ಜಾವಾ 21 ಅಥವಾ ಮೇಲು ಬಳಿಸುತ್ತಿದ್ದೀರಾ ಎಂದು ಪರಿಶೀಲಿಸಿ: `java -version`
   - ನಿರ್ಮಾಣವನ್ನು ಶುದ್ಧಗೊಳಿಸಲು ಪ್ರಯತ್ನಿಸಿ: `mvnw clean`

### ಡಿಬಗ್ಗಿಂಗ್

ಡಿಬಗ್ ಲಾಗಿಂಗ್ ಸಕ್ರಿಯಗೊಳಿಸಲು, ಅಪ್ಲಿಕೇಶನ್ ಚಾಲನೆಯಲ್ಲಿದ್ದಾಗ ಕೆಳಗಿನ JVM ಆರ್ಗುಮೆಂಟ್ ಅನ್ನು ಸೇರಿಸಿ:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## ಸಂರಚನೆ

ಅಪ್ಲಿಕೇಶನ್ ಈ ಪ್ರಕಾರ ಸಂರಚಿತವಾಗಿದೆ:
- ಡೀಫಾಲ್ಟ್ ಆಗಿ ಮಿನಿಮ್ಯಾಕ್ಸ್-M3 ಉಪಯೋಗಿಸುವುದು, ಅಥವಾ `MINIMAX_MODEL_ID` ಹೊಂದಿರುವಾಗ ಮಿನಿಮ್ಯಾಕ್ಸ್-M2.7 ಬಳಕೆ
- `OPENAI_BASE_URL` ಹೊಂದಿದ್ದರೆ ಅದಕ್ಕೆ ಸಂಪರ್ಕಿಸುವುದು; ಇಲ್ಲದಿದ್ದರೆ `MINIMAX_REGION=cn_zh` ಇದ್ದಾಗ `https://api.minimaxi.com/v1` ಅಥವಾ ಡೀಫಾಲ್ಟ್ ಆಗಿ `https://api.minimax.io/v1` ಬಳಸುವುದು
- MCP ಸೇವೆಗೆ `http://localhost:8080/sse` ನಲ್ಲಿ ಸಂಪರ್ಕಿಸುವುದು
- ವಿನಂತಿಗಳಿಗೆ 60 ಸೆಕೆಂಡುಗಳ ಟೈಮ್‌ಔಟ್ ಬಳಕೆ

## ಅವಲಂಬಣೆಗಳು

ಈ ಪ್ರಾಜೆಕ್ಟಿನಲ್ಲಿ ಬಳಕೆಯಾದ ಮುಖ್ಯ ಅವಲಂಬನೆಗಳು:
- **ಲಾಂಚೈನ್4j**: AI ಸಂಯೋಜನೆ ಮತ್ತು ಉಪಕರಣ ನಿರ್ವಹಣೆಗೆ
- **ಲಾಂಚೈನ್4j MCP**: ಮೋಡಲ್ ಕಂಟೆಕ್ಸ್ಟ್ ಪ್ರೊಟೋಕಾಲ್ ಬೆಂಬಲಕ್ಕೆ
- **ಲಾಂಚೈನ್4j ಓಪನ್ಎಐ ಅಧಿಕೃತ**: ಮಿನಿಮ್ಯಾಕ್ಸ್ ಓಪನ್ಎಐ-ಹೊಂದುಕೊಳ್ಳುವ API ಸಂಯೋಜನೆಗೆ
- **ಸ್ಪ್ರಿಂಗ್ ಬೂಟ್**: ಅಪ್ಲಿಕೇಶನ್ ಫ್ರೇಮ್‌ವರ್ಕ್ ಮತ್ತು ಅವಲಂಬನೆ ಇಂಜೆಕ್ಷನ್ ಗಾಗಿ
