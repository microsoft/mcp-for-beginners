# ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ LLM ಕ್ಲೈಂಟ್

LangChain4j ಬಳಸಿ MiniMax OpenAI-ಅನುಕೂಲ API ಮೂಲಕ MCP (ಮಾಡೆಲ್ ಸೆಂಟೆಕ್ಸ್ಟ್ ಪ್ರೊಟೋಕಾಲ) ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆಗೆ ಸಂಪರ್ಕಿಸುವ ಪುಟದ ಜಾವಾ ಅಪ್ಲಿಕೇಶನ್.

## ಅಗತ್ಯವಿರುವವುಗಳು

- ಜಾವಾ 21 ಅಥವಾ ಹೆಚ್ಚಿನ ಆವೃತ್ತಿ
- ಮೆವೆן 3.6+ (ಹಾಗೂ ಸೇರಿಸಲಾದ ಮೆವೆನ್ ರಾಪರ್ ಬಳಸಿ)
- ಒಂದು MiniMax API ಕೀ
- `http://localhost:8080` ನಲ್ಲಿ ನಡೆಯುತ್ತಿರುವ MCP ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆ

## API ಕೀ ಪಡೆಯುವುದು

ಈ ಅಪ್ಲಿಕೇಶನ್ MiniMax OpenAI-ಅನುಕೂಲ API ಉಪಯೋಗಿಸುತ್ತದೆ. ನಿಮ್ಮ ಕೀ ಮತ್ತು ಎಂಡಪಾಯಿಂಟ್ ಪಡೆಯಲು ಈ ಹಂತಗಳನ್ನು ಅನುಸರಿಸಿ:

### 1. ಎಂಡಪಾಯಿಂಟ್ ಆಯ್ಕೆಮಾಡಿ
1. ಗ್ಲೋಬಲ್ ಎಂಡಪಾಯಿಂಟ್‌ಗೆ `https://api.minimax.io/v1` ಬಳಸಿ
2. ಚೀನಾ ಎಂಡಪಾಯಿಂಟ್‌ಗೆ `https://api.minimaxi.com/v1` ಬಳಸಿ

### 2. API ಕೀ ರಚಿಸಿ
1. ನಿಮ್ಮ MiniMax ಖಾತೆಯಿಂದ MiniMax API ಕೀ ರಚಿಸಿ
2. ಆ ಕೀ ಅನ್ನು ಸುರಕ್ಷಿತ ಸ್ಥಳದಲ್ಲಿ ಇಟ್ಟುಕೊಳ್ಳಿ

### 3. ಎನ್ವರನ್ಮೆಂಟ್ ವ್ಯಾರಿಯಬಲ್ಗಳನ್ನು ಸೆಟ್ ಮಾಡಿ

#### ವಿಂಡೋಸ್ (ಕಮಾಂಡ್ ಪ್ರಾಂಪ್ಟ್)ನಲ್ಲಿ:
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### ವಿಂಡೋಸ್ (ಪವರ್‌ಶೆಲ್)ನಲ್ಲಿ:
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### macOS/Linux ನಲ್ಲಿ:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## ಸೆಟ್ ಅಪ್ ಮತ್ತು ಸ್ಥಾಪನೆ

1. **ಪ್ರಾಜೆಕ್ಟ್ ಡೈರೆಕ್ಟರಿಯನ್ನ ಕ್ಲೋನ್ ಅಥವಾ ಅವುಗೆ ನವಿಗೇಟ್ ಮಾಡಿ**

2. **ನಿರ್ಬಂಧಗಳನ್ನು ಸ್ಥಾಪಿಸಿ**:
   ```cmd
   mvnw clean install
   ```
   ನಿಮಗೆ ಮೆವೆನ್ ಗ್ಲೋಬಲಾಗಿ ಇನ್ಸ್ಟಾಲ್ ಆಗಿದ್ದರೆ:
   ```cmd
   mvn clean install
   ```

3. **ಎನ್ವರನ್ಮೆಂಟ್ ವ್ಯಾರಿಯಬಲ್ಗಳನ್ನು ಸೆಟ್ ಮಾಡಿ** ("API ಕೀ ಪಡೆಯುವುದು" ವಿಭಾಗ ನೋಡಿ)

4. **MCP ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆಯನ್ನು ಪ್ರಾರಂಭಿಸಿ**:
   ಅಧ್ಯಾಯ 1ನ MCP ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆಯನ್ನು `http://localhost:8080/sse` ನಲ್ಲಿ ಚಾಲನೆಯಲ್ಲಿರಲಿ. ಕ್ಲೈಂಟ್ ಪ್ರಾರಂಭಿಸುವ ಮೊದಲು ಇದು ಚಾಲನೆಯಲ್ಲಿರಬೇಕು.

## ಅಪ್ಲಿಕೇಶನ್ ಚಾಲನೆ

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## ಅಪ್ಲಿಕೇಶನ್ ಏನು ಮಾಡುತ್ತದೆ

ಅಪ್ಲಿಕೇಶನ್ ಮೂರು ಪ್ರಮುಖ ಸಂಪರ್ಕಗಳನ್ನು ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆಯೊಂದಿಗೆ ತೋರಿಸುತ್ತದೆ:

1. **ಅಡಿಶನ್**: 24.5 ಮತ್ತು 17.3 ರ ಮೊತ್ತವನ್ನು ಲೆಕ್ಕಹಾಕುತ್ತದೆ
2. **ಸ್ಕ್ವೇರ್ ರೂಟ್**: 144 ರ ವರ್ಗಮೂಲವನ್ನು ಲೆಕ್ಕಹಾಕುತ್ತದೆ
3. **ಹೆಲ್ಪ್**: ಲಭ್ಯವಿರುವ ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಕಾರ್ಯಗಳನ್ನು ತೋರಿಸುತ್ತದೆ

## ನಿರೀಕ್ಷಿತ ಔಟ್ಪುಟ್

ಯಶಸ್ವಿಯಾಗಿ ಚಾಲನೆಯಾದಾಗ, ನೀವು ಹೀಗೊಂದು ಔಟ್ಪುಟ್ ನೋಡಬಹುದು:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## ಸಮಸ್ಯೆಗಳ ನಿವಾರಣೆ

### ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

1. **"OPENAI_API_KEY ಎನ್ವರನ್ಮೆಂಟ್ ವ್ಯಾರಿಯಬಲ್ ಸೆಟ್ ಆಗಿಲ್ಲ"**
   - ನೀವು `OPENAI_API_KEY` ಎನ್ವರನ್ಮೆಂಟ್ ವ್ಯಾರಿಯಬಲ್ ಸೆಟ್ ಮಾಡಿಕೊಂಡಿದ್ದೀರಾ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ
   - ವ್ಯಾರಿಯಬಲ್ ಸೆಟ್ ಮಾಡಿದ ನಂತರ ನಿಮ್ಮ ಟರ್ಮಿನಲ್/ಕಮಾಂಡ್ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಪುನರ್‌ಪ್ರಾರಂಭಿಸಿ

2. **"localhost:8080 ಗೆ ಸಂಪರ್ಕ ನಿರಾಕರಿಸಲಾಗಿದೆ"**
   - MCP ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸೇವೆ 8080 ಪೋರ್ಟ್‌ನಲ್ಲಿ ಚಾಲನೆಯಲ್ಲಿದೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ
   - ಬೇರೆ ಯಾವುದೇ ಸೇವೆ 8080 ಪೋರ್ಟ್ ಬಳಸುತ್ತಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ

3. **"ಪ್ರಮಾಣೀಕರಣ ವಿಫಲವಾಗಿದೆ"**
   - ನಿಮ್ಮ API ಕೀ ಮಾನ್ಯವಿದೆ ಎಂದು ಪರಿಶೀಲಿಸಿ
   - ನೀವು ಬಳಸಲು ಉದ್ದೇಶಿಸಿದ್ದ ಎಂಡಪಾಯಿಂಟ್‌ಗೆ `OPENAI_BASE_URL` ಹೊಂದಿಕೆ ಹೊಂದಿದೆಯಾ ಎಂದು ಪರಿಶೀಲಿಸಿ

4. **ಮೆವೆನ್ ನಿರ್ಮಾಣ ದೋಷಗಳು**
   - ನೀವು ಜಾವಾ 21 ಅಥವಾ ಹೆಚ್ಚಿನ ಆವೃತ್ತಿ ಬಳಸುತ್ತಿದ್ದಾರೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ: `java -version`
   - ನಿರ್ಮಾಣವನ್ನು ಕ್ಲೀನ್ ಮಾಡಲು ಪ್ರಯತ್ನಿಸಿ: `mvnw clean`

### ಡಿಬಗಿಂಗ್

ಡಿಬಗ್ ಲಾಗಿಂಗ್ ಸಕ್ರಿಯಗೊಳಿಸಲು, ಕೆಳಗಿನ JVM ಆರ್ಗ್ಯುಮೆಂಟ್ ಅನ್ನು ಚಾಲನೆಯಾಗುವಾಗ ಸೇರಿಸಿ:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## ಸಂರಚನೆ

ಅಪ್ಲಿಕೇಶನ್ ಸಂರಚನೆಯಲ್ಲಿದೆ:
- ಡೀಫಾಲ್ಟ್ ಆಗಿ MiniMax-M3 ಬಳಸಿ; `MINIMAX_MODEL_ID` ಹೊಂದಿಸಿ `MiniMax-M3` ಅಥವಾ `MiniMax-M2.7` ಆಯ್ಕೆಮಾಡಿ
- `OPENAI_BASE_URL` ಸೆಟ್ ಆಗಿದ್ದರೆ ಅದನ್ನು ಸಂಪರ್ಕಿಸಿ; ಇಲ್ಲದಿದ್ದರೆ `MINIMAX_REGION=cn_zh` ಆಗಿದ್ದರೆ `https://api.minimaxi.com/v1` ಅಥವಾ ಡೀಫಾಲ್ಟ್ `https://api.minimax.io/v1` ಬಳಸಿ
- MCP ಸೇವೆಗೆ `http://localhost:8080/sse` ಮೂಲಕ ಸಂಪರ್ಕಿಸು
- ವಿನಂತಿಗಳಿಗೆ 60 ಸೆಕೆಂಡ್ ಟೈಮೌಟ್ ಬಳಸಿ

## ಅವಲಂಬಿತೆಗಳು

ಈ ಪ್ರಾಜೆಕ್ಟ್‌ನಲ್ಲಿ ಬಳಸಲ್ಪಡುವ ಪ್ರಮುಖ ಅವಲಂಬಿತೆಗಳು:
- **LangChain4j**: AI ಏಕೀಕರಣ ಮತ್ತು ಸಾಧನ ನಿರ್ವಹಣೆಗೆ
- **LangChain4j MCP**: ಮಾಡೆಲ್ ಸೆಂಟೆಕ್ಸ್ಟ್ ಪ್ರೊಟೋಕಾಲ್ ಬೆಂಬಲಕ್ಕೆ
- **LangChain4j OpenAI ಅಧಿಕೃತ**: MiniMax OpenAI-ಅನುಕೂಲ API ಏಕೀಕರಣಕ್ಕೆ
- **Spring Boot**: ಅಪ್ಲಿಕೇಶನ್ ಫ್ರೇಮ್ವರ್ಕ್ ಮತ್ತು ಅವಲಂಬಿತೆಯ ಇಂಜೆಕ್ಷನ್‌ಗೆ
