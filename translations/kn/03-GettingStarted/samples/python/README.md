# MCP ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಸರ್ವರ್ (Python)



ಪೈಥಾನ್‌ನಲ್ಲಿ ಸರಳ ಮಾದರಿ ಸಂಧರ್ಭ ಪ್ರೋಟೋಕಾಲ್ (MCP) ಸರ್ವರ್ ಅನುಷ್ಠಾನ, ಅದು ಮೂಲ ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಕಾರ್ಯಕ್ಷಮತೆಯನ್ನು ಒದಗಿಸುತ್ತದೆ.


## ಸ್ಥಾಪನೆ

ಅಗತ್ಯ ಡಿಪೆಂಡೆನ್ಸಿಗಳು ಸ್ಥಾಪಿಸಿ:

```bash
pip install -r requirements.txt
```

ಅಥವಾ MCP Python SDK ನೇರವಾಗಿ ಸ್ಥಾಪಿಸಿ:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## ಉಪಯೋಗ

### ಸರ್ವರ್ ಚಾಲನೆ

ಸರ್ವರ್ ಅನ್ನು MCP ಗ್ರಾಹಕರು (Claude ಡೆಸ್ಕ್‌ಟಾಪ್ ಮುಂತಾದವು) ಉಪಯೋಗಿಸಲು ವಿನ್ಯಾಸಗೊಳ್ಳಲಾಗಿದೆ. ಸರ್ವರ್ ಪ್ರಾರಂಭಿಸಲು:

```bash
python mcp_calculator_server.py
```

**ಗಮನಿಸಿ**: ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ನೇರವಾಗಿ ಚಾಲನೆ ಮಾಡಿದಾಗ, ನೀವು JSON-RPC ಮಾನ್ಯತೆ ದೋಷಗಳನ್ನು ಕಾಣಬಹುದು. ಇದು ಸಹಜ ವರ್ತನೆ - ಸರ್ವರ್ ಸರಿಯಾಗಿ ರೂಪಿಸಲಾದ MCP ಗ್ರಾಹಕ ಸಂದೇಶಗಳನ್ನು ಕಾಯುತ್ತಿದೆ.

### ಕಾರ್ಯಗಳ ಪರೀಕ್ಷೆ

ಕ್ಯಾಲ್ಕ್ಯುಲೇಟರ್ ಕಾರ್ಯಗಳು ಸರಿಯಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತವೆಯೇ ಎಂದು ಪರೀಕ್ಷಿಸಲು:

```bash
python test_calculator.py
```

## ಸಮಸ್ಯೆಗಳ ಪರಿಹಾರ

### ಆಮದು ದೋಷಗಳು

`ModuleNotFoundError: No module named 'mcp'` ಎನ್ನುವ ಸಂದೇಶ ಕಾಣಿಸಿದರೆ, MCP Python SDK ಅನ್ನು ಸ್ಥಾಪಿಸಿ:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### ನೇರವಾಗಿ ಚಾಲನೆ ಮಾಡಿದಾಗ JSON-RPC ದೋಷಗಳು

"Invalid JSON: EOF while parsing a value" ಎಂಬ ದೋಷಗಳು ಸರ್ವರ್ ನೇರವಾಗಿ ಚಾಲನೆ ಮಾಡಿದಾಗ ನಿರೀಕ್ಷಿತವಾಗಿವೆ. ಸರ್ವರ್‌ಗೆ MCP ಗ್ರಾಹಕ ಸಂದೇಶಗಳು ಬೇಕು, ನೇರ ಟರ್ಮಿನಲ್ ಇನ್ಪುಟ್ ಅಲ್ಲ.
