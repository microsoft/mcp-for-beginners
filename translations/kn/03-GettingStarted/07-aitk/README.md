# Visual Studio Code ಗಾಗಿ AI Toolkit ವಿಸ್ತರಣೆದಿಂದ ಸರ್ವರ್ ಅನ್ನು ಉಪಭೋಗಿಸುವುದು

ನೀವು ಒಂದು AI ಏಜೆಂಟ್ನ್ನು ನಿರ್ಮಿಸುತ್ತಿರುವಾಗ, ಅದು ಕೇವಲ ಬುದ್ಧಿವಂತಿಕೆಯಿಂದ ಉತ್ತರಗಳನ್ನು ಸೃಷ್ಟಿಸುವುದಲ್ಲ; ನಿಮ್ಮ ಏಜೆಂಟ್ನು ಕ್ರಿಯೆಗಳನ್ನು ಕೈಗೊಳ್ಳುವ ಸಾಮರ್ಥ್ಯವನ್ನೂ ನೀಡುವುದು ಮುಖ್ಯ. ಅದಕ್ಕಾಗಿ Model Context Protocol (MCP) ಇದೆ. MCP ಏಜೆಂಟ್ಗಳು ಹೊರಗಿನ ಸಾಧನಗಳನ್ನೂ ಸೇವೆಗಳನ್ನು ಸुसಂಬಂಧಿತ ರೀತಿಯಲ್ಲಿ ಪ್ರವೇಶಿಸುವುದನ್ನು ಸುಲಭ ಮಾಡುತ್ತದೆ. ಇದನ್ನು ನಿಮ್ಮ ಏಜೆಂಟ್ನು ಬಳಕೆಮಾಡಬಹುದಾದ ಟೂಲ್ಬಾಕ್ಸ್‌ಗೆ ಸಂಪರ್ಕಿಸುವಂತೆ ಭಾವಿಸಿರಿ.

ಉದಾಹರಣೆಗೆ, ನೀವು ಒಂದು ಏಜೆಂಟ್ನ್ನು ನಿಮ್ಮ ಕ್ಯಾಲ್ಕುಲೆಟರ್ MCP ಸರ್ವರ್‌ಗೆ ಸಂಪರ್ಕಿಸಿದಾಗ, ನಿಮಗೆ "47 ಅನ್ನು 89ರಿಂದ ಗುಣಿಸಿ" ಎಂಬ ಪ್ರಾಂಪ್ಟ್ ಬರುವಂತೆ, ನಿಮ್ಮ ಏಜೆಂಟು ಗಣಿತ ಆಪರೇಷನ್‌ಗಳನ್ನು ಸಹಜವಾಗಿ ನಿರ್ವಹಿಸಬಹುದಾಗಿದೆ—ಕಷ್ಟಸಾಧ್ಯ ಲಾಜಿಕ್ಸ್ ಅಥವಾ ಕಸ್ಟಮ್ API ಗಳ ನಿರ್ಮಾಣ ಅಗತ್ಯವಿಲ್ಲ.

## ಅವಲೋಕನ

ಈ ಪಾಠದಲ್ಲಿ, Visual Studio Code ನ [AI Toolkit](https://aka.ms/AIToolkit) ವಿಸ್ತರಣೆಯ ಮೂಲಕ, ಕ್ಯಾಲ್ಕುಲೆಟರ್ MCP ಸರ್ವರ್ ಅನ್ನು ಏಜೆಂಟ್ಗೆ ಸಂಪರ್ಕಿಸುವ ರೀತಿಯನ್ನು ಹಾಗೂ ನಿಮ್ಮ ಏಜೆಂಟು ಸಾದಾರಣ ಭಾಷೆ ಮೂಲಕ ಸೇರ್ಪಡೆ, ಬಾಕಿ ಬಗೆಗಿನ ಗಣಿತ ಕಾರ್ಯಗಳನ್ನು ಹೇಗೆ ನಿರ್ವಹಿಸುತ್ತದೆ ಎಂಬುದನ್ನು ತಿಳಿಯುವುದಾಗಿದೆ.

AI Toolkit Visual Studio Code ಗಾಗಿ ಶಕ್ತಿಶಾಲಿ ವಿಸ್ತರಣೆ ಆಗಿದ್ದು, ಏಜೆಂಟ್ ಅಭಿವೃದ್ಧಿಯನ್ನು ಸುಲಭಗೊಳಿಸುತ್ತದೆ. AI ಎಂಜಿನಿಯರ್ಸ್ ಸ್ಥಳೀಯ ಅಥವಾ ಕ್ಲೌಡ್‌ನಲ್ಲಿ ಜನರೇಟಿವ್ AI ಮಾದರಿಗಳನ್ನು ಅಭಿವೃದ್ಧಿಪಡಿಸಿ ಪರೀಕ್ಷಿಸುವ ಮೂಲಕ AI ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ಸುಲಭವಾಗಿ ರಚಿಸಬಹುದು. ಈ ವಿಸ್ತರಣೆ ಇಂದು ಲಭ್ಯವಿರುವ ಪ್ರಮುಖ ಜನರೇಟಿವ್ ಮಾದರಿಗಳ ಹೆಚ್ಚಿನাংশವನ್ನು ಸಹ ಬೆಂಬಲಿಸುತ್ತದೆ.

*ಗಮನಿಸಿರಿ*: AI Toolkit ಇತ್ತೀಚೆಗೆ Python ಮತ್ತು TypeScript ಬೆಂಬಲಿಸುತ್ತದೆ.

## ಕಲಿಕೆ ಕೇಳ್ಗೋಳು

ಈ ಪಾಠದ ಅಂತ್ಯಕ್ಕೆ ನೀವು ಸಾಮರ್ಥ್ಯ ಹೊಂದಿರಲಿದ್ದು:

- AI Toolkit ಮೂಲಕ MCP ಸರ್ವರ್ ಅನ್ನು ಉಪಯೋಗಿಸುವುದು.
- MCP ಸರ್ವರ್ ನೀಡುವ ಸಾಧನಗಳನ್ನು ಕಂಡುಹಿಡಿದು, ಉಪಯೋಗಿಸಲು ಏಜೆಂಟ್ ಸಂರಚನೆကို ಕಾನ್ಫಿಗರ್ ಮಾಡುವದು.
- ಸಹಜ ಲಿಂಗ ಮೂಲಕ MCP ಸಾಧನಗಳನ್ನು ಉಪಯೋಗಿಸುವುದು.

## ಸ್ಪಷ್ಟನೆ

ಅದನ್ನೇ ನಾವು ಹೇಗೆ ಮಾಡುವೋ ಅದು ಹೀಗಿದೆ:

- ಕ್ಯಾಲ್ಕುಲೆಟರ್ ಸಾಧನಗಳೊಂದಿಗೆ MCP ಸರ್ವರ್ ರಚಿಸಿ.
- ಏಜೆಂಟ್ ಬಿಲ್ಡರ್ ಅನ್ನು MCP ಸರ್ವರ್ ಗೆ ಸಂಪರ್ಕಿಸಿ.
- ಸಹಜ ಭಾಷೆ ಮೂಲಕ ಏಜೆಂಟ್‌ನ ಸಾಧನ ಕರೆಗಳನ್ನು ಪರೀಕ್ಷಿಸಿ.

ಬಹುಮಾನ, ನಾವು ಕಷ್ಟರಹಿತ ಪ್ರಕ್ರಿಯೆಯನ್ನು ತಿಳಿದುಕೊಂಡೀವಿ, ಈಗ ನಾವು MCP ಮೂಲಕ ಹೊರಗಿನ ಸಾಧನಗಳನ್ನು ಉಪಯೋಗಿಸುವಂತೆ AI ಏಜೆಂಟ್ ಅನ್ನು ಸಂರಚಿಸೋಣ, ಇದರ ಸಾಮರ್ಥ್ಯವನ್ನು ವೃದ್ಧಿಸೋಣ!

### -2- ಏಜೆಂಟ್‌ಗಾಗಿ ಸಿಸ್ಟಂ ಪ್ರಾಂಪ್ಟ್ ರಚಿಸಿ

ಏಜೆಂಟ್ ಟ್ರಯಿಂಗಳಾದ ಬಳಿಕ, ಅದರ ವ್ಯಕ್ತಿತ್ವ ಮತ್ತು ಉದ್ದೇಶವನ್ನು ನಿಗದಿಪಡಿಸುವ ಸಮಯ. ಈ ಭಾಗದಲ್ಲಿ ನೀವು **Generate system prompt** ವೈಶಿಷ್ಟ್ಯವನ್ನು ಬಳಸುತ್ತೀರಿ, ಇದರಲ್ಲಿ ನೀವು ಏಜೆಂಟ್ ನಿರೀಕ್ಷಿತ ವರ್ತನೆಯನ್ನು ವಿವರಣೆ ಮಾಡುತ್ತೀರಿ,—ಈ ಸಂದರ್ಭದಲ್ಲಿ, ಕ್ಯಾಲ್ಕುಲೆಟರ್ ಏಜೆಂಟ್ ಆಗಿ,—ಮತ್ತು ಮಾದರಿ ಆ ಪ್ರಾಂಪ್ಟ್ ಅನ್ನು ಬರೆಯುತ್ತದೆ.

![Visual Studio Code ಗಾಗಿ AI Toolkit ನಲ್ಲಿ "Calculator Agent" ಇಂಟರ್ಫೇಸ್ ಚಿತ್ರ, "Generate a prompt" ಶೀರ್ಷಿಕೆಯೊಂದಿಗಿನ ಮೋಡಲ್ ವಿಂಡೋ ತೆರೆದಿದೆ. ಮೋಡಲ್ ನಲ್ಲಿ_PROMPT_ ಟ್ಯಾಂಪ್ಲೇಟನ್ನು ಸರಳ ಮಾಹಿತಿ ಹಂಚಿಕೆಯಿಂದ ರಚಿಸಬಹುದು ಎಂದು ವಿವರಿಸಲಾಗಿದೆ ಮತ್ತು ಮಾದರಿ system prompt ಹೀಗೆ ಇದೆ: "ನೀವು ಸಹಾಯಕ ಮತ್ತು ಕಾರ್ಯಕ್ಷಮ ಗಣಿತ ಸಹಾಯಕ. ಮೂಲ ಭಿನ್ನಾಕಾರಗಳಿಗೆ ಸಂಬಂಧಿಸಿದ ಪ್ರಶ್ನೆ ನೀಡಿದಾಗ, ನೀವು ಸರಿಯಾದ ಫಲಿತಾಂಶವನ್ನು ಕೊಡುವಿರಿ." ಇಡೀ ಮೋಡಲ್ ಕೆಳಗೆ "Close" ಮತ್ತು "Generate" ಬಟನ್‌ಗಳಿವೆ. ಹಿಂದೆ ಏಜೆಂಟ್ ಸಂರಚನೆ ಸೆಕ್ಷನ್ ಇರುವದು, ಆಯ್ಕೆಮಾಡಿದ ಮಾದರಿ: "OpenAI GPT-4o (via GitHub)" ಮತ್ತು ಸಿಸ್ಟಂ ಹಾಗೂ ಬಳಕೆದಾರ ಪ್ರಾಂಪ್ಟ್ ಕ್ಷೇತ್ರಗಳು ಗೋಚರಿಸುತ್ತವೆ.](../../../../translated_images/kn/aitk-generate-prompt.ba9e69d3d2bbe2a2.webp)

1. **Prompts** ಭಾಗದಲ್ಲಿ **Generate system prompt** ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ. ಈ ಬಟನ್ ಪ್ರಾಂಪ್ಟ್ ಬಿಲ್ಡರ್ ಅನ್ನು ತೆರೆಯುತ್ತದೆ, ಅದು AI ಬಳಸಿ system prompt ಅನ್ನು ರಚಿಸುತ್ತದೆ.
1. **Generate a prompt** ವಿಂಡೋದಲ್ಲಿ ಕೆಳಗಿನಂತೆ ನಮೂದಿಸಿ: `You are a helpful and efficient math assistant. When given a problem involving basic arithmetic, you respond with the correct result.`
1. **Generate** ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ. ಪ್ರಾಂಪ್ಟ್ ರಚನೆಯ ಸ್ಥಿತಿಯನ್ನು ಖಚಿತಪಡಿಸುವ ನೋಟಿಫಿಕೇಶನ್ ಅಗಲ್ಬಾಗದಲ್ಲಿ ಮೂಡುತ್ತದೆ. ರಚನೆ ಪೂರ್ಣವಾದ ನಂತರ, system prompt **Agent (Prompt) Builder**ನ system prompt ಕ್ಷೇತ್ರದಲ್ಲಿ ಕಾಣಿಸಿಕೊಳ್ಳುತ್ತದೆ.
1. system prompt ಪರಿಶೀಲಿಸಿ, ಅಗತ್ಯ ಇದ್ದರೆ ತಿದ್ದುಪಡಿ ಮಾಡಿ.

### -3- MCP ಸರ್ವರ್ ರಚಿಸಿ

ನೀವು ಈಗಳಿಗೆ ಎಜೆಂಟ್ system prompt ಅನ್ನು ವ್ಯಾಖ್ಯಾನಿಸಿದ್ದೀರಾ—ಅದರ ವರ್ತನೆ ಮತ್ತು ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ನಿಯಂತ್ರಿಸುವಂತಹದು— ಈಗ ಪ್ರಾಯೋಗಿಕ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಹೊಂದಿಸುವ ಸಮಯ. ಈ ಭಾಗದಲ್ಲಿ ನೀವು ಸೇರಿಸುವುದು, ಮಾಡಿ, ಗುಣಿಸಿ, ಭಾಗಿಸಿ ಕಾರ್ಯಗಳನ್ನು ನಡೆಸುವ ಕ್ಯಾಲ್ಕುಲೆಟರ್ MCP ಸರ್ವರ್. ಈ ಸರ್ವರ್ ಮೂಲಕ ನಿಮ್ಮ ಏಜೆಂಟ್ ಸಹಜ ಭಾಷೆ ಪ್ರಾಂಪ್ಟ್ ಗಳಿಗೆ ತಕ್ಷಣದ ಗಣಿತ ರಿಯಲ್-ಟೈಮ್ ಲೆಕ್ಕಾಚಾರಗಳನ್ನು ಮಾಡಬಲ್ಲದು.

![Visual Studio Code ಗಾಗಿ AI Toolkit ವಿಸ್ತರಣೆಯಲ್ಲಿನ Calculator Agent ಇಂಟರ್ಫೇಸ್ ತಗ್ಗಿನ ಭಾಗದ ಚಿತ್ರ. “Tools” ಔಟ್‌ಪುಟ್ ವಿಭಾಗಗಳಿಗೆ ವಿಸ್ತರಿಸಬಹುದಾದ ಮೆನುಗಳು ಹಾಗೂ "Choose output format" ಡ್ರಾಪ್ಡೌನ್, “text” ಆಯ್ಕೆಯಾಗಿರುವುದು, ಪಕ್ಕದಲ್ಲಿ "+ MCP Server" ಬಟನ್ ಇರುತ್ತದೆ. “Tools” ವಿಭಾಗದ ಮೇಲ್ಭಾಗದಲ್ಲಿ ಚಿತ್ರ ಚಿಹ್ನೆಯ ಪ್ಲೇಸ್‌ಹೋಲ್ಡರ್ ಕಾಣುತ್ತದೆ.](../../../../translated_images/kn/aitk-add-mcp-server.9742cfddfe808353.webp)

AI Toolkit ನಿಮ್ಮ ಸ್ವಂತ MCP ಸರ್ವರ್ ರಚಿಸಲು ಟೆಂಪ್ಲೇಟ್ಗಳನ್ನು ಒದಗಿಸಿದೆ. ನಾವು ಕ್ಯಾಲ್ಕುಲೆಟರ್ MCP ಸರ್ವರ್ ಸೃಷ್ಟಿಸಲು Python ಟೆಂಪ್ಲೇಟನ್ನು ಬಳಸೋಣ.

*ಗಮನಿಸಿರಿ*: AI Toolkit ಇತ್ತೀಚೆಗೆ Python ಮತ್ತು TypeScript ಬೆಂಬಲಿಸುತ್ತದೆ.

1. **Agent (Prompt) Builder**ನ **Tools** ವಿಭಾಗದಲ್ಲಿ **+ MCP Server** ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ. ವಿಸ್ತರಣೆ **Command Palette** ಮೂಲಕ ಸೆಟ್ ಅಪ್ ವಿಸ್ತರುವಿಕೆಯನ್ನು ಪ್ರಾರಂಭಿಸುತ್ತದೆ.
1. **+ Add Server** ಆಯ್ಕೆಮಾಡಿ.
1. **Create a New MCP Server** ಆಯ್ಕೆಮಾಡಿ.
1. ಟೆಂಪ್ಲೇಟಾಗಿ **python-weather** ಅನ್ನು ಆರಿಸಿ.
1. MCP ಸರ್ವರ್ ಟೆಂಪ್ಲೇಟನ್ನು ಉಳಿಸಲು **Default folder** ಆಯ್ಕೆಮಾಡಿ.
1. ಸರ್ವರ್‌ಗೆ ಹೆಸರಿಸುವಂತೆ ನಮೂದಿಸಿ: **Calculator**
1. ಹೊಸ Visual Studio Code ವಿಂಡೋ ತೆರೆಯುತ್ತದೆ. **Yes, I trust the authors** ಆಯ್ಕೆ ಮಾಡಿ.
1. ಟರ್ಮಿನಲ್ ಬಳಸಿಕೊಂಡು (Terminal > New Terminal), ವರ್ಚುವಲ್ ಪರಿಸರ ರಚಿಸಿ: `python -m venv .venv`
1. ಟರ್ಮಿನಲ್ ಬಳಸಿ ವರ್ಚುವಲ್ ಪರಿಸರ ಸಕ್ರಿಯಗೊಳಿಸಿ:
    1. Windows - `.venv\Scripts\activate`
    1. macOS/Linux - `source .venv/bin/activate`
1. ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ ಅವಶ್ಯಕತೆಗಳನ್ನು ಸ್ಥಾಪಿಸಿ: `pip install -e .[dev]`
1. **Activity Bar**ನ **Explorer** ವೀಕ್ಷಣೆಯಲ್ಲಿ **src** ಡೈರೆಕ್ಟರಿಯನ್ನು ವಿಸ್ತರಿಸಿ ಮತ್ತು **server.py** ಫೈಲ್ ತೆರೆಯಿರಿ.
1. **server.py** ಫೈಲ್‌ನಲ್ಲಿನ ಕೋಡ್ ಈ ಕೆಳಗಿನಂತಿದೆ, ಅದನ್ನು ಬದಲಾಗಿ ಉಳಿಸಿ:

    ```python
    """
    Sample MCP Calculator Server implementation in Python.

    
    This module demonstrates how to create a simple MCP server with calculator tools
    that can perform basic arithmetic operations (add, subtract, multiply, divide).
    """
    
    from mcp.server.fastmcp import FastMCP
    
    server = FastMCP("calculator")
    
    @server.tool()
    def add(a: float, b: float) -> float:
        """Add two numbers together and return the result."""
        return a + b
    
    @server.tool()
    def subtract(a: float, b: float) -> float:
        """Subtract b from a and return the result."""
        return a - b
    
    @server.tool()
    def multiply(a: float, b: float) -> float:
        """Multiply two numbers together and return the result."""
        return a * b
    
    @server.tool()
    def divide(a: float, b: float) -> float:
        """
        Divide a by b and return the result.
        
        Raises:
            ValueError: If b is zero
        """
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    ```

### -4- ಕ್ಯಾಲ್ಕುಲೆಟರ್ MCP ಸರ್ವರ್ ಜೊತೆ ಏಜೆಂಟ್ ಅನ್ನು ಚಾಲನೆ ಮಾಡುವುದು

ಈಗ ಏಜೆಂಟ್‌ಗೆ ಸಾಧನಗಳಿವೆ, ಅವನ್ನು ಉಪಯೋಗಿಸುವ ಸಮಯ ಬಂದಿದೆ! ಈ ವಿಭಾಗದಲ್ಲಿ, ನೀವು ಏಜೆಂಟ್‌ಗೆ ಪ್ರಾಂಪ್ಟ್‌ಗಳನ್ನು ನೀಡುತ್ತೀರಿ ಮತ್ತು ಏಜೆಂಟ್ ಸೂಕ್ತ ಕ್ಯಾಲ್ಕುಲೆಟರ್ MCP ಸರ್ವರ್‌ನ ಸಾಧನವನ್ನು ಉಪಯೋಗಿಸುತ್ತಿದೆಯೇ ಎಂದು ಪರೀಕ್ಷಿಸುವಿರಿ.

![Visual Studio Code ಗಾಗಿ AI Toolkit ವಿಸ್ತರಣೆಯಲ್ಲಿನ Calculator Agent ಇಂಟರ್ಫೇಸ್ ಚಿತ್ರ. ಎಡ ಪ್ಯಾನೆಲ್‌ನಲ್ಲಿ “Tools” ಅಡಿಯಲ್ಲಿ local-server-calculator_server ಎಂಬ MCP ಸರ್ವರ್ ಸೇರಿಸಲಾಗಿದೆ, ಅದರಲ್ಲಿ ನಾಲ್ಕು ಸಾಧನಗಳು: ಸೇರಿಸಿ(add), ಅಳಿಸಿ(subtract), ಗುಣಿಸಿ(multiply), ಮತ್ತು ಭಾಗಿಸಿ(divide) ಇವೆ. ನಾಲ್ಕು ಸಾಧನಗಳು ಸಕ್ರಿಯವಾಗಿವೆ ಕಂಡುಬರುತ್ತದೆ. ಕೆಳಗೆ "Structure output" ವಿಭಾಗ ಕುಗ್ಗಿಹೋಗಿದೆ ಮತ್ತು ನೀಲಿ "Run" ಬಟನ್ ಇದೆ. ಬಲ ಪ್ಯಾನೆಲ್‌ನಲ್ಲಿ, "Model Response" ಅಡಿಯಲ್ಲಿ ಏಜೆಂಟ್ multiply ಮತ್ತು subtract ಸಾಧನಗಳನ್ನು {"a": 3, "b": 25} ಮತ್ತು {"a": 75, "b": 20} ಜೋಡಣೆಗಳ ಜೊತೆ ಕರೆಮಾಡಿದೆ. ಕೊನೆ "Tool Response" 75.0 ಎಂದು ತೋರಿಸಲಾಗಿದೆ. ಕೆಳಗೆ "View Code" ಬಟನ್ ಇದೆ.](../../../../translated_images/kn/aitk-agent-response-with-tools.e7c781869dc8041a.webp)

ನೀವು ನಿಮ್ಮ ಸ್ಥಳೀಯ ಅಭಿವೃದ್ಧಿ ಯಂತ್ರದಲ್ಲಿ MCP ಕ್ಲೈಂಟ್ ಆಗಿ **Agent Builder** ಮೂಲಕ ಕ್ಯಾಲ್ಕುಲೆಟರ್ MCP ಸರ್ವರ್ ಅನ್ನು ನೆರವೇರಿಸುವಿರಿ.

1. MCP ಸರ್ವರ್ ಡಿಬಗಿಂಗ್ ಪ್ರಾರಂಭಿಸಲು `F5` ಒತ್ತಿರಿ. **Agent (Prompt) Builder** ಹೊಸ ಎಡಿಟರ್ ಟ್ಯಾಬ್‌ನಲ್ಲಿ ತೆರೆಯುತ್ತದೆ. ಟರ್ಮಿನಲ್ನಲ್ಲಿ ಸರ್ವರ್ ಸ್ಟೇಟಸ್ ನೋಡಬಹುದು.
1. **Agent (Prompt) Builder**ನ **User prompt** ಕ್ಷೇತ್ರದಲ್ಲಿ ಈ ಪ್ರಾಂಪ್ಟ್ ನಮೂದಿಸಿ: `I bought 3 items priced at $25 each, and then used a $20 discount. How much did I pay?`
1. **Run** ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ, ಏಜೆಂಟ್ ಉತ್ತರವನ್ನು ಪಡೆಯಿರಿ.
1. ಏಜೆಂಟ್ ಫಲಿತಾಂಶ ಪರಿಶೀಲಿಸಿ. ಮಾದರಿಯು ನೀವು **$55** ಕಟ್ಟಿದೀರಿ ಎಂದು ತಿರುಗಿ ಹೇಳಬೇಕು.
1. ಘಟನಾವಳಿಗಳ ವಿಭಾಗ ವಿವರಣೆ:
    - ಲೆಕ್ಕಾಚಾರಕ್ಕಾಗಿ ಏಜೆಂಟ್ **multiply** ಮತ್ತು **subtract** ಸಾಧನಗಳನ್ನು ಆರಿಸುತ್ತದೆ.
    - **multiply** ಸಾಧನಕ್ಕೆ `a` ಮತ್ತು `b` ಮೌಲ್ಯಗಳನ್ನು ನಿಯೋಜಿಸಲಾಗಿದೆ.
    - **subtract** ಸಾಧನಕ್ಕೂ `a` ಮತ್ತು `b` ಮೌಲ್ಯಗಳನ್ನು ನಿಯೋಜಿಸಲಾಗಿದೆ.
    - ಪ್ರತಿಯೊಂದು ಸಾಧನದಿಂದ ಲಭಿಸಿದ ಉತ್ತರವನ್ನು **Tool Response**ನಲ್ಲಿ ನೀಡಲಾಗಿದೆ.
    - ಕೊನೆಗೊಳ್ಳುವ **Model Response**ನಲ್ಲಿ ಸಂಪೂರ್ಣ ಉತ್ತರ ನೀಡಲಾಗಿದೆ.
1. ತಯಾರಾದ ಪ್ರಾಂಪ್ಟ್ ಬದಲಿಸಿ ಹೆಚ್ಚಿನ ಪರೀಕ್ಷೆ ನಡೆಸಬಹುದು. **User prompt** ಕ್ಷೇತ್ರದಲ್ಲಿದ್ದ ಪ್ರಾಂಪ್ಟ್‌ನಲ್ಲಿ ಕ್ಲಿಕ್ ಮಾಡಿ ಅದನ್ನು ಬದಲಾಯಿಸಿ.
1. ಪರಿಶೀಲನೆ ಮುಗಿದ ಮೇಲೆ, ಟರ್ಮಿನಲ್‌ನಲ್ಲಿ **CTRL/CMD+C** ಒತ್ತಿ ಸರ್ವರ್ ನಿಲ್ಲಿಸಿ.

- AI Toolkit ಕಸ್ಟಮ್ ಸಾಧನವನ್ನು ಸುಲಭವಾಗಿ ರಚಿಸಲು ಟೆಂಪ್ಲೇಟ್ಗಳನ್ನು (ಉದಾ: Python MCP ಸರ್ವರ್ ಟೆಂಪ್ಲೇಟುಗಳು) ಒದಗಿಸುತ್ತದೆ.
