## ಪ್ರಾರಂಭಿಸೋಣ  

[![ನಿಮ್ಮ ಮೊದಲ MCP ಸರ್ವರ್ ನಿರ್ಮಿಸಿ](../../../translated_images/kn/04.0ea920069efd979a.webp)](https://youtu.be/sNDZO9N4m9Y)

_(ಈ ಪಾಠದ ವೀಡಿಯೊವನ್ನು ವೀಕ್ಷಿಸಲು ಮೇಲಿನ ಚಿತ್ರವನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ)_

ಈ ವಿಭಾಗದಲ್ಲಿ ಹಲವು ಪಾಠಗಳಿವೆ:

- **1 ನಿಮ್ಮ ಮೊದಲ ಸರ್ವರ್**, ಈ ಮೊದಲ ಪಾಠದಲ್ಲಿ, ನೀವು ನಿಮ್ಮ ಮೊದಲ ಸರ್ವರ್ ಅನ್ನು ರಚಿಸುವ ಮತ್ತು ಅದನ್ನು ಇನ್ಸ್‌പೆಕ್ಟರ್ ಸಾಧನದಿಂದ ಪರಿಶೀಲಿಸುವುದನ್ನು ಕಲಿಯುತ್ತೀರಿ, ಇದು ನಿಮ್ಮ ಸರ್ವರ್ ಅನ್ನು ಪರೀಕ್ಷಿಸಲು ಮತ್ತು ಡಿಬಗ್ ಮಾಡಲು ಅಮೂಲ್ಯವಾದ ವಿಧಾನ, [ಪಾಠಕ್ಕೆ](01-first-server/README.md)

- **2 ಕ್ಲೈಂಟ್**, ಈ ಪಾಠದಲ್ಲಿ, ನೀವು ನಿಮ್ಮ ಸರ್ವರ್‌ಗೆ ಸಂಪರ್ಕ ಸಾಧಿಸಲುವ ಕ್ಲೈಯಿಂಟ್ ಅನ್ನು ಬರೆಯುವುದು ಹೇಗೆ ಎಂಬುದನ್ನು ಕಲಿಯುತ್ತೀರಿ, [ಪಾಠಕ್ಕೆ](02-client/README.md)

- **3 LLM ಜೊತೆಗೆ ಕ್ಲೈಂಟ್**, ಕ್ಲೈಂಟ್ ಬರೆಯುವ ಇನ್ನೂ ಉತ್ತಮ ವಿಧಾನವೆಂದರೆ ಅದರಲ್ಲಿ LLM ಸೇರಿಸುವುದು, ಇದರಿಂದ ಅದು ನಿಮ್ಮ ಸರ್ವರ್ ಜೊತೆಗೆ "ನಿರ್ಣಯ" ಮಾಡಿಕೊಳ್ಳಬಹುದಾಗಿದೆ, [ಪಾಠಕ್ಕೆ](03-llm-client/README.md)

- **4 Visual Studio Code ನಲ್ಲಿ GitHub Copilot ಏಜೆಂಟ್ ಮೋಡ್ ಬಳಸಿ ಸರ್ವರ್ ಸೇವಿಸುವಿಕೆ**. ಇಲ್ಲಿ, ನಾವು ನಮ್ಮ MCP ಸರ್ವರ್ ಅನ್ನು Visual Studio Codeನಲ್ಲಿ ಒಡೆಯಲು ನೋಡುತ್ತಿದ್ದೇವೆ, [ಪಾಠಕ್ಕೆ](04-vscode/README.md)

- **5 stdio ಸಂಚಾರ ಸರ್ವರ್** stdio ಸಂಚಾರವು ಸ್ಥಳೀಯ MCP ಸರ್ವರ್-ಕ್ಲೈಂಟ್ ಸಂವಹನಕ್ಕಾಗಿ ಶಿಫಾರಸು ಮಾಡಲಾದ ಮಾನಕವಾಗಿದೆ, ಇದು ನಿರ್ಮಿತ ಪ್ರಕ್ರಿಯೆ ವಿಭಜನೆಯೊಂದಿಗೆ ಸುರಕ್ಷಿತ ಉಪಪ್ರಕ್ರಿಯೆ ಆಧಾರಿತ ಸಂವಹನವನ್ನು ಒದಗಿಸುತ್ತದೆ [ಪಾಠಕ್ಕೆ](05-stdio-server/README.md)

- **6 MCP ಜೊತೆಗೆ HTTP ಸ್ಟ್ರೀಮಿಂಗ್ (Streamable HTTP)**. ಮಾನಕ
	ದೂರಸ್ಥ ಸಂಚಾರದ ಬಗ್ಗೆ [MCP ವಿವರಣೆ 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http) ನಲ್ಲಿ ಕಲಿತುಕೊಳ್ಳಿ,
	ಹಿನ್ನೆಲೆ ಸೆಷನ್ ಆಧಾರಿತ ಅನುಷ್ಠಾನವನ್ನು ಸಹ ಈ ಪಾಠದಲ್ಲಿ ಸೇರಿಸಲಾಗಿದೆ.
	[ಪಾಠಕ್ಕೆ](06-http-streaming/README.md)

- **7 MCP ಕ್ಲೈಂಟ್ಸ್ ಮತ್ತು ಸರ್ವರ್ ಗಳನ್ನು ಉಪಯೋಗಿಸಿ ಮತ್ತು ಪರೀಕ್ಷಿಸಲು VSCode ಗೆ AI ಉಪಕರಣಗಳನ್ನು ಬಳಸುವುದು** [ಪಾಠಕ್ಕೆ](07-aitk/README.md)

- **8 ಪರೀಕ್ಷೆ**. ಇಲ್ಲಿ ನಾವು ವಿಶೇಷವಾಗಿ ನಮ್ಮ ಸರ್ವರ್ ಮತ್ತು ಕ್ಲೈಂಟ್ ಅನ್ನು ವಿಭಿನ್ನ ವಿಧಾನಗಳಲ್ಲಿ ಹೇಗೆ ಪರೀಕ್ಷಿಸಬಹುದು ಎಂದು ನೋಡುತ್ತೇವೆ, [ಪಾಠಕ್ಕೆ](08-testing/README.md)

- **9 ನಿಯೋಜನೆ**. ಈ ಅಧ್ಯಾಯವು ನಿಮ್ಮ MCP ಪರಿಹಾರಗಳನ್ನು ನಿಯೋಜಿಸುವ ವಿಭಿನ್ನ ವಿಧಾನಗಳನ್ನು ನೋಡುತ್ತದೆ, [ಪಾಠಕ್ಕೆ](09-deployment/README.md)

- **10 ಅತ್ಯಾಧುನಿಕ ಸರ್ವರ್ ಬಳಕೆ**. ಈ ಅಧ್ಯಾಯವು ಅತ್ಯಾಧುನಿಕ ಸರ್ವರ್ ಬಳಕೆಗಳನ್ನು ಒಳಗೊಂಡಿದೆ, [ಪಾಠಕ್ಕೆ](./10-advanced/README.md)

- **11 ಪ್ರಾಮಾಣೀಕರಣ**. ಈ ಅಧ್ಯಾಯವು ಸರಳ ಪ್ರಾಮಾಣೀಕರಣವನ್ನು ಸೇರಿಸುವ ವಿಧಾನಗಳನ್ನು ಒಳಗೊಂಡಿದ್ದು, ಮೂಲಭೂತ ಪ್ರಾಮಾಣೀಕರಣದಿಂದ JWT ಮತ್ತು RBAC ಬಳಕೆ ತನಕನ್ನು ಒಳಗೊಂಡಿದೆ. ನೀವು ಇಲ್ಲಿ ಪ್ರಾರಂಭಿಸಿ ನಂತರ ಅಧ್ಯಾಯ 5 ರ ಅತ್ಯಾಧುನಿಕ ವಿಷಯಗಳನ್ನು ನೋಡಬಹುದು ಮತ್ತು ಅಧ್ಯಾಯ 2 ರ ಶಿಫಾರಸುಗಳ ಮೂಲಕ ಹೆಚ್ಚುವರಿ ಭದ್ರತಾ ಸುಧಾರಣೆಯನ್ನು ಮಾಡಬಹುದು, [ಪಾಠಕ್ಕೆ](./11-simple-auth/README.md)

- **12 MCP ಹೋಸ್ಟ್‌ಗಳು**. ಪ್ರಸಿದ್ಧ MCP ಹೋಸ್ಟ್ ಕ್ಲೈಂಟ್‌ಗಳನ್ನು ವ್ಯವಸ್ಥೆ ಮಾಡುವುದು ಮತ್ತು ಬಳಸುವುದು, ಇದರಲ್ಲಿ Claude ಡೆಸ್ಕ್‌ಟಾಪ್, ಕರಸರ್, ಕ್ಲೈನ್ ಮತ್ತು ವಿಂಡ್ಸರಫ್ ಸೇರಿವೆ. ಸಂಚಾರ ವಿಧಗಳು ಹಾಗೂ ಸಮಸ್ಯೆಗಳ ಪರಿಹಾರಗಳನ್ನು ಕಲಿಯಿರಿ, [ಪಾಠಕ್ಕೆ](./12-mcp-hosts/README.md)

- **13 MCP ಇನ್ಸ್‌ಪೆಕ್ಟರ್**. MCP ಇನ್ಸ್‌ಪೆಕ್ಟರ್ ಸಾಧನವನ್ನು ಉಪಯೋಗಿಸಿ ನಿಮ್ಮ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಸಂವಾದಾತ್ಮಕವಾಗಿ ಡಿಬಗ್ ಮಾಡಿ ಮತ್ತು ಪರೀಕ್ಷಿಸಿ. ಸಾಧನಗಳು, ಸಂಪನ್ಮೂಲಗಳು ಮತ್ತು ಪ್ರೋಟೋಕಾಲ್ ಸಂದೇಶಗಳನ್ನು ಪರಿಹರಿಸುವುದನ್ನು ಕಲಿಯಿರಿ, [ಪಾಠಕ್ಕೆ](./13-mcp-inspector/README.md)


- **14 ಸ್ಯಾಂಪ್ಲಿಂಗ್**. `2025-11-25` ಗಾಗಿ ಪರಂಪರাগত ಸ್ಯಾಂಪ್ಲಿಂಗ್ ಪ್ರಿಮಿಟಿವ್ ಮತ್ತು
	ಹೊಸ ವಿನ್ಯಾಸಗಳನ್ನು ನೇರ LLM ಪ್ರೊವೈಡರ್ ಇಂಟಿಗ್ರೇಶನ್ ಗೆ ಹೇಗೆ ಮೈಸ್ಮಾಗಿಸುವುದು ಎಂಬುದನ್ನು ತಿಳಿಯಿರಿ. ಸ್ಯಾಂಪ್ಲಿಂಗ್
	MCP `2026-07-28` ರಂದು ನಿವೃತ್ತಿ ಹೊಂದಿದೆ. [ಪಾಠಕ್ಕೆ](./14-sampling/README.md)

- **15 MCP ಅಪ್ಲಿಕೇಶನ್‌ಗಳು**. UI ಸೂಚನೆಗಳೊಂದಿಗೆ ಉತ್ತರಿಸುವ MCP ಸರ್ವರ್‌ಗಳನ್ನು ನಿರ್ಮಿಸಿ, [ಪಾಠಕ್ಕೆ](./15-mcp-apps/README.md)

ಮಾದರಿ ಸಂಧರ್ಭ ಪ್ರೋಟೋಕಾಲ್ (MCP)ವು ಅಪನಾಯಿತ ಪ್ರೋಟೋಕಾಲ್ ಆಗಿದ್ದು LLMಗಳಿಗೆ ಅಪ್ಲಿಕೇಶನ್ಗಳು ಸಂಧರ್ಭವನ್ನು ಹೇಗೆ ಒದಗಿಸುತ್ತವೆ ಎಂಬುದನ್ನು ಸಾಮರಸ್ಯಗೊಳಿಸುತ್ತದೆ. MCP ಅನ್ನು AI ಅಪ್ಲಿಕೇಶನ್‌ಗಳಿಗೆ USB-C ಪೋರ್ಟ್ ಎಂದು ತಿಳಿದುಕೊಳ್ಳಿ - ಇದು ವಿಭಿನ್ನ ಡೇಟಾ ಮೂಲಗಳು ಮತ್ತು ಸಾಧನಗಳಿಗೆ AI ಮಾದರಿಗಳನ್ನು ಸಂಪರ್ಕಿಸುವ ಆಧುನಿಕ ವಿಧಾನವನ್ನು ಒದಗಿಸುತ್ತದೆ.

## ಕಲಿಕೆಯ ಗುರಿಗಳು

ಈ ಪಾಠದ ಕೊನೆಯಲ್ಲಿ, ನೀವು ಸಾಧ್ಯವಿರುವುದು:

- C#, ಜಾವಾ, ಪೈಥನ್, ಟೈಪ್ಸ್ಕ್ರಿಪ್ಟ್ ಮತ್ತು ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್‌ನಲ್ಲಿ MCP ಅಭಿವೃದ್ಧಿ ಪರಿಸರಗಳನ್ನು ಸ್ಥಾಪಿಸುವುದು
- ಕಸ್ಟಮ್ ವೈಶಿಷ್ಟ್ಯಗಳ (ಸಂಪನ್ಮೂಲಗಳು, ಪ್ರಾಂಪ್ಟ್‌ಗಳು ಮತ್ತು ಸಾಧನಗಳು)ೊಂದಿಗೆ ಬೇರ MCP ಸರ್ವರ್‌ಗಳನ್ನು ನಿರ್ಮಿಸಿ ಮತ್ತು ನಿಯೋಜಿಸುವುದು
- MCP ಸರ್ವರ್‌ಗಳಿಗೆ ಸಂಪರ್ಕಿಸುವ ಹೋಸ್ಟ್ ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ರಚಿಸುವುದು
- MCP ಅನುಷ್ಠಾನಗಳನ್ನು ಪರೀಕ್ಷಿಸಿ ದೋಷಮುಕ್ತಗೊಳಿಸುವುದು
- ಸಾಮಾನ್ಯ ಸೆಟಪ್ ಸವಾಲುಗಳನ್ನು ಮತ್ತು ಅವುಗಳ ಪರಿಹಾರಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವುದು
- ನಿಮ್ಮ MCP ಅನುಷ್ಠಾನಗಳನ್ನು ಜನಪ್ರಿಯ LLM ಸೇವೆಗಳಿಗೆ ಸಂಪರ್ಕಿಸುವುದು

## ನಿಮ್ಮ MCP ಪರಿಸರವನ್ನು ಸೆಟ್ ಮಾಡಲು

MCP ಜೊತೆ ಕೆಲಸ ಪ್ರಾರಂಭಿಸುವ ಮುನ್ನ, ನಿಮ್ಮ ಅಭಿವೃದ್ಧಿ ಪರಿಸರವನ್ನು ತಯಾರಿಸುವುದು ಮತ್ತು ಮೂಲ ಕಾರ್ಯಪ್ರವಾಹವನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವುದು ಮಹತ್ವದ್ದು. ಸರಳ ಆರಂಭಕ್ಕಾಗಿ ಈ ವಿಭಾಗ ನಿಮ್ಮನ್ನು ಮುಖ್ಯ ಅವಶ್ಯಕತೆಗಳ ಮೂಲಕ ಮಾರ್ಗದರ್ಶಿಸುತ್ತದೆ.

### ಪೂರ್ವಾಪೇಕ್ಷಿತಗಳು

MCP ಅಭಿವೃದ್ಧಿಗೆ ಕೈ ಹಾಕುವ ಮೊದಲು, ನಿಮಗೆ ಇದ್ದವು ಹೇಗಿದೆ ಎಂದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ:

- **ಅಭಿವೃದ್ಧಿ ಪರಿಸರ**: ನಿಮ್ಮ ಆಯ್ಕೆಮಾಡಿದ ಭಾಷೆಗೆ (C#, ಜಾವಾ, ಪೈಥನ್, ಟೈಪ್ಸ್ಕ್ರಿಪ್ಟ್ ಅಥವಾ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್)
- **IDE/ಎಡಿಟರ್**: Visual Studio, Visual Studio Code, IntelliJ, Eclipse, PyCharm ಅಥವಾ ಯಾವುದೇ ಆಧುನಿಕ ಕೋಡ್ ಎಡಿಟರ್
- **ಪ್ಯಾಕೇಜ್ ಮ್ಯಾನೇಜರ್‌ಗಳು**: NuGet, Maven/Gradle, pip ಅಥವಾ npm/yarn
- **API ಕೀಲಿಗಳು**: ನೀವು ಬಳಸಲಿರುವ ಯಾವುದೇ AI ಸೇವೆಗಳಿಗೆ ваши 호스트 ಅಪ್ಲಿಕೇಶನ್‌ಗಳಲ್ಲಿ


### ಅಧಿಕೃತ SDKಗಳು

ಮುಂದಿನ ಅಧ್ಯಾಯಗಳಲ್ಲಿ ನೀವು ಪೈಥನ್, ಟೈಪ್ಸ್ಕ್ರಿಪ್ಟ್,
ಜಾವಾ ಮತ್ತು .NET ಬಳಸಿ ನಿರ್ಮಿಸಲಾದ ಪರಿಹಾರಗಳನ್ನು ನೋಡಿರುತ್ತೀರಿ. ಇಲ್ಲಿ ಅಧಿಕೃತ SDKಗಳ ಮಾಹಿತಿ ಇದೆ.

MCP `2026-07-28` ಗೆ SDK ಬೆಂಬಲವು ಭಾಷೆಗಳ ಪ್ರಕಾರ ಸ್ವತಂತ್ರವಾಗಿ ವಿಸ್ತಾರಗೊಳ್ಳುತ್ತಿದೆ.
ಉದಾಹರಣೆಯನ್ನು ಚಾಲನೆಗೊಳಿಸುವ ಮೊದಲು, ಅದರ ಪ್ಯಾಕೇಜ್ ಆವೃತ್ತಿ ಮತ್ತು SDK ಬಿಡುಗಡೆ ಸುತ್ತಳಿಕೆಗಳ ಪೂರಕವಾಗಿ ಪರಿಶೀಲಿಸಿ
ಬೆಂಬಲಿತ ಪ್ರೋಟೋಕಾಲ್ ಪರಿಷ್ಕರಣೆಗಳನ್ನು. ನೋಡಿ
[ಅಧಿಕೃತ SDK ಪಟ್ಟಿ](https://modelcontextprotocol.io/docs/sdk):
- [C# SDK](https://github.com/modelcontextprotocol/csharp-sdk) - ಮೈಕ್ರೋಸಾಫ್ಟ್ ಜೊತೆಗಾರಿಕೆಯಿಂದ ನಿರ್ವಹಿಸಲಾಗುತ್ತಿದೆ
- [Java SDK](https://github.com/modelcontextprotocol/java-sdk) - Spring AI ಜೊತೆಗಾರಿಕೆಯಿಂದ ನಿರ್ವಹಿಸಲಾಗುತ್ತಿದೆ
- [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) - ಅಧಿಕೃತ TypeScript ಅನುಷ್ಠಾನ
- [Python SDK](https://github.com/modelcontextprotocol/python-sdk) - ಅಧಿಕೃತ ಪೈಥಾನ್ ಅನುಷ್ಠಾನ (FastMCP)
- [Kotlin SDK](https://github.com/modelcontextprotocol/kotlin-sdk) - ಅಧಿಕೃತ ಕೊಟ್ಲಿನ್ ಅನುಷ್ಠಾನ
- [Swift SDK](https://github.com/modelcontextprotocol/swift-sdk) - Loopwork AI ಜೊತೆಗಾರಿಕೆಯಿಂದ ನಿರ್ವಹಿಸಲಾಗುತ್ತಿದೆ
- [Rust SDK](https://github.com/modelcontextprotocol/rust-sdk) - ಅಧಿಕೃತ ರಸ್ಟ್ ಅನುಷ್ಠಾನ
- [Go SDK](https://github.com/modelcontextprotocol/go-sdk) - ಅಧಿಕೃತ Go ಅನುಷ್ಠಾನ

## ಮುಖ್ಯ ವಿಚಾರಣೆಗಳು

- ಭಾಷೆ-ನಿರ್ದಿಷ್ಟ SDKಗಳೊಂದಿಗೆ MCP ಅಭಿವೃದ್ಧಿ ಪರಿಸರವನ್ನು ಸುಲಭವಾಗಿ ಸ್ಥಾಪಿಸಬಹುದಾಗಿದೆ
- MCP ಸರ್ವರ್‌ಗಳನ್ನು ಕಟ್ಟುವುದು ಸ್ಪಷ್ಟ ಮಾದರಿಯೊಂದಿಗೆ ಸಾಧನಗಳನ್ನು ರಚಿಸಿ ನೋಂದಾಯಿಸುವುದನ್ನು ಒಳಗೊಂಡಿದೆ

- ಎಂಸಿಪಿ ಕ್ಲೈಯಿಂಟ್‌‌‌ಗಳು ವಿಸ್ತೃತ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಬಳಸಿಕೊಳ್ಳಲು ಸರ್ವರ್‌ಗಳಿಗೆ ಮತ್ತು ಮಾದರಿಗಳಿಗೆ ಸಂಪರ್ಕಿಸುತ್ತವೆ
- ಪರೀಕ್ಷೆ ಮತ್ತು ಡಿಬಗ್‌ ಮಾಡುವುದು ವಿಶ್ವಾಸಾರ್ಹ ಎಂಸಿಪಿ ಅನುಷ್ಠಾನಗಳಿಗಾಗಿ ಅವಶ್ಯಕ
- ನಿಯೋಜನೆ ಆಯ್ಕೆಗಳು ಸ್ಥಳೀಯ ಅಭಿವೃದ್ಧಿಯಿಂದ ಮেঘಾಧಾರಿತ ಪರಿಹಾರಗಳವರೆಗೆ ಇರುತ್ತವೆ
