# MCP ಸರ್ವರ್‌ಗಳನ್ನು ನಿಯೋಜಿಸುವುದು

> [!NOTE]
> `/sse` ಎಂಡ್‌ಪಾಯಿಂಟ್ ಬಳಸುವ ಸಂರಚನಾ ಉದಾಹರಣೆಗಳು ಪುರಾತನ HTTP+SSE 
> ಸಾರಣಿಯನ್ನು ಗುರಿಯಾಗಿಸುತ್ತವೆ. MCP `2026-07-28` ದೂರಸ್ಥ ಸರ್ವರ್‌ಗಳು ಸಾಮಾನ್ಯವಾಗಿ `/mcp` 
> ಮುಂತಾದ ಸರ್ವರ್-ನಿಗದಿತ ಎಂಡ್‌ಪಾಯಿಂಟ್‌ನಲ್ಲಿ Streamable HTTP ಬಳಸುತ್ತವೆ.

ನಿಮ್ಮ MCP ಸರ್ವರ್ ಅನ್ನು ನಿಯೋಜಿಸುವುದರಿಂದ ಇತರರು ನೀವು ಬಳಕೆಯಲ್ಲದ ಪರಿಸರದಿಂದ ಅದ್ರವರನ್ನು ತಲುಪಬಹುದು. ನಿಮ್ಮ ಅಗತ್ಯಗಳಿಗೆ ಅನುಗುಣವಾಗಿ, ಅಳೆಮಟ್ಟ, ವಿಶ್ವಾಸಾರ್ಹತೆ ಮತ್ತು ನಿರ್ವಹಣೆಗೆ ಅನುಕೂಲಕರತೆಗಾಗಿ ಹಲವು ನಿಯೋಜನೆ ತಂತ್ರಗಳನ್ನು ಪರಿಗಣಿಸಬಹುದು. ಕೆಳಗೆ ನೀವು ಸ್ಥಳೀಯ, ಕೊಂಟೈನರ್‌ಗಳಲ್ಲಿ ಮತ್ತು ಮೋಘದಲ್ಲಿ MCP ಸರ್ವರ್‌ಗಳನ್ನು ನಿಯೋಜಿಸುವ ಮಾರ್ಗದರ್ಶನವನ್ನು ಕಾಣಲಿದ್ದೀರಿ.

## ಅವಲೋಕನ

ಈ ಪಾಠವು ನಿಮ್ಮ MCP ಸರ್ವರ್ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ಹೇಗೆ ನಿಯೋಜಿಸುವುದನ್ನು ಒಳಗೊಂಡಿದೆ.

## ಕಲಿಕೆ ಗುರಿಗಳು

ಈ ಪಾಠದ ಕೊನೆಯಲ್ಲಿ, ನೀವು ಕೆಳಕಂಡವುಗಳನ್ನು ಮಾಡಲು ಸಾಧ್ಯವಾಗುತ್ತದೆ:

- ವಿಭಿನ್ನ ನಿಯೋಜನೆ ವಿಧಾನಗಳನ್ನು ಮೌಲ್ಯಮಾಪನ ಮಾಡುವುದು.
- ನಿಮ್ಮ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ನಿಯೋಜಿಸುವುದು.

## ಸ್ಥಳೀಯ ಅಭಿವೃದ್ಧಿ ಮತ್ತು ನಿಯೋಜನೆ

ನಿಮ್ಮ ಸರ್ವರ್ ಬಳಕೆದಾರರ ಯಂತ್ರದಲ್ಲಿ ನಡೆಯಲು ಉದ್ದೇಶಿತವಾಗಿದೆ ಎಂದಾದರೆ, ನೀವು ಕೆಳಕಂಡ ಹಂತಗಳನ್ನು ಅನುಸರಿಸಬಹುದು:

1. **ಸರ್ವರ್ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ**. ನೀವು ಸರ್ವರ್ ಅನ್ನು ಬರೆಯದಿದ್ದರೆ, ಮೊದಲು ಅದನ್ನು ನಿಮ್ಮ ಯಂತ್ರಕ್ಕೆ ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ.
1. **ಸರ್ವರ್ ಪ್ರಕ್ರಿಯೆಯನ್ನು ಪ್ರಾರಂಭಿಸಿ**: ನಿಮ್ಮ MCP ಸರ್ವರ್ ಅಪ್ಲಿಕೇಶನ್ ಅನ್ನು ರನ್ ಮಾಡಿ

SSE ಗೆ (stdio ಪ್ರಕಾರ ಸರ್ವರ್‌ಗೆ ಅವಶ್ಯಕವಿಲ್ಲ)

1. **ನೆಟ್ವರ್ಕಿಂಗ್ ಮೋಜುಗೊಳಿಸಿ**: ಸರ್ವರ್ ನಿರೀಕ್ಷಿತ ಪೋರ್ಟ್‌ನಲ್ಲಿ ಎಲ್ಲಾ ಬಳಕೆದಾರರಿಗೆ ಲಭ್ಯವಿರುವಂತೆ ಮಾಡಿ
1. **ಗ್ರಾಹಕರನ್ನು ಸಂಪರ್ಕಿಸಿ**: `http://localhost:3000` ಮುಂತಾದ ಸ್ಥಳೀಯ ಸಂಪರ್ಕ URLs ಬಳಸಿ

## ಮೋಘ ನಿಯೋಜನೆ

MCP ಸರ್ವರ್‌ಗಳನ್ನು ವಿವಿಧ ಮೋಘ ವೇದಿಕೆಗಳಿಗೆ ನಿಯೋಜಿಸಬಹುದು:

- **ಸರ್ವರ್ ಇಲ್ಲದ ಕಾರ್ಯಗಳು**: ತೂಕಹೀನ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಸರ್ವರ್ ಇಲ್ಲದ ಕಾರ್ಯಗಳಾಗಿ ನಿಯೋಜಿಸಿ
- **ಕಂಟೈನರ್ ಸೇವೆಗಳು**: Azure Container Apps, AWS ECS, ಅಥವಾ Google Cloud Run ಮುಂತಾದ ಸೇವೆಗಳನ್ನು ಬಳಸಿ
- **ಕ್ಯುಬರ್‍ನೇಟಿಸ್**: MCP ಸರ್ವರ್‌ಗಳನ್ನು ಕ್ಯುಬರ್‍ನೇಟಿಸ್ ಕ್ಲಸ್ಟರ್‌ಗಳಲ್ಲಿ ಹೆಚ್ಚಿನ ಲಭ್ಯತೆಯಿಗಾಗಿ ನಿಯೋಜಿಸಿ ಮತ್ತು ನಿರ್ವಹಿಸಿ

### ಉದಾಹರಣೆ: Azure Container Apps

Azure Container Apps MCP ಸರ್ವರ್‌ಗಳ ನಿಯೋಜನೆಯನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ. ಇದು ಇನ್ನೂ ಪ್ರಗತಿ ಮಧ್ಯದಲ್ಲಿದ್ದು ಪ್ರಸ್ತುತ SSE ಸರ್ವರ್‌ಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ.

ನೀವು ಹೀಗೆ ಮಾಡಬಹುದು:

1. ಒಂದು ರೆಪೋ ಕ್ಲೋನ್ ಮಾಡಿ:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. ವೀಕ್ಷಣೆಗೆ ಸ್ಥಳೀಯವಾಗಿ ರನ್ ಮಾಡಿ:

  ```sh
  uv venv
  uv sync

  # ಲಿನಕ್ಸ್ನ/ಮ್ಯಾಕ್‌ಒಎಸ್
  export API_KEYS=<AN_API_KEY>
  # ವಿಂಡೋಸ್
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. ಅದನ್ನು ಸ್ಥಳೀಯವಾಗಿ ಪ್ರಯತ್ನಿಸಲು, *.vscode* ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ *mcp.json* ಫೈಲ್ ರಚಿಸಿ ಮತ್ತು ಕೆಳಗಿನ ವಿಷಯವನ್ನು ಸೇರಿಸಿ:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  SSE ಸರ್ವರ್ ಪ್ರಾರಂಭವಾದ ನಂತರ, ನೀವು JSON ಫೈಲಿನಲ್ಲಿ ಪ್ಲೇ ಐಕಾನ್ ಕ್ಲಿಕ್ ಮಾಡಬಹುದು, ಈಗ GitHub Copilot ಮೂಲಕ ಸರ್ವರ್‌ನ ಸಾಧನಗಳನ್ನು ನೋಡಬಹುದು, ಸಾಧನ ಐಕಾನ್ ನೋಡಿ.

1. ನಿಯೋಜಿಸಲು, ಕೆಳಗಿನ ಕಮಾಂಡ್ ಅನ್ನು ರನ್ ಮಾಡಿ:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

ಹೀಗಾಗಿದೆ, ನೀವು ಇನ್ನುಳಿದ ಹಂತಗಳ ಮೂಲಕ ಸ್ಥಳೀಯವಾಗಿ ಅಥವಾ Azureಗೆ ನಿಯೋಜಿಸಬಹುದು.
