# ಕಾರ್ಯಾತ್ಮಕ ಅನುಷ್ಠಾನ

[![ಯಥಾರ್ಥ ಸಾಧನಗಳು ಮತ್ತು ಕಾರ್ಯವಿಧಾನಗಳೊಂದಿಗೆ MCP ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ಹೇಗೆ ನಿರ್ಮಿಸುವುದು, ಪರೀಕ್ಷಿಸುವುದು ಮತ್ತು ನಿಯೋಜಿಸುವುದು](../../../translated_images/kn/05.64bea204e25ca891.webp)](https://youtu.be/vCN9-mKBDfQ)

_(ಈ ಪಾಠದ ವೀಡಿಯೊವನ್ನು ವೀಕ್ಷಿಸಲು ಮೇಲಿನ ಚಿತ್ರವನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ)_

ಕಾರ್ಯಾತ್ಮಕ ಅನುಷ್ಠಾನವು ಮಾದರಿ ಪ್ರಾಸಂಗಿಕ ಪ್ರೋಟೋಕಾಲ್ (MCP) ಶಕ್ತಿಯನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ತೋರಿಸುತ್ತದೆ. MCP ಹಿಂದಿನ ಸಿದ್ಧಾಂತರ ಮತ್ತು ವಾಸ್ತುಶಾಸ್ತ್ರವನ್ನು ತಿಳಿದುಕೊಳ್ಳುವುದು ಮಹತ್ವದಾದರೂ, ನಿಜವಾದ ಮೌಲ್ಯವು ಈ ತತ್ತ್ವಗಳನ್ನು ನೂತನ ಪ್ರಪಂಚ ಸಮಸ್ಯೆಗಳನ್ನು ಪರಿಹರಿಸುವ ಪರಿಹಾರಗಳನ್ನು ನಿರ್ಮಿಸುವ, ಪರೀಕ್ಷಿಸುವ ಮತ್ತು ನಿಯೋಜಿಸುವ ಸಂದರ್ಭದಲ್ಲಿ ವ್ಯಕ್ತವಾಗುತ್ತದೆ. ಈ ಅಧ್ಯಾಯವು ವಿಚಾರಾಧಾರಿತ ಜ್ಞಾನ ಮತ್ತು ಕೈಯಿಂದ ಮಾಡಲಾದ ಅಭಿವೃದ್ಧಿಯ ನಡುವೆ ಸೇತುವೆಯನ್ನು ನಿರ್ಮಿಸುತ್ತದೆ, MCP ಆಧಾರಿತ ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ಜೀವಂತಗೊಳಿಸುವ ಪ್ರಕ್ರಿಯೆಯನ್ನು ಮಾರ್ಗದರ್ಶಿಸುತ್ತದೆ.

ನೀವು ಬುದ್ಧಿವಂತ ಸಹಾಯಕರನ್ನು ಅಭಿವೃದ್ಧಿಪಡಿಸುತ್ತಿದ್ದೀರಾ, ವ್ಯವಹಾರ ಕಾರ್ಯಪ್ರವಾಹಗಳಲ್ಲಿ AI ಅನ್ನು ಸಂಯೋಜಿಸುತ್ತಿದ್ದೀರಾ ಅಥವಾ ಡೇಟಾ ಪ್ರಕ್ರಿಯೆಗಾಗಿ ಕಸ್ಟಮ್ ಸಾಧನಗಳನ್ನು ನಿರ್ಮಿಸುತ್ತಿದ್ದೀರಾ, MCP ಗಾತ್ರಕೂಡಿ ಬಲವಾದ ಭೂಮಿಕೆಯನ್ನು ಒದಗಿಸುತ್ತದೆ. ಅದರ ಭಾಷಾ ಸ್ವಾತಂತ್ರ್ಯ ವಿನ್ಯಾಸ ಮತ್ತು ಜನಪ್ರಿಯ ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಭಾಷೆಗಳ ಅಧಿಕೃತ SDKಗಳು ವಿವಿಧ ರೀತಿಯ ಡೆವೆಲಪರ್‌ಗಳಿಗೆ ಲಭ್ಯವಿದೆ. ಈ SDKಗಳನ್ನು ಬಳಸಿ, ನೀವು ವೇಗವಾಗಿ ಪ್ರೋಟೋಟೈಪ್ ಮಾಡಬಹುದು, ತಿದ್ದಿಸಬಹುದು ಮತ್ತು ವಿವಿಧ ವೇದಿಕೆ ಮತ್ತು ಪರಿಸರಗಳಲ್ಲಿ ನಿಮ್ಮ ಪರಿಹಾರಗಳನ್ನು ವಿಸ್ತರಿಸಬಹುದು.

ಮುಂದಿನ ವಿಭಾಗಗಳಲ್ಲಿ, ನೀವು C#, ಜಾವಾ (Spring ನೊಂದಿಗೆ), ಟೈಪ್‌ಸ್ಕ್ರಿಪ್ಟ್, ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಮತ್ತು ಪೈಥಾನ್‌ನಲ್ಲಿ MCP ಅನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸುವ ವಿಶೇಷ ಉದಾಹರಣೆಗಳು, ಮಾದರಿ ಕೋಡ್ ಮತ್ತು ನಿಯೋಜನೆ ತಂತ್ರಗಳು ಕಾಣುತ್ತವೆ. ನೀವು ನಿಮ್ಮ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಡಿಬಗ್ ಮಾಡುವುದು ಮತ್ತು ಪರೀಕ್ಷಿಸುವುದು, APIಗಳನ್ನು ನಿರ್ವಹಿಸುವುದು ಮತ್ತು ಅಜೂರ್ ಬಳಸಿ ಪರಿಹಾರಗಳನ್ನು ಮೋಘದಲ್ಲಿ ನಿಯೋಜಿಸುವುದು ಸಹ ಕಲಿಯೋಿರಿ. ಈ ಕೈಯಿಂದ ಮಾಡಲಾದ ಸಂಪನ್ಮೂಲಗಳು ನಿಮ್ಮ ಅಧ್ಯಯನವನ್ನು ತ್ವರಿತಗೊಳಿಸಲು ಮತ್ತು ವಿಶ್ವಾಸದಿಂದ ಮುಟ್ಟಲು ತಯಾರಾದ MCP ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ನಿರ್ಮಿಸಲು ಸಹಾಯ ಮಾಡಲಿವೆ.

## ಅವಲೋಕನ

ಈ ಪಾಠವು ಹಲವಾರು ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಭಾಷೆಗಳಲ್ಲಿ MCP ಅನುಷ್ಠಾನದ ಕಾರ್ಯಾತ್ಮಕ ಅಂಶಗಳನ್ನು ಗುರಿಯಾಗಿಟ್ಟುಕೊಂಡಿದೆ. ನಾವು C#, ಜಾವಾ Springೊಂದಿಗೆ, ಟೈಪ್‌ಸ್ಕ್ರಿಪ್ಟ್, ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಮತ್ತು ಪೈಥಾನ್‌ನಲ್ಲಿ MCP SDKಗಳನ್ನು ಬಳಸುವುದನ್ನು ಪರೀಕ್ಷಿಸುತ್ತೇವೆ, ಬಲವಾದ ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ನಿರ್ಮಿಸುವುದು, MCP ಸರ್ವರ್‌ಗಳನ್ನು ಡಿಬಗ್ ಮತ್ತು ಪರೀಕ್ಷಿಸುವುದು, ಮತ್ತು ಮರುಬಳಕೆ ಹುಡುಕಲು ಸಂಪನ್ಮೂಲಗಳು, ಪ್ರಂಪ್ಟ್ಗಳು, ಮತ್ತು ಸಾಧನಗಳನ್ನು ರಚಿಸುವುದು.

## ಕಲಿಕೆಯ ಗುರಿಗಳು

ಈ ಪಾಠದ ಕೊನೆಯಲ್ಲಿ, ನೀವು ಈ ಕೆಳಕಂಡವುಗಳನ್ನು ಮಾಡಲು ಸಾಧ್ಯವಾಗುತ್ತದೆ:

- ವಿವಿಧ ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಭಾಷೆಗಳಲ್ಲಿ ಅಧಿಕೃತ SDK ಗಳ ಬಳಸಿ MCP ಪರಿಹಾರಗಳನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸುವುದು
- ಕ್ರಮಬದ್ಧವಾಗಿ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಡಿಬಗ್ ಮತ್ತು ಪರೀಕ್ಷಿಸುವುದು
- ಸರ್ವರ್ ವೈಶಿಷ್ಟ್ಯಗಳನ್ನು (ಸಂಪನ್ಮೂಲಗಳು, ಪ್ರಂಪ್ಟ್ಗಳು, ಮತ್ತು ಸಾಧನಗಳು) ರಚಿಸಿ ಹಾಗೂ ಬಳಸುವುದು
- ಸಂಕೀರ್ಣ ಕಾರ್ಯಗಳಿಗಾಗಿ ಪರಿಣಾಮಕಾರಿ MCP ಕಾರ್ಯವಿಧಾನಗಳನ್ನು ವಿನ್ಯಾಸ ಮಾಡುವುದು
- ಕಾರ್ಯಕ್ಷಮತೆ ಮತ್ತು ವಿಶ್ವಾಸಾರ್ಹತೆಗಾಗಿ MCP ಅನುಷ್ಠಾನಗಳನ್ನು ಆಪ್ಟಿಮೈಸ್ ಮಾಡುವುದು

## ಕೋರ್ ಸರ್ವರ್ ವೈಶಿಷ್ಟ್ಯಗಳು

MCP ಸರ್ವರ್ಗಳು ಈ ವೈಶಿಷ್ಟ್ಯಗಳ ಯಾವುದೇ ಸಂಯೋಜನೆಯನ್ನು ಜಾರಿಗೆ ತಂದಬಹುದು:

### ಸಂಪನ್ಮೂಲಗಳು

ಬಳಕೆದಾರರು ಅಥವಾ AI ಮಾದರಿ ಉಪಯೋಗಿಸಲು ಪರಿಸರ ಮತ್ತು ಡೇಟಾವನ್ನು ನೀಡುವ ಸಂಪನ್ಮೂಲಗಳು:

- ಡಾಕ್ಯುಮೆಂಟ್ ಗೌಡ್
- ಜ್ಞಾನ ಆಧಾರಗಳು
- ರಚನೆಗೈದ ಡೇಟಾ ಮೌಲ್ಯಿಸ್ಥಾನಗಳು
- ಫೈಲ್ ಸಿಸ್ಟಂಗಳ

### ಪ್ರಾಂಪ್ಟ್‌ಗಳು

ಬಳಕೆದಾರರಿಗಾಗಿ ಟೆಂಪ್ಲೇಟು ಮಾಡಲಾದ ಸಂದೇಶಗಳು ಮತ್ತು ಕಾರ್ಯಪ್ರವಾಹಗಳು:

- ಪೂರ್ವ ನಿರ್ವಾಚಿತ ಸಂವಾದ ಟೆಂಪ್ಲೇಟುಗಳು
- ಮಾರ್ಗದರ್ಶಿತ ಸಂವಹನ ಮಾದರಿಗಳು
- ವಿಶೇಷ ಸಂವಾದ ರಚನೆಗಳು

### ಉಪಕರಣಗಳು

AI ಮಾದರಿ ಕಾರ್ಯಗತಗೊಳಿಸಲು ಉಪಕರಣಗಳಾಗಿರುವ ಕಾರ್ಯಗಳು:

- ಡೇಟಾ ಪ್ರಕ್ರಿಯೆ ಯೂಟಿಲಿಟಿಗಳು
- ಬಾಹ್ಯ API ಸಮ್ಮಿಲನಗಳು
- ಗಣನಾ ಸಾಮರ್ಥ್ಯಗಳು
- ಹುಡುಕಾಟ ಕಾರ್ಯಕ್ಷಮತೆ

## ಮಾದರಿ ಜಾರಿಗೆ: C# ಜಾರಿಗೆ

ಅಧಿಕೃತ C# SDK ಗೌಡ್‌ನಲ್ಲಿ MCP ವಿವಿಧ ಅಂಶಗಳನ್ನು ಬಿಡಿಸಿ ಪ್ರದರ್ಶಿಸುವ ಹಲವಾರು ಮಾದರಿ ಜಾರಿಗೆಗಳಿವೆ:

- **ಮೂಲ MCP ಕ್ಲೈಂಟ್**: MCP ಕ್ಲೈಂಟ್ ರಚಿಸುವ ಮತ್ತು ಉಪಕರಣಗಳನ್ನು ಕರೆ ಮಾಡುವ ಸರಳ ಉದಾಹರಣೆ
- **ಮೂಲ MCP ಸರ್ವರ್**: ಮೂಲ ಉಪಕರಣ ನೋಂದಣಿ ಜೊತೆಗೆ ಕನಿಷ್ಟ ಸರ್ವರ್ ಜಾರಿಗೊಳಿಸುವಿಕೆ
- **ಅತ್ಯಾಧುನಿಕ MCP ಸರ್ವರ್**: ಉಪಕರಣ ನೋಂದಣಿ, ಪ್ರಮಾಣೀಕರಣ ಮತ್ತು ದೋಷ ನಿರ್ವಹಣೆಗಳೊಂದಿಗೆ ಸಂಪೂರ್ಣ ಕಾರ್ಯಸಾಧ್ಯ ಸರ್ವರ್
- **ASP.NET ಏಕೀಕರಣ**: ASP.NET ಕೋರ್ ಜೊತೆಗೆ ಏಕೀಕರಣ ತೋರಿಸುವ ಉದಾಹರಣೆಗಳು
- **ಉಪಕರಣ ಜಾರಿಗೆ ಮಾದರಿಗಳು**: ವಿವಿಧ ಸಂಕೀರ್ಣತೆಯ ಮಟ್ಟಗಳೊಂದಿಗೆ ಉಪಕರಣಗಳನ್ನು ಜಾರಿಗೊಳಿಸುವ ವಿವಿಧ ಮಾದರಿಗಳು

MCP C# SDK ಪೂರ್ವावलೋಕನದಲ್ಲಿದ್ದು APIಗಳು ಬದಲಾಯಿಸಬಹುದು. SDK ಬೆಳವಣಿಗೆಯೊಂದಿಗೆ ನಾವು ಈ ಬ್ಲಾಗ್ ಅನ್ನು ನಿರಂತರವಾಗಿ ನವೀಕರಿಸುತ್ತೇವೆ.

## રિમોટ MCP સર્વર Azure પર ડેપ્લોય કરો

જે નમૂનાના આપણે પહેલાથી ઉલ્લેખ કર્યો તે આપણે કેવી રીતે ડેપ્લોય કરી શકીએ તે જોઇએ:

1. રેપૉ ક્લોન કરો

    ```bash
    git clone https://github.com/Azure-Samples/remote-mcp-apim-functions-python.git
    cd remote-mcp-apim-functions-python
    ```

1. `Microsoft.App` રિસોર્સ પ્રોવાઇડરને રજીસ્ટર કરો.

   - જો તમે Azure CLI નો ઉપયોગ કરશો તો `az provider register --namespace Microsoft.App --wait` ચલાવો.
   - જો તમે Azure PowerShell નો ઉપયોગ કરશો તો `Register-AzResourceProvider -ProviderNamespace Microsoft.App` ચલાવો. થોડા સમય પછી તપાસો `(Get-AzResourceProvider -ProviderNamespace Microsoft.App).RegistrationState` કે રજીસ્ટ્રેશન પૂર્ણ થયું કે નહી.

1. આ [azd](https://aka.ms/azd) કમાન્ડ ચલાવો જે API મેનેજમેન્ટ સર્વિસ, ફંકશન એપ (કોડ સાથે) અને અન્ય જરૂરી Azure રિસોર્સ્સ પ્રોવિઝન કરશે

    ```shell
    azd up
    ```

    આ કમાન્ડ Azure પર તમામ ક્લાઉડ રિસોર્સસ ડિપ્લોય કરે તેવું હોવું જોઈએ

### MCP ઇન્સ્પેક્ટરના સાથે તમારા સર્વરનું પરીક્ષણ

1. **નવા ટર્મિનલ વિન્ડોમાં**, MCP ઇન્સ્પેક્ટર ઇન્સ્ટોલ કરો અને ચાલાવો

    ```shell
    npx @modelcontextprotocol/inspector
    ```

    તમને એવું ઈન્ટરફેસ જોવા મળશે:

    ![નોડ ઇન્સ્પેક્ટરને જોડો](../../../translated_images/kn/connect.141db0b2bd05f096.webp)

1. CTRL ક્લિક કરીને MCP ઇન્સ્પેક્ટર વેબ એપ લોડ કરો આ એપ દ્વારા પ્રદર્શિત URL (ઉદાહરણ તરીકે [http://127.0.0.1:6274/#resources](http://127.0.0.1:6274/#resources))
1. ટ્રાન્સપોર્ટ ટ્વાઇપ `SSE` સેટ કરો
1. URL તરીકે `azd up` પછી પ્રદર્શિત તમારા API મેનેજમેન્ટ SSE એન્ડપોઇન્ટ સેટ કરો અને **Connect** કરો:

    ```shell
    https://<apim-servicename-from-azd-output>.azure-api.net/mcp/sse
    ```

1. **લિસ્ટ ટૂલ્સ**.  ટૂલ પર ક્લિક કરો અને **ટૂલ ચલાવો**.  

જો બધા સ્ટેપ્સ સફળ રહ્યા હોય તો હવે તમે MCP સર્વર સાથે જોડાયેલા છો અને તમે ટૂલને કોલ કરી શક્યા છો.

## Azure માટે MCP સર્વર્સ

[Remote-mcp-functions](https://github.com/Azure-Samples/remote-mcp-functions-dotnet): આ રેપોઝિટરીઝ એઝ્યોર ફંક્શન્સ સાથે Python, C# .NET અથવા Node/TypeScript નો ઉપયોગ કરીને કસ્ટમ રિમોટ MCP (મોડલ કોન્ટેક્સ્ટ પ્રોટોકોલ) સર્વર્સ બનાવવા અને ડિપ્લોય કરવા માટે ઝડપી શરુઆતનો ટેમ્પલેટ છે.

નમૂના એક સંપૂર્ણ સોલ્યુશન આપે છે જે વિકાસકર્તાઓને નીમ્ન બાબતો કરવાની મંજૂરી આપે છે:

- સ્થાનિક રીતે બિલ્ડ અને ચલાવો: સ્થાનિક મશીન પર MCP સર્વર વિકસાવો અને ડિબગ કરો
- Azure પર ડિપ્લોય કરો: સરળ `azd up` કમાન્ડ વડે ક્લાઉડ પર સરળતાથી ડિપ્લોય કરો
- ક્લાયન્ટ તરફથી જોડાવો: વિવિધ ક્લાયંટ્સમાંથી MCP સર્વર સાથે જોડાવા માટે, જેમાં VS Code ના Copilot એજન્ટ મોડ અને MCP ઇન્સ્પેક્ટર ટૂલનો સમાવેશ થાય છે

### મુખ્ય ફીચર્સ

- ડિઝાઇન દ્વારા સુરક્ષા: MCP સર્વર કીઝ અને HTTPS દ્વારા સુરક્ષિત છે
- ઑથેન્ટિકેશન વિકલ્પો: બિલ્ટ-ઈન ઑથેન્ટિકેશન અને/અથવા API મેનેજમેન્ટને ઉપયોગ કરીને OAuth માટે સપોર્ટ આપે છે
- નેટવર્ક આઇસોલેશન: Azure વર્ચ્યુઅલ નેટવર્ક્સ (VNET) વડે નેટવર્ક આઇસોલેશન માટે મંજૂરી આપે છે
- સર્વરલેસ આર્કિટેક્ચર: કક્ષમ અને ઘટના-ચલિત અમલ માટે Azure ફંક્શન્સનો લાભ લે છે
- સ્થાનિક વિકાસ: વ્યાપક સ્થાનિક વિકાસ અને ડિબગિંગ સપોર્ટ
- સરળ ડિપ્લોયમેન્ટ: Azure માટે સરળિત અને સુવ્યવસ્થિત ડિપ્લોયમેન્ટ પ્રકિયા

રેપોઝિટરી તાત્કાલિક પ્રોડક્શન-પ્રસ্তুત MCP સર્વર અમલ માટે તમામ જરૂરી કોન્ફિગરેશન ફાઇલો, સોર્સ કોડ અને ઇન્ફ્રાસ્ટ્રક્ચર વ્યાખ્યા શામેલ કરે છે.

- [Azure Remote MCP Functions Python](https://github.com/Azure-Samples/remote-mcp-functions-python) - Azure Functions સાથે Python ઉપયોગ કરીને MCP નું નમૂનુ અમલ

- [Azure Remote MCP Functions .NET](https://github.com/Azure-Samples/remote-mcp-functions-dotnet) - Azure Functions સાથે C# .NET ઉપયોગ કરીને MCP નું નમૂનુ અમલ

- [Azure Remote MCP Functions Node/Typescript](https://github.com/Azure-Samples/remote-mcp-functions-typescript) - Azure Functions સાથે Node/TypeScript ઉપયોગ કરીને MCP નું નમૂનુ અમલ.

## મુખ્ય શીખσματα

- MCP SDKs મજબૂત MCP સોલ્યુશન્સ અમલવાશીલ બનાવવા માટે ભાષા-નિર્દિષ્ટ ટૂલ્સ પ્રદાન કરે છે
- ડિબગીંગ અને પરીક્ષણ પ્રક્રિયા વિશ્વસનીય MCP એપ્લિકેશન્સ માટે તાત્કાલિક છે
- પુનઃઉપયોગ યોગ્ય પ્રોમ્પ્ટ ટેમ્પ્લેટ્સ સતત AI ક્રિયાઓ માટે સક્ષમ કરે છે
- સુવ્યવસ્થિત વર્કફ્લોઝ અનેક ટૂલ્સનો ઉપયોગ કરીને જટિલ કાર્યોનું સંચાલન કરી શકે છે
- MCP સોલ્યુશન્સ અમલમાં લાવવા માટે સુરક્ષા, પ્રદર્શન અને ભૂલ સંભાળવાની વિચારણા જરૂરી છે

1. આ સમસ્યા ઉકેલવા માટે 3-4 ઉપયોગી ટૂલ્સ ઓળખો
2. કેવી રીતે આ ટૂલ્સ પરસ્પર ક્રિયા કરે છે તે બતાવતા વર્કફ્લો ડાયગ્રામ બનાવો
3. તમારી પસંદગીની ભાષામાં ટૂલમાંથી એકનું આધારભૂત સંસ્કરણ અમલમાં લાવો
4. એક પ્રોમ્પ્ટ ટેમ્પ્લેટ બનાવો જે મોડેલને અસરકારક રીતે તમારા ટૂલનો ઉપયોગ કરવાની મદદ કરે
