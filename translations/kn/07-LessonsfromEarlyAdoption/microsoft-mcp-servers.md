# 🚀 ಡೆವಲಪರ್ ಉತ್ಪಾದಕತೆ ಮಾರ್ಪಡಿಸುತ್ತಿರುವ 10 ಮೈಕ್ರೋಸಾಫ್ಟ್ MCP ಸರ್ವರ್ ಗಳು

## 🎯 ನೀವು ಈ ಮಾರ್ಗದರ್ಶಿಕೆಯಲ್ಲಿ ಕಲಿಯುವವುಗಳು

ಈ ವ್ಯವಹಾರಿಕ ಮಾರ್ಗದರ್ಶಿಕೆ ಡೆವಲಪರ್‌ಗಳು AI ಸಹಾಯಕರೊಂದಿಗೆ ಕೆಲಸ ಮಾಡುವ ರೀತಿಯನ್ನು ಕ್ರಿಯಾಶೀಲವಾಗಿ ಮಾರ್ಪಡಿಸುತ್ತಿರುವ 10 ಮೈಕ್ರೋಸಾಫ್ಟ್ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಪ್ರದರ್ಶಿಸುತ್ತದೆ. MCP ಸರ್ವರ್‌ಗಳು *ಮಾಡಬಹುದಾದ* ಸಂಗತಿಗಳನ್ನು ವಿವರಣೆ ಮಾಡುವ ಬದಲು, ನಾವು ಮೈಕ್ರೋಸಾಫ್ಟ್ ಮತ್ತು ಇತರಲ್ಲಿ ದೈನಂದಿನ ಅಭಿವೃದ್ಧಿ ಕಾರ್ಯವಾಹಕಗಳಲ್ಲಿ ಈಗಾಗಲೇ ನಿಜವಾದ ಪರಿಣಾಮ ನೀಡುತ್ತಿರುವ ಸರ್ವರ್‌ಗಳನ್ನು ತೋರಿಸುತ್ತೇವೆ.

ಈ ಮಾರ್ಗದರ್ಶಿಕೆಯಲ್ಲಿ ಪ್ರತಿಯೊಂದು ಸರ್ವರ್ ಅನ್ನು ನೈಜ ಜಾಗತಿಕ ಬಳಕೆ ಮತ್ತು ಡೆವಲಪರ್ ಪ್ರತಿಕ್ರಿಯೆಯ ಆಧಾರದಲ್ಲಿ ಆಯ್ದುಕೊಂಡಿದೆ. ನೀವು ಪ್ರತಿ ಸರ್ವರ್ ಏನು ಮಾಡುತ್ತದೆ ಎಂಬುದನ್ನು ಮಾತ್ರ ಅಲ್ಲದೆ ಅದು ಯಾಕಾಗಿ ಮುಖ್ಯವಿದೆ ಮತ್ತು ನಿಮ್ಮದೇ ಯೋಜನೆಗಳಲ್ಲಿ ಇದರಿಂದ ತುಂಬಾ ಲಾಭ ಪಡೆಯುವ ವಿಧಾನವನ್ನು ಕಂಡುಕೊಳ್ಳುತ್ತೀರಾ. ನೀವು MCP ಗೆ ಹೊಸವನು ಆಗಿದ್ದೀರಾ ಅಥವಾ ನಿಮ್ಮ ಹಳೆಯ ವ್ಯವಸ್ಥೆಯನ್ನು ವಿಸ್ತರಿಸಲು ಯತ್ನಿಸುತ್ತಿದ್ದೀರಾ, ಈ ಸರ್ವರ್‌ಗಳು ಮೈಕ್ರೋಸಾಫ್ಟ್ ಪರಿಸರದಲ್ಲಿ ಲಭ್ಯವಿರುವ ಅತ್ಯಂತ ವ್ಯವಹಾರಿಕ ಮತ್ತು ಪರಿಣಾಮಕಾರಿ ಸಾಧನಗಳನ್ನು ಪ್ರತಿನಿಧಿಸುತ್ತವೆ.

> **💡 ತ್ವರಿತ ಪ್ರಾರಂಭ ಸಲಹೆ**
>
> MCP ಗೆ ಹೊಸವನಾ? ಚಿಂತಿಸಬೇಡಿ! ಈ ಮಾರ್ಗದರ್ಶಿಕೆ ಪ್ರಾರಂಭಿಕರಿಗೆ ಅನುಕೂಲಕರವಾಗಿರುತ್ತದೆ. ನಾವು ಕಲಿಕೆ ಪ್ರಕ್ರಿಯೆಯಲ್ಲಿ ತತ್ವಗಳನ್ನು ವಿವರಿಸುತ್ತೇವೆ ಮತ್ತು ನೀವು ಯಾವಾಗಲೂ ನಮ್ಮ [MCP ಪರಿಚಯ](../00-Introduction/README.md) ಮತ್ತು [ಮೂಲತತ್ವಗಳು](../01-CoreConcepts/README.md) ಘಟಕಗಳಿಗೆ ಹಿಂತಿರುಗಬಹುದು.

## ಅವಲೋಕನ

ಈ ಸಮಗ್ರ ಮಾರ್ಗದರ್ಶಿಕೆ ಡೆವಲಪರ್‌ಗಳು AI ಸಹಾಯಕರೊಂದಿಗೆ ಮತ್ತು ಬಾಹ್ಯ ಸಾಧನಗಳೊಂದಿಗೆ ಸಂವಹನ ಮಾಡುವ ರೀತಿಯನ್ನು ಕ್ರಾಂತಿಕರವಾಗಿ ಬದಲಾಯಿಸುತ್ತಿರುವ 10 ಮೈಕ್ರೋಸಾಫ್ಟ್ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಅನ್ವೇಷಿಸುತ್ತದೆ. ಅಜೂರ್ ಸಂಪನ್ಮೂಲ ನಿರ್ವಹಣೆಯಿಂದ ದಾಖಲೆ ಪ್ರಕ್ರಿಯೆಗೆ, ಈ ಸರ್ವರ್‌ಗಳು ಸಾಧಾರಣ, ಉತ್ಪಾದಕತೆ ನೈವೇದ್ಯಕರ ಅಭಿವೃದ್ಧಿ ಕಾರ್ಯವಾಹಕಗಳನ್ನು ನಿರ್ಮಿಸಲು ಮಾದರಿ ಸಂತ್ರಸ್ತ ಪ್ರೋಟೋಕಾಲ್ ಶಕ್ತಿಯನ್ನು ತೋರಿಸುತ್ತವೆ.

## ಕಲಿಕೆಯ ಉದ್ದೇಶಗಳು

ಈ ಮಾರ್ಗದರ್ಶಿಕೆಯಿಂದ ನೀವು:
- MCP ಸರ್ವರ್‌ಗಳು ಹೇಗೆ ಡೆವಲಪರ್ ಉತ್ಪಾದಕತೆ ಹೆಚ್ಚಿಸುತ್ತವೆ ಎಂದು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವಿರಿ
- ಮೈಕ್ರೋಸಾಫ್ಟ್‌ನ ಅತ್ಯಂತ ಪರಿಣಾಮಕಾರಿ MCP ಸರ್ವರ್ ಜಾರಿಗೆ ಸಂಬಂಧಿಸಿದ ಮಾಹಿತಿ ಪಡೆಯುವಿರಿ
- ಪ್ರತಿ ಸರ್ವರ್‌ಗೆ ಸಂಬಂಧಿಸಿದ ವ್ಯವಹಾರಿಕ ಬಳಕೆಯ ಸಂದರ್ಭಗಳನ್ನು ಕಂಡುಹಿಡಿಯುವಿರಿ
- VS ಕೋಡ್ ಮತ್ತು ವಿವುಲ್ ಸ್ಟುಡಿಯೋದಲ್ಲಿ ಈ ಸರ್ವರ್‌ಗಳನ್ನು ಹೇಗೆ ಅನ್ನುಕಳಿಸಲು ಮತ್ತು ಸಂರಚಿಸಲು ತಿಳಿಯುವಿರಿ
- MCP ಪರಿಸರವನ್ನು ವಿಶ್ಲೇಪಿಸಿ ಭವಿಷ್ಯದ ದಿಕ್ಕುಗಳನ್ನು ಅನ್ವೇಷಿಸುವಿರಿ

## 🔧 MCP ಸರ್ವರ್‌ಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವುದು: ಪ್ರಾರಂಭಿಕರಿಗೆ ಮಾರ್ಗದರ್ಶಿಕೆ

### MCP ಸರ್ವರ್‌ಗಳು ಎಂದಾಗೇನು?

ಮಾದರಿ ಸಂತ್ರಸ್ತ ಪ್ರೋಟೋಕಾಲ್ (MCP) ಗೆ ಹೊಸವನೇ ಆಗಿದ್ದರೆ, ನೀವು ಅಲೋಚಿಸಬಹುದು: "ಎಂCP ಸರ್ವರ್ ಎಂದು ನಿಜವಾಗಿ ಏನು ಅರ್ಥ? ಇದರಿಂದ ನನಗೆ ಏನು ಪ್ರಯೋಜನ?" ನಾವೆಲ್ಲ ಸರಳ ಉದಾಹರಣೆಯಿಂದ ಪ್ರಾರಂಭಿಸೋಣ.

MCP ಸರ್ವರ್‌ಗಳನ್ನು ವಿಶಿಷ್ಟ ಸಹಾಯಕರಾಗಿ ಯೋಚಿಸಿ, ಅದು ನಿಮ್ಮ AI ಕೋಡಿಂಗ್ ಸಹಾಯಗಾರನಿಗೆ (ಉದಾಹರಣೆಗೆ GitHub Copilot) ಬಾಹ್ಯ ಸಾಧನಗಳು ಮತ್ತು ಸೇವೆಗಳಿಗೆ ಸಂಪರ್ಕ ಕಲ್ಪಿಸುತ್ತದೆ. ನೀವು ನಿಮ್ಮ ಫೋನಿನಲ್ಲಿ ವಿಭಿನ್ನ ಕೆಲಸಕ್ಕೆ ವಿವಿಧ ಆಪ್‌ಗಳನ್ನು ಬಳಸುತ್ತಿದ್ದಂತೆ — ಹವಾಮಾನಕ್ಕೆ ಒಂದನ್ನು, ನ್ಯಾವಿಗೇಶನ್‌ಗೆ ಒಂದನ್ನು, ಬ್ಯಾಂಕಿಂಗ್‌ಗೆ ಒಂದನ್ನು — MCP ಸರ್ವರ್‌ಗಳು ನಿಮ್ಮ AI ಸಹಾಯಗಾರನಿಗೆ ವಿವಿಧ ಅಭಿವೃದ್ಧಿ ಸಾಧನಗಳು ಮತ್ತು ಸೇವೆಗಳೊಂದಿಗೆ ಸಂವಹನ ಮಾಡುವ ಸಾಮರ್ಥ್ಯವನ್ನು ನೀಡುತ್ತವೆ.

### MCP ಸರ್ವರ್‌ಗಳು ಪರಿಹರಿಸುವ ಸಮಸ್ಯೆ

MCP ಸರ್ವರ್‌ಗಳ ಹಿಂದಿನ ಸ್ಥಿತಿಯಲ್ಲಿ, ನೀವು:
- ನಿಮ್ಮ ಅಜೂರ್ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಪರಿಶೀಲಿಸಲು
- GitHub ಅಶವನ್ನು ಸೃಷ್ಟಿಸಲು
- ನಿಮ್ಮ ಡೇಟಾಬೇಸ್ನ್ನು ಪ್ರಶ್ನಿಸಲು
- ದಾಖಲೆಗಳಲ್ಲಿ ಹುಡುಕಲು

ಪ್ರತೀ ಬಾರಿ ಕೋಡಿಂಗ್ ನಿಲ್ಲಿಸಿ ಬ್ರೌಸರ್ ತೆರೆಯಲು, ಸರಿಯಾದ ವೆಬ್‌ಸೈಟ್‌ಗೆ ಹೋಗಿ, ಈ ಕಾರ್ಯಗಳನ್ನು ಕೈಯಿಂದ ಮಾಡಬೇಕಾಗುತ್ತಿತ್ತು. ಈ ನಿರಂತರ ವಿಷಯ ಬದಲಾವಣೆ ನಿಮ್ಮ ಕೆಲಸದ ಸಂಪ್ರೇಕ್ಷಣೆಯನ್ನು ಮುರಿದು ಉತ್ಪಾದಕತೆಯನ್ನು ಕಡಮೆಯಾಗಿ ಮಾಡುತ್ತದೆ.

### MCP ಸರ್ವರ್‌ಗಳು ನಿಮ್ಮ ಅಭಿವೃದ್ಧಿ ಅನುಭವವನ್ನು ಹೇಗೆ ಪರಿವರ್ತಿಸುತ್ತವೆ

MCP ಸರ್ವರ್‌ಗಳೊಂದಿಗೆ ನೀವು ನಿಮ್ಮ ಅಭಿವೃದ್ಧಿ ಪರಿಸರದಲ್ಲಿಯೇ (VS ಕೋಡ್, ವಿವುಲ್ ಸ್ಟುಡಿಯೋ, ಇತ್ಯಾದಿ) ಇರಬಹುದು ಮತ್ತು ನಿಮ್ಮ AI ಸಹಾಯಗಾರನಿಗೆ ಈ ಕಾರ್ಯಗಳನ್ನು ನಿರ್ವಹಿಸಲು ಕೇಳಬಹುದು. ಉದಾಹರಣೆಗಾಗಿ:

**ಸಾಂಪ್ರದಾಯಿಕ ಕಾರ್ಯವಾಹಕದ ಬದಲು:**
1. ಕೋಡಿಂಗ್ ನಿಲ್ಲಿಸಿ
2. ಬ್ರೌಸರ್ ತೆರೆಯಿರಿ
3. ಅಜೂರ್ ಪೋರ್ಟಲ್‌ಗೆ ನಾವಿಗೇಟ್ ಮಾಡಿರಿ
4. ಸ್ಟೋರೇಜ್ ಖಾತೆ ವಿವರಗಳನ್ನು ಪರಿಶೀಲಿಸಿ
5. VS ಕೋಡ್‌ಗೆ ಮರುಹೋಗಿ
6. ಕೋಡಿಂಗ್ ಪುನರಾರಂಭಿಸಿ

**ನೀವು ಈಗಾ ಮುಂದೆ ಇದನ್ನು ಮಾಡಬಹುದು:**
1. AIಗೆ ಕೇಳಿ: "ನನ್ನ ಅಜೂರ್ ಸ್ಟೋರೇಜ್ ಖಾತೆಗಳ ಸ್ಥಿತಿ ಏನು?"
2. ಪೂರೈಕೆ ಮಾಡಿದ ಮಾಹಿತಿಯನ್ನು ಬಳಸಿಕೊಂಡು ಕೋಡಿಂಗ್ ಮುಂದುವರೆಸಿ

### ಪ್ರಾರಂಭಿಕರಿಗಾಗಿ ಪ್ರಮುಖ ಪ್ರಯೋಜನಗಳು

#### 1. 🔄 **ನಿಮ್ಮ ಕೆಲಸದ ಹರಿವಿನಲ್ಲಿ ಉಳಿಯಿರಿ**
- ಹಲವು ಆಪ್‌ಗಳ ನಡುವೆ ಬದಲಾವಣೆ ಇಲ್ಲ
- ನೀವು ಬರೆಯುತ್ತಿರುವ ಕೋಡ್ ಮೇಲೆ ನಿಮ್ಮ ಗಮನ ಕೇಂದ್ರೀಕರಿಸಿ
- ವಿವಿಧ ಸಾಧನಗಳನ್ನು ನಿರ್ವಹಿಸುವ ಮಾನಸಿಕ ಒತ್ತಡ ಕಡಿಮೆ ಮಾಡಿ

#### 2. 🤖 **ಜಟಿಲ ಆಜ್ಞೆಗಳ ಬದಲು ಸಾಮಾನ್ಯ ಭಾಷೆಯನ್ನು ಬಳಸಿ**
- SQL ಸಿಂಟ್ಯಾಕ್ಸ್ ನೆನಪಿನಲ್ಲಿ ಇಟ್ಟುಕೊಳ್ಳುವುದರ ಬದಲು ನೀವು ಬೇಕಾದ ಡೇಟಾವನ್ನು ವರ್ಣಿಸಿ
- ಅಜೂರ್ CLI ಆಜ್ಞೆಗಳನ್ನು ನೆನಪಿನಲ್ಲಿ ಇಟ್ಟುಕೊಳ್ಳುವುದರ ಬದಲು ನೀವು ಸಾಧಿಸಲು ಬಯಸುವುದನ್ನು ವಿವರಿಸಿ
- ತಾಂತ್ರಿಕ ವಿವರಗಳನ್ನು AIಗೆ ನಿಭಾಯಿಸಲು ಬಿಡಿ ಮತ್ತು ನೀವು ನಿಯಮಿತ ತರ್ಕದ ಮೇಲೆ ಗಮನ ಕೇಂದ್ರೀಕರಿಸಿ

#### 3. 🔗 **ಬಹು ಸಾಧನಗಳನ್ನು ಕೊಡುಗೆ ಮಾಡಿಸಿ**
- ವಿವಿಧ ಸೇವೆಗಳನ್ನು ಸಂಯೋಜಿಸುವ ಮೂಲಕ ಶಕ್ತिशಾಲಿ ಕಾರ್ಯವಾಹಕಗಳನ್ನು ನಿರ್ಮಿಸಿ
- ಉದಾಹರಣೆ: "ಇತ್ತೀಚಿನ GitHub ಅಶಗಳೆಲ್ಲ ಪಡೆಯಿರಿ ಮತ್ತು ಸಂಬಂಧಪಟ್ಟ ಅಜೂರ್ ಡೆವ್‌ಆಪ್ಸ್ ಕೆಲಸದ ಐಟಂಗಳನ್ನು ಸೃಷ್ಟಿಸು"
- ಜಟಿಲ ಸ್ಕ್ರಿಪ್ಟ್ ಬರವಣಿಗೆ ಇಲ್ಲದೆ ಸ್ವಯಂಚಾಲಿತ ಮಾಡಿಕೊಳ್ಳಿ

#### 4. 🌐 **ವಿಸ್ತಾರವಾಗುತ್ತಿರುವ ಪರಿಸರಕ್ಕೆ ಪ್ರಾಪ್ತಿಯಾಗಿರಿ**
- ಮೈಕ್ರೋಸಾಫ್ಟ್, ಗಿಥಬ್ ಮತ್ತು ಇತರ ಕಂಪನಿಗಳು ನಿರ್ಮಿಸಿದ ಸರ್ವರ್‌ಗಳಿಂದ ಲಾಭ ಪಡೆಯಿರಿ
- ವಿಭಿನ್ನ ವಿಕ್ರೇತಾರ ಸಾಧನಗಳನ್ನು ನಿಗದಿತವಾಗಿ ಮತ್ತು ಅನುಕೂಲಕರವಾಗಿ ಸೇರಿಸಿ
- ವಿಭಿನ್ನ AI ಸಹಾಯಕರ ನಡುವೆ ಕಾರ್ಯನಿರ್ವಹಿಸುವ ಮಾನಕಿತ ಪರಿಸರವನ್ನು ಸೇರಿ

#### 5. 🛠️ **ಮಾಡುತ್ತಾ ಕಲಿಯಿರಿ**
- ತತ್ವಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ಪೂರ್ವನಿರ್ಮಿತ ಸರ್ವರ್‌ಗಳಿಂದ ಪ್ರಾರಂಭಿಸಿ
- ಆರಾಮವಾಗಿ ನೈಜ MCP ಸರ್ವರ್ ಗಳನ್ನು ಹಂತ ಹಂತವಾಗಿ ನಿರ್ಮಿಸಿ
- ಕಲಿಕೆಯ ಮಾರ್ಗದರ್ಶನಕ್ಕಾಗಿ ಲಭ್ಯವಿರುವ SDK ಮತ್ತು ದಾಖಲೆಗಳನ್ನು ಬಳಸಿ

### ಪ್ರಾರಂಭಿಕರಿಗಾಗಿ ನೈಜ ಜಾಗತಿಕ ಉದಾಹರಣೆ

ನೀವು ವೆಬ್ ಅಭಿವೃದ್ಧಿಯಲ್ಲಿ ಹೊಸವನೆಂದು ನಿ ನಿಮ್ಮ ಮೊದಲ ಯೋಜನೆಯ ಮೇಲೆ ಕೆಲಸ ಮಾಡುತ್ತಿದ್ದರೆ, MCP ಸರ್ವರ್‌ಗಳು ಇದನ್ನು ಹೇಗೆ ಸಹಾಯ ಮಾಡಬಹುದು ನೋಡೋಣ:

**ಸಾಂಪ್ರದಾಯಿಕ ವಿಧಾನ:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP ಸರ್ವರ್‌ಗಳೊಂದಿಗೆ:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### ಉದ್ಯಮ ಮಾನಕ ಲಾಭ

MCP ಉದ್ಯಮ ವ್ಯಾಪ್ತಿಯ ಮಾನಕವಾಗುತ್ತಿದೆ; ಅಂದರೆ:
- **ತಾಳಮೇಳ**: ವಿವಿಧ ಸಾಧನ ಮತ್ತು ಕಂಪನಿಗಳಲ್ಲಿ ಸಮಾನ ಅನುಭವ
- **ಪರಸ್ಪರಕಾರ್ಯ ಸಮರ್ಥತೆ**: ವಿಭಿನ್ನ ವಿಕ್ರೇತಾರ ಸರ್ವರ್‌ಗಳು ಒಟ್ಟಿಗೆ ಕೆಲಸ ಮಾಡುತ್ತವೆ
- **ಭವಿಷ್ಯಕ್ಕಾಗಿ ತಯಾರಿ**: ವಿವಿಧ AI ಸಹಾಯಕರ ನಡುವೆ ಕೌಶಲಗಳು ಮತ್ತು ವ್ಯವಸ್ಥೆಗಳು ವರ್ಗಾವಣೆಯಾಗುತ್ತವೆ
- **ಸಮುದಾಯ**: ಹಂಚಿದ ಜ್ಞಾನ ಮತ್ತು ಸಂಪನ್ಮೂಲಗಳ ದೊಡ್ಡ ಪರಿಸರ

### ಪ್ರಾರಂಭ: ನೀವು ಕಲಿಯುವವುಗಳು

ಈ ಮಾರ್ಗದರ್ಶಿಕೆಯಲ್ಲಿ, ಎಲ್ಲಾ ಮಟ್ಟದ ಡೆವಲಪರ್‌ಗಳಿಗೆ ವಿಶೇಷವಾಗಿ ಉಪಯುಕ್ತವಾದ 10 ಮೈಕ್ರೋಸಾಫ್ಟ್ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಅನ್ವೇಷಿಸುವುದು. ಪ್ರತಿಯೊಂದು ಸರ್ವರ್ ವಿನ್ಯಾಸಗೊಳಿಸಲಾಗಿದೆ:
- ಸಾಮಾನ್ಯ ಅಭಿವೃದ್ಧಿ ಸವಾಲುಗಳನ್ನು ಪರಿಹರಿಸಲು
- পুনರಾವರ್ತನೇಯ ಕೆಲಸಗಳನ್ನು ಕಡಿಮೆ ಮಾಡಲು
- ಕೋಡ್ ಗುಣಮಟ್ಟವನ್ನು ಹೆಚ್ಚಿಸಲು
- ಕಲಿಕೆಯ ಅವಕಾಶಗಳನ್ನು ಅಭಿವೃದ್ಧಿಪಡಿಸಲು

> **💡 ಕಲಿಕೆಯ ಸಲಹೆ**
>
> ನೀವು MCP ಗೆ ಸಂಪೂರ್ಣ ಹೊಸವನೇ ಇದ್ದೀರಾ, ಆದ್ದರಿಂದ ನಮ್ಮ [MCP ಪರಿಚಯ](../00-Introduction/README.md) ಮತ್ತು [ಮೂಲತತ್ವಗಳು](../01-CoreConcepts/README.md) ಘಟಕಗಳಿಂದ ಪ್ರಾರಂಭಿಸಿ. ನಂತರ ಇಲ್ಲಿ ಬಂದು ಈ ತತ್ವಗಳನ್ನು ನೈಜ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಸಾಧನಗಳೊಂದಿಗೆ ಹೇಗೆ ಜಾರಿಗೆ ತರುವುದೆನ್ನುವುದನ್ನು ನೋಡಿ.
>
> MCP ಮಹತ್ವದ ಹೆಚ್ಚು ಮಾಹಿತಿ ವಿವರಕ್ಕಾಗಿ, ಮಾರಿಯಾ ನಗ್ಗೆಗಾ ಅವರ ಪೋಸ್ಟ್ ನೋಡಿ: [Connect Once, Integrate Anywhere with MCP](https://devblogs.microsoft.com/blog/connect-once-integrate-anywhere-with-mcps).

## VS ಕೋಡ್ ಮತ್ತು ವಿವುಲ್ ಸ್ಟುಡಿಯೋದಲ್ಲಿ MCP ಪ್ರಾರಂಭಿಸುವುದು 🚀

ನೀವು GitHub Copilot ಜೊತೆಗೆ Visual Studio Code ಅಥವಾ Visual Studio 2022 ಬಳಕೆ ಮಾಡುತ್ತಿದ್ದರೆ ಈ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಸ್ಥಾಪಿಸುವುದು ಸುಲಭವಾಗಿದೆ.

### VS ಕೋಡ್ ಸ್ಥಾಪನೆ

VS ಕೋಡ್‌ಗೆ ಮೂಲ ಪ್ರಕ್ರಿಯೆಯಂತಿದೆ:

1. **ಏಜೆಂಟ್ ಮೋಡ್ ಸಕ್ರಿಯಗೊಳಿಸಿರಿ**: VS ಕೋಡ್‌ನಲ್ಲಿ, Copilot ಚಾಟ್ ವಿಂಡೋದಲ್ಲಿ ಏಜೆಂಟ್ ಮೋಡ್‌ಗೆ ಬಲೆಗೆ ಬದಲಾಯಿಸಿ
2. **MCP ಸರ್ವರ್‌ಗಳನ್ನು ಸಂರಚಿಸಿರಿ**: ನಿಮ್ಮ VS ಕೋಡ್ settings.json ಫೈಲ್‌ಗೆ ಸರ್ವರ್ ಸಂರಚನೆಗಳನ್ನು ಸೇರಿಸಿ
3. **ಸರ್ವರ್‌ಗಳನ್ನು ಪ್ರಾರಂಭಿಸಿ**: ನೀವು ಬಳಸಲು ಬಯಸುವ ಪ್ರತಿಯೊಂದು ಸರ್ವರ್‌ಗೆ "ಪ್ರಾರಂಬಿಸಿ" ಬಟನ್ ಕ್ಲಿಕ್ ಮಾಡಿ
4. **ಸಾಧನಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿ**: ನಿಮ್ಮ ಪ್ರಸ್ತುತ ಅಧಿವೇಶನಕ್ಕೆ ಸಕ್ರಿಯಗೊಳಿಸಬಹುದಾದ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಆಯ್ಕೆಮಾಡಿ

ಇದಕ್ಕೆ ಸಂಬಂಧಿಸಿದ ವಿಶದು ಸ್ಥಾಪನೆ ನಿರ್ದೇಶನಗಳಿಗೆ [VS ಕೋಡ್ MCP ದಸ್ತಾವೇಜು](https://code.visualstudio.com/docs/copilot/copilot-mcp) ನೋಡಿ.

> **💡 ಪ್ರೊ ಸಲಹೆ: MCP ಸರ್ವರ್‌ಗಳನ್ನು ಪ್ರೊ ವಿಕ್ರಯಕೊಂಡಂತೆ ನಿರ್ವಹಿಸಿರಿ!**
>
> VS ಕೋಡ್ ವಿಸ್ತರಣೆ ವೀಕ್ಷಣಾ ಭಾಗದಲ್ಲಿ ಈಗ [ಸ್ಥಾಪಿತ MCP ಸರ್ವರ್‌ಗಳನ್ನು ನಿರ್ವಹಿಸಲು ಹೊಸ ಸರಳ UI](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode) ಇರುವಂತೆ ಬಂದಿದೆ! ನೀವು ಸ್ಥಾಪಿಸಿದ ಯಾವುದೇ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಪ್ರಾರಂಭಿಸುವ, ನಿಲ್ಲಿಸುವ ಮತ್ತು ನಿರ್ವಹಿಸುವುದಕ್ಕೆ ಸುಲಭ, ಸ್ವಚ್ಛವಾದ ಪರದೆ ಮೂಲಕ ತ್ವರಿತ ಪ್ರಾಪ್ತಿಯನ್ನು ಹೊಂದಿದ್ದೀರಿ. ಪ್ರಯತ್ನಿಸಿ!

### Visual Studio 2022 ಸ್ಥಾಪನೆ

Visual Studio 2022 (17.14 ಅಥವಾ ನಂತರದ ಆವೃತ್ತಿ) ಗಾಗಿ:

1. **ಏಜೆಂಟ್ ಮೋಡ್ ಸಕ್ರಿಯಗೊಳಿಸಿ**: GitHub Copilot ಚಾಟ್ ವಿಂಡೋದಲ್ಲಿ "Ask" ಡ್ರಾಪ್ಡೌನ್ ಕ್ಲಿಕ್ ಮಾಡಿ "Agent" ಆಯ್ಕೆಮಾಡಿ
2. **ಸಂರಚನಾ ಫೈಲ್ ರಚಿಸಿ**: ನಿಮ್ಮ ಸೊಲ್ಯೂಷನ್ ಡೈರೆಕ್ಟರಿಯಲ್ಲಿ `.mcp.json` ಫೈಲ್ ರಚಿಸಿ (ಶಿಫಾರಸು ಮಾಡಿದ ಸ್ಥಳ: `<SOLUTIONDIR>\.mcp.json`)
3. **ಸರ್ವರ್‌ಗಳನ್ನು ಸಂರಚಿಸಿ**: ಸಾಮಾನ್ಯ MCP ಸ್ವರೂಪ ಬಳಸಿ ನಿಮ್ಮ MCP ಸರ್ವರ್ ಸಂರಚನೆಗಳನ್ನು ಸೇರಿಸಿ
4. **ಸಾಧನ ಅನುಮತಿ**: ಪ್ರಾಂಪ್ಟ್ ಆಗಿದಾಗ ಉಪಯೋಗಿಸಲು ಬಯಸಿದ ಸಾಧನಗಳಿಗೆ ಸೂಕ್ತ ವ್ಯಾಪ್ತಿಯ ಅನುಮತಿಗಳನ್ನು ಒಪ್ಪಿಸಿ

Visual Studio ಸ್ಥಾಪನೆಗೆ ವಿವರವಾದ ನಿರ್ದೇಶನಗಳಿಗಾಗಿ [Visual Studio MCP ದಸ್ತಾವೇಜು](https://learn.microsoft.com/visualstudio/ide/mcp-servers) ನೋಡಿ.

ಪ್ರತಿಯೊಂದು MCP ಸರ್ವರ್‌ನಿಗೂ ತನ್ನದೇ ಆದ ಸಂರಚನಾ ಅವಶ್ಯಕತೆಗಳಿವೆ (ಸಂಪರ್ಕ ಸ್ಟ್ರಿಂಗ್‌ಗಳು, ಪ್ರಮಾಣೀಕರಣ, ಇತ್ಯಾದಿ), ಆದರೆ ಎರಡೂ IDE ಗಳು ಸಜಾತಿ ಸ್ಥಾಪನಾ ಮಾದರಿಯನ್ನು ಪಾಲಿಸುತ್ತವೆ.

**ಏನು ಮಾಡುತ್ತದೆ**: ಮೈಕ್ರೋಸಾಫ್ಟ್ ಕಲಿಕೆ ಡಾಕ್ಸ್ MCP ಸರ್ವರ್ ಒಂದು ಕ್ಲೌಡ್-ನಿರ್ವಹಿತ ಸೇವೆ, ಇದು AI ಸಹಾಯಕರಿಗೆ ಮodel Context Protocol ಮೂಲಕ ಅಧಿಕೃತ ಮೈಕ್ರೋಸಾಫ್ಟ್ ದಸ್ತಾವೇಜುವಿಗೆ ನವೀನ ದೃಷ್ಟಿ ಒದಗಿಸುತ್ತದೆ. ಇದು `https://learn.microsoft.com/api/mcp` ಗೆ ಸಂಪರ್ಕಿಸಿ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಕಲಿಕೆ, ಅಜೂರ್ ದಸ್ತಾವೇಜು, ಮೈಕ್ರೋಸಾಫ್ಟ್ 365 ದಸ್ತಾವೇಜು, ಮತ್ತು ಇತರ ಅಧಿಕೃತ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಮೂಲಗಳಲ್ಲಿ ಸಿಮೆಂಟಿಕ್ ಹುಡುಕಾಟವನ್ನು ಸಾಧ್ಯಗೊಳಿಸುತ್ತದೆ.

**ಏಕೆ ಉಪಯುಕ್ತ**: "ಮಾತ್ರ ದಸ್ತಾವೇಜುಗಳು" ಅನ್ನಿಸಬಹುದು, ಆದರೆ ಈ ಸರ್ವರ್ ವೈರಾಗಿ ಮೈಕ್ರೋಸಾಫ್ಟ್ ತಂತ್ರಜ್ಞಾನಗಳನ್ನು ಬಳಸುವ ಪ್ರತಿಯೊಂದು ಡೆವಲಪರ್‌ಗಾಗಿ ಅತ್ಯಂತ ಮುಖ್ಯವಾಗಿದೆ. .NET ಡೆವಲಪರ್‌ಗಳಿಂದ AI ಕೋಡಿಂಗ್ ಸಹಾಯಕರ ಬಗ್ಗೆ ದೊಡ್ಡ ಅಸಮಾಧಾನವೆಂದರೆ ಅವು ಹೊಸ .NET ಮತ್ತು C# ಬಿಡುಗಡೆಗಳ ಬಗ್ಗೆ ಹೊಸ ಮಾಹಿತಿ ನೀಡುವುದಿಲ್ಲ. ಮೈಕ್ರೋಸಾಫ್ಟ್ ಕಲಿಕೆ ಡಾಕ್ಸ್ MCP ಸರ್ವರ್ ನವೀನ ದಸ್ತಾವೇಜು, API ಕಂಡಿಬಗೆಗಳು, ಮತ್ತು ಉತ್ತಮ ಅಭ್ಯಾಸಗಳನ್ನು ನೇರವಾಗಿ ಒದಗಿಸುವ ಮೂಲಕ ಇದನ್ನು ಪರಿಹರಿಸುತ್ತದೆ. ನೀವು ಇತ್ತೀಚಿನ ಅಜೂರ್ SDK ಗಳು, ಹೊಸ C# 13 ವೈಶಿಷ್ಟ್ಯಗಳ ಅನ್ವೇಷಣೆ, ಅಥವಾ ಪ್ರಗತಿಶೀಲ Aspire ಪ್ಯಾಟರ್ನ್‌ಗಳು ಬಳಸುತ್ತಿದ್ದರೂ, ಈ ಸರ್ವರ್ ನಿಮ್ಮ AI ಸಹಾಯಕರಿಗೆ ನಿರ್ದಿಷ್ಟ, ನವೀನ ಮಾಹಿತಿ ಕೊಡುವ ಮೂಲಕ ನಿಖರ ಮತ್ತು ಆಧುನಿಕ ಕೋಡ್ ರಚನೆಗೆ ಸಹಾಯ ಮಾಡುತ್ತದೆ.

**ನೈಜ ಜಾಗತಿಕ ಬಳಕೆ**: "ಅಧಿಕೃತ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಕಲಿಕೆ ದಸ್ತಾವೇಜಿನ ಪ್ರಕಾರ ಅಜೂರ್ ಕಂಟೈನರ್ ಆ್ಯಪ್ ಸೃಷ್ಟಿಸುವ az cli ಆಜ್ಞೆಗಳು ಯಾವುವು?" ಅಥವಾ "ASP.NET ಕೋರ್ ನಲ್ಲಿ ಡಿಪೆಂಡೆನ್ಸಿ ಇಂಜೆಕ್ಷನ್ ಮೂಲಕ Entity Framework ಅನ್ನು ಹೇಗೆ ಸಂರಚಿಸಬೇಕು?" ಅಥವಾ "ಈ ಕೋಡ್ ನ ವೈಖರಿ microsoft ಕಲಿಕೆ ದಸ್ತಾವೇಜಿನ ಪ್ರದರ್ಶನ ಶಿಫಾರಸುಗಳಿಗೆ ಹೊಂದಿಕೆಯಾಗಿದೆಯೇ ಎಂದು ಪರಿಶೀಲಿಸಿ." ಈ ಸರ್ವರ್ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಕಲಿಕೆ, ಅಜೂರ್ ದಸ್ತಾವೇಜುಗಳು ಮತ್ತು ಮೈಕ್ರೋಸಾಫ್ಟ್ 365 ದಸ್ತಾವೇಜುಗಳಲ್ಲಿ ತಿಳಿವಳಿಕೆಯ ಹುಡುಕಾಟ ಒದಗಿಸಿ ಉತ್ತಮ ವಿಷಯ ವಿಷಯಗಳ ಶೀರ್ಷಿಕೆ ಮತ್ತು URLಗಳನ್ನು 10ಕ್ಕೂ ಹೆಚ್ಚಾದ ಗುಣಮಟ್ಟದ ತುಣುಕುಗಳೊಂದಿಗೆ ಹಿಂತಿರುಗಿಸುತ್ತದೆ, ಸದಾ ಇತ್ತೀಚಿನ ದಸ್ತಾವೇಜುಗಳನ್ನು ಪಡೆಯುತ್ತದೆ.

**ಪ್ರಮುಖ ಉದಾಹರಣೆ**: ಸರ್ವರ್ `microsoft_docs_search` ಸಾಧನವನ್ನು ಒದಗಿಸುತ್ತದೆ, ಇದು ಮೈಕ್ರೋಸಾಫ್ಟ್ ಅಧಿಕೃತ ತಾಂತ್ರಿಕ ದಸ್ತಾವೇಜಿನ ವಿರುದ್ಧ ಸಿಮೆಂಟಿಕ್ ಹುಡುಕಾಟ ನಡೆಸುತ್ತದೆ. ಸಂರಚನೆ ಆದ ಬಳಿಕ, ನೀವು "ASP.NET ಕೋರ್ ನಲ್ಲಿ JWT ದೃಢೀಕರಣವನ್ನು ಹೇಗೆ ಜಾರಿಗೆ ತರುತ್ತೇನೆ?" ಎಂದು ಪ್ರಶ್ನಿಸಿ, ಮೂಲ ಲಿಂಕ್‌ಗಳೊಂದಿಗೆ ವಿವರವಾದ ಅಧಿಕೃತ ಉತ್ತರಗಳನ್ನು ಪಡೆಯಬಹುದು. ಹುಡುಕಾಟ ಗುಣಮಟ್ಟ ಅತ್ಯುತ್ತಮವಾಗಿದೆ ಏಕೆಂದರೆ ಇದು ಸಂಧರ್ಭವನ್ನು ತಿಳಿದುಕೊಳ್ಳುತ್ತದೆ – "ಕಂಟೈನರ್‌ಗಳು" ಎಂಬ ಪದವನ್ನು ಅಜೂರ್ ಸಂಧರ್ಭದಲ್ಲಿ ಕೇಳಿದರೆ ಅಜೂರ್ ಕಂಟೈನರ್ ಇನ್ಸ್ಟಾನ್ಸ್ ದಸ್ತಾವೇಜು ಬರುತ್ತದೆ, ಹಾಗೆಯೇ .NET ಸಂಧರ್ಭದಲ್ಲಿ ಇದಕ್ಕೆ ಸಂಬಂಧಿಸಿದ C# ಸಂಗ್ರಹಣಾ ಮಾಹಿತಿ ದೊರೆಯುತ್ತದೆ.

ಇದು ಎಚ್ಚರಿಕೆಯಿಂದ ಬದಲಾವಣೆಯಾಗುತ್ತಿರುವ ಅಥವಾ ಇತ್ತೀಚೆಗೆ ನವೀಕರಿಸಿದ ಗ್ರಂಥಾಲಯಗಳು ಮತ್ತು ಬಳಕೆಯ ಪ್ರಕಾರಗಳಲ್ಲಿ ವಿಶೇಷ ಉಪಕಾರಿ. ಉದಾಹರಣೆಗೆ, ಇತ್ತೀಚಿನ ಕೆಲವು ಕೋಡಿಂಗ್ ಯೋಜನೆಗಳಲ್ಲಿ Aspire ಮತ್ತು Microsoft.Extensions.AI ನ ಇತ್ತೀಚಿನ ಬಿಡುಗಡೆಗಳ ವೈಶಿಷ್ಟ್ಯಗಳನ್ನು ಉಪಯೋಗಿಸಲು ಇಚ್ಛಿಸಿದ್ದು, ಮೈಕ್ರೋಸಾಫ್ಟ್ ಕಲಿಕೆ ಡಾಕ್ಸ್ MCP ಸರ್ವರ್ ಸೇರಿಸುವ ಮೂಲಕ, ನಾನು ಕೇವಲ API ದಸ್ತಾವೇಜುಗಳನ್ನೇ ಅಲ್ಲದೆ ಸಾರ್ ಮಾರ್ಗದರ್ಶನ ಮತ್ತು ರೂಪರೇಖೆಗಳನ್ನು ಸಹ ಪಡೆಯಲು ಸಾಧ್ಯವಾಯಿತು.

**ಯಥಾರ್ಥ ಉಪಯೋಗ**: "ನನ್ನ ಆಜೂರ್ ಸ್ಟೋರೇಜ್ ಖಾತೆಗಳ ಪಟ್ಟಿಯನ್ನು ತೋರಿಸಿ", "ಕೊನೆಯ ಗಂಟೆಯಲ್ಲಿ ದೋಷಗಳಿಗಾಗಿ ನನ್ನ ಲಾಗ್ ಅನಾಲಿಟಿಕ್ಸ್ ವರ್ಕ್‌ಸ್ಪೇಸ್ ಅನ್ನು ವಿಚಾರಿಸಿ", ಅಥವಾ "ನಿಮ್ಮ ಜಯಂತಿಕೃತ	DefaultAzureCredential ನೊಂದಿಗೆ ನೋಡ್.ಜೆಎಸ್ ಬಳಸಿ ಆಜೂರ್ ಅಪ್ಲಿಕೇಶನ್ ರೂಪಿಸುವಲ್ಲಿ ಸಹಾಯಮಾಡಿ"

**ಸಂಪೂರ್ಣ ಡೆಮೊ ದೃಶ್ಯಾವಳಿ**: ಇಲ್ಲಿ ಆಜೂರ್ MCP ಮತ್ತು VS ಕೋಡ್‌ನ GitHub Copilot for Azure ವಿಸ್ತರಣೆ ಜೊತೆಗೆ ಹಮ್ಮಿಕೊಂಡಿರುವ ಶಕ್ತಿ ಪೂರ್ಣ ಚಾಲನೆ ಇದೆ. ನೀವು ಎರಡನ್ನೂ ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ ಪ್ರಾಂಪ್ಟ್ ಮಾಡಿದಾಗ:

> "ಡೀಫಾಲ್ಟ್ ಆಜೂರ್ ಕ್ರಿಡೆನ್ಷಿಯಲ್ ಪ್ರಮಾಣೀಕರಣ ಬಳಸಿ ಆಜೂರ್ ಬ್ಲಾಬ್ ಸ್ಟೋರೇಜ್ಗೆ ಫೈಲ್ ಅಪ್ಲೋಡ್ ಮಾಡುವ ಪೈಥಾನ್ ಸ್ಕ್ರಿಪ್ಟ್ ಸೃಷ್ಟಿಸಿ. ಸ್ಕ್ರಿಪ್ಟ್ мое ತಮ್ಮ ಆಜೂರ್ ಸ್ಟೋರೇಜ್ ಖಾತೆ 'mycompanystorage' ಇದರೊಂದಿಗೆ ಸಂಪರ್ಕ ಸಾಧಿಸಿ, 'documents' ಎಂಬ ಕಂಟೈನರ್‌ಗೆ ಅಪ್ಲೋಡ್ ಮಾಡಲಿ, ಪ್ರಸ್ತುತ ಟೈಮ್‌ಸ್ಟಾಂಪ್ನೊಂದಿಗೆ ಪರೀಕ್ಷಾ ಫೈಲ್ ಸೃಷ್ಟಿಸಬೇಕು, ದೋಷಗಳನ್ನು ಸರಳವಾಗಿ ನಿರ್ವಹಿಸಿ ಮತ್ತು ಮಾಹಿತಿ ಒದಗಿಸುವ ವಾಗಿ ಇರಲಿ, ಆಜೂರ್ ಪ್ರಮಾಣೀಕರಣ ಮತ್ತು ದೋಷ ನಿರ್ವಹಣೆಯ ಉತ್ತಮ ಅಭ್ಯಾಸಗಳನ್ನು ಅನುಸರಿಸಲಿ, DefaultAzureCredential ಪ್ರಮಾಣೀಕರಣ ಹೇಗಿದೆ ಎಂಬುದನ್ನು ವಿವರಿಸುವ ಕಾಮೆಂಟ್ಸ್ ಇರಲಿ ಮತ್ತು ಸ್ಕ್ರಿಪ್ಟ್ ಸರಿಯಾಗಿ ಕಾರ್ಯವಿಧಾನಗಳು ಮತ್ತು ಡಾಕ್ಯುಮೆಂಟೇಷನ್ ಸಹಿತ ವ್ಯವಸ್ಥಿತವಾಗಿರಲಿ."

ಆಜೂರ್ MCP ಸರ್ವರ್ ಸಂಪೂರ್ಣವಾಗಿ ತಯಾರಾದ ಉತ್ಪಾದನಾ ಮಟ್ಟದ ಪೈಥಾನ್ ಸ್ಕ್ರಿಪ್ಟ್ ರಚಿಸುತ್ತದೆ, ಇದು:
- ಇತ್ತೀಚಿನ ಆಜೂರ್ ಬ್ಲಾಬ್ ಸ್ಟೋರೇಜ್ SDK ನೊಂದಿಗೆ ಸರಿಯಾದ ಅಸಿಂಕ್ರೋನಸ್ ಮಾದರಿಗಳನ್ನು ಬಳಸುತ್ತದೆ
- DefaultAzureCredential ಅನ್ನು ಪೂರ್ಣ ವೈಫಲ್ಯ ಸರಪಳಿ ವಿವರದೊಂದಿಗೆ ಜಾರಿಗೆ ತರುತ್ತದೆ
- ವಿಶೇಷ ಆಜೂರ್ excepción ಮಾದರಿಗಳೊಂದಿಗೆ ಭರವಸಾಯೋಗ್ಯ ದೋಷ ನಿರ್ವಹಣೆಯನ್ನು ಒಳಗೊಳ್ಳುತ್ತದೆ
- ಸಂಪನ್ಮೂಲ ನಿರ್ವಹಣೆ ಮತ್ತು ಸಂಪರ್ಕ ನಿರ್ವಹಣೆಯಲ್ಲಿ ಆಜೂರ್ SDK ಉತ್ತಮ ಅಭ್ಯಾಸಗಳನ್ನು ಅನುಸರಿಸುತ್ತದೆ
- ವಿವರವಾದ ಲಾಗಿಂಗ್ ಮತ್ತು ಮಾಹಿತಿ ನೀಡುವ ಕಾನ್ಸೋಲ್ ಔಟ್‌ಪುಟ್ ಅನ್ನು ಒದಗಿಸುತ್ತದೆ
- ಕಾರ್ಯವಿಧಾನಗಳು, ದಾಖಲೆ ಮತ್ತು ಪ್ರಕಾರ ಸೂಚನಗಳೊಂದಿಗೆ ಸರಿಯಾದ ರಚನೆಯ ಸ್ಕ್ರಿಪ್ಟ್ ಸೃಷ್ಟಿಸುತ್ತದೆ

ಇದನ್ನು ವಿಶೇಷಮಾಡುವುದು ಏನೆಂದರೆ, ಆಜೂರ್ MCP ಇಲ್ಲದೆ, ನೀವು ಸಾಮಾನ್ಯ ಬ್ಲಾಬ್ ಸ್ಟೋರೇಜ್ ಕೋಡ್ ಪಡೆಯಬಹುದು ಅದು ಕೆಲಸ ಮಾಡುತ್ತದೆ ಆದರೆ ಇತ್ತೀಚಿನ ಆಜೂರ್ ಮಾದರಿಗಳನ್ನು ಅನುಸರಿಸುವುದಿಲ್ಲ. ಆಜೂರ್ MCP ಬಳಸಿದರೆ, ನೀವು ಹೊಸ ಪ್ರಮಾಣೀಕರಣ ವಿಧಾನಗಳನ್ನು, ಆಜೂರ್-ನಿರ್ದಿಷ್ಟ ದೋಷ ಪರಿಸ್ಥಿತಿಗಳನ್ನು ನಿರ್ವಹಿಸುವ ಕೋಡ್ ಪಡೆಯುತ್ತೀರಿ ಮತ್ತು ಮೈಕ್ರೋಸಾಫ್ಟ್ ಶಿಫಾರಸು ಮಾಡಿದ ಉತ್ಪಾದನಾ ಅಪ್ಲಿಕೇಶನ್ ಅಭ್ಯಾಸಗಳನ್ನು ಅನುಸರಿಸುತ್ತೀರಿ.

**ವೈಶಿಷ್ಟ್ಯಪೂರ್ಣ ಉದಾಹರಣೆ**: ನಾನು `az` ಮತ್ತು `azd` CLI ಗಳಿಗೆ ಸಂಬಂಧಿಸಿದ ನಿರ್ದಿಷ್ಟ ಕಮಾಂಡ್‌ಗಳನ್ನು ನೆನಪಿಸಿಕೊಳ್ಳಲು ಹತಾಶನಾಗಿದ್ದೇನೆ. ನನಗೆ ಅದು ಎರಡು ಹಂತದ ಪ್ರಕ್ರಿಯೆ: ಮೊದಲಿಗೆ ಸಿಂಟ್ಯಾಕ್ಸ್ ಪರಿಶೀಲಿಸಿ, ನಂತರ ಆ ಕಮಾಂಡ್ ಓಡಿಸಬೇಕು. ಪ್ರತಿ ಬಾರಿ ನಾನು ಕೆಲಸ ಮಾಡಲು ಪೋರ್ಟಲ್‌ಗೆ ಹೋಗಿ ಕ್ಲಿಕ್ ಮಾಡುತ್ತೇನೆ ಏಕೆಂದರೆ CLI ಸಿಂಟ್ಯಾಕ್ಸ್ ಅನ್ನು ನೆನಪಿಸಿಕೊಳ್ಳಲಾಗೋದಿಲ್ಲ. ನಾನು ಇಚ್ಛಿತ ವಸ್ತುವನ್ನು ಸರಳವಾಗಿ ವರ್ಣಿಸುವುದೇ ಅದ್ಭುತವಾದದ್ದು ಮತ್ತು ಅದನ್ನೇ ನನ್ನ IDE ನಿಂದ ಹೊರಹೊಮ್ಮದೆ ಮಾಡಲು ಸಾಧ್ಯವಾದರೆ ಇನ್ನೂ ಉತ್ತಮ.

ಆರಂಭಿಸಲು [ಆಜೂರ್ MCP ರೆಪೊ](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) ನಲ್ಲಿ ಉಪಯೋಗ ಪ್ರಕರಣಗಳ ಒಳ್ಳೆಯ ಪಟ್ಟಿಯಿದೆ. ಸಮಗ್ರ ಸೆಟಪ್ ಮಾರ್ಗದರ್ಶನಗಳು ಮತ್ತು ಮುಂದಿನ高级ಕಟ್ಟುಗಳಿಗಾಗಿ, [ಆಧಿಕೃತ ಆಜೂರ್ MCP ಡಾಕ್ಯುಮೆಂಟೇಷನ್](https://learn.microsoft.com/azure/developer/azure-mcp-server/) ನೋಡಿ.

GitHub MCP ಸರ್ವರ್:

- ಭದ್ರತಾ ಸ್ಕ್ಯಾನಿಂಗ್ ಫಲಿತಾಂಶಗಳನ್ನು ಸಂಗ್ರಹಿಸಿ ಗಂಭೀರ ಎಚ್ಚರಿಕೆಗಳನ್ನು ಪ್ರಾಥಮ್ಯ ಮಾಡುತ್ತದೆ

- ಸ್ಪ್ರಿಂಟ್ ಯೋಜನೆ ಮತ್ತು ಬಿಡುಗಡೆ ಸಿದ್ಧತೆಗಾಗಿ ಕಾರ್ಯಾಚರಣೀಯ ಮುಂದಿನ ಹಂತಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ

**ವೈಶಿಷ್ಟ್ಯಪೂರ್ಣ ಉದಾಹರಣೆ**: ನಾನು ಇದನ್ನು ಕೋಡ್ ವಿಮರ್ಶೆ ವರ್ಕ್‌ಫ್ಲೋಗಳಿಗಾಗಿ ಬಳಸುವುದು ಇಷ್ಟಪಡುತ್ತೇನೆ. VS ಕೋಡ್, GitHub ಸೂಚನೆಗಳು ಮತ್ತು ಪುಲ್ ರಿಕ್ವೆಸ್ಟ್ ಪುಟಗಳ ನಡುವೆ ಒಡೆವ ಬದಲಿಸುವ ಬದಲು, ನಾನು "ನನ್ನ ವಿಮರ್ಶೆಗೆ ಕಾಯುತ್ತಿರುವ ಎಲ್ಲಾ PR ಗಳನ್ನು ತೋರಿ" ಅಂದ್ರೆ, ನಂತರ "PR #123 ಗೆ authentication ವಿಧಾನದಲ್ಲಿ ದೋಷ ನಿರ್ವಹಣೆ ಬಗ್ಗೆ ಅಂದುಕೊಳ್ಳುವ ಕಾಮೆಂಟ್ ಸೇರಿಸಿ" ಅಂದುತ್ತೇನೆ. ಸರ್ವರ್ GitHub API ಕರೆಗಳನ್ನೆ ನಡೆಸುತ್ತದೆ, ಸಂವಾದದ ಸಾಪೇಕ್ಷತೆಯನ್ನು ಕಾಯ್ದಿರಿಸುತ್ತದೆ ಮತ್ತು ಇನ್ನಷ್ಟು ನಿರ್ಮಾಣಾತ್ಮಕ ವಿಮರ್ಶಾ ಕಾಮೆಂಟ್ ಗಳು ರಚಿಸಲು ಸಹಾಯ ಮಾಡುತ್ತದೆ.

**ಪ್ರಮಾಣೀಕರಣ ಆಯ್ಕೆಗಳು**: ಸರ್ವರ್ OAuth (VS ಕೋಡ್‌ನಲ್ಲಿ ಸಲೀಸಾಗಿ) ಮತ್ತು ವೈಯಕ್ತಿಕ ಪ್ರವೇಶ ಟೋಕನ್ ಗಳನ್ನೂ ಬೆಂಬಲಿಸುತ್ತದೆ, ಮತ್ತು ನೀವು ಬೇಕಾದ GitHub ಕಾರ್ಯಕ್ಷಮತೆಯನ್ನು ಮಾತ್ರ ಸಕ್ರಿಯಗೊಳಿಸಲು ನಿಮ್ಮ MCP ಸರ್ವರ್ ಸೆಟ್ಟಿಂಗ್ಸ್‌ನಲ್ಲಿ ಕಾನ್ಫಿಗರೆಷನ್ ಆಯ್ಕೆಗಳು ಲಭ್ಯವಿದೆ. ನೀವು ಅದನ್ನು ತಕ್ಷಣ ಧರೆಯುವ ದೂರಸೇವಾ ಸೇವೆಯಾಗಿ ಅಥವಾ ಸಂಪೂರ್ಣ ನಿಯಂತ್ರಣಕ್ಕಾಗಿ ಸ್ಥಳೀಯ ಡೋಕರ್ ಮೂಲಕ ಚಾಲನೆ ಮಾಡಬಹುದು.

- **ವೆಬ್ ವಿಷಯ**: HTML, RSS ಫೀಡ್ಗಳು, YouTube URL ಗಳು, ವಿಕಿಪೀಡಿಯಾ ಪುಟಗಳು
- **ಡೇಟಾ ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು**: CSV, JSON, XML, ZIP ಫೈಲ್‌ಗಳು (ಅಧಿಕಾರಿಯೋ ಪರಿಗಣಿಸುತ್ತದೆ)
- **ಪ್ರಕಟಣೆ ಫಾರ್ಮ್ಯಾಟ್‌ಗಳು**: EPub, ಜ್ಯೂಪಿಟರ್ ನೋಟುಪುಸ್ತಕಗಳು (.ipynb)
- **ಇಮೇಲ್**: ಔಟ್‌ಲುಕ್ ಸಂದೇಶಗಳು (.msg)
- **ಮುನ್ನಡೆಯುವಿಕೆ**: ಸುಧಾರಿತ PDF ಪ್ರಕ್ರಿಯೆಗಾಗಿ ಆಶರ್ ಡಾಕ್ಯುಮೆಂಟ್ ಇಂಟಲಿಜೆನ್ಸ್ ಒಕ್ಕೂಟ

**ಮುಂದುವರಿದ ಸಾಮರ್ಥ್ಯಗಳು**: MarkItDown LLM ಚಾಲಿತ ಚಿತ್ರ ವಿವರಣೆಗಳನ್ನು (ಒಪನ್‌ಎಐ ಕ್ಲೈಯೆಂಟ್ ನೀಡಿದಾಗ), ಆಶರ್ ಡಾಕ್ಯುಮೆಂಟ್ ಇಂಟಲಿಜೆನ್ಸ್ PDF ಪ್ರಕ್ರಿಯೆಗೆ, ಭಾಷಾಂತರಣೆಗೆ ಆಡಿಯೋ ಟ್ರಾನ್ಸ್ಕ್ರಿಪ್ಷನ್, ಮತ್ತು ಹೆಚ್ಚಿನ ಫೈಲ್ ಫಾರ್ಮ್ಯಾಟ್‌ಗಳಿಗೆ ಪ್ಲಗಿನ್ ವ್ಯವಸ್ಥೆಯನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ.

**ವಾಸ್ತವಿಕ ಬಳಕೆ**: "ಈ ಪವರ್‌ಪಾಯಿಂಟ್ ಪ್ರಸ್ತುತಿಯನ್ನು ನಮ್ಮ ಡಾಕ್ಯುಮೆಂಟೇಷನ್ ಸೈಟ್‌ಗೆ ಮಾರ್ಕ್‌ಡೌನ್ ಆಗಿ ಪರಿವರ್ತಿಸಿ", "ಈ PDF ನಿಂದ ಸರಿಯಾದ ಹೆಡ್‌ಇಂಗ್ ರಚನೆ ಜೊತೆಗೆ ಪಠ್ಯವನ್ನು ತೆಗೆಯಿರಿ", ಅಥವಾ "ಈ ಎಕ್ಸೆಲ್ ಸ್ಪ್ರೆಡ್‌ಶೀಟ್ ಅನ್ನು ಓದುವಂತಪಟ್ಟಿಕೆಯಾಗಿ ಪರಿವರ್ತಿಸಿ"

**ವೈಶಿಷ್ಟ್ಯಗೊಳಿಸಿದ ಉದಾಹರಣೆ**: [MarkItDown ಡಾಕ್](https://github.com/microsoft/markitdown#why-markdown) ಗಳನ್ನು ಉಲ್ಲೇಖಿಸಲು:

> ಮಾರ್ಕ್‌ಡೌನ್ ಸರಳ ಪಠ್ಯಕ್ಕೆ ಅತ್ಯಂತ ಹತ್ತಿರವಾಗಿದ್ದು, ಅಲ್ಪ ಮಾರುಕಟ್ಟೆ ಅಥವಾ ಫಾರ್ಮ್ಯಾಟಿಂಗ್ ಹೊಂದಿದೆ, ಆದರೆ ಮಹತ್ವಪೂರ್ಣ ಡಾಕ್ಯುಮೆಂಟ್ ರಚನೆ ಪ್ರತಿನಿಧಿಸಲು ಮාර්ಗ್ಗ ವರ್ತಿಸುತ್ತದೆ. ಮುಖ್ಯಪ್ರವಾಹದ LLM ಗಳು, ಉದಾಹರಣೆಗೆ OpenAI ನ GPT-4o, ಸ್ವತಃ "ಮಾರ್ಕ್‌ಡೌನ್" ಭಾಷೆ ಮಾತನಾಡುತ್ತವೆ ಮತ್ತು ಅನೇಕ ಬಾರಿ ನಿರ್ಧೇಶಿಸದೇ ಮಾರ್ಕ್‌ಡೌನ್ ಅನ್ನು ತಮ್ಮ ಪ್ರತಿಕ್ರಿಯೆಗಳಲ್ಲಿ ಸೇರಿಸುತ್ತವೆ. ಇದು ಅವು ದೊಡ್ಡ ಪ್ರಮಾಣದ ಮಾರ್ಕ್‌ಡೌನ್ ರೂಪಾಂತರಿತ ಪಠ್ಯದಲ್ಲಿ ತರಬೇತುಗೊಂಡಿರುವುದನ್ನು ಮತ್ತು ಅದನ್ನು ಚೆನ್ನಾಗಿ ಅರ್ಥಮಾಡಿಕೊಂಡಿರುವುದನ್ನು ಸೂಚಿಸುತ್ತದೆ. ಪಕ್ಕದ ಪ್ರಯೋಜನವಾಗಿ, ಮಾರ್ಕ್‌ಡೌನ್ ಸಂಪ್ರದಾಯಗಳು ಬಹಳ ಟೋಕನ್-ಕ್ಷಮತೆ ಯುಕ್ತವಾಗಿವೆ.

MarkItDown ಡಾಕ್ಯುಮೆಂಟ್ ರಚನೆಯನ್ನು ಉತ್ತಮವಾಗಿ ಉಳಿಸುವಲ್ಲಿ ಎಚ್ಚರಿಕೆಯಾಗಿದ್ದು, ಇದು AI ಕಾರ್ಯಪ್ರವಾಹಗಳಿಗೆ ಪ್ರಮುಖವಾಗಿದೆ. ಉದಾಹರಣೆಗೆ, ಪವರ್‌ಪಾಯಿಂಟ್ ಪ್ರಸ್ತುತಿಯನ್ನು ಪರಿವರ್ತಿಸುವಾಗ, ಇದು ಸ್ಲೈಡ್ ಸಂಘಟನೆಗೆ ಸೂಕ್ತ ಹೆಡ್‌ಇಂಗ್‌ಗಳನ್ನು ಉಳಿಸುತ್ತದೆ, ಪಟ್ಟಿಕೆಗಳನ್ನೂ ಮಾರ್ಕ್‌ಡೌನ್ ಪಟ್ಟಿಕೆಗಳಾಗಿ ತೆಗೆಯುತ್ತದೆ, ಚಿತ್ರಗಳಿಗೆ alt ಪಠ್ಯ ಸೇರಿಸುತ್ತದೆ, ಮತ್ತು ಸ್ಪೀಕರ್ ಟಿಪ್ಪಣಿಗಳನ್ನು ಕೂಡ ಪ್ರಕ್ರಿಯೆಗೊಳಿಸುತ್ತದೆ. ಚಾರ್ಟ್‌ಗಳು ಓದುವಂತ ಡೇಟಾ ಟೇಬಲ್ಗಳಾಗಿ ಪರಿವರ್ತಿಸುತ್ತವೆ ಮತ್ತು ಫಲಿತಾಂಕವಾದ ಮಾರ್ಕ್‌ಡೌನ್ ಮೂಲ ಪ್ರಸ್ತುತಿಯ ತರ್ಕಬದ್ಧ ಹರಿವನ್ನು ಉಳಿಸುತ್ತದೆ. ಇದು ಪ್ರಸ್ತುತ ವಿಷಯವನ್ನು AI ವ್ಯವಸ್ಥೆಗಳಿಗೆ ಪೂರೈಸಲು ಅಥವಾ ಇದುವರೆಗೆ ಇರುವ ಸ್ಲೈಡ್‍ಗಳಿಂದ ಡಾಕ್ಯುಮೆಂಟೇಷನ್ ಸೃಷ್ಟಿಸಲು ಸೂಕ್ತವೆಂದು ಮಾಡುತ್ತದೆ.
### 6. 🗃️ SQL ಸರ್ವರ್ MCP ಸರ್ವರ್

**ಇದು ಯಾಕೆ ಉಪಯುಕ್ತ**: ಪೋಸ್ಟ್‌ഗ്രೆಎಸ್‌ಕ್ಯೂಎಲ್ ಸರ್ವರ್ ಹೋಲುವುದೇ ಆದರೆ ಮೈಕ್ರೊಸಾಫ್ಟ್ SQL ಪರಿಸರದಿಗಾಗಿ. ಸರಳ ಸಂಪರ್ಕ ಸ್ಟ್ರಿಂಗ್ ಜೊತೆಗೆ ಸಂಪರ್ಕಿಸಿ ಹಾಗೂ ಸಹಜ ಭಾಷೆಯಲ್ಲಿ ಕೇಳಿ – ಇನ್ನು ಪರಸ್ಪರ ತಲೆತಪ್ಪಣೆಯ ಅಗತ್ಯವಿಲ್ಲ!

**ವಾಸ್ತವಿಕ ಬಳಕೆ**: "ಕೊನೆಯ 30 ದಿನಗಳಲ್ಲಿ ಪೂರ್ಣಗೊಳ್ಳದಿರುವ ಎಲ್ಲಾ ಆದೇಶಗಳನ್ನು ಹುಡುಕಿ" ಎಂಬುವುದನ್ನು ಸೂಕ್ತ SQL ಪ್ರಶ್ನೆಗಳಿಗೆ ಅನುವಾದಿಸಿ, ಸ್ವರೂಪಿತ ಫಲಿತಾಂಶಗಳನ್ನು ನೀಡುತ್ತದೆ

**ವೈಶಿಷ್ಟ್ಯಗೊಳಿಸಿದ ಉದಾಹರಣೆ**: ನಿಮ್ಮ ಡೇಟಾಬೇಸ್ ಸಂಪರ್ಕವನ್ನು ಸೆಟ್ ಮಾಡಿದ ಮೇಲೆ, ತಕ್ಷಣವೇ ನಿಮ್ಮ ಡೇಟಾ ಜೊತೆ ಸಂವಾದಗಳನ್ನು ಪ್ರಾರಂಭಿಸಬಹುದು. ಬ್ಲಾಗ್ ಪೋಸ್ಟ್ ಇದನ್ನು ಸರಳ ಪ್ರಶ್ನೆಯಾಗಿಯೇ ತೋರಿಸುತ್ತದೆ: "ನೀವು ಯಾವ ಡೇಟಾಬೇಸ್‌ಗೆ ಸಂಪರ್ಕ ಹೊಂದಿದ್ದೀರಿ?" MCP ಸರ್ವರ್ ಸೂಕ್ತ ಡೇಟಾಬೇಸ್ ಸಾಧನವನ್ನು ಕರೆಯುತ್ತದೆ, ನಿಮ್ಮ SQL ಸರ್ವರ್ ಇನ್ಸ್‌ಟ್ಯಾನ್ಸ್‌ಗೆ ಸಂಪರ್ಕಿಸುತ್ತದೆ ಮತ್ತು ನಿಮ್ಮ ಪ್ರಸ್ತುತ ಡೇಟಾಬೇಸ್ ಸಂಪರ್ಕದ ವಿವರಗಳನ್ನು ನೀಡುತ್ತದೆ – ಒಂದು ಸಾಲಿನ SQL ಬರೆಯದೇ. ಸರ್ವರ್ ಸ್ಥೂಲವಾಗಿ ಡೇಟಾಬೇಸ್ ಕಾರ್ಯಾಚರಣೆಗಳನ್ನು (ಸ್ಕಿಮಾ ನಿರ್ವಹಣೆ ಮತ್ತು ಡೇಟಾ ಮ್ಯಾನಿಪ್ಯುಲೇಷನ್) ಸಹಜ ಭಾಷೆಯ ಸೂಚನೆಗಳ ಮೂಲಕ ಬೆಂಬಲಿಸುತ್ತದೆ. ಪೂರ್ಣ ಸೆಟ್‌ಅಪ್ ಸೂಚನೆಗಳು ಮತ್ತು VS ಕೋಡ್ ಹಾಗೂ ಕ್ಲೋಡ್ ಡೆಸ್ಕ್‌ಟಾಪ್ ಕಾನ್ಫಿಗರ್ ಉದಾಹರಣೆಗಳಿಗೆ: [Introducing MSSQL MCP Server (Preview)](https://devblogs.microsoft.com/azure-sql/introducing-mssql-mcp-server/) ನೋಡಿ.

MCP ಬ್ರೌಸರ್ ಸೆಷನ್ ಪ್ರಾರಂಭಿಸಿದೆ, DOM snapshots ಬಳಸಿ ಪುಟ ರಚನೆ ಪರಿಶೀಲಿಸಿದೆ, ಸರಿಯಾದ ಸೆಲೆಕ್ಟರ್‌ಗಳನ್ನು ಕಂಡುಹಿಡಿದಿದೆ ಮತ್ತು ಮೊದಲ ಕಾರ್ಯಾಚರಣೆ ನಲ್ಲಿ ಪಾಸಾದ ಪೂರ್ಣ ಕಾರ್ಯನಿರ್ವಹಣಾ ಟೈಪ್ಸ್ಕ್ರಿಪ್ಟ್ ಪರೀಕ್ಷೆ ರಚಿಸಿದೆ.

ಇದು ನಿಜವಾಗಿ ಶಕ್ತಿಶಾಲಿಯಾಗಿರುವುದು ಸಹಜ ಭಾಷಾ ಸೂಚನೆಗಳ ಮತ್ತು ಕಾರ್ಯನಿರ್ವಹಣಾ ಪರೀಕ್ಷಾ ಕೋಡ್ ನಡುವಿನ ದ್ವಾರವನ್ನು ಸೇರುವುದರಿಂದ. ಸಾಂಪ್ರದಾಯಿಕ ವಿಧಾನಗಳು ಕಡ್ಡಾಯವಾಗಿ ಕೈಯಿಂದ ಪರೀಕ್ಷೆ ಬರೆಯಬೇಕಾಗುತ್ತದೆ ಅಥವಾ ಕೋಡ್ ಆಧಾರಕ್ಕೆ ಪ್ರವೇಶ ಬೇಕಾಗುತ್ತದೆ. ಆದರೆ ಪ್ಲೇರೈಟ್ MCP ನೊಂದಿಗೆ, ನೀವು ಹೊರಗಿನ ಸೈಟ್‌ಗಳು, ಕ್ಲೈಂಟ್ ಅಪ್ಲಿಕೇಶನ್‌ಗಳು ಅಥವಾ ಕೋಡ್ ಪ್ರವೇಶ ಇಲ್ಲದ ಬ್ಲಾಕ್ ಬಾಕ್ಸ್ ತಪಾಸಣೆ ಸಂದರ್ಭದಲ್ಲಿ ಪರೀಕ್ಷೆ ನಡೆಸಬಹುದು.

> **💡 ಪ್ರೋ ಟಿಪ್**
> 
> ಸೂಕ್ತ M365 ಅಭಿವೃದ್ಧಿ ಬೆಂಬಲಕ್ಕಾಗಿ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಲರ್ನ್ ಡಾಕ್ಸ್ MCP ಸರ್ವರ್ ಜೊತೆ ಈ ಸರ್ವರ್ ಅನ್ನು ಬಳಸಿ – ಒಂದು ಅಧಿಕೃತ ಡಾಕ್ಯುಮೆಂಟೇಶನ್ ಒದಗಿಸುತ್ತದೆ ಮತ್ತು ಇನ್ನೊಂದು ಅನ್ವಯಿಸುವ ಸಾಧನಗಳು ಮತ್ತು ಸಮಸ್ಯೆ ಪರಿಹಾರದ ಸಹಾಯವನ್ನು ಒದಗಿಸುತ್ತದೆ.


## ಮುಂದೇನು? 🔮

## 📋 ಸಂಕ್ಷೇಪ

ಮಾದರಿ ಸಂಧರ್ಭ ಪ್ರೋಟೋಕಾಲ್ (MCP) ಅಭಿವೃದ್ಧಿಪಡಿಸುವವರು AI ಸಹಾಯಕರು ಮತ್ತು ಹೊರಗಿನ ಸಾಧನಗಳೊಂದಿಗೆ ಸಂವಹನ ಹೇಗೆ ಮಾಡಬಹುದು ಎಂಬುದನ್ನು ಬದಲಾಯಿಸುತ್ತಿದೆ. ಈ 10 ಮೈಕ್ರೋಸಾಫ್ಟ್ MCP ಸರ್ವರ್‌ಗಳು ಐಕ್ಯತೆಯ AI ಸಂಯೋಜನೆಯ ಶಕ್ತಿಯನ್ನು ತೋರಿಸುತ್ತವೆ, ಇದು ಅಭಿವೃದ್ಧಿಪಡಿಸುವವರಿಗೆ ತಮ್ಮ ಪ್ರವಾಹ ಸ್ಥಿತಿಯಲ್ಲಿ ಉಳಿದಂತೆ ಶಕ್ತಿಶಾಲಿ ಹೊರಗಿನ ಸಾಮರ್ಥ್ಯಗಳಿಗೆ ಪ್ರವೇಶ ಹಂಚಿಕೊಳ್ಳುವ ನಿರಂತರ ಕಾರ್ಯಪ್ರವಾಹಗಳನ್ನು ಸಾಧ್ಯ ಮಾಡುತ್ತವೆ.

ಸಮಗ್ರ ಆಜೂರ್ ಪರಿಸರ ಸಮನ್ವಯದಿಂದ ಆರಂಭಿಸಿ ಬ್ರೌಸರ್ ಸ್ವಯಂಕರಣಕ್ಕಾಗಿ ಪ್ಲೇರೈಟ್ ಮತ್ತು ಡಾಕ್ಯುಮೆಂಟ್ ಪ್ರಕ್ರಿಯೆಗಾಗಿ ಮಾರ್ಕ್‌ಇಟ್‌ಡೌನ್ ಮುಂತಾದ ವಿಶೇಷ ಸಾಧನಗಳು, ಈ ಸರ್ವರ್‌ಗಳು MCP ಹೇಗೆ ವಿವಿಧ ಅಭಿವೃದ್ಧಿ ಸನ್ನಿವೇಶಗಳಲ್ಲಿ ಉತ್ಪಾದಕತೆಯನ್ನು ಹೆಚ್ಚಿಸುತ್ತದೆ ಎಂಬುದನ್ನು ತೋರಿಸುತ್ತವೆ. ಮಾನಕೃತ ಪ್ರೋಟೋಕಾಲ್ ಈ ಎಲ್ಲ ಸಾಧನಗಳು ಸೇರಿ ಕಾರ್ಯನಿರ್ವಹಿಸುವಂತೆ ಖಚಿತಪಡಿಸಿಕೊಳ್ಳುತ್ತದೆ, ಸಹಜವಾದ ಅಭಿವೃದ್ಧಿ ಅನುಭವ ಸೃಷ್ಟಿಸುತ್ತದೆ.

MCP ಪರಿಸರ ಅಭಿವೃದ್ದಿಯಾಗುತ್ತಿರೋಂತೆ, ಸಮುದಾಯದೊಂದಿಗೆ ನಿರಂತರ ಸಂಪರ್ಕದಲ್ಲಿರುವುದು, ಹೊಸ ಸರ್ವರ್‌ಗಳನ್ನು ಅನ್ವೇಷಿಸುವುದು ಮತ್ತು ಕಸ್ಟಮ್ ಪರಿಹಾರಗಳನ್ನು ನಿರ್ಮಿಸುವುದು ನಿಮ್ಮ ಅಭಿವೃದ್ಧಿ ಉತ್ಪಾದಕತೆಯನ್ನು ಗರಿಷ್ಠಗೊಳಿಸಲು ಮುಖ್ಯವಾಗುತ್ತದೆ. MCP ಯ ಉದ್ಘಾಟಿತ ಮಾನಕ ಸ್ವಭಾವವು ನೀವು ವಿಭಿನ್ನ ವಿಕ್ರೇತರಿಂದ ಸಾಧನಗಳನ್ನು ಮಿಶ್ರಿತವಾಗಿ ಬಳಸುವ ಅವಕಾಶವನ್ನು ನೀಡುತ್ತದೆ, ನಿಮ್ಮ ನಿರ್ದಿಷ್ಟ ಅಗತ್ಯಗಳಿಗೆ ಪರಿಪೂರ್ಣ ಕಾರ್ಯಪ್ರವಾಹವನ್ನು ಸೃಜಿಸುವಂತೆ.

1. **ಸ್ಥಾಪನೆ ಮತ್ತು ಸಂರಚನೆ**: ನಿಮ್ಮ VS ಕೋಡ್ ಪರಿಸರದಲ್ಲಿ ಒಂದು MCP ಸರ್ವರ್ ಅನ್ನು ಸೆಟ್ ಅಪ್ ಮಾಡಿ ಮತ್ತು ಮೂಲ ಕಾರ್ಯಕ್ಷಮತೆಯನ್ನು ಪರೀಕ್ಷಿಸಿ.

3. **ಕಸ್ಟಮ್ ಸರ್ವರ್ ಯೋಜನೆ**: ನಿಮ್ಮ ದೈನಂದಿನ ಅಭಿವೃದ್ಧಿ ಕಾರ್ಯದಲ್ಲಿ ಒಂದು ಕಾರ್ಯವನ್ನು ಗುರುತಿಸಿ ಅದಕ್ಕೆ ಲಾಭವಾಗುವಂತೆ ಕಸ್ಟಮ್ MCP ಸರ್ವರ್ ನಿಯೋಜಿಸಿ ಮತ್ತು ಅದರ विन್ಯಾಸವನ್ನು ಸೃಷ್ಟಿಸಿ.
4. **ಕಾರ್ಯಕ್ಷಮತೆ ವಿಶ್ಲೇಷಣೆ**: ಸಾಮಾನ್ಯ ಅಭಿವೃದ್ಧಿ ಕಾರ್ಯಗಳಿಗೆ MCP ಸರ್ವರ್‌ಗಳನ್ನು ಬಳಸುವ ಕಾರ್ಯಕ್ಷಮತೆಯನ್ನು ಪರಂಪರಿಕ ವಿಧಾನಗಳೊಂದಿಗೆ ಹೋಲಿಸಿ.
5. **ಸುರಕ್ಷತೆ ಮೌಲ್ಯಮಾಪನ**: ನಿಮ್ಮ ಅಭಿವೃದ್ಧಿ ಪರಿಸರದಲ್ಲಿ MCP ಸರ್ವರ್ ಬಳಕೆಯ ಸುರಕ್ಷತಾ ಪರಿಣಾಮಗಳನ್ನು ಮೌಲ್ಯಮಾಪನ ಮಾಡಿ ಮತ್ತು ಉತ್ತಮ ಅಭ್ಯಾಸಗಳನ್ನು ಸೂಚಿಸಿ.
