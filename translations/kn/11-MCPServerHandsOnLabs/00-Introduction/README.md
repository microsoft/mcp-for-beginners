## 🎯 ಈ ಪ್ರಯೋಗಾಲಯದಲ್ಲಿ ಏನು ಕವರ್ ಮಾಡಲಾಗಿದೆ

ಈ ಪರಿಚಯ ಪ್ರಯೋಗಾಲಯವು ಡೇಟಾಬೇಸ್ ಸಂಯೋಜನೆಯೊಂದಿಗೆ ಮಾದರಿ ಸಂಧರ್ಭ ಪ್ರೋಟೋಕಾಲ್ (MCP) ಸರ್ವರ್‌ಗಳನ್ನು ನಿರ್ಮಿಸುವ ಸಮಗ್ರ ವಿಮರ್ಶೆಯನ್ನು ನೀಡುತ್ತದೆ. ನೀವು ವ್ಯವಹಾರ ಪ್ರಕರಣ, ತಾಂತ್ರಿಕ ವಾಸ್ತುಶಿಲ್ಪ ಮತ್ತು ನಿಜಜೀವನ ಅನ್ವಯಗಳನ್ನು https://github.com/microsoft/MCP-Server-and-PostgreSQL-Sample-Retail ನಲ್ಲಿ ಜಾವಾ ರೀಟೆಲ್ ವಿಶ್ಲೇಷಣೆ ಬಳಕೆ ಪ್ರಕರಣದ ಮೂಲಕ ಅರ್ಥಮಾಡಿಕೊಳ್ಳುತ್ತೀರಿ.

## ಅವಲೋಕನ

**ಮಾದರಿ ಸಂಧರ್ಭ ಪ್ರೋಟೋಕಾಲ್ (MCP)** ಹೊರಗಿನ ಡೇಟಾ ಮೂಲಗಳಿಗೆ ಸುರಕ್ಷಿತವಾಗಿ ಪ್ರವೇಶಿಸಿ ನೈಜಕಾಲೀನವಾಗಿ ಸಂವಹನ ಮಾಡುವುದಕ್ಕೆ AI ಅಸಿಸ್ಟೆಂಟ್ಗಳಿಗೆ ಅವಕಾಶ ನೀಡುತ್ತದೆ. ಡೇಟಾಬೇಸ್ ಸಂಯೋಜನೆಯೊಂದಿಗೆ ಕೊಂಡಿಗೊಂಡಾಗ, MCP ಡೇಟಾ ಚಾಲಿತ AI ಅನ್ವಯಗಳ ಸಮರ್ಥ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ಅನ್ಲಾಕ್ ಮಾಡುತ್ತದೆ.

ಈ ಅಧ್ಯಯನ ಮಾರ್ಗವು PostgreSQL ಮೂಲಕ ರೀಟೆಲ್ ಮಾರಾಟ ಡೇಟಾಕ್ಕೆ AI ಅಸಿಸ್ಟೆಂಟ್ಗಳನ್ನು ಸಂಪರ್ಕಿಸುವ ಉತ್ಪಾದನೆ-ಸಿದ್ಧ MCP ಸರ್ವರ್‌ಗಳನ್ನು ನಿರ್ಮಿಸುವುದನ್ನು ಕಲಿಸುತ್ತದೆ, ರೋ ಲೆವೆಲ್ ಸೆಕ್ಯುರಿಟಿ, ಅರ್ಥಾತ್ಮಕ ಹುಡುಕಾಟ ಮತ್ತು ಬಹು-ಕರೆದ ಡೇಟಾ ಪ್ರವೇಶದಂತಹ ಸಂತೃಪ್ತ ಮಾದರಿಗಳನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸುತ್ತದೆ.

## ಅಧ್ಯಯನ ಉದ್ದೇಶಗಳು

ಈ ಪ್ರಯೋಗಾಲಯದ ಕೊನೆಯಲ್ಲಿ, ನೀವು ಸಾಧ್ಯವಾಗುವುದು:

- **ಮಾದರಿ ಸಂಧರ್ಭ ಪ್ರೋಟೋಕಾಲ್ ಮತ್ತು ಅದರ ಡೇಟಾಬೇಸ್ ಸಂಯೋಜನೆಯ ಪ್ರಮುಖ ಪ್ರಯೋಜನಗಳನ್ನು ವ್ಯಾಖ್ಯಾನಿಸಿ**
- **ಡೇಟಾಬೇಸ್‌ಗಳೊಂದಿಗೆ MCP ಸರ್ವರ್ ವಾಸ್ತುಶಿಲ್ಪದ ಪ್ರಮುಖ ಘಟಕಗಳನ್ನು ಗುರುತಿಸಿ**
- **ಜವಾ ರೀಟೆಲ್ ಬಳಕೆ ಪ್ರಕರಣ ಮತ್ತು ಅದರ ವ್ಯವಹಾರ ಅಗತ್ಯಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಿ**
- **ಸುರುಕ್ಷಿತ, ಪ್ರಮಾಣಕಟ್ಟಡ ಡೇಟಾಬೇಸ್ ಪ್ರವೇಶಕ್ಕಾಗಿ ಸಂಸ್ಥೆಯ ಮಾದರಿಗಳನ್ನು ಗುರುತಿಸಿ**
- **ಈ ಅಧ್ಯಯನ ಮಾರ್ಗದಲ್ಲಿ ಬಳಸುವ ಉಪಕರಣಗಳು ಮತ್ತು ತಂತ್ರಜ್ಞಾನಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡಿ**

## 🧭 ಸವಾಲು: AI ಮತ್ತು ನೈಜ ಲೋಕದ ಡೇಟಾ

### ಶಾಸ್ತ್ರೀಯ AI ಮಿತಿ

ಆಧುನಿಕ AI ಅಸಿಸ್ಟೆಂಟ್ಗಳು ಅತಿಮಹತ್ವದ ಸಾಮರ್ಥ್ಯ ಹೊಂದಿದ್ದರೂ ನೈಜ ಲೋಕದ ವ್ಯವಹಾರ ಡೇಟಾವನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸುವಾಗ ಪ್ರಮುಖ ಮಿತಿಗಳನ್ನು ಎದುರಿಸುತ್ತವೆ:

| **ಸವಾಲು** | **ವಿವರಣೆ** | **ವ್ಯವಹಾರ ಪರಿಣಾಮ** |
|---------------|-----------------|-------------------|
| **ಸ್ಥಿರ ಜ್ಞಾನ** | AI ಮಾದರಿಗಳು ಸ್ಥಿರ ಡೇಟಾ ಮೇಲೆ ತರಬೇತಿ ಹೊಂದಿದ್ದು, ಇತ್ತೀಚಿನ ವ್ಯವಹಾರ ಡೇಟಾವನ್ನು ಪ್ರವೇಶಿಸಲು ಆಗುವುದಿಲ್ಲ | ಹಳೆಯಾಗಿ ಮುಂಚೂಣಿಗೊಳಿಸದ ತಿಳಿವು, ಅವಕಾಶಗಳ ತಪ್ಪುಹಾಕಿಕೆ |
| **ಡೇಟಾ ಸೈಲೋಗಳು** | ಡೇಟಾಬೇಸ್‌ಗಳು, APIಗಳು ಮತ್ತು ವ್ಯವಸ್ಥೆಗಳು AI ತಲುಪಲಾರದೆ ಮಾಹಿತಿಯನ್ನು ಮುಚ್ಚಿಕೊಳ್ಳುತ್ತವೆ | ಅಪೂರ್ಣ ವಿಶ್ಲೇಷಣೆ, ವಿಭಾಗೀಕೃತ ಕೆಲಸದ ಹರಿವು |
| **ಭದ್ರತಾ ನಿಯಂತ್ರಣಗಳು** | ನೇರ ಡೇಟಾಬೇಸ್ ಪ್ರವೇಶ ಭದ್ರತೆ ಮತ್ತು ನಿಯಮಾನುಸಾರ ಆತಂಕಗಳನ್ನು ಹೊರತೂಗುತ್ತದೆ | ಸೀಮಿತ ಬಿತ್ತರಣೆ, ಕೈಯಿಂದ ಡೇಟಾ ಸಿದ್ಧತೆ |
| **ಸಂಕೀರ್ಣ ಪ್ರಶ್ನೆಗಳು** | ವ್ಯವಹಾರ ಬಳಕೆದಾರರು ಡೇಟಾ ಒಳನೋಟಗಳನ್ನು ಹಾಕಲು ತಾಂತ್ರಿಕ ಜ್ಞಾನ ಬೇಕಾಗುತ್ತದೆ | ಕಡಿಮೆ ಸ್ವೀಕಾರ, ಅಕಾರ್ಯಕ್ಷಮ ಪ್ರಕ್ರಿಯೆಗಳು |

### MCP ಪರಿಹಾರ

ಮಾದರಿ ಸಂಧರ್ಭ ಪ್ರೋಟೋಕಾಲ್ ಈ ಸವಾಲುಗಳನ್ನು ಈ ರೀತಿಯಲ್ಲಿ ಪರಿಹರಿಸುತ್ತದೆ:

- **ನೈಜಕಾಲೀನ ಡೇಟಾ ಪ್ರವೇಶ**: AI ಅಸಿಸ್ಟೆಂಟ್ಗಳು ಲೈವ್ ಡೇಟಾಬೇಸ್‌ಗಳು ಮತ್ತು APIಗಳನ್ನು ಪ್ರಶ್ನಿಸುತ್ತವೆ
- **ಸುರುಕ್ಷಿತ ಸಂಯೋಜನೆ**: ಪ್ರಮಾಣೀಕರಣ ಮತ್ತು ಅನುಮತಿಗಳೊಂದಿಗೆ ನಿಯಂತ್ರಿತ ಪ್ರವೇಶ
- **ಸ್ವಭಾವಿಕ ಭಾಷಾ ಸಂವಹನ**: ವ್ಯವಹಾರ ಬಳಕೆದಾರರು ಸರಳ ಇಂಗ್ಲೀಷ್‌ನಲ್ಲಿ ಪ್ರಶ್ನಿಸುತ್ತಾರೆ
- **ಪ್ರಮಾಣಿತ ಪ್ರೋಟೋಕಾಲ್**: ಬೇರೆ ಬೇರೆ AI ವೇದಿಕೆಗಳು ಮತ್ತು ಉಪಕರಣಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ

### ವ್ಯವಹಾರ ಅಗತ್ಯಗಳು

ಅಂಗಡಿ ವ್ಯವಸ್ಥಾಪಕರು ಮತ್ತು ಕಾರ್ಯನಿರ್ವಾಹಕರು AI ಚಾಲಿತ ವಿಶ್ಲೇಷಣೆಗಳನ್ನು ಅಗತ್ಯವಿರುತ್ತದೆ:

1. **ಅಂಗಡಿಗಳ ಮತ್ತು ಸಮಯ ಅವಧಿಗಳ ಮೂಲಕ ಮಾರಾಟದ ಪ್ರದರ್ಶನವನ್ನು ವಿಶ್ಲೇಷಿಸಿ**
2. **ಸರಕುಮಾಳಿಗೆ ಮಟ್ಟಗಳನ್ನು ಹอตಿಸಿ ಮತ್ತು ಪುನಃ ಸಂಗ್ರಹಿಸುವ ಅಗತ್ಯಗಳನ್ನು ಗುರುತಿಸಿ**
3. **ಗ್ರಾಹಕರ ನಡೆ ಮತ್ತು ಖರೀದಿ ಮಾದರಿಗಳನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳಿ**
4. **ಅರ್ಥಾತ್ಮಕ ಹುಡುಕಾಟದ ಮೂಲಕ ಉತ್ಪನ್ನ ಒಳನೋಟಗಳನ್ನು ಕಂಡುಹಿಡಿಯಿರಿ**
5. **ಸ್ವಾಭಾವಿಕ ಭಾಷಾ ಪ್ರಶ್ನೆಗಳೊಂದಿಗೆ ವರದಿಗಳನ್ನು ರಚಿಸಿ**
6. **ಪದವಿ ಆಧಾರಿತ ಪ್ರವೇಶ ನಿಯಂತ್ರಣ ಮೂಲಕ ಡೇಟಾ ಭದ್ರತೆಯನ್ನು ಕಾಪಾಡಿ**

### ತಾಂತ್ರಿಕ ಅಗತ್ಯಗಳು

MCP ಸರ್ವರ್ ಒದಗಿಸಬೇಕು:

- **ಬಹು-ಕರೆತ ಡೇಟಾ ಪ್ರವೇಶ**, ಅಂಗಡಿ ವ್ಯವಸ್ಥಾಪಕರು ತಾವು ನಿರ್ವಹಿಸುವ ಅಂಗಡಿಯ ಡೇಟಾ ಮಾತ್ರ ನೋಡಬಹುದು
- **ಲಾಗಲಿರುವ ಚಾಚು ಪ್ರಕಾರ ಪ್ರಶ್ನೆಗಳು** ಸಂಕೀರ್ಣ SQL ಕಾರ್ಯಾಚರಣೆಗಳನ್ನು ಬೆಂಬಲಿಸುವುದೇ ಆಗಬೇಕು
- **ಅರ್ಥಾತ್ಮಕ ಹುಡುಕಾಟ** ಉತ್ಪನ್ನ ಅನ್ವೇಷಣೆ ಮತ್ತು ಶಿಫಾರಸುಗಳಿಗೆ
- **ನೈಜಕಾಲೀನ ಡೇಟಾ** ಪ್ರಸ್ತುತ ವ್ಯವಹಾರ ಸ್ಥಿತಿಯನ್ನು ಪ್ರತಿಬಿಂಬಿಸುವುದು
- **ಭದ್ರತಾ ದೃಢೀಕರಣ** ರೋ ಲೆವೆಲ್ ಸೆಕ್ಯುರಿಟಿಯೊಂದಿಗೆ
- **ಪ್ರಮಾಣಕಟ್ಟಡ ವಾಸ್ತುಶಿಲ್ಪ** ಒಂದೇ ಸಮಯದಲ್ಲಿ ಅನೇಕ ಬಳಕೆದಾರರನ್ನು ಬೆಂಬಲಿಸುವುದು

### ಪ್ರಮುಖ ಘಟಕಗಳು

#### **1. MCP ಸರ್ವರ್ ಪದರ**
- **FastMCP ಫ್ರೇಮ್ವರ್ಕ್**: ಆಧುನಿಕ Python MCP ಸರ್ವರ್ ಅನುಷ್ಠಾನ
- **ಉಪಕರಣ ನೋಂದಣಿ**: ಪ್ರಕಾರದ ಸುರಕ್ಷತೆಯೊಂದಿಗೆ ಘೋಷಿತ ಉಪಕರಣ ವ್ಯಾಖ್ಯಾನಗಳು

- **ಪ್ರಶ್ನೆ ನಿರ್ವಾಹಕ**: RLS ಸಂಧರ್ಭದೊಂದಿಗೆ ಸುರಕ್ಷಿತ SQL ನಿರ್ವಹಣೆ
- **ಲೆನದ ನಿರ್ವಹಣೆ**: ACID ಅನುಕೂಲತೆ ಮತ್ತು ರೋದೀಕರಣ ನಿರ್ವಹಣೆ

#### **3. ಭದ್ರತಾ ಪದರ**
- **ರೋ ಲೆವೆಲ್ ಸೆಕ್ಯುರಿಟಿ**: ಬಹು-ಕರೆದ ಡೇಟಾ ಒಡೆಯತೆಯನ್ನು PostgreSQL RLS ಒದಗಿಸುತ್ತದೆ
- **ಬಳಕೆದಾರ ಗುರುತು**: ಅಂಗಡಿ ವ್ಯವಸ್ಥಾಪಕ ದೃಢೀಕರಣ ಮತ್ತು ಅನುಮತಿ
- **ಪ್ರವೇಶ ನಿಯಂತ್ರಣ**: ಸೂಕ್ಷ್ಮ ಅನುಮತಿಗಳು ಮತ್ತು ಆಡಿಟ್ ಟ್ರೇಲ್ಸ್
- **ಇನ್‌ಪುಟ್ ಮಾನ್ಯತೆ**: SQL ಇಂಜೆಕ್ಷನ್ ತಡೆ ಮತ್ತು ಪ್ರಶ್ನೆ ಮಾನ್ಯತೆ

#### **4. AI ವರ್ಧನೆ ಪದರ**
- **ಅರ್ಥಾತ್ಮಕ ಹುಡುಕಾಟ**: ಉತ್ಪನ್ನ ಅನ್ವೇಷಣೆಗೆ ವೆಕ್ಟರ್ ಎಂಬೆಡಿಂಗ್‌ಗಳು
- **ಅ್ಯಜುರ್ ಓಪನ್AI ಸಂಯೋಜನೆ**: ಪಠ್ಯ ಎಂಬೆಡಿಂಗ್ ತಯಾರಿ
- **ಸಮಾನತೆಯ ಆಲ್ಗಾರಿಥಮ್‌ಗಳು**: pgvector ಕೋಸೈನ್ ಸಮಾನತೆ ಹುಡುಕಾಟ
- **ಹುಡುಕಾಟ ಆಪ್ಟಿಮೈಜೇಶನ್**: ಸೂಚ್ಯಂಕ ಮತ್ತು ಕಾರ್ಯಕ್ಷಮತೆ ಸುಧಾರಣೆ

### ರೋ ಲೆವೆಲ್ ಸೆಕ್ಯುರಿಟಿ (RLS)

PostgreSQL RLS ಡೇಟಾ ಒಡೆಯತೆಯನ್ನು ಖಚಿತಪಡಿಸುತ್ತದೆ:

```sql
-- Store managers see only their store's data
CREATE POLICY store_manager_policy ON retail.orders
  FOR ALL TO store_managers
  USING (store_id = get_current_user_store());

-- Regional managers see multiple stores
CREATE POLICY regional_manager_policy ON retail.orders
  FOR ALL TO regional_managers
  USING (store_id = ANY(get_user_store_list()));
```

### ಬಳಕೆದಾರ ಗುರುತು ನಿರ್ವಹಣೆ

ಪ್ರತಿ MCP ಸಂಪರ್ಕದಲ್ಲಿ ಒಳಗೊಂಡಿದೆ:
- **ಅಂಗಡಿ ವ್ಯವಸ್ಥಾಪಕರ ID**: RLS ದೃಷ್ಟಿಕೋನಕ್ಕಾಗಿ ವಿಶಿಷ್ಟ ಗುರುತು
- **ಪದವಿ ಹಂಚಿಕೆ**: ಅನುಮತಿಗಳು ಮತ್ತು ಪ್ರವೇಶ ಮಟ್ಟಗಳು
- **ಸೆಷನ್ ನಿರ್ವಹಣೆ**: ಸುರಕ್ಷಿತ ದೃಢೀಕರಣ ಟೋಕನ್‌ಗಳು
- **ಆಡಿಟ್ ಲಾಗಿಂಗ್**: ಪೂರ್ಣ ಪ್ರವೇಶ ಇತಿಹಾಸ

### ಡೇಟಾ ರಕ್ಷಣೆ

ಭದ್ರತೆ ಬಹು ಪದರಗಳು:

- **SQL ಇಂಜೆಕ್ಷನ್ ತಡೆಯುವುದು**: ನಿಯಮಿತವಾದ ಪ್ರಶ್ನೆಗಳು ಮಾತ್ರ

✅ **ತಂತ್ರಜ್ಞಾನ ತಂತ್ರ**: ಈ ಅಧ್ಯಯನ ಮಾರ್ಗದಲ್ಲಿ ಉಪಕರಣಗಳು ಮತ್ತು ಫ್ರೇಮ್ವರ್ಕ್‌ಗಳು  
✅ **ಭದ್ರತಾ ಮಾದರಿ**: ಬಹು-ಕರೆತ ಡೇಟಾ ಪ್ರವೇಶ ಮತ್ತು ರಕ್ಷಣೆ  
✅ **ಬಳಕೆ ಮಾದರಿಗಳು**: ನೈಜ ಲೋಕದ ಪ್ರಶ್ನೆ ಘಟನೆಗಳು ಮತ್ತು ಕಾರ್ಯಪ್ರವಾಹಗಳು
