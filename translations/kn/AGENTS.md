# AGENTS.md

## ಯೋಜನೆಯ ಅವಲೋಕನ

**ಆರಂಭಿಕರಿಗಾಗಿ MCP** ಎಐ ಮಾದರಿಗಳ ಮತ್ತು ಕ್ಲೈಂಟ್ ಅನ್ವಯಿಕೆಗಳ ನಡುವೆ ಸಂವಹನಗಳಿಗಾಗಿರುವ ಮಾನಕೀಕೃತ ಬಾಧಕದ ರೂಪವಾದ ಮಾದರಿ ಸಂಧಿಭಾಷಣಾ ಪ್ರೋಟೋಕಾಲ್ (MCP) ಕಲಿಯುವ ಉಚಿತ ಶೈಕ್ಷಣಿಕ ಪಾಠಕ್ರಮವಾಗಿದೆ. ಈ ಸಂಗ್ರಹವು ಬಹು ಭಾಷೆಗಳಲ್ಲಿ ಕೈಲಾದ ಕೋಡ್ ಉದಾಹರಣೆಗಳು ಒಳಗೊಂಡ ಸಮಗ್ರ ಕಲಿಕಾ ಸಾಮಗ್ರಿಗಳನ್ನು ಒದಗಿಸುತ್ತದೆ.

### ಮುಖ್ಯ ತಂತ್ರಜ್ಞಾನಗಳು

- **ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಭಾಷೆಗಳು**: C#, ಜಾವಾ, ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್, ಟೈಪ್ಸ್ಕ್ರಿಪ್ಟ್, ಪೈಥಾನ್, ರಸ್ಟ್
- **ಫ್ರೇಮ್ವರ್ಕ್ಗಳು ಮತ್ತು SDKs**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - ಸ್ಪ್ರಿಂಗ್ ಬೂಟ್ (ಜಾವಾ)
  - ಫಾಸ್ಟ್MCP (ಪೈಥಾನ್)
  - ಲಾಂಗ್‌ಚೈನ್4ಜೆ (ಜಾವಾ)
- **ಡೇಟಾಬೇಸುಗಳು**: pgvector ವಿಸ್ತರಣೆ ಹೊಂದಿರುವ ಪೋಸ್ಟ್‌ಗ್ರೆಸ್‌ಕ್ಯೂಎಲ್
- **ಮೇಘ ವೇದಿಕೆಗಳು**: ಏಜೂರ್ (ಕಂಟೈನರ್ ಅಪ್ಲಿಕೇಶನ್ಸ್, ಓಪನ್‌ಎಐ, ವಿಷಯ ಭದ್ರತೆ, ಅಪ್ಲಿಕೇಶನ್ ಇನ್‌ಸೈಟ್ಸ್)
- **ಬಿಲ್ಡ್ ಸಾಧನಗಳು**: npm, ಮೇವೆನ್, ಪಿಪ್, ಕಾರ್ಗೋ
- **ದಾಖಲೆಗಳ ನಿರ್ಮಿತಿ**: ಸ್ವಯಂಚಾಲಿತ ಬಹುಭಾಷಾ ಅನುವಾದದೊಂದಿಗೆ ಮಾರ್ಕ್ಡೌನ್ (48+ ಭಾಷೆಗಳು)

### ವಾಸ್ತುಶಿಲ್ಪ

- **11 ಮುಖ್ಯ ಘಟಕಗಳು (00-11)**: ಮೂಲಭೂತಗಳಿಂದ ಪ್ರಗತಿಶೀಲ ವಿಷಯಗಳವರೆಗಿನ ಕ್ರಮಬದ್ಧ ಕಲಿಕೆ ಮಾರ್ಗ
- **ಪ್ರಾಯೋಗಿಕ ಪ್ರಯೋಗಾಲಯಗಳು**: ಬಹು ಭಾಷೆಗಳಲ್ಲಿ ಪೂರ್ಣ ಪರಿಹಾರ ಕೋಡ್ ಸಹಿತ ಪ್ರಾಯೋಗಿಕ ವ್ಯಾಯಾಮಗಳು
- **ನಮೂನಾ ಯೋಜನೆಗಳು**: ಕಾರ್ಯನಿರ್ವಹಿಸುವ MCP ಸರ್ವರ್ ಮತ್ತು ಕ್ಲೈಂಟ್ ಅನುಷ್ಠಾನಗಳು
- **ಅನುವಾದ ವ್ಯವಸ್ಥೆ**: ಬಹುಭಾಷಾ ಬೆಂಬಲಕ್ಕಾಗಿ ಸ್ವಯಂಚಾಲಿತ GitHub ಕ್ರಿಯೆಗಳು
- **ಚಿತ್ರ ಸಂಪನ್ಮೂಲಗಳು**: ಅನುವಾದಿತ varianteಗಳೊಂದಿಗೆ ಕೇಂದ್ರಿತ ಚಿತ್ರ ಡೈರೆಕ್ಟರಿ

## ಸ್ಥಾಪನೆ ಆಜ್ಞೆಗಳು

ಇದು ದಸ್ತಾವೇಜು-ಕೇಂದ್ರಿತ ಸಂಗ್ರಹವಾಗಿದೆ. ಬಹಳಷ್ಟು ಸ್ಥಾಪನೆ ವೈಯಕ್ತಿಕ ನಮೂನಾ ಯೋಜನೆಗಳು ಮತ್ತು ಪ್ರಯೋಗಾಲಯಗಳೊಳಗೆ ನಡೆಯುತ್ತದೆ.

### ಸಂಗ್ರಹಸ್ಥಳ ಸ್ಥಾಪನೆ

```bash
# ಸಂಗ್ರಹಣೆಯನ್ನು ನಕಲಿಸಿ
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### ನಮೂನಾ ಯೋಜನೆಗಳೊಂದಿಗಿನ ಕೆಲಸ

ನಮೂನಾ ಯೋಜನೆಗಳು ಇವುಗಳಲ್ಲಿ ಇವೆ:
- `03-GettingStarted/samples/` - ಭಾಷಾ-ವಿಶೇಷ ಉದಾಹರಣೆಗಳು
- `03-GettingStarted/01-first-server/solution/` - ಮೊದಲು ಸರ್ವರ್ ಅನುಷ್ಠಾನಗಳು
- `03-GettingStarted/02-client/solution/` - ಕ್ಲೈಂಟ್ ಅನುಷ್ಠಾನಗಳು
- `11-MCPServerHandsOnLabs/` - ಸಮಗ್ರ ಡೇಟಾಬೇಸ್ ಏಕೀಕರಣ ಪ್ರಯೋಗಾಲಯಗಳು

ಪ್ರತಿ ನಮೂನಾ ಯೋಜನೆಗೆ ಅದರ ಸ್ವಂತ ಸ್ಥಾಪನೆ ಸೂಚನೆಗಳು ಇವೆ:

#### ಟೈಪ್ಸ್ಕ್ರಿಪ್ಟ್/ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಯೋಜನೆಗಳು
```bash
cd <project-directory>
npm install
npm start
```

#### ಪೈଥಾನ್ ಯೋಜನೆಗಳು
```bash
cd <project-directory>
pip install -r requirements.txt
# ಅಥವಾ
pip install -e .
python main.py
```

#### ಜಾವಾ ಯೋಜನೆಗಳು
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

##### ಗುರಿ

ಪಠ್ಯಕ್ರಮದ ದಾಖಲೆ ಬದಲಾವಣೆಗಳು ಮತ್ತು ಪ್ರತಿನಿಧಿ ಮಾದರಿ ಕೋಡ್
ಸದೃಢತೆಯನ್ನು ಮರ್ಜ್ ಮಾಡುವ ಮೊದಲು ಪರಿಶೀಲಿಸಿ.

##### ಇನ್ಪುಟ್ಗಳು

- `changed_paths: string[]` (ಅಗತ್ಯವಿದ್ದು) - PRನಲ್ಲಿ ಬದಲಾಗಿದೆ ಅಪೇಕ್ಷಿತ ನಕ್ಷೆಗಳು.
- `run_docs_lint: boolean` (ಡೀಫಾಲ್ಟ್ `true`)
- `run_links_audit: boolean` (ಡೀಫಾಲ್ಟ್ `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (ಡೀಫಾಲ್ಟ್ ಎಲ್ಲಾ `false`)

##### ಔಟ್‌ಪುಟ್‌ಗಳು

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### ಅನುಮತಿಗಳು

- ವರ್ಕ್‌ಸ್ಪೇಸ್ ಕಡತಗಳನ್ನು ಓದಿ ಮತ್ತು ಸಾಧನ-ಎರಡಿಸಿದ ಕೃತಿಗಳನ್ನು ಬರೆಯಿರಿ (ಉದಾ: ಲಿಂಟ್
  ವರದಿಗಳು, ಪರೀಕ್ಷಾ ಲಾಗ್‌ಗಳು) ಮಾತ್ರ; `translations/` ಅಥವಾ
  `translated_images/` ಗೆ ಯಾವುದೇ ಬರವಣಿಗೆಗಳಿಲ್ಲ.
- ಸ್ಥಳೀಯ ಶೆಲ್ ಆಜ್ಞೆಗಳನ್ನು ನಿರ್ವಹಿಸಿ.
- ಪ್ಯಾಕೇಜ್ ಮರುಸ್ಥಾಪನೆಗೆ ಮಾತ್ರ ಐಚ್ಛಿಕ ಜಾಲ ಪ್ರವೇಶ (`npm ci`,
  `python -m pip install`, `mvn` ಡಿಪೆಂಡೆನ್ಸಿ ಪರಿಹಾರ).
- `translations/` ಅಥವಾ `translated_images/` ಗೆ ಪುಷ್, ಮರ್ಜ್ ಅಥವಾ
  ಬದಲಾವಣೆ ಮಾಡಲು ಅನುಮತಿ ಇಲ್ಲ.

##### ವಿಫಲನ ಇರುವ ಮಾರುಗುಗಳು

- `E_NO_INPUT_PATHS`: `changed_paths` ಖಾಲಿ.
- `E_INVALID_PATH`: ಇನ್ಪುಟ್ ಮಾರ್ಗವು ರೆಪೊ ರೂಟ್‌ಗೆ ಬಾಗಿಲುದಾಟುತ್ತದೆ.
- `E_LINT_FAILED`: ಮಾರ್ಕ್‌ಡೌನ್ ಲಿಂಟ್ ಶೂನ್ಯವಲ್ಲದ ನಿರ್ಗಮಿಸುತ್ತದೆ.
- `E_LINK_AUDIT_FAILED`: ಲಿಂಕ್ ಆಡಿಟ್ ಆಜ್ಞೆ ಶೂನ್ಯವಲ್ಲದ ನಿರ್ಗಮಿಸುತ್ತದೆ.
- `E_SAMPLE_TEST_FAILED`: ಮಾದರಿ ಪರೀಕ್ಷೆ/ನಿರ್ಮಾಣ ಶೂನ್ಯವಲ್ಲದ ನಿರ್ಗಮಿಸುತ್ತದೆ.
- `E_TIMEOUT`: ಆಜ್ಞೆ ನಿರ್ದಿಷ್ಟ ಸಮಯ ಮೀರಿದೆ.

##### ಶಿಫಾರಸು ಮಾಡಿದ CI ಒಪ್ಪಂದ

ಮಾನ್ಯತೆ ಸ್ವಯಂಚಾಲಿತಗೊಳಿಸಲು, ಕೆಳಗಿನಂತೆ CI ಕೆಲಸವನ್ನು ಗೂಡಿಸಿದಿರಿ:

- `*.md`, ಮಾದರಿ ಕೋಡ್ ಅಥವಾ ಈ ಕಡತವನ್ನು ಸ್ಪರ್ಶಿಸುವ ಪುಲ್ ಮನವಿ ಥಳಚಿಸುತ್ತವೆ.
- ಮೇಲ್ಕಂಡ ಆಜ್ಞೆಗಳು ನಿಖರವಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ.
- ಲಾಗ್ಗಳನ್ನು ಕೃತಿಗಳಿಂದ ತಡೆಹಿಡಿಯುತ್ತದೆ.
- ಯಾವುದೇ ಶೂನ್ಯವಲ್ಲದ ನಿರ್ಗಮಕೊಡ್‌ನಲ್ಲಿ ಕೆಲಸ ವಿಫಲ.
