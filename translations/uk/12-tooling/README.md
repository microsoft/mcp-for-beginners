# 🚀 Інструменти MCP

## 🧠 Огляд навчального шляху інтеграції бази даних MCP

Тут ви навчитеся використовувати інструменти, які використовують MCP. Ваш досвід роботи з цими інструментами покращиться, коли ви підключатимете до них MCP сервери.

## 🔗 Офіційні ресурси MCP

- 📘 [Документація MCP](https://modelcontextprotocol.io/) – Детальні підручники та керівництва користувача
- 📜 [Специфікація MCP (2026-07-28)](https://modelcontextprotocol.io/specification/2026-07-28/) – Архітектура протоколу та технічні посилання
- 🧑‍💻 [Репозиторій MCP на GitHub](https://github.com/modelcontextprotocol) – Відкриті SDK, інструменти та приклади коду
- 🌐 [Спільнота MCP](https://github.com/orgs/modelcontextprotocol/discussions) – Приєднуйтесь до обговорень та робіть внесок у спільноту
- 🔒 [OWASP MCP Топ 10](https://microsoft.github.io/mcp-azure-security-guide/mcp/) – Найкращі практики безпеки та зниження ризиків
