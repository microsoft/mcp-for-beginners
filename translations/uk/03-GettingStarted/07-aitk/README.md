# Використання сервера з розширення AI Toolkit для Visual Studio Code

Коли ви створюєте агент ШІ, справа не лише у генерації розумних відповідей; важливо також надати вашому агенту можливість діяти. Ось тут і вступає в гру Протокол контексту моделі (MCP). MCP полегшує агентам доступ до зовнішніх інструментів та сервісів у послідовний спосіб. Уявіть це як підключення вашого агента до набору інструментів, які він *справді* може використовувати.

Припустимо, ви підключаєте агента до сервера MCP калькулятора. Раптом ваш агент може виконувати математичні операції, просто отримуючи запит на кшталт «Яке 47 помножити на 89?» — без необхідності жорстко кодувати логіку або створювати спеціальні API.

## Огляд

У цьому уроці розглядається, як підключити сервер калькулятора MCP до агента за допомогою розширення [AI Toolkit](https://aka.ms/AIToolkit) у Visual Studio Code, даючи можливість вашому агенту виконувати математичні операції такі, як додавання, віднімання, множення та ділення через природну мову.

AI Toolkit — це потужне розширення для Visual Studio Code, яке спрощує розробку агентів. Інженери ШІ можуть легко створювати AI-додатки, розробляючи та тестуючи генеративні AI-моделі — локально або в хмарі. Розширення підтримує більшість провідних генеративних моделей, доступних сьогодні.

*Примітка*: Наразі AI Toolkit підтримує Python та TypeScript.

## Цілі навчання

Наприкінці цього уроку ви зможете:

- Використовувати сервер MCP через AI Toolkit.
- Налаштувати конфігурацію агента для виявлення та використання інструментів, наданих сервером MCP.
- Застосовувати інструменти MCP за допомогою природної мови.

## Підхід

Ось як слід підходити до цього на високому рівні:

- Створити агента та визначити його системний підказ.
- Створити сервер MCP з інструментами калькулятора.
- Підключити Agent Builder до сервера MCP.
- Перевірити виклик інструментів агента через природну мову.

Добре, тепер, коли ми розуміємо послідовність, налаштуємо агента ШІ для використання зовнішніх інструментів через MCP, розширивши його можливості!

## Вправа: Використання сервера

> [!WARNING]
> Примітка для користувачів macOS. Ми наразі розслідуємо проблему із встановленням залежностей на macOS. Через це користувачі macOS не зможуть завершити цей підручник на цей момент. Ми оновимо інструкції, як тільки з’явиться виправлення. Дякуємо за ваше терпіння та розуміння!

У цій вправі ви створите, запустите та покращите агента ШІ з інструментами сервера MCP у Visual Studio Code за допомогою AI Toolkit.

### -0- Підготовчий крок, додавання моделі OpenAI GPT-4o до Моїх моделей

Вправа використовує модель **GPT-4o**. Модель потрібно додати до **Моїх моделей** до створення агента.

![Знімок екрана інтерфейсу вибору моделів у розширенні AI Toolkit для Visual Studio Code. Заголовок "Find the right model for your AI Solution" із підписом, який заохочує користувачів відкривати, тестувати та розгортати AI-моделі. Нижче, у розділі “Popular Models,” відображено шість карт моделей: DeepSeek-R1 (хоститься на GitHub), OpenAI GPT-4o, OpenAI GPT-4.1, OpenAI o1, Phi 4 Mini (CPU - Small, Fast) та DeepSeek-R1 (хоститься на Ollama). Кожна картка включає опції “Add” модель або “Try in Playground](../../../../translated_images/uk/aitk-model-catalog.2acd38953bb9c119.webp)

1. Відкрийте розширення **AI Toolkit** із **Панелі активності**.
1. У розділі **Каталог** виберіть **Моделі**, щоб відкрити **Каталог моделей**. Вибір **Моделі** відкриває **Каталог моделей** у новій вкладці редактора.
1. У рядку пошуку **Каталогу моделей** введіть **OpenAI GPT-4o**.
1. Натисніть **+ Додати**, щоб додати модель до списку **Мої моделі**. Переконайтеся, що ви вибрали модель, яка **хоститься на GitHub**.
1. У **Панелі активності** переконайтеся, що модель **OpenAI GPT-4o** з’явилась у списку.

### -1- Створення агента

Конструктор **Agent (Prompt) Builder** дозволяє створювати та налаштовувати власних агентів на основі ШІ. У цьому розділі ви створите нового агента і призначите модель для ведення розмови.

![Знімок екрана інтерфейсу "Calculator Agent" у AI Toolkit для Visual Studio Code. Ліва панель: вибрано модель "OpenAI GPT-4o (через GitHub)". Системний підказ: "Ви професор університету, що викладає математику," користувацький підказ: "Поясни мені рівняння Фур’є простими словами." Додаткові опції: кнопки для додавання інструментів, увімкнення MCP Server, вибору структурованого виходу. Внизу синя кнопка «Запустити». На правій панелі в розділі «Get Started with Examples» наведено три приклади агентів: Веб-розробник (з MCP Server, Спрощувач другого класу, та Тлумач снів — кожен із коротким описом функцій.](../../../../translated_images/uk/aitk-agent-builder.901e3a2960c3e477.webp)

1. Відкрийте розширення **AI Toolkit** із **Панелі активності**.
1. У розділі **Інструменти** виберіть **Agent (Prompt) Builder**. Вибір цього відкриє конструктор у новій вкладці редактора.
1. Натисніть кнопку **+ Новий агент**. Розширення запустить майстер налаштувань через **Palette команд**.
1. Введіть ім’я **Calculator Agent** та натисніть **Enter**.
1. У конструкторі **Agent (Prompt) Builder** для поля **Модель** виберіть модель **OpenAI GPT-4o (через GitHub)**.

### -2- Створення системного підказу для агента

Коли агент готовий, час визначити його особистість і призначення. У цьому розділі ви використаєте функцію **Generate system prompt** для опису поведінки агента — у даному випадку агента-калькулятора — і дозволите моделі сформувати системний підказ для вас.

![Знімок екрана інтерфейсу "Calculator Agent" у AI Toolkit для Visual Studio Code із відкритим вікном моделі "Generate a prompt." Текст модального вікна пояснює, що шаблон підказки можна згенерувати, поділившись основними деталями, включаючи текстовий блок із прикладом системного підказу: "Ви корисний і ефективний асистент математики. При отриманні завдання з базової арифметики ви відповідаєте правильним результатом." Нижче кнопки "Close" та "Generate". На фоні видно частину конфігурації агента з вибраною моделлю "OpenAI GPT-4o (через GitHub)" і полями для системного та користувацького підказів.](../../../../translated_images/uk/aitk-generate-prompt.ba9e69d3d2bbe2a2.webp)

1. У розділі **Підказки** натисніть кнопку **Generate system prompt**. Ця кнопка відкриває будівник підказок, який використовує ШІ для створення системного підказу агента.
1. У вікні **Generate a prompt** введіть наступне: `Ви корисний і ефективний асистент математики. При отриманні завдання з базової арифметики ви відповідаєте правильним результатом.`
1. Натисніть кнопку **Generate**. У правому нижньому кутку з’явиться сповіщення про створення системного підказу. Після завершення генерації підказ увійде у поле **System prompt** у конструкторі **Agent (Prompt) Builder**.
1. Перегляньте системний підказ і при необхідності відредагуйте.

### -3- Створення сервера MCP

Тепер, коли ви визначили системний підказ агента — що керує його поведінкою та відповідями — пора надати агенту практичним можливостям. У цьому розділі ви створите сервер MCP калькулятора з інструментами для виконання додавання, віднімання, множення та ділення. Цей сервер дозволить вашому агенту виконувати математичні операції в режимі реального часу у відповідь на природномовні запити.

![Знімок екрана нижньої частини інтерфейсу Calculator Agent у розширенні AI Toolkit для Visual Studio Code. Відображаються розгортні меню “Інструменти” та “Структурований вихід,” а також розкривне меню "Виберіть формат виходу" із встановленим значенням “текст.” Справа кнопка “+ MCP Server” для додавання сервера Model Context Protocol. Вище розділу “Інструменти” показаний заповнювач для іконки зображення.](../../../../translated_images/uk/aitk-add-mcp-server.9742cfddfe808353.webp)

AI Toolkit оснащений шаблонами, щоб спростити створення власного сервера MCP. Ми використаємо шаблон Python для створення сервера MCP калькулятора.

*Примітка*: Наразі AI Toolkit підтримує Python та TypeScript.

1. У розділі **Інструменти** конструктора **Agent (Prompt) Builder** натисніть кнопку **+ MCP Server**. Розширення запустить майстер налаштувань через **Palette команд**.
1. Виберіть **+ Додати сервер**.
1. Виберіть **Створити новий сервер MCP**.
1. Виберіть шаблон **python-weather**.
1. Виберіть **Папка за замовчуванням** для збереження шаблону сервера MCP.
1. Введіть таке ім'я сервера: **Calculator**
1. Відкриється нове вікно Visual Studio Code. Виберіть **Так, я довіряю авторам**.
1. Використовуючи термінал (**Термінал** > **Новий термінал**), створіть віртуальне середовище: `python -m venv .venv`
1. У терміналі активуйте віртуальне середовище:
    1. Windows - `.venv\Scripts\activate`
    1. macOS/Linux - `source .venv/bin/activate`
1. У терміналі встановіть залежності: `pip install -e .[dev]`
1. У перегляді **Explorer** панелі **Activity Bar** розгорніть директорію **src** і відкрийте файл **server.py** у редакторі.
1. Замініть код у файлі **server.py** наступним кодом і збережіть:

    ```python
    """
    Sample MCP Calculator Server implementation in Python.

    
    This module demonstrates how to create a simple MCP server with calculator tools
    that can perform basic arithmetic operations (add, subtract, multiply, divide).
    """
    
    from mcp.server.fastmcp import FastMCP
    
    server = FastMCP("calculator")
    
    @server.tool()
    def add(a: float, b: float) -> float:
        """Add two numbers together and return the result."""
        return a + b
    
    @server.tool()
    def subtract(a: float, b: float) -> float:
        """Subtract b from a and return the result."""
        return a - b
    
    @server.tool()
    def multiply(a: float, b: float) -> float:
        """Multiply two numbers together and return the result."""
        return a * b
    
    @server.tool()
    def divide(a: float, b: float) -> float:
        """
        Divide a by b and return the result.
        
        Raises:
            ValueError: If b is zero
        """
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    ```

### -4- Запуск агента із сервером MCP калькулятора

Тепер, коли у вашого агента є інструменти, час їх використовувати! У цьому розділі ви надішлете запити агенту, щоб перевірити та переконатися, що агент використовує відповідний інструмент із сервера MCP калькулятора.

![Знімок екрана інтерфейсу Calculator Agent у AI Toolkit для Visual Studio Code. Ліва панель відображає сервер MCP під назвою local-server-calculator_server з чотирма доступними інструментами: add, subtract, multiply, та divide. Значок показує, що чотири інструменти активні. Нижче — згорнутий розділ “Структурований вихід” і синя кнопка “Запустити”. На правій панелі в розділі “Відповідь моделі” агент виконує інструменти multiply та subtract з вхідними даними {"a": 3, "b": 25} та {"a": 75, "b": 20} відповідно. Кінцева “Відповідь інструменту” показана як 75.0. Нижче є кнопка “Переглянути код”.](../../../../translated_images/uk/aitk-agent-response-with-tools.e7c781869dc8041a.webp)

Ви запустите сервер MCP калькулятора на вашому локальному ПК розробника через **Agent Builder** як клієнт MCP.

1. Натисніть `F5`, щоб почати відлагодження сервера MCP. **Agent (Prompt) Builder** відкриється в новій вкладці редактора. Статус сервера відображатиметься у терміналі.
1. У полі **User prompt** конструктора **Agent (Prompt) Builder** введіть: `Я купив 3 товари по 25 доларів кожен, а потім використав знижку 20 доларів. Скільки я заплатив?`
1. Натисніть кнопку **Запустити**, щоб отримати відповідь агента.
1. Перегляньте відповідь агента. Модель має зробити висновок, що ви заплатили **55 доларів**.
1. Ось що має відбутися:
    - Агент вибирає інструменти **multiply** і **subtract** для допомоги в розрахунках.
    - Встановлюються відповідні значення `a` і `b` для інструменту **multiply**.
    - Встановлюються відповідні значення `a` і `b` для інструменту **subtract**.
    - Відповіді кожного інструменту показані у відповідних **Tool Response**.
    - Кінцева відповідь моделі наведена у фінальній **Model Response**.
1. Надсилайте додаткові запити для подальшого тестування агента. Ви можете змінити існуючий запит у полі **User prompt**, натиснувши в поле та замінивши текст.
1. Після завершення тестування агента ви можете зупинити сервер через **термінал**, натиснувши **CTRL/CMD+C** для виходу.

## Завдання

Спробуйте додати новий інструмент у файл **server.py** (наприклад, функцію, що повертає квадратний корінь числа). Надсилайте додаткові запити, які вимагатимуть використання вашого нового інструменту (або існуючих інструментів). Не забудьте перезапустити сервер, щоб завантажити додані інструменти.
