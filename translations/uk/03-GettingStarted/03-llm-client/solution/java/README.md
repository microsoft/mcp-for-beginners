# Клієнт калькулятора LLM

> [!NOTE]
> Це рішення підключається до спадкового HTTP+SSE сервісу калькулятора курсу і
> орієнтоване на MCP API SDK `2025-11-25`. Це не приклад Streamable HTTP
> версії `2026-07-28`.

Java-застосунок, який демонструє, як використовувати LangChain4j для підключення до MCP (Model Context Protocol) сервісу калькулятора через MiniMax API, сумісний з OpenAI.

## Необхідні умови

- Java 21 або вище
- Maven 3.6+ (або використайте вкладений Maven wrapper)
- Ключ MiniMax API
- Запущений MCP сервіс калькулятора на `http://localhost:8080`

## Отримання ключа API

Цей застосунок використовує MiniMax API, сумісний з OpenAI. Дотримуйтесь цих кроків, щоб отримати ключ та кінцеву точку:

### 1. Оберіть кінцеву точку
1. Використовуйте `https://api.minimax.io/v1` для глобальної кінцевої точки
2. Використовуйте `https://api.minimaxi.com/v1` для кінцевої точки в Китаї

### 2. Створіть ключ API
1. Створіть ключ MiniMax API у вашому обліковому записі MiniMax
2. Збережіть ключ у безпечному місці

### 3. Встановіть змінні середовища

#### У Windows (Command Prompt):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### У Windows (PowerShell):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### У macOS/Linux:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## Налаштування та встановлення

1. **Клонуйте або перейдіть до каталогу проекту**

2. **Встановіть залежності**:
   ```cmd
   mvnw clean install
   ```
   Або якщо Maven встановлено глобально:
   ```cmd
   mvn clean install
   ```

3. **Встановіть змінні середовища** (див. розділ "Отримання ключа API" вище)

4. **Запустіть MCP сервіс калькулятора**:
   Переконайтеся, що сервіс MCP калькулятора з першої глави запущений на `http://localhost:8080/sse`. Він повинен працювати перед запуском клієнта.

## Запуск застосунку

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## Що робить застосунок

Застосунок демонструє три основні взаємодії з сервісом калькулятора:

1. **Додавання**: Обчислення суми 24.5 та 17.3
2. **Квадратний корінь**: Обчислення квадратного кореня з 144
3. **Допомога**: Показує доступні функції калькулятора

## Очікуваний результат

Під час успішного запуску ви побачите вивід, подібний до:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## Усунення несправностей

### Поширені проблеми

1. **"Змінна середовища OPENAI_API_KEY не встановлена"**
   - Переконайтеся, що змінна середовища `OPENAI_API_KEY` встановлена
   - Перезапустіть термінал/командний рядок після встановлення змінної

2. **"Відмова в підключенні до localhost:8080"**
   - Переконайтеся, що MCP сервіс калькулятора запущено на порту 8080
   - Перевірте, чи інший сервіс не використовує порт 8080

3. **"Не вдалося автентифікуватися"**
   - Перевірте дійсність вашого ключа API
   - Переконайтеся, що `OPENAI_BASE_URL` відповідає кінцевій точці, яку ви планували використовувати

4. **Помилки збірки Maven**
   - Переконайтеся, що у вас Java 21 або вище: `java -version`
   - Спробуйте очистити збірку: `mvnw clean`

### Налагодження

Щоб увімкнути налагоджувальне логування, додайте наступний аргумент JVM при запуску:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## Конфігурація

Застосунок налаштовано на:
- Використання MiniMax-M3 за замовчуванням; встановіть `MINIMAX_MODEL_ID` для вибору `MiniMax-M3` або `MiniMax-M2.7`
- Підключення до `OPENAI_BASE_URL`, якщо вона встановлена; інакше використовувати `https://api.minimaxi.com/v1` при `MINIMAX_REGION=cn_zh`, або `https://api.minimax.io/v1` за замовчуванням
- Підключення до MCP сервісу за адресою `http://localhost:8080/sse`
- Таймаут запитів 60 секунд

## Залежності

Ключові залежності, що використовуються в проекті:
- **LangChain4j**: для інтеграції ШІ та управління інструментами
- **LangChain4j MCP**: для підтримки Model Context Protocol
- **LangChain4j OpenAI official**: для інтеграції MiniMax API, сумісного з OpenAI
- **Spring Boot**: для фреймворку застосунку та впровадження залежностей
