- **2 Клієнт**, у цьому уроці ви дізнаєтесь, як написати клієнта, що може підключатися до вашого сервера, [до уроку](02-client/README.md)

- **3 Клієнт з LLM**, ще кращий спосіб написання клієнта — це додати LLM, щоб він міг "домовлятися" з вашим сервером про подальші дії, [до уроку](03-llm-client/README.md)

- **4 Використання режиму агента GitHub Copilot сервера в Visual Studio Code**. Тут ми розглядаємо запуск MCP сервера безпосередньо з Visual Studio Code, [до уроку](04-vscode/README.md)

- **5 Сервер транспортного рівня stdio** stdio — рекомендований стандарт для локальної комунікації MCP серверів і клієнтів, що забезпечує безпечну комунікацію через підпроцеси з вбудованою ізоляцією процесів [до уроку](05-stdio-server/README.md)

- **6 HTTP трансляція з MCP (Streamable HTTP)**. Дізнайтеся про стандартний
	віддалений транспорт у [MCP Специфікації 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http),
	а також про застарілу реалізацію на основі сесій, яка збережена в уроці.
	[до уроку](06-http-streaming/README.md)

- **7 Використання AI Toolkit для VSCode** для споживання та тестування ваших MCP клієнтів і серверів [до уроку](07-aitk/README.md)

- **8 Тестування**. Тут ми зосередимося на різних способах тестування нашого сервера й клієнта, [до уроку](08-testing/README.md)

- **9 Розгортання**. Цей розділ розгляне різні способи розгортання ваших MCP рішень, [до уроку](09-deployment/README.md)

- **10 Розширене використання сервера**. Цей розділ охоплює просунуті способи експлуатації сервера, [до уроку](./10-advanced/README.md)

- **11 Аутентифікація**. У цьому розділі йдеться про додавання простої аутентифікації — від Basic Auth до використання JWT і RBAC. Рекомендується почати з цього розділу, а потім ознайомитися з Розширеними темами в Розділі 5 та додатково посилити безпеку за рекомендаціями Розділу 2, [до уроку](./11-simple-auth/README.md)

- **12 MCP хости**. Налаштування та використання популярних хост-клієнтів MCP, включаючи Claude Desktop, Cursor, Cline і Windsurf. Вивчайте типи транспортів і усунення несправностей, [до уроку](./12-mcp-hosts/README.md)

- **13 MCP Інспектор**. Інтерактивне налагодження та тестування MCP серверів за допомогою інструменту MCP Інспектор. Вивчайте інструменти усунення несправностей, ресурси та протокольні повідомлення, [до уроку](./13-mcp-inspector/README.md)

- **14 Вибірка**. Опануйте застарілий примітив вибірки для `2025-11-25` і
	як мігрувати нові дизайни до прямої інтеграції постачальника LLM. Вибірка
	вилучена з MCP `2026-07-28`. [до уроку](./14-sampling/README.md)

- **15 MCP додатки**. Створюйте MCP сервери, які також відповідають інструкціями для UI, [до уроку](./15-mcp-apps/README.md)

Протокол Model Context (MCP) — відкритий протокол, що стандартизує спосіб надання контексту LLM застосунками. Думайте про MCP як про порт USB-C для AI-додатків — він забезпечує стандартизований спосіб підключення моделей штучного інтелекту до різних джерел даних і інструментів.

## Налаштування вашого MCP середовища

Перед початком роботи з MCP важливо підготувати середовище розробки та зрозуміти базовий робочий процес. Цей розділ проведе вас через початкові кроки налаштування для плавного старту з MCP.

### Передумови

Перед зануренням у розробку MCP переконайтеся, що у вас є:

- **Середовище розробки**: для обраної вами мови (C#, Java, Python, TypeScript або JavaScript)
- **IDE/Редактор**: Visual Studio, Visual Studio Code, IntelliJ, Eclipse, PyCharm або будь-який сучасний редактор коду
- **Менеджери пакетів**: NuGet, Maven/Gradle, pip або npm/yarn
- **API ключі**: для будь-яких AI сервісів, які ви плануєте використовувати у ваших хост-застосунках


### Офіційні SDK

У наступних розділах ви побачите рішення, побудовані на Python, TypeScript,
Java та .NET. Ось офіційні SDK.

Підтримка SDK для MCP `2026-07-28` впроваджується окремо для кожної мови.
Перед запуском прикладу перевірте версію пакета та примітки до релізу SDK
для підтримуваних ревізій протоколу. Дивіться
[офіційний список SDK](https://modelcontextprotocol.io/docs/sdk):
- [C# SDK](https://github.com/modelcontextprotocol/csharp-sdk) - Підтримується у співпраці з Microsoft
- [Java SDK](https://github.com/modelcontextprotocol/java-sdk) - Підтримується у співпраці з Spring AI
- [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) - Офіційна реалізація на TypeScript
- [Python SDK](https://github.com/modelcontextprotocol/python-sdk) - Офіційна реалізація на Python (FastMCP)
- [Kotlin SDK](https://github.com/modelcontextprotocol/kotlin-sdk) - Офіційна реалізація на Kotlin
- [Swift SDK](https://github.com/modelcontextprotocol/swift-sdk) - Підтримується у співпраці з Loopwork AI
- [Rust SDK](https://github.com/modelcontextprotocol/rust-sdk) - Офіційна реалізація на Rust
- [Go SDK](https://github.com/modelcontextprotocol/go-sdk) - Офіційна реалізація на Go

## Основні висновки

- Налаштування середовища розробки MCP є простим завдяки мовно-специфічним SDK
- Створення MCP серверів включає створення й реєстрацію інструментів з чіткими схемами
- MCP клієнти підключаються до серверів і моделей, щоб використовувати розширені можливості
- Тестування і налагодження є обов’язковими для надійної реалізації MCP
- Варіанти розгортання включають локальну розробку та хмарні рішення
