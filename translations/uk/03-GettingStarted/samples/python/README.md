# Сервер калькулятора MCP (Python)



Просте серверне впровадження Model Context Protocol (MCP) на Python, що забезпечує базову функціональність калькулятора.


## Встановлення

Встановіть необхідні залежності:

```bash
pip install -r requirements.txt
```

Або безпосередньо встановіть MCP Python SDK:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## Використання

### Запуск сервера

Сервер призначено для використання клієнтами MCP (наприклад, Claude Desktop). Щоб запустити сервер:

```bash
python mcp_calculator_server.py
```

**Примітка**: При запуску безпосередньо в терміналі ви побачите помилки валідації JSON-RPC. Це нормальна поведінка — сервер очікує повідомлення від MCP клієнтів у правильному форматі.

### Тестування функцій

Щоб перевірити правильність роботи функцій калькулятора:

```bash
python test_calculator.py
```

## Усунення неполадок

### Помилки імпорту

Якщо з'являється `ModuleNotFoundError: No module named 'mcp'`, встановіть MCP Python SDK:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### Помилки JSON-RPC при запуску безпосередньо

Помилки на кшталт "Invalid JSON: EOF while parsing a value" при безпосередньому запуску сервера — це очікувано. Сервер потребує повідомлень від MCP клієнтів, а не прямого вводу в терміналі.
