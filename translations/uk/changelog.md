# Журнал змін: MCP для навчальної програми початківців

Цей документ служить записом усіх значних змін, внесених до навчальної програми Model Context Protocol (MCP) для початківців. Зміни задокументовані у зворотному хронологічному порядку (новіші зміни спочатку).

## 29 липня 2026 року

### Новий модуль 08 Супутній урок: Надійні сайдкари та безпечні повтори

Додано незалежний від постачальника супутній урок для MCP-інструментів, які створюють реальні
ефекти, узгоджений із остаточною специфікацією `2026-07-28`.

- **Новий**: [урок-супутник про надійність сайдкарів][reliability-sidecar]
  використовує одну історію з підтримкою квитків, два діаграми Mermaid та потік рішень повторної спроби,
  щоб пояснити ключі стабільної роботи, атомарне подвійне приймання,
  примирення, докази та межу розширення Tasks.
- **Новий**: Вправи зі штучного введення помилок на стандартній бібліотеці Python та SQLite,
  які використовують окремі сховища операцій і квитків, щоб показати втрату відповіді
  після фіксації зовнішнього ефекту. Шість детерміністичних тестів охоплюють наївне
  дублювання, захищене відновлення перезапуску, конфлікти корисного навантаження,
  кешовані результати, активні претензії та одночасне подвійне прийняття.
- **Оновлено**: Модуль 08 тепер пов’язує супутній урок, ідентифікує
  фінальну модель Stateless Request `2026-07-28`, відокремлює OpenTelemetry
  спостережність від застарілої функції журналювання MCP і обмежує
  приклад повторної спроби лише для операцій читання.
- **Опціонально**: Урок відображає свої портативні концепції до однієї позначеної впровадженої спільноти
  реалізації, не роблячи хостинговий сервіс або мережевий виклик частиною
  вправи.

#### Виправлення безпеки на рівні коду (OWASP A03: Інжекція)

- **10-StreamliningAIWorkflows.../lab4/code/github_mcp_server/src/server.py**: Видалено `shell=True` з інструменту `open_in_vscode`. #### Основні поняття (01-CoreConcepts/) — повна модернізація
- **Оновлення версії протоколу**: Оновлено посилання на актуальну MCP Specification 2025-06-18 з версіонуванням за датою (формат YYYY-MM-DD)
- **Уточнення архітектури**: Покращені описи Host, Client і Server для відображення поточних архітектурних патернів MCP
  - Hosts тепер чітко визначені як AI-додатки, що координують кілька клієнтських MCP-з’єднань
  - Клієнти описані як протокольні конектори, які підтримують один-до-одного відносини із серверами
  - Сервери покращені з урахуванням сценаріїв локального та віддаленого розгортання
- **Перебудова примітивів**: Повне оновлення примітивів серверів і клієнтів
  - Примітиви серверів: Ресурси (джерела даних), Підказки (шаблони), Інструменти (виконувані функції) з детальними поясненнями та прикладами
  - Примітиви клієнтів: Вибірка (LLM completions), Залучення (ввід користувача), Логування (налагодження/моніторинг)
  - Оновлено згідно з актуальними патернами методів відкриття (`*/list`), отримання (`*/get`) та виконання (`*/call`)
- **Архітектура протоколу**: Запроваджено двошарову модель архітектури
  - Шар даних: базується на JSON-RPC 2.0 з управлінням життєвим циклом і примітивами
  - Транспортний шар: STDIO (локальний) та Streamable HTTP з SSE (віддалений) транспортні механізми
- **Фреймворк безпеки**: Комплексні принципи безпеки, включно з явною згодою користувача, захистом конфіденційності даних, безпекою виконання інструментів і безпекою транспортного шару
- **Патерни комунікації**: Оновлені повідомлення протоколу для демонстрації потоків ініціалізації, виявлення, виконання та сповіщення
- **Приклади коду**: Оновлені приклади на кількох мовах (.NET, Java, Python, JavaScript) для відображення сучасних патернів MCP SDK

#### Безпека (02-Security/) — комплексне оновлення безпеки  
- **Відповідність стандартам**: Повна відповідність вимогам безпеки MCP Specification 2025-06-18
- **Еволюція автентифікації**: Документовано розвиток від власних серверів OAuth до делегування зовнішньому провайдеру ідентифікації (Microsoft Entra ID)
- **Аналіз загроз, специфічних для ШІ**: Розширене покриття сучасних векторів атак на ШІ
  - Детальні сценарії атак ін’єкції підказок з прикладами з реального життя
  - Механізми отруєння інструментів та патерни атак "rug pull"
  - Отруєння вікна контексту та атаки на плутанину моделей
- **Рішення Microsoft для безпеки AI**: Комплексне покриття екосистеми безпеки Microsoft
  - AI Prompt Shields з передовими технологіями виявлення, виділення та техніками розмежування
  - Патерни інтеграції Azure Content Safety
  - GitHub Advanced Security для захисту ланцюга постачання
- **Розширене пом’якшення загроз**: Детальні засоби контролю безпеки для
  - Викрадення сесій із сценаріями атак, специфічними для MCP, та криптографічними вимогами до ідентифікаторів сесій
  - Проблеми Confused Deputy у проксі-сценаріях MCP з чіткими вимогами згоди
  - Уразливості пропуску токенів із обов’язковими контролями валідації
- **Безпека ланцюга постачання**: Розширено покриття AI ланцюга постачання з фондаційними моделями, сервісами embeddings, провайдерами контексту та API третіх сторін
- **Фундаментальна безпека**: Покращено інтеграцію з корпоративними патернами безпеки, включаючи архітектуру нульової довіри та екосистему безпеки Microsoft
- **Організація ресурсів**: Категоризовані комплексні посилання за типом (Офіційна документація, Стандарти, Дослідження, Рішення Microsoft, Посібники з впровадження)
