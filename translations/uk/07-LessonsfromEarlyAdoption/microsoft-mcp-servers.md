## 🔧 Розуміння серверів MCP: керівництво для початківців

### Що таке сервери MCP?

Якщо ви новачок у Протоколі Контексту Моделі (MCP), у вас може виникнути питання: "Що саме є сервером MCP і чому мені це цікаво?" Почнемо з простої аналогії.

Уявіть сервери MCP як спеціалізованих асистентів, які допомагають вашому AI-компаньйону з кодування (наприклад, GitHub Copilot) підключатися до зовнішніх інструментів та сервісів. Як ви використовуєте різні додатки на телефоні для різних задач — один для погоди, один для навігації, один для банкінгу — так і сервери MCP дають вашому AI-помічнику можливість взаємодіяти з різними інструментами та службами розробки.

### Проблема, яку вирішують сервери MCP

Раніше, якщо ви хотіли:
- Перевірити ваші ресурси Azure
- Створити проблему в GitHub
- Запитати дані з бази даних
- Знайти інформацію в документації

Вам доводилось припиняти кодування, відкривати браузер, переходити на потрібний вебсайт і вручну виконувати ці завдання. Це постійне переключення контексту порушує ваш потік і знижує продуктивність.

### Як сервери MCP трансформують ваш досвід розробки

За допомогою серверів MCP ви можете залишатися у своєму середовищі розробки (VS Code, Visual Studio тощо) і просто просити AI-помічника виконувати ці завдання. Наприклад:

**Замість традиційного робочого процесу:**
1. Припинити кодування
2. Відкрити браузер
3. Перейти в портал Azure
4. Переглянути деталі облікового запису зберігання
5. Повернутись до VS Code
6. Продовжити кодування

**Тепер ви можете робити так:**
1. Запитати в AI: "Який статус моїх облікових записів зберігання в Azure?"
2. Продовжувати кодувати з отриманою інформацією

### Ключові переваги для початківців

#### 1. 🔄 **Залишайтеся у стані потоку**
- Не потрібно перемикатися між багатьма додатками

- Замість запам'ятовування синтаксису SQL опишіть, які дані вам потрібні
- Замість запам'ятовування команд Azure CLI поясніть, що хочете зробити
- Нехай AI розбирається з технічними деталями, поки ви зосереджуєтесь на логіці

#### 3. 🔗 **З'єднуйте кілька інструментів разом**
- Створюйте потужні робочі процеси, поєднуючи різні сервіси

#### 4. 🌐 **Майте доступ до зростаючої екосистеми**
- Користуйтеся серверами, створеними Microsoft, GitHub та іншими компаніями
- Плавно комбінуйте інструменти від різних постачальників
- Приєднуйтесь до стандартизованої екосистеми, яка працює з різними AI-помічниками

#### 5. 🛠️ **Навчайтеся на практиці**
- Починайте з готових серверів, щоб зрозуміти концепції
- Поступово створюйте власні сервери, коли відчуєте впевненість

## Початок роботи з MCP у VS Code та Visual Studio 🚀

Налаштування цих серверів MCP просте, якщо ви використовуєте Visual Studio Code або Visual Studio 2022 з GitHub Copilot.

### Налаштування VS Code

Ось базовий процес для VS Code:

1. **Увімкніть режим агента**: у VS Code переключіться в режим агента у вікні Copilot Chat
2. **Налаштуйте сервери MCP**: додайте конфігурації серверів у ваш файл settings.json VS Code
3. **Запустіть сервери**: натисніть кнопку "Start" для кожного сервера, який хочете використовувати
4. **Виберіть інструменти**: оберіть, які сервери MCP увімкнути для поточної сесії

Для детальних інструкцій див. [документацію VS Code MCP](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Професійна порада: Керуйте сервери MCP як профі!**
> 
> У перегляді розширень VS Code тепер є [зручний новий інтерфейс для керування встановленими серверами MCP](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Ви можете швидко запускати, зупиняти та керувати будь-якими встановленими серверами MCP за допомогою чіткого, простого інтерфейсу. Спробуйте!

### Налаштування Visual Studio 2022

Для Visual Studio 2022 (версія 17.14 або новіша):

1. **Увімкніть режим агента**: натисніть випадаюче меню "Ask" у вікні GitHub Copilot Chat і оберіть "Agent"
2. **Створіть конфігураційний файл**: створіть файл `.mcp.json` у каталозі вашого рішення (рекомендоване розташування: `<SOLUTIONDIR>\.mcp.json`)
3. **Налаштуйте сервери**: додайте конфігурації серверів MCP у стандартному форматі MCP
4. **Схвалення інструментів**: під час запиту схваліть інструменти, які хочете використовувати, з відповідними дозволами

Для докладних інструкцій з налаштування Visual Studio див. [документацію Visual Studio MCP](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Кожен сервер MCP має свої вимоги до налаштування (рядки підключення, автентифікація тощо), але шаблон налаштування послідовний у обох IDE.

### 1. 📚 Сервер Microsoft Learn Docs MCP

[![Встановити у VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![Встановити у VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**Що він робить**: Сервер Microsoft Learn Docs MCP — це хмарний сервіс, який надає AI-помічникам доступ у реальному часі до офіційної документації Microsoft через Протокол Контексту Моделі. Він підключається до `https://learn.microsoft.com/api/mcp` і дозволяє виконувати семантичний пошук по Microsoft Learn, документації Azure, Microsoft 365 та інших офіційних джерелах Microsoft.

**Чому це корисно**: Хоча це може виглядати "просто як документація", цей сервер насправді є критично важливим для кожного розробника, який використовує технології Microsoft. Одна з найбільших скарг .NET розробників на AI-помічників полягає в тому, що вони не в курсі останніх випусків .NET і C#. Сервер Microsoft Learn Docs MCP розв’язує цю проблему, забезпечуючи доступ у реальному часі до найактуальнішої документації, API-референсів та кращих практик. Незалежно від того, чи ви працюєте з останніми SDK для Azure, вивчаєте нові функції C# 13 або впроваджуєте передові патерни Aspire, цей сервер гарантує, що ваш AI-помічник має доступ до авторитетної, актуальної інформації для створення точного, сучасного коду.

**Використання у реальному житті**: "Які команди az cli створити Azure контейнерний додаток відповідно до офіційної документації Microsoft Learn?" або "Як налаштувати Entity Framework з dependency injection в ASP.NET Core?" Або "Перевір цей код, щоб переконатися, що він відповідає рекомендаціям з продуктивності в документації Microsoft Learn." Сервер забезпечує комплексне охоплення Microsoft Learn, Azure docs і Microsoft 365 за допомогою просунутого семантичного пошуку для знаходження найбільш релевантної контекстно інформації. Він повертає до 10 високоякісних фрагментів контенту з назвами статей і URL-адресами, завжди отримуючи найновішу офіційну документацію від Microsoft у момент її публікації.

**Приклад**: Сервер надає інструмент `microsoft_docs_search`, який виконує семантичний пошук за офіційною технічною документацією Microsoft. Після налаштування ви можете ставити питання типу "Як реалізувати JWT-аутентифікацію в ASP.NET Core?" і отримувати детальні офіційні відповіді з посиланнями на джерело. Якість пошуку відмінна, бо він розуміє контекст – запитання про "контейнери" в контексті Azure поверне інформацію про Azure Container Instances, тоді як той самий термін у контексті .NET поверне релевантний опис колекцій C#.

Це особливо корисно для швидкозмінних або недавно оновлених бібліотек і сценаріїв використання. Наприклад, у деяких нещодавніх проєктах кодування я хотів використати нові функції останніх випусків Aspire та Microsoft.Extensions.AI. Завдяки включенню сервера Microsoft Learn Docs MCP я міг використовувати не лише API-документацію, але й інструкції та керівництва, які щойно були опубліковані.

### 2. ☁️ Azure MCP Server


[![Встановити у VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Встановити у VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Що це робить**: Azure MCP Server — це комплексний пакет із понад 15 спеціалізованих підключень до сервісів Azure, що інтегрує всю екосистему Azure у ваш AI робочий процес. Це не просто один сервер – це потужний набір, який включає управління ресурсами, підключення до баз даних (PostgreSQL, SQL Server), аналіз журналів Azure Monitor із KQL, інтеграцію з Cosmos DB і багато іншого.

**Чому це корисно**: Окрім управління ресурсами Azure, цей сервер суттєво покращує якість коду при роботі з SDK Azure. Використовуючи Azure MCP у режимі агента, ви не просто отримуєте допомогу у написанні коду – ви отримуєте *кращий* Azure-код, який відповідає сучасним схемам автентифікації, рекомендаціям з обробки помилок і використовує останні функції SDK. Замість загального коду, який можливо працює, ви отримуєте код, що дотримується рекомендованих Azure патернів для виробничих навантажень.

**Основні модулі включають**:
- **🗄️ Підключення до баз даних**: Прямий доступ природною мовою до Azure Database для PostgreSQL і SQL Server
- **📊 Azure Monitor**: Аналіз журналів на базі KQL та операційні інсайти
- **🌐 Управління ресурсами**: Повний життєвий цикл управління ресурсами Azure
- **🔐 Автентифікація**: Патерни DefaultAzureCredential і керованої ідентичності
- **📦 Сервіси збереження**: Операції з Blob Storage, Queue Storage та Table Storage
- **🚀 Контейнерні сервіси**: Azure Container Apps, Container Instances та управління AKS
- **І багато інших спеціалізованих підключень**

**Використання у реальному світі**: "Покажи мої облікові записи збереження Azure", "Запитай мою Log Analytics робочу область щодо помилок за останню годину" або "Допоможи мені створити Azure-додаток на Node.js з правильною автентифікацією"

**Повний демонстраційний сценарій**: Ось повний приклад, який показує потужність поєднання Azure MCP з розширенням GitHub Copilot для Azure у VS Code. Коли у вас встановлені обидва та ви даєте запит:

> "Створи скрипт на Python, який завантажує файл у Azure Blob Storage, використовуючи автентифікацію DefaultAzureCredential. Скрипт має підключатися до мого облікового запису Azure storage з назвою 'mycompanystorage', завантажувати у контейнер 'documents', створювати тестовий файл з поточним таймстемпом для завантаження, коректно обробляти помилки та виводити корисну інформацію, дотримуватись найкращих практик Azure щодо автентифікації та обробки помилок, містити коментарі про роботу автентифікації DefaultAzureCredential, а також бути структурованим з функціями та документацією."

Azure MCP Server згенерує повний продакшен-скрипт на Python, який:
- Використовує останній Azure Blob Storage SDK з правильними async патернами
- Реалізує DefaultAzureCredential з докладним поясненням ланцюжка fallback
- Містить надійну обробку помилок із врахуванням специфічних типів виключень Azure
- Дотримується найкращих практик Azure SDK для управління ресурсами та підключеннями
- Забезпечує детальне логування та інформативний вивід у консоль
- Створює коректно структурований скрипт з функціями, документацією та типізацією

Особливість у тому, що без Azure MCP ви могли би отримати загальний код для blob storage, який працює, але не відповідає актуальним Azure патернам. З Azure MCP ви отримуєте код, який використовує сучасні методи автентифікації, обробляє характерні помилки Azure і дотримується рекомендованих Microsoft практик для виробничих додатків.

**Приклад на практиці**: Мені завжди важко запам’ятати точні команди для CLI `az` і `azd` для випадкового використання. Це завжди двокроковий процес: спочатку шукаю синтаксис, потім виконую команду. Можливість просто описати, що мені потрібно, — це диво, а ще краще, що не треба покидати IDE!

- **🔔 Сповіщення**: Інтелектуальне керування сповіщеннями та контроль підписки на репозиторії

- Узагальнення результатів сканування безпеки з пріоритетизацією критичних сповіщень

**Опції автентифікації**: Сервер підтримує і OAuth (безшовно у VS Code), і Personal Access Tokens, з налаштовуваними наборами інструментів, щоб увімкнути лише потрібний функціонал GitHub. ### 5. 📝 MarkItDown MCP Server


[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_MarkItDown_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_MarkItDown_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/markitdown)

**Що це робить**: MarkItDown — це комплексний сервер конвертації документів, який перетворює різні формати файлів у високоякісний Markdown, оптимізований для використання з LLM та робочими процесами аналізу тексту.

**Чому це корисно**: Незамінний для сучасних робочих процесів документації! MarkItDown підтримує широкий спектр форматів файлів, зберігаючи при цьому важливу структуру документа, таку як заголовки, списки, таблиці та посилання. На відміну від простих інструментів витягання тексту, він орієнтується на збереження семантичного значення та форматування, що є цінним як для обробки ШІ, так і для зручного читання людьми.

**Підтримувані формати файлів**:
- **Офісні документи**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Медійні файли**: Зображення (з метаданими EXIF та OCR), Аудіо (з метаданими EXIF та транскрипцією мовлення)
- **Веб-контент**: HTML, RSS-канали, URL-адреси YouTube, сторінки Вікіпедії
- **Формати даних**: CSV, JSON, XML, ZIP-файли (рекурсивна обробка вмісту)
- **Публікаційні формати**: EPub, ноутбуки Jupyter (.ipynb)
- **Електронна пошта**: Повідомлення Outlook (.msg)
- **Розширені**: Інтеграція Azure Document Intelligence для покращеного опрацювання PDF

**Розширені можливості**: MarkItDown підтримує описи зображень на базі LLM (за наявності клієнта OpenAI), Azure Document Intelligence для покращеної обробки PDF, транскрипцію аудіо для мовного контенту та систему плагінів для розширення підтримки інших форматів файлів.

**Реальне застосування**: «Конвертувати цю презентацію PowerPoint у Markdown для нашого сайту документації», «Витягнути текст із цього PDF із правильною структурою заголовків» або «Перетворити цю таблицю Excel у читабельний формат таблиці»

**Приклад із документації**: Цитуючи [документацію MarkItDown](https://github.com/microsoft/markitdown#why-markdown):

> Markdown надзвичайно близький до простого тексту з мінімальним розміткою або форматуванням, але водночас дає змогу представляти важливу структуру документів. Основні LLM, такі як GPT-4o від OpenAI, нативно «говорять» Markdown і часто незаохочено включають Markdown у свої відповіді. Це свідчить про те, що вони були навчанні на величезних обсягах тексту у форматі Markdown і добре його розуміють. Як додаткову перевагу, конвенції Markdown також дуже ефективні щодо кількості токенів.

MarkItDown чудово зберігає структуру документів, що важливо для робочих процесів ШІ. Наприклад, при конвертації презентації PowerPoint він зберігає організацію слайдів із правильними заголовками, витягує таблиці як таблиці Markdown, додає альтернативний текст до зображень і навіть обробляє нотатки доповідача. Діаграми перетворюються у читабельні таблиці даних, і отриманий Markdown зберігає логічний потік оригінальної презентації. Це ідеально підходить для передачі контенту презентацій у системи ШІ або створення документації з існуючих слайдів.

- **📚 Управління знаннями**: Створюйте та керуйте індексами Azure AI Search, додавайте документи, налаштовуйте індексатори та створюйте складні системи RAG
- **⚡ Інтеграція AI агентів**: Підключайтеся до агентів Azure AI, запитуйте наявних агентів та оцінюйте їх продуктивність у реальних сценаріях
- **📊 Фреймворк оцінки**: Проводьте комплексні тестування тексту та агентів, генеруйте звіти в markdown та впроваджуйте контроль якості для застосунків ШІ
- **🚀 Інструменти прототипування**: Отримуйте інструкції зі встановлення для прототипування на GitHub та доступ до Microsoft Foundry Labs для дослідницьких моделей

## 📋 Висновок

Протокол Model Context Protocol (MCP) трансформує спосіб взаємодії розробників з AI асистентами та зовнішніми інструментами. Ці 10 серверів Microsoft MCP демонструють потужність стандартизованої інтеграції ШІ, дозволяючи забезпечити безперервні робочі процеси, що підтримують концентрацію розробників і одночасно надають доступ до потужних зовнішніх можливостей.

Від комплексної інтеграції екосистеми Azure до спеціалізованих інструментів, таких як Playwright для автоматизації браузера та MarkItDown для обробки документів, ці сервери демонструють як MCP може підвищити продуктивність у різних сценаріях розробки. Стандартизований протокол забезпечує безперебійну співпрацю цих інструментів, створюючи цілісний досвід розробки.

У міру розвитку екосистеми MCP важливо залишатися залученим до спільноти, досліджувати нові сервери та створювати власні рішення для максимізації продуктивності розробки. Відкритий характер стандарту MCP означає, що ви можете комбінувати інструменти від різних постачальників для створення ідеального робочого процесу, що відповідає вашим конкретним потребам.
