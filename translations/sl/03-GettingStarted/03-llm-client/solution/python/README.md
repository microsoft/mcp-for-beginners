# Zagon tega vzorca

Priporočamo, da namestite `uv`, vendar to ni obvezno, glejte [navodila](https://docs.astral.sh/uv/#highlights)

## -0- Ustvarite virtualno okolje

```bash
python -m venv venv
```

## -1- Aktivirajte virtualno okolje

```bash
venv\Scrips\activate
```

## -2- Namestite odvisnosti

```bash
pip install "mcp[cli]"
pip install openai
```

## -3- Konfigurirajte Microsoft Foundry

Namestite aktiven model, kot je `gpt-5.1` v Microsoft Foundry, nato nastavite:

```bash
export AZURE_OPENAI_ENDPOINT="https://<resource-name>.openai.azure.com"
export AZURE_OPENAI_API_KEY="<api-key>"
export AZURE_OPENAI_DEPLOYMENT="gpt-5.1"
```

`AZURE_OPENAI_DEPLOYMENT` je ime namestitve, ki se lahko razlikuje od
imena osnovnega modela. Pred izbiro modela preverite
[Microsoft Foundry urnik upokojitev modelov](https://learn.microsoft.com/azure/foundry/openai/concepts/model-retirement-schedule)
.

## -4- Zaženite vzorec


```bash
python client.py
```
