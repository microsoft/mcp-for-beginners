# MCP ਕੈਲਕੁਲੇਟਰ ਸਰਵਰ (ਪਾਇਥਨ)



ਇੱਕ ਸਧਾਰਣ ਮਾਡਲ ਕੰਟੈਕਸਟ ਪ੍ਰੋਟੋਕਾਲ (MCP) ਸਰਵਰ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ ਜੋ ਪਾਇਥਨ ਵਿੱਚ ਬੁਨਿਆਦੀ ਕੈਲਕੁਲੇਟਰ ਫੰਕਸ਼ਨਲਿਟੀ ਦਿੰਦਾ ਹੈ।


## ਇੰਸਟਾਲੇਸ਼ਨ

ਲੋੜੀਂਦੇ ਡਿਪੈਂਡੇਸੀਜ਼ ਨੂੰ ਇੰਸਟਾਲ ਕਰੋ:

```bash
pip install -r requirements.txt
```

ਜਾਂ MCP ਪਾਇਥਨ SDK ਸਿੱਧਾ ਇੰਸਟਾਲ ਕਰੋ:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## ਵਰਤੋਂ

### ਸਰਵਰ ਚਲਾਉਣਾ

ਸਰਵਰ MCP ਕਲਾਇੰਟਾਂ (ਜਿਵੇਂ ਕਿ Claude Desktop) ਵੱਲੋਂ ਵਰਤੋਂ ਲਈ ਤਿਆਰ ਕੀਤਾ ਗਿਆ ਹੈ। ਸਰਵਰ ਸ਼ੁਰੂ ਕਰਨ ਲਈ:

```bash
python mcp_calculator_server.py
```

**ਨੋਟ**: ਜਦੋਂ ਟਰਮੀਨਲ ਵਿੱਚ ਸਿੱਧਾ ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ, ਤਦ ਤੁਹਾਨੂੰ JSON-RPC ਵੈਧਤਾ ਗਲਤੀਆਂ ਦਿਖਾਈ ਦੇਣਗੀਆਂ। ਇਹ ਸਧਾਰਣ ਵਅਹਰ ਹੈ - ਸਰਵਰ MCP ਕਲਾਇੰਟ ਸੁਨੇਹਿਆਂ ਦੀ ਉਡੀਕ ਕਰ ਰਿਹਾ ਹੈ ਜੋ ਢੰਗ ਨਾਲ ਫਾਰਮੈਟ ਕੀਤੇ ਗਏ ਹਨ।

### ਫੰਕਸ਼ਨਾਂ ਦੀ ਜਾਂਚ

ਇਹ ਜਾਂਚਣ ਲਈ ਕਿ ਕੈਲਕੁਲੇਟਰ ਫੰਕਸ਼ਨ ਠੀਕ ਕੰਮ ਕਰਦੇ ਹਨ:

```bash
python test_calculator.py
```

## ਸਮੱਸਿਆ ਨਿਵਾਰਣ

### ਇੰਪੋਰਟ ਗਲਤੀਆਂ

ਜੇ ਤੁਹਾਨੂੰ `ModuleNotFoundError: No module named 'mcp'` ਦਿਸਦਾ ਹੈ, ਤਾਂ MCP ਪਾਇਥਨ SDK ਇੰਸਟਾਲ ਕਰੋ:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### ਸਿੱਧਾ ਚਲਾਉਂਦੇ ਸਮੇਂ JSON-RPC ਗਲਤੀਆਂ

ਜਦੋਂ ਸਰਵਰ ਸਿੱਧਾ ਚਲਾਇਆ ਜਾਂਦਾ ਹੈ ਤਾਂ "Invalid JSON: EOF while parsing a value" ਵਰਗੀਆਂ ਗਲਤੀਆਂ ਆਉਂਣਾ ਆਮ ਗੱਲ ਹੈ। ਸਰਵਰ ਨੂੰ MCP ਕਲਾਇੰਟ ਸੁਨੇਹਿਆਂ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ, ਸਿੱਧੇ ਟਰਮੀਨਲ ਇਨਪੁੱਟ ਦੀ ਨਹੀਂ।
