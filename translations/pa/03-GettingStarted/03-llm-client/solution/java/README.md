# ਕੈਲਕੂਲੇਟਰ LLM ਕਲਾਇੰਟ

ਇਕ ਜਾਵਾ ਐਪਲੀਕੇਸ਼ਨ ਜੋ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ LangChain4j ਨੂੰ ਵਰਤ ਕੇ ਕਿਸ ਤਰ੍ਹਾਂ MCP (ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕਾਲ) ਕੈਲਕੂਲੇਟਰ ਸੇਵਾ ਨਾਲ MiniMax OpenAI-ਸੰਗਤ API ਰਾਹੀਂ ਜੋੜਿਆ ਜਾ ਸਕਦਾ ਹੈ।

## ਲੋੜੀਂਦੇ

- ਜਾਵਾ 21 ਜਾਂ ਉਪਰਲੇ ਵਰਜ਼ਨ
- ਮਾਵਨ 3.6+ (ਜਾਂ ਸ਼ਾਮਲ ਮਾਵਨ ਰੈਪਰ ਨੂੰ ਵਰਤੋਂ)
- ਇੱਕ MiniMax API ਕੁੰਜੀ
- ਇੱਕ MCP ਕੈਲਕੂਲੇਟਰ ਸੇਵਾ ਜੋ `http://localhost:8080` 'ਤੇ ਚੱਲ ਰਹੀ ਹੋਵੇ

## API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰਨਾ

ਇਹ ਐਪਲੀਕੇਸ਼ਨ MiniMax OpenAI-ਸੰਗਤ API ਨੂੰ ਵਰਤਦਾ ਹੈ। ਆਪਣੀ ਕੁੰਜੀ ਅਤੇ ਐਂਡਪੁਆਇੰਟ ਪ੍ਰਾਪਤ ਕਰਨ ਲਈ ਹੇਠਾਂ ਦਿੱਤੇ ਕਦਮਾਂ ਦੀ ਪਾਲਣਾ ਕਰੋ:

### 1. ਇੱਕ ਐਂਡਪੁਆਇੰਟ ਚੁਣੋ
1. ਵਿਸ਼ਵਪੱਧਰੀ ਐਂਡਪੁਆਇੰਟ ਲਈ `https://api.minimax.io/v1` ਵਰਤੋ
2. ਚੀਨ ਐਂਡਪੁਆਇੰਟ ਲਈ `https://api.minimaxi.com/v1` ਵਰਤੋ

### 2. API ਕੁੰਜੀ ਬਣਾਓ
1. ਆਪਣੀ MiniMax ਖਾਤੇ ਤੋਂ MiniMax API ਕੁੰਜੀ ਬਣਾਓ
2. ਕੁੰਜੀ ਨੂੰ ਸੁਰੱਖਿਅਤ ਥਾਂ 'ਤੇ ਰੱਖੋ

### 3. ਵਾਤਾਵਰਣ ਵਰਨਾਨੀਆਂ ਸੈੱਟ ਕਰੋ

#### ਵਿੰਡੋਜ਼ (ਕਮਾਂਡ ਪ੍ਰਾਮਪਟ) 'ਤੇ:
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### ਵਿੰਡੋਜ਼ (ਪਾਵਰਸ਼ੈਲ) 'ਤੇ:
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### macOS/Linux 'ਤੇ:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## ਸੈਟਅਪ ਅਤੇ ਇੰਸਟਾਲੇਸ਼ਨ

1. **ਪ੍ਰੋਜੈਕਟ ਡਾਇਰੈਕਟਰੀ ਨੂੰ ਕਲੋਨ ਕਰੋ ਜਾਂ ਉਸ ਵਿੱਚ ਜਾਓ**

2. **ਡਿਪੈਂਡੇਨਸੀਜ਼ ਇੰਸਟਾਲ ਕਰੋ**:
   ```cmd
   mvnw clean install
   ```
   ਜਾਂ ਜੇ ਤੁਸੀਂ ਮਾਵਨ ਗਲੋਬਲੀ ਇੰਸਟਾਲ ਕੀਤਾ ਹੈ ਤਾਂ:
   ```cmd
   mvn clean install
   ```

3. **ਵਾਤਾਵਰਣ ਵਰਨਾਨੀਆਂ ਸੈੱਟ ਕਰੋ** (ਉਪਰ "API ਕੁੰਜੀ ਪ੍ਰਾਪਤ ਕਰਨਾ" ਸੈਕਸ਼ਨ ਵੇਖੋ)

4. **MCP ਕੈਲਕੂਲੇਟਰ ਸੇਵਾ ਸ਼ੁਰੂ ਕਰੋ**:
   ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਤੁਸੀਂ ਪਹਿਲੇ ਚੈਪਟਰ ਦੀ MCP ਕੈਲਕੂਲੇਟਰ ਸੇਵਾ `http://localhost:8080/sse` 'ਤੇ ਚਲਾ ਰਹੇ ਹੋ। ਇਹ ਕਲਾਇੰਟ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਚੱਲ ਰਹੀ ਹੋਣੀ ਚਾਹੀਦੀ ਹੈ।

## ਐਪਲੀਕੇਸ਼ਨ ਚਲਾਉਣਾ

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## ਐਪਲੀਕੇਸ਼ਨ ਕੀ ਕਰਦਾ ਹੈ

ਐਪਲੀਕੇਸ਼ਨ ਕੈਲਕੂਲੇਟਰ ਸੇਵਾ ਨਾਲ ਤਿੰਨ ਮੁੱਖ ਇੰਟਰੈਕਸ਼ਨਾਂ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ:

1. **ਜੋੜ**: 24.5 ਅਤੇ 17.3 ਦਾ ਜੋੜ ਪ੍ਰਾਪਤ ਕਰਦਾ ਹੈ
2. **ਬਰਾਬਰ ਵਿਰਲੀ**: 144 ਦੀ ਵਰਗਮੂਲ ਕੱਢਦਾ ਹੈ
3. **ਸਹਾਇਤਾ**: ਉਪਲਬਧ ਕੈਲਕੂਲੇਟਰ ਫੰਕਸ਼ਨਾਂ ਦਿਖਾਉਂਦਾ ਹੈ

## ਉਮੀਦ ਕੀਤੀ ਨਤੀਜਾ

ਸਫਲ ਤੌਰ 'ਤੇ ਚਲਾਉਂਦੇ ਸਮੇਂ, ਤੁਹਾਨੂੰ ਲਗਭਗ ਹੇਠਾਂ ਦਿੱਤਾ ਨਤੀਜਾ ਮਿਲੇਗਾ:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## ਸਮੱਸਿਆ ਨਿਵਾਰਣ

### ਆਮ ਸਮੱਸਿਆਵਾਂ

1. **"OPENAI_API_KEY ਵਾਤਾਵਰਣ ਵਰਨਾਨੀ ਸੈੱਟ ਨਹੀਂ ਹੈ"**
   - ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਤੁਸੀਂ `OPENAI_API_KEY` ਵਾਤਾਵਰਣ ਵਰਨਾਨੀ ਸੈੱਟ ਕੀਤੀ ਹੈ
   - ਵਰਨਾਨੀ ਸੈੱਟ ਕਰਨ ਤੋਂ ਬਾਅਦ ਆਪਣਾ ਟਰਮੀਨਲ/ਕਮਾਂਡ ਪ੍ਰਾਮਪਟ ਰੀਸਟਾਰਟ ਕਰੋ

2. **"localhost:8080 ਨਾਲ ਕਨੈਕਸ਼ਨ ਅਸਵੀਕਾਰ ਕੀਤਾ ਗਿਆ"**
   - ਯਕੀਨੀ ਬਣਾਓ ਕਿ MCP ਕੈਲਕੂਲੇਟਰ ਸੇਵਾ ਪੋਰਟ 8080 'ਤੇ ਚੱਲ ਰਹੀ ਹੈ
   - ਵੇਖੋ ਕਿ ਕੋਈ ਹੋਰ ਸੇਵਾ ਪੋਰਟ 8080 ਵਰਤ ਰਹੀ ਹੈ ਜਾਂ ਨਹੀਂ

3. **"ਪ੍ਰਮਾਣਿਕਤਾ ਅਸਫਲ ਰਹੀ"**
   - ਆਪਣੀ API ਕੁੰਜੀ ਦੀ ਵੈਧਤਾ ਸਤਿਆਪਿਤ ਕਰੋ
   - ਜਾਂਚ ਕਰੋ ਕਿ `OPENAI_BASE_URL` ਉਸ ਐਂਡਪੁਆਇੰਟ ਨਾਲ ਮੇਲ ਖਾਂਦਾ ਹੈ ਜੋ ਤੁਸੀਂ ਵਰਤਣ ਦਾ ਇरਾਦਾ ਰੱਖਦੇ ਹੋ

4. **ਮਾਵਨ ਬਿਲਡ ਗਲਤੀਆਂ**
   - ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਤੁਸੀਂ ਜਾਵਾ 21 ਜਾਂ ਉੱਚਾ ਵਰਤ ਰਹੇ ਹੋ: `java -version`
   - ਬਿਲਡ ਸਾਫ਼ ਕਰੋ: `mvnw clean` ਕੋਸ਼ਿਸ਼ ਕਰੋ

### ਡੀਬੱਗਿੰਗ

ਡੀਬੱਗ ਲੌਗਿੰਗ ਨੂੰ ਯੋਗ ਕਰਨ ਲਈ, ਚਲਾਉਂਦੇ ਸਮੇਂ ਹੇਠਾਂ ਦਿੱਤੀ JVM ਆਰਗੁਮੈਂਟ ਸ਼ਾਮਿਲ ਕਰੋ:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## ਸੰਰਚਨਾ

ਐਪਲੀਕੇਸ਼ਨ ਨੂੰ ਇਸ ਤਰ੍ਹਾਂ ਸੰਰਚਿਤ ਕੀਤਾ ਗਿਆ ਹੈ:
- ਮੂਲ ਰੂਪ ਵਿੱਚ MiniMax-M3 ਵਰਤਦਾ ਹੈ, ਜਾਂ ਜਦ `MINIMAX_MODEL_ID` ਸੈੱਟ ਹੁੰਦੀ ਹੈ ਤਾਂ MiniMax-M2.7
- ਜਦੋਂ `OPENAI_BASE_URL` ਸੈੱਟ ਹੁੰਦਾ ਹੈ ਤਾਂ ਇਸ ਨਾਲ ਜੁੜਦਾ ਹੈ; ਨਹੀਂ ਤਾਂ `MINIMAX_REGION=cn_zh` ਹੋਣ 'ਤੇ `https://api.minimaxi.com/v1` ਜਾਂ ਮੂਲ ਰੂਪ ਵਿੱਚ `https://api.minimax.io/v1` ਵਰਤਦਾ ਹੈ
- MCP ਸੇਵਾ ਨਾਲ `http://localhost:8080/sse` 'ਤੇ ਜੁੜਦਾ ਹੈ
- ਬੇਨਤੀ ਲਈ 60-ਸਕਿੰਟ ਦੀ ਟਾਈਮਆਉਟ ਵਰਤਦਾ ਹੈ

## ਡਿਪੈਂਡੇਨਸੀਜ਼

ਇਸ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਵਰਤੀ ਗਈਆਂ ਮੁੱਖ ਡਿਪੈਂਡੇਨਸੀਜ਼:
- **LangChain4j**: AI ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਅਤੇ ਟੂਲ ਪ੍ਰਬੰਧਨ ਲਈ
- **LangChain4j MCP**: ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕਾਲ ਸਹਿਯੋਗ ਲਈ
- **LangChain4j OpenAI ਅਧਿਕਾਰਿਕ**: MiniMax OpenAI-ਸੰਗਤ API ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਲਈ
- **Spring Boot**: ਐਪਲੀਕੇਸ਼ਨ ਫਰੇਮਵਰਕ ਅਤੇ ਡਿਪੈਂਡੇਨਸੀ ਇੰਜੈਕਸ਼ਨ ਲਈ

## ਲਾਇਸੈਂਸ

ਇਹ ਪ੍ਰੋਜੈਕਟ ਅਪਾਚੀ ਲਾਇਸੈਂਸ 2.0 ਤਹਿਤ ਲਾਇਸੈਂਸ ਕੀਤਾ ਗਿਆ ਹੈ - ਵੇਰਵਾ ਲਈ [LICENSE](../../../../../../03-GettingStarted/03-llm-client/solution/java/LICENSE) ਫ਼ਾਈਲ ਵੇਖੋ।
