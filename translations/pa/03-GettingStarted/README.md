## ਸ਼ੁਰੂਆਤ ਕਰਨਾ  

[![Build Your First MCP Server](../../../translated_images/pa/04.0ea920069efd979a.webp)](https://youtu.be/sNDZO9N4m9Y)

_(ਇਸ ਪਾਠ ਦੀ ਵੀਡੀਓ ਦੇਖਣ ਲਈ ਉਪਰ ਦਿੱਤੀ ਚਿੱਤਰ 'ਤੇ ਕਲਿੱਕ ਕਰੋ)_

ਇਸ ਭਾਗ ਵਿੱਚ ਕਈ ਪਾਠ ਹਨ:

- **1 ਤੁਹਾਡਾ ਪਹਿਲਾ ਸਰਵਰ**, ਇਸ ਪਹਿਲੇ ਪਾਠ ਵਿੱਚ, ਤੁਸੀਂ ਸਿੱਖੋਗੇ ਕਿ ਆਪਣਾ ਪਹਿਲਾ ਸਰਵਰ ਕਿਵੇਂ ਬਣਾਇਆ ਜਾਵੇ ਅਤੇ ਇੰਸਪੈਕਟਰ ਟੂਲ ਨਾਲ ਜाँचਿਆ ਜਾਵੇ, ਜੋ ਤੁਹਾਡੇ ਸਰਵਰ ਨੂੰ ਟੈਸਟ ਅਤੇ ਡੀਬੱਗ ਕਰਨ ਲਈ ਇੱਕ ਮੁੱਲਵਾਨ ਤਰੀਕਾ ਹੈ, [ਪਾਠ ਵੱਲ](01-first-server/README.md)

- **2 ਕਲਾਇੰਟ**, ਇਸ ਪਾਠ ਵਿੱਚ, ਤੁਸੀਂ ਸਿੱਖੋਗੇ ਕਿ ਉਹ ਕਿਵੇਂ ਲਿਖਿਆ ਜਾਵੇ ਜੋ ਤੁਹਾਡੇ ਸਰਵਰ ਨਾਲ ਜੁੜ ਸਕੇ, [ਪਾਠ ਵੱਲ](02-client/README.md)

- **3 ਕਲਾਇੰਟ ਲੈਗਲ੍ਰ ਮਾਡਲ (LLM) ਨਾਲ**, ਇੱਕ ਵਧੀਆ ਤਰੀਕਾ ਕਲਾਇੰਟ ਲਿਖਣ ਦਾ ਇਹ ਹੈ ਕਿ ਇਸ ਵਿੱਚ LLM ਜੋੜਿਆ ਜਾਵੇ ਤਾਂ ਜੋ ਇਹ ਤੁਹਾਡੇ ਸਰਵਰ ਨਾਲ "ਗੱਲਬਾਤ" ਕਰ ਸਕੇ ਕਿ ਕੀ ਕਰਨਾ ਹੈ, [ਪਾਠ ਵੱਲ](03-llm-client/README.md)

- **4 ਸਰਵਰ GitHub ਕੋਪਾਇਲਟ ਏਜੈਂਟ ਮੋਡ ਨੂੰ ਵਿਜੁਅਲ ਸਟੂਡੀਓ ਕੋਡ ਵਿੱਚ ਖਪਤ ਕਰਨਾ**। ਇੱਥੇ, ਅਸੀਂ ਵਿਜੁਅਲ ਸਟੂਡੀਓ ਕੋਡ ਤੋਂ ਅੰਦਰ MCP ਸਰਵਰ ਚਲਾਉਣ ਬਾਰੇ ਵੇਖ ਰਹੇ ਹਾਂ, [ਪਾਠ ਵੱਲ](04-vscode/README.md)

- **5 stdio ਟ੍ਰਾਂਸਪੋਰਟ ਸਰਵਰ** stdio ਟ੍ਰਾਂਸਪੋਰਟ ਸਥਾਨਕ MCP ਸਰਵਰ-ਤੋਂ-ਕਲਾਇੰਟ ਸੰਚਾਰ ਲਈ ਸਿਫਾਰਸ਼ੀ ਮਿਆਰੀ ਹੈ, ਜੋ ਸੁਰੱਖਿਅਤ subprocess-ਆਧਾਰਿਤ ਸੰਚਾਰ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ ਜਿਸ ਵਿੱਚ ਬਿਲਟ-ਇਨ ਪ੍ਰਕਿਰਿਆ ਇਕਲਤਾ ਹੁੰਦੀ ਹੈ [ਪਾਠ ਵੱਲ](05-stdio-server/README.md)

- **6 MCP ਨਾਲ HTTP ਸਟਰੀਮਿੰਗ (ਸਟਰੀਮੇਬਲ HTTP)** ਸਿੱਖੋ ਮਿਆਰੀ
	ਦੂਰੀ ਸੰਚਾਰ ਬਾਰੇ [MCP ਵਿਸ਼ੇਸ਼ਤਾ 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http),
	ਨਾਲ ਹੀ ਪੁਰਾਣੀ ਸੈਸ਼ਨ-ਆਧਾਰਿਤ ਲਾਗੂ ਕਾਰਵਾਈ ਜੋ ਪਾਠ ਵਿੱਚ ਸ਼ਾਮਲ ਹੈ।
	[ਪਾਠ ਵੱਲ](06-http-streaming/README.md)

- **7 VSCode ਲਈ AI ਟੂਲਕਿਟ ਦੀ ਵਰਤੋਂ** ਤੁਹਾਡੇ MCP ਕਲਾਇੰਟ ਅਤੇ ਸਰਵਰਾਂ ਨੂੰ ਖਪਤ ਅਤੇ ਟੈਸਟ ਕਰਨ ਲਈ [ਪਾਠ ਵੱਲ](07-aitk/README.md)

- **8 ਟੈਸਟਿੰਗ** ਇਸ ਵਿੱਚ ਅਸੀਂ ਖਾਸ ਤੌਰ 'ਤੇ ਫੋਕਸ ਕਰਾਂਗੇ ਕਿ ਕਿਵੇਂ ਅਸੀਂ ਵੱਖ-ਵੱਖ ਤਰੀਕਿਆਂ ਨਾਲ ਆਪਣੇ ਸਰਵਰ ਅਤੇ ਕਲਾਇੰਟ ਦੀ ਜਾਂਚ ਕਰ ਸਕਦੇ ਹਾਂ, [ਪਾਠ ਵੱਲ](08-testing/README.md)

- **9 ਡਿਪਲੋਇਮੈਂਟ** ਇਸ ਅਧਿਆਇ ਵਿੱਚ ਅਸੀਂ ਤੁਹਾਡੇ MCP ਹੱਲਾਂ ਨੂੰ ਵਖ-ਵਖ ਤਰੀਕਿਆਂ ਨਾਲ ਡਿਪਲੋਇ ਕਰਨ 'ਤੇ ਧਿਆਨ ਦੇਵਾਂਗੇ, [ਪਾਠ ਵੱਲ](09-deployment/README.md)

- **10 ਅਗਾਂਹ ਦਾ ਸਰਵਰ ਉਪਯੋਗ** ਇਸ ਅਧਿਆਇ ਵਿੱਚ ਅਗਾਂਹ ਦਾ ਸਰਵਰ ਉਪਯੋਗ ਢਕਿਆ ਗਿਆ ਹੈ, [ਪਾਠ ਵੱਲ](./10-advanced/README.md)

- **11 ਪਰਮਾਣਿਕਤਾ (Auth)** ਇਸ ਅਧਿਆਇ ਵਿੱਚ ਸادہ ਪਰਮਾਣਿਕਤਾ ਜੋੜਨ ਬਾਰੇ ਹੈ, ਬੇਸਿਕ ਆਥ ਤੋਂ ਲੈ ਕੇ JWT ਅਤੇ RBAC ਦੀ ਵਰਤੋਂ ਤੱਕ। ਤੁਹਾਨੂੰ ਸਲਾਹ ਦਿੱਤੀ ਜਾਂਦੀ ਹੈ ਕਿ ਇੱਥੋਂ ਸ਼ੁਰੂ ਕਰੋ ਅਤੇ ਫਿਰ ਅਗਾਂਹ ਦੇ ਵਿਚਾਰ ਤੀਜੇ ਅਧਿਆਇ ਵਿੱਚ ਵੇਖੋ ਅਤੇ ਦੂਜੇ ਅਧਿਆਇ ਵਿੱਚ ਸਿਫ਼ਾਰਸ਼ਾਂ ਅਨੁਸਾਰ ਵਾਧੂ ਸੁਰੱਖਿਆ ਮਜ਼ਬੂਤੀ ਕਰੋ, [ਪਾਠ ਵੱਲ](./11-simple-auth/README.md)

- **12 MCP ਹੋਸਟ** ਪਸੰਦੀਦਾ MCP ਹੋਸਟ ਕਲਾਇੰਟ ਜਿਵੇਂ ਕਿ Claude Desktop, Cursor, Cline, ਅਤੇ Windsurf ਨੂੰ ਕਨਫਿਗਰ ਕਰੋ ਅਤੇ ਵਰਤੋ। ਟ੍ਰਾਂਸਪੋਰਟ ਪ੍ਰਕਾਰ ਅਤੇ ਸਮੱਸਿਆ-ਹੱਲ ਬਾਰੇ ਸਿੱਖੋ, [ਪਾਠ ਵੱਲ](./12-mcp-hosts/README.md)

- **13 MCP ਇੰਸਪੈਕਟਰ** ਆਪਣੇ MCP ਸਰਵਰਾਂ ਨੂੰ ਇੰਟਰਐਕਟਿਵ ਤਰੀਕੇ ਨਾਲ ਡੀਬੱਗ ਅਤੇ ਟੈਸਟ ਕਰੋ MCP ਇੰਸਪੈਕਟਰ ਟੂਲ ਦੀ ਵਰਤੋਂ ਨਾਲ। ਟ੍ਰਬਲਸ਼ੂਟਿੰਗ ਟੂਲ, ਸਰੋਤ, ਅਤੇ ਪ੍ਰੋਟੋਕੋਲ ਸੁਨੇਹਿਆਂ ਬਾਰੇ ਸਿੱਖੋ, [ਪਾਠ ਵੱਲ](./13-mcp-inspector/README.md)


- **14 ਸੈਂਪਲਿੰਗ**। `2025-11-25` ਲਈ ਲੈਗਸੀ ਸੈਂਪਲਿੰਗ ਪ੍ਰਿਮਿਟਿਵ ਸਿੱਖੋ ਅਤੇ
	ਨਵੀਂ ਡਿਜ਼ਾਇਨਾਂ ਨੂੰ ਸਿੱਧਾ LLM ਪ੍ਰਦਾਤਾ ਸੰਕਲਨ ਵੱਲ ਕਿਵੇਂ ਮਾਈਗਰੇਟ ਕਰਨਾ ਹੈ। ਸੈਂਪਲਿੰਗ MCP `2026-07-28` ਵਿੱਚ
	ਡਿਪ੍ਰਿਕੇਟਡ ਹੈ। [ਸਬਕ ਵੱਲ](./14-sampling/README.md)

- **15 MCP ਐਪਸ**। ਉਹ MCP ਸਰਵਰ ਬਣਾਓ ਜੋ UI ਨਿਰਦੇਸ਼ਾਂ ਨਾਲ ਵੀ ਜਵਾਬ ਦਿੰਦੇ ਹਨ, [ਸਬਕ ਵੱਲ](./15-mcp-apps/README.md)

ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੌਲ (MCP) ਇੱਕ ਖੁਲ੍ਹਾ ਪ੍ਰੋਟੋਕੌਲ ਹੈ ਜੋ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ LLMs ਨੂੰ ਸੰਦਰਭ ਪ੍ਰਦਾਨ ਕਰਨ ਦਾ ਮਿਆਰੀਕ੍ਰਿਤ ਤਰੀਕਾ ਹੈ। MCP ਨੂੰ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ USB-C ਪੋਰਟ ਵਾਂਗ ਸੋਚੋ - ਇਹ AI ਮੌਡਲਾਂ ਨੂੰ ਵੱਖ-ਵੱਖ ਡੇਟਾ ਸਰੋਤਾਂ ਅਤੇ ਟੂਲਜ਼ ਨਾਲ ਜੁੜਨ ਦਾ ਮਿਆਰੀਕ੍ਰਿਤ ਤਰੀਕਾ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ।

## ਸਿੱਖਣ ਦੇ ਲਕੜੀ

ਇਸ ਸਬਕ ਦੇ ਅੰਤ ਤੱਕ, ਤੁਸੀਂ ਸਮਰੱਥ ਹੋਵੋਗੇ:

- MCP ਲਈ C#, ਜਾਵਾ, ਪਾਇਥਨ, ਟਾਈਪਸਕ੍ਰਿਪਟ, ਅਤੇ ਜਾਵਾਸਕ੍ਰਿਪਟ ਵਿੱਚ ਵਿਕਾਸ ਪ੍ਰਵਾਹ ਸੈੱਟਅੱਪ ਕਰਨਾ
- ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ (ਸੰਸਾਧਨ, ਪ੍ਰਾਂਪਟ, ਅਤੇ ਟੂਲਜ਼) ਨਾਲ ਬੁਨਿਆਦੀ MCP ਸਰਵਰ ਬਣਾਉਣਾ ਅਤੇ ਤਾਇਨਾਤ ਕਰਨਾ
- MCP ਸਰਵਰ ਨਾਲ ਜੁੜਨ ਵਾਲੀਆਂ ਹੋਸਟ ਐਪਲੀਕੇਸ਼ਨਾਂ ਬਣਾਉਣਾ
- MCP ਇੰਪਲੀਮੈਂਟੇਸ਼ਨਾਂ ਦਾ ਟੈਸਟ ਅਤੇ ਡੀਬੱਗ ਕਰਨਾ
- ਆਮ ਸੈੱਟਅੱਪ ਚੁਣੌਤੀਆਂ ਅਤੇ ਉਹਨਾਂ ਦੇ ਹੱਲ ਸਮਝਣਾ
- ਆਪਣੀਆਂ MCP ਇੰਪਲੀਮੈਂਟੇਸ਼ਨਾਂ ਨੂੰ ਲੋਕਪ੍ਰਿਯ LLM ਸੇਵਾਵਾਂ ਨਾਲ ਕਨੈਕਟ ਕਰਨਾ

## ਆਪਣਾ MCP ਵਾਤਾਵਰਣ ਸੈਟ ਕਰਨਾ

MCP ਨਾਲ ਕੰਮ ਕਰਨਾ ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ, ਆਪਣੇ ਵਿਕਾਸ ਵਾਤਾਵਰਣ ਨੂੰ ਤਿਆਰ ਕਰਨਾ ਅਤੇ ਮੂਲ ਵਰਕਫਲੋ ਨੂੰ ਸਮਝਣਾ ਮਹੱਤਵਪੂਰਨ ਹੈ। ਇਹ ਭਾਗ ਤੁਹਾਨੂੰ ਪ੍ਰਾਰੰਭਿਕ ਸੈਟਅੱਪ ਕਦਮਾਂ ਰਾਹੀਂ ਮਦਦ ਕਰੇਗਾ ਤਾਂ ਜੋ MCP ਨਾਲ ਸੁਚਾਰੂ ਸ਼ੁਰੂਆਤ ਹੋਵੇ।

### ਜ਼ਰੂਰੀਆਂ ਸ਼ਰਤਾਂ

MCP ਵਿਕਾਸ ਵਿੱਚ ਦਾਖਲ ਹੋਣ ਤੋਂ ਪਹਿਲਾਂ, ਇਹ ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਤੁਹਾਡੇ ਕੋਲ ਹੈ:

- **ਵਿਕਾਸ ਵਾਤਾਵਰਣ**: ਤੁਹਾਡੇ ਚੁਣੇ ਹੋਏ ਭਾਸ਼ਾ ਲਈ (C#, ਜਾਵਾ, ਪਾਇਥਨ, ਟਾਈਪਸਕ੍ਰਿਪਟ, ਜਾਂ ਜਾਵਾਸਕ੍ਰਿਪਟ)
- **IDE/ਸੰਪਾਦਕ**: Visual Studio, Visual Studio Code, IntelliJ, Eclipse, PyCharm, ਜਾਂ ਕੋਈ ਆਧੁਨਿਕ ਕੋਡ ਐਡੀਟਰ
- **ਪੈਕੇਜ ਮੈਨੇਜਰਜ਼**: NuGet, Maven/Gradle, pip, ਜਾਂ npm/yarn
- **API ਕੀਜ਼**: ਜੇਕਰ ਤੁਸੀਂ ਕਿਸੇ ਵੀ AI ਸੇਵਾਵਾਂ ਨੂੰ ਆਪਣੇ ਹੋਸਟ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿੱਚ ਵਰਤਣ ਦੀ ਯੋਜਨਾ ਕਰਦੇ ਹੋ


### ਅਧਿਕਾਰਿਕ SDKs

ਆਉਣ ਵਾਲੇ ਅਧਿਆਇਆਂ ਵਿੱਚ ਤੁਸੀਂ ਪਾਇਥਨ, ਟਾਈਪਸਕ੍ਰਿਪਟ,
ਜਾਵਾ ਅਤੇ .NET ਵਰਗੀਆਂ ਭਾਸ਼ਾਵਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਬਣੇ ਹੱਲ ਵੇਖੋਗੇ। ਇਹ ਹਨ ਅਧਿਕਾਰਿਕ SDKs।

MCP `2026-07-28` ਲਈ SDK ਦਾ ਸਮਰਥਨ ਭਾਸ਼ਾ ਮੁਤਾਬਕ ਅਲੱਗ-ਅਲੱਗ ਤਰੀਕੇ ਨਾਲ ਆ ਰਿਹਾ ਹੈ।
ਕਿਸੇ ਉਦਾਹਰਨ ਨੂੰ ਚਲਾਉਣ ਤੋਂ ਪਹਿਲਾਂ, ਉਸਦੇ ਪੈਕੇਜ ਵਰਜਨ ਅਤੇ SDK ਦੇ ਰਿਲੀਜ਼ ਨੋਟਸ ਵੇਖੋ
ਜੋ ਸਹਾਇਕ ਪ੍ਰੋਟੋਕੌਲ ਸੰਸ਼ੋਧਨਾਂ ਲਈ ਹਨ। ਵੇਖੋ
[ਅਧਿਕਾਰਿਕ SDK ਸੂਚੀ](https://modelcontextprotocol.io/docs/sdk):
- [C# SDK](https://github.com/modelcontextprotocol/csharp-sdk) - ਮਾਇਕਰੋਸਾਫਟ ਨਾਲ ਸਹਿਯੋਗ ਵਿੱਚ ਰੱਖਿਆ ਗਿਆ
- [Java SDK](https://github.com/modelcontextprotocol/java-sdk) - Spring AI ਨਾਲ ਸਹਿਯੋਗ ਵਿੱਚ ਰੱਖਿਆ ਗਿਆ
- [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) - ਅਧਿਕਾਰਿਕ ਟਾਈਪਸਕ੍ਰਿਪਟ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ
- [Python SDK](https://github.com/modelcontextprotocol/python-sdk) - ਅਧਿਕਾਰਿਕ ਪਾਇਥਨ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ (FastMCP)
- [Kotlin SDK](https://github.com/modelcontextprotocol/kotlin-sdk) - ਅਧਿਕਾਰਿਕ ਕੋਟਲਿਨ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ
- [Swift SDK](https://github.com/modelcontextprotocol/swift-sdk) - Loopwork AI ਨਾਲ ਸਹਿਯੋਗ ਵਿੱਚ ਰੱਖਿਆ ਗਿਆ
- [Rust SDK](https://github.com/modelcontextprotocol/rust-sdk) - ਅਧਿਕਾਰਿਕ ਰੱਸਟ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ
- [Go SDK](https://github.com/modelcontextprotocol/go-sdk) - ਅਧਿਕਾਰਿਕ ਗੋ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ

## ਮੁੱਖ ਨਤੀਜੇ

- MCP ਵਿਕਾਸ ਵਾਤਾਵਰਣ ਸੈੱਟ ਕਰਨਾ ਭਾਸ਼ਾ-ਨਿਰਧਾਰਿਤ SDKs ਨਾਲ ਸਿੱਧਾ ਸਧਾਰਾ ਹੈ
- MCP ਸਰਵਰ ਬਣਾਉਣ ਵਿੱਚ ਸਾਫ਼ ਸਕੀਮਿਆਂ ਨਾਲ ਟੂਲਜ਼ ਬਣਾਉਣਾ ਅਤੇ ਰਜਿਸਟਰ ਕਰਨਾ ਸ਼ਾਮਿਲ ਹੈ

- MCP ਗਾਹਕ ਸਰਵਰਾਂ ਅਤੇ ਮਾਡਲਾਂ ਨਾਲ ਜੁੜਦੇ ਹਨ ਤਾਂ ਜੋ ਵਧੀਕ ਸਮਰੱਥਾਵਾਂ ਦਾ ਲਾਭ ਉਠਾਇਆ ਜਾ ਸਕੇ
- ਟੈਸਟਿੰਗ ਅਤੇ ਡੀਬੱਗਿੰਗ ਭਰੋਸੇਯੋਗ MCP ਨਿਆਮਾਵਲੀ ਲਈ ਜਰੂਰੀ ਹਨ
