# ਚੇਂਜ਼ਲੌਗ: ਬਿਗਿਨਰਜ਼ ਲਈ MCP ਕਰਿਕੁਲਮ

ਇਹ ਦਸਤਾਵੇਜ਼ ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੋਲ (MCP) ਬਿਗਿਨਰਜ਼ ਕਰਿਕੁਲਮ ਵਿੱਚ ਕੀਤੀਆਂ ਗਈਆਂ ਸਾਰੀਆਂ ਮਹੱਤਵਪੂਰਣ ਬਦਲਾਵਾਂ ਦਾ ਰਿਕਾਰਡ ਹੈ। ਬਦਲਾਵ ਵਿਰੂੱਧ ਕਾਲਕ੍ਰਮਕ ਅਨੁਕ੍ਰਮ ਵਿੱਚ ਦਸਤਾਵੇਜ਼ ਕੀਤੇ ਗਏ ਹਨ (ਨਵੇਂ ਬਦਲਾਵ ਪਹਿਲਾਂ)।

## 6 ਅਕਤੂਬਰ, 2025

### ਸ਼ੁਰੂਆਤ ਹਿੱਸਾ ਵਧਾਈ - ਉੱਨਤ ਸਰਵਰ ਵਰਤੋਂ ਅਤੇ ਸਧਾਰਣ ਪ੍ਰਮਾਣੀਕਰਨ

#### ਉੱਨਤ ਸਰਵਰ ਵਰਤੋਂ (03-GettingStarted/10-advanced)
- **ਨਵਾਂ ਅਧਿਆਇ ਸ਼ਾਮਲ ਕੀਤਾ**: ਉੱਨਤ MCP ਸਰਵਰ ਵਰਤੋਂ ਲਈ ਵਿਸ਼ਤ੍ਰਿਤ ਮਾਰਗਦਰਸ਼ਕ, ਦੋਹਾਂ ਸਧਾਰਣ ਅਤੇ ਨੀਵੀਂ ਪੱਧਰੀ ਸਰਵਰ ਬਣਾਉਣ ਵਾਲੇ ਢਾਂਚਿਆਂ ਨੂੰ ਕਵਰ ਕੀਤਾ
  - **ਸਧਾਰਣ ਵਿ. ਨੀਵੀ ਪੱਧਰ ਸਰਵਰ**: ਦੋਹਾਂ ਪਹੁੰਚਿਆਂ ਲਈ ਪਾਇਥਨ ਅਤੇ ਟਾਈਪਸਕ੍ਰਿਪਟ ਵਿੱਚ ਵਿਸ਼ਤ੍ਰਿਤ ਤੁਲਨਾ ਅਤੇ ਕੋਡ ਉਦਾਹਰਨਾਂ
  - **ਹੈਂਡਲਰ-ਅਧਾਰਿਤ ਡਿਜ਼ਾਈਨ**: ਸਕੇਲ ਕਰਨਯੋਗ, ਲਚਕੀਲੇ ਸਰਵਰ ਲਾਗੂ ਕਰਨ ਲਈ ਟੂਲ/ਸਰੋਤ/ਪਰੰਪਟ ਪ੍ਰਬੰਧਨ ਦਾ ਵਰਣਨ
  - **ਪ੍ਰਯੋਗਿਕ ਪੈਟਰਨ**: ਅਸਲੀ ਦੁਨੀਆ ਦੇ ਸਿਨਾਰਿਓਜ਼ ਜਿੱਥੇ ਨੀਵੀ ਪੱਧਰੀ ਸਰਵਰ ਪੈਟਰਨ ਉੱਨਤ ਖਾਸੀਅਤਾਂ ਅਤੇ ਆਰਕੀਟੈਕਚਰ ਲਈ ਲਾਭਦਾਇਕ ਹਨ

#### ਸਧਾਰਣ ਪ੍ਰਮਾਣੀਕਰਨ (03-GettingStarted/11-simple-auth)
- **ਨਵਾਂ ਅਧਿਆਇ ਸ਼ਾਮਲ ਕੀਤਾ**: MCP ਸਰਵરો ਵਿੱਚ ਸਧਾਰਣ ਪ੍ਰਮਾਣੀਕਰਨ ਲਾਗੂ ਕਰਨ ਲਈ ਕਦਮ-ਦਰ-কਦਮ ਮਾਰਗਦਰਸ਼ਕ
  - **ਪ੍ਰਮਾਣੀਕਰਨ ਸੰਕਲਪ**: ਪ੍ਰਮਾਣੀਕਰਨ ਵਿ. ਅਧਿਕਾਰਤਾ ਅਤੇ ਕ੍ਰੈਡੇਨਸ਼ੀਅਲ ਪ੍ਰਬੰਧਨ ਦੀ ਸਪੱਠ ਵਿਆਖਿਆ
  - **ਮੂਲ ਪ੍ਰਮਾਣੀਕਰਨ ਲਾਗੂ ਕਰਨਾ**: ਪਾਇਥਨ (ਸਟਾਰਲੈੱਟ) ਅਤੇ ਟਾਈਪਸਕ੍ਰਿਪਟ (ਐਕਸਪ੍ਰੈੱਸ) ਵਿੱਚ ਮਿਡਲਵੇਅਰ ਅਧਾਰਿਤ ਪ੍ਰਮਾਣੀਕਰਨ ਪੈਟਰਨ, ਕੋਡ ਉਦਾਹਰਨਾਂ ਸਮੇਤ
  - **ਉੱਨਤ ਸੁਰੱਖਿਆ ਵਾਲੀ ਪਗੜੀ**: ਸਧਾਰਣ ਪ੍ਰਮਾਣੀਕਰਨ ਨਾਲ ਸ਼ੁਰੂਆਤ ਕਰਨ ਅਤੇ OAuth 2.1 ਅਤੇ RBAC ਤੱਕ ਅੱਗੇ ਵਧਣ ਲਈ ਮਾਰਗਦਰਸ਼ਨ, ਉੱਨਤ ਸੁਰੱਖਿਆ ਮਾਡਿਊਲਾਂ ਲਈ ਹਵਾਲੇ ਸਮੇਤ

ਇਹ ਜੋੜ MCP ਸਰਵਰ ਲਾਗੂ ਕਰਨ ਲਈ ਵਧੇਰੇ ਮਜ਼ਬੂਤ, ਸੁਰੱਖਿਅਤ ਅਤੇ ਲਚਕੀਲੇ ਹੱਥ-ਓਨ ਮਾਰਗਦਰਸ਼ਨ ਪ੍ਰਦਾਨ ਕਰਦੇ ਹਨ, ਬੁਨਿਆਦੀ ਸੰਕਲਪਾਂ ਨੂੰ ਉੱਨਤ ਉਤਪਾਦਨ ਪੈਟਰਨਾਂ ਨਾਲ ਜੋੜਦੇ ਹੋਏ।

- **ਵਿਜੂਅਲ ਸੰਕੇਤ**: ਜ਼ਰੂਰੀ ਲੋੜਾਂ ਵਿਰੁੱਧ ਸਿਫਾਰਸ਼ਸ਼ੁਦਾ ਅਭਿਆਸਾਂ ਦੀ ਸਪਸ਼ਟ ਨਿਸ਼ਾਨਦਹੀ


#### ਮੁੱਖ ਧਾਰਨਾਵਾਂ (01-CoreConcepts/) - ਪੂਰਾ ਨਵੀਕਰਨ
- **ਪ੍ਰੋਟੋਕਾਲ ਵਰਜਨ ਅਪਡੇਟ**: ਮੌਜੂਦਾ MCP ਵਿਸ਼ੇਸ਼ਜਾਣੀ 2025-06-18 ਦਾ ਹਵਾਲਾ ਦੇਣ ਨਾਲ ਅਪਡੇਟ ਕੀਤਾ (YYYY-MM-DD ਫਾਰਮੈਟ)
- **ਆਰਕੀਟੈਕਚਰ ਸੁਧਾਰ**: ਹੋਸਟਸ, ਕਲਾਇੰਟਸ ਅਤੇ ਸਰਵਰਾਂ ਦੀਆਂ ਵੇਰਵਿਆਂ ਨੂੰ ਵਧੀਆ ਕਰਨ ਲਈ MCP ਆਰਕੀਟੈਕਚਰ ਪੈਟਰਨਸ
  - ਹੋਸਟਸ ਹੁਣ ਸਾਫ਼-ਸੂਤਰੀ ਤੌਰ 'ਤੇ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਦੇ ਤੌਰ 'ਤੇ ਸਮਝਾਏ ਗਏ ਹਨ ਜੋ ਕਈ MCP ਕਲਾਇੰਟ ਕਨੈਕਸ਼ਨਾਂ ਨੂੰ ਸਮਨਵਯ ਕਰਦੀਆਂ ਹਨ
  - ਕਲਾਇੰਟਸ ਨੂੰ ਪ੍ਰੋਟੋਕਾਲ ਕਨੈਕਟਰ ਜਿਹਾ ਬਣਾਇਆ ਗਿਆ ਜੋ ਸਰਵਰ ਨਾਲ ਇੱਕ-ਇੱਕ ਕੁਨੈਕਸ਼ਨ ਬਣਾਈ ਰੱਖਦੇ ਹਨ
  - ਸਰਵਰਾਂ ਨੂੰ ਸਥਾਨਕ ਅਤੇ ਰਿਮੋਟ ਤਾਇਨਾਤੀ ਪਰਿਸ਼ਥਿਤੀਆਂ ਨਾਲ ਵਧੀਆ ਕੀਤਾ ਗਿਆ
- **ਮੂਲ ਭਾਗ ਮੁੜ ਬਣਤਰ**: ਸਰਵਰ ਅਤੇ ਕਲਾਇੰਟ ਪ੍ਰਿਮਿਟਿਵਜ਼ ਦਾ ਪੂਰਾ ਨਵੀਨੀਕਰਨ
  - ਸਰਵਰ ਪ੍ਰਿਮਿਟਿਵਜ਼: ਸਾਧਨ (ਡਾਟਾ ਸਰੋਤ), ਪ੍ਰੰਪਟ (ਟੈਮਪਲੇਟ), ਟੂਲ (ਕਾਰਜਸ਼ੀਲ ਫੰਕਸ਼ਨ) ਵਿਸਥਾਰਕ ਵਿਆਖਿਆ ਅਤੇ ਉਦਾਹਰਨਾਂ ਨਾਲ
  - ਕਲਾਇੰਟ ਪ੍ਰਿਮਿਟਿਵਜ਼: ਸੈਂਪਲਿੰਗ (LLM ਕੰਪਲੀਸ਼ਨ), ਸਮੱਗਰੀ ਮੰਗਣਾ (ਉਪਭੋਗਤਾ ਇਨਪੁੱਟ), ਲਾਗਿੰਗ (ਡਿਬੱਗਿੰਗ/ਮਾਨੀਟਰਿੰਗ)
  - ਮੌਜੂਦਾ ਖੋਜ (`*/list`), ਪ੍ਰਾਪਤੀ (`*/get`), ਅਤੇ ਕਾਰਜਾਨਵਿਆਂ (`*/call`) ਢਾਂਚਿਆਂ ਨਾਲ ਅਪਡੇਟ ਕੀਤਾ
- **ਪ੍ਰੋਟੋਕਾਲ ਆਰਕੀਟੈਕਚਰ**: ਦੋ-ਸਤਰੀ ਆਰਕੀਟੈਕਚਰ ਮਾਡਲ ਪੇਸ਼ ਕੀਤਾ
  - ਡਾਟਾ ਲੇਅਰ: JSON-RPC 2.0 ਅਧਾਰ ਨਾਲ ਲਾਈਫਸਾਇਕਲ ਪ੍ਰਬੰਧਨ ਅਤੇ ਪ੍ਰਿਮਿਟਿਵਜ਼
  - ਟਰਾਂਸਪੋਰਟ ਲੇਅਰ: STDIO (ਸਥਾਨਕ) ਅਤੇ HTTP ਸਟ੍ਰੀਮਬਲ ਮੈਂ SSE (ਰਿਮੋਟ) ਟਰਾਂਸਪੋਰਟ ਮਕੈਨਿਜ਼ਮ
- **ਸੁਰੱਖਿਆ ਫਰੇਮਵਰਕ**: ਖਾਸ ਉਪਭੋਗਤਾ ਸਹਿਮਤੀ, ਡਾਟਾ ਗੋਪਨੀਯਤਾ ਸੁਰੱਖਿਆ, ਟੂਲ ਕਾਰਜ ਸ਼ੁੱਧਤਾ, ਅਤੇ ਟਰਾਂਸਪੋਰਟ ਲੇਅਰ ਸੁਰੱਖਿਆ ਸਮੇਤ ਪੂਰਾ ਸੁਰੱਖਿਆ ਸਿਧਾਂਤ
- **ਸੰਚਾਰ ਪੈਟਰਨ**: ਸ਼ੁਰੂਆਤ, ਖੋਜ, ਕਾਰਜਾਨਵਿਆ, ਅਤੇ ਸੂਚਨਾ ਪ੍ਰਵਾਹ ਦੇਖਾਉਦੇ ਪ੍ਰੋਟੋਕਾਲ ਸੁਨੇਹੇ ਅਪਡੇਟ ਕੀਤੇ
- **ਕੋਡ ਉਦਾਹਰਨ**: ਮੌਜੂਦਾ MCP SDK ਪੈਟਰਨ ਦੇ ਪ੍ਰਤੀਕਰਮ ਦੇਣ ਲਈ ਬਹੁ-ਭਾਸ਼ਾਈ ਉਦਾਹਰਨ (.NET, ਜਾਵਾ, ਪਾਇਥਨ, ਜਾਵਾਸਕ੍ਰਿਪਟ) ਤਾਜ਼ਾ ਕੀਤੀਆਂ

#### ਸੁਰੱਖਿਆ (02-Security/) - ਵਿਆਪਕ ਸੁਰੱਖਿਆ ਨਵੀਨੀਕਰਨ  
- **ਮਿਆਰ ਮੇਲ**: MCP ਵਿਸ਼ੇਸ਼ਜਾਣੀ 2025-06-18 ਸੁਰੱਖਿਆ ਲੋੜਾਂ ਨਾਲ ਪੂਰੀ ਤਰ੍ਹਾਂ ਮੇਲ
- **ਪ੍ਰਮਾਣਿਕਤਾ ਵਿਕਾਸ**: ਕਸਟਮ OAuth ਸਰਵਰਾਂ ਤੋਂ ਬਾਹਰੀ ਪਛਾਣ ਪ੍ਰਦਾਤਾ ਡੈਲੀਗੇਸ਼ਨ (Microsoft Entra ID) ਤੱਕ ਵਿਕਾਸ ਦਸਤਾਵੇਜ਼ ਕੀਤਾ
- **ਏਆਈ-ਖਾਸ ਧਮਕੀ ਵਿਸ਼ਲੇਸ਼ਣ**: ਆਧੁਨਿਕ ਏਆਈ ਹਮਲੇ ਵਾਲੇ ਐਲਾਕਿਆਂ ਦਾ ਵਧਾਇਆ ਕਵਰੇਜ
  - ਵਿਸਥਾਰਕ ਪ੍ਰੰਪਟ ਇੰਜੈਕਸ਼ਨ ਹਮਲੇ ਦੇ ਦ੍ਰਿਸ਼ਾਂਤ ਸੱਚਾਈ ਨਾਲ
  - ਟੂਲ ਪੋਇਜ਼ਨਿੰਗ ਮਕੈਨਿਜ਼ਮ ਅਤੇ "ਰੱਗ ਪੁੱਲ" ਹਮਲੇ ਦੇ ਪੈਟਰਨ
  - ਪ੍ਰਸੰਗ ਵਿੰਡੋ ਪੋਇਜ਼ਨਿੰਗ ਅਤੇ ਮਾਡਲ ਗੁਮਰਾਹੀ ਹਮਲੇ
- **ਮਾਇਕ੍ਰੋਸੌਫਟ ਏਆਈ ਸੁਰੱਖਿਆ ਹੱਲ**: ਮਾਇਕ੍ਰੋਸੌਫਟ ਸੁਰੱਖਿਆ ਪਰਿਯਾਵਰਣ ਦਾ ਵਿਆਪਕ ਕਵਰੇਜ
  - AI ਪ੍ਰੰਪਟ ਸ਼ੀਲਡਜ਼ ਉੱਚ-ਸਤਹ ਦੀ ਖੋਜ, ਸਪਾਟਲਾਈਟਿੰਗ ਅਤੇ ਡਿਲਿਮੀਟਰ ਤਕਨੀਕਾਂ ਨਾਲ
  - ਅਜ਼ੂਰੇ ਸਮੱਗਰੀ ਸੁਰੱਖਿਆ ਇੰਟਿਗ੍ਰੇਸ਼ਨ ਪੈਟਰਨ
  - ਸਪਲਾਈ ਚੇਨ ਸੁਰੱਖਿਆ ਲਈ GitHub ਐਡਵਾਂਸਡ ਸੁਰੱਖਿਆ
- **ਉੱਨਤ ਧਮਕੀ ਨਿਵਾਰਨ**: ਵਿਸਥਾਰਕ ਸੁਰੱਖਿਆ ਨਿਯੰਤਰਣ
  - MCP-ਖਾਸ ਸੈਸ਼ਨ ਹਾਈਜੈਕਿੰਗ ਹਮਲੇ ਅਤੇ ਗੁਪਤ ਲਿਖਾਈ ਵਾਲੀਆਂ ਲੋੜਾਂ ਸਮੇਤ
  - MCP ਪ੍ਰਾਕਸੀ ਦਰਸ਼ਾਨਾਂ ਵਿੱਚ Confused Deputy ਸਮੱਸਿਆਵਾਂ ਸਪੱਠ ਸਹਿਮਤੀ ਲੋੜਾਂ ਨਾਲ
  - ਟੋਕਨ ਪਾਸਥਰੂ ਕਮਜ਼ੋਰੀਆਂ ਜ਼ਰੂਰੀ ਪ੍ਰਮਾਣਿਕਤਾ ਨਿਯੰਤਰਣਾਂ ਨਾਲ
- **ਸਪਲਾਈ ਚੇਨ ਸੁਰੱਖਿਆ**: ਫਾਉਂਡੇਸ਼ਨ ਮਾਡਲਾਂ, ਏਮਬੈਡੀਡ ਸੇਵਾਵਾਂ, ਪ੍ਰਸੰਗ ਪ੍ਰਦਾਤਾ, ਅਤੇ ਤੀਜੀ-ਪਾਰਟੀ API ਨਾਲ AI ਸਪਲਾਈ ਚੇਨ ਕਵਰੇਜ ਵਧਾਈ ਗਈ
- **ਫਾਉਂਡੇਸ਼ਨ ਸੁਰੱਖਿਆ**: ਜ਼ੀਰੋ ਟਰਸਟ ਆਰਕੀਟੈਕਚਰ ਅਤੇ ਮਾਇਕ੍ਰੋਸੌਫਟ ਸੁਰੱਖਿਆ ਪਰਿਯਾਵਰਣ ਸਮੇਤ ਉਦਯੋਗੀ ਸੁਰੱਖਿਆ ਪੈਟਰਨ ਨਾਲ ਵਧੀਆ ਇੰਟਿਗ੍ਰੇਸ਼ਨ
- **ਸਰੋਤ ਸੰਗਠਨ**: ਕਿਸਮ ਦੇ ਅਨੁਸਾਰ ਅਧਿਕਾਰਿਕ ਦਸਤਾਵੇਜ਼, ਮਿਆਰ, ਖੋਜ, ਮਾਇਕ੍ਰੋਸੌਫਟ ਹੱਲ ਅਤੇ ਲਾਗੂ ਕਰਨ ਦੇ ਮਾਰਗਦਰਸ਼ਨ ਦੀ ਵਿਸਥਾਰਕ ਵਰਗੀਕਰਨ
