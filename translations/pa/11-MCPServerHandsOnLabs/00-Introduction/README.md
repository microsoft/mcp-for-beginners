## ਝਲਕ

**ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੋਲ (MCP)** AI ਸਹਾਇਕਾਂ ਨੂੰ ਬਾਹਰੀ ਡੇਟਾ ਸਰੋਤਾਂ ਨਾਲ ਸੁਰੱਖਿਅਤ ਤਰੀਕੇ ਨਾਲ ਅਸਲੀ ਸਮੇਂ ਵਿੱਚ ਪਰਸਪਰ ਕਾਰਵਾਈ ਕਰਨ ਦੀ ਸਹੂਲਤ ਦਿੰਦਾ ਹੈ। ਡੇਟਾਬੇਸ ਇੰਟਿਗ੍ਰੇਸ਼ਨ ਨਾਲ ਮਿਲ ਕੇ, MCP ਡਾਟਾ-ਚਲਿਤ AI ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਤਾਕਤਵਰ ਸਮਰੱਥਾਵਾਂ ਖੋਲ੍ਹਦਾ ਹੈ।

ਇਹ ਸਿੱਖਣ ਵਾਲਾ ਰਸਤਾ ਤੁਹਾਨੂੰ ਉਤਪਾਦਨ-ਤੈਯਾਰ MCP ਸਰਵਰ ਬਣਾਉਣ ਸਿਖਾਵੇਗਾ ਜੋ AI ਸਹਾਇਕਾਂ ਨੂੰ ਰੀਟੇਲ ਸੇਲਜ਼ ਡੇਟਾ ਨਾਲ PostgreSQL ਰਾਹੀਂ ਜੋੜਦਾ ਹੈ, ਜਿਹੜਾ ਉਦਯੋਗਿਕ ਪੈਟਰਨ ਜਿਵੇਂ ਕਿ ਰੋ ਲੈਵਲ ਸੁਰੱਖਿਆ, ਅਰਥਪੂਰਨ ਖੋਜ ਅਤੇ ਬਹੁ-ਕਿਰਾਏਦਾਰ ਡੇਟਾ ਪਹੁੰਚ ਨੂੰ ਲਾਗੂ ਕਰਦਾ ਹੈ।

### ਮੁੱਖ ਘਟਕ

#### **1. MCP ਸਰਵਰ ਪਰਤ**
- **FastMCP ਫਰੇਮਵਰਕ**: ਆਧੁਨਿਕ ਪਾਇਥਨ MCP ਸਰਵਰ ਲਾਗੂਕਰਨ
- **ਟੂਲ ਰਜਿਸਟ੍ਰੇਸ਼ਨ**: ਕਿਸਮ ਸੁਰੱਖਿਆ ਨਾਲ ਘੋਸ਼ਿਤ ਟੂਲ ਪਰਿਭਾਸ਼ਾਵਾਂ
- **ਅਨੁਰੋਧ ਸੰਦਰਭ**: ਉਪਭੋਗਤਾ ਪਹਿਚਾਣ ਅਤੇ ਸੈਸ਼ਨ ਪ੍ਰਬੰਧਨ
- **ਗਲਤੀ ਸੰਭਾਲ**: ਮਜ਼ਬੂਤ ਗਲਤੀ ਪ੍ਰਬੰਧਨ ਅਤੇ ਲਾਗਿੰਗ

#### **2. ਡੇਟਾਬੇਸ ਇੰਟਿਗ੍ਰੇਸ਼ਨ ਪਰਤ**
- **ਕਨੈਕਸ਼ਨ ਪੂਲਿੰਗ**: ਕੁਸ਼ਲ asyncpg ਕਨੈਕਸ਼ਨ ਪ੍ਰਬੰਧਨ
- **ਸਕਿਮਾ ਪ੍ਰਦਾਤਾ**: ਗਤੀਸ਼ੀਲ ਟੇਬਲ ਸਕੀਮਾ ਦੀ ਖੋਜ
- **ਕਵੇਰੀ ਐਕਸਿਊਟਰ**: RLS ਸੰਦਰਭ ਨਾਲ ਸੁਰੱਖਿਅਤ SQL ਕਾਰਜ
- **ਟ੍ਰਾਂਜ਼ੈਕਸ਼ਨ ਪ੍ਰਬੰਧਨ**: ACID ਅਨੁਕੂਲਤਾ ਅਤੇ ਰੋਲਬੈਕ ਸੰਭਾਲ

#### **3. ਸੁਰੱਖਿਆ ਪਰਤ**
- **ਰੋ ਲੈਵਲ ਸੁਰੱਖਿਆ**: PostgreSQL RLS ਬਹੁ-ਕਿਰਾਏਦਾਰ ਡੇਟਾ ਵੱਖਰਾ ਕਰਨ ਲਈ
- **ਉਪਭੋਗਤਾ ਪਹਿਚਾਣ**: ਸਟੋਰ ਮੈਨੇਜਰ ਪ੍ਰਮਾਣਿਕਤਾ ਅਤੇ ਅਧਿਕਾਰ
- **ਪਹੁੰਚ ਨਿਯੰਤਰਣ**: ਬਰੀਕੀ ਨਾਲ ਅਨੁਮਤੀਆਂ ਅਤੇ ਆਡਟ ਟਰੇਲ
- **ਇਨਪੁਟ ਵੈਧਤਾ**: SQL ਇੰਜੈਕਸ਼ਨ ਰੋਕਥਾਮ ਅਤੇ ਕਵੇਰੀ ਵੈਧਤਾ

#### **4. AI ਸੁਧਾਰ ਪਰਤ**
- **ਅਰਥਪੂਰਨ ਖੋਜ**: ਉਤਪਾਦ ਦੀ ਖੋਜ ਲਈ ਵੈਕਟਰ ਐਮਬੈਡਿੰਗ
- **Azure OpenAI ਇੰਟਿਗ੍ਰੇਸ਼ਨ**: ਟੈਕਸਟ ਐਮਬੈਡਿੰਗ ਤਿਆਰ ਕਰਨਾ
- **ਸਮਾਨਤਾ ਅਲਗੋਰਿਦਮ**: pgvector ਕੋਸਾਈਨ ਸਮਾਨਤਾ ਖੋਜ
- **ਖੋਜ ਸੁਧਾਰ**: ਇੰਡੈਕਸਿੰਗ ਅਤੇ ਕਾਰਗੁਜਾਰੀ ਸੁਧਾਰ

## 🔒 ਸੁਰੱਖਿਆ ਅਤੇ ਬਹੁ-ਕਿਰਾਏਦਾਰੀ ਗਹਿਰਾਈ ਨਾਲ

ਸਾਡਾ ਲਾਗੂਕਰਨ ਉਦਯੋਗ-ਪੱਧਰੀ ਸੁਰੱਖਿਆ ਨੂੰ ਪਹਿਲ ਦਿੰਦਾ ਹੈ:

### ਰੋ ਲੈਵਲ ਸੁਰੱਖਿਆ (RLS)

PostgreSQL RLS ਡੇਟਾ ਵੱਖਰਾ ਕਰਨ ਨੂੰ ਯਕੀਨੀ ਬਣਾਉਂਦਾ ਹੈ:

```sql
-- Store managers see only their store's data
CREATE POLICY store_manager_policy ON retail.orders
  FOR ALL TO store_managers
  USING (store_id = get_current_user_store());

-- Regional managers see multiple stores
CREATE POLICY regional_manager_policy ON retail.orders
  FOR ALL TO regional_managers
  USING (store_id = ANY(get_user_store_list()));
```

### ਉਪਭੋਗਤਾ ਪਹਿਚਾਣ ਪ੍ਰਬੰਧਨ

ਹਰ MCP ਕਨੈਕਸ਼ਨ ਵਿੱਚ ਸ਼ਾਮਿਲ ਹੈ:
- **ਸਟੋਰ ਮੈਨੇਜਰ ID**: RLS ਸੰਦਰਭ ਲਈ ਵਿਅਕਤੀਗਤ ਪਹਿਚਾਣ
- **ਰੋਲ ਅਸਾਈਨਮੈਂਟ**: ਅਨੁਮਤੀਆਂ ਅਤੇ ਪਹੁੰਚ ਪੱਧਰ
- **ਸੈਸ਼ਨ ਪ੍ਰਬੰਧਨ**: ਸੁਰੱਖਿਅਤ ਪ੍ਰਮਾਣਿਕਤਾ ਟੋਕਨ
- **ਆਡਿਟ ਲਾਗਿੰਗ**: ਪੂਰੀ ਪਹੁੰਚ ਇਤਿਹਾਸ

### ਡੇਟਾ ਸੁਰੱਖਿਆ

ਕਈ ਸੁਰੱਖਿਆ ਪੱਧਰ:
- **ਕਨੈਕਸ਼ਨ ਇੰਕ੍ਰਿਪਸ਼ਨ**: ਸਾਰੇ ਡੇਟਾਬੇਸ ਕਨੈਕਸ਼ਨਾਂ ਲਈ TLS
- **SQL ਇੰਜੈਕਸ਼ਨ ਰੋਕਥਾਮ**: ਸਿਰਫ ਪੈਰਾਮੀਟਰਾਈਜ਼ਡ ਕਵੇਰੀਆਂ
- **ਇਨਪੁੱਟ ਵੈਧਤਾ**: ਵਿਸ਼ਤ੍ਰਤ ਅਨੁਰੋਧ ਵੈਧਤਾ
