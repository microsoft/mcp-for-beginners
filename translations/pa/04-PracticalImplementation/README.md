# ਵਿਹਾਰਤਮਕ ਲਾਗੂ ਕਰਨ

[![ਅਸਲ ਟੂਲਾਂ ਅਤੇ ਵਰਕਫ਼ਲੋਜ਼ ਨਾਲ MCP ਐਪਸ ਨੂੰ ਕਿਵੇਂ ਬਣਾਉਣਾ, ਟੈਸਟ ਕਰਨਾ, ਅਤੇ ਡਿਪਲੋਇ ਕਰਨਾ](../../../translated_images/pa/05.64bea204e25ca891.webp)](https://youtu.be/vCN9-mKBDfQ)

_(ਇਸ ਪਾਠ ਦਾ ਵੀਡੀਓ ਦੇਖਣ ਲਈ ਉਪਰੋਕਤ ਚਿੱਤਰ 'ਤੇ ਕਲਿੱਕ ਕਰੋ)_

ਵਿਹਾਰਤਮਕ ਲਾਗੂ ਕਰਨ ਉਹ ਥਾਂ ਹੈ ਜਿੱਥੇ ਮਾਡਲ ਕন্টੈਕਸਟ ਪ੍ਰੋਟੋਕਾਲ (MCP) ਦੀ ਤਾਕਤ ਮਹਿਸੂਸ ਹੋਣ ਲੱਗਦੀ ਹੈ। ਜਦਕਿ MCP ਪਿੱਛੇ ਸਿਧਾਂਤ ਅਤੇ ਆਰਕੀਟੈਕਚਰ ਨੂੰ ਸਮਝਣਾ ਮਹੱਤਵਪੂਰਨ ਹੈ, ਅਸਲ ਮੁੱਲ ਉਸ ਵੇਲੇ ਉਭਰਦਾ ਹੈ ਜਦੋਂ ਤੁਸੀਂ ਇਹਨਾਂ ਧਾਰਣਾਵਾਂ ਨੂੰ ਲਾਗੂ ਕਰਦੇ ਹੋ ਤਾਂ ਜੋ ਅਸਲ ਦੁਨੀਆ ਦੀਆਂ ਸਮੱਸਿਆਵਾਂ ਦਾ ਹੱਲ ਬਣਾ ਸਕੋ। ਇਹ ਅਧਿਆਇ ਸੰਕਲਪਾਤਮਕ ਗਿਆਨ ਅਤੇ ਹੱਥੋਂ-ਹੱਥ ਵਿਕਾਸ ਦਰਮਿਆਨ ਦਾ ਫ਼ਰਕ ਪੂਰਾ ਕਰਦਾ ਹੈ, ਤੁਹਾਨੂੰ MCP-ਆਧਾਰਿਤ ਐਪਲੀਕੇਸ਼ਨਜ਼ ਨੂੰ ਜੀਵੰਤ ਕਰਨ ਦੇ ਪ੍ਰਕਿਰਿਆ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ।

ਚਾਹੇ ਤੁਸੀਂ ਬੁੱਧੀਮਾਨ ਸਹਾਇਕਾਂ ਨੂੰ ਵਿਕਸਿਤ ਕਰ ਰਹੇ ਹੋ, ਕਾਰੋਬਾਰੀ ਵਰਕਫ਼ਲੋਜ਼ ਵਿੱਚ AI ਨੂੰ ਇਕਠਾ ਕਰ ਰਹੇ ਹੋ, ਜਾਂ ਡਾਟਾ ਪ੍ਰੋਸੈਸਿੰਗ ਲਈ ਕਸਟਮ ਟੂਲ ਬਣਾ ਰਹੇ ਹੋ, MCP ਲਚਕੀਲੇ ਮੂਲਧਾਰ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ। ਇਸ ਦੀ ਭਾਸ਼ਾ-ਹੀਨ ਡਿਜ਼ਾਈਨ ਅਤੇ ਪ੍ਰਸਿੱਧ ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ ਲਈ ਅਧਿਕਾਰਿਕ SDK ਇਸਨੂੰ ਵੱਖ-ਵੱਖ ਵਿਕਾਸਕਾਰਾਂ ਲਈ ਪਹੁੰਚ ਯੋਗ ਬਣਾਉਂਦੇ ਹਨ। ਇਨ੍ਹਾਂ SDKs ਦਾ ਲਾਭ ਉਠਾ ਕੇ, ਤੁਸੀਂ ਤੇਜ਼ੀ ਨਾਲ ਪ੍ਰੋਟੋਟਾਈਪ, ਦੁਹਰਾਈ, ਅਤੇ ਵੱਖ-ਵੱਖ ਪਲੇਟਫਾਰਮ ਅਤੇ ਵਾਤਾਵਰਨਾਂ ਵਿੱਚ ਆਪਣੇ ਹੱਲਾਂ ਦਾ ਪੈਮਾਨਾ ਵਧਾ ਸਕਦੇ ਹੋ।

ਅਗਲੇ ਭਾਗਾਂ ਵਿੱਚ, ਤੁਹਾਨੂੰ MCP ਨੂੰ C#, Java ਸਪ੍ਰਿੰਗ ਨਾਲ, ਟਾਈਪਸਕ੍ਰਿਪਟ, ਜਾਵਾਸਕ੍ਰਿਪਟ, ਅਤੇ ਪਾਇਥਨ ਵਿੱਚ ਲਾਗੂ ਕਰਨ ਵਾਲੇ ਵਿਹਾਰਤਮਕ ਉਦਾਹਰਣਾਂ, ਸੈਂਪਲ ਕੋਡ, ਅਤੇ ਡਿਪਲੋਇਮੈਂਟ ਰਣਨੀਤੀਆਂ ਮਿਲਣਗੀਆਂ। ਤੁਸੀਂ ਆਪਣੇ MCP ਸਰਵਰਾਂ ਨੂੰ ਡੀਬੱਗ ਅਤੇ ਟੈਸਟ ਕਰਨ, API ਪ੍ਰਬੰਧਿਤ ਕਰਨ, ਅਤੇ Azure ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਕਲਾਉਡ ਵਿੱਚ ਹੱਲਾਂ ਨੂੰ ਡਿਪਲੋਇ ਕਰਨ ਦੇ ਤਰੀਕੇ ਵੀ ਸਿੱਖੋਗੇ। ਇਹ ਹੱਥੋਂ-ਹੱਥ ਸਾਧਨ ਤੇਜ਼ੀ ਨਾਲ ਤੁਹਾਡੀ ਸਿੱਖਿਆ ਨੂੰ ਤੇਜ ਕਰਨ ਅਤੇ ਡੰਭੀ, ਉਤਪਾਦਨ-ਤਿਆਰ MCP ਐਪਲੀਕੇਸ਼ਨਜ਼ ਨੂੰ ਵਿਸ਼ਵਾਸ ਨਾਲ ਬਣਾਉਣ ਵਿੱਚ ਮਦਦ ਲਈ ਤਿਆਰ ਕੀਤੇ ਗਏ ਹਨ।

## ਝਲਕ

ਇਹ ਪਾਠ MCP ਲਾਗੂ ਕਰਨ ਦੇ ਵਿਹਾਰਤਮਕ ਪਹਿਲੂਆਂ 'ਤੇ ਕੇਂਦਰਤ ਹੈ ਜੋ ਵੱਖ-ਵੱਖ ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ ਵਿੱਚ ਵਰਤੇ ਜਾ ਰਹੇ ਹਨ। ਅਸੀਂ ਵੇਖਾਂਗੇ ਕਿ ਕਿਵੇਂ MCP SDKs ਨੂੰ C#, Java ਸਪ੍ਰਿੰਗ ਨਾਲ, ਟਾਈਪਸਕ੍ਰਿਪਟ, ਜਾਵਾਸਕ੍ਰਿਪਟ, ਅਤੇ ਪਾਇਥਨ ਵਿੱਚ ਵਰਤ ਕੇ ਮਜ਼ਬੂਤ ਐਪਲੀਕੇਸ਼ਨ ਬਣਾਈ ਜਾ ਸਕਦੀ ਹੈ, MCP ਸਰਵਰਾਂ ਨੂੰ ਡੀਬੱਗ ਅਤੇ ਟੈਸਟ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ, ਅਤੇ ਦੁਬਾਰਾ ਵਰਤੇ ਜਾ ਸਕਣ ਵਾਲੇ ਸਾਧਨ, ਪ੍ਰੰਪਟ, ਅਤੇ ਟੂਲ ਤਿਆਰ ਕੀਤੇ ਜਾ ਸਕਦੇ ਹਨ।

## ਸਿੱਖਣ ਦੇ ਲਕੜੇ

ਇਸ ਪਾਠ ਦੇ ਅੰਤ ਤੇ, ਤੁਸੀਂ ਸਮਰੱਥ ਹੋਵੋਗੇ:

- ਵੱਖ-ਵੱਖ ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ ਵਿੱਚ ਅਧਿਕਾਰਿਕ SDKs ਵਰਤ ਕੇ MCP ਹੱਲ ਲਾਗੂ ਕਰਨ
- MCP ਸਰਵਰਾਂ ਨੂੰ ਵਿਧੀਪੂਰਵਕ ਡੀਬੱਗ ਅਤੇ ਟੈਸਟ ਕਰਨ
- ਸਰਵਰ ਫੀਚਰ (ਸਾਧਨ, ਪ੍ਰੰਪਟ, ਅਤੇ ਟੂਲ) ਤਿਆਰ ਕਰਨ ਅਤੇ ਵਰਤਣ
- ਜਟਿਲ ਕੰਮਾਂ ਲਈ ਪ੍ਰਭਾਵਸ਼ਾਲੀ MCP ਵਰਕਫ਼ਲੋਜ਼ ਡਿਜ਼ਾਈਨ ਕਰਨ
- ਕਾਰਗੁਜ਼ਾਰੀ ਅਤੇ ਭਰੋਸੇਯੋਗਤਾ ਲਈ MCP ਲਾਗੂ ਕਰਨ ਦੀਆਂ ਵਿਧੀਆਂ ਦੇ ਨਾਲ ਸੁਧਾਰ ਕਰਨ

ਮਾਡਲ ਕਨਟੈਕਸਟ ਪ੍ਰੋਟੋਕਾਲ ਕਈ ਭਾਸ਼ਾਵਾਂ ਲਈ ਅਧਿਕਾਰਿਕ SDK ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ। SDK

ਰਿਲੀਜ਼ ਨੋਟ ਅਤੇ ਉਦਾਹਰਣ ਦੇ ਪੈਕੇਜ ਵਰਜਨ ਨੂੰ ਚੈੱਕ ਕਰੋ, ਇਸ ਤੋਂ ਪਹਿਲਾਂ ਕਿ ਤੁਸੀਂ ਪ੍ਰੋਟੋਕਾਲ

## ਕੋਰ ਸਰਵਰ ਫੀਚਰ

MCP ਸਰਵਰ ਇਨ੍ਹਾਂ ਫੀਚਰਾਂ ਦੇ ਕਿਸੇ ਵੀ ਸੰਯੋਜਨ ਨੂੰ ਲਾਗੂ ਕਰ ਸਕਦੇ ਹਨ:

### ਸਾਧਨ

ਸਾਧਨ ਉਪਭੋਗਤਾ ਜਾਂ AI ਮਾਡਲ ਲਈ ਪ੍ਰਸੰਗ ਅਤੇ ਡਾਟਾ ਪ੍ਰਦਾਨ ਕਰਦੇ ਹਨ:

- ਡਾਕੂਮੈਂਟ ਰੇਪੋਜ਼ਟਰੀਜ਼
- ਗਿਆਨ ਆਧਾਰ
- ਸੰਰਚਿਤ ਡਾਟਾ ਸਰੋਤ
- ਫਾਇਲ ਸਿਸਟਮ

### ਪ੍ਰੰਪਟ

ਪ੍ਰੰਪਟ ਉਪਭੋਗਤਾਵਾਂ ਲਈ ਟੈਮਪਲੇਟ ਕੀਤੇ ਗਏ ਸੁਨੇਹੇ ਅਤੇ ਵਰਕਫ਼ਲੋਜ਼ ਹਨ:

- ਪੂਰਵ-ਪ੍ਰਿਭਾਧਿਤ ਗੱਲਬਾਤ ਟੈਮਪਲੇਟ
- ਮਾਰਗਦਰਸ਼ਿਤ ਇੰਟਰਏਕਸ਼ਨ ਪੈਟਰਨ
- ਵਿਸ਼ੇਸ਼ ਭਾਸ਼ਣ ਢਾਂਚੇ

### ਟੂਲ

ਟੂਲ AI ਮਾਡਲ ਲਈ ਕਾਰਜਾਂ ਨੂੰ ਅੰਜਾਮ ਦੇਣ ਵਾਲੇ ਫੰਕਸ਼ਨ ਹਨ:

- ਡਾਟਾ ਪ੍ਰੋਸੈਸਿੰਗ ਯੂਟਿਲਿਟੀਜ਼
- ਬਾਹਰੀ API ਇੰਟਿਗ੍ਰੇਸ਼ਨ
- ਗਣਨਾਤਮਕ ਸਮਰਥਾ
- ਖੋਜ功能

## ਸੈਂਪਲ ਲਾਗੂ ਕਰਨ: C# ਲਾਗੂ ਕਰਨ

ਅਧਿਕਾਰਿਕ C# SDK ਰਿਪੋਜ਼ਟਰੀ ਵਿੱਚ ਕਈ ਸੈਂਪਲ ਲਾਗੂ ਕਰਨ ਸ਼ਾਮਲ ਹਨ ਜੋ MCP ਦੇ ਵੱਖ-ਵੱਖ ਪੱਖਾਂ ਨੂੰ ਦਰਸਾਉਂਦੇ ਹਨ:

- **ਮੂਲ MCP ਕਲਾਇੰਟ**: MCP ਕਲਾਇੰਟ ਬਣਾਉਣ ਅਤੇ ਟੂਲਾਂ ਨੂੰ ਕਾਲ ਕਰਨ ਵਾਲਾ ਸਧਾਰਣ ਉਦਾਹਰਣ
- **ਮੂਲ MCP ਸਰਵਰ**: ਮੂਲ ਟੂਲ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਨਾਲ ਘੱਟੋ-ਘੱਟ ਸਰਵਰ ਲਾਗੂ ਕਰਨਾ
- **ਉੱਚ ਸਤਹ MCP ਸਰਵਰ**: ਟੂਲ ਰਜਿਸਟ੍ਰੇਸ਼ਨ, ਪ੍ਰਮਾਣਿਕਤਾ, ਅਤੇ ਗਲਤੀ ਸੰਭਾਲਣ ਨਾਲ ਪੂਰਨ ਸਰਵਰ
- **ASP.NET ਇੰਟੀਗ੍ਰੇਸ਼ਨ**: ASP.NET ਕੋਰ ਨਾਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਦਿਖਾਉਣ ਵਾਲੇ ਉਦਾਹਰਣ
- **ਟੂਲ ਲਾਗੂ ਕਰਨ ਦੇ ਪੈਟਰਨ**: ਵੱਖ-ਵੱਖ ਜਟਿਲਤਾ ਪੱਧਰਾਂ ਲਈ ਟੂਲ ਲਾਗੂ ਕਰਨ ਦੇ ਪ੍ਰਣਾਲੀਕ ਪੱਟਰਨ

MCP C# SDK ਪ੍ਰੀਵੀਅੂ ਵਿੱਚ ਹੈ ਅਤੇ APIs ਬਦਲ ਸਕਦੇ ਹਨ। ਅਸੀਂ ਇਸ ਬਲਾਗ ਨੂੰ SDK ਦੇ ਵਿਕਾਸ ਨਾਲ ਲਗਾਤਾਰ ਅਪਡੇਟ ਕਰਦੇ ਰਹਾਂਗੇ।

## ਰਿਮੋਟ MCP ਸਰਵਰ ਨੂੰ Azure 'ਤੇ ਡਿਪਲੋਏ ਕਰੋ

ਆਓ ਦੇਖੀਏ ਕਿ ਅਸੀਂ ਪਹਿਲਾਂ ਦਿੱਤੇ ਨਮੂਨੇ ਨੂੰ ਡਿਪਲੋਏ ਕਰ ਸਕਦੇ ਹਾਂ:

1. ਰੇਪੋ ਕਲੋਨ ਕਰੋ

    ```bash
    git clone https://github.com/Azure-Samples/remote-mcp-apim-functions-python.git
    cd remote-mcp-apim-functions-python
    ```

1. `Microsoft.App` ਰਿਸੋਰਸ ਪ੍ਰੋਵਾਈਡਰ ਨੂੰ ਰਜਿਸਟਰ ਕਰੋ।

   - ਜੇ ਤੁਸੀਂ Azure CLI ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ `az provider register --namespace Microsoft.App --wait` ਚਲਾਓ।
   - ਜੇ ਤੁਸੀਂ Azure PowerShell ਵਰਤ ਰਹੇ ਹੋ, ਤਾਂ `Register-AzResourceProvider -ProviderNamespace Microsoft.App` ਚਲਾਓ। ਫੇਰ ਕੁਝ ਸਮੇਂ ਬਾਅਦ ਜਾਂਚਣ ਲਈ `(Get-AzResourceProvider -ProviderNamespace Microsoft.App).RegistrationState` ਚਲਾਓ ਕਿ ਰਜਿਸਟ੍ਰੇਸ਼ਨ ਮੁਕੰਮਲ ਹੋ ਚੁਕਾ ਹੈ ਜਾਂ ਨਹੀਂ।

1. ਇਹ [azd](https://aka.ms/azd) ਕਮਾਂਡ ਚਲਾਓ ਤਾ ਕਿ API ਮੈਨੇਜਮੈਂਟ ਸਰਵਿਸ, ਫਂਕਸ਼ਨ ਐਪ (ਕੋਡ ਸਮੇਤ) ਅਤੇ ਹੋਰ ਸਾਰੇ ਜ਼ਰੂਰੀ Azure ਰਿਸੋਰਸ ਪ੍ਰੋਵੀਜ਼ਨ ਕੀਤੇ ਜਾ ਸਕਣ

    ```shell
    azd up
    ```

    ਇਹ ਕਮਾਂਡਾਂ Azure 'ਤੇ ਸਾਰੇ ਕਲਾਉਡ ਰਿਸੋਰਸ ਡਿਪਲੋਏ ਕਰਨਾ ਚਾਹੀਦੇ ਹਨ

### ਆਪਣੇ ਸਰਵਰ ਨੂੰ MCP ਇਨਸਪੈਕਟਰ ਨਾਲ ਟੈਸਟ ਕਰਣਾ

1. ਇੱਕ **ਨਵੀਂ ਟਰਮੀਨਲ ਵਿੰਡੋ** ਵਿੱਚ MCP ਇਨਸਪੈਕਟਰ ਇੰਸਟਾਲ ਅਤੇ ਚਲਾਓ

    ```shell
    npx @modelcontextprotocol/inspector
    ```

    ਤੁਹਾਨੂੰ ਇੱਕ ਇੰਟਰਫੇਸ ਇਸ ਤਰ੍ਹਾਂ ਦਿੱਸਣਾ ਚਾਹੀਦਾ ਹੈ:

    ![Connect to Node inspector](../../../translated_images/pa/connect.141db0b2bd05f096.webp)

1. CTRL ਕਲਿੱਕ ਕਰਕੇ MCP ਇਨਸਪੈਕਟਰ ਵੈੱਬ ਐਪ ਨੂੰ ਐਪ ਦੁਆਰਾ ਦਰਸਾਏ URL ਤੋਂ ਲੋਡ ਕਰੋ (ਜਿਵੇਂ ਕਿ [http://127.0.0.1:6274/#resources](http://127.0.0.1:6274/#resources))
1. ਟ੍ਰਾਂਸਪੋਰਟ ਕਿਸਮ ਨੂੰ `SSE` ਸੈੱਟ ਕਰੋ
1. URL ਨੂੰ ਆਪਣੀ ਚਲ ਰਹੀ API ਮੈਨੇਜਮੈਂਟ SSE ਐਂਡਪોઈਂਟ ਤੇ ਸੈੱਟ ਕਰੋ ਜੋ `azd up` ਦੇ ਬਾਅਦ ਦਿਖਾਇਆ ਗਿਆ ਹੈ ਅਤੇ **ਕਨੈਕਟ** ਕਰੋ:

    ```shell
    https://<apim-servicename-from-azd-output>.azure-api.net/mcp/sse
    ```

1. **ਸੰਦ ਸੂਚੀਬੱਧ ਕਰੋ**। ਕਿਸੇ ਸੰਦ 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ **ਸੰਦ ਚਲਾਓ**।

ਜੇ ਸਾਰੇ ਕਦਮ ਸਫਲ ਰਹੇ ਹਨ, ਤਾਂ ਹੁਣ ਤੁਸੀਂ MCP ਸਰਵਰ ਨਾਲ ਜੁੜੇ ਹੋ ਅਤੇ ਤੁਸੀਂ ਇੱਕ ਸੰਦ ਨੂੰ ਕਾਲ ਕਰ ਸਕੇ ਹੋ।

## Azure ਲਈ MCP ਸਰਵਰ

[Remote-mcp-functions](https://github.com/Azure-Samples/remote-mcp-functions-dotnet): ਇਹ ਰੇਪੋਜ਼ਟਰੀਆਂ ਦਾ ਸੈੱਟ ਇੱਕ ਕਵਿਕਸਟਾਰਟ ਟੈਮਪਲੇਟ ਹੈ ਜੋ Azure Functions ਨਾਲ Python, C# .NET ਜਾਂ Node/TypeScript ਵਰਤਕੇ कਸਟਮ ਰਿਮੋਟ MCP (ਮਾਡਲ ਕਾਂਟੈਕਸਟ ਪ੍ਰੋਟੋਕੋਲ) ਸਰਵਰ ਬਣਾਉਣ ਅਤੇ ਡਿਪਲੋਏ ਕਰਨ ਲਈ ਹੈ।

ਇਹ ਨਮੂਨੇ ਵਿਕਾਸਕਾਰਾਂ ਨੂੰ ਇੱਕ ਮੁਕੰਮਲ ਹੱਲ ਪ੍ਰਦਾਨ ਕਰਦੇ ਹਨ ਜੋ:

- ਸਥਾਨਕ ਤੌਰ ਤੇ ਬਣਾਉਣਾ ਅਤੇ ਚਲਾਉਣਾ: ਇੱਕ ਸਥਾਨਕ ਮਸ਼ੀਨ 'ਤੇ MCP ਸਰਵਰ ਨੂੰ ਵਿਕਸਿਤ ਅਤੇ ਡਿਬੱਗ ਕਰੋ
- Azure 'ਤੇ ਡਿਪਲੋਏ ਕਰੋ: ਸਧਾਰਨ azd up ਕਮਾਂਡ ਨਾਲ ਆਸਾਨੀ ਨਾਲ ਕਲਾਉਡ 'ਤੇ ਡਿਪਲੋਏ ਕਰੋ
- ਕਲਾਇੰਟਾਂ ਤੋਂ ਕਨੈਕਟ ਕਰੋ: ਵੱਖ-ਵੱਖ ਕਲਾਇੰਟਾਂ ਤੋਂ MCP ਸਰਵਰ ਨਾਲ ਜੁੜੋ ਜਿਸ ਵਿੱਚ VS ਕੋਡ ਦੇ ਕੋਪਾਇਲਟ ਏਜੰਟ ਮੋਡ ਅਤੇ MCP ਇਨਸਪੈਕਟਰ ਟੂਲ ਸ਼ਾਮਿਲ ਹਨ

### ਮੁੱਖ ਫੀਚਰ

- ਡਿਜ਼ਾਇਨ ਵਿੱਚ ਸੁਰੱਖਿਆ: MCP ਸਰਵਰ ਨੂੰ ਕੀ ਅਤੇ HTTPS ਦੀ ਵਰਤੋਂ ਨਾਲ ਸੁਰੱਖਿਅਤ ਕੀਤਾ ਗਿਆ ਹੈ
- ਪ੍ਰਮਾਣੀਕੀਕਰਨ ਵਿਕਲਪ: ਬਿਲਟ-ਇਨ ਪ੍ਰਮਾਣੀਕੀਕਰਨ ਅਤੇ/ਜਾਂ API ਮੈਨੇਜਮੈਂਟ ਵਰਤਕੇ OAuth ਨੂੰ ਸਹਾਇਤਾ ਦਿੰਦਾ ਹੈ
- ਨੈੱਟਵਰਕ ਇਕੱਲਾ: Azure ਵਰਚੁਅਲ ਨੈੱਟਵਰਕ (VNET) ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਨੈੱਟਵਰਕ ਇਕੱਲਾ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ
- ਸਰਵਰਲੇਸ ਆਰਕੀਟੈਕਚਰ: Azure Functions ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ ਜੋ ਕਿ ਸਕੇਲ ਕਰਨਯੋਗ, ਘਟਨਾ-ਕੰਟਰੋਲਿਤ ਐਕਜ਼ੀਕਿਊਸ਼ਨ ਲਈ ਹੈ
- ਸਥਾਨਕ ਵਿਕਾਸ: ਵਿਆਪਕ ਸਥਾਨਕ ਵਿਕਾਸ ਅਤੇ ਡਿਬੱਗਿੰਗ ਸਹਾਇਤਾ
- ਸਧਾਰਨ ਡਿਪਲੋਏਮੈਂਟ: Azure 'ਤੇ ਹੋਰਨਾਂ ਪਕੜਾਂ ਨੂੰ ਆਸਾਨ ਬਣਾਉਂਦਾ ਹੈ

ਰੇਪੋ ਵਿੱਚ ਸਾਰੇ ਜਰੂਰੀ ਕਨਫਿਗਰੇਸ਼ਨ ਫਾਈਲਾਂ, ਸੋర్స్ ਕੋਡ ਅਤੇ ਇੰફਰਾਸਟਰੱਕਚਰ ਪਰਿਭਾਸ਼ਾਵਾਂ ਸ਼ਾਮਿਲ ਹਨ ਤਾਂ ਜੋ ਤੁਰੰਤ ਪ੍ਰੋਡਕਸ਼ਨ-ਤਯਾਰ MCP ਸਰਵਰ ਅਮਲ ਵਿਚ ਲਿਆ ਸਕੀਏ।

- ਦੁਬਾਰਾ ਵਰਤ ਸਕਣ ਵਾਲੇ ਪ੍ਰੋੰਪਟ ਟੈਮਪਲੇਟ ਸਥਿਰ AI ਇੰਟਰੈਕਸ਼ਨਾਂ ਨੂੰ ਯਕੀਨੀ ਬਣਾਉਂਦੇ ਹਨ
- ਚੰਗੀ ਤਰ੍ਹਾਂ ਡਿਜ਼ਾਇਨ ਕੀਤੇ ਗਏ ਵਰਕਫਲੋਜ਼ ਕਈ ਸੰਦਾਂ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਕਠਿਨ ਕਾਰਜਾਂ ਦਾ ਸੰਗਠਨ ਕਰ ਸਕਦੇ ਹਨ
- MCP ਹੱਲਾਂ ਨੂੰ ਲਾਗੂ ਕਰਨ ਲਈ ਸੁਰੱਖਿਆ, ਪ੍ਰਦਰਸ਼ਨ ਅਤੇ ਗਲਤੀ ਸੰਭਾਲਣ ਦਾ ਵਿਚਾਰ ਕਰਨਾ ਲਾਜ਼ਮੀ ਹੈ

## ਅਭਿਆਸ

ਆਪਣੇ ਖੇਤਰ ਵਿੱਚ ਕੋਈ ਅਸਲੀ ਦੁਨੀਆ ਦੀ ਸਮੱਸਿਆ ਹੱਲ ਕਰਨ ਲਈ ਇੱਕ ਵਿਆਵਹਾਰਿਕ MCP ਵਰਕਫਲੋ ਡਿਜ਼ਾਇਨ ਕਰੋ:

1. 3-4 ਸੰਦਾਂ ਦੀ ਪਹਚਾਣ ਕਰੋ ਜੋ ਇਸ ਸਮੱਸਿਆ ਨੂੰ ਹੱਲ ਕਰਨ ਲਈ ਲਾਭਦਾਇਕ ਹੋਣਗੇ
2. ਇੱਕ ਵਰਕਫਲੋ ਡਾਇਗ੍ਰਾਮ ਬਣਾਓ ਜੋ ਦਿਖਾਵੇ ਕਿ ਇਹ ਸੰਦ ਕਿਵੇਂ ਇਕੱਠੇ ਕੰਮ ਕਰਦੇ ਹਨ
3. ਆਪਣੀ ਪਸੰਦ ਦੀ ਭਾਸ਼ਾ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਇੱਕ ਸੰਦ ਦਾ ਬੁਨਿਆਂਦੀ ਸੰસ્કਰਣ ਲਾਗੂ ਕਰੋ
4. ਇੱਕ ਪ੍ਰੋੰਪਟ ਟੈਮਪਲੇਟ ਬਣਾਓ ਜੋ ਮਾਡਲ ਨੂੰ ਤੁਹਾਡੇ ਸੰਦ ਦੀ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਵਰਤੋਂ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰੇ
