## 🔧 MCP ਸਰਵਰਾਂ ਨੂੰ ਸਮਝਣਾ: ਸ਼ੁਰੂਆਤੀ ਮਾਰਗਦਰਸ਼ਿਕਾ

### MCP ਸਰਵਰ ਕੀ ਹਨ?

ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੋਲ (MCP) ਤੋਂ ਬਿਲਕੁਲ ਨਵੇਂ ਹੋ ਕੇ, ਤੁਹਾਡੇ ਮਨ ਵਿਚ ਇਹ ਸਵਾਲ ਆ ਸਕਦਾ ਹੈ: "MCP ਸਰਵਰ ਅਸਲ ਵਿੱਚ ਕੀ ਹੈ, ਅਤੇ ਮੈਨੂੰ ਇਸ ਦੀ ਚਿੰਤਾ ਕਿਉਂ ਕਰਨੀ ਚਾਹੀਦੀ ਹੈ?" ਆਓ ਇੱਕ ਸਰਲ ਉਦਾਹਰਨ ਨਾਲ ਸ਼ੁਰੂ ਕਰੀਏ।

MCP ਸਰਵਰਾਂ ਨੂੰ ਵਿਸ਼ੇਸ਼ ਸਹਾਇਕ ਸਮਝੋ ਜੋ ਤੁਹਾਡੇ AI ਕੋਡਿੰਗ ਸਾਥੀ (ਜਿਵੇਂ GitHub Copilot) ਨੂੰ ਬਾਹਰੀ ਸੰਦਾਂ ਅਤੇ ਸੇਵਾਵਾਂ ਨਾਲ ਜੁੜਨ ਵਿੱਚ ਮਦਦ ਕਰਦੇ ਹਨ। ਜਿਵੇਂ ਤੁਸੀਂ ਆਪਣੇ ਫ਼ੋਨ 'ਤੇ ਵੱਖ-ਵੱਖ ਕੰਮਾਂ ਲਈ ਵੱਖ-ਵੱਖ ਐਪ ਵਰਤਦੇ ਹੋ—ਇੱਕ ਮੌਸਮ ਲਈ, ਇੱਕ ਰਾਹ ਨਿਰਦੇਸ਼ ਲਈ, ਇੱਕ ਬੈਂਕਿੰਗ ਲਈ—MCP ਸਰਵਰ ਤੁਹਾਡੇ AI ਸਹਾਇਕ ਨੂੰ ਵੱਖਰੇ ਵਿਕਾਸਿਕ ਸੰਦਾਂ ਅਤੇ ਸੇਵਾਵਾਂ ਨਾਲ ਸੰਵਾਦ ਕਰਨ ਦੀ ਯੋਗਤਾ ਦਿੰਦੇ ਹਨ।

### MCP ਸਰਵਰ ਜੋ ਸਮੱਸਿਆ ਹੱਲ ਕਰਦੇ ਹਨ

MCP ਸਰਵਰਾਂ ਤੋਂ ਪਹਿਲਾਂ, ਜੇ ਤੁਹਾਨੂੰ:
- ਆਪਣੇ Azure ਸਰੋਤ ਦੇਖਣੇ ਸਨ
- GitHub ਇਸਸ਼ਊ ਬਣਾਉਣਾ ਸੀ
- ਆਪਣਾ ਡੇਟਾਬੇਸ ਪੁੱਛਤਾਛ ਕਰਨੀ ਸੀ
- ਦਸਤਾਵੇਜ਼ਾਂ ਵਿਚ ਖੋਜ ਕਰਨੀ ਸੀ

ਤੁਹਾਨੂੰ ਕੋਡਿੰਗ ਰੋਕ ਕੇ ਬਰਾਊਜ਼ਰ ਖੋਲਣਾ ਪੈਂਦਾ, ਉਚਿਤ ਵੈੱਬਸਾਈਟ ਤੇ ਜਾਣਾ ਅਤੇ ਇਹ ਸਾਰੇ ਕੰਮ ਮੈਨੂਅਲ ਕਰਣੇ ਪੈਂਦੇ। ਇਹ ਲਗਾਤਾਰ ਸੰਦਰਭ ਬਦਲਾਉ ਤੁਹਾਡੇ ਧਿਆਨ ਨੂੰ ਭੰਗ ਕਰਦਾ ਸੀ ਅਤੇ ਉਤਪਾਦਕਤਾ ਘਟਾਉਂਦਾ ਸੀ।

### MCP ਸਰਵਰ ਤੁਹਾਡੇ ਵਿਕਾਸ ਅਨੁਭਵ ਨੂੰ ਕਿਵੇਂ ਬਦਲਦੇ ਹਨ

MCP ਸਰਵਰਾਂ ਨਾਲ, ਤੁਸੀਂ ਆਪਣੇ ਵਿਕਾਸ ਮਾਹੌਲ (VS Code, Visual Studio ਆਦਿ) ਵਿੱਚ ਹੀ ਰਹਿ ਕੇ ਆਪਣੇ AI ਸਹਾਇਕ ਨੂੰ ਇਹ ਕੰਮ ਕਰਨ ਲਈ ਕਹਿ ਸਕਦੇ ਹੋ। ਉਦਾਹਰਨ ਵਜੋਂ:

**ਇਹ ਸਰੰਪ੍ਰਦਾ ਸਿੱਧਾ ਉੱਤਰ:**
1. ਕੋਡਿੰਗ ਰੋਕੋ
2. ਬਰਾਊਜ਼ਰ ਖੋਲ੍ਹੋ

**ਹੁਣ ਤੁਸੀਂ ਹੋਰ ਕਰ سکتے ਹੋ:**

```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP ਸਰਵਰਾਂ ਨਾਲ:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

2. **MCP ਸਰਵਰ ਸੰਰਚਨਾ ਕਰੋ**: VS Code settings.json ਫ਼ਾਈਲ ਵਿੱਚ ਸਰਵਰ ਦੀ ਸੰਰਚਨਾ ਸ਼ਾਮਲ ਕਰੋ

4. **ਸੰਦ ਚੁਣੋ**: ਆਪਣੇ ਮੌਜੂਦਾ ਸੈਸ਼ਨ ਲਈ ਕਿਹੜੇ MCP ਸਰਵਰ ਚਾਲੂ ਕਰਨੇ ਹਨ, ਇਹ ਚੁਣੋ

ਵਿਸਥਾਰ ਵਿੱਚ ਸੈਟਅੱਪ ਦਿਸ਼ਾ-ਨਿਰਦੇਸ਼ ਲਈ, ਦੇਖੋ [VS Code MCP ਦਸਤਾਵੇਜ਼](https://code.visualstudio.com/docs/copilot/copilot-mcp)।

> **💡 ਪੇਸ਼ੇਵਰ ਟਿੱਪ: MCP ਸਰਵਰਾਂ ਨੂੰ ਪ੍ਰੋ ਵਾਂਗ ਪ੍ਰਬੰਧਿਤ ਕਰੋ!**
>
> VS Code ਐਕਸਟੈਂਸ਼ਨ ਵਿਊ ਹੁਣ ਇੱਕ [ਆਸਾਨ ਨਵਾਂ UI ਦਿੰਦਾ ਹੈ ਜੋ ਇੰਸਟਾਲਡ MCP ਸਰਵਰਾਂ ਨੂੰ ਸੰਭਾਲਦਾ ਹੈ](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! ਤੁਸੀਂ ਜਲਦੀ ਨਾਲ ਕਿਸੇ ਵੀ MCP ਸਰਵਰ ਨੂੰ ਸ਼ੁਰੂ, ਰੋਕ, ਅਤੇ ਪ੍ਰਬੰਧਿਤ ਕਰ ਸਕਦੇ ਹੋ ਇਸ ਸਪਸ਼ਟ ਅਤੇ ਸੌਖੇ ਇੰਟਰਫ਼ੇਸ ਦੀ ਵਰਤੋਂ ਕਰਕੇ। ਇਸਨੂੰ ਆਜ਼ਮਾਓ!

### Visual Studio 2022 ਸੈਟਅੱਪ

Visual Studio 2022 (ਸੰਸਕਰਣ 17.14 ਜਾਂ ਬਾਅਦ) ਲਈ:

1. **Agent ਮੋਡ ਚਾਲੂ ਕਰੋ**: GitHub Copilot Chat ਵਿੰਡੋ ਵਿੱਚ "Ask" ਡ੍ਰਾਪਡਾਊਨ 'ਤੇ ਕਲਿਕ ਕਰੋ ਅਤੇ "Agent" ਚੁਣੋ
2. **ਸੰਰਚਨਾ ਫ਼ਾਈਲ ਬਣਾਓ**: ਆਪਣੇ ਸੋਲੂਸ਼ਨ ਡਾਇਰੈਕਟਰੀ ਵਿੱਚ `.mcp.json` ਫ਼ਾਈਲ ਤਿਆਰ ਕਰੋ (ਸੁਝਾਈ ਗਈ ਥਾਂ: `<SOLUTIONDIR>\.mcp.json`)
3. **ਸਰਵਰ ਸੰਰਚਨਾ**: ਮਿਆਰੀ MCP ਫਾਰਮੈਟ ਦਾ ਇਸਤੇਮਾਲ ਕਰਕੇ ਆਪਣੀ MCP ਸਰਵਰ ਸੰਰਚਨਾ ਸ਼ਾਮਲ ਕਰੋ
4. **ਸੰਦ ਮੰਜੂਰੀ**: ਜਦੋਂ ਪੁੱਛਿਆ ਜਾਵੇ, ਤਾਂ ਵਾਂਙੋਂ ਦੀ ਸਹੀ ਸਕੋਪ ਅਨੁਮਤੀਆਂ ਨਾਲ ਸੰਦ ਨੂੰ ਮਨਜ਼ੂਰ ਕਰੋ

ਵਿਸਥਾਰ ਨਾਲ Visual Studio ਸੈਟਅੱਪ ਦਿਸ਼ਾ-ਨਿਰਦੇਸ਼ ਲਈ, ਵੇਖੋ [Visual Studio MCP ਦਸਤਾਵੇਜ਼](https://learn.microsoft.com/visualstudio/ide/mcp-servers)।

ਹਰ MCP ਸਰਵਰ ਦੀਆਂ ਆਪਣੇ ਵਿਸ਼ੇਸ਼ ਸੰਰਚਨਾ ਲੋੜਾਂ ਹੁੰਦੀਆਂ ਹਨ (ਕਨੈਕਸ਼ਨ ਸਟਰਿੰਗ, ਪ੍ਰਮਾਣਿਕਤਾ ਆਦਿ), ਪਰ ਦੋਹਾਂ IDEs ਵਿੱਚ ਸੈਟਅੱਪ ਪੈਟਰਨ ਸਮਾਨ ਹੈ।

### 2. ☁️ Azure MCP ਸਰਵਰ

**ਇਹ ਕੀ ਕਰਦਾ ਹੈ**: Azure MCP ਸਰਵਰ 15+ ਵਿਸ਼ੇਸ਼ Azure ਸਰਵਿਸ ਕੰਨੈਕਟਰਾਂ ਦਾ ਇੱਕ ਵਿਆਪਕ ਸੂਟ ਹੈ ਜੋ ਤੁਹਾਡੇ AI ਵਰਕਫਲੋ ਵਿੱਚ ਪੂਰੇ Azure ਪਰਿਵੇਸ਼ ਨੂੰ ਲੈ ਕੇ ਆਉਂਦਾ ਹੈ। ਇਹ ਸਿਰਫ ਇੱਕ ਸਰਵਰ ਨਹੀਂ ਹੈ – ਇਹ ਇਕ ਸ਼ਕਤੀਸ਼ਾਲੀ ਸਮੱਗਰੀ ਹੈ ਜੋ ਰਿਸੋਰਸ ਪ੍ਰਬੰਧਨ, ਡੇਟਾਬੇਸ ਕਨੈਕਟਿਵਿਟੀ (PostgreSQL, SQL Server), KQL ਨਾਲ Azure ਮਾਨੀਟਰ ਲੌਗ ਵਿਸ਼ਲੇਸ਼ਣ, Cosmos DB ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਅਤੇ ਬਹੁਤ ਕੁਝ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ।

**ਇਹ ਕਿਉਂ ਲਾਭਕਾਰੀ ਹੈ**: ਸਿਰਫ Azure ਰਿਸੋਰਸਾਂ ਦੀ ਮੈਨੇਜਮੈਂਟ ਤੋਂ ਇਲਾਵਾ, ਇਹ ਸਰਵਰ Azure SDKs ਨਾਲ ਕੰਮ ਕਰਨ ਵੇਲੇ ਕੋਡ ਦੀ ਗੁਣਵੱਤਾ ਵਿੱਚ ਗੰਭੀਰ ਸੁਧਾਰ ਕਰਦਾ ਹੈ। ਜਦੋਂ ਤੁਸੀਂ Agent ਮੋਡ ਵਿੱਚ Azure MCP ਵਰਤਦੇ ਹੋ, ਤਾਂ ਇਹ ਸਿਰਫ ਤੁਹਾਡਾ ਕੋਡ ਲਿਖਣ ਵਿੱਚ ਮਦਦ ਨਹੀਂ ਕਰਦਾ – ਇਹ ਤੁਹਾਨੂੰ *ਵਧੀਆ* Azure ਕੋਡ ਲਿਖਣ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ ਜੋ ਮੌਜੂਦਾ ਪ੍ਰਮਾਣਿਕਤਾ ਪੈਟਰਨਾਂ, ਐਰਰ ਹੈਂਡਲਿੰਗ ਦੇ ਸਭ ਤੋਂ ਵਧੀਆ ਤਰੀਕਿਆਂ ਦਾ ਪਾਲਣ ਕਰਦਾ ਹੈ ਅਤੇ ਨਵੀਂ SDK ਖੂਬੀਆਂ ਨੂੰ ਵਰਤਦਾ ਹੈ। ਕਾਮਨ ਕੋਡ ਦੀ ਥਾਂ, ਤੁਹਾਨੂੰ ਐਸਾ ਕੋਡ ਮਿਲਦਾ ਹੈ ਜੋ ਉਤਪਾਦਨ ਭਾਰਵਾਹ ઇન્ડਸਟਰੀ ਦੇ ਨਿਯਮਾਂ ਨੂੰ ਮੰਨਦਾ ਹੈ।

**ਮੁੱਖ ਮੋਡੀਊਲ ਸ਼ਾਮਲ ਨੇ**:
- **🗄️ ਡੇਟਾਬੇਸ ਕੰਨੈਕਟਰ**: Azure ਡੇਟਾਬੇਸ ਲਈ PostgreSQL ਅਤੇ SQL Server ਤੱਕ ਸਿੱਧਾ ਕੁਦਰਤੀ ਭਾਸ਼ਾ ਪਹੁੰਚ
- **📊 Azure ਮਾਨੀਟਰ**: KQL-ਚਲਾਏ ਲੌਗ ਵਿਸ਼ਲੇਸ਼ਣ ਅਤੇ ਆਪਰੇਸ਼ਨਲ ਝਲਕੀਆਂ
- **🌐 ਰਿਸੋਰਸ ਮੈਨੇਜਮੈਂਟ**: ਪੂਰੀ Azure ਰਿਸੋਰਸ ਦਾ ਜ਼ਿੰਦਗੀ ਚੱਕਰ ਪ੍ਰਬੰਧਨ
- **🔐 ਪ੍ਰਮਾਣਿਕਤਾ**: DefaultAzureCredential ਅਤੇ ਪ੍ਰਬੰਧਿਤ ਪਛਾਣ ਪੈਟਰਨ
- **📦 ਸਟੋਰੇਜ ਸਰਵਿਸਜ਼**: ਬਲੌਬ ਸਟੋਰੇਜ, ਕਿਊ ਸਟੋਰੇਜ, ਅਤੇ ਟੇਬਲ ਸਟੋਰੇਜ ਆਪਰੇਸ਼ਨਾਂ
- **🚀 ਕਨਟੇਨਰ ਸਰਵਿਸਜ਼**: Azure ਕਨਟੇਨਰ ਐਪਸ, ਕਨਟੇਨਰ ਇਨਸਟੈਂਸ ਅਤੇ AKS ਪ੍ਰਬੰਧਨ
- **ਅਤੇ ਹੋਰ ਬਹੁਤ ਸਾਰੇ ਵਿਸ਼ੇਸ਼ ਕੰਨੈਕਟਰ**

**ਅਸਲੀ ਜ਼ਿੰਦਗੀ ਦੀ ਵਰਤੋਂ**: "ਮੇਰੇ Azure ਸਟੋਰੇਜ ਅਕਾਉਂਟਾਂ ਦੀ ਸੂਚੀ ਬਨਾਓ", "ਮੇਰੇ ਲੌਗ ਐਨਾਲਿਟਿਕਸ ਵਰਕਸਪੇਸ ਵਿਚ ਪਿਛਲੇ ਘੰਟੇ ਦੇ ਗਲਤੀ ਦੇਖੋ", ਜਾਂ "Node.js ਨਾਲ ਇੱਕ ਸਹੀ ਪ੍ਰਮਾਣਿਕਤਾ ਵਾਲੀ Azure ਐਪਲੀਕੇਸ਼ਨ ਬਣਾਉਣ ਵਿੱਚ ਮਦਦ ਕਰੋ"

**ਪੂਰਾ ਡੈਮੋ ਸਿਨੇਰੀਓ**: ਇੱਥੇ ਇੱਕ ਪੂਰਾ ਵਾਕਥਰੂ ਹੈ ਜੋ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਕਿਵੇਂ Azure MCP GitHub Copilot ਲਈ VS Code ਵਿਕਾਸ ਵਿੱਚ ਸ਼ਕਤੀਸ਼ਾਲੀ ਹੈ। ਜਦੋਂ ਤੁਹਾਡੇ ਕੋਲ ਦੋਨਾਂ ਇੰਸਟਾਲ ਹੋ ਜਾਂਦੇ ਹਨ ਅਤੇ ਤੁਸੀਂ ਆਦੇਸ਼ ਦਿੰਦੇ ਹੋ:

> "ਇੱਕ Python ਸਕ੍ਰਿਪਟ ਬਣਾਓ ਜੋ DefaultAzureCredential ਪ੍ਰਮਾਣਿਕਤਾ ਨਾਲ Azure Blob Storage ਵਿੱਚ ਫਾਈਲ ਅੱਪਲੋਡ ਕਰਦਾ ਹੈ। ਸਕ੍ਰਿਪਟ ਮੇਰੇ Azure ਸਟੋਰੇਜ ਅਕਾਉਂਟ 'mycompanystorage' ਨਾਲ ਜੁੜੇ, 'documents' ਨਾਂ ਦੇ ਕਨਟੇਨਰ ਵਿੱਚ ਅੱਪਲੋਡ ਕਰੇ, ਮੌਜੂਦਾ ਸਮੇਂ ਦੇ ਟਾਈਮਸਟੈਂਪ ਨਾਲ ਇੱਕ ਟੈਸਟ ਫਾਈਲ ਬਣਾਉਂਦੇ ਹੋਏ, ਗਲਤੀਆਂ ਨੂੰ ਸੁੰਦਰ ਢੰਗ ਨਾਲ ਕਢਦਿਆਂ ਅਤੇ ਜਾਣਕਾਰੀ ਵਾਲਾ ਨਤੀਜਾ ਦੇਂਦਾ ਹੋਵੇ, ਪ੍ਰਮਾਣਿਕਤਾ ਅਤੇ ਗਲਤੀ ਹੈਂਡਲਿੰਗ ਲਈ Azure ਦੇ ਵਧੀਆ ਤਰੀਕੇ ਮੰਨਦਾ ਹੋਵੇ, ਟਿੱਪਣੀਆਂ ਦਿੰਦਾ ਹੋਵੇ ਜੋ DefaultAzureCredential ਕਿਵੇਂ ਕੰਮ ਕਰਦਾ ਹੈ ਸਮਝਾਉਂਦੀਆਂ ਹੋਣ ਅਤੇ ਸਕ੍ਰਿਪਟ ਨੂੰ ਸਹੀ ਫੰਕਸ਼ਨ ਅਤੇ ਦਸਤਾਵੇਜ਼ੀ ਦੇ ਨਾਲ ਸ਼ੁੱਧ ਢੰਗ ਨਾਲ ਬਣਾਉਂਦਾ ਹੋਵੇ।"

Azure MCP ਸਰਵਰ ਇੱਕ ਪੂਰੀ, ਉਤਪਾਦਨ-ਤਿਆਰ Python ਸਕ੍ਰਿਪਟ ਤਿਆਰ ਕਰੇਗਾ ਜੋ:
- XXX ਰੂਪ ਵਿੱਚ ਨਵੀਨਤਮ Azure Blob Storage SDK ਵਰਤਦਾ ਹੈ
- DefaultAzureCredential ਨੂੰ ਵਿਸਥਾਰ ਨਾਲ fallback ਲੜੀ ਵੇਖਾਉਂਦਾ ਹੈ
- ਖਾਸ Azure exception ਕਿਸਮਾਂ ਸਮੇਤ ਮਜ਼ਬੂਤ ਗਲਤੀ ਸੰਭਾਲ ਦਿੰਦਾ ਹੈ
- Azure SDK ਦੇ ਵਧੀਆ ਤਰੀਕਿਆਂ ਨਾਲ ਰਿਸੋਰਸ ਅਤੇ ਕਨੈਕਸ਼ਨ ਹੈਂਡਲਿੰਗ ਕਰਦਾ ਹੈ
- ਵਿਸਥਾਰਿਤ ਲਾਗਿੰਗ ਅਤੇ ਜਾਣਕਾਰੀ ਵਾਲੀ ਕੰਸੋਲ ਆਉਟਪੁੱਟ ਮੁਹੱਈਆ ਕਰਦਾ ਹੈ
- ਸਹੀ ਢੰਗ ਨਾਲ ਫੰਕਸ਼ਨ, ਦਸਤਾਵੇਜ਼ੀ ਅਤੇ ਟਾਈਪ ਹਿੰਟ ਦੇ ਨਾਲ ਸਕ੍ਰਿਪਟ ਬਣਾਉਂਦਾ ਹੈ

ਖਾਸ ਗੱਲ ਇਹ ਹੈ ਕਿ ਬਿਨਾਂ Azure MCP ਦੇ, ਤੁਹਾਨੂੰ ਸ਼ਾਇਦ ਐਸਾ ਜੈਨੇਰਿਕ ਬਲੌਬ ਸਟੋਰੇਜ ਕੋਡ ਮਿਲੇ ਜੋ ਕੰਮ ਕਰਦਾ ਹੈ ਪਰ ਮੌਜੂਦਾ Azure ਪੈਟਰਨਾਂ ਦਾ ਪਾਲਣ ਨਹੀਂ ਕਰਦਾ। Azure MCP ਨਾਲ ਤੁਸੀਂ ਐਸਾ ਕੋਡ ਪ੍ਰਾਪਤ ਕਰਦੇ ਹੋ ਜੋ ਨਵੀਨਤਮ ਪ੍ਰਮਾਣਿਕਤਾ ਤਰੀਕੇ ਵਰਤਦਾ ਹੈ, Azure ਵਿਸ਼ੇਸ਼ ਗਲਤੀ ਸਥਿਤੀਆਂ ਨੂੰ ਕਵਰ ਕਰਦਾ ਹੈ ਅਤੇ ਮਾਈਕ੍ਰੋਸੌਫਟ ਦੇ ਉਤਪਾਦਨ ਦੀਆਂ ਸਿਫਾਰਸ਼ਾਂ ਦੇ ਅਨੁਸਾਰ ਹੈ।

**ਮਿਸਾਲ**: ਮੈਨੂੰ `az` ਅਤੇ `azd` CLI ਕਮਾਂਡਾਂ ਯਾਦ ਰੱਖਣ ਵਿੱਚ ਮੁਸ਼ਕਿਲ ਹੁੰਦੀ ਹੈ, ਇਹ ਮੈਂ ਹਮੇਸ਼ਾ ਦੋ ਕਦਮਾਂ ਵਾਂਗ ਕਰਦਾ ਹਾਂ: ਪਹਿਲਾਂ ਸਿੰਟੈਕਸ ਵੇਖਦਾ ਹਾਂ ਫਿਰ ਕਮਾਂਡ ਚਲਾਉਂਦਾ ਹਾਂ। ਮੈਂ ਅਕਸਰ ਪੋਰਟਲ 'ਤੇ ਜਾ ਕੇ ਕਲਿੱਕ ਕਰਦਾ ਹਾਂ ਕਿਉਂਕਿ CLI ਸਿੰਟੈਕਸ ਯਾਦ ਨਹੀਂ ਹੁੰਦੀ। ਜੋ ਮੈਂ ਚਾਹੁੰਦਾ ਹਾਂ ਉਹ ਸਿੱਧਾ ਬਿਆਨ ਕਰਨਾ ਬਹੁਤ ਵਧੀਆ ਹੈ ਅਤੇ IDE ਛੱਡਣ ਬਿਨਾਂ ਇਹ ਕਰਨਾ ਹੋਰ ਵੀ ਵਧੀਆ ਹੈ!

ਤੁਹਾਨੂੰ ਸ਼ੁਰੂਆਤ ਕਰਨ ਲਈ [Azure MCP ਰਿਪੋਜ਼ਟਰੀ](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) ਵਿੱਚ ਬਹੁਤ ਸਾਰੇ ਵਰਤੋਂ ਕੇਸ ਮਿਲਣਗੇ। ਵਿਸਥਾਰਿਤ ਸੈਟਅੱਪ ਗਾਈਡਾਂ ਅਤੇ ਉੱਚ ਕੋਟਿ ਦੀਆਂ ਵਿਵਸਥਾਵਾਂ ਲਈ, [ਅਧਿਕਾਰਕ Azure MCP ਦਸਤਾਵੇਜ਼ ਜਾਣਚੋ](https://learn.microsoft.com/azure/developer/azure-mcp-server/)।

**ਅਸਲੀ ਜ਼ਿੰਦਗੀ ਦੀ ਵਰਤੋਂ**: "ਮੌਜੂਦਾ ਸਪ੍ਰਿੰਟ ਵਿੱਚ WebApp ਪ੍ਰੋਜੇਕਟ ਲਈ ਸਾਰੇ ਸਰਗਰਮ ਵਰਕ ਆਈਟਮ ਦਿਖਾਓ", "ਜੇ ਵੀ ਕੋਈ ਲੌਗਿਨ ਸਮੱਸਿਆ ਹੈ ਉਸ ਲਈ ਬੱਗ ਰਿਪੋਰਟ ਬਣਾਓ", ਜਾਂ "ਸਾਡੇ ਬਿਲਡ ਪਾਈਪਲਾਈਨਾਂ ਦੀ ਸਥਿਤੀ ਚੈੱਕ ਕਰੋ ਅਤੇ ਹਾਲੀਆ ਨਾਕਾਮੀਆਂ ਦਿਖਾਓ"

**ਮਿਸਾਲ**: ਤੁਸੀਂ ਆਪਣੇ ਟੀਮ ਦੇ ਮੌਜੂਦਾ ਸਪ੍ਰਿੰਟ ਦੀ ਸਥਿਤੀ ਆਸानी ਨਾਲ ਇੱਕ ਸਧਾਰਣ ਕਵੈਰੀ ਨਾਲ ਵੇਖ ਸਕਦੇ ਹੋ ਜਿਵੇਂ "ਮੌਜੂਦਾ ਸਪ੍ਰਿੰਟ ਲਈ ਸਾਰੇ ਸਰਗਰਮ ਵਰਕ ਆਈਟਮ ਦਿਖਾਓ ਜੋ WebApp ਪ੍ਰੋਜੇਕਟ ਦੇ ਹਨ" ਜਾਂ "ਜੋ ਨਵਾਂ ਲੌਗਿਨ ਮੁੱਦਾ ਮਿਲਿਆ ਉਹਦਾ ਬੱਗ ਰਿਪੋਰਟ ਬਣਾਓ" ਬਿਨਾਂ ਵਿਕਾਸ ਮਾਹੌਲ ਛੱਡੇ।

**ਇਹ ਕੀ ਕਰਦਾ ਹੈ**: MarkItDown ਇੱਕ ਵਿਸਤ੍ਰਿਤ ਦਸਤਾਵੇਜ਼ ਰੂਪਾਂਤਰਣ ਸਰਵਰ ਹੈ ਜੋ ਵੱਖ-ਵੱਖ ਫਾਇਲ ਫਾਰਮੇਟਾਂ ਨੂੰ ਉੱਚ-ਗੁਣਵੱਤਾ ਵਾਲੇ Markdown ਵਿੱਚ ਬਦਲਦਾ ਹੈ, ਜੋ LLM ਉਪਭੋਗਤਾ ਅਤੇ ਲਿਖਤ ਵਿਸ਼ਲੇਸ਼ਣ ਵਾਰਕਫਲੋਜ਼ ਲਈ ਅਪਟੀਮਾਈਜ਼ਡ ਹੈ।

**ਇਹ ਕਿਉਂ ਲਾਭਦਾਇਕ ਹੈ**: ਆਧੁਨਿਕ ਦਸਤਾਵੇਜ਼ਕਾਰੀ ਵਰਕਫਲੋਜ਼ ਲਈ ਜ਼ਰੂਰੀ! MarkItDown ਬਹੁਤ ਸਾਰੇ ਫਾਇਲ ਫਾਰਮੇਟਾਂ ਨੂੰ ਹੈਂਡਲ ਕਰਦਾ ਹੈ ਜਦੋਂ ਕਿ ਮੁੱਖ ਦਸਤਾਵੇਜ਼ ਦੀ ਬਣਤਰ ਜਿਵੇਂ ਕਿ ਸਿਰਲੇਖ, ਸੂਚੀਆਂ, ਟੇਬਲਾਂ ਅਤੇ ਲਿੰਕਾਂ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਦਾ ਹੈ। ਸਧਾਰਣ ਟੈਕਸਟ ਨਿਰਯਾਤ ਯੰਤਰਾਂ ਦੇ ਉਲਟ, ਇਹ ਅਰਥਪੂਰਣ ਅਰਥ ਅਤੇ ਫਾਰਮੇਟਿੰਗ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਣ 'ਤੇ ਧਿਆਨ ਦਿੰਦਾ ਹੈ ਜੋ ਦੋਹਾਂ AI ਪ੍ਰਕਿਰਿਆ ਅਤੇ ਮਨੁੱਖੀ ਪਾਠਨ ਯੋਗਤਾ ਲਈ ਕੀਮਤੀ ਹੈ।

**ਸਮਰਥਿਤ ਫਾਇਲ ਫਾਰਮੇਟ**:
- **ਦਫ਼ਤਰੀ ਦਸਤਾਵੇਜ਼**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **ਮੀਡੀਆ ਫਾਇਲਾਂ**: ਚਿੱਤਰ (EXIF ਮੈਟਾ ਡਾਟਾ ਅਤੇ OCR ਨਾਲ), ਆਡੀਓ (EXIF ਮੈਟਾ ਡਾਟਾ ਅਤੇ ਵਾਕ ਪ੍ਰਤਿਲਿਪੀ ਨਾਲ)
- **ਵੈੱਬ ਸਮੱਗਰੀ**: HTML, RSS ਫੀਡ, YouTube URLs, Wikipedia ਪੰਨੇ
- **ਡਾਟਾ ਫਾਰਮੇਟ**: CSV, JSON, XML, ZIP ਫਾਇਲਾਂ (ਸਮੱਗਰੀ ਨੂੰ ਪੂਨਰਾਵਲੋਕਨ ਕਰਦਾ ਹੈ)
- **ਪਬਲਿਸ਼ਿੰਗ ਫਾਰਮੇਟ**: EPub, Jupyter ਨੋਟਬੁੱਕ (.ipynb)
- **ਈਮੇਲ**: Outlook ਸੁਨੇਹੇ (.msg)
- **ਅੱਗੇਵਧੀਆ**: Azure Document Intelligence ਇੰਟਿਗਰੇਸ਼ਨ ਸੁਧਾਰਿਆ PDF ਪ੍ਰੋਸੈਸਿੰਗ ਲਈ

**ਅਗਾਂਹ ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ**: MarkItDown LLM-ਸਮਰਥਿਤ ਚਿੱਤਰ ਵਰਣਨ (ਜਦੋਂ OpenAI ਕਲਾਇੰਟ ਦਿੱਤਾ ਜਾਵੇ), ਸੁਧਾਰਿਆ PDF ਪ੍ਰੋਸੈਸਿੰਗ ਲਈ Azure Document Intelligence, ਵਾਕ ਸਮੱਗਰੀ ਲਈ ਆਡੀਓ ਟ੍ਰਾਂਸਕ੍ਰਿਪਸ਼ਨ ਅਤੇ ਹੋਰ ਫਾਇਲ ਫਾਰਮੇਟਾਂ ਤੇ ਵਧਾਵਾ ਕਰਨ ਲਈ ਪਲੱਗਇਨ ਸਿਸਟਮ ਦਾ ਸਮਰਥਨ ਕਰਦਾ ਹੈ।

**ਵਾਸਤਵਿਕ ਵਰਤੋਂ**: "ਸਾਡੇ ਦਸਤਾਵੇਜ਼ਕਾਰੀ ਸਾਈਟ ਲਈ ਇਸ PowerPoint ਪ੍ਰਜ਼ੇਂਟੇਸ਼ਨ ਨੂੰ Markdown ਵਿੱਚ ਬਦਲੋ", "ਇਸ PDF ਤੋਂ ਸਹੀ ਸਿਰਲੇਖ ਬਣਤਰ ਨਾਲ ਟੈਕਸਟ ਕੱਢੋ", ਜਾਂ "ਇਸ Excel ਸਪ੍ਰੈੱਡਸ਼ੀਟ ਨੂੰ ਪਾਠਨ ਯੋਗ ਟੇਬਲ ਫਾਰਮੇਟ ਵਿੱਚ ਬਦਲੋ"

**ਮਿਸਾਲ ਪ੍ਰਸਤੁਤ**: [MarkItDown ਦਸਤਾਵੇਜ਼](https://github.com/microsoft/markitdown#why-markdown) ਤੋਂ ਹਵਾਲੇ ਲਈ:

> Markdown ਸਾਧਾਰਣ ਪਾਠ ਦੇ ਬਹੁਤ ਨੇੜੇ ਹੈ, ਘੱਟ ਤੋਂ ਘੱਟ ਮਾਰਕਅੱਪ ਜਾਂ ਫਾਰਮੈਟਿੰਗ ਦੇ ਨਾਲ, ਪਰ ਮੁੱਖ ਦਸਤਾਵੇਜ਼ ਬਣਤਰ ਨੂੰ ਦਰਸਾਉਣ ਦਾ ਤਰੀਕਾ ਦਿੰਦਾ ਹੈ। ਪ੍ਰਮੁੱਖ LLMs, ਜਿਵੇਂ OpenAI ਦਾ GPT-4o, ਕੁਦਰਤੀ ਤੌਰ 'ਤੇ Markdown "ਬੋਲਦੇ" ਹਨ, ਅਤੇ ਅਕਸਰ ਬਿਨਾਂ ਪੁੱਛੇ Markdown ਨੂੰ ਆਪਣੇ ਜਵਾਬਾਂ ਵਿੱਚ ਸ਼ਾਮਲ ਕਰ ਲੈਂਦੇ ਹਨ। ਇਸ ਦਾ ਮਤਲਬ ਹੈ ਕਿ ਉਨ੍ਹਾਂ ਨੂੰ ਵੱਡੀ ਮਾਤਰਾ ਵਿੱਚ Markdown-ਫਾਰਮੈਟ ਕੀਤਾ ਪਾਠ ਸਿਖਾਇਆ ਗਿਆ ਹੈ ਅਤੇ ਉਹ ਇਸ ਨੂੰ ਚੰਗੀ ਤਰ੍ਹਾਂ ਸਮਝਦੇ ਹਨ। ਇਕ ਸाइड ਫਾਇਦਾ ਇਹ ਵੀ ਹੈ ਕਿ Markdown ਪ੍ਰਵਣਤਾ ਬਹੁਤ ਟੋਕਨ-ਕੁਸ਼ਲ ਹੈ।

MarkItDown ਦਸਤਾਵੇਜ਼ ਦੀ ਬਣਤਰ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਣ ਵਿੱਚ ਬਹੁਤ ਚੰਗਾ ਹੈ, ਜੋ ਕਿ AI ਵਰਕਫਲੋਜ਼ ਲਈ ਮਹੱਤਵਪੂਰਨ ਹੈ। ਉਦਾਹਰਣ ਲਈ, ਜਦੋਂ PowerPoint ਪ੍ਰਜ਼ੇਂਟੇਸ਼ਨ ਨੂੰ ਬਦਲਿਆ ਜਾਂਦਾ ਹੈ, ਇਹ ਸਲਾਈਡ ਸੰਗਠਨ ਨੂੰ ਠੀਕ ਸਿਰਲੇਖਾਂ ਨਾਲ ਰੱਖਦਾ ਹੈ, ਟੇਬਲਾਂ ਨੂੰ Markdown ਟੇਬਲਾਂ ਵਜੋਂ ਕੱਢਦਾ ਹੈ, ਚਿੱਤਰਾਂ ਲਈ alt ਟੈਕਸਟ ਸ਼ਾਮਲ ਕਰਦਾ ਹੈ, ਅਤੇ ਬੋਲਣ ਵਾਲੇ ਨੋਟਾਂ ਦੀ ਵੀ ਪ੍ਰਕਿਰਿਆ ਕਰਦਾ ਹੈ। ਚਾਰਟਾਂ ਨੂੰ ਪਾਠਨ ਯੋਗ ਡਾਟਾ ਟੇਬਲਾਂ ਵਿੱਚ ਬਦਲ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ, ਅਤੇ ਪ੍ਰਾਪਤ Markdown ਮੂਲ ਪ੍ਰਜ਼ੇਂਟੇਸ਼ਨ ਦੀ ਤਰਕਸ਼ੀਲ ਪ੍ਰਵਾਹ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਦਾ ਹੈ। ਇਹ ਪ੍ਰਜ਼ੇਂਟੇਸ਼ਨ ਸਮੱਗਰੀ ਨੂੰ AI ਸਿਸਟਮਾਂ ਵਿੱਚ ਖੁਰਾਕ ਦੇਣ ਜਾਂ ਮੌਜੂਦਾ ਸਲਾਈਡਾਂ ਤੋਂ ਦਸਤਾਵੇਜ਼ ਬਣਾਉਣ ਲਈ ਇdeal ਹੈ।

**ਇਹ ਕਿਉਂ ਲਾਭਦਾਇਕ ਹੈ**: ਇਹ ਸਰਵਰ ਤੁਹਾਡੇ ਐਜ਼ੂਰ ਏਆਈ ਸੇਵਾਵਾਂ ਦੇ ਨਾਲ ਕੰਮ ਕਰਨ ਦੇ ਢੰਗ ਨੂੰ ਬਦਲਦਾ ਹੈ ਅਤੇ ਉੱਦਯੋਗ-ਗਰੇਡ ਏਆਈ ਸਮਰੱਥਾਵਾਂ ਨੂੰ ਸਿੱਧਾ ਤੁਹਾਡੇ ਵਿਕਾਸ ਵਰਕਫ਼ਲੋ ਵਿੱਚ ਲਿਆਉਂਦਾ ਹੈ। ਐਜ਼ੂਰ ਪੋਰਟਲ, ਦਸਤਾਵੇਜ਼ੀकरण ਅਤੇ ਤੁਹਾਡੇ IDE ਵਿੱਚ ਬਦਲਣ ਦੇ ਬਜਾਏ, ਤੁਸੀਂ ਮਾਡਲ ਖੋਜ ਸਕਦੇ ਹੋ, ਸੇਵਾਵਾਂ ਡਿਪਲੌਇ ਕਰ ਸਕਦੇ ਹੋ, ਗਿਆਨ ਅਧਾਰਾਂ ਨੂੰ ਪਰਬੰਧਿਤ ਕਰ ਸਕਦੇ ਹੋ, ਅਤੇ ਕੁਦਰਤੀ ਭਾਸ਼ਾ ਕਮਾਂਡਾਂ ਰਾਹੀਂ ਏਆਈ ਕਾਰਗੁਜ਼ਾਰੀ ਦਾ ਮੁਲਾਂਕਣ ਕਰ ਸਕਦੇ ਹੋ। ਇਹ ਖਾਸ ਕਰਕੇ ਉਹਨਾਂ ਵਿਕਸਿਤਕਾਰਾਂ ਲਈ ਸ਼ਕਤੀਸ਼ালী ਹੈ ਜੋ RAG (ਰੀਟਰੀਵਲ-ਆਗਮੈਂਟਡ ਜਨਰੇਸ਼ਨ) ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਬਣਾਉਂਦੇ ਹਨ, ਮਲਟੀ-ਮਾਡਲ ਡਿਪਲੌਇਮੈਂਟ ਪ੍ਰਬੰਧਿਤ ਕਰਦੇ ਹਨ, ਜਾਂ ਵਿਸ਼ਤ੍ਰਿਤ ਏਆਈ ਮੁਲਾਂਕਣ ਪਾਈਪਲਾਈਨ ਬਣਾਉਂਦੇ ਹਨ।

**ਮੁੱਖ ਵਿਕਸਿਤਕਾਰ ਸਮਰੱਥਾਵਾਂ**:
- **🔍 ਮਾਡਲ ਖੋਜ ਅਤੇ ਡਿਪਲੌਇਮੈਂਟ**: ਮਾਈਕ੍ਰੋਸੌਫਟ ਫਾਉਂਡਰੀ ਦੇ ਮਾਡਲ ਕੈਟਾਲੌਗ ਦੀ ਖੋਜ ਕਰੋ, ਕੋਡ ਨਮੂਨੇ ਨਾਲ ਵਿਸਥਾਰਵਾਦੀ ਮਾਡਲ ਜਾਣਕਾਰੀ ਪ੍ਰਾਪਤ ਕਰੋ, ਅਤੇ ਮਾਡਲਾਂ ਨੂੰ ਐਜ਼ੂਰ ਏਆਈ ਸੇਵਾਵਾਂ 'ਤੇ ਡਿਪਲੌਇ ਕਰੋ
- **📚 ਗਿਆਨ ਪ੍ਰਬੰਧਨ**: ਐਜ਼ੂਰ ਏਆਈ ਸਰਚ ਇੰਡੈਕਸ ਬਣਾਓ ਅਤੇ ਪ੍ਰਬੰਧਿਤ ਕਰੋ, ਦਸਤਾਵੇਜ਼ ਜੋੜੋ, ਇੰਡੈਕਸਰ ਨੂੰ ਸੰਰਚਿਤ ਕਰੋ, ਅਤੇ ਸੁਗਠਿਤ RAG ਸਿਸਟਮ ਬਣਾਓ
- **⚡ ਏਆਈ ਏਜੰਟ ਇੰਟੀਗ੍ਰੇਸ਼ਨ**: ਐਜ਼ੂਰ ਏਆਈ ਏਜੰਟਾਂ ਨਾਲ ਜੁੜੋ, ਮੌਜੂਦਾ ਏਜੰਟਾਂ ਨੂੰ ਕਵੈਰੀ ਕਰੋ, ਅਤੇ ਉਤਪਾਦਨ ਪ੍ਰਸੰਗਾਂ ਵਿੱਚ ਏਜੰਟ ਪ੍ਰਦਰਸ਼ਨ ਦਾ ਮੁਲਾਂਕਣ ਕਰੋ
- **📊 ਮੁਲਾਂਕਣ ਫਰੇਮਵਰਕ**: ਵਿਸਥਾਰਵਾਦੀ ਟੈਕਸਟ ਅਤੇ ਏਜੰਟ ਮੁਲਾਂਕਣ ਚਲਾਓ, ਮਾਰਕਡਾਊਨ ਰਿਪੋਰਟ ਤਿਆਰ ਕਰੋ, ਅਤੇ ਏਆਈ ਐਪਲੀਕੇਸ਼ਨਾਂ ਲਈ ਕੁਆਲਟੀ ਅਸ਼ਿਊਰਨਸ ਲਾਗੂ ਕਰੋ
- **🚀 ਪ੍ਰੋਟੋਟਾਈਪਿੰਗ ਟੂਲਜ਼**: GitHub ਆਧਾਰਿਤ ਪ੍ਰੋਟੋਟਾਈਪਿੰਗ ਲਈ ਸੈਟਅੱਪ ਹਦਾਇਤਾਂ ਪ੍ਰਾਪਤ ਕਰੋ ਅਤੇ ਮਾਈਕ੍ਰੋਸੌਫਟ ਫਾਉਂਡਰੀ ਲੈਬਜ਼ ਤੱਕ ਪਹੁੰਚ ਪ੍ਰਾਪਤ ਕਰੋ ਜੋ ਅਗੇਤਕ ਰੀਸਰਚ ਮਾਡਲ ਪ੍ਰਦਾਨ ਕਰਦੇ ਹਨ

**ਅਸਲੀ ਦੁਨੀਆ ਵਿੱਚ ਵਿਕਸਿਤਕਾਰ ਪ੍ਰਭਾਵ**: "ਮੇਰੇ ਐਪਲੀਕੇਸ਼ਨ ਲਈ Phi-4 ਮਾਡਲ ਨੂੰ ਐਜ਼ੂਰ ਏਆਈ ਸੇਵਾਵਾਂ 'ਤੇ ਡਿਪਲੌਇ ਕਰੋ", "ਮੇਰੇ ਦਸਤਾਵੇਜ਼ੀ RAG ਸਿਸਟਮ ਲਈ ਨਵਾਂ ਸਰਚ ਇੰਡੈਕਸ ਬਣਾਓ", "ਮੇਰੇ ਏਜੰਟ ਦੇ ਜਵਾਬਾਂ ਨੂੰ ਕੁਆਲਟੀ ਮੈਟਰਿਕਸ ਦੇ ਖਿਲਾਫ ਮੁਲਾਂਕਣ ਕਰੋ", ਜਾਂ "ਮੇਰੇ ਜਟਿਲ ਵਿਸ਼ਲੇਸ਼ਣ ਕਾਰਜਾਂ ਲਈ ਸਭ ਤੋਂ ਵਧੀਆ reasoning ਮਾਡਲ ਲੱਭੋ"

**ਪੂਰਾ ਡੈਮੋ ਸਕੇਨਾਰੀਓ**: ਇਥੇ ਇੱਕ ਸ਼ਕਤੀਸ਼ਾਲੀ ਏਆਈ ਵਿਕਾਸ ਵਰਕਫ਼ਲੋ ਹੈ:

> "ਮੈਂ ਇੱਕ ਗਾਹਕ ਸਹਾਇਤਾ ਏਜੰਟ ਬਣਾ ਰਿਹਾ ਹਾਂ। ਮੈਨੂੰ ਕੈਟਾਲੌਗ ਤੋਂ ਇੱਕ ਵਧੀਆ reasoning ਮਾਡਲ ਲੱਭਣ ਵਿੱਚ ਮਦਦ ਕਰੋ, ਇਸਨੂੰ ਐਜ਼ੂਰ ਏਆਈ ਸੇਵਾਵਾਂ 'ਤੇ ਡਿਪਲੌਇ ਕਰੋ, ਸਾਡੀ ਦਸਤਾਵੇਜ਼ੀ ਤੋਂ ਇੱਕ ਗਿਆਨ ਅਧਾਰ ਬਣਾਓ, ਜਵਾਬ ਦੀ ਕੁਆਲਟੀ ਦੀ ਜਾਂਚ ਲਈ ਮੁਲਾਂਕਣ ਫਰੇਮਵਰਕ ਸੈਟ ਕਰੋ, ਅਤੇ ਫਿਰ GitHub ਟੋਕਨ ਨਾਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਲਈ ਪ੍ਰੋਟੋਟਾਈਪਿੰਗ ਵਿੱਚ ਮਦਦ ਕਰੋ।"

ਮਾਈਕਰੋਸੌਫਟ ਫਾਉਂਡਰੀ MCP ਸਰਵਰ ਇਹ ਕਰੇਗਾ:
- ਤੁਹਾਡੇ ਲੋੜਾਂ ਦੇ ਅਧਾਰ 'ਤੇ ਸਭ ਤੋਂ ਵਧੀਆ reasoning ਮਾਡਲਾਂ ਦੀ ਸਿਫਾਰਸ਼ ਕਰਨ ਲਈ ਮਾਡਲ ਕੈਟਾਲੌਗ ਨੂੰ ਕਵੈਰੀ ਕਰੇਗਾ
- ਤੁਹਾਡੇ ਪਸੰਦੀਦਾ ਐਜ਼ੂਰ ਖੇਤਰ ਲਈ ਡਿਪਲੌਇਮੈਂਟ ਕਮਾਂਡਸ ਅਤੇ ਕੋਟਾ ਜਾਣਕਾਰੀ ਪ੍ਰਦਾਨ ਕਰੇਗਾ
- ਤੁਹਾਡੇ ਦਸਤਾਵੇਜ਼ੀ ਲਈ ਸਹੀ ਸਕੀਮਾ ਨਾਲ ਐਜ਼ੂਰ ਏਆਈ ਸਰਚ ਇੰਡੈਕਸ ਸੈਟਅੱਪ ਕਰੇਗਾ
- ਕੁਆਲਟੀ ਮੈਟਰਿਕਸ ਅਤੇ ਸੁਰੱਖਿਆ ਜਾਂਚਾਂ ਨਾਲ ਮੁਲਾਂਕਣ ਪਾਈਪਲਾਈਨਾਂ ਨੂੰ ਸੰਰਚਿਤ ਕਰੇਗਾ
- ਤੁਰੰਤ ਟੈਸਟਿੰਗ ਲਈ GitHub ਪ੍ਰਮਾਣੀਕਰਨ ਨਾਲ ਪ੍ਰੋਟੋਟਾਈਪਿੰਗ ਕੋਡ ਤਿਆਰ ਕਰੇਗਾ
- ਤੁਹਾਡੇ ਖਾਸ ਤਕਨਾਲੋਜੀ ਸਟੈਕ ਲਈ ਵਿਸਥਾਰਵਾਦੀ ਸੈਟਅੱਪ ਗਾਈਡਜ਼ ਪ੍ਰਦਾਨ ਕਰੇਗਾ

**ਚੁਣੀ ਹੋਈ ਉਦਾਹਰਨ**: ਇੱਕ ਵਿਕਸਿਤਕਾਰ ਵਜੋਂ, ਮੈਂ ਵੱਖ-ਵੱਖ LLM ਮਾਡਲਾਂ ਨਾਲ ਅਪ-ਟੂ-ਡੇਟ ਰਹਿਣ ਵਿੱਚ ਮੁਸ਼ਕਲ ਮਹਿਸੂਸ ਕਰਦਾ ਹਾਂ। ਮੈਂ ਕੁਝ ਮੁੱਖ ਮਾਡਲਾਂ ਨੂੰ ਜਾਣਦਾ ਹਾਂ, ਪਰ ਮਹਿਸੂਸ ਕਰਦਾ ਹਾਂ ਕਿ ਮੈਂ ਕੁਝ ਉਤਪਾਦਕਤਾ ਅਤੇ ਕਾਰਗੁਜ਼ਾਰੀ ਲਾਭਾਂ ਨੂੰ ਗੁਆ ਰਿਹਾ ਹਾਂ। ਟੋਕਨਾਂ ਅਤੇ ਕੋਟੇਜ਼ ਨੂੰ ਪਰਬੰਧਿਤ ਕਰਨਾ ਤਣਾਅਪੂਰਨ ਅਤੇ ਮੁਸ਼ਕਲ ਹੈ – ਮੈਂ ਕਦੇ ਨਹੀਂ ਜਾਣਦਾ ਕਿ ਮੈਂ ਸਹੀ ਕਾਰਜ ਲਈ ਸਹੀ ਮਾਡਲ ਚੁਣ ਰਿਹਾ ਹਾਂ ਜਾਂ ਆਪਣੇ ਬਜਟ ਨੂੰ ਬੇਫ਼ਾਇਦੇ ਨਾਲ ਖਰਚ ਕਰ ਰਿਹਾ ਹਾਂ। ਮੈਂ ਜੇਮਜ਼ ਮੋਂਟੇਮਾਗਨ ਤੋਂ MCP ਸਰਵਰ ਬਾਰੇ ਸੁਣਿਆ ਹੋਇਆ ਹੈ ਜਦੋਂ ਮੈਂ ਆਪਣੀ ਟੀਮ ਨਾਲ MCP ਸਰਵਰ ਸੁਝਾਵਾਂ ਲਈ ਗੱਲ ਕਰ ਰਿਹਾ ਸੀ, ਅਤੇ ਮੈਂ ਇਸਨੂੰ ਵਰਤਣ ਲਈ ਉਤਸ਼ਾਹਿਤ ਹਾਂ! ਮਾਡਲ ਖੋਜ ਸਮਰੱਥਾਵਾਂ ਖਾਸ ਕਰਕੇ ਉਨ੍ਹਾਂ ਲਈ ਬਹੁਤ ਪ੍ਰਭਾਵਸ਼ালী ਹਨ ਜੋ ਆਮ ਮਾਡਲਾਂ ਤੋਂ ਅੱਗੇ ਵਧ ਕੇ ਖਾਸ ਕਾਰਜਾਂ ਲਈ ਉਪਯੋਗ ਮਾਡਲ ਖੋਜਣਾ ਚਾਹੁੰਦੇ ਹਨ। ਮੁਲਾਂਕਣ ਫਰੇਮਵਰਕ ਮੈਨੂੰ ਇਹ ਸਾਬਤ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰੇਗਾ ਕਿ ਮੈਂ ਵਾਸਤਵ ਵਿੱਚ ਚੰਗੇ ਨਤੀਜੇ ਪ੍ਰਾਪਤ ਕਰ ਰਿਹਾ ਹਾਂ, ਨਾ ਕਿ ਸਿਰਫ਼ ਨਵਾਂ ਕੁਝ ਕਰ ਰਹਾ ਹਾਂ।

**ਇਹ ਕੀ ਕਰਦਾ ਹੈ**: ਮਾਈਕ੍ਰੋਸੌਫਟ 365 ਅਤੇ ਮਾਈਕ੍ਰੋਸੌਫਟ 365 ਕੋਪਾਇਲਟ ਨਾਲ ਇੰਟੀਗਰੇਟ ਕਰਨ ਵਾਲੇ ਏਆਈ ਏਜੰਟਾਂ ਅਤੇ ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਬਣਾਉਣ ਲਈ ਅਵਸ਼ਯਕ ਉਪਕਰਣ ਵਿਕਸਿਤਕਾਰਾਂ ਨੂੰ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ, ਜਿਸ ਵਿੱਚ ਸਕੀਮਾ ਵੈਧਤਾ, ਨਮੂਨਾ ਕੋਡ ਪ੍ਰਾਪਤੀ, ਅਤੇ ਟ੍ਰਬਲਸ਼ੂਟਿੰਗ ਸਹਾਇਤਾ ਸ਼ਾਮਲ ਹਨ।

**ਇਹ ਕਿਉਂ ਲਾਭਦਾਇਕ ਹੈ**: ਮਾਈਕ੍ਰੋਸੌਫਟ 365 ਅਤੇ ਕੋਪਾਇਲਟ ਲਈ ਬਣਾਉਣ ਵਿੱਚ ਜਟਿਲ ਮੈਨਿਫੈਸਟ ਸਕੀਮਾਂ ਅਤੇ ਵਿਸ਼ੇਸ਼ ਵਿਕਾਸ ਪੈਟਰਨ ਸ਼ਾਮਲ ਹੁੰਦੇ ਹਨ। ਇਹ MCP ਸਰਵਰ ਬਿਨਾਂ ਲਗਾਤਾਰ ਦਸਤਾਵੇਜ਼ੀ ਨੂੰ ਵੇਖੇ ਸਿੱਧਾ ਤੁਹਾਡੇ ਕੋਡਿੰਗ ਵਾਤਾਵਰਨ ਵਿੱਚ ਜ਼ਰੂਰੀ ਵਿਕਾਸ ਸੰਸਾਧਨ ਲਿਆਉਂਦਾ ਹੈ, ਜੋ ਤੁਹਾਨੂੰ ਸਕੀਮਾ ਵੈਧ ਕਰਨ, ਨਮੂਨਾ ਕੋਡ ਲੱਭਣ, ਅਤੇ ਆਮ ਸਮੱਸਿਆਵਾਂ ਦਾ ਟ੍ਰਬਲਸ਼ੂਟ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰਦਾ ਹੈ।

**ਅਸਲੀ ਦੁਨੀਆ ਵਰਤੋਂ**: "ਮੇਰੇ ਘੋਸ਼ਿਤ ਏਜੰਟ ਮੈਨਿਫੈਸਟ ਨੂੰ ਵੈਧ ਕਰੋ ਅਤੇ ਕਿਸੇ ਵੀ ਸਕੀਮਾ ਗਲਤੀਆਂ ਨੂੰ ਠੀਕ ਕਰੋ", "ਮਾਈਕ੍ਰੋਸੌਫਟ ਗ੍ਰਾਫ API ਪਲੱਗਇਨ ਨੂੰ ਲਾਗੂ ਕਰਨ ਲਈ ਨਮੂਨਾ ਕੋਡ ਦਿਖਾਓ", ਜਾਂ "ਮੇਰੇ Teams ਐਪ ਪ੍ਰਮਾਣੀਕਰਨ ਸਮੱਸਿਆਵਾਂ ਨੂੰ ਠੀਕ ਕਰਨ ਵਿੱਚ ਮਦਦ ਕਰੋ"

**ਚੁਣੀ ਹੋਈ ਉਦਾਹਰਨ**: ਮੈਂ ਮਾਈ  ਦੋਸਤ ਜੌਨ ਮਿਲਰ ਨਾਲ Build 'ਤੇ M365 ਏਜੰਟਸ ਬਾਰੇ ਗੱਲ ਕਰਨ ਤੋਂ ਬਾਅਦ ਸੰਪਰਕ ਕੀਤਾ, ਅਤੇ ਉਸਨੇ ਇਹ MCP ਸਿਫਾਰਸ਼ ਕੀਤੀ। ਇਹ M365 ਏਜੰਟਸ ਵਿੱਚ ਨਵੇਂ ਵਿਕਸਿਤਕਾਰਾਂ ਲਈ ਬਹੁਤ ਵਧੀਆ ਹੋ ਸਕਦਾ ਹੈ ਕਿਉਂਕਿ ਇਹ ਟੈਮਪਲੇਟ, ਨਮੂਨਾ ਕੋਡ, ਅਤੇ ਸ਼ੁਰੂਆਤ ਲਈ ਢਾਂਚਾ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ ਬਿਨਾਂ ਭਾਰੀ ਦਸਤਾਵੇਜ਼ੀ ਵਿੱਚ ਡੁੱਬਣ ਦੇ। ਸਕੀਮਾ ਵੈਧਤਾ ਵਿਸ਼ੇਸ਼ ਤੌਰ 'ਤੇ ਮੈਨਿਫੈਸਟ ਸੰਰਚਨਾ ਦੀਆਂ ਗਲਤੀਆਂ ਤੋਂ ਬਚਣ ਲਈ ਲਾਗੂ ਕੀਤੀ ਜਾ ਸਕਦੀ ਹੈ ਜੋ ਘੰਟਿਆਂ ਦੀ ਡੀਬੱਗਿੰਗ ਵਜੋਂ ਸਮਾਂ ਲੈ ਸਕਦੀਆਂ ਹਨ।

> **💡 ਪ੍ਰੋ ਟਿਪ**
> 
> ਵਿਸਥਾਰਵਾਦੀ M365 ਵਿਕਾਸ ਸਮਰਥਨ ਲਈ ਇਸ ਸਰਵਰ ਨੂੰ Microsoft Learn Docs MCP Server ਨਾਲ ਇਕੱਠੇ ਵਰਤੋਂ – ਇੱਕ ਅਧਿਕਾਰਤ ਦਸਤਾਵੇਜ਼ੀ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ ਜਦਕਿ ਇਹ ਵਰਤੋਂਕਾਰਪ੍ਰਧਾਨ ਵਿਕਾਸ ਟੂਲ ਅਤੇ ਟ੍ਰਬਲਸ਼ੂਟਿੰਗ ਸਹਾਇਤਾ ਦਿੰਦਾ ਹੈ।


## ਅਗਲਾ ਕੀ? 🔮

## 📋 ਨਤੀਜਾ

ਮਾਡਲ ਕਾਂਟੈਕਸਟ ਪ੍ਰਾਟੋਕੋਲ (MCP) ਵਿਕਸਿਤਕਾਰਾਂ ਅਤੇ ਬਾਹਰੀ ਸੰਦਾਂ ਨਾਲ ਏਆਈ ਸਹਾਇਕਾਂ ਦੇ ਸੰਚਾਰ ਦਾ ਤਰੀਕਾ ਬਦਲ ਰਿਹਾ ਹੈ। ਇਹ 10 ਮਾਈਕਰੋਸੌਫਟ MCP ਸਰਵਰ ਇੱਕ ਸੰਚਿਤ ਸਟੈਂਡਰਡ ਏਆਈ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਦੀ ਤਾਕਤ ਦਿਖਾਉਂਦੇ ਹਨ, ਜੋ ਅਸੀਮਤ ਵਰਕਫ਼ਲੋ ਸੰਭਵ ਬਣਾਉਂਦੇ ਹਨ ਜੋ ਵਿਕਸਿਤਕਾਰਾਂ ਨੂੰ ਸ਼ਕਤੀਸ਼ਾਲੀ ਬਾਹਰੀ ਸਮਰੱਥਾਵਾਂ ਤੱਕ ਪਹੁੰਚ ਦਿੰਦੇ ਹੋਏ ਉਹਨਾਂ ਦੇ ਫਲੋ ਵਿੱਚ ਰੱਖਦੇ ਹਨ।

ਵਿਆਪਾਰਕ ਐਜ਼ੂਰ ਇਕੋਸਿਸਟਮ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਤੋਂ ਲੈ ਕੇ ਖਾਸ ਸੰਦਾਂ ਤੱਕ ਜਿਵੇਂ ਕਿ Playwright ਬ੍ਰਾਊਜ਼ਰ ਆਟੋਮੇਸ਼ਨ ਲਈ ਅਤੇ MarkItDown ਦਸਤਾਵੇਜ਼ ਪ੍ਰੋਸੈਸਿੰਗ ਲਈ, ਇਹ ਸਰਵਰ ਦਿਖਾਉਂਦੇ ਹਨ ਕਿ MCP ਕਿਵੇਂ ਵੱਖ-ਵੱਖ ਵਿਕਾਸ ਪ੍ਰਸੰਗਾਂ ਵਿੱਚ ਉਤਪਾਦਕਤਾ ਨੂੰ ਵਧਾ ਸਕਦਾ ਹੈ। ਸਟੈਂਡਰਡ ਪ੍ਰਾਟੋਕੋਲ ਇਹ ਯਕੀਨੀ ਬਣਾਉਂਦਾ ਹੈ ਕਿ ਇਹ ਸੰਦ ਇਕੱਠੇ ਬਿਨਾਂ ਰੁਕਾਵਟ ਦੇ ਕੰਮ ਕਰਦੇ ਹਨ, ਜਿਸ ਨਾਲ ਇੱਕ ਇੱਕਸਾਰ ਵਿਕਾਸ ਅਨੁਭਵ ਬਣਦਾ ਹੈ।

ਜਿਵੇਂ-जਿਵੇਂ MCP ਇਕੋਸਿਸਟਮ ਵਿਕਸਤ ਹੁੰਦਾ ਰਹੇਗਾ, ਸਮੁਦਾਇ ਨਾਲ ਜੁੜੇ ਰਹਿਣਾ, ਨਵੇਂ ਸਰਵਰਾਂ ਦੀ ਖੋਜ ਕਰਨਾ, ਅਤੇ ਵਿਸ਼ੇਸ਼ ਹੱਲ ਬਣਾਉਣਾ ਤੁਹਾਡੇ ਵਿਕਾਸ ਉਤਪਾਦਕਤਾ ਨੂੰ ਵੱਧ ਤੋਂ ਵੱਧ ਕਰਨ ਲਈ ਜਰੂਰੀ ਹੋਵੇਗਾ। MCP ਦਾ ਖੁਲ੍ਹਾ ਸਟੈਂਡਰਡ ਸੁਭਾਵ ਇਹ ਹੁੰਦਾ ਹੈ ਕਿ ਤੁਸੀਂ ਵੱਖ-ਵੱਖ ਵੈਂਡਰਾਂ ਦੇ ਸੰਦਾਂ ਨੂੰ ਮਿਲਾ ਕੇ ਆਪਣੇ ਖਾਸ ਲੋੜਾਂ ਲਈ ਪਰਫੈਕਟ ਵਰਕਫਲੋ ਬਣਾਉਂਦੇ ਹੋ।

## 🎯 ਅਭਿਆਸ

1. **ਇੰਸਟਾਲ ਅਤੇ ਸੰਰਚਿਤ ਕਰੋ**: ਆਪਣੇ VS ਕੋਡ ਵਾਤਾਵਰਨ ਵਿੱਚ ਕਿਸੇ ਇੱਕ MCP ਸਰਵਰ ਨੂੰ ਸੈਟਅੱਪ ਕਰੋ ਅਤੇ ਮੂਲ ਫੰਕਸ਼ਨਲਿਟੀ ਦੀ ਜਾਂਚ ਕਰੋ।
2. **ਵਰਕਫਲੋ ਇੰਟੀਗ੍ਰੇਸ਼ਨ**: ਇੱਕ ਵਿਕਾਸ ਵਰਕਫਲੋ ਡਿਜ਼ਾਈਨ ਕਰੋ ਜੋ ਘੱਟੋ-ਘੱਟ ਤਿੰਨ ਵੱਖਰੇ MCP ਸਰਵਰਾਂ ਨੂੰ ਜੋੜਦਾ ਹੋਵੇ।
3. **ਕਸਟਮ ਸਰਵਰ ਯੋਜਨਾ**: ਆਪਣੀ ਰੋਜ਼ਾਨਾ ਵਿਕਾਸ ਰੁਟੀਨ ਵਿੱਚ ਕੋਈ ਇੱਕ ਕਾਰਜ ਪਛਾਣੋ ਜੋ ਕਸਟਮ MCP ਸਰਵਰ ਨਾਲ ਲਾਭਕਾਰੀ ਹੋ ਸਕਦਾ ਹੈ ਅਤੇ ਉਸ ਲਈ ਇੱਕ ਵਿਸ਼ੇਸ਼ਤਾ ਬਣਾਓ।
4. **ਕਾਰਗੁਜ਼ਾਰੀ ਵਿਸ਼ਲੇਸ਼ਣ**: ਆਮ ਵਿਕਾਸ ਕਾਰਜਾਂ ਲਈ MCP ਸਰਵਰਾਂ ਦੀ ਵਰਤੋਂ ਅਤੇ ਪਰੰਪਰਾਵਾਦੀ ਤਰੀਕਿਆਂ ਦੀ ਕੁਸ਼ਲਤਾ ਦੀ ਤੁਲਨਾ ਕਰੋ।
5. **ਸੁਰੱਖਿਆ ਮੁਲਾਂਕਣ**: ਆਪਣੀ ਵਿਕਾਸ ਵਾਤਾਵਰਨ ਵਿੱਚ MCP ਸਰਵਰਾਂ ਦੀ ਵਰਤੋਂ ਦੇ ਸੁਰੱਖਿਆ ਪ੍ਰਭਾਵਾਂ ਦਾ ਮੁਲਾਂਕਣ ਕਰੋ ਅਤੇ ਸਭ ਤੋਂ ਵਧੀਆ ਅਭਿਆਸ ਸੁਝਾਓ।
