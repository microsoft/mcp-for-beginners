# MCP ਕਾਰਜ ਵਿਚ: ਅਸਲੀ ਦੁਨੀਆ ਦੇ ਕੇਸ ਅਧਿਐਨ

[![MCP ਕਾਰਜ ਵਿਚ: ਅਸਲੀ ਦੁਨੀਆਂ ਦੇ ਕੇਸ ਅਧਿਐਨ](../../../translated_images/pa/10.3262cc80b4de5071.webp)](https://youtu.be/IxshWb2Az5w)

_(ਇਸ ਪਾਠ ਦਾ ਵੀਡੀਓ ਵੇਖਣ ਲਈ ਉਪਰ ਦਿੱਤੀ ਤਸਵੀਰ 'ਤੇ ਕਲਿੱਕ ਕਰੋ)_

ਮਾਡਲ ਕੰਟੈਕਸਟ ਪ੍ਰੋਟੋਕਾਲ (MCP) ਇਹ ਬਦਲ ਰਿਹਾ ਹੈ ਕਿ ਕਿਵੇਂ ਏਆਈ ਐਪਲੀਕੇਸ਼ਨ ਡੇਟਾ, ਟੂਲਾਂ ਅਤੇ ਸੇਵਾਵਾਂ ਨਾਲ ਇੰਟਰਐਕਟ ਕਰਦੀਆਂ ਹਨ। ਇਹ ਭਾਗ ਅਸਲੀ ਦੁਨੀਆਂ ਦੇ ਕੇਸ ਅਧਿਐਨਾਂ ਨੂੰ ਪੇਸ਼ ਕਰਦਾ ਹੈ ਜੋ ਵੱਖ-ਵੱਖ ਉਦਯੋਗਿਕ ਸਥਿਤੀਆਂ ਵਿੱਚ MCP ਦੀਆਂ ਵਰਤੋਂ ਦੀਆਂ ਢੰਗਾਂ ਨੂੰ ਦਰਸਾਉਂਦੇ ਹਨ।

## ਓਵਰਵਿਊ

ਇਹ ਭਾਗ MCP ਦੇ ਲਾਗੂ ਕਰਨ ਦੇ ਧੁਰਾਂਤ ਉਦਾਹਰਣਾਂ ਨੂੰ ਦਰਸਾਉਂਦਾ ਹੈ, ਜੋ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਕਿਵੇਂ ਸੰਗਠਨ ਇਸ ਪ੍ਰੋਟੋਕਾਲ ਨੂੰ ਉੱਚ ਦਰਜੇ ਦੀਆਂ ਕਾਰੋਬਾਰੀ ਚੁਣੌਤੀਆਂ ਨੂੰ ਹੱਲ ਕਰਨ ਲਈ ਵਰਤ ਰਹੇ ਹਨ। ਇਹ ਕੇਸ ਅਧਿਐਨ ਵੇਖ ਕੇ, ਤੁਸੀਂ MCP ਦੀ ਬਹੁਰੂਪਤਾ, ਸਕੇਲਬਿਲਿਟੀ ਅਤੇ ਅਸਲ ਦੁਨੀਆਂ ਵਿੱਚ ਉਸਤਰੀ ਲਾਭਾਂ ਬਾਰੇ ਜਾਣਕਾਰੀਆਂ ਪ੍ਰਾਪਤ ਕਰੋਂਗੇ।

## ਮੁੱਖ ਸਿੱਖਣ ਦੇ ਉਦੇਸ਼

ਇਹ ਕੇਸ ਅਧਿਐਨਾਂ ਨੂੰ ਖੰਗਾਲ ਕੇ, ਤੁਸੀਂ:

- ਸਮਝੋਗੇ ਕਿ MCP ਕਿਸ ਤਰ੍ਹਾਂ ਵੱਖ-ਵੱਖ ਕਾਰੋਬਾਰੀ ਸਮੱਸਿਆਵਾਂ ਦਾ ਹੱਲ ਦੇਣ ਲਈ ਲਾਗੂ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ
- ਵੱਖ-ਵੱਖ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਪੈਟਰਨਾਂ ਅਤੇ ਆਰਕੀਟੈਕਚਰਲ ਦ੍ਰਿਸ਼ਟੀਕੋਣਾਂ ਬਾਰੇ ਸਿੱਖੋਗੇ
- ਉਦਯੋਗਿਕ ਵਾਤਾਵਰਨ ਵਿੱਚ MCP ਨੂੰ ਲਾਗੂ ਕਰਨ ਲਈ ਸਭ ਤੋਂ ਵਧੀਆ ਰੀਤੀਆਂ ਨੂੰ ਪਛਾਣੋਗੇ
- ਅਸਲ ਜੀਵਨ ਅਮਲਾਂ ਵਿੱਚ ਆਈਆਂ ਚੁਣੌਤੀਆਂ ਅਤੇ ਹੱਲ ਬਾਰੇ ਜਾਣੂ ਹੋਵੋਗੇ
- ਆਪਣੇ ਪ੍ਰੋਜੈਕਟਾਂ ਵਿੱਚ ਸਮਾਨ ਪੈਟਰਨਾਂ ਲਾਗੂ ਕਰਨ ਦੇ ਮੌਕੇ ਪਛਾਣੋਗੇ

## ਪ੍ਰਸ਼ੰਸਿਤ ਕੇਸ ਅਧਿਐਨ

### 1. [Azure AI ਟ੍ਰੈਵਲ ਏਜੰਟਸ – ਰੈਫਰੈਂਸ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ](./travelagentsample.md)

ਇਹ ਕੇਸ ਅਧਿਐਨ ਮਾਈਕ੍ਰੋਸੌਫਟ ਦੇ ਵਿਆਪਕ ਰੈਫਰੈਂਸ ਹੱਲ ਨੂੰ ਪਰਖਦਾ ਹੈ ਜੋ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ MCP, Azure OpenAI ਅਤੇ Azure AI Search ਦੀ ਵਰਤੋਂ ਨਾਲ ਕਿਵੇਂ ਇੱਕ ਮਲਟੀ-ਏਜੰਟ, ਏਆਈ-ਚਲਿਤ ਟ੍ਰੈਵਲ ਪਲਾਨਿੰਗ ਐਪਲੀਕੇਸ਼ਨ ਬਣਾਈ ਜਾ ਸਕਦੀ ਹੈ। ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਦਰਸਾਇਆ ਗਿਆ ਹੈ:

- MCP ਰਾਹੀਂ ਮਲਟੀ-ਏਜੰਟ ਅੋਰਕੈਸਟ੍ਰੇਸ਼ਨ
- ਏਜੰਸੀ ਡੇਟਾ ਸੰਮਿਲਨ Azure AI Search ਨਾਲ
- ਸੁਰੱਖਿਅਤ, ਸਕੇਲਬਲ ਆਰਕੀਟੈਕਚਰ Azure ਸੇਵਾਵਾਂ ਦੇ ਨਾਲ
- ਕਈ ਵਾਰੀ ਵਰਤੋਂਯੋਗ MCP ਘਟਕ ਨਾਲ ਵਿਸਥਾਰਯੋਗ ਟੂਲਿੰਗ
- Azure OpenAI ਦੁਆਰਾ ਚਲਾਈ ਜਾਂਦੇ ਗੱਲਬਾਤੀ ਉਪਭੋਗਤਾ ਅਨੁਭਵ

ਆਰਕੀਟੈਕਚਰ ਅਤੇ ਲਾਗੂ ਕਰਨਾ ਦੇ ਵੇਰਵੇ MCP ਦੀ ਸੰਯੋਜਨਾ ਲੇਅਰ ਵਜੋਂ ਮਲਟੀ-ਏਜੰਟ ਪ੍ਰਣਾਲੀਆਂ ਬਣਾਉਣ ਵਿੱਚ ਕੀਮਤੀ ਜਾਣਕਾਰੀਆਂ ਦਿੰਦੇ ਹਨ।

### 2. [ਯੂਟਿਊਬ ਡੇਟਾ ਤੋਂ Azure DevOps ਆਇਟਮ ਅੱਪਡੇਟ ਕਰਨਾ](./UpdateADOItemsFromYT.md)

ਇਹ ਕੇਸ ਅਧਿਐਨ MCP ਦੀ ਵਰਤੋਂ ਇੱਕ ਵਰਕਫਲੋਅ ਪ੍ਰਕਿਰਿਆ ਆਟੋਮੈਸ਼ਨ ਲਈ ਦਿਖਾਉਂਦਾ ਹੈ। ਇਹ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ MCP ਟੂਲਜ਼ ਕਿਵੇਂ ਵਰਤੇ ਜਾ ਸਕਦੇ ਹਨ:

- ਔਨਲਾਈਨ ਪਲੇਟਫਾਰਮਾਂ (ਯੂਟਿਊਬ) ਤੋਂ ਡੇਟਾ ਐਕਸਟ੍ਰੈਕਟ ਕਰਨਾ
- Azure DevOps ਸਿਸਟਮਾਂ ਵਿੱਚ ਵਰਕ ਆਇਟਮ ਅੱਪਡੇਟ ਕਰਨਾ
- ਦੁਹਰਾਏ ਜਾ ਸਕਣ ਵਾਲੇ ਆਟੋਮੇਟਿਕ ਵਰਕਫਲੋਅ ਬਣਾਉਣਾ
- ਵੱਖ-ਵੱਖ ਸਿਸਟਮਾਂ ਵਿੱਚ ਡੇਟਾ ਇੰਟੀਗ੍ਰੇਟ ਕਰਨਾ

ਇਹ ਉਦਾਹਰਣ ਦਿਖਾਉਂਦੀ ਹੈ ਕਿ ਸਧਾਰਣ MCP ਲਾਗੂ ਕਰਨਾ ਵੀ ਰੁਟੀਨ ਕਾਰਜਾਂ ਨੂੰ ਆਟੋਮੈਟ ਕਰਨ ਅਤੇ ਸਿਸਟਮਾਂ ਵਿੱਚ ਡੇਟਾ ਅਨੁਕੂਲਤਾ ਸੁਧਾਰਨ ਨਾਲ ਕਿੰਨੀ ਪ੍ਰਭਾਵਸ਼ਾਲੀ ਹੋ ਸਕਦੀ ਹੈ।

### 3. [MCP ਨਾਲ ਰੀਅਲ-ਟਾਈਮ ਡੌਕੂਮੈਂਟੇਸ਼ਨ ਪ੍ਰਾਪਤੀ](./docs-mcp/README.md)

ਇਹ ਕੇਸ ਅਧਿਐਨ ਤੁਹਾਨੂੰ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿਵੇਂ ਇੱਕ Python ਕਨਸੋਲ ਕਲਾਇੰਟ ਨੂੰ ਮਾਡਲ ਕੰਟੈਕਸਟ ਪ੍ਰੋਟੋਕਾਲ (MCP) ਸਰਵਰ ਨਾਲ ਜੋੜ ਕੇ Microsoft ਦੀ ਰੀਅਲ-ਟਾਈਮ, ਸੰਦਰਭ-ਸਮਝਦਾਰ ਡੌਕੂਮੈਂਟੇਸ਼ਨ ਪ੍ਰਾਪਤ ਕੀਤੀ ਜਾ ਸਕਦੀ ਹੈ ਅਤੇ ਲਾਗ ਕੀਤੀ ਜਾ ਸਕਦੀ ਹੈ। ਤੁਸੀਂ ਸਿੱਖੋਗੇ ਕਿ:

- ਅਧਿਕਾਰਤ MCP SDK ਨਾਲ Python ਕਲਾਇੰਟ ਰਾਹੀਂ MCP ਸਰਵਰ ਨਾਲ ਜੁੜਨਾ
- ਪ੍ਰਭਾਵਸ਼ਾਲੀ, ਰੀਅਲ-ਟਾਈਮ ਡੇਟਾ ਪ੍ਰਾਪਤੀ ਲਈ ਸਟ੍ਰੀਮਿੰਗ HTTP ਕਲਾਇੰਟਾਂ ਦੀ ਵਰਤੋਂ
- ਸਰਵਰ 'ਤੇ ਡੌਕੂਮੈਂਟੇਸ਼ਨ ਟੂਲਜ਼ ਨੂੰ ਕਾਲ ਕਰਨਾ ਅਤੇ ਜਵਾਬ ਸਿੱਧਾ ਕਨਸੋਲ ਤੇ ਲਾਗ ਕਰਨਾ
- ਟਰਮੀਨਲ ਛੱਡੇ ਬਿਨਾਂ ਆਪਣੇ ਵਰਕਫਲੋਅ ਵਿੱਚ ਤਾਜ਼ਾ Microsoft ਡੌਕੂਮੈਂਟੇਸ਼ਨ ਸ਼ਾਮਲ ਕਰਨਾ

ਇਸ ਅਧਿਆਇ ਵਿੱਚ ਇੱਕ ਹੱਥ-ਅਧਿਐਨ ਅਸਾਈਨਮੈਂਟ, ਇੱਕ ਘੱਟੋ-ਘੱਟ ਕਾਰਜਸ਼ੀਲ ਕੋਡ ਸੈਂਪਲ, ਅਤੇ ਗਹਿਰੇ ਸਿੱਖਣ ਲਈ ਵਾਧੂ ਸਰੋਤਾਂ ਦੇ ਲਿੰਕ ਸ਼ਾਮਲ ਹਨ। ਪੂਰੀ ਯਾਤਰਾ ਅਤੇ ਕੋਡ ਜਾਨਣ ਲਈ ਜੁੜੇ ਅਧਿਆਇ ਨੂੰ ਵੇਖੋ ਕਿ ਕਿਵੇਂ MCP ਡੌਕੂਮੈਂਟੇਸ਼ਨ ਪ੍ਰਾਪਤੀ ਅਤੇ ਡਿਵੈਲਪਰ ਉਤਪਾਦਕਤਾ ਵਿੱਚ ਕਨਸੋਲ-ਆਧਾਰਿਤ ਵਾਤਾਵਰਣਾਂ ਵਿੱਚ ਬਦਲਾਅ ਕਰ ਸਕਦਾ ਹੈ।

### 4. [MCP ਨਾਲ ਇੰਟਰੈਕਟਿਵ ਅਧਿਐਨ ਯੋਜਨਾ ਜਨਰੇਟਰ ਵੈੱਬ ਐਪ](./docs-mcp/README.md)

ਇਹ ਕੇਸ ਅਧਿਐਨ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ Chainlit ਅਤੇ ਮਾਡਲ ਕੰਟੈਕਸਟ ਪ੍ਰੋਟੋਕਾਲ (MCP) ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਕਿਸ ਤਰ੍ਹਾਂ ਕਿਸੇ ਵੀ ਵਿਸ਼ੇ ਲਈ ਨਿੱਜੀਕ੍ਰਿਤ ਅਧਿਐਨ ਯੋਜਨਾਵਾਂ ਬਣਾਉਣ ਲਈ ਇੱਕ ਇੰਟਰੈਕਟਿਵ ਵੈੱਬ ਐਪ ਬਣਾਈ ਜਾਂਦੀ ਹੈ। ਉਪਭੋਗਤਾ ਇਕ ਵਿਸ਼ਾ (ਜਿਵੇਂ "AI-900 ਸਰਟੀਫਿਕੇਸ਼ਨ") ਅਤੇ ਅਧਿਐਨ ਅਵਧੀ (ਜਿਵੇਂ 8 ਹਫ਼ਤੇ) ਦਰਜ ਕਰ ਸਕਦੇ ਹਨ, ਅਤੇ ਐਪ ਹਰ ਹਫ਼ਤੇ ਲਈ ਪ੍ਰਸਤਾਵਿਤ ਸਮੱਗਰੀ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ ਦਿੰਦੀ ਹੈ। Chainlit ਗੱਲਬਾਤੀ ਚੈਟ ਇੰਟਰਫੇਸ ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਅਨੁਭਵ ਮਨੋਰੰਜਕ ਅਤੇ ਅਨੁਕੂਲ ਬਣਦਾ ਹੈ।

- Chainlit ਦੁਆਰਾ ਚਲਾਈ ਜਾਣ ਵਾਲੀ ਗੱਲਬਾਤੀ ਵੈੱਬ ਐਪ
- ਵਿਸ਼ਾ ਅਤੇ ਅਵਧੀ ਲਈ ਉਪਭੋਗਤਾ-ਨਿਰਦੇਸ਼ਿਤ ਪ੍ਰਾਂਪਟ
- MCP ਰਾਹੀਂ ਹਫ਼ਤਾਵਾਰੀ ਸਮੱਗਰੀ ਦੀ ਸਿਫਾਰਸ਼
- ਚੈਟ ਇੰਟਰਫੇਸ ਵਿੱਚ ਰੀਅਲ-ਟਾਈਮ, ਅਨੁਕੂਲ ਜਵਾਬ

ਪ੍ਰੋਜੈਕਟ ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ ਕਿਵੇਂ ਗੱਲਬਾਤੀ ਏਆਈ ਅਤੇ MCP ਨੂੰ ਮਿਲਾ ਕੇ ਇੱਕ ਆਧੁਨਿਕ ਵੈੱਬ ਵਾਤਾਵਰਣ ਵਿੱਚ ਗਤੀਸ਼ੀਲ, ਉਪਭੋਗਤਾਵਾਂ ਦੁਆਰਾ ਨਿਰਦੇਸ਼ਿਤ ਵਿਚਾਰਸ਼ੀਲ ਸਿੱਖਿਆ ਟੂਲ ਬਨਾਏ ਜਾ ਸਕਦੇ ਹਨ।

### 5. [VS ਕੋਡ ਵਿੱਚ MCP ਸਰਵਰ ਨਾਲ ਇੰ-ਐਡੀਟਰ ਡੌਕਸ](./docs-mcp/README.md)

ਇਹ ਕੇਸ ਅਧਿਐਨ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਤੁਸੀਂ MCP ਸਰਵਰ ਦੀ ਵਰਤੋਂ ਕਰਕੇ ਮਾਈਕ੍ਰੋਸੌਫਟ ਲਰਨ ਡੌਕਸ ਸਿੱਧਾ ਆਪਣੇ VS ਕੋਡ ਵਾਤਾਵਰਣ ਵਿੱਚ ਕਿਵੇਂ ਲਿਆ ਸਕਦੇ ਹੋ—ਹੁਣ ਬ੍ਰਾਊਜ਼ਰ ਟੈਬ ਸਵੀਚ ਕਰਨ ਦੀ ਲੋੜ ਨਹੀਂ! ਤੁਸੀਂ ਦੇਖੋਗੇ ਕਿ:

- MCP ਪੈਨਲ ਜਾਂ ਕਮਾਂਡ ਪੈਲੇਟ ਦੀ ਵਰਤੋਂ ਕਰਕੇ VS ਕੋਡ ਵਿੱਚ ਤੁਰੰਤ ਡਾਕੂਮੈਂਟ ਖੋਜ ਅਤੇ ਪੜ੍ਹਨਾ
- ਆਪਣੇ README ਜਾਂ ਕੋਰਸ ਮਾਰਕਡਾਊਨ ਫਾਇਲਾਂ ਵਿੱਚ ਸਿੱਧੇ ਡੌਕਸ ਰਿਫਰੈਂਸ ਅਤੇ ਲਿੰਕ ਸ਼ਾਮਲ ਕਰਨਾ
- GitHub Copilot ਅਤੇ MCP ਨੂੰ ਮਿਲਾ ਕੇ ਬਿਨਾ ਰੁਕਾਵਟ ਵਾਲੇ, ਏਆਈ-ਚਲਿਤ ਡੌਕਯੂਮੈਂਟ ਅਤੇ ਕੋਡ ਵਰਕਫਲੋਅਜ਼ ਦਾ ਉਪਯੋਗ
- ਰੀਅਲ-ਟਾਈਮ ਫੀਡਬੈਕ ਅਤੇ Microsoft-ਸੰਬੰਧਿਤ ਸ਼ੁੱਧਤਾ ਨਾਲ ਆਪਣੀ ਡੌਕਸ ਨੂੰ ਮਾਨਤਾ ਦੇਣਾ ਅਤੇ ਸੁਧਾਰਨਾ
- ਕਾਂਟੀਨੂੰਅਸ ਡੌਕਸ ਵੈਲੀਡੇਸ਼ਨ ਲਈ MCP ਦਾ GitHub ਵਰਕਫਲੋਜ਼ ਨਾਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ

ਇਸ ਲਾਗੂ ਕਰਨ ਵਿੱਚ ਸ਼ਾਮਲ ਹੈ:

- ਅਸਾਨ ਸੈੱਟਅੱਪ ਲਈ ਉਦਾਹਰਣ `.vscode/mcp.json` ਕਾਨਫਿਗਰੇਸ਼ਨ
- ਇੰ-ਐਡੀਟਰ ਅਨੁਭਵ ਦੇ ਸਕ੍ਰੀਨਸ਼ਾਟ-ਅਧਾਰਿਤ ਵਾਕ-ਥਰੂ
- ਜ਼ਿਆਦਾ ਉਤਪਾਦਕਤਾ ਲਈ Copilot ਅਤੇ MCP ਦੇ ਮਿਲਾਪ ਲਈ ਸੁਝਾਅ

ਇਹ ਦ੍ਰਿਸ਼ ਮਨਾਉਂਦੇ ਹਨ ਕਿ ਕੋਰਸ ਲੇਖਕਾਂ, ਡੌਕੂਮੈਂਟ ਲੇਖਕਾਂ, ਅਤੇ ਡਿਵੈਲਪਰਾਂ ਲਈ ਜੋ ਆਪਣੇ ਐਡੀਟਰ ਵਿੱਚ ਟਕੀ ਰਹਿਣਾ ਚਾਹੁੰਦੇ ਹਨ ਜਦੋਂ ਕਿ ਡੌਕਸ, Copilot, ਅਤੇ ਵੈਲੀਡੇਸ਼ਨ ਟੂਲਜ਼ ਨਾਲ ਕੰਮ ਕਰ ਰਹੇ ਹਨ—ਸਭ MCP ਦੇ ਦੂਆਰਾ ਚਲਾਏ ਜਾਂਦੇ ਹਨ।

### 6. [APIM MCP ਸਰਵਰ ਬਣਾਉਣਾ](./apimsample.md)

ਇਹ ਕੇਸ ਅਧਿਐਨ ਦੱਸਦਾ ਹੈ ਕਿ ਕਿਵੇਂ Azure API Management (APIM) ਦਾ ਉਪਯੋਗ ਕਰਕੇ MCP ਸਰਵਰ ਬਣਾਇਆ ਜਾ ਸਕਦਾ ਹੈ। ਇਸ ਵਿੱਚ ਸ਼ਾਮਲ ਹੈ:

- Azure API Management ਵਿੱਚ MCP ਸਰਵਰ ਦੀ ਸੈੱਟਅੱਪ
- MCP ਟੂਲਜ਼ ਵਜੋਂ API ਆਪਰੇਸ਼ਨਾਂ ਨੂੰ ਪ੍ਰਗਟ ਕਰਨਾ
- ਰੇਟ ਲਿਮਿਟਿੰਗ ਅਤੇ ਸੁਰੱਖਿਆ ਲਈ ਪਾਲਿਸੀਆਂ ਕਾਨਫਿਗਰ ਕਰਨਾ
- Visual Studio Code ਅਤੇ GitHub Copilot ਦੀ ਵਰਤੋਂ ਕਰਕੇ MCP ਸਰਵਰ ਦੀ ਪੜਤਾਲ

ਇਹ ਉਦਾਹਰਣ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ Azure ਦੀਆਂ ਸਮਰੱਥਾਵਾਂ ਨੂੰ ਕਿਵੇਂ ਵਰਤ ਕੇ ਇੱਕ ਮਜ਼ਬੂਤ MCP ਸਰਵਰ ਬਣਾਇਆ ਜਾ ਸਕਦਾ ਹੈ ਜੋ ਵੱਖ-ਵੱਖ ਐਪਲੀਕੇਸ਼ਨਾਂ ਵਿੱਚ ਵਰਤਿਆ ਜਾ ਸਕਦਾ ਹੈ, ਜਿਸ ਨਾਲ ਏਆਈ ਸਿਸਟਮਾਂ ਦਾ ਉਦਯੋਗੀ APIs ਨਾਲ ਸਰਲ ਸੰਯੋਜਨ ਹੁੰਦਾ ਹੈ।

### 7. [GitHub MCP ਰਜਿਸਟਰੀ — ਏਜੈਂਟਿਕ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਨੂੰ ਤੇਜ਼ ਕਰਨਾ](https://github.com/mcp)

ਇਹ ਕੇਸ ਅਧਿਐਨ ਦਿਖਾਉਂਦਾ ਹੈ ਕਿ ਕਿਵੇਂ GitHub ਦੀ MCP ਰਜਿਸਟਰੀ, ਜੋ ਸਤੰਬਰ 2025 ਵਿੱਚ ਸ਼ੁਰੂ ਕੀਤੀ ਗਈ, ਏਆਈ ਸਿਸਟਮ ਵਿੱਚ ਇੱਕ ਅਹੰਕਾਰਪੂਰਨ ਸਮੱਸਿਆ ਦਾ ਹੱਲ ਕੱਢਦੀ ਹੈ: ਮਾਡਲ ਕੰਟੈਕਸਟ ਪ੍ਰੋਟੋਕਾਲ (MCP) ਸਰਵਰਾਂ ਦੀ ਟੁੱਟੀ ਫੁੱਟੀ ਖੋਜ ਅਤੇ ਤਾਇਨਾਤੀ।

#### ਓਵਰਵਿਊ
**MCP ਰਜਿਸਟਰੀ** ਅਸਮਾਨਤ MCP ਸਰਵਰਾਂ ਦੀ ਵਧਦੀ ਸਮੱਸਿਆ ਨੂੰ ਹੱਲ ਕਰਦੀ ਹੈ, ਜੋ ਪਹਿਲਾਂ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਨੂੰ ਧੀਮਾ ਅਤੇ ਗਲਤੀਆਂ ਵਾਲਾ ਬਣਾ ਦਿੰਦੇ ਸਨ। ਇਹ ਸਰਵਰ ਏਆਈ ਏਜੰਟਾਂ ਨੂੰ ਬਾਹਰੀ ਸਿਸਟਮਾਂ ਜਿਵੇਂ API, ਡਾਟਾਬੇਸ, ਅਤੇ ਡੌਕਸ ਸਰੋਤਾਂ ਨਾਲ ਸੰਚਾਰ ਕਰਨ ਯੋਗ ਬਣਾਉਂਦੇ ਹਨ।

#### ਸਮੱਸਿਆ ਦਾ ਬਿਆਨ
ਏਜੈਂਟਿਕ ਵਰਕਫਲੋਅ ਬਨਾਣ ਵਾਲੇ ਡਿਵੈਲਪਰਾਂ ਨੇ ਕਈ ਮੁਸ਼ਕਿਲਾਂ ਦਾ ਸਾਹਮਣਾ ਕੀਤਾ:
- ਵਿੱਖਰੇ ਪਲੇਟਫਾਰਮਾਂ `ਤੇ MCP ਸਰਵਰਾਂ ਦੀ ਖੋਜ ਕਰਨਾ ਮੁਸ਼ਕਿਲ
- ਫੋਰਮਾਂ ਅਤੇ ਡੌਕਸ ਵਿੱਚ ਵੱਧ ਚੁੱਕੀ ਸੈੱਟਅੱਪ ਸਵਾਲ
- ਅਣਪ੍ਰਮਾਣਿਤ ਅਤੇ ਅਣਵਿਸ਼ਵਾਸਯੋਗ ਸਰੋਤਾਂ ਤੋਂ ਸੁਰੱਖਿਆ ਖ਼ਤਰੇ
- ਸਰਵਰ ਦੀ ਗੁਣਵੱਤਾ ਅਤੇ ਅਨੁਕੂਲਤਾ ਵਿੱਚ ਮਿਆਰੀਕਰਨ ਦੀ ਘਾਟ

#### ਸਮਾਧਾਨ ਦੇ ਆਰਕੀਟੈਕਚਰ
GitHub ਦੀ MCP ਰਜਿਸਟਰੀ ਭਰੋਸੇਯੋਗ MCP ਸਰਵਰਾਂ ਨੂੰ ਕੇਂਦਰੀਕ੍ਰਿਤ ਕਰਦੀ ਹੈ ਜਿਸ ਵਿੱਚ ਮੁੱਖ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਹਨ:
- ਏਕ ਕਲਿੱਕ ਇੰਸਟਾਲ - VS ਕੋਡ ਰਾਹੀਂ ਸਰਲ ਸੈੱਟਅੱਪ ਲਈ ਇੰਟੀਗ੍ਰੇਸ਼ਨ
- ਸਿਗਨਲ ਓਵਰ ਨੌਇਜ਼ ਸੋਰਟਿੰਗ - ਤਾਰਿਆਂ, ਸਰਗਰਮੀ ਅਤੇ ਕਮਿਊਨਿਟੀ ਵੈਰੀਫਿਕੇਸ਼ਨ ਨਾਲ
- ਡਾਇਰੇਕਟ ਇੰਟੀਗ੍ਰੇਸ਼ਨ GitHub Copilot ਅਤੇ ਹੋਰ MCP-ਸੰਗਤ ਟੂਲਜ਼ ਨਾਲ
- ਖੁੱਲ੍ਹਾ ਯੋਗਦਾਨ ਮਾਡਲ - ਕਮਿਊਨਿਟੀ ਅਤੇ ਉਦਯੋਗਿਕ ਭਾਗੀਦਾਰਾਂ ਦੋਹਾਂ ਨੂੰ ਯੋਗਦਾਨ ਦੇਣ ਲਈ ਯੋਗ

#### ਵਪਾਰਕ ਪ੍ਰਭਾਵ
ਰਜਿਸਟਰੀ ਨੇ ਮਾਪਯੋਗ ਸੁਧਾਰ ਦਿੱਤੇ ਹਨ:
- ਡਿਵੈਲਪਰਾਂ ਲਈ ਤੇਜ਼ onboarding ਜਿਵੇਂ Microsoft Learn MCP ਸਰਵਰ, ਜੋ ਅਧਿਕਾਰਤ ਡੌਕਸ ਨੂੰ ਸਿੱਧਾ ਏਜੰਟਾਂ ਵਿੱਚ ਸਟ੍ਰੀਮ ਕਰਦਾ ਹੈ
- ਵਿਸ਼ੇਸ਼ ਸਰਵਰਾਂ ਜਿਵੇਂ `github-mcp-server` ਰਾਹੀਂ ਵਧੀਆ ਉਤਪਾਦਕਤਾ, ਕੁਦਰਤੀ ਭਾਸ਼ਾ GitHub ਆਟੋਮੇਸ਼ਨ (PR ਬਣਾਉਣਾ, CI ਰੀਰੰਸ, ਕੋਡ ਸਕੈਨਿੰਗ)
- ਵਧੀਆ ਇਕੋਸਿਸਟਮ ਭਰੋਸਾ curated ਸੂਚੀਆਂ ਅਤੇ ਪਾਰਦਰਸ਼ੀ ਕਾਨਫਿਗ੍ਰੇਸ਼ਨ ਮਿਆਰੀਕਰਨ ਰਾਹੀਂ

#### ਰਣਨੀਤਿਕ ਮੁੱਲ
ਏਜੈਂਟ ਲਾਈਫਸਾਈਕਲ ਮੈਨੇਜਮੈਂਟ ਅਤੇ ਦੁਹਰਾਏ ਜਾ ਸਕਣ ਵਾਲੇ ਵਰਕਫਲੋਅ ਵਿਸ਼ੇਸ਼ਜਨਾਂ ਲਈ MCP ਰਜਿਸਟਰੀ ਮੁਹੱਈਆ ਕਰਦੀ ਹੈ:
- ਮੋਡੀਯੂਲਰ ਏਜੈਂਟ ਡੀਪਲੋਇਮੈਂਟ ਯੋਗਤਾਵਾਂ ਮਿਆਰੀਤ ਘਟਕਾਂ ਨਾਲ
- ਰਜਿਸਟਰੀ-ਆਧਾਰਿਤ ਮੁੱਲਾਂਕਣ ਪਾਈਪਲਾਈਨਾਂ ਲਗਾਤਾਰ ਟੈਸਟਿੰਗ ਅਤੇ ਵੈਰੀਫਿਕੇਸ਼ਨ ਲਈ
- ਕ੍ਰਾਸ-ਟੂਲ ਇੰਟਰਓਪਰੇਬਿਲਿਟੀ ਵੱਖ-ਵੱਖ ਏਆਈ ਪਲੇਟਫਾਰਮਾਂ ਵਿੱਚ ਬਿਨਾ ਰੁਕਾਵਟ ਦੇ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਲਈ

ਇਹ ਕੇਸ ਅਧਿਐਨ ਦਰਸਾਉਂਦਾ ਹੈ ਕਿ MCP ਰਜਿਸਟਰੀ ਸਿਰਫ਼ ਇੱਕ ਡਾਇਰੈਕਟਰੀ ਨਹੀਂ ਬਲਕਿ ਇੱਕ ਮੂਲ ਧਾਰਾ ਹੈ ਸਕੇਲਬਲ ਅਸਲ ਦੁਨੀਆ ਮਾਡਲ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਅਤੇ ਏਜੈਂਟਿਕ ਸਿਸਟਮ ਡੀਪਲੋਇਮੈਂਟ ਲਈ।

### 8. [ਏਜੰਟ ਤੋਂ ਸੋਸ਼ਲ ਨੈੱਟਵਰਕਾਂ 'ਤੇ ਪ੍ਰਕਾਸ਼ਨ](./publora-social-publishing.md)

ਇਹ ਕੇਸ ਅਧਿਐਨ ਇੱਕ **ਲਿਖਣ ਯੋਗ ਰਿਮੋਟ MCP ਸਰਵਰ** ਰਾਹੀਂ ਗੁਜ਼ਰਦਾ ਹੈ — ਜਿਸਦੇ ਟੂਲ ਉਪਭੋਗਤਾ ਵੱਲੋਂ ਪਰਮਾਣਿਤ ਨਹੀਂ ਕੀਤੇ ਗਏ ਕਾਰਜ ਕਰਦੇ ਹਨ — ਜਿਸਦੇ ਉਦਾਹਰਣ ਵਜੋਂ ਸੋਸ਼ਲ ਪ੍ਰਕਾਸ਼ਨ ਲਿਆ ਗਿਆ ਹੈ। ਇੱਕ ਏਜੰਟ ਪੋਸਟ ਤਿਆਰ ਕਰਦਾ ਹੈ, ਇੱਕ ਮਨੁੱਖ ਉਸਨੂੰ ਮਨਜ਼ੂਰ ਕਰਦਾ ਹੈ, ਅਤੇ ਸਰਵਰ ਉਹਨੂੰ ਨੈੱਟਵਰਕਾਂ 'ਤੇ ਸ਼ਡਿਊਲ ਕਰਦਾ ਹੈ।

ਦਿਲਚਸਪ ਹਿੱਸਾ ਹੈ ਪ੍ਰਕਾਸ਼ਨ ਵੱਲੋਂ ਲਾਏ ਗਏ ਡਿਜ਼ਾਈਨ ਸੀਮਾਵਾਂ, ਜੋ ਕਿਸੇ ਵੀ ਸਰਵਰ ਉੱਤੇ ਲਾਗੂ ਹੁੰਦੀਆਂ ਹਨ ਜੋ ਪੜ੍ਹਦਾ ਨਹੀਂ ਪਲਿਟਾ ਲਿਖਦਾ ਹੈ:

- **ਖੁੱਲ੍ਹੀ ਖੋਜ, ਪ੍ਰਮਾਣਿਤ ਕਾਰਜ** — `tools/list` ਕ੍ਰੈਡੈਂਸ਼ਲ ਬਿਨਾਂ ਜਵਾਬ ਦੇਂਦਾ ਹੈ ਤਾਂ ਜੋ ਰਜਿਸਟਰੀ ਅਤੇ ਕਲਾਇੰਟ ਅੰਦਰੂਨੀ ਜਾਣਕਾਰੀ ਪ੍ਰਾਪਤ ਕਰ ਸਕਣ, ਪਰ ਹਰ `tools/call` ਲਈ ਟੋਕਨ ਲੋੜੀਂਦਾ ਹੈ ਅਤੇ ਕਿਸੇ ਹੋਰ ਸਥਿਤੀ ਵਿੱਚ `401` ਅਤੇ `WWW-Authenticate` ਹੇਡਰ ਚੜ੍ਹਦਾ ਹੈ
- **ਬਾਹਰਲੇ ਕਦਮ ਬਿਨਾਂ OAuth ਰਜਿਸਟਰੇਸ਼ਨ** — ਅੱਜ ਦਾ ਡਾਇਨੈਮਿਕ ਕਲਾਇੰਟ ਰਜਿਸਟਰੇਸ਼ਨ-ਸਪੈਸੀਫਿਕੇਸ਼ਨ `2026-07-28` ਵੱਲ ਇਸ਼ਾਰਾ ਕਰਦਾ ਹੈ Client ID ਮੈਟਾਡੇਟਾ ਡੌਕਯੂਮੈਂਟ
- **ਟੂਲ ਫ਼ੁਰਮਾਨੇ** (`readOnlyHint`, `destructiveHint`, `idempotentHint`) ਜੋ ਕਲਾਇੰਟ ਇਸ ਫੈਸਲੇ ਲਈ ਵਰਤਦੇ ਹਨ ਕਿ ਕੀ ਪੁਸ਼ਟੀ ਕਰਨੀ ਹੈ — ਕਾਨੂੰਨੀ ਲਾਗੂ ਕਰਨ ਦੀ ਬਜਾਏ ਇਸ਼ਾਰਿਆਂ ਵਜੋਂ, ਅਤੇ ਕੁਝ ਜੋ ਹੁਣ ਕਨੈਕਟਰ ਡਾਇਰੈਕਟਰੀਜ਼ ਰਿਵਿਊ ਤੇ ਉਮੀਦ ਕਰਦੀਆਂ ਹਨ
- **ਅਣਜਾਣ ਪਛਾਣ** , ਤਾਂ ਜੋ ਕੋਈ ਹੈਲੂਸੀਨੇਟ ਕੀਤੀ ਗਈ ਕੀਮਤ ਸ਼ੋਰ ਮਚਾਉਂਦੀ ਹੈ ਨਾ ਕਿ ਵਿਸ਼ਵਾਸਯੋਗ ਦਿਸ਼ਤੀ ਜਾਂਦੇ ਮੁੱਲ ਤੇ ਕਮ ਮੈਂਦਾ ਕਾਰਵਾਈ ਕਰਦੀ ਹੈ
- **ਪੋਸਟ ਬਣਾਉਣ ਵਾਲੇ ਟੂਲਾਂ 'ਤੇ ਆਇਡੈਮਪੋਟੈਂਸੀ ਕੀਜ਼**, ਤਾਂ ਜੋ ਏਜੰਟ ਰੰਟਾਈਮ ਦਾ ਦੁਹਰਾਵਾ ਡੁਪਲੀਕੇਟ ਪ੍ਰਕਾਸ਼ਨ ਨਾ ਬਣੇ
- **ਟੂਲ ਸਕੀਮਾ ਵਿੱਚ ਇਕ ਨੋ-ਓਪ ਟਾਰਗੇਟ** ਜੋ ਪੂਰੀ ਲਿਖਾਈ ਪ੍ਰਕਿਰਿਆ ਦਾ ਅਭਿਆਸ ਕਰਦਾ ਹੈ ਅਤੇ ਕਿਛੇ ਨਹੀਂ ਪ੍ਰਕਾਸ਼ਿਤ ਕਰਦਾ, ਜਾਂਚਕਾਰਾਂ ਅਤੇ CI ਲਈ

ਅਧਿਆਇ ਇੱਕ ਛੋਟੀ ਜਾਂਚ ਸੂਚੀ ਨਾਲ ਖ਼ਤਮ ਹੁੰਦਾ ਹੈ ਜੋ ਤੁਸੀਂ ਆਪਣੇ ਬਣਾ ਰਹੇ ਸਰਵਰ ਉੱਤੇ ਲਾਗੂ ਕਰ ਸਕਦੇ ਹੋ।

## ਨਿਸ਼ਕਰਸ਼

ਇਹ ਐਠ ਕੰਪ੍ਰਿਹੈਂਸਿਵ ਕੇਸ ਅਧਿਐਨ ਮਾਡਲ ਕੰਟੈਕਸਟ ਪ੍ਰੋਟੋਕਾਲ ਦੀ ਅਦਭੁਤ ਬਹੁਪੱਖੀਤਾ ਅਤੇ ਅਸਲ ਦੁਨੀਆ ਦੀਆਂ ਵੱਖ-ਵੱਖ ਸਥਿਤੀਆਂ ਵਿੱਚ ਉਸਤਰੀ ਵਰਤੋਂ ਦਿਖਾਉਂਦੇ ਹਨ। ਜਟਿਲ ਮਲਟੀ-ਏਜੰਟ ਟ੍ਰੈਵਲ ਪਲਾਨਿੰਗ ਪ੍ਰਣਾਲੀਆਂ ਅਤੇ ਉਦਯੋਗੀ API ਪ੍ਰਬੰਧਨ ਤੋਂ ਲੈ ਕੇ ਸਧਾਰਣ ਡੌਕਮੈਂਟੇਸ਼ਨ ਵਰਕਫਲੋਅਜ਼ ਅਤੇ ਕ੍ਰਾਂਤੀਕਾਰੀ GitHub MCP ਰਜਿਸਟਰੀ ਤਕ, ਇਹ ਉਦਾਹਰਣ ਦੱਸਦੇ ਹਨ ਕਿ MCP ਕਿਵੇਂ ਇੱਕ ਮਿਆਰੀਕ੍ਰਿਤ, ਸਕੇਲਬਲ ਤਰੀਕਾ ਮੁਹੱਈਆ ਕਰਦਾ ਹੈ ਜੋ ਏਆਈ ਪ੍ਰਣਾਲੀਆਂ ਨੂੰ ਉਹਨਾਂ ਦੇ ਜਰੂਰੀ ਟੂਲਾਂ, ਡੇਟਾ, ਅਤੇ ਸੇਵਾਵਾਂ ਨਾਲ ਜੋੜਦਾ ਹੈ ਜੋ ਸ਼ਾਨਦਾਰ ਮੁੱਲ ਪੈਦਾ ਕਰਦੇ ਹਨ।

ਕੇਸ ਅਧਿਐਨ MCP ਲਾਗੂ ਕਰਨ ਦੇ ਵੱਖ-ਵੱਖ ਪੱਖਾਂ ਨੂੰ ਕਵਰ ਕਰਦੇ ਹਨ:
- **ਉਦਯੋਗਿਕ ਇੰਟੀਗ੍ਰੇਸ਼ਨ**: Azure API ਮੇਨੇਜਮੈਂਟ ਅਤੇ Azure DevOps ਆਟੋਮੇਸ਼ਨ
- **ਮਲਟੀ-ਏਜੰਟ ਅੋਰਕੈਸਟ੍ਰੇਸ਼ਨ**: ਟ੍ਰੈਵਲ ਪਲਾਨਿੰਗ ਨਾਲ ਸਹਿਯੋਗੀ ਏਆਈ ਏਜੰਟ
- **ਡਿਵੈਲਪਰ ਉਤਪਾਦਕਤਾ**: VS ਕੋਡ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਅਤੇ ਰੀਅਲ-ਟਾਈਮ ਡੌਕੂਮੈਂਟ ਐਕਸੈਸ
- **ਇਕੋਸਿਸਟਮ ਵਿਕਾਸ**: GitHub ਦੀ MCP ਰਜਿਸਟਰੀ ਮੂਲ ਧਾਰਾ ਪਲੇਟਫਾਰਮ ਵਜੋਂ
- **ਸ਼ਿੱਖਿਆ ਸੰਬੰਧੀ ਐਪਲੀਕੇਸ਼ਨ**: ਇੰਟਰੈਕਟਿਵ ਅਧਿਐਨ ਯੋਜਨਾ ਜਨਰੇਟਰ ਅਤੇ ਗੱਲਬਾਤੀ ਇੰਟਰਫੇਸ

ਇਹ ਲਾਗੂ ਕਰ ਕ ਤੁਹਾਨੂੰ ਮਹੱਤਵਪੂਰਨ ਜਾਣਕਾਰੀਆਂ ਮਿਲਦੀਆਂ ਹਨ:
- **ਆਰਕੀਟੈਕਚਰੋ ਪੈਟਰਨ** ਵੱਖ-ਵੱਖ ਮਾਪੇ ਅਤੇ ਵਰਤੋਂ ਮਾਮਲਿਆਂ ਲਈ
- **ਲਾਗੂ ਕਰਨ ਦੀਆਂ ਰਣਨੀਤੀਆਂ** ਜੋ ਕਾਰਜਕੁਸ਼ਲਤਾ ਨੂੰ ਸੰਭਾਲਣਯੋਗਤਾ ਨਾਲ ਸੰਤੁਲਿਤ ਕਰਦੀਆਂ ਹਨ
- **ਸੁਰੱਖਿਆ ਅਤੇ ਸਕੇਲਬਿਲਿਟੀ** ਉਤਪਾਦਨ ਲਾਗੂ ਕਰਨ ਲਈ ਧਿਆਨਵੰਦੀਆਂ
- **MCP ਸਰਵਰ ਵਿਕਾਸ ਅਤੇ ਕਲਾਇੰਟ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਲਈ ਸਭ ਤੋਂ ਵਧੀਆ ਅਮਲ**
- **ਇਕੋਸਿਸਟਮ ਸੋਚ** ਸੰਪਰਕਿਤ ਏਆਈ-ਚਲਿਤ ਹੱਲ ਬਣਾਉਣ ਲਈ

ਇਹ ਉਦਾਹਰਣ ਸਮੂਹਿਕ ਤੌਰ 'ਤੇ ਦਿਖਾਉਂਦੇ ਹਨ ਕਿ MCP ਸਿਰਫ ਸਿਧਾਂਤਕ ਢਾਂਚਾ ਨਹੀਂ ਹੈ ਪਰ ਇੱਕ ਪੱਕਾ, ਉਤਪਾਦਨ-ਤਿਆਰ ਪ੍ਰੋਟੋਕਾਲ ਹੈ ਜੋ ਜਟਿਲ ਕਾਰੋਬਾਰੀ ਚੁਣੌਤੀਆਂ ਲਈ ਵਿਹਾਰਿਕ ਹੱਲ ਮੁਹੱਈਆ ਕਰਦਾ ਹੈ। ਚਾਹੇ ਤੁਸੀਂ ਸਧਾਰਣ ਆਟੋਮੇਸ਼ਨ ਟੂਲ ਬਣਾ ਰਹੇ ਹੋ ਜਾਂ ਸੁਧਾਰਿਆ ਹੋਇਆ ਮਲਟੀ-ਏਜੰਟ ਪ੍ਰਣਾਲੀਆਂ, ਇੱਥੇ ਦਰਸਾਏ ਗਏ ਪੈਟਰਨ ਅਤੇ ਢੰਗ ਤੁਹਾਡੇ ਆਪਣੇ MCP ਪ੍ਰੋਜੈਕਟਾਂ ਲਈ ਇੱਕ ਮਜ਼ਬੂਤ ਬੁਨਿਆਦ ਮੁਹੱਈਆ ਕਰਦੇ ਹਨ।
