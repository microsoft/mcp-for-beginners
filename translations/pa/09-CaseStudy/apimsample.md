# ਕੇਸ ਅਧਿਐਨ: MCP ਸਰਵਰ ਵਜੋਂ API ਪ੍ਰਬੰਧਨ ਵਿੱਚ REST API ਨੂੰ ਪ੍ਰਗਟ ਕਰੋ

ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਇੱਕ ਸੇਵਾ ਹੈ ਜੋ ਤੁਹਾਡੇ API ਐਂਡਪੋਇੰਟਾਂ ਦੇ ਉੱਪਰ ਗੇਟਵੇ ਪ੍ਰਦਾਨ ਕਰਦੀ ਹੈ। ਇਹ ਇਸ ਤਰ੍ਹਾਂ ਕੰਮ ਕਰਦਾ ਹੈ ਕਿ ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਤੁਹਾਡੇ APIs ਦੇ ਸਾਹਮਣੇ ਪ੍ਰਾਕਸੀ ਵਾਂਗ ਕੰਮ ਕਰਦਾ ਹੈ ਅਤੇ ਆਉਣ ਵਾਲੀਆਂ ਬੇਨਤੀਆਂ ਨਾਲ ਕੀ ਕਰਨਾ ਹੈ ਇਹ ਫੈਸਲਾ ਕਰਦਾ ਹੈ।

ਇਸਦਾ ਉਪਯੋਗ ਕਰਕੇ, ਤੁਸੀਂ ਕਈ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਸ਼ਾਮਲ ਕਰਦੇ ਹੋ ਜਿਵੇਂ ਕਿ:

- **ਸੁਰੱਖਿਆ**, ਤੁਸੀਂ API ਕੁੰਜੀਆਂ, JWT ਤੋਂ ਲੈ ਕੇ ਪ੍ਰਬੰਧਿਤ ਪਹਿਚਾਣ ਤੱਕ ਹਰ ਚੀਜ਼ ਦੀ ਵਰਤੋਂ ਕਰ ਸਕਦੇ ਹੋ।
- **ਰੇਟ ਸੀਮਾਬੱਧਤਾ**, ਇਹ ਇੱਕ ਸ਼ਾਨਦਾਰ ਫੀਚਰ ਹੈ ਜੋ ਤੁਹਾਨੂੰ ਫੈਸਲਾ ਕਰਨ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ ਕਿ ਇੱਕ ਨਿਸ਼ਚਿਤ ਸਮੇਂ ਇਕਾਈ ਵਿੱਚ ਕਿੰਨੀ ਕਾਲਾਂ ਹੋਣੀਆਂ ਚਾਹੀਦੀਆਂ ਹਨ। ਇਸ ਨਾਲ ਸਾਰਿਆਂ ਯੂਜ਼ਰ ਨੂੰ ਵਧੀਆ ਅਨੁਭਵ ਮਿਲਦਾ ਹੈ ਅਤੇ ਇਹ ਵੀ ਯਕੀਨੀ ਬਣਦਾ ਹੈ ਕਿ ਤੁਹਾਡੀ ਸੇਵਾ ਬੇਨਤੀਆਂ ਨਾਲ ਓਵਰਲੋਡ ਨਹੀਂ ਹੁੰਦੀ।
- **ਸਕੇਲਿੰਗ ਅਤੇ ਲੋਡ ਸੰਤੁਲਨ**। ਤੁਸੀਂ ਕਈ ਐਂਡਪੋਇੰਟ ਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ ਤਾਂ ਜੋ ਲੋਡ ਸੰਤੁਲਿਤ ਹੋਵੇ ਅਤੇ ਤੁਸੀਂ ਇਹ ਵੀ ਨਿਰਧਾਰਿਤ ਕਰ ਸਕਦੇ ਹੋ ਕਿ "ਲੋਡ ਸੰਤੁਲਨ" ਕਿਵੇਂ ਕਰਨਾ ਹੈ।
- **AI ਫੀਚਰ ਜਿਵੇਂ ਸੈਮੈਂਟਿਕ ਕੈਸ਼ਿੰਗ**, ਟੋਕਨ ਸੀਮਿਤਤਾ ਅਤੇ ਟੋਕਨ ਮਾਨੀਟਰਿੰਗ ਆਦਿ। ਇਹ ਸ਼ਾਨਦਾਰ ਫੀਚਰ ਹਨ ਜੋ ਜਵਾਬਦੇਹਤਾ ਵਿੱਚ ਸੁਧਾਰ ਕਰਦੇ ਹਨ ਅਤੇ ਤੁਹਾਨੂੰ ਆਪਣੇ ਟੋਕਨ ਖਰਚ 'ਤੇ ਨਜ਼ਰ ਰੱਖਣ ਵਿੱਚ ਮਦਦ ਕਰਦੇ ਹਨ। [ਇੱਥੇ ਹੋਰ ਪੜ੍ਹੋ](https://learn.microsoft.com/en-us/azure/api-management/genai-gateway-capabilities)۔

## ਕਿਉਂ MCP + ਏਜੁਰ API ਪ੍ਰਬੰਧਨ?

ਮਾਡਲ ਸੰਦਰਭ ਪ੍ਰੋਟੋਕੋਲ ਤੇਜ਼ੀ ਨਾਲ ਏਜੰਟਿਕ AI ਐਪਸ ਲਈ ਇੱਕ ਮਿਆਰੀ ਬਣਦਾ ਜਾ ਰਿਹਾ ਹੈ ਅਤੇ ਸੰਦਾਂ ਅਤੇ ਡੇਟਾ ਨੂੰ ਇੱਕ ਸੰਗਤ ਢੰਗ ਨਾਲ ਪ੍ਰਗਟ ਕਰਨ ਲਈ। ਜਦੋਂ ਤੁਹਾਨੂੰ APIs ਨੂੰ "ਪ੍ਰਬੰਧਿਤ" ਕਰਨ ਦੀ ਲੋੜ ਹੁੰਦੀ ਹੈ ਤਾਂ ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਇੱਕ ਕੁਦਰਤੀ ਚੋਣ ਹੈ। MCP ਸਰਵਰ ਅਕਸਰ ਹੋਰ APIs ਨਾਲ ਇੰਟੀਗ੍ਰੇਟ ਹੁੰਦੇ ਹਨ ਤਾਂ ਜੋ ਉਦਾਹਰਣ ਲਈ ਇੱਕ ਸੰਦ ਲਈ ਬੇਨਤੀਆਂ ਨੂੰ ਹੱਲ ਕੀਤਾ ਜਾ ਸਕੇ। ਇਸ ਲਈ ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਅਤੇ MCP ਨੂੰ ਮਿਲਾਉਣਾ ਬਹੁਤ ਸਾਰਥਕ ਹੈ।

## ਜਾਇਜ਼ਾ

ਇਸ ਖਾਸ ਉਪਯੋਗ ਕੇਸ ਵਿੱਚ ਅਸੀਂ ਜਾਣਾਂਗੇ ਕਿ API ਐਂਡਪੋਇੰਟਾਂ ਨੂੰ MCP ਸਰਵਰ ਵਜੋਂ ਕਿਵੇਂ ਪ੍ਰਗਟ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ। ਇਸ ਤਰ੍ਹਾਂ, ਅਸੀਂ ਇਸ ਐਂਡਪੋਇੰਟ ਨੂੰ ਆਸਾਨੀ ਨਾਲ ਇੱਕ ਏਜੰਟਿਕ ਐਪ ਦਾ ਹਿੱਸਾ ਬਣਾ ਸਕਦੇ ਹਾਂ ਅਤੇ ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਦੀਆਂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਤੋਂ ਵੀ ਲਾਭ ਉਠਾ ਸਕਦੇ ਹਾਂ।

## ਮੁੱਖ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ

- ਤੁਸੀਂ ਉਹ ਐਂਡਪੋਇੰਟ ವಿಧಾನ ਚੁਣਦੇ ਹੋ ਜਿਹੜੇ ਤੁਸੀਂ ਟੂਲ ਵਜੋਂ ਪ੍ਰਗਟ ਕਰਨੇ ਚਾਹੁੰਦੇ ਹੋ।
- ਜੋ ਵਾਧੂ ਵਿਸ਼ੇਸ਼ਤਾਵਾਂ ਤੁਸੀਂ ਪ੍ਰਾਪਤ ਕਰਦੇ ਹੋ ਉਹ ਤੁਸੀਂ ਆਪਣੇ API ਲਈ ਨੀਤੀ (policy) ਸੈਕਸ਼ਨ ਵਿੱਚ ਜੋ ਕੁਝ ਸੰਰਚਿਤ ਕਰਦੇ ਹੋ ਉਸ 'ਤੇ ਨਿਰਭਰ ਕਰਦੀਆਂ ਹਨ। ਪਰ ਇੱਥੇ ਅਸੀਂ ਤੁਹਾਨੂੰ ਦਿਖਾਵਾਂਗੇ ਕਿ ਤੁਸੀਂ ਰੇਟ ਸੀਮਾਬੱਧਤਾ ਕਿਵੇਂ ਸ਼ਾਮਲ ਕਰ ਸਕਦੇ ਹੋ।

## ਪਹਿਲਾ ਕਦਮ: API ਆਯਾਤ ਕਰੋ

ਜੇ ਤੁਹਾਡੇ ਕੋਲ ਪਹਿਲਾਂ ਹੀ ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਵਿੱਚ API ਹੈ ਤਾਂ ਬਹੁਤ ਵਧੀਆ, ਫਿਰ ਤੁਸੀਂ ਇਸ ਕਦਮ ਨੂੰ ਛੱਡ ਸਕਦੇ ਹੋ। ਨਹੀਂ ਤਾਂ ਇਸ ਲਿੰਕ ਨੂੰ ਦੇਖੋ, [ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਵਿੱਚ API ਆਯਾਤ ਕਰਨਾ](https://learn.microsoft.com/en-us/azure/api-management/import-and-publish#import-and-publish-a-backend-api).

## API ਨੂੰ MCP ਸਰਵਰ ਵਜੋਂ ਪ੍ਰਗਟ ਕਰੋ

API ਐਂਡਪੋਇੰਟਾਂ ਨੂੰ ਪ੍ਰਗਟ ਕਰਨ ਲਈ, ਚਲੋ ਇਹ ਕਦਮ ਅਪਣਾਈਏ:

1. ਏਜੁਰ ਪੋਰਟਲ 'ਤੇ ਜਾਓ ਅਤੇ ਇਸ ਪਤੇ ਤੇ: <https://portal.azure.com/?Microsoft_Azure_ApiManagement=mcp>  
ਆਪਣੇ API ਪ੍ਰਬੰਧਨ ਇੰਸਟੈਂਸ 'ਤੇ ਜਾਓ।

1. ਖੱਬੇ ਮੇਨੂ ਵਿੱਚ, APIs > MCP Servers > + Create new MCP Server ਚੁਣੋ।

1. API ਵਿੱਚ, ਇੱਕ REST API ਨੂੰ MCP ਸਰਵਰ ਵਜੋਂ ਪ੍ਰਗਟ ਕਰਨ ਲਈ ਚੁਣੋ।

1. ਇੱਕ ਜਾਂ ਕਈ API ਓਪਰੇਸ਼ਨਾਂ ਨੂੰ ਟੂਲ ਵਜੋਂ ਪ੍ਰਗਟ ਕਰਨ ਲਈ ਚੁਣੋ। ਤੁਸੀਂ ਸਾਰੇ ਓਪਰੇਸ਼ਨ ਜਾਂ ਕੇਵਲ ਖਾਸ ਓਪਰੇਸ਼ਨ ਚੁਣ ਸਕਦੇ ਹੋ।

    ![ਪ੍ਰਗਟ ਕਰਨ ਲਈ ਵਿਧੀਆਂ ਚੁਣੋ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/create-mcp-server-small.png)


1. **ਬਣਾਓ (Create)** ਚੁਣੋ।

1. ਮੇਨੂ ਚੋਣ **APIs** ਅਤੇ **MCP Servers** ਤੇ ਜਾਓ, ਤੁਸੀਂ ਇਹ ਵੇਖੋਗੇ:

    ![ਮੁੱਖ ਪੈਨ ਵਿੱਚ MCP ਸਰਵਰ ਵੇਖੋ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-list.png)

    MCP ਸਰਵਰ ਬਣਾਇਆ ਗਿਆ ਹੈ ਅਤੇ API ਓਪਰੇਸ਼ਨ ਟੂਲ ਵਜੋਂ ਪ੍ਰਗਟ ਕੀਤੇ ਗਏ ਹਨ। MCP ਸਰਵਰ MCP Servers ਪੈਨ ਵਿੱਚ ਸੂਚੀਬੱਧ ਹੈ। URL ਕਾਲਮ में MCP ਸਰਵਰ ਦਾ ਐਂਡਪੋਇੰਟ ਦਿਖਾਇਆ ਗਿਆ ਹੈ ਜਿਸ ਨੂੰ ਤੁਸੀਂ ਟੈਸਟ ਕਰਨ ਜਾਂ ਕਲਾਇੰਟ ਐਪਲੀਕੇਸ਼ਨ ਵਿਚ ਕਾਲ ਕਰ ਸਕਦੇ ਹੋ।

## ਵਿਕਲਪਿਕ: ਨੀਤੀਆਂ ਸੰਰਚਿਤ ਕਰੋ

ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਵਿੱਚ ਨੀਤੀਆਂ ਦਾ ਮੁੱਖ ਸੰਕਲਪ ਹੁੰਦਾ ਹੈ ਜਿੱਥੇ ਤੁਸੀਂ ਆਪਣੇ ਐਂਡਪੋਇੰਟਾਂ ਲਈ ਵੱਖ-ਵੱਖ ਨਿਯਮ ਸੈੱਟ ਕਰਦੇ ਹੋ ਜਿਵੇਂ ਕਿ ਰੇਟ ਸੀਮਾਬੱਧਤਾ ਜਾਂ ਸੈਮੈਂਟਿਕ ਕੈਸ਼ਿੰਗ। ਇਹ ਨੀਤੀਆਂ XML ਵਿੱਚ ਲਿਖੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।

ਇੱਥੇ ਹੈ ਕਿ ਤੁਸੀਂ ਆਪਣੀ MCP ਸਰਵਰ ਦੀ ਰੇਟ ਸੀਮਾਬੱਧਤਾ ਕਿਵੇਂ ਸੈੱਟ ਕਰ ਸਕਦੇ ਹੋ:

1. ਪੋਰਟਲ ਵਿੱਚ, APIs ਹੇਠਾਂ, **MCP Servers** ਚੁਣੋ।

1. ਆਪਣੇ ਬਣਾਏ MCP ਸਰਵਰ ਨੂੰ ਚੁਣੋ।

1. ਖੱਬੇ ਮੇਨੂ ਵਿੱਚ, MCP ਹੇਠਾਂ, **Policies** ਚੁਣੋ।

1. ਨੀਤੀ ਸੰਪਾਦਕ ਵਿੱਚ, ਉਹ ਨੀਤੀਆਂ ਜੋ ਤੁਸੀਂ MCP ਸਰਵਰ ਦੇ ਟੂਲਾਂ 'ਤੇ ਲਗਾਉਣਾ ਚਾਹੁੰਦੇ ਹੋ, ਸ਼ਾਮਲ ਕਰੋ ਜਾਂ ਸੋਧੋ। ਨੀਤੀਆਂ XML ਫਾਰਮੈਟ ਵਿੱਚ ਪਰਿਭਾਸ਼ਿਤ ਹੁੰਦੀਆਂ ਹਨ। ਉਦਾਹਰਣ ਲਈ, ਤੁਸੀਂ MCP ਸਰਵਰ ਦੇ ਟੂਲਾਂ ਲਈ ਕਾਲਾਂ ਦੀ ਸੀਮਾਬੱਧਤਾ ਨੂੰ ਨਿਰਧਾਰਤ ਕਰਨ ਵਾਲੀ ਨੀਤੀ ਸ਼ਾਮਲ ਕਰ ਸਕਦੇ ਹੋ (ਇਸ ਉਦਾਹਰਣ ਵਿੱਚ, ਪ੍ਰਤੀ ਗ੍ਰਾਹਕ IP ਪਤਾ 30 ਸੈਕਿੰਡ ਵਿੱਚ 5 ਕਾਲਾਂ)। ਇਹ ਰੇਟ ਸੀਮਾਬੱਧਤਾ ਵਾਲੀ ਨੀਤੀ ਦਾ XML ਇਸ ਤਰ੍ਹਾਂ ਹੋਵੇਗਾ:

    ```xml
     <rate-limit-by-key calls="5" 
       renewal-period="30" 
       counter-key="@(context.Request.IpAddress)" 
       remaining-calls-variable-name="remainingCallsPerIP" 
    />
    ```

    ਨੀਤੀ ਸੰਪਾਦਕ ਦੀ ਇੱਕ ਤਸਵੀਰ ਇੱਥੇ ਹੈ:

    ![ਨੀਤੀ ਸੰਪਾਦਕ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-policies-small.png)
 
## ਇਸਨੂੰ ਆਜ਼ਮਾਓ

ਆਓ ਯਕੀਨੀ ਬਣਾਈਏ ਕਿ ਸਾਡਾ MCP ਸਰਵਰ ਮਨੋਰਥ ਅਨੁਸਾਰ ਕੰਮ ਕਰ ਰਿਹਾ ਹੈ।

> [!NOTE]
> ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਇਸ ਸਮੇਂ ਇਸ ਸਰਵਰ ਨੂੰ Streamable
> HTTP `/mcp` ਐਂਡਪੋਇੰਟ ਰਾਹੀਂ ਪ੍ਰਗਟ ਕਰਦਾ ਹੈ। ਪੁਰਾਣੀ HTTP+SSE `/sse` ਤਰਾਂਸਪੋਰਟ ਨੂੰ ਅਪ੍ਰਚੀਤ ਕੀਤਾ ਗਿਆ ਹੈ ਅਤੇ
> ਕੇਵਲ ਲੇਗੇਸੀ ਕਲਾਇੰਟਾਂ ਲਈ ਵਰਤਣਾ ਚਾਹੀਦਾ ਹੈ।

ਇਸ ਲਈ, ਅਸੀਂ Visual Studio Code ਅਤੇ GitHub Copilot ਦੇ Agent ਮੋਡ ਦੀ ਵਰਤੋਂ ਕਰਾਂਗੇ। ਅਸੀਂ MCP ਸਰਵਰ ਨੂੰ *mcp.json* ਵਿੱਚ ਸ਼ਾਮਲ ਕਰਾਂਗੇ। ਇਸ ਤਰ੍ਹਾਂ, Visual Studio Code ਇੱਕ ਏਜੰਟਿਕ ਸਮਰੱਥਾ ਵਾਲਾ ਕਲਾਇੰਟ ਵਜੋਂ ਕੰਮ ਕਰੇਗਾ ਅਤੇ ਅੰਤ-ਉਪਭੋਗਤਾ ਪ੍ਰਾਂਪਟ ਟਾਈਪ ਕਰਕੇ ਉਸ ਸਰਵਰ ਨਾਲ ਇੰਟਰੈਕਟ ਕਰ ਸਕਣਗੇ।

ਚਲੋ ਵੇਖੀਏ ਕਿ MCP ਸਰਵਰ ਨੂੰ Visual Studio Code ਵਿੱਚ ਕਿਵੇਂ ਸ਼ਾਮਲ ਕਰਨਾ ਹੈ:

1. ਕਮਾਂਡ ਪੈਲੇਟ ਤੋਂ MCP: **Add Server ਕਮਾਂਡ ਦੀ ਵਰਤੋਂ ਕਰੋ**।

1. ਜਦੋਂ ਪੁੱਛਿਆ ਜਾਵੇ, ਸਰਵਰ ਕਿਸਮ ਚੁਣੋ: **HTTP (HTTP ਜਾਂ Server Sent Events)**।

1. API ਪ੍ਰਬੰਧਨ ਵਿੱਚ MCP ਸਰਵਰ ਲਈ ਦਰਸਾਇਆ Streamable HTTP URL ਦਰਜ ਕਰੋ।
    ਉਦਾਹਰਣ ਵਜੋਂ:
    `https://<apim-service-name>.azure-api.net/<api-name>-mcp/mcp`।

1. ਆਪਣੀ ਪਸੰਦ ਦਾ ਇੱਕ ਸਰਵਰ ID ਦਰਜ ਕਰੋ। ਇਹ ਇੱਕ ਅਹੰਕਾਰਪੂਰਵਕ ਮੁੱਲ ਨਹੀਂ ਹੈ ਪਰ ਇਹ ਤੁਹਾਨੂੰ ਯਾਦ ਰੱਖਣ ਵਿੱਚ ਮਦਦ ਕਰੇਗਾ ਕਿ ਇਹ ਸਰਵਰ ਇੰਸਟੈਂਸ ਕੀ ਹੈ।

1. ਨਿਰਧਾਰਿਤ ਕਰੋ ਕਿ ਸੰਰਚਨਾ ਨੂੰ ਆਪਣੇ ਵਰਕਸਪੇਸ ਸੈਟਿੰਗ ਜਾਂ ਯੂਜ਼ਰ ਸੈਟਿੰਗ ਵਿੱਚ ਸੇਵ ਕਰਨਾ ਹੈ।

  - **ਵਰਕਸਪੇਸ ਸੈਟਿੰਗਜ਼** - ਸਰਵਰ ਸੰਰਚਨਾ ਸਿਰਫ ਮੌਜੂਦਾ ਵਰਕਸਪੇਸ ਵਿੱਚ ਉਪਲਬਧ .vscode/mcp.json ਫਾਈਲ ਵਿੱਚ ਸੇਵ ਕੀਤੀ ਜਾਂਦੀ ਹੈ।

    *mcp.json*

    ```json
    "servers": {
        "APIM petstore" : {
            "type": "http",
            "url": "url-to-mcp-server/mcp"
        }
    }
    ```

  - **ਯੂਜ਼ਰ ਸੈਟਿੰਗਜ਼** - ਸਰਵਰ ਸੰਰਚਨਾ ਤੁਹਾਡੇ ਗਲੋਬਲ *settings.json* ਫਾਈਲ ਵਿੱਚ ਸ਼ਾਮਲ ਕੀਤੀ ਜਾਂਦੀ ਹੈ ਅਤੇ ਸਾਰੇ ਵਰਕਸਪੇਸਾਂ ਵਿੱਚ ਉਪਲਬਧ ਹੁੰਦੀ ਹੈ। ਸੰਰਚਨਾ ਏਨੀ ਜਿਹੀ ਹੈ:

    ![ਯੂਜ਼ਰ ਸੈਟਿੰਗ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-servers-visual-studio-code.png)

1. ਤੁਹਾਨੂੰ ਐਜੁਰ API ਪ੍ਰਬੰਧਨ ਵੱਲ ਠੀਕ ਤਰ੍ਹਾਂ ਪ੍ਰਮਾਣਿਕਤਾ ਕਰਨ ਲਈ ਇੱਕ ਹੈਡਰ ਜੋੜਨ ਦੀ ਲੋੜ ਹੈ। ਇਹ **Ocp-Apim-Subscription-Key** ਨਾਮਕ ਹੈਡਰ ਦੀ ਵਰਤੋਂ ਕਰਦਾ ਹੈ।

    - ਇਸਨੂੰ ਸੈਟਿੰਗਜ਼ ਵਿੱਚ ਜੋੜਨ ਦਾ ਤਰੀਕਾ ਇੱਥੇ ਹੈ:

    ![ਪ੍ਰਮਾਣਿਕਤਾ ਲਈ ਹੈਡਰ ਜੋੜਨਾ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-with-header-visual-studio-code.png), ਇਹ ਇੱਕ ਪ੍ਰਾਰੰਭਿਕਤਾ ਪੇਸ਼ ਕਰੇਗਾ ਜੋ ਤੁਹਾਡੇ ਕੋਲ API ਕੁੰਜੀ ਦਾ ਮੁੱਲ ਮੰਗੇਗਾ ਜੋ ਤੁਸੀਂ ਏਜੁਰ ਪੋਰਟਲ ਤੋਂ ਆਪਣੇ ਏਜੁਰ API ਪ੍ਰਬੰਧਨ ਇੰਸਟੈਂਸ ਲਈ ਲੱਭ ਸਕਦੇ ਹੋ।

   - *mcp.json* ਵਿੱਚ ਸ਼ਾਮਲ ਕਰਨ ਲਈ, ਤੁਸੀਂ ਇਸ ਤਰ੍ਹਾਂ ਜੋੜ ਸਕਦੇ ਹੋ:

    ```json
    "inputs": [
      {
        "type": "promptString",
        "id": "apim_key",
        "description": "API Key for Azure API Management",
        "password": true
      }
    ]
    "servers": {
        "APIM petstore" : {
            "type": "http",
            "url": "url-to-mcp-server/mcp",
            "headers": {
                "Ocp-Apim-Subscription-Key": "Bearer ${input:apim_key}"
            }
        }
    }
    ```

### ਏਜੰਟ ਮੋਡ ਦੀ ਵਰਤੋਂ ਕਰੋ

ਹੁਣ ਅਸੀਂ ਸੈਟਿੰਗਜ਼ ਜਾਂ *.vscode/mcp.json* ਵਿੱਚ ਸਾਰੇ ਤਿਆਰ ਹਾਂ। ਆਓ ਇਸਨੂੰ ਆਜ਼ਮਾਈਏ।

ਅਜੇ ਕੋਈ ਸਾਥੀਆਂ ਆਈਕਨ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ ਇਸ ਤਰ੍ਹਾਂ, ਜਿੱਥੇ ਤੁਹਾਡੇ ਸਰਵਰ ਤੋਂ ਪ੍ਰਗਟ ਕੀਤੇ ਟੂਲਸ ਦੀ ਸੂਚੀ ਹੋਵੇਗੀ:

![ਸਰਵਰ ਤੋਂ ਟੂਲਸ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/tools-button-visual-studio-code.png)

1. ਟੂਲ ਆਈਕਨ 'ਤੇ ਕਲਿੱਕ ਕਰੋ ਅਤੇ ਤੁਹਾਨੂੰ ਟੂਲਸ ਦੀ ਇਕ ਸੂਚੀ ਵੇਖਣ ਨੂੰ ਮਿਲੇਗੀ, ਇਹ ਤਰ੍ਹਾਂ:

    ![ਟੂਲਸ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/select-tools-visual-studio-code.png)

1. ਚੈਟ ਵਿੱਚ ਪ੍ਰਾਂਪਟ ਦਰਜ ਕਰੋ ਜਿਵੇਂ ਕਿ ਟੂਲ ਨੂੰ ਕਾਲ ਕਰਨ ਲਈ। ਉਦਾਹਰਣ ਵਜੋਂ, ਜੇ ਤੁਸੀਂ ਇੱਕ ਟੂਲ ਚੁਣਿਆ ਹੈ ਜੋ ਆਰਡਰ ਬਾਰੇ ਜਾਣਕਾਰੀ ਦਿੰਦਾ ਹੈ, ਤਾਂ ਤੁਸੀਂ ਏਜੰਟ ਨੂੰ ਆਰਡਰ ਬਾਰੇ ਪੁੱਛ ਸਕਦੇ ਹੋ। ਇੱਥੇ ਇੱਕ ਉਦਾਹਰਣ ਪ੍ਰਾਂਪਟ ਹੈ:

    ```text
    get information from order 2
    ```

    ਹੁਣ ਤੁਹਾਨੂੰ ਇੱਕ ਟੂਲ ਆਈਕਨ ਦੇ ਨਾਲ ਪ੍ਰਗਟ ਕੀਤਾ ਜਾਵੇਗਾ ਜੋ ਟੂਲ ਨੂੰ ਕਾਲ ਕਰਨ ਲਈ ਪੁੱਛੇਗਾ। ਚੱਲਦੇ ਰਹੋ ਅਤੇ ਟੂਲ ਨੂੰ ਚਲਾਉਣਾ ਜਾਰੀ ਰੱਖੋ, ਤੁਹਾਨੂੰ ਹੁਣ ਇਸ ਤਰ੍ਹਾਂ ਨਤੀਜਾ ਵੇਖਣ ਨੂੰ ਮਿਲੇਗਾ:

    ![ਪ੍ਰਾਂਪਟ ਤੋਂ ਨਤੀਜਾ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/chat-results-visual-studio-code.png)

    **ਜੋ ਤੁਸੀਂ ਉਪਰ ਵੇਖਦੇ ਹੋ ਉਹ ਤੁਹਾਡੇ ਸੈੱਟਅਪ ਕੀਤੇ ਟੂਲਾਂ 'ਤੇ ਨਿਰਭਰ ਕਰਦਾ ਹੈ, ਪਰ ਸਿਧਾਂਤ ਇਹ ਹੈ ਕਿ ਤੁਹਾਨੂੰ ਉਪਰ ਦਿੱਤੀ ਤਰ੍ਹਾਂ ਲਿਖਤੀ ਜਵਾਬ ਮਿਲਦਾ ਹੈ।**
