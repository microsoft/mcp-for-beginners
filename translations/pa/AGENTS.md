# AGENTS.md

## ਪ੍ਰੋਜੈਕਟ ਦਾ ਸਾਰ

**MCP for Beginners** ਮਾਡਲ ਕਾਂਟੈਕਸਟ ਪ੍ਰੋਟੋਕੋਲ (MCP) ਸਿੱਖਣ ਲਈ ਇੱਕ ਖੁੱਲ੍ਹਾ ਸਰੋਤ ਸਿੱਖਿਆਤਮਕ ਪਾਠਕ੍ਰਮ ਹੈ - ਏ.ਆਈ. ਮਾਡਲਾਂ ਅਤੇ ਕਲਾਇਆਂਟ ਐਪਲੀਕੇਸ਼ਨਾਂ ਦਰਮਿਆਨ ਇੰਟਰਐਕਸ਼ਨਾਂ ਲਈ ਇੱਕ ਮਿਆਰੀਕ੍ਰਿਤ ਫ੍ਰੇਮਵਰਕ। ਇਹ ਰਿਪੋਜ਼ਿਟਰੀ ਕਈ ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ 'ਚ व्यवहारਕ ਕੋਡ ਉਦਾਹਰਣਾਂ ਨਾਲ ਵਿਸਤ੍ਰਿਤ ਸਿੱਖਣ ਸਮੱਗਰੀ ਪ੍ਰਦਾਨ ਕਰਦੀ ਹੈ।

### ਮੁੱਖ ਤਕਨਾਲੋਜੀਆਂ

- **ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਭਾਸ਼ਾਵਾਂ**: C#, ਜਾਵਾ, ਜਾਵਾਸਕ੍ਰਿਪਟ, ਟਾਈਪਸਕ੍ਰਿਪਟ, ਪਾਇਥਨ, ਰੱਸਟ
- **ਫ੍ਰੇਮਵਰਕ ਅਤੇ SDKs**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - ਸਪ੍ਰਿੰਗ ਬੂਟ (ਜਾਵਾ)
  - FastMCP (ਪਾਇਥਨ)
  - LangChain4j (ਜਾਵਾ)
- **ਡੇਟਾਬੇਸ**: pgvector ਐਕਸਟੈਨਸ਼ਨ ਸਮੇਤ PostgreSQL
- **ਕਲਾਉਡ ਪਲੇਟਫਾਰਮਾਂ**: Azure (ਕੰਟੇਨਰ ਐਪਸ, OpenAI, ਕੰਟੈਂਟ ਸੇਫਟੀ, ਐਪਲੀਕੇਸ਼ਨ ਇਨਸਾਈਟਸ)
- **ਬਿਲਡ ਟੂਲਜ਼**: npm, Maven, pip, Cargo
- **ਡੌਕਯੂਮੈਂਟੇਸ਼ਨ**: ਮਾਰਕਡਾਊਨ ਨਾਲ ਸੁਚਾਲਿਤ ਬਹੁ-ਭਾਸ਼ਾਈ ਅਨuvad (48+ ਭਾਸ਼ਾਵਾਂ)

### ਢਾਂਚਾ

- **11 ਮੁੱਖ ਮਾਡਿਊਲ (00-11)**: ਬੁਨਿਆਦੀ ਤੋਂ ਅੱਗੇਲੀ ਵਿਸ਼ਿਆਂ ਲਈ ਲਗਾਤਾਰ ਸਿੱਖਣ ਦਾ ਮਾਰਗ
- **ਹੈਂਡਸ-ਆਨ ਲੈਬਜ਼**: ਵੱਖ-ਵੱਖ ਭਾਸ਼ਾਵਾਂ ਵਿੱਚ ਪੂਰੀ ਸਲੂਸ਼ਨ ਕੋਡ ਨਾਲ ਵਿਹਾਰਿਕ ਅਭਿਆਸ
- **ਨਮੂਨਾ ਪ੍ਰੋਜੈਕਟ**: ਕਾਰਗਰ MCP ਸਰਵਰ ਅਤੇ ਕਲਾਇੰਟ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨ
- **ਅਨੁਵਾਦ ਪ੍ਰਣਾਲੀ**: ਬਹੁ-ਭਾਸ਼ਾਈ ਸਹਾਇਤਾ ਲਈ ਸਵੈਚਾਲਿਤ GitHub Actions ਵਰਕਫਲੋ
- **ਚਿੱਤਰ ਸਾਂਝਾ ਕਰਨ ਵਾਲਾ ਫੋਲਡਰ**: ਕੇਂਦਰੀ ਤਸਵੀਰਾਂ ਡਾਇਰੈਕਟਰੀ ਸਾਥੀ ਅਨੁਵਾਦਿਤ ਵਰਜਨਾਂ

## ਸੈਟਅੱਪ ਕਮਾਂਡਜ਼

ਇਹ ਡੌਕਯੂਮੈਂਟੇਸ਼ਨ-ਕੇਂਦਰਤ ਰਿਪੋਜ਼ਿਟਰੀ ਹੈ। ਜ਼ਿਆਦਾਤਰ ਸੈਟਅੱਪ ਵੱਖਰੇ ਨਮੂਨਾ ਪ੍ਰੋਜੈਕਟਾਂ ਅਤੇ ਲੈਬਜ਼ ਵਿੱਚ ਹੁੰਦਾ ਹੈ।

### ਰਿਪੋਜ਼ਿਟਰੀ ਸੈਟਅੱਪ

```bash
# ਰਿਪੋਜ਼ਿਟਰੀ ਨੂੰ ਕਲੋਨ ਕਰੋ
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### ਨਮੂਨਾ ਪ੍ਰੋਜੈਕਟਾਂ ਨਾਲ ਕੰਮ

ਨਮੂਨਾ ਪ੍ਰੋਜੈਕਟ ਇੱਥੇ ਹਨ:
- `03-GettingStarted/samples/` - ਭਾਸ਼ਾ-ਵਿਸ਼ੇਸ਼ ਉਦਾਹਰਣਾਂ
- `03-GettingStarted/01-first-server/solution/` - ਪਹਿਲਾ ਸਰਵਰ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨਾਂ
- `03-GettingStarted/02-client/solution/` - ਕਲਾਇੰਟ ਇੰਪਲੀਮੈਂਟੇਸ਼ਨਾਂ
- `11-MCPServerHandsOnLabs/` - ਵਿਸਤ੍ਰਿਤ ਡੇਟਾਬੇਸ ਇੰਟੀਗ੍ਰੇਸ਼ਨ ਲੈਬਜ਼

ਹਰ ਨਮੂਨਾ ਪ੍ਰੋਜੈਕਟ ਦੇ ਆਪਣੇ ਸੈਟਅੱਪ ਨਿਰਦੇਸ਼ ਹਨ:

#### ਟਾਈਪਸਕ੍ਰਿਪਟ / ਜਾਵਾਸਕ੍ਰਿਪਟ ਪ੍ਰੋਜੈਕਟ
```bash
cd <project-directory>
npm install
npm start
```

#### ਪਾਇਥਨ ਪ੍ਰੋਜੈਕਟ
```bash
cd <project-directory>
pip install -r requirements.txt
# ਜਾਂ
pip install -e .
python main.py
```

#### ਜਾਵਾ ਪ੍ਰੋਜੈਕਟ
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

##### ਲਕੜੀਹਲ

ਕਰੀਕੁਲਮ ਦਸਤਾਵੇਜ਼ੀਕਰਨ ਬਦਲਾਵਾਂ ਅਤੇ ਪ੍ਰਤਿਨਿਧੀ ਨਮੂਨਾ ਕੋਡ ਦੀ
ਸਿਹਤ ਸੰਮਿਲਨ ਤੋਂ ਪਹਿਲਾਂ ਵੈਰੀਫਾਈ ਕਰੋ।

##### ਇਨਪੁੱਟ

- `changed_paths: string[]` (ਜ਼ਰੂਰੀ) - PR ਵਿੱਚ ਬਦਲੇ ਗਏ ਸਬੰਧਤ ਪੱਥ।
- `run_docs_lint: boolean` (ਡਿਫੌਲਟ `true`)
- `run_links_audit: boolean` (ਡਿਫੌਲਟ `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (ਡਿਫੌਲਟ ਸਾਰੇ `false`)

##### ਆਉਟਪੁੱਟ

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### ਅਧਿਕਾਰ

- ਵਰਕਸਪੇਸ ਫਾਇਲਾਂ ਪੜ੍ਹੋ ਅਤੇ ਸਿਰਫ ਟੂਲ-ਜਨਰੇਟ ਕੀਤੇ ਆਰਟਿਫ਼ੈਕਟ ਲਿਖੋ (ਜਿਵੇਂ, ਲਿੰਟ
  ਰਿਪੋਰਟਾਂ, ਟੈਸਟ ਲੌਗ); `translations/` ਜਾਂ
  `translated_images/` ਵਿੱਚ ਕੋਈ ਲਿਖਤ ਨਹੀਂ।
- ਸਥਾਨਕ ਸ਼ੈਲ ਕਮਾਂਡ ਚਲਾਓ।
- ਪੈਕੇਜ ਰੀਸਟੋਰ ਲਈ ਸਿਰਫ਼ ਵਿਕਲਪਕ ਨੈੱਟਵਰਕ ਐਕਸੈੱਸ (`npm ci`,
  `python -m pip install`, `mvn` ਡਿਪੈਂਡੈਂਸੀ ਸਲਾਹਕਾਰ)।
- `translations/` ਜਾਂ
  `translated_images/` ਨੂੰ ਪੁਸ਼, ਮਰਜ, ਜਾਂ ਬਦਲਣ ਦੀ ਇਜਾਜ਼ਤ ਨਹੀਂ।

##### ਅਸਫਲਤਾ ਮੋਡ

- `E_NO_INPUT_PATHS`: `changed_paths` ਖਾਲੀ ਹੈ।
- `E_INVALID_PATH`: ਇਨਪੁੱਟ ਪੱਥ ਰਿਪੋਜ਼ਿਟਰੀ ਰੂਟ ਤੋਂ ਬਾਹਰ ਹੈ।
- `E_LINT_FAILED`: ਮਾਰਕਡਾਊਨ ਲਿੰਟ ਗੈਰ-ਜ਼ੀਰੋ ਨਿਕਾਸਾ ਹੈ।
- `E_LINK_AUDIT_FAILED`: ਲਿੰਕ ਆਡੀਟ ਕਮਾਂਡ ਗੈਰ-ਜ਼ੀਰੋ ਨਿਕਾਸਾ ਹੈ।
- `E_SAMPLE_TEST_FAILED`: ਨਮੂਨਾ ਟੈਸਟ/ਬਿਲਡ ਗੈਰ-ਜ਼ੀਰੋ ਨਿਕਾਸਾ ਹੈ।
- `E_TIMEOUT`: ਕਮਾਂਡ ਨਿਰਧਾਰਤ ਸਮਾਂ ਸੀਮਾ ਤੋਂ ਵੱਧ ਚੱਲੀ।

**ਸਵਾਲ: ਤਸਵੀਰਾਂ ਦਿਖਾਈ ਨਹੀਂ ਦੇ ਰਹੀਆਂ**
ਉੱਤਰ: ਯਕੀਨੀ ਬਣਾਓ ਕਿ ਤਸਵੀਰਾਂ ਦੇ ਰਸਤੇ ਸਾਪੇਖ ਹਨ ਅਤੇ ਫਾਰਵਰਡ ਸਲੈਸ਼ ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਗਈ ਹੈ। ਤਸਵੀਰਾਂ `images/` ਡਾਇਰੈਕਟਰੀ ਚ ਹੋਣੀਆਂ ਚਾਹੀਦੀਆਂ ਹਨ ਜਾਂ ਲੋਕੇਲਾਈਜ਼ ਕੀਤੀਆਂ ਵਰਜਨਾਂ ਲਈ `translated_images/` ਵਿੱਚ।
