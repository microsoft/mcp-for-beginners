# 🚀 ১০টি Microsoft MCP সার্ভার যা ডেভেলপারদের উৎপাদনশীলতা রূপান্তর করছে

## 🎯 এই গাইডে আপনি যা শিখবেন

এই ব্যবহারিক গাইডটি দশটি Microsoft MCP সার্ভার তুলে ধরেছে যা সক্রিয়ভাবে ডেভেলপারদের কিভাবে AI সহকারী নিয়ে কাজ করে তা রূপান্তর করছে। শুধু MCP সার্ভারগুলি *কি করতে পারে* তা ব্যাখ্যা করার বদলে, আমরা আপনাকে এমন সার্ভারগুলো দেখাব যা ইতিমধ্যে Microsoft এবং তার বাইরে দৈনন্দিন উন্নয়ন কাজের প্রবাহে সত্যিকার প্রভাব ফেলছে।

এই গাইডে প্রতিটি সার্ভারকে বাস্তব জীবনের ব্যবহার এবং ডেভেলপার প্রতিক্রিয়ার ভিত্তিতে নির্বাচন করা হয়েছে। আপনি বুঝতে পারবেন কেবল প্রতিটি সার্ভার কি করে তা নয়, কেন তা গুরুত্বপূর্ণ এবং কীভাবে আপনার নিজের প্রকল্পগুলিতে সর্বোচ্চ সুবিধা নেওয়া যায়। আপনি MCP এর প্রতি সম্পূর্ণ নতুন হোন বা আপনার বিদ্যমান সেটআপ বাড়াতে চান, এগুলো Microsoft ইকোসিস্টেমের সবচেয়ে ব্যবহারিক এবং প্রভাবশালী সরঞ্জামগুলোর মধ্যে কিছু উপস্থাপন করে।

> **💡 দ্রুত শুরু করার টিপস**
>
> MCP তে নতুন? দুশ্চিন্তা করবেন না! এই গাইডটি নতুনদের জন্য বানানো হয়েছে। আমরা পুরো পথে ধারণাগুলো ব্যাখ্যা করব, এবং আপনি সবসময় আমাদের [MCP এর পরিচিতি](../00-Introduction/README.md) এবং [কোর কনসেপ্ট](../01-CoreConcepts/README.md) মডিউলগুলোতে ফিরে যেতে পারেন আরও গভীর পটভূমির জন্য।

## সারসংক্ষেপ

এই বিস্তৃত গাইডটি দশটি Microsoft MCP সার্ভার অন্বেষণ করে যা ডেভেলপারদের AI সহকারী এবং বাইরের টুলের সাথে আলাপচারিতার পদ্ধতি বিপ্লব করছে। Azure রিসোর্স ব্যবস্থাপনা থেকে শুরু করে ডকুমেন্ট প্রসেসিং পর্যন্ত, এই সার্ভারগুলি মডেল কনটেক্সট প্রোটোকলের শক্তি প্রদর্শন করে যা সম্পূর্ণ এবং উৎপাদনশীল ডেভেলপমেন্ট ওয়ার্কফ্লো তৈরি করে।

## শেখার উদ্দেশ্য

এই গাইডের শেষ নাগাদ আপনি:
- বুঝতে পারবেন MCP সার্ভারগুলি কিভাবে ডেভেলপারদের উৎপাদনশীলতা বৃদ্ধি করে
- শিখবেন Microsoft এর সবচেয়ে প্রভাবশালী MCP সার্ভার বাস্তবায়নসমূহ সম্পর্কে
- প্রতিটি সার্ভারের ব্যবহারিক ব্যবহার আবিষ্কার করবেন
- বুঝবেন কিভাবে এগুলো VS Code এবং Visual Studio তে সেটআপ এবং কনফিগার করতে হয়
- MCP ইকোসিস্টেম এবং ভবিষ্যৎ দিকনির্দেশনা অন্বেষণ করবেন

## 🔧 MCP সার্ভার বোঝা: নতুনদের জন্য গাইড

### MCP সার্ভার কি?

মডেল কনটেক্সট প্রোটোকল (MCP) এ নতুন হিসেবে আপনি ভাবতে পারেন: "MCP সার্ভার আসলে কি, এবং আমার কেন এটা জানা উচিত?" চলুন সহজ একটি উদাহরণ দিয়ে শুরু করি।

MCP সার্ভারগুলোকে ভাবুন বিশেষায়িত সহকারী হিসেবে যারা আপনার AI কোডিং সঙ্গী (যেমন GitHub Copilot) কে বাইরের টুল এবং সেবার সাথে যুক্ত হতে সাহায্য করে। যেমন আপনি ফোনে বিভিন্ন কাজের জন্য বিভিন্ন অ্যাপ ব্যবহার করেন — আবহাওয়ার জন্য একটি, নেভিগেশনের জন্য অন্য একটি, ব্যাংকিং এর জন্য আরেকটি — MCP সার্ভারগুলি আপনার AI সহকারীকে বিভিন্ন উন্নয়ন টুল এবং সেবার সাথে আলাপ করার ক্ষমতা দেয়।

### MCP সার্ভারগুলি যে সমস্যা সমাধান করে

MCP সার্ভার আসার আগে, আপনি যদি করতে চাইতেন:
- আপনার Azure রিসোর্সগুলো পরীক্ষা করা
- একটি GitHub ইস্যু তৈরি করা
- আপনার ডেটাবেসে প্রশ্ন করা
- ডকুমেন্টেশন সার্চ করা

আপনাকে কোড লেখা থামিয়ে ব্রাউজার খুলতে হত, প্রাসঙ্গিক ওয়েবসাইটে যেতে হত, এবং ম্যানুয়ালি এই কাজগুলো করতে হত। এই প্রক্রিয়ার ধারাবাহিক বিরতি আপনার কাজের প্রবাহকে ভঙ্গ করে এবং উৎপাদনশীলতা কমিয়ে দেয়।

### MCP সার্ভারগুলি কিভাবে আপনার উন্নয়ন অভিজ্ঞতা রূপান্তর করে

MCP সার্ভার ব্যবহার করলে, আপনি আপনার উন্নয়ন পরিবেশ (VS Code, Visual Studio ইত্যাদি) এ থেকেই থাকবেন এবং শুধু AI সহকারীকে এই কাজগুলো করতে বলতে পারবেন। উদাহরণস্বরূপ:

**এই প্রথাগত ওয়ার্কফ্লোর পরিবর্তে:**
1. কোড লেখা বন্ধ করুন
2. ব্রাউজার খুলুন
3. Azure পোর্টালে যান
4. স্টোরেজ অ্যাকাউন্টের বিস্তারিত দেখুন
5. VS Code এ ফিরে আসুন
6. কোড লেখা পুনরায় শুরু করুন

**আপনি এখন এটা করতে পারেন:**
1. AI কে জিজ্ঞাসা করুন: "আমার Azure স্টোরেজ অ্যাকাউন্টগুলোর অবস্থা কী?"
2. প্রাপ্ত তথ্য নিয়ে কোড লেখা চালিয়ে যান

### নতুনদের জন্য মূল সুবিধাসমূহ

#### ১. 🔄 **আপনার প্রবাহ অবস্থা বজায় রাখুন**
- একাধিক অ্যাপ্লিকেশনের মধ্যে বারবার সোয়াচিং বন্ধ
- আপনি যেই কোড লিখছেন তার উপরে মনোযোগ রাখুন
- বিভিন্ন টুল পরিচালনার মানসিক চাপ কমান

#### ২. 🤖 **জটিল কমান্ডের পরিবর্তে প্রাকৃতিক ভাষা ব্যবহার করুন**
- SQL সিনট্যাক্স মুখস্থ করার পরিবর্তে ধরনের তথ্য আপনি চান তা বর্ণনা করুন
- Azure CLI কমান্ড মনে রাখার পরিবর্তে যা করতে চান তা ব্যাখ্যা করুন
- প্রযুক্তিগত বিবরণ AI কে দিয়ে দিন, আপনি লজিকে মনোযোগ দিন

#### ৩. 🔗 **একাধিক টুল একত্র করুন**
- বিভিন্ন সেবা মিশিয়ে শক্তিশালী ওয়ার্কফ্লো তৈরি করুন
- উদাহরণ: "সাম্প্রতিক সব GitHub ইস্যু নাও এবং সংশ্লিষ্ট Azure DevOps কাজ আইটেম তৈরি করো"
- জটিল স্ক্রিপ্ট না লিখেই অটোমেশান তৈরি করুন

#### ৪. 🌐 **বর্ধিত ইকোসিস্টেম অ্যাক্সেস করুন**
- Microsoft, GitHub, এবং অন্যান্য কোম্পানির তৈরি সার্ভার থেকে উপকৃত হোন
- বিভিন্ন বিক্রেতার টুলগুলো নির্বিঘ্নে মিলিয়ে নিন
- একটি স্ট্যান্ডার্ড ইকোসিস্টেমের অংশ হন যা বিভিন্ন AI সহকারীর সাথে কাজ করে

#### ৫. 🛠️ **করা শেখার মাধ্যমে শিখুন**
- ধাপে ধাপে প্রস্তুত সার্ভারগুলো দিয়ে ধারণা বোঝা শুরু করুন
- আরামদায়ক হওয়ার সাথে সাথে নিজের সার্ভার তৈরি করতে থাকুন
- উপলব্ধ SDK এবং ডকুমেন্টেশন ব্যবহার করে আপনার শেখার পথনির্দেশ করুন

### নতুনদের জন্য বাস্তব জীবনের উদাহরণ

ধরুন আপনি ওয়েব ডেভেলপমেন্টে নতুন এবং আপনার প্রথম প্রকল্পে কাজ করছেন। MCP সার্ভারগুলো কিভাবে সাহায্য করতে পারে তা এখানে:

**প্রথাগত পদ্ধতি:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP সার্ভার ব্যবহারে:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### এন্টারপ্রাইজ স্ট্যান্ডার্ড সুবিধা

- **সঙ্গতি**: বিভিন্ন টুল এবং কোম্পানির মধ্যে সাদৃশ্যপূর্ণ অভিজ্ঞতা
- **ইন্টারঅপারেবিলিটি**: বিভিন্ন বিক্রেতার সার্ভার একসাথে কাজ করে
- **ভবিষ্যতের জন্য প্রস্তুতি**: দক্ষতা এবং সেটআপ বিভিন্ন AI সহকারীর মধ্যে স্থানান্তরযোগ্য
- **কমিউনিটি**: ভাগ করা জ্ঞান এবং সম্পদের বড় ইকোসিস্টেম

## VS Code এবং Visual Studio তে MCP শুরু করা 🚀

আপনি যদি Visual Studio Code অথবা Visual Studio 2022 GitHub Copilot সহ ব্যবহার করেন তবে এই MCP সার্ভারগুলি সেটআপ করা সহজ।

### VS Code সেটআপ

VS Code এর জন্য মৌলিক প্রক্রিয়া হল:

1. **এজেন্ট মোড চালু করুন**: VS Code এ Copilot Chat উইন্ডোতে Agent মোড চালু করুন
2. **MCP সার্ভার কনফিগার করুন**: VS Code settings.json ফাইলে সার্ভার কনফিগারেশন যোগ করুন
3. **সার্ভার শুরু করুন**: আপনি যেই সার্ভার ব্যবহার করতে চান, তার জন্য "Start" বাটনে ক্লিক করুন
4. **টুল নির্বাচন করুন**: আপনার বর্তমান সেশনের জন্য কোন MCP সার্ভার চালু করবেন তা বেছে নিন

**বাস্তব জীবনের ব্যবহার**: "আমার Azure স্টোরেজ অ্যাকাউন্টের তালিকা দেখাও", "গত এক ঘন্টায় আমার Log Analytics ওয়ার্কস্পেসে ত্রুটি অনুসন্ধান করো", অথবা "Node.js ব্যবহার করে সঠিক প্রমাণীকরণসহ একটি Azure অ্যাপ তৈরি করতে সাহায্য করো"

**পূর্ণ ডেমো পরিস্থিতি**: এখানে একটি সম্পূর্ণ ওয়াকথ্রু রয়েছে যা Azure MCP এবং GitHub Copilot for Azure এক্সটেনশনকে VS Code এ একত্রিত করার ক্ষমতা প্রদর্শন করে। যখন আপনি দুটোই ইনস্টল করবেন এবং প্রম্পট করবেন:

> "একটি Python স্ক্রিপ্ট তৈরি কর যা DefaultAzureCredential প্রমাণীকরণ ব্যবহার করে Azure Blob Storage-এ একটি ফাইল আপলোড করে। স্ক্রিপ্টটি আমার 'mycompanystorage' নামক Azure স্টোরেজ অ্যাকাউন্টের সাথে সংযোগ করবে, 'documents' নামক কন্টেইনারে আপলোড করবে, আপলোড করার জন্য বর্তমান টাইমস্ট্যাম্প সহ একটি টেস্ট ফাইল তৈরি করবে, ত্রুটিগুলি সুন্দরভাবে হ্যান্ডল করবে এবং তথ্যবহুল আউটপুট প্রদান করবে, প্রমাণীকরণ ও ত্রুটি ব্যবস্থাপনার জন্য Azure-এর সর্বোত্তম পদ্ধতি অনুসরণ করবে, DefaultAzureCredential প্রমাণীকরণ কিভাবে কাজ করে তা ব্যাখ্যা করে মন্তব্য অন্তর্ভুক্ত করবে, এবং স্ক্রিপ্টটিকে সুষ্ঠুভাবে ফাংশন ও ডকুমেন্টেশন সহ গঠিত করবে।"

Azure MCP সার্ভার একটি পূর্ণাঙ্গ, প্রোডাকশন-রেডি Python স্ক্রিপ্ট তৈরি করবে যা:
- সর্বশেষ Azure Blob Storage SDK সঠিক অ্যাসিঙ্ক প্যাটার্ন ব্যবহার করে
- DefaultAzureCredential সম্পূর্ণ fallback চেইন ব্যাখাসহ প্রয়োগ করে
- নির্দিষ্ট Azure ব্যতিক্রম ধরনের সাথে শক্তিশালী ত্রুটি হ্যান্ডলিং অন্তর্ভুক্ত করে
- রিসোর্স ম্যানেজমেন্ট ও সংযোগ পরিচালনার জন্য Azure SDK এর সেরা অভ্যাস অনুসরণ করে
- বিস্তারিত লগিং এবং তথ্যবহুল কনসোল আউটপুট প্রদান করে
- ফাংশন, ডকুমেন্টেশন এবং টাইপ হিন্ট সহ সঠিকভাবে গঠিত স্ক্রিপ্ট তৈরি করে

এইটি বিশেষ কারণ এটি ছাড়া আপনি সাধারণ একটি ব্লব স্টোরেজ কোড পেতে পারেন যা কাজ করবে কিন্তু বর্তমান Azure প্যাটার্ন অনুসরণ করবে না। Azure MCP সহ আপনি এমন কোড পাবেন যা সর্বশেষ প্রমাণীকরণ পদ্ধতি ব্যবহার করে, Azure-নির্দিষ্ট ত্রুটি পরিস্থিতি হ্যান্ডল করে এবং মাইক্রোসফটের প্রোডাকশন অ্যাপ্লিকেশন ব্যবহারের সুপারিশকৃত পদ্ধতি অনুসরণ করে।

**বৈশিষ্ট্যযুক্ত উদাহরণ**: আমি কখনও কখনও `az` এবং `azd` CLI এর সুনির্দিষ্ট কমান্ডগুলো মনে রাখতে কষ্ট পাই। আমার জন্য এটি সবসময় দুই-ধাপের প্রক্রিয়া: প্রথমে সিনট্যাক্স খুঁজে বের করা, তারপর কমান্ড চালানো। আমি প্রায়ই পোর্টালে লগইন করে ম্যানুয়ালি কাজ করি কারণ CLI সিনট্যাক্স মনে রাখতে পারি না সেটা স্বীকার করতে চাই না। শুধু আমি যা চাই তা বর্ণনা করতে পারা চমৎকার, এবং আরো ভাল যখন তা করতে পারি IDE ছাড়াই!

[Azure MCP repository](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) এ শুরু করার জন্য দুর্দান্ত ইউজ কেস তালিকা রয়েছে। বিস্তৃত সেটআপ গাইড ও উন্নত কনফিগারেশন বিকল্পের জন্য দেখুন [অফিসিয়াল Azure MCP ডকুমেন্টেশন](https://learn.microsoft.com/azure/developer/azure-mcp-server/)।

### ৩. 🐙 GitHub MCP সার্ভার

[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**এটি কি করে**: অফিসিয়াল GitHub MCP সার্ভার GitHub এর পুরো ইকোসিস্টেমের সাথে নির্বিঘ্ন সংযোগ প্রদান করে, উভয় হোস্টেড রিমোট অ্যাক্সেস এবং লোকাল ডকার ডিপ্লয়মেন্ট অপশন সহ। এটি কেবল বেসিক রিপোজিটরি অপারেশন নয় – এটি একটি বিস্তৃত টুলকিট যা GitHub Actions ম্যানেজমেন্ট, পুল রিকোয়েস্ট ওয়ার্কফ্লো, ইস্যু ট্র্যাকিং, সিকিউরিটি স্ক্যানিং, বিজ্ঞপ্তি, এবং উন্নত অটোমেশন ক্ষমতা অন্তর্ভুক্ত করে।

**এটি কেন উপকারী**: এই সার্ভার GitHub ব্যবহার করার পদ্ধতি পরিবর্তন করে, পুরো প্ল্যাটফর্ম অভিজ্ঞতাকে সরাসরি আপনার উন্নয়ন পরিবেশে নিয়ে আসে। নিয়মিত VS Code এবং GitHub.com এর মধ্যে পরিবর্তন করার পরিবর্তে প্রকল্প ব্যবস্থাপনা, কোড পর্যালোচনা, ও CI/CD পর্যবেক্ষণ, আপনি প্রাকৃতিক ভাষার কমান্ডের মাধ্যমে সবকিছু পরিচালনা করতে পারেন এবং আপনার কোডে মনোযোগ রাখতে পারেন।

> **ℹ️ নোট: বিভিন্ন ধরণের 'এজেন্ট'**
> 
> এই GitHub MCP সার্ভারটিকে GitHub এর Coding Agent (যে AI এজেন্ট আপনি স্বয়ংক্রিয় কোডিং টাস্কের জন্য ইস্যু বরাদ্দ করতে পারেন) এর সাথে বিভ্রান্ত করবেন না। GitHub MCP সার্ভার VS Code এর এজেন্ট মোডে GitHub API ইন্টিগ্রেশন প্রদান করে, আর GitHub এর Coding Agent একটি আলাদা ফিচার যা GitHub ইস্যুতে বরাদ্দ পুল রিকোয়েস্ট তৈরি করে।

**মূল ক্ষমতাসমূহ অন্তর্ভুক্ত**:
- **⚙️ GitHub Actions**: সম্পূর্ণ CI/CD পাইপলাইন ম্যানেজমেন্ট, ওয়ার্কফ্লো পর্যবেক্ষণ, এবং আর্টিফ্যাক্ট পরিচালনা
- **🔀 পুল রিকোয়েস্ট**: তৈরি, পর্যালোচনা, মার্জ এবং ব্যাপক স্ট্যাটাস ট্র্যাকিং সহ PR ম্যানেজমেন্ট
- **🐛 ইস্যুসমূহ**: পূর্ণ ইস্যু লাইফসাইকেল ম্যানেজমেন্ট, মন্তব্য, লেবেলিং, এবং বরাদ্দ
- **🔒 সিকিউরিটি**: কোড স্ক্যানিং অ্যালার্ট, সিক্রেট সনাক্তকরণ, এবং Dependabot ইন্টিগ্রেশন
- **🔔 বিজ্ঞপ্তি**: স্মার্ট নোটিফিকেশন ম্যানেজমেন্ট এবং রিপোজিটরি সাবস্ক্রিপশন নিয়ন্ত্রণ
- **📁 রিপোজিটরি ম্যানেজমেন্ট**: ফাইল অপারেশন, ব্রাঞ্চ ম্যানেজমেন্ট, এবং রিপোজিটরি প্রশাসন
- **👥 সহযোগিতা**: ব্যবহারকারী ও সংস্থা অনুসন্ধান, দল ম্যানেজমেন্ট, এবং অ্যাক্সেস নিয়ন্ত্রণ

**বাস্তব জীবনের ব্যবহার**: "আমার ফিচার ব্রাঞ্চ থেকে একটি পুল রিকোয়েস্ট তৈরি করো", "আমার সব ব্যর্থ CI রান এই সপ্তাহে দেখাও", "আমার রিপোজিটরির জন্য সমস্ত সক্রিয় সিকিউরিটি অ্যালার্ট গুলো তালিকাভুক্ত করো", অথবা "আমার সমস্ত সংস্থায় আমার কাছে বরাদ্দকৃত ইস্যুগুলো খুঁজে বের করো"

**পূর্ণ ডেমো পরিস্থিতি**: এখানে একটি শক্তিশালী ওয়ার্কফ্লো যা GitHub MCP সার্ভারের ক্ষমতা প্রদর্শন করে:

> "আমাদের স্প্রিন্ট রিভিউ-এর জন্য প্রস্তুতি নিতে হবে। এই সপ্তাহে আমি যেসব পুল রিকোয়েস্ট তৈরি করেছি তা দেখাও, আমাদের CI/CD পাইপলাইনগুলোর অবস্থা পরীক্ষা করো, আমাদের সমাধান করতে হবে এমন কোন সিকিউরিটি অ্যালার্টের সংক্ষিপ্তসার তৈরি করো, এবং 'feature' লেবেলযুক্ত মার্জ করা PR থেকে রিলিজ নোট খসড়া করতে সাহায্য করো।"

GitHub MCP সার্ভার করবে:
- আপনার সাম্প্রতিক পুল রিকোয়েস্টগুলো বিস্তারিত স্ট্যাটাস সহ অনুসন্ধান করবে
- ওয়ার্কফ্লো রান বিশ্লেষণ করবে এবং কোনো ব্যর্থতা বা কর্মক্ষমতা সমস্যা হাইলাইট করবে
- সিকিউরিটি স্ক্যানিং ফলাফল সংগ্রহ করবে এবং গুরুত্বপূর্ন অ্যালার্টগুলো গুরুত্বের ক্রম অনুসারে সাজাবে
- মার্জ করা PR থেকে তথ্য বের করে বিস্তৃত রিলিজ নোট তৈরি করবে
- স্প্রিন্ট পরিকল্পনা এবং রিলিজ প্রস্তুতির জন্য কার্যকর পরবর্তী ধাপ প্রদান করবে

**বৈশিষ্ট্যযুক্ত উদাহরণ**: আমি কোড পর্যালোচনা ওয়ার্কফ্লোতে এটি ব্যবহার করতে পছন্দ করি। VS Code, GitHub নোটিফিকেশন ও পুল রিকোয়েস্ট পৃষ্ঠার মধ্যে বারবার যাওয়ার পরিবর্তে আমি বলতে পারি "আমার পর্যালোচনার অপেক্ষায় থাকা সব PR দেখাও" এবং তারপর "PR #123-এ মন্তব্য যোগ করো, প্রমাণীকরণ পদ্ধতির ত্রুটি পরিচালনা সম্পর্কে"। সার্ভার GitHub API কল করে, আলোচনার প্রসঙ্গ সংরক্ষণ করে, এবং আমাকে আরও গঠনমূলক রিভিউ মন্তব্য লিখতে সাহায্য করে।

**প্রমাণীকরণ বিকল্পসমূহ**: সার্ভার OAuth (VS Code-এ নির্বিঘ্ন) এবং Personal Access Token উভয়কেই সমর্থন করে, কনফিগারযোগ্য টুলসেটের মাধ্যমে শুধুমাত্র প্রয়োজনীয় GitHub কার্যকারিতাই সক্ষম করে। আপনি এটি রিমোট হোস্টেড সার্ভিস হিসেবে তবে তৎক্ষণাৎ সেটআপ করতে পারেন বা ডকারের মাধ্যমে লোকাল বিতরণ করে পূর্ণ নিয়ন্ত্রণ নিতে পারেন।

### ৫. 📝 MarkItDown MCP সার্ভার


[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_MarkItDown_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_MarkItDown_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/markitdown)

**এটি কী করে**: MarkItDown একটি বিস্তৃত ডকুমেন্ট রূপান্তর সার্ভার যা বিভিন্ন ফাইল ফরম্যাটকে উচ্চ-মানের মার্কডাউনে রূপান্তরিত করে, যেটি LLM ব্যবহারের জন্য এবং টেক্সট বিশ্লেষণ কাজের জন্য অপ্টিমাইজ করা হয়েছে।

**এটি কেন উপযোগী**: আধুনিক ডকুমেন্টেশন ওয়ার্কফ্লোর জন্য অপরিহার্য! MarkItDown অসংখ্য ফাইল ফরম্যাট সামলায় একই সময়ে গুরুত্বপূর্ণ ডকুমেন্ট কাঠামো যেমন শিরোনাম, তালিকা, টেবিল, এবং লিঙ্ক সংরক্ষণ করে। সাধারণ টেক্সট এক্সট্রাকশন টুলের মতো নয়, এটি অর্থবোধ এবং ফরম্যাটিং বজায় রাখার উপর ফোকাস করে যা AI প্রক্রিয়াকরণ এবং মানুষের পঠনযোগ্যতার জন্য মূল্যবান।

**সমর্থিত ফাইল ফরম্যাটগুলি**:
- **অফিস ডকুমেন্টস**: PDF, পাওয়ারপয়েন্ট (PPTX), ওয়ার্ড (DOCX), এক্সেল (XLSX/XLS)
- **মিডিয়া ফাইলস**: ছবি (EXIF মেটাডেটা এবং OCR সহ), অডিও (EXIF মেটাডেটা এবং স্পিচ ট্রান্সক্রিপশন সহ)
- **ওয়েব সামগ্রী**: HTML, RSS ফিড, ইউটিউব URL, উইকিপিডিয়া পেজ
- **ডেটা ফরম্যাটস**: CSV, JSON, XML, ZIP ফাইল (বহুগুণে বিষয়বস্তু প্রক্রিয়াকরণ)
- **পাবলিশিং ফরম্যাটস**: EPub, জুপিটার নোটবুক (.ipynb)
- **ইমেইল**: Outlook মেসেজ (.msg)
- **অ্যাডভান্সড**: উন্নত PDF প্রক্রিয়াকরণের জন্য Azure Document Intelligence ইন্টিগ্রেশন

**অ্যাডভান্সড ক্ষমতা**: MarkItDown LLM চালিত ইমেজ বর্ণনা (যখন OpenAI ক্লায়েন্ট সরবরাহ করা হয়), উন্নত PDF প্রক্রিয়াকরণের জন্য Azure Document Intelligence, স্পিচ কনটেন্টের জন্য অডিও ট্রান্সক্রিপশন, এবং অতিরিক্ত ফাইল ফরম্যাট সম্প্রসারণের জন্য প্লাগইন সিস্টেম সমর্থন করে।

**বাস্তব জীবনের ব্যবহার**: "আমাদের ডকুমেন্টেশন সাইটের জন্য এই পাওয়ারপয়েন্ট প্রেজেন্টেশনটি মার্কডাউনে রূপান্তর করুন", "এই PDF থেকে সঠিক শিরোনাম কাঠামো সহ টেক্সট এক্সট্রাক্ট করুন", বা "এই এক্সেল স্প্রেডশীটকে একটি পাঠযোগ্য টেবিল ফরম্যাটে রূপান্তর করুন"

**বৈশিষ্ট্যযুক্ত উদাহরণ**: [MarkItDown ডকুমেন্টস](https://github.com/microsoft/markitdown#why-markdown) থেকে উদ্ধৃত:

> মার্কডাউন প্রায় পুরোপুরি প্লেইন টেক্সটের মতো, খুবই কম মার্কআপ বা ফরম্যাটিং নিয়ে, কিন্তু এখনও গুরুত্বপূর্ণ ডকুমেন্ট কাঠামো উপস্থাপনের পথ দেয়। প্রধানধারার LLM, যেমন OpenAI এর GPT-4o, নেটিভলি "মার্কডাউন" ভাষায় কথা বলে, এবং প্রায়ই অনিচ্ছাকৃতভাবেই তাদের উত্তরগুলোতে মার্কডাউন জুড়ে দেয়। এটি নির্দেশ করে যে তারা বিপুল পরিমাণ মার্কডাউন-ফরম্যাটেড টেক্সটের ওপর প্রশিক্ষিত এবং এটিকে ভালভাবে বুঝতে পারে। এছাড়াও, মার্কডাউন নিয়মাবলী অত্যন্ত টোকেন-দক্ষ।

MarkItDown ডকুমেন্ট কাঠামো সংরক্ষণে খুবই দক্ষ, যা AI ওয়ার্কফ্লোর জন্য গুরুত্বপূর্ণ। উদাহরণস্বরূপ, একটি পাওয়ারপয়েন্ট প্রেজেন্টেশন রূপান্তর করার সময়, এটি স্লাইড সংগঠন ঠিকমতো শিরোনাম সহ রাখে, টেবিলগুলোকে মার্কডাউন টেবিলে রূপান্তর করে, ছবিগুলোর জন্য অল্ট টেক্সট অন্তর্ভুক্ত করে, এবং স্পিকার নোটস পর্যন্ত প্রক্রিয়াকরণ করে। চার্টগুলোকে পাঠযোগ্য ডেটা টেবিলে রূপান্তরিত করে, এবং ফলস্বরূপ মার্কডাউন মূল উপস্থাপনার যুক্তিসংগত প্রবাহ বজায় রাখে। এটি AI সিস্টেমে উপস্থাপনা সামগ্রী সরবরাহ বা বিদ্যমান স্লাইড থেকে ডকুমেন্টেশন তৈরির জন্য একদম উপযুক্ত।

**এটি কেন উপযোগী**: PostgreSQL সার্ভারের মতোই, তবে Microsoft SQL ইকোসিস্টেমের জন্য। সহজ একটি কানেকশন স্ট্রিং দিয়ে সংযোগ স্থাপন করুন এবং প্রাকৃতিক ভাষায় প্রশ্ন শুরু করুন – আর অন্যান্য প্রসঙ্গ পরিবর্তনের দরকার নেই!

**বাস্তব জীবনের ব্যবহার**: "গত ৩০ দিনে যে সব অর্ডার গৃহীত হয়নি তা খুঁজুন" এই প্রশ্নটি সঠিক SQL কোয়েরিতে রূপান্তরিত হয় এবং ফরম্যাট করা ফলাফল প্রদান করে

**বৈশিষ্ট্যযুক্ত উদাহরণ**: একবার আপনার ডেটাবেস কানেকশন সেটআপ করলে, আপনি সাথে সাথেই আপনার ডেটার সাথে কথোপকথন শুরু করতে পারেন। ব্লগ পোস্টে একটি সহজ প্রশ্ন দেখানো হয়েছে: "আপনি কোন ডেটাবেসে সংযুক্ত?" MCP সার্ভার মানানসই ডেটাবেস টুলটি ডেকে এনে আপনার SQL সার্ভারের ইনস্ট্যান্সের সাথে সংযোগ স্থাপন করে এবং আপনার বর্তমান ডেটাবেস সংযোগের বিবরণ প্রদান করে – এক লাইন SQL কোড না লিখেই। সার্ভার স্কিমা ম্যানেজমেন্ট থেকে ডেটা পরিবর্তন পর্যন্ত ব্যাপক ডেটাবেস অপারেশন সমর্থন করে, সবই প্রাকৃতিক ভাষার প্রম্পটের মাধ্যমে। সম্পূর্ণ সেটআপ নির্দেশিকা এবং VS Code ও Claude Desktop এর কনফিগারেশন উদাহরণ জানতে দেখুন: [Introducing MSSQL MCP Server (Preview)](https://devblogs.microsoft.com/azure-sql/introducing-mssql-mcp-server/)।

**কেন এটি উপকারী**: এই সার্ভারটি আজুর AI পরিষেবাগুলোর সাথে কাজ করার পদ্ধতিকে রূপান্তরিত করে, ব্যবসায়িক মানের AI ক্ষমতাগুলো সরাসরি আপনার ডেভেলপমেন্ট ওয়ার্কফ্লো এ নিয়ে আসে। আজুর পোর্টাল, ডকুমেন্টেশন এবং আপনার আইডিই এর মধ্যে বার বার স্যুইচ করার পরিবর্তে, আপনি মডেল আবিষ্কার করতে, পরিষেবা মোতায়েন করতে, জ্ঞানভিত্তি পরিচালনা করতে এবং প্রাকৃতিক ভাষার কমান্ডের মাধ্যমে AI পারফরম্যান্স মূল্যায়ন করতে পারবেন। এটি বিশেষত শক্তিশালী RAG (রিট্রিভাল-অগমেন্টেড জেনারেশন) অ্যাপ্লিকেশন তৈরি করা, বহু-মডেল মোতায়েন পরিচালনা করা, বা ব্যাপক AI মূল্যায়ন পাইপলাইন বাস্তবায়নের জন্য।

**বাস্তব ডেভেলপার ব্যবহার**: "আমার অ্যাপ্লিকেশনের জন্য Phi-4 মডেলটিকে আজুর AI পরিষেবায় মোতায়েন করুন", "আমার ডকুমেন্টেশন RAG সিস্টেমের জন্য একটি নতুন সার্চ ইনডেক্স তৈরি করুন", "আমার এজেন্টের প্রতিক্রিয়াগুলো গুণমানের মেট্রিক্সের বিরুদ্ধে মূল্যায়ন করুন", অথবা "আমার জটিল বিশ্লেষণ কাজের জন্য সেরা রিজনিং মডেলটি খুঁজে বের করুন"

**সম্পূর্ণ ডেমো পরিস্থিতি**: এখানে একটি শক্তিশালী AI ডেভেলপমেন্ট ওয়ার্কফ্লো:

> "আমি একটি কাস্টমার সাপোর্ট এজেন্ট নির্মাণ করছি। আমার জন্য ক্যাটালগ থেকে একটি ভালো রিজনিং মডেল খুঁজে দিতে সাহায্য করুন, এটিকে আজুর AI পরিষেবায় মোতায়েন করুন, আমাদের ডকুমেন্টেশন থেকে একটি জ্ঞানভিত্তি তৈরি করুন, প্রতিক্রিয়া গুণমান পরীক্ষা করার জন্য একটি মূল্যায়ন ফ্রেমওয়ার্ক সেট আপ করুন, এরপর GitHub টোকেন দিয়ে একত্রকরণের প্রোটোটাইপ তৈরিতে সাহায্য করুন।"

মাইক্রোসফ্ট ফাউন্ড্রি MCP সার্ভারটি করবে:
- আপনার প্রয়োজন অনুযায়ী সর্বোত্তম রিজনিং মডেল সুপারিশের জন্য মডেল ক্যাটালগ প্রশ্ন করবে
- আপনার পছন্দসই আজুর অঞ্চলের জন্য মোতায়েন কমান্ড এবং কোটা তথ্য প্রদান করবে
- আপনার ডকুমেন্টেশনের জন্য সঠিক স্কিমা সহ আজুর AI সার্চ ইনডেক্স সেট আপ করবে
- গুণগত মানের মেট্রিক্স এবং নিরাপত্তা পরীক্ষা সহ মূল্যায়ন পাইপলাইন কনফিগার করবে
- তাত্ক্ষণিক পরীক্ষার জন্য GitHub প্রমাণীকরণ সহ প্রোটোটাইপিং কোড তৈরি করবে
- আপনার নির্দিষ্ট প্রযুক্তি স্ট্যাকের জন্য বিস্তৃত সেটআপ নির্দেশিকা প্রদান করবে

**বিশিষ্ট উদাহরণ**: একজন ডেভেলপার হিসেবে, আমি বিভিন্ন LLM মডেল সম্পর্কে বুঝতে কষ্ট পাচ্ছিলাম। আমি কয়েকটি প্রধান মডেল জানি, কিন্তু মনে হচ্ছিল কিছু উৎপাদনশীলতা এবং দক্ষতা বাড়ানোর সুযোগ হারাচ্ছি। টোকেন এবং কোটা পরিচালনা করা চাপের এবং কঠিন – কখনো জানি না আমি সঠিক কাজের জন্য সঠিক মডেল বেছে নিচ্ছি কিনা বা বাজেট অকার্যকরভাবে শেষ করছি কিনা। সম্প্রতি আমি James Montemagno থেকে এই MCP সার্ভার সম্পর্কে শুনেছি যখন কিছু সহকর্মীর সাথে MCP সার্ভার পরামর্শ নিচ্ছিলাম, এবং আমি এটি ব্যবহারের জন্য উচ্ছ্বসিত! মডেল আবিষ্কারের ক্ষমতাগুলো বিশেষভাবে আমার মতো কারো জন্য আকর্ষণীয় যিনি সাধারণ মডেলের বাইরে অনুসন্ধান করতে চান এবং নির্দিষ্ট কাজের জন্য উন্নত মডেল খুঁজছেন। মূল্যায়ন ফ্রেমওয়ার্ক আমাকে নিশ্চিত করতে সাহায্য করবে যে আমি সত্যিই উন্নত ফল পাচ্ছি, শুধুমাত্র নতুন কিছু চেষ্টা করার জন্য নয়।

> **ℹ️ পরীক্ষামূলক অবস্থা**
> 
> এই MCP সার্ভার পরীক্ষামূলক এবং সক্রিয় উন্নয়নের অধীনে রয়েছে। ফিচার এবং API পরিবর্তিত হতে পারে। আজুর AI ক্ষমতাগুলি অন্বেষণ করার এবং প্রোটোটাইপ তৈরি করার জন্য উপযুক্ত, কিন্তু প্রোডাকশন ব্যবহারের জন্য স্থিতিশীলতার প্রয়োজনীয়তাগুলো যাচাই করুন।

**কেন এটি উপকারী**: Microsoft 365 এবং Copilot এর জন্য তৈরি করা জটিল ম্যানিফেস্ট স্কিমা এবং নির্দিষ্ট ডেভেলপমেন্ট প্যাটার্ন প্রয়োজন। এই MCP সার্ভারটি আপনার কোডিং পরিবেশে প্রয়োজনীয় ডেভেলপমেন্ট সম্পদ সরাসরি নিয়ে আসে, যা আপনাকে স্কিমা যাচাই করতে, নমুনা কোড খুঁজে পেতে এবং সাধারণ সমস্যা সমাধান করতে সাহায্য করে, বার বার ডকুমেন্টেশন দেখে ক্লান্ত না হয়ে।

**বিশিষ্ট উদাহরণ**: Build এ M365 Agents নিয়ে আলাপ করে আমি আমার বন্ধু John Miller এর সাথে যোগাযোগ করেছিলাম, তিনি এই MCP সুপারিশ করেছেন। যারা M365 Agents এ নতুন, তাদের জন্য এটি দুর্দান্ত হতে পারে কারণ এটি টেমপ্লেট, নমুনা কোড এবং স্ক্যাফোল্ড প্রদান করে যা ডকুমেন্টেশনে ডুবে না থেকে শুরু করতে সাহায্য করে। স্কিমা যাচাই ফিচারগুলো বিশেষভাবে উপকারী দেখাচ্ছে ম্যানিফেস্ট স্ট্রাকচার ত্রুটি এড়াতে যা ঘণ্টার পর ঘণ্টার ডিবাগিং ঘটাতে পারে।

## 📋 উপসংহার

মডেল কনটেক্সট প্রোটোকল (MCP) ডেভেলপারদের AI সহকারী এবং বাহ্যিক সরঞ্জামের সাথে ইন্টারঅ্যাক্ট করার পদ্ধতিকে রূপান্তরিত করছে। এই ১০টি মাইক্রোসফ্ট MCP সার্ভার মানসম্মত AI ইন্টিগ্রেশনের শক্তি প্রদর্শন করে, যা ডেভেলপারদের প্রবাহ অবস্থা বজায় রেখে শক্তিশালী বাহ্যিক ক্ষমতাগুলো অ্যাক্সেস করার জন্য নিরবচ্ছিন্ন ওয়ার্কফ্লো তৈরি করে।

ব্যাপক আজুর ইকোসিস্টেম ইন্টিগ্রেশন থেকে শুরু করে Playwright এর মতো বিশেষায়িত টুল (ব্রাউজার অটোমেশন) এবং MarkItDown (ডকুমেন্ট প্রসেসিং)-এর মতো সরঞ্জাম পর্যন্ত, এই সার্ভারগুলো দেখায় কিভাবে MCP বিভিন্ন ডেভেলপমেন্ট পরিস্থিতিতে উৎপাদনশীলতা বাড়াতে পারে। মানসম্মত প্রোটোকল নিশ্চিত করে যে এই টুলগুলো একত্রে নির্বিঘ্নে কাজ করে, একটি সুসংহত ডেভেলপমেন্ট অভিজ্ঞতা তৈরি করে।

MCP ইকোসিস্টেম যেমন উন্নীত হচ্ছে, কমিউনিটির সাথে সংযুক্ত থাকা, নতুন সার্ভার অন্বেষণ করা, এবং কাস্টম সমাধান নির্মাণ করা উন্নয়নশীল উৎপাদনশীলতা সর্বাধিককরণের জন্য গুরুত্বপূর্ণ হবে। MCP এর ওপেন স্ট্যান্ডার্ড প্রকৃতির জন্য, আপনি বিভিন্ন বিক্রেতার টুল মিশ্রিত করে আপনার নির্দিষ্ট প্রয়োজনের জন্য সর্বোত্তম ওয়ার্কফ্লো তৈরি করতে পারবেন।

২. **ওয়ার্কফ্লো ইন্টিগ্রেশন**: অন্তত তিনটি ভিন্ন MCP সার্ভার মিশিয়ে একটি ডেভেলপমেন্ট ওয়ার্কফ্লো ডিজাইন করুন।
৩. **কাস্টম সার্ভার পরিকল্পনা**: আপনার দৈনন্দিন ডেভেলপমেন্ট রুটিনের একটি কাজ চিহ্নিত করুন যা একটি কাস্টম MCP সার্ভার দ্বারা উন্নত হতে পারে এবং এর স্পেসিফিকেশন তৈরি করুন।
৪. **পারফরম্যান্স বিশ্লেষণ**: সাধারণ ডেভেলপমেন্ট কাজের জন্য MCP সার্ভার ব্যবহার এবং ঐতিহ্যবাহী পদ্ধতির কার্যকারিতার তুলনা করুন।
৫. **নিরাপত্তা মূল্যায়ন**: আপনার ডেভেলপমেন্ট পরিবেশে MCP সার্ভার ব্যবহারের নিরাপত্তা প্রভাব মূল্যায়ন করুন এবং সেরা অনুশীলন প্রস্তাব করুন।
