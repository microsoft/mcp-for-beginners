# ক্যালকুলেটর LLM ক্লায়েন্ট

> [!NOTE]
> এই সমাধানটি কোর্সের লেগ্যাসি HTTP+SSE ক্যালকুলেটর সার্ভিসের সাথে সংযুক্ত হয় এবং
> MCP `2025-11-25` SDK API লক্ষ্য করে। এটি একটি `2026-07-28` স্ট্রিমেবল HTTP
> উদাহরণ নয়।

একটি জাভা অ্যাপ্লিকেশন যা LangChain4j ব্যবহার করে MCP (মডেল কনটেক্সট প্রোটোকল) ক্যালকুলেটর সার্ভিসের সাথে MiniMax OpenAI-অনুকূলে API মাধ্যমে সংযুক্ত হওয়ার উপায় প্রদর্শন করে।

## পূর্বপ্রয়োজনীয়তা

- জাভা ২১ বা তার উপরে
- মেভেন ৩.৬+ (অথবা অন্তর্ভুক্ত Maven র্যাপার ব্যবহার করুন)
- একটি MiniMax API কী
- `http://localhost:8080` এ চলমান MCP ক্যালকুলেটর সার্ভিস

## API কী পাওয়া

এই অ্যাপ্লিকেশনটি MiniMax OpenAI-অনুকূলে API ব্যবহার করে। আপনার কী এবং এন্ডপয়েন্ট পেতে নিম্নলিখিত ধাপগুলি অনুসরণ করুন:

### ১। একটি এন্ডপয়েন্ট নির্বাচন করুন
১। বিশ্বব্যাপী এন্ডপয়েন্টের জন্য `https://api.minimax.io/v1` ব্যবহার করুন
২। চীন এন্ডপয়েন্টের জন্য `https://api.minimaxi.com/v1` ব্যবহার করুন

### ২। একটি API কী তৈরি করুন
১। আপনার MiniMax অ্যাকাউন্ট থেকে একটি MiniMax API কী তৈরি করুন
২। কীটি নিরাপদ স্থানে রাখুন

### ৩। পরিবেশ ভেরিয়েবল সেট করুন

#### উইন্ডোজ এ (কমান্ড প্রম্পট):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### উইন্ডোজ এ (পাওয়ারশেল):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### ম্যাকওএস/লিনাক্স এ:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## সেটআপ এবং ইনস্টলেশন

১। **প্রকল্প ডিরেক্টরিতে ক্লোন অথবা নেভিগেট করুন**

২। **ডিপেনডেন্সি ইনস্টল করুন**:
   ```cmd
   mvnw clean install
   ```
   অথবা যদি আপনার মেভেন গ্লোবালি ইনস্টল থাকে:
   ```cmd
   mvn clean install
   ```

৩। **পরিবেশ ভেরিয়েবল সেট করুন** (উপরের "API কী পাওয়া" সেকশন দেখুন)

৪। **MCP ক্যালকুলেটর সার্ভিস চালু করুন**:
   নিশ্চিত করুন যে অধ্যায় ১ এর MCP ক্যালকুলেটর সার্ভিস `http://localhost:8080/sse` এ চলছে। ক্লায়েন্ট শুরু করার আগে এটি চালু থাকতে হবে।

## অ্যাপ্লিকেশন চালানো

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## অ্যাপ্লিকেশন কী করে

অ্যাপ্লিকেশনটি ক্যালকুলেটর সার্ভিসের সাথে তিনটি প্রধান ইন্টারঅ্যাকশন প্রদর্শন করে:

১। **যোগ**: ২৪.৫ এবং ১৭.৩ এর যোগফল হিসাব করে
২। **বর্গমূল**: ১৪৪ এর বর্গমূল হিসাব করে
৩। **সাহায্য**: পাওয়া যায় এমন ক্যালকুলেটর ফাংশনগুলো দেখায়

## প্রত্যাশিত আউটপুট

সফলভাবে চলার সময়, আপনি নিম্নলিখিত আউটপুট দেখতে পাবেন:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## সমস্যা সমাধান

### সাধারণ সমস্যা

১। **"OPENAI_API_KEY পরিবেশ ভেরিয়েবল সেট করা হয়নি"**
   - নিশ্চিত করুন আপনি `OPENAI_API_KEY` পরিবেশ ভেরিয়েবল সেট করেছেন
   - ভেরিয়েবল সেট করার পর টার্মিনাল/কমান্ড প্রম্পট পুনরায় চালু করুন

২। **"localhost:8080 এ সংযোগ প্রত্যাখ্যাত"**
   - নিশ্চিত করুন MCP ক্যালকুলেটর সার্ভিস পোর্ট ৮০৮০ এ চলছে
   - পরীক্ষা করুন অন্য কোনো সার্ভিস পোর্ট ৮০৮০ ব্যবহার করছে কিনা

৩। **"অথেনটিকেশন ব্যর্থ"**
   - নিশ্চিত করুন আপনার API কী বৈধ
   - পরীক্ষা করুন `OPENAI_BASE_URL` আপনি যে এন্ডপয়েন্ট ব্যবহার করতে চেয়েছিলেন তা মেলে কি না

৪। **Maven বিল্ড ত্রুটি**
   - নিশ্চিত করুন আপনি জাভা ২১ বা তার উপরের সংস্করণ ব্যবহার করছেন: `java -version`
   - বিল্ড পরিষ্কার করার চেষ্টা করুন: `mvnw clean`

### ডিবাগিং

ডিবাগ লগিং সক্ষম করতে, চালানোর সময় নিম্নলিখিত JVM আর্গুমেন্ট যুক্ত করুন:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## কনফিগারেশন

অ্যাপ্লিকেশনটি কনফিগার করা হয়েছে:
- ডিফল্টে MiniMax-M3 ব্যবহার; `MINIMAX_MODEL_ID` সেট করে `MiniMax-M3` অথবা `MiniMax-M2.7` নির্বাচন করা যায়
- `OPENAI_BASE_URL` সেট থাকলে সেটায় সংযোগ করবে; অন্যথায় `MINIMAX_REGION=cn_zh` হলে `https://api.minimaxi.com/v1` অথবা ডিফল্টে `https://api.minimax.io/v1` ব্যবহার করবে
- MCP সার্ভিসে সংযোগ করবে `http://localhost:8080/sse` 
- অনুরোধের জন্য ৬০ সেকেন্ডের টাইমআউট ব্যবহার করবে
