# ক্যালকুলেটর এলএলএম ক্লায়েন্ট

একটি জাভা অ্যাপ্লিকেশন যা LangChain4j কীভাবে ব্যবহার করে MCP (মডেল কনটেক্সট প্রোটোকল) ক্যালকুলেটর সার্ভিসের সাথে MiniMax OpenAI-সঙ্গত API এর মাধ্যমে সংযোগ স্থাপন করা যায় তা প্রদর্শন করে।

## পূর্বশর্তসমূহ

- জাভা ২১ বা তার উপরের সংস্করণ
- মেভেন ৩.৬+ (অথবা অন্তর্ভুক্ত মেভেন র‍্যান্ডার ব্যবহার করুন)
- একটি MiniMax API কী
- একটি MCP ক্যালকুলেটর সার্ভিস যা `http://localhost:8080` এ চলমান

## API কী পাওয়া

এই অ্যাপ্লিকেশনটি MiniMax OpenAI-সঙ্গত API ব্যবহার করে। আপনার কী এবং এন্ডপয়েন্ট পাওয়ার জন্য নিম্নলিখিত ধাপগুলো অনুসরণ করুন:

### ১. একটি এন্ডপয়েন্ট বেছে নিন
১. গ্লোবাল এন্ডপয়েন্টের জন্য `https://api.minimax.io/v1` ব্যবহার করুন
২. চীন এন্ডপয়েন্টের জন্য `https://api.minimaxi.com/v1` ব্যবহার করুন

### ২. একটি API কী তৈরি করুন
১. আপনার MiniMax একাউন্ট থেকে একটি MiniMax API কী তৈরি করুন
২. কীটি নিরাপদ স্থানে রাখুন

### ৩. পরিবেশ ভেরিয়েবল সেট করুন

#### উইন্ডোজে (কমান্ড প্রম্পট):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### উইন্ডোজে (পাওয়ারশেল):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### ম্যাকওএস/লিনাক্সে:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## সেটআপ এবং ইনস্টলেশন

১. **প্রকল্পের ডিরেক্টরিটি ক্লোন করুন বা সেখানে যান**

২. **ডিপেন্ডেন্সি ইনস্টল করুন**:
   ```cmd
   mvnw clean install
   ```
   অথবা যদি আপনার মেভেন গ্লোবালি ইনস্টল করা থাকে:
   ```cmd
   mvn clean install
   ```

৩. **পরিবেশ ভেরিয়েবল সেট করুন** (উপরের "API কী পাওয়া" অংশ দেখুন)

৪. **MCP ক্যালকুলেটর সার্ভিস চালু করুন**:
   নিশ্চিত করুন যে আপনি অধ্যায় ১ এর MCP ক্যালকুলেটর সার্ভিস `http://localhost:8080/sse` এ চালু রেখেছেন। ক্লায়েন্ট শুরু করার আগে এটি চালু থাকা উচিত।

## অ্যাপ্লিকেশন চালানো

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## অ্যাপ্লিকেশন কি করে

অ্যাপ্লিকেশনটি ক্যালকুলেটর সার্ভিসের সাথে তিনটি প্রধান ইন্টারঅ্যাকশন প্রদর্শন করে:

১. **যোগফল**: ২৪.৫ এবং ১৭.৩ এর যোগফল হিসাব করা
২. **বর্গমূল**: ১৪৪ এর বর্গমূল হিসাব করা
৩. **সাহায্য**: উপলব্ধ ক্যালকুলেটর ফাংশনগুলি দেখানো

## প্রত্যাশিত আউটপুট

সফলভাবে চালানোর পরে আপনি নিম্নরূপ আউটপুট দেখতে পাবেন:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## সমস্যার সমাধান

### সাধারণ সমস্যাসমূহ

১. **"OPENAI_API_KEY পরিবেশ ভেরিয়েবল সেট করা হয়নি"**
   - নিশ্চিত করুন আপনি `OPENAI_API_KEY` পরিবেশ ভেরিয়েবল সেট করেছেন
   - ভেরিয়েবল সেট করার পর আপনার টার্মিনাল/কমান্ড প্রম্পট পুনরায় চালু করুন

২. **"localhost:8080 এ সংযোগ অস্বীকৃত হয়েছে"**
   - নিশ্চিত করুন MCP ক্যালকুলেটর সার্ভিস ৮০৮০ পোর্টে চলছে
   - পরীক্ষা করুন অন্য কোন সার্ভিস ৮০৮০ পোর্ট ব্যবহার করছে কি না

৩. **"প্রমাণীকরণ ব্যর্থ হয়েছে"**
   - আপনার API কী বৈধ কিনা যাচাই করুন
   - দেখুন `OPENAI_BASE_URL` আপনি যে এন্ডপয়েন্ট ব্যবহার করতে চেয়েছিলেন তা মেলে কিনা

৪. **মেভেন বিল্ড ত্রুটি**
   - নিশ্চিত করুন আপনি জাভা ২১ বা তার উপরের সংস্করণ ব্যবহার করছেন: `java -version`
   - বিল্ড পরিষ্কার করার চেষ্টা করুন: `mvnw clean`

### ডিবাগিং

ডিবাগ লগ সক্রিয় করতে, চালানোর সময় নিচের JVM আর্গুমেন্টটি যোগ করুন:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## কনফিগারেশন

অ্যাপ্লিকেশনটি কনফিগার করা হয়েছে:
- ডিফল্ট হিসেবে MiniMax-M3 ব্যবহার করে, অথবা যখন `MINIMAX_MODEL_ID` সেট থাকে তখন MiniMax-M2.7
- `OPENAI_BASE_URL` সেট থাকলে এটিতে সংযোগ স্থাপন করে; অন্যথায় `MINIMAX_REGION=cn_zh` হলে `https://api.minimaxi.com/v1` অথবা ডিফল্টে `https://api.minimax.io/v1` ব্যবহার করে
- MCP সার্ভিসের সাথে `http://localhost:8080/sse` এ সংযোগ স্থাপন করে
- অনুরোধগুলির জন্য ৬০ সেকেন্ড টাইমআউট ব্যবহার করে
