# ক্যালকুলেটর LLM ক্লায়েন্ট

একটি জাভা অ্যাপ্লিকেশন যা দেখায় কিভাবে LangChain4j ব্যবহার করে MCP (মডেল কনটেক্সট প্রোটোকল) ক্যালকুলেটর সার্ভিসের সাথে MiniMax OpenAI-সঙ্গত API মাধ্যমে সংযোগ করা যায়।

## পূর্ববর্তী প্রয়োজনীয়তা

- জাভা ২১ বা তার উপরে
- মেভেন ৩.৬+ (অথবা অন্তর্ভুক্ত মেভেন র‍্যাপার ব্যবহার করুন)
- একটি MiniMax API কী
- `http://localhost:8080` এ চলমান একটি MCP ক্যালকুলেটর সার্ভিস

## API কী পাওয়া

এই অ্যাপ্লিকেশনটি MiniMax OpenAI-সঙ্গত API ব্যবহার করে। আপনার কী এবং এন্ডপয়েন্ট পেতে এই ধাপগুলি অনুসরণ করুন:

### ১. একটি এন্ডপয়েন্ট নির্বাচন করুন
১. গ্লোবাল এন্ডপয়েন্টের জন্য `https://api.minimax.io/v1` ব্যবহার করুন
২. চীনা এন্ডপয়েন্টের জন্য `https://api.minimaxi.com/v1` ব্যবহার করুন

### ২. একটি API কী তৈরি করুন
১. আপনার MiniMax অ্যাকাউন্ট থেকে একটি MiniMax API কী তৈরি করুন
২. কীটি নিরাপদে কোথাও সংরক্ষণ করুন

### ৩. পরিবেশ পরিবর্তনশীলগুলি সেট করুন

#### উইন্ডোজে (কমান্ড প্রম্পট):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### উইন্ডোজে (PowerShell):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### macOS/Linux-এ:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## সেটআপ এবং ইনস্টলেশন

১. **প্রজেক্ট ডিরেক্টরিতে ক্লোন করুন অথবা নেভিগেট করুন**

২. **ডিপেন্ডেন্সি ইনস্টল করুন**:
   ```cmd
   mvnw clean install
   ```
   অথবা যদি আপনার মেভেন গ্লোবালি ইনস্টল থাকে:
   ```cmd
   mvn clean install
   ```

৩. **পরিবেশ পরিবর্তনশীলগুলি সেট করুন** (উপরের "API কী পাওয়া" অংশ দেখুন)

৪. **MCP ক্যালকুলেটর সার্ভিস চালু করুন**:
   নিশ্চিত করুন যে আপনি অধ্যায় ১ এর MCP ক্যালকুলেটর সার্ভিস `http://localhost:8080/sse` এ চালু রেখেছেন। ক্লায়েন্ট শুরু করার আগে এটি চালু থাকতে হবে।

## অ্যাপ্লিকেশন চালানো

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## অ্যাপ্লিকেশন কেমন কাজ করে

অ্যাপ্লিকেশন ক্যালকুলেটর সার্ভিসের সাথে তিনটি প্রধান পারস্পরিক ক্রিয়া প্রদর্শন করে:

১. **যোগ**: ২৪.৫ এবং ১৭.৩ এর যোগফল গণনা করে
২. **বর্গমূল**: ১৪৪ এর বর্গমূল গণনা করে
৩. **সহায়তা**: উপলব্ধ ক্যালকুলেটর ফাংশনগুলি প্রদর্শন করে

## প্রত্যাশিত আউটপুট

সফলভাবে চালানোর সময়, আপনি নিম্নলিখিত মত আউটপুট দেখতে পাবেন:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## সমস্যা সমাধান

### সাধারণ সমস্যা

১. **“OPENAI_API_KEY পরিবেশ পরিবর্তনশীল সেট করা হয়নি”**
   - নিশ্চিত করুন যে আপনি `OPENAI_API_KEY` পরিবেশ পরিবর্তনশীল সেট করেছেন
   - পরিবর্তনশীল সেট করার পর টার্মিনাল/কমান্ড প্রম্পট পুনরায় শুরু করুন

২. **“localhost:8080 এ সংযোগ প্রত্যাখ্যান”**
   - নিশ্চিত করুন MCP ক্যালকুলেটর সার্ভিস ৮০৮০ পোর্টে চলছে
   - দেখুন অন্য কোনো সার্ভিস ৮০৮০ পোর্ট ব্যবহার করছে কি না

৩. **“প্রমাণীকরণ ব্যর্থ”**
   - যাচাই করুন আপনার API কী সঠিক কিনা
   - নিশ্চিত করুন `OPENAI_BASE_URL` আপনি যে এন্ডপয়েন্ট ব্যবহার করতে চেয়েছেন সেটির সাথে মেলে

৪. **মেভেন বিল্ড ত্রুটি**
   - নিশ্চিত করুন আপনি জাভা ২১ বা তার উপরে ব্যবহার করছেন: `java -version`
   - বিল্ড পরিষ্কার করতে চেষ্টা করুন: `mvnw clean`

### ডিবাগিং

ডিবাগ লগিং সক্রিয় করতে, চালানোর সময় নিম্নলিখিত JVM আর্গুমেন্ট যোগ করুন:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## কনফিগারেশন

অ্যাপ্লিকেশন নিম্নলিখিত ভাবে কনফিগার করা হয়েছে:
- ডিফল্টরূপে MiniMax-M3 ব্যবহার করে; `MINIMAX_MODEL_ID` সেট করে `MiniMax-M3` অথবা `MiniMax-M2.7` নির্বাচন করুন
- যখন `OPENAI_BASE_URL` সেট থাকে তখন তা ব্যবহার করে; অন্যথায় `MINIMAX_REGION=cn_zh` হলে `https://api.minimaxi.com/v1` অথবা ডিফল্টরূপে `https://api.minimax.io/v1` ব্যবহার করে
- MCP সার্ভিসের সাথে `http://localhost:8080/sse` এ সংযোগ স্থাপন করে
- অনুরোধের জন্য ৬০ সেকেন্ড টাইমআউট ব্যবহার করে
