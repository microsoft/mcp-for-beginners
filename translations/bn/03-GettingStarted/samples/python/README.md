# MCP ক্যালকুলেটর সার্ভার (পাইথন)



পাইথনে একটি সহজ মডেল কন্টেক্সট প্রোটোকল (MCP) সার্ভার ইমপ্লিমেন্টেশন যা বেসিক ক্যালকুলেটর ফাংশনালিটি প্রদান করে।


## ইনস্টলেশন

প্রয়োজনীয় ডিপেন্ডেন্সিগুলো ইনস্টল করুন:

```bash
pip install -r requirements.txt
```

অথবা সরাসরি MCP পাইথন SDK ইনস্টল করুন:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## ব্যবহার

### সার্ভার চালানো

সার্ভারটি MCP ক্লায়েন্টরা (যেমন Claude Desktop) ব্যবহার করার জন্য ডিজাইন করা হয়েছে। সার্ভার চালু করতে:

```bash
python mcp_calculator_server.py
```

**টিপ**: সরাসরি টার্মিনালে চালালে, আপনি JSON-RPC ভ্যালিডেশন এরর দেখতে পাবেন। এটি স্বাভাবিক আচরণ—সার্ভার সঠিকভাবে ফরম্যাট করা MCP ক্লায়েন্ট মেসেজের জন্য অপেক্ষা করছে।

### ফাংশনগুলো পরীক্ষা করা

ক্যালকুলেটর ফাংশনগুলো সঠিকভাবে কাজ করছে কিনা পরীক্ষা করতে:

```bash
python test_calculator.py
```

## সমস্যা সমাধান

### ইমপোর্ট ত্রুটি

যদি আপনি দেখতে পান `ModuleNotFoundError: No module named 'mcp'`, তাহলে MCP পাইথন SDK ইনস্টল করুন:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### সরাসরি চালানোর সময় JSON-RPC ত্রুটি

সার্ভার সরাসরি চালানোর সময় "Invalid JSON: EOF while parsing a value" এর মতো ত্রুটিগুলো আশা করা যায়। সার্ভারকে MCP ক্লায়েন্ট মেসেজের প্রয়োজন, সরাসরি টার্মিনাল ইনপুটের নয়।
