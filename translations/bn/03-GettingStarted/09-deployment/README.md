# MCP সার্ভার ডিপ্লয়মেন্ট করা

> [!NOTE]
> কনফিগারেশন উদাহরণসমূহ যা একটি `/sse` এন্ডপয়েন্ট ব্যবহার করে, সেগুলো লিগ্যাসি HTTP+SSE ট্রান্সপোর্ট লক্ষ্য করে। MCP `2026-07-28` রিমোট সার্ভারগুলো সাধারণত সার্ভার-পরিচালিত এন্ডপয়েন্ট যেমন `/mcp` এ স্ট্রিমেবল HTTP ব্যবহার করে।
> 
>

আপনার MCP সার্ভার ডিপ্লয়মেন্ট করলে অন্যরা আপনার লোকাল পরিবেশ ছাড়িয়ে এর টুলস ও রিসোর্সসমূহ অ্যাক্সেস করতে পারবে। বিভিন্ন ডিপ্লয়মেন্ট কৌশল বিবেচনা করা যেতে পারে আপনার স্কেলেবিলিটি, নির্ভরযোগ্যতা এবং পরিচালনার সহজতার প্রয়োজন অনুসারে। নিচে MCP সার্ভার লোকালি, কন্টেইনারে এবং ক্লাউডে ডিপ্লয় করার নির্দেশিকা দেওয়া আছে।

## ওভারভিউ

এই লেসনে আপনি শিখবেন কীভাবে MCP সার্ভার অ্যাপ ডিপ্লয় করতে হয়।

## শেখার উদ্দেশ্যসমূহ

এই লেসনের শেষে, আপনি দক্ষ হবেন:

- বিভিন্ন ডিপ্লয়মেন্ট পদ্ধতির মূল্যায়ন করতে।
- আপনার অ্যাপ ডিপ্লয় করতে।

## লোকাল ডেভেলপমেন্ট এবং ডিপ্লয়মেন্ট

যদি আপনার সার্ভারটি ব্যবহারকারীর মেশিনে রান করার জন্য হয়, তাহলে নিম্নলিখিত ধাপগুলো অনুসরণ করুন:

1. **সার্ভার ডাউনলোড করুন**। যদি আপনি সার্ভার লিখে না থাকেন, তবে প্রথমে সেটি আপনার মেশিনে ডাউনলোড করুন।
1. **সার্ভার প্রসেস শুরু করুন**: আপনার MCP সার্ভার অ্যাপ্লিকেশন চালান।

SSE এর জন্য (stdio টাইপ সার্ভারের জন্য প্রয়োজন নেই)

1. **নেটওয়ার্কিং কনফিগার করুন**: সার্ভার প্রত্যাশিত পোর্টে অ্যাক্সেসযোগ্য হয়েছে কি না নিশ্চিত করুন।
1. **ক্লায়েন্ট সংযোগ করুন**: স্থানীয় সংযোগ URL যেমন `http://localhost:3000` ব্যবহার করুন।

## ক্লাউড ডিপ্লয়মেন্ট

MCP সার্ভার বিভিন্ন ক্লাউড প্ল্যাটফর্মে ডিপ্লয় করা যেতে পারে:

- **সার্ভারলেস ফাংশনস**: হালকা MCP সার্ভার সার্ভারলেস ফাংশন হিসেবে ডিপ্লয় করুন।
- **কন্টেইনার সার্ভিসেস**: Azure Container Apps, AWS ECS, বা Google Cloud Run এর মতো সার্ভিস ব্যবহার করুন।
- **কুবেরনেটিস**: উচ্চ উপলব্ধতার জন্য কুবেরনেটিস ক্লাস্টারে MCP সার্ভার ডিপ্লয় এবং পরিচালনা করুন।

### উদাহরণ: Azure Container Apps

Azure Container Apps MCP সার্ভার ডিপ্লয়মেন্ট সমর্থন করে। এটি এখনও একটি প্রক্রিয়াধীন কাজ এবং বর্তমানে SSE সার্ভার সমর্থিত।

নিচে কীভাবে এটি করবেন তার নির্দেশনা দেওয়া হলো:

1. একটি রিপো ক্লোন করুন:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. লোকালি এটি রান করে পরীক্ষা করুন:

  ```sh
  uv venv
  uv sync

  # লিনাক্স/ম্যাকওএস
  export API_KEYS=<AN_API_KEY>
  # উইন্ডোজ
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. লোকালি চেষ্টা করার জন্য, *.vscode* ডিরেক্টরিতে *mcp.json* ফাইল তৈরি করুন এবং নিম্নলিখিত কনটেন্ট যোগ করুন:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  একবার SSE সার্ভার শুরু হলে, আপনি JSON ফাইলে প্লে আইকনে ক্লিক করতে পারবেন, এখন আপনি সার্ভার থেকে টুলসগুলি GitHub Copilot দ্বারা নির্বাচিত দেখবেন, Tool আইকন দেখুন।

1. ডিপ্লয় করতে, নিম্নলিখিত কমান্ড চালান:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

এভাবেই, লোকালি বা Azure এ এই ধাপগুলি অনুসরণ করে ডিপ্লয় করুন।
