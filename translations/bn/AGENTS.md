# AGENTS.md

## প্রকল্প পর্যালোচনা

**শুরুকারীদের জন্য MCP** হল মডেল কন্টেক্সট প্রোটোকল (MCP) শেখার জন্য একটি ওপেন-সোর্স শিক্ষামূলক পাঠক্রম - যা AI মডেল এবং ক্লায়েন্ট অ্যাপ্লিকেশনের মধ্যে যোগাযোগের জন্য একটি মানসম্মত কাঠামো। এই রিপোজিটরিটি বিভিন্ন প্রোগ্রামিং ভাষায় হাতে-কলমে কোড উদাহরণের সাথে ব্যাপক শিক্ষামূলক উপকরণ সরবরাহ করে।

### মূল প্রযুক্তি

- **প্রোগ্রামিং ভাষাসমূহ**: C#, Java, JavaScript, TypeScript, Python, Rust
- **ফ্রেমওয়ার্ক এবং SDK**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **ডেটাবেস**: pgvector এক্সটেনশনের সাথে PostgreSQL
- **ক্লাউড প্ল্যাটফর্ম**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **বিল্ড টুল**: npm, Maven, pip, Cargo
- **ডকুমেন্টেশন**: ৪৮+ ভাষার স্বয়ংক্রিয় বহু-ভাষা অনুবাদ সহ Markdown

### স্থাপত্য

- **১১টি মূল মডিউল (00-11)**: মৌলিক থেকে উন্নত বিষয়ের ধারাবাহিক শিক্ষা পাথ
- **হাতে-কলমে ল্যাবস**: বিভিন্ন ভাষায় সম্পূর্ণ সমাধান কোড সহ ব্যবহারিক অনুশীলন
- **নমুনা প্রকল্প**: কার্যকর MCP সার্ভার এবং ক্লায়েন্ট বাস্তবায়ন
- **অনুবাদ সিস্টেম**: বহু-ভাষা সহায়তার জন্য স্বয়ংক্রিয় GitHub Actions ওয়ার্কফ্লো
- **ইমেজ এসেটস**: অনুবাদিত সংস্করণসহ কেন্দ্রীভূত ইমেজ ডিরেক্টরি

## সেটআপ কমান্ড

এটি একটি ডকুমেন্টেশন-কেন্দ্রিক রিপোজিটরি। বেশিরভাগ সেটআপ আলাদা আলাদা নমুনা প্রকল্প এবং ল্যাবসের মধ্যে হয়।

### রিপোজিটরি সেটআপ

```bash
# রিপোজিটোরি ক্লোন করুন
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### নমুনা প্রকল্পের সাথে কাজ করা

নমুনা প্রকল্পগুলি অবস্থিত:
- `03-GettingStarted/samples/` - ভাষা-বিশেষ উদাহরণ
- `03-GettingStarted/01-first-server/solution/` - প্রথম সার্ভার বাস্তবায়ন
- `03-GettingStarted/02-client/solution/` - ক্লায়েন্ট বাস্তবায়ন
- `11-MCPServerHandsOnLabs/` - পূর্ণাঙ্গ ডেটাবেস একীকরণ ল্যাবস

প্রতিটি নমুনা প্রকল্পে নিজস্ব সেটআপ নির্দেশিকা থাকে:

#### TypeScript/JavaScript প্রকল্প
```bash
cd <project-directory>
npm install
npm start
```

#### Python প্রকল্প
```bash
cd <project-directory>
pip install -r requirements.txt
# অথবা
pip install -e .
python main.py
```

#### Java প্রকল্প
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

#### সম্ভাব্য MCP টুল কর্মপ্রবাহ: `validate_curriculum_change`

##### লক্ষ্য

পাঠক্রম ডকুমেন্টেশনের পরিবর্তন এবং প্রতিনিধিত্বমূলক নমুনা কোড
একত্রিকরণের পূর্বে স্বাস্থ্য যাচাই করা।

##### ইনপুট

- `changed_paths: string[]` (প্রয়োজনীয়) - PR-এ পরিবর্তিত আপেক্ষিক পথসমূহ।
- `run_docs_lint: boolean` (ডিফল্ট `true`)
- `run_links_audit: boolean` (ডিফল্ট `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (ডিফল্ট সব `false`)

##### আউটপুট

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### অনুমতি

- শুধুমাত্র ওয়ার্কস্পেস ফাইল পড়ুন এবং টুল-উৎপাদিত আর্টিফ্যাক্ট (যেমন, লিন্ট
  রিপোর্ট, টেস্ট লগ) লিখুন; `translations/` বা
  `translated_images/`-এ লিখবেন না।
- স্থানীয় শেল কমান্ড চালান।
- প্যাকেজ পুনরুদ্ধারের জন্য বিকল্প নেটওয়ার্ক অ্যাক্সেস (`npm ci`,
  `python -m pip install`, `mvn` নির্ভরতা সমাধান)।
- `translations/` বা
  `translated_images/`-এ পুশ, মার্জ বা পরিবর্তনের অনুমতি নেই।

##### ব্যর্থতা মোড

- `E_NO_INPUT_PATHS`: `changed_paths` ফাঁকা।
- `E_INVALID_PATH`: ইনপুট পথ রিপোজিটরি রুটের বাইরে চলে গেছে।
- `E_LINT_FAILED`: মার্কডাউন লিন্ট অ-শূন্য এক্সিট দেয়।
- `E_LINK_AUDIT_FAILED`: লিঙ্ক অডিট কমান্ড অ-শূন্য এক্সিট দেয়।
- `E_SAMPLE_TEST_FAILED`: নমুনা টেস্ট/বিল্ড অ-শূন্য এক্সিট দেয়।
- `E_TIMEOUT`: কমান্ড কনফিগার করা টাইমআউট ছাড়িয়ে গেছে।

##### প্রস্তাবিত CI চুক্তি

স্বয়ংক্রিয় যাচাইয়ের জন্য একটি CI কাজ কনফিগার করুন যা:

- `*.md`, নমুনা কোড, বা এই ফাইল স্পর্শ করা পুল রিকোয়েস্টে ট্রিগার করে।
- উপরোক্ত ঠিক কমান্ডগুলো চালায়।
- লগ আর্কাইভ হিসেবে সংরক্ষণ করে।
- যেকোনো অ-শূন্য এক্সিট কোডে জব ব্যর্থ হয়।

### ডকুমেন্টেশন কাঠামো

4. মূল শাখায় পুশ করলে অনুবাদ পুনরায় তৈরি হয়
