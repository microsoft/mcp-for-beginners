# AGENTS.md

## প্রকল্প পর্যালোচনা

**শুরু করার জন্য MCP** হল একটি ওপেন-সোর্স শিক্ষামূলক কারিক্যুলাম যা মডেল কনটেক্সট প্রটোকল (MCP) শেখার জন্য — যা AI মডেল এবং ক্লায়েন্ট অ্যাপ্লিকেশনগুলোর মধ্যে পারস্পরিক ক্রিয়াকলাপের জন্য একটি মানানসই কাঠামো। এই রিপোজিটরি বহু প্রোগ্রামিং ভাষায় হাতে কলমে কোড উদাহরণসহ বিস্তৃত শেখার উপকরণ সরবরাহ করে।

### মূল প্রযুক্তি

- **প্রোগ্রামিং ভাষাসমূহ**: C#, Java, JavaScript, TypeScript, Python, Rust
- **ফ্রেমওয়ার্ক ও SDK**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **ডাটাবেস**: PostgreSQL সাথে pgvector এক্সটেনশন
- **ক্লাউড প্ল্যাটফর্ম**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **বিল্ড টুলস**: npm, Maven, pip, Cargo
- **ডকুমেন্টেশন**: স্বয়ংক্রিয় বহু-ভাষা অনুবাদসহ মার্কডাউন (৪৮+ ভাষা)

### আর্কিটেকচার

- **১১টি মূল মডিউল (০০-১১)**: মৌলিক থেকে উন্নত বিষয় পর্যন্ত ধারাবাহিক শেখার পথ
- **হ্যান্ডস-অন ল্যাবস**: বহুভাষায় সম্পূর্ণ সমাধান কোড সহ ব্যবহারিক অনুশীলন
- **নমুনা প্রকল্পসমূহ**: কার্যকর MCP সার্ভার এবং ক্লায়েন্ট ইমপ্লিমেন্টেশন
- **অনুবাদ ব্যবস্থা**: বহু-ভাষা সমর্থনের জন্য স্বয়ংক্রিয় GitHub Actions ওয়ার্কফ্লো
- **ছবি সম্পদ**: কেন্দ্রীভূত ইমেজ ডিরেক্টরি এবং অনূদিত সংস্করণসমূহ

## সেটআপ কমান্ডসমূহ

এটি একটি ডকুমেন্টেশন-কেন্দ্রিক রিপোজিটরি। বেশিরভাগ সেটআপ পৃথক নমুনা প্রকল্প এবং ল্যাবে ঘটে।

### রিপোজিটরি সেটআপ

```bash
# রিপোজিটরি ক্লোন করুন
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### নমুনা প্রকল্প নিয়ে কাজ করা

নমুনা প্রকল্পগুলি অবস্থিত:
- `03-GettingStarted/samples/` - ভাষা-নির্দিষ্ট উদাহরণ
- `03-GettingStarted/01-first-server/solution/` - প্রথম সার্ভার ইমপ্লিমেন্টেশন
- `03-GettingStarted/02-client/solution/` - ক্লায়েন্ট ইমপ্লিমেন্টেশন
- `11-MCPServerHandsOnLabs/` - ব্যাপক ডাটাবেস ইন্টিগ্রেশন ল্যাবস

প্রতিটি নমুনা প্রকল্পের আলাদা সেটআপ নির্দেশাবলী থাকে:

#### TypeScript/JavaScript প্রকল্পসমূহ
```bash
cd <project-directory>
npm install
npm start
```

#### Python প্রকল্পসমূহ
```bash
cd <project-directory>
pip install -r requirements.txt
# অথবা
pip install -e .
python main.py
```

#### Java প্রকল্পসমূহ
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

#### প্রার্থী MCP টুল কার্যপ্রবাহ: `validate_curriculum_change`

##### লক্ষ্য

কারিকুলাম ডকুমেন্টেশনের পরিবর্তন এবং প্রতিনিধিমূলক নমুনা কোড
সম্মিলিতভাবে যাচাই করা সহজ স্থিতিশীলতার জন্য।

##### ইনপুটসমূহ

- `changed_paths: string[]` (আবশ্যক) - PR এ পরিবর্তিত আপেক্ষিক পথসমূহ।
- `run_docs_lint: boolean` (ডিফল্ট `true`)
- `run_links_audit: boolean` (ডিফল্ট `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (ডিফল্ট সকল `false`)

##### আউটপুটসমূহ

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### অনুমতি

- ওয়ার্কস্পেস ফাইল পড়ুন এবং শুধুমাত্র টুল-উৎপাদিত আর্টিফ্যাক্টস লিখুন (যেমন, লিন্ট
  রিপোর্ট, টেস্ট লগ); `translations/` বা
  `translated_images/`-এ লিখার অনুমতি নেই।
- স্থানীয় শেল কমান্ড চালানোর অনুমতি।
- প্যাকেজ রিস্টোরের জন্য অপশনাল নেটওয়ার্ক অ্যাক্সেস (যেমন `npm ci`,
  `python -m pip install`, `mvn` নির্ভরতা সমাধান)।
- `translations/` বা
  `translated_images/`-এ পুশ, মার্জ, অথবা পরিবর্তনের অনুমতি নেই।

##### ব্যর্থতা মোডসমূহ

- `E_NO_INPUT_PATHS`: `changed_paths` ফাঁকা।
- `E_INVALID_PATH`: ইনপুট পথ রিপোজিটরি মূল এলাকা থেকে বাইরে।
- `E_LINT_FAILED`: মার্কডাউন লিন্ট নন-জিরো এক্সিট।
- `E_LINK_AUDIT_FAILED`: লিংক অডিট কমান্ড নন-জিরো এক্সিট।
- `E_SAMPLE_TEST_FAILED`: নমুনা টেস্ট/বিল্ড নন-জিরো এক্সিট।
- `E_TIMEOUT`: কমান্ড নির্ধারিত সময়সীমা অতিক্রম করেছে।

##### সুপারিশকৃত CI চুক্তি

স্বয়ংক্রিয় যাচাইয়ের জন্য একটি CI কাজ কনফিগার করুন যা:

- লগসমূহ আর্টিফ্যাক্ট হিসেবে সংরক্ষণ করে।

- পরিষ্কার, নবীন-বান্ধব ভাষা ব্যবহার করুন
- প্রযোজ্য স্থানে একাধিক ভাষায় কোড উদাহরণ অন্তর্ভুক্ত করুন
- মার্কডাউন সেরা অনুশীলন অনুসরণ করুন:
  - ATX-স্টাইল হেডার ব্যবহার করুন (`#` সিনট্যাক্স)
  - ভাষা সনাক্তকারী সহ বেড়াওয়ালা কোড ব্লক ব্যবহার করুন
  - ছবির জন্য বর্ণনামূলক alt টেক্সট অন্তর্ভুক্ত করুন
  - সারির দৈর্ঘ্য যুক্তিসঙ্গত রাখুন (কোন কঠোর সীমা নেই, তবে বোধগম্য হোন)

### কোড নমুনার শৈলী

- ES মডিউলস ব্যবহার করুন (`import`/`export`)
- টাইপস্ক্রিপ্ট স্ট্রিক্ট মোড নিয়ম অনুসরণ করুন

- প্রয়োজনীয় ক্ষেত্রে টাইপ হিন্ট ব্যবহার করুন
- ফাংশন এবং ক্লাসের জন্য ডকস্ট্রিং অন্তর্ভুক্ত করুন
- আধুনিক পাইথন ফিচার ব্যবহার করুন (৩.৮+)

#### জাভা

- জাভা ২১ ফিচার ব্যবহার করুন
- স্ট্যান্ডার্ড মেভেন প্রকল্প কাঠামো অনুসরণ করুন
- জাভাডক মন্তব্য অন্তর্ভুক্ত করুন

## বিল্ড এবং ডেপ্লয়মেন্ট

### ডকুমেন্টেশন ডেপ্লয়মেন্ট

রিপজিটরি ডকুমেন্টেশন হোস্টিং এর জন্য গিটহাব পেজ বা অনুরূপ ব্যবহার করে (যদি প্রযোজ্য হয়)। মেইন ব্রাঞ্চ পরিবর্তনের ফলে:

1. অনুবাদ কার্যপ্রবাহ (`.github/workflows/co-op-translator.yml`)
2. সমস্ত ইংরেজি মার্কডাউন ফাইলের স্বয়ংক্রিয় অনুবাদ
3. দরকার হলে ছবি স্থানীয়করণ

### কোনও বিল্ড প্রক্রিয়া প্রয়োজন নেই

এই রিপজিটরি মূলত মার্কডাউন ডকুমেন্টেশন ধারণ করে। মূল কারিকুলাম বিষয়বস্তুর জন্য কোনও কম্পাইলেশন বা বিল্ড স্টেপের প্রয়োজন নেই।

### নমুনা প্রকল্প ডেপ্লয়মেন্ট

ব্যক্তিগত নমুনা প্রকল্পগুলির ডেপ্লয়মেন্ট নির্দেশিকা থাকতে পারে:
- MCP সার্ভার ডেপ্লয়মেন্ট নির্দেশিকার জন্য `03-GettingStarted/09-deployment/` দেখুন
- `11-MCPServerHandsOnLabs/` এ Azure Container Apps ডেপ্লয়মেন্ট উদাহরণ

## অবদান Guidelines

### পুল রিকোয়েস্ট প্রক্রিয়া

1. **Fork এবং Clone করুন**: রিপজিটরি Fork করে আপনার লোকাল মেশিনে Clone করুন
2. **একটি শাখা তৈরি করুন**: বর্ণনামূলক শাখার নাম ব্যবহার করুন (যেমন, `fix/typo-module-3`, `add/python-example`)
3. **পরিবর্তন করুন**: শুধুমাত্র ইংরেজি মার্কডাউন ফাইল সম্পাদনা করুন (অনুবাদ নয়)
4. **স্থানীয়ভাবে পরীক্ষা করুন**: যাচাই করুন মার্কডাউন সঠিকভাবে রেন্ডার হয়
5. **PR সাবমিট করুন**: পরিষ্কার PR শিরোনাম এবং বিবরণ ব্যবহার করুন
6. **CLA**: প্রম্পট পেলে Microsoft Contributor License Agreement তে স্বাক্ষর করুন

### PR শিরোনামের ফরম্যাট

পরিষ্কার এবং বর্ণনামূলক শিরোনাম ব্যবহার করুন:
- মডিউল-নির্দিষ্ট পরিবর্তনের জন্য `[Module XX] সংক্ষিপ্ত বর্ণনা`
- নমুনা কোড পরিবর্তনের জন্য `[Samples] বর্ণনা`
- সাধারণ ডকুমেন্টেশন আপডেটের জন্য `[Docs] বর্ণনা`

### সাধারণ সমস্যা সমাধান

**প্রঃ আমার PR অনুবাদ যাচাইকরণ ফেল করছে**
উঃ নিশ্চিত করুন আপনি শুধুমাত্র মূল মডিউলের ইংরেজি মার্কডাউন ফাইল সম্পাদনা করেছেন, অনূদিত ফাইল নয়।

**প্রঃ আমি কীভাবে নতুন ভাষা যোগ করব?**
উঃ ভাষা সমর্থন co-op-translator কার্যপ্রবাহের মাধ্যমে পরিচালিত হয়। নতুন ভাষা যোগ করার আলোচনার জন্য একটি ইস্যু খুলুন।

**প্রঃ কোড নমুনা কাজ করছে না**

উত্তর: নিশ্চিত করুন যে আপনি নির্দিষ্ট নমুনার README তে সেটআপ নির্দেশনা অনুসরণ করেছেন। যাচাই করুন আপনার কাছে সঠিক সংস্করণের নির্ভরশীলতা ইনস্টল করা আছে।

**প্রশ্ন: ছবি প্রদর্শিত হচ্ছে না**
উত্তর: নিশ্চিত করুন ছবির পথ আপেক্ষিক এবং ফরোয়ার্ড স্ল্যাশ ব্যবহার করছে। ছবি থাকা উচিত `images/` ডিরেক্টরিতে বা স্থানীয় সংস্করণের জন্য `translated_images/` এ।
