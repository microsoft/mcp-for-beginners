# AGENTS.md

## សេចក្ដីសង្ខេបគម្រោង

**MCP សម្រាប់អ្នកចាប់ផ្តើម** គឺជាកម្មវិធីសិក្សាអប់រំបើកចំហសម្រាប់រៀន Model Context Protocol (MCP) - ស៊ុមខ្នាតមានគ្រប់លក្ខណៈស្តង់ដារសម្រាប់ការប្រាស្រ័យទាក់ទងរវាងម៉ូឌែល AI និងកម្មវិធីអតិថិជន។ ឃ្លាំងនេះផ្តល់ជូននូវសម្ភារៈសិក្សាដ៏ទូលំទូលាយជាមួយឧទាហរណ៍កូដដៃគូក្នុងភាសាកម្មវិធីច្រើន។

### បច្ចេកវិទ្យាជាក់ស្តែង

- **ភាសាកម្មវិធី**: C#, Java, JavaScript, TypeScript, Python, Rust
- **ផ្ដុំបណ្ដុំ និង SDKs**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **មូលដ្ឋានទិន្នន័យ**: PostgreSQL ជាមួយផ្នែកបន្ថែម pgvector
- **វេទិកាមេឃ**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **ឧបករណ៍សាងសង់**: npm, Maven, pip, Cargo
- **ឯកសារ**: Markdown ជាមួយប្រព័ន្ធបកប្រែភាសាច្រើនដោយស្វ័យប្រវត្តិ (ជាង ៤៨ ភាសា)

### ស្ថាបត្យកម្ម

- **១១ ម៉ូឌុលស្នូល (០០-១១)**: ផ្លូវរៀនជាស្វ័យប្រវត្តិត последовательពីមូលហេតុទៅមុខវិជ្ជាជំនាញខ្ពស់
- **កន្លែងហាត់ដឹង**: ការអនុវត្តជាក់ស្តែងជាមួយកូដដំណោះស្រាយពេញលេញក្នុងភាសាច្រើន
- **គំរូគម្រោង**: ការអនុវត្តម៉ាស៊ីនមេ MCP និងអតិថិជន ដែលអាចដំណើរការ
- **ប្រព័ន្ធបកប្រែ**: ជំហាន GitHub Actions ដើម្បីគាំទ្រភាសាច្រើនដោយស្វ័យប្រវត្តិ
- **ទ្រព្យសម្បត្តិរូបភាព**: ហ្គាដ្នកីឡារូបភាពមួយកណ្ដាលជាមួយកំណែបកប្រែ

## ពាក្យបញ្ជាតំឡើង

ទីនេះជាគម្រោងផ្ដោតទៅលើឯកសារ។ ការតំឡើងភាគច្រើនធ្វើនៅក្នុងគម្រោងគំរូនិងកន្លែងហាត់នីមួយៗ។

### ការតំឡើងឃ្លាំង

```bash
# ចម្លងរ៉ೆបូស៊ីតរី
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### ធ្វើការជាមួយគំរូគម្រោង

គំរូគម្រោងស្ថិតនៅ៖
- `03-GettingStarted/samples/` - ឧទាហរណ៍ជាក់ស្តែងតាមភាសា
- `03-GettingStarted/01-first-server/solution/` - ការអនុវត្តម៉ាស៊ីនមើដំបូង
- `03-GettingStarted/02-client/solution/` - ការអនុវត្តអតិថិជន
- `11-MCPServerHandsOnLabs/` - កន្លែងហាត់ច្នៃប្រឌិតបញ្ចូលមូលដ្ឋានទិន្នន័យ

គំរូគម្រោងនីមួយៗមានការណែនាំការតំឡើងរបស់ខ្លួន៖

#### គំរូគម្រោង TypeScript/JavaScript
```bash
cd <project-directory>
npm install
npm start
```

#### គំរូគម្រោង Python
```bash
cd <project-directory>
pip install -r requirements.txt
# ឬ
pip install -e .
python main.py
```

#### គំរូគម្រោង Java
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

##### គោលបំណង

ស្ទង់មើលភាពបំរើការផ្លាស់ប្តូរឯកសារផែនការសិក្សា និងកូដគំរូតំណាង
ក្នុងសុខភាព មុនការរួមបញ្ចូល។

##### ការបញ្ចូល

- `changed_paths: string[]` (ចាំបាច់) - ផ្លូវដែលបានផ្លាស់ប្តូរក្នុង PR។
- `run_docs_lint: boolean` (លំនាំដើម `true`)
- `run_links_audit: boolean` (លំនាំដើម `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (លំនាំដើមទាំងអស់ `false`)

##### ការបញ្ចេញ

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### ការអនុញ្ញាត

- អានឯកសារប្រតិបត្តិការទៅ និងសរសេរឯកសារដែលបង្កើតដោយឧបករណ៍ (ឧ. របាយការណ៍ lint,
  កំណត់ហេតុសាកល្បង) តែប៉ុណ្ណោះ; មិនអាចសរសេរទៅ `translations/` ឬ
  `translated_images/`។
- ប្រតិបត្តិការកម្មង់ shell នៅលើកុំព្យូទ័រផ្ទាល់ខ្លួន។
- សិទ្ធិចូលប្រព័ន្ធបណ្តាញជាជម្រើស សម្រាប់ការលុបទំព័រកញ្ចប់ (`npm ci`,
  `python -m pip install`, `mvn` សំរាប់ដោះស្រាយការពឹងផ្អែក)។
- មិនមានសិទ្ធិដើម្បីដាក់, រួមបញ្ចូល ឬកែលម្អ `translations/` ឬ
  `translated_images/`។

##### របៀបខ្វះបរាជ័យ

- `E_NO_INPUT_PATHS`: តារាង `changed_paths` ទទេ។
- `E_INVALID_PATH`: ផ្លូវបញ្ចូលចេញពីឫសឃ្លាំងកូដ។
- `E_LINT_FAILED`: ការត្រួតពិនិត្យ markdown lint បញ្ចប់ជាមួយកូដមិនសូន្យ។
- `E_LINK_AUDIT_FAILED`: ការត្រួតពិនិត្យតំណភ្ជាប់បញ្ចប់ជាមួយកូដមិនសូន្យ។
- `E_SAMPLE_TEST_FAILED`: ការតេស្ត/បញ្ចុំគំរូចេញជាមួយកូដមិនសូន្យ។
- `E_TIMEOUT`: កម្មង់លើសពេលកំណត់។

##### សំណិទ្ធិកម្ម CI ដែលផ្ដល់អនុសាសន៍

ដើម្បីស្វ័យប្រវត្តិក្នុងការត្រួតពិនិត្យ, បង្កើតកិច្ចការក្នុង CI ដែល:

- បើកសកម្មនៅពេលមាន pull request ដែលប៉ះពាល់ទៅ `*.md`, កូដគំរូ, ឬឯកសារនេះ។
- ប្រតិបត្តិការកម្មង់តែមួយដែលបានរាយការណ៍ខាងលើ។
- រក្សាកំណត់ហេតុជា artifacts។
- បរាជ័យក្នុងកិច្ចការពេលមានកូដចេញមិនសូន្យណាមួយ។
