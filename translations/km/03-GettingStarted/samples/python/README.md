# ម៉ាស៊ីនគណនាសេវា MCP (Python)



ការអនុវត្តមួយសេវាម៉ាស៊ីនបុព្វបទគំរូ (MCP) ក្នុងភាសា Python ដែលផ្តល់មុខងារម៉ាស៊ីនគណនាពេញមួយទម្រង់មួយ។


## ការ​ដំឡើង

តំឡើងការពឹងផ្អែកដែលត្រូវការ៖

```bash
pip install -r requirements.txt
```

ឬតំឡើង MCP Python SDK ដោយផ្ទាល់៖

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## ការប្រើប្រាស់

### ការរត់ម៉ាស៊ីនសេវា

ម៉ាស៊ីនសេវាត្រូវបានរចនាឡើងសម្រាប់ប្រើប្រាស់ដោយអតិថិជន MCP (ដូចជា Claude Desktop)។ ដើម្បីចាប់ផ្តើមម៉ាស៊ីនសេវា៖

```bash
python mcp_calculator_server.py
```

**ចំណាំ**: ពេលរត់ដោយផ្ទាល់នៅក្នុងផ្ទាំងបញ្ជា អ្នកនឹងឃើញកំហុសផ្ទៀងផ្ទាត់ JSON-RPC។ នេះជាការប្រតិបត្តិត្រឹមត្រូវ - ម៉ាស៊ីនសេវាកំពុងរងចាំសារអតិថិជន MCP ដែលមានទម្រង់ត្រឹមត្រូវ។

### ការពិនិត្យមុខងារ

ដើម្បីសាកល្បងមុខងារម៉ាស៊ីនគណនា ឱ្យប្រាកដថាគ្រាន់តែដំណើរការជាប់ល្អ៖

```bash
python test_calculator.py
```

## ការដោះស្រាយបញ្ហា

### កំហុសនាំចូល

ប្រសិនបើអ្នកឃើញ `ModuleNotFoundError: No module named 'mcp'` សូមដំឡើង MCP Python SDK៖

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### កំហុស JSON-RPC ពេលរត់ដោយផ្ទាល់

កំហុសដូចជា "Invalid JSON: EOF while parsing a value" ពេលរត់ម៉ាស៊ីនសេវាដោយផ្ទាល់គឺជារឿងធម្មតា។ ម៉ាស៊ីនសេវាត្រូវការសារអតិថិជន MCP មិនមែនការបញ្ចូលផ្ទាល់ពីផ្ទាំងបញ្ជា។
