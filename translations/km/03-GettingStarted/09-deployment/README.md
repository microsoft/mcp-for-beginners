## សេចក្ដីសង្ខេប

មេរៀននេះគ្របដណ្តប់ពីរបៀបចេញផ្សាយកម្មវិធីម៉ាស៊ីនមេ MCP របស់អ្នក។

## គោលបំណងសិក្សា

នៅចុងបញ្ចប់នៃមេរៀននេះ អ្នកនឹងអាច:

- វាយតម្លៃវិធីការចេញផ្សាយផ្សេងៗ។
- ចេញផ្សាយកម្មវិធីរបស់អ្នក។

## ការអភិវឌ្ឍន៍ និងចេញផ្សាយក្នុងតំបន់

ប្រសិនបើម៉ាស៊ីនមេរបស់អ្នកមានគោលបំណងប្រើប្រាស់ដោយរត់នៅលើកុំព្យូទ័រ របស់អ្នកប្រើ អ្នកអាចអនុវត្តជំហានខាងក្រោម៖

1. **ទាញយកម៉ាស៊ីនមេ**។ ប្រសិនបើអ្នកមិនបានសរសេរស្រាវជ្រាវម៉ាស៊ីនមេ អ្នកត្រូវទាញយកវាទៅកុំព្យូទ័រមុន។
1. **ចាប់ផ្តើមដំណើរការម៉ាស៊ីនមេ**៖ រត់កម្មវិធីម៉ាស៊ីនមេ MCP របស់អ្នក

សម្រាប់ SSE (មិនចាំបាច់សម្រាប់ម៉ាស៊ីនមេទ្រង់ទ្រាយ stdio)

1. **កំណត់បណ្តាញ**៖ ប្រាកដថាម៉ាស៊ីនមេអាចចូលប្រើបានលើឈុតច្រកដែលបានគិតទុក
1. **ភ្ជាប់អតិថិជន**៖ ប្រើ URL ការភ្ជាប់ក្នុងតំបន់ដូចជា `http://localhost:3000`

## ការចេញផ្សាយទៅពពក

ម៉ាស៊ីនមេ MCP អាចចេញផ្សាយទៅវេទិកាពពកជាច្រើនដែលមាន:

- **មុខងារដោយគ្មានម៉ាស៊ីនមេ**៖ ចេញផ្សាយម៉ាស៊ីនមេ MCP ស្រាលជាមុខងារដោយគ្មានម៉ាស៊ីនមេ
- **សេវាកម្មផុង**៖ ប្រើសេវាកម្មដូចជា Azure Container Apps, AWS ECS, ឬ Google Cloud Run
- **Kubernetes**៖ ចេញផ្សាយ និងគ្រប់គ្រងម៉ាស៊ីនមេ MCP នៅក្នុងក្រុមហ៊ុន Kubernetes សម្រាប់ភាពមានតម្លាភាពខ្ពស់

### ឧទាហរណ៍៖ Azure Container Apps

Azure Container Apps គាំទ្រការចេញផ្សាយម៉ាស៊ីនមេ MCP។ វាត្រូវបានបន្តការងារហើយបច្ចុប្បន្នគាំទ្រម៉ាស៊ីនមេ SSE។

នេះជារបៀបដែលអ្នកអាចធ្វើបាន៖

1. ចម្លងរ៉េបូ

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. រត់វា​ក្នុងតំបន់ដើម្បីសាកល្បង

  ```sh
  uv venv
  uv sync

  # លីនុច / ម៉ាក់អូអេស
  export API_KEYS=<AN_API_KEY>
  # វីនដোজ
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. សម្រាប់សាកល្បងនៅក្នុងតំបន់ បង្កើតឯកសារ *mcp.json* នៅក្នុងថត *.vscode* ហើយបញ្ចូលមាតិកាខាងក្រោម៖

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  ពេលម៉ាស៊ីនមេ SSE ចាប់ផ្តើម អ្នកអាចចុចរូបតំណាងចាក់ចម្រៀងក្នុងឯកសារ JSON, ឥឡូវនេះអ្នកគួរតែឃើញឧបករណ៍នៅលើម៉ាស៊ីនមេដែលបានជ្រើសរើសដោយ GitHub Copilot សូមមើលរូបតំណាងឧបករណ៍។

1. សម្រាប់ការចេញផ្សាយ រត់ពាក្យបញ្ជាខាងក្រោម៖

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

នេះហើយជារបៀបចេញផ្សាយនៅក្នុងតំបន់ និងចេញផ្សាយទៅ Azure តាមជំហានទាំងនេះ។
