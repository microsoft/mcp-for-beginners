## 🔧 Razumijevanje MCP poslužitelja: vodič za početnike

### Što su MCP poslužitelji?

Kao početnik u Model Context Protocolu (MCP), možda se pitate: "Što je točno MCP poslužitelj i zašto bih ga trebao koristiti?" Počnimo s jednostavnom analogijom.

Zamislite MCP poslužitelje kao specijalizirane asistente koji pomažu vašem AI pomoćniku za kodiranje (poput GitHub Copilot) da se poveže s vanjskim alatima i uslugama. Baš kao što na svom telefonu koristite različite aplikacije za različite zadatke — jednu za vremensku prognozu, jednu za navigaciju, jednu za bankarstvo — MCP poslužitelji vašem AI pomoćniku daju mogućnost interakcije s različitim alatima i uslugama za razvoj.

### Problem koji MCP poslužitelji rješavaju

Prije MCP poslužitelja, ako ste željeli:
- Provjeriti svoje Azure resurse
- Kreirati GitHub problem (issue)
- Izvršiti upit u bazu podataka
- Pretražiti dokumentaciju

Morali biste prestati s kodiranjem, otvoriti preglednik, navigirati na prikladnu web stranicu i ručno obaviti te zadatke. Ovo stalno mijenjanje konteksta prekida vaš tijek rada i smanjuje produktivnost.

### Kako MCP poslužitelji transformiraju vaše razvojno iskustvo

Uz MCP poslužitelje, možete ostati u svom razvojnim okruženju (VS Code, Visual Studio, itd.) i jednostavno zatražiti od AI asistenta da obavi ove zadatke. Na primjer:

**Umjesto tradicionalnog tijeka rada:**
1. Prekinuti kodiranje
2. Otvoriti preglednik
3. Navigirati na Azure portal
4. Pogledati detalje spremišta
5. Vratiti se u VS Code
6. Nastaviti kodiranje

**Sada možete učiniti ovo:**
1. Pitati AI: "Koje je stanje mojih Azure računa za pohranu?"
2. Nastaviti kodirati s pruženim informacijama

### Ključne prednosti za početnike

#### 1. 🔄 **Ostanite u svom stanju toka**
- Nema više prebacivanja između više aplikacija
- Ostanite usredotočeni na kod koji pišete
- Smanjite mentalni napor pri upravljanju različitim alatima

#### 2. 🤖 **Koristite prirodni jezik umjesto složenih naredbi**
- Umjesto da pamtite SQL sintaksu, opišite koje podatke trebate
- Umjesto da pamtite Azure CLI naredbe, objasnite što želite postići
- Neka AI rješava tehničke detalje dok se vi fokusirate na logiku

#### 3. 🔗 **Povežite više alata zajedno**
- Stvorite moćne tijekove rada kombiniranjem različitih usluga
- Primjer: "Dohvati sve nedavne GitHub probleme i kreiraj odgovarajuće radne stavke u Azure DevOps-u"
- Izgradite automatizaciju bez pisanja složenih skripti

#### 4. 🌐 **Pristup rastućem ekosustavu**
- Iskoristite poslužitelje koje su izgradili Microsoft, GitHub i druge tvrtke
- Besprijekorno kombinirajte alate različitih dobavljača
- Pridružite se standardiziranom ekosustavu koji radi preko različitih AI asistenata

#### 5. 🛠️ **Učite kroz praksu**
- Počnite s unaprijed izgrađenim poslužiteljima da biste razumjeli koncepte
- Postupno izgrađujte vlastite poslužitelje kako postajete sigurniji
- Koristite dostupne SDK-ove i dokumentaciju kao vodič za učenje

### Primjer iz stvarnog svijeta za početnike

Recimo da ste novi u web razvoju i radite na svom prvom projektu. Evo kako vam MCP poslužitelji mogu pomoći:

**Tradicionalni pristup:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**S MCP poslužiteljima:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### Prednost standarda u poduzeću

MCP postaje industrijski standard, što znači:
- **Dosljednost**: Slično iskustvo na različitim alatima i tvrtkama
- **Interoperabilnost**: Poslužitelji različitih dobavljača rade zajedno
- **Zaštita za budućnost**: Vještine i postavke se prenose između različitih AI asistenata
- **Zajednica**: Veliki ekosustav zajedničkog znanja i resursa

## Početak rada s MCP u VS Code i Visual Studio 🚀

Postavljanje ovih MCP poslužitelja je jednostavno ako koristite Visual Studio Code ili Visual Studio 2022 s GitHub Copilotom.

### Postavljanje u VS Code

Osnovni postupak za VS Code:

1. **Omogućite Agent način rada**: U VS Code-u prebacite se na Agent način rada u prozoru Copilot Chat
2. **Konfigurirajte MCP poslužitelje**: Dodajte konfiguracije poslužitelja u vaš VS Code settings.json
3. **Pokrenite poslužitelje**: Kliknite tipku "Start" za svaki poslužitelj koji želite koristiti
4. **Odaberite alate**: Odaberite koje MCP poslužitelje želite omogućiti za vašu trenutnu sesiju

Za detaljne upute o postavljanju, pogledajte [VS Code MCP dokumentaciju](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Profesionalni savjet: Upravljajte MCP poslužiteljima kao profesionalac!**
> 
> Prikaz dodataka VS Code sada uključuje [zgodan novi UI za upravljanje instaliranim MCP poslužiteljima](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Imate brz pristup za pokretanje, zaustavljanje i upravljanje bilo kojim instaliranim MCP poslužiteljima koristeći jasno i jednostavno sučelje. Isprobajte!

### Postavljanje u Visual Studio 2022

Za Visual Studio 2022 (verzija 17.14 ili novija):

1. **Omogućite Agent način rada**: Kliknite padajući izbornik "Ask" u GitHub Copilot Chat prozoru i odaberite "Agent"
2. **Izradite konfiguracijsku datoteku**: Kreirajte `.mcp.json` datoteku u direktoriju vaše solucije (preporučena lokacija: `<SOLUTIONDIR>\.mcp.json`)
3. **Konfigurirajte poslužitelje**: Dodajte konfiguracije MCP poslužitelja koristeći standardni MCP format
4. **Odobrenje alata**: Kad se zatraži, odobrite alate koje želite koristiti s odgovarajućim dozvolama

Za detaljne upute za Visual Studio postavljanje, pogledajte [Visual Studio MCP dokumentaciju](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Svaki MCP poslužitelj ima svoje zahtjeve za konfiguracijom (streamovi veze, autentikacija itd.), ali obrazac postavljanja je dosljedan u oba IDE-a.

**Što radi**: Microsoft Learn Docs MCP poslužitelj je usluga u oblaku koja AI asistentima pruža pristup službenoj Microsoft dokumentaciji u stvarnom vremenu putem Model Context Protocol-a. Povezuje se s `https://learn.microsoft.com/api/mcp` i omogućuje semantičko pretraživanje Microsoft Learn, Azure dokumentacije, Microsoft 365 dokumentacije i drugih službenih Microsoft izvora.

**Zašto je koristan**: Iako se može činiti kao "samo dokumentacija", ovaj poslužitelj je zapravo ključan za svakog programera koji koristi Microsoft tehnologije. Jedna od najvećih pritužbi .NET programera na AI asistente za kodiranje je da nisu ažurirani s najnovijim .NET i C# izdanjima. Microsoft Learn Docs MCP poslužitelj to rješava pružajući pristup najnovijoj dokumentaciji, referencama API-ja i najboljim praksama u stvarnom vremenu. Bilo da radite s najnovijim Azure SDK-ovima, istražujete nove značajke C# 13 ili implementirate najnovije Aspire obrasce, ovaj poslužitelj osigurava da vaš AI asistent ima pristup autoritativnim, ažuriranim informacijama potrebnim za generiranje točnog i modernog koda.

**Primjeri iz stvarnog svijeta**: "Koje su az cli naredbe za kreiranje Azure container aplikacije prema službenoj Microsoft Learn dokumentaciji?" ili "Kako konfigurirati Entity Framework s dependency injection u ASP.NET Core?" Ili možda "Pregledaj ovaj kod da se uvjeriš da odgovara preporukama za performanse u Microsoft Learn Dokumentaciji." Poslužitelj pruža temeljitu pokrivenost Microsoft Learn, Azure i Microsoft 365 dokumentacije koristeći napredno semantičko pretraživanje kako bi pronašao najrelevantnije informacije u kontekstu. Vraća do 10 visokokvalitetnih sadržajnih cjelina s naslovima članaka i URL-ovima, uvijek pristupajući najnovijoj Microsoft dokumentaciji čim je objavljena.

**Naglašeni primjer**: Poslužitelj izlaže `microsoft_docs_search` alat koji vrši semantičko pretraživanje službene Microsoft tehničke dokumentacije. Nakon konfiguracije, možete postaviti pitanja poput "Kako implementirati JWT autentikaciju u ASP.NET Core?" i dobiti detaljne, službene odgovore s poveznicama na izvore. Kvaliteta pretraživanja je izvrsna jer razumije kontekst – upit za "containers" u Azure kontekstu vraća dokumentaciju za Azure Container Instances, dok isti pojam u .NET kontekstu vraća relevantne informacije o C# kolekcijama.

Ovo je posebno korisno za brzo mijenjajuće ili nedavno ažurirane biblioteke i slučajeve upotrebe. Na primjer, u nekim nedavnim projektima kodiranja htio sam iskoristiti značajke u najnovijim izdanjima Aspire i Microsoft.Extensions.AI. Uključivanjem Microsoft Learn Docs MCP poslužitelja, uspio sam iskoristiti ne samo API dokumentaciju, već i vodiče i smjernice koje su tek objavljene.

### 2. ☁️ Azure MCP poslužitelj

[![Instaliraj u VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Instaliraj u VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Što radi**: Azure MCP poslužitelj je opsežan paket od 15+ specijaliziranih konektora za Azure usluge koji dovodi cijeli Azure ekosustav u vaš AI tijek rada. Ovo nije samo jedan poslužitelj – to je moćna kolekcija koja uključuje upravljanje resursima, povezivanje s bazama podataka (PostgreSQL, SQL Server), analiziranje logova Azure Monitor-a s KQL, integraciju Cosmos DB-a i još mnogo toga.

**Zašto je koristan**: Osim upravljanja Azure resursima, ovaj poslužitelj značajno poboljšava kvalitetu koda pri radu s Azure SDK-ovima. Kad koristite Azure MCP u Agent načinu rada, ne pomaže vam samo pisati kod – pomaže vam pisati *bolji* Azure kod koji prati aktualne obrasce autentikacije, najbolje prakse rukovanja greškama i koristi najnovije značajke SDK-a. Umjesto da dobijete generički kod koji bi mogao raditi, dobivate kod koji slijedi Azure preporučene obrasce za produkcijske radne opterećenja.

**Ključni moduli uključuju**:
- **🗄️ Konektori za baze podataka**: Direktan pristup prirodnim jezikom Azure bazi podataka za PostgreSQL i SQL Server
- **📊 Azure Monitor**: Analiza logova pogonjena KQL-om i operativni uvidi
- **🌐 Upravljanje resursima**: Potpuno upravljanje životnim ciklusom Azure resursa
- **🔐 Autentikacija**: DefaultAzureCredential i obrasci upravljanog identiteta
- **📦 Usluge pohrane**: Operacije Blob Storage, Queue Storage i Table Storage
- **🚀 Usluge kontejnera**: Azure Container Apps, Container Instances i upravljanje AKS-om
- **I mnogi drugi specijalizirani konektori**

**Primjeri iz stvarnog svijeta**: "Nabroji moje Azure račune za pohranu", "Upitaj moj Log Analytics workspace za greške u posljednjem satu" ili "Pomozi mi izgraditi Azure aplikaciju koristeći Node.js s ispravnom autentikacijom"

**Cijeli demo scenarij**: Evo kompletne demonstracije koja pokazuje snagu kombiniranja Azure MCP-a s GitHub Copilot for Azure ekstenzijom u VS Code-u. Kad imate oboje instalirano i pošaljete upit:

> "Napravite Python skriptu koja učitava datoteku u Azure Blob Storage koristeći autentifikaciju DefaultAzureCredential. Skripta bi trebala povezati moj Azure storage račun nazvan 'mycompanystorage', učitati u spremnik nazvan 'documents', kreirati testnu datoteku s trenutačnim vremenskim žigom za učitavanje, smireno rukovati pogreškama i pružiti informativni ispis, slijediti najbolje prakse Azurea za autentifikaciju i rukovanje pogreškama, uključiti komentare koji objašnjavaju kako funkcionira DefaultAzureCredential autentifikacija te napraviti skriptu dobro strukturiranom s odgovarajućim funkcijama i dokumentacijom."

Azure MCP Server generirat će potpunu, spremnu za proizvodnju Python skriptu koja:
- Koristi najnoviji Azure Blob Storage SDK s ispravnim async obrascima
- Implementira DefaultAzureCredential s detaljnim objašnjenjem lanca povratnih rješenja
- Uključuje robusno rukovanje pogreškama sa specifičnim Azure tipovima iznimki
- Slijedi najbolje prakse Azure SDK-a za upravljanje resursima i rukovanje vezama
- Pruža detaljno zapisivanje i informativni ispis na konzoli
- Stvara ispravno strukturiranu skriptu s funkcijama, dokumentacijom i tipizacijom

Ono što je upečatljivo jest da bez Azure MCP-a mogli biste dobiti generički kod za blob spremnik koji radi, ali ne slijedi trenutačne Azure obrasce. S Azure MCP-om dobivate kod koji koristi najnovije metode autentifikacije, rukuje specifičnim Azure scenarijima pogrešaka i slijedi Microsoftove preporučene prakse za proizvodne aplikacije.

**Istaknuti primjer**: Imao sam problema s pamćenjem specifičnih naredbi za `az` i `azd` CLI alate za ad-hoc upotrebu. Uvijek je to dvofazni proces za mene: prvo pogledam sintaksu, zatim pokrenem naredbu. Često samo uđem u portal i klikam po njemu da obavim posao jer ne želim priznati da ne mogu zapamtiti sintaksu CLI-ja. Mogućnost da jednostavno opišem što želim je nevjerojatna, a još je bolje to moći učiniti bez napuštanja svog IDE-a!

Postoji sjajan popis slučajeva upotrebe u [Azure MCP spremištu](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) za početak. Za opsežne vodiče za postavljanje i napredne opcije konfiguracije, pogledajte [službenu Azure MCP dokumentaciju](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

**Zašto je korisno**: Neophodno za moderne tijekove rada s dokumentacijom! MarkItDown podržava impresivan broj formata datoteka uz očuvanje ključne strukture dokumenata poput naslova, lista, tablica i poveznica. Za razliku od jednostavnih alata za ekstrakciju teksta, fokusira se na održavanje semantičkog značenja i formatiranja koje je vrijedno i za AI obradu i za čitljivost ljudi.

**Podržani formati datoteka**:
- **Office dokumenti**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Medijski fajlovi**: Slike (s EXIF metapodacima i OCR-om), Audio (s EXIF metapodacima i transkripcijom govora)
- **Sadržaj weba**: HTML, RSS feedovi, YouTube URL-ovi, Wikipedia stranice
- **Format podataka**: CSV, JSON, XML, ZIP datoteke (rekurzivno obrađuje sadržaj)
- **Formati za izdavaštvo**: EPub, Jupyter bilježnice (.ipynb)
- **Email**: Outlook poruke (.msg)
- **Napredno**: Integracija Azure Document Intelligence za naprednu obradu PDF-a

**Napredne mogućnosti**: MarkItDown podržava LLM-om vođene opise slika (kada se koristi OpenAI klijent), Azure Document Intelligence za poboljšanu obradu PDF-ova, transkripciju audio sadržaja, te sustav dodataka za proširenje na dodatne formate datoteka.

**Upotreba u stvarnom svijetu**: "Pretvori ovu PowerPoint prezentaciju u Markdown za naš dokumentacijski site", "Izvuci tekst iz ovog PDF-a s pravilnom strukturom naslova", ili "Pretvori ovaj Excel proračunski list u čitljiv format tablice"

**Istaknuti primjer (parafrazirano)**: 
[MarkItDown dokumentacija](https://github.com/microsoft/markitdown#why-markdown) objašnjava
da Markdown očuva strukturu dokumenata s malo formatiranja.
Jezični modeli često proizvode Markdown, što ga čini korisnim, token-efikasnim
formatom za tijekove rada u obradi dokumenata.

MarkItDown izvrsno čuva strukturu dokumenata, što je važno za AI tijekove rada. Na primjer, prilikom konverzije PowerPoint prezentacije, čuva organizaciju slajdova s ispravnim naslovima, izvlači tablice kao Markdown tablice, uključuje alt tekst za slike, pa čak obrađuje i bilješke govornika. Grafikon se pretvara u čitljive podatkovne tablice, a konačni Markdown očuvava logičan tijek originalne prezentacije. ## 📋 Zaključak

Model Context Protocol (MCP) mijenja način na koji programeri komuniciraju s AI asistentima i vanjskim alatima. Ovi 10 Microsoft MCP servera pokazuju moć standardizirane AI integracije, omogućujući besprijekorne tijekove rada koji programerima omogućuju da ostanu u svom flow stanju dok pristupaju moćnim vanjskim mogućnostima.

Od sveobuhvatne integracije Azure ekosustava do specijaliziranih alata poput Playwrighta za automatizaciju preglednika i MarkItDowna za obradu dokumenata, ovi serveri pokazuju kako MCP može povećati produktivnost u različitim razvojnim scenarijima. Standardizirani protokol osigurava da ovi alati besprijekorno rade zajedno, stvarajući kohezivno iskustvo razvoja.

Kako MCP ekosustav nastavlja rasti, ostati angažiran s zajednicom, istraživati nove servere i izgraditi prilagođena rješenja bit će ključno za maksimiziranje vaše produktivnosti u razvoju. Otvorena priroda MCP standarda znači da možete kombinirati alate različitih dobavljača kako biste stvorili savršen tijek rada za vaše specifične potrebe.
