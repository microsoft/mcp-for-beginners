## 🔧 Razumijevanje MCP poslužitelja: Vodič za početnike

### Što su MCP poslužitelji?

Kao početnik u Model Context Protocolu (MCP), možda se pitate: „Što je točno MCP poslužitelj i zašto mi je važan?“ Počnimo jednostavnom analogijom.

Zamislite MCP poslužitelje kao specijalizirane asistente koji pomažu vašem AI programskom suputniku (poput GitHub Copilota) da se poveže s vanjskim alatima i uslugama. Baš kao što možda koristite različite aplikacije na telefonu za različite zadatke — jednu za vremensku prognozu, drugu za navigaciju, treću za bankarstvo — MCP poslužitelji daju vašem AI asistentu mogućnost interakcije s različitim razvojnim alatima i uslugama.

### Problem koji MCP poslužitelji rješavaju

Prije MCP poslužitelja, ako ste htjeli:
- Provjeriti svoje Azure resurse
- Kreirati GitHub problem
- Upit baze podataka
- Pretražiti dokumentaciju

Morali biste prestati kodirati, otvoriti preglednik, otići na odgovarajuću web stranicu i ručno obaviti te zadatke. Ovo stalno prebacivanje konteksta prekida vaš radni tok i smanjuje produktivnost.

### Kako MCP poslužitelji transformiraju vaše razvojno iskustvo

S MCP poslužiteljima možete ostati u vašem razvojnom okruženju (VS Code, Visual Studio itd.) i jednostavno zamoliti AI asistenta da obavi ove zadatke. Na primjer:

**Umjesto ovog tradicionalnog tijeka rada:**
1. Prestanite kodirati
2. Otvorite preglednik
3. Otiđite na Azure portal
4. Pogledajte detalje o skladišnom računu
5. Vratite se u VS Code
6. Nastavite s kodiranjem

**Sada možete napraviti ovo:**
1. Pitajte AI: „Kakav je status mojih Azure skladišnih računa?“
2. Nastavite kodirati sa dobijenim informacijama

### Ključne prednosti za početnike

#### 1. 🔄 **Ostanite u svom stanju fokusa**
- Nema više prebacivanja između više aplikacija
- Zadržite svoj fokus na kodu koji pišete
- Smanjite mentalni napor upravljanja različitim alatima

#### 2. 🤖 **Koristite prirodni jezik umjesto složenih naredbi**
- Umjesto da pamtite SQL sintaksu, opišite koje podatke trebate
- Umjesto da pamćenje Azure CLI naredbi, objasnite što želite postići
- Neka AI preuzme tehničke pojedinosti dok vi fokusirate na logiku

#### 3. 🔗 **Povežite više alata zajedno**
- Kreirajte snažne tijekove rada kombiniranjem različitih usluga
- Primjer: „Dohvati sve nedavne GitHub probleme i kreiraj odgovarajuće radne stavke u Azure DevOps-u“
- Izgradite automatizaciju bez pisanja složenih skripti

#### 4. 🌐 **Pristup rastućem ekosustavu**
- Iskoristite poslužitelje koje su izgradili Microsoft, GitHub i druge tvrtke
- Kombinirajte i usklađujte alate iz različitih dobavljača bez problema
- Pridružite se standardiziranom ekosustavu koji radi s različitim AI asistentima

#### 5. 🛠️ **Učite kroz praksu**
- Počnite s unaprijed izgrađenim poslužiteljima da razumijete koncepte
- Postupno gradite vlastite poslužitelje kako postajete sigurniji
- Koristite dostupne SDK-ove i dokumentaciju za vođenje učenja

### Primjer iz stvarnog svijeta za početnike

Recimo da ste novi u web razvoju i radite na svom prvom projektu. Evo kako vam MCP poslužitelji mogu pomoći:

**Tradicionalni pristup:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**S MCP poslužiteljima:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### Prednost industrijskog standarda

MCP postaje industrijski standard, što znači:
- **Dosljednost**: Slično iskustvo preko različitih alata i tvrtki
- **Međuproizvodna suradnja**: Poslužitelji različitih dobavljača rade zajedno
- **Zaštita za budućnost**: Vještine i postavke prenose se između različitih AI asistenata
- **Zajednica**: Veliki ekosustav zajedničkog znanja i resursa

## Početak korištenja MCP-a u VS Code i Visual Studio 🚀

Postavljanje ovih MCP poslužitelja je jednostavno ako koristite Visual Studio Code ili Visual Studio 2022 s GitHub Copilotom.

### Postavljanje u VS Code

Osnovni postupak za VS Code izgleda ovako:

1. **Omogući Agent Mode**: U VS Code-u prebacite se na Agent Mode u prozoru Copilot Chat
2. **Konfigurirajte MCP poslužitelje**: Dodajte konfiguracije poslužitelja u datoteku settings.json
3. **Pokrenite poslužitelje**: Kliknite gumb „Start“ za svaki poslužitelj koji želite koristiti
4. **Odaberite alate**: Izaberite koje MCP poslužitelje želite uključiti u trenutnoj sesiji

Za detaljne upute postavljanja pogledajte [VS Code MCP dokumentaciju](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Profesionalni savjet: Upravljajte MCP poslužiteljima kao profesionalac!**
> 
> Pogled upravljačkih ekstenzija u VS Code sada uključuje [praktično novo sučelje za upravljanje instaliranim MCP poslužiteljima](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Imate brz pristup za pokretanje, zaustavljanje i upravljanje bilo kojim instaliranim MCP poslužiteljima putem jasnog i jednostavnog sučelja. Isprobajte!

### Postavljanje u Visual Studio 2022

Za Visual Studio 2022 (verzija 17.14 ili novija):

1. **Omogući Agent Mode**: Kliknite na padajući izbornik „Ask“ u GitHub Copilot Chat prozoru i odaberite „Agent“
2. **Kreiraj konfiguracijsku datoteku**: Stvorite `.mcp.json` datoteku u direktoriju svoje solucije (preporučena lokacija: `<SOLUTIONDIR>\.mcp.json`)
3. **Konfiguriraj poslužitelje**: Dodajte konfiguracije za MCP poslužitelje koristeći standardni MCP format
4. **Odobrenje alata**: Kada se zatraži, odobrite alate koje želite koristiti s odgovarajućim dozvolama

Za detaljne upute za Visual Studio pogledajte [Visual Studio MCP dokumentaciju](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Svaki MCP poslužitelj ima svoje zahtjeve konfiguracije (povezne stringove, autentikaciju itd.), ali obrazac postavljanja je dosljedan u oba IDE-a.

**Što radi**: Microsoft Learn Docs MCP Server je usluga u oblaku koja AI asistentima pruža pristup službenoj Microsoft dokumentaciji u stvarnom vremenu putem Model Context Protocola. Povezuje se s `https://learn.microsoft.com/api/mcp` i omogućava semantičko pretraživanje kroz Microsoft Learn, Azure dokumentaciju, Microsoft 365 dokumentaciju i druge službene Microsoft izvore.

**Zašto je koristan**: Iako se možda čini kao „samo dokumentacija“, ovaj je poslužitelj zapravo ključan za svakog programera koji koristi Microsoft tehnologije. Jedna od najvećih zamjerki .NET programera na AI pomoćnike za kodiranje jest da nisu u toku s najnovijim .NET i C# izdanjima. Microsoft Learn Docs MCP Server to rješava pružajući pristup u stvarnom vremenu najnovijoj dokumentaciji, API referencama i najboljim praksama. Bilo da radite s najnovijim Azure SDK-ovima, istražujete nove značajke C# 13 ili implementirate napredne Aspire obrasce, ovaj poslužitelj osigurava da vaš AI asistent ima pristup autoritativnim, ažurnim informacijama potrebnim za generiranje točnog i suvremenog koda.

**Primjena u stvarnom svijetu**: „Koje su az cli naredbe za kreiranje Azure container aplikacije prema službenoj Microsoft Learn dokumentaciji?“ ili „Kako konfigurirati Entity Framework s dependency injection u ASP.NET Core?“ Ili što kažete na „Pregledaj ovaj kod da vidim da li odgovara preporukama za performanse iz Microsoft Learn dokumentacije.“ Poslužitelj pruža sveobuhvatno pretraživanje Microsoft Learn, Azure i Microsoft 365 dokumentacije koristeći napredno semantičko pretraživanje kako bi pronašao najrelevantnije informacije u kontekstu. Vraća do 10 kvalitetnih sadržajnih segmenata s naslovima članaka i URL-ovima, uvijek pristupajući najnovijoj Microsoft dokumentaciji čim je objavljena.

**Istaknuti primjer**: Poslužitelj izlaže alat `microsoft_docs_search` koji vrši semantičko pretraživanje službene tehničke dokumentacije Microsofta. Jednom konfiguriran, možete postavljati pitanja kao što su „Kako implementirati JWT autentikaciju u ASP.NET Core?“ i dobiti detaljne, službene odgovore s izvorima. Kvaliteta pretraživanja je izvanredna jer razumije kontekst – pitanje o „kontejnerima“ u Azure kontekstu vratit će dokumentaciju o Azure Container Instances, dok isti pojam u .NET kontekstu vraća relevantne informacije o C# kolekcijama.

Ovo je osobito korisno za brzo mijenjajuće ili nedavno ažurirane biblioteke i primjere uporabe. Na primjer, u nekim nedavnim projektima kodiranja želio sam koristiti značajke iz najnovijih izdanja Aspire i Microsoft.Extensions.AI. Uključivanjem Microsoft Learn Docs MCP poslužitelja, uspio sam iskoristiti ne samo API dokumentaciju, već i vodiče te upute koje su upravo objavljene.

### 2. ☁️ Azure MCP poslužitelj


[![Instaliraj u VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Instaliraj u VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Što radi**: Azure MCP Server je sveobuhvatni paket od 15+ specijaliziranih Azure servisnih konektora koji dovodi cijeli Azure ekosustav u vaš AI tijek rada. Ovo nije samo jedan server – to je moćna kolekcija koja uključuje upravljanje resursima, povezivanje s bazama podataka (PostgreSQL, SQL Server), analizu logova Azure Monitora s KQL-om, integraciju Cosmos DB-a i mnogo više.

**Zašto je koristan**: Osim upravljanja Azure resursima, ovaj server značajno poboljšava kvalitetu koda prilikom rada s Azure SDK-ovima. Kada koristite Azure MCP u Agent načinu, on vam ne pomaže samo pisati kod – pomaže vam pisati *bolji* Azure kod koji prati trenutačne obrasce autentifikacije, najbolje prakse za obradu pogrešaka i koristi najnovije značajke SDK-a. Umjesto generičkog koda koji možda radi, dobijete kod koji slijedi Azure preporučene obrasce za proizvodne radne procese.

**Ključni moduli uključuju**:
- **🗄️ Konektori za baze podataka**: Izravni pristup prirodnim jezikom za Azure Database za PostgreSQL i SQL Server
- **📊 Azure Monitor**: KQL-pokretana analiza logova i operativni uvidi
- **🌐 Upravljanje resursima**: Potpuno upravljanje životnim ciklusom Azure resursa
- **🔐 Autentifikacija**: DefaultAzureCredential i obrasci upravljanog identiteta
- **📦 Storage servisi**: Operacije Blob Storage, Queue Storage i Table Storage
- **🚀 Servisi za kontejnere**: Azure Container Apps, Container Instances i upravljanje AKS-om
- **I mnogi drugi specijalizirani konektori**

**Primjena u stvarnom svijetu**: "Navedite moje Azure račune za pohranu", "Upitaj moj Log Analytics radni prostor za pogreške u posljednjem satu", ili "Pomozi mi izraditi Azure aplikaciju koristeći Node.js s pravilnom autentifikacijom"

**Cijeli demo scenarij**: Evo kompletnog prikaza koji pokazuje moć kombiniranja Azure MCP sa GitHub Copilot za Azure ekstenziju u VS Code-u. Kada imate oba instalirana i zatražite:

> "Napravi Python skriptu koja učitava datoteku u Azure Blob Storage koristeći DefaultAzureCredential autentifikaciju. Skripta bi se trebala povezati na moj Azure račun za pohranu naziva 'mycompanystorage', učitati u kontejner naziva 'documents', stvoriti testnu datoteku s trenutnim vremenskim žigom za učitavanje, rukovati pogreškama na nježan način i pružiti informativni ispis, slijediti najbolje Azure prakse za autentifikaciju i obradu pogrešaka, uključiti komentare koji objašnjavaju kako DefaultAzureCredential autentifikacija funkcionira te napraviti skriptu dobro strukturiranom s pravilnim funkcijama i dokumentacijom."

Azure MCP Server će generirati kompletnu, proizvodno spremnu Python skriptu koja:
- Koristi najnoviji Azure Blob Storage SDK s ispravnim asinkronim obrascima
- Implementira DefaultAzureCredential s detaljnim objašnjenjem kompletnog lanaca rezervnih metoda
- Uključuje robusnu obradu pogrešaka sa specifičnim Azure vrstama iznimki
- Prati najbolje prakse Azure SDK-a za upravljanje resursima i rukovanje vezama
- Omogućuje detaljno praćenje i informativni izlaz na konzolu
- Stvara pravilno strukturiranu skriptu s funkcijama, dokumentacijom i naznakama tipova

Ono što je impresivno je da bez Azure MCP-a možete dobiti generički kod za blob pohranu koji radi, ali ne slijedi trenutačne Azure obrasce. S Azure MCP-om dobivate kod koji koristi najnovije metode autentifikacije, rukuje Azure-specifičnim scenarijima pogrešaka i slijedi Microsoftove preporučene prakse za proizvodne aplikacije.

**Istaknuti primjer**: Mučio sam se s pamćenjem specifičnih naredbi za `az` i `azd` CLI alate za ad-hoc korištenje. Uvijek je to za mene dvostupanjski proces: prvo provjeriti sintaksu, zatim pokrenuti naredbu. Često samo odem u portal i klikam po njemu da obavim posao jer ne želim priznati da ne pamtim CLI sintaksu. Mogućnost da samo opišem što želim je izvanredna, a još bolje je moći to učiniti bez napuštanja IDE-a!

Izvrsna se lista slučajeva upotrebe nalazi u [Azure MCP repozitoriju](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) da vam pomogne započeti. Za detaljne vodiče za postavljanje i napredne opcije konfiguracije, pogledajte [službenu Azure MCP dokumentaciju](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

**Što radi**: MarkItDown je sveobuhvatni server za konverziju dokumenata koji pretvara različite formate datoteka u visokokvalitetni Markdown, optimiziran za LLM obradu i tokove rada za analizu teksta.

**Zašto je koristan**: Neophodan za moderne tokove rada s dokumentacijom! MarkItDown podržava impresivan raspon formata datoteka pritom zadržavajući ključnu strukturu dokumenta poput naslova, popisa, tablica i poveznica. Za razliku od jednostavnih alata za izvlačenje teksta, fokusira se na održavanje semantičkog značenja i oblikovanja vrijednog kako za AI obradu, tako i za ljudsku čitljivost.

**Podržani formati datoteka**:
- **Office dokumenti**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Medijski zapisi**: Slike (s EXIF metapodacima i OCR-om), audio (s EXIF metapodacima i transkripcijom govora)
- **Web sadržaj**: HTML, RSS feedovi, YouTube URL-ovi, Wikipedija stranice
- **Podatkovni formati**: CSV, JSON, XML, ZIP datoteke (rekurzivno obrađuje sadržaj)
- **Format za izdavanje**: EPub, Jupyter notebook (.ipynb)
- **Email**: Outlook poruke (.msg)
- **Napredno**: Integracija Azure Document Intelligence za poboljšanu obradu PDF-a

**Napredne mogućnosti**: MarkItDown podržava LLM-pokretane opise slika (kada je dostupan OpenAI klijent), Azure Document Intelligence za poboljšanu obradu PDF-a, transkripciju zvuka za govorni sadržaj te sustav dodataka za proširenje na dodatne formate datoteka.

**Primjena u stvarnom svijetu**: "Pretvori ovu PowerPoint prezentaciju u Markdown za našu stranicu dokumentacije", "Izvuci tekst iz ovog PDF-a uz pravilnu strukturu naslova", ili "Pretvori ovaj Excel tablični dokument u čitljiv tablični format"

**Istaknuti primjer**: Da citiramo [MarkItDown dokumentaciju](https://github.com/microsoft/markitdown#why-markdown):

> Markdown je vrlo blizak običnom tekstu, s minimalnim označavanjem ili oblikovanjem, ali ipak pruža način predstavljanja važne strukture dokumenta. Glavni LLM-ovi, poput OpenAI-jevog GPT-4o, izvorno "govore" Markdown i često ga uključuju u svoje odgovore bez zahtjeva. To sugerira da su trenirani na velikim količinama teksta u Markdown formatu i dobro ga razumiju. Kao dodatna prednost, Markdown konvencije su vrlo učinkovite u pogledu tokena.

MarkItDown je stvarno dobar u očuvanju strukture dokumenta, što je važno za AI tokove rada. Na primjer, pri konverziji PowerPoint prezentacije, zadržava organizaciju slajdova s pravim naslovima, izvlači tablice kao markdown tablice, uključuje alt tekst za slike, pa čak obrađuje i bilješke govornika. Grafikoni se pretvaraju u čitljive podatkovne tablice, a dobiveni Markdown održava logičan tijek originalne prezentacije. To ga čini savršenim za unos sadržaja prezentacije u AI sustave ili za stvaranje dokumentacije iz postojećih slajdova.

- Pružiti naredbe za implementaciju i informacije o kvotama za vaš preferirani Azure regiju
- Postaviti Azure AI Search indekse s pravom shemom za vašu dokumentaciju
- Konfigurirati evaluacijske procese s metrikama kvalitete i sigurnosnim provjerama
- Generirati prototipni kod s GitHub autentifikacijom za neposredno testiranje
- Pružiti detaljne vodiče za postavljanje prilagođene vašem tehnološkom stacku

**Primjer iz prakse**: Kao programer, imao sam poteškoća pratiti različite LLM modele dostupne na tržištu. Znam nekoliko glavnih, ali osjećam da propuštam neke dobitke u produktivnosti i učinkovitosti. Tokeni i kvote su stresni i teško ih je upravljati – nikad ne znam da li biram pravi model za određeni zadatak ili nepotrebno trošim budžet. Upravo sam čuo za ovaj MCP Server od Jamesa Montemagna dok sam tražio preporuke od kolega za ovaj post i uzbuđen sam što ću ga isprobati! Mogućnosti otkrivanja modela posebno su impresivne za nekoga poput mene tko želi istražiti izvan poznatih opcija i pronaći modele optimizirane za specifične zadatke. Okvir za evaluaciju trebao bi mi pomoći potvrditi da zapravo dobivam bolje rezultate, a ne samo da pokušavam nešto novo zbog samog pokušavanja.

## 📋 Zaključak

Protokol Model Context (MCP) transformira način na koji programeri komuniciraju s AI asistentima i vanjskim alatima. Ovih 10 Microsoft MCP servera demonstrira snagu standardizirane integracije AI-ja, omogućujući besprijekorne tijekove rada koji programerima omogućuju da ostanu u stanju produktivnosti dok pristupaju moćnim vanjskim mogućnostima.

Od sveobuhvatne integracije Azure ekosustava do specijaliziranih alata poput Playwrighta za automatizaciju preglednika i MarkItDowna za obradu dokumenata, ovi poslužitelji pokazuju kako MCP može poboljšati produktivnost u različitim razvojnim scenarijima. Standardizirani protokol osigurava da ovi alati rade skladno zajedno, stvarajući kohezivno razvojno iskustvo.

Kako MCP ekosustav nastavlja rasti, važno je ostati uključen u zajednicu, istraživati nove poslužitelje i izrađivati prilagođena rješenja kako biste maksimalno iskoristili svoju razvojnu produktivnost. Otvorena standardna priroda MCP-a znači da možete kombinirati alate različitih proizvođača kako biste stvorili savršen tijek rada za svoje specifične potrebe.
