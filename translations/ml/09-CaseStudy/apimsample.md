# കേസ്സ് സ്റ്റഡി: API മാനേജ്മെന്റിൽ REST API ഒരു MCP സെർവറായി പ്രദർശിപ്പിക്കുക

Azure API Management, നിങ്ങളുടെ API എൻഡ്‌പോയിന്റുകളുടെ മുകളിലൂടെ ഒരു ഗേറ്റ്‌വേ നൽകുന്ന ഒരു സേവനമാണ്. ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു అంటే Azure API Management നിങ്ങളുടെ APIs നു മുൻപിൽ ഒരു പ്രോക്സി പോലെ പ്രവർത്തിച്ച് വരാനിരിക്കുന്ന അഭ്യർത്ഥനകളെ എന്താണെന്നും നിർണ്ണയിക്കാവുന്നതാണ്.

ഇതു ഉപയോഗിച്ച്, നിങ്ങൾക്ക് താഴെപ്പറയുന്നവ പോലുള്ള നിരവധി സവിശേഷതകൾ ഉൾപ്പെടുത്താം:

- **സുരക്ഷ**, API കീകൾ, JWT മുതൽ മാനേജ് ചെയ്ത ഐഡന്റിറ്റി വരെ എല്ലാം നിങ്ങൾക്ക് ഉപയോഗിക്കാം.
- **റേറ്റ് ലിമിറ്റിംഗ്**, ഒരു വലിയ സവിശേഷത എന്തെന്നാൽ ഒരു നിശ്ചിത സമയം യൂണിറ്റിൽ എത്ര കോളുകൾ കടന്നു പോകാൻ അനുവദിക്കാമെന്ന് തീരുമാനിക്കാൻ കഴിവുള്ളതും. ഇത് എല്ലാ ഉപയോക്താക്കൾക്കും മികച്ച അനുഭവം ഉറപ്പാക്കാനും നിങ്ങളുടെ സേവനം അഭ്യർത്ഥനകളാൽ അളവിന് മീതെ ചൊരിയാൻ നിന്നു സംരക്ഷിക്കാനും സഹായിക്കുന്നു.
- **സ്കെയിലിംഗ് & ലോഡ് ബാലൻസിംഗ്**. ലോഡ് തുല്യപ്പെടുത്താൻ പല എൻഡ്‌പോയിന്റുകളും സെറ്റ് ചെയ്യാം, കൂടാതെ നിങ്ങൾക്ക് "ലോഡ് ബാലൻസ്" എങ്ങനെ ചെയ്യണമെന്നു തീരുമാനിക്കാനും കഴിയും.
- **സെമാന്റിക് കാഷിംഗ്, ടോകൺ പരിധി, ടോകൺ നിരീക്ഷണം എന്നിവ പോലുള്ള AI സവിശേഷതകൾ**. ഇവ മികച്ച പ്രതികരണശേഷി നൽകുന്ന കൂടാതെ നിങ്ങളുടെ ടോകൺ ചെലവ് നിയന്ത്രണത്തിലാക്കാൻ സഹായിക്കുന്ന മികച്ച സവിശേഷതകൾ ആണ്. [കൂടുതൽ വായിക്കുക ഇവിടെ](https://learn.microsoft.com/en-us/azure/api-management/genai-gateway-capabilities). 

## MCP + Azure API മാനേജ്മെന്റ് എന്തുകൊണ്ട്?

മോഡൽ കോൺടക്സ് പ്രോട്ടോക്കോൾ ഏജന്റിക് AI ആപ്പുകളുടെയും ടൂളുകളെയും ഡാറ്റയെയും ഒരേ രീതിയിൽ പരസ്യമാക്കുന്നതിനുള്ള ഒരു സ്റ്റാൻഡേഡായി വേഗത്തിൽ മാറുകയാണ്. APIs "മേനേജ്മെന്റ്" ചെയ്യേണ്ടതിനായി Azure API Management ഒരു സ്വാഭാവികമായ തിരഞ്ഞെടുപ്പാണ്. MCP സെർവറുകൾ സാധാരണയായി കൂടെ മറ്റ് APIs സംയോജിപ്പിച്ച് ഒരു ടൂളിലേക്ക് അഭ്യർത്ഥനകൾ പരിഹരിക്കാറാണ്. അതിനാൽ Azure API Management നെയും MCP നെയും ചേർത്തെ ഉപയോഗിക്കുന്നത് വളരെ അർത്ഥമാക്കുന്നു.

## അവലോകനം

ഈ പ്രത്യേക ഉപയോഗത്തിൽ നാം API എൻഡ്‌പോയിന്റുകളെ MCP സെർവറായി എങ്ങനെ പരസ്യമാക്കാമെന്നു പഠിക്കും. ഇതിലൂടെ, ഈ എൻഡ്‌പോയിന്റുകൾ എളുപ്പത്തിൽ ഏജന്റിക് ആപ്പിന്റെ ഭാഗമാക്കാൻ കഴിയും കൂടാതെ Azure API Management ലെ സവിശേഷതകൾ ഉപയോഗിക്കാനും കഴിയും.

## പ്രധാന സവിശേഷതകൾ

- നിങ്ങൾ ടൂളുകളായി പരസ്യമാക്കാൻ ആഗ്രഹിക്കുന്ന എൻഡ്‌പോയിന്റ് മെഥഡുകൾ തിരഞ്ഞെടുക്കും.
- നിങ്ങൾക്ക് ലഭിക്കുന്ന അധിക സവിശേഷതകൾ നിങ്ങളുടെ API നുള്ള പാളിസി സെക്ഷനിൽ സംരചിക്കുന്ന വിധത്തിൽ ആശ്രയിക്കുന്നതാണ്. പക്ഷേ ഇവിടെ നാം റേറ്റ് ലിമിറ്റിംഗ് എങ്ങനെ ചേർക്കാമെന്ന് കാണിക്കും.

## മുൻപുളള ചുവടു: ഒരു API ഇറക്കുമതി ചെയ്യുക

നിങ്ങൾക്ക് Azure API Management ൽ ഒരു API തത്സമയം ഉള്ളതായി എങ്കിൽ നല്ലതാണ്, പിന്നീട് ഈ ഘട്ടം ഒഴിവാക്കാം. ഇല്ലെങ്കിൽ ഇതു പരിശോധിക്കുക, [Azure API Management ൽ API ഇറക്കുമതി ചെയ്യൽ](https://learn.microsoft.com/en-us/azure/api-management/import-and-publish#import-and-publish-a-backend-api).

## API MCP സെർവറായി പരസ്യമാക്കുക

API എൻഡ്‌പോയിന്റുകൾ പരസ്യമാക്കാൻ, ഈ ചുവടുകൾ പിന്തുടരുക:

1. Azure പോർട്ടലിലേക്കു പോവുക, താഴെപ്പറയുന്ന വിലാസം സന്ദർശിക്കുക <https://portal.azure.com/?Microsoft_Azure_ApiManagement=mcp> 
നിങ്ങളുടെ API മാനേജ്മെന്റ് ഇൻസ്റ്റൻസ് വഴി നാവിഗേറ്റ് ചെയ്യുക.

1. ഇടത്തു ഇനിൻമുള്ള മെനുവിൽ, APIs > MCP Servers > + Create new MCP Server തിരഞ്ഞെടുക്കുക.

1. API ത്തിൽ MCP സെർവറായി പരസ്യമാക്കാനുള്ള REST API തിരഞ്ഞെടുത്തുക.

1. ഉപകരണങ്ങളായി പരസ്യമാക്കാൻ ഒരോ ഒരു API ഓപ്പറേഷൻ തിരഞ്ഞെടുക്കുക. നിങ്ങൾക്ക് എല്ലാ ഓപ്പറേഷനുകളും അല്ലെങ്കിൽ കൃത്യമായ ചില ഓപ്പറേഷനുകൾ മാത്രമേ തിരഞ്ഞെടുക്കാൻ കഴിയൂ.

    ![പരസ്യമാക്കാനുള്ള മെഥഡുകൾ തിരഞ്ഞെടുക്കുക](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/create-mcp-server-small.png)


1. **Create** തിരഞ്ഞെടുക്കുക.

1. മെനു ഓപ്ഷനുകളിൽ **APIs** ഉം **MCP Servers** ഉം തിരഞ്ഞെടുത്താൽ അടുത്തത് കാണും:

    ![പ്രധാന പെയ്നിൽ MCP സെർവർ കാണുക](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-list.png)

    MCP സെർവർ സൃഷ്ടിക്കപ്പെട്ടു, API ഓപ്പറേഷനുകൾ ടൂളുകളായാണ് പരസ്യമാക്കപ്പെട്ടത്. MCP സെർവർ MCP Servers പെയ്നിൽ ലിസ്റ്റ് ചെയ്യപ്പെട്ടിരിക്കുന്നു. URL കോളം MCP സെർവറിന്റെ എൻഡ്‌പോയിന്റ് കാണിക്കുന്നു, ഇത് നിങ്ങൾ ടെസ്റ്റിന് വിളിക്കാനും ക്ലയന്റ് ആപ്പിൽ ഉപയോഗിക്കാനും കഴിയും.

## ഐച്ഛികം: നയങ്ങൾ ക്രമീകരിക്കുക

Azure API Management നെ പല വിധത്തിലുള്ള എൻഡ്‌പോയിന്റിനുള്ള വ്യത്യസ്ത നിയമങ്ങൾ ക്രമീകരിക്കാൻ പോലീസി എന്ന കേർ കോൺസെപ്റ്റ് ഉള്ളതാണ്, ഉദാഹരണം ആയി റേറ്റ് ലിമിറ്റിംഗ് അല്ലെങ്കിൽ സെമാന്റിക് കാഷിംഗ്. ഈ നയങ്ങൾ XML രൂപത്തിൽ എഴുതപ്പെടുന്നു.

MCP സെർവറിന് റേറ്റ് ലിമിറ്റ് നയം ക്രമീകരിക്കുന്നത് ഇങ്ങനെ:

1. പോർട്ടലിൽ APIs ത്തിൽ MCP Servers തിരഞ്ഞെടുക്കുക.

1. നിങ്ങൾ സൃഷ്ടിച്ച MCP സെർവർ തിരഞ്ഞെടുക്കുക.

1. ഇടതു മെനുവിൽ MCP ൽ പോളിസികൾ തിരഞ്ഞെടുക്കുക.

1. പോളിസി എഡിറ്ററിൽ MCP സെർവറിന്റെ ടൂളുകളിൽ പ്രയോഗിക്കുവാൻ ആഗ്രഹിക്കുന്ന പോളിസികൾ ചേർക്കുകയോ തിരുത്തുകയോ ചെയ്യുക. പോളിസികൾ XML ഫോർമാറ്റിലാണ് നിർവ്വചിച്ചത്. ഉദാഹരണത്തിന്, MCP സെർവറിന്റെ ടൂളുകളിലേക്കുള്ള വിളികൾ 30 സെക്കന്റ് കേജ് 5 കോളുകൾ എന്നിങ്ങനെ നിയന്ത്രിക്കുന്ന പോളിസി ചേർക്കാം. ഇത് റേറ്റ് ലിമിറ്റിംഗ് ഉണ്ടാക്കും:

    ```xml
     <rate-limit-by-key calls="5" 
       renewal-period="30" 
       counter-key="@(context.Request.IpAddress)" 
       remaining-calls-variable-name="remainingCallsPerIP" 
    />
    ```

    പോളിസി എഡിറ്ററിന്റെ ചിത്രം കാണുക:

    ![പോളിസി എഡിറ്റർ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-policies-small.png)
 
## പരീക്ഷിച്ചു നോക്കൂ

നമ്മുടെ MCP സെർവർ ത歌ദ്ദേശിച്ചപോലെ പ്രവർത്തിക്കുന്നുവെന്ന് ഉറപ്പാക്കാം.

> [!NOTE]
> Azure API Management നിലവിൽ ഈ സെർവറെ Streamable
> HTTP `/mcp` എൻഡ്‌പോയിന്റിലൂടെ പ്രദർശിപ്പിക്കുന്നു. പഴയ HTTP+SSE `/sse` ട്രാൻസ്പോർട്ട് അപവാദമായി മാറിയിട്ടുണ്ട്
> പഴയ ക്ലയന്റുകളോടു മാത്രമാണ് ഇത് ഉപയോഗിക്കേണ്ടത്.

ഇതിന്, നാം Visual Studio Code, GitHub Copilot, അതിന്റെ ഏജന്റ് മോഡ് എന്നിവ ഉപയോഗിക്കും. MCP സെർവർ *mcp.json* ൽ ചേർക്കും. ഇതിലൂടെ Visual Studio Code ഏജന്റിക് കഴിവുള്ള ഒരു ക്ലയന്റായി പ്രവർത്തിക്കും, അന്തിമ ഉപയോക്താക്കൾ പ്രോംപ്റ്റ് টাইപ്പ് ചെയ്ത് ആ സെർവറുമായി പ്രമോഹിക്കാനാകും.

MCP സെർവർ Visual Studio Code ൽ എങ്ങനെ ചേർക്കാം നോക്കാം:

1. കമാൻഡ് പാലറ്റിൽ നിന്ന് MCP: **Add Server command** ഉപയോഗിക്കുക.

1. പ്രോംപ്റ്റ് വന്നപ്പോൾ സെർവർ തരം തിരഞ്ഞെടുക്കുക: **HTTP (HTTP or Server Sent Events)**.

1. API Management ൽ MCP സെർവറിനുള്ള Streamable HTTP URL നൽകുക.
    ഉദാഹരണം:
    `https://<apim-service-name>.azure-api.net/<api-name>-mcp/mcp`.

1. നിങ്ങളുടെ ഇഷ്ടത്തിന് അനുയോജ്യമായ സെർവർ ഐഡി നൽകുക. ഇത് നിർണായകമല്ല, പക്ഷേ ഈ സെർവർ ഇൻസ്റ്റൻസ് എന്താണെന്നു നിങ്ങൾക്ക് ഓർമ്മിപ്പിക്കും.

1. കോൺഫിഗറേഷൻ വർക്ക്‌സ്‌പേസിന്റെ സെറ്റിംഗ്സിൽ അല്ലെങ്കിൽ ഉപയോക്തൃ സെറ്റിംഗ്സിൽ സേവ് ചെയ്യാമെന്ന് തെരഞ്ഞെടുക്കുക.

  - **വർക്ക്സ്‌പേസ് സെറ്റിങ്സ്** - സെർവർ കോൺഫിഗറേഷൻ നിലവിലെ വർക്ക്‌സ്‌പേസിൽ മാത്രം ലഭ്യമാകുന്ന .vscode/mcp.json ഫയലിൽ സേവ് ചെയ്യപ്പെടും.

    *mcp.json*

    ```json
    "servers": {
        "APIM petstore" : {
            "type": "http",
            "url": "url-to-mcp-server/mcp"
        }
    }
    ```

  - **ഉപയോക്തൃ സെറ്റിങ്സ്** - സെർവർ കോൺഫിഗർ *settings.json* എന്ന ഗ്ലോബൽ ഫയലിൽ ചേർക്കപ്പെടും, എല്ലാ വർക്ക്‌സ്‌പേസുകളിലും ലഭ്യമാണ്. കോൺഫിഗറേഷൻ ഇങ്ങനെ തോന്നും:

    ![ഉപയോക്തൃ സെറ്റിംഗ്](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-servers-visual-studio-code.png)

1. നിങ്ങൾക്ക് Azure API Management ന് ശരിയായ വരിക്കുള്ള സമർപ്പണം ഉറപ്പാക്കാൻ കോൺഫിഗറേഷനായി ഹെട്ഡർ ചേർക്കേണ്ടതുണ്ട്. ഇത് **Ocp-Apim-Subscription-Key** എന്ന ഹെഡർ ഉപയോഗിക്കുന്നു.

    - സജ്ജമാക്കുന്നതിന് എങ്ങനെ ആണ് ഇതു ചേര്ക്കുക:

    ![അധികാരപ്രമാണത്തിനായി ഹെഡർ ചേർക്കൽ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-with-header-visual-studio-code.png), ഇത് പ്രോംപ്റ്റ് കാണിക്കുകയും API കീ മൂല്യം നൽകാൻ ആവശ്യപ്പെടുകയും ചെയ്യും, ഇത് Azure പോർട്ടലിൽ നിങ്ങളുടെ Azure API Management ഇൻസ്റ്റൻസിലുണ്ടാകും.

   - *mcp.json*-ൽ ചേർക്കാൻ വേണ്ടി നിങ്ങൾക്ക് ഇങ്ങനെ ചേർക്കാം:

    ```json
    "inputs": [
      {
        "type": "promptString",
        "id": "apim_key",
        "description": "API Key for Azure API Management",
        "password": true
      }
    ]
    "servers": {
        "APIM petstore" : {
            "type": "http",
            "url": "url-to-mcp-server/mcp",
            "headers": {
                "Ocp-Apim-Subscription-Key": "Bearer ${input:apim_key}"
            }
        }
    }
    ```

### ഏജന്റ് മോഡ് ഉപയോഗിക്കുക

ഇപ്പോൾ കോൺഫിഗറേഷൻ സജ്ജമാക്കി, അതാ സെറ്റിംഗ്സിലും അല്ലെങ്കിൽ *.vscode/mcp.json* ൽ. പരീക്ഷിച്ചു നോക്കാം.

ടൂൾസ് ഐകൺ ഇങ്ങനെ വേണം, അവിടെ സെർവറിൻറെ പരസ്യമായ ടൂളുകൾ ലിസ്റ്റ് ചെയ്തിരിക്കും:

![സെർവറിലുള്ള ടൂളുകൾ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/tools-button-visual-studio-code.png)

1. ടൂൾസ് ഐകൺ ക്ലിക് ചെയ്യുക. ടൂളുകളുടെ ലിസ്റ്റ് കാണും:

    ![ടൂളുകൾ](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/select-tools-visual-studio-code.png)

1. ടൂൾ പ്രവർത്തിപ്പിക്കാൻ ചാറ്റിൽ പ്രോംപ്റ്റ് നൽകുക. ഉദാഹരണത്തിന്, നിങ്ങൾ ഓർഡറിന 관한 വിവരങ്ങൾ ലഭിക്കാൻ ഒരു ടൂൾ തിരഞ്ഞെടുക്കുകയാണെങ്കിൽ, ഏജന്റ്‌റെ ഒഡറിനെക്കുറിച്ച് ചോദിക്കാം. ഉദാഹരണ പ്രോംപ്റ്റ്:

    ```text
    get information from order 2
    ```

    ഇനി ഒരു ടൂൾ പ്രവർത്തിപ്പിക്കാനായി ടൂൾസ് ഐകൺ കാണിക്കും. തുടർന്നു ടൂൾ പ്രവർത്തിപ്പിക്കാൻ തെരഞ്ഞെടുത്താൽ, താഴെപ്പറയുന്ന രീതിയിൽ ഔട്ട്‌പുട്ട് കാണും:

    ![പ്രോംപ്റ്റിൽ നിന്നുള്ള ഫലം](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/chat-results-visual-studio-code.png)

    **ഇവിടെ കാണുന്നത് നിങ്ങൾ സജ്ജമാക്കിയ ടൂളുകളെ ആശ്രയിച്ചിരിക്കുന്നു, എന്നാൽ ആശയം നിങ്ങൾക്ക് മുകളിൽ കാണുന്ന പോലെ ടെക്സ്റ്റ് പ്രതികരണം ലഭിക്കുന്നതാണ്**
