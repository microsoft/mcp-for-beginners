# MCP കാൽക്കുലേറ്റർ സെർവർ (പൈതൺ)



പൈതണിൽ ലളിതമായ മോഡൽ കോൺടെക്‌സ് പ്രോട്ടോക്കോൾ (MCP) സെർവർ നടപ്പാക്കൽ, അടിസ്ഥാന കാൽക്കുലേറ്റർ പ്രവർത്തനക്ഷമത നൽകുന്നു.


## ഇൻസ്റ്റലേഷൻ

ആവശ്യമായ ഡിപ്പൻഡൻസികൾ ഇൻസ്റ്റാൾ ചെയ്യുക:

```bash
pip install -r requirements.txt
```

അല്ലെങ്കിൽ MCP Python SDK നേരിട്ട് ഇൻസ്റ്റാൾ ചെയ്യുക:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## ഉപയോഗം

### സെർവർ പ്രവർത്തിപ്പിക്കൽ

സെർവർ MCP ക്ലയന്റുകൾ (പോലെ Claude ഡെസ്‌ക്ടോപ്പ്) ഉപയോഗിക്കാനായി രൂപകൽപ്പന ചെയ്തത് ആണ്. സെർവർ തുടങ്ങാൻ:

```bash
python mcp_calculator_server.py
```

**കുറിപ്പ്**: ടേർമിനലിൽ നേരിട്ട് പ്രവർത്തിപ്പിക്കുമ്പോൾ, JSON-RPC പരിശോദന പിശകുകൾ കാണാം. ഇത് സാധാരണ പ്രവൃത്തി ആഖ്യാനമാണ് - സെർവർ ശരിയായ MCP ക്ലയന്റ് സന്ദേശങ്ങൾക്കായി കാത്തിരിക്കുന്നു.

### പ്രവർത്തനങ്ങൾ പരിശോദിക്കൽ

കാൽക്കുലേറ്റർ പ്രവർത്തനങ്ങൾ ശരിയായി പ്രവർത്തിക്കുന്നുവോ എന്ന് പരിശോധിക്കാൻ:

```bash
python test_calculator.py
```

## പ്രശ്ന പരിഹാര മാർഗങ്ങൾ

### ഇറക്കുമതി പിശകുകൾ

`ModuleNotFoundError: No module named 'mcp'` എന്ന് കാണുമ്പോൾ, MCP Python SDK ഇൻസ്റ്റാൾ ചെയ്യുക:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### നേരിട്ട് പ്രവർത്തിപ്പിക്കുമ്പോൾ JSON-RPC പിശകുകൾ

"Invalid JSON: EOF while parsing a value" പോലുള്ള പിശകുകൾ സെർവർ നേരിട്ട് പ്രവർത്തിപ്പിക്കുമ്പോൾ പ്രതീക്ഷിക്കാവുന്നതാണ്. സെർവർ MCP ക്ലയന്റ് സന്ദേശങ്ങൾ വേണ്ടതാണ്, നേരിട്ടുള്ള ടേർമിനൽ ഇൻപുട്ട് അല്ല.
