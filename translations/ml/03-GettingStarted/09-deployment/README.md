# MCP സെർവറുകൾ വിന്യസിക്കൽ

> [!NOTE]
> `/sse` എൻഡ്പോയിന്റ് ഉപയോഗിക്കുന്ന കോൺഫിഗറേഷൻ ഉദാഹരണങ്ങൾ പാരമ്പര്യ HTTP+SSE
> ട്രാൻസ്പോർട്ടിനെ ലക്ഷ്യമിടുന്നു. MCP `2026-07-28` റിമോട്ട് സെർവറുകൾ സാധാരണയായി
> `/mcp` പോലുള്ള സെർവർ നിർവ്വചിച്ച എൻഡ്പോയിന്റിൽ Streamable HTTP ഉപയോഗിക്കുന്നു.

നിങ്ങളുടെ MCP സെർവർ വിന്യസിക്കുന്നത് മറ്റ് ആളുകൾക്ക് നിങ്ങളുടെ ലൊക്കൽ പരിതസ്ഥിതിക്ക് മപ്പിലുള്ള അവന്റെ ടൂളുകളും വിഭവങ്ങളും പ്രവേശിക്കുവാൻ അനുവദിക്കുന്നു. സ്കെയിലബിലിറ്റി, വിശ്വാസ്യത, മാനേജ്മെന്റ് സൗകര്യം എന്നിവയെ ആശ്രയിച്ച് പല വിന്യാസ തന്ത്രങ്ങൾ പരിഗണിക്കാം. താഴെ നിങ്ങൾക്ക് MCP സെർവറുകൾ ലൊക്കലായി, കണ്ടെയ്‌നറുകളിൽ, ക്ലൗഡിലേയ്ക്കും വിന്യസിക്കുന്നതിന്റെ മാർഗ്ഗനിർദ്ദേശം ലഭിക്കും.

## അവലോകനം

നിങ്ങളുടെ MCP സെർവർ ആപ്പ് എങ്ങനെ വിന്യസിക്കുക എന്നതിനെ കുറിച്ചുള്ള പാഠമാണ് ഇത്.

## പഠന ലക്ഷ്യങ്ങൾ

ഈ പാഠം കഴിഞ്ഞാൽ, നിങ്ങൾക്ക് സാധിക്കും:

- വിവിധ വിന്യാസ രീതികൾ വിലയിരുത്തുക.
- നിങ്ങളുടെ ആപ്പ് വിന്യസിക്കുക.

## ലൊക്കൽ വികസനം және വിന്യാസം

നിങ്ങളുടെ സെർവർ ഉപയോക്താക്കളുടെ മെഷീനിൽ പ്രവർത്തിക്കാനുള്ളത് ആണെങ്കിൽ, താഴെ പറയുന്ന ഘട്ടങ്ങൾ പിന്തുടരാം:

1. **സെർവർ ഡൗൺലോഡ് ചെയ്യുക**. സെർവർ നിങ്ങൾ എഴുതിയിട്ടില്ലെങ്കിൽ ആദ്യം അത് നിങ്ങളുടെ മെഷീനിലേക്ക് ഡൗൺലോഡ് ചെയ്യുക.
1. **സെർവർ പ്രോസസ്സ് ആരംഭിക്കുക**: നിങ്ങളുടെ MCP സെർവർ ആപ്പ് പ്രവർത്തിപ്പിക്കുക

SSEയ്ക്കായി (stdio തര സാഹായം ആവശ്യമില്ല)

1. **നെറ്റ്‌വർക്ക് ക്രമീകരിക്കുക**: സെർവർ പ്രതീക്ഷിക്കപ്പെട്ട പോർട്ടിൽ പ്രവേശനയോഗ്യമാകണം
1. **ക്ലയന്റുകൾ കണക്ട് ചെയ്യുക**: `http://localhost:3000` പോലുള്ള ലൊക്കൽ കണക്ഷൻ URLകൾ ഉപയോഗിക്കുക

## ക്ലൗഡ് വിന്യാസം

MCP സെർവറുകൾ വിവിധ ക്ലൗഡ് പ്ലാറ്റ്ഫോമുകളിൽ വിന്യസിക്കാം:

- **സെർവർലെസ് ഫംഗ്ഷനുകൾ**: ലളിതമായ MCP സെർവറുകൾ സെർവർലെസ് ഫംഗ്ഷനുകളായി വിന്യസിക്കുക
- **കണ്ടെയ്‌നർ സർവീസുകൾ**: Azure Container Apps, AWS ECS, അല്ലെങ്കിൽ Google Cloud Run പോലുള്ള സേവനങ്ങൾ ഉപയോഗിക്കുക
- **കുബർനേറ്റിസ്**: ഉയർന്ന ലഭ്യതയ്ക്കായി MCP സെർവറുകൾ കുബർനേറ്റിസ് ക്ലസ്റ്ററുകളിൽ വിന്യസിക്കുകയും നിയന്ത്രിക്കുകയും ചെയ്യുക

### ഉദാഹരണം: Azure Container Apps

Azure Container Apps MCP സെർവറുകളുടെ വിന്യാസത്തെ പിന്തുണയ്ക്കുന്നു. ഇത് ഇപ്പോഴും പുരോഗമനത്തിലാണെന്നും നിലവിൽ SSE സെർവറുകൾ പിന്തുണയ്ക്കുന്നു.

ഈവിധം ഇത് ചെയ്യാം:

1. ഒരു റീപ്പോ ക്ലോൺ ചെയ്യുക:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. പരീക്ഷിക്കാൻ അത് ലൊക്കലായി പ്രവർത്തിപ്പിക്കുക:

  ```sh
  uv venv
  uv sync

  # ലിനക്സ്/മാക്‌ഓ.എസ്
  export API_KEYS=<AN_API_KEY>
  # വിൻഡോഴ്സ്
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. ലൊക്കലായി പരീക്ഷിക്കാൻ, *.vscode* ഡയറക്ടറിയിൽ *mcp.json* ഫയൽ സൃഷ്ടിച്ച് താഴെ പറയുന്ന ഉള്ളടക്കം ചേർക്കുക:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  SSE സെർവർ സ്റ്റാർട്ട് ചെയ്തതിനു ശേഷം, JSON ഫയലിൽ പ്ലേ ഐക്കണിൽ ക്ലിക്ക് ചെയ്യാം, GitHub Copilot സെർവറിലെ ടൂളുകൾ കണ്ടെത്തുന്നത് കാണാൻ സാധിക്കും, ടൂൾ ഐക്കൺ കാണുക.

1. വിന്യസിക്കാൻ, താഴെ കാണുന്ന കമാൻഡ് ഓടിക്കുക:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

ഇതാണ്, ഈ ഘട്ടങ്ങൾ പാലിച്ച് ലൊക്കലായി അല്ലെങ്കിൽ Azure ലേക്ക് വിന്യസിക്കാം.
