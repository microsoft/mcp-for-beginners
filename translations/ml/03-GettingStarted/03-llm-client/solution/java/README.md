# കാൽക്കുലേറ്റർ LLM ക്ലയന്റ്

LangChain4j ഉപയോഗിച്ച് MCP (Model Context Protocol) കാൽക്കുലേറ്റർ സർവീസുമായി MiniMax OpenAI-സഹജമായ API വഴി ബന്ധപ്പെടുന്നത് എങ്ങനെ ചെയ്യാമെന്ന് കാണിക്കുന്ന ഒരു ജാവ അപ്ലിക്കേഷൻ.

## മുൻ‌വിധികൾ

- ജാവ 21 അല്ലെങ്കിൽ അതിന് മുകളിലുള്ള ഒരു പതിപ്പ്
- Maven 3.6+ (അഥവാ ഉൾപ്പെടുത്തിയ Maven wrapper ഉപയോഗിക്കുക)
- ഒരു MiniMax API കീ
- `http://localhost:8080`-ൽ പ്രവർത്തിക്കുന്ന MCP കാൽക്കുലേറ്റർ സർവീസ്

## API കീ എങ്ങനെ നേടാം

ഈ അപ്ലിക്കേഷൻ MiniMax OpenAI-സഹജമായ API ഉപയോഗിക്കുന്നു. നിങ്ങളുടെ കീയും എൻഡ്‌പോയിന്റും ലഭിക്കുന്നതിന് താഴെ പറയുന്ന ചുവടുകൾ പിന്തുടരുക:

### 1. ഒരു എൻഡ്‌പോയിന്റ് തിരഞ്ഞെടുക്കുക
1. ഗ്ലോബൽ എൻഡ്‌പോയിന്റിന് `https://api.minimax.io/v1` ഉപയോഗിക്കുക
2. ചൈന എൻഡ്‌പോയിന്റിന് `https://api.minimaxi.com/v1` ഉപയോഗിക്കുക

### 2. API കീ സൃഷ്ടิกരിക്കുക
1. നിങ്ങളുടെ MiniMax അക്കൗണ്ടിൽ നിന്നു MiniMax API കീ സൃഷ്ടിക്കുക
2. കി സുരക്ഷിതമായ എവിടെയെങ്കിലും സൂക്ഷിക്കുക

### 3. പരിസ്ഥിതി.characters മാറ്റുക

#### Windows (Command Prompt)ൽ:
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### Windows (PowerShell)ൽ:
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### macOS/Linux-ൽ:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## സെറ്റ് അപ്പ് ആൻഡ് ഇൻസ്റ്റലേഷൻ

1. **പ്രോജക്റ്റ് ഡയറക്ടറിയിലേക്ക് ക്ലോൺ ചെയ്യുക അല്ലെങ്കിൽ പോകുക**

2. **അനുബന്ധങ്ങൾ ഇൻസ്റ്റാൾ ചെയ്യുക**:
   ```cmd
   mvnw clean install
   ```
   അല്ലെങ്കിൽ മാവേൻ ഗ്ലോബലായി ഇൻസ്റ്റാൾ ചെയ്തിട്ടുണ്ടെങ്കിൽ:
   ```cmd
   mvn clean install
   ```

3. **പരിസ്ഥിതി.characters മാറ്റം സജ്ജമാക്കുക** ("Getting the API Key" വിഭാഗം കാണുക)

4. **MCP കാൽക്കുലേറ്റർ സർവീസ് ആരംഭിക്കുക**:
   `http://localhost:8080/sse`-ൽ अध्याय 1-ലെ MCP കാൽക്കുലേറ്റർ സർവീസ് പ്രവർത്തിക്കുകയാണെന്ന് ഉറപ്പ് വരുത്തുക. ക്ലയന്റ് ആരംഭിക്കുന്നതിന് മുമ്പ് ഇത് പ്രവർത്തിക്കണം.

## അപ്ലിക്കേഷൻ പ്രവർത്തിപ്പിക്കൽ

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## അപ്ലിക്കേഷൻ എന്ത് ചെയ്യുന്നു

അപ്ലിക്കേഷൻ കാൽക്കുലേറ്റർ സർവീസുമായി മൂന്ന് പ്രധാന ഇടപെടലുകൾ പ്രദർശിപ്പിക്കുന്നു:

1. **ചേർക്കലും കൂട്ടിച്ചേർക്കൽ**: 24.5 ഉം 17.3 ഉം കൂട്ടിച്ചേർക്കുന്നു
2. **സ്ക്വയർ റൂട്ട്**: 144-ന്റെ സ്ക്വയർ റൂട്ടിൻറെ മൂല്യം കണക്കാക്കുന്നു
3. **സഹായം**: ലഭ്യമായ കാൽക്കുലേറ്റർ ഫംഗ്ഷനുകൾ കാണിക്കുന്നു

## പ്രതീക്ഷിക്കുന്ന ഔട്ട്പുട്ട്

വിജയകരമായി പ്രവർത്തിക്കുമ്പോൾ, നിങ്ങൾക്ക് താഴെ കാണുന്ന പോലുള്ള ഔട്ട്പുട്ട് കാണാനാകും:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## പ്രശ്‌നപരിഹാരം

### സാധാരണ പ്രശ്‌നങ്ങൾ

1. **"OPENAI_API_KEY പരിസ്ഥിതി.characters സജ്ജമാക്കിയിട്ടില്ല"**
   - `OPENAI_API_KEY` പരിസ്ഥിതി.characters മാറ്റം സജ്ജമാക്കിയിട്ടുണ്ടെന്ന് ഉറപ്പ് വരുത്തുക
   - മാറ്റം ചെയ്തതിന് ശേഷം ടർമിനൽ/കമാൻഡ് പ്രോമ്പ്റ്റ് വീണ്ടും ആരംഭിക്കുക

2. **"localhost:8080-യിലേക്ക് കണക്ഷൻ മടക്കി നിഷേധിച്ചു"**
   - MCP കാൽക്കുലേറ്റർ സർവീസ് പോർട്ട് 8080-ൽ പ്രവർത്തിക്കുന്നുണ്ടെന്ന് ഉറപ്പ് വരുത്തുക
   - മറ്റൊരു സർവീസ് പോർട്ട് 8080 ഉപയോഗിക്കുന്നുണ്ടോ എന്ന് പരിശോധിക്കുക

3. **"അധികാരശേഖരണം പരാജയപ്പെട്ടു"**
   - നിങ്ങളുടെ API കീ സാധുവാണെന്ന് പരിശോധിക്കുക
   - `OPENAI_BASE_URL` നിങ്ങൾ ഉപയോഗിക്കാൻ ഉദ്ദേശിച്ച എൻഡ്‌പോയിന്റുമായി പൊരുത്തപ്പെടുന്നുണ്ടോ എന്ന് പരിശോധിക്കുക

4. **Maven ബിൽഡ് പിശകുകൾ**
   - ജാവ 21 അല്ലെങ്കിൽ അതിന് മുകളിലുള്ള പതിപ്പാണ് നിങ്ങൾ ഉപയോഗിക്കുന്നത് എന്ന് ഉറപ്പ് വരുത്തുക: `java -version`
   - ബിൽഡ് ಕ್ಲീൻ ചെയ്യാൻ ശ്രമിക്കുക: `mvnw clean`

### ഡിബഗ്ഗിംഗ്

ഡിബഗ് ലോഗിംഗ് ഒരുക്കാൻ, പ്രവർത്തിക്കുമ്പോൾ താഴെ പറയുന്ന JVM ആർഗ്യൂമെന്റ് കൂടി ചേർക്കുക:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## കോൺഫിഗറേഷൻ

അപ്ലിക്കേഷൻ ക്രമീകരിച്ചിരിക്കുന്നത്:
- സാധാരണയായി MiniMax-M3 ഉപയോഗിക്കുന്നത്, അല്ലെങ്കിൽ `MINIMAX_MODEL_ID` സജ്ജമാക്കിയാൽ MiniMax-M2.7 ഉപയോഗിക്കുന്നു
- `OPENAI_BASE_URL` സജ്ജമാക്കിയാൽ അതുമായി ബന്ധപ്പെടുന്നു; അല്ലെങ്കിൽ `MINIMAX_REGION=cn_zh` ആണെങ്കിൽ `https://api.minimaxi.com/v1` ഉപയോഗിക്കുകയും അല്ലെങ്കിൽ സാധാരണമായി `https://api.minimax.io/v1` ഉപയോഗിക്കുകയും ചെയ്യുന്നു
- MCP സർവീസുമായി `http://localhost:8080/sse`-ൽ ബന്ധപ്പെടുന്നു
- അഭ്യർത്ഥനകൾക്ക് 60 സെക്കൻറ് ടൈംഔട്ട് ഉണ്ട്

## ആശ്രിതകൾ

ഈ പ്രോജക്റ്റിൽ ഉപയോഗിക്കുന്ന പ്രധാന ആശ്രിതകൾ:
- **LangChain4j**: AI ഇന്റഗ്രേഷൻക്കും ഉപകരണ മാനേജ്മെന്റിനും
- **LangChain4j MCP**: Model Context Protocol പിന്തുണയ്ക്കും

- **Spring Boot**: അപ്ലിക്കേഷൻ ഫ്രെയിംവർക്കിനും ആശ്രിത എൻജക്ഷനിനും
