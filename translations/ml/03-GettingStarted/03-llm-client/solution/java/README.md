# കാൽക്കുലേറ്റർ LLM ക്ലയന്റ്

LangChain4j ഉപയോഗിച്ച് MCP (Model Context Protocol) കാൽക്കുലേറ്റർ സേവനവുമായി MiniMax OpenAI-സമാനമായ API വഴിയുള്ള കണക്ഷൻ എങ്ങനെ സ്ഥാപിക്കാമെന്ന് കാണിക്കുന്ന ഒരു ജാവ അപ്ലിക്കേഷൻ.

## മുൻകൂട്ടി ആവശ്യമുള്ള കാര്യങ്ങൾ

- ജാവ 21 അല്ലെങ്കിൽ അതിനുമുകൾ
- മാവൺ 3.6+ (അല്ലെങ്കിൽ ഉൾപ്പെടുത്തിയ മാവൺ റാപ്പർ ഉപയോഗിക്കുക)
- ഒരു MiniMax API കീ
- `http://localhost:8080` ൽ പ്രവർത്തിക്കുന്ന ഒരു MCP കാൽക്കുലേറ്റർ സേവനം

## API കീ എടുക്കൽ

ഈ അപ്ലിക്കേഷൻ MiniMax OpenAI-സമാനമായ API ഉപയോഗിക്കുന്നു. നിങ്ങളുടെ കീയും ഇന്റർഫേസ് ഈന്പോയ്റ്റും എടുക്കാൻ താഴെയുള്ള നടപടികൾ പാലിക്കുക:

### 1. ഒരു ഇന്റർഫേസ് തിരഞ്ഞെടുക്കുക
1. ഗ്ലോബൽ ഇന്റർഫേസ് വേണ്ടി `https://api.minimax.io/v1` ഉപയോഗിക്കുക
2. ചൈന ഇന്റർഫേസ് വേണ്ടി `https://api.minimaxi.com/v1` ഉപയോഗിക്കുക

### 2. ഒരു API കീ സൃഷ്ടിക്കുക
1. നിങ്ങളുടെ MiniMax അക്കൗണ്ടിൽ നിന്ന് MiniMax API കീ സൃഷ്ടിക്കുക
2. കീയെ സുരക്ഷിതമായി സൂക്ഷിക്കുക

### 3. പരിസ്ഥിതി വേരിയബിളുകൾ സജ്ജീകരിക്കുക

#### വിൻഡോസ് (കമാൻഡ് പ്രാംപ്റ്റ്) ൽ:
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### വിൻഡോസ് (പവർഷെൽ) ൽ:
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### macOS/Linux ൽ:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## സജ്ജീകരണവും ഇൻസ്റ്റാളേഷനും

1. **പ്രോജക്ട് ഡയറക്ടറിയിലേക്ക് ക്ളോൺ ചെയ്യുക അല്ലെങ്കിൽ പോകുക**

2. **അവലംബങ്ങൾ ഇൻസ്റ്റാൾ ചെയ്യുക**:
   ```cmd
   mvnw clean install
   ```
   അല്ലെങ്കിൽ മാവൺ ഗ്ലോബലായി ഇൻസ്റ്റാൾ ചെയ്തിട്ടുണ്ടെങ്കിൽ:
   ```cmd
   mvn clean install
   ```

3. **പരിസ്ഥിതി വേരിയബിളുകൾ സജ്ജമാക്കുക** ("API കീ എടുക്കൽ" വകുപ്പ് കാണുക)

4. **MCP കാൽക്കുലേറ്റർ സേവനം ആരംഭിക്കുക**:
   `http://localhost:8080/sse` എന്ന വിലാസത്തിൽ അബദ്ധരഹിതമായി ഇടിച്ചത് ഉറപ്പാക്കുക. ക്ലയന്റ് തുടങ്ങുന്നതിനു മുൻപ് ഇത് പ്രവർത്തിച്ചിരിക്കണം.

## അപ്ലിക്കേഷൻ പ്രവർത്തിപ്പിക്കൽ

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## അപ്ലിക്കേഷൻ ചെയ്യുന്നത് എന്താണ്

അപ്ലിക്കേഷൻ കാൽക്കുലേറ്റർ സേവനത്തോട് മൂന്ന് പ്രധാന ഇടപെടലുകൾ കാണിക്കുന്നു:

1. **ചേർന്നുകൂടൽ**: 24.5 റ്റെയും 17.3 റ്റെയും ചിതറി
2. **സ്‌ക്വയർ മൂലം**: 144 ൽ സ്ക്വയർ മൂലം കണക്കാക്കുന്നു
3. **സഹായം**: ലഭ്യമായ കാൽക്കുലേറ്റർ ഫങ്ഷൻസ് കാണിക്കുന്നു

## പ്രതീക്ഷിച്ച ഔട്ട്പുട്ട്

വിജയകരമായി പ്രവർത്തിക്കുമ്പോൾ താഴെപോലുള്ള output കാണാനാകും:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## പ്രശ്ന പരിഹാരം

### സാധാരണ പ്രശ്നങ്ങൾ

1. **"OPENAI_API_KEY പരിസ്ഥിതി വേരിയബിൾ സജ്ജമാക്കിയിട്ടില്ല"**
   - `OPENAI_API_KEY` പരിസ്ഥിതി വേരിയബിൾ സജ്ജമെയ്ക്കുന്നതുണ്ടെന്ന് ഉറപ്പാക്കുക
   - വേരിയബിൾ സജ്ജമാക്കിയതിന് ശേഷം ടർമിനലോ കമാൻഡ് പ്രാംപ്റ്റോ റീസ്റ്റാർട്ട് ചെയ്യുക

2. **"localhost:8080 യോടുള്ള കണക്ഷൻ നിരസിച്ചു"**
   - MCP കാൽക്കുലേറ്റർ സേവനം പോർട്ട് 8080 ൽ പ്രവർത്തിക്കുന്നുണ്ടെന്ന് ഉറപ്പാക്കുക
   - മറ്റൊരു സേവനം പോർട്ട് 8080 ഉപയോഗിക്കുന്നുണ്ടോ എന്ന് പരിശോധിക്കുക

3. **"അധികൃതി പരാജയം"**
   - നിങ്ങളുടെ API കീ സാധുവാണെന്ന് സ്ഥിരീകരിക്കുക
   - `OPENAI_BASE_URL` നിങ്ങൾ ഉപയോഗിക്കാൻ ഉദ്ദേശിച്ച ഇന്റർഫേസ് അടിസ്ഥാനമാക്കിയാണെന്ന് പരിശോധിക്കുക

4. **മാവൺ ബിൽഡ് പിശകുകൾ**
   - ജാവ 21 അല്ലെങ്കിൽ അതിനുമുകൾ ഉപയോഗിച്ചുകൊണ്ടിരിക്കുമെന്ന് ഉറപ്പാക്കുക: `java -version`
   - ബിൽഡ് ക്ലീൻ ചെയ്യാൻ ശ്രമിക്കുക: `mvnw clean`

### ഡീബഗ്ഗിംഗ്

ഡീബഗ് ലോഗിംഗ് സജ്ജമാക്കാൻ, പ്രവർത്തിപ്പിക്കുമ്പോൾ താഴെയുള്ള JVM_ARGUMENT ചേർക്കുക:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## കോൺഫിഗറേഷൻ

അപ്ലിക്കേഷൻ സജ്ജമാക്കിയിരിക്കുന്നത്:
- ഡിഫോൾട്ട് ആയി MiniMax-M3 ഉപയോഗിക്കുക; `MINIMAX_MODEL_ID` സെറ്റ് ചെയ്ത് MiniMax-M3 അല്ലെങ്കിൽ MiniMax-M2.7 തിരഞ്ഞെടുക്കാം
- `OPENAI_BASE_URL` സെറ്റ് ചെയ്തിരിക്കുകയാണെങ്കിൽ അത് കണക്ട് ചെയ്യുക; അല്ലെങ്കിൽ `MINIMAX_REGION=cn_zh` ആണെങ്കിൽ `https://api.minimaxi.com/v1` ഉപയോഗിക്കുക, അല്ലെങ്കിൽ ഡിഫോൾട്ടായി `https://api.minimax.io/v1`
- MCP സേവനവുമായി കണക്ട് ചെയ്യുക `http://localhost:8080/sse` ൽ
- അഭ്യർത്ഥനകൾക്കായി 60 സെക്കന്റ് ടൈംഔട്ട് ഉപയോഗിക്കുക

## ആശ്രിതത്വങ്ങൾ

ഈ പ്രോജക്ടിൽ ഉപയോഗിക്കുന്ന പ്രധാന ആശ്രിതത്വങ്ങൾ:
- **LangChain4j**: AI ഇന്റഗ്രേഷൻ এবং ടൂൾ മാനേജ്മെന്റ്
- **LangChain4j MCP**: മോഡൽ കോൺടെക്സ്റ്റ് പ്രോട്ടോക്കോൾ പിന്തുണയ്ക്കായി
- **LangChain4j OpenAI ഔദ്യോഗിക**: MiniMax OpenAI-സമാനമായ API ഇന്റഗ്രേഷനായി
- **Spring Boot**: അപ്ലിക്കേഷൻ ഫ്രെയിമ്വർക്ക്, ആശ്രിതത്വ ഇൻജക്ഷൻ
