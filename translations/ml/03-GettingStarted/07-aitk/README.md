# Visual Studio Code ഇന്റഗ്രേറ്റഡ് AI Toolkit വിപുലീകരണത്തിലെ ഒരു സെർവറുകൾ ഉപയോഗിക്കൽ

നിങ്ങളെങ്കിൽ AI ഏജന്റ് ഒരു പക്ഷം നിർമ്മിക്കുമ്പോൾ, സ്മാർട്ടായ പ്രതികരണങ്ങൾ ഉണ്ടാക്കുന്നതിനു മാത്രം കാര്യമല്ല; ഏജന്റിന് പ്രവർത്തിക്കാനുള്ള കഴിവും നൽകുകയാണ് പ്രധാനമേം. അതിനാണ് മോഡൽ കോൺടെക്സ് പ്രോട്ടോകോൾ (MCP) പ്രയോഗിക്കുന്നത്. MCP ഏജന്റുകൾക്ക് കോൺസിസ്റ്റന്റ് രീതിയിലുള്ള പുറം ഉപകരണങ്ങൾക്കും സർവീസ് മാര്ക്കും ആക്സസ് നൽകുകയും ചെയ്യുന്നു. അത് നിങ്ങൾക്ക് ഏജന്റ് ഉപയോഗിക്കാൻ കഴിയുന്ന ഒരു ടൂൾബോക്സ് ഇളകുന്ന പോലെ ആണ്.

ചിന്തിക്കൂ, ഏതാനും ഒരു ഏജന്റിനെ കാൽക്കുലേറ്റർ MCP സെർവറുമായി ബന്ധിപ്പിച്ചു. അപ്രതീക്ഷിതമായി, നിങ്ങളുടെ ഏജന്റ് "47 × 89 എത്ര?" പോലുള്ള പ്രോംപ്ടുകൾ വാങ്ങിയാൽ ഗണിത പ്രവർത്തനങ്ങൾ നടത്താൻ കഴിയും — ഹാർഡ്‌കോഡ് ചെയ്ത ലോജിക് അല്ലെങ്കിൽ കസ്റ്റം APIകൾ നിർമ്മിക്കുന്ന ആവശ്യം ഇല്ല.

## അവലോകനം

ഈ പാഠം Visual Studio Code-നുള്ള [AI Toolkit](https://aka.ms/AIToolkit) വിപുലീകരണത്തോടുകൂടി കാൽക്കുലേറ്റർ MCP സെർവറിനെ ഏജന്റുമായി ബന്ധിപ്പിച്ച്, ഏജന്റ് കൂട്ടിച്ചേർക്കൽ, കുറവ്, ഗുണനം, വിഭജനം പോലുള്ള ഗണിത പ്രവർത്തനങ്ങൾ സ്വാഭാവിക ഭാഷയിലൂടെ നടത്താൻ കഴിയുന്നതിനെക്കുറിച്ചാണ്.

AI Toolkit Visual Studio Code നും‌ശക്തമായ ഒരു വിപുലീകരണം ആണ്, ഏജന്റ് വികസനത്തെ ലളിതമാക്കുന്നു. AI എഞ്ചിനീയർമാർക്ക് ജനിതക AI മോഡലുകൾ സൃഷ്ടിക്കുകയും പരിശോധന നടത്തുകയും ചെയ്യരുത് — പ്രാദേശികമായി അല്ലെങ്കിൽ ക്ലൗഡിൽ. ഈ വിപുലീകരണം നിലവിലുള്ള ഭൂരിഭാഗം ജനിതക മോഡലുകളും പിന്തുണയ്ക്കുന്നു.

*കുറിപ്പ്*: AI Toolkit നിലവിൽ Python, TypeScript എന്നിവ പിന്തുണക്കുന്നു.

## പഠന ലക്ഷ്യങ്ങൾ

ഈ പാഠം അവസാനത്തിൽ നിങ്ങൾക്ക് സാധിക്കേണ്ടത്:

- AI Toolkit ഉപയോഗിച്ച് MCP സെർവർ ഉപയോഗിക്കുക.
- MCP സെർവർ നൽകുന്ന ഉപകരണങ്ങൾ കണ്ടെത്താനും ഉപയോഗിക്കാനും ഏജന്റ് കോൺഫിഗറേഷൻ ക്രമീകരിക്കുക.
- സ്വാഭാവിക ഭാഷയിലൂടെ MCP ഉപകരണങ്ങൾ പ്രവർത്തിപ്പിക്കുക.

## സമീപനം

ഇതാ ഒരു ഉയർന്നതല സമീപനം:

- ഒരു ഏജന്റ് സൃഷ്ടിച്ച് അതിന്റെ സിസ്റ്റം പ്രോംപ്റ്റ് നിർവ്വചിക്കുക.
- കാൽക്കുലേറ്റർ ഉപകരണങ്ങളടങ്ങിയ MCP സെർവർ സൃഷ്ടിക്കുക.
- ഏജന്റ് ബിൽഡറെ MCP സെർവറുമായി ബന്ധിപ്പിക്കുക.
- സ്വാഭാവിക ഭാഷയിലൂടെ ഏജന്റിന്റെ ഉപകരണം വിളിക്കുക പരീക്ഷിക്കുക.

അതുപോലെ ഈ ഫ്ലോ മനസ്സിലായപ്പോൾ, MCP മുഖാന്തിരം പുറം ഉപകരണങ്ങൾ ഉപയോഗിച്ച് AI ഏജന്റ് ക്രമീകരിച്ച് അതിന്റെ ശേഷികൾ വർദ്ധിപ്പിക്കാം!

ഈ അഭ്യാസത്തിൽ, Visual Studio Code-ൽ AI Toolkit ഉപയോഗിച്ച് MCP സെർവറിലുള്ള ഉപകരണങ്ങളടങ്ങിയ AI ഏജന്റിനെ നിങ്ങൾ നിർമ്മിക്കുകയും പ്രവർത്തിപ്പിക്കുകയും മെച്ചപ്പെടുത്തുകയും ചെയ്യും.

![Visual Studio Code-ന്റെ AI Toolkit വിപുലീകരണത്തിൽ മോഡൽ തിരഞ്ഞെടുപ്പ് ഇന്റർഫേസ് സ്ക്രീൻഷോട്ട്. തലക്കെട്ട് "Find the right model for your AI Solution" എന്നാണ്, ഉപശീർഷകം AI മോഡലുകൾ കണ്ടെത്താനും പരീക്ഷിക്കാനും വിനിയോഗിക്കാനുമുള്ള പ്രേരണയോട് കൂടിയിരിക്കുന്നു. താഴിലുള്ള "Popular Models" വിഭാഗത്തിൽ ആറ് മോഡൽ കാർഡുകൾ കാണപ്പെടുന്നു: DeepSeek-R1 (GitHub-മാർഗ്ഗം), OpenAI GPT-4o, OpenAI GPT-4.1, OpenAI o1, Phi 4 Mini (CPU - Small, Fast), DeepSeek-R1 (Ollama-മാർഗ്ഗം). ഓരോ കാർഡിലും മോഡൽ ചേർക്കാനും പ്ലേഗ്രൗണ്ടിൽ പരീക്ഷിക്കാനും ഉള്ള ഓപ്ഷനുകൾ ഉണ്ട്.](../../../../translated_images/ml/aitk-model-catalog.2acd38953bb9c119.webp)

### -1- ഏജന്റ് സൃഷ്ടിക്കുക

**Agent (Prompt) Builder** നിങ്ങളെ സഹായിക്കുന്ന ഉപകരണം ആണ് നിങ്ങളുടെ സ്വന്തം AI-ഏജന്റുകൾ സൃഷ്ടിച്ചും പെർസണലൈസ് ചെയ്യാനും. ഈ ഘട്ടത്തിൽ, പുതിയ ഏജന്റ് നിർമ്മിച്ച് ഒരു മോഡൽ സംഭാവന നൽകുന്നു.

![Visual Studio Code AI Toolkit-ൽ "Calculator Agent" ബിൽഡർ ഇന്റർഫേസ് സ്ക്രീൻഷോട്ട്. ഇടത് പാനലിൽ "OpenAI GPT-4o (via GitHub)" മോഡൽ തിരഞ്ഞെടുത്തിട്ടുണ്ട്. സിസ്റ്റം പ്രോംപ്റ്റ് "You are a professor in university teaching math" എന്നും, യൂസർ പ്രോംപ്റ്റിൽ "Explain to me the Fourier equation in simple terms" എന്നും കാണിക്കുന്നു. ടൂൾസ് ചേർക്കാനുള്ള ബട്ടൺ, MCP സെർവർ സജ്ജീകരിക്കൽ, സ്ട്രക്ചേർഡ് ഔട്ട്പുട്ട് ചോയ്സ് എന്നിവയും കാണിക്കുന്നു. വലത് പാനലിൽ "Get Started with Examples" പ്രകാരം മൂന്നു സാമ്പിൾ ഏജന്റുകൾ പട്ടികയിലാണ്: വെബ് ഡവലപ്പർ (MCP സെർവർ, സെക്കൻഡ്-ഗ്രേഡ് സിംപ്ലിഫയർ, ഡ്രീം ഇൻറർപ്രിറ്റർ എന്നിവയുടെ വ്യാപാര വിവരണങ്ങളോടുകൂടി).](../../../../translated_images/ml/aitk-agent-builder.901e3a2960c3e477.webp)

1. **Activity Bar**-ൽ നിന്നു **AI Toolkit** വിപുലീകരണം തുറക്കുക.
1. **Tools** വിഭാഗത്തിൽ **Agent (Prompt) Builder** തിരഞ്ഞെടുക്കുക. പുതിയ എഡിറ്റർ ടാബിൽ **Agent (Prompt) Builder** തുറക്കും.
1. **+ New Agent** ബട്ടൺ ക്ലിക്ക് ചെയ്യുക. **Command Palette** വഴിയും സെറ്റപ്പ് വിസാർഡ് ആരംഭിക്കും.
1. പേരു നൽകുക: **Calculator Agent**, **Enter** അമർത്തുക.
1. **Agent (Prompt) Builder**-ൽ **Model** ഫീൽഡിൽ **OpenAI GPT-4o (via GitHub)** മോഡൽ തിരഞ്ഞെടുക്കുക.

### -2- ഏജന്റിനായി ഒരു സിസ്റ്റം പ്രോംപ്റ്റ് സൃഷ്ടിക്കുക

ഏജന്റ് ഒരുക്കിയ ശേഷം, അതിന്റെ വ്യക്തിത്വവും ഉദ്ദേശവും നിർവ്വചിക്കാനുള്ള സമയം ആണ്. ഈ ഭാഗത്ത്, **Generate system prompt** ഫീച്ചർ ഉപയോഗിച്ച് കാൽക്കുലേറ്റർ ഏജന്റ് സൈകിളിനായി മോഡലിനെ ഉപയോഗിച്ച് സിസ്റ്റം പ്രോംപ്റ്റ് നിർമ്മിക്കും.

![Visual Studio Code AI Toolkit-ൽ "Calculator Agent" ഇന്റർഫേസിൽ "Generate a prompt" എന്ന മോഡൽ വിൻഡോ തുറന്നിരിക്കുന്നത്. മോഡൽ പറയുന്നു ഒരു പ്രോംപ്റ്റ് ടെംപ്ലേറ്റ് സൃഷ്ടിക്കാൻ അടിസ്ഥാന വിവരം നൽകാമെന്ന്, ടെക്സ്റ്റ് ബോക്‌സിൽ ഉദാഹരണമായി "You are a helpful and efficient math assistant. When given a problem involving basic arithmetic, you respond with the correct result." പ്രദർശിപ്പിക്കുന്നു. ചുവട്ടിൽ "Close" ഒപ്പം "Generate" ബട്ടണുകൾ കാണിക്കുന്നു. പിന്നിൽ മോഡൽ നിരീക്ഷണങ്ങളിൽ "OpenAI GPT-4o (via GitHub)" മോഡൽ തിരഞ്ഞെടുത്തിട്ടുണ്ട്, സിസ്റ്റം പ്രോംപ്റ്റും യൂസർ പ്രോംപ്റ്റും കാണിക്കുന്നു.](../../../../translated_images/ml/aitk-generate-prompt.ba9e69d3d2bbe2a2.webp)

1. **Prompts** സെക്ഷനിൽ **Generate system prompt** ബട്ടൺ ക്ലിക്ക് ചെയ്യുക. പ്രോംപ്റ്റ് ബിൽഡർ തുറക്കുകയും, AI ഉപയോഗിച്ച് സിസ്റ്റം പ്രോംപ്റ്റ് ജനറേറ്റ് ചെയ്യുന്നു.
1. **Generate a prompt** വിൻഡോയിൽ، താഴെ പറയുന്നവിടെയ്ക്കു നൽകിയതായി എഴുതി: `You are a helpful and efficient math assistant. When given a problem involving basic arithmetic, you respond with the correct result.`
1. **Generate** ബട്ടൺ അമർത്തുക. തിരഞ്ഞെടുപ്പ് ഉണ്ടാകുമ്പോൾ ചുവട് മുരടിയിലുള്ള നോട്ടിഫിക്കേഷൻ കാണും. പ്രോംപ്റ്റ് സൃഷ്ടിക്കൽ പൂർത്തിയായ ശേഷം, **Agent (Prompt) Builder**-ലെ **System prompt** ഫീൽഡിൽ പ്രോംപ്റ്റ് പ്രത്യക്ഷപ്പെടും.
1. **System prompt** അവലോകനം ചെയ്ത് ആവശ്യമെങ്കിൽ തിരുത്തുക.

### -3- MCP സെർവർ സൃഷ്ടിക്കുക

നിങ്ങൾ ഏജന്റിന്റെ സിസ്റ്റം പ്രോംപ്റ്റ് നിർവചിച്ചതിനുശേഷം — അതിന്റെ പെരുമാറ്റവും പ്രതികരണങ്ങളും മാനദണ്ഡമാകുന്നു — ഇപ്പോൾ പ്രായോഗിക കഴിവുകൾ നൽകാനുള്ള സമയമാണ്. ഈ ഘട്ടത്തിൽ, കാൽക്കുലേറ്റർ MCP സെർവർ സൃഷ്ടിച്ച് കൂട്ടിച്ചേർക്കൽ, കുറവ്, ഗുണനം, വിഭജനം പ്രവർത്തനങ്ങൾ നടത്താനുള്ള ഉപകരണങ്ങൾ ചേർക്കാം. ഈ സെർവർ നിങ്ങളുടെ ഏജന്റിന് സ്വാഭാവിക ഭാഷാപ്രോംപ്റ്റുകൾക്ക് പ്രതികരിച്ച് റിയൽ ടൈം ഗണിത പ്രവർത്തനങ്ങൾ നടത്താൻ സഹായിക്കും.

![Visual Studio Code AI Toolkit വിപുലീകരണത്തിലെ Calculator Agent ഇന്റർഫേസ് താഴ്‌വും ഭാഗം. "Tools" / "Structure output" പരിസരങ്ങളിലേക്കുള്ള വിപുലപ്പെടുത്താവുന്ന മെന്യുകളും "Choose output format" എന്ന ഡ്രോപ്പ്‌ഡൗൺ "text" ആയി തിരഞ്ഞെടുക്കപ്പെട്ടിരിക്കുന്നു. വലതു ഭാഗത്ത് "+ MCP Server" എന്ന ബട്ടൺ കാണുന്നു, മോഡൽ കോൺടെക്സ് പ്രോട്ടോക്കോൾ സെർവർ ചേർക്കാനുള്ള. ടൂൾസ് വിഭാഗത്തിന് മുകളിൽ ഒരു ഇമേജ് ഐക്കൺ പ്ലേസ്‌ഹോള്ഡർ.](../../../../translated_images/ml/aitk-add-mcp-server.9742cfddfe808353.webp)

AI Toolkit നിങ്ങളുടെ സ്വന്തം MCP സെർവർ സൃഷ്ടിക്കാൻ സമ്മർദ്ദരഹിതമായി ഉപയോഗിക്കാവുന്ന ടെംപ്ലേറ്റുകൾ ഉൾക്കൊള്ളുന്നു. നാം Python ടെംപ്ലേറ്റ് ഉപയോഗിച്ച് കാൽക്കുലേറ്റർ MCP സെർവർ സൃഷ്ടിക്കും.

*കുറിപ്പ്*: AI Toolkit നിലവിൽ Python, TypeScript പിന്തുണയ്ക്കുന്നു.

1. **Agent (Prompt) Builder**-ലെ **Tools** വിഭാഗത്തിൽ **+ MCP Server** ബട്ടൺ ക്ലിക്ക് ചെയ്യുക. **Command Palette** വഴി സെറ്റപ്പ് വിസാർഡ് ആരംഭിക്കും.
1. **+ Add Server** തിരഞ്ഞെടുക്കുക.
1. **Create a New MCP Server** തിരഞ്ഞെടുക്കുക.
1. ടെംപ്ലേറ്റ് ആയി **python-weather** തിരഞ്ഞെടുക്കുക.
1. MCP സെർവർ ടെംപ്ലേറ്റ് സേവ് ചെയ്യാൻ **Default folder** തിരഞ്ഞെടുക്കുക.
1. സെർവറിന് താഴെ പറയുന്ന പേര് നൽകുക: **Calculator**
1. പുതിയ Visual Studio Code വിൻഡോ തുറക്കും. **Yes, I trust the authors** തിരഞ്ഞെടുക്കുക.
1. ടെർമിനൽ (**Terminal** > **New Terminal**) ഉപയോഗിച്ച് വേർച്വൽ എൻവയോൺമെന്റ് സൃഷ്ടിക്കുക: `python -m venv .venv`
1. ടെർമിനൽ ഉപയോഗിച്ച് വേർച്വൽ എൻവയോൺമെന്റ് പ്രവർത്തനമാക്കുക:
    1. വിൻഡോസ് - `.venv\Scripts\activate`
    1. macOS/Linux - `source .venv/bin/activate`
1. ടെർമിനലിൽ ഡിപ്പൻഡൻസிகள் ഇൻസ്റ്റാൾ ചെയ്യുക: `pip install -e .[dev]`
1. **Activity Bar**-ൽ നിന്ന് **Explorer** കാഴ്ചയിൽ **src** ഫോൾഡർ വിപുലീകരിച്ച് **server.py** തിരഞ്ഞെടുത്ത് എഡിറ്ററിൽ തുറക്കുക.
1. **server.py** ഫയലിൽ ഉള്ള കോഡ് താഴെ കൊടുത്തതിൽ മാറ്റുകയും സൂക്ഷിക്കുകയുമാക്കുക:

    ```python
    """
    Sample MCP Calculator Server implementation in Python.

    
    This module demonstrates how to create a simple MCP server with calculator tools
    that can perform basic arithmetic operations (add, subtract, multiply, divide).
    """
    
    from mcp.server.fastmcp import FastMCP
    
    server = FastMCP("calculator")
    
    @server.tool()
    def add(a: float, b: float) -> float:
        """Add two numbers together and return the result."""
        return a + b
    
    @server.tool()
    def subtract(a: float, b: float) -> float:
        """Subtract b from a and return the result."""
        return a - b
    
    @server.tool()
    def multiply(a: float, b: float) -> float:
        """Multiply two numbers together and return the result."""
        return a * b
    
    @server.tool()
    def divide(a: float, b: float) -> float:
        """
        Divide a by b and return the result.
        
        Raises:
            ValueError: If b is zero
        """
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    ```

### -4- കാൽക്കുലേറ്റർ MCP സെർവറുമായി ഏജന്റ് പ്രവർത്തിപ്പിക്കുക

ഏജന്റിന് ഉപകരണങ്ങൾ ലഭിച്ചപ്പോൾ, അവ ഉപയോഗിക്കാനുള്ള സമയമായി! ഈ ഘട്ടത്തിൽ, ഈ പ്രോംപ്റ്റുകളേ ഏജന്റിന് നൽകും, കാൽക്കുലേറ്റർ MCP സെർവറില് നിന്നുള്ള ശരിയായ ഉപകരണം തരംതിരിച്ച് ഉപയോഗിക്കുന്നുണ്ടോ എന്നത് പരിശോധിച്ച വിലയിരുത്തും.

![Visual Studio Code AI Toolkit വിപുലീകരണത്തിലെ Calculator Agent ഇന്റർഫേസ് സ്ക്രീൻഷോട്ട്. ഇടത്ത് "Tools" ആയി MCP സെർവർ "local-server-calculator_server" ചേർത്തിട്ടുണ്ട്, നാല് ഉപകരണങ്ങൾ: add, subtract, multiply, divide സജ്ജമാണ്. ഉപകരണങ്ങൾ ചലിപ്പിച്ചു സമയം ബാഡ്ജും കാണിക്കുന്നു. താഴെ "Structure output" വിഭാഗം മുടഞ്ഞതാണ്. നീല "Run" ബട്ടൺ താഴെ. വലത് പാനലിൽ, "Model Response" ഭാഗത്ത് multiply, subtract ഉപകരണങ്ങളായ "a":3, "b":25, "a":75, "b":20 എന്ന വിവരങ്ങളോടെ വിളിക്കുന്നു. അവസാന "Tool Response" 75.0 ആണ്. താഴെ "View Code" ബട്ടൺ.](../../../../translated_images/ml/aitk-agent-response-with-tools.e7c781869dc8041a.webp)

നിങ്ങളുടെ പ്രാദേശിക ഡെവാസ് മഷീൻ-ൽ MCP ക്ലയന്റ് ആയി **Agent Builder** വഴി കാൽക്കുലേറ്റർ MCP സെർവർ പ്രവർത്തിപ്പിക്കും.

1. MCP സെർവർ ഡിബഗ്ഗിംഗ് ആരംഭിക്കാൻ `F5` അമർത്തുക. **Agent (Prompt) Builder** പുതിയ എഡിറ്റർ ടാബിൽ തുറക്കും. സെർവറിന്റെ സ്ഥിതി ടെർമിനലിൽ കാണാം.
1. **Agent (Prompt) Builder**-ലുള്ള **User prompt** ഫീൽഡിൽ താഴെ കാണുന്ന പ്രോംപ്റ്റ് നൽകുക: `I bought 3 items priced at $25 each, and then used a $20 discount. How much did I pay?`
1. **Run** ബട്ടൺ അമർത്തി ഏജന്റിന്റെ പ്രതികരണം ജനरेटുചെയ്യുക.
1. ഏജന്റ് ഔട്‌പുട്ട് പരിശോധിക്കുക. മോഡൽ നിങ്ങൾ **$55** അടച്ചിട്ടുവെന്ന് കാണിച്ച് തീർക്കണം.
1. സംഭവിക്കേണ്ട പ്രവർത്തനങ്ങൾ:
    - കാൽക്കുലേറ്റിനായി **multiply** and **subtract** ഉപകരണങ്ങൾ ഏജന്റ് തിരഞ്ഞെടുക്കുന്നു.
    - **multiply** ഉപകരണത്തിന് `a` , `b` മൂല്യങ്ങൾ നൽകുന്നു.
    - **subtract** ഉപകരണത്തിന് `a` , `b` മൂല്യങ്ങൾ നൽകുന്നു.
    - ഓരോ ഉപകരണത്തിന്റെയും **Tool Response** ലഭിക്കുന്നു.
    - അവസാന **Model Response** നൽകുന്നു.
1. ഏജന്റിനെ പരീക്ഷിക്കാൻ കൂടുതൽ പ്രോംപ്റ്റുകൾ നൽകാം. ചെയ്തിട്ടുള്ള **User prompt** തിരുത്തുന്നതിലൂടെ അത് സാധിക്കും.
1. പരീക്ഷണം കഴിഞ്ഞാൽ ടെർമിനലിൽ **CTRL/CMD+C** അമർത്തി സെർവർ നിർത്താം.
