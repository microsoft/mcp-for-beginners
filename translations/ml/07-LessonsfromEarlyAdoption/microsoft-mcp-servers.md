## 🎯 ഈ ഗൈഡിൽ നിങ്ങൾ പഠിക്കാനുള്ളത്

ഈ പ്രായോഗിക ഗൈഡ് പത്തുലക്ഷം Microsoft MCP സെർവർസ്സ് കാണിക്കുന്നു, AI അസിസ്റ്റന്റുകളുമായി ഡെവലപ്പർമാർ എങ്ങിനെ പ്രവർത്തിക്കുന്നു എന്ന് സജീവമായി മാറ്റം വരുത്തുന്നു. MCP സെർവർസ് *എന്ത്* ചെയ്യുമെന്ന് പറയുന്നതിന് പകരം, Microsoft-ലും അതിന് പുറമെയും ദിവസേന വികസന പ്രവർത്തനശൈലിയിൽ സത്യമായ മാറ്റം വരുത്തുന്ന സത്യമായ സെർവർസ് കാണിക്കും.

ഈ ഗൈഡിലെ ഓരോ സെർവറും യഥാർത്ഥ ലോക ഉപയോഗവും ഡെവലപ്പർ പ്രതികരണവും കൂടി അടിസ്ഥാനമാക്കി തെരഞ്ഞെടുക്കപ്പെട്ടതാണ്. നിങ്ങൾ ഓരോ സെർവർ എന്ത് ചെയ്യുന്നു മാത്രമല്ല, ഇത് എന്തുകൊണ്ട് പ്രധാനമാണ് എന്നും നിങ്ങളുടെ സ്വന്തം പദ്ധതികളിൽ എങ്ങനെ അതിൽ നിന്ന് മധുരം നേടാമെന്ന് കണ്ടെത്തും. MCP യോടു പൂർണ്ണമായി പുതിയത് ആണോ, അല്ലെങ്കിൽ നിലവിലുള്ള സജ്ജീകരണം വിപുലീകരിക്കാൻ ആഗ്രഹിക്കുന്നവനോ ആണെങ്കിൽ, ഈ സെർവർസ് Microsoft പരിസ്ഥിതിയിലെ ഏറ്റവും പ്രായോഗികവും പ്രഭവവുമുള്ള ഉപകരണങ്ങളെയാണ് പ്രതിനിധാനം ചെയ്യുന്നത്.

- ഈ സെർവർ കൾ VS Code, Visual Studio എന്നിവയിൽ എങ്ങനെ ക്രമീകരിക്കാമെന്നും മുന്നോട്ട് കൊണ്ടുപോകാം
- MCP പരിസ്ഥിതി വ്യാപകം, ഭാവി ദിശകൾ പരിശോധിക്കുക

## 🔧 MCP സെർവർസ്: ഒരിടത്തുള്ള തുടക്കക്കാരന്റെ ഗൈഡ്

### MCP സെർവർസ് എന്നത് എന്തെല്ലാം?

Model Context Protocol (MCP)-ൽ പുതുതായി ചുരുക്കം: "MCP സെർവർ അർത്ഥം എന്ത്? എന്തുകൊണ്ട് ഞാൻ ശ്രദ്ധിക്കണം?" എങ്കിൽ നമുക്ക് ഒരു ലളിതമായ ഉത്തമവാദം പ്രാരംഭം చేదിക്കുന്നതാം.

MCP സെർവർസ് നിങ്ങളുടെ AI കോഡിംഗ് സഹായി (GitHub Copilot പോലുള്ള) ബാഹ്യ ഉപകരണങ്ങളിലും സേവനങ്ങളിലും ബന്ധിപ്പിക്കാൻ സഹായിക്കാമെന്നു വിചാരിക്കുക. ഫോണിൽ പലതരം ആപ്പുകൾ ഉപയോഗിക്കുന്നത് പോലെ — ഒരു കാലാവസ്ഥയ്ക്ക്, മറ്റൊരു നാവിഗേഷനിനായി, മറ്റൊന്ന് ബാങ്കിംഗിനായി — MCP സെർവർസ് നിങ്ങളുടെ AI അസിസ്റ്റന്റിന് വ്യത്യസ്ത ഡെവലപ്പ്മെന്റ് ഉപകരണങ്ങൾക്കും സേവനങ്ങൾക്കുമൊപ്പം ഇടപെടാൻ കഴിവ് നൽകുന്നു.

### MCP സെർവർസ് പരിഹരിക്കുന്ന പ്രശ്നം

MCP സെർവർസ് വരുന്നതിനു മുമ്പ്, നിങ്ങൾ ആഗ്രഹിച്ചാൽ:
- നിങ്ങളുടെ Azure വിഭവങ്ങൾ പരിശോധിക്കുക
- GitHub ഇഷ്യൂ ഉണ്ടാക്കുക
- നിങ്ങളുടെ ഡാറ്റാബേസ് വഴി ചോദ്യം ചേർക്കുക
- ഡോക്യുമെന്റേഷൻ തിരയുക

നിങ്ങൾ കോഡിംഗ് നിർത്തണം, ബ്രൗസർ തുറന്ന് തുടര്‍ന്നു പോകേണ്ടിവരും, യോജിച്ച വെബ്സൈറ്റിലേക്ക് പോയി ഈ കാര്യങ്ങൾ കൈകാര്യം ചെയ്യേണ്ടിവരും. ഈ തുടർച്ചയായ കോൺടെക്സ്റ്റ് മാറ്റം നിങ്ങളുടെ പ്രവൃത്തി നില നിഷേധിക്കുകയും ഫലപ്രദത കുറയ്ക്കുകയും ചെയ്യുന്നു.

### MCP സെർവർസ് നിങ്ങളുടെ വികസന അനുഭവം എങ്ങനെ മാറ്റുന്നു

MCP സെർവർസുകളോടൊപ്പം നിങ്ങൾ നിങ്ങളുടെ വികസന പരിസ്ഥിതിയിൽ (VS Code, Visual Studio മുതലായവ) ഒരു തരത്തിലുള്ള പ്രവർത്തനത്തിൽ തുടരാനും, AI അസിസ്റ്റന്റിനോട് ഈ കാര്യങ്ങൾ കൈകാര്യം ചെയ്യാൻ മാത്രം പറയാനും സാധിക്കും. ഉദാഹരണത്തിന്:

**പാരമ്പര്യ പ്രവർത്തി രീതി ഇതുപോലെയാണ്:**
1. കോഡിംഗ് നിർത്തുക
2. ബ്രൗസർ തുറക്കുക
3. Azure പോർട്ടലിലേക്ക് പോകുക
4. സ്റ്റോറേജ് അക്കൗണ്ട് വിശദാംശങ്ങൾ പരിശോധിക്കുക
5. VS Code-ലേക്ക് മടങ്ങുക
6. കോഡിംഗ് തുടരുക

**ഇപ്പൊഴിങ്ങനെ ചെയ്യാം:**
1. AI-നെ ചോദിക്കുക: "എന്റെ Azure സ്റ്റോറേജ് അക്കൗണ്ടുകളുടെ നില എന്താണ്?"
2. ലഭിച്ച വിവരത്തോടെ കോഡിംഗ് തുടരുക

### തുടക്കക്കാർക്കുള്ള പ്രധാന ഗുണങ്ങൾ

#### 1. 🔄 **നിങ്ങളുടെ പ്രവൃത്തി നിലയിൽ തുടരുക**
- പല ആപ്പുകൾ തമ്മിൽ മാറാതെ
- നിങ്ങൾ എഴുതുന്ന കോഡിൽ ശ്രദ്ധ കേന്ദ്രീകരിക്കുക
- വ്യത്യസ്ത ഉപകരണങ്ങൾ നിയന്ത്രിക്കുന്ന മാനസിക ഭാരം കുറയ്ക്കുക

#### 2. 🤖 **കമ്പ്ളക്സായ കമാൻഡുകൾക്കു പകരം സ്വാഭാവിക ഭാഷ ഉപയോഗിക്കുക**
- SQL സിന്റാക്സ് ഓർക്കാതെ, നിങ്ങൾക്ക് വേണ്ട ഡാറ്റ തൽസമയം വിവരിക്കുക
- Azure CLI കമാൻഡുകൾ ഓർത്തു നിർത്താതെ, നിങ്ങൾ പൂർത്തിയാക്കാനാഗ്രഹിക്കുന്ന കാര്യം വിശദീകരിക്കുക
- AI സാങ്കേതിക വിശദാംശങ്ങൾ കൈകാര്യം ചെയ്യട്ടെ, നിങ്ങൾ ലാജിക്-ൽ ശ്രദ്ധ കേന്ദ്രീകരിക്കണം

#### 3. 🔗 **പല ഉപകരണങ്ങൾ തമ്മിൽ ബന്ധിപ്പിക്കുക**
- വ്യത്യസ്ത സേവനങ്ങൾ സംയോജിപ്പിച്ച് ശക്തമായ പ്രവൃത്തി പ്രവാഹങ്ങൾ സൃഷ്ടിക്കുക
- ഉദാഹരണം: "സമീപകാലത്തെ GitHub ഇഷ്യൂകൾ എല്ലാം നേടൂ, അവയുമായി ബന്ധപ്പെട്ട Azure DevOps പ്രവൃത്തി ഇനങ്ങൾ സൃഷ്ടിക്കുക"
- ജടിലമായ സ്ക്രിപ്റ്റ് എഴുതാതെ ഓട്ടോമേഷൻ നിർമ്മിക്കുക

#### 4. 🌐 **വികസിച്ചുവരുന്ന സമ്പ്രദായത്തിൽ പ്രവേശിക്കുക**
- Microsoft, GitHub, മറ്റ് കമ്പനികൾ നിർമ്മിച്ച സെർവർസിന്റെ ഗുണങ്ങൾ പ്രയോജനപ്പെടുത്തുക
- വിവിധ വിൽപ്പനക്കാരുടെ ഉപകരണങ്ങൾ സാരമായി സംയോജിപ്പിക്കാം
- വിവിധ AI അസിസ്റ്റന്റുകൾക്കിടയിൽ പ്രവൃത്തി ചെയ്യുന്ന ഒരു മാനദണ്ഡ സമ്പ്രദായത്തിലേക്ക് ചേരുക

#### 5. 🛠️ **പ്രവർത്തനം വഴിയാണ് പഠിക്കുക**
- ആശയങ്ങൾ മനസ്സിലാക്കാൻ മുൻ-നിർമ്മിച്ച സെർവർകളോട് ആരംഭിക്കുക
- നിങ്ങളുടെ സ്വന്തം സെർവർസ് ഘടിപ്പിക്കുക, കൂടുതൽ ആത്മവിശ്വാസം സമ്പാദിക്കുമ്പോൾ
- ലഭ്യമായ SDK-കളും ഡോക്യുമെന്റേഷനും നിങ്ങളുടെ പഠനത്തിന് വഴികാട്ടി ആയി ഉപയോഗിക്കുക

## VS Code, Visual Studio-യിൽ MCP ആരംഭിക്കുക 🚀

ഈ MCP സെർവർസ് ക്രമീകരിക്കുന്നത് വളരെ എളുപ്പമാണ്, നിങ്ങൾ Visual Studio Code അല്ലെങ്കിൽ Visual Studio 2022 GitHub Copilot ഉപയോഗിച്ചിരിക്കുകയാണെങ്കിൽ.

### VS Code ക്രമീകരണം

VS Code-ൽ അടിസ്ഥാന പ്രക്രിയ ഇതാണ്:

1. **എജന്റ് മോഡ് സജീവമാക്കുക**: Copilot Chat വിൻഡോയിലോ VS Code-യിൽ Agent mode ενεργοποιήστε
2. **MCP സെർവറുകൾ ക്രമീകരിക്കുക**: നിങ്ങളുടെ VS Code settings.json ഫയലിൽ സെർവർ കോൺഫിഗറേഷൻസ് ചേർക്കുക
3. **സെർവർസ് തുടങ്ങുക**: ഉപയോഗിക്കാൻ ആഗ്രഹിക്കുന്ന ഓരോ സെർവർക്കും "Start" ബട്ടൺ ക്ലിക്ക് ചെയ്യുക
4. **ഉപകരണങ്ങൾ തിരഞ്ഞെടുക്കുക**: നിലവിലെ സെഷനിൽ ഏത് MCP സെർവർകൾ സജീവമാക്കണമെന്ന് തിരഞ്ഞെടുക്കുക

വിശദമായ ക്രമീകരണ നിർദ്ദേശങ്ങൾക്കായി, [VS Code MCP ഡോക്യുമെന്റേഷൻ](https://code.visualstudio.com/docs/copilot/copilot-mcp) കാണുക.

> **💡 പ്രൊ ടിപ്: MCP സെർവർസുകൾ പ്രൊഫഷണൽ രീതിയിൽ കൈകാര്യം ചെയ്യുക!**
> 
> VS Code എക്സ്റ്റെൻഷൻ വ്യൂയിൽ ഇപ്പോൾ [ഉപയോഗത്തിലുള്ള MCP സെർവർസ് മാനേജുചെയ്യാനുള്ള ഒരു സൗകര്യപ്രദമായ UI](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode) ഉൾപ്പെടുത്തിയിട്ടുണ്ട്! നിങ്ങൾക്ക് സ്പഷ്ടവും ലളിതവുമായ ഇന്റർഫേസിലൂടെ ഇൻസ്റ്റാൾ ചെയ്ത MCP സെർവർസ് ആരംഭിക്കാനും നിർത്താനും മാനേജ് ചെയ്യാനും വേഗത്തിലുള്ള പ്രവേശനം ലഭ്യമാണ്. പരീക്ഷിച്ച് നോക്കൂ!

### Visual Studio 2022 ക്രമീകരണം

Visual Studio 2022 (17.14 പതിപ്പ് അല്ലെങ്കിൽ പിന്നീട്) ഉപയോഗിക്കുന്നതിന്:

1. **എജന്റ് മോഡ് സജ്ജമാക്കുക**: GitHub Copilot Chat വിൻഡോയിലെ "Ask" ഡ്രോപ്പ്ഡൗണിൽ ക്ലിക്ക് ചെയ്ത് "Agent" തിരഞ്ഞെടുക്കുക
2. **കോൺഫിഗറേഷൻ ഫയൽ സൃഷ്ടിക്കുക**: നിങ്ങളുടെ സൊലൂഷൻ ഡയറക്ടറിയിൽ `.mcp.json` ഫയൽ സൃഷ്ടിക്കുക (ശുപാർശ ചെയ്യുന്ന സ്ഥലം: `<SOLUTIONDIR>\.mcp.json`)
3. **സെർവർസ് ക്രമീകരിക്കുക**: MCP എന്നാൽ സാധാരണ MCP ഫോർമാറ്റ് ഉപയോഗിച്ചുള്ള സെർവർ കോൺഫിഗറേഷൻസ് ചേർക്കുക
4. **ഉപകരണ അനുമതി**: ആവശ്യപ്പെട്ടാൽ, അനുയോജ്യമായ സ്കോപ്പ് അനുമതികളോടെ ഉപയോഗിക്കാൻ ഉള്ള ഉപകരണങ്ങൾ അംഗീകരിക്കുക

വിശദമായ Visual Studio ക്രമീകരണ നിർദ്ദേശങ്ങൾക്കായി, [Visual Studio MCP ഡോക്യുമെന്റേഷൻ](https://learn.microsoft.com/visualstudio/ide/mcp-servers) ശ്രദ്ധിക്കുക.

ഓരോ MCP സെർവറും അതിന്റെ വ്യക്തിഗത ക്രമീകരണ ആവശ്യകതകൾ (കണക്ഷൻ സ്ട്രിംഗുകൾ, അംഗീകാരം, തുടങ്ങിയവ) ഉണ്ടാകാം, എന്നാൽ രണ്ട് IDE-യിലും ക്രമീകരണ മാതൃക സാമ്യമാണ۔

**ഇത് എന്തുകൊണ്ട് പ്രയോജനകരമാണ്**: Azure വറ്റ്‌സ്ഫ്രേം പ്രയോഗിക്കുമ്പോൾ കോഡ് ഗുണമേന്മ നന്നാക്കുന്നതിന് മാത്രമല്ല, ഈ server Azure SDKs ഉപയോഗിക്കുമ്പോൾ ഡെവലപ്പർമാർക്കായി വളരെ മികച്ചതാണ്. Azure MCP യെ Agent മോഡിൽ ഉപയോഗിക്കുമ്പോൾ, ഇത് നമുക്ക് കോഡ് എഴുതാൻ സഹായിക്കുന്നതല്ല; ഇത് നിലവിലുള്ള പ്രാമാണിക ഡാറ്റാ രീതികൾ, പിശക് കൈകാര്യം ചെയ്യുന്ന മികച്ച രീതികൾ, ഏറ്റവും പുതിയ SDK ഫീച്ചറുകൾ എന്നിവ പിന്തുടരുന്ന *മികച്ച* Azure കോഡ് എഴുതാൻ സഹായിക്കുന്നു. പ്രവർത്തനസാധ്യതയുള്ള പൊതുവായ കോഡ് ലഭിക്കുന്നതിന് പകരം, ഉത്പാദന പ്രവർത്തനങ്ങൾക്കുള്ള Azure ന്റെ നിർദ്ദേശിച്ച മാതൃകകൾ പാലിക്കുന്ന കോഡ് നിങ്ങൾക്ക് ലഭിക്കും.

**പ്രധാന module കൊളക്ഷനുകൾ**:
- **🗄️ ഡാറ്റാബേസ് കണക്റ്ററുകൾ**: Azure Database for PostgreSQL, SQL Server എന്നിവയ്ക്ക് നേരിട്ട് സ്വാഭാവിക ഭാഷ മുഖേന ആക്‌സസ്
- **📊 Azure Monitor**: KQL പ്രയോഗിച്ച് ലോഗ് വിശകലനം, പ്രവർത്തന സൂചനകൾ
- **🌐 റിസോഴ്‌സ് മാനേജ്മെന്റ്**: പൂർണ്ണ Azure റിസോഴ്‌സ് ജീവിതചക്രം മാനേജ്മെന്റ്
- **🔐 authentication**: DefaultAzureCredential, managed identity മാതൃകകൾ
- **📦 സ്ടോറേജ് സേവനങ്ങൾ**: Blob Storage, Queue Storage, Table Storage പ്രവർത്തനങ്ങൾ
- **🚀 കണ്ടെയ്‌നർ സേവനങ്ങൾ**: Azure Container Apps, Container Instances, AKS മാനേജ്മെന്റ്
- **മറ്റും നിരവധി പ്രത്യേകിച്ചുള്ള കണക്റ്ററുകൾ**

**പ്രായോഗിക ഉപയോഗം**: "എന്റെ Azure സ്റ്റോറേജ് അക്കൗണ്ടുകൾ പട്ടിക ചെയ്യുക", "കഴിഞ്ഞ മണിക്കൂറിൽ ലോഗ് അനാലിറ്റിക്സ് വർക്ക്സ്പേസ് പിഴവുകൾ അന്വേഷിക്കുക", "സही authentication ഉപയോഗിച്ച് Node.js ഉപയോഗിച്ച് Azure ആപ്ലിക്കേഷൻ നിർമ്മിക്കാൻ സഹായിക്കുക"

**സമ്പൂർണ്ണ ഡെമോ സീനാരിയോ**: Azure MCP GitHub Copilot for Azure എക്സ്റ്റൻഷനോടൊപ്പം VS Code-ൽ ഉപയോഗിക്കുന്നതിനുള്ള ശക്തിയുള്ള ഒരു പൂർണ്ണ ആപകട വിവരിക്കുന്ന താളിപ്പ്. നിങ്ങൾക്ക് രണ്ടും ഇൻസ്റ്റാൾ ചെയ്‌തിരിക്കുന്നുവെങ്കിൽ, ചോദിക്കുക:

> "DefaultAzureCredential authentication ഉപയോഗിച്ച് ഒരു ഫയൽ Azure Blob Storage-ൽ അപ്‌ലോഡ് ചെയ്യുന്ന Python സ്ക്രിപ്റ്റ് സൃഷ്ടിക്കുക. സ്ക്രിപ്റ്റ് എന്റെ 'mycompanystorage' എന്ന Azure സ്റ്റോറേജ് അക്കൗണ്ടുമായി ബന്ധപ്പെടണം, 'documents' എന്ന കണ്ടെയ്‌നറിലേക്ക് അപ്‌ലോഡ് ചെയ്യണം, നിലവിലെ ടൈംസ്റ്റാമ്പ് ഉപയോഗിച്ച് ഒരു ടെസ്റ്റ് ഫയൽ സൃഷ്ടിച്ച് അപ്‌ലോഡ് ചെയ്യണം, പിശകുകൾ ശ്രмилമായി കൈകാര്യംചെയ്ത് വിവരപ്രദമായ ഔട്ട്‌പുട്ട് നൽകണം, Azure authentication, പിശക് കൈകാര്യം എന്നിവയ്ക്കുള്ള മികച്ച രീതികൾ പാലിക്കുക, DefaultAzureCredential authentication എങ്ങനെ പ്രവർത്തിക്കുന്നു എന്നെ കുറിച്ചുള്ള കമന്റുകൾ ഉൾപ്പെടുത്തുക, ഫങ്ഷനുകൾ, ഡോക്യുമെന്റേഷൻ എന്നിവ കൊണ്ട് സംതൃപ്തമായ സ്ക്രിപ്റ്റ് ആകണം."

Azure MCP Server ഒരു മുഴുവൻ, ഉത്പാദനത്തിനായി ഒരുങ്ങിയ Python സ്ക്രിപ്റ്റ് സൃഷ്ടിക്കും, ഇത്:
- ഏറ്റവും പുതിയ Azure Blob Storage SDK യും async മാതൃകകളും ഉപയോഗിക്കുന്നു
- DefaultAzureCredential സമഗ്രമായ ഫോള്ബാക്ക് ശൃംഖലയോടുകൂടി ഉള്‍ക്കൊള്ളുന്നു
- വിശിഷ്ടമായ Azure Exception ടൈപ്പുകളിലുള്ള ശക്തമായ പിശക് കൈകാര്യം ഉൾപ്പെടുന്നു
- റിസോഴ്‌സ് മാനേജ്മെന്റ്, കണക്ഷൻ കൈകാര്യം എന്നിവയ്‌ക്ക് Azure SDK മികച്ച രീതികൾ പാലിക്കുന്നു
- വിശദമായ ലോഗിംഗ്, വിവരപ്രദമായ കൺസോള ഔട്ട്‌പുട്ട് നൽകുന്നു
- ഫങ്ഷനുകൾ, ഡോക്യുമെന്റേഷൻ, ടൈപ്പ് ഹിന്റുകളോടെ നല്ല ഘടനയുള്ള സ്ക്രിപ്റ്റ് സൃഷ്ടിക്കുന്നു

Azure MCP ഇല്ലാതെ നിങ്ങൾക്ക് സാധാരണമായ, പ്രവർത്തിക്കുന്ന പ്രമാണ സമ്പാദ്യതയും ഈ കോഡ് ലഭിച്ചേനെ. Azure MCP ഉപയോഗിച്ച് നിങ്ങൾക്ക് ഏറ്റവും പുതിയ authentication രീതികൾ പ്രയോഗിക്കുന്ന, Azure പ്രത്യേക പിശക് സംഭവങ്ങൾ കൈകാര്യം ചെയ്യുന്ന, Microsoft-ന്റെ ഉത്പാദന അപേക്ഷകളുടെ നിർദ്ദേശിച്ച രീതികൾ പാലിക്കുന്ന കോഡ് ലഭിക്കും.

**പ്രമുഖ ഉദാഹരണം**: `az` ആൻഡ് `azd` CLIs-ന്റെ പ്രത്യേക കമാൻഡുകൾ ഓർക്കുന്നതിൽ എനിക്ക് ബുദ്ധിമുട്ടുണ്ട്. പലപ്പോഴും രണ്ട് ചുവടുകൾ ആവുന്നു: ആദ്യം സിന്റാക്സ് തിരയുക, പിന്നെ കമാൻഡ് നടത്തുക. ഞാൻ പലപ്പോഴും പോർട്ടലിൽ പോയി ക്ലിക്കുചെയ്തു ജോലി ചെയ്യുന്നു, കാരണം CLI സിന്റാക്സ് ഓർക്കാനാകുന്നില്ല എന്നത് സമ്മതിക്കാൻ ഞാൻ ആഗ്രഹിക്കുന്നില്ല. ഞാൻ ആവശ്യമായത് വിവരണം നൽകാനാകും എന്നത് അതിശയകരമാണ്, അത് IDE വിട്ട് എവിടെ പോകാതെ ചെയ്യാൻ കഴിഞ്ഞാൽ അതേക്കാളും മികച്ചത്!

[Azure MCP repository](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) ൽ നമുക്ക് ആരംഭിക്കാനുള്ള വലിയ use case പട്ടിക ഉണ്ട്. സമഗ്രമായ സെറ്റ്അപ്പ് ഗൈഡുകളും മെച്ചപ്പെട്ട കോൺഫിഗറേഷൻ ഓപ്ഷനുകളും അറിയാൻ [അധികൃത Azure MCP ഡോക്യുമെന്റേഷൻ](https://learn.microsoft.com/azure/developer/azure-mcp-server/) കാണുക.

### 3. 🐙 GitHub MCP Server

[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**ഇത് എന്ത് ചെയ്യുന്നു**: GitHub MCP Server GitHub-ന്റെ മുഴുവൻ പരിസ്ഥിതിയുമായി സുന്ദരമായ ഒരുമിപ്പിക്കൽ നൽകുന്നു, ഹോസ്റ്റ് ചെയ്ത രിമോട്ട് ആക്‌സസ്, ലൊക്കൽ Docker വിന്യാസ ഓപ്ഷനുകൾ എന്നിവ ഉൾപ്പെടുന്നു. ഇത് അടിസ്ഥാന റീപ്പോ ഓപ്പറേഷനുകൾക്ക് മാത്രമല്ല; GitHub Actions മാനേജ്മെന്റ്, പുൾ റിക്വസ്റ്റ് പ്രവൃത്തിവഴികൾ, ഇഷ്യൂ ട്രാക്കിംഗ്, സുരക്ഷാ സ്കാനിംഗ്, അറിയിപ്പുകൾ, ആധുനിക ഓട്ടോമേഷൻ കഴിവുകൾ എന്നിവ ഉൾക്കൊള്ളുന്ന സമഗ്രമായ ടൂൾകിറ്റ് ആണ്.

**ഇത് എന്തുകൊണ്ട് ഉപകാരപ്രദമാണ്**: ഇത് GitHub-നോടുള്ള 당신의 상호 작용을 변형하여, പ്രൊജെക്ട് മാനേജ്മെന്റ്, കോഡ് റിവ്യൂ, CI/CD നിരീക്ഷണം എന്നിവയ്ക്കായി VS Code-നും GitHub.com-നുമിടയിൽ തുടർച്ചയായി മാറുന്നതുപകരം, സ്വാഭാവിക ഭാഷ കമാൻഡുകൾ ഉപയോഗിച്ച് എല്ലാ കാര്യങ്ങളും നിഷ്‌പ്രയാസം ചെയ്‌തുകൊണ്ട് കോഡിൽ ശ്രദ്ധ കേന്ദ്രീകരിക്കാൻ കഴിയുന്നു.

> **ℹ️ കുറിപ്പ്: വ്യത്യസ്ത 'എജന്റുകളുടെ' തരം**
> 
> GitHub MCP Server-നെ GitHub-ന്റെ Coding Agent (താനായി കോഡിംഗ് പ്രവർത്തനങ്ങൾക്കായി GitHub ഇഷ്യൂകളിൽ നിയോഗിക്കാവുന്ന AI ഏജന്റ്) ഏജന്റുമായി തെറ്റിദ്ധരിക്കരുത്. GitHub MCP Server VS Code-ന്റെ Agent മോഡിൽ GitHub API ഏകീകരണം നൽകുന്നത് ആണെന്ന് പക്ഷേ GitHub Coding Agent സെപറേറ്റ് ഒരു ഫീച്ചർ ആണ്, ഇത് GitHub ഇഷ്യൂകൾക്ക് നിയോഗിക്കുമ്പോൾ പുൾ റിക്വസ്റ്റ് സൃഷ്ടിക്കുന്നു.

**പ്രധാന കഴിവുകൾ**:
- **⚙️ GitHub Actions**: സമഗ്രമായ CI/CD പൈപ്പ്‌ലൈൻ മാനേജ്മെന്റ്, പ്രവൃത്തിവഴി നിരീക്ഷണം, ആർട്ടിഫാക്റ്റ് കൈകാര്യം
- **🔀 പുൾ റിക്വസ്റ്റുകൾ**: സൃഷ്ടിക്കൽ, റിവ്യൂ, മേഴ്ജ് മാനേജ്മെന്റ്, സമഗ്ര സ്ഥിതി ട്രാക്കിംഗ്
- **🐛 ഇഷ്യൂകൾ**: പൂർണ്ണ ഇഷ്യൂ ജീവനചക്ര മാനേജ്മെന്റ്, കമന്റിംഗും ലേബലിംഗും അസൈൻമെന്റും
- **🔒 സുരക്ഷ**: കോഡ് സ്കാനിംഗ് അറിയിപ്പുകൾ, രഹസ്യ കണ്ടെത്തൽ, Dependabot ഏകീകരണം
- **🔔 അറിയിപ്പുകൾ**: സ്മാർട്ട് അറിയിപ്പ് മാനേജ്മെന്റ്, റീപ്പോ സബ്സ്ക്രിപ്ഷൻ നിയന്ത്രണം
- **📁 റീപ്പോ മാനേജ്മെന്റ്**: ഫയൽ പ്രവർത്തനങ്ങൾ, ബ്രാഞ്ച് മാനേജ്മെന്റ്, റീപ്പോ അഡ്മിനിസ്ട്രേഷൻ
- **👥 കൂട്ടായ്മ**: ഉപയോക്തൃ-സംഘാടന സെർച്ച്, ടീം മാനേജ്മെന്റ്, ആക്‌സസ് നിയന്ത്രണം

**പ്രായോഗിക ഉപയോഗം**: "എന്റെ ഫീച്ചർ ബ്രാഞ്ചിൽ നിന്നുള്ള പുൾ റിക്വസ്റ്റ് സൃഷ്ടിക്കുക", "ഈ ആഴ്ചയിലെ എല്ലാ ഫെയ്‌ലായ CI റൺസും കാണിക്കുക", "എന്റെ റീപ്പോകളിലേയ്ക്ക് തുറന്നിരിക്കുന്ന എല്ലാ സുരക്ഷാ അറിയിപ്പുകൾ പട്ടിക ചെയ്യുക", "എന്റെ സംഘടനകളിലെ എനിക്ക് നിയോഗിച്ച എല്ലാ ഇഷ്യൂകളും കണ്ടെത്തുക"

**സമ്പൂർണ്ണ ഡെമോ സീനാരിയോ**: GitHub MCP Server-ന്റെ കഴിവുകൾ പ്രദർശിപ്പിക്കുന്ന ശക്തമായ പ്രവൃത്തിവഴി:

> "ഞാൻ നമ്മുടെ സ്പ്രിന്റ് റിവ്യൂക്ക് തയ്യാറാകണം. ഞാൻ ഈ ആഴ്ച സൃഷ്ടിച്ച എല്ലാ പുൾ റിക്വസ്റ്റുകളും കാണിക്കൂ, CI/CD പൈപ്പ്‌ലൈൻ നില പരിശോധിക്കൂ, പരിഹരിക്കേണ്ട സുരക്ഷാ അറിയിപ്പുകളുടെ ഒരു സംഗ്രഹം സൃഷ്ടിക്കൂ, എന്നിവ തയ്യാറാക്കാൻ സഹായിക്കൂ, 'feature' ലേബലുള്ള മേഴ്ജ് ചെയ്ത പുൾ റിക്വസ്റ്റുകളിൽ നിന്ന് റീലീസ് നോട്ടുകൾ ഒരുക്കാൻ സഹായിക്കൂ."

GitHub MCP Server ചെയ്യുന്നത്:
- നിങ്ങളുടെ പുതുക്കിയ പുൾ റിക്വസ്റ്റുകളെ വിശദമായ സ്ഥിതി വിവരങ്ങളോടുകൂടി ചോദ്യം ചെയ്യുക
- പ്രവൃത്തിവഴി പ്രവർത്തനങ്ങൾ വിശകലനം ചെയ്ത് പരാജയങ്ങൾ അല്ലെങ്കിൽ പ്രകടന പ്രശ്നങ്ങൾ അടയാളപ്പെടുത്തുക
- സുരക്ഷാ സ്കാനിംഗ് ഫലങ്ങൾ ക്രമീകരിക്കുകയും പ്രധാനപ്പെട്ട അറിയിപ്പുകൾ മുൻഗണന നൽകുകയും ചെയ്യുക
- മേഴ്ജഡ് പുൾ റിക്വസ്റ്റുകളിൽ നിന്നും വിവരങ്ങൾ എടുത്ത് സമഗ്ര റീലീസ് നോട്ടുകൾ സൃഷ്ടിക്കുക

**എന്ത് ചെയ്യുന്നു**: MarkItDown പല ഫയൽ ഫോർമാറ്റുകൾ ഉയർന്ന നിലവാരമുള്ള Markdown-ലേക്ക് പരിവർത്തനം ചെയ്യുന്ന സമഗ്രമായ ഡോക്യുമെന്റ് کنവർഷൻ സർവർ ആണ്, LLM ഉപയോഗത്തിനും വാചക വിശകലന പ്രവൃത്തികൾക്കുമായിoptimized ചെയ്തതാണ്.

**എന്തിന് ഇത് ഉപകാരപ്രദമാണെന്ന്**: ആധുനിക ഡോക്യുമെന്റേഷൻ പ്രവൃത്തികൾക്കായി അനിവാര്യമാണ്! MarkItDown ഡോക്യുമെന്റിന്റെ പ്രധാന ഘടനകളായ തലക്കെട്ടുകൾ, പട്ടികകൾ, പട്ടികകൾ, ലിങ്കുകൾ എന്നിവ സംരക്ഷിക്കുമ്പോൾ വിവിധ ഫയൽ ഫോർമാറ്റുകളെ കൈകാര്യം ചെയ്യുന്നു. ലളിതമായ വാചകഏകീകരണ ഉപകരണങ്ങളെ അപേക്ഷിച്ച്, ഇത് AI പ്രോസസ്സിംഗിനും മനുഷ്യ വായനയ്ക്കും മൂല്യപ്പെട്ടതായ സാംവേദശീല അർത്ഥവും ഫോർമാറ്റിംഗും നിലനിര്‍ത്തുന്നതിൽ ശ്രദ്ധ കേന്ദ്രീകരിക്കുന്നു.

**പിന്തുണ ലഭിക്കുന്ന ഫയൽ ഫോർമാറ്റുകൾ**:
- **ഓഫീസ് ഡോക്യുമെന്റുകൾ**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **മീഡിയ ഫയലുകൾ**: ചിത്രങ്ങൾ (EXIF മെറ്റാഡാറ്റയും OCR-ഉം ഉൾപ്പെടെ), ഓഡിയോ (EXIF മെറ്റാഡാറ്റയും സംസാര ട്രാൻസ്ക്രിപ്ഷനും ഉൾപ്പെടെ)
- **വെബ് ഉള്ളടക്കം**: HTML, RSS ഫീഡുകൾ, YouTube URL-കൾ, വിക്കీపీഡിയ പേജുകൾ
- **ഡാറ്റ ഫോർമാറ്റുകൾ**: CSV, JSON, XML, ZIP ഫയലുകൾ (ആവൃത്തി അടിസ്ഥാനത്തിൽ ഉള്ളടക്കം പ്രോസസ്സ് ചെയ്യുന്നു)
- **പ്രസിദ്ധീകരണ ഫോർമാറ്റുകൾ**: EPub, Jupyter നോട്ട്‌ബുക്കുകൾ (.ipynb)
- **ഇമെയിൽ**: Outlook സന്ദേശങ്ങൾ (.msg)
- **അടുക്കളം**: PDF പ്രോസസ്സിംഗിനായി Azure Document Intelligence ഇന്റഗ്രേഷൻ

**അടുത്ത തലത്തിലുള്ള കഴിവുകൾ**: OpenAI ക്ലയന്റ് നൽകുന്നെങ്കിൽ LLM- അടിസ്ഥാനമുള്ള ചിത്രം വിവരണങ്ങൾ, മികച്ച PDF പ്രോസസ്സിംഗിനായി Azure Document Intelligence, സംസാര ഉള്ളടക്കത്തിനുള്ള ഓഡിയോ ട്രാൻസ്ക്രിപ്ഷൻ, കൂടാതെ കൂടുതലുള്ള ഫയൽ ഫോർമാറ്റുകളിലേക്ക് വിപുലീകരിക്കാനായി പ്ലഗിൻ സിസ്റ്റം MarkItDown നൽകുന്നു.

**വാസ്തവ ലോകത്തിൽ ഉപയോഗം**: "ഈ PowerPoint പ്രദർശനം Markdown-ലേക്ക് പരിവർത്തിക്കൂ ഞങ്ങളുടെ ഡോക്യുമെന്റേഷൻ സൈറ്റിനായി", "ഈ PDF-യിൽ നിന്നുള്ള വാചകം ശരിയായ തലക്കെട്ട് ഘടനയോടെ എടുക്കുക", അല്ലെങ്കിൽ "ഈ Excel സ്പ്രഡ്‌ഷീറ്റ് വായനക്ക് സാധിക്കുന്ന പട്ടിക ഫോർമാറ്റിലേക്ക് മാറ്റുക"

**പ്രധാന ഉദാഹരണം**: [MarkItDown ഡോകുകൾ](https://github.com/microsoft/markitdown#why-markdown) ഉദ്ധരിക്കാൻ:

> Markdown ലഘു മാര്‍ക്ക് അപ്പും ഫോർമാറ്റിംഗും ഉള്ള പLAIN ടെക്സ്റ്റിന് വളരെ അടുത്തതാണ്, എന്നിരുന്നാലും പ്രധാനപ്പെട്ട ഡോക്യുമെന്റ് ഘടന പ്രതിനിധീകരിക്കുന്ന മാർഗം നൽകുന്നു. OpenAI-യുടെ GPT-4o പോലുള്ള പ്രധാന LLMകൾ സ്വാഭാവികമായും "Markdown" സംസാരിക്കുന്നു, കൂടാതെ പലപ്പോഴും പ്രചോദനം കൂടാതെMarkdown അവരവരുടെ പ്രതികരണങ്ങളിൽ ഉൾപ്പെടുത്തുന്നു. ഇത് അവര് വിപുലമായ Markdown-ഫോർമാറ്റ് ചെയ്ത വാചകത്തിന്റെ അളവിൽ പരിശീലിക്കപ്പെട്ടുവെന്നും അതിനെ നന്നായിത്തു മനസ്സിലാക്കുന്നതുമാണ് സൂചിപ്പിക്കുന്നത്. പക്കാലായി, Markdown രീതി വളരെ ടോക്കൺ കാര്യക്ഷമവും ആണ്.

MarkItDown ഡോക്യുമെന്റ് ഘടന സംരക്ഷിക്കുന്നതിൽ വളരെ മികച്ചതാണ്, അത് AI പ്രവൃത്തികൾക്ക് സുപ്രധാനമാണ്. ഉദാഹരണത്തിന്, ഒരു PowerPoint പ്രദർശനം പരിവർത്തിക്കുമ്പോൾ, ഇത് ശരിയായ തലക്കെട്ടുകളോടൊപ്പം സ്ലൈഡ് സംഘാടകത്വം നിലനിര്‍ത്തുന്നു, ടേബിളുകൾ Markdown പട്ടികകളായി എടുക്കുന്നു, ചിത്രങ്ങൾക്ക് alt ടെക്സ്റ്റ് ഉൾക്കൊള്ളുന്നു, കൂടാതെ സ്പീക്കർ നോട്ടുകളും പ്രോസസ്സ് ചെയ്യുന്നു. ചാർട്ടുകൾ വായനക്ക് എളുപ്പമുള്ള ഡാറ്റ പട്ടികകളായി മാറ്റപ്പെടുന്നു, പരിവർത്തന ഫലം പതിമൂന്നാം ഘടകത്തിന്റെ യുക്തിപരമായ പ്രവാഹം നിലനിര്‍ത്തുന്നു. ഇത് അവതരണം ഉള്ളടക്കം AI സിസ്റ്റങ്ങളിൽ നൽകാനും നിലവിലുള്ള സ്ലൈഡുകളിൽ നിന്നുള്ള ഡോക്യുമെന്റേഷൻ സൃഷ്ടിക്കാനും യോജിക്കുന്നു.

**പ്രസിദ്ധമായ ഉദാഹരണം**: ഡെവലപ്പറായി, ലഭ്യമായ വ്യത്യസ്ത LLM മോഡലുകൾ പിന്തുടരാൻ എനിക്ക് ബുദ്ധിമുട്ടുണ്ട്. ഞാൻ ചില പ്രധാന മോഡലുകൾക്ക് പരിചിതനാണ്, പക്ഷേ കുറച്ച് ഉത്പാദകതയും കാര്യക്ഷമതയും നഷ്ടപ്പെടുന്ന അനുഭവമുണ്ടെന്ന് തോന്നുന്നു. ടോക്കണുകളും ക്വോട്ടാസും മാനേജുചെയ്യുന്നത് സമ്മർദ്ദമുണർത്തുന്നു — കഴിഞ്ഞിടത്തോളം ശരിയായ മോഡൽ ശരിയായ പ്രവർത്തനത്തിന് തിരഞ്ഞെടുക്കുകയാണോ എന്ന് ഉറപ്പില്ല, അല്ലെങ്കിൽ ബഡ്ജറ്റ് അസാധുവായി ഉപയോഗിക്കുകയാണോ എന്നും സംശയമാണ്. ഈ MCP സർവർ James Montemagno ക്ക് നിന്നാണ് അറിയുന്നത്, ഈ പോസ്റ്റുകൊണ്ട് ടീം പ്രവർത്തകരുമായി MCP സർവർ ശുപാർശകൾ തേടുമ്പോൾ, ഇത് ഉപയോഗിക്കാൻ ഞാനുഷ്‌ടിക്കുന്നു! മോഡൽ കണ്ടെത്തൽ കഴിവുകൾ എന്നെ ഏറ്റവും ആകര്‍ഷിക്കുകയാണ്, സാധാരണ മോഡലുകളെക്കാളും കൂടുതൽ ഗവേഷണം നടത്താനും പ്രത്യേക പ്രവർത്തനങ്ങൾക്ക് അനുയോജ്യമായ മോഡലുകൾ കണ്ടെത്താനും കഴിയുമെന്ന് പ്രതീക്ഷിക്കുന്നു. വിലയിരുത്തൽ ഫ്രെയിംവർക്കിലൂടെ പുതിയ ഒരു രീതി പരീക്ഷിക്കുന്നതിനല്ല, حقیقیന്നും നല്ല ഫലമുണ്ടോ എന്ന് ഉറപ്പാക്കാൻ സഹായിക്കും.

## 📋 സമാപനം

മോഡൽ കോൺടെക്സ്റ്റ് പ്രോട്ടോക്കോൾ (MCP) വികസിതരുടെ AI അസിസ്റ്റന്റുകളുമായി, ബാഹ്യ ഉപകരണങ്ങളുമായി സംവദിക്കുന്ന വിധം മാറ്റുകയാണ്. ഈ 10 മൈക്രോസോഫ്റ്റ് MCP സർവറുകൾ ഏകീകൃത AI ഇന്റഗ്രേഷൻ ശക്തി പ്രകടിപ്പിക്കുന്നു, ശക്തമായ ബാഹ്യ ശേഷികൾക്കായി വികസകരെ അവരുടെ പ്രവാഹാവസ്ഥയിൽ നിലനിർത്തി പ്രവർത്തനം എളുപ്പമാക്കുന്നു.

സമഗ്രമായ Azure ഇക്കോസിസ്റ്റം സംയോജനം മുതൽ ബ്രൗസർ ഓട്ടോമേഷനന് Playwright, ഡോക്യുമെന്റ് പ്രോസസ്സിങ്ങിന് MarkItDown പോലുള്ള പ്രത്യേക ഉപകരണങ്ങൾ വരെ, ഈ സർവർകൾ MCP വളർച്ചയ്ക്ക് പ്രോത്സാഹനം നൽകുന്നില്ല, വ്യത്യസ്ത വികസന സാഹചര്യങ്ങളിൽ ഉൽപ്പാദകത്വം വർദ്ധിപ്പിക്കുന്നു. ഏകീകൃത പ്രോട്ടോക്കോൾ ഈ ഉപകരണങ്ങൾ ശ്രേണി ചേർന്ന് സുതാര്യമുള്ള വികസന അനുഭവം സൃഷ്ടിക്കുന്നു.

MCP ഇക്കോസിസ്റ്റം വളർന്ന് വരുന്നതിനാൽ, സമൂഹത്തിൽ സജീവമായി പങ്കെടുക്കുക, പുതിയ സർവർകൾ പരീക്ഷിക്കുക, കസ്റ്റം പരിഹാരങ്ങൾ നിർമ്മിക്കുക എന്നിവ നിങ്ങളുടെ വികസന ഉൽപ്പാദകത്വം പരമാവധി ഉപയോഗപ്പെടുത്താൻ നിർണായകമാണ്. MCPയുടെ തുറന്ന സ്റ്റാൻഡേർഡായ സ്വഭാവം വ്യത്യസ്ത വിൽപ്പനക്കാരുടെ ഉപകരണങ്ങൾ മിക്സും മാച്ചും ചെയ്ത് നിങ്ങളുടെ പ്രത്യേക ആവശ്യങ്ങൾക്ക് അനുയോജ്യമായ പ്രവാഹം സൃഷ്ടിക്കാൻ അനുവദിക്കുന്നു.

3. **സ്വകാര്യ സർവർ പ്ലാനിങ്ങ്**: നിങ്ങളുടെ ദൈനംദിന വികസന പ്രവൃത്തി ഒരു MCP സർവർ കൊണ്ടുചേരുമ്പോൾ പ്രയോജനം ലഭിക്കുമെന്ന തരത്തിൽ ഒരു സ്പെസിഫിക്കേഷൻ സൃഷ്‌ടിക്കുക.
4. **പ്രകടന വിശകലനം**: MCP സർവറുകൾ ഉപയോഗിക്കുമ്പോഴുള്ള കാര്യക്ഷമത പരമ്പരാഗത രീതികളോട് താരതമ്യം ചെയ്യുക.
5. **സുരക്ഷാ വിലയിരുത്തൽ**: MCP സർവറുകൾ ഉപയോഗിക്കുന്ന സാഹചര്യത്തിലെ സുരക്ഷാ പ്രശ്‌നങ്ങൾ വിലയിരുത്തി മികച്ച രീതികൾ നിർദ്ദേശിക്കുക.
