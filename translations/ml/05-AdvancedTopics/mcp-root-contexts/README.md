# MCP റൂട്ടുകൾ (പഴയ ഫീച്ചർ)

> [!WARNING]
> MCP `2026-07-28` മുതൽ റൂട്ടുകൾ വിരമിച്ചിരിക്കുന്നു. ഇവ ഈ പതിപ്പിൽ വേണ്ടത്രമായ
> അനുകൂലതക്കായി തുടരുന്നത് മാത്രമാണ്, ജൂലൈ 28, 2027 മുതൽ ഇറക്കുന്ന ആദ്യ സ്പെസിഫിക്കേഷൻ
> പതിപ്പിൽ ഇവ ഒഴിവാക്കാനുള്ള സാധ്യത ഉണ്ട്. പുതിയ നടപ്പാക്കലുകൾ ടൂൾ പാരാമീറ്ററുകൾ,
> റിസോഴ്‌സ് URIകൾ, അല്ലെങ്കിൽ സെർവർ കോൺഫിഗറേഷൻ വഴി ഡയറക്ടറികളോ ഫയലുകളോ കൈമാറണം.


## അവലോകനം

റൂട്ടുകൾ MCP ക്ലയന്റ് ഒരു സെർവറിനോട് നിലവിലെ അഭ്യർത്ഥനയ്ക്ക് പ്രസക്തമായ ഫയൽസിസ്റ്റം സ്ഥിതികള്‍
കാണിക്കാനാകും. ഒരു റൂട്ടിൽ ആവശ്യമായ `file://` URIയും, ഐച്ഛികമായി വായിക്കാൻ കഴിയുന്ന പേര്‍
ഉണ്ടാകാം.

റൂട്ടുകൾ നിർദേശം നൽകുന്ന സൂചനകളാണ്. അവ സംഭാഷണ ചരിത്ര കണ്ടെയ്നറുകളും, പ്രോട്ടോക്കോൾ
സെഷനുകളുമോ, ആക്‌സസ് നിയന്ത്രണ മാര്‍ഗങ്ങളും അല്ല. ഒരു സെർവർ നൽകിയ റൂട്ടുകളിലേക്ക് മാത്രം
കിടക്കുമെന്ന് പ്രോട്ടോക്കോൾ നിർബന്ധമില്ല.

## പഠന ലക്ഷ്യങ്ങൾ

ഈ പാഠം അവസാനിപ്പിച്ചാൽ നിങ്ങൾക്ക് കഴിയുന്നതല്ല:

- MCP റൂട്ടുകൾ എന്തിനെ പ്രതിനിധീകരിക്കുന്നു എന്നതും എന്തിനെ പ്രതിനിധീകരിക്കാത്തതും വിശദീകരിക്കുക.
- നിലവിലുള്ള `roots/list` മള്‍റൗണ്ട്-ട്രിപ്പ് ഫ്ലോ മനസ്സിലാക്കുക.
- റൂട്ടുകളിൽ നിന്നും സ്വതന്ത്രമായി സുരക്ഷാ നിയന്ത്രണങ്ങൾ പ്രയോഗിക്കുക.
- പുതിയ നടപ്പാക്കലുകൾ പിന്തുണയ്ക്കപ്പെടുന്ന പകരക്കാരിലേക്ക് മാറ്റുക.

## റൂട്ടിന്റെ ഡാറ്റ

ഒരു ക്ലയന്റ് ഓരോ റൂട്ടും `file://` URI ആയി, ഐച്ഛിക പ്രദർശന പടിയോടുകൂടി തിരിച്ചുവിടുന്നു:

```json
{
  "roots": [
    {
      "uri": "file:///home/user/projects/weather-service",
      "name": "Weather Service"
    }
  ]
}
```

ക്ലയന്റുകൾ ഉപയോഗിക്കുന്ന ആളുകളുടെ അംഗീകൃത സ്ഥലങ്ങൾ മാത്രമേ പ്രദർശിപ്പിക്കണമായുള്ളൂ. സെർവർ
ഫലത്തെ പ്രസക്തമായ ഫയലുകൾക്ക് മാർഗ്ഗനിർദ്ദേശമായി കാണണം, അധികാരസമ്പ്രാപ്തിയുടെ തെളിവായി അല്ല.

## MCP 2026-07-28 ഫ്ലോ

റൂട്ടുകൾ പിന്തുണയ്ക്കുന്ന ഒരു ക്ലയന്റ് എല്ലാ അഭ്യർത്ഥനയിലും കഴിവ് പ്രഖ്യാപിക്കുന്നു:

```json
{
  "_meta": {
    "io.modelcontextprotocol/clientCapabilities": {
      "roots": {}
    }
  }
}
```

ഒരു ക്ലയന്റിന്റെ അഭ്യർത്ഥന സംസ്‌കരിക്കുമ്പോൾ, ഒരു സെർവർ `roots/list` ഇൻപുട്ട് അഭ്യർത്ഥന ഉൾക്കൊള്ളുന്ന
`InputRequiredResult` നൽകാം:

```json
{
  "resultType": "input_required",
  "inputRequests": {
    "workspaceRoots": {
      "method": "roots/list"
    }
  },
  "requestState": "opaque-state-from-server"
}
```

ക്ലയന്റ് അംഗീകൃത റൂട്ടുകൾ ശേഖരിച്ച് പൊരുത്തപ്പെടുന്ന `inputResponses` ഉപയോഗിച്ച് യഥാർത്ഥ അഭ്യർത്ഥന വീണ്ടും
അയയ്ക്കുന്നു, മാറാതെ ഇരിക്കുന്ന `requestState` ഉപയോഗിച്ച്. ഈ മള്‍റൗണ്ട്-ട്രിപ്പ് മാതൃക പ്രോട്ടോക്കോൾ
സ്റ്റേറ്റ്ലസ്സ് ആക്കുന്നു; `initialize` കൈമാറലോ പ്രോട്ടോക്കോൾ-തല സെഷനോ ഇല്ല.


## പഴയ 2025-11-25 പെരുമാറ്റം

MCP `2025-11-25`ൽ, ക്ലയന്റുകൾ ഇൻീഷ്യലൈസേഷനിൽ റൂട്ടുകൾ പ്രഖ്യാപിച്ചിരുന്നു. ഒരു സെർവർ നേരിട്ട് `roots/list`
അഭ്യർത്ഥന അയയ്ക്കാമായിരുന്നു, ക്ലയന്റ് റൂട്ടുകൾ മാറ്റം വന്നപ്പോൾ `notifications/roots/list_changed` അയയ്ക്കാമായിരുന്നു.


നടപ്പാക്കലുമായി സംയോജിപ്പിക്കരുത്.


## ശുപാർശ ചെയ്‌ത പകരംവിധി

### ടൂൾ പാരാമീറ്ററുകൾ

ആവശ്യമായ ഡയറക്ടറി അല്ലെങ്കിൽ ഫയൽ ടൂൾ സ്കീമയിൽ വ്യക്തമാക്കുക:

```json
{
  "name": "analyze_project",
  "inputSchema": {
    "type": "object",
    "properties": {
      "projectDirectory": {
        "type": "string",
        "description": "Approved project directory to analyze"
      }
    },
    "required": ["projectDirectory"]
  }
}
```

### റിസോഴ്‌സ് URIകൾ

ഒരു സെർവർ പ്രസക്തമായ ഫയലുകൾ സ്ഥിരമായ URIകൾ വഴി പ്രദർശിപ്പിക്കാൻ കഴിന്നപ്പിൽ MCP റിസോഴ്‌സുകൾ ഉപയോഗിക്കുക.
ഇത് കണ്ടെത്തലും പുനഃപ്രാപ്തിയും വ്യക്തമാക്കുന്നു.

### സെർവർ കോൺഫിഗറേഷൻ

സ്ഥിരമായ വിന്യാസങ്ങൾക്കായി സെർവർ ആരംഭിക്കുമ്പോൾ അനുവദനീയ ഡയറക്ടറികൾ ക്രമീകരിക്കുക.
ഇത് ഒരു ടൂൾ കോൾ സമയത്ത് കണ്ടെത്തുന്നതിന് വെളിപ്പെടുത്തിയതാണ്.

## സുരക്ഷാ ആവശ്യകതകൾ

നിങ്ങൾ തിരഞ്ഞെടുക്കുന്ന പകരംവിധി എന്തായാലും:

- ഫയൽസിസ്റ്റം സ്ഥാനങ്ങൾ വെളിപ്പെടുത്തുന്നതിന് മുമ്പ് ഉപയോക്തൃ അംഗീകാരം നേടുക.
- സഞ്ചാരം തടയാനുള്ള canonicalization/സാധുത പരിശോധന നടത്തുക.
- റൂട്ടിന്റെ മൂല്യങ്ങളിൽ നിന്ന് സ്വതന്ത്രമായി അധികാരസംബന്ധവും സാൻഡ്‌ബോക്സിംഗും പ്രയോഗിക്കുക.
- ഫയൽ ആക്സസ് ചെയ്തപ്പോൾ പരസ്യാനുമതികൾ വീണ്ടും പരിശോധിക്കുക, വെറും ലിസ്റ്റ് ചെയ്തപ്പോൾ മാത്രമല്ല.
- ലോഗുകളിലും പിശക് സന്ദേശങ്ങളിലും സൂക്ഷ്മമായ പാതകൾ കാണിക്കരുത്.

## പ്രധാനപ്പെട്ട കാര്യങ്ങൾ

- റൂട്ടുകൾ പ്രസക്തമായ ഫയൽസിസ്റ്റം സ്ഥിതികൾ വിവരിക്കുന്നു; സംവാദ സ്ഥിതികൾ സൂക്ഷിക്കുന്നില്ല.

- റൂട്ടുകൾ മാർഗ്ഗനിർദേശം നൽകുന്നു, ആക്‌സസ് നിയന്ത്രണ ഹദി അല്ല.
- MCP `2026-07-28` കഴിവ് ഓരോ അഭ്യർത്ഥനയിലും ഉൾക്കൊള്ളുന്നു, `roots/list`ൻ `InputRequiredResult` ഉപയോഗിക്കുന്നു.
- പുതിയ നടപ്പാക്കലുകൾ ടൂൾ പാരാമീറ്ററുകൾ, റിസോഴ്‌സ് URIകൾ അല്ലെങ്കിൽ സെർവർ കോൺഫിഗറേഷൻ ഉപയോഗിക്കണം.
