# മാറ്റം രേഖപ്പെടുത്തൽ: MCP for Beginners പാഠ്യക്രമം

മോഡൽ കോൺടെകസ്റ്റ് പ്രോട്ടോകോൾ (MCP) for Beginners പാഠ്യക്രമത്തിൽ ചെയ്തിരിക്കുന്ന എല്ലാ പ്രധാന മാറ്റങ്ങളും രേഖപ്പെടുത്താനുള്ള ഒന്ന് ആയി ഈ പ്രമാണം സേവിക്കുന്നു. മാറ്റങ്ങൾ ക്രമവ്യവസ്ഥയിൽ ഏറ്റവും പുതിയ മാറ്റങ്ങൾ ആദ്യം കാണിക്കുന്ന തരത്തിലാണ് രേഖപ്പെടുത്തുന്നത്.

## 2026 ജൂലൈ 29

### പുതിയ മോഡ്യൂൾ 08 കൂട്ടിരിപ്പുകാരൻ: വിശ്വാസ്യത സൈഡ്‌കാറുകളും സുരക്ഷിത പുനരയവിഷ്കരണങ്ങളും

MCP ടൂളുകൾക്ക് വിൽപ്പനക്കാരൻ-ന്യൂട്രൽ കൂട്ടിരിപ്പുകാരൻ പാഠം ചേർത്തു; അത് യാഥാർത്ഥ്യഫലങ്ങൾ സൃഷ്ടിക്കുന്നു,
ഒടുവിലെ `2026-07-28` കാഴ്ചപ്പാട് അനുസരിച്ച്.

- **പുതിയത്**: [വിശ്വാസ്യത സൈഡ്‍കാർ കൂട്ടിരിപ്പുകാരൻ പാഠം][reliability-sidecar]
  ഒരൊറ്റ പിന്തുണ-ടിക്കറ്റിൽ നിന്നുള്ള കഥ, രണ്ട് Mermaid ഡയഗ്രാമുകൾ, പുനരയവിഷ്കരണ തീരുമാനപ്രവാഹം എന്നിവ ഉപയോഗിച്ച്
  സ്ഥിരതയുള്ള പ്രവർത്തന കവികൾ, ആറ്റോമിക് ഡ്യൂപ്ലിക്കേറ്റ് അഡ്മിഷൻ, പൊരുത്തപ്പെടുത്തൽ,
  തെളിവുകൾ, എക്സ്റ്റൻഷൻ ബൗണ്ടറി എന്നിവ വിശദീകരിക്കുന്നു.
- **പുതിയത്**: സ്റ്റാൻഡേർഡ് ലൈബ്രറി Python, SQLite ഫെയില്യൂർ-ഇൻജക്ഷൻ വിജ്ഞാനം
  വേർതിരിച്ച പ്രവർത്തനവും ടിക്കറ്റ് സ്റ്റോറും ഉപയോഗിച്ച്, പുറം ഫലം പ്രതിബന്ധിച്ച ശേഷം പ്രതികരണം നഷ്ടപ്പെടുന്നത് കാണിക്കുന്നു. ആറ് നിർദ്ദിഷ്ട പരീക്ഷണം
  അന്ധമായ പുനരാവൃത്തി, സംരക്ഷിത പുനരാരംഭം,
  പെയ്ലോഡ് കോന്ഫ്ലിക്ടുകൾ, കാഷ്ഡ് ഫലങ്ങൾ,
  സജീവ അവകാശങ്ങൾ, സമകാലിക ഡ്യൂപ്ലിക്കേറ്റ് അഡ്മിഷൻ എന്നിവ പരി
- **ഇപ്പോൾ പുതുക്കിയത്**: മോഡ്യൂൾ 08 ഇപ്പോൾ കൂട്ടിരിപ്പുകാരൻ പാഠം കണ്ണി നൽകുന്നു, ഒടുവിലെ `2026-07-28` സ്റ്റേറ്റ്ലസ്
  അഭിമുഖ അഭ്യർത്ഥന മോഡൽ തിരിച്ചറിയുന്നു, OpenTelemetry  
  മുൻപ് ഉപേക്ഷിച്ച MCP ലോഗിംഗ് ഫീച്ചറുമായുള്ള വ്യത്യാസം വ്യക്തമാക്കുന്നു, പിന്നീട് ഏറ്റവും
  ജനറിക് പുനരയവിഷ്കരണ ഉദാഹരണം വായന-മാത്ര ഓപ്പറേഷനുകൾക്ക് പരിമിതപ്പെടുത്തിയിട്ടുണ്ട്.
- **ഐച്ഛികം**: പാഠം സാന്ദ്രമായ ആശയങ്ങൾ ഒരു ടാഗ്ഡ് സമുദായ
  നടപ്പിലാക്കലിലേക്ക് മാപ്പുചെയ്യുന്നു, ഹോസ്റ്റുചെയ്യുന്ന സേവനമോ നെറ്റ്‌വർക്കോൾ ഒരു ഭാഗമാക്കാതെ
  പരീക്ഷണത്തിന്റെ ഭാഗമാക്കാതെ.

## 2026 ജൂലൈ 2

വരാനിരിക്കുന്ന `2026-07-28` MCP കാഴ്ചപ്പാട് റിലീസ് കാൻഡിഡേറ്റ് (2026 മേയ് 21-ന് പ്രഖ്യാപനം; 2026 ജൂലൈ 28-ന് അന്തിമമേറ്റ发布日期) ഉൾക്കൊണ്ടു് [അധികൃത പ്രഖ്യാപന ബ്ലോഗ് പോസ്റ്റ്](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) സംക്ഷേപം നൽകുന്നു. പാഠ്യക്രമം പ്രധാനമായും MCP സവിശേഷണം 2025-11-25 ആണ് പുതിയ പതിപ്പ് വരുന്നതുവരെ തുടരുമെങ്കിലും, ഇതൊരു പുറമനസ്സുള്ള മാർഗ്ഗനിർദ്ദേശമായി അവതരിപ്പിക്കപ്പെടുന്നു.

- **പുതിയത്**: [01-CoreConcepts/mcp-2026-07-28-release-candidate.md](./01-CoreConcepts/mcp-2026-07-28-release-candidate.md) — സ്റ്റേറ്റ്ലസ് പ്രോട്ടോകോൾ കോർ എല്ലാം ഉൾപ്പെടുന്ന പൂർണ്ണ പാഠം ( `initialize` ഹാൻഡ്‌ഷേക്ക്, `Mcp-Session-Id` നീക്കം ചെയ്യൽ), പുതിയ `Mcp-Method`/`Mcp-Name` റൗട്ടിംഗ് ഹെഡറുകൾ , `ttlMs`/`cacheScope` കാഷിംഗ് മെറ്റാഡാറ്റ, W3C ട്രേസ് കോൺടെക്സ്റ്റ് `_meta`-ൽ, ഔപചാരിക എക്സ്റ്റൻഷൻ ഫ്രെയിംവർക്ക് (MCP ആപ്പുകളും പുതിയ ടാസ്‌ക്സ് എക്സ്റ്റൻഷനും), ആറ് അതോറൈസേഷൻ ഹാർഡനിങ് SEP-കൾ, Roots/Sampling/Logging ഉപേക്ഷിക്കൽ, പൂര്‍ണ്ണ JSON സ്കീമ 2020-12 വഴി ടൂൾ സ്കീമ സ്വാഗതം.

## 2026 ജൂൺ 16

### MCP സ്പെസിഫിക്കേഷൻ പൊരുത്തപ്പെടുത്തൽ & സാമ്പിൾ പരിശോധന

ഇതിനകം നിലവിലുള്ള **MCP Specification 2025-11-25** അടിസ്ഥാനമാക്കി കരിക്കുലം പരിശോധിച്ചു, ഏറ്റവും പുതിയ ഔദ്യോഗിക SDKs പരിശോധന നടത്തി, പിന്നെ പഴകിയ സ്പെസിഫിക്കേഷൻ റഫറൻസുകൾ ശരിയാക്കി, കോർ സാമ്പിൾ കെട്ടിടവും പ്രവർത്തിക്കുകയും സ്ഥിരീകരിച്ചു.

#### സ്പെസിഫിക്കേഷൻ പതിപ്പ് ശരിയാക്കൽ (2025-06-18 / 2025-03-26 → 2025-11-25)

- **05-AdvancedTopics/mcp-security/README.md**: "നിലവിലെ സ്റ്റാൻഡേർഡ്" ബാനർ, പരിചയം, കോർ സുരക്ഷാ സിദ്ധാന്തങ്ങളുടെ തലക്കെട്ട്, നിർബന്ധമായ ആവശ്യകതകൾ തലക്കെട്ട്, Microsoft Entra ID സെക്ഷൻ, റഫറൻസുകളും റിസോഴ്സുകളും ലിങ്കുകൾ, അവസാനിച്ച് സുരക്ഷാ സബൂതി (8 റഫറൻസുകൾ) 2025-11-25-നായി അപ്ഡേറ്റു ചെയ്തു
- **05-AdvancedTopics/mcp-transport/README.md**: അധിക റിസോഴ്സുകൾ സ്പെക്സ് ലിങ്കും "നിലവിലെ സ്റ്റാൻഡേർഡ്" ബാനറും 2025-11-25-നായി അപ്ഡേറ്റ് ചെയ്തു

#### കോർ ആശയങ്ങൾ മെച്ചപ്പെടുത്തൽ (01-CoreConcepts/)
- **പുതിയ ക്ലയന്റ് പ്രിമിറ്റീവ് - റൂട്ട്സ്**: ഫയൽസിസ്റ്റം പരിധിയും ആക്‌സസ് അനുമതികളും സെർവർക്ക് മനസിലാക്കാൻ സഹായിക്കുന്ന റൂട്ട്സ് ക്ലയന്റ് പ്രിമിറ്റീവ് പൂർണമായ ഡോക്യുമെന്റേഷൻ ചേർത്തു
- **ടൂൾ അണൊടേഷനുകൾ**: മെച്ചപ്പെട്ട ടൂൾ നിർവ്വഹണ തീരുമാനങ്ങൾക്കായി ടൂൾ ബഹാവിയറൽ അണൊടേഷനുകളുടെ (`readOnlyHint`, `destructiveHint`) ഡോക്യുമെന്റേഷൻ ചേർത്തു
- **സാമ്പ്ലിങ്ങിൽ ടൂൾ കോൾ**: സാമ്പ്ലിങ്ങ് അഭ്യർത്ഥനകളിൽ മോഡൽ നയിക്കുന്ന ടൂൾ കോൾ പ്രവർത്തനങ്ങൾക്ക് `tools` ഉം `toolChoice` ഉം പാരാമീറ്ററുകൾ ഉൾപ്പെടുത്തിയതായി സാമ്പ്ലിങ് ഡോക്യുമെന്റേഷൻ പുതുക്കി
- **URL മോഡ് പുറപ്പെടുവിക്കൽ**: സെർവർ-ആരംഭിച്ച പുറം വെബ് ഇടപെടലുകൾക്കായി URL അധിഷ്ഠിത പുറപ്പെടുവിക്കൽ ഡോക്യുമെന്റേഷൻ ചേർത്തു
- **ടാസ്കുകൾ (പരിക്ഷണപരമായി)**: ദിർഘകാല നിർവ്വഹണ റാപ്പറുകളും നീണ്ട മുടക്കിയ ഫലം എടുക്കലും സജ്ജമാക്കിയ പരീക്ഷണ ടാസ്ക് ഫീച്ചർ രേഖപ്പെടുത്തുന്ന പുതിയ വിഭാഗം ചേർത്തു
- **ഐക്കണുകൾ പിന്തുണ**: ടൂളുകൾ, റിസോഴ്‌സുകൾ, റിസോഴ്‌സ് ടെംപ്ലേറ്റുകൾ, പ്രോംപ്റ്റുകൾ എന്നിവയ്ക്ക് ഐക്കണുകൾ(metadata) കൂടി ഉൾപ്പെടുത്താനാകും എന്ന് കുറിച്ചു

#### ഡോക്യുമെന്റേഷൻ അപ്ഡേറ്റുകൾ

- **study_guide.md**: കോർ ആശയങ്ങൾ വിഭാഗത്തിൽ ടാസ്കുകളും ടൂൾ അണൊടേഷനുകളും ഉൾപ്പെടുത്തി കറിക്കുലം മാപ്പ് പുതുക്കി; ഡോക്യുമെന്റ് ടൈംസ്റ്റാംപ് പുതുക്കി

#### സ്പെസിഫിക്കേഷൻ കീഴടങ്ങൽ പരിശോധന
- **പ്രോട്ടോക്കോൾ പതിപ്പ്**: എല്ലാ ഡോക്യുമെന്റേഷൻ MCP സ്പെസിഫിക്കേഷൻ 2025-11-25 നിലവിലുള്ള പതിപ്പിന്FIFO സൂചിപ്പിച്ചതായി സ്ഥിരീകരിച്ചു
- **നിർമ്മാണം സര്പ്രവേശനം**: രണ്ട് ലെയർ നിർമ്മാണം (ഡേറ്റാ ലെയർ + ട്രാൻസ്പോർട്ട് ലെയർ) ഡോക്യുമെന്റേഷൻ കൃത്യത സ്ഥിരീകരിച്ചു
- **പ്രിമിറ്റീവുകൾ ഡോക്യുമെന്റേഷൻ**: സർവർ പ്രിമിറ്റീവുകൾ (റിസോഴ്‌സുകൾ, പ്രോംപ്റ്റുകൾ, ടൂളുകൾ) ഒരു ക്ലയന്റ് പ്രിമിറ്റീവുകൾ (സാമ്പ്ലിങ്ങ്, പുറപ്പെടുവിക്കൽ, ലോഗിംഗ്, റൂട്ട്സ്) ശരിയായി രേഖപ്പെടുത്തിയതായി ഉറപ്പ് വരുത്തി
- **ട്രാൻസ്പോർട്ട് മേക്കാനിസങ്ങൾ**: STDIO, സ്റ്റ്രീമബിൾ HTTP ട്രാൻസ്പോർട്ട് ഡോക്യുമെന്റേഷൻ കൃത്യത സ്ഥിരീകരിച്ചു
- **സുരക്ഷാ മാർഗനിർദ്ദേശം**: നിലവിലെ MCP സുരക്ഷാ മികച്ച പ്രാക്ടീസുകൾ ഡോക്യുമെന്റ് അനുസരിച്ചു സ്ഥിരീകരിച്ചു

#### മുൻനിര സേർവർ ഉപയോഗം (03-GettingStarted/10-advanced)
- **പുതിയ അധ്യായം ചേർത്തു**: MCP മുൻനിര സേർവർ ഉപയോഗത്തിന്റെ സമഗ്ര ഗൈഡ് അവതരിപ്പിച്ചു, സാധാരണയും താഴ്ന്നതല സേർവർ ആർക്കിടെക്ചറുകളും ഉൾപ്പെടുത്തി.
  - **സാധാരണയും താഴ്ന്നതല സർവറും**: രണ്ട് രീതികൾക്കും പൈതൺ, ടൈപ്‌സ്‌ക്രിപ്റ്റ് കോഡ് ഉദാഹരണങ്ങൾ സഹിതം സവിശേഷതകളുടെ താരതമ്യം.
  - **ഹാൻഡ്ലർ അടിസ്ഥാന ഡിസൈൻ**: സ്കേലബിൾ, ലളിതമായ സേർവർ നടപ്പിലാക്കലിനുള്ള ടൂൾ/റിസോഴ്‌സ്/പ്രോംപ്റ്റ് മാനേജ്മെന്റിന്റെ ഹാൻഡ്ലർ അടിസ്ഥാന വിശദീകരണം.
  - **പ്രായോഗിക പാറ്റേണുകൾ**: പുരോഗമിച്ച സവിശേഷതകൾക്കും ആർക്കിടെക്ചറിനും താഴ്ന്നതല സേർവർ മാതൃകകൾ എങ്ങനെ ઉપયોગപ്രദമാണ് എന്ന വ്യവഹാരിക ദൃശ്യങ്ങൾ.

#### ലളിതമായ അംഗീകാരം (03-GettingStarted/11-simple-auth)
- **പുതിയ അധ്യായം ചേർത്തു**: MCP സർവറുകളിൽ ലളിതമായ അംഗീകരണം നടപ്പിലാക്കാനുള്ള അവസാന ഘട്ട പ്രകടനം.
  - **അംഗീകാരം ആശയങ്ങൾ**: അംഗീകാരവും അധികാരവും, ക്രെഡൻഷ്യൽ കൈകാര്യം എന്നിവയുടെ വ്യക്തമായ വിശദീകരണം.
  - **മൂലരൂപ് അംഗീകാരം നടപ്പാക്കൽ**: പൈതൺ (Starlette) ടൈപ്‌സ്‌ക്രിപ്റ്റ് (Express) എന്നിവയിൽ മിഡിൽവെയർ അടിസ്ഥാനത്തിലുള്ള അംഗീകാരം പാറ്റേണുകൾ, കോഡ് ഉദാഹരണങ്ങളോടുകൂടി.
  - **പുരോഗമിച്ച സുരക്ഷയിലേക്ക് സംവൃതം**: ലളിതമായ അംഗീകാരത്തിൽ ആരംഭിച്ച് OAuth 2.1, RBAC എന്നിവയിലേക്കും പുരോഗതിക്കുള്ള മാർഗ്ഗനിർദ്ദേശങ്ങളും, മുൻനിര സുരക്ഷാ മോഡ്യൂളുകൾക്കുള്ള റഫറൻസുകളും.

ഈ ചേർത്തലുകൾ കൂടുതൽ ഉറപ്പുള്ള, സുരക്ഷിതവും ലളിതവുമായ MCP സർവർ നടപ്പിലാക്കലുകൾ നിർമ്മിക്കാൻ പ്രായോഗികമായി കൈ കൊണ്ടുള്ള മാർഗ്ഗനിർദ്ദേശങ്ങൾ നൽകുന്നു; അടിസ്ഥാന ആശയങ്ങളെ മുൻനിര പ്രൊഡക്ഷൻ മാതൃകകളുമായി ബന്ധപ്പെടുത്തുന്നു.

#### കേന്ദ്ര ആശയങ്ങൾ (01-CoreConcepts/) - പൂർണ്ണ നവീകരണം
- **പ്രോട്ടോക്കോൾ പതിപ്പ് അപ്ഡേറ്റ്**: MCP സ്പെസിഫിക്കേഷൻ 2025-06-18-നുള്ള വ്യാകരണ തീയതി അടിസ്ഥാനത്തിലുള്ള പതിപ്പായി പുതുക്കൽ (YYYY-MM-DD ഫോർമാറ്റ്)
- **ആർക്കിടെക്ചർ പരിഷ്കരണം**: ഹോസ്റ്റുകൾ, ക്ലയന്റുകളും, സെർവറുകളും ഇപ്പോഴത്തെ MCP ആർക്കിടെക്ചർ മാതൃക പ്രതിഫലിപ്പിക്കുന്ന വിധം മെച്ചപ്പെടുത്തി
  - ഹോസ്റ്റുകൾ എഐ ആപ്ലിക്കേഷനുകൾ ആയി വ്യക്തമാക്കിയിരിക്കുന്നത്, ഒട്ടേറെ MCP ക്ലയന്റ് കണക്ഷനുകൾ ഏകോപിപ്പിക്കുന്നത്
  - ക്ലയൻറുകൾ പ്രോട്ടോക്കോൾ കണക്ടറുകളായി, ഒറ്റയ്ക്ക് ഒറ്റ സെർവറുമായി ബന്ധം സൂക്ഷിക്കുന്നതുപോലെ വിവരണപ്പെടുത്തിയിരിക്കുന്നു
  - സെർവറുകൾ ലൊക്കൽ vs. റിമോട്ട് ഘടനാപരമായ സാഹചര്യങ്ങളിൽ മെച്ചപ്പെടുത്തി
- **പ്രിമിറ്റിവ് പുനസംഘടനം**: സെർവർ, ക്ലയന്റ് പ്രിമിറ്റീവ് ഘടകങ്ങളുടെ പൂർണ നവീകരണം
  - സെർവർ പ്രിമിറ്റീവുകൾ: റിസോഴ്സുകൾ (ഡാറ്റാ സ്രോതസ്), പ്രോംപ്റ്റുകൾ (ടെംപ്ലേറ്റുകൾ), ടൂളുകൾ (പ്രമാണിക്കാവുന്ന ഫംഗ്ഷനുകൾ) വിശദീകരണങ്ങൾ ഉൾപ്പെടെ
  - ക്ലയന്റ് പ്രിമിറ്റീവുകൾ: സാമ്പ്ലിംഗ് (LLM പൂർത്തീകരണങ്ങൾ), സാന്ദർഭനിർമിതി (ഉപയോക്തൃ ഇൻപുട്ട്), ലോഗിംഗ് (ഡീബഗ്/നിരീക്ഷണം)
  - നിലവിലെ കണ്ടെത്തൽ (`*/list`), പ്രാപ്തി (`*/get`), പ്രവർത്തനരീതി (`*/call`) മാതൃകകൾ പുതുക്കൽ
- **പ്രോട്ടോക്കോൾ ആർക്കിടെക്ചർ**: രണ്ടിരു-ലെയർ ആർക്കിടെക്ചർ മോഡൽ പരിചയപ്പെടുത്തി
  - ഡാറ്റ ലെയർ: JSON-RPC 2.0 അടിസ്ഥാനത്തോടെ ജീവിതചക്ര മാനേജ്‌മെന്റ് & പ്രിമിറ്റീവ് ഘടകങ്ങൾ
  - ട്രാൻസ്പോർട്ട് ലെയർ: STDIO (ലൊക്കൽ) & Streamable HTTP SSE (റിമോട്ട്) ട്രാൻസ്പോർട്ട് ഭാഗമായി
- **സുരക്ഷാ ഘടകം**: വ്യക്തമായ ഉപയോക്തൃ സമ്മതം, ഡാറ്റാ പ്രൈവസി സംരക്ഷണം, ടൂൾ പ്രവർത്തന സുരക്ഷ, ട്രാൻസ്പോർട്ട് ലെയർ സുരക്ഷ എന്നിവ ഉൾപ്പെട്ട സമഗ്ര സുരക്ഷാ തത്വങ്ങൾ
- **സംവേദന മാതൃകകൾ**: ഇൻഷിയലൈസേഷൻ, കണ്ടെത്തൽ, പ്രവർത്തനവും അറിയിപ്പുമുള്ള പ്രോട്ടോക്കോൾ സന്ദേശങ്ങൾ പുതുക്കി
- **കോഡ് ഉദാഹരണങ്ങൾ**: .NET, Java, Python, JavaScript മുതലായവയിൽ MCP SDK സമകാലീന മാതൃകകൾ പ്രതിഫലിപ്പിക്കുന്നവ പുതുക്കുന്നു
