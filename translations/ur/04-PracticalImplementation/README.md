# عملی نفاذ

[![حقیقی آلات اور ورک فلو کے ساتھ MCP ایپس بنانے، ٹیسٹ کرنے اور تعینات کرنے کا طریقہ](../../../translated_images/ur/05.64bea204e25ca891.webp)](https://youtu.be/vCN9-mKBDfQ)

_(اس سبق کی ویڈیو دیکھنے کے لیے اوپر والے تصویر پر کلک کریں)_

عملی نفاذ وہ جگہ ہے جہاں ماڈل کانٹیکسٹ پروٹوکول (MCP) کی طاقت محسوس کی جاتی ہے۔ اگرچہ MCP کے نظریہ اور فن تعمیر کو سمجھنا اہم ہے، حقیقی قدر اس وقت سامنے آتی ہے جب آپ ان تصورات کو استعمال کرتے ہوئے حقیقی دنیا کے مسائل حل کرنے کے لیے حل تیار کرتے، ٹیسٹ کرتے اور تعینات کرتے ہیں۔ یہ باب آپ کو تصوراتی علم اور عملی ترقی کے درمیان پل فراہم کرتا ہے، اور آپ کو MCP پر مبنی ایپلیکیشنز کو زندگی میں لانے کے عمل سے گزارتا ہے۔

چاہے آپ ذہین اسسٹنٹس تیار کر رہے ہوں، کاروباری ورک فلو میں AI کو شامل کر رہے ہوں، یا ڈیٹا پروسیسنگ کے لیے حسب ضرورت آلات بنا رہے ہوں، MCP ایک لچکدار بنیاد فراہم کرتا ہے۔ اس کا زبانوں سے آزاد ڈیزائن اور مقبول پروگرامنگ زبانوں کے لیے سرکاری SDKs اسے وسیع پیمانے پر ڈویلپرز کے لیے قابل رسائی بناتے ہیں۔ ان SDKs کا فائدہ اٹھا کر، آپ اپنے حلوں کی تیز پروٹوٹائپنگ، تکرار، اور مختلف پلیٹ فارمز اور ماحول میں پیمانہ بندی کر سکتے ہیں۔

اگلے حصوں میں، آپ کو عملی مثالیں، نمونہ کوڈ، اور تعیناتی کی حکمت عملی ملیں گی جو دکھاتی ہیں کہ C#، جاوا ود اسپرنگ، ٹائپ اسکرپٹ، جاوا اسکرپٹ، اور پائیتھن میں MCP کو کیسے نافذ کیا جائے۔ آپ یہ بھی سیکھیں گے کہ اپنے MCP سرورز کو کیسے ڈیبگ اور ٹیسٹ کریں، APIs کا انتظام کریں، اور Azure کے ذریعے کلاؤڈ میں حل تعینات کریں۔ یہ عملی وسائل آپ کی سیکھنے کی رفتار تیز کرنے اور آپ کو مضبوط اور پیداواری طور پر تیار MCP ایپلیکیشنز بنانے میں اعتماد دینے کے لیے ڈیزائن کیے گئے ہیں۔

## جائزہ

یہ سبق MCP نفاذ کے عملی پہلوؤں پر توجہ دیتا ہے جو متعدد پروگرامنگ زبانوں میں محیط ہیں۔ ہم دیکھیں گے کہ C#، جاوا ود اسپرنگ، ٹائپ اسکرپٹ، جاوا اسکرپٹ، اور پائیتھن میں MCP SDKs کا استعمال کرکے مضبوط ایپلیکیشنز کیسے بنائیں، MCP سرورز کو ڈیبگ اور ٹیسٹ کریں، اور قابل استعمال وسائل، پرامپٹس، اور آلات تیار کریں۔

## سیکھنے کے مقاصد

اس سبق کے اختتام تک، آپ قابل ہوں گے:

- مختلف پروگرامنگ زبانوں میں سرکاری SDKs استعمال کرتے ہوئے MCP حل نافذ کریں
- MCP سرورز کو منظم طریقے سے ڈیبگ اور ٹیسٹ کریں
- سرور خصوصیات (وسائل، پرامپٹس، اور آلات) بنائیں اور استعمال کریں
- پیچیدہ کاموں کے لیے مؤثر MCP ورک فلو ڈیزائن کریں
- کارکردگی اور اعتماد کے لیے MCP نفاذ کو بہتر بنائیں

## نمونہ نفاذ: C# نفاذ

آفیشل C# SDK مخزن میں کئی نمونہ نفاذ شامل ہیں جو MCP کے مختلف پہلوؤں کو ظاہر کرتے ہیں:

- **بنیادی MCP کلائنٹ**: ایک سادہ مثال جو دکھاتی ہے کہ کیسے MCP کلائنٹ بنایا جائے اور اوزار کال کیے جائیں
- **بنیادی MCP سرور**: بنیادی اوزار رجسٹریشن کے ساتھ ایک کم از کم سرور نفاذ
- **متقدم MCP سرور**: مکمل فیچرڈ سرور جس میں اوزار رجسٹریشن، توثیق، اور خرابی کا نظم شامل ہیں
- **ASP.NET انٹیگریشن**: ASP.NET کور کے ساتھ انٹیگریشن ظاہر کرنے والی مثالیں
- **آلے کے نفاذ کے نمونے**: مختلف پیچیدگی کی سطح کے ساتھ اوزار نافذ کرنے کے مختلف نمونے

MCP C# SDK پیش نظارہ میں ہے اور APIs میں تبدیلیاں آ سکتی ہیں۔ جیسے جیسے SDK ترقی کرے گی ہم اس بلاگ کو مسلسل اپ ڈیٹ کریں گے۔

## ریموٹ MCP سرور کو Azure پر تعینات کریں

آئیے دیکھتے ہیں کہ کیا ہم پہلے ذکر کیے گئے نمونے کو تعینات کر سکتے ہیں:

1. ریپو کو کلون کریں

    ```bash
    git clone https://github.com/Azure-Samples/remote-mcp-apim-functions-python.git
    cd remote-mcp-apim-functions-python
    ```

1. `Microsoft.App` ریسورس پرووائیڈر کو رجسٹر کریں۔

- اگر آپ Azure CLI استعمال کر رہے ہیں تو `az provider register --namespace Microsoft.App --wait` چلائیں۔
- اگر آپ Azure PowerShell استعمال کر رہے ہیں تو `Register-AzResourceProvider -ProviderNamespace Microsoft.App` چلائیں۔ پھر کچھ دیر بعد `(Get-AzResourceProvider -ProviderNamespace Microsoft.App).RegistrationState` چلا کر چیک کریں کہ رجسٹریشن مکمل ہو گئی ہے یا نہیں۔

1. یہ [azd](https://aka.ms/azd) کمانڈ چلائیں تاکہ api مینجمنٹ سروس، فنکشن ایپ (کوڈ کے ساتھ) اور دیگر تمام مطلوبہ Azure وسائل کو پروویژن کیا جا سکے

    ```shell
    azd up
    ```

یہ کمانڈز Azure پر تمام کلاؤڈ وسائل کو تعینات کرنا چاہئیں۔

### MCP انسپیکٹر کے ساتھ اپنے سرور کی جانچ کریں

1. **نئی ٹرمینل ونڈو** میں MCP انسپیکٹر انسٹال کریں اور چلائیں

    ```shell
    npx @modelcontextprotocol/inspector
    ```

آپ کو ایک ایسا انٹرفیس نظر آنا چاہئے:

![Connect to Node inspector](../../../translated_images/ur/connect.141db0b2bd05f096.webp)

1. CTRL کلک کرکے انسپیکٹر ویب ایپ کو اس یو آر ایل سے لوڈ کریں جو ایپ نے ظاہر کیا ہے (مثلاً [http://127.0.0.1:6274/#resources](http://127.0.0.1:6274/#resources))
1. ٹرانسپورٹ کی قسم `SSE` سیٹ کریں
1. یو آر ایل اپنے چل رہے API مینجمنٹ SSE اینڈ پوائنٹ کی سیٹ کریں جو `azd up` کے بعد ظاہر ہوتا ہے اور **Connect** کریں:

    ```shell
    https://<apim-servicename-from-azd-output>.azure-api.net/mcp/sse
    ```

1. **List Tools**۔ کسی ٹول پر کلک کریں اور **Run Tool** کریں۔

اگر تمام مراحل کامیاب ہوئے ہیں تو آپ اب MCP سرور سے جُڑ چکے ہیں اور آپ نے ایک ٹول کال کر کے اسے چلایا ہے۔

## Azure کے لیے MCP سرورز

[Remote-mcp-functions](https://github.com/Azure-Samples/remote-mcp-functions-dotnet): یہ ریپوزٹریز کا سیٹ Azure Functions کے ساتھ Python، C# .NET یا Node/TypeScript استعمال کرتے ہوئے کسٹم ریموٹ MCP (Model Context Protocol) سرورز بنانے اور تعینات کرنے کے لیے کوئیک اسٹارٹ ٹیمپلیٹ ہیں۔

نمونے ایک مکمل حل فراہم کرتے ہیں جو ڈویلپرز کو اجازت دیتا ہے کہ وہ:

- مقامی طور پر بنائیں اور چلائیں: کسی لوکل مشین پر MCP سرور کو تیار اور ڈیبگ کریں
- Azure پر تعینات کریں: آسانی سے آسمان پر سادہ azd up کمانڈ کے ساتھ تعینات کریں
- کلائنٹس سے جڑیں: مختلف کلائنٹس سے، بشمول VS کوڈ کے کوپائلٹ ایجنٹ موڈ اور MCP انسپیکٹر ٹول، MCP سرور سے جڑیں

### کلیدی خصوصیات

- ڈیزائن کے لحاظ سے سیکیورٹی: MCP سرور کو کیز اور HTTPS کے ذریعے محفوظ کیا گیا ہے
- توثیق کے اختیارات: بلٹ ان آتھ اور/یا API مینجمنٹ کا استعمال کرتے ہوئے OAuth کی حمایت کرتا ہے
- نیٹ ورک علیحدگی: Azure Virtual Networks (VNET) کا استعمال کرتے ہوئے نیٹ ورک علیحدگی کی اجازت دیتا ہے
- سرور لیس آرکیٹیکچر: مقیاس پذیر، ایونٹ ڈرائیون عمل کے لیے Azure فنکشنز کا سہارا لیتا ہے
- مقامی ترقی: جامع مقامی ترقی اور ڈیبگنگ کی معاونت
- آسان تعیناتی: Azure پر تعیناتی کا آسان عمل

ریپوزٹری میں تمام ضروری کنفیگریشن فائلز، ماخذ کوڈ، اور بنیادی ڈھانچے کی تعریفیں شامل ہیں تاکہ تیزی سے پروڈکشن کے لیے تیار MCP سرور کی تعمیل شروع کی جا سکے۔

- [Azure Remote MCP Functions Python](https://github.com/Azure-Samples/remote-mcp-functions-python) - Python کے ساتھ Azure Functions استعمال کرتے ہوئے MCP کی نمونہ عمل درآمد

- [Azure Remote MCP Functions .NET](https://github.com/Azure-Samples/remote-mcp-functions-dotnet) - C# .NET کے ساتھ Azure Functions استعمال کرتے ہوئے MCP کی نمونہ عمل درآمد

- [Azure Remote MCP Functions Node/Typescript](https://github.com/Azure-Samples/remote-mcp-functions-typescript) - Node/TypeScript کے ساتھ Azure Functions استعمال کرتے ہوئے MCP کی نمونہ عمل درآمد۔

## اہم نکات

- MCP SDKs زبان-مخصوص ٹولز فراہم کرتے ہیں جو مضبوط MCP حل نافذ کرنے میں معاون ہیں
- ڈیبگنگ اور جانچ کا عمل معتبر MCP ایپلیکیشنز کے لیے انتہائی اہم ہے
- دہرائے جانے والے پرامپٹ ٹیمپلیٹس مستقل AI تعاملات کو ممکن بناتے ہیں
- اچھی ڈیزائن کی ہوئی ورک فلو مختلف ٹولز کے استعمال سے پیچیدہ کاموں کو ترتیب دے سکتی ہے
- MCP حل نافذ کرنے میں سیکیورٹی، کارکردگی، اور غلطی کی ہینڈلنگ پر غور کرنا ضروری ہے

## مشق

ایک عملی MCP ورک فلو ڈیزائن کریں جو آپ کے میدان کا ایک حقیقی مسئلہ حل کرے:

1. 3-4 ایسے ٹولز کی نشاندہی کریں جو اس مسئلے کو حل کرنے میں مددگار ہوں
2. ایک ورک فلو ڈایاگرام بنائیں جو دکھائے کہ یہ ٹولز کس طرح تعامل کرتے ہیں
3. اپنی پسندیدہ زبان استعمال کرتے ہوئے ان میں سے ایک ٹول کا بنیادی ورژن نافذ کریں
4. ایک پرامپٹ ٹیمپلیٹ بنائیں جو ماڈل کو آپ کے ٹول کو مؤثر طریقے سے استعمال کرنے میں مدد دے
