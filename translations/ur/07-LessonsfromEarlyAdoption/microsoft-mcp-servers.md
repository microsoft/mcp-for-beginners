# 🚀 10 مائیکروسافٹ MCP سرورز جو ڈویلپر کی پیداوری کو بدل رہے ہیں

## 🎯 اس گائیڈ میں آپ کیا سیکھیں گے

یہ عملی گائیڈ دس مائیکروسافٹ MCP سرورز کو ظاہر کرتی ہے جو فعال طور پر یہ تبدیل کر رہے ہیں کہ ڈویلپرز AI اسسٹنٹس کے ساتھ کیسے کام کرتے ہیں۔ صرف یہ بیان کرنے کے بجائے کہ MCP سرورز *کیا* کر سکتے ہیں، ہم آپ کو وہ سرورز دکھائیں گے جو پہلے ہی مائیکروسافٹ اور اس سے آگے روزمرہ کے ترقیاتی ورک فلو میں حقیقی فرق لا رہے ہیں۔

اس گائیڈ میں شامل ہر سرور کو حقیقی دنیا کے استعمال اور ڈویلپر کی رائے کی بنیاد پر منتخب کیا گیا ہے۔ آپ نہ صرف جانیں گے کہ ہر سرور کیا کرتا ہے بلکہ یہ بھی کہ یہ کیوں اہم ہے اور اسے اپنے منصوبوں میں زیادہ سے زیادہ کیسے فائدہ اٹھائیں۔ چاہے آپ MCP میں بالکل نئے ہوں یا اپنی موجودہ سیٹ اپ کو وسیع کرنا چاہتے ہوں، یہ سرورز مائیکروسافٹ کے ماحولیاتی نظام میں دستیاب سب سے عملی اور موثر اوزار کی نمائندگی کرتے ہیں۔

> **💡 فوری آغاز کا مشورہ**
> 
> MCP میں نئے ہیں؟ پریشان نہ ہوں! یہ گائیڈ شروع کرنے والوں کے لیے آسان بنا ہے۔ ہم مفاہیم کو سمجھاتے جائیں گے، اور آپ ہمیشہ ہمارے [MCP کا تعارف](../00-Introduction/README.md) اور [بنیادی تصورات](../01-CoreConcepts/README.md) ماڈیولز کو گہرے پس منظر کے لیے دیکھ سکتے ہیں۔

## جائزہ

یہ جامع گائیڈ دس مائیکروسافٹ MCP سرورز کو بیان کرتی ہے جو ڈویلپرز اور AI اسسٹنٹس کے ساتھ تعاون کے طریقے کو انقلاب لا رہے ہیں۔ Azure کے وسائل کی مینجمنٹ سے لے کر دستاویزات کی پروسیسنگ تک، یہ سرورز Model Context Protocol کی طاقت کو ظاہر کرتے ہیں جو ایک مربوط، پیداواری ترقیاتی ورک فلو پیدا کرتا ہے۔

## سیکھنے کے مقاصد

اس گائیڈ کے اختتام تک، آپ:
- سمجھ جائیں گے کہ MCP سرورز ڈویلپر کی پیداوری کو کیسے بڑھاتے ہیں
- مائیکروسافٹ کے سب سے مؤثر MCP سرور نفاذ کے بارے میں جانیں گے
- ہر سرور کے عملی استعمالات دریافت کریں گے
- VS Code اور Visual Studio میں ان سرورز کو سیٹ اپ اور کنفیگر کرنا سیکھیں گے
- MCP کے وسیع تر ماحولیاتی نظام اور مستقبل کے رجحانات کو دریافت کریں گے

## 🔧 MCP سرورز کو سمجھنا: ابتدائیوں کے لیے گائیڈ

### MCP سرورز کیا ہیں؟

Model Context Protocol (MCP) میں ایک نئے کے طور پر، آپ سوچ سکتے ہیں: "MCP سرور کیا ہے، اور مجھے اس کی پرواہ کیوں کرنی چاہیے؟" آئیے ایک آسان مماثلت سے شروع کرتے ہیں۔

MCP سرورز کو خاص معاونین سمجھیں جو آپ کے AI کوڈنگ ساتھی (جیسے GitHub Copilot) کو بیرونی اوزار اور خدمات سے جوڑنے میں مدد دیتے ہیں۔ جیسے آپ اپنے فون پر مختلف کاموں کے لیے مختلف ایپس استعمال کرتے ہیں — ایک موسم کے لیے، ایک نیویگیشن کے لیے، ایک بینکنگ کے لیے — MCP سرورز آپ کے AI اسسٹنٹ کو مختلف ترقیاتی اوزار اور خدمات سے رابطہ کرنے کی صلاحیت دیتے ہیں۔

### MCP سرورز جو مسئلہ حل کرتے ہیں

MCP سرورز سے پہلے، اگر آپ کو:
- اپنے Azure وسائل چیک کرنے تھے
- GitHub ایشو بنانا تھا
- اپنے ڈیٹا بیس سے سوال کرنا تھا
- دستاویزات میں تلاش کرنا تھا

تو آپ کو کوڈنگ روکنی پڑتی، براؤزر کھولنا پڑتا، متعلقہ ویب سائٹ پر جانا پڑتا، اور یہ کام دستی طور پر انجام دینے پڑتے۔ یہ مسلسل سیاق و سباق کی تبدیلی آپ کے ورک فلو کو توڑ دیتی اور پیداواری صلاحیت کم کرتی تھی۔

### MCP سرورز آپ کے ترقیاتی تجربے کو کیسے بدلتے ہیں

MCP سرورز کے ساتھ، آپ اپنے ترقیاتی ماحول (VS Code، Visual Studio، وغیرہ) میں رہ سکتے ہیں اور اپنے AI اسسٹنٹ سے یہ کام کرنے کو کہہ سکتے ہیں۔ مثال کے طور پر:

**روایتی ورک فلو کے بجائے:**
1. کوڈنگ روکیں
2. براؤزر کھولیں
3. Azure پورٹل پر جائیں
4. اسٹوریج اکاؤنٹ کی تفصیلات دیکھیں
5. VS Code پر واپس آئیں
6. کوڈنگ دوبارہ شروع کریں

**آپ اب یہ کر سکتے ہیں:**
1. AI سے پوچھیں: "میرے Azure اسٹوریج اکاؤنٹس کی صورتحال کیا ہے؟"
2. دی گئی معلومات کے ساتھ کوڈنگ جاری رکھیں

### ابتدائیوں کے لیے اہم فوائد

#### 1. 🔄 **اپنے فلو اسٹیٹ میں رہیں**
- متعدد ایپس کے درمیان سوئچ کرنا بند کریں
- اس کوڈ پر توجہ مرکوز رکھیں جو آپ لکھ رہے ہیں
- مختلف اوزار کو مینج کرنے کا ذہنی بوجھ کم کریں

#### 2. 🤖 **پیچیدہ کمانڈز کے بجائے قدرتی زبان استعمال کریں**
- SQL نحو کو یاد رکھنے کی بجائے بتائیں کہ آپ کو کون سا ڈیٹا چاہیے
- Azure CLI کمانڈز یاد رکھنے کے بجائے وضاحت کریں کہ آپ کیا حاصل کرنا چاہتے ہیں
- AI سے تکنیکی تفصیلات سنبھالنے دیں جبکہ آپ منطق پر توجہ دیں

#### 3. 🔗 **متعدد اوزار ایک ساتھ جوڑیں**
- مختلف خدمات کو ملا کر طاقتور ورک فلو بنائیں
- مثال: "تازہ ترین GitHub ایشوز لیں اور ان کے مطابق Azure DevOps ورک آئٹمز بنائیں"
- پیچیدہ اسکرپٹس لکھے بغیر آٹومیشن بنائیں

#### 4. 🌐 **بڑھتا ہوا ماحولیاتی نظام تک رسائی**
- مائیکروسافٹ، GitHub، اور دیگر کمپنیوں کی جانب سے بنائے گئے سرورز سے فائدہ اٹھائیں
- مختلف وینڈرز کے اوزار کو بلا رکاوٹ مکس اور میچ کریں
- ایک معیاری ماحولیاتی نظام میں شامل ہوں جو مختلف AI اسسٹنٹس پر کام کرتا ہے

#### 5. 🛠️ **عملی تجربے کے ذریعے سیکھیں**
- تصورات کو سمجھنے کے لیے پری بلٹ سرورز سے شروع کریں
- جیسے جیسے آرام دہ ہوں، اپنے سرورز خود تعمیر کریں
- دستیاب SDKs اور دستاویزات کا استعمال کر کے اپنی سیکھنے کی رہنمائی کریں

### ابتدائیوں کے لیے حقیقی دنیا کی مثال

فرض کریں آپ ویب ڈویلپمنٹ میں نئے ہیں اور اپنے پہلے پروجیکٹ پر کام کر رہے ہیں۔ MCP سرورز آپ کی مدد کیسے کر سکتے ہیں:

**روایتی طریقہ:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP سرورز کے ساتھ:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### انٹرپرائز معیار کا فائدہ

MCP صنعت میں ایک وسیع معیار بنتا جا رہا ہے، جس کا مطلب ہے:
- **اتساق**: مختلف اوزار اور کمپنیوں میں ایک جیسا تجربہ
- **تعلقات**: مختلف وینڈرز کے سرورز ایک ساتھ کام کرتے ہیں
- **مستقبل کی تیاری**: مہارتیں اور سیٹ اپ مختلف AI اسسٹنٹس میں منتقل ہو سکتے ہیں
- **کمیونٹی**: مشترکہ علم اور وسائل کا بڑا ماحولیاتی نظام

- عام ترقیاتی چیلنجز حل کرے
- دہرانے والے کاموں کو کم کرے
- کوڈ کے معیار کو بہتر بنائے
- سیکھنے کے مواقع میں اضافہ کرے

## VS Code اور Visual Studio میں MCP کے ساتھ شروع کرنا 🚀

اگر آپ Visual Studio Code یا Visual Studio 2022 کے ساتھ GitHub Copilot استعمال کر رہے ہیں تو ان MCP سرورز کی سیٹ اپ آسان ہے۔

### VS Code سیٹ اپ

VS Code کے لیے بنیادی عمل درج ذیل ہے:

1. **ایجنٹ موڈ فعال کریں**: VS Code میں Copilot Chat ونڈو میں ایجنٹ موڈ پر سوئچ کریں
2. **MCP سرورز کو ترتیب دیں**: اپنے VS Code کے settings.json فائل میں سرور کنفیگریشنز شامل کریں
3. **سرورز شروع کریں**: ہر اس سرور کے لیے "Start" بٹن پر کلک کریں جسے آپ استعمال کرنا چاہتے ہیں
4. **اوزار منتخب کریں**: اپنے موجودہ سیشن کے لیے MCP سرورز منتخب کریں

تفصیلی سیٹ اپ ہدایات کے لیے، [VS Code MCP دستاویزات](https://code.visualstudio.com/docs/copilot/copilot-mcp) دیکھیں۔

> **💡 پرو ٹپ: MCP سرورز کو پیشہ ور کی طرح منظم کریں!**
> 
> VS Code Extensions ویو اب [انسٹال شدہ MCP سرورز کو مینج کرنے کے لیے نیا UI](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode) شامل کرتی ہے! آپ کو ایک واضح، آسان انٹرفیس کے ذریعے کسی بھی انسٹالڈ MCP سرور کو شروع، بند، اور منظم کرنے کی جلد رسائی حاصل ہے۔ آزمائیں!

### Visual Studio 2022 سیٹ اپ

Visual Studio 2022 (ورژن 17.14 یا بعد) کے لیے:

1. **ایجنٹ موڈ فعال کریں**: GitHub Copilot Chat ونڈو میں "Ask" ڈراپ ڈاؤن پر کلک کریں اور "Agent" منتخب کریں
2. **کنفیگریشن فائل بنائیں**: اپنے حل کی ڈائریکٹری میں `.mcp.json` فائل بنائیں (تجویز کردہ مقام: `<SOLUTIONDIR>\.mcp.json`)
3. **سرورز ترتیب دیں**: اپنے MCP سرور کنفیگریشنز معیاری MCP فارمیٹ کا استعمال کرتے ہوئے شامل کریں
4. **اوزار کی منظوری**: جب کہا جائے، تو مناسب اسکوب اجازتوں کے ساتھ اوزار کو استعمال کی منظوری دیں

تفصیلی Visual Studio سیٹ اپ ہدایات کے لیے، [Visual Studio MCP دستاویزات](https://learn.microsoft.com/visualstudio/ide/mcp-servers) دیکھیں۔

ہر MCP سرور اپنی کنفیگریشن کی ضروریات کے ساتھ آتا ہے (کنکشن اسٹرنگز، آتھنٹیکیشن، وغیرہ)، لیکن دونوں IDEs میں سیٹ اپ کا نمونہ یکساں ہے۔

**حقیقی دنیا میں استعمال**: "Azure container app بنانے کے لیے az cli کمانڈز کیا ہیں سرکاری Microsoft Learn دستاویزات کے مطابق؟" یا "ASP.NET Core میں Entity Framework کی dependency injection کیسے کنفیگر کریں؟" یا "اس کوڈ کا جائزہ لیں کہ آیا یہ Microsoft Learn Documentation میں کارکردگی کی سفارشات سے میل کھاتا ہے۔" یہ سرور Microsoft Learn، Azure docs، اور Microsoft 365 دستاویزات کے وسیع احاطے کو جدید معنوی تلاش کے ذریعے سب سے زیادہ متعلقہ معلومات فراہم کرتا ہے۔ یہ 10 اعلی معیار کے مواد کے ٹکڑے، آرٹیکل کے عنوانات، اور URLs واپس کرتا ہے، ہمیشہ تازہ ترین مائیکروسافٹ دستاویزات تک رسائی رکھتے ہوئے جیسا کہ شائع کی جاتی ہیں۔

**نمونہ مثال**: یہ سرور `microsoft_docs_search` ٹول فراہم کرتا ہے جو Microsoft کی سرکاری تکنیکی دستاویزات کے خلاف معنوی تلاش کرتا ہے۔ ایک بار کنفیگر ہونے کے بعد، آپ ایسے سوالات پوچھ سکتے ہیں جیسے "ASP.NET Core میں JWT authentication کیسے نافذ کریں؟" اور تفصیلی، سرکاری جوابات لنکس سمیت حاصل کریں۔ تلاش کا معیار شاندار ہے کیونکہ یہ سیاق و سباق کو سمجھتا ہے – Azure کے سیاق میں "containers" کے بارے میں پوچھنے پر Azure Container Instances کی دستاویزات ملتی ہیں، جبکہ .NET کے سیاق میں یہی اصطلاح متعلقہ C# کلیکشن معلومات دیتی ہے۔

یہ خاص طور پر جلدی تبدیل ہونے والے یا حال ہی میں اپ ڈیٹ شدہ لائبریریز اور استعمال کے کیسز کے لیے مفید ہے۔ مثال کے طور پر، حالیہ کچھ کوڈنگ پروجیکٹس میں میں نے Aspire اور Microsoft.Extensions.AI کے تازہ ترین ورژنز کی خصوصیات کا فائدہ اٹھانا چاہا۔ Microsoft Learn Docs MCP سرور شامل کر کے، میں نے نہ صرف API دستاویزات بلکہ حال ہی میں شائع شدہ گائیڈ اور ویالکس کا فائدہ اٹھایا۔

### 2. ☁️ Azure MCP سرور


[![VS Code میں انسٹال کریں](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![VS Code Insiders میں انسٹال کریں](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**یہ کیا کرتا ہے**: Azure MCP سرور 15+ خصوصی Azure سروس کنیکٹرز کا جامع مجموعہ ہے جو پورے Azure ماحولیاتی نظام کو آپ کے AI ورک فلو میں لاتا ہے۔ یہ صرف ایک سرور نہیں ہے – یہ ایک طاقتور مجموعہ ہے جس میں وسائل کا انتظام، ڈیٹا بیس کنیکٹیویٹی (PostgreSQL، SQL Server)، Azure Monitor لاگ تجزیہ KQL کے ساتھ، Cosmos DB انٹیگریشن، اور بہت کچھ شامل ہے۔

**یہ کیوں مفید ہے**: صرف Azure وسائل کا انتظام کرنے سے بڑھ کر، یہ سرور Azure SDKs کے ساتھ کام کرتے ہوئے کوڈ کی کوالٹی کو نمایاں طور پر بہتر بناتا ہے۔ جب آپ Azure MCP کو ایجنٹ موڈ میں استعمال کرتے ہیں، تو یہ صرف کوڈ لکھنے میں مدد نہیں دیتا – یہ آپ کو *بہتر* Azure کوڈ لکھنے میں مدد دیتا ہے جو موجودہ توثیقی پیٹرن، خطا ہینڈلنگ کی بہترین مشقوں، اور تازہ ترین SDK فیچرز کا استعمال کرتا ہے۔ عام کوڈ حاصل کرنے کی بجائے جو کام کر سکتا ہے، آپ کو وہ کوڈ ملتا ہے جو Azure کی سفارش کردہ پیٹرن پر عمل کرتا ہے جو پروڈکشن ورک لوڈز کے لیے موزوں ہے۔

**کلیدی ماڈیولز میں شامل ہیں**:
- **🗄️ ڈیٹا بیس کنیکٹرز**: Azure Database for PostgreSQL اور SQL Server تک براہ راست نیچرل لینگویج رسائی
- **📊 Azure Monitor**: KQL سے چلنے والا لاگ تجزیہ اور آپریشنل ان سائٹس
- **🌐 وسائل کا انتظام**: مکمل Azure وسائل کا لائف سائیکل مینجمنٹ
- **🔐 توثیق**: DefaultAzureCredential اور منیجڈ آئیڈینٹی پیٹرنز
- **📦 اسٹوریج سروسز**: Blob Storage، Queue Storage، اور Table Storage آپریشنز
- **🚀 کنٹینر سروسز**: Azure Container Apps، Container Instances، اور AKS مینجمنٹ
- **اور بہت سے دیگر خصوصی کنیکٹرز**

**حقیقی دنیا میں استعمال**: "میرے Azure اسٹوریج اکاؤنٹس کی فہرست بنائیں"، "میرے لاگ اینالٹکس ورک اسپیس میں گزشتہ ایک گھنٹے کے دوران کی خرابیوں کے لیے سوال کریں"، یا "مجھ میں Node.js استعمال کرتے ہوئے ایک Azure ایپلیکیشن بنائیں جس میں درست توثیق ہو"

**مکمل ڈیمو منظرنامہ**: یہاں ایک مکمل واک تھرو ہے جو Azure MCP کو GitHub Copilot for Azure ایکسٹینشن کے ساتھ VS Code میں ملانے کی طاقت دکھاتا ہے۔ جب آپ دونوں انسٹال کرتے ہیں اور پرامٹ دیتے ہیں:

> "ایک Python اسکرپٹ بنائیں جو DefaultAzureCredential توثیق کے ساتھ Azure Blob Storage پر فائل اپ لوڈ کرے۔ اسکرپٹ کو میرے Azure اسٹوریج اکاؤنٹ 'mycompanystorage' سے کنیکٹ کرنا چاہئے، 'documents' نامی کنٹینر میں اپ لوڈ کرنا چاہئے، موجودہ ٹائم اسٹیمپ کے ساتھ ایک ٹیسٹ فائل بنانا چاہئے، خطاؤں کو مہذب انداز میں سنبھالنا چاہئے اور معلوماتی آؤٹ پٹ فراہم کرنا چاہئے، توثیق اور خطا ہینڈلنگ کے لیے Azure کی بہترین مشقوں پر عمل کرنا چاہئے، تبصرے شامل ہونے چاہئیں جو بتائیں کہ DefaultAzureCredential توثیق کیسے کام کرتی ہے، اور اسکرپٹ کو مناسب فنکشنز اور دستاویزات کے ساتھ اچھی طرح سے منظم کریں۔"

Azure MCP سرور ایک مکمل، پروڈکشن کے قابل Python اسکرپٹ تیار کرے گا جو کہ:
- جدید Azure Blob Storage SDK کو مکمل async پیٹرنز کے ساتھ استعمال کرتا ہے
- DefaultAzureCredential کو مکمل fallback چین وضاحت کے ساتھ نافذ کرتا ہے
- مخصوص Azure استثناء کی اقسام کے ساتھ مضبوط خطا ہینڈلنگ شامل کرتا ہے
- وسائل کے انتظام اور کنیکشن ہینڈلنگ کے لیے Azure SDK کی بہترین مشقوں پر عمل کرتا ہے
- تفصیلی لاگنگ اور معلوماتی کنسول آؤٹ پٹ فراہم کرتا ہے
- فنکشنز، دستاویزات، اور ٹائپ ہنٹس کے ساتھ مناسب طور پر منظم اسکرپٹ بناتا ہے

جو چیز اسے قابل ذکر بناتی ہے وہ یہ ہے کہ Azure MCP کے بغیر آپ کو عام blob storage کوڈ مل سکتا ہے جو کام کرتا ہے لیکن موجودہ Azure پیٹرنز کی پیروی نہیں کرتا۔ Azure MCP کے ساتھ، آپ کو ایسا کوڈ ملتا ہے جو جدید ترین توثیقی طریقے استعمال کرتا ہے، Azure مخصوص خطا کی صورتوں کو سنبھالتا ہے، اور Microsoft کی تجویز کردہ پروڈکشن ایپلی کیشنز کی مشقوں کی پیروی کرتا ہے۔

**نمایاں مثال**: میں `az` اور `azd` CLI کے مخصوص کمانڈز یاد رکھنے میں مشکل کا سامنا کرتا ہوں۔ میرے لیے ہمیشہ دو قدم کا عمل ہوتا ہے: پہلے سینٹیکس دیکھنا، پھر کمانڈ چلانا۔ میں اکثر پورٹل میں جا کر کام کر لیتا ہوں کیونکہ مجھے قبول نہیں کرنا کہ CLI سینٹیکس یاد نہیں۔ جو صرف بیان کر سکنا کہ آپ کیا چاہتے ہیں بہت حیرت انگیز ہے، اور یہ کہ یہ IDE چھوڑے بغیر کیا جا سکے تو اور بھی بہتر!

[Azure MCP repository](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) میں شروع کرنے کے لیے بہت سے استعمال کے کیسز کی عمدہ فہرست موجود ہے۔ مکمل سیٹ اپ گائیڈز اور جدید کنفیگریشن آپشنز کے لیے، [رسمی Azure MCP دستاویزات](https://learn.microsoft.com/azure/developer/azure-mcp-server/) دیکھیں۔

### 3. 🐙 GitHub MCP سرور

[![VS Code میں انسٹال کریں](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![VS Code Insiders میں انسٹال کریں](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**یہ کیا کرتا ہے**: سرکاری GitHub MCP سرور GitHub کے پورے ایکوسسٹم کے ساتھ بلا تعطل انضمام فراہم کرتا ہے، جس میں ہوسٹڈ ریموٹ رسائی اور مقامی Docker تعیناتی کے آپشنز شامل ہیں۔ یہ صرف بنیادی ریپوزیٹری آپریشنز کی بات نہیں – یہ ایک جامع ٹول کٹ ہے جس میں GitHub Actions مینجمنٹ، پول ریکویسٹ ورک فلو، ایشو ٹریکنگ، سیکیورٹی اسکیننگ، نوٹیفیکیشنز، اور جدید خودکاری صلاحیتیں شامل ہیں۔

**یہ کیوں مفید ہے**: یہ سرور آپ کو GitHub کے ساتھ بات چیت کا طریقہ بدل کر مکمل پلیٹ فارم تجربہ آپ کے ڈیولپمنٹ ماحول میں براہ راست لاتا ہے۔ VS Code اور GitHub.com کے درمیان بار بار سوئچ کرنے کی بجائے پروجیکٹ مینجمنٹ، کوڈ ریویوز، اور CI/CD مانیٹرنگ کے لیے، آپ قدرتی زبان کے کمانڈز کے ذریعے سب کچھ سنبھال سکتے ہیں اور اپنے کوڈ پر توجہ مرکوز رکھ سکتے ہیں۔

> **ℹ️ نوٹ: مختلف اقسام کے 'ایجنٹس'**
> 
> اس GitHub MCP سرور کو GitHub کے Coding Agent (وہ AI ایجنٹ جسے خودکار کوڈنگ کاموں کے لیے مسائل تفویض کیے جا سکتے ہیں) سے مت نہیں کریں۔ GitHub MCP سرور VS Code کے ایجنٹ موڈ میں کام کرتا ہے تاکہ GitHub API انضمام فراہم کرے، جبکہ GitHub کا Coding Agent ایک الگ فیچر ہے جو GitHub ایشوز پر تفویض کیے جانے پر پول ریکویسٹ بناتا ہے۔

**کلیدی صلاحیتیں شامل ہیں**:
- **⚙️ GitHub Actions**: مکمل CI/CD پائپ لائن مینجمنٹ، ورک فلو مانیٹرنگ، اور آرٹیفیکٹ ہینڈلنگ
- **🔀 پول ریکویسٹس**: پی آرز بنائیں، جائزہ لیں، ضم کریں، اور جامع اسٹیٹس ٹریکنگ کے ساتھ مینیج کریں
- **🐛 ایشوز**: مکمل ایشو لائف سائیکل مینجمنٹ، تبصرے، لیبلنگ، اور تفویض
- **🔒 سیکیورٹی**: کوڈ اسکیننگ الرٹس، سیکریٹ ڈیٹیکشن، اور Dependabot انٹیگریشن
- **🔔 نوٹیفیکیشنز**: سمارٹ نوٹیفیکیشن مینجمنٹ اور ریپوزیٹری سبسکرپشن کنٹرول
- **📁 ریپوزیٹری مینجمنٹ**: فائل آپریشنز، برانچ مینجمنٹ، اور ریپوزیٹری انتظامیہ
- **👥 تعاون**: صارف اور تنظیم کی تلاش، ٹیم مینجمنٹ، اور رسائی کنٹرول

### 5. 📝 MarkItDown MCP سرور


[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_MarkItDown_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_MarkItDown_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/markitdown)

**یہ کیا کرتا ہے**: MarkItDown ایک جامع دستاویز کنورژن سرور ہے جو مختلف فائل فارمیٹس کو اعلی معیار کے مارک ڈاؤن میں تبدیل کرتا ہے، جو LLM کے استعمال اور ٹیکسٹ تجزیہ کے لیے بہترین ہے۔

**یہ کیوں مفید ہے**: جدید دستاویزی ورک فلو کے لیے ضروری ہے! MarkItDown متعدد فائل فارمیٹس کو سنبھالتا ہے جبکہ اہم دستاویزی ڈھانچے جیسے سرخیاں، فہرستیں، جدولیں، اور روابط کو محفوظ رکھتا ہے۔ سادہ متن نکالنے والے اوزار کے برعکس، یہ معنوی مفہوم اور فارمیٹنگ کو برقرار رکھنے پر توجہ دیتا ہے جو AI پراسیسنگ اور انسانی پڑھائی دونوں کے لیے قیمتی ہے۔

**مدد یافتہ فائل فارمیٹس**:
- **آفس دستاویزات**: PDF، پاورپوائنٹ (PPTX)، ورڈ (DOCX)، ایکسل (XLSX/XLS)
- **میڈیا فائلز**: تصاویر (EXIF میٹا ڈیٹا اور OCR کے ساتھ)، آڈیو (EXIF میٹا ڈیٹا اور تقریر تحریر کے ساتھ)
- **ویب مواد**: HTML، RSS فیڈز، یوٹیوب URL، ویکیپیڈیا پیجز
- **ڈیٹا فارمیٹس**: CSV، JSON، XML، ZIP فائلز (مواد کو بار بار پراسیس کرتا ہے)
- **اشاعت فارمیٹس**: EPub، Jupyter نوٹ بکس (.ipynb)
- **ای میل**: آؤٹ لک پیغامات (.msg)
- **جدید**: بہتر PDF پراسیسنگ کے لیے Azure Document Intelligence انٹیگریشن

**جدید صلاحیتیں**: MarkItDown LLM سے چلنے والی تصویری وضاحتوں کی حمایت کرتا ہے (جب OpenAI کلائنٹ مہیا کیا جائے)، بہتر PDF پراسیسنگ کے لیے Azure Document Intelligence، تقریر مواد کے لیے آڈیو تحریر، اور اضافی فائل فارمیٹس کے لیے پلگ ان سسٹم فراہم کرتا ہے۔

**حقیقی دنیا میں استعمال**: "اس پاورپوائنٹ پریزنٹیشن کو مارک ڈاؤن میں تبدیل کریں ہماری دستاویزی سائٹ کے لیے"، "اس PDF سے متن نکالیں صحیح سرخی ڈھانچے کے ساتھ"، یا "اس ایکسل اسپریڈشیٹ کو ایک قابل پڑھائی جدول میں تبدیل کریں"

**نمونہ مثال**: [MarkItDown دستاویزات](https://github.com/microsoft/markitdown#why-markdown) کے اقتباس کے طور پر:

> مارک ڈاؤن بالکل سادہ متن کے بہت قریب ہے، جس میں کم سے کم مارک اپ یا فارمیٹنگ ہوتی ہے، لیکن پھر بھی اہم دستاویزی ڈھانچے کی نمائندگی کا طریقہ فراہم کرتا ہے۔ مرکزی دھارے کے LLMs، جیسے OpenAI کا GPT-4o، قدرتی طور پر "مارک ڈاؤن بولتے ہیں"، اور اکثر بغیر پوچھے اپنے جوابات میں مارک ڈاؤن شامل کرتے ہیں۔ اس سے ظاہر ہوتا ہے کہ انہیں وسیع مقدار میں مارک ڈاؤن فارمیٹ شدہ متن پر تربیت دی گئی ہے اور وہ اسے اچھی طرح سمجھتے ہیں۔ ایک ضمنی فائدے کے طور پر، مارک ڈاؤن کنونشنز انتہائی ٹوکن-مؤثر بھی ہیں۔

MarkItDown دستاویزی ڈھانچہ برقرار رکھنے میں واقعی اچھا ہے، جو AI ورک فلو کے لیے اہم ہے۔ مثلاً، جب پاورپوائنٹ پریزنٹیشن کو تبدیل کیا جائے، تو یہ سلائیڈ تنظیم کو درست سرخیوں کے ساتھ برقرار رکھتا ہے، جدولوں کو مارک ڈاؤن جدولوں کے طور پر نکالتا ہے، تصویروں کے لیے آلٹ ٹیکسٹ شامل کرتا ہے، اور یہاں تک کہ اسپیکر نوٹس کو بھی پروسیس کرتا ہے۔ چارٹس کو قابل پڑھائی ڈیٹا جدولوں میں تبدیل کیا جاتا ہے، اور نتیجے میں مارک ڈاؤن اصل پریزنٹیشن کی منطقی روانی کو برقرار رکھتا ہے۔ یہ AI سسٹمز میں پریزنٹیشن مواد داخل کرنے یا موجودہ سلائیڈز سے دستاویزات بنانے کے لیے بہترین بناتا ہے۔

**نمونہ مثال**: میں نے بلڈ میں M365 ایجنٹس کے بارے میں بات کرنے کے بعد اپنے دوست جان میلر سے رابطہ کیا، اور اس نے اس MCP کی سفارش کی۔ یہ M365 ایجنٹس میں نئے ڈویلپرز کے لیے بہترین ہو سکتا ہے کیونکہ یہ ٹیمپلیٹس، سیمپل کوڈ، اور سکیفولڈنگ فراہم کرتا ہے تاکہ وہ بغیر دستاویزات کی مشکل میں پڑے آغاز کر سکیں۔ سکیمہ کی توثیق کی خصوصیات خاص طور پر مفید لگ رہی ہیں جو مینیفیسٹ ساخت کی غلطیوں سے بچنے میں مدد دیتی ہیں جو گھنٹوں کی ڈیبگنگ کا باعث بن سکتی ہیں۔

> **💡 پرو ٹِپ**
> 
> مکمل M365 ترقی کی معاونت کے لیے اس سرور کو Microsoft Learn Docs MCP سرور کے ساتھ استعمال کریں – ایک سرکاری دستاویزات فراہم کرتا ہے جبکہ یہ عملی ترقیاتی ٹولز اور خرابیوں کے حل کی مدد دیتا ہے۔


## آگے کیا ہے؟ 🔮

## 📋 نتیجہ

ماڈل کانٹیکسٹ پروٹوکول (MCP) ڈویلپرز کے AI اسسٹنٹس اور بیرونی ٹولز کے ساتھ تعامل کے طریقے کو تبدیل کر رہا ہے۔ یہ 10 مائیکروسافٹ MCP سرورز معیاری AI انٹیگریشن کی طاقت کو ظاہر کرتے ہیں، جو ایسے بے جوڑ ورک فلو کو ممکن بناتے ہیں جو ڈویلپرز کو ان کے فلو کی حالت میں رکھتے ہوئے طاقتور بیرونی صلاحیتوں تک رسائی فراہم کرتے ہیں۔

جامع Azure ایکو سسٹم انٹیگریشن سے لے کر براؤزر آٹومیشن کے لیے Playwright اور دستاویزات کی پروسیسنگ کے لیے MarkItDown جیسے مخصوص ٹولز تک، یہ سرورز دکھاتے ہیں کہ MCP کس طرح مختلف ترقیاتی منظرناموں میں پیداواری صلاحیت کو بڑھا سکتا ہے۔ معیاری پروٹوکول یقینی بناتا ہے کہ یہ ٹولز بخوبی کام کریں، ایک مربوط ترقیاتی تجربہ فراہم کریں۔

جیسے جیسے MCP ایکو سسٹم ترقی کرتا رہے گا، کمیونٹی کے ساتھ فعال رابطہ، نئے سرورز کی تلاش، اور حسب ضرورت حل بنانے سے آپ کی ترقیاتی پیداواری صلاحیت زیادہ سے زیادہ ہوگی۔ MCP کی کھلی معیاری نوعیت کا مطلب ہے کہ آپ مختلف فروشندوں کے ٹولز کو ملا کر اپنے مخصوص ضروریات کے لیے بہترین ورک فلو بنا سکتے ہیں۔
