# 🚀 MCP ٹولنگ

## 🧠 MCP ڈیٹابیس انٹیگریشن لرننگ پاتھ کا جائزہ

یہاں آپ سیکھیں گے کہ MCP استعمال کرنے والے اوزار کیسے کام کرتے ہیں۔ جب آپ MCP سرورز کو ان اوزار سے جوڑیں گے تو آپ کا تجربہ بہتر ہوگا۔

## 🔗 آفیشل MCP وسائل

- 📘 [MCP دستاویزات](https://modelcontextprotocol.io/) – تفصیلی ٹیوٹوریلز اور صارف گائیڈز
- 📜 [MCP وضاحت (2026-07-28)](https://modelcontextprotocol.io/specification/2026-07-28/) – پروٹوکول کی ساخت اور تکنیکی حوالہ جات
- 🧑‍💻 [MCP گٹ ہب ریپوزٹری](https://github.com/modelcontextprotocol) – اوپن سورس ایس ڈی کے، اوزار، اور کوڈ نمونے
- 🌐 [MCP کمیونٹی](https://github.com/orgs/modelcontextprotocol/discussions) – مباحثوں میں شامل ہوں اور کمیونٹی میں حصہ لیں
- 🔒 [OWASP MCP ٹاپ 10](https://microsoft.github.io/mcp-azure-security-guide/mcp/) – سیکیورٹی کی بہترین مشقیں اور خطرات کی تلافی
