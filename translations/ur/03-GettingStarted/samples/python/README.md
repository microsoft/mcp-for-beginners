# MCP کیلکولیٹر سرور (پائتھن)



پائتھن میں ایک سادہ ماڈل کانٹیکسٹ پروٹوکول (MCP) سرور کی تنفیذ جو بنیادی کیلکولیٹر کی فعالیت فراہم کرتا ہے۔


## تنصیب

درکار dependencies انسٹال کریں:

```bash
pip install -r requirements.txt
```

یا MCP پائتھن SDK براہ راست انسٹال کریں:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## استعمال

### سرور چلانا

سرور کو MCP کلائنٹس (جیسے Claude Desktop) کے ذریعے استعمال کرنے کے لیے ڈیزائن کیا گیا ہے۔ سرور شروع کرنے کے لیے:

```bash
python mcp_calculator_server.py
```

**نوٹ**: جب آپ اسے براہِ راست ٹرمینل میں چلائیں گے تو JSON-RPC کی تصدیقی خرابیوں کا سامنا ہوگا۔ یہ معمول کی بات ہے – سرور مناسب فارمیٹ کردہ MCP کلائنٹ پیغامات کا انتظار کر رہا ہوتا ہے۔

### فنکشنز کی جانچ

یہ جانچنے کے لیے کہ کیلکولیٹر فنکشنز درست کام کر رہے ہیں:

```bash
python test_calculator.py
```

## مسئلہ حل کرنا

### درآمد کی غلطیاں

اگر آپ کو `ModuleNotFoundError: No module named 'mcp'` نظر آئے تو MCP پائتھن SDK انسٹال کریں:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### براہِ راست چلانے پر JSON-RPC کی غلطیاں

سرور کو براہِ راست چلانے پر "Invalid JSON: EOF while parsing a value" جیسی غلطیاں متوقع ہیں۔ سرور کو MCP کلائنٹ کے پیغامات کی ضرورت ہوتی ہے، براہِ راست ٹرمینل ان پٹ کی نہیں۔
