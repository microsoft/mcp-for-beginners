# Visual Studio Code کے لیے AI Toolkit توسیع سے سرور کا استعمال کرنا

جب آپ ایک AI ایجنٹ بنا رہے ہوتے ہیں، تو یہ صرف ذہین جوابات پیدا کرنے کے بارے میں نہیں ہوتا؛ بلکہ اپنے ایجنٹ کو عمل کرنے کی صلاحیت دینا بھی اہم ہوتا ہے۔ یہی وہ جگہ ہے جہاں Model Context Protocol (MCP) آتا ہے۔ MCP ایجنٹس کو ایک مستقل طریقے سے بیرونی اوزاروں اور خدمات تک رسائی آسان بناتا ہے۔ اسے اس طرح سوچیں جیسے آپ اپنے ایجنٹ کو ایک ایسی ٹول باکس میں پلگ ان کر رہے ہوں جسے وہ *واقعی* استعمال کر سکتا ہے۔

فرض کریں کہ آپ اپنے ایجنٹ کو اپنے کیلکولیٹر MCP سرور سے جوڑتے ہیں۔ اچانک، آپ کا ایجنٹ صرف اس طرح کی پرامپٹ حاصل کر کے ریاضی کے عمل انجام دے سکتا ہے جیسے "47 ضرب 89 کیا ہے؟" — لاجک کو ہارڈکوڈ کرنے یا کسٹم APIs بنانے کی ضرورت نہیں۔

## جائزہ

یہ سبق بتاتا ہے کہ آپ کس طرح ایک کیلکولیٹر MCP سرور کو AI Toolkit کی مدد سے Visual Studio Code میں ایک ایجنٹ سے مربوط کر سکتے ہیں، تاکہ آپ کا ایجنٹ قدرتی زبان کے ذریعے جمع، تفریق، ضرب اور تقسیم جیسے ریاضیاتی عمل انجام دے سکے۔

AI Toolkit Visual Studio Code کے لیے ایک طاقتور توسیع ہے جو ایجنٹ کی ترقی کو آسان بناتا ہے۔ AI انجینئرز آسانی سے جنریٹیو AI ماڈلز کی ترقی اور جانچ کر کے مقامی یا کلاؤڈ میں AI ایپلیکیشنز بنا سکتے ہیں۔ یہ توسیع آج کل موجود زیادہ تر بڑے جنریٹیو ماڈلز کی حمایت کرتی ہے۔

*نوٹ*: AI Toolkit فی الحال Python اور TypeScript کی حمایت کرتی ہے۔

### -3- ایک MCP سرور بنائیں

اب جب آپ نے اپنے ایجنٹ کا سسٹم پرامپٹ متعین کر لیا ہے — جو اس کے رویے اور جوابات کو رہنمائی دیتا ہے — تو اب ایجنٹ کو عملی صلاحیتوں سے لیس کرنے کا وقت ہے۔ اس حصے میں، آپ ایک کیلکولیٹر MCP سرور بنائیں گے جس میں جمع، تفریق، ضرب اور تقسیم کرنے کے اوزار شامل ہوں گے۔ یہ سرور آپ کے ایجنٹ کو قدرتی زبان کی پرامپٹس کے جواب میں حقیقی وقت میں ریاضیاتی عمل انجام دینے کی اجازت دے گا۔

![Visual Studio Code کی AI Toolkit توسیع میں Calculator Agent انٹرفیس کے نیچے کے حصے کی اسکرین شاٹ۔ اس میں "Tools" اور "Structure output" کے توسیعی مینو دکھائے گئے ہیں، اور "Choose output format" کا ایک ڈراپ ڈاؤن مینو ہے جو "text" پر سیٹ ہے۔ دائیں جانب، ایک بٹن ہے جس پر "+ MCP Server" لکھا ہے جو Model Context Protocol سرور شامل کرنے کے لیے ہے۔ Tools کے سیکشن کے اوپر ایک تصویر آئیکون کا پلیس ہولڈر دکھایا گیا ہے۔](../../../../translated_images/ur/aitk-add-mcp-server.9742cfddfe808353.webp)

AI Toolkit میں آپ کے اپنے MCP سرور بنانے کو آسان بنانے کے لیے ٹیمپلیٹس فراہم کیے گئے ہیں۔ ہم کیلکولیٹر MCP سرور بنانے کے لیے Python ٹیمپلیٹ استعمال کریں گے۔

*نوٹ*: AI Toolkit فی الحال Python اور TypeScript کی حمایت کرتی ہے۔

1. **Agent (Prompt) Builder** کے **Tools** سیکشن میں، **+ MCP Server** بٹن پر کلک کریں۔ توسیع ایک سیٹ اپ وزرڈ **Command Palette** کے ذریعے لانچ کرے گی۔
1. **+ Add Server** منتخب کریں۔
1. **Create a New MCP Server** منتخب کریں۔
1. ٹیمپلیٹ کے طور پر **python-weather** منتخب کریں۔
1. MCP سرور ٹیمپلیٹ کو محفوظ کرنے کے لیے **Default folder** منتخب کریں۔
1. سرور کے لیے درج ذیل نام لکھیں: **Calculator**
1. ایک نیا Visual Studio Code ونڈو کھلے گی۔ **Yes, I trust the authors** منتخب کریں۔
1. ٹرمینل کا استعمال کرتے ہوئے (Terminal > New Terminal) ایک ورچوئل ماحول بنائیں: `python -m venv .venv`
1. ٹرمینل میں ورچوئل ماحول کو فعال کریں:
    1. Windows - `.venv\Scripts\activate`
    1. macOS/Linux - `source .venv/bin/activate`
1. ٹرمینل میں انحصارات انسٹال کریں: `pip install -e .[dev]`
1. **Explorer** ویو میں **src** ڈائریکٹری کو بڑھائیں اور **server.py** فائل کو ایڈیٹر میں کھولیں۔
1. **server.py** فائل کا کوڈ درج ذیل سے تبدیل کریں اور محفوظ کریں:

    ```python
    """
    Sample MCP Calculator Server implementation in Python.

    
    This module demonstrates how to create a simple MCP server with calculator tools
    that can perform basic arithmetic operations (add, subtract, multiply, divide).
    """
    
    from mcp.server.fastmcp import FastMCP
    
    server = FastMCP("calculator")
    
    @server.tool()
    def add(a: float, b: float) -> float:
        """Add two numbers together and return the result."""
        return a + b
    
    @server.tool()
    def subtract(a: float, b: float) -> float:
        """Subtract b from a and return the result."""
        return a - b
    
    @server.tool()
    def multiply(a: float, b: float) -> float:
        """Multiply two numbers together and return the result."""
        return a * b
    
    @server.tool()
    def divide(a: float, b: float) -> float:
        """
        Divide a by b and return the result.
        
        Raises:
            ValueError: If b is zero
        """
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    ```

### -4- کیلکولیٹر MCP سرور کے ساتھ ایجنٹ چلائیں

اب جب کہ آپ کے ایجنٹ کے پاس اوزار ہیں، انہیں استعمال کرنے کا وقت ہے! اس حصے میں، آپ ایجنٹ کو پرامپٹس بھیج کر یہ جانچیں گے کہ آیا ایجنٹ کیلکولیٹر MCP سرور کے مناسب اوزار استعمال کرتا ہے یا نہیں۔

![Visual Studio Code کی AI Toolkit توسیع میں Calculator Agent انٹرفیس کی اسکرین شاٹ۔ بائیں پینل میں، "Tools" کے تحت، ایک MCP سرور جس کا نام ہے local-server-calculator_server شامل کیا گیا ہے، چار دستیاب اوزار دکھا رہا ہے: add، subtract، multiply، اور divide۔ ایک بیج دکھا رہا ہے کہ چار اوزار فعال ہیں۔ نیچے ایک بند شدہ "Structure output" سیکشن اور نیلا "Run" بٹن ہے۔ دائیں پینل میں، "Model Response" کے تحت، ایجنٹ نے multiply اور subtract اوزار کو ان پٹس کے ساتھ کال کیا ہے {"a": 3, "b": 25} اور {"a": 75, "b": 20} بالترتیب۔ آخری "Tool Response" 75.0 کے طور پر دکھایا گیا ہے۔ نیچے "View Code" بٹن موجود ہے۔](../../../../translated_images/ur/aitk-agent-response-with-tools.e7c781869dc8041a.webp)

آپ اپنے لوکل ڈیولپمنٹ مشین پر MCP سرور کو **Agent Builder** کے ذریعے MCP کلائنٹ کی حیثیت سے چلائیں گے۔

1. `F5` دبائیں تاکہ MCP سرور کی ڈیبگنگ شروع ہو جائے۔ **Agent (Prompt) Builder** ایک نئے ایڈیٹر ٹیب میں کھلے گا۔ سرور کی حالت ٹرمینل میں نظر آئے گی۔
1. **Agent (Prompt) Builder** کے **User prompt** فیلڈ میں درج کریں: `میں نے 3 اشیاء خریدیں جن کی قیمت ہر ایک $25 تھی، اور پھر $20 کی چھوٹ استعمال کی۔ میں نے کتنی رقم ادا کی؟`
1. **Run** بٹن پر کلک کریں تاکہ ایجنٹ کا جواب حاصل ہو۔
1. ایجنٹ کے آؤٹ پٹ کا جائزہ لیں۔ ماڈل کو نتیجہ اخذ کرنا چاہیے کہ آپ نے **$55** ادا کیے۔
1. یہاں اس بات کی تفصیل ہے کہ کیا ہونا چاہیے:
    - ایجنٹ کیلکولیشن میں مدد کے لیے **multiply** اور **subtract** اوزار منتخب کرتا ہے۔
    - متعلقہ `a` اور `b` اقدار **multiply** اوزار کے لیے مقرر کی جاتی ہیں۔
    - متعلقہ `a` اور `b` اقدار **subtract** اوزار کے لیے مقرر کی جاتی ہیں۔
    - ہر اوزار سے جواب متعلقہ **Tool Response** میں فراہم کیا جاتا ہے۔
    - ماڈل کا حتمی نتیجہ آخری **Model Response** میں فراہم کیا جاتا ہے۔
1. مزید پرامپٹس جمع کرائیں تاکہ ایجنٹ کی مزید جانچ ہو سکے۔ آپ موجودہ پرامپٹ کو **User prompt** فیلڈ میں کلک کر کے تبدیل کر سکتے ہیں۔
1. جب آپ ٹیسٹنگ مکمل کر لیں، تو آپ سرور کو **terminal** میں **CTRL/CMD+C** دبا کر روک سکتے ہیں۔

## اسائنمنٹ

اپنے **server.py** فائل میں ایک اضافی ٹول انٹری شامل کرنے کی کوشش کریں (مثلاً: کسی عدد کا مربع جذر نکالنا)۔ مزید پرامپٹ جمع کرائیں جنہیں ایجنٹ کو آپ کا نیا ٹول (یا موجودہ اوزار) استعمال کرنا پڑے۔ یقینی بنائیں کہ آپ نے نئے اوزار لوڈ کرنے کے لیے سرور کو دوبارہ شروع کیا ہے۔
