اس سیکشن میں کئی دروس شامل ہیں:

- **1 آپ کا پہلا سرور**، اس پہلے سبق میں، آپ سیکھیں گے کہ اپنا پہلا سرور کیسے بنائیں اور انسکپٹر ٹول کے ذریعے اسے کیسے معائنہ کریں، جو کہ آپ کے سرور کو ٹیسٹ اور ڈیبگ کرنے کا ایک قیمتی طریقہ ہے، [سبق کی طرف](01-first-server/README.md)

- **2 کلائنٹ**، اس سبق میں، آپ سیکھیں گے کہ ایسا کلائنٹ کیسے لکھیں جو آپ کے سرور سے جڑ سکے، [سبق کی طرف](02-client/README.md)

- **3 ایل ایل ایم کے ساتھ کلائنٹ**، کلائنٹ لکھنے کا ایک اور بہتر طریقہ یہ ہے کہ اس میں ایل ایل ایم شامل کیا جائے تاکہ یہ آپ کے سرور کے ساتھ بات چیت کر سکے کہ کیا کرنا ہے، [سبق کی طرف](03-llm-client/README.md)

- **4 Visual Studio Code میں سرور GitHub Copilot ایجنٹ موڈ کا استعمال**۔ یہاں، ہم MCP سرور کو Visual Studio Code کے اندر چلانے پر غور کر رہے ہیں، [سبق کی طرف](04-vscode/README.md)

- **5 stdio ٹرانسپورٹ سرور** stdio ٹرانسپورٹ مقامی MCP سرور سے کلائنٹ کمیونیکیشن کے لیے تجویز کردہ معیار ہے، جو اندرونی عمل کی تنہائی کے ساتھ محفوظ ذیلی عمل کی بنیاد پر مواصلات فراہم کرتا ہے [سبق کی طرف](05-stdio-server/README.md)

- **6 MCP کے ساتھ HTTP اسٹریمنگ (Streamable HTTP)**۔ معیاری
	ریموٹ ٹرانسپورٹ کے بارے میں جانیں [MCP Specification 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http),
	اس کے علاوہ سبق میں موجود پرانا سیشن پر مبنی نفاذ بھی دیکھیں۔
	[سبق کی طرف](06-http-streaming/README.md)

- **7 VSCode کے لیے AI Toolkit کا استعمال** تاکہ آپ اپنے MCP کلائنٹس اور سرورز کو استعمال اور ٹیسٹ کر سکیں [سبق کی طرف](07-aitk/README.md)

- **8 ٹیسٹنگ**۔ یہاں ہم خاص طور پر اس بات پر توجہ دیں گے کہ ہم اپنے سرور اور کلائنٹ کو مختلف طریقوں سے کیسے ٹیسٹ کر سکتے ہیں، [سبق کی طرف](08-testing/README.md)

- **9 ڈپلائمنٹ**۔ یہ باب آپ کے MCP حل کو مختلف طریقوں سے تعینات کرنے پر غور کرے گا، [سبق کی طرف](09-deployment/README.md)

- **10 جدید سرور کا استعمال**۔ یہ باب جدید سرور کے استعمال کو بیان کرتا ہے، [سبق کی طرف](./10-advanced/README.md)

- **11 تصدیق**۔ یہ باب سادہ تصدیق کے طریقے بیان کرتا ہے، جیسے Basic Auth سے JWT اور RBAC تک۔ شروع کرنے کے لیے یہاں سے آغاز کریں، پھر باب 5 میں جدید موضوعات دیکھیں اور باب 2 میں دی گئی سفارشات کے ذریعے اضافی سیکورٹی سختی کریں، [سبق کی طرف](./11-simple-auth/README.md)

- **12 MCP ہوسٹس**۔ مشہور MCP ہوسٹ کلائنٹس جیسے Claude Desktop، Cursor، Cline، اور Windsurf کو ترتیب دیں اور استعمال کریں۔ ٹرانسپورٹ اقسام اور مسئلہ حل کرنے کے بارے میں جانیں، [سبق کی طرف](./12-mcp-hosts/README.md)

- **13 MCP انسکپٹر**۔ MCP انسکپٹر ٹول کا استعمال کرتے ہوئے اپنے MCP سرورز کو انٹرایکٹو طور پر ڈیبگر اور ٹیسٹ کریں۔ مسئلہ حل کرنے کے اوزار، وسائل، اور پروٹوکول پیغامات کے بارے میں سیکھیں، [سبق کی طرف](./13-mcp-inspector/README.md)


- **14 سیمپلنگ**۔ `2025-11-25` کے لیے روایت کردہ سیمپلنگ پرمیٹو کو سیکھیں اور
	نئے ڈیزائنز کو براہ راست LLM فراہم کنندہ کے انضمام کی طرف کیسے منتقل کریں۔ سیمپلنگ
	MCP `2026-07-28` میں غیر مستعمل ہو چکا ہے۔ [سبق پر جائیں](./14-sampling/README.md)

- **15 MCP ایپس**۔ MCP سرورز بنائیں جو UI ہدایات کے ساتھ جواب دیتے ہیں، [سبق پر جائیں](./15-mcp-apps/README.md)

ماڈل کانٹیکسٹ پروٹوکول (MCP) ایک کھلا پروٹوکول ہے جو معیاری بناتا ہے کہ ایپلیکیشنز کس طرح LLMs کو کانٹیکسٹ فراہم کرتی ہیں۔ MCP کو AI ایپلیکیشنز کے لیے USB-C پورٹ سمجھیں - یہ AI ماڈلز کو مختلف ڈیٹا ذرائع اور ٹولز سے منسلک کرنے کا معیاری طریقہ فراہم کرتا ہے۔

## تعلیمی مقاصد

اس سبق کے اختتام تک، آپ کے قابل ہوں گے:

- MCP کے لیے C#, Java, Python, TypeScript, اور JavaScript میں ترقیاتی ماحول ترتیب دیں
- حسب ضرورت خصوصیات (وسائل، پرامپٹس، اور ٹولز) کے ساتھ بنیادی MCP سرورز تعمیر اور تعینات کریں
- MCP سرورز سے منسلک میزبان ایپلیکیشنز بنائیں
- MCP نفاذ کی جانچ اور ڈیبگنگ کریں
- عام سیٹ اپ چیلنجز اور ان کے حل کو سمجھیں
- اپنی MCP نفاذ کو مقبول LLM خدمات سے منسلک کریں

## اپنا MCP ماحول ترتیب دینا

MCP کے ساتھ کام شروع کرنے سے پہلے، یہ ضروری ہے کہ آپ اپنا ترقیاتی ماحول تیار کریں اور بنیادی ورک فلو کو سمجھیں۔ یہ سیکشن آپ کو ابتدائی سیٹ اپ کے مراحل سے رہنمائی کرے گا تاکہ MCP کے ساتھ آسان آغاز ممکن ہو۔

### متطلبات

MCP کی ترقی میں کودنے سے پہلے، یقینی بنائیں کہ آپ کے پاس موجود ہیں:

- **ترقیاتی ماحول**: اپنی منتخب شدہ زبان کے لیے (C#, Java, Python, TypeScript، یا JavaScript)
- **IDE/ایڈیٹر**: Visual Studio، Visual Studio Code، IntelliJ، Eclipse، PyCharm، یا کوئی جدید کوڈ ایڈیٹر
- **پیکج مینیجرز**: NuGet، Maven/Gradle، pip، یا npm/yarn
- **API کیز**: کسی بھی AI خدمات کے لیے جو آپ اپنی میزبان ایپلیکیشنز میں استعمال کرنا چاہتے ہیں


### سرکاری SDKs

آنے والے ابواب میں آپ Python, TypeScript,
Java اور .NET استعمال کرتے ہوئے حل دیکھیں گے۔ یہاں سرکاری SDKs موجود ہیں۔

MCP `2026-07-28` کے لیے SDK کی حمایت زبان کے حساب سے آزادانہ طور پر جاری کی جا رہی ہے۔
مثال چلانے سے پہلے، اس کے پیکج ورژن اور SDK کی ریلیز نوٹس چیک کریں
تاکہ پروٹوکول کے حمایت شدہ ترمیمات معلوم ہوں۔ دیکھیں
[سرکاری SDK فہرست](https://modelcontextprotocol.io/docs/sdk):
- [C# SDK](https://github.com/modelcontextprotocol/csharp-sdk) - Microsoft کے تعاون سے جاری
- [Java SDK](https://github.com/modelcontextprotocol/java-sdk) - Spring AI کے تعاون سے جاری
- [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) - سرکاری TypeScript عمل درآمد
- [Python SDK](https://github.com/modelcontextprotocol/python-sdk) - سرکاری Python عمل درآمد (FastMCP)
- [Kotlin SDK](https://github.com/modelcontextprotocol/kotlin-sdk) - سرکاری Kotlin عمل درآمد
- [Swift SDK](https://github.com/modelcontextprotocol/swift-sdk) - Loopwork AI کے تعاون سے جاری
- [Rust SDK](https://github.com/modelcontextprotocol/rust-sdk) - سرکاری Rust عمل درآمد
- [Go SDK](https://github.com/modelcontextprotocol/go-sdk) - سرکاری Go عمل درآمد

## اہم نکات

- MCP ترقیاتی ماحول کا قیام زبان مخصوص SDKs کے ساتھ آسان ہے
- MCP سرورز کی تعمیر میں واضح اسکیموں کے ساتھ ٹولز بنانا اور رجسٹر کرنا شامل ہے

- MCP کلائنٹس سرورز اور ماڈلز سے جڑتے ہیں تاکہ زیادہ صلاحیتوں سے فائدہ اٹھا سکیں
- قابلِ اعتماد MCP نفاذ کے لیے جانچ اور ڈیبگنگ ضروری ہے
- تعیناتی کے اختیارات مقامی ترقی سے لے کر کلاؤڈ پر مبنی حل تک ہوتے ہیں
