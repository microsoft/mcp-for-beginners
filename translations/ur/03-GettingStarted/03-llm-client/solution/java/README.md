# کیلکولیٹر LLM کلائنٹ

ایک جاوا ایپلیکیشن جو دکھاتی ہے کہ LangChain4j کو کیسے MCP (ماڈل کانٹیکسٹ پروٹوکول) کیلکولیٹر سروس کے ساتھ منی میکس اوپن اے آئی-مطابق API کے ذریعے جوڑا جائے۔

## ضروریات

- جاوا 21 یا جدید تر
- میون 3.6+ (یا شامل میون ریپر استعمال کریں)
- ایک MiniMax API کی
- ایک MCP کیلکولیٹر سروس جو `http://localhost:8080` پر چل رہی ہو

## API کی حاصل کرنا

یہ ایپلیکیشن MiniMax اوپن اے آئی-مطابق API استعمال کرتی ہے۔ اپنی کی اور اینڈپوائنٹ حاصل کرنے کے لیے یہ اقدامات کریں:

### 1. ایک اینڈپوائنٹ منتخب کریں
1. عالمی اینڈپوائنٹ کے لیے `https://api.minimax.io/v1` استعمال کریں
2. چین کے اینڈپوائنٹ کے لیے `https://api.minimaxi.com/v1` استعمال کریں

### 2. API کی بنائیں
1. اپنے MiniMax اکاؤنٹ سے MiniMax API کی بنائیں
2. کی کو محفوظ جگہ پر رکھیں

### 3. ماحول کے متغیرات سیٹ کریں

#### ونڈوز (کمانڈ پرامپٹ) پر:
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### ونڈوز (پاور شیل) پر:
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### میک او ایس / لینکس پر:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## سیٹ اپ اور تنصیب

1. **پروجیکٹ ڈائریکٹری کلون یا داخل ہوں**

2. **انحصارات انسٹال کریں**:
   ```cmd
   mvnw clean install
   ```
   یا اگر آپ کے پاس میون گلوبلی انسٹال ہے:
   ```cmd
   mvn clean install
   ```

3. **ماحول کے متغیرات سیٹ کریں** (اوپر "API کی حاصل کرنا" سیکشن ملاحظہ کریں)

4. **MCP کیلکولیٹر سروس شروع کریں**:
   یقینی بنائیں کہ آپ کے پاس باب 1 کی MCP کیلکولیٹر سروس `http://localhost:8080/sse` پر چل رہی ہو۔ کلائنٹ شروع کرنے سے پہلے یہ چل رہی ہونی چاہیے۔

## ایپلیکیشن چلانا

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## ایپلیکیشن کیا کرتی ہے

ایپلیکیشن کیلکولیٹر سروس کے ساتھ تین بنیادی تعاملات دکھاتی ہے:

1. **جمع**: 24.5 اور 17.3 کا مجموعہ نکالنا
2. **اسکوائر روٹ**: 144 کا مربع جذر نکالنا
3. **مدد**: دستیاب کیلکولیٹر فنکشنز دکھانا

## متوقع نتیجہ

کامیابی سے چلانے پر، آپ کو تقریباً درج ذیل آؤٹ پٹ نظر آئے گا:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## مسائل کا حل

### عام مسائل

1. **"OPENAI_API_KEY ماحول کا متغیر سیٹ نہیں ہے"**
   - یقینی بنائیں کہ `OPENAI_API_KEY` ماحول کا متغیر سیٹ کیا گیا ہو
   - متغیر سیٹ کرنے کے بعد ٹرمینل/کمانڈ پرامپٹ دوبارہ شروع کریں

2. **"localhost:8080 سے کنکشن انکار کر دیا گیا"**
   - اس بات کو یقینی بنائیں کہ MCP کیلکولیٹر سروس پورٹ 8080 پر چل رہی ہو
   - دیکھیں کہ کوئی اور سروس پورٹ 8080 استعمال تو نہیں کر رہی

3. **"تصدیق ناکام ہو گئی"**
   - اپنی API کی کی درستگی کی پڑتال کریں
   - چیک کریں کہ `OPENAI_BASE_URL` آپ کے ارادے کے مطابق اینڈپوائنٹ کے ساتھ میل کھاتا ہو

4. **میون بلڈ کی غلطیاں**
   - یقینی بنائیں کہ آپ جاوا 21 یا جدید استعمال کر رہے ہیں: `java -version`
   - تعمیر صاف کریں: `mvnw clean` آزما کر دیکھیں

### ڈیبگنگ

ڈیبگ لاگ ان ایبل کرنے کے لیے، جب چلائیں تو درج ذیل JVM دلیل شامل کریں:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## ترتیب

ایپلیکیشن کی ترتیب درج ذیل ہے:
- ڈیفالٹ کے طور پر MiniMax-M3 استعمال کرے گا؛ `MINIMAX_MODEL_ID` سیٹ کریں تاکہ یا تو `MiniMax-M3` یا `MiniMax-M2.7` منتخب کیا جا سکے
- `OPENAI_BASE_URL` سیٹ ہونے پر اس سے کنکٹ ہو؛ ورنہ `MINIMAX_REGION=cn_zh` ہو تو `https://api.minimaxi.com/v1`، یا بصورت دیگر ڈیفالٹ میں `https://api.minimax.io/v1` استعمال کرے
- MCP سروس `http://localhost:8080/sse` پر جوڑے
- درخواستوں کے لیے 60 سیکنڈ کا ٹائم آؤٹ استعمال کرے

## انحصارات

اس پروجیکٹ میں استعمال ہونے والے کلیدی انحصارات:
- **LangChain4j**: AI انضمام اور ٹول مینجمنٹ کے لیے
- **LangChain4j MCP**: ماڈل کانٹیکسٹ پروٹوکول کی حمایت کے لیے
- **LangChain4j OpenAI official**: MiniMax اوپن اے آئی-مطابق API انضمام کے لیے
- **Spring Boot**: ایپلیکیشن فریم ورک اور انحصارات کا انجیکشن کے لیے
