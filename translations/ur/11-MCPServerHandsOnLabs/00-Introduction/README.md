## 🎯 یہ لیب کیا کور کرتی ہے

یہ تعارفی لیب MCP سرورز بنانے کا جامع جائزہ پیش کرتی ہے جو ڈیٹا بیس انٹیگریشن کے ساتھ ہوتے ہیں۔ آپ کاروباری کیس، تکنیکی آرکیٹیکچر، اور حقیقی دنیا کی ایپلیکیشنز کو https://github.com/microsoft/MCP-Server-and-PostgreSQL-Sample-Retail پر زاوہ ریٹیل اینالٹکس کے استعمال کے کیس کے ذریعے سمجھیں گے۔

## جائزہ

**ماڈل کانٹیکسٹ پروٹوکول (MCP)** AI اسسٹنٹس کو محفوظ طریقے سے بیرونی ڈیٹا ذرائع تک رسائی اور تعامل کی سہولت دیتا ہے حقیقی وقت میں۔ جب ڈیٹا بیس انٹیگریشن کے ساتھ ملایا جائے، تو MCP ڈیٹا پر مبنی AI ایپلیکیشنز کے لیے طاقتور صلاحیتیں فراہم کرتا ہے۔

یہ لرننگ پاتھ آپ کو پروڈکشن کے لیے تیار MCP سرور بنانے سکھاتا ہے جو AI اسسٹنٹس کو ریٹیل سیلز ڈیٹا کے ساتھ PostgreSQL کے ذریعے جوڑتا ہے، جہاں انٹرپرائز پیٹرنز جیسے رو لیول سیکیورٹی، سیمانٹک سرچ، اور ملٹی ٹیننٹ ڈیٹا رسائی نافذ کیے جاتے ہیں۔

- **MCP سرور آرکیٹیکچر کے اہم اجزاء کی شناخت کریں**

- **محفوظ، قابل توسیع ڈیٹا بیس رسائی کے انٹرپرائز پیٹرنز کو پہچانیں**
- **اس لرننگ پاتھ میں استعمال ہونے والے ٹولز اور ٹیکنالوجیز کی فہرست بنائیں**

| **سیکیورٹی پابندیاں** | ڈیٹا بیس تک براہ راست رسائی حفاظتی اور تعمیل کے خدشات پیدا کرتی ہے | محدود تعیناتی، دستی ڈیٹا کی تیاری |
| **پیچیدہ سوالات** | کاروباری صارفین کو ڈیٹا کی بصیرت نکالنے کے لیے فنی معلومات کی ضرورت ہوتی ہے | کم اپنانا، غیر موثر عمل |

- **معیاری پروٹوکول**: مختلف AI پلیٹ فارمز اور ٹولز کے درمیان کام کرتا ہے

**زاوہ ریٹیل** چلتی ہے:

- **کثیر سطحی انتظامیہ** جس میں اسٹور مینیجرز، علاقائی مینیجرز، اور ایگزیکٹوز شامل ہیں

### کاروباری ضروریات

اسٹور مینیجرز اور ایگزیکٹوز کو AI سے چلنے والی اینالٹکس کی ضرورت ہے تاکہ وہ:

1. **سیلز کی کارکردگی کا تجزیہ کریں** اسٹورز اور وقت کے ادوار کے لحاظ سے
2. **انوینٹری لیولز پر نظر رکھیں** اور دوبارہ اسٹاک کرنے کی ضروریات کی شناخت کریں
3. **کسٹمر کے رویے اور خریداری کے پیٹرنز کو سمجھیں**
4. **مصنوعات کی بصیرت تلاش کریں** سیمانٹک سرچ کے ذریعے
5. **قدرتی زبان کی سوالات کے ساتھ رپورٹس تیار کریں**
6. **ڈیٹا سیکیورٹی برقرار رکھیں** رول بیسڈ رسائی کنٹرول کے ساتھ

### تکنیکی ضروریات

MCP سرور کو فراہم کرنا ہوگا:

- **ملٹی ٹیننٹ ڈیٹا رسائی** جہاں اسٹور مینیجرز صرف اپنے اسٹور کا ڈیٹا دیکھ سکیں
- **لچکدار سوالات** جو پیچیدہ SQL آپریشنز کو سپورٹ کریں
- **سیمانٹک سرچ** مصنوعات کی دریافت اور تجاویز کے لیے
- **حقیقی وقت کا ڈیٹا** جو موجودہ کاروباری حالت کی عکاسی کرے
- **محفوظ تصدیق** رو لیول سیکیورٹی کے ساتھ
- **قابل توسیع آرکیٹیکچر** جو متعدد صارفین کو بیک وقت سپورٹ کرے

### اہم اجزاء

#### **1. MCP سرور کی تہہ**
- **FastMCP فریم ورک**: جدید Python MCP سرور کی امپلیمینٹیشن
- **ٹول رجسٹریشن**: ڈی clarative ٹول کی تعریفیں ٹائپ سیفٹی کے ساتھ
- **ریکویسٹ کانٹیکسٹ**: صارف کی شناخت اور سیشن مینجمنٹ
- **ایرر ہینڈلنگ**: مضبوط ایرر مینجمنٹ اور لاگنگ

#### **2. ڈیٹا بیس انٹیگریشن کی تہہ**
- **کنییکشن پولنگ**: مؤثر asyncpg کنکشن مینجمنٹ
- **اسکیما فراہم کنندہ**: جدول کے اسکیمے کی متحرک دریافت
- **سوال چلانے والا**: محفوظ SQL نفاذ RLS کانٹیکسٹ کے ساتھ
- **ٹرانزیکشن مینجمنٹ**: ACID تعمیل اور رول بیک ہینڈلنگ

#### **3. سیکیورٹی کی تہہ**
- **رو لیول سیکیورٹی**: PostgreSQL RLS ملٹی ٹیننٹ ڈیٹا انزولیٹیشن کے لیے
- **صارف کی شناخت**: اسٹور مینیجر کی توثیق اور اجازت
- **رسائی کنٹرول**: باریک بینی کے ساتھ اجازت اور آڈٹ ٹریلز
- **ان پٹ کی توثیق**: SQL انجیکشن سے حفاظت اور سوالات کی توثیق

#### **4. AI بہتری کی تہہ**
- **سیمانٹک سرچ**: مصنوعات کی تلاش کے لیے ویکٹر ایمبیڈنگز
- **Azure OpenAI انٹیگریشن**: متن کے ایمبیڈنگ کی تخلیق
- **مماثلت الگورتھمز**: pgvector کاسائن سیمیلیکرتی سرچ
- **سرچ کی اصلاح**: انڈیکسنگ اور کارکردگی کی بہتری

## 🎬 حقیقی دنیا کے استعمال کے منظرنامے

آئیے دیکھتے ہیں کہ مختلف صارفین ہمارے MCP سرور کے ساتھ کیسے تعامل کرتے ہیں:

### منظرنامہ 1: اسٹور مینیجر کی کارکردگی کا جائزہ

**صارف**: سارہ، سیئٹل اسٹور مینیجر  
**مقصد**: گزشتہ سہ ماہی کی سیلز کارکردگی کا تجزیہ

**کیا ہوتا ہے**:
1. VS Code AI چیٹ سوال MCP سرور کو بھیجتا ہے
2. MCP سرور سارہ کے اسٹور کانٹیکسٹ کی شناخت کرتا ہے (سیئٹل)
3. RLS پالیسیاں صرف سیئٹل اسٹور کے ڈیٹا کو چھانٹتی ہیں
4. SQL سوال تیار اور چلایا جاتا ہے
5. نتائج فارمیٹ کر کے AI چیٹ کو بھیجے جاتے ہیں
6. AI تجزیہ اور بصیرت فراہم کرتا ہے

### منظرنامہ 2: سیمانٹک سرچ کے ساتھ مصنوعات کی دریافت

**صارف**: مائیک، انوینٹری مینیجر  
**مقصد**: کسٹمر کی درخواست کے مشابہ مصنوعات تلاش کریں

**قدرتی زبان کا سوال**:

**کیا ہوتا ہے**:
1. سوال سیمانٹک سرچ ٹول کے ذریعہ پروسیس ہوتا ہے
2. Azure OpenAI ایمبیڈنگ ویکٹر جنریٹ کرتا ہے
3. pgvector مماثلت کی تلاش کرتا ہے
4. متعلقہ مصنوعات کو مطابقت کے حساب سے درجہ بندی کیا جاتا ہے
5. نتائج میں مصنوعات کی تفصیلات اور دستیابی شامل ہوتی ہے
6. AI متبادل اور بنڈل کے مواقع تجویز کرتا ہے

### منظرنامہ 3: کراس اسٹور اینالٹکس

**صارف**: جینیفر، علاقائی مینیجر  
**مقصد**: تمام اسٹورز میں کارکردگی کا موازنہ

**کیا ہوتا ہے**:

2. پیچیدہ ملٹی اسٹور سوال تیار کیا جاتا ہے
3. اسٹور مقامات کے حساب سے ڈیٹا جمع کیا جاتا ہے
4. نتائج میں رجحانات اور موازنہ شامل ہے
5. AI بصیرت اور سفارشات فراہم کرتا ہے

## 🔒 سیکیورٹی اور ملٹی ٹیننسی کی تفصیلی معلومات

ہمارا نفاذ انٹرپرائز گریڈ سیکیورٹی کو ترجیح دیتا ہے:

### رو لیول سیکیورٹی (RLS)

PostgreSQL RLS ڈیٹا کی علیحدگی کو یقینی بناتا ہے:

```sql
-- Store managers see only their store's data
CREATE POLICY store_manager_policy ON retail.orders
  FOR ALL TO store_managers
  USING (store_id = get_current_user_store());

-- Regional managers see multiple stores
CREATE POLICY regional_manager_policy ON retail.orders
  FOR ALL TO regional_managers
  USING (store_id = ANY(get_user_store_list()));
```

### صارف کی شناخت کا انتظام

ہر MCP کنکشن میں شامل ہے:
- **اسٹور مینیجر ID**: RLS کانٹیکسٹ کے لیے منفرد شناخت کنندہ
- **رول اسائنمنٹ**: اجازت نامے اور رسائی کی سطحیں
- **سیشن مینجمنٹ**: محفوظ تصدیقی ٹوکنز
- **آڈٹ لاگنگ**: مکمل رسائی کی تاریخ

### ڈیٹا کی حفاظت

سیکیورٹی کی متعدد پرتیں:
- **کنکشن انکرپشن**: تمام ڈیٹا بیس کنکشنز کے لیے TLS
- **SQL انجیکشن کی روک تھام**: صرف پیرامیٹرائزڈ سوالات
- **ان پٹ کی توثیق**: جامع درخواست کی توثیق
- **ایرر ہینڈلنگ**: حساس معلومات کو ایرر پیغامات میں شامل نہ کرنا

## 🎯 اہم نکات

اس تعارف کے مکمل ہونے کے بعد آپ سمجھ چکے ہوں گے:

✅ **MCP ویلیو پروپوزیشن**: MCP کس طرح AI اسسٹنٹس اور حقیقی دنیا کے ڈیٹا کے درمیان پل کا کام کرتا ہے  
✅ **کاروباری سیاق و سباق**: زاوہ ریٹیل کی ضروریات اور چیلنجز  
✅ **آرکیٹیکچر کا جائزہ**: اہم اجزاء اور ان کا باہمی تعلق  
✅ **ٹیکنالوجی اسٹیک**: اس پورے لرننگ پاتھ میں استعمال ہونے والے ٹولز اور فریم ورکس  
✅ **سیکیورٹی ماڈل**: ملٹی ٹیننٹ ڈیٹا رسائی اور تحفظ  
✅ **استعمال کے پیٹرنز**: حقیقی دنیا کے سوالات اور ورک فلو
