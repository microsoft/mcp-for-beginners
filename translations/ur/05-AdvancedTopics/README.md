# ایم سی پی میں جدید موضوعات

[![جدید ایم سی پی: محفوظ، توسیعی، اور کثیر النمو AI ایجنٹس](../../../translated_images/ur/06.42259eaf91fccfc6.webp)](https://youtu.be/4yjmGvJzYdY)

_(اس سبق کی ویڈیو دیکھنے کے لیے اوپر دی گئی تصویر پر کلک کریں)_

یہ باب ماڈل کانٹیکسٹ پروٹوکول (MCP) کی تنصیب میں متعدد جدید موضوعات کا احاطہ کرتا ہے، جن میں کثیر النمو انضمام، توسیع پزیری، سیکیورٹی کے بہترین طریقے، اور انٹرپرائز انضمام شامل ہیں۔ یہ موضوعات مضبوط اور پیداواری تیار MCP ایپلیکیشنز بنانے کے لیے انتہائی اہم ہیں جو جدید AI نظاموں کی ضروریات کو پورا کر سکیں۔

## جائزہ

یہ سبق ماڈل کانٹیکسٹ پروٹوکول کی تنصیب میں جدید تصورات کا جائزہ لیتا ہے، خاص طور پر کثیر النمو انضمام، توسیع پزیری، سیکیورٹی کے بہترین طریقے، اور انٹرپرائز انضمام پر توجہ مرکوز کرتا ہے۔ یہ موضوعات پیداواری معیار کی MCP ایپلیکیشنز بنانے کے لیے ضروری ہیں جو ادارہ جاتی ماحول میں پیچیدہ ضروریات کو سنبھال سکیں۔

> **موجودہ وضاحت کی نوٹ:** MCP `2026-07-28` سبق 5.4 اور 5.6 میں شامل Roots اور
> Sampling ابتدائیات کو غیر مستند قرار دیتا ہے۔ یہ
> تجرباتی Tasks خصوصیت جس کی Protocol Features (5.16) میں حوالہ دی گئی ہے، کو
> ایک مخصوص Tasks توسیع میں منتقل کرتا ہے۔ وہ سبق `2025-11-25` کی پرانی
> تنصیبات کے لیے رہ گئے ہیں اور ہجرت کی رہنمائی شامل کرتے ہیں۔ دیکھیں
> [MCP میں کیا بدلا ہے: 2026-07-28 وضاحت](../01-CoreConcepts/mcp-2026-07-28.md)۔

## تعلیمی مقاصد

اس سبق کے آخر تک، آپ قابل ہو جائیں گے:

- MCP فریم ورک میں کثیر النمو صلاحیتوں کا نفاذ کریں
- اعلیٰ مانگ والے حالات کے لیے توسیع پزیر MCP فن تعمیر ڈیزائن کریں
- MCP کے حفاظتی اصولوں سے ہم آہنگ سیکیورٹی کے بہترین طریقے اپنائیں
- MCP کو انٹرپرائز AI نظاموں اور فریم ورکس کے ساتھ انضمام کریں
- پیداواری ماحول میں کارکردگی اور اعتبار کو بہتر بنائیں

## کلیدی نکات

- کثیر النمو MCP نفاذات AI صلاحیتوں کو متن کی پروسیسنگ سے آگے بڑھاتے ہیں
- توسیع پزیری ادارہ جاتی تعیناتیوں کے لیے ضروری ہے اور افقی و عمودی توسیع کے ذریعے حاصل کی جا سکتی ہے
- جامع حفاظتی اقدامات ڈیٹا کی حفاظت کرتے ہیں اور مناسب رسائی کنٹرول کو یقینی بناتے ہیں
- Azure OpenAI اور Microsoft AI Foundry جیسے پلیٹ فارمز کے ساتھ ادارہ جاتی انضمام MCP کی صلاحیتوں کو بڑھاتا ہے
- جدید MCP نفاذات بهتری فن تعمیرات اور احتیاطی وسائل کے انتظام سے مستفید ہوتے ہیں

## مشق

کسی مخصوص استعمال کے کیس کے لیے ادارہ جاتی معیار کا MCP نفاذ ڈیزائن کریں:

1. اپنے استعمال کے کیس کے لیے کثیر النمو ضروریات کی شناخت کریں
2. حساس ڈیٹا کی حفاظت کے لیے حفاظتی ہدایات کا خاکہ تیار کریں
3. ایک توسیعی فن تعمیر ڈیزائن کریں جو مختلف بوجھ کو سنبھال سکے
4. انٹرپرائز AI نظاموں کے ساتھ انضمام کے مقامات کی منصوبہ بندی کریں
5. ممکنہ کارکردگی کے رکاوٹوں اور تدارک کی حکمت عملیوں کو دستاویز کریں
