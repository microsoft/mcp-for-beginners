# व्यावहारिक अंमलबजावणी

[![खऱ्या साधनांसह आणि कार्यप्रवाहांसह MCP अनुप्रयोग कसे तयार, चाचणी आणि तैनात करायचे](../../../translated_images/mr/05.64bea204e25ca891.webp)](https://youtu.be/vCN9-mKBDfQ)

_(या धड्याचा व्हिडिओ पाहण्यासाठी वरच्या प्रतिमेवर क्लिक करा)_

व्यावहारिक अंमलबजावणी म्हणजे मॉडेल कॉन्टेक्स्ट प्रोटोकॉल (MCP) ची सामर्थ्य दृश्यमान होते. MCP मागील सिद्धांत आणि वास्तुकलेचे ज्ञान नक्कीच महत्त्वाचे आहे, पण वास्तविक मूल्य तेव्हा दिसून येते जेव्हा आपण या संकल्पनांचा वापर करून वास्तविक जगातील समस्या सोडवणाऱ्या उपायांची निर्मिती, चाचणी आणि तैनाती करता. हा अध्याय सैद्धांतिक ज्ञान आणि प्रत्यक्ष विकास यातील दुवा जोडतो, ज्यामुळे आपण MCP आधारित अनुप्रयोग जिवंत आणण्याच्या प्रक्रियेत मार्गदर्शन मिळवाल.

आपण बुद्धिमान सहाय्यक विकसित करत असाल, व्यवसाय कार्यप्रवाहांमध्ये AI समाकलित करत असाल, किंवा डेटा प्रक्रिया साठी सानुकूल साधने तयार करत असाल, MCP ही एक लवचीक पाया प्रदान करते. त्याची भाषा-स्वतंत्र रचना आणि लोकप्रिय प्रोग्रॅमिंग भाषांसाठी अधिकृत SDK उपलब्ध असल्यामुळे ती विविध विकासकांपर्यंत पोहोचते. या SDK चा वापर करून तुम्ही जलद प्रोटोटाइप तयार करू शकता, पुनरावृत्ती करू शकता, आणि वेगवेगळ्या प्लॅटफॉर्म व वातावरणांवर तुमचे उपाय विस्तृत करू शकता.

पुढील विभागांमध्ये तुम्हाला व्यावहारिक उदाहरणे, नमुना कोड, आणि तैनाती धोरणे आढळतील जी C#, Java with Spring, TypeScript, JavaScript, आणि Python मध्ये MCP कसे अंमलात आणायचे हे दाखवतील. तुम्हाला MCP सर्व्हर्सचे डिबगिंग आणि चाचणी कशी करायची, API व्यवस्थापन कसे करायचे, आणि Azure वापरून क्लाउडवर उपाय तैनात कसे करायचे हे समजेल. ही प्रत्यक्ष संसाधने तुमच्या शिकण्याला गती देतील आणि तुम्हाला आत्मविश्वासाने मजबूत, उत्पादनासाठी तयार MCP अनुप्रयोग तयार करण्यास मदत करतात.

## आढावा

हा धडा अनेक प्रोग्रॅमिंग भाषांमध्ये MCP अंमलबजावणीच्या व्यावहारिक पैलूंवर लक्ष केंद्रित करतो. आपण C#, Java with Spring, TypeScript, JavaScript, आणि Python मधील MCP SDK वापरून मजबूत अनुप्रयोग तयार करणे, MCP सर्व्हर्सची डिबगिंग व चाचणी करणे, आणि पुनर्वापरयोग्य संसाधने, प्रॉम्प्ट्स, आणि साधने तयार करण्याचा अभ्यास करू.

## शिकण्याचे उद्दिष्ट

या धड्याच्या शेवटी, तुम्ही सक्षम असाल:

- विविध प्रोग्रॅमिंग भाषांमध्ये अधिकृत SDK वापरून MCP उपायांची अंमलबजावणी करणे
- MCP सर्व्हर्सची प्रणालीबद्ध डिबगिंग आणि चाचणी करणे
- सर्व्हर वैशिष्ट्ये (संसाधने, प्रॉम्प्ट्स, आणि साधने) तयार करणे आणि वापरणे
- जटिल कार्यांसाठी प्रभावी MCP कार्यप्रवाह डिझाइन करणे
- कार्यक्षमता आणि विश्वासार्हतेसाठी MCP अंमलबजावणी सुधारित करणे

## मुख्य सर्व्हर वैशिष्ट्ये

MCP सर्व्हर्स खालील वैशिष्ट्ये एकत्रितपणे लागू करू शकतात:

### संसाधने

संसाधने वापरकर्त्यास किंवा AI मॉडेलसाठी संदर्भ आणि डेटा पुरवतात:

- दस्तऐवज संच
- ज्ञान बेस
- संरचीत डेटा स्रोत
- फाईल सिस्टम

### प्रॉम्प्ट्स

प्रॉम्प्ट्स वापरकर्त्यांसाठी टेम्प्लेट केलेले संदेश आणि कार्यप्रवाह आहेत:

- पूर्वनिर्धारित संवाद टेम्प्लेट्स
- मार्गदर्शित संवाद नमुने
- विशेष संवाद संरचना

### साधने

साधने AI मॉडेलसाठी कार्ये आहेत:

- डेटा प्रक्रिया उपयुक्तता
- बाह्य API समाकलन
- संगणकीय क्षमता
- शोध कार्यक्षमता

## नमुना अंमलबजावणी: C# अंमलबजावणी

अधिकृत C# SDK संग्रहालयात MCP च्या विविध पैलूंवर अनेक नमुना अंमलबजावण्या आहेत:

- **मूलभूत MCP क्लायंट**: साधा उदाहरण कसे MCP क्लायंट तयार करायचा आणि साधने कॉल करायची ते दाखवते
- **मूलभूत MCP सर्व्हर**: मूलभूत साधने नोंदणीसह किमान सर्व्हर अंमलबजावणी
- **प्रगत MCP सर्व्हर**: पूर्ण वैशिष्ट्ययुक्त सर्व्हर साधने नोंदणी, प्रमाणीकरण, आणि त्रुटी हाताळणीसह
- **ASP.NET समाकलन**: ASP.NET Core सह समाकलन दाखवणारे उदाहरणे
- **साधन अंमलबजावणी नमुने**: वेगवेगळ्या क्लिष्टता स्तरांसह साधने तयार करण्याचे विविध नमुने

MCP C# SDK पूर्वावलोकन स्थितीत आहे आणि API मध्ये बदल होऊ शकतात. SDK विकसित होत असल्याने हा ब्लॉग सातत्याने अद्ययावत करू.

## रिमोट MCP सर्व्हर Azure वर तैनात करा

आपण आधी नमूद केलेल्या नमुन्याची तैनाती करू शकतो का ते पाहूया:

1. रेपो क्लोन करा

    ```bash
    git clone https://github.com/Azure-Samples/remote-mcp-apim-functions-python.git
    cd remote-mcp-apim-functions-python
    ```

1. `Microsoft.App` रिसोर्स प्रदाता नोंदणी करा.

   - जर तुम्ही Azure CLI वापरत असाल, तर `az provider register --namespace Microsoft.App --wait` चालवा.
   - जर तुम्ही Azure PowerShell वापरत असाल, तर `Register-AzResourceProvider -ProviderNamespace Microsoft.App` चालवा. नंतर काही वेळाने `(Get-AzResourceProvider -ProviderNamespace Microsoft.App).RegistrationState` तपासा की नोंदणी पूर्ण झाली आहे का.

1. या [azd](https://aka.ms/azd) आदेशाचा वापर करून API Management सेवा, फंक्शन अॅप (कोडसह), आणि इतर आवश्यक Azure संसाधने प्रदान करा

    ```shell
    azd up
    ```

    हे आदेश Azure वर सर्व क्लाउड संसाधने तैनात करेल

### MCP Inspector सह तुमचा सर्व्हर चाचणी करा

1. **नवीन टर्मिनल विंडो** मध्ये MCP Inspector इन्स्टॉल करा आणि चालवा

    ```shell
    npx @modelcontextprotocol/inspector
    ```

    तुल्यलिंगी इंटरफेस यासारखा दिसेल:

    ![Connect to Node inspector](../../../translated_images/mr/connect.141db0b2bd05f096.webp)

1. URL वर CTRL क्लिक करा जो app द्वारे दर्शविला जातो (उदा. [http://127.0.0.1:6274/#resources](http://127.0.0.1:6274/#resources)) आणि MCP Inspector वेब अॅप उघडा
1. ट्रान्सपोर्ट प्रकार `SSE` सेट करा
1. URL तुमच्या चालू API Management SSE एंडपॉइंटला जे `azd up` नंतर दर्शविले जाते असे सेट करा आणि **Connect** करा:

    ```shell
    https://<apim-servicename-from-azd-output>.azure-api.net/mcp/sse
    ```

1. **सूचीतील साधने**. एखाद्या साधनावर क्लिक करा आणि **Run Tool** करा.

सर्व चरणं यशस्वी झाली असल्यास, तुम्ही MCP सर्व्हरशी जोडलेले आहात आणि साधन कॉल करू शकलेले आहात.

[Remote-mcp-functions](https://github.com/Azure-Samples/remote-mcp-functions-dotnet): या संचिका Azure Functions वापरून Python, C# .NET किंवा Node/TypeScript सह सानुकूल रिमोट MCP (मॉडेल कॉन्टेक्स्ट प्रोटोकॉल) सर्व्हर तयार करण्यासाठी आणि तैनात करण्यासाठी जलद प्रारंभ टेम्प्लेट समाविष्ट करतात.

हे नमुने एक पूर्ण समाधान पुरवतात ज्याद्वारे विकसक:

- स्थानिक मशीनवर निर्माण व डिबग करू शकतात
- सहजरित्या क्लाउडवर `azd up` आदेशाने तैनात करू शकतात
- विविध क्लायंट्स वरुन MCP सर्व्हरशी कनेक्ट होऊ शकतात ज्यात VS Code चा Copilot एजंट मोड आणि MCP Inspector साधन समाविष्ट आहे

### मुख्य वैशिष्ट्ये

- डिझाइनद्वारे सुरक्षा: MCP सर्व्हर की आणि HTTPS द्वारे सुरक्षित
- प्रमाणीकरण पर्याय: अंगभूत प्रमाणीकरण आणि/किंवा API Management वापरून OAuth समर्थित
- नेटवर्क अलगावा: Azure Virtual Networks (VNET) वापरून नेटवर्क अलगावाची परवानगी
- सर्व्हरलेस आर्किटेक्चर: स्केलेबल, इव्हेंट-चालित अंमलबजावणीसाठी Azure Functions चा उपयोग
- स्थानिक विकास: सर्वसमावेशक स्थानिक विकास आणि डिबगिंग समर्थन
- सोपी तैनाती: Azure साठी सुलभ तैनाती प्रक्रिया

या संग्रहालयात सर्व आवश्यक कॉन्फिगरेशन फाइल्स, स्त्रोत कोड, आणि इन्फ्रास्ट्रक्चर परिभाषा आहेत जेणेकरून तुम्ही उत्पादनासाठी तयार MCP सर्व्हर अंमलबजावणी त्वरीत सुरू करू शकता.

- [Azure Remote MCP Functions Python](https://github.com/Azure-Samples/remote-mcp-functions-python) - Azure Functions सह Python वापरून MCP ची नमुना अंमलबजावणी

- [Azure Remote MCP Functions .NET](https://github.com/Azure-Samples/remote-mcp-functions-dotnet) - Azure Functions सह C# .NET वापरून MCP ची नमुना अंमलबजावणी

- [Azure Remote MCP Functions Node/Typescript](https://github.com/Azure-Samples/remote-mcp-functions-typescript) - Azure Functions सह Node/TypeScript वापरून MCP ची नमुना अंमलबजावणी.

## मुख्य मुद्दे

- MCP SDKs भाषा-विशिष्ट साधने प्रदान करतात जी मजबूत MCP उपाय तयार करण्यासाठी उपयुक्त
- विश्वासार्ह MCP अनुप्रयोगांसाठी डिबगिंग आणि चाचणी प्रक्रिया महत्त्वाची आहे
- पुनर्वापरयोग्य प्रॉम्प्ट टेम्प्लेट्स सुसंगत AI संवाद सक्षम करतात
- चांगले डिझाइन केलेले कार्यप्रवाह अनेक साधने वापरून जटिल कार्य यशस्वी करतात
- MCP उपाय लागू करताना सुरक्षा, कार्यक्षमता, आणि त्रुटी हाताळणीचा विचार आवश्यक आहे

## व्यायाम

तुमच्या क्षेत्रातील एखाद्या वास्तविक समस्या सोडवणारा व्यावहारिक MCP कार्यप्रवाह डिझाइन करा:

1. या समस्येसाठी उपयुक्त 3-4 साधने ओळखा
2. या साधनांच्या परस्परसंवादाचे कार्यप्रवाह आकृती बनवा
3. तुमच्या पसंतीच्या भाषेत एका साधनाचा मूलभूत आवृत्ती अंमलात आणा
4. मॉडेलला तुमच्या साधनाचा प्रभावीपणे वापर करण्यास मदत करणारा प्रॉम्प्ट टेम्प्लेट तयार करा
