# AGENTS.md

## प्रकल्पाचा आढावा

**MCP for Beginners** हे Model Context Protocol (MCP) शिकण्यासाठी एक ओपन-सोर्स शैक्षणिक अभ्यासक्रम आहे - एआय मॉडेल्स आणि क्लायंट अनुप्रयोगांमधील संवादासाठी एक मानकीकृत चौकट. हा रिपॉझिटरी अनेक प्रोग्रामिंग भाषांमध्ये व्यावहारिक कोड उदाहरणांसह व्यापक शिक्षण सामग्री प्रदान करतो.

### मुख्य तंत्रज्ञान

- **प्रोग्रामिंग भाषा**: C#, Java, JavaScript, TypeScript, Python, Rust
- **फ्रेमवर्क आणि SDKs**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **डाटाबेस**: PostgreSQL विथ pgvector विस्तार
- **क्लाउड प्लॅटफॉर्म्स**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **बिल्ड टूल्स**: npm, Maven, pip, Cargo
- **डॉक्युमेंटेशन**: ऑटोमेटेड बहुभाषिक भाषांतरासह मार्कडाउन (४८+ भाषा)

### आर्किटेक्चर

- **११ मुख्य मोड्यूल्स (००-११)**: मूलभूत ते प्रगत विषयांपर्यंत अनुक्रमिक शिक्षण मार्ग
- **प्रायोगिक प्रयोगशाळा**: अनेक भाषांमध्ये पूर्ण निराकरण कोडसह व्यावहारिक व्यायाम
- **नमुना प्रकल्प**: कार्यरत MCP सर्व्हर आणि क्लायंट अंमलबजावणी
- **भाषांतर प्रणाली**: बहुभाषिक समर्थनासाठी ऑटोमेटेड GitHub Actions कार्यप्रवाह
- **प्रतिमा साधने**: अनुवादित आवृत्त्यांसह केंद्रीकृत प्रतिमा निर्देशिक

## सेटअप आदेश

हा एक दस्तऐवजीकरण-केंद्रित रिपॉझिटरी आहे. बहुतेक सेटअप स्वतंत्र नमुना प्रकल्प आणि प्रयोगशाळांमध्ये होते.

### रिपॉझिटरी सेटअप

```bash
# संग्रहीत स्थान क्लोन करा
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### नमुना प्रकल्पांवर काम करणे

नमुना प्रकल्प खालील ठिकाणी आहेत:
- `03-GettingStarted/samples/` - भाषा-विशिष्ट उदाहरणे
- `03-GettingStarted/01-first-server/solution/` - पहिले सर्व्हर अंमलबजावणी
- `03-GettingStarted/02-client/solution/` - क्लायंट अंमलबजावणी
- `11-MCPServerHandsOnLabs/` - व्यापक डेटाबेस एकत्रीकरण प्रयोगशाळा

प्रत्येक नमुना प्रकल्पातील स्वतःचे सेटअप निर्देश आहेत:

#### TypeScript/JavaScript प्रकल्प
```bash
cd <project-directory>
npm install
npm start
```

#### Python प्रकल्प
```bash
cd <project-directory>
pip install -r requirements.txt
# किंवा
pip install -e .
python main.py
```

#### Java प्रकल्प
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

##### उद्दिष्ट

अभ्यासक्रम दस्तऐवजीकरण बदल आणि प्रतिनिधी नमुना कोड
विलीन होण्यापूर्वी निरोगी आहे का याची पडताळणी करा.

##### इनपुट

- `changed_paths: string[]` (आवश्यक) - PR मध्ये बदललेले सापेक्ष मार्ग.
- `run_docs_lint: boolean` (मूल्य `true`)
- `run_links_audit: boolean` (मूल्य `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (मूल्य सर्व `false`)

##### आउटपुट

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### परवानग्या

- वर्कस्पेस फायली वाचा आणि टूल-जनरेट केलेले आर्टिफॅक्ट्स लिहा (उदा., लिंट
  अहवाल, चाचणी लॉग) फक्त; `translations/` किंवा
  `translated_images/` मध्ये कोणताही लेखन नाही.
- स्थानिक शेल कमांड्स चालवा.
- फक्त पॅकेज पुनर्संचयनेसाठी इंटरनेट प्रवेश पर्यायी (`npm ci`,
  `python -m pip install`, `mvn` अवलंबित्व समाधान).
- `translations/` किंवा `translated_images/` मध्ये पुश, विलीन किंवा सुधारणा करण्याची परवानगी नाही.
- `translated_images/` मध्येही नाही.

##### अयशस्वी होण्याचे प्रकार

- `E_NO_INPUT_PATHS`: `changed_paths` रिकामी आहे.
- `E_INVALID_PATH`: इनपुट मार्ग रिपॉजिटरीच्या मूळ बाहेर आहे.
- `E_LINT_FAILED`: मार्कडाउन लिंट नॉन-जिरो कोडानं बाहेर पडला.
- `E_LINK_AUDIT_FAILED`: लिंक ऑडिट आदेश नॉन-जिरो कोडानं बाहेर पडला.
- `E_SAMPLE_TEST_FAILED`: नमुना चाचणी/बिल्ड नॉन-जिरो कोडानं बाहेर पडला.
- `E_TIMEOUT`: आदेश पूर्ण वेळेच्या मर्यादेपेक्षा जास्त वेळ घेतला.

2. **ब्रांच तयार करा**: वर्णनात्मक ब्रांच नावे वापरा (उदा., `fix/typo-module-3`, `add/python-example`)
3. **बदल करा**: फक्त इंग्रजी मार्कडाउन फायली संपादित करा (भाषांतर नाही)
4. **स्थानिक चाचणी करा**: मार्कडाउन नीट रेंडर होते याची खात्री करा
5. **PR सबमिट करा**: स्पष्ट PR शीर्षक आणि वर्णन वापरा
6. **CLA**: विचारल्यावर Microsoft Contributor License Agreement वर सही करा

### PR शीर्षक स्वरूप

स्पष्ट, वर्णनात्मक शीर्षके वापरा:
- मॉड्यूल-विशिष्ट बदलांसाठी `[Module XX] थोडक्यात वर्णन`
- नमुना कोड बदलांसाठी `[Samples] वर्णन`
- सामान्य दस्तऐवजीकरण अद्यतनांसाठी `[Docs] वर्णन`

### काय योगदान द्यावे

- दस्तऐवजीकरण किंवा कोड नमुन्यांमधील बग दुरुस्ती
- अतिरिक्त भाषांमध्ये नवीन कोड उदाहरणे
- विद्यमान सामग्रीसाठी स्पष्टता आणि सुधारणा
- नवीन केस स्टडीज किंवा व्यावहारिक उदाहरणे
- अस्पष्ट किंवा चुकीच्या सामग्रीसाठी समस्या अहवाल
