# 🚀 10 मायक्रोसॉफ्ट MCP सर्व्हर्स जे विकासकांची उत्पादकता बदलत आहेत

## 🎯 या मार्गदर्शकात तुम्ही काय शिकाल

हा व्यावहारिक मार्गदर्शक दहा मायक्रोसॉफ्ट MCP सर्व्हर्स दर्शवितो जे सक्रियपणे कसे विकासक AI सहाय्यकांसह काम करतात यामध्ये बदल घडवत आहेत. MCP सर्व्हर्स *काय* करू शकतात हे फक्त स्पष्ट करण्याऐवजी, आम्ही तुम्हाला असे सर्व्हर्स दाखवू ज्यामुळे मायक्रोसॉफ्ट आणि त्याहून पुढील रोजच्या विकासाच्या कार्यप्रवाहांमध्ये वास्तविक फरक पडत आहे.

या मार्गदर्शकातील प्रत्येक सर्व्हर वास्तविक वापर आणि विकासकांच्या अभिप्रायावर आधारित निवडला गेला आहे. तुम्हाला फक्त प्रत्येक सर्व्हर काय करतो हेच नाही, तर ते का महत्त्वाचे आहे आणि तुमच्या प्रकल्पांमध्ये याचा कसा जास्तीत जास्त फायदा घेता येईल हे समजेल. तुम्ही MCP मध्ये पूर्णपणे नवीन असलात किंवा तुमची विद्यमान सेटअप वाढवू इच्छित असाल, हे सर्व्हर्स मायक्रोसॉफ्ट परिसंस्थेत उपलब्ध काही सर्वात व्यावहारिक आणि परिणामकारक साधने आहेत.

> **💡 जलद प्रारंभ सूचना**
>
> MCP मधील नवीन आहात का? काळजी करू नका! हा मार्गदर्शक सुरुवातीसाठी अनुकूल आहे. आम्ही पुढे जाऊन संकल्पना स्पष्ट करू आणि तुम्ही कधीही आमच्या [MCP ची ओळख](../00-Introduction/README.md) आणि [मुख्य संकल्पना](../01-CoreConcepts/README.md) मॉड्यूलवर परत जाऊ शकता अधिक सखोल पार्श्वभूमीसाठी.

## सारांश

हा सर्वसमावेशक मार्गदर्शक दहा मायक्रोसॉफ्ट MCP सर्व्हर्स तपासतो जे विकासकांच्या AI सहाय्यकांशी आणि बाह्य साधनांशी संवाद कसा करत असतील त्यामध्ये क्रांती घडवत आहेत. अ‍ॅझ्युअर संसाधन व्यवस्थापनापासून दस्तऐवज प्रक्रियेसाठी, हे सर्व्हर्स मॉडेल कॉन्टेक्स्ट प्रोटोकॉलच्या सामर्थ्याचा उपयोग करून अखंड, उत्पादक विकास कार्यप्रवाह निर्माण करतात.

## शिकण्याचे उद्दिष्टे

या मार्गदर्शकाच्या शेवटी, तुम्ही:
- MCP सर्व्हर्स कसे विकासकांची उत्पादकता वाढवतात हे समजून घ्याल
- मायक्रोसॉफ्टचे सर्वात प्रभावी MCP सर्व्हर अंमलबजावणीबद्दल जाणून घ्याल
- प्रत्येक सर्व्हरसाठी प्रायोगिक वापर प्रकरणे शोधाल
- VS कोड आणि व्हिज्युअल स्टुडिओमध्ये हे सर्व्हर्स कसे सेटअप आणि कॉन्फिगर करायचे ते शिकाल
- व्यापक MCP परिसंस्था आणि भविष्यातील दिशा यांचा अभ्यास कराल

## 🔧 MCP सर्व्हर्स समजून घेणे: नवीनांसाठी मार्गदर्शक

### MCP सर्व्हर्स म्हणजे काय?

मॉडेल कॉन्टेक्स्ट प्रोटोकॉल (MCP) मध्ये नवीन असल्यास, तुम्हाला कदाचित वाटेल: "MCP सर्व्हर म्हणजे नक्की काय आणि मला याची काळजी का घ्यायला हवी?" चला साध्या उपमा पासून सुरुवात करूया.

MCP सर्व्हर्स म्हणजे विशेष सहाय्यक जसे तुमच्या AI कोडिंग साथीदाराला (GitHub Copilot सारखा) बाह्य साधने आणि सेवा जोडण्यासाठी मदत करतात. जशाप्रकारे तुम्ही वेगवेगळ्या कामांसाठी तुमच्या फोनवर वेगवेगळ्या अ‍ॅप्स वापरता — हवामानासाठी एक, मार्गदर्शनासाठी एक, बँकिंगसाठी एक — तसेच MCP सर्व्हर्स तुमच्या AI सहाय्यकाला वेगवेगळ्या विकास साधने आणि सेवा वापरण्याची क्षमता देतात.

### MCP सर्व्हर्स कोणती समस्या सोडवतात

आधी MCP सर्व्हर्स नसताना, तुम्हाला:
- अ‍ॅझ्युअर संसाधने तपासायची असती
- GitHub मुद्दा तयार करायचा असायचा
- तुमचा डेटाबेस क्वेरी करायचा असायचा
- दस्तऐवज शोधायचा असायचा

तुम्हाला कोडिंग थांबवावे लागायचे, ब्राउझर उघडावा लागायचा, संबंधित वेबसाइटवर जावे लागायचे आणि हे सर्व काम हस्तचालित करावे लागायचे. हा सततचा संदर्भ बदल तुमच्या कामाच्या प्रवाहात अडथळा आणून उत्पादकता कमी करतो.

### MCP सर्व्हर्स तुमचा विकासाचा अनुभव कसा बदलतात

MCP सर्व्हर्ससह, तुम्ही तुमच्या विकास पर्यावरणात (VS कोड, व्हिज्युअल स्टुडिओ, इ.) राहून फक्त तुमच्या AI सहाय्याकडे हे कामे करण्यास सांगू शकता. उदाहरणादाखल:

**परंपरागत कार्यप्रवाहाऐवजी:**
1. कोडिंग थांबवा
2. ब्राउझर उघडा
3. अ‍ॅझ्युअर पोर्टलवर जा
4. स्टोरेज अकाउंट तपशील पहा
5. VS कोडवर परत या
6. कोडिंग सुरू ठेवा

**आता तुम्ही हे करू शकता:**
1. AI ला विचारा: "माझ्या अ‍ॅझ्युअर स्टोरेज अकाउंट्सची स्थिती काय आहे?"
2. दिलेल्या माहितीने कोडिंग सुरू ठेवा

### नवीनांसाठी मुख्य फायदे

#### 1. 🔄 **तुमच्या प्रवाहाच्या स्थितीत रहा**
- एकापेक्षा जास्त अ‍ॅप्लिकेशन्समध्ये स्विच करण्याची गरज नाही
- कोडिंगवर लक्ष केंद्रित ठेवा
- वेगवेगळ्या साधनांचे मानसिक ओझे कमी करा

#### 2. 🤖 **संकुचित आदेशांऐवजी नैसर्गिक भाषा वापरा**
- SQL सिंटॅक्स लक्षात ठेवण्याऐवजी तुम्हाला हवे असलेले डेटा वर्णन करा
- अ‍ॅझ्युअर CLI आदेश लक्षात ठेवण्याऐवजी तुम्ही काय साध्य करू इच्छिता ते स्पष्ट करा
- तांत्रिक तपशील AI कडे सोपा, तुम्ही लॉजिकवर लक्ष केंद्रित करा

#### 3. 🔗 **वेगवेगळ्या साधनांना एकत्र जोडा**
- वेगवेगळ्या सेवा मिसळून मजबूत कार्यप्रवाह तयार करा
- उदाहरणार्थ: "अलीकडील सर्व GitHub मुद्दे मिळवा आणि त्यास अनुरूप Azure DevOps काम वस्तू तयार करा"
- गुंतागुंतीचे स्क्रिप्ट न लिहिता ऑटोमेशन करा

#### 4. 🌐 **वाढणाऱ्या परिसंस्थेचा उपयोग करा**
- मायक्रोसॉफ्ट, GitHub, आणि इतर कंपन्यांनी तयार केलेल्या सर्व्हर्सचा फायदा घ्या
- वेगवेगळ्या विक्रेत्यांचे साधने सहज वापरा
- विविध AI सहाय्यकांसाठी बाह्य मानके स्वीकारलेल्या परिसंस्थेत सामील व्हा

#### 5. 🛠️ **करून शिकणे**
- आधी तयार केलेल्या सर्व्हर्सपासून सुरुवात करा ज्यामुळे संकल्पना समजतील
- हळूहळू स्वतःचे सर्व्हर्स तयार करा जेव्हा तुम्हाला सोय होईल
- उपलब्ध SDK आणि दस्तऐवजांचा वापर करून शिकण्यास मार्गदर्शन मिळवा

### नवीनांसाठी वास्तविक उदाहरण

समजा तुम्ही वेब विकासात नवीन आहात आणि तुमचा पहिला प्रकल्प चालवत आहात. हे MCP सर्व्हर्स कसे मदत करतात:

**परंपरागत दृष्टिकोन:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP सर्व्हर्ससह:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### उद्योग मानक फायदे

MCP एक उद्योगव्यापी मानक बनत आहे, म्हणजे:
- **सुसंगतता**: वेगवेगळ्या साधने आणि कंपन्यांमध्ये समान अनुभव
- **आंतरक्रियाशीलता**: वेगवेगळ्या विक्रेत्यांचे सर्व्हर्स एकत्र काम करतात
- **भविष्यातील सुरक्षितता**: कौशल्ये आणि सेटअप वेगवेगळ्या AI सहाय्यकांमध्ये हस्तांतरित होतात
- **समुदाय**: सामायिक ज्ञान आणि संसाधनांचा मोठा परिसंस्था

### सुरू करणे: तुम्ही काय शिकाल

या मार्गदर्शकात, आपण 10 मायक्रोसॉफ्ट MCP सर्व्हर्स तपासणार आहोत जे सर्व स्तरांवरच्या विकासकांसाठी उपयुक्त आहेत. प्रत्येक सर्व्हर डिझाइन केले आहे:
- सामान्य विकास आव्हाने सोडवण्यासाठी
- पुनरावृत्ती होणार्‍या कामे कमी करण्यासाठी
- कोड गुणवत्ता सुधारण्यासाठी
- शिकण्याच्या संधी वाढवण्यासाठी

## VS कोड आणि व्हिज्युअल स्टुडिओमध्ये MCP सह सुरू करणे 🚀

व्हिज्युअल स्टुडिओ कोड किंवा व्हिज्युअल स्टुडिओ 2022 GitHub Copilot सह वापरत असल्यास हे MCP सर्व्हर्स सेट करणे सोपे आहे.

### VS कोड सेटअप

VS कोडसाठी मूलभूत प्रक्रिया:

1. **एजंट मोड सक्षम करा**: VS कोड मध्ये, Copilot Chat विंडोत एजंट मोड वर स्विच करा
2. **MCP सर्व्हर्स कॉन्फिगर करा**: तुमच्या VS कोड च्या settings.json फाईलमध्ये सर्व्हर कॉन्फिगरेशन जोडा
3. **सर्व्हर्स सुरू करा**: प्रत्येक वापरायच्या सर्व्हरसाठी "Start" बटण क्लिक करा
4. **साधने निवडा**: सध्याच्या सत्रासाठी कोणती MCP सर्व्हर्स सक्षम करायची ते निवडा

विस्तृत सेटअप सूचना साठी, [VS कोड MCP दस्तऐवज](https://code.visualstudio.com/docs/copilot/copilot-mcp) पहा.

> **💡 व्यावसायिक सूचना: MCP सर्व्हर्स व्यावसायिकांसारखे व्यवस्थापित करा!**
>
> VS कोड विस्तार विंडो आता [स्थापित MCP सर्व्हर्स व्यवस्थापित करण्यासाठी नवीन UI](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode) समाविष्ट करते! तुम्हाला कोणत्याही MCP सर्व्हरची सुरुवात, थांबवणं, आणि व्यवस्थापन करण्यासाठी जलद आणि सोपी इंटरफेस मिळते. ताबडतोब वापरून पहा!

### व्हिज्युअल स्टुडिओ 2022 सेटअप

व्हिज्युअल स्टुडिओ 2022 (आवृत्ती 17.14 किंवा नंतर) साठी:

1. **एजंट मोड सक्षम करा**: GitHub Copilot Chat विंडो मधील "Ask" ड्रॉपडाउन क्लिक करा आणि "Agent" निवडा
2. **कॉन्फिगरेशन फाईल तयार करा**: तुमच्या सोल्युशन डायरेक्टरीमध्ये `.mcp.json` फाईल तयार करा (शिफारसीत स्थान: `<SOLUTIONDIR>\.mcp.json`)
3. **सर्व्हर्स कॉन्फिगर करा**: प्रमाणभूत MCP फॉरमॅट वापरून तुमचे MCP सर्व्हर कॉन्फिगरेशन जोडा
4. **साधन मंजुरी**: जेव्हा विचारले जाईल तेव्हा योग्य स्कोप परवानग्यासह वापरायच्या साधनांना मान्यता द्या

विस्तृत व्हिज्युअल स्टुडिओ सेटअप सूचना साठी, [व्हिज्युअल स्टुडिओ MCP दस्तऐवज](https://learn.microsoft.com/visualstudio/ide/mcp-servers) पहा.

प्रत्येक MCP सर्व्हर आपल्या स्वतःच्या कॉन्फिगरेशन आवश्यकता (कनेक्शन स्ट्रींग्ज, प्रमाणीकरण, इ.) सह येतो, पण सेटअप पद्धती दोन्ही IDE मध्ये सुसंगत आहेत.

**हे काय करतं**: मायक्रोसॉफ्ट Learn Docs MCP Server हा क्लाउड-होस्टेड सेवा आहे जी AI सहाय्यकांना Real-time Microsoft अधिकृत दस्तऐवजांमध्ये मॉडेल कॉन्टेक्स्ट प्रोटोकॉलद्वारे प्रवेश देते. हे `https://learn.microsoft.com/api/mcp` शी जोडते आणि मायक्रोसॉफ्ट Learn, अ‍ॅझ्युअर दस्तऐवज, मायक्रोसॉफ्ट 365 दस्तऐवज आणि इतर अधिकृत मायक्रोसॉफ्ट स्रोतांमध्ये सैमँटिक शोध सक्षम करते.

**हे उपयोगी का आहे**: "फक्त दस्तऐवज" सारखे वाटले तरी, हा सर्व्हर प्रत्येक मायक्रोसॉफ्ट तंत्रज्ञान वापरणाऱ्या विकासकांसाठी अत्यंत महत्त्वाचा आहे. .NET विकासकांकडून AI कोडिंग सहाय्यकांबद्दल सर्वात मोठी तक्रार म्हणजे त्यांना नवीनतम .NET आणि C# रिलीजांबद्दल अद्ययावत माहिती नाही. मायक्रोसॉफ्ट Learn Docs MCP Server हे समस्या सोडवते कारण ते सर्वात अद्ययावत दस्तऐवज, API संदर्भ, आणि सर्वोत्तम सराव तत्काळ प्रदान करते. तुम्ही नवीनतम अ‍ॅझ्युअर SDKs वापरत असाल, नवीन C# 13 वैशिष्ट्ये पाहत असाल किंवा कटर-एज Aspire पॅटर्न्स अंमलात आणत असाल, हा सर्व्हर तुमच्या AI सहाय्यकाला अधिकारप्राप्त, अद्ययावत माहिती मिळवून अचूक, आधुनिक कोड निर्माण करत ठेवतो.

**वास्तविक वापर**: "अधिकारिक Microsoft Learn दस्तऐवजांनुसार Azure कंटेनर अ‍ॅप तयार करण्यासाठी az cli आदेश काय आहेत?" किंवा "ASP.NET Core मध्ये डेटावेससह Entity Framework कसे कॉन्फिगर करायचे?" किंवा "हा कोड Microsoft Learn Documents मधील परफॉर्मन्स शिफारसींशी सुसंगत आहे का तपासा." हा सर्व्हर मायक्रोसॉफ्ट Learn, अ‍ॅझ्युअर डॉक्युमेंट्स आणि मायक्रोसॉफ्ट 365 दस्तऐवजांमध्ये प्रगत सैमँटिक शोध वापरून अत्यंत संदर्भसापेक्ष माहिती प्रदान करतो. हा संबंधित उच्च-गुणवत्तेच्या 10 कंटेंट चंकसह लेख शीर्षक आणि URLs परत देतो, सदैव नवीनतम दस्तऐवज प्रवेश करतो जसे ते प्रकाशित होतात.

**विशेष उदाहरण**: हा सर्व्हर `microsoft_docs_search` साधन प्रदर्शित करतो जे अधिकृत टेक्निकल दस्तऐवजांवर सैमँटिक शोध करतो. कॉन्फिगर केल्यावर, तुम्ही प्रश्न विचारू शकता "ASP.NET Core मध्ये JWT प्रमाणीकरण कसे अंमलात आणायचे?" आणि मूळ दुवाांसह सविस्तर अधिकृत उत्तरे मिळवा. शोधाचे गुणवत्ता उत्कृष्ट आहे कारण तो संदर्भ समजतो – उदाहरणार्थ Azure संदर्भातील "containers" विचारल्यावर Azure Container Instances दस्तऐवज परत करतो, आणि .NET संदर्भातील समान शब्दासाठी संबंधित C# संग्रह माहिती परत करतो.

हे विशेषतः जलद बदलणाऱ्या किंवा अलीकडे अद्ययावत झालेल्या लायब्ररीसाठी उपयुक्त आहे. उदाहरणार्थ, माझ्या काही अलीकडील कोडिंग प्रकल्पांमध्ये मला Aspire आणि Microsoft.Extensions.AI च्या नवीनतम रेलेझमधील वैशिष्ट्यांचा वापर करायचा होता. मायक्रोसॉफ्ट Learn Docs MCP सर्व्हरचा समावेश करून, मला केवळ API दस्तऐवज नव्हे तर नुकतेच प्रसिद्ध झालेले मार्गदर्शक आणि शिकवण मिळाली.

### 2. ☁️ अ‍ॅझ्युअर MCP सर्व्हर


[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**याचा उपयोग काय आहे**: Azure MCP Server हा 15+ विशेषीकृत Azure सेवा कनेक्टर्सचा एक व्यापक संच आहे जो संपूर्ण Azure परिसंस्थेला तुमच्या AI कार्यप्रवाहात आणतो. हा फक्त एकच सर्व्हर नाही - हा एक सामर्थ्यशाली संकलन आहे ज्यात संसाधन व्यवस्थापन, डेटाबेस कनेक्टिव्हिटी (PostgreSQL, SQL Server), KQL सह Azure Monitor लॉग विश्लेषण, Cosmos DB एकत्रीकरण आणि बरेच काही समाविष्ट आहे.

**हे उपयोगी का आहे**: Azure संसाधने व्यवस्थापित करण्याबरोबरच, हा सर्व्हर Azure SDKs सह काम करताना कोडची गुणवत्ता नाटकीय पद्धतीने सुधारतो. जेव्हा तुम्ही Azure MCP Agent मोडमध्ये वापरता, तेव्हा तो फक्त कोड लिहिण्यात मदत करत नाही - तो तुम्हाला *चांगला* Azure कोड लिहिण्यात मदत करतो जो सध्याच्या प्रमाणीकरण पद्धती, त्रुटी हाताळणी सर्वोत्तम पद्धती आणि नवीनतम SDK वैशिष्ट्यांचा वापर करतो. सामान्य कोड मिळण्याऐवजी जो कदाचित काम करेल, तुम्हालाAzure च्या उत्पादन कार्यभारासाठी शिफारस केलेल्या पद्धतींचे पालन करणारा कोड मिळतो.

**मुख्य मॉड्यूल्समध्ये समाविष्ट आहेत**:
- **🗄️ डेटाबेस कनेक्टर्स**: Azure Database for PostgreSQL आणि SQL Server साठी थेट नैसर्गिक भाषा प्रवेश
- **📊 Azure Monitor**: KQL-चालित लॉग विश्लेषण आणि ऑपरेशनल अंतर्दृष्टी
- **🌐 संसाधन व्यवस्थापन**: संपूर्ण Azure संसाधन जीवनचक्र व्यवस्थापन
- **🔐 प्रमाणीकरण**: DefaultAzureCredential आणि व्यवस्थापित ओळखीच्या पद्धती
- **📦 संग्रहण सेवा**: Blob Storage, Queue Storage, आणि Table Storage कार्य
- **🚀 कंटेनर सेवा**: Azure Container Apps, Container Instances, आणि AKS व्यवस्थापन
- **आणि बरेच काही विशेषीकृत कनेक्टर्स**

**प्रत्यक्ष वापर**: "माझे Azure संग्रहण खाते सूचीबद्ध करा", "माझ्या Log Analytics कार्यक्षेत्रातील गेल्या तासातील त्रुटी चौकशी करा", किंवा "योग्य प्रमाणीकरणासह Node.js वापरून Azure अॅप्लिकेशन तयार करण्यात मदत करा"

**पूर्ण डेमो परिस्थिती**: येथे एक संपूर्ण वॉकथ्रू दिला आहे जो VS Code मधील GitHub Copilot for Azure विस्तारासोबत Azure MCP च्या संयोजनाची शक्ती दाखवतो. जेव्हा तुम्ही दोन्ही स्थापित करता आणि पुढील आज्ञा देता:

> "DefaultAzureCredential प्रमाणीकरण वापरून Azure Blob Storage मध्ये फाइल अपलोड करणारा Python स्क्रिप्ट तयार करा. स्क्रिप्टने माझ्या 'mycompanystorage' नावाचा Azure संग्रहण खात्याशी कनेक्ट करावा, 'documents' नावाच्या कंटेनरमध्ये अपलोड करावे, सध्याच्या timestamp सह एक चाचणी फाइल तयार करावी, त्रुटी सौम्यतेने हाताळाव्यात आणि माहितीपूर्ण आउटपुट द्यावे, प्रमाणीकरण आणि त्रुटी हाताळणीसाठी Azure सर्वोत्तम पद्धतींचे पालन करावे, DefaultAzureCredential प्रमाणीकरण कसे कार्य करते याचे स्पष्टीकरण देणारी टिप्पण्या असाव्यात, आणि स्क्रिप्ट योग्य प्रकारे रचलेली असून योग्य फंक्शन्स आणि दस्तऐवजीकरण असावे."

Azure MCP Server पूर्ण, उत्पादन-तयार Python स्क्रिप्ट तयार करेल जी:
- योग्य async पद्धतींसह नवीनतम Azure Blob Storage SDK वापरते
- DefaultAzureCredential ची अंमलबजावणी करतो ज्यात सर्वसमावेशक फॉलबॅक चेन स्पष्टीकरण आहे
- विशिष्ट Azure अपवाद प्रकारांसह मजबूत त्रुटी हाताळणी समाविष्ट करते
- संसाधन व्यवस्थापन आणि कनेक्शन हँडलिंगसाठी Azure SDK सर्वोत्तम पद्धतींचे पालन करतो
- तपशीलवार लॉगिंग आणि माहितीपूर्ण कन्सोल आउटपुट प्रदान करतो
- फंक्शन्स, दस्तऐवजीकरण, आणि प्रकार संकेतांसह योग्य प्रकारे रचित स्क्रिप्ट तयार करतो

हे लक्षात घेण्यासारखे कारण म्हणजे Azure MCP शिवाय तुम्हाला सामान्य ब्लॉब स्टोरेज कोड मिळू शकतो जो कार्य करेल पण सध्याच्या Azure पद्धतींचे पालन करत नाही. Azure MCP सह, तुम्हाला कोड मिळतो जो नवीनतम प्रमाणीकरण पद्धती वापरतो, Azure-विशिष्ट त्रुटी परिस्थिती हाताळतो आणि मायक्रोसॉफ्टच्या उत्पादन अनुप्रयोगांसाठी शिफारस केलेल्या पद्धतींचे पालन करतो.

**वैशिष्ट्यीकृत उदाहरण**: मला `az` आणि `azd` CLI च्या विशिष्ट आदेश आठवणीत ठेवण्यासाठी त्रास झाला आहे. माझ्यासाठी हे नेहमी दोन टप्प्यांचे काम असते: प्रथम सिंटॅक्स शोधणे, नंतर कमांड चालवणे. मी अनेकदा पोर्टलमध्ये जाऊन फक्त कार्य करण्यासाठी क्लिक करतो कारण मला मान्य करायचे नाही की मला CLI सिंटॅक्स आठवत नाही. जे मला हवा आहे ते फक्त वर्णन करू शकणे आश्चर्यकारक आहे, आणि माझ्या IDE सोडता न देता ते करू शकणे अजूनच छान आहे!

सुरुवात करण्यासाठी [Azure MCP repository](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) येथे वापराच्या उत्तम प्रकरणांची यादी आहे. संपूर्ण सेटअप मार्गदर्शकांसाठी आणि प्रगत कॉन्फिगरेशन पर्यायांसाठी, [अधिकृत Azure MCP दस्तऐवज](https://learn.microsoft.com/azure/developer/azure-mcp-server/) तपासा.

**याचा उपयोग काय आहे**: अधिकृत GitHub MCP Server GitHub च्या संपूर्ण परिसंस्थेसह सुलभ एकत्रीकरण प्रदान करतो, ज्यामध्ये होस्टेड रिमोट प्रवेश आणि स्थानिक डॉकटर तैनाती पर्याय दिले आहेत. हे फक्त मूलभूत रिपॉझिटरी ऑपरेशन्ससाठी नाही – ते एक सर्वसमावेशक टूलकिट आहे ज्यामध्ये GitHub Actions व्यवस्थापन, पुल रिक्वेस्ट वर्कफ्लोज, समस्या ट्रॅकिंग, सुरक्षा स्कॅनिंग, सूचना आणि प्रगत ऑटोमेशन क्षमता आहेत.

**हे उपयोगी का आहे**: हा सर्व्हर तुमच्या विकास वातावरणात संपूर्ण GitHub प्लॅटफॉर्मचा अनुभव आणून GitHub सह तुमचे संवाद कसे बदलतो. प्रोजेक्ट व्यवस्थापन, कोड समीक्षा आणि CI/CD मॉनिटरिंग करासाठी सतत VS Code आणि GitHub.com दरम्यान स्विच करण्याऐवजी, तुम्ही नैसर्गिक भाषा आदेशांद्वारे सर्व काही हाताळू शकता आणि कोडवर लक्ष केंद्रित करू शकता.

> **ℹ️ टीप: 'एजंट्स' चे वेगळे प्रकार**
> 
> अधिकृत GitHub MCP सर्व्हरला GitHub च्या Coding Agent शी गोंधळू नका (जो AI एजंट आहे ज्याला तुम्ही प्रकरणांसाठी स्वयंचलित कोडिंग कार्यांसाठी नियुक्त करू शकता). GitHub MCP Server VS Code च्या Agent मोडमध्ये GitHub API एकात्मिकरण प्रदान करतो, तर GitHub चा Coding Agent वेगळे वैशिष्ट्य आहे जे GitHub प्रकरणांसाठी नियुक्त केल्यावर पुल रिक्वेस्ट तयार करते.

**मुख्य क्षमता समाविष्ट आहेत**:
- **⚙️ GitHub Actions**: पूर्ण CI/CD पाइपलाइन व्यवस्थापन, वर्कफ्लो निरीक्षण, आणि आर्टिफॅक्ट हँडलिंग
- **🔀 पुल रिक्वेस्ट्स**: PR तयार करा, पुनरावलोकन करा, मर्ज करा, आणि कॉम्प्रीहेंसिव्ह स्थिती ट्रॅकिंगसह व्यवस्थापित करा
- **🐛 प्रकरणे**: पूर्ण प्रकरण जीवनचक्र व्यवस्थापन, टिप्पणी करणे, लेबल करणे, आणि नियुक्ती
- **🔒 सुरक्षा**: कोड स्कॅनिंग अलर्ट, गुप्त शोध, आणि Dependabot एकत्रीकरण
- **🔔 सूचना**: स्मार्ट सूचना व्यवस्थापन आणि रिपॉझिटरी सदस्यता नियंत्रण
- **📁 रिपॉझिटरी व्यवस्थापन**: फाइल ऑपरेशन्स, ब्रांच व्यवस्थापन, आणि रिपॉझिटरी प्रशासन
- **👥 सहयोग**: वापरकर्ता आणि संघटना शोध, संघ व्यवस्थापन, आणि प्रवेश नियंत्रण

**प्रत्यक्ष वापर**: "माझ्या फिचर ब्रांचमधून पुल रिक्वेस्ट तयार करा", "मला या आठवड्यातील सर्व अपयशी CI runs दाखवा", "माझ्या रिपॉझिटरीजसाठी उघडलेले सर्व सुरक्षा अलर्ट सूचीबद्ध करा", किंवा "माझ्या संघटना मध्ये मला नियुक्त केलेली सर्व मुद्दे शोधा"

**पूर्ण डेमो परिस्थिती**: येथे GitHub MCP Server च्या क्षमतांचा दाखला देणारा एक प्रभावी वर्कफ्लो दिला आहे:

> "मला आमच्या स्प्रिंट पुनरावलोकनासाठी तयार होण्याची गरज आहे. मला या आठवड्यात मी तयार केलेल्या सर्व पुल रिक्वेस्ट दाखवा, आमच्या CI/CD पाइपलाइनच्या स्थितीची तपासणी करा, कोणत्याही सुरक्षा अलर्टचा सारांश तयार करा ज्यावर लक्ष देणे आवश्यक आहे, आणि मर्ज झालेल्या PRs सह 'फिचर' लेबल असलेल्या आधारित प्रकाशन नोट्स तयार करण्यात मदत करा."

GitHub MCP Server:
- तपशीलवार स्थिती माहिती सह तुमच्या अलीकडील पुल रिक्वेस्ट्सची चौकशी करेल
- वर्कफ्लो रनचे विश्लेषण करेल आणि कोणतीही अपयशे किंवा कामगिरी समस्या हायलाइट करेल
- सुरक्षा स्कॅनिंग निकाल संकलित करेल आणि महत्त्वाच्या अलर्ट्स प्राधान्याने हाताळेल
- मर्ज झालेले PR मधून माहिती काढून व्यापक प्रकाशन नोट्स तयार करेल
- स्प्रिंट नियोजन आणि प्रकाशन तयारीसाठी कृतीयोग्य पुढील टप्पे प्रदान करेल

**वैशिष्ट्यीकृत उदाहरण**: मला हे कोड पुनरावलोकन वर्कफ्लोजसाठी वापरणे आवडते. VS Code, GitHub सूचना, आणि पुल रिक्वेस्ट पृष्ठे दरम्यान उडी मारण्याऐवजी, मी "माझ्या पुनरावलोकनासाठी वाट पहात असलेल्या सर्व PRs दाखवा" म्हणू शकतो आणि नंतर "PR #123 मध्ये प्रमाणीकरण पद्धतीतील त्रुटी हाताळणीबद्दल टिप्पणी जोड़ा." सर्व्हर GitHub API कॉल्स हाताळतो, चर्चेचा संदर्भ राखतो, आणि मला अधिक रचनात्मक पुनरावलोकन टिप्पण्या तयार करण्यातदेखील मदत करतो.

**प्रमाणीकरण पर्याय**: सर्व्हरमध्ये OAuth (VS Code मध्ये सहजतेने) आणि वैयक्तिक प्रवेश टोकन दोन्ही समर्थन आहेत, तसेच केवळ आवश्यक GitHub कार्यक्षमतेसाठी कॉन्फिगर करण्यायोग्य टूलसेट्स आहेत. तुम्ही ते रिमोट होस्टेड सेवा म्हणून त्वरीत सेटअपसाठी चालवू शकता किंवा पूर्ण नियंत्रणासाठी स्थानिक डॉकटरमार्फत चालवू शकता.

> **💡 प्रो टिप**
> 
> तुमच्या MCP सर्व्हर सेटिंग्जमध्ये `--toolsets` पॅरामीटर कॉन्फिगर करून तुम्हाला फक्त आवश्यक असलेले टूलसेट सक्षम करा, ज्यामुळे संदर्भाचा आकार कमी होतो आणि AI टूल निवड सुधारते. उदाहरणार्थ, कोर विकास वर्कफ्लोजसाठी `"--toolsets", "repos,issues,pull_requests,actions"` तुमच्या MCP कॉन्फिगरेशन args मध्ये जोडा, किंवा जर तुम्हाला प्रामुख्याने GitHub मॉनिटरिंग क्षमता हवी असेल तर `"--toolsets", "notifications, security"` वापरा.

### 5. 📝 MarkItDown MCP Server


[![VS Code मध्ये स्थापित करा](https://img.shields.io/badge/VS_Code-Install_MarkItDown_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D) [![VS Code Insiders मध्ये स्थापित करा](https://img.shields.io/badge/VS_Code_Insiders-Install_MarkItDown_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/markitdown)

**यामुळे काय होते**: MarkItDown हा एक सर्वसमावेशक दस्तऐवज रूपांतरित करणारा सर्व्हर आहे जो विविध फाइल स्वरूपांना उच्च-गुणवत्तेच्या Markdown मध्ये रूपांतरित करतो, जो LLM वापरासाठी आणि मजकूर विश्लेषण कार्यप्रवाहांसाठी अनुकूलित केलेला आहे.

**हे फायदेशीर का आहे**: आधुनिक दस्तऐवज कार्यप्रवाहांसाठी अत्यावश्यक! MarkItDown अनेक फाइल स्वरूपांचे समर्थित करत असताना महत्त्वपूर्ण दस्तऐवज रचना जसे की शीर्षके, यादी, तक्ते, आणि दुवे जपतो. सोप्या मजकूर काढण्याच्या साधनांच्या विपरीत, हे संमितार्थाचा अर्थ आणि स्वरूप जपण्यावर लक्ष केंद्रित करते जे AI प्रक्रियेसाठी आणि मानवी वाचनासाठी उपयुक्त आहे.

**समर्थित फाइल स्वरूप**:
- **ऑफिस दस्तऐवज**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **मिडिया फाइल्स**: प्रतिमा (EXIF मेटाडेटा आणि OCR सह), ऑडिओ (EXIF मेटाडेटा आणि भाषांतरासह)
- **वेब सामग्री**: HTML, RSS फीड्स, YouTube URLs, विकिपीडिया पृष्ठे
- **डेटा स्वरूप**: CSV, JSON, XML, ZIP फाइल्स (सामग्री पुनरावृत्तीपूर्वक प्रक्रिया करते)
- **प्रकाशन स्वरूप**: EPub, Jupyter नोटबुक (.ipynb)
- **ईमेल**: Outlook संदेश (.msg)
- **प्रगत**: Azure Document Intelligence सह एकत्रीकरणासाठी सुधारित PDF प्रक्रिया

**प्रगत कार्यक्षमता**: MarkItDown हे LLM-शक्तीप्राप्त प्रतिमा वर्णने समर्थन करते (जेव्हा OpenAI क्लायंट दिलेला असतो), Azure Document Intelligence द्वारे सुधारित PDF प्रक्रिया, भाषण सामग्रीसाठी ऑडिओ ट्रान्सक्रिप्शन आणि अतिरिक्त फाइल स्वरूपांसाठी विस्तारित करण्यासाठी प्लगइन प्रणाली देते.

**वास्तविक वापर**: "हा PowerPoint सादरीकरण Markdown मध्ये रूपांतरित करा आमच्या दस्तऐवज साइटसाठी", "या PDF मधून योग्य शीर्षक रचना असलेला मजकूर काढा", किंवा "हा Excel स्प्रेडशीट वाचण्यायोग्य तक्ता स्वरूपात रूपांतरित करा"

**वैशिष्ट्यीकृत उदाहरण**: [MarkItDown docs](https://github.com/microsoft/markitdown#why-markdown) चे उद्धरण देण्यासाठी:

> Markdown मुख्यत: सामान्य मजकूरासारखा असतो, ज्यामध्ये कमी मार्कअप किंवा स्वरूपन असते, पण तरीही महत्त्वपूर्ण दस्तऐवज रचना दर्शवण्याचा मार्ग प्रदान करतो. सामान्यतः LLMs, जसे OpenAI चे GPT-4o, नैसर्गिकरित्या Markdown "बोलतात," आणि बर्‍याचदा त्यांच्या प्रतिसादांमध्ये Markdown अप्रत्यक्षपणे समाविष्ट करतात. याचा अर्थ असा की त्यांना Markdown-रूपांतरित केलेल्या मोठ्या प्रमाणातील मजकूरावर प्रशिक्षित केले गेले आहे आणि ते त्यास चांगले समजतात. एक उपयुक्त लाभ म्हणजे, Markdown च्या परंपरा देखील अत्यंत टोकन-कार्यक्षम आहेत.

MarkItDown दस्तऐवज रचना नीट जपतो, जी AI कार्यप्रवाहांसाठी महत्त्वाची आहे. उदाहरणार्थ, PowerPoint सादरीकरण रूपांतरित करताना, ते स्लाइडचे आयोजन योग्य शीर्षकांसह जपतो, तक्ते Markdown तक्त्यांमध्ये काढते, प्रतिमांसाठी alt मजकूर समाविष्ट करते आणि वक्ता नोट्स देखील प्रक्रिया करते. चार्ट्स वाचण्यायोग्य डेटाटेबल्समध्ये रूपांतरित होतात, आणि परिणामी Markdown मूळ सादरीकरणाचा तार्किक प्रवाह राखतो. हे सादरीकरण सामग्री AI प्रणालींमध्ये वापरण्यासाठी किंवा विद्यमान स्लाइड्समधून दस्तऐवज तयार करण्यासाठी परिपूर्ण बनवते.

- **⚡ AI एजंट समाकलन**: Azure AI एजंट्सशी कनेक्ट व्हा, विद्यमान एजंट्स चौकशी करा, आणि उत्पादन परिस्थितीत एजंट कामगिरीचे मूल्यमापन करा
- **📊 मूल्यमापन चौकट**: व्यापक मजकूर आणि एजंट मूल्यमापन चालवा, मार्कडाउन अहवाल तयार करा, आणि AI अनुप्रयोगांसाठी गुणवत्ता आश्वासन राबवा
- **🚀 प्रोटोटायपिंग साधने**: GitHub-आधारित प्रोटोटायपिंगसाठी सेटअप सूचना मिळवा आणि Microsoft Foundry Labs मधील अत्याधुनिक संशोधन मॉडेल्स वापरा

**प्रत्यक्ष जगातील विकासक वापर**: "माझ्या अनुप्रयोगासाठी Azure AI सेवांवर Phi-4 मॉडेल डिप्लॉय करा", "माझ्या दस्तऐवज RAG सिस्टीमसाठी नवीन सर्च अनुक्रमणिका तयार करा", "माझ्या एजंटच्या प्रतिसादांचे गुणवत्ता निकषांशी मूल्यमापन करा", किंवा "माझ्या गुंतागुंतीच्या विश्लेषण कार्यांसाठी सर्वोत्तम कारणीभूत मॉडेल शोधा"

**पूर्ण डेमो परिदृश्य**: येथे एक प्रभावी AI विकास कार्यप्रवाह आहे:

> "मी एक ग्राहक समर्थन एजंट तयार करत आहे. कॅटलॉगमधून चांगला कारणीभूत मॉडेल शोधण्यास मदत करा, त्याला Azure AI सेवांवर डिप्लॉय करा, आमच्या दस्तऐवजांमधून ज्ञान आधार तयार करा, प्रतिसाद गुणवत्तेची चाचणी करण्यासाठी मूल्यांकन चौकट सेट करा, आणि नंतर GitHub टोकनसह चाचणीसाठी समाकलन प्रोटोटाइप करण्यात मदत करा."

Microsoft Foundry MCP Server हे करेल:
- तुमच्या गरजांवर आधारित सर्वोत्तम कारणीभूत मॉडेल शिफारस करण्यासाठी मॉडेल कॅटलॉगची चौकशी करा
- तुमच्या प्राधान्य सेवा Azure प्रदेशासाठी डिप्लॉयमेंट आदेश आणि कोटाची माहिती द्या
- तुमच्या दस्तऐवजांसाठी योग्य स्कीमासह Azure AI Search अनुक्रमणिका सेट करा
- गुणवत्ता निकष आणि सुरक्षा तपासणींसह मूल्यांकन पाइपलाईन्स कॉन्फिगर करा
- त्वरित चाचणीसाठी GitHub प्रमाणीकरणासह प्रोटोटायपिंग कोड तयार करा
- तुमच्या विशिष्ट तंत्रज्ञान स्टॅकसाठी सविस्तर सेटअप मार्गदर्शक द्या

**विशेष उदाहरण**: विकसक म्हणून, मला विविध LLM मॉडेल्ससह सामना करणे आव्हानात्मक वाटले. मी काही मुख्य मॉडेल्स ओळखतो, पण काही उत्पादकता आणि कार्यक्षमता वाढीपासून वंचित असल्यासारखे वाटत होते. टोकन्स आणि कोटांसाठी ताण आणि व्यवस्थापन कठीण होते – मला नेहमी खात्री नसते की योग्य कार्यासाठी योग्य मॉडेल निवडतोय की माझा बजेट अकार्यक्षमपणे खर्च होत आहे. जेव्हा मी या पोस्टसाठी MCP सर्व्हरच्या शिफारसींसाठी सहकाऱ्यांशी बोलत होतो तेव्हा जेम्स मोंटेमॅग्नो यांच्याकडून मला हा MCP सर्व्हर कळाला आणि मला तो वापरायला उत्सुकता वाटते! मॉडेल शोधण्याच्या क्षमतेबाबत विशेषतः आकर्षक वाटते, ज्यामुळे मी पारंपारिक मॉडेल्सपेक्षा वेगळे आणि विशिष्ट कार्यांसाठी ऑप्टिमाइझ्ड मॉडेल्स शोधू शकतो. मूल्यांकन चौकट मला खरोखर चांगले परिणाम मिळत आहेत का ते पडताळण्यास मदत करेल, फक्त काही नवीन करण्यासाठी नव्हे.

> **ℹ️ प्रयोगात्मक स्थिती**
> 
> हा MCP सर्व्हर प्रयोगात्मक असून सक्रिय विकासात आहे. वैशिष्ट्ये आणि API बदलू शकतात. Azure AI क्षमतांचा शोध घेण्यासाठी आणि प्रोटोटाइप तयार करण्यासाठी उत्तम, पण उत्पादन वापरासाठी स्थिरता आवश्यकतांचे परीक्षण करा.
### 10. 🏢 Microsoft 365 एजंट्स टूलकिट MCP सर्व्हर

**हे काय करते**: Microsoft 365 आणि Microsoft 365 Copilot शी समाकलित होणाऱ्या AI एजंट्स आणि अनुप्रयोगांसाठी आवश्यक टूल्स विकसकांसाठी पुरवते, ज्यात स्कीमा पडताळणी, नमुना कोड मिळवणे आणि त्रुटी निराकरण सहाय्य यांचा समावेश आहे.

**ते का उपयुक्त आहे**: Microsoft 365 आणि Copilot साठी विकसित करताना गुंतागुंतीच्या मॅनिफेस्ट स्कीमाही आणि विशिष्ट विकास नमुने लागतात. हा MCP सर्व्हर आवश्यक विकास संसाधने थेट तुमच्या कोडिंग वातावरणात आणतो, ज्यामुळे तुम्ही स्कीमा पडताळणी करू शकता, नमुना कोड शोधू शकता, आणि सामान्य त्रुटी निराकरण करू शकता, दस्तऐवज सतत पाहण्याची गरज नाही.

**प्रत्यक्ष वापर**: "माझा घोषणात्मक एजंट मॅनिफेस्ट पडताळा आणि स्कीमा त्रुटी दुरुस्त करा", "Microsoft Graph API प्लगिन अंमलात आणण्यासाठी नमुना कोड दाखवा", किंवा "माझ्या Teams अॅप प्रमाणीकृत समस्यांचे निराकरण करण्यात मदत करा"

**विशेष उदाहरण**: मला मोजणी करत असताना माझ्या मित्र जॉन मिलरशी संपर्क साधला, त्याने या MCP ची शिफारस केली. हे M365 एजंट्ससाठी नवीन असलेल्या विकासकांसाठी उत्तम ठरू शकते कारण ते टेम्प्लेट, नमुना कोड, आणि स्कॅफोल्डिंग पुरवते ज्यामुळे सुरुवात करणे सोपे होते आणि जास्त दस्तऐवजांमध्ये डुबर होण्याची गरज पडत नाही. स्कीमा पडताळणी वैशिष्ट्ये विशेषतः उपयोगी वाटतात कारण मॅनिफेस्ट संरचनेतील चुका दूर करण्यासाठी तासोंचा डिबगिंग टाळला जाऊ शकतो.

> **💡 प्रो टीप**

> व्यापक M365 विकास समर्थनासाठी या सर्व्हरचा वापर Microsoft Learn Docs MCP Server सोबत करा – एक अधिकृत दस्तऐवज पुरवितो तर दुसरा व्यावहारिक विकास साधने आणि त्रुटी निराकरण सहाय्य पुरवितो.


## पुढे काय? 🔮

## 📋 निष्कर्ष

मॉडेल कॉन्टेक्स्ट प्रोटोकॉल (MCP) विकसकांशी AI सहाय्यक आणि बाह्य साधने यांच्यातील संवाद कसा होतो ते बदलत आहे. हे 10 Microsoft MCP सर्व्हर मानकीकृत AI समाकलनाची ताकद दाखवतात, ज्यामुळे सामंजस्यपूर्ण कार्यप्रवाह निर्माण होतात जे विकसकांना त्यांचे काम सुरू ठेवण्यास आणि शक्तिशाली बाह्य क्षमता वापरण्यास मदत करतात.

व्यापक Azure पर्यावरण समाकलनापासून ते Playwright सारख्या ब्राउझर स्वयंचलन आणि MarkItDown सारख्या दस्तऐवज प्रक्रियेतील विशेष साधनांपर्यंत, हे सर्व्हर विविध विकास परिस्थितींमध्ये उत्पादकता कशी वाढवू शकतात हे दर्शवतात. मानकीकृत प्रोटोकॉल यामुळे ही साधने एकत्र सुसंवादाने काम करतात, एकसंध विकास अनुभव तयार करतात.

MCP पर्यावरण जसे विकसित होत आहे, समुदायाशी सक्रिय राहणे, नवीन सर्व्हर शोधणे, आणि सानुकूल सोल्यूशन्स तयार करणे हे तुमच्या विकास उत्पादकतेसाठी महत्त्वाचे असेल. MCP चा खुला मानक असल्याने तुम्ही विविध विक्रेते यांचे साधने एकत्र वापरून तुमच्या विशेष गरजांसाठी परिपूर्ण कार्यप्रवाह तयार करू शकता.
