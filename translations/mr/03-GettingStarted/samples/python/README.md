# MCP कॅल्क्युलेटर सर्व्हर (Python)



Python मध्ये एक साधे Model Context Protocol (MCP) सर्व्हर इम्प्लिमेंटेशन जे मूलभूत कॅल्क्युलेटर कार्यक्षमता प्रदान करते.


## इन्स्टॉलेशन

आवश्यक डिपेंडन्सीज इन्स्टॉल करा:

```bash
pip install -r requirements.txt
```

किंवा थेट MCP Python SDK इन्स्टॉल करा:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## वापर

### सर्व्हर चालू करणे

सर्व्हर MCP क्लायंट्स (जसे की Claude Desktop) द्वारे वापरण्यासाठी डिझाइन केलेले आहे. सर्व्हर चालू करण्यासाठी:

```bash
python mcp_calculator_server.py
```

**सूचना**: थेट टर्मिनलमध्ये चालवल्यावर, तुम्हाला JSON-RPC व्हॅलिडेशन एरर्स दिसतील. हे सामान्य वर्तन आहे - सर्व्हर योग्यरित्या फॉरमॅट केलेल्या MCP क्लायंट मेसेजेसची वाट पाहत आहे.

### फंक्शन्सची चाचणी घेणे

कॅल्क्युलेटर फंक्शन्स बरोबर काम करतात का हे तपासण्यासाठी:

```bash
python test_calculator.py
```

## समस्या निवारण

### इम्पोर्ट एरर्स

जर तुम्हाला `ModuleNotFoundError: No module named 'mcp'` असा संदेश दिसत असेल, तर MCP Python SDK इन्स्टॉल करा:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### थेट चालवताना JSON-RPC एरर्स

थेट सर्व्हर चालवताना "Invalid JSON: EOF while parsing a value" अशी त्रुटी येणे अपेक्षित आहे. सर्व्हरला MCP क्लायंट मेसेजेसची आवश्यकता असते, थेट टर्मिनल इनपुट नाही.
