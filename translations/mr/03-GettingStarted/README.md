## सुरुवात करीत आहेत  

[![Build Your First MCP Server](../../../translated_images/mr/04.0ea920069efd979a.webp)](https://youtu.be/sNDZO9N4m9Y)

_(या धड्याचा व्हिडिओ पाहण्यासाठी वर दिलेल्या प्रतिमेवर क्लिक करा)_

या विभागात अनेक धडे आहेत:

- **1 तुमचा पहिला सर्व्हर**, या पहिल्या धड्यात, तुम्ही तुमचा पहिला सर्व्हर कसा तयार करायचा आणि त्याची तपासणी कसे करायची हे शिकाल, इन्स्पेक्टर साधनाचा वापर करून, जो तुमच्या सर्व्हरची चाचणी आणि डिबगिंग करण्याचा मौल्यवान मार्ग आहे, [धड्यासाठी](01-first-server/README.md)

- **2 क्लायंट**, या धड्यात, तुम्ही तुमच्या सर्व्हरशी कनेक्ट होणारा क्लायंट कसा लिहायचा हे शिकाल, [धड्यासाठी](02-client/README.md)

- **3 LLM सह क्लायंट**, क्लायंट लिहिण्याचा आणखी एक चांगला मार्ग म्हणजे त्यात LLM जोडणे जेणेकरून तो तुमच्या सर्व्हरशी "नेगोशिएट" करू शकेल काय करायचे, [धड्यासाठी](03-llm-client/README.md)

- **4 Visual Studio Code मध्ये सर्व्हर GitHub Copilot एजंट मोड वापरणे**. येथे, आपण Visual Studio Code मधून आमचा MCP सर्व्हर कसा चालवायचा ते पाहणार आहोत, [धड्यासाठी](04-vscode/README.md)

- **5 stdio ट्रान्सपोर्ट सर्व्हर** stdio ट्रान्सपोर्ट हा स्थानिक MCP सर्व्हर-टू-क्लायंट संवादाचा शिफारस केलेला मानक आहे, जो अंतर्गत प्रक्रिया पृथक्करणासह सुरक्षित उपप्रक्रिया-आधारित संवाद प्रदान करतो [धड्यासाठी](05-stdio-server/README.md)

- **6 MCP सह HTTP स्ट्रिमिंग (Streamable HTTP)**. या मानकाबद्दल शिका
	दूरस्थ ट्रान्सपोर्टाबद्दल [MCP Specification 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http),
	पारंपारिक सत्र-आधारित अंमलबजावणी धड्यात ठेवलेली आहे.
	[धड्यासाठी](06-http-streaming/README.md)

- **7 AI टूलकिट वापरणे VSCode साठी** तुमचे MCP क्लायंट आणि सर्व्हर तपासण्यासाठी आणि वापरण्यासाठी [धड्यासाठी](07-aitk/README.md)

- **8 चाचणी**. येथे आपण विशेषतः पाहणार आहोत की आपण आमच्या सर्व्हर आणि क्लायंटची विविध प्रकारे कशी चाचणी करू शकतो, [धड्यासाठी](08-testing/README.md)

- **9 तैनात करणे**. हा अध्याय तुमच्या MCP सोल्यूशन्स तैनात करण्याचे विविध मार्ग पाहील, [धड्यासाठी](09-deployment/README.md)

- **10 प्रगत सर्व्हर वापर**. हा अध्याय प्रगत सर्व्हर वापराकडे लक्ष देतो, [धड्यासाठी](./10-advanced/README.md)

- **11 प्रमाणीकरण**. हा अध्याय सोपे प्रमाणीकरण कसे जोडायचे ते कव्हर करतो, बेसिक ऑथ पासून JWT आणि RBAC वापरण्यापर्यंत. तुम्हाला येथे सुरु करण्यास प्रोत्साहित केले जाते आणि नंतर प्रगत विषय ते Chapter 5 मध्ये आणि पुढील सुरक्षा मजबूत करण्यासाठी Chapter 2 मध्ये शिफारसी पाहा, [धड्यासाठी](./11-simple-auth/README.md)

- **12 MCP होस्ट्स**. लोकप्रिय MCP होस्ट क्लायंट्स जसे की Claude Desktop, Cursor, Cline, आणि Windsurf कॉन्फिगर करा आणि वापरा. ट्रान्सपोर्ट प्रकार आणि समस्या निराकरण जाणून घ्या, [धड्यासाठी](./12-mcp-hosts/README.md)

- **13 MCP इन्स्पेक्टर**. तुमचे MCP सर्व्हर इंटरऐक्टिव्हपणे डिबग व टेस्ट करा MCP इन्स्पेक्टर साधन वापरून. टूल्स, संसाधने, आणि प्रोटोकॉल मेसेजेसची समस्या निवारण शिकू शकता, [धड्यासाठी](./13-mcp-inspector/README.md)

- **14 सॅंपलिंग**. `2025-11-25` च्या पारंपारिक सॅंपलिंग प्रिमिटिव्हबद्दल आणि
	नवीन डिझाइन्स कसे थेट LLM प्रदाता एकत्रीकरणाकडे स्थलांतरित करायचे ते शिका. सॅंपलिंग
	MCP `2026-07-28` मध्ये अवलंबून राहिलेला नाही. [धड्यासाठी](./14-sampling/README.md)

- **15 MCP अॅप्स**. असे MCP सर्व्हर तयार करा जे UI सूचनांसह देखील उत्तर देतील, [धड्यासाठी](./15-mcp-apps/README.md)

मॉडेल कॉन्टेक्स्ट प्रोटोकॉल (MCP) हा एक खुला प्रोटोकॉल आहे जे अॅप्लिकेशन्सना LLMs कडे संदर्भ प्रदान करण्यासाठी मानक निर्माण करतो. MCP ला AI अॅप्लिकेशन्ससाठी USB-C पोर्ट समजा - तो AI मॉडेल्सना वेगवेगळ्या डेटा स्त्रोतांशी आणि साधनांशी कनेक्ट करण्याचा एक मानकीकृत मार्ग प्रदान करतो.

## शिकण्याचे उद्दिष्टे

या धड्याच्या शेवटी, तुम्ही सक्षम असाल:

- C#, Java, Python, TypeScript, आणि JavaScript मध्ये MCP साठी विकास वातावरण सेटअप करणे
- खासगी वैशिष्ट्यांसह मुलभूत MCP सर्व्हर तयार करणे आणि तैनात करणे (संसाधने, सुचना, आणि साधने)
- MCP सर्व्हरशी कनेक्ट होणाऱ्या होस्ट अॅप्लिकेशन्स तयार करणे
- MCP अंमलबजावणींची चाचणी व डिबगिंग करणे
- सामान्य सेटअप अडचणी आणि त्यांचे समाधान समजून घेणे
- तुमच्या MCP अंमलबजावणींना लोकप्रिय LLM सेवा कनेक्ट करणे

## तुमचे MCP वातावरण सेट करणे

MCP सोबत काम सुरू करण्यापूर्वी, तुमचे विकास वातावरण तयार करणे आणि मूलभूत कामकाज समजून घेणे महत्त्वाचे आहे. या विभागात प्रारंभीच्या सेटअप चरणांबद्दल मार्गदर्शन केले जाईल जेणेकरून MCP वापरण्यास सुरळीत सुरुवात होईल.

### आवश्यक पूर्वशर्ती

MCP विकासात उतरता येण्यापूर्वी, खात्री करा की तुमच्याकडे आहे:

- **विकास वातावरण**: तुमच्या निवडलेल्या भाषेसाठी (C#, Java, Python, TypeScript, किंवा JavaScript)
- **IDE/एडिटर**: Visual Studio, Visual Studio Code, IntelliJ, Eclipse, PyCharm, किंवा कोणताही आधुनिक कोड एडिटर
- **पॅकेज मॅनेजर्स**: NuGet, Maven/Gradle, pip, किंवा npm/yarn
- **API कीज**: तुमच्या होस्ट अॅप्लिकेशन्समध्ये वापरण्यासाठी कोणत्याही AI सेवांसाठी


### अधिकृत SDKs

येणाऱ्या अध्यायांमध्ये तुम्हाला Python, TypeScript,
Java आणि .NET वापरून तयार केलेले उपाय दिसतील. येथे अधिकृत SDKs आहेत.

MCP `2026-07-28` साठी SDK समर्थन स्वतंत्रपणे भाषानिहाय जारी केले जात आहे.
उदाहरण चालवायच्या आधी, त्याचा पॅकेज व्हर्जन आणि SDK च्या रिलीज नोट्स तपासा
समर्थित प्रोटोकॉल पुनरावलोकनांसाठी. पाहा
[अधिकृत SDK यादी](https://modelcontextprotocol.io/docs/sdk):
- [C# SDK](https://github.com/modelcontextprotocol/csharp-sdk) - Microsoft सह सहयोगाने देखभाल केलेले
- [Java SDK](https://github.com/modelcontextprotocol/java-sdk) - Spring AI सह सहयोगाने देखभाल केलेले
- [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) - अधिकृत TypeScript अंमलबजावणी
- [Python SDK](https://github.com/modelcontextprotocol/python-sdk) - अधिकृत Python अंमलबजावणी (FastMCP)
- [Kotlin SDK](https://github.com/modelcontextprotocol/kotlin-sdk) - अधिकृत Kotlin अंमलबजावणी
- [Swift SDK](https://github.com/modelcontextprotocol/swift-sdk) - Loopwork AI सह सहयोगाने देखभाल केलेले
- [Rust SDK](https://github.com/modelcontextprotocol/rust-sdk) - अधिकृत Rust अंमलबजावणी
- [Go SDK](https://github.com/modelcontextprotocol/go-sdk) - अधिकृत Go अंमलबजावणी

## मुख्य मुद्दे

- भाषा-विशिष्ट SDK सह MCP विकास वातावरण सेट करणे सोपे आहे
- MCP सर्व्हर तयार करणे म्हणजे स्पष्ट स्कीमांसह साधने तयार करणे आणि नोंदणी करणे
- MCP क्लायंट सर्व्हर आणि मॉडेलशी कनेक्ट होतात विस्तारित क्षमता वापरण्यासाठी
- चाचणी आणि डिबगिंग विश्वसनीय MCP अंमलबजावणीसाठी आवश्यक आहेत
- स्थानिक विकासापासून ते क्लाऊड-आधारित सोल्यूशन्सपर्यंत तैनातीचे पर्याय असतात
