# MCP सर्व्हर डिप्लॉय करणे

> [!NOTE]
> `/sse` एंडपॉइंट वापरणारे कॉन्फिगरेशन उदाहरणे जुना HTTP+SSE ट्रान्सपर्ट वापरतात. MCP `2026-07-28` रिमोट सर्व्हर सामान्यतः `/mcp` सारख्या सर्व्हर-निर्धारित एंडपॉइंटवर Streamable HTTP वापरतात.
>
>

तुमचा MCP सर्व्हर डिप्लॉय केल्याने इतर लोकांना त्यांच्या स्थानिक वातावरणाबाहेर त्याचे टूल्स आणि साधने वापरण्याची परवानगी मिळते. स्केलेबिलिटी, विश्वसनीयता आणि व्यवस्थापन सुलभतेच्या तुमच्या गरजांनुसार काही डिप्लॉयमेंट धोरणे आहेत. खाली तुम्हाला स्थानिक, कंटेनरमध्ये आणि क्लाउडमध्ये MCP सर्व्हर डिप्लॉय करण्यासाठी मार्गदर्शन मिळेल.

## आढावा

हा धडा तुमच्या MCP सर्व्हर अ‍ॅप कसा डिप्लॉय करायचा ते शिकवतो.

## शिकण्याची उद्दिष्टे

या धड्याच्या शेवटी, तुम्ही सक्षम असाल:

- वेगवेगळ्या डिप्लॉयमेंट पद्धतींचे मूल्यमापन करा.
- तुमचे अ‍ॅप डिप्लॉय करा.

## स्थानिक विकास आणि डिप्लॉयमेंट

जर तुमचा सर्व्हर वापरकर्त्यांच्या मशीनवर चालण्यासाठी बनवलेला असेल, तर तुम्ही खालील पावले अनुसरू शकता:

1. **सर्व्हर डाउनलोड करा**. जर तुम्ही सर्व्हर लिहिलेला नसेल, तर प्रथम ते तुमच्या मशीनवर डाउनलोड करा.
1. **सर्व्हर प्रक्रिया सुरू करा**: तुमचा MCP सर्व्हर अ‍ॅप्लिकेशन चालवा

SSE साठी (stdio प्रकाराच्या सर्व्हरसाठी आवश्यक नाही)

1. **नेटवर्किंग कॉन्फिगर करा**: सर्व्हर अपेक्षित पोर्टवर पोहोचण्यायोग्य आहे याची खात्री करा
1. **क्लायंट कनेक्ट करा**: स्थानिक कनेक्शन URL वापरा जसे की `http://localhost:3000`

## क्लाउड डिप्लॉयमेंट

MCP सर्व्हर विविध क्लाउड प्लॅटफॉर्मवर डिप्लॉय केले जाऊ शकतात:

- **सर्व्हररहित फंक्शन्स**: हलक्या MCP सर्व्हरचे सर्व्हररहित फंक्शन्स म्हणून डिप्लॉय करा
- **कंटेनर सेवा**: Azure Container Apps, AWS ECS किंवा Google Cloud Run सारख्या सेवा वापरा
- **कुबेरनेट्स**: उच्च उपलब्धतेसाठी Kubernetes क्लस्टरमध्ये MCP सर्व्हर डिप्लॉय आणि व्यवस्थापित करा

### उदाहरण: Azure Container Apps

Azure Container Apps MCP सर्व्हरचे डिप्लॉयमेंट समर्थन करतात. हे अजूनही प्रगतीच्या टप्प्यात असून सध्या SSE सर्व्हर सपोर्ट करतात.

तुम्ही असे करू शकता:

1. एक रिपॉजिटरी क्लोन करा:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. स्थानिकपणे चालवून तपासा:

  ```sh
  uv venv
  uv sync

  # लिनक्स/मॅकओएस
  export API_KEYS=<AN_API_KEY>
  # विंडोज
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. स्थानिकपणे प्रयत्न करण्यासाठी, *.vscode* निर्देशिकेत *mcp.json* फाइल तयार करा आणि खालील सामग्री जोडा:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  एकदा SSE सर्व्हर सुरू झाल्यावर, तुम्ही JSON फाइलमधील प्ले आयकॉनवर क्लिक करू शकता, आता तुम्हाला GitHub Copilot द्वारे सर्व्हरवरील टूल्स ओळखले जाताना दिसतील, टूल आयकॉन पहा.

1. डिप्लॉय करण्यासाठी, खालील आदेश चालवा:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

मूळ संकल्पनेप्रमाणे, स्थानिकपणे डिप्लॉय करा, Azure मध्ये या पायऱ्यांमार्फत डिप्लॉय करा.
