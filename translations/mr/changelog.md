# चेंजलोड: सुरुवातीसाठी MCP अभ्यासक्रम

हा दस्तऐवज मॉडल कॉन्टेक्स्ट प्रोटोकॉल (MCP) सुरुवातीसाठी अभ्यासक्रमात झालेल्या सर्व महत्त्वाच्या बदलांचा नोंद म्हणून काम करतो. बदल उलट तारखेनुसार नोंदवलेले आहेत (नवीनतम बदल प्रथम).

## २९ जुलै, २०२६

### नवीन मोड्यूल ०८ उत्तराधिकारी: विश्वसनीयता साइडकार आणि सुरक्षित पुनर्प्रयत्न

MCP साधनांसाठी एक विक्रेता-निरपेक्ष उत्तराधिकारी धडा जोडला आहे जे वास्तविक जगातील परिणाम तयार करतात,
अंतिम `2026-07-28` तपशीलवार स्पेसिफिकेशनशी सुसंगत.

- **नवीन**: [विश्वसनीयता साइडकार उत्तराधिकारी धडा][reliability-sidecar]
  एका समर्थन-तिकीट कथेमुळे, दोन Mermaid आकृत्या वापरून आणि पुनर्प्रयत्न निर्णय
  फ्लो द्वारे स्थिर कार्यप्रणाली कळा, अणु duplicate प्रवेश,
  समन्वय, पुरावा आणि टास्क विस्तार सीमा समजावून सांगितली.
- **नवीन**: एक standard-library Python आणि SQLite अपयश-इंजेक्शन सराव
  वेगवेगळ्या ऑपरेशन आणि तिकीट संचांचा वापर करून एका बाह्य परिणामाची
  प्रतिक्रिया हरवली गेल्याचे प्रदर्शन केले. सहा निश्चित चाचण्या naïve
  दुहेरीकरण, संरक्षित रीस्टार्ट पुनर्प्राप्ती, payload संघर्ष, साठवलेले निकाल,
  सक्रिय दावा आणि समकालीन duplicate प्रवेश यांची पूर्तता करतात.
- **अद्ययावत**: मोड्यूल ०८ आता उत्तराधिकारी धडा लिंक करतो, अंतिम
  `2026-07-28` स्टेटलेस विनंती मॉडेल ओळखतो, OpenTelemetry
  निरीक्षण तपासणी आणि डिप्रिकेटेड MCP लॉगिंग वैशिष्ट्य स्पष्ट करतो आणि
  त्याचा सामान्य पुनर्प्रयत्न उदाहरण फक्त वाचन-संबंधी ऑपरेशन्सपुरते मर्यादित करतो.
- **ऐच्छिक**: धडा त्याच्या साध्या संकल्पनांना एका टॅग केलेल्या समुदाय
  अंमलबजावणीशी नकाशित करतो पण होस्ट केलेल्या सेवेचा किंवा नेटवर्क कॉलचा भाग
  सरावात समाविष्ट करत नाही.

[reliability-sidecar]: ./08-BestPractices/reliability-sidecars/README.md

### MCP तपशीलवार जुळणी & नमुना प्रमाणीकरण

अभ्यासक्रमाची सध्याच्या **MCP Specification 2025-11-25** आणि नवीनतम अधिकृत SDKs सोबत पडताळणी केली, नंतर जुन्या तपशीलवार संदर्भ दुरुस्त केले आणि मुख्य नमुन्यांचे बिल्ड व रन अजूनही चालू असल्याची पुष्टी केली.

#### तपशीलवार आवृत्ती दुरुस्त्या (2025-06-18 / 2025-03-26 → 2025-11-25)

इंग्रजी मजकूर अद्ययावत केला जिथे अजून जुन्या आवृत्तीचे नियम *सध्याचे/नवीनतम* मानले जात होते, आणि लिंक केनॉनिकल `modelcontextprotocol.io` तपशील पथांकडे पुनर्निर्देशित केल्या:
- **05-AdvancedTopics/mcp-security/README.md**: "सध्याचा मानक" बॅनर, परिचय, मुख्य सुरक्षा तत्त्वे शीर्षक, अनिवार्य आवश्यकता शीर्षक, Microsoft Entra ID विभाग, संदर्भ व साधन ऍक्सेस लिंक आणि अंतिम सुरक्षा सूचना (8 संदर्भ) 2025-11-25 प्रमाणे अद्ययावत
- **05-AdvancedTopics/mcp-transport/README.md**: अतिरिक्त साधने तपशील लिंक आणि "सद्याचा मानक" बॅनर 2025-11-25 प्रमाणे अद्ययावत
- **05-AdvancedTopics/mcp-realtimesearch/README.md**: जुना `2025-03-26` सुरक्षा-आणि-विश्वास लिंक बदलून वर्तमान 2025-11-25 सुरक्षा सर्वोत्तम सरावाचे पान वापरले
- **03-GettingStarted/14-sampling/README.md**: अधिकृत Sampling दस्तऐवज लिंक 2025-11-25 प्रमाणे अद्ययावत

#### सध्याच्या SDKs विरुद्ध नमुना प्रमाणीकरण

- **TypeScript (03-GettingStarted/01-first-server/solution/typescript)**: `npm install` ने `@modelcontextprotocol/sdk@1.29.0` सादर केले; `tsc --noEmit` मध्ये कोणतेही टाइप त्रुटी नसल्यास उत्तीर्ण — विद्यमान `McpServer`/`StdioServerTransport` API बरोबर आहेत

#### मुख्य संकल्पना (01-CoreConcepts/) - संपूर्ण आधुनिकीकरण
- **प्रोटोकॉल आवृत्ती अद्यतन**: चालू MCP तपशील 2025-06-18 संदर्भित करून तारीख-आधारित आवृत्तीकरण (YYYY-MM-DD स्वरूप)
- **आर्किटेक्चर सुधारणा**: Hosts, Clients, आणि Servers चे सध्याच्या MCP आर्किटेक्चर नमुन्यांचे प्रतिबिंब प्रतिबिंबित वर्णन
  - Hosts आता स्पष्टपणे AI अनुप्रयोग म्हणून परिभाषित जे अनेक MCP क्लायंट कनेक्शन्स समन्वयित करतात
  - Clients प्रोटोकॉल कनेक्टर म्हणून वर्णन ज्यांनी एक-टू-वन सर्व्हर संबंध राखला आहे
  - Servers स्थानिक विरुद्ध दूरस्थ तैनाती परिस्थितींसह सुधारलेले
- **मूलभूत पुनर्रचना**: सर्व्हर आणि क्लायंट मूलभूत घटकांचे संपूर्ण पुनर्रचना
  - सर्व्हर मूलभूत घटक: संसाधने (डेटा स्रोत), प्रॉम्प्ट (टेम्प्लेट्स), टूल्स (कार्यरत फंक्शन्स) सविस्तर स्पष्टीकरणे आणि उदाहरणांसह
  - क्लायंट मूलभूत घटक: सॅम्पलिंग (LLM पूर्णता), एलिसिटेशन (वापरकर्ता इनपुट), लॉगिंग (डिबगिंग/निरीक्षण)
  - सध्याच्या शोध (`*/list`), पुनर्प्राप्ती (`*/get`), आणि अंमलबजावणी (`*/call`) पद्धतींच्या नमुन्यांसह अद्ययावत
- **प्रोटोकॉल आर्किटेक्चर**: दोन-स्तरीय आर्किटेक्चर मॉडेलची ओळख
  - डेटा स्तर: JSON-RPC 2.0 पाया ज्यात जीवनचक्र व्यवस्थापन आणि मूलभूत घटकांचा समावेश
  - वाहतूक स्तर: STDIO (स्थानिक) आणि स्लॉट HTTP सह SSE (दूरस्थ) वाहतूक यंत्रणा
- **सुरक्षा फ्रेमवर्क**: स्पष्ट वापरकर्ता संमती, डेटा गोपनीयता संरक्षण, टूल अंमलबजावणी सुरक्षा, आणि वाहतूक स्तर सुरक्षा यांचा समावेश असलेल्या व्यापक सुरक्षा तत्त्वे
- **संवाद नमुने**: प्रारंभ, शोध, अंमलबजावणी, आणि सूचना प्रवाह दर्शविण्यासाठी प्रोटोकॉल संदेश अद्ययावत
- **कोड उदाहरणे**: वर्तमान MCP SDK नमुन्यांचे प्रतिबिंबित करणार्‍या बहुभाषिक उदाहरणे (.NET, Java, Python, JavaScript) ताजे केले

  - वास्तव विश्वातील उदाहरणांसह सविस्तर प्रॉम्प्ट इंजेक्शन हल्ला परिस्थिती

  - AI Prompt Shields ज्यात प्रगत शोध, हायलाइटिंग, आणि डिलिमीटर तंत्रज्ञान

  - टोकन पासथ्रू कमकुवतपणा अनिवार्य पडताळणी नियंत्रणांसह
- **पुरवठा साखळी सुरक्षा**: स्थापत्य मॉडेल्स, एम्बेडिंग सेवा, संदर्भ प्रदाते, आणि तृतीय-पक्ष API यांचा समावेश करून AI पुरवठा साखळी विस्तारीत कव्हरेज
