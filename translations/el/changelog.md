  διπλή εισαγωγή, ανάκτηση επανεκκίνησης με φύλαξη, συγκρούσεις φορτίου,

#### Βασικές Έννοιες (01-CoreConcepts/) - Πλήρης Εκσυγχρονισμός
- **Ενημέρωση Έκδοσης Πρωτοκόλλου**: Ενημέρωση αναφορών στην τρέχουσα Προδιαγραφή MCP 2025-06-18 με μορφή έκδοσης βάσει ημερομηνίας (YYYY-MM-DD)
- **Βελτίωση Αρχιτεκτονικής**: Ενισχυμένες περιγραφές Hosts, Clients, και Servers για να αντανακλούν πρότυπα τρέχουσας αρχιτεκτονικής MCP
  - Hosts πλέον ορισμένα ρητά ως εφαρμογές AI που συντονίζουν πολλαπλές συνδέσεις πελάτη MCP
  - Clients περιγράφονται ως πρωτόκολλα συνδετήρων που διατηρούν σχέσεις ένα-προς-ένα με servers
  - Servers βελτιωμένα με σενάρια τοπικής έναντι απομακρυσμένης ανάπτυξης
- **Πρωτογενής Αναδιαμόρφωση**: Πλήρης αναθεώρηση των primitives του server και client
  - Primitives Server: Πόροι (πηγές δεδομένων), Prompts (πρότυπα), Εργαλεία (εκτελέσιμες λειτουργίες) με λεπτομερείς εξηγήσεις και παραδείγματα
  - Primitives Client: Δειγματοληψία (LLM completions), Πρόκληση (εισροή χρήστη), Καταγραφή (αποσφαλμάτωση/παρακολούθηση)
  - Ενημερωμένο με τρέχοντα μοτίβα μεθόδων ανακάλυψης (`*/list`), ανάκτησης (`*/get`), και εκτέλεσης (`*/call`)
- **Αρχιτεκτονική Πρωτοκόλλου**: Εισαγωγή μοντέλου δύο επιπέδων αρχιτεκτονικής
  - Επίπεδο Δεδομένων: Θεμέλιο JSON-RPC 2.0 με διαχείριση κύκλου ζωής και primitives
  - Επίπεδο Μεταφοράς: STDIO (τοπική) και ροή HTTP με SSE (απομακρυσμένη) μηχανισμοί μεταφοράς
- **Πλαίσιο Ασφάλειας**: Ολοκληρωμένες αρχές ασφάλειας συμπεριλαμβανομένης ρητής συναίνεσης χρήστη, προστασίας απορρήτου δεδομένων, ασφάλειας εκτέλεσης εργαλείων, και ασφάλειας επιπέδου μεταφοράς
- **Πρότυπα Επικοινωνίας**: Ενημερωμένα μηνύματα πρωτοκόλλου για εμφάνιση ροών εκκίνησης, ανακάλυψης, εκτέλεσης, και ειδοποίησης
- **Παραδείγματα Κώδικα**: Ανανέωση πολυγλωσσικών παραδειγμάτων (.NET, Java, Python, JavaScript) για να αντανακλούν τρέχοντα πρότυπα SDK MCP

- **Ευθυγράμμιση Προτύπων**: Πλήρης ευθυγράμμιση με απαιτήσεις ασφάλειας Προδιαγραφής MCP 2025-06-18
- **Εξέλιξη Πιστοποίησης**: Τεκμηριωμένη εξέλιξη από προσαρμοσμένους διακομιστές OAuth σε ανάθεση εξωτερικού παρόχου ταυτότητας (Microsoft Entra ID)
- **Ανάλυση Απειλών ειδική για AI**: Ενισχυμένη κάλυψη σύγχρονων επιθέσεων AI
  - Λεπτομερή σενάρια επιθέσεων εισαγωγής prompt με πραγματικά παραδείγματα
  - Μηχανισμοί δηλητηρίασης εργαλείων και πρότυπα επιθέσεων "rug pull"
  - Δηλητηρίαση παραθύρου συμφραζομένων και επιθέσεις σύγχυσης μοντέλου
- **Λύσεις Ασφάλειας Microsoft AI**: Ολοκληρωμένη κάλυψη οικοσυστήματος ασφάλειας Microsoft
  - AI Prompt Shields με προηγμένη ανίχνευση, επισήμανση, και τεχνικές διαχωρισμού
  - Πρότυπα ενσωμάτωσης Azure Content Safety
  - GitHub Advanced Security για προστασία εφοδιαστικής αλυσίδας
- **Προηγμένη Αντιμετώπιση Απειλών**: Λεπτομερείς έλεγχοι ασφάλειας για
  - Απαγωγή συνεδρίας με σενάρια επιθέσεων ειδικά MCP και απαιτήσεις κρυπτογραφικού αναγνωριστικού συνεδρίας
  - Προβλήματα Confused Deputy σε σενάρια μεσολάβησης MCP με ρητές απαιτήσεις συναίνεσης
  - Ευπάθειες παράκαμψης διακριτικών με υποχρεωτικούς ελέγχους επικύρωσης
- **Ασφάλεια Εφοδιαστικής Αλυσίδας**: Επέκταση κάλυψης αλυσίδας εφοδιασμού AI συμπεριλαμβανομένων θεμελιωδών μοντέλων, υπηρεσιών ενσωμάτωσης, παρόχων συμφραζομένων, και API τρίτων
- **Θεμελιώδης Ασφάλεια**: Ενισχυμένη ενσωμάτωση με πρότυπα ασφαλείας επιχειρήσεων συμπεριλαμβανομένης αρχιτεκτονικής μηδενικής εμπιστοσύνης και οικοσυστήματος ασφαλείας Microsoft
- **Οργάνωση Πόρων**: Κατηγοριοποίηση ολοκληρωμένων συνδέσμων πόρων ανά τύπο (Επίσημη Τεκμηρίωση, Πρότυπα, Έρευνα, Λύσεις Microsoft, Οδηγοί Υλοποίησης)
