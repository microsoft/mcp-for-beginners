# 🚀 Εργαλεία MCP

## 🧠 Επισκόπηση της Διαδρομής Μάθησης Ενσωμάτωσης Βάσης Δεδομένων MCP

Εδώ θα μάθετε πώς να χρησιμοποιείτε εργαλεία που χρησιμοποιούν το MCP. Η εμπειρία σας κατά τη χρήση αυτών των εργαλείων θα βελτιωθεί καθώς συνδέετε διακομιστές MCP σε αυτά.

## 🔗 Επίσημοι Πόροι MCP

- 📘 [Τεκμηρίωση MCP](https://modelcontextprotocol.io/) – Λεπτομερή σεμινάρια και οδηγοί χρήστη
- 📜 [Προδιαγραφή MCP (2026-07-28)](https://modelcontextprotocol.io/specification/2026-07-28/) – Αρχιτεκτονική πρωτοκόλλου και τεχνικές αναφορές
- 🧑‍💻 [Αποθετήριο MCP στο GitHub](https://github.com/modelcontextprotocol) – SDK ανοιχτού κώδικα, εργαλεία και δείγματα κώδικα
- 🌐 [Κοινότητα MCP](https://github.com/orgs/modelcontextprotocol/discussions) – Συμμετοχή σε συζητήσεις και συμβολή στην κοινότητα
- 🔒 [OWASP MCP Top 10](https://microsoft.github.io/mcp-azure-security-guide/mcp/) – Καλύτερες πρακτικές ασφάλειας και αντιμετώπιση κινδύνων
