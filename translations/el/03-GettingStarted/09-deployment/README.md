# Ανάπτυξη Διακομιστών MCP

> [!NOTE]
> Παραδείγματα ρυθμίσεων που χρησιμοποιούν ένα endpoint `/sse` στοχεύουν στη παλαιά μεταφορά HTTP+SSE. Οι απομακρυσμένοι διακομιστές MCP `2026-07-28` χρησιμοποιούν Streamable HTTP, συνήθως σε ένα endpoint που ορίζεται από τον διακομιστή όπως το `/mcp`.
> 
> 

Η ανάπτυξη του διακομιστή MCP σου επιτρέπει σε άλλους να έχουν πρόσβαση στα εργαλεία και τους πόρους του πέρα από το τοπικό σου περιβάλλον. Υπάρχουν διάφορες στρατηγικές ανάπτυξης που πρέπει να ληφθούν υπόψη, ανάλογα με τις απαιτήσεις σου για επεκτασιμότητα, αξιοπιστία και ευκολία διαχείρισης. Παρακάτω θα βρεις οδηγίες για την ανάπτυξη διακομιστών MCP τοπικά, σε κοντέινερ και στο cloud.

## Επισκόπηση

Αυτό το μάθημα καλύπτει πώς να αναπτύξεις την εφαρμογή MCP Server σου.

## Στόχοι Μάθησης

Μέχρι το τέλος αυτού του μαθήματος, θα είσαι σε θέση να:

- Αξιολογήσεις διαφορετικών προσεγγίσεων ανάπτυξης.
- Ανάπτυξη της εφαρμογής σου.

## Τοπική ανάπτυξη και ανάπτυξη

Εάν ο διακομιστής σου προορίζεται για χρήση σε μηχανήματα χρηστών, μπορείς να ακολουθήσεις τα παρακάτω βήματα:

1. **Κατεβάστε τον διακομιστή**. Αν δεν έγραψες εσύ τον διακομιστή, τότε κατέβασέ τον πρώτα στην μηχανή σου. 
1. **Ξεκίνα τη διαδικασία διακομιστή**: Τρέξε την εφαρμογή MCP server σου 

Για SSE (δεν χρειάζεται για διακομιστή τύπου stdio)

1. **Διαμόρφωση δικτύου**: Εξασφαλίστε ότι ο διακομιστής είναι προσβάσιμος στην αναμενόμενη θύρα 
1. **Σύνδεση πελατών**: Χρησιμοποίησε τοπικές διευθύνσεις URL όπως `http://localhost:3000`

## Ανάπτυξη στο cloud

Οι διακομιστές MCP μπορούν να αναπτυχθούν σε διάφορες πλατφόρμες cloud:

- **Serverless Functions**: Αναπτύξτε ελαφριούς διακομιστές MCP ως serverless functions
- **Υπηρεσίες Κοντέινερ**: Χρησιμοποιήστε υπηρεσίες όπως Azure Container Apps, AWS ECS ή Google Cloud Run
- **Kubernetes**: Αναπτύξτε και διαχειριστείτε διακομιστές MCP σε συμπλέγματα Kubernetes για υψηλή διαθεσιμότητα

### Παράδειγμα: Azure Container Apps

Τα Azure Container Apps υποστηρίζουν την ανάπτυξη διακομιστών MCP. Είναι ακόμα σε εξέλιξη και αυτή τη στιγμή υποστηρίζουν διακομιστές SSE.

Ακολουθεί πώς μπορείς να το κάνεις:

1. Κλωνοποίησε ένα αποθετήριο:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. Τρέξε το τοπικά για να δοκιμάσεις:

  ```sh
  uv venv
  uv sync

  # linux/macOS
  export API_KEYS=<AN_API_KEY>
  # windows
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. Για να το δοκιμάσεις τοπικά, δημιούργησε ένα αρχείο *mcp.json* μέσα σε έναν κατάλογο *.vscode* και πρόσθεσε το παρακάτω περιεχόμενο:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  Μόλις ξεκινήσει ο διακομιστής SSE, μπορείς να κάνεις κλικ στο εικονίδιο εκτέλεσης στο αρχείο JSON, τώρα θα πρέπει να βλέπεις εργαλεία στον διακομιστή να εντοπίζονται από το GitHub Copilot, δες το εικονίδιο εργαλείου. 

1. Για να αναπτύξεις, τρέξε την παρακάτω εντολή:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

Έτοιμο, αναπτυξέ το τοπικά, αναπτυξέ το στο Azure μέσω αυτών των βημάτων.
