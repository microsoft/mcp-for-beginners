# Πελάτης LLM Αριθμομηχανής

Μια εφαρμογή Java που δείχνει πώς να χρησιμοποιήσετε το LangChain4j για να συνδεθείτε σε μια υπηρεσία αριθμομηχανής MCP (Model Context Protocol) μέσω του MiniMax API συμβατού με OpenAI.

## Προαπαιτούμενα

- Java 21 ή νεότερο
- Maven 3.6+ (ή να χρησιμοποιήσετε το συμπεριλαμβανόμενο Maven wrapper)
- Ένα κλειδί API MiniMax
- Μια υπηρεσία αριθμομηχανής MCP που τρέχει στο `http://localhost:8080`

## Αποκτώντας το Κλειδί API

Αυτή η εφαρμογή χρησιμοποιεί το MiniMax API συμβατό με OpenAI. Ακολουθήστε αυτά τα βήματα για να λάβετε το κλειδί και το endpoint σας:

### 1. Επιλέξτε ένα endpoint
1. Χρησιμοποιήστε το `https://api.minimax.io/v1` για το παγκόσμιο endpoint
2. Χρησιμοποιήστε το `https://api.minimaxi.com/v1` για το endpoint στην Κίνα

### 2. Δημιουργήστε κλειδί API
1. Δημιουργήστε ένα κλειδί MiniMax API από τον λογαριασμό σας στο MiniMax
2. Αποθηκεύστε το κλειδί κάπου ασφαλή

### 3. Ορίστε τις Μεταβλητές Περιβάλλοντος

#### Σε Windows (Command Prompt):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### Σε Windows (PowerShell):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### Σε macOS/Linux:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## Ρύθμιση και Εγκατάσταση

1. **Κλωνοποιήστε ή πλοηγηθείτε στον φάκελο του έργου**

2. **Εγκαταστήστε τις εξαρτήσεις**:
   ```cmd
   mvnw clean install
   ```
   Ή αν έχετε εγκατεστημένο το Maven παγκοσμίως:
   ```cmd
   mvn clean install
   ```

3. **Ορίστε τις μεταβλητές περιβάλλοντος** (βλέπε την ενότητα "Αποκτώντας το Κλειδί API" παραπάνω)

4. **Εκκινήστε την Υπηρεσία Αριθμομηχανής MCP**:
   Βεβαιωθείτε ότι η υπηρεσία αριθμομηχανής MCP του κεφαλαίου 1 τρέχει στο `http://localhost:8080/sse`. Πρέπει να τρέχει πριν ξεκινήσετε τον πελάτη.

## Εκτέλεση της Εφαρμογής

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## Τι Κάνει η Εφαρμογή

Η εφαρμογή παρουσιάζει τρεις βασικές αλληλεπιδράσεις με την υπηρεσία αριθμομηχανής:

1. **Πρόσθεση**: Υπολογίζει το άθροισμα του 24.5 και 17.3
2. **Τετραγωνική Ρίζα**: Υπολογίζει την τετραγωνική ρίζα του 144
3. **Βοήθεια**: Εμφανίζει διαθέσιμες λειτουργίες αριθμομηχανής

## Αναμενόμενο Αποτέλεσμα

Όταν τρέξει επιτυχώς, θα πρέπει να δείτε παρόμοιο αποτέλεσμα με:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## Αντιμετώπιση Προβλημάτων

### Συνηθισμένα Προβλήματα

1. **"Η μεταβλητή περιβάλλοντος OPENAI_API_KEY δεν έχει οριστεί"**
   - Βεβαιωθείτε ότι έχετε ορίσει τη μεταβλητή περιβάλλοντος `OPENAI_API_KEY`
   - Επανεκκινήστε το τερματικό/command prompt αφού ορίσετε τη μεταβλητή

2. **"Απόρριψη σύνδεσης στο localhost:8080"**
   - Βεβαιωθείτε ότι η υπηρεσία αριθμομηχανής MCP τρέχει στην πόρτα 8080
   - Ελέγξτε αν κάποια άλλη υπηρεσία χρησιμοποιεί την πόρτα 8080

3. **"Αποτυχία πιστοποίησης"**
   - Επαληθεύστε ότι το κλειδί API σας είναι έγκυρο
   - Ελέγξτε ότι το `OPENAI_BASE_URL` ταιριάζει με το endpoint που θέλατε να χρησιμοποιήσετε

4. **Σφάλματα κατασκευής Maven**
   - Βεβαιωθείτε ότι χρησιμοποιείτε Java 21 ή νεότερο: `java -version`
   - Προσπαθήστε να καθαρίσετε την κατασκευή: `mvnw clean`

### Αποσφαλμάτωση

Για να ενεργοποιήσετε το debug logging, προσθέστε το ακόλουθο όρισμα JVM κατά την εκτέλεση:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## Ρυθμίσεις

Η εφαρμογή είναι ρυθμισμένη να:
- Χρησιμοποιεί το MiniMax-M3 από προεπιλογή, ή MiniMax-M2.7 όταν έχει οριστεί το `MINIMAX_MODEL_ID`
- Συνδέεται στο `OPENAI_BASE_URL` όταν αυτό έχει οριστεί· αλλιώς χρησιμοποιεί το `https://api.minimaxi.com/v1` όταν `MINIMAX_REGION=cn_zh`, ή το `https://api.minimax.io/v1` από προεπιλογή
- Συνδέεται στην υπηρεσία MCP στο `http://localhost:8080/sse`
- Χρησιμοποιεί χρονικό όριο 60 δευτερολέπτων για αιτήσεις

## Εξαρτήσεις

Κύριες εξαρτήσεις που χρησιμοποιούνται σε αυτό το έργο:
- **LangChain4j**: Για ενσωμάτωση AI και διαχείριση εργαλείων
- **LangChain4j MCP**: Για υποστήριξη Model Context Protocol
- **LangChain4j OpenAI official**: Για ενσωμάτωση MiniMax API συμβατού με OpenAI
- **Spring Boot**: Για πλαίσιο εφαρμογής και εισαγωγή εξαρτήσεων
