# Ρίζες MCP (Παλιό Χαρακτηριστικό)

> [!WARNING]
> Οι ρίζες έχουν αποσυρθεί από το MCP `2026-07-28`. Παραμένουν σε αυτήν την αναθεώρηση για
> συμβατότητα και είναι επιλέξιμες για αφαίρεση στην πρώτη αναθεώρηση προδιαγραφής
> που κυκλοφορεί στις ή μετά τις 28 Ιουλίου 2027. Οι νέες υλοποιήσεις θα πρέπει να περνούν
> καταλόγους ή αρχεία μέσω παραμέτρων εργαλείων, URI πόρων ή ρύθμισης διακομιστή.


## Επισκόπηση

Οι ρίζες επιτρέπουν σε έναν πελάτη MCP να ενημερώνει έναν διακομιστή ποιες θέσεις στο σύστημα αρχείων είναι σχετικές
με το τρέχον αίτημα. Μια ρίζα περιέχει ένα υποχρεωτικό URI `file://` και ένα προαιρετικό
ανθρώπινα αναγνώσιμο όνομα.

Οι ρίζες είναι πληροφοριακές ενδείξεις. Δεν είναι κοντέινερ ιστορικού συνομιλίας,
πρωτόκολλα συνεδρίας ή μηχανισμός ελέγχου πρόσβασης. Το πρωτόκολλο δεν
επιβάλλει ότι ένας διακομιστής παραμένει εντός των καταχωρημένων ριζών.

## Εκπαιδευτικοί Στόχοι

Μέχρι το τέλος αυτού του μαθήματος, θα μπορείτε να:

- Εξηγήσετε τι αντιπροσωπεύουν οι ρίζες MCP και τι δεν αντιπροσωπεύουν.
- Αναγνωρίζετε τη ροή πολλαπλών ταξιδιών `roots/list` της τρέχουσας έκδοσης.
- Εφαρμόζετε τους ελέγχους ασφαλείας ανεξάρτητα από τις ρίζες.
- Μεταφέρετε νέες υλοποιήσεις σε υποστηριζόμενες εναλλακτικές λύσεις.

## Δεδομένα Ρίζας

Ένας πελάτης επιστρέφει κάθε ρίζα ως URI `file://` με ένα προαιρετικό όνομα παρουσίασης:

```json
{
  "roots": [
    {
      "uri": "file:///home/user/projects/weather-service",
      "name": "Weather Service"
    }
  ]
}
```

Οι πελάτες θα πρέπει να εκθέτουν μόνο θέσεις εγκεκριμένες από τον χρήστη. Οι διακομιστές θα πρέπει να χειρίζονται
το αποτέλεσμα ως οδηγία για σχετικά αρχεία, όχι ως απόδειξη εξουσιοδότησης.

## Ροή MCP 2026-07-28

Ένας πελάτης που υποστηρίζει τις ρίζες δηλώνει τη δυνατότητα σε κάθε αίτημα:

```json
{
  "_meta": {
    "io.modelcontextprotocol/clientCapabilities": {
      "roots": {}
    }
  }
}
```

Κατά την επεξεργασία ενός αιτήματος πελάτη, ένας διακομιστής μπορεί να επιστρέψει ένα
`InputRequiredResult` που περιέχει ένα αίτημα εισόδου `roots/list`:

```json
{
  "resultType": "input_required",
  "inputRequests": {
    "workspaceRoots": {
      "method": "roots/list"
    }
  },
  "requestState": "opaque-state-from-server"
}
```

Ο πελάτης συγκεντρώνει τις εγκεκριμένες ρίζες και ξαναδοκιμάζει το αρχικό αίτημα με τις
ταιριαστές `inputResponses` και το απαράλλακτο `requestState`. Αυτή η ροή πολλαπλών ταξιδιών
κρατά το πρωτόκολλο χωρίς κατάσταση· δεν υπάρχει χειραψία `initialize` ή
συνεδρία σε επίπεδο πρωτοκόλλου.

## Παλιότερη Συμπεριφορά 2025-11-25

Στο MCP `2025-11-25`, οι πελάτες διαφημίζαν ρίζες κατά την αρχικοποίηση. Ένας διακομιστής
μπορούσε να ζητήσει απευθείας `roots/list`, και ένας πελάτης μπορούσε να στείλει
`notifications/roots/list_changed` όταν οι ρίζες του άλλαζαν.

Αυτή η κυκλική ζωή είναι παλαιότερη συμπεριφορά. Μην συνδυάζετε τα παραδείγματα αρχικοποίησης ή
ειδοποίησης με μια υλοποίηση `2026-07-28`.

## Συνιστώμενες Αντικαταστάσεις

### Παράμετροι Εργαλείων

Κάντε τον απαιτούμενο φάκελο ή αρχείο ρητό στο σχήμα εργαλείου:

```json
{
  "name": "analyze_project",
  "inputSchema": {
    "type": "object",
    "properties": {
      "projectDirectory": {
        "type": "string",
        "description": "Approved project directory to analyze"
      }
    },
    "required": ["projectDirectory"]
  }
}
```

### URI Πόρων

Χρησιμοποιήστε πόρους MCP όταν ο διακομιστής μπορεί να εκθέσει τα σχετικά αρχεία μέσω σταθερών
URI. Αυτό καθιστά την ανακάλυψη και ανάκτηση ρητή.

### Ρύθμιση Διακομιστή

Για σταθερές αναπτύξεις, ρυθμίστε τους επιτρεπόμενους καταλόγους κατά την εκκίνηση του διακομιστή.
Αυτό είναι συχνά πιο ξεκάθαρο από το να τους ανακαλύπτει κατά την κλήση εργαλείου.

## Απαιτήσεις Ασφαλείας

Όποια και αν είναι η αντικατάστασή σας:

- Λάβετε τη συγκατάθεση του χρήστη πριν αποκαλύψετε θέσεις του συστήματος αρχείων.
- Κανονικοποιήστε και επικυρώστε τις διαδρομές για να αποτρέψετε τη διάσχιση.
- Επιβάλετε εξουσιοδότηση και sandboxing ανεξάρτητα από τις τιμές ρίζας.
- Επανεξετάζετε τα δικαιώματα όταν προσπελαύνεται ένα αρχείο, όχι μόνο όταν καταγράφεται.
- Αποφύγετε να επιστρέφετε ευαίσθητες διαδρομές σε αρχεία καταγραφής ή μηνύματα σφάλματος.

## Βασικά Συμπεράσματα

- Οι ρίζες περιγράφουν σχετικές θέσεις στο σύστημα αρχείων· δεν αποθηκεύουν κατάσταση
  συνομιλίας.
- Οι ρίζες είναι καθοδήγηση, όχι όριο ελέγχου πρόσβασης.
- Το MCP `2026-07-28` μεταφέρει τη δυνατότητα ανά αίτημα και χρησιμοποιεί
  `InputRequiredResult` για `roots/list`.
- Οι νέες υλοποιήσεις θα πρέπει να χρησιμοποιούν παράμετρους εργαλείων, URI πόρων ή
  ρύθμιση διακομιστή αντί γι’ αυτό.
