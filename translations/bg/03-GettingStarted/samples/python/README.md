# MCP Calculator Server (Python)



Просто изпълнение на сървър за Model Context Protocol (MCP) в Python, който предоставя базова функционалност на калкулатор.


## Инсталация

Инсталирайте необходимите зависимости:

```bash
pip install -r requirements.txt
```

Или инсталирайте директно MCP Python SDK:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## Използване

### Стартиране на сървъра

Сървърът е предназначен за употреба от MCP клиенти (като Claude Desktop). За да стартирате сървъра:

```bash
python mcp_calculator_server.py
```

**Бележка**: Когато се стартира директно в терминал, ще видите грешки при валидацията на JSON-RPC. Това е нормално поведение - сървърът чака правилно форматирани съобщения от MCP клиент.

### Тестване на функциите

За да тествате, че функциите на калкулатора работят правилно:

```bash
python test_calculator.py
```

## Отстраняване на неизправности

### Грешки при импорт

Ако видите `ModuleNotFoundError: No module named 'mcp'`, инсталирайте MCP Python SDK:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### Грешки с JSON-RPC при директно изпълнение

Грешки като "Invalid JSON: EOF while parsing a value" при стартиране на сървъра директно са очаквани. Сървърът се нуждае от съобщения от MCP клиент, а не директен вход от терминал.
