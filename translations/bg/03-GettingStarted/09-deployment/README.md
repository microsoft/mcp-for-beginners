# Разгръщане на MCP сървъри

> [!NOTE]
> Примерите за конфигурация, които използват `/sse` крайна точка, са насочени към наследената HTTP+SSE
> транспортна технология. Отдалечените MCP сървъри `2026-07-28` използват Streamable HTTP, обикновено на
> сървърно дефинирана крайна точка като `/mcp`.

Разгръщането на вашия MCP сървър позволява на други да имат достъп до неговите инструменти и ресурси извън вашата локална среда. Съществуват няколко стратегии за разгръщане, които трябва да се вземат под внимание, в зависимост от вашите изисквания за мащабируемост, надеждност и лесно управление. По-долу ще намерите указания за разгръщане на MCP сървъри локално, в контейнери и в облака.

## Преглед

Този урок обхваща как да разположите вашето MCP Server приложение.

## Цели на обучението

Към края на този урок ще можете да:

- Оцените различни подходи за разгръщане.
- Разгърнете вашето приложение.

## Локална разработка и разгръщане

Ако вашият сървър е предназначен да се използва на потребителските машини, можете да следвате следните стъпки:

1. **Изтеглете сървъра**. Ако не сте писали сървъра, изтеглете го първо на вашата машина.
1. **Стартирайте сървърния процес**: Стартирайте вашето MCP сървърно приложение

За SSE (не е необходимо за stdio тип сървър)

1. **Конфигурирайте мрежата**: Уверете се, че сървърът е достъпен на очаквания порт
1. **Свържете клиенти**: Използвайте локални URL адреси като `http://localhost:3000`

## Разгръщане в облака

MCP сървърите могат да бъдат разположени в различни облачни платформи:

- **Serverless функции**: Разгърнете леки MCP сървъри като serverless функции
- **Контейнерни услуги**: Използвайте услуги като Azure Container Apps, AWS ECS или Google Cloud Run
- **Kubernetes**: Разгръщайте и управлявайте MCP сървъри в Kubernetes клъстери за висока наличност

### Пример: Azure Container Apps

Azure Container Apps поддържат разгръщането на MCP сървъри. Това все още е в процес на разработка и в момента поддържа SSE сървъри.

Ето как можете да го направите:

1. Клонирайте едно хранилище:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. Стартирайте го локално, за да тествате:

  ```sh
  uv venv
  uv sync

  # linux/macOS
  export API_KEYS=<AN_API_KEY>
  # windows
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. За да го опитате локално, създайте *mcp.json* файл в директория *.vscode* и добавете следното съдържание:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  След като SSE сървърът започне работа, можете да кликнете върху иконата за стартиране в JSON файла, трябва да видите как GitHub Copilot разпознава инструментите на сървъра, вижте иконата Tool.

1. За да разположите, изпълнете следната команда:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

Ето ви, разположете го локално, разположете го в Azure чрез тези стъпки.
