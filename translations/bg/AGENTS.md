# AGENTS.md

## Преглед на проекта

**MCP за начинаещи** е отворена учебна програма за изучаване на Model Context Protocol (MCP) - стандартизиран рамков протокол за взаимодействие между AI модели и клиентски приложения. Това хранилище предоставя изчерпателни учебни материали с практични примери с код на няколко програмни езика.

### Ключови технологии

- **Програмиращи езици**: C#, Java, JavaScript, TypeScript, Python, Rust
- **Фреймуъркове и SDK**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **Бази данни**: PostgreSQL с разширение pgvector
- **Облачни платформи**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **Инструменти за изграждане**: npm, Maven, pip, Cargo
- **Документация**: Markdown с автоматизиран превод на множество езици (над 48 езика)

### Архитектура

- **11 основни модула (00-11)**: Последователен учебен път от основи до напреднали теми
- **Практически лаборатории**: Практически упражнения с пълен код на решения на няколко езика
- **Примерни проекти**: Работещи реализации на MCP сървър и клиент
- **Система за превод**: Автоматизиран GitHub Actions workflow за поддръжка на множество езици
- **Графични ресурси**: Централизирана директория с изображения с преведени версии

#### Кандидатски MCP работен процес: `validate_curriculum_change`

##### Цел

Проверка на здравето на промените в документацията на учебната програма и представителен примерен код
преди сливане.

##### Входове

- `changed_paths: string[]` (задължително) - относителни пътища, променени в PR.
- `run_docs_lint: boolean` (по подразбиране `true`)
- `run_links_audit: boolean` (по подразбиране `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (по подразбиране всички `false`)

##### Изходи

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### Права

- Четене на файлове от работната област и писане на артефакти, генерирани от инструменти (например доклади за lint,
  дневници от тестове) само; без писане в `translations/` или
  `translated_images/`.
- Изпълнение на локални shell команди.
- Допълнителен достъп до мрежата само за възстановяване на пакети (`npm ci`,
  `python -m pip install`, разрешаване на зависимости с `mvn`).
- Без разрешение за push, сливане или модифициране на `translations/` или
  `translated_images/`.

##### Режими на повреда

- `E_NO_INPUT_PATHS`: `changed_paths` е празен.
- `E_INVALID_PATH`: входният път излиза извън корена на хранилището.
- `E_LINT_FAILED`: markdown lint изходен код е различен от нула.
- `E_LINK_AUDIT_FAILED`: командата за проверка на линкове изходен код е различен от нула.
- `E_SAMPLE_TEST_FAILED`: тест/съставяне на пример изходен код е различен от нула.
- `E_TIMEOUT`: командата е надвишила конфигурираното време за изчакване.

##### Препоръчан договор за CI

За автоматизация на валидацията, конфигурирайте CI задача, която:

- Стартира при pull requests, засягащи `*.md`, примерен код или този файл.
- Изпълнява точно описаните по-горе команди.
- Запазва дневници като артефакти.
- Проваля задачата при всеки изходен код различен от нула.
