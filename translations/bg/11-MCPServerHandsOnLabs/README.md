# 🚀 MCP сървър с PostgreSQL - Пълен учебен наръчник

## 🧠 Преглед на учебния път за интеграция на MCP с база данни

Този изчерпателен учебен наръчник ви учи как да изграждате производствени **Model Context Protocol (MCP) сървъри**, които се интегрират с бази данни чрез практическа реализация за търговска аналитика. Ще научите корпоративни модели, включително **Row Level Security (RLS)**, **семантично търсене**, **интеграция с Azure AI** и **мулти-клиентски достъп до данни**.

Независимо дали сте бекенд разработчик, AI инженер или архитект на данни, този наръчник предоставя структурирано обучение с реални примери и практически упражнения, които ви водят през следния MCP сървър https://github.com/microsoft/MCP-Server-and-PostgreSQL-Sample-Retail.

### 💻 Какво ще изградите

В края на този учебен път ще имате изграден пълен **Zava Retail Analytics MCP сървър** с:

- **Мулти-таблична търговска база данни** с клиентски поръчки, продукти и наличности
- **Row Level Security** за изолация на данни по магазини
- **Семантично търсене на продукти** чрез Azure OpenAI вграждания
- **Интеграция на AI чат във VS Code** за заявки на естествен език
- **Производствено внедряване** с Docker и Azure
- **Пълно мониториране** с Application Insights
