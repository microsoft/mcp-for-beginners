## 🔧 Wat zijn MCP-servers: Een beginnersgids

### Wat zijn MCP-servers?

Als beginner in het Model Context Protocol (MCP) vraag je je misschien af: "Wat is een MCP-server precies en waarom zou het mij iets kunnen schelen?" Laten we beginnen met een eenvoudige vergelijking.

Zie MCP-servers als gespecialiseerde assistenten die je AI-codeermaatje (zoals GitHub Copilot) helpen verbinden met externe tools en diensten. Net zoals je verschillende apps op je telefoon gebruikt voor verschillende taken — één voor het weer, één voor navigatie, één voor bankieren — geven MCP-servers je AI-assistent de mogelijkheid om met verschillende ontwikkeltools en diensten te communiceren.

### Het probleem dat MCP-servers oplossen

Voor de komst van MCP-servers moest je:
- Je Azure-resources controleren
- Een GitHub-issue aanmaken
- Je database bevragen
- Documentatie doorzoeken

Je code pauzeren, een browser openen, naar de juiste website navigeren en deze taken handmatig uitvoeren. Deze constante contextwisselingen onderbreken je flow en verminderen je productiviteit.

### Hoe MCP-servers je ontwikkelervaring transformeren

Met MCP-servers kun je in je ontwikkelomgeving blijven (VS Code, Visual Studio, enz.) en gewoon je AI-assistent vragen deze taken uit te voeren. Bijvoorbeeld:

**In plaats van deze traditionele workflow:**
1. Stop met coderen
2. Open de browser
3. Navigeer naar het Azure-portaal
4. Zoek opslagaccountgegevens op
5. Ga terug naar VS Code
6. Hervat het coderen

**Kun je nu dit doen:**
1. Vraag aan AI: "Wat is de status van mijn Azure-opslagaccounts?"
2. Ga door met coderen met de gegeven informatie

### Belangrijkste voordelen voor beginners

## Aan de slag met MCP in VS Code en Visual Studio 🚀

Het instellen van deze MCP-servers is eenvoudig als je Visual Studio Code of Visual Studio 2022 met GitHub Copilot gebruikt.

### VS Code Setup

Hier is het basisproces voor VS Code:

1. **Schakel Agent-modus in**: Schakel in VS Code over naar Agent-modus in het Copilot Chat-venster
2. **Configureer MCP-servers**: Voeg serverconfiguraties toe aan je settings.json-bestand van VS Code
3. **Start servers**: Klik op de knop "Start" voor elke server die je wilt gebruiken
4. **Selecteer tools**: Kies welke MCP-servers je wilt inschakelen voor je huidige sessie

Voor gedetailleerde setupinstructies, zie de [VS Code MCP-documentatie](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Pro-tip: Beheer MCP-servers als een professional!**
> 
> Het Extensies-venster van VS Code bevat nu een [handige nieuwe UI om geïnstalleerde MCP-servers te beheren](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Je hebt snelle toegang om geïnstalleerde MCP-servers te starten, stoppen en beheren met een duidelijke, eenvoudige interface. Probeer het eens uit!

### Visual Studio 2022 Setup

Voor Visual Studio 2022 (versie 17.14 of later):

1. **Schakel Agent-modus in**: Klik op de dropdown "Ask" in het GitHub Copilot Chat-venster en selecteer "Agent"
2. **Maak configuratiebestand**: Maak een `.mcp.json`-bestand aan in je oplossingmap (aanbevolen locatie: `<SOLUTIONDIR>\.mcp.json`)
3. **Configureer servers**: Voeg je MCP-serverconfiguraties toe met het standaard MCP-formaat
4. **Toolgoedkeuring**: Keur de tools goed die je wilt gebruiken met passende machtigingen wanneer hierom wordt gevraagd

Voor gedetailleerde Visual Studio setupinstructies, zie de [Visual Studio MCP-documentatie](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Elke MCP-server heeft zijn eigen configuratievereisten (zoals verbindingstrings, authenticatie, etc.), maar het setup-patroon is consistent in beide IDE’s.

### 1. 📚 Microsoft Learn Docs MCP Server

[![Installeren in VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![Installeren in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**Wat het doet**: De Microsoft Learn Docs MCP-server is een cloud-hosted service die AI-assistenten real-time toegang geeft tot officiële Microsoft-documentatie via het Model Context Protocol. Het maakt verbinding met `https://learn.microsoft.com/api/mcp` en stelt semantisch zoeken mogelijk over Microsoft Learn, Azure-documentatie, Microsoft 365-documentatie en andere officiële Microsoft-bronnen.

**Waarom het nuttig is**: Hoewel het misschien lijkt als "alleen documentatie," is deze server cruciaal voor elke ontwikkelaar die met Microsoft-technologieën werkt. Een van de grootste klachten van .NET-ontwikkelaars over AI-codeerassistenten is dat ze niet up-to-date zijn met de laatste .NET- en C#-versies. De Microsoft Learn Docs MCP-server lost dit op door real-time toegang te bieden tot de meest actuele documentatie, API-referenties en best practices. Of je nu werkt met de nieuwste Azure SDK's, nieuwe C# 13-functies verkent of geavanceerde Aspire-patronen implementeert, deze server zorgt ervoor dat je AI-assistent toegang heeft tot de gezaghebbende, up-to-date informatie die nodig is voor het genereren van accurate, moderne code.

**Praktisch gebruik**: "Wat zijn de az cli-commando's om een Azure containerapp te maken volgens de officiële Microsoft Learn-documentatie?" of "Hoe configureer ik Entity Framework met dependency injection in ASP.NET Core?" Of wat dacht je van "Bekijk deze code om te controleren of deze overeenkomt met de prestatieaanbevelingen in de Microsoft Learn-documentatie." De server biedt uitgebreide dekking over Microsoft Learn, Azure-documentatie en Microsoft 365-documentatie via geavanceerd semantisch zoeken om de meest contextueel relevante informatie te vinden. Het levert tot 10 hoogwaardige inhoudsstukken met artikeltitels en URL's, altijd met toegang tot de meest recente Microsoft-documentatie zodra deze wordt gepubliceerd.

**Uitgelicht voorbeeld**: De server biedt de `microsoft_docs_search`-tool die semantisch zoekt in de officiële technische documentatie van Microsoft. Eenmaal geconfigureerd kun je vragen stellen zoals "Hoe implementeer ik JWT-authenticatie in ASP.NET Core?" en gedetailleerde, officiële antwoorden met bronlinks krijgen. De zoekkwaliteit is uitstekend omdat het de context begrijpt – een vraag over "containers" in een Azure-context geeft Azure Container Instances-documentatie, terwijl dezelfde term in een .NET-context relevante C#-collectie-informatie teruggeeft.

Dit is bijzonder nuttig voor snel veranderende of recent bijgewerkte bibliotheken en use cases. Bijvoorbeeld, in enkele recente codeerprojecten wilde ik functies gebruiken in de nieuwste releases van Aspire en Microsoft.Extensions.AI. Door de Microsoft Learn Docs MCP-server toe te voegen, kon ik profiteren van niet alleen API-docs, maar ook van doorloop- en begeleiding die net was gepubliceerd.

### 2. ☁️ Azure MCP Server


[![Installeren in VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Installeren in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Wat het doet**: De Azure MCP Server is een uitgebreide suite van meer dan 15 gespecialiseerde Azure-servicekoppelingen die het volledige Azure-ecosysteem in je AI-werkstroom brengen. Dit is niet zomaar een enkele server – het is een krachtige verzameling die resourcebeheer, databaseconnectiviteit (PostgreSQL, SQL Server), Azure Monitor loganalyse met KQL, Cosmos DB-integratie en nog veel meer omvat.

**Waarom het nuttig is**: Naast het beheren van Azure-resources verbetert deze server aanzienlijk de codekwaliteit bij het werken met Azure SDK's. Wanneer je Azure MCP in Agent-modus gebruikt, helpt het je niet alleen code te schrijven, maar helpt het je *betere* Azure-code te schrijven die de actuele authenticatiepatronen volgt, best practices voor foutenafhandeling hanteert en gebruikmaakt van de nieuwste SDK-functies. In plaats van generieke code te krijgen die misschien werkt, krijg je code die de aanbevolen patronen van Azure volgt voor productie-omgevingen.

**Belangrijke modules omvatten**:
- **🗄️ Databasekoppelingen**: Directe toegang in natuurlijke taal tot Azure Database voor PostgreSQL en SQL Server
- **📊 Azure Monitor**: KQL-gestuurde loganalyse en operationele inzichten
- **🌐 Resourcebeheer**: Volledig lifecyclebeheer van Azure-resources
- **🔐 Authenticatie**: DefaultAzureCredential en managed identity-patronen
- **📦 Opslagdiensten**: Blob-opslag, Wachtrijopslag en Tabelopslag-operaties
- **🚀 Containerservices**: Azure Container Apps, Container Instances en AKS-beheer
- **En vele andere gespecialiseerde koppelingen**

**Praktisch gebruik**: "Toon mijn Azure opslagaccounts", "Vraag mijn Log Analytics-werkruimte om fouten in het laatste uur op te zoeken" of "Help me een Azure-applicatie te bouwen met Node.js met de juiste authenticatie"

**Volledig demo scenario**: Hier is een complete walkthrough die de kracht toont van de combinatie van Azure MCP met de GitHub Copilot for Azure-extensie in VS Code. Wanneer je beide hebt geïnstalleerd en de prompt geeft:

> "Maak een Python-script dat een bestand uploadt naar Azure Blob Storage met gebruik van DefaultAzureCredential authenticatie. Het script moet verbinding maken met mijn Azure-opslagaccount genaamd 'mycompanystorage', uploaden naar een container genaamd 'documents', een testbestand maken met de huidige tijdstempel om te uploaden, fouten netjes afhandelen en informatieve uitvoer geven, Azure best practices volgen voor authenticatie en foutenafhandeling, opmerkingen bevatten die uitleggen hoe DefaultAzureCredential authenticatie werkt, en het script goed gestructureerd maken met correcte functies en documentatie."

De Azure MCP Server genereert een compleet, productie-klaar Python-script dat:
- De nieuwste Azure Blob Storage SDK gebruikt met correcte async-patronen
- DefaultAzureCredential implementeert met een uitgebreide uitleg over het fallback-mechanisme
- Robuuste foutafhandeling bevat met specifieke Azure exceptietypes
- Azure SDK best practices volgt voor resourcebeheer en verbindingsbeheer
- Gedetailleerde logging en informatieve console-uitvoer levert
- Een correct gestructureerd script creëert met functies, documentatie en type hints

Wat dit opmerkelijk maakt, is dat je zonder Azure MCP wellicht generieke blob storage code krijgt die werkt maar niet de actuele Azure-patronen volgt. Met Azure MCP krijg je code die de nieuwste authenticatiemethoden gebruikt, Azure-specifieke foutscenario’s afhandelt en de aanbevolen praktijken van Microsoft voor productieapplicaties volgt.

**Uitgelicht voorbeeld**: Ik heb moeite gehad om de specifieke commando's voor de `az` en `azd` CLI's te onthouden voor ad-hoc gebruik. Het is altijd een tweestapsproces voor mij: eerst de syntaxis opzoeken, dan het commando uitvoeren. Vaak ga ik gewoon naar de portal en klik wat rond om mijn werk te doen omdat ik niet wil toegeven dat ik de CLI-syntaxis niet herinner. Gewoon kunnen beschrijven wat ik wil, is geweldig, en nog beter dat ik dat kan doen zonder mijn IDE te verlaten!

Er is een geweldige lijst met use cases in de [Azure MCP repository](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) om je op weg te helpen. Voor uitgebreide installatierichtlijnen en geavanceerde configuratieopties, bekijk de [officiële Azure MCP documentatie](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

### 3. 🐙 GitHub MCP Server

[![Installeren in VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Installeren in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**Wat het doet**: De officiële GitHub MCP Server biedt naadloze integratie met het volledige GitHub-ecosysteem, met zowel gehoste remote-toegang als lokale Docker-deploy opties. Dit gaat verder dan basisrepository-operaties – het is een uitgebreide toolkit die GitHub Actions beheer, pull request-workflows, issue tracking, beveiligingsscan, notificaties en geavanceerde automatiseringsmogelijkheden bevat.

**Waarom het nuttig is**: Deze server verandert hoe je met GitHub omgaat door de volledige platformervaring direct in je ontwikkelomgeving te brengen. In plaats van voortdurend te schakelen tussen VS Code en GitHub.com voor projectbeheer, codebeoordelingen en CI/CD monitoring, kun je alles afhandelen via commando's in natuurlijke taal terwijl je gefocust blijft op je code.

> **ℹ️ Opmerking: Verschillende soorten 'Agents'**
> 
> Verwar deze GitHub MCP Server niet met GitHub's Coding Agent (de AI-agent die je issues kunt toewijzen voor geautomatiseerde codeertaken). De GitHub MCP Server werkt binnen VS Code's Agent-modus om GitHub API-integratie te bieden, terwijl GitHub's Coding Agent een aparte functie is die pull requests maakt wanneer toegewezen aan GitHub issues.

**Belangrijke mogelijkheden omvatten**:
- **⚙️ GitHub Actions**: Volledig CI/CD pipelinebeheer, workflow monitoring en artifactafhandeling
- **🔀 Pull Requests**: Aanmaken, beoordelen, samenvoegen en beheren van PR’s met uitgebreide statusmonitoring
- **🐛 Issues**: Volledig lifecyclebeheer van issues, inclusief commentaar, labelen en toewijzen
- **🔒 Beveiliging**: Code scanning waarschuwingen, geheime detectie en Dependabot integratie
- **🔔 Notificaties**: Slim beheer van notificaties en controle over repository-abonnementen
- **📁 Repositorybeheer**: Bestandoperaties, branchbeheer en repositoryadministratie
- **👥 Samenwerking**: Zoeken naar gebruikers en organisaties, teambeheer en toegangscontrole

**Praktisch gebruik**: "Maak een pull request vanaf mijn feature branch", "Toon alle mislukte CI-runs deze week", "Lijst openstaande beveiligingsmeldingen voor mijn repositories" of "Vind alle aan mij toegewezen issues in mijn organisaties"

**Volledig demo scenario**: Hier is een krachtige workflow die de mogelijkheden van de GitHub MCP Server demonstreert:

> "Ik moet me voorbereiden op onze sprintreview. Toon alle pull requests die ik deze week heb gemaakt, controleer de status van onze CI/CD pipelines, maak een samenvatting van eventuele beveiligingsmeldingen die we moeten aanpakken en help me met het opstellen van release notes gebaseerd op samengevoegde PR’s met het label 'feature'."

De GitHub MCP Server zal:
- Je recente pull requests opvragen met gedetailleerde statusinformatie
- Workflow-runs analyseren en eventuele fouten of prestatieproblemen markeren
- Resultaten van beveiligingsscans compileren en prioriteit geven aan kritieke waarschuwingen
- Uitgebreide release notes genereren door informatie te extraheren uit samengevoegde PR’s
- Uitvoerbare volgende stappen bieden voor sprintplanning en releasevoorbereiding

**Uitgelicht voorbeeld**: Ik vind het geweldig om dit te gebruiken voor code review-workflows. In plaats van te springen tussen VS Code, GitHub-notificaties en pull request-pagina’s, kan ik zeggen "Toon alle PR’s die wachten op mijn review" en daarna "Voeg een opmerking toe aan PR #123 met een vraag over de foutafhandeling in de authenticatiemethode." De server beheert de GitHub API-aanroepen, behoudt de context van de discussie en helpt zelfs om constructievere reviewcommentaren op te stellen.

**Authenticatie-opties**: De server ondersteunt zowel OAuth (naadloos in VS Code) als Personal Access Tokens, met configureerbare toolsets om alleen de GitHub-functionaliteit te activeren die je nodig hebt. Je kunt het draaien als een gehoste remote service voor directe setup of lokaal via Docker voor volledige controle.

> **💡 Pro-tip**
> 
> Activeer alleen de toolsets die je nodig hebt door de `--toolsets` parameter te configureren in je MCP serverinstellingen om de contextgrootte te verminderen en de AI-toolselectie te verbeteren. **Waarom het nuttig is**: Essentieel voor moderne documentatieworkflows! MarkItDown verwerkt een indrukwekkend scala aan bestandsformaten terwijl het cruciale documentstructuur behoudt zoals koppen, lijsten, tabellen en links. In tegenstelling tot eenvoudige tekstdetectietools richt het zich op het behouden van semantische betekenis en opmaak die waardevol is voor zowel AI-verwerking als menselijke leesbaarheid.

**Ondersteunde bestandsformaten**:
- **Office Documenten**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Media Bestanden**: Afbeeldingen (met EXIF-metadata en OCR), Audio (met EXIF-metadata en spraaktranscriptie)
- **Webinhoud**: HTML, RSS-feeds, YouTube-URL's, Wikipedia-pagina's
- **Dataformaten**: CSV, JSON, XML, ZIP-bestanden (verwerkt inhoud recursief)
- **Publicatieformaten**: EPub, Jupyter-notebooks (.ipynb)
- **E-mail**: Outlook-berichten (.msg)
- **Geavanceerd**: Azure Document Intelligence-integratie voor verbeterde PDF-verwerking

**Geavanceerde mogelijkheden**: MarkItDown ondersteunt LLM-gestuurde afbeeldingsbeschrijvingen (wanneer voorzien van een OpenAI-client), Azure Document Intelligence voor verbeterde PDF-verwerking, audiotranscriptie van spraakinhoud en een plug-insysteem voor uitbreiding naar extra bestandsformaten.

**Praktisch gebruik**: "Zet deze PowerPoint-presentatie om naar Markdown voor onze documentatiesite", "Extraheer tekst uit deze PDF met correcte kopstructuur" of "Transformeer deze Excel-spreadsheet naar een leesbaar tabel-formaat"

**Uitgelicht voorbeeld**: Om de [MarkItDown-documentatie](https://github.com/microsoft/markitdown#why-markdown) te citeren:

> Markdown lijkt erg op platte tekst, met minimale markering of opmaak, maar biedt toch een manier om belangrijke documentstructuur weer te geven. Mainstream LLM's, zoals OpenAI's GPT-4o, "spreken" van nature Markdown en verwerken Markdown vaak ongevraagd in hun antwoorden. Dit suggereert dat ze zijn getraind op enorme hoeveelheden tekst in Markdown-formaat en het goed begrijpen. Als nevenvoordeel zijn Markdown-conventies ook zeer token-efficiënt.

MarkItDown is zeer goed in het behouden van documentstructuur, wat belangrijk is voor AI-workflows. Bijvoorbeeld, bij het converteren van een PowerPoint-presentatie behoudt het de diaorganisatie met de juiste koppen, extraheert tabellen als Markdown-tabellen, voegt alt-tekst toe voor afbeeldingen en verwerkt zelfs de sprekernotities. Grafieken worden omgezet in leesbare datatabellen en de resulterende Markdown behoudt de logische flow van de originele presentatie. Dit maakt het perfect voor het voeden van presentatie-inhoud naar AI-systemen of het aanmaken van documentatie uit bestaande dia's.

## 📋 Conclusie

Het Model Context Protocol (MCP) verandert hoe ontwikkelaars omgaan met AI-assistenten en externe tools. Deze 10 Microsoft MCP-servers tonen de kracht van gestandaardiseerde AI-integratie, waardoor naadloze workflows ontstaan die ontwikkelaars in hun flowstate houden terwijl ze krachtige externe mogelijkheden gebruiken.

Van de uitgebreide integratie in het Azure-ecosysteem tot gespecialiseerde tools zoals Playwright voor browserautomatisering en MarkItDown voor documentverwerking, tonen deze servers hoe MCP de productiviteit kan verhogen in diverse ontwikkelscenario’s. Het gestandaardiseerde protocol zorgt ervoor dat deze tools naadloos samenwerken en zo een samenhangende ontwikkelervaring creëren.

Terwijl het MCP-ecosysteem zich blijft ontwikkelen, is het belangrijk om betrokken te blijven bij de community, nieuwe servers te verkennen en aangepaste oplossingen te bouwen om je ontwikkelproductiviteit te maximaliseren. Het open standaardeigenschap van MCP betekent dat je tools van verschillende leveranciers kunt combineren om de perfecte workflow voor jouw specifieke behoeften te creëren.
