## 🏔️ הדרכת אבטחה מעשית

לצורך ניסיון יישום מעשי, אנו ממליצים על **[סדנת פסגת אבטחת MCP (שרפה)](https://azure-samples.github.io/sherpa/)** - משלחת מודרכת מקיפה לאבטחת שרתי MCP ב-Azure. הסדנה מכסה את כל עשרת הסיכונים המובילים של OWASP MCP באמצעות מתודולוגיית "פגיעות → ניצול → תיקון → אימות".

כל ההנחיות במסמך זה תואמות את **[מדריך האבטחה של OWASP MCP Azure](https://microsoft.github.io/mcp-azure-security-guide/)** להנחיות יישום ספציפיות ל-Azure.

## הנחיות אבטחה חיוניות ליישום MCP

פרוטוקול הקשר המודלי מציג אתגרים ייחודיים לאבטחה החורגים
מאבטחת תוכנה מסורתית. הנחיות אלה מטפלות בדרישות יסוד
ואיומים ספציפיים ל-MCP כולל הזרקות פקודות, הרעלת כלים,
חטיפת מצבי עסק (state-handle), בעיות של נציג מבולבל, ופגיעות בנתיבי אסימון.


### **דרישות אבטחה חובה**

**דרישות קריטיות מהמפרט MCP:**

> **אסור**: שרתי MCP **אסור** לקבל כל אסימונים שלא הונפקו במפורש עבור שרת ה-MCP
> 
> **חובה**: שרתי MCP המיישמים הרשאה **חובה** לאמת את כל הבקשות הנכנסות
>  
> **אסור**: שרתי MCP **אסור** להשתמש במפגשים לאימות
>
> **חובה**: שרתי Proxy של MCP המשתמשים במזהה לקוח צד שלישי סטטי **חובה**
> לקבל הסכמה עבור כל לקוח MCP לפני העברת ההרשאה

---

## 1. **אבטחת אסימונים ואימות**

**בקרות אימות והרשאה:**
   - **ביקורת הרשאות קפדנית**: ערוך ביקורות מקיפות על לוגיקת ההרשאה של שרת MCP כדי לוודא שרק משתמשים ולקוחות מיועדים יקבלו גישה למשאבים
   - **אינטגרציה עם ספקי זהות חיצוניים**: השתמש בספקי זהות מוכרים כמו Microsoft Entra ID במקום ליישם אימות מותאם אישית
   - **וולידציית קהל אסימון**: תמיד אמת שאסימונים הונפקו במפורש עבור שרת ה-MCP שלך - לעולם אל תקבל אסימוני מקורות עליונים
   - **מחזור חיים תקין לאסימונים**: יישם סיבוב אסימונים מאובטח, מדיניות תפוגה, ומנע מתקפות שיחזור אסימונים

**אחסון אסימונים מוגן:**
   - השתמש ב-Azure Key Vault או מאגרי סודות מאובטחים דומים עבור כל הסודות
   - יישם הצפנה לאסימונים הן במנוחה והן במעבר
   - סיבוב סודות ומעקב שוטף לגילוי גישה לא מורשית

## 2. **אבטחת מצבי עסק ותקשורת**

**הנחיות לאבטחת מצבי עסק:**

- **מצבי עסק אטומים**: השתמש במצבים מאובטחים ולא דטרמיניסטיים עבור
   מצבי יישום החוצים בקשות
- **קישור למשתמש ספציפי**: קשר מצבים בצד השרת ליישות המאומתת ודחה שימוש חוצה משתמשים
- **ניהול מחזור חיים**: תקף ושלול מצבים להגבלת חלונות הפגיעות
- **הרשאה per-request**: לעולם אל תטפל במצב עסק כאימות; אשר כל בקשה המציגה מצב

- **הרשאת מצבי עסק per-request**: לעולם אל תטפל במצב עסק כאימות; אשר כל בקשה המציגה אחד
   אנא אשר כל בקשה המציגה מצב עסק

**אבטחת שכבת התקשורת:**

- דרוש HTTPS עבור תחבורה HTTP מרחוק בסביבת הפקה
- השתמש בבידוד תהליכים ואישורי סביבה לשרתי stdio מקומיים
- הגדר TLS מודרני עם סיבוב ואימות תעודות תקינים

## 3. **הגנה מפני איומי בינה מלאכותית** 🤖

**הגנה מפני הזרקת פקודות:**
   - **מגן פקודות Microsoft**: פרוס מגן פקודות AI לזיהוי וסינון מתקדם של הוראות זדוניות
   - **ניקוי קלט**: אמת ונקה את כל הקלטים למניעת מתקפות הזרקה ובעיות נציג מבולבל
   - **גבולות תוכן**: השתמש במערכות סימון מפרידים ובתיוג נתונים להבחין בין הוראות מהימנות לתוכן חיצוני

**מניעת הרעלת כלים:**
   - **אימות מטא-נתוני כלים**: יישם בדיקות שלמות להגדרות כלים ופיקוח על שינויים בלתי צפויים
   - **מעקב דינמי על כלים**: נטר התנהגות בזמן ריצה והגדר התראות לדפוסי הרצה בלתי צפויים
   - **תהליכי אישור**: דרוש אישור מפורש מהמשתמש לשינויים בכלים ולשינויים ביכולות

## 4. **שליטה בגישה והרשאות**

**עקרון המינימום הרשאה:**
   - הענק לשרתי MCP רק את ההרשאות המינימליות הנדרשות לתפקוד המיועד
   - יישם בקרת גישה מבוססת תפקידים (RBAC) עם הרשאות מפורטות
   - סקירות הרשאות תקופתיות ומעקב רציף אחר עליית הרשאות

**בקרות הרשאות בזמן ריצה:**
   - הטמע הגבלות משאבים למניעת מתקפות ניצול משאבים
   - השתמש בבידוד קונטיינרים לסביבות הרצת כלים  
   - יישם גישה בזמן אמת לביצוע פונקציות ניהוליות

## 5. **בטיחות תוכן ומעקב**

**יישום בטיחות תוכן:**
   - **אינטגרציה עם Azure Content Safety**: השתמש ב-Azure Content Safety לזיהוי תכנים מזיקים, ניסיונות פריצה והפרות מדיניות
   - **ניתוח התנהגותי**: יישם מעקב התנהגותי בזמן ריצה לזיהוי חריגות בהרצת שרת MCP וכלים
   - **תיעוד מקיף**: רישום כל ניסיונות האימות, קריאות כלים ואירועי אבטחה עם אחסון בטוח וללא אפשרות שינוי

**מעקב רציף:**
   - התראות בזמן אמת על דפוסים חשודים וניסיונות גישה לא מורשים  
   - אינטגרציה עם מערכות SIEM לניהול מרכזי של אירועי אבטחה
   - ביקורות אבטחה תקופתיות ובדיקות חדירה של יישומי MCP

## 6. **אבטחת שרשרת אספקה**

**אימות רכיבים:**
   - **סריקת תלותיות**: השתמש בסריקת פגיעויות אוטומטית לכל התלותיות התוכנתיות ורכיבי AI
   - **אימות מקור**: אמת את מקור, רישוי ושלמות המודלים, מקורות הנתונים והשירותים החיצוניים
   - **חבילות חתומות**: השתמש בחבילות חתומות קריפטוגרפית ואמת חתימות לפני הפריסה

**צינור פיתוח מאובטח:**
   - **GitHub Advanced Security**: יישם סריקת סודות, ניתוח תלותיות, וניתוח סטטי של CodeQL
   - **אבטחת CI/CD**: שלב אימות אבטחה לאורך כל צינורות הפריסה האוטומטיים
   - **שלמות ארטיפקטים**: יישם אימות קריפטוגרפי לארטיפקטים והגדרות בפריסה

## 7. **אבטחת OAuth ומניעת נציג מבולבל**

**יישום OAuth 2.1:**
   - **יישום PKCE**: השתמש ב-Proof Key for Code Exchange (PKCE) לכל בקשות ההרשאה
    - **רישום לקוח**: העדף מסמכי Client ID Metadata או רישום מראש; השתמש ברישום לקוח דינמי מיושן רק כפיתרון תאימות
    - **הסכמה מפורשת**: פרוקסי MCP המשתמש במזהה לקוח צד שלישי סטטי חייב לקבל הסכמה עבור כל לקוח לפני העברת ההרשאה
   - **אימות URI הפנייה מחדש**: יישם אימות קפדני של URI הפנייה ומזהי לקוח

**אבטחת פרוקסי:**
   - מנע עקיפת הרשאה באמצעות ניצול מזהה לקוח סטטי

   - נטר גניבת קודי הרשאה וניסיונות גישה לא מורשית ל-API

## 8. **תגובה לאירועים ושחזור**


   - **תגובה אוטומטית**: יישם מערכות אוטומטיות לסיבוב סודות ולבלימת איומים

**יכולות תגובה מהירה:**
   - **תגובה אוטומטית**: יישום מערכות אוטומטיות לסיבוב אישורים ולהכחדת איומים
   - **נהלי החזרה לאחור**: יכולת לחזור במהירות לתצורות ורכיבים ידועים וטובים
   - **יכולות פורנזיות**: מעקבים מפורטים ורישום לחקירת תקריות

**תקשורת ותיאום:**
   - נהלי הסלמה ברורים לתקריות אבטחה
   - אינטגרציה עם צוותי תגובה לתקריות בארגון
   - סימולציות תקריות אבטחה ותרגילי שולחן קבועים

## 9. **ציות ומשילות**

**ציות לרגולציות:**
   - הבטחת יישום MCP התואם לדרישות ספציפיות לתעשייה (GDPR, HIPAA, SOC 2)
   - יישום סיווג נתונים ובקרות פרטיות לעיבוד נתוני AI
   - שמירת תיעוד מקיף לביקורת ציות

**ניהול שינויים:**
   - תהליכי סקירה רשמיים לשינויים במערכת MCP
   - בקרת גרסאות ותהליכי אישור לשינויים בקונפיגורציה
   - הערכות ציות סדירות וניתוח פערים

## 10. **בקרות אבטחה מתקדמות**

**ארכיטקטורת Zero Trust:**
   - **לעולם לא לסמוך, תמיד לאמת**: אימות רציף של משתמשים, מכשירים וחיבורים
   - **מיקרו-סגמנטציה**: בקרות רשת מדויקות המבודדות רכיבי MCP בודדים
   - **גישה מותנית**: בקרות גישה מבוססות סיכון המסתגלות להקשר ולהתנהגות הנוכחיים

**הגנה על יישומים בזמן ריצה:**
   - **הגנה עצמית של יישומים בזמן ריצה (RASP)**: פריסת טכניקות RASP לגילוי איומים בזמן אמת
   - **ניטור ביצועי יישומים**: מעקב אחר חריגות ביצועים שעשויות להעיד על התקפות
   - **מדיניות אבטחה דינמית**: יישום מדיניות אבטחה המסתגלת לנוף האיומים הנוכחי

## 11. **אינטגרציה עם אקוסיסטם אבטחת מיקרוסופט**

**אבטחה מקיפה של מיקרוסופט:**
   - **Microsoft Defender for Cloud**: ניהול מצב אבטחה בענן לעומסי עבודה של MCP
   - **Azure Sentinel**: SIEM ו-SOAR מקומיים בענן לגילוי איומים מתקדם
   - **Microsoft Purview**: ממשל וציות לנתונים עבור זרמי עבודה ונתוני AI

**ניהול זהויות וגישה:**
   - **Microsoft Entra ID**: ניהול זהויות ארגוני עם מדיניות גישה מותנית
   - **ניהול זהויות ממעמד גבוה (PIM)**: גישה ואישור בזמן אמת לפונקציות אדמיניסטרטיביות
   - **הגנת זהות**: גישה מותנית מבוססת סיכון ותגובה אוטומטית לאיומים

## 12. **התפתחות אבטחה רציפה**

**שמירה על עדכניות:**
   - **ניטור מפרטים**: סקירות סדירות של עדכוני מפרט MCP ושינויים בהנחיות אבטחה
   - **מודיעין איומים**: אינטגרציה של פידאי איומים ספציפיים ל-AI ואינדיקטורים לפגיעה
   - **מעורבות בקהילת אבטחה**: השתתפות פעילה בקהילת אבטחת MCP ותוכניות דיווח פגיעויות

**אבטחה אדפטיבית:**
   - **אבטחת למידת מכונה**: שימוש בגילוי חריגות מבוסס ML לזיהוי תבניות התקפה חדשניות
   - **אנליטיקה אבטחתית חיזוי**: יישום מודלים חיזויים לזיהוי איומים מוקדם
   - **אוטומציה באבטחה**: עדכוני מדיניות אבטחה אוטומטיים בהתבסס על מודיעין איומים ושינויים במפרט
