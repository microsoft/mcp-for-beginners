# 🚀 שרת MCP עם PostgreSQL - מדריך למידה שלם

## 🧠 סקירה כללית של מסלול הלמידה לאינטגרציית מסד הנתונים MCP

מדריך למידה מקיף זה ילמד אתכם כיצד לבנות שרתי **Model Context Protocol (MCP)** מוכנים לפרודקשן שמתחברים למסדי נתונים באמצעות מימוש מעשי של ניתוח קמעונאי. תלמדו דפוסים ברמת ארגון כגון **Row Level Security (RLS)**, **חיפוש סמנטי**, **אינטגרציית Azure AI**, ו**גישה מרובת שוכרים לנתונים**.

בין אם אתם מפתח backend, מהנדס AI או ארכיטקט נתונים, מדריך זה מספק למידה מובנית עם דוגמאות אמיתיות ותרגילים מעשיים המדריכים אתכם לאורך שרת ה-MCP הבא https://github.com/microsoft/MCP-Server-and-PostgreSQL-Sample-Retail.

### 💻 מה תוכלו לבנות

לקראת סיום מסלול הלמידה, תבנו שרת MCP של **Zava Retail Analytics** הכולל:

- **מסד נתונים קמעונאי מרובה טבלאות** עם הזמנות לקוחות, מוצרים ומלאי
- **Row Level Security** לבידוד נתונים מבוססי חנות
- **חיפוש סמנטי של מוצרים** באמצעות אמבדינגס מ-Azure OpenAI
- **אינטגרציית VS Code AI Chat** לשאילתות בשפה טבעית
- **הפצה מוכנה לפרודקשן** עם Docker ו-Azure
- **ניטור מקיף** עם Application Insights
