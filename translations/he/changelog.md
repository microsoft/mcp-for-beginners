# יומן שינויים: תכנית MCP למתחילים

מסמך זה משמש כרשומה של כל השינויים המשמעותיים שבוצעו בתכנית Model Context Protocol (MCP) למתחילים. השינויים מתועדים בסדר כרונולוגי הפוך (השינויים החדשים ביותר מופיעים ראשונים).

עדכון תכנית הלימודים באנגלית מגרסת המועמד לשחרור והנחיית הבסיס `2025-11-25`

  ב-38 קבצי תיעוד באנגלית.

  `sampling/createMessage`, ו-`InputRequiredResult.resultType` משתמש ב-

- **הוחלף**: שיעור מצב שיחה של Root Context לא מדויק עם
  שיעור Roots מדויק לפרוטוקול המכסה רמזים למערכת קבצים אינפורמטיבית,
  זרימת סיבובים מרובים נוכחית, גבולות אבטחה, ואפשרויות הגירה.
- **הובהר**: Roots, דגימה, רישום, ורישום דינמי של לקוח בוטלו ב-`2026-07-28`,

  לחיצות יד לאתחול, או מושבי פרוטוקול נשמרות כדוגמאות תאימות מורשת
  במקום להיות מוצגות כמימושים עדכניים.
  דוגמאות תאימות במקום להיות מוצגות כמימושים נוכחיים.
- **הנחיות אבטחה**: עודכנו מדריכי האבטחה העצמאיים לשימוש
  באישור לפי בקשה וידיות מצבי יישום מפורשים במקום
  מזהי session של הפרוטוקול שהוסרו. מסמכי מטא-נתוני מזהה לקוח הם כעת
  הנתיב המועדף לרישום, כאשר DCR מתועד כמתאים בלבד.
- **חומרי תמיכה**: עודכן מדריך הלמידה, רשימת הבדיקה של התורם,
  מקרה הלימוד Publora, ומקרה הלימוד APIM. סיור ה-APIM כעת ממליץ
  על נקודת הקצה הנוכחית Streamable HTTP `/mcp` במקום `/sse` שהוכרז כמבוטל.
- **קישורים קאנוניים**: הוחלפו כתובות ה-URL לפירוט הפסקות והשברי ניסוח באנגלית

  קישורים מפורשים לגרסאות ישנות אם דוגמה עדיין אפופה לכלי ישנים.
- **שמות קבצים יציבים**: שונה שם מדריך הפירוט הסופי ושני מדריכי אבטחה
  להסרת הסיומות של מועמד לשחרור והשנה, ולאחר מכן עודכנו כל הקישורים באנגלית

- **דוגמת הרשאה חדשה**: נוספה דוגמה שנבדקה

### החמרות אבטחה ותיקון פירצות תלות

הפעלנו סריקת אבטחה מלאה על כל מניפסט תלות וקוד המקור בדוגמה, לאחר מכן טפלנו בכל האזהרות ה-npm המדווחות ובממצא קוד אחד. לאחר הטיפול, `npm audit` מדווח על **0 פרצות אבטחה** בכל תיקייה שבודקה.

#### פגיעויות תלות npm (טרנזיטיביות) — תוקנו

בדקנו את כל 15 קבצי `package-lock.json` שהתחייבו. הפגיעויות התרכזו בתלויות הטרנזיטיביות שהביאו כלי הפיתוח MCP Inspector, לקוח OpenAI ו-SDK של MCP; כולם טופלו כעת ללא שבירת הדוגמאות:
- **10-StreamliningAIWorkflows.../lab4/code/github_mcp_server/inspector** ו- **lab3/code/weather_mcp/inspector**: שודרג `@modelcontextprotocol/inspector` (`0.16.6` / `0.14.1` → `0.22.0`), מה ששחרר את האזהרות ״בנדל״ של `ajv`, `brace-expansion`, `diff`, `path-to-regexp` ו-`ws`. נוסף ערך npm `overrides` שמאלץ את ה`shell-quote@1.8.4` המתוקן לבטל את האזהרה הקריטית הנותרת שנשא `concurrently`; נוצר מחדש שני קבצי הנעילה (כעת ללא פגיעויות)
- **03-GettingStarted/samples/typescript**: `npm audit fix` שידרג את `qs` העקיף (בינוני) לגירסה מתוקנת
- **03-GettingStarted/samples/javascript**: `npm audit fix` שידרג את `hono` העקיף (בינוני) לגירסה מתוקנת
- **03-GettingStarted/03-llm-client/solution/typescript**: `npm audit fix` שידרג את `form-data` העקיף (גבוה) לגירסה מתוקנת
- **03-GettingStarted/11-simple-auth/solution/typescript**: נוצר הקובץ החסר `package-lock.json` כך שהפרויקט ניתן לשחזור ולאימות (0 פגיעויות)

#### תיקון אבטחה ברמת קוד (OWASP A03: Injection)

- **10-StreamliningAIWorkflows.../lab4/code/github_mcp_server/src/server.py**: הוסר `shell=True` מכלי `open_in_vscode`. ה-`subprocess.run(["start", "", vscode_path, folder_path], shell=True)` הקודם אפשר תווי מטא של shell בנתיב של תיקיה להתפרש על ידי `cmd.exe` (וקטור הזרקת פקודה). כעת הוא מפעיל ישירות את `Code.exe` שנפתר עם התיקיה כארגומנט — ללא shell — שזה שווה פונקציונלית ובטוח

#### בדיקת תלות בפייתון

- בוצע ביקורת על כל סט דרישות הפייתון עם `pip-audit`. `05-AdvancedTopics` ו-`03-GettingStarted/samples/python` דיווחו על **אין פגיעויות ידועות** (הטווחים שלהם `mcp` / `httpx` / `pydantic` / `python-dotenv` מתאימים לגרסאות המתוקנות הנוכחיות)
- **09-CaseStudy/docs-mcp/solution/python/requirements.txt**: `pip-audit` סימן תלות טרנזיטיבית **`werkzeug` 3.1.1** עם שלוש `safe_join` אזהרות DoS הקשורות לשם התקן של Windows — `CVE-2025-66221`, `CVE-2026-21860`, ו-`CVE-2026-27199` (כולן תוקנו ב-3.1.6). נוספה הצמדה בטיחותית מפורשת `werkzeug>=3.1.6` כך שהגרסה המתוקנת תיפתר; אומתה שההגבלה מתפענחת כיאות עם ה `chainlit` / `mcp` / `semantic-kernel` סטאק
