## 🔧 Memahami Pelayan MCP: Panduan Untuk Pemula

### Apakah Pelayan MCP?

Sebagai pemula kepada Protokol Konteks Model (MCP), anda mungkin tertanya-tanya: "Apakah sebenarnya pelayan MCP, dan mengapa saya harus ambil peduli?" Mari kita mulakan dengan satu analogi mudah.

Fikirkan pelayan MCP sebagai pembantu khusus yang membantu rakan pembantu AI pengkodan anda (seperti GitHub Copilot) berhubung dengan alat dan perkhidmatan luaran. Sama seperti bagaimana anda mungkin menggunakan aplikasi berbeza pada telefon anda untuk tugasan berbeza—satu untuk cuaca, satu untuk navigasi, satu untuk perbankan—pelayan MCP memberi pembantu AI anda keupayaan untuk berinteraksi dengan pelbagai alat dan perkhidmatan pembangunan.

### Masalah Yang Diselesaikan Pelayan MCP

Sebelum pelayan MCP, jika anda ingin:
- Semak sumber Azure anda
- Cipta isu GitHub 
- Kuiri pangkalan data anda
- Cari melalui dokumentasi

Anda perlu berhenti menulis kod, buka penyemak imbas, pergi ke laman web yang sesuai, dan lakukan tugasan ini secara manual. Penukaran konteks yang berterusan ini memecahkan aliran kerja anda dan mengurangkan produktiviti.

### Bagaimana Pelayan MCP Mengubah Pengalaman Pembangunan Anda

Dengan pelayan MCP, anda boleh kekal dalam persekitaran pembangunan anda (VS Code, Visual Studio, dll.) dan hanya minta pembantu AI anda mengendalikan tugasan ini. Contohnya:

**Sebaliknya daripada aliran kerja tradisional ini:**
1. Berhenti menulis kod
2. Buka penyemak imbas
3. Pergi ke portal Azure
4. Cari butiran akaun storan
5. Kembali ke VS Code
6. Sambung semula menulis kod

**Kini anda boleh lakukan ini:**
1. Tanya AI: "Apakah status akaun storan Azure saya?"
2. Teruskan menulis kod dengan maklumat yang diberikan

### Manfaat Utama untuk Pemula

#### 1. 🔄 **Kekal Dalam Keadaan Aliran Anda**
- Tidak perlu beralih antara pelbagai aplikasi
- Kekalkan fokus pada kod yang anda tulis
- Kurangkan beban mental menguruskan pelbagai alat

#### 2. 🤖 **Gunakan Bahasa Semula Jadi Daripada Arahan Kompleks**
- Daripada menghafal sintaks SQL, terangkan data apa yang anda perlukan
- Daripada mengingati arahan Azure CLI, terangkan apa yang anda ingin capai
- Biarkan AI mengendalikan butiran teknikal sementara anda fokus pada logik

#### 3. 🔗 **Sambungkan Pelbagai Alat Bersama**
- Cipta aliran kerja yang berkuasa dengan menggabungkan perkhidmatan berbeza
- Contoh: "Dapatkan semua isu GitHub terkini dan cipta item kerja Azure DevOps yang sepadan"
- Bina automasi tanpa menulis skrip yang kompleks

#### 4. 🌐 **Akses Ekosistem Yang Berkembang**
- Manfaatkan pelayan yang dibina oleh Microsoft, GitHub, dan syarikat lain
- Campur dan padan alat dari vendor berbeza dengan lancar
- Sertai ekosistem piawai yang berfungsi merentasi pelbagai pembantu AI

#### 5. 🛠️ **Belajar Dengan Melakukan**
- Mulakan dengan pelayan yang telah dibina untuk memahami konsep
- Secara berperingkat bina pelayan sendiri apabila anda semakin selesa
- Gunakan SDK dan dokumentasi yang tersedia untuk membimbing pembelajaran anda

```
3. Create an issue for testing
```

```
3. Ask AI: "How do I deploy this to Azure according to the docs?"

5. Continue coding with all the information you need
```

## Memulakan dengan MCP dalam VS Code dan Visual Studio 🚀

Menyediakan pelayan MCP ini adalah mudah jika anda menggunakan Visual Studio Code atau Visual Studio 2022 dengan GitHub Copilot.

### Persediaan VS Code

Berikut adalah proses asas untuk VS Code:

1. **Aktifkan Mod Ejen**: Dalam VS Code, beralih ke mod Ejen dalam tetingkap Copilot Chat
2. **Konfigurasikan Pelayan MCP**: Tambah konfigurasi pelayan ke dalam fail settings.json VS Code anda
3. **Mula Pelayan**: Klik butang "Mula" untuk setiap pelayan yang anda ingin gunakan
4. **Pilih Alat**: Pilih pelayan MCP mana yang hendak diaktifkan untuk sesi semasa anda

Untuk arahan persediaan terperinci, lihat [dokumentasi VS Code MCP](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Petua Pro: Urus Pelayan MCP seperti pakar!**
> 
> Paparan Sambungan VS Code kini termasuk [antara muka pengguna baru yang berguna untuk mengurus Pelayan MCP yang dipasang](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Anda mendapat akses cepat untuk mula, berhenti, dan mengurus mana-mana Pelayan MCP yang dipasang menggunakan antara muka yang jelas dan mudah. Cuba ia!

### Persediaan Visual Studio 2022

Untuk Visual Studio 2022 (versi 17.14 atau lebih baru):

1. **Aktifkan Mod Ejen**: Klik dropdown "Ask" dalam tetingkap GitHub Copilot Chat dan pilih "Agent"
2. **Cipta Fail Konfigurasi**: Cipta fail `.mcp.json` dalam direktori penyelesaian anda (lokasi disyorkan: `<SOLUTIONDIR>\.mcp.json`)
3. **Konfigurasikan Pelayan**: Tambah konfigurasi pelayan MCP anda menggunakan format MCP standard
4. **Kelulusan Alat**: Apabila diminta, sahkan alat yang anda mahu guna dengan kebenaran skop yang sesuai

Untuk arahan persediaan Visual Studio terperinci, lihat [dokumentasi Visual Studio MCP](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Setiap pelayan MCP mempunyai keperluan konfigurasi tersendiri (rentetan sambungan, pengesahan, dll.), tetapi corak persediaan adalah konsisten dalam kedua-dua IDE.

**Mengapa ia berguna**: Walaupun ia mungkin kelihatan seperti "hanya dokumentasi," pelayan ini sebenarnya penting untuk setiap pembangun yang menggunakan teknologi Microsoft. Salah satu aduan terbesar daripada pembangun .NET terhadap pembantu pengkodan AI ialah mereka tidak dikemas kini dengan pelepasan .NET dan C# terkini. Pelayan MCP Microsoft Learn Docs menyelesaikan masalah ini dengan menyediakan akses masa nyata kepada dokumentasi, rujukan API, dan amalan terbaik terkini. Sama ada anda bekerja dengan SDK Azure terkini, meneroka ciri baru C# 13, atau melaksanakan corak Aspire terkemuka, pelayan ini memastikan pembantu AI anda mempunyai akses kepada maklumat yang sahih dan terkini untuk menjana kod yang tepat dan moden.

Kualiti carian adalah luar biasa kerana ia memahami konteks – bertanya tentang "kontena" dalam konteks Azure akan mengembalikan dokumentasi Azure Container Instances, manakala istilah yang sama dalam konteks .NET mengembalikan maklumat koleksi C# yang relevan.

Ini amat berguna untuk pustaka dan kes penggunaan yang cepat berubah atau baru dikemas kini. Contohnya, dalam beberapa projek pengkodan terkini saya mahu memanfaatkan ciri dalam pelepasan terkini Aspire dan Microsoft.Extensions.AI. Dengan memasukkan pelayan MCP Microsoft Learn Docs, saya dapat memanfaatkan bukan sahaja dokumen API, tetapi juga panduan dan penerangan yang baru diterbitkan.

### 2. ☁️ Pelayan MCP Azure


[![Pasang di VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Pasang di VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Apa yang ia lakukan**: Azure MCP Server adalah suite komprehensif yang terdiri daripada lebih 15 penyambung perkhidmatan Azure khusus yang membawa keseluruhan ekosistem Azure ke dalam aliran kerja AI anda. Ini bukan sekadar satu pelayan – ia adalah koleksi berkuasa yang merangkumi pengurusan sumber, sambungan pangkalan data (PostgreSQL, SQL Server), analisis log Azure Monitor dengan KQL, integrasi Cosmos DB, dan banyak lagi.

**Mengapa ia berguna**: Selain mengurus sumber Azure, pelayan ini secara dramatik meningkatkan kualiti kod apabila bekerja dengan SDK Azure. Apabila anda menggunakan Azure MCP dalam mod Ejen, ia bukan sahaja membantu anda menulis kod – ia membantu anda menulis kod Azure yang *lebih baik* yang mengikut corak pengesahan semasa, amalan terbaik pengendalian ralat, dan menggunakan ciri SDK terkini. Daripada mendapat kod generik yang mungkin berfungsi, anda mendapat kod yang mengikut corak yang disyorkan Azure untuk beban kerja produksi.

**Modul utama termasuk**:
- **🗄️ Penyambung Pangkalan Data**: Akses bahasa semula jadi terus ke Azure Database untuk PostgreSQL dan SQL Server
- **📊 Azure Monitor**: Analisis log dikuasakan oleh KQL dan pandangan operasi
- **🌐 Pengurusan Sumber**: Pengurusan kitar hayat sumber Azure penuh
- **🔐 Pengesahan**: Corak DefaultAzureCredential dan identiti terurus
- **📦 Perkhidmatan Storan**: Operasi Blob Storage, Queue Storage, dan Table Storage
- **🚀 Perkhidmatan Kontena**: Azure Container Apps, Container Instances, dan pengurusan AKS
- **Dan banyak lagi penyambung khusus**

**Penggunaan dunia sebenar**: "Senaraikan akaun storan Azure saya", "Tanya ruang kerja Log Analytics saya untuk ralat dalam sejam yang lalu", atau "Bantu saya membina aplikasi Azure menggunakan Node.js dengan pengesahan yang betul"

**Senario demo penuh**: Berikut adalah panduan lengkap yang menunjukkan kuasa gabungan Azure MCP dengan sambungan GitHub Copilot untuk Azure dalam VS Code. Apabila anda mempunyai kedua-duanya dipasang dan memberi arahan:

> "Cipta skrip Python yang memuat naik fail ke Azure Blob Storage menggunakan pengesahan DefaultAzureCredential. Skrip ini harus bersambung ke akaun storan Azure saya yang bernama 'mycompanystorage', memuat naik ke kontena bernama 'documents', mencipta fail ujian dengan cap masa semasa untuk dimuat naik, mengendalikan ralat dengan baik dan memberi output yang bermaklumat, mengikuti amalan terbaik Azure untuk pengesahan dan pengendalian ralat, termasuk komen yang menerangkan cara pengesahan DefaultAzureCredential berfungsi, dan buat skrip itu tersusun dengan baik dengan fungsi dan dokumentasi yang betul."

Azure MCP Server akan menjana skrip Python lengkap yang sedia untuk produksi yang:
- Menggunakan SDK Azure Blob Storage terkini dengan corak async yang betul
- Melaksanakan DefaultAzureCredential dengan penjelasan lengkap rantai fallback
- Termasuk pengendalian ralat yang kukuh dengan jenis pengecualian Azure yang khusus
- Mengikut amalan terbaik SDK Azure untuk pengurusan sumber dan pengendalian sambungan
- Menyediakan log terperinci dan output konsol yang bermaklumat
- Mencipta skrip yang tersusun dengan betul dengan fungsi, dokumentasi, dan petunjuk jenis

Apa yang menjadikan ini luar biasa ialah tanpa Azure MCP, anda mungkin mendapat kod storan blob generik yang berfungsi tetapi tidak mengikut corak Azure semasa. Dengan Azure MCP, anda mendapat kod yang menggunakan kaedah pengesahan terkini, mengendalikan senario ralat khusus Azure, dan mengikut amalan disyorkan Microsoft untuk aplikasi produksi.

**Contoh diketengahkan**: Saya pernah bergelut dengan mengingati perintah spesifik untuk CLI `az` dan `azd` untuk penggunaan ad-hoc. Selalu ada proses dua langkah bagi saya: pertama cari sintaks, kemudian jalankan perintah. Saya sering masuk ke portal dan klik untuk menyelesaikan kerja kerana saya tidak mahu mengaku saya tidak boleh ingat sintaks CLI. Boleh meluahkan apa yang saya mahu dengan mudah adalah luar biasa, dan lagi bagus boleh buat itu tanpa meninggalkan IDE saya!

Ada senarai hebat kes penggunaan di [repositori Azure MCP](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) untuk memulakan anda. Untuk panduan pemasangan menyeluruh dan pilihan konfigurasi lanjutan, semak [dokumentasi rasmi Azure MCP](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

### 3. 🐙 GitHub MCP Server

[![Pasang di VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Pasang di VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**Apa yang ia lakukan**: GitHub MCP Server rasmi menyediakan integrasi lancar dengan keseluruhan ekosistem GitHub, menawarkan kedua-dua akses jauh yang dihoskan dan pilihan penyebaran Docker tempatan. Ini bukan hanya operasi repositori asas – ia adalah toolkit komprehensif yang merangkumi pengurusan GitHub Actions, aliran kerja permintaan tarik, pengesanan isu, imbasan keselamatan, notifikasi, dan keupayaan automasi lanjutan.

**Mengapa ia berguna**: Pelayan ini mengubah cara anda berinteraksi dengan GitHub dengan membawa pengalaman platform penuh terus ke dalam persekitaran pembangunan anda. Daripada sentiasa bertukar antara VS Code dan GitHub.com untuk pengurusan projek, semakan kod, dan pemantauan CI/CD, anda boleh mengendalikan semuanya melalui arahan bahasa semula jadi sambil terus fokus pada kod anda.

> **ℹ️ Nota: Jenis 'Ejen' Berbeza**
> 
> Jangan kelirukan GitHub MCP Server ini dengan GitHub's Coding Agent (ejen AI yang boleh anda tugaskan isu untuk tugas pengkodan automatik). GitHub MCP Server berfungsi dalam mod Ejen VS Code untuk menyediakan integrasi API GitHub, manakala Coding Agent GitHub adalah ciri berasingan yang mencipta permintaan tarik apabila ditugaskan ke isu GitHub.

**Keupayaan utama termasuk**:
- **⚙️ GitHub Actions**: Pengurusan saluran paip CI/CD lengkap, pemantauan aliran kerja, dan pengendalian artifak
- **🔀 Permintaan Tarik**: Cipta, semak, gabungkan, dan urus PR dengan penjejakan status komprehensif
- **🐛 Isu**: Pengurusan kitar hayat isu penuh, pengulas komen, pelabelan, dan penugasan
- **🔒 Keselamatan**: Amaran pengimbasan kod, pengesanan rahsia, dan integrasi Dependabot
- **🔔 Notifikasi**: Pengurusan notifikasi pintar dan kawalan langganan repositori
- **📁 Pengurusan Repositori**: Operasi fail, pengurusan cabang, dan pentadbiran repositori
- **👥 Kerjasama**: Carian pengguna dan organisasi, pengurusan pasukan, dan kawalan akses

**Penggunaan dunia sebenar**: "Cipta permintaan tarik dari cawangan ciri saya", "Tunjukkan semua larian CI gagal minggu ini", "Senaraikan semua amaran keselamatan terbuka untuk repositori saya", atau "Cari semua isu yang ditugaskan kepada saya merentasi organisasi saya"

**Apa yang dilakukan**: MarkItDown adalah pelayan penukaran dokumen lengkap yang menukarkan pelbagai format fail ke dalam Markdown berkualiti tinggi, dioptimumkan untuk penggunaan LLM dan aliran kerja analisis teks.

**Kenapa ia berguna**: Penting untuk aliran kerja dokumentasi moden! MarkItDown menangani pelbagai format fail yang mengagumkan sambil mengekalkan struktur dokumen penting seperti tajuk, senarai, jadual, dan pautan. Berbeza daripada alat ekstrak teks mudah, ia menumpukan pada mengekalkan makna semantik dan pemformatan yang bernilai untuk pemprosesan AI dan kebolehbacaan manusia.

**Format fail yang disokong**:
- **Dokumen Office**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Fail Media**: Imej (dengan metadata EXIF dan OCR), Audio (dengan metadata EXIF dan transkripsi pertuturan)
- **Kandungan Web**: HTML, suapan RSS, URL YouTube, halaman Wikipedia
- **Format Data**: CSV, JSON, XML, fail ZIP (memproses kandungan secara rekursif)
- **Format Penerbitan**: EPub, buku nota Jupyter (.ipynb)
- **Emel**: Mesej Outlook (.msg)
- **Lanjutan**: Integrasi Azure Document Intelligence untuk pemprosesan PDF yang dipertingkatkan

**Keupayaan lanjutan**: MarkItDown menyokong penerangan imej yang dikuasakan oleh LLM (apabila diberikan klien OpenAI), Azure Document Intelligence untuk pemprosesan PDF yang dipertingkatkan, transkripsi audio untuk kandungan pertuturan, dan sistem plugin untuk menambah format fail tambahan.

**Penggunaan dunia sebenar**: "Tukar pembentangan PowerPoint ini ke Markdown untuk laman dokumentasi kami", "Ekstrak teks dari PDF ini dengan struktur tajuk yang betul", atau "Tukar hamparan Excel ini ke format jadual yang boleh dibaca"

**Contoh pilihan**: Untuk memetik [dokumentasi MarkItDown](https://github.com/microsoft/markitdown#why-markdown):

> Markdown hampir sama dengan teks biasa, dengan penandaan atau pemformatan yang minimum, tetapi masih menyediakan cara untuk mewakili struktur dokumen penting. LLM arus perdana, seperti GPT-4o OpenAI, secara asli "berbicara" Markdown, dan sering memasukkan Markdown ke dalam respons mereka tanpa disuruh. Ini menunjukkan bahawa mereka telah dilatih pada sejumlah besar teks berformat Markdown, dan memahaminya dengan baik. Sebagai faedah sampingan, konvensyen Markdown juga sangat cekap token.

MarkItDown sangat baik dalam mengekalkan struktur dokumen, yang penting untuk aliran kerja AI. Contohnya, semasa menukar pembentangan PowerPoint, ia mengekalkan organisasi slaid dengan tajuk yang betul, mengekstrak jadual sebagai jadual Markdown, memasukkan teks alt untuk imej, dan malah memproses nota penceramah. Carta ditukar menjadi jadual data yang boleh dibaca, dan Markdown hasilnya mengekalkan aliran logik pembentangan asal. Ini menjadikannya sempurna untuk memberi makan kandungan pembentangan ke dalam sistem AI atau membuat dokumentasi dari slaid sedia ada.

## 📋 Kesimpulan

Model Context Protocol (MCP) sedang mengubah cara pembangun berinteraksi dengan pembantu AI dan alat luaran. 10 server Microsoft MCP ini menunjukkan kuasa integrasi AI standard, membolehkan aliran kerja lancar yang mengekalkan pembangun dalam keadaan fokus sambil mengakses kemampuan luaran yang berkuasa.

Dari integrasi ekosistem Azure yang menyeluruh hingga alat khusus seperti Playwright untuk automasi pelayar dan MarkItDown untuk pemprosesan dokumen, server-server ini mempamerkan bagaimana MCP boleh meningkatkan produktiviti dalam pelbagai senario pembangunan. Protokol standard memastikan alat-alat ini berfungsi bersama dengan harmoni, mencipta pengalaman pembangunan yang kohesif.

Semasa ekosistem MCP terus berkembang, kekal terlibat dengan komuniti, meneroka server baru, dan membina penyelesaian tersuai akan menjadi kunci untuk memaksimumkan produktiviti pembangunan anda. Sifat standard terbuka MCP bermakna anda boleh gabungkan alat dari vendor berbeza untuk mencipta aliran kerja sempurna mengikut keperluan khusus anda.
