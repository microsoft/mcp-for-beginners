## 🔧 Forstå MCP-servere: En begyndervejledning

### Hvad er MCP-servere?

Som begynder til Model Context Protocol (MCP) kan du undre dig over: "Hvad præcist er en MCP-server, og hvorfor skulle jeg bekymre mig?" Lad os starte med en simpel analogi.

Tænk på MCP-servere som specialiserede assistenter, der hjælper din AI-kodekompagnon (som GitHub Copilot) med at forbinde til eksterne værktøjer og tjenester. Ligesom du måske bruger forskellige apps på din telefon til forskellige opgaver – én til vejr, én til navigation, én til bank – giver MCP-servere din AI-assistent mulighed for at interagere med forskellige udviklingsværktøjer og -tjenester.

### Problemet MCP-servere løser

Før MCP-servere, hvis du ville:
- Tjekke dine Azure-ressourcer
- Oprette en GitHub-issue
- Forespørge din database
- Søge gennem dokumentation

Skulle du stoppe med at kode, åbne en browser, navigere til det relevante websted, og manuelt udføre disse opgaver. Denne konstante kontekstskift bryder dit flow og reducerer produktiviteten.

### Hvordan MCP-servere forvandler din udviklingsoplevelse

Med MCP-servere kan du blive i dit udviklingsmiljø (VS Code, Visual Studio osv.) og blot bede din AI-assistent om at håndtere disse opgaver. For eksempel:

**I stedet for denne traditionelle arbejdsgang:**
1. Stoppe med at kode
2. Åbne browser
3. Navigere til Azure-portalen
4. Slå detaljer op på lagringskonto
5. Gå tilbage til VS Code
6. Genoptage kodning

**Kan du nu gøre dette:**
1. Spørg AI: "Hvad er status for mine Azure-lagre?"
2. Fortsæt kodning med den givne information

### Vigtige fordele for begyndere

#### 1. 🔄 **Bliv i dit flow**
- Ingen flere skift mellem flere applikationer
- Bevar fokus på den kode du skriver
- Reducer mental belastning ved at håndtere forskellige værktøjer

#### 2. 🤖 **Brug naturligt sprog i stedet for komplekse kommandoer**
- I stedet for at huske SQL-syntaks, beskriv hvilke data du har brug for
- I stedet for at huske Azure CLI-kommandoer, forklar hvad du vil opnå
- Lad AI håndtere tekniske detaljer, mens du fokuserer på logikken

#### 3. 🔗 **Forbind flere værktøjer sammen**
- Skab kraftfulde arbejdsgange ved at kombinere forskellige tjenester
- Eksempel: "Hent alle nylige GitHub-issues og opret tilsvarende Azure DevOps arbejdsopgaver"
- Automatiser uden at skrive komplekse scripts

#### 4. 🌐 **Få adgang til et voksende økosystem**
- Drag fordel af servere bygget af Microsoft, GitHub og andre virksomheder
- Bland og match værktøjer fra forskellige leverandører sømløst
- Deltag i et standardiseret økosystem, der fungerer på tværs af forskellige AI-assistenter

#### 5. 🛠️ **Lær ved at gøre**
- Start med færdigbyggede servere for at forstå koncepterne
- Byg gradvist dine egne servere, når du bliver mere tryg
- Brug tilgængelige SDK'er og dokumentation til at guide din læring

### Virkelighedsnært eksempel for begyndere

Lad os sige, at du er ny til webudvikling og arbejder på dit første projekt. Sådan kan MCP-servere hjælpe:

**Traditionel tilgang:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code

```

```

4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

## Kom godt i gang med MCP i VS Code og Visual Studio 🚀

Opsætning af disse MCP-servere er ligetil, hvis du bruger Visual Studio Code eller Visual Studio 2022 med GitHub Copilot.

### VS Code opsætning

Her er den grundlæggende proces for VS Code:

1. **Aktiver Agent-tilstand**: I VS Code skift til Agent-tilstand i Copilot Chat-vinduet
2. **Konfigurer MCP-servere**: Tilføj serverkonfigurationer til din VS Code settings.json-fil
3. **Start servere**: Klik på "Start" knappen for hver server, du vil bruge
4. **Vælg værktøjer**: Vælg hvilke MCP-servere der skal aktiveres for din nuværende session

For detaljerede opsætningsinstruktioner, se [VS Code MCP-dokumentationen](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Pro-tip: Administrer MCP-servere som en professionel!**
> 
> VS Code Extensions-visningen inkluderer nu en [praktisk ny brugerflade til at administrere installerede MCP-servere](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Du har hurtig adgang til at starte, stoppe og administrere alle installerede MCP-servere via en klar og simpel grænseflade. Prøv det!

### Visual Studio 2022 opsætning

For Visual Studio 2022 (version 17.14 eller senere):

1. **Aktiver Agent-tilstand**: Klik på "Ask" dropdown i GitHub Copilot Chat-vinduet og vælg "Agent"
2. **Opret konfigurationsfil**: Opret en `.mcp.json` fil i din løsningsmappe (anbefalet placering: `<SOLUTIONDIR>\.mcp.json`)
3. **Konfigurer servere**: Tilføj dine MCP-serverkonfigurationer vha. den standard MCP-format
4. **Godkend værktøjer**: Når du bliver bedt om det, godkend de værktøjer, du vil bruge med passende scope-tilladelser

For detaljerede Visual Studio-opsætningsinstruktioner, se [Visual Studio MCP-dokumentationen](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Hver MCP-server har egne krav til konfiguration (forbindelsesstrenge, godkendelse, osv.), men opsætningsmønstret er konsistent på tværs af begge IDE'er.

### 1. 📚 Microsoft Learn Docs MCP-server

[![Installer i VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![Installer i VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**Hvad den gør**: Microsoft Learn Docs MCP-serveren er en cloud-hostet tjeneste, der giver AI-assistenter realtidsadgang til officiel Microsoft-dokumentation via Model Context Protocol. Den forbinder til `https://learn.microsoft.com/api/mcp` og muliggør semantisk søgning på tværs af Microsoft Learn, Azure-dokumentation, Microsoft 365-dokumentation og andre officielle Microsoft-kilder.

**Hvorfor den er nyttig**: Selvom det måske bare virker som "dokumentation", er denne server faktisk afgørende for enhver udvikler, der bruger Microsoft-teknologier. En af de største klager fra .NET-udviklere om AI-kodeassistenter er, at de ikke er opdateret med de nyeste .NET- og C#-udgivelser. Microsoft Learn Docs MCP-serveren løser dette ved at give realtidsadgang til den mest aktuelle dokumentation, API-referencer og bedste praksis. Uanset om du arbejder med de nyeste Azure SDK'er, udforsker nye funktioner i C# 13, eller implementerer banebrydende Aspire-mønstre, sikrer denne server, at din AI-assistent har adgang til autoritativ og opdateret information til at generere præcis, moderne kode.

**Reel brug**: "Hvad er az cli-kommandoerne til at oprette en Azure container app ifølge den officielle Microsoft Learn-dokumentation?" eller "Hvordan konfigurerer jeg Entity Framework med dependency injection i ASP.NET Core?" Eller hvad med "Gennemgå denne kode for at sikre, at den matcher ydelsesanbefalingerne i Microsoft Learn-dokumentationen." Serveren giver omfattende dækning på tværs af Microsoft Learn, Azure-dokumenter og Microsoft 365-dokumentation ved hjælp af avanceret semantisk søgning for at finde den mest kontekstuelt relevante information. Den returnerer op til 10 indholdsbidder af høj kvalitet med artikeltitler og URL'er, altid med adgang til den nyeste Microsoft-dokumentation, så snart den udgives.

**Fremhævet eksempel**: Serveren eksponerer værktøjet `microsoft_docs_search`, som udfører semantisk søgning mod Microsofts officielle tekniske dokumentation. Når den er konfigureret, kan du stille spørgsmål som "Hvordan implementerer jeg JWT-autentifikation i ASP.NET Core?" og få detaljerede, officielle svar med kildelinks. Søgekvaliteten er fremragende, fordi den forstår konteksten – at spørge om "containers" i en Azure-kontekst vil returnere Azure Container Instances-dokumentation, mens det samme udtryk i en .NET-kontekst returnerer relevant C# collections-information.

Dette er især nyttigt for hurtigt skiftende eller nyligt opdaterede biblioteker og brugstilfælde. For eksempel ønskede jeg i nogle nyere kodeprojekter at udnytte funktioner i de seneste udgivelser af Aspire og Microsoft.Extensions.AI. Ved at inkludere Microsoft Learn Docs MCP-serveren kunne jeg udnytte ikke kun API-dokumenter, men også vejledninger og guider, der lige var blevet offentliggjort.

> **💡 Pro-tip**
> 
> Selv modeller, der er værktøjsvenlige, har brug for opmuntring til at bruge MCP-værktøjer! Overvej at tilføje en systemprompt eller [copilot-instructions.md](https://docs.github.com/copilot/how-tos/custom-instructions/adding-repository-custom-instructions-for-github-copilot) som fx: "Du har adgang til `microsoft.docs.mcp` – brug dette værktøj til at søge i Microsofts nyeste officielle dokumentation, når du håndterer spørgsmål om Microsoft-teknologier som C#, Azure, ASP.NET Core eller Entity Framework."
>
> For et godt eksempel på dette i praksis, se [C# .NET Janitor chat mode](https://github.com/awesome-copilot/chatmodes/blob/main/csharp-dotnet-janitor.chatmode.md) fra Awesome GitHub Copilot-repositoriet. Denne tilstand udnytter specifikt Microsoft Learn Docs MCP-serveren til at hjælpe med at rydde op og modernisere C#-kode ved brug af de nyeste mønstre og bedste praksis.
### 2. ☁️ Azure MCP-server

[![Installer i VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Installer i VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Hvad den gør**: Azure MCP-serveren er en omfattende samling af 15+ specialiserede Azure-serviceforbindelser, der bringer hele Azure-økosystemet ind i din AI-arbejdsgang. Det er ikke bare én server – det er en kraftfuld samling, der inkluderer ressourcehåndtering, databaseforbindelser (PostgreSQL, SQL Server), Azure Monitor loganalyse med KQL, Cosmos DB-integration og meget mere.

**Hvorfor den er nyttig**: Ud over blot at håndtere Azure-ressourcer forbedrer denne server dramatisk kodekvaliteten ved arbejde med Azure SDK'er. Når du bruger Azure MCP i Agent-tilstand, hjælper den dig ikke bare med at skrive kode – den hjælper dig med at skrive *bedre* Azure-kode, der følger aktuelle autentifikationsmønstre, bedste fejlbehandlingspraksis og udnytter de seneste SDK-funktioner. I stedet for at få generisk kode, der måske virker, får du kode, der følger Azures anbefalede mønstre til produktionsarbejdsbelastninger.

**Nøglemoduler inkluderer**:
- **🗄️ Databaseconnectorer**: Direkte adgang via naturligt sprog til Azure Database for PostgreSQL og SQL Server
- **📊 Azure Monitor**: KQL-drevet loganalyse og operationelle indsigter
- **🌐 Ressourcestyring**: Fuld Azure-ressource livscyklusstyring
- **🔐 Autentifikation**: DefaultAzureCredential og managed identity mønstre
- **📦 Lagringstjenester**: Blob Storage, Queue Storage og Table Storage-operationer
- **🚀 Container-tjenester**: Azure Container Apps, Container Instances og AKS-håndtering
- **Og mange flere specialiserede forbindelser**

**Reel brug**: "List mine Azure-lagre", "Forespørg mit Log Analytics workspace for fejl i sidste time" eller "Hjælp mig med at bygge en Azure-applikation med Node.js og korrekt autentifikation"

**Fuld demo-scenarie**: Her er en komplet gennemgang, der viser kraften ved at kombinere Azure MCP med GitHub Copilot for Azure-udvidelsen i VS Code. Når du har begge installeret og anmoder:

> "Opret et Python-script, der uploader en fil til Azure Blob Storage ved hjælp af DefaultAzureCredential-godkendelse. Scriptet skal forbinde til min Azure Storage-konto med navnet 'mycompanystorage', uploade til en container med navnet 'documents', oprette en testfil med det aktuelle tidsstempel til upload, håndtere fejl på en forsigtig måde og give informativ output, følge Azures bedste praksis for godkendelse og fejlhåndtering, inkludere kommentarer, der forklarer, hvordan DefaultAzureCredential-godkendelsen fungerer, og gøre scriptet velstruktureret med passende funktioner og dokumentation."

Azure MCP-serveren vil generere et komplet, produktionsklart Python-script, der:
- Bruger den nyeste Azure Blob Storage SDK med korrekte async-mønstre
- Implementerer DefaultAzureCredential med omfattende forklaring af fallback-kæden
- Indeholder robust fejlhåndtering med specifikke Azure-undtagelsestyper
- Følger Azure SDK's bedste praksis for ressourcestyring og forbindelseshåndtering
- Tilbyder detaljeret logging og informativ konsoloutput
- Opretter et korrekt struktureret script med funktioner, dokumentation og typeangivelser

Det bemærkelsesværdige er, at uden Azure MCP ville du måske få generisk blob storage-kode, der fungerer, men som ikke følger de aktuelle Azure-mønstre. Med Azure MCP får du kode, der udnytter de nyeste godkendelsesmetoder, håndterer Azure-specifikke fejlsituationer og følger Microsofts anbefalede praksis til produktionsapplikationer.

**Fremhævet eksempel**: Jeg har kæmpet med at huske de specifikke kommandoer for `az`- og `azd`-CLI'erne til ad hoc-brug. Det er altid en to-trins proces for mig: først slå syntaksen op, så køre kommandoen. Jeg hopper tit bare ind i portalen og klikker rundt for at få arbejdet gjort, fordi jeg ikke vil indrømme, at jeg ikke kan huske CLI-syntaksen. At kunne beskrive, hvad jeg vil, er fantastisk, og det er endnu bedre at kunne gøre det uden at forlade mit IDE!

Der er en god liste over brugssager i [Azure MCP repository](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) til at komme i gang. For omfattende opsætningsvejledninger og avancerede konfigurationsmuligheder, se [den officielle Azure MCP-dokumentation](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

### 3. 🐙 GitHub MCP Server

[![Installer i VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Installer i VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**Hvad det gør**: Den officielle GitHub MCP Server tilbyder sømløs integration med GitHubs hele økosystem, med både hosted fjernadgang og lokale Docker-implementeringsmuligheder. Det handler ikke kun om grundlæggende repository-operationer – det er et omfattende værktøjssæt, der inkluderer GitHub Actions-styring, pull request-workflows, issue-tracking, sikkerhedsscanning, notifikationer og avancerede automatiseringsmuligheder.

**Hvorfor det er nyttigt**: Denne server ændrer, hvordan du interagerer med GitHub ved at bringe hele platformoplevelsen direkte ind i dit udviklingsmiljø. I stedet for konstant at skifte mellem VS Code og GitHub.com for projektstyring, kodegennemgange og CI/CD-monitorering kan du klare alt gennem naturlige sprogkommandoer, mens du bevarer fokus på din kode.

> **ℹ️ Note: Forskellige typer af 'Agenter'**
> 
> Forveksl ikke denne GitHub MCP Server med GitHubs Coding Agent (AI-agenten, du kan tildele issues til for automatiserede kodningsopgaver). GitHub MCP Serveren fungerer inden for VS Codes Agent-mode for at tilbyde GitHub API-integration, mens GitHubs Coding Agent er en separat funktion, der opretter pull requests, når den tildeles GitHub-issues.

**Nøglefunktioner inkluderer**:
- **⚙️ GitHub Actions**: Komplethåndtering af CI/CD-pipelines, workflow-overvågning og håndtering af artefakter
- **🔀 Pull Requests**: Opret, gennemgå, merge og administrer PR'er med omfattende statussporing
- **🐛 Issues**: Fuld lifecycle-håndtering af issues, kommentarer, mærkning og tildeling
- **🔒 Sikkerhed**: Kodescanning, advarsler, hemmelighedsdetektion og Dependabot-integration
- **🔔 Notifikationer**: Smart notifikationsstyring og kontrol af repositories abonnementer
- **📁 Repository-styring**: Filoperationer, branchestyring og repository-administration
- **👥 Samarbejde**: Bruger- og organisationssøgning, teamstyring og adgangskontrol

**Brug i praksis**: "Opret en pull request fra min feature-branch", "Vis mig alle fejlede CI-kørsler denne uge", "List åbne sikkerhedsadvarsler for mine repositories", eller "Find alle issues tildelt mig på tværs af mine organisationer"

**Fuld demo-scenario**: Her er et stærkt workflow, der demonstrerer GitHub MCP Serverens muligheder:

> "Jeg skal forberede mig til vores sprint review. Vis mig alle pull requests, jeg har oprettet denne uge, tjek status på vores CI/CD-pipelines, opret et resumé af eventuelle sikkerhedsalarmer, vi skal tage os af, og hjælp mig med at udarbejde release-noter baseret på merged PR'er med 'feature'-mærket."

GitHub MCP Serveren vil:
- Forespørge dine seneste pull requests med detaljeret statusinformation
- Analysere workflow-kørsler og fremhæve eventuelle fejl eller ydeevneproblemer
- Samle resultater fra sikkerhedsscanning og prioritere kritiske advarsler
- Generere omfattende release-noter ved at udtrække information fra merged PR'er
- Give handlingsrettede næste skridt til sprintplanlægning og release-forberedelse

**Fremhævet eksempel**: Jeg elsker at bruge dette til kodegennemgangs-workflows. I stedet for at hoppe mellem VS Code, GitHub-notifikationer og pull request-sider, kan jeg sige "Vis mig alle PR'er, der venter på min gennemgang" og derefter "Tilføj en kommentar til PR #123 og spørg om fejlhåndteringen i godkendelsesmetoden." Serveren håndterer GitHub API-kald, bevarer kontekst om diskussionen og hjælper endda med at udforme mere konstruktive review-kommentarer.

**Godkendelsesmuligheder**: Serveren understøtter både OAuth (sømløst i VS Code) og Personal Access Tokens med konfigurerbare værktøjssæt til kun at aktivere den GitHub-funktionalitet, du har brug for. - **Dataformater**: CSV, JSON, XML, ZIP-filer (behandler indhold rekursivt)
- **Publiceringsformater**: EPub, Jupyter-notebooks (.ipynb)
- **Email**: Outlook-beskeder (.msg)
- **Avanceret**: Azure Document Intelligence-integration for forbedret PDF-behandling

**Avancerede funktioner**: MarkItDown understøtter LLM-drevne billedbeskrivelser (når den forsynes med en OpenAI-klient), Azure Document Intelligence til forbedret PDF-behandling, lydtransskription for taleindhold og et pluginsystem til udvidelse til yderligere filformater.

**Virkelighedsnært brug**: "Konverter denne PowerPoint-præsentation til Markdown til vores dokumentationssite", "Udtræk tekst fra denne PDF med korrekt overskriftsstruktur", eller "Omform denne Excel-regneark til et læsbart tabel format"

at Markdown bevarer dokumentstruktur med minimal formateringsoverhead.

format til dokumentbehandlingsarbejdsprocesser.

MarkItDown er virkelig god til at bevare dokumentstruktur, hvilket er vigtigt for AI-arbejdsprocesser. For eksempel, når man konverterer en PowerPoint-præsentation, bevarer den slide-organisation med de rigtige overskrifter, udtrækker tabeller som Markdown-tabeller, inkluderer alt-tekst til billeder og behandler endda talernoterne. Diagrammer konverteres til læselige datatabeller, og den resulterende Markdown bevarer den logiske flow fra den oprindelige præsentation. Dette gør den perfekt til at fodre præsentationsindhold ind i AI-systemer eller skabe dokumentation ud fra eksisterende slides.

Disse 10 Microsoft MCP-servere viser kraften i standardiseret AI-integration, der muliggør sømløse workflows, som holder udviklere i deres flow-tilstand, mens de får adgang til kraftfulde eksterne funktioner.

Fra den omfattende Azure-økosystemintegration til specialiserede værktøjer som Playwright til browserautomatisering og MarkItDown til dokumentbehandling, illustrerer disse servere, hvordan MCP kan øge produktiviteten på tværs af forskellige udviklingsscenarier. Den standardiserede protokol sikrer, at disse værktøjer arbejder sammen gnidningsløst og skaber en sammenhængende udviklingsoplevelse.

Efterhånden som MCP-økosystemet fortsætter med at udvikle sig, vil engagement med fællesskabet, udforskning af nye servere og opbygning af brugerdefinerede løsninger være nøglen til at maksimere din udviklingsproduktivitet. MCP's åbne standard-natur betyder, at du kan mixe og matche værktøjer fra forskellige leverandører for at skabe den perfekte workflow til dine specifikke behov.
