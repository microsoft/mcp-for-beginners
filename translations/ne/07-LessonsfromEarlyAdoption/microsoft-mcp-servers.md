# 🚀 १० माइक्रोसफ्ट एमसीपी सर्भरहरू जसले विकासकर्ताको उत्पादकत्व परिवर्तन गर्दैछन्

## 🎯 यस मार्गदर्शनमा तपाईंले के सिक्नुहुनेछ

यो व्यवहारगत मार्गदर्शनले दस माइक्रोसफ्ट एमसीपी सर्भरहरूलाई प्रदर्शन गर्दछ जुन सक्रिय रूपमा विकासकर्ताहरूले एआई सहायकहरू संग काम गर्ने तरिका परिवर्तन गर्दैछ। केवल एमसीपी सर्भरहरूले *के* गर्न सक्छन् भनेर व्याख्या गर्ने सट्टा, हामीले तपाईंलाई यस्ता सर्भरहरू देखाउने छौं जो माइक्रोसफ्ट र अन्य ठाउँहरूमा दैनिक विकास कार्यप्रवाहहरूमा वास्तविक फरक पार्दैछन्।

यस मार्गदर्शनमा प्रत्येक सर्भरलाई वास्तविक प्रयोग र विकासकर्ताको प्रतिक्रिया आधारमा छनौट गरिएको छ। तपाईंले प्रत्येक सर्भरले के गर्छ भन्ने मात्र होइन, किन यो महत्वपूर्ण छ र आफ्नै परियोजनाहरूमा यसबाट कसरी अधिकतम लाभ लिन सकिन्छ भन्ने पत्ता लगाउनुहुनेछ। तपाईं एमसीपीमा पूर्ण रूपमा नयाँ हुनुहुन्छ वा आफ्नो वर्तमान सेटअप विस्तार गर्न खोज्दै हुनुहुन्छ भने, यी सर्भरहरू माइक्रोसफ्ट इकोसिस्टममा उपलब्ध सबैभन्दा व्यवहारिक र प्रभावकारी उपकरणहरू मध्येका हुन्।

> **💡 छिटो सुरु गर्ने सुझाव**
>
> एमसीपीमा नयाँ हुनुहुन्छ? चिन्ता नलिनुहोस्! यो मार्गदर्शन सुरुमा शौकिन व्यक्तिहरूका लागि डिजाइन गरिएको हो। हामीले अवधारणाहरू वर्णन गर्दा तपाईंलाई सजिलै बुझ्न सकिने कुरा गर्नेछौं, र तपाईं सँधै हाम्रो [एमसीपी परिचय](../00-Introduction/README.md) र [मूल अवधारणाहरू](../01-CoreConcepts/README.md) मोड्युलहरूमा फर्केर बढी पृष्ठभूमि प्राप्त गर्न सक्नुहुन्छ।

## अवलोकन

यो समग्र मार्गदर्शनले दस माइक्रोसफ्ट एमसीपी सर्भरहरूलाई अन्वेषण गर्दछ जुन विकासकर्ताहरूले एआई सहायक र बाह्य उपकरणहरूसँग कसरी अन्तरक्रिया गर्छन् भन्ने तरीका क्रान्तिकारी तरिकाले परिवर्तन गर्दैछन्। Azure स्रोत व्यवस्थापनदेखि कागजात प्रशोधनसम्म, यी सर्भरहरूले मोडेल कन्टेक्स्ट प्रोटोकलको शक्तिलाई सहज र उत्पादक विकास कार्यप्रवाहहरू सिर्जना गर्न प्रदर्शन गर्छन्।

## सिकाइका उद्देश्यहरू

यस मार्गदर्शनको अन्त्य सम्म तपाईं:
- कसरी एमसीपी सर्भरहरूले विकासकर्ताको उत्पादकत्व सुधार गर्छन् बुझ्ने
- माइक्रोसफ्टका सबैभन्दा प्रभावकारी एमसीपी सर्भर कार्यान्वयनहरूबारे जान्ने
- प्रत्येक सर्भरका व्यवहारिक प्रयोग केसहरू पत्ता लगाउने
- VS कोड र भिजुअल स्टुडियोमा यी सर्भरहरू कसरी सेटअप र कन्फिगर गर्ने जान्ने
- व्यापक एमसीपी इकोसिस्टम र भविष्यका दिशाहरू अन्वेषण गर्ने

## 🔧 एमसीपी सर्भरहरू बुझ्ने: एक शुरुवाती गाइड

### एमसीपी सर्भरहरू के हुन्?

मोडेल कन्टेक्स्ट प्रोटोकल (एमसीपी) मा नयाँ हुनुहुन्छ भने तपाईंलाई लाग्न सक्छ: "एमसीपी सर्भर भनेको के हो र यो किन महत्वपूर्ण छ?" एक सरल उपमा बाट सुरु गरौं।

एमसीपी सर्भरहरूलाई विशेष सहायकहरू जस्तो बुझ्नुहोस् जसले तपाईंको AI कोडिङ्ग साथी (जस्तै GitHub Copilot) लाई बाह्य उपकरण र सेवाहरूसँग जडान गर्न मद्दत गर्छ। जस्तो तपाईं मोबाइलमा विभिन्न कामहरूका लागि फरक-फरक एपहरू प्रयोग गर्नुहुन्छ—एक मौसमका लागि, अर्को नेभिगेसनका लागि, अर्को बैंकिङका लागि—एमसीपी सर्भरहरूले तपाईंको AI सहायकलाई विभिन्न विकास उपकरण र सेवाहरू सँग अन्तरक्रिया गर्ने क्षमता दिन्छ।

### एमसीपी सर्भरहरूले समाधान गर्ने समस्या

एमसीपी सर्भरहरू भन्दा पहिले, तपाईंले गर्न चाहेको भए:
- Azure स्रोतहरू जाँच गर्ने
- GitHub मुद्दा सिर्जना गर्ने
- आफ्नो डाटाबेस सोधपुछ गर्ने
- कागजातहरू खोज्ने

तपाईंले लेखाइ छोडेर ब्राउजर खोल्नु पर्थ्यो, उपयुक्त वेबसाइटमा जानु पर्थ्यो, र यी कार्यहरू म्यानुअली गर्नु पर्थ्यो। यस निरन्तर सन्दर्भ परिवर्तनले तपाईंको सृजनात्मक प्रवाह भंग गर्छ र उत्पादकत्व घटाउँछ।

### एमसीपी सर्भरहरूले विकास अनुभव कसरी परिवर्तन गर्छ

एमसीपी सर्भरहरूका साथ आप विकास वातावरण (VS कोड, भिजुअल स्टुडियो आदि) मा नै रहन सक्नुहुन्छ र केवल आफ्नो AI सहायकलाई यी कार्यहरू गर्न भन्न सक्नुहुन्छ। उदाहरणको लागि:

**परम्परागत कार्यप्रवाह यसरी हुन सक्थ्यो:**
1. लेखाइ रोक्ने
2. ब्राउजर खोल्ने
3. Azure पोर्टलमा जाने
4. भण्डारण खाताका विवरणहरू हेर्ने
5. VS कोडमा फर्कने
6. लेखाइ जारी राख्ने

**अब तपाईं यसो गर्न सक्नुहुन्छ:**
1. AI लाई सोध्ने: "मेरो Azure भण्डारण खाताहरूको स्थिति के छ?"
2. प्राप्त जानकारीको साथ लेखाइ जारी राख्ने

### शुरुवातीहरूका लागि मुख्य लाभहरू

#### 1. 🔄 **आफ्नो प्रवाहको अवस्थामा रहनुहोस्**
- धेरै एप्लिकेशनहरू बीच स्विच नगर्नुहोस्
- तपाईंले लेखिरहेको कोडमा ध्यान केन्द्रित राख्नुहोस्
- विभिन्न उपकरणहरू व्यवस्थापन गर्ने मानसिक भार घटाउनुहोस्

#### 2. 🤖 **जटिल आदेशहरूको सट्टा साधारण प्राकृतिक भाषा प्रयोग गर्नुहोस्**
- SQL सिन्ट्याक्स याद राख्नुभन्दा, तपाईंलाई चाहिने डाटाको वर्णन गर्नुहोस्
- Azure CLI आदेशहरू सम्झनुभन्दा, तपाईं के गर्न चाहानुहुन्छ व्याख्या गर्नुहोस्
- AI लाई प्रविधि विवरणहरू सम्हाल्न दिनुहोस् र तपाईं तर्कमा ध्यान दिनुहोस्

#### 3. 🔗 **धेरै उपकरणहरूलाई एकसाथ जडान गर्नुहोस्**
- विभिन्न सेवाहरूलाई संयोजन गरेर शक्तिशाली कार्यप्रवाहहरू सिर्जना गर्नुहोस्
- उदाहरण: "सबै भर्खरका GitHub मुद्दाहरू ल्याएर सम्बन्धित Azure DevOps कामहरू सिर्जना गर्नुहोस्"
- जटिल स्क्रिप्ट लेख्नु नपरी स्वचालन बनाउनुहोस्

#### 4. 🌐 **वृद्धिगत इकोसिस्टममा पहुँच प्राप्त गर्नुहोस्**
- माइक्रोसफ्ट, GitHub र अन्य कम्पनीहरू द्वारा बनाइएका सर्भरहरूको फाइदा लिनुहोस्
- विभिन्न विक्रेता उपकरणहरूलाई सहज तरिकाले मिश्रण र मेल गर्न सकिन्छ
- विभिन्न AI सहायकहरूमा काम गर्ने मानकीकृत इकोसिस्टममा सामेल हुनुहोस्

#### 5. 🛠️ **व्यावहारिक सिकाइ**
- अवधारणाहरू बुझ्न पूर्वनिर्मित सर्भरहरूसँग सुरु गर्नुहोस्
- जति सहज हुन्छ त्यसरी आफैंका सर्भरहरू विकास गर्नुहोस्
- उपलब्ध SDK र दस्तावेजीकरण प्रयोग गरेर सिकाइ मार्गदर्शन लिनुहोस्

### शुरुवातीहरूको लागि वास्तविक उदाहरण

तपाईं वेब विकासमा नयाँ हुनुहुन्छ र आफ्नो पहिलो परियोजनामा काम गर्दै हुनुहुन्छ भनी मानौं। एमसीपी सर्भरहरूले तपाईंलाई यसरी सहयोग गर्न सक्छ:

**परम्परागत तरिका:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**एमसीपी सर्भरहरूसँग:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### उद्यम स्तरको मानक फाइदा

एमसीपी उद्योगव्यापी मानक बन्दैछ, जसको अर्थ छ:
- **समानता**: विभिन्न उपकरण र कम्पनीहरूमा समान अनुभव
- **अन्तरक्रियाशीलता**: फरक विक्रेताबाट आएका सर्भरहरू सँगै काम गर्छन्
- **भविष्यरेटोपूर्णता**: विभिन्न AI सहायकहरूबीच सीप र सेटअपहरू सार्न सकिन्छ
- **समुदाय**: साझा ज्ञान र स्रोतहरूको ठूलो इकोसिस्टम

### सुरु कसरी गर्ने: तपाईंले के सिक्नुहुनेछ

यस मार्गदर्शनमा, हामी १० माइक्रोसफ्ट एमसीपी सर्भरहरू अन्वेषण गर्नेछौं जुन सबै स्तरका विकासकर्ताहरूका लागि विशेष रूपमा उपयोगी छन्। प्रत्येक सर्भरले डिजाइन गरिएको छ:
- सामान्य विकास चुनौतीहरू समाधान गर्न
- पुनरावृत्ति हुने कार्यहरू घटाउन
- कोडको गुणस्तर सुधार गर्न
- सिकाइ अवसरहरू बढाउन

> **💡 सिक्ने सुझाव**
>
> तपाईं पूर्ण रूपमा एमसीपीमा नयाँ हुनुहुन्छ भने, सुरुमा हाम्रो [एमसीपी परिचय](../00-Introduction/README.md) र [मूल अवधारणाहरू](../01-CoreConcepts/README.md) मोड्युलहरूबाट सुरु गर्नुहोस्। त्यसपछि यहाँ फर्केर यी अवधारणाहरूलाई माइक्रोसफ्टका वास्तविक उपकरणहरूसँग कसरी प्रयोग गर्ने देख्नुहोस्।
>
> एमसीपीको महत्त्वको अतिरिक्त प्रसंगका लागि, मारिया नग्गागाको पोस्ट हेर्नुहोस्: [Connect Once, Integrate Anywhere with MCP](https://devblogs.microsoft.com/blog/connect-once-integrate-anywhere-with-mcps)।

## VS कोड र भिजुअल स्टुडियोमा एमसीपी सुरु गर्ने 🚀

यदि तपाईं Visual Studio Code वा Visual Studio 2022 GitHub Copilot सँग प्रयोग गर्दै हुनुहुन्छ भने यी एमसीपी सर्भरहरू सेटअप गर्न सजिलो छ।

### VS कोड सेटअप

VS कोडको लागि आधारभूत प्रक्रिया यस प्रकार छ:

1. **एजेन्ट मोड सक्षम गर्नुहोस्**: VS कोडमा, Copilot Chat विन्डोमा एजेन्ट मोडमा स्विच गर्नुहोस्
2. **एमसीपी सर्भरहरू कन्फिगर गर्नुहोस्**: आफ्नो VS कोड settings.json फाइलमा सर्भर कन्फिगरेसन थप्नुहोस्
3. **सर्भरहरू सुरु गर्नुहोस्**: तपाईंले प्रयोग गर्न चाहेको प्रत्येक सर्भरको "Start" बटन क्लिक गर्नुहोस्
4. **उपकरणहरू चयन गर्नुहोस्**: तपाईंको हालको सत्रका लागि कुन एमसीपी सर्भरहरू सक्षम गर्ने छनौट गर्नुहोस्

विस्तृत सेटअप निर्देशनहरूको लागि, [VS कोड एमसीपी कागजात](https://code.visualstudio.com/docs/copilot/copilot-mcp) हेर्नुहोस्।

> **💡 प्रो सुझाव: एमसीपी सर्भरहरूलाई प्रबन्धन गर्नुहोस् जस्तै एक प्रो!**
>
> VS कोड एक्स्टेन्सनहरू दृश्यमा अब [इन्स्टल गरिएका एमसीपी सर्भरहरू प्रबन्ध गर्नको लागि सजिलो नयाँ UI छ](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! तपाईंले स्पष्ट र सरल इन्टरफेस प्रयोग गरेर सर्भरहरू सुरु, रोक्न र व्यवस्थापन गर्न सक्नुहुन्छ। प्रयोग गरेर हेर्नुहोस्!

### भिजुअल स्टुडियो २०२२ सेटअप

भिजुअल स्टुडियो २०२२ (संस्करण १७.१४ वा पछिको लागि):

1. **एजेन्ट मोड सक्षम गर्नुहोस्**: GitHub Copilot Chat विन्डोमा "Ask" ड्रपडाउन क्लिक गरेर "Agent" चयन गर्नुहोस्
2. **कन्फिगरेसन फाइल सिर्जना गर्नुहोस्**: तपाईंको सोलुसन डाइरेक्टरीमा `.mcp.json` फाइल सिर्जना गर्नुहोस् (सिफारिस स्थान: `<SOLUTIONDIR>\.mcp.json`)
3. **सर्भरहरू कन्फिगर गर्नुहोस्**: मानक एमसीपी ढाँचामा आफ्नो सर्भर कन्फिगरेसन थप्नुहोस्
4. **उपकरण अनुमोदन**: जब सोधिन्छ, उपयुक्त दायराका अनुमति संग प्रयोग गर्न चाहेका उपकरणहरू अनुमोदन गर्नुहोस्

विस्तृत भिजुअल स्टुडियो सेटअप निर्देशनहरूका लागि, [भिजुअल स्टुडियो एमसीपी कागजात](https://learn.microsoft.com/visualstudio/ide/mcp-servers) हेर्नुहोस्।

प्रत्येक एमसीपी सर्भरसँग यसको कन्फिगरेसन आवश्यकताहरू छन् (जडान स्ट्रिङहरू, प्रमाणीकरण आदि), तर सेटअप ढाँचा दुवै आईडीईहरूमा समान छ।

**किन उपयोगी छ**: यो "केवल कागजात" जैसा लाग्न सक्छ, तर यो सर्भर हरेक माइक्रोसफ्ट प्रविधि प्रयोग गर्ने विकासकर्ताका लागि अत्यन्त महत्त्वपूर्ण छ। AI कोडिङ सहायकहरूका लागि .NET विकासकर्ताहरूको ठूलो गुनासो हो कि उनीहरूले नयाँ .NET र C# रिलिजहरूको अपडेट पाउँदैनन्। माइक्रोसफ्ट लर्न डक्स एमसीपी सर्भरले यो समस्या समाधान गर्छ, वास्तविक-समयमा सबैभन्दा नयाँ कागजात, API सन्दर्भ र उत्कृष्ट अभ्यासहरू उपलब्ध गराएर। तपाईं नयाँ Azure SDK हरूमा काम गर्दै हुनुहुन्छ वा C# १३ को नयाँ सुविधा अन्वेषण गर्दै हुनुहुन्छ वा Aspire ढाँचाहरू कार्यान्वयन गर्दै हुनुहुन्छ, यो सर्भरले तपाईंको AI सहायकलाई सही, आधुनिक कोड उत्पादन गर्न आवश्यक अधिकारिक, अद्यावधिक जानकारीको पहुँच सुनिश्चित गर्छ।

**वास्तविक प्रयोग**: "अधिकृत माइक्रोसफ्ट लर्न कागजात अनुसार Azure कन्टेनर एप सिर्जना गर्न कस्ता az cli कमान्डहरू छन्?" वा "ASP.NET Core मा निर्भरता इन्जेक्सनसहित Entity Framework कसरी कन्फिगर गर्ने?" वा "यो कोड समीक्षा गर्नुहोस् र यो माइक्रोसफ्ट लर्न कागजातको प्रदर्शन सिफारिससँग मेल खान्छ कि छैन हेर्नुहोस्।" यो सर्भरले माइक्रोसफ्ट लर्न, Azure डक्स र माइक्रोसफ्ट ३६५ कागजातहरूमा उन्नत सेमेन्टिक खोज प्रयोग गरेर सबैभन्दा सान्दर्भिक जानकारी प्रदान गर्दछ। यसले लेख शीर्षकहरू र URL सहित १० सम्म उच्च गुणस्तरका सामग्री खण्डहरू फर्काउँछ, सधैं सबैभन्दा नयाँ माइक्रोसफ्ट कागजातहरू जस्तै प्रकाशन हुँदैछन् त्यसरी पहुँच गर्दै।

**प्रदर्शित उदाहरण**: सर्भरले `microsoft_docs_search` उपकरण उपलब्ध गराउँछ जसले माइक्रोसफ्टको आधिकारिक प्राविधिक कागजातमा सेमेन्टिक खोज गर्छ। एक पटक कन्फिगर भएपछि, तपाईं "ASP.NET Core मा JWT प्रमाणीकरण कसरी कार्यान्वयन गर्ने?" जस्ता प्रश्नहरू सोध्न सक्नुहुन्छ र विस्तृत, आधिकारिक जवाफहरू स्रोत लिंकहरूसँग प्राप्त गर्न सक्नुहुन्छ। खोज गुणस्तर उत्कृष्ट छ किनभने यसले सन्दर्भ बुझ्छ – Azure सन्दर्भमा "कन्टेनरहरू" बारे सोध्दा Azure कन्टेनर इन्स्टेन्स कागजात फर्काउँछ, जबकि .NET सन्दर्भमा सोही शब्दले सान्दर्भिक C# संग्रह जानकारी दिन्छ।

यो विशेष गरी छिटो परिवर्तन हुने वा भर्खर अद्यावधिक गरिएको पुस्तकालयहरू र प्रयोग केसहरूको लागि उपयोगी छ। उदाहरणका लागि, केही भर्खरका कोडिङ परियोजनाहरूमा मैले Aspire र Microsoft.Extensions.AI का नयाँ संस्करणका सुविधाहरू प्रयोग गर्न चाहन्थें। माइक्रोसफ्ट लर्न डक्स एमसीपी सर्भर समावेश गरेर, मैले केवल API डक्स मात्र होइन, भर्खर प्रकाशित भएका वाकथ्रु र मार्गनिर्देशनहरू पनि उपयोग गर्न पाएको थिएँ।

### २. ☁️ Azure एमसीपी सर्भर


[![VS कोडमा इन्स्टल गर्नुहोस्](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![VS कोड इन्साइडर्समा इन्स्टल गर्नुहोस्](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**के गर्छ**: Azure MCP सर्भर १५+ विशेष Azure सेवा कनेक्सनहरूको समग्र सुइट हो जसले तपाइँको AI कार्यप्रवाहमा सम्पूर्ण Azure पारिस्थितिकी तन्त्र ल्याउँछ। यो केवल एउटा सर्भर मात्र होइन – यो शक्तिशाली संग्रह हो जसमा स्रोत व्यवस्थापन, डेटाबेस कन्ट्याक्टिभिटी (PostgreSQL, SQL Server), KQL सहित Azure Monitor लग विश्लेषण, Cosmos DB एकीकरण, र धेरै अन्य समावेश छन्।

**किन उपयोगी छ**: केवल Azure स्रोतहरू व्यवस्थापन गर्नुको अतिरिक्त, यो सर्भर Azure SDKs सँग काम गर्दा कोड गुणस्तर निकै सुधार गर्दछ। जब तपाईं Azure MCP लाई एजेन्ट मोडमा प्रयोग गर्नुहुन्छ, यसले तपाइँलाई केवल कोड लेख्न मद्दत गर्दैन – यो तपाईंलाई *राम्रो* Azure कोड लेख्न मद्दत गर्दछ जसले वर्तमान प्रमाणीकरण ढाँचाहरू, त्रुटि ह्यान्डलिंग उत्तम व्यवहारहरू अनुसरण गर्दछ, र नवीनतम SDK सुविधाहरू प्रयोग गर्दछ। तपाईंलाई साधारण कोड प्राप्त हुने सट्टा, यस्तो कोड प्राप्त हुन्छ जुन उत्पादन कार्यभारहरूका लागि Azure का सिफारिस गरिएका ढाँचाहरू अनुसरण गर्दछ।

**मुख्य मोड्युलहरू समावेश छन्**:
- **🗄️ डेटाबेस कनेक्सनहरू**: Azure Database for PostgreSQL र SQL Server प्रकोप प्राकृतिक भाषामा पहुँच
- **📊 Azure Monitor**: KQL-शक्ति प्राप्त लग विश्लेषण र सञ्चालन अन्तर्दृष्टि
- **🌐 स्रोत व्यवस्थापन**: पूर्ण Azure स्रोत जीवनचक्र व्यवस्थापन
- **🔐 प्रमाणीकरण**: DefaultAzureCredential र व्यवस्थापन पहिचान ढाँचाहरू
- **📦 भण्डारण सेवाहरू**: Blob Storage, Queue Storage, र Table Storage अपरेसनहरू
- **🚀 कन्टेनर सेवाहरू**: Azure Container Apps, Container Instances, र AKS व्यवस्थापन
- **र धेरै अन्य विशेष कनेक्सनहरू**

**वास्तविक विश्व प्रयोग**: "मेरो Azure भण्डारण खाताहरू सूचीबद्ध गर्नुहोस्", "अन्तिम घण्टामा मेरी लग एनालिटिक्स कार्यक्षेत्रमा त्रुटिहरूको लागि क्योरी गर्नुहोस्", वा "Node.js प्रयोग गरी उचित प्रमाणीकरणसहित Azure एप्लिकेशन बनाउन मद्दत गर्नुहोस्"

**पूर्ण डेमो परिदृश्य**: यहाँ Azure MCP र GitHub Copilot for Azure विस्तारलाई VS Code मा संयोजन गरेर शक्ति देखाउने पूर्ण वाकथ्रू छ। जब तपाइँले दुवै इन्स्टल गर्नुहुन्छ र आदेश दिनुहुन्छ:

> "DefaultAzureCredential प्रमाणीकरण प्रयोग गरेर Azure Blob Storage मा फाइल अपलोड गर्ने Python स्क्रिप्ट बनाउनुहोस्। स्क्रिप्टले मेरो Azure भण्डारण खाता 'mycompanystorage' सँग जडान हुनुपर्छ, 'documents' नामको कन्टेनरमा अपलोड गर्नुपर्छ, हालको टाइमस्ट्याम्प सहित परीक्षण फाइल सिर्जना गर्नुपर्छ, त्रुटिहरूलाई सजगतापूर्वक ह्यान्डल गर्नुपर्छ र जानकारीपूर्ण आउटपुट प्रदान गर्नुपर्छ, Azure प्रमाणीकरण र त्रुटि व्यवस्थापनका उत्तम अभ्यासहरू अनुसरण गर्नुपर्छ, DefaultAzureCredential प्रमाणीकरण कसरी काम गर्छ भनेर व्याख्या गर्ने टिप्पणीहरू समावेश हुनुपर्छ, र स्क्रिप्टलाई उचित कार्यहरू र दस्तावेजीकरणसहित राम्रो संरचित बनाउनुपर्छ।"

Azure MCP सर्भर पूर्ण, उत्पादन-तयार Python स्क्रिप्ट तयार पार्नेछ जुन:
- नवीनतम Azure Blob Storage SDK लाई उचित async ढाँचासहित प्रयोग गर्दछ
- व्यापक fallback श्रृंखलाको व्याख्या सहित DefaultAzureCredential लागु गर्दछ
- विशेष Azure अपवाद प्रकारहरूसँग मजबूत त्रुटि व्यवस्थापन समावेश गर्दछ
- स्रोत व्यवस्थापन र जडान ह्यान्डलिंगका लागि Azure SDK का उत्तम अभ्यासहरू अनुसरण गर्दछ
- विस्तृत लगिङ र जानकारीपूर्ण कन्सोल आउटपुट प्रदान गर्दछ
- कार्यहरू, दस्तावेजीकरण, र प्रकार सङ्केतहरूसहित उचित रूपमा संरचित स्क्रिप्ट सिर्जना गर्दछ

यसलाई उल्लेखनीय बनाउने कुरा हो कि Azure MCP विना तपाईंलाई सामान्य blob storage कोड मिल्न सक्छ जुन काम त गर्छ तर वर्तमान Azure ढाँचाहरू अनुसरण गर्दैन। Azure MCP सहित, तपाईंले नवीनतम प्रमाणीकरण विधिहरू प्रयोग गर्ने, Azure-विशिष्ट त्रुटि परिदृश्यहरू सम्हाल्ने, र उत्पादन एप्लिकेसनका लागि Microsoft का सिफारिस गरिएको अभ्यासहरू अनुसरण गर्ने कोड पाउनुहुन्छ।

**प्रदर्शित उदाहरण**: मैले `az` र `azd` CLI का विशेष आदेशहरू सम्झन समस्या भोगेको छु। यो सँधै मेरो लागि दुई चरणको प्रक्रिया हो: पहिले सिन्ट्याक्स खोज्ने, त्यसपछि आदेश चलाउने। प्रायः म पोर्टलमा जान्छु र काम गर्नका लागि क्लिक गर्छु किनकि म CLI सिन्ट्याक्स सम्झन नसक्ने स्वीकार गर्न चाहन्न। के चाहिन्छ भनेर केवल वर्णन गर्न सक्नु एकदमै राम्रो छ, र अझ राम्रो कुरा हो यो मलाई मेरो IDE छोडेर नगरेको!

तपाईलाई सुरु गर्न केही राम्रो उपयोग केसहरूको सूची [Azure MCP रिपोजिटोरी](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) मा छ। पूर्ण सेटअप निर्देशनहरू र उन्नत कन्फिगरेसन विकल्पहरूको लागि, [आधिकारिक Azure MCP कागजात](https://learn.microsoft.com/azure/developer/azure-mcp-server/) हेर्नुहोस्।

### 3. 🐙 GitHub MCP सर्भर

[![VS कोडमा इन्स्टल गर्नुहोस्](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![VS कोड इन्साइडर्समा इन्स्टल गर्नुहोस्](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**के गर्छ**: आधिकारिक GitHub MCP सर्भरले GitHub को सम्पूर्ण पारिस्थितिकी तन्त्रसँग सहज एकीकरण प्रदान गर्दछ, जसले होस्ट गरिएको रिमोट पहुँच र स्थानीय Docker परिनियोजन विकल्पहरू दुवै उपलब्ध गराउँछ। यो केवल आधारभूत रिपोजिटरी अपरेसनहरू मात्र नभई GitHub Actions व्यवस्थापन, पुल रिक्वेस्ट वर्कफ्लोहरू, समस्या ट्र्याकिङ, सुरक्षा स्क्यानिङ, सूचना, र उन्नत स्वचालन क्षमताहरू समावेश गर्ने व्यापक उपकरण हो।

**किन उपयोगी छ**: यस सर्भरले तपाइँको विकास वातावरणमा पूर्ण प्लेटफर्म अनुभव ल्याएर GitHub सङ्ग अन्तरक्रिया गर्ने तरिका परिवर्तन गर्दछ। परियोजना व्यवस्थापन, कोड समीक्षा, र CI/CD अनुगमनका लागि बारम्बार VS Code र GitHub.com बीच स्विच गर्नुपर्ने सट्टा, तपाईं सबै कुरा प्राकृतिक भाषा आदेशहरू द्वारा आफ्नो कोडमा ध्यान केन्द्रित गर्दै ह्यान्डल गर्न सक्नुहुन्छ।

> **ℹ️ नोट: 'एजेन्ट' को फरक प्रकारहरू**
> 
> यस GitHub MCP सर्भरलाई GitHub को Coding Agent (जो तपाईंले अटोमेटेड कोडिङ कार्यहरूको लागि मुद्दाहरूमा तोक्न सक्ने AI एजेन्ट हो) सँग भ्रमित नगर्नुहोस्। GitHub MCP सर्भर VS Code को Agent मोड भित्र GitHub API एकीकरण प्रदान गर्दछ, जबकि GitHub को Coding Agent एउटा अलग सुविधा हो जुन GitHub मुद्दाहरूमा तोकिएको बेला पुल रिक्वेस्टहरू सिर्जना गर्दछ।

**मुख्य क्षमता समावेश छन्**:
- **⚙️ GitHub Actions**: पूर्ण CI/CD पाइपलाइन व्यवस्थापन, वर्कफ्लो अनुगमन, र आर्टिफ्याक्ट ह्यान्डलिंग
- **🔀 पुल रिक्वेस्टहरू**: PR सिर्जना, समीक्षा, मर्ज, र व्यवस्थापन व्यापक स्थिति ट्र्याकिङसहित
- **🐛 समस्याहरू**: पूर्ण समस्या जीवनचक्र व्यवस्थापन, टिप्पणी, लेबलिङ, र असाइनमेन्ट
- **🔒 सुरक्षा**: कोड स्क्यानिङ अलर्टहरू, गोप्य पता लगाउने, र Dependabot एकीकरण
- **🔔 सूचना**: स्मार्ट सूचना व्यवस्थापन र रिपोजिटरी सदस्यता नियन्त्रण
- **📁 रिपोजिटरी व्यवस्थापन**: फाइल अपरेसनहरू, शाखा व्यवस्थापन, र रिपोजिटरी प्रशासन
- **👥 सहकार्य**: प्रयोगकर्ता र संगठन खोज, टोली व्यवस्थापन, र पहुँच नियन्त्रण

**वास्तविक विश्व प्रयोग**: "मेरो फिचर शाखाबाट पुल रिक्वेस्ट सिर्जना गर्नुहोस्", "यो साता मेरो सबै असफल CI रनहरू देखाउनुहोस्", "मेरो रिपोजिटरीहरूका लागि सबै खुला सुरक्षा अलर्टहरू सूचीबद्ध गर्नुहोस्", वा "मेरो संगठनहरूमा मेरो लागि असाइन गरिएको सबै समस्याहरू फेला पार्नुहोस्"

**पूर्ण डेमो परिदृश्य**: यहाँ GitHub MCP सर्भरका क्षमता प्रदर्शित गर्ने शक्तिशाली वर्कफ्लो छ:

> "हामीले हाम्रा स्प्रिन्ट समीक्षा तयारी गर्नुपर्छ। यो साता मैले सिर्जना गरेका सबै पुल रिक्वेस्टहरू देखाउनुहोस्, हाम्रो CI/CD पाइपलाइनहरूको स्थिति जाँच गर्नुहोस्, कुनै सुरक्षा अलर्टहरू जुन सम्बोधन गर्नुपर्ने हो तिनको सारांश बनाउनुहोस्, र 'feature' लेबल भएका मर्ज भएका PRहरूको आधारमा रिलिज नोट्स तयार पार्न मद्दत गर्नुहोस्।"

GitHub MCP सर्भरले:
- तपाईका भर्खरका पुल रिक्वेस्टहरू विस्तृत स्थिति जानकारीसहित सोधपुछ गर्दछ
- वर्कफ्लो रनहरू विश्लेषण गर्दछ र कुनै पनि असफलता वा प्रदर्शन समस्याहरू हाइलाइट गर्दछ
- सुरक्षा स्क्यानिङ परिणामहरू सङ्कलन गर्दछ र महत्वपूर्ण अलर्टहरू प्राथमिकता दिन्छ
- मर्ज भएका PR बाट जानकारी निकालेर व्यापक रिलिज नोट्स तयार पार्छ
- स्प्रिन्ट योजना र रिलिज तयारीका लागि व्यवहार्य अर्को कदमहरू प्रस्ताव गर्दछ

**प्रदर्शित उदाहरण**: मलाई यो कोड समीक्षा वर्कफ्लोहरूमा प्रयोग गर्न मन पर्छ। VS Code, GitHub सूचनाहरू, र पुल रिक्वेस्ट पृष्ठहरू बीच उफ्रिदा सट्टा, म भन्न सक्छु "मेरो समीक्षा पर्खिरहेका सबै PR देखाउनुहोस्" र त्यसपछि "PR #123 मा प्रमाणीकरण विधिमा त्रुटि ह्यान्डलिंगबारे टिप्पणी थप गर्नुहोस्।" सर्भरले GitHub API कलहरू ह्यान्डल गर्दछ, छलफलको सन्दर्भ कायम राख्दछ, र मलाई अझ रचनात्मक समीक्षा टिप्पणीहरू तयार पार्न मद्दत गर्दछ।

**प्रमाणीकरण विकल्पहरू**: सर्भरले OAuth (VS Code मा सहज) र Personal Access Tokens दुवै समर्थन गर्दछ, र आवश्यक GitHub कार्यक्षमता मात्र सक्षम गर्न कन्फिगरेबल उपकरण सेटहरू प्रदान गर्दछ। तपाईं यसलाई तत्काल सेटअपका लागि रिमोट होस्ट गरिएको सेवा रूपमा वा पूर्ण नियन्त्रणका लागि स्थानीय Docker मार्फत चलाउन सक्नुहुन्छ।

> **💡 प्रो सुझाव**
> 
> तपाईंले आवश्यक उपकरण सेटहरू मात्र सक्षम गर्दै आफ्नो MCP सर्भर सेटिङमा `--toolsets` प्यारामिटर कन्फिगर गर्नुहोस् जसले सन्दर्भ आकार घटाउँछ र AI उपकरण छनोट सुधार गर्दछ। उदाहरणका लागि, मुख्य विकास वर्कफ्लोहरूका लागि तपाईंको MCP कन्फिगरेशन args मा `"--toolsets", "repos,issues,pull_requests,actions"` थप्नुहोस्, वा GitHub अनुगमन क्षमताहरू प्राथमिकता दिने हो भने `"--toolsets", "notifications, security"` प्रयोग गर्नुहोस्।

- **प्रकाशन ढाँचाहरू**: EPub, Jupyter नोटबुकहरू (.ipynb)
- **इमेल**: आउटलुक सन्देशहरू (.msg)
- **उन्नत**: Azure Document Intelligence एकीकरणद्वारा उन्नत PDF प्रशोधन

**उन्नत क्षमता**: MarkItDown ले LLM-सञ्चालित छवि विवरणहरू (जब OpenAI क्लाइन्ट उपलब्ध हुन्छ), Azure Document Intelligence मार्फत उन्नत PDF प्रशोधन, भाषण ट्रान्सक्रिप्शन, र अतिरिक्त फाइल ढाँचाहरू विस्तार गर्न प्लगइन प्रणाली समर्थन गर्दछ।

**वास्तविक प्रयोग**: "यस PowerPoint प्रस्तुतीकरणलाई Markdown मा रूपान्तरण गर्नुहोस् हाम्रो दस्तावेज साइटका लागि", "यो PDF बाट सही शीर्षक संरचनासहित पाठ निकाल्नुहोस्", वा "यस Excel स्प्रेडशीटलाई पढ्न मिल्ने तालिका ढाँचामा रुपान्तरण गर्नुहोस्"

**विशेष उदाहरण**: उद्धृत गर्न [MarkItDown डकुमेन्टेशन](https://github.com/microsoft/markitdown#why-markdown):

> Markdown अत्यन्तै नजिक छ सादासरिलो पाठसँग, न्यूनतम मार्कअप वा रूपरेखा सहित, तर अझै महत्त्वपूर्ण कागजात संरचना प्रतिनिधित्व गर्ने तरिका प्रदान गर्दछ। मुख्यधाराका LLM हरू, जस्तै OpenAI को GPT-4o, मूल रूपमा Markdown बोल्छन्, र प्रायः अनप्रम्प्टेड Markdown लाई आफ्नो प्रतिक्रियामा समावेश गर्छन्। यसले देखाउँछ कि तिनीहरू विशाल मात्रामा Markdown-रूपरेखा गरिएको पाठमा प्रशिक्षित भएका छन् र यसलाई राम्रोसँग बुझ्छन्। एक अतिरिक्त लाभको रूपमा, Markdown नियमहरू धेरै टोकन-कुशल पनि हुन्छन्।

MarkItDown साँच्चिकै राम्रो छ कागजात संरचना जोगाउन, जुन AI कार्यप्रवाहहरूसँग महत्त्वपूर्ण छ। उदाहरणका लागि, PowerPoint प्रस्तुतीकरण रूपान्तरण गर्दा, यो स्लाइड संगठन सटीक शीर्षकहरूसँग राख्छ, तालिकाहरूलाई Markdown तालिकाहरूको रूपमा निकाल्छ, छविहरूका लागि alt पाठ समावेश गर्छ, र वक्ता नोटहरू समेत प्रशोधन गर्छ। चार्टहरू पढ्न मिल्ने डेटाटेबलहरूमा रूपान्तरण हुन्छन्, र परिणामस्वरूप Markdownले मूल प्रस्तुतीकरणको तार्किक प्रवाह कायम राख्छ। यसले यसलाई AI प्रणालीहरूमा प्रस्तुतीकरण सामग्री खानका लागि वा अस्तित्वमा रहेका स्लाइडहरूबाट दस्तावेजहरू बनाउनका लागि उत्तम बनाउँछ।

**किन यो उपयोगी छ**: यस सर्भरले Azure AI सेवाहरू संग तपाइँको काम गर्ने तरिका परिवर्तन गर्दछ जसले उद्यम स्तरको AI क्षमता विकास कार्यप्रवाहमा सिधै ल्याउँछ। Azure पोर्टल, दस्तावेजीकरण, र IDE बीच स्विच गर्ने सट्टा, तपाईं मोडेलहरू पत्ता लगाउन, सेवाहरू डिप्लोय गर्न, ज्ञान आधारहरू व्यवस्थापन गर्न, र AI प्रदर्शन प्राकृतिक भाषा आदेशहरू मार्फत मूल्याङ्कन गर्न सक्नुहुन्छ। यो विशेष गरी विकासकर्ताहरूका लागि शक्तिशाली छ जसले RAG (पुनःप्राप्ति-वर्धित उत्पादन) अनुप्रयोगहरू बनाउँदै छन्, बहु-मोडेल डिप्लोयमेन्टहरू व्यवस्थापन गर्दै छन्, वा व्यापक AI मूल्याङ्कन पाइपलाइनहरू कार्यान्वयन गर्दै छन्।

**मुख्य विकासकर्ता क्षमताहरू**:
- **🔍 मोडेल पत्ता लगाउने र डिप्लोयमेन्ट**: माइक्रोसफ्ट फाउन्ड्रीको मोडेल क्याटलग अन्वेषण गर्नुहोस्, कोड नमूनाहरूसहित विस्तृत मोडेल जानकारी पाउनुहोस्, र मोडेलहरूलाई Azure AI सेवाहरूमामा डिप्लोय गर्नुहोस्
- **📚 ज्ञान व्यवस्थापन**: Azure AI खोज अनुक्रमणिका सिर्जना र व्यवस्थापन गर्नुहोस्, कागजातहरू थप्नुहोस्, अनुक्रमणिका कन्फिगर गर्नुहोस्, र जटिल RAG प्रणालीहरू बनाउनुहोस्
- **⚡ AI एजेंट एकीकरण**: Azure AI एजेन्टहरूसँग जडान गर्नुहोस्, अवस्थित एजेन्टहरू सोध्नुहोस्, र उत्पादन परिदृश्यमा एजेन्ट प्रदर्शन मूल्याङ्कन गर्नुहोस्
- **📊 मूल्याङ्कन फ्रेमवर्क**: व्यापक पाठ र एजेन्ट मूल्याङ्कन दौडाउनुहोस्, मार्कडाउन रिपोर्टहरू सिर्जना गर्नुहोस्, र AI अनुप्रयोगहरूको गुणस्तर आश्वासन कार्यान्वयन गर्नुहोस्
- **🚀 प्रोटोटाइपिङ उपकरणहरू**: गिटहबसँग आधारित प्रोटोटाइपिङका लागि सेटअप निर्देशनहरू प्राप्त गर्नुहोस् र माइक्रोसफ्ट फाउन्ड्री ल्याब्समा पहुँच पाउनुहोस् जुन अगाडि सारिएका अनुसन्धान मोडेलहरू प्रदान गर्दछ

**वास्तविक संसारको विकासकर्ता प्रयोग**: "मेरो अनुप्रयोगको लागि Phi-4 मोडेल Azure AI सेवाहरूमामा डिप्लोय गर्नुहोस्", "मेरो दस्तावेजीकरण RAG प्रणालीको लागि नयाँ खोज अनुक्रमणिका सिर्जना गर्नुहोस्", "मेरो एजेन्टका जवाफहरू गुणस्तर मेट्रिक्स विरुद्ध मूल्याङ्कन गर्नुहोस्", वा "मेरो जटिल विश्लेषण कार्यहरूका लागि सबैभन्दा राम्रो तर्क मोडेल फेला पार्नुहोस्"

**पूर्ण डेमो परिदृश्य**: यहाँ एक शक्तिशाली AI विकास कार्यप्रवाह छ:

> "म ग्राहक सहायता एजेन्ट निर्माण गर्दैछु। मलाई क्याटलगबाट राम्रो तर्क मोडेल खोज्न मद्दत गर्नुहोस्, यसलाई Azure AI सेवाहरूमा डिप्लोय गर्नुहोस्, हाम्रो दस्तावेजीकरणबाट ज्ञान आधार सिर्जना गर्नुहोस्, जवाफ गुणस्तर परीक्षण गर्न मूल्याङ्कन फ्रेमवर्क सेटअप गर्नुहोस्, र त्यसपछि परीक्षणको लागि GitHub टोकनसँग एकीकरण प्रोटोटाइप बनाउन मलाई मद्दत गर्नुहोस्।"

माइक्रोसफ्ट फाउन्ड्री MCP सर्भरले:
- तपाइँका आवश्यकताहरूका आधारमा उत्तम तर्क मोडेलहरू सिफारिस गर्न मोडेल क्याटलग सोध्छ
- तपाइँको रोजाइको Azure क्षेत्रमा डिप्लोयमेन्ट आदेश र कोटा जानकारी प्रदान गर्छ
- तपाइँको दस्तावेजीकरणको लागि उपयुक्त स्कीमासहित Azure AI खोज अनुक्रमणिका सेटअप गर्छ
- गुणस्तर मेट्रिक्स र सुरक्षा जाँचहरू सहित मूल्याङ्कन पाइपलाइनहरू कन्फिगर गर्छ
- तुरुन्तै परीक्षणका लागि GitHub प्रमाणीकरणसहित प्रोटोटाइपिङ कोड उत्पादन गर्छ
- तपाइँको विशिष्ट प्रविधि ढाँचालाई लक्षित गरी व्यापक सेटअप गाइडहरू प्रदान गर्छ

**विशेष उदाहरण**: विकासकर्ताको रूपमा, म विभिन्न LLM मोडेलहरू पछ्याउन संघर्ष गर्दैछु। म केही मुख्य मोडेलहरू जान्छु, तर कहिलेकाहीँ लाग्छ म केही उत्पादकता र दक्षता लाभहरू गुमाइरहेको छु। र टोकनहरू र कोटा व्यवस्थापन तनावपूर्ण र कठिन छ – म कहिल्यै निश्चित छैन कि म सही कार्यका लागि सही मोडेल छान्दैछु वा मेरो बजेट अनावश्यक रूपमा खर्च गर्दैछु। मैले यस MCP सर्भरको बारेमा जेम्स मोंतेमाग्नोबाट थाहा पाएँ जब म टिमका सदस्यहरूसँग MCP सर्भर सन्दर्भहरू बारे छलफल गर्दै थिएँ, र म यसलाई प्रयोग गर्न उत्साहित छु! मोडेल पत्ता लगाउने क्षमता विशेष गरी मलाई जस्तोहरूका लागि प्रभावशाली देखिन्छ जसले सामान्यमा भन्दा बाहिर खोजी गर्न चाहन्छन् र विशेष कार्यका लागि अनुकूलित मोडेलहरू फेला पार्न चाहन्छन्। मूल्याङ्कन फ्रेमवर्कले मलाई साँच्चै राम्रो परिणाम पाइरहेको छु भन्ने सुनिश्चित गर्न मद्दत पुर्‍याउने छ, मात्र नयाँ कुरा प्रयास गर्नका लागि होइन।

> **ℹ️ प्रयोगात्मक स्थिति**
> 
> यो MCP सर्भर प्रयोगात्मक छ र सक्रिय विकासमा छ। सुविधाहरू र API हरू परिवर्तन हुन सक्छन्। Azure AI क्षमताहरू अन्वेषण गर्न र प्रोटोटाइपहरू बनाउनका लागि उपयुक्त, तर उत्पादन प्रयोगको लागि स्थिरता आवश्यकताहरू प्रमाणीकरण गर्नुहोस्।

**यसले के गर्छ**: विकासकर्ताहरूलाई Microsoft 365 र Microsoft 365 Copilot सँग एकीकरण भएका AI एजेन्टहरू र अनुप्रयोगहरू निर्माण गर्न आवश्यक उपकरणहरू प्रदान गर्दछ, जसमा स्कीमा प्रमाणीकरण, नमूना कोड पुनःप्राप्ति, र समस्यासम्बन्धी सहायता समावेश छ।

**किन यो उपयोगी छ**: Microsoft 365 र Copilot का लागि विकास जटिल म्यानिफेस्ट स्कीमाहरू र विशिष्ट विकास ढाँचाहरू समावेश गर्दछ। यो MCP सर्भरले तपाइँको कोडिङ वातावरणमा सिधै आवश्यक विकास स्रोतहरू ल्याउँछ, जसले तपाइँलाई स्कीमाहरू प्रमाणीकरण गर्न, नमूना कोड फेला पार्न, र सामान्य समस्याहरू समाधान गर्न मद्दत गर्दछ बिना लगातार दस्तावेजहरू सन्दर्भ गर्न।

**वास्तविक संसार प्रयोग**: "मेरो घोषित एजेन्ट म्यानिफेस्ट प्रमाणीकरण गर र कुनै स्कीमा त्रुटिहरू सच्याऊ", "Microsoft Graph API प्लगइन लागू गर्ने नमूना कोड देखाऊ", वा "मेरो Teams एप प्रमाणीकरण समस्याहरू समाधान गर्न मद्दत गर"

**विशेष उदाहरण**: मैले Build मा उसँग कुरा गर्दा मेरो साथी John Miller लाई सम्पर्क गरेँ र उनले मलाई यो MCP सिफारिस गरे। यो M365 एजेन्टहरूमा नयाँ विकासकर्ताहरूका लागि उत्कृष्ट हुन सक्छ किनभने यसले टेम्प्लेटहरू, नमूना कोड, र स्काफोल्डिङ प्रदान गर्दछ जसले दस्तावेजीकरणमा डुब्ने बिना सुरु गर्न मद्दत गर्छ। स्कीमा प्रमाणीकरण सुविधाहरू विशेष गरी उपयोगी देखिन्छन् जसले म्यानिफेस्ट संरचना त्रुटिहरूबाट बचाउछन् जसले घण्टौं डिबगिङ अप्ठ्यारो पार्न सक्छ।

## 📋 निष्कर्ष

मोडेल कन्टेक्स्ट प्रोटोकल (MCP)ले विकासकर्ताहरूलाई AI सहायक र बाह्य उपकरणहरूसँग अन्तरक्रिया गर्ने तरिका परिवर्तन गरिरहेको छ। यी १० माइक्रोसफ्ट MCP सर्भरहरूले मानकीकृत AI एकीकरणको शक्ति प्रदर्शन गर्छन्, जसले सहज कार्यप्रवाहहरू सक्षम बनाउँछ र विकासकर्ताहरूलाई उनीहरूको प्रवाह अवस्थामा राख्दछ जबकि शक्तिशाली बाह्य क्षमताहरू पहुँचयोग्य हुन्छन्।

व्यापक Azure पारिस्थितिकी तंत्र एकीकरणदेखि लिएर Playwright जस्तो ब्राउजर अटोमेसन र MarkItDown जस्तो कागजात प्रशोधनका विशेष उपकरणहरूसम्म, यी सर्भरहरूले देखाउँछन् कि MCP ले विभिन्न विकास परिदृश्यमाहरूमा उत्पादकता कसरी वृद्धि गर्न सक्छ। मानकीकृत प्रोटोकलले सुनिश्चित गर्दछ कि यी उपकरणहरू सँगै बिना कुनै बाधा काम गर्छन्, एक समग्र विकास अनुभव सिर्जना गर्दै।

जस्तै-जसरी MCP पारिस्थितिकी तंत्र विकसित भइरहेको छ, समुदाय संग संलग्न रहनु, नयाँ सर्भरहरू अन्वेषण गर्नु, र अनुकूलित समाधानहरू निर्माण गर्नु तपाइँको विकास उत्पादकता अधिकतम गर्नको लागि कुञ्जी हुनेछ। MCP को खुला मानक प्रकृतिले मतलब तपाइँ फरक विक्रेताहरूका उपकरणहरू मिक्स र म्याच गरेर तपाइँको विशिष्ट आवश्यकताहरूको लागि उत्तम कार्यप्रवाह बनाउन सक्नुहुन्छ।
