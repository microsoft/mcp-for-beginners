# केस अध्ययन: API व्यवस्थापनमा REST API लाई MCP सर्भर रूपमा प्रदर्शन गर्नुहोस्

Azure API व्यवस्थापन, तपाईंका API अन्तबिन्दुहरूमा गेटवे प्रदान गर्ने सेवा हो। यसले यसरी काम गर्छ कि Azure API व्यवस्थापनले तपाईंका API हरूको अगाडि प्रोक्सीको रूपमा काम गर्छ र आउँदै गरेका अनुरोधहरूसँग के गर्ने निर्णय गर्नसक्छ।

यसको प्रयोग गरेर, तपाईंले धेरै सुविधाहरू थप्न सक्नुहुन्छ जस्तै:

- **सुरक्षा**, तपाईं API कुञ्जी, JWT देखि व्यवस्थृत पहिचानसम्म सबै कुरा प्रयोग गर्न सक्नुहुन्छ।
- **रेट लिमिटिङ**, एक उत्कृष्ट सुविधा हो जुनले निश्चित समयमा कति कलहरू जान सकिन्छ निर्धारण गर्न मद्दत गर्दछ। यसले सुनिश्चित गर्छ कि सबै प्रयोगकर्ताहरूलाई राम्रो अनुभव होस् र तपाईंको सेवा अनुरोधहरूले ओभरलोड नहोस्।
- **स्केलिङ र लोड ब्यालेन्सिङ**। तपाईं लोड सन्तुलन गर्न धेरै अन्तबिन्दुहरू सेटअप गर्न सक्नुहुन्छ र तपाईं लोड ब्यालेन्सिङ कसरी गर्ने निर्णय पनि गर्न सक्नुहुन्छ।
- **AI सुविधाहरू जस्तै सेम्यान्टिक क्यासिङ**, टोकन सीमा र टोकन निगरानी र थप। यी उत्कृष्ट सुविधाहरूले प्रतिक्रियाशीलता सुधार्छन् साथै तपाईंको टोकन खर्चमा नियन्त्रण मद्दत गर्छन्। [यहाँ थप पढ्नुहोस्](https://learn.microsoft.com/en-us/azure/api-management/genai-gateway-capabilities)। 

## किन MCP + Azure API व्यवस्थापन?

मोडल कण्टेक्स्ट प्रोटोकल छिट्टै एजेण्टिक AI एपहरूका लागि मापदण्ड बन्दै गएको छ र कसरी उपकरण र डेटा सुसंगत तरिकाले प्रदर्शन गर्ने भन्ने कुरा हो। Azure API व्यवस्थापन तब स्वाभाविक विकल्प हो जब तपाईंले API हरू "प्रबन्धन" गर्नु पर्छ। MCP सर्भरहरू प्रायः अन्य API हरूसँग समाकलित हुन्छन् उदाहरणका लागि उपकरणको लागि अनुरोध समाधान गर्न। त्यसैले Azure API व्यवस्थापन र MCP लाई संयोजन गर्नु धेरै उपयुक्त हुन्छ।

## अवलोकन

यस विशेष प्रयोग केसमा हामी API अन्तबिन्दुहरूलाई MCP सर्भर रूपमा प्रदर्शन गर्न सिक्नेछौं। यसरी गर्दा, हामी सजिलैसँग यी अन्तबिन्दुहरूलाई एजेण्टिक एपको भाग बनाउन सक्छौं साथै Azure API व्यवस्थापनका सुविधाहरूको फाइदा लिन सक्छौं।

## मुख्य सुविधाहरू

- तपाईंले उपकरणको रूपमा प्रदर्शन गर्न चाहने अन्तबिन्दु विधिहरू छनोट गर्नुहुन्छ।
- तपाईंले प्राप्त गर्ने थप सुविधाहरू तपाईंको API को नीति सेक्सनमा के सेटअप गर्नुहुन्छमा निर्भर हुन्छ। तर यहाँ हामी तपाईंलाई रेट लिमिटिङ कसरी थप्ने देखाउनेछौं।

## पूर्व-चरण: API आयात गर्नुहोस्

यदि तपाईंको Azure API व्यवस्थापनमा पहिले नै API छ भने राम्रो, त्यसो भए यो चरण छोड्न सक्नुहुन्छ। नभए, यो लिंक जाँच्नुहोस्, [Azure API व्यवस्थापनमा API आयात गर्न](https://learn.microsoft.com/en-us/azure/api-management/import-and-publish#import-and-publish-a-backend-api)।

## API लाई MCP सर्भर रूपमा प्रदर्शन गर्नुहोस्

API अन्तबिन्दुहरू प्रदर्शन गर्न, यी चरणहरू पालना गरौं:

1. Azure पोर्टलमा जानुहोस् र तलको ठेगाना खोल्नुहोस् <https://portal.azure.com/?Microsoft_Azure_ApiManagement=mcp> 
तपाईंको API व्यवस्थापन उदाहरणमा जानुहोस्।

1. बाँयाको मेनुमा, APIs > MCP सर्भरहरू > + नयाँ MCP सर्भर सिर्जना गर्नुहोस् छनोट गर्नुहोस्।

1. API मा, MCP सर्भर रूपमा प्रदर्शन गर्न REST API छनोट गर्नुहोस्।

1. एक वा बढी API अपरेसनहरू उपकरणको रूपमा प्रदर्शन गर्न छनोट गर्नुहोस्। तपाईंले सबै अपरेसनहरू वा केवल विशिष्ट अपरेसनहरू छनोट गर्न सक्नुहुन्छ।

    ![प्रदर्शन गर्न विधि छनोट गर्नुहोस्](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/create-mcp-server-small.png)


1. **सिर्जना गर्नुहोस्** चयन गर्नुहोस्।

1. मेनु विकल्प **APIs** र **MCP सर्भरहरू** मा जानुहोस्, तपाईंले तल देख्नुहुनेछ:

    ![मुख्य पाटोमा MCP सर्भर हेर्नुहोस्](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-list.png)

    MCP सर्भर सिर्जना भइसकेको छ र API अपरेसनहरू उपकरणको रूपमा प्रदर्शन भएका छन्। MCP सर्भर MCP सर्भरहरू पाटोमा सूचीबद्ध छ। URL स्तम्भले MCP सर्भर अन्तबिन्दु देखाउँछ जुन तपाईं परीक्षण गर्न वा क्लाइन्ट एपमा कल गर्न सक्नुहुन्छ।

## वैकल्पिक: नीतिहरू कन्फिगर गर्नुहोस्

Azure API व्यवस्थापनसँग नीतिहरूको प्रमुख अवधारणा छ जहाँ तपाईंले तपाईंका अन्तबिन्दुहरूको लागि विभिन्न नियमहरू सेटअप गर्न सक्नुहुन्छ जस्तै रेट लिमिटिङ वा सेम्यान्टिक क्यासिङ। यी नीतिहरू XML मा लेखिन्छन्।

MCP सर्भरको लागि रेट लिमिट सेटअप गर्न तपाईं यसरी नीति सेटअप गर्न सक्नुहुन्छ:

1. पोर्टलमा, APIs अन्तर्गत, **MCP सर्भरहरू** चयन गर्नुहोस्।

1. तपाईंले सिर्जना गरेको MCP सर्भर चयन गर्नुहोस्।

1. बाँयाको मेनुमा, MCP अन्तर्गत, **नीतिहरू** चयन गर्नुहोस्।

1. नीति सम्पादकमा, MCP सर्भरका उपकरणहरूमा लागू गर्न चाहने नीतिहरू थप्नुहोस् वा सम्पादन गर्नुहोस्। नीतिहरू XML ढाँचामा परिभाषित छन्। उदाहरणका लागि, तपाईंले MCP सर्भरका उपकरणहरूमाथि कल सीमित गर्ने नीति थप्न सक्नुहुन्छ (यस उदाहरणमा, प्रति क्लाइन्ट IP ठेगानामा ३० सेकेन्डमा ५ कलहरू)। यहाँ XML छ जसले यो रेट लिमिट निम्त्याउँछ:

    ```xml
     <rate-limit-by-key calls="5" 
       renewal-period="30" 
       counter-key="@(context.Request.IpAddress)" 
       remaining-calls-variable-name="remainingCallsPerIP" 
    />
    ```

    यहाँ नीति सम्पादकको एउटा छवि छ:

    ![नीति सम्पादक](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-policies-small.png)
 
## प्रयास गर्नुहोस्

आउनुहोस् हाम्रो MCP सर्भर उचित रूपमा काम गरिरहेको छ कि छैन पक्का गरौं।

> [!NOTE]
> Azure API व्यवस्थापन हाल यो सर्भरलाई Streamable HTTP `/mcp` अन्तबिन्दुबाट प्रदर्शन गर्दछ। पुरानो HTTP+SSE `/sse` ट्रान्सपोर्ट अब प्रयोगबाट परित्यक्त छ र केवल पुराना क्लाइन्टहरूसँग मात्र प्रयोग गर्नुपर्छ।

> 

यसका लागि, हामी Visual Studio Code र GitHub Copilot को Agent मोड प्रयोग गर्नेछौं। हामी MCP सर्भरलाई *mcp.json* मा थप्नेछौं। यसरी गर्दा, Visual Studio Code एक एजेन्टिक क्षमतासहित क्लाइन्टको रूपमा कार्य गर्नेछ र अन्त प्रयोगकर्ताहरूले प्रम्प्ट टाइप गरेर उक्त सर्भरसँग अन्तरक्रिया गर्न सक्नेछन्।

Visual Studio Code मा MCP सर्भर कसरी थप्ने हेर्नुहोस्:

1. आदेश प्यालेटबाट MCP: **सर्भर थप्नुहोस् आदेश** प्रयोग गर्नुहोस्।

1. सोध्दा सर्भर प्रकार चयन गर्नुहोस्: **HTTP (HTTP वा Server Sent Events)**।

1. API व्यवस्थापनमा MCP सर्भरको लागि देखाइएको Streamable HTTP URL प्रविष्ट गर्नुहोस्।
    उदाहरणका लागि:
    `https://<apim-service-name>.azure-api.net/<api-name>-mcp/mcp`.

1. तपाईंको मनपर्ने सर्भर ID प्रविष्ट गर्नुहोस्। यो महत्वपूर्ण मान होइन तर यसले तपाईंलाई यो सर्भर इन्स्ट्यान्स के हो सम्झन मद्दत गर्नेछ।

1. कन्फिगरेसन तपाईंको कार्यस्थान सेटिङहरूमा र को उपयोगकर्ता सेटिङहरूमा बचत गर्ने छनोट गर्नुहोस्।

  - **वर्कस्पेस सेटिङहरू** - सर्भर कन्फिगरेसन .vscode/mcp.json फाइलमा मात्र बचत हुन्छ जुन हालको कार्यस्थानमा उपलब्ध हुन्छ।

    *mcp.json*

    ```json
    "servers": {
        "APIM petstore" : {
            "type": "http",
            "url": "url-to-mcp-server/mcp"
        }
    }
    ```

  - **प्रयोगकर्ता सेटिङहरू** - सर्भर कन्फिगरेसन तपाईंको ग्लोबल *settings.json* फाइलमा थपिन्छ र सबै कार्यस्थानहरूमा उपलब्ध हुन्छ। कन्फिगरेसन तल झैँ देखिन्छ:

    ![प्रयोगकर्ता सेटिङ्](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-servers-visual-studio-code.png)

1. तपाईंले Azure API व्यवस्थापनलाई सही रूपमा प्रमाणित गर्न कन्फिगरेसनमा हेडर पनि थप्न आवश्यक छ। यसले **Ocp-Apim-Subscription-Key** नामक हेडर प्रयोग गर्छ। 


    - यसरी तपाईंले यसलाई सेटिङहरूमा थप्न सक्नुहुन्छ:

    ![प्रमाणीकरणको लागि हेडर थप्दै](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-with-header-visual-studio-code.png), यसले तपाईंलाई API कुञ्जी मान सोध्न एक प्रॉम्प्ट देखाउनेछ जुन तपाईंले Azure पोर्टलमा आफ्नै Azure API व्यवस्थापन उदाहरणको लागि फेला पार्न सक्नुहुन्छ।

   - अन्तरगर्न *mcp.json* मा थप्न चाहनुहुन्छ भने, यसरी थप्न सक्नुहुन्छ:

    ```json
    "inputs": [
      {
        "type": "promptString",
        "id": "apim_key",
        "description": "API Key for Azure API Management",
        "password": true
      }
    ]
    "servers": {
        "APIM petstore" : {
            "type": "http",
            "url": "url-to-mcp-server/mcp",
            "headers": {
                "Ocp-Apim-Subscription-Key": "Bearer ${input:apim_key}"
            }
        }
    }
    ```

### एजेन्ट मोड प्रयोग गर्नुहोस्

अब हामी सेटिङहरूमा वा *.vscode/mcp.json* मा सबै तयार छौं। आउनुहोस् यसलाई प्रयास गरौं। 

त्यहाँ यस्तो टूलहरूको आइकन हुनुपर्छ, जहाँ तपाईंको सर्भरबाट उपलब्ध टूलहरू सूचीबद्ध छन्:

![सर्भरबाट टूलहरू](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/tools-button-visual-studio-code.png)

1. टूल आइकनमा क्लिक गर्नुहोस् र तपाईंले यस्तो टूलहरूको सूची देख्नु पर्नेछ:

    ![टूलहरू](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/select-tools-visual-studio-code.png)

1. टूललाई कल गर्न च्याटमा प्रॉम्प्ट प्रविष्ट गर्नुहोस्। उदाहरणका लागि, यदि तपाईंले अर्डरको जानकारी प्राप्त गर्न एउटा टूल चयन गर्नुभयो भने, तपाईं एजेन्टलाई अर्डरको बारेमा सोध्न सक्नुहुन्छ। यहाँ एउटा उदाहरण प्रॉम्प्ट छ:

    ```text
    get information from order 2
    ```

    अब तपाईंलाई टूललाई कल गर्न जारी राख्न टूलको आइकन देखाइनेछ। टूल चलाउन जारी राख्न चयन गर्नुहोस्, अब तपाईंलाई यस्तो नतिजा देखिनेछ:

    ![प्रॉम्प्टबाट नतिजा](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/chat-results-visual-studio-code.png)

    **तपाईंले माथि के देख्नुभयो त्यो तपाईंले सेटअप गरेको टूलहरूमा निर्भर गर्दछ, तर विचार यो हो कि तपाईंले माथि जस्तै पाठात्मक प्रतिक्रिया पाउनुहुन्छ**
