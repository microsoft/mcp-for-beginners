# MCP क्यालेकुलेटर सर्भर (Python)



एक सरल मोडेल कन्टेक्स्ट प्रोटोकल (MCP) सर्भर कार्यान्वयन जुन Python मा आधारित छ र आधारभूत क्यालेकुलेटर कार्यक्षमता प्रदान गर्छ।


## स्थापना

आवश्यक निर्भरताहरु स्थापना गर्नुहोस्:

```bash
pip install -r requirements.txt
```

वा MCP Python SDK सिधै स्थापना गर्नुहोस्:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## प्रयोग

### सर्भर सञ्चालन

सर्भर MCP क्लाइन्टहरु (जस्तै Claude Desktop) द्वारा प्रयोग गर्न डिजाइन गरिएको छ। सर्भर सुरु गर्न:

```bash
python mcp_calculator_server.py
```

**सूचना**: जब सिधै टर्मिनलमा चलाइन्छ, तपाईं JSON-RPC मान्यकरण त्रुटिहरु देख्नुहुनेछ। यो सामान्य व्यवहार हो - सर्भर सही रूपमा स्वरूपित MCP क्लाइन्ट सन्देशहरूको प्रतिक्षा गर्दैछ।

### कार्यक्षमताहरु परीक्षण गर्ने

सुनिश्चित गर्न कि क्यालेकुलेटर कार्यहरु ठीकसँग काम गरिरहेका छन्:

```bash
python test_calculator.py
```

## समस्या समाधान

### आयात त्रुटिहरु

यदि तपाईंले `ModuleNotFoundError: No module named 'mcp'` देख्नु भयो भने, MCP Python SDK स्थापना गर्नुहोस्:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### सिधै चलाउँदा JSON-RPC त्रुटिहरु

सर्भर सिधै चलाउँदा "Invalid JSON: EOF while parsing a value" जस्ता त्रुटिहरु अपेक्षित छन्। सर्भरले MCP क्लाइन्ट सन्देशहरु चाहन्छ, सिधा टर्मिनल इनपुट होइन।
