## सुरु गर्दै  

[![तपाईंको पहिलो MCP सर्भर बनाउनुहोस्](../../../translated_images/ne/04.0ea920069efd979a.webp)](https://youtu.be/sNDZO9N4m9Y)

_(यस पाठको भिडियो हेर्न माथि भएको छविमा क्लिक गर्नुहोस्)_

यो खण्डमा केही पाठहरू समावेश छन्:

- **1 तपाईंको पहिलो सर्भर**, यस पहिलो पाठमा, तपाईंले आफ्नो पहिलो सर्भर कसरी सिर्जना गर्ने र इन्स्पेक्टर उपकरणसँग जाँच गर्ने सिक्नु हुनेछ, जुन तपाईंको सर्भरको परीक्षण र डिबग गर्नमा एक महत्वपूर्ण तरिका हो, [पाठमा](01-first-server/README.md)

- **2 क्लाइχट**, यस पाठमा, तपाईंले कसरी क्लाइχट लेख्ने जुन तपाईंको सर्भरमा जडान हुन सक्छ भन्ने सिक्नु हुनेछ, [पाठमा](02-client/README.md)

- **3 LLM सहित क्लाइχट**, क्लाइχट लेख्ने अझ राम्रो तरिका भनेको यसमा LLM थप्नु हो जसले तपाईंको सर्भरसँग "बातचीत" गर्न सक्षम गर्दछ कि के गर्नु, [पाठमा](03-llm-client/README.md)

- **4 Visual Studio Code मा GitHub Copilot एजेन्ट मोडबाट सर्भर उपभोग गर्ने**। यहाँ, हामी Visual Studio Code भित्रबाट हाम्रो MCP सर्भर चलाउने तरिका हेरिरहेका छौं, [पाठमा](04-vscode/README.md)

- **5 stdio यातायात सर्भर** stdio यातायात स्थानीय MCP सर्भर-देखि-क्लाइχट संचारको लागि सिफारिस गरिएको मानक हो, जसले सुरक्षित subprocess आधारित संचार र निर्मित प्रक्रिया पृथक्करण प्रदान गर्दछ [पाठमा](05-stdio-server/README.md)

- **6 MCP सँग HTTP स्ट्रिमिङ (स्ट्रिमेबल HTTP)**। स्ट्यान्डर्ड
	रिमोट यातायात [MCP विशिष्टता 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http) मा सिक्नुहोस्,
	साथै पाठमा राखिएको पुरानो सेसन-आधारित कार्यान्वयन।
	[पाठमा](06-http-streaming/README.md)

- **7 VSCode को लागि AI टूलकिट उपयोग गर्ने** तपाईंका MCP क्लाइχट र सर्भरहरू उपभोग र परीक्षण गर्न [पाठमा](07-aitk/README.md)

- **8 परीक्षण**। यहाँ हामी विशेष गरी हेरौं कसरी विभिन्न तरिकाले सर्भर र क्लाइχट परीक्षण गर्न सकिन्छ, [पाठमा](08-testing/README.md)

- **9 परिनियोजन**। यो अध्यायमा तपाईंका MCP समाधानहरू विभिन्न तरिकाले कसरी परिनियोजन गर्ने भनेर हेर्नेछौं, [पाठमा](09-deployment/README.md)

- **10 उन्नत सर्भर प्रयोग**। यो अध्याय उन्नत सर्भर प्रयोगलाई समेट्छ, [पाठमा](./10-advanced/README.md)

- **11 प्रमाणीकरण**। यो अध्यायमा तपाईं कसरी सरल प्रमाणीकरण थप्ने (Basic Auth देखि JWT र RBAC सम्म) सिक्नुहुनेछ। तपाईंलाई यहाँबाट सुरु गर्न र त्यसपछि अध्याय 5 को उन्नत विषयहरू हेर्न तथा अध्याय 2 का सिफारिसहरू अनुसार थप सुरक्षा कडा गर्ने प्रोत्साहन दिइन्छ, [पाठमा](./11-simple-auth/README.md)

- **12 MCP होस्टहरू**। लोकप्रिय MCP होस्ट क्लाइχटहरू जस्तै Claude Desktop, Cursor, Cline, र Windsurf कन्फिगर र प्रयोग गर्ने तरिका सिक्नुहोस्। यातायात प्रकार र समस्याको समाधान सिक्नुहोस्, [पाठमा](./12-mcp-hosts/README.md)

- **13 MCP इन्स्पेक्टर**। MCP इन्स्पेक्टर उपकरण प्रयोग गरी तपाईंका MCP सर्भरहरूलाई अन्तरक्रियात्मक रूपमा डिबग र परीक्षण गर्ने तरिका सिक्नुहोस्। उपकरणहरू, स्रोतहरू, र प्रोटोकल सन्देशहरूको त्रुटि सुल्झाउने तरिका सिक्नुहोस्, [पाठमा](./13-mcp-inspector/README.md)

- **14 नमूना लिने (सैम्पलिंग)**। `2025-11-25` को लागि पुरानो नमूना लिने प्रारम्भिक तरिका सिक्नुहोस् र
	नयाँ ढाँचाहरूलाई प्रत्यक्ष LLM प्रदायक एकीकरणमा कसरी स्थानान्तरण गर्ने। MCP मा सैम्पलिंग `2026-07-28` मा अवसान भएको छ। [पाठमा](./14-sampling/README.md)










- कस्टम सुविधाहरू (स्रोतहरू, प्रॉम्प्टहरू, र उपकरणहरू) सहित आधारभूत MCP सर्भरहरू निर्माण र परिनियोजन गर्न
- MCP सर्भरहरूमा जडान हुने होस्ट अनुप्रयोगहरू सिर्जना गर्न
- MCP कार्यान्वयनहरू परीक्षण र डिबग गर्न
- सामान्य सेटअप चुनौतीहरू र तिनीहरूको समाधान बुझ्न
- लोकप्रिय LLM सेवाहरूमा तपाईंका MCP कार्यान्वयनहरू जडान गर्न










- **IDE/सम्पादक**: Visual Studio, Visual Studio Code, IntelliJ, Eclipse, PyCharm, वा कुनै आधुनिक कोड सम्पादक
- **प्याकेज म्यानेजरहरू**: NuGet, Maven/Gradle, pip, वा npm/yarn
- **API कुञ्जीहरू**: तपाईंको होस्ट अनुप्रयोगहरूमा प्रयोग गर्न चाहेको कुनै पनि AI सेवाका लागि





Java र .NET प्रयोग गरेर समाधानहरू देख्नु हुनेछ। यहाँ आधिकारिक SDK हरू छन्।


उदाहरण चलाउनु अघि, यसको प्याकेज संस्करण र SDK को रिलिज नोटहरू
समर्थित प्रोटोकल संशोधनहरूको लागि जाँच गर्नुहोस्। 
हेर्नुहोस्
[आधिकारिक SDK सूची](https://modelcontextprotocol.io/docs/sdk):
- [C# SDK](https://github.com/modelcontextprotocol/csharp-sdk) - माइक्रोसफ्टसँगको सहकार्यमा मर्मत गरिएको
- [Java SDK](https://github.com/modelcontextprotocol/java-sdk) - Spring AI सँगको सहकार्यमा मर्मत गरिएको
- [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) - आधिकारिक TypeScript कार्यान्वयन
- [Python SDK](https://github.com/modelcontextprotocol/python-sdk) - आधिकारिक Python कार्यान्वयन (FastMCP)
- [Kotlin SDK](https://github.com/modelcontextprotocol/kotlin-sdk) - आधिकारिक Kotlin कार्यान्वयन
- [Swift SDK](https://github.com/modelcontextprotocol/swift-sdk) - Loopwork AI सँगको सहकार्यमा मर्मत गरिएको
- [Rust SDK](https://github.com/modelcontextprotocol/rust-sdk) - आधिकारिक Rust कार्यान्वयन
- [Go SDK](https://github.com/modelcontextprotocol/go-sdk) - आधिकारिक Go कार्यान्वयन

## प्रमुख सारांशहरू

- भाषा विशिष्ट SDK हरूको साथ MCP विकास वातावरण सेट अप गर्न सजिलो छ
- MCP सर्भरहरू निर्माण गर्दा स्पष्ट स्किमाहरू सहित उपकरणहरू बनाउनु र दर्ता गर्नु पर्छ
- MCP क्लाइχटहरूले सर्भरहरू र मोडेलहरूलाई जडान गरी विस्तारित क्षमता प्रयोग गर्छन्
- परीक्षण र डिबगिङ विश्वसनीय MCP कार्यान्वयनको लागि आवश्यक छ
- परिनियोजन विकल्पहरू स्थानीय विकासदेखि क्लाउड-आधारित समाधानहरू सम्म फरक छन्
