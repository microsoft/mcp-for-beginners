# Visual Studio Code का लागि AI Toolkit एक्सटेन्सनबाट सर्भर उपभोग गर्दै

जब तपाईं AI एजेन्ट निर्माण गर्दै हुनुहुन्छ, यो केवल स्मार्ट प्रतिक्रियाहरू उत्पादन गर्ने मात्र कुरा होइन; यो तपाईंको एजेन्टलाई कार्य गर्न सक्षम पार्ने कुरा पनि हो। त्यसको लागि Model Context Protocol (MCP) काममा आउँछ। MCP ले एजेन्टहरूलाई बाह्य उपकरण र सेवाहरूलाई सुसंगत तरिकाले पहुँच गर्न सजिलो बनाउँछ। यसलाई तपाईंको एजेन्टलाई एउटा उपकरण बाकसमा जडान गर्ने जस्तो सोच्नुहोस् जुन यसले *वास्तविक रुपमा* प्रयोग गर्न सक्छ।

मानौं तपाईंले आफ्नो एजेन्टलाई आफ्नो क्याल्क्युलेटर MCP सर्भरसँग जडान गर्नुहुन्छ। अचानक, तपाईंको एजेन्ट "47 गुणा 89 कति हुन्छ?" जस्तो प्रॉम्प्ट पाएर मात्र गणितीय अपरेशन गर्न सक्छ—कुनै हार्डकोड गरिएको तर्क वा अनुकूल API निर्माण गर्न आवश्यक छैन।

## अवलोकन

यस पाठले Visual Studio Code मा [AI Toolkit](https://aka.ms/AIToolkit) विस्तारका साथ क्याल्क्युलेटर MCP सर्भरलाई एजेन्टमा कसरी जडान गर्ने सिकाउँछ, जसले तपाईंको एजेन्टलाई प्राकृतिक भाषाको माध्यमबाट जोड, घटाउ, गुणा, र भागजस्ता गणितीय अपरेशनहरू गर्न सक्षम बनाउँछ।

AI Toolkit Visual Studio Code को लागि एक शक्तिशाली एक्सटेन्सन हो जसले एजेन्ट विकासलाई सहज बनाउँछ। AI इन्जिनियरहरूले स्थानीय वा क्लाउडमा जेनेरेटिभ AI मोडेलहरू विकास र परीक्षण गरेर सजिलै AI अनुप्रयोगहरू निर्माण गर्न सक्छन्। यस एक्सटेन्सनले आज उपलब्ध प्राय: सबै मुख्य जेनेरेटिभ मोडेलहरू समर्थन गर्दछ।

*सूचना*: AI Toolkit हाल Python र TypeScript समर्थन गर्दछ।

## सिकाइका उद्देश्यहरू

यस पाठको अन्त्यमा, तपाईं सक्षम हुनुहुनेछ:

- एजेन्ट कन्फिगरेसन गर्न जसले MCP सर्भरद्वारा प्रदान गरिएका उपकरणहरू पत्ता लगाउन र प्रयोग गर्न सक्षम बनाउने।
- प्राकृतिक भाषाबाट MCP उपकरणहरूको प्रयोग गर्ने।

### -1- एजेन्ट सिर्जना गर्नुहोस्

**Agent (Prompt) Builder** ले तपाईंलाई आफ्नै AI-समर्थित एजेन्टहरू सिर्जना गर्न र अनुकूलन गर्न सक्षम पार्छ। यस खण्डमा, तपाईं नयाँ एजेन्ट सिर्जना गरी कुराकानीको लागि मोडेल सेट गर्नुहुनेछ।

![Visual Studio Code को AI Toolkit एक्सटेन्सनमा "Calculator Agent" बिल्डर इन्टरफेसको स्क्रिनशट। बाँया प्यानलमा चयन गरिएको मोडेल "OpenAI GPT-4o (via GitHub)" छ। सिस्टम प्रॉम्प्ट भन्छ "तपाईं विश्वविद्यालयमा गणित पढाउने प्राध्यापक हुनुहुन्छ," र युजर प्रॉम्प्ट भन्छ, "सरलीकृत तरिकाले Fourier समीकरण व्याख्या गर्नुहोस्।" थप विकल्पहरूमा उपकरणहरू थप्ने, MCP Server सक्षम गर्ने, र संरचित आउटपुट छान्ने बटनहरू छन्। तल नीलो "Run" बटन छ। दायाँ प्यानलमा "Get Started with Examples" अन्तर्गत तीन नमूना एजेन्टहरू छन्: Web Developer (MCP Server, Second-Grade Simplifier, र Dream Interpreter सहित, हरेक फंक्शनहरूको संक्षिप्त वर्णन) देखाइएको छ।](../../../../translated_images/ne/aitk-agent-builder.901e3a2960c3e477.webp)

1. **Agent (Prompt) Builder** मा **Model** फिल्डमा **OpenAI GPT-4o (via GitHub)** मोडेल चयन गर्नुहोस्।

### -2- एजेन्टको लागि सिस्टम प्रॉम्प्ट बनाउनुहोस्

एजेन्ट स्क्याफोल्ड भएपछि, यसको व्यक्तित्व र उद्देश्य परिभाषित गर्ने समय आएको छ। यस खण्डमा, तपाईंले **Generate system prompt** सुविधा प्रयोग गरी एजेन्टको अपेक्षित व्यवहार—यस केसमा एक क्याल्क्युलेटर एजेन्ट—लाई वर्णन गर्नुहुनेछ र मोडेललाई सिस्टम प्रॉम्प्ट लेख्न दिनुहुनेछ।

![Visual Studio Code को AI Toolkit मा "Calculator Agent" इन्टरफेसको स्क्रिनशट जसमा "Generate a prompt" शीर्षकको मोडल विन्डो खुलेको छ। मोडलले भन्छ कि एक प्रॉम्प्ट टेम्प्लेट उत्पन्न गर्न आधारभूत विवरणहरू साझेदारी गर्न सकिन्छ र एउटा पाठ बक्समा नमूना सिस्टम प्रॉम्प्ट छ: "तपाईं एक सहयोगी र प्रभावकारी गणित सहायक हुनुहुन्छ। आधारभूत अंकगणितको समस्या दिइएको बेला तपाईं सही परिणाम दिनुहुन्छ।" तल दुई बटनहरू छन्: "Close" र "Generate"। पृष्ठभूमिमा एजेन्ट कन्फिगरेसनको केही भाग, चयन गरिएको मोडेल "OpenAI GPT-4o (via GitHub)" र सिस्टम तथा युजर प्रॉम्प्ट फिल्डहरू देखिन्छन्।](../../../../translated_images/ne/aitk-generate-prompt.ba9e69d3d2bbe2a2.webp)

1. **Prompts** सेक्सनमा, **Generate system prompt** बटन थिच्नुहोस्। यसले प्रॉम्प्ट बिल्डर खोल्नेछ जुन AI प्रयोग गरी एजेन्टको लागि सिस्टम प्रॉम्प्ट उत्पन्न गर्छ।
1. **Generate a prompt** विन्डोमा निम्न लेख्नुहोस्: `तपाईं एक सहयोगी र प्रभावकारी गणित सहायक हुनुहुन्छ। आधारभूत अंकगणितको समस्या दिइएको बेला तपाईं सही परिणाम दिनुहुन्छ।`
1. **Generate** बटन क्लिक गर्नुहोस्। दायाँ तल्लो कुनामा सूचनाले सिस्टम प्रॉम्प्ट उत्पन्न भइरहेको पुष्टि गर्नेछ। पूर्ण भएपछि प्रॉम्प्ट **Agent (Prompt) Builder** को **System prompt** फिल्डमा देखा पर्नेछ।
1. सिस्टम प्रॉम्प्ट समीक्षा गरी आवश्यक परिमार्जन गर्नुहोस्।

### -3- MCP सर्भर सिर्जना गर्नुहोस्

अब तपाईंले एजेन्टको सिस्टम प्रॉम्प्ट परिभाषित गर्नुभयो—यसको व्यवहार र प्रतिक्रियाहरूलाई मार्गनिर्देशन गर्दै—अहिले एजेन्टलाई व्यवहारिक क्षमता दिनुपर्ने समय हो। यस खण्डमा, तपाईं एउटा क्याल्क्युलेटर MCP सर्भर सिर्जना गर्नुहुनेछ जससँग जोड, घटाउ, गुणा, र भाग गणना गर्न उपकरणहरू हुनेछन्। यो सर्भरले तपाईंको एजेन्टलाई प्राकृतिक भाषाको प्रॉम्प्ट प्रति वास्तविक-समय गणितीय अपरेशन गर्न सक्षम बनाउनेछ।

![Visual Studio Code को AI Toolkit एक्सटेन्सन अन्तर्गत Calculator Agent इन्टरफेसको तल्लो भागको स्क्रिनशट। यसमा “Tools” र “Structure output” को विस्तारणयोग्य मेनूहरू देखिन्छन् र “Choose output format” ड्रपडाउन मेनू "text" मा सेट गरिएको छ। दायाँतर्फ “+ MCP Server” बटन छ जुन Model Context Protocol सर्भर थप्न प्रयोग हुन्छ। Tools सेक्सनमाथि छवि आइकन प्लेसहोल्डर देखाइएको छ।](../../../../translated_images/ne/aitk-add-mcp-server.9742cfddfe808353.webp)

AI Toolkit मा आफ्नै MCP सर्भर बनाउन सजिलो बनाउन टेम्पलेटहरू उपलब्ध छन्। हामी क्याल्क्युलेटर MCP सर्भर बनाउन Python टेम्पलेट प्रयोग गर्छौं।

*सूचना*: AI Toolkit हाल Python र TypeScript समर्थन गर्दछ।

1. **Agent (Prompt) Builder** को **Tools** सेक्सनमा, **+ MCP Server** बटन क्लिक गर्नुहोस्। एक्सटेन्सनले **Command Palette** मार्फत सेटअप विजार्ड सुरु गर्नेछ।
1. **+ Add Server** चयन गर्नुहोस्।
1. **Create a New MCP Server** चयन गर्नुहोस्।
1. टेम्पलेटको रूपमा **python-weather** चयन गर्नुहोस्।
1. MCP सर्भर टेम्पलेट बचाउन **Default folder** चयन गर्नुहोस्।
1. सर्भरको नाम **Calculator** दिनुहोस्।
1. नयाँ Visual Studio Code विन्डो खुल्नेछ। **Yes, I trust the authors** चयन गर्नुहोस्।
1. टर्मिनल प्रयोग गरी एउटा भर्चुअल वातावरण सिर्जना गर्नुहोस्: `python -m venv .venv`
1. टर्मिनलमा भर्चुअल वातावरण एक्टिभेट गर्नुहोस्:
    1. Windows - `.venv\Scripts\activate`
    1. macOS/Linux - `source .venv/bin/activate`
1. टर्मिनलमा निर्भरता इन्स्टल गर्नुहोस्: `pip install -e .[dev]`
1. **Activity Bar** को **Explorer** भ्यूमा, **src** डिरेक्टरी विस्तार गरी **server.py** खोल्नुहोस्।
1. तलको कोडले **server.py** फाइलमा रहेको कोड प्रतिस्थापन गरी फाइल बचत गर्नुहोस्:

    ```python
    """
    Sample MCP Calculator Server implementation in Python.

    
    This module demonstrates how to create a simple MCP server with calculator tools
    that can perform basic arithmetic operations (add, subtract, multiply, divide).
    """
    
    from mcp.server.fastmcp import FastMCP
    
    server = FastMCP("calculator")
    
    @server.tool()
    def add(a: float, b: float) -> float:
        """Add two numbers together and return the result."""
        return a + b
    
    @server.tool()
    def subtract(a: float, b: float) -> float:
        """Subtract b from a and return the result."""
        return a - b
    
    @server.tool()
    def multiply(a: float, b: float) -> float:
        """Multiply two numbers together and return the result."""
        return a * b
    
    @server.tool()
    def divide(a: float, b: float) -> float:
        """
        Divide a by b and return the result.
        
        Raises:
            ValueError: If b is zero
        """
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    ```

### -4- क्याल्क्युलेटर MCP सर्भरसहित एजेन्ट चलाउनुहोस्

अब तपाईंको एजेन्टसँग उपकरण छन्, तिनीहरू प्रयोग गर्ने समय आएको छ! यस खण्डमा, तपाईं एजेन्टमा प्रॉम्प्टहरू पेश गरी परीक्षण गर्नुहुनेछ कि एजेन्टले क्याल्क्युलेटर MCP सर्भरबाट उपयुक्त उपकरण प्रयोग गरिरहेको छ वा छैन भनेर।

![Visual Studio Code को AI Toolkit एक्सटेन्सनमा Calculator Agent इन्टरफेसको स्क्रिनशट। बाँया प्यानल अन्तर्गत “Tools,” एउटा MCP सर्भर नाम "local-server-calculator_server" थपिएको छ जसले चार उपकरणहरू देखाइरहेको छ: add, subtract, multiply, र divide। चार उपकरणहरू सक्रिय भइसकेको सूचकता छ। तल "Structure output" भाग सङ्कुचित गरिएको छ र नीलो रंगको "Run" बटन छ। दायाँ प्यानलमा “Model Response” मा एजेन्टले multiply र subtract उपकरणहरू क्रमशः {"a": 3, "b": 25} र {"a": 75, "b": 20} इनपुटसँग आह्वान गरेको छ। अन्तिम “Tool Response” 75.0 देखाइएको छ। तल “View Code” बटन छ।](../../../../translated_images/ne/aitk-agent-response-with-tools.e7c781869dc8041a.webp)

तपाईं क्याल्क्युलेटर MCP सर्भर आफ्नो स्थानीय विकास मेशिनमा **Agent Builder** मार्फत MCP क्लाएन्टको रूपमा चलाउनु हुनेछ।

1. MCP सर्भर डिबग गर्न `F5` थिच्नुहोस्। **Agent (Prompt) Builder** नयाँ एडिटर ट्याबमा खुल्नेछ। सर्भरको स्थिति टर्मिनलमा देखिनेछ।
1. **Agent (Prompt) Builder** को **User prompt** फिल्डमा यो प्रॉम्प्ट राख्नुहोस्: `I bought 3 items priced at $25 each, and then used a $20 discount. How much did I pay?`
1. एजेन्टको प्रतिक्रिया उत्पन्न गर्न **Run** बटन क्लिक गर्नुहोस्।
1. एजेन्टको आउटपुट समीक्षा गर्नुहोस्। मोडेलले तपाईंले **$55** तिरेको निष्कर्ष निकाल्नुपर्छ।
1. के हुने छ यसको विवरण यसप्रकार छ:
    - गणना मद्दतका लागि एजेन्टले **multiply** र **subtract** उपकरण चयन गर्छ।
    - **multiply** उपकरणका लागि `a` र `b` मानहरू निर्दिष्ट गरिन्छ।
    - **subtract** उपकरणका लागि `a` र `b` मानहरू निर्दिष्ट गरिन्छ।
    - हरेक उपकरणबाट आएको प्रतिक्रिया सम्बन्धित **Tool Response** मा दिइन्छ।
    - मोडेलबाट अन्तिम परिणाम **Model Response** मा प्रस्तुत गरिन्छ।
1. थप परीक्षणका लागि अतिरिक्त प्रॉम्प्टहरू पेश गर्नुहोस्। तपाईं **User prompt** फिल्डमा गएर पुरानो प्रॉम्प्ट परिवर्तन गरी नयाँ प्रॉम्प्ट राख्न सक्नुहुन्छ।
1. परीक्षण सकिएपछि, टर्मिनलबाट **CTRL/CMD+C** थिचेर सर्भर रोक्न सक्नुहुन्छ।

## असाइन्मेन्ट

आफ्नो **server.py** फाइलमा थप उपकरण प्रविष्टि थप्न प्रयास गर्नुहोस् (उदाहरण: कुनै संख्याको वर्गमूल फर्काउने)। थप प्रॉम्प्टहरू पेश गरी एजेन्टलाई नयाँ वा अवस्थित उपकरणहरू प्रयोग गर्न बाध्य पार्नुहोस्। नयाँ उपकरण लोड गर्न सर्भर पुनः सुरु गर्न नबिर्सनुहोस्।
