# क्यालकुलेटर LLM क्लाइन्ट

> [!NOTE]
> यो समाधान कोर्सको लेगासी HTTP+SSE क्यालकुलेटर सेवासँग जडित छ र
> MCP `2025-11-25` SDK API लक्षित गर्दछ। यो `2026-07-28` स्ट्रिमेबल HTTP
> उदाहरण होईन।

एउटा जाभा एप्लिकेसन जसले LangChain4j प्रयोग गरेर मिनिम्याक्स OpenAI-समर्थित API मार्फत MCP (मोडेल कन्टेक्स्ट प्रोटोकल) क्यालकुलेटर सेवासँग कसरी जडान गर्ने देखाउँछ।

## पूर्वआवश्यकताहरू

- जाभा २१ वा माथि
- मेभेन ३.६+ (वा समावेश गरिएको मेभेन रैपर प्रयोग गर्नुहोस्)
- एक मिनिम्याक्स API कुञ्जी
- `http://localhost:8080` मा चलिरहेको MCP क्यालकुलेटर सेवा

## API कुञ्जी प्राप्त गर्दै

यो एप्लिकेसन मिनिम्याक्स OpenAI-समर्थित API प्रयोग गर्दछ। आफ्नो कुञ्जी र अन्तविन्दु प्राप्त गर्न यी चरणहरू पछ्याउनुहोस्:

### १. एउटा अन्तविन्दु छान्नुहोस्
१. ग्लोबल अन्तविन्दुका लागि `https://api.minimax.io/v1` प्रयोग गर्नुहोस्
२. चीन अन्तविन्दुका लागि `https://api.minimaxi.com/v1` प्रयोग गर्नुहोस्

### २. API कुञ्जी सिर्जना गर्नुहोस्
१. आफ्नो मिनिम्याक्स खाताबाट मिनिम्याक्स API कुञ्जी सिर्जना गर्नुहोस्
२. कुञ्जीलाई सुरक्षित ठाउँमा राख्नुहोस्

### ३. वातावरण चर सेट गर्नुहोस्

#### विन्डोज (कमाण्ड प्रॉम्प्ट) मा:
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### विन्डोज (पावरशेल) मा:
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### म्याकओएस/लिनक्समा:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## सेटअप र स्थापना

१. **प्रोजेक्ट डाइरेक्टरी क्लोन वा नेभिगेट गर्नुहोस्**

२. **निर्भरतालाई स्थापना गर्नुहोस्**:
   ```cmd
   mvnw clean install
   ```
   वा यदि तपाईंसँग मेभेन ग्लोबली स्थापित छ भने:
   ```cmd
   mvn clean install
   ```

३. **पर्यावरण चरहरू सेटअप गर्नुहोस्** ("API कुञ्जी प्राप्त गर्दै" सेक्सन हेर्नुहोस्)

४. **MCP क्यालकुलेटर सेवा सुरु गर्नुहोस्**:
   सुनिश्चित गर्नुहोस् कि तपाईंसँग अध्याय १ को MCP क्यालकुलेटर सेवा `http://localhost:8080/sse` मा चलिरहेको छ। क्लाइन्ट सुरु गर्नु अघि यो चलिरहेको हुनुपर्छ।

## एप्लिकेसन चलाउदै

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## एप्लिकेसनले के गर्छ

एप्लिकेसनले क्यालकुलेटर सेवासँग तीन मुख्य अन्तरक्रियाहरू देखाउँछ:

१. **थप**: २४.५ र १७.३ को जम्मा गणना गर्दछ
२. **स्क्वायर रूट**: १४४ को वर्गमूल गणना गर्दछ
३. **मद्दत**: उपलब्ध क्यालकुलेटर कार्यहरू देखाउँछ

## अपेक्षित नतिजा

सफलतापूर्वक चलाउँदा तपाईंसँग निम्न जस्तै नतिजा देखिनेछ:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## समस्यानिवारण

### सामान्य समस्याहरू

१. **"OPENAI_API_KEY 환경 변수 सेट छैन"**
   - सुनिश्चित गर्नुहोस् कि तपाईले `OPENAI_API_KEY` वातावरण चर सेट गर्नुभएको छ
   - चर सेट गरेपछि आफ्नो टर्मिनल/कमाण्ड प्रॉम्प्ट पुनः सुरु गर्नुहोस्

२. **"localhost:8080 लाई जडान अस्वीकृत"**
   - सुनिश्चित गर्नुहोस् कि MCP क्यालकुलेटर सेवा पोर्ट ८०८० मा चलिरहेको छ
   - जाँच गर्नुहोस् कि अरू कुनै सेवा पोर्ट ८०८० प्रयोग गरिरहेको छ कि छैन

३. **"प्रमाणीकरण असफल"**
   - आफ्नो API कुञ्जी मान्य छ कि छैन जाँच गर्नुहोस्
   - सुनिश्चित गर्नुहोस् कि `OPENAI_BASE_URL` तपाईले उपयोग गर्न चाहेको अन्तविन्दुसँग मेल खान्छ

४. **मेभेन निर्माण त्रुटिहरू**
   - सुनिश्चित गर्नुहोस् कि तपाईले जाभा २१ वा साँढे उच्च संस्करण प्रयोग गर्दै हुनुहुन्छ: `java -version`
   - बिल्ड सफा गरेर प्रयास गर्नुहोस्: `mvnw clean`

### डिबगिंग

डिबग लग सक्षम गर्न, java चलाउँदा तलको JVM आर्ग्युमेन्ट थप्नुहोस्:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## कन्फिगरेसन

एप्लिकेसन यसरी कन्फिगर गरिएको छ:
- डिफल्ट रूपमा MiniMax-M3 प्रयोग गर्ने; `MINIMAX_MODEL_ID` सेट गरेर `MiniMax-M3` वा `MiniMax-M2.7` रोज्न सकिन्छ
- `OPENAI_BASE_URL` सेट गरिएको बेला त्यहाँ जडान गर्ने; नभए `MINIMAX_REGION=cn_zh` हुँदा `https://api.minimaxi.com/v1` र सामान्य रूपमा `https://api.minimax.io/v1` प्रयोग गर्ने
- MCP सेवामा `http://localhost:8080/sse` मा जडान गर्ने
- अनुरोधका लागि ६० सेकेन्ड टाईमआउट प्रयोग गर्ने

## निर्भरता

यस प्रोजेक्टमा प्रयोग भएका मुख्य निर्भरता:
- **LangChain4j**: AI एकीकरण र उपकरण व्यवस्थापनका लागि
- **LangChain4j MCP**: मोडेल कन्टेक्स्ट प्रोटोकल समर्थनका लागि
- **LangChain4j OpenAI अफिसियल**: मिनिम्याक्स OpenAI-समर्थित API एकीकरणका लागि
- **Spring Boot**: एप्लिकेसन फ्रेमवर्क र निर्भरता इन्जेक्सनका लागि
