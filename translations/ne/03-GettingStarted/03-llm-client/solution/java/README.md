# क्याल्कुलेटर LLM क्लाइन्ट

एक Java अनुप्रयोग जुन LangChain4j कसरी प्रयोग गर्ने देखाउँछ, MCP (मोडेल सन्दर्भ प्रोटोकल) क्याल्कुलेटर सेवामा MiniMax OpenAI-अनुकूल API मार्फत जडान गर्न।

## पूर्वशर्तहरू

- Java 21 वा माथि
- Maven 3.6+ (वा समावेश गरिएको Maven र्यापर प्रयोग गर्नुहोस्)
- MiniMax API कुञ्जी
- `http://localhost:8080` मा चलिरहेको MCP क्याल्कुलेटर सेवा

## API कुञ्जी कसरी प्राप्त गर्ने

यस अनुप्रयोगले MiniMax OpenAI-अनुकूल API प्रयोग गर्दछ। तपाईंको कुञ्जी र अन्त बिन्दु प्राप्त गर्न यी चरणहरू पालना गर्नुहोस्:

### 1. अन्त बिन्दु रोज्नुहोस्
1. विश्वव्यापी अन्त बिन्दुको लागि `https://api.minimax.io/v1` प्रयोग गर्नुहोस्
2. चीन अन्त बिन्दुको लागि `https://api.minimaxi.com/v1` प्रयोग गर्नुहोस्

### 2. API कुञ्जी सिर्जना गर्नुहोस्
१. तपाईंको MiniMax खाताबाट MiniMax API कुञ्जी सिर्जना गर्नुहोस्
२. कुञ्जी सुरक्षित कुनै ठाउँमा राख्नुहोस्

### 3. वातावरण चरहरू सेट गर्नुहोस्

#### Windows मा (कमाण्ड प्रम्प्ट):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### Windows मा (PowerShell):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### macOS/Linux मा:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## सेटअप र स्थापना

1. **प्रकल्प निर्देशिकामा क्लोन वा नेभिगेट गर्नुहोस्**

2. **निर्भरता स्थापना गर्नुहोस्**:
   ```cmd
   mvnw clean install
   ```
   वा यदि तपाईंले Maven ग्लोबली स्थापना गर्नुभएको छ भने:
   ```cmd
   mvn clean install
   ```

3. **वातावरण चरहरू सेटअप गर्नुहोस्** (माथिको "API कुञ्जी कसरी प्राप्त गर्ने" खण्ड हेर्नुहोस्)

4. **MCP क्याल्कुलेटर सेवा सुरु गर्नुहोस्**:
   पक्का गर्नुहोस् कि तपाईंले पहिलो अध्यायको MCP क्याल्कुलेटर सेवा `http://localhost:8080/sse` मा चलाइरहनुभएको छ। क्लाइन्ट सुरु गर्नु अघि यो चलिरहेको हुनुपर्छ।

## अनुप्रयोग चलाउने तरिका

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## अनुप्रयोगले के गर्छ

अनुप्रयोगले क्याल्कुलेटर सेवासँग तीन मुख्य अन्तरक्रियाहरू देखाउँछ:

1. **थप**: 24.5 र 17.3 को योग गणना गर्दछ
2. **वर्गमूल**: 144 को वर्गमूल गणना गर्दछ
3. **मद्दत**: उपलब्ध क्याल्कुलेटर कार्यहरू देखाउँछ

## अपेक्षित आउटपुट

सफलतापूर्वक चल्दा, तपाईं यस्तै आउटपुट देख्नुहुनेछ:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## समस्या समाधान

### सामान्य समस्याहरू

1. **"OPENAI_API_KEY वातावरण चर सेट गरिएको छैन"**
   - सुनिश्चित गर्नुहोस् तपाईंले `OPENAI_API_KEY` वातावरण चर सेट गर्नुभएको छ
   - चर सेट गरेपछि टर्मिनल/कमाण्ड प्रम्प्ट पुनः सुरु गर्नुहोस्

2. **"localhost:8080 सँग जडान अस्वीकृत"**
   - सुनिश्चित गर्नुहोस् कि MCP क्याल्कुलेटर सेवा पोर्ट 8080 मा चल्दैछ
   - जाँच गर्नुहोस् अर्को सेवा पोर्ट 8080 प्रयोग गरिरहेको छ कि छैन

3. **"प्रमाणीकरण असफल"**
   - तपाईको API कुञ्जी मान्य छ कि छैन जाँच गर्नुहोस्
   - हेर्नुहोस् `OPENAI_BASE_URL` तपाईंले प्रयोग गर्न चाहेको अन्त बिन्दुसँग मेल खान्छ कि छैन

4. **Maven बिल्ड त्रुटिहरू**
   - सुनिश्चित गर्नुहोस् तपाईं Java 21 वा माथि प्रयोग गर्दै हुनुहुन्छ: `java -version`
   - बिल्ड क्लिन गर्ने प्रयास गर्नुहोस्: `mvnw clean`

### डिबगिङ

डिबग लगिङ सक्षम गर्न, चलाउँदा निम्न JVM आर्गुमेन्ट थप्नुहोस्:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## कन्फिगरेसन

अनुप्रयोग यसरी कन्फिगर गरिएको छ:
- पहिलेबाट MiniMax-M3 प्रयोग गर्ने, वा `MINIMAX_MODEL_ID` सेट हुँदा MiniMax-M2.7 प्रयोग गर्ने
- `OPENAI_BASE_URL` सेट भएको बेला त्यहाँ जडान गर्ने; नत्र `MINIMAX_REGION=cn_zh` भएमा `https://api.minimaxi.com/v1` प्रयोग गर्ने, नभए `https://api.minimax.io/v1` पहिलेबाट प्रयोग गर्ने
- MCP सेवामा `http://localhost:8080/sse` जडान गर्ने
- अनुरोधका लागि ६० सेकेन्डको टाइमआउट प्रयोग गर्ने

## निर्भरताहरू

यस परियोजनामा प्रयोग भएका मुख्य निर्भरता:
- **LangChain4j**: AI इंटीग्रेशन र उपकरण व्यवस्थापनको लागि
- **LangChain4j MCP**: मोडेल सन्दर्भ प्रोटोकल समर्थनको लागि
- **LangChain4j OpenAI आधिकारिक**: MiniMax OpenAI-अनुकूल API इंटीग्रेशनको लागि
- **Spring Boot**: अनुप्रयोग फ्रेमवर्क र निर्भरता इन्जेक्शनको लागि
