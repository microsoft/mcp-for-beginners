# व्यावहारिक कार्यान्वयन

[![कसरी MCP एपहरूलाई वास्तविक उपकरणहरू र कार्यप्रवाहहरूसँग निर्माण, परीक्षण, र परिनियोजन गर्ने](../../../translated_images/ne/05.64bea204e25ca891.webp)](https://youtu.be/vCN9-mKBDfQ)

_(यो पाठको भिडियो हेर्न माथिको छवि क्लिक गर्नुहोस्)_

व्यावहारिक कार्यान्वयन नै मोडेल सन्दर्भ प्रोटोकल (MCP) को शक्ति महसुस गर्न सकिने स्थान हो। MCP को सिद्धान्त र आर्किटेक्चर बुझ्नु महत्वपूर्ण भए पनि, वास्तविक मूल्य तब आउँछ जब तपाईं यी अवधारणाहरूलाई वास्तविक विश्वका समस्याहरू समाधान गर्ने समाधानहरू निर्माण, परीक्षण, र तैनाथ गर्न लागू गर्नुहुन्छ। यो अध्याय वैचारिक ज्ञान र व्यावहारिक विकास बीचको दूरीलाई पूर्ति गर्छ, तपाईंलाई MCP-आधारित अनुप्रयोगहरूलाई जीवन्त बनाउन मार्गदर्शन गर्दै।

तपाईं बुद्धिमान सहायकहरू विकास गर्दै हुनुहुन्छ, व्यवसायिक कार्यप्रवाहहरूमा AI एकीकृत गर्दै हुनुहुन्छ, वा डेटा प्रशोधनका लागि अनुकूल उपकरणहरू निर्माण गर्दै हुनुहुन्छ भने पनि, MCP ले लचिलो आधार प्रदान गर्दछ। यसको भाषा-स्वतन्त्र डिजाइन र लोकप्रिय प्रोग्रामिङ भाषाहरूको लागि आधिकारिक SDKs ले यसलाई व्यापक विकासकर्ताहरूका लागि पहुँचयोग्य बनाउँछ। यी SDK हरूको प्रयोग गरेर, तपाईं छिटो प्रोटोटाइप बनाउन, पुनरावृत्ति गर्न, र आफ्नो समाधानहरू विभिन्न प्लेटफर्म र वातावरणहरूमा विस्तार गर्न सक्नुहुन्छ।

तलका खण्डहरूमा तपाईंले C#, Java with Spring, TypeScript, JavaScript, र Python मा MCP कसरी कार्यान्वयन गर्ने, MCP सर्भरहरू डिबग र परीक्षण गर्ने, API व्यवस्थापन गर्ने, र Azure मार्फत क्लाउडमा समाधानहरू स्थापना गर्ने व्यावहारिक उदाहरणहरू, नमूना कोड, र परिनियोजन रणनीतिहरू फेला पार्नु हुनेछ। यी व्यावहारिक स्रोतहरू तपाईंको सिकाइलाई तीव्र पार्न र विश्वस्त रूपमा बलियो, उत्पादन-तय MCP अनुप्रयोगहरू निर्माण गर्न मद्दत गर्न डिजाइन गरिएको हो।

## अवलोकन

यो पाठले MCP कार्यान्वयनका व्यावहारिक पक्षहरूमा ध्यान केन्द्रित गर्दछ जसले विभिन्न प्रोग्रामिङ भाषाहरूमा काम गर्दछ। हामी C#, Java with Spring, TypeScript, JavaScript र Python मा MCP SDKs प्रयोग गरेर बलियो अनुप्रयोगहरू निर्माण गर्ने, MCP सर्भरहरू डिबग र परीक्षण गर्ने, र पुन: प्रयोगयोग्य स्रोतहरू, प्रॉम्प्टहरू, र उपकरणहरू सिर्जना गर्ने तरिका अन्वेषण गर्ने छौं।

## सिकाइ लक्ष्यहरू

यस पाठको अन्त्यसम्म, तपाईं सक्षम हुनुहुनेछ:

- विभिन्न प्रोग्रामिङ भाषाहरूमा आधिकारिक SDK हरू प्रयोग गरेर MCP समाधानहरू कार्यान्वयन गर्न
- व्यवस्थित रूपमा MCP सर्भरहरू डिबग र परीक्षण गर्न
- सर्भर सुविधाहरू (स्रोतहरू, प्रॉम्प्टहरू, र उपकरणहरू) सिर्जना र प्रयोग गर्न
- जटिल कार्यहरूका लागि प्रभावकारी MCP कार्यप्रवाहहरू डिजाइन गर्न
- प्रदर्शन र विश्वसनीयताका लागि MCP कार्यान्वयनहरू अनुकूलित गर्न

## मुख्य सर्भर सुविधाहरू

MCP सर्भरहरूले यी सुविधाहरूको कुनै पनि संयोजन कार्यान्वयन गर्न सक्दछन्:

### स्रोतहरू

स्रोतहरूले प्रयोगकर्ता वा AI मोडेलले प्रयोग गर्न सन्दर्भ र डेटा प्रदान गर्छन्:

- कागजात भण्डारहरू
- ज्ञान आधारहरू
- संरचित डाटा स्रोतहरू
- फाइल प्रणालीहरू

### प्रॉम्प्टहरू

प्रॉम्प्टहरू प्रयोगकर्ताहरूका लागि टेम्प्लेट गरिएको सन्देशहरू र वर्कफ्लोहरू हुन्:

- पूर्व-निर्धारित वार्ता टेम्प्लेटहरू
- मार्गनिर्देशित अन्तरक्रिया ढाँचाहरू
- विशेषज्ञ संवाद संरचनाहरू

### उपकरणहरू

उपकरणहरू AI मोडेलले कार्यान्वयन गर्ने कार्यहरू हुन्:

- डाटा प्रशोधन युटिलिटीहरू
- बाह्य API एकीकरणहरू
- कम्प्युटेशनल क्षमता
- खोज कार्यक्षमता

## नमूना कार्यान्वयनहरू: C# कार्यान्वयन

आधिकारिक C# SDK रिपोजिटरीले MCP का विभिन्न पक्षहरू प्रदर्शन गर्ने धेरै नमूना कार्यान्वयनहरू समावेश गर्दछ:

- **बेसिक MCP क्लाइन्ट**: एउटा सरल उदाहरण जसले MCP क्लाइन्ट कसरी बनाउने र उपकरणहरूलाई कल गर्ने देखाउँछ
- **बेसिक MCP सर्भर**: न्यूनतम सर्भर कार्यान्वयन जसमा आधारभूत उपकरण दर्ता समावेश छ
- **अड्भान्स्ड MCP सर्भर**: पूर्ण-सुविधायुक्त सर्भर जसमा उपकरण दर्ता, प्रमाणीकरण, र त्रुटि ह्यान्डलिङ्ग समावेश छन्
- **ASP.NET एकीकरण**: ASP.NET कोरसँग एकीकरण देखाउने उदाहरणहरू
- **उपकरण कार्यान्वयन ढाँचाहरू**: विभिन्न जटिलता स्तरहरूका उपकरणहरू कार्यान्वयन गर्ने विभिन्न ढाँचाहरू

MCP C# SDK पूर्वावलोकनमा छ र API हरू परिवर्तन हुन सक्छन्। हामी SDK विकसित हुनेक्रममा निरन्तर यो ब्लग अपडेट गर्नेछौं।

## Azure मा रिमोट MCP सर्भर तैनाथ गर्नुहोस्

हामीले पहिला उल्लेख गरेको नमूना तैनाथ गर्न सक्छौं कि छैनौं हेर्नुहोस्:

1. रेपो क्लोन गर्नुहोस्

    ```bash
    git clone https://github.com/Azure-Samples/remote-mcp-apim-functions-python.git
    cd remote-mcp-apim-functions-python
    ```

1. `Microsoft.App` स्रोत प्रदायक दर्ता गर्नुहोस्।

   - यदि तपाईं Azure CLI प्रयोग गर्दै हुनुहुन्छ भने, `az provider register --namespace Microsoft.App --wait` चलाउनुहोस्।
   - यदि तपाईं Azure PowerShell प्रयोग गर्दै हुनुहुन्छ भने, `Register-AzResourceProvider -ProviderNamespace Microsoft.App` चलाउनुहोस्। त्यसपछि केही समयपछि `(Get-AzResourceProvider -ProviderNamespace Microsoft.App).RegistrationState` चलाएर दर्ता पूरा भयो कि भएन जाँच गर्नुहोस्।

1. यो [azd](https://aka.ms/azd) आदेश चलाएर api व्यवस्थापन सेवा, function एप (कोडसहित) र सबै आवश्यक Azure स्रोतहरू प्रावधान गर्नुहोस्

    ```shell
    azd up
    ```

    यो आदेशले Azure मा सबै क्लाउड स्रोतहरू तैनाथ गर्नुपर्नेछ

    ![Connect to Node inspector](../../../translated_images/ne/connect.141db0b2bd05f096.webp)

1. URL बाट (जस्तै [http://127.0.0.1:6274/#resources](http://127.0.0.1:6274/#resources)) MCP निरीक्षक वेब एप लोड गर्न CTRL क्लिक गर्नुहोस्
1. ट्रान्सपोर्ट प्रकारलाई `SSE` सेट गर्नुहोस्
1. URL लाई तपाईंले `azd up` पछि देखाइएको चलिरहेको API व्यवस्थापन SSE अन्त बिन्दुमा सेट गर्नुहोस् र **Connect** गर्नुहोस्:

    ```shell
    https://<apim-servicename-from-azd-output>.azure-api.net/mcp/sse
    ```

1. **सूची उपकरणहरू**। उपकरणमा क्लिक गरी **Run Tool** गर्नुहोस्।  

यदि सबै चरणहरू सफल भए, तपाईं अहिले MCP सर्भरसँग जडान हुनुभएको छ र उपकरण कल गर्न सक्षम हुनुहुन्छ।

## Azure का लागि MCP सर्भरहरू

[Remote-mcp-functions](https://github.com/Azure-Samples/remote-mcp-functions-dotnet): यी रिपोजिटोरीहरू Azure Functions सँग Python, C# .NET वा Node/TypeScript प्रयोग गरेर कस्टम रिमोट MCP (Model Context Protocol) सर्भरहरू निर्माण र तैनाथ गर्ने छिटो आरम्भ टेम्प्लेट हुन्।

नमूनाले पूर्ण समाधान प्रदान गर्दछ जसले विकासकर्ताहरूलाई:

- स्थानीय रूपमा निर्माण र चलाउने: स्थानीय मेसिनमा MCP सर्भर विकास र डिबग गर्ने
- Azure मा तैनाथ गर्ने: सजिलै क्लाउडमा `azd up` आदेशले तैनाथ गर्ने
- ग्राहकहरूले जडान गर्ने: विभिन्न ग्राहकहरूबाट MCP सर्भरसँग जडान गर्ने जसमा VS Code को Copilot एजेन्ट मोड र MCP निरीक्षक उपकरण समावेश छ

### प्रमुख विशेषताहरू

- डिजाइन अनुसार सुरक्षा: MCP सर्भर कुञ्जीहरू र HTTPS प्रयोग गरेर सुरक्षित छ
- प्रमाणिकरण विकल्पहरू: ईन्बिल्ट प्रमाणीकरण र/वा API व्यवस्थापन प्रयोग गरेर OAuth समर्थन गर्दछ
- नेटवर्क अलगाव: Azure भर्चुअल नेटवर्कहरू (VNET) प्रयोग गरेर नेटवर्क अलगाव अनुमति दिन्छ
- सर्भरलेस आर्किटेक्चर: Azure Functions प्रयोग गरेर स्केलेबल, घटना-चालित कार्यान्वयन
- स्थानीय विकास: व्यापक स्थानीय विकास र डिबग समर्थन
- सरल तैनाथ: Azure तर्फ प्रवाहयुक्त तैनाथ प्रक्रिया

रिपोजिटरीमा सबै आवश्यक कन्फिगरेसन फाइलहरू, स्रोत कोड, र पूर्वाधार परिभाषाहरू समावेश छन् जसले छिटो उत्पादन-तय MCP सर्भर कार्यान्वयन सुरु गर्न मद्दत गर्दछ।

- [Azure Remote MCP Functions Python](https://github.com/Azure-Samples/remote-mcp-functions-python) - Python सँग Azure Functions प्रयोग गरेर MCP को नमूना कार्यान्वयन

- [Azure Remote MCP Functions .NET](https://github.com/Azure-Samples/remote-mcp-functions-dotnet) - C# .NET सँग Azure Functions प्रयोग गरेर MCP को नमूना कार्यान्वयन

- [Azure Remote MCP Functions Node/Typescript](https://github.com/Azure-Samples/remote-mcp-functions-typescript) - Node/TypeScript सँग Azure Functions प्रयोग गरेर MCP को नमूना कार्यान्वयन।

## मुख्य सन्देशहरू

- MCP SDKs ले भाषा-विशिष्ट उपकरणहरू प्रदान गर्छन् जसले मजबुत MCP समाधानहरू कार्यान्वयन गर्न सकिन्छ
- डिबग र परीक्षण प्रक्रिया विश्वसनीय MCP अनुप्रयोगहरूको लागि महत्वपूर्ण छ
- पुनः प्रयोगयोग्य प्रॉम्प्ट टेम्प्लेटले सुसंगत AI अन्तरक्रियाहरू सक्षम पार्दछ
- राम्रो डिजाइन गरिएका वर्कफ्लोहरूले बहु उपकरणहरूले जटिल कार्यहरू समन्वय गर्न सक्छन्
- MCP समाधानहरू कार्यान्वयन गर्दा सुरक्षा, प्रदर्शन, र त्रुटि ह्यान्डलिङ विचार गर्न आवश्यक छ

## अभ्यास

तपाईंको क्षेत्रमा वास्तविक समस्या समाधान गर्ने व्यावहारिक MCP वर्कफ्लो डिजाइन गर्नुहोस्:

1. यस समस्यालाई समाधान गर्न उपयोगी हुने 3-4 उपकरणहरू पहिचान गर्नुहोस्
2. यी उपकरणहरू कसरी अन्तरक्रिया गर्छन् भनेर वर्कफ्लो चित्र बनाउनुहोस्
3. आफ्नो रोजाइको भाषामा एउटा उपकरणको आधारभूत संस्करण कार्यान्वयन गर्नुहोस्
4. मोडेललाई तपाईंको उपकरण प्रभावकारी तरिकाले प्रयोग गर्न मद्दत गर्ने प्रॉम्प्ट टेम्प्लेट बनाउनुहोस्
