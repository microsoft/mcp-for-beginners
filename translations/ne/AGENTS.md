# AGENTS.md

## परियोजना अवलोकन

**MCP नयाँहरूका लागि** मोडेल कन्टेक्स्ट प्रोटोकल (MCP) सिक्नको लागि खुला स्रोत शैक्षिक पाठ्यक्रम हो - एआई मोडेलहरू र ग्राहक अनुप्रयोगहरू बीच अन्तरक्रियाको लागि एक मानकीकृत ढाँचा। यस रिपोजिटरीले बहु प्रोग्रामिङ भाषाहरूमा व्यवहारिक कोड उदाहरणहरूसहित व्यापक शैक्षिक सामग्री प्रदान गर्दछ।

### मुख्य प्रविधिहरू

- **प्रोग्रामिङ भाषाहरू**: C#, Java, JavaScript, TypeScript, Python, Rust
- **फ्रेमवर्कहरू र SDK हरू**:
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **डाटाबेसहरू**: pgvector एक्सटेन्शनसहित PostgreSQL
- **क्लाउड प्लेटफर्महरू**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **निर्माण उपकरणहरू**: npm, Maven, pip, Cargo
- **प्रलेखन**: स्वचालित बहुभाषी अनुवाद सहित Markdown (४८+ भाषाहरू)

### संरचना

- **११ कोर मोड्युलहरू (००-११)**: आधारभूतदेखि उन्नत विषयहरूमा क्रमिक सिकाइ मार्ग
- **व्यावहारिक प्रयोगशाला**: बहुभाषी पूर्ण समाधान कोडसहित व्यावहारिक अभ्यासहरू
- **नमूना परियोजनाहरू**: कार्यशील MCP सर्भर र ग्राहक क्रियान्वयनहरू
- **अनुवाद प्रणाली**: बहुभाषी समर्थनको लागि स्वचालित GitHub Actions कार्यप्रवाह
- **छविहरूका सामग्रीहरू**: केन्द्रीयकृत छवि निर्देशिका अनूदित संस्करणहरूसहित

## सेटअप आदेशहरू

यो प्रलेखन-केंद्रित रिपोजिटरी हो। अधिकांश सेटअप व्यक्तिगत नमूना परियोजनाहरू र प्रयोगशालाहरू भित्र हुन्छ।

### रिपोजिटरी सेटअप

```bash
# रिपोजिटोरी क्लोन गर्नुहोस्
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### नमूना परियोजनाहरू सँग काम गर्ने तरिका

नमूना परियोजनाहरू रहेको स्थानहरू:
- `03-GettingStarted/samples/` - भाषा-विशिष्ट उदाहरणहरू
- `03-GettingStarted/01-first-server/solution/` - पहिलो सर्भर कार्यान्वयनहरू
- `03-GettingStarted/02-client/solution/` - ग्राहक कार्यान्वयनहरू
- `11-MCPServerHandsOnLabs/` - व्यापक डाटाबेस एकीकरण प्रयोगशालाहरू

प्रत्येक नमूना परियोजनासँग यसको आफ्नै सेटअप निर्देशनहरू छन्:

#### TypeScript/JavaScript परियोजनाहरू
```bash
cd <project-directory>
npm install
npm start
```

#### Python परियोजनाहरू
```bash
cd <project-directory>
pip install -r requirements.txt
# वा
pip install -e .
python main.py
```

#### Java परियोजनाहरू
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

##### लक्ष्य

पाठ्यक्रम दस्तावेज परिवर्तनहरू र प्रतिनिधि नमूना कोडको
स्वास्थ्य विलय अघि जाँच गर्नुहोस्।

##### इनपुटहरू

- `changed_paths: string[]` (आवश्यक) - PR मा परिवर्तन गरिएको सापेक्ष पथहरू।
- `run_docs_lint: boolean` (पूर्वनिर्धारित `true`)
- `run_links_audit: boolean` (पूर्वनिर्धारित `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (पूर्वनिर्धारित सबै `false`)

##### आउटपुटहरू

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### अनुमति

- कार्यक्षेत्र फाइलहरू पढ्ने र उपकरण-उत्पन्न आर्टिफ्याक्टहरू मात्र लेख्ने (जस्तै, लिंट
  रिपोर्टहरू, परीक्षण लगहरू); `translations/` वा
  `translated_images/` मा कुनै लेखन छैन।
- स्थानीय शेल आदेशहरू चलाउने।
- प्याकेज पुनर्स्थापना मात्रका लागि वैकल्पिक नेटवर्क पहुँच (`npm ci`,
  `python -m pip install`, `mvn` निर्भरता समाधान)।
- `translations/` वा
  `translated_images/` मा पुश, मर्ज, वा संशोधन गर्ने अनुमति छैन।

##### असफलता मोडहरू

- `E_NO_INPUT_PATHS`: `changed_paths` खाली छ।
- `E_INVALID_PATH`: इनपुट पथ रेपो भित्र नपर्ने।
- `E_LINT_FAILED`: मार्कडाउन लिंटले शून्य भन्दा फरक निकास कोड फर्कायो।
- `E_LINK_AUDIT_FAILED`: लिंक अडिट आदेशले शून्य भन्दा फरक निकास कोड फर्कायो।
- `E_SAMPLE_TEST_FAILED`: नमूना परीक्षण/बिल्डले शून्य भन्दा फरक निकास कोड फर्कायो।
- `E_TIMEOUT`: आदेशले निर्धारण गरिएको समय सीमा पार गर्यो।
