# AGENTS.md

## परियोजना अवलोकन

**शुरुआतीहरूको लागि MCP** मोडेल कन्टेक्स्ट प्रोटोकल (MCP) सिक्नको लागि एक खुला स्रोत शैक्षिक पाठ्यक्रम हो - यो एआई मोडेलहरू र क्लाइन्ट अनुप्रयोगहरूको बीच अन्तरक्रियाको लागि एक मानकीकृत संरचना हो। यो रिपोजिटरी धेरै प्रोग्रामिङ भाषाहरूमा हातमा कोड उदाहरणहरूसहित व्यापक सिकाइ सामग्री प्रदान गर्दछ।

### मुख्य प्रविधिहरू

- **प्रोग्रामिङ भाषाहरू**: C#, Java, JavaScript, TypeScript, Python, Rust
- **फ्रेमवर्कहरू र SDKs**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **डेटाबेसहरू**: pgvector विस्तार सहित PostgreSQL
- **क्लाउड प्लेटफर्महरू**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **निर्माण उपकरणहरू**: npm, Maven, pip, Cargo
- **प्रलेखन**: स्वचालित बहुभाषिक अनुवादसहित मार्कडाउन (48+ भाषाहरू)

### संरचना

- **११ मुख्य मोड्युलहरू (००-११)**: आधारदेखि उन्नत विषयहरूमा क्रमिक सिकाइ पथ
- **हातमा अभ्यासहरू**: बहु भाषाहरूमा पूर्ण समाधान कोड सहित प्रयोगात्मक अभ्यासहरू
- **नमूना परियोजनाहरू**: कार्यरत MCP सर्भर र क्लाइन्ट कार्यान्वयनहरू
- **अनुवाद प्रणाली**: बहुभाषिक समर्थनको लागि स्वचालित GitHub Actions कार्यप्रवाह
- **छवि स्रोतमाथि**: अनुवादित संस्करणहरू सहित केन्द्रीय छवि निर्देशिका

## सेटअप आदेशहरू

यो एउटा प्रलेखन-केंद्रित रिपोजिटरी हो। अधिकांश सेटअप व्यक्तिगत नमूना परियोजनाहरू र प्रयोगशालाहरूमा हुन्छ।

### रिपोजिटरी सेटअप

```bash

git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### नमूना परियोजनाहरूमा काम गर्ने

नमूना परियोजनाहरू रहेका छन्:
- `03-GettingStarted/samples/` - भाषा-विशिष्ट उदाहरणहरू
- `03-GettingStarted/01-first-server/solution/` - पहिलो सर्भर कार्यान्वयनहरू
- `03-GettingStarted/02-client/solution/` - क्लाइन्ट कार्यान्वयनहरू

प्रत्येक नमूना परियोजनाले आफ्नै सेटअप निर्देशनहरू समावेश गर्दछ:

#### TypeScript/JavaScript परियोजनाहरू
```bash
cd <project-directory>
npm install
npm start
```

#### Python परियोजनाहरू
```bash
cd <project-directory>
pip install -r requirements.txt
# वा
pip install -e .
python main.py
```

#### Java परियोजनाहरू
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,

- `failed_checks: string[]`

- कार्यक्षेत्र फाइलहरू पढ्ने र उपकरण-उत्पन्न कलाकृतिहरू मात्र लेख्ने (जस्तै, लिन्ट
  रिपोर्टहरू, परीक्षण लगहरू); `translations/` वा
  `translated_images/` मा कुनै लेखन छैन।

- `translations/` वा
  `translated_images/` मा पुश, मर्ज, वा संशोधन गर्न अनुमति छैन।

### पुल अनुरोध प्रक्रिया

1. **फोर्क र क्लोन**: रिपोजिटरी फोर्क गरी आफ्नो फोर्क स्थानीयमा क्लोन गर्नुहोस्
2. **शाखा सिर्जना गर्नुहोस्**: वर्णनात्मक शाखा नामहरू प्रयोग गर्नुहोस् (जस्तै, `fix/typo-module-3`, `add/python-example`)
3. **परिवर्तनहरू गर्नुहोस्**: केवल अंग्रेजी मार्कडाउन फाइलहरू सम्पादन गर्नुहोस् (अनुवादहरू होइन)

5. **PR सबमिट गर्नुहोस्**: स्पष्ट PR शीर्षकहरू र विवरणहरू प्रयोग गर्नुहोस्
6. **CLA**: Microsoft योगदानकर्ता लाइसेन्स सम्झौता हस्ताक्षर गर्नुहोस् जब सोधियो

- मोड्युल-विशिष्ट परिवर्तनहरूका लागि `[Module XX] संक्षिप्त वर्णन`
