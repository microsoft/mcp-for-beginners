# வழக்கு ஆய்வு: API மேலாண்மையில் REST API ஐ MCP சேவையகமாக வெளிப்படுத்துதல்

Azure API மேலாண்மை, உங்கள் API இறுதிப்புள்ளிகளின் மேல் ஒரு கேட்வே ஆகிய சேவையாகும். இது எப்படி வேலை செய்கிறது என்றால் Azure API மேலாண்மை உங்கள் API களுக்கு முன் ஒரு ப்ராக்சி போல செயல்படுகிறது மற்றும் வரும் கோரிக்கைகள் மீது என்ன செய்ய வேண்டும் என்று முடிவு செய்ய முடியும்.

இதைப் பயன்படுத்தி, நீங்கள் பல்வேறு அம்சங்களை சேர்ப்பீர்கள்:

- **பாதுகாப்பு**, API விசைகள், JWT முதல் நிர்வகிக்கப்பட்ட அடையாளம் வரை அனைத்தையும் பயன்படுத்த முடியும்.
- **களஞ்சல் வரம்புவிதி**, ஒரு சிறந்த அம்சம் இது குறிப்பிட்ட நேர அலகிற்கு எத்தனை அழைப்புகள் அனுமதிக்கப்பட வேண்டும் என முடிவு செய்ய முடியும். இதனால் அனைத்து பயனாளர்களுக்கும் சிறந்த அனுபவம் கிடைக்கும் மற்றும் உங்கள் சேவை கோரிக்கைகளால் மிகப்பெரிய பயத்தை சந்திக்காது.
- **கட்டமைப்பு மற்றும் ஏற்றம் சமநிலைபடுத்தல்**. ஏற்றத்தை சமநிலை செய்ய பல இறுதிப்புள்ளிகளை அமைக்க முடியும் மேலும் "ஏற்றம் சமநிலை" செய்யும் முறையையும் நீங்கள் தேர்வு செய்ய முடியும். 
- **அ.மி அம்சங்கள் போன்ற பொருள் நிலை காப்பகம்**, டோக்கன் வரம்பு மற்றும் டோக்கன் கண்காணிப்பு மற்றும் மேலும். இவை திறன்களை மேம்படுத்தும் சிறந்த அம்சங்கள் மற்றும் உங்கள் டோக்கன் செலவுகளை கண்காணிக்க உதவுவன. [மேலும் படிக்கவும்](https://learn.microsoft.com/en-us/azure/api-management/genai-gateway-capabilities). 

## ஏன் MCP + Azure API மேலாண்மை?

மாடல் உள்ளடக்க உடன்படிக்கை விரைவாக முகப்புக் கலை இலக்கண AI செயலிகளுக்கான ஒரு தரமாகும் மற்றும் சாதனங்கள் மற்றும் தரவை தொடர்ச்சியான முறையில் வெளிப்படுத்தும் வழியாக உள்ளது. Azure API மேலாண்மை API களை "மேலாண்மை" செய்ய வேண்டிய போது இயல்பான தேர்வாகும். MCP சேவையகங்கள் பெரும்பாலும் பிற API களுடன் ஒருங்கிணைத்து ஒரு கருவிக்கு கோரிக்கைகளை தீர்க்கும் உதாரணமாக உள்ளது. எனவே Azure API மேலாண்மை மற்றும் MCP இணைத்தல் பொருத்தமானது.

## மேலோட்டம்

இந்த குறிப்பிட்ட பயன்பாட்டில், நாம் API இறுதிப்புள்ளிகளைக் MCP சேவையகமாக வெளிப்படுத்துவது கற்கப்போகின்றோம். இதனால், இந்த இறுதிப்புள்ளிகள் முகப்புக் கலையின் ஒரு பகுதியாக எளிதில் ஆகலாம் மற்றும் Azure API மேலாண்மையின் அம்சங்களையும் பயன்படுத்த முடியும்.

## முக்கிய அம்சங்கள்

- நீங்கள் கருவிகளாக வெளிப்படுத்த விரும்பும் இறுதிப்புள்ளி முறைகளை தேர்வு செய்வீர்கள்.
- நீங்கள் பெறும் கூடுதல் அம்சங்கள் உங்கள் API க்கான கொள்கை பகுதியில்அமைக்கப்பட்டவற்றின் அடிப்படையில் இருக்கும். ஆனால் இங்கு நாம் வரம்புவிதியை எப்படி சேர்ப்பது என்பதை காட்டுவோம்.

## முன்னிலை: ஒரு API ஐ இறக்குமதி செய்க

உங்களிடம் ஏற்கனவே Azure API மேலாண்மையில் API இருந்தால் நன்றாக உள்ளது, இந்த படியை தவிர்க்கலாம். இல்லை என்றால், இந்த இணைப்பைக் காண்க, [Azure API மேலாண்மையில் API இறக்குமதி செய்தல்](https://learn.microsoft.com/en-us/azure/api-management/import-and-publish#import-and-publish-a-backend-api).

## API ஐ MCP சேவையகமாக வெளிப்படுத்தல்

API இறுதிப்புள்ளிகளை வெளிப்படுத்த, இவ்வாறு செயல்படுவோம்:

1. Azure போர்ட்டலில் செல்லவும் மற்றும் பின்வரும் முகவரிக்கு செல் <https://portal.azure.com/?Microsoft_Azure_ApiManagement=mcp> 
உங்கள் API மேலாண்மை நிகழ்வுக்கு செல்லவும்.

1. இடது மெனுவில், APIs > MCP Servers > + Create new MCP Server என்பதைத் தேர்ந்தெடுக்கவும்.

1. API இல், MCP சேவையகமாக வெளிப்படுத்த REST API ஐ தேர்வுசெய்க.

1. கருவிகளாக வெளிப்படுத்த ஒரு அல்லது அதற்கு மேற்பட்ட API செயல்பாடுகளைத் தேர்ந்தெடுக்கவும். நீங்கள் அனைத்து செயல்பாடுகளையும் அல்லது குறிப்பிட்ட செயல்பாடுகளையே தேர்வு செய்யலாம்.

    ![Select methods to expose](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/create-mcp-server-small.png)


1. **Create** ஐ தேர்ந்தெடுக்கவும்.

1. **APIs** மற்றும் **MCP Servers** என்ற மெனு விருப்பத்திற்கு செல்லவும், பின்வரும் காண்பிக்கபடும்:

    ![See the MCP Server in the main pane](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-list.png)

    MCP சேவையகம் உருவாக்கப்பட்டது மற்றும் API செயல்பாடுகள் கருவிகளாக வெளிப்படுத்தப்பட்டன. MCP சேவையகம் MCP Servers பகுதியில் பட்டியலிடப்பட்டுள்ளது. URL நெடுவரிசை MCP சேவையகத்தின் இறுதிப்புள்ளியை காட்டுகிறது, நீங்கள் அதை சோதனை அல்லது வாடிக்கையாளர் செயலியில் அழைக்க முடியும்.

## விருப்பம்: கொள்கைகளை அமைக்கவும்

Azure API மேலாண்மையின் முக்கியக் கருத்து கொள்கைகள் ஆகும், இதில் நீங்கள் உங்கள் இறுதிப்புள்ளிகளுக்கு விதிகளை அமைக்கலாம், உதாரணமாக வரம்புவிதி அல்லது பொருள் நிலை காப்பகம் போன்றவை. இந்த கொள்கைகள் XML இல் எழுதப்படுகின்றன.

MCP சேவையகத்திற்கு வரம்புவிதி கொள்கையை எப்படி அமைக்கலாம் என்பதை இதோ:

1. போர்ட்டலில், APIs கீழ் **MCP Servers** ஐ தேர்வு செய்யவும்.

1. நீங்கள் உருவாக்கிய MCP சேவையகத்தைத் தேர்ந்தெடுக்கவும்.

1. இடதுபக்க மெனுவில், MCP கீழ் **Policies** ஐ தேர்வுசெய்க.

1. கொள்கை தொகுப்பியில், MCP சேவையக கருவிகளுக்கு பொருந்தும் கொள்கைகளை சேர்க்கவோ திருத்தவோ செய்யவும். கொள்கைகள் XML வடிவில் வரையறுக்கப்பட்டுள்ளன. உதாரணமாக, MCP சேவையக கருவிகளுக்கு அழைப்புகளை கட்டுப்படுத்த ஒரு கொள்கையை சேர்க்கலாம் (இந்த உதாரணத்தில், 30 விநாடிக்கு 5 அழைப்புகள் ஒரு கிளையண்ட் IP முகவரிக்கு). இதோ வரம்புவிதியை ஏற்படுத்த XML:

    ```xml
     <rate-limit-by-key calls="5" 
       renewal-period="30" 
       counter-key="@(context.Request.IpAddress)" 
       remaining-calls-variable-name="remainingCallsPerIP" 
    />
    ```

    கொள்கை தொகுப்பியின் படமொன்று இங்கே:

    ![Policy editor](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-policies-small.png)
 
## சோதனை செய்யுங்கள்

நம் MCP சேவையகம் கணிக்கப்பட்டபடி செயல்படுகிறது என்பதை உறுதி செய்தோம்.

> [!NOTE]
> Azure API மேலாண்மை தற்போது இந்த சேவையகத்தை Streamable
> HTTP `/mcp` இறுதிப்புள்ளியாக வெளிப்படுத்துகிறது. பழைய HTTP+SSE `/sse` போக்குவரத்து பழைய வாடிக்கையாளர்களுக்கே பயன்படுத்தப்பட வேண்டும்.


இதற்காக, நாம் Visual Studio Code மற்றும் GitHub Copilot மற்றும் அதன் முகவர் (Agent) முறையைப் பயன்படுத்துவோம். நாம் MCP சேவையகத்தை *mcp.json* கோப்பில் சேர்ப்போம். இதனால் Visual Studio Code முகவர் திறன்களுடன் ஒரு கிளையண்டாக செயல்படும் மற்றும் இறப்பு பயனாளர்கள் ஒரு அம்புதொழில்(type a prompt) தட்டச்சு செய்து அந்த சேவையகத்துடன் தொடர்பு கொள்ளலாம்.

எப்படி Visual Studio Code இல் MCP சேவையகத்தைச் சேர்ப்பது காண்போம்:

1. Command Palette இலிருந்து MCP: **Add Server** கட்டளையைப் பயன்படுத்தவும்.

1. கேட்கப்பட்டால், சேவையக வகையைத் தேர்ந்தெடுக்கவும்: **HTTP (HTTP அல்லது Server Sent Events)**.

1. API மேலாண்மையில் MCP சேவையகத்திற்கான Streamable HTTP URL ஐ உள்ளிடவும்.
    உதாரணமாக:
    `https://<apim-service-name>.azure-api.net/<api-name>-mcp/mcp`.

1. உங்கள் விருப்பமான சேவையக ஐடியை உள்ளிடவும். இது முக்கியமான மதிப்பு அல்ல ஆனால் இந்த சேவையக எடுத்துக்காட்டின் என்ன என்பதை நினைவுக்கு உதவும்.

1. அமைப்பை உங்கள் வேலைப்பகுதி அமைப்புகளில் அல்லது பயனர் அமைப்புகளில் சேமிக்க தேர்வு செய்யவும்.

    - **வேலைப்பகுதி அமைப்புகள்** - சேவையக அமைப்பு `.vscode/mcp.json` கோப்பில் சேமிக்கப்படுகிறது, இது தற்போதைய வேலைப்பகுதியில் மட்டுமே கிடைக்கும்.

      *mcp.json*

      ```json
      "servers": {
          "APIM petstore" : {
              "type": "http",
              "url": "url-to-mcp-server/mcp"
          }
      }
      ```

    - **பயனர் அமைப்புகள்** - சேவையக அமைப்பு உங்கள் உலகளாவிய *settings.json* கோப்பில் சேர்க்கப்படுகிறது மற்றும் அனைத்து வேலைப்பகுதிகளிலும் கிடைக்கும். அமைப்பின் வடிவம் கீழே உள்ளது:

      ![User setting](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-servers-visual-studio-code.png)

1. Azure API மேலாண்மையை சரியாக உறுதிப்படுத்த வேண்டும் என்பதற்காக ஒரு கட்டமைப்பு தலைப்பை (configuration header) சேர்க்க வேண்டும். இது **Ocp-Apim-Subscription-Key** என்ற தலைப்பைப் பயன்படுத்துகிறது.

    - அதை அமைப்புகளில் சேர்க்கும் வழி:


    ![Adding header for authentication](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/mcp-server-with-header-visual-studio-code.png), இது API விசை மதிப்பை கேட்டு ஒரு அம்புதொழில் காட்டும், அதை நீங்கள் Azure போர்ட்டலில் உங்கள் Azure API மேலாண்மை நிகழ்விற்காகக் காணலாம்.

   - அதற்கு பதிலாக *mcp.json* இல் சேர்க்க, இப்படிச் சேர்க்கலாம்:

    ```json
    "inputs": [
      {
        "type": "promptString",
        "id": "apim_key",
        "description": "API Key for Azure API Management",
        "password": true
      }
    ]
    "servers": {
        "APIM petstore" : {
            "type": "http",
            "url": "url-to-mcp-server/mcp",
            "headers": {
                "Ocp-Apim-Subscription-Key": "Bearer ${input:apim_key}"
            }
        }
    }
    ```

### முகவர் முறையைப் பயன்படுத்தவும்

இப்போது நாம் அமைப்புகளில் அல்லது *.vscode/mcp.json* இல் அனைத்து பாடங்களும் அமைக்கப்பட்டுள்ளன. இதை சோதனை செய்யலாம். 

கருவிகள் ஐகான் அப்படி இருக்க வேண்டும், நீங்கள் உங்கள் சேவையகத்திலிருந்து வெளிப்படுத்தப்பட்ட கருவிகள் பட்டியலிடப்படும்:

![சேவையகத்தில் இருந்து கருவிகள்](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/tools-button-visual-studio-code.png)

1. கருவிகள் ஐகானை கிளிக் செய்யவும், அப்படியே கீழ்க்கண்டபோன்று கருவிகள் பட்டியலை நீங்கள் காண்பீர்கள்:

    ![கருவிகள்](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/select-tools-visual-studio-code.png)

1. கருவியை இயக்கச் செய்தல் செய்ய கூற்று ஒன்றை உரையாடலில் உள்ளிடவும். உதாரணமாக, ஒரு ஆர்டரைப் பற்றி தகவல் பெற கருவியைத் தேர்ந்தெடுத்திருந்தால், நீங்கள் முகவரிடம் அந்த ஆர்டரைப் பற்றி கேட்கலாம். இதோ ஒரு கூற்று உதாரணம்:

    ```text
    get information from order 2
    ```

    இப்போது நீங்கள் கருவியை அழைக்க தொடர கேட்டு கருவிகள் ஐகான் ஒன்று காட்சியிடப்படும். கருவியை இயக்கத் தொடர தேர்வு செய்யவும், அப்படியே கீழ்க்கண்டபோன்று வெளியீடு காணப்படும்:

    ![கூற்றிலிருந்து கிடைத்த முடிவு](https://learn.microsoft.com/en-us/azure/api-management/media/export-rest-mcp-server/chat-results-visual-studio-code.png)

    **மேலே நீங்கள் பார்க்கும் விஷயங்கள் நீங்கள் அமைத்த கருவிகளின் படி மாறுபடும், ஆனால் கருத்து இத்தகைய ஒரு எழுத்துப்படி பதிலைப் பெறுவதாகும்**
