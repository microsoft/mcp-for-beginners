# 🚀 10 மைக்ரோசொப்ட் MCP சர்வர்கள் கொண்டு டெவலப்பர் செயல்திறனை மாற்றி அமைக்கியவை

## 🎯 இந்த வழிகாட்டியில் நீங்கள் கற்றுக்கொள்ளப்போகும் விஷயங்கள்

இந்த நடைமுறை வழிகாட்டியில், டெவலப்பர்கள் AI உதவியாளர்களுடன் எவ்வாறு வேலைபடுகிறார்கள் என்பதை மாற்றிவிடும் பத்து மைக்ரோசொப்ட் MCP சர்வர்களை நாங்கள் காட்டுகிறோம். MCP சர்வர்கள் *என்ன செய்ய முடியும்* என்பதை விளக்கும் பதிலாக, நாங்கள் தொடர்ந்து மைக்ரோசொப்ட் மற்றும் அதற்கும் மேற்பட்ட அடிப்படையில் தினசரி வளர்ச்சி பணிகளில் உண்மையான மாற்றத்தை ஏற்படுத்தும் சர்வர்களை உங்களுக்கு காண்பிப்போம்.

இந்த வழிகாட்டியில் உள்ள ஒவ்வொரு சர்வரும் உண்மையான பயன்பாடு மற்றும் டெவலப்பர் பின்னூட்டத்தின் அடிப்படையில் தேர்ந்தெடுக்கப்பட்டது. நீங்கள் ஒவ்வொரு சர்வர் என்ன செய்கிறது என்பதையே அல்லாமல், அது ஏன் முக்கியம் மற்றும் உங்கள் சொந்த திட்டங்களில் அதிலிருந்து அதிகபட்சம் எப்படி பெறுவது என்பதையும் புரிந்துகொள்ளப்போகிறீர்கள். நீங்கள் MCPக்கு முற்றிலும் புதியவராக இருந்தாலும் அல்லது உங்கள் உள்ளமைவை விரிவுபடுத்திக்கொள்ள விரும்பினாலும், இந்த சர்வர்கள் மைக்ரோசொப்ட் சூழலைச் சேர்ந்த மிகவும் நடைமுறை மற்றும் தாக்கம் வாய்ந்த கருவிகளாகும்.

> **💡 விரைவு தொடக்கம் குறிப்பு**
> 
> MCPக்கு புதியவரா? கவலைப்படாதீர்கள்! இந்த வழிகாட்டி ஆரம்பநிலை பயனர்களுக்குப் பொருத்தமாக வடிவமைக்கப்பட்டுள்ளது. நாங்கள் கருத்துக்களை படிப்படியாக விளக்கும், மேலும் நீங்கள் எப்போதும் நமது [MCP அறிமுகம்](../00-Introduction/README.md) மற்றும் [முக்கிய கருத்துக்கள்](../01-CoreConcepts/README.md) மாடியூல்களை ஆழமான பின்னணிக்காக காணலாம்.

## கண்ணோட்டம்

இந்த விரிவான வழிகாட்டி, டெவலப்பர்கள் AI உதவியாளர்களுடன் மற்றும் வெளியொய்வுகள் கருவிகளுடன் எவ்வாறு தொடர்பு கொள்கிறார்கள் என்பதை மாற்றியமைக்கும் பத்துப் மைக்ரோசொப்ட் MCP சர்வர்களை ஆராய்கிறது. அசர் வள நிர்வாகத்திலிருந்து கொள்குறிப்பு செயலாக்கம் வரை, இந்த சர்வர்கள் மாதிரிப் பிரசங்கக் குறுக்கு நடைமுறை செயல்முறைகளை உருவாக்குவதில் Model Context Protocolன் சக்தியை காட்டுகின்றன.

## கற்றல் நோக்குகள்

இந்த வழிகாட்டி முடிவில், நீங்கள்:
- MCP சர்வர்கள் டெவலப்பர் செயல்திறனை எவ்வாறு மேம்படுத்துகின்றன என்பதைப் புரிந்துகொள்வீர்கள்
- மைக்ரோசொப்டின் மிக தாக்கமுள்ள MCP சர்வர் செயல்பாடுகளை கற்றுக்கொள்ளப்போகிறீர்கள்
- ஒவ்வொருந் சர்வருக்கான நடைமுறை பயன்பாடுகளை கண்டறிவீர்கள்
- VS Code மற்றும் Visual Studioவில் இந்த சர்வர்களை அமைத்து கட்டமைப்பது எப்படி என்பதை அறிவீர்கள்
- MCP சூழல் மற்றும் எதிர்கால பாதைகள் பற்றி ஆராய்வீர்கள்

## 🔧 MCP சர்வர்களை புரிந்து கொள்வது: தொடங்கியவருக்கான வழிகாட்டி

### MCP சர்வர்கள் என்றால் என்ன?

Model Context Protocol (MCP)க்கு புதியவராக இருந்தால், "MCP சர்வர் என்றால் என்ன, நான் அதை எதற்கு கவலையாயிருக்க வேண்டும்?" என்று நீங்கள் ஐயமோட்டிருக்கலாம். ஒரு எளிய ஒப்புமையை எடுத்துக்கொள்வோம்.

MCP சர்வர்கள் உங்கள் AI குறியீட்டு துணையை (GitHub Copilot போன்ற) வேறுபட்ட கருவிகள் மற்றும் சேவைகளுடன் இணைக்க உதவும் சிறப்பான உதவியாளர்கள் போல இருக்கிறார்கள். நீங்கள் உங்கள் மொபைல் போனில் வேறு வேறு பயன்பாடுகளை ஒருங்கிணைத்து பயன்படுத்துகிறீர்கள் போலவே—ஒன்று வானிலை, ஒன்று வழி காட்டும், ஒன்று வங்கி செய்ய இவை போன்றவை—MCP சர்வர்கள் உங்கள் AI உதவியாளருக்கு பல்வேறு டெவலப்பர் கருவிகளும் சேவைகளும் தொடர்பு கொள்ளும் திறனைக் கொடுக்கின்றன.

### MCP சர்வர்கள் தீர்க்கும் பிரச்சினை

MCP சர்வர்கள் வருவிக்கும் முன், நீங்கள்:
- உங்கள் அசர் வளங்களை சரிபார்க்க
- GitHub பிரச்சினையைக் உருவாக்க
- உங்கள் தரவுத்தளத்தைக் கேள்வி செய்தல்
- ஆவணங்களைத் தேடுதல்

குறியீடு எழுதுவதை நிறுத்தி, உலாவியை திறந்து, சரியான வலைத்தளத்திற்கு செல்லும் பணி செய்யவேண்டும். இந்த இடையிடை சூழல் மாறுதல்கள் உங்கள் வேலை ஓட்டத்தைத் தடைசெய்யும் மற்றும் செயல்திறனை குறைக்கும்.

### MCP சர்வர்கள் உங்கள் வளர்ச்சி அனுபவத்தை மாற்றுவது எப்படி

MCP சர்வர்களுடன், நீங்கள் உங்கள் வளர்ச்சி சூழலில் (VS Code, Visual Studio, போன்றவை) தங்கியிருக்க முடியும் மற்றும் உங்கள் AI உதவியாளரிடம் இந்த பணிகளை கையாளச் சொல்லலாம். உதாரணமாக:

**பழைய வழிமுறையுடன் ஒப்பிடுகையில்:**
1. குறியீடு எழுதுவது நிறுத்தவும்
2. உலாவியைத் திறக்கவும்
3. அசர் போர்டலை சென்று செல்லவும்
4. சேமிப்பு கணக்கு விவரங்களை பார்வையிடவும்
5. மீண்டும் VS Codeக்கு திரும்பவும்
6. குறியீடு தொடரவும்

**இப்போது இதை செய்யலாம்:**
1. AIக்கு கேளுங்கள்: "எனது அசர் சேமிப்பு கணக்குகளின் தற்போதைய நிலை என்ன?"
2. பெறப்பட்ட தகவலுடன் குறியீடு தொடருங்கள்

### தொடங்கியவருக்கு முக்கியமான நன்மைகள்

#### 1. 🔄 **உங்கள் வேலை ஓட்டத்தில் நிலைத்திருங்கள்**
- பல்வேறு பயன்பாடுகளுக்கு இடையில் மாற வேண்டாம்
- நீங்கள் எழுதும் குறியீட்டில் கவனம் செலுத்துங்கள்
- வேறுபட்ட கருவிகளை நிர்வகிக்க மனநிலை சுமையை குறைக்கவும்

#### 2. 🤖 **சிக்கலான கட்டளைகளின் மாற்றமாக இயற்கை மொழியைப் பயன்படுத்துங்கள்**
- SQL சனாக்களை மறைவதற்கு பதிலாக தேவையான தரவை விவரிக்கவும்
- அசர் CLI கட்டளைகளை நினைவுபடுத்துவதற்கு பதிலாக நீங்கள் செய்ய விரும்பும் பணியை விளக்கவும்
- AI திறனை தொழில்நுட்ப விவரங்களை கையாள வைத்து, நீங்கள் தர்க்கத்தில் கவனம் வைக்கலாம்

#### 3. 🔗 **பல கருவிகளை இணைத்து இணைக்கும் திறன்**
- வலுவான வேலை ஓட்டங்களை உருவாக்க பல சேவைகளை ஒருங்கிணைக்கவும்
- உதாரணம்: "சமீபத்திய GitHub பிரச்சினைகளைப் பெற்று அதற்கு ஏற்ப அசர் டெவ்அப்ஸ் பணித் தொகுதிகள் உருவாக்கவும்"
- சிக்கலான ஸ்கிரிப்ட்களை எழுதாமல் தானியங்கி செயல்முறைகளை கட்டமைக்கவும்

#### 4. 🌐 **வளரும் சூழலை அணுகல்**
- மைக்ரோசொப்ட், GitHub மற்றும் பிற நிறுவனங்கள் உருவாக்கிய சர்வர்களை பயன்படுத்தவும்
- வெவ்வேறு விற்பனையாளர்களின் கருவிகளை கடந்து இணைத்து பயன்படுத்தவும்
- பல AI உதவியாளர்கள் மூலம் இயங்கும் ஒரு செய்முறை சூழல் சீரமைப்புடன் இணைக

#### 5. 🛠️ **பயிற்சியாக கற்றுக்கொள்ளுங்கள்**
- கருத்துக்களை புரிந்துகொள்ள முன்-உருவாக்கப்பட்ட சர்வர்களுடன் தொடங்குங்கள்
- நீங்கள் நம்பிக்கை பெறுவதை அதிகரிக்கும்போது உங்கள் சொந்த சர்வர்களை கட்டமைக்கவும்
- கற்றலுக்கு கிடைக்கும் SDKகள் மற்றும் ஆவணங்களைப் பயன்படுத்தவும்

### புதியவர்களுக்கு உண்மையான உலக உதாரணம்

நீங்கள் இணைய வளர்ச்சியில் புதியவராகி உங்கள் முதல் திட்டத்தில் வேலை செய்கிறீர்கள் என நிலைபெற்றால், MCP சர்வர்கள் உதவும் விதம்:

**பழைய முறையாக:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP சர்வர்களுடன்:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### தொழில்துறை தரநிலை நன்மை

MCP என்பது தொழில்துறை நிலையான தரமாக மாறி வருகிறது, அதனால்:
- **ஒத்திணைப்பு**: வேறுபட்ட கருவிகள் மற்றும் நிறுவனங்களுக்கு இடையேயான ஒரே மாதிரி அனுபவம்
- **இணைப்பு திறன்**: பல விற்பனையாளர்களின் சர்வர்கள் ஒருங்கிணைந்த செயல்பாடு
- **எதிர்கால பாதுகாப்பு**: திறன்களும் அமைப்புகளும் வெவ்வேறு AI உதவியாளர்களுக்கு பரிமாறப்பட்டு கையாள முடியும்
- **சமூகம்**: பரஸ்பர பகிரப்பட்ட அறிவு மற்றும் வளங்களுள்ள பெரிய சூழல்

### தொடக்கம்: நீங்கள் கற்றுக்கொள்ளக்கூடியவை

இந்த வழிகாட்டியில், அனைத்து நிலைகளிலும் பயனுள்ளதாக இருக்கும் 10 மைக்ரோசொப்ட் MCP சர்வர்களை நாங்கள் ஆராயப் போகிறோம். ஒவ்வொரு சர்வரும் இவற்றை நோக்கி வடிவமைக்கப்பட்டுள்ளது:
- பொதுவான வளர்ச்சி சவால்களை தீர்க்க
- மீண்டும் மீண்டும் செய்யும் வேலைகளை குறைக்கும்
- குறியீட்டு தரத்தை மேம்படுத்தும்
- கற்றல் வாயிலாக மேம்படுத்தும்

> **💡 கற்றல் குறிப்பு**
> 
> MCPக்கு முற்றிலும் புதியவர்கள் என்றால், முதலில் நமது [MCP அறிமுகம்](../00-Introduction/README.md) மற்றும் [முக்கிய கருத்துக்கள்](../01-CoreConcepts/README.md) மாடியூல்களில் தொடங்குங்கள். பின்னர் நிபுணத்துவ மைக்ரோசொப்ட் கருவிகளுடன் இங்கே திரும்பி அதில் கொடுக்கப்பட்ட கருத்துக்களை நடைமுறைப்படுத்திப் பாருங்கள்.
>
> MCP முக்கியத்துவம் குறித்த கூடுதல் விளக்கங்களுக்கு, Maria Naggaga அவர்களின் பதிவைப் பார்க்கவும்: [Connect Once, Integrate Anywhere with MCP](https://devblogs.microsoft.com/blog/connect-once-integrate-anywhere-with-mcps).

## VS Code மற்றும் Visual Studioஇல் MCP தொடங்குவது 🚀

நீங்கள் Visual Studio Code அல்லது Visual Studio 2022 ஐ GitHub Copilot உடன் பயன்படுத்தினால், இந்த MCP சர்வர்களை அமைப்பது எளிது.

### VS Code அமைப்பு

VS Codeக்கான அடிப்படை செயல்முறை இதோ:

1. **உடனடி முகவர் முறை செயல்படுத்தவும்**: VS Codeல், Copilot Chat சாளரத்தில் Agent modeக்கு மாற்றவும்
2. **MCP சர்வர்கள் அமைக்கவும்**: உங்கள் VS Code settings.json கோப்பில் சர்வர் அமைப்புகளை சேர்க்கவும்
3. **சர்வர்கள் துவக்கவும்**: நீங்கள் பயன்படுத்த விரும்பும் ஒவ்வொரு சர்வருக்கும் "தொடக்கம்" பொத்தானை சொடுக்கவும்
4. **கருவிகளை தேர்ந்தெடுக்கவும்**: உங்கள் தற்போது இருக்கட்சியில் எத்தனை MCP சர்வர்களை இயக்க வேண்டும் என்பதை தேர்வு செய்யவும்

விரிவான அமைப்பு வழிமுறைக்காக, [VS Code MCP ஆவணம்](https://code.visualstudio.com/docs/copilot/copilot-mcp) பார்க்கவும்.

> **💡 நிபுணர் குறிப்பு: MCP சர்வர்களை ஒரு நிபுணர் போல நிர்வகிக்கவும்!**
> 
> VS Code விரிவாக்க பார்வையில் இப்போது [நிறைந்த MCP சர்வர்களை நிர்வகிக்க புதிய UI உள்ளது](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! நீங்கள் எந்த MCP சர்வர்களையும் துவக்க, நிறுத்த மற்றும் நிர்வகிக்க எளிய இடைமுகத்துடன் விரைவு அணுகலை பெற்றுள்ளீர்கள். முயற்சித்து பாருங்கள்!

### Visual Studio 2022 அமைப்பு

Visual Studio 2022 (பதிப்பு 17.14 அல்லது அதன் பின்)க்கான:

1. **உடனடி முகவர் முறை செயல்படுத்தவும்**: GitHub Copilot Chat சாளரத்தில் "Ask" விருப்பத்தில் இருந்து "Agent" ஐத் தேர்ந்தெடுக்கவும்
2. **அமைப்பு கோப்பு உருவாக்கவும்**: உங்கள் தீர்வு அடைவில் `.mcp.json` கோப்பை உருவாக்கவும் (மிகவும் பரிந்துரைக்கப்படும் இடம்: `<SOLUTIONDIR>\.mcp.json`)
3. **சர்வர்கள் அமைக்கவும்**: நிலையான MCP வடிவத்தில் உங்கள் MCP சர்வர் கட்டமைப்புகளைச் சேர்க்கவும்
4. **கருவி அங்கீகாரம்**: கேட்கப்பட்ட போது, தேவையான அனுமதிகளுடன் நீங்கள் பயன்படுத்த விரும்பும் கருவி அனுமதிகளை ஒப்புக்கொள்ளவும்

விரிவான Visual Studio அமைப்பு வழிமுறைக்காக, [Visual Studio MCP ஆவணம்](https://learn.microsoft.com/visualstudio/ide/mcp-servers) பார்க்கவும்.

ஒவ்வொரு MCP சர்வரும் தனிப்பட்ட கட்டமைப்பு தேவைகள் (தொடர்பு சரங்கள், அங்கீகாரம், முதலியன) கொண்டிருந்தாலும், IDE இரண்டிலும் அமைப்பு மாதிரிகள் ஒரே மாதிரி.

## மைக்ரோசொப்ட் MCP சர்வர்களிடமிருந்து கற்ற பாடங்கள் 🛠️

### 1. 📚 மைக்ரோசொப்ட் லெர்ன் டாக்ஸ் MCP சர்வர்

[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**இது செய்யும் பணிகள்**: மைக்ரோசொப்ட் லெர்ன் டாக்ஸ் MCP சர்வர், Model Context Protocol மூலம் AI உதவியாளர்களுக்கு மைக்ரோசொப்ட் அதிகாரப்பூர்வ ஆவணங்களை நேரடி அணுகலை வழங்கும் மேகப்பிரதேச சேவையாகும். இது `https://learn.microsoft.com/api/mcp`க்கு இணைகிறது மேலும் மைக்ரோசொப்ட் லெர்ன், அசர் ஆவணங்கள், மைக்ரோசொப்ட் 365 ஆவணங்கள் மற்றும் பிற அதிகாரப்பூர்வ மைக்ரோசொப்ட் ஆதாரங்களில் அர்த்த சற்று ஆராய்ச்சி செய்ய உதவுகிறது.

**கிைன்கும் பயன்கள்**: இது "ஆவணங்கள் மட்டுமே" போல இருக்கலாம் என்றாலும், மைக்ரோசொப்ட் தொழில்நுட்பங்களைக் கையாளும் ஒவ்வொரு டெவலப்பருக்கும் இது முக்கியம். .NET டெவலப்பர்களிடமிருந்து AI குறியீட்டு உதவியாளர்கள் பற்றி மிகப்பெரிய குறைசொற்களில் ஒன்று அவர்கள் சமீபத்திய .NET மற்றும் C# வெளியீடுகளுக்கு புதுப்பிக்கப்பட்டவர்கள் அல்ல என்பது. மைக்ரோசொப்ட் லெர்ன் டாக்ஸ் MCP சர்வர், சமீபத்திய ஆவணங்கள், API குறிப்புக்கள் மற்றும் சிறந்த நடைமுறைகளை நேரடியாக வழங்குவதன் மூலம் இதை தீர்க்கிறது. நீங்கள் சமீபத்திய அசர் SDKகளை பயன்படுத்தினாலும், புதிய C# 13 அம்சங்களை ஆராய்ந்தாலும், Aspire மாதிரிகளைச் செயல்படுத்தினாலும், இந்த சர்வர் உங்கள் AI உதவியாளருக்கு சரியான மற்றும் நவீன குறியீட்டை உருவாக்க அதிகாரப்பூர்வ, தற்போதைய தகவல்களைப் பெற்றிருப்பதை உறுதி செய்கிறது.

**உண்மையான பயன்பாடு**: "அசர் கன்டெய்னர் பயன்பாட்டை அதிகாரப்பூர்வ மைக்ரோசொப்ட் லெர்ன் ஆவணத்துடன் உருவாக்க az cli கட்டளைகள் என்ன?" அல்லது "ASP.NET கோர் இல் Entity Framework ஐ சார்பு ஊழியத்துடன் எவ்வாறு அமைக்க வேண்டும்?" அல்லது "Microsoft Learn ஆவணத்தில் பரிந்துரைக்கப்பட்ட செயல்திறன் வழிகாட்டல்களுடன் இந்த குறியீடு பொருந்துகிறதா என மதிப்பாய்வு செய்." இந்த சர்வர் மிக முன்மாதிரியாக மைக்ரோசொப்ட் லெர்ன், அசர் ஆவணங்கள் மற்றும் மைக்ரோசொப்ட் 365 ஆவணங்களின் விரிவான உள்ளடக்கத்தை சிறந்த அர்த்த ஆராய்ச்சி மூலம் கொடுக்கிறது. அது மேம்பட்ட அர்த்த சார்ந்த தேடலை பயன்படுத்தி, 10 உயர்தர உள்ளடக்க துண்டுகளைக் கட்டுரைகள் தலைப்புகள் மற்றும் URLகளுடன் வழங்குகிறது, எப்போதும் வெளியிடப்படும் சமீபத்திய அதிகாரப்பூர்வ ஆவணங்களை அணுகுகிறது.

**முக்கிய எடுத்துக்காட்டு**: இந்த சர்வர் `microsoft_docs_search` கருவியை வெளிப்படுத்துகிறது, இது மைக்ரோசொப்ட் அதிகாரப்பூர்வ தொழில்நுட்ப ஆவணங்களில் அர்த்த ஆராய்ச்சி செய்கிறது. ஒருமுறை அமைக்கப்பட்ட பிறகு, "ASP.NET கோர் இல் JWT அங்கீகாரத்தை எவ்வாறு செயல்படுத்துவது?" போன்ற கேள்விகளை கேட்டு விரிவான, அதிகாரப்பூர்வ பதில்களை மூல இணையத்தள இணைப்புகளுடன் பெறலாம். தேடல் தரம் சிறந்தது ஏனெனில் அது சூழலை உணர்கிறது – அசர் சூழலில் "கன்டெய்னர்கள்" பற்றி கேட்கும்போது Azure Container Instances ஆவணங்கள் திரும்பப்படும், அதே சொல் .NET சூழலில் அப்போது தொடர்புடைய C# தொகுப்பு தகவல்கள் திரும்பப்படும்.

இது வேகமாக மாறும் அல்லது சமீபத்தில் புதுப்பிக்கப்பட்ட ப ešteiëntenை மற்றும் பயன்பாடுகளுக்கு மிகவும் உதவிகரமாகும். உதாரணமாக, சமீபத்தில் சில குறியீடு திட்டங்களில் Aspire மற்றும் Microsoft.Extensions.AIன் சமீபத்திய வெளியீடுகளில் அம்சங்களை பயன்படுத்த விரும்பினேன். மைக்ரோசொப்ட் லெர்ன் டாக்ஸ் MCP சர்வரைச் சேர்ப்பதால், நான் API ஆவணங்கள் மட்டுமல்ல, தற்போது வெளியிடப்பட்ட நடைமுறைகள் மற்றும் வழிகாட்டல்களையும் அனுபவிக்க முடிந்தது.

### 2. ☁️ அசர் MCP சர்வர்


[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**இது என்ன செய்கிறது**: Azure MCP சர்வர் 15+ சிறப்பு Azure சேவை இணைப்பிகள் கொண்ட விரிவான தொகுப்பு ஆகும், இது முழு Azure சூழலை உங்கள் AI பணிசெயல் ஓட்டத்தில் கொண்டு வருகிறது. இது ஒரு தனி சர்வர் மட்டும் அல்ல – இது வள மேலாண்மை, தரவுத்தள இணைப்பு (PostgreSQL, SQL Server), KQL உடன் Azure கண்காணிப்பு பதிவு பகுப்பாய்வு, Cosmos DB ஒருங்கிணைப்பு மற்றும் பலவற்றை உள்ளடக்கும் சக்திவாய்ந்த தொகுப்பு ஆகும்.

**இது ஏன் பயனுள்ளது**: Azure வளங்களை நிர்வகிப்பதையேத் தவிர, இந்த சர்வர் Azure SDK-களுடன் பணியாற்றும்போது குறியீட்டு தரத்தை முக்கியமாக மேம்படுத்துகிறது. நீங்கள் Azure MCP-ஐ Agent முறையில் பயன்படுத்தும் போது, இது குறியீடு எழுத உதவுவதையே அல்ல – மாற்றாக நீங்கள் *சிறந்த* Azure குறியீட்டை எழுத உதவுகிறது, இது தற்போதைய அங்கீகார மாதிரிகள், பிழை கையாளுதல் சிறந்த நடைமுறைகள் மற்றும் சமீபத்திய SDK அம்சங்களை பின்பற்றுகிறது. இயல்பான குறியீடு பெறுவதற்குப் பதிலாக, உற்பத்தி பணிகளுக்கான Azure பரிந்துரை முறைகளை பின்பற்றும் குறியீடு உங்களுக்கிடையே கிடைக்கும்.

**முக்கிய கூறுகள்**:
- **🗄️ தரவுத்தள இணைப்பிகள்**: Azure Database for PostgreSQL மற்றும் SQL Server க்கு நேரடி இயற்கை மொழி அணுகல்
- **📊 Azure கண்காணிப்பு**: KQL இயக்கிய பதிவு பகுப்பாய்வு மற்றும் செயல்பாட்டு உள்ளதுகளிகள்
- **🌐 வள மேலாண்மை**: முழு Azure வள வாழ்க்கைச்சுழற்சி மேலாண்மை
- **🔐 அங்கீகாரம்**: DefaultAzureCredential மற்றும் மேலாண்மை அடையாள மாதிரிகள்
- **📦 சேமிப்பு சேவைகள்**: Blob Storage, Queue Storage மற்றும் Table Storage செயல்பாடுகள்
- **🚀 கன்டெய்னர் சேவைகள்**: Azure Container Apps, Container Instances மற்றும் AKS மேலாண்மை
- **மற்றும் பல சிறப்பு இணைப்பிகள்**

**உயிரணுக்கான பயன்பாடு**: "என் Azure சேமிப்பு கணக்குகளை பட்டியலிடு", "கடந்த மணி நேரத்தில் பிழைகள் இருப்பதை என் Log Analytics பணியிடத்தில் கேள்விப்பட்டுவிட்டு", அல்லது "சரியான அங்கீகாரத்துடன் Node.js பயன்படுத்தி Azure செயலியை உருவாக்க உதவுக"

**முழு டெமோ காட்சி நிலை**: Azure MCP ஐ GitHub Copilot for Azure விரிவாக்கத்துடன் VS Code இல் இணைத்து அதன் சக்தி எப்படி இருக்கும் என முழுமையான நடைமுறையை இங்கே காணலாம். இரண்டும் நிறுவப்பட்டு பின்வருமாறு கேட்கும்போது:

> "DefaultAzureCredential அங்கீகாரம் பயன்படுத்தி Azure Blob Storage-க்கு ஒரு கோப்பை பதிவேற்ற Python ஸ்கிரிப்ட்டை உருவாக்கு. அந்த ஸ்கிரிப்ட் 'mycompanystorage' என்ற Azure சேமிப்பு கணக்குடன் இணைந்து 'documents' என்ற கன்டெய்னருக்கு பதிவேற்ற வேண்டும், தற்போதைய நேர முத்திரையுடன் ஒரு சோதனை கோப்பை உருவாக்கி அதனை பதிவேற்ற வேண்டும், பிழைகளை நுணுக்கமாக கையாள வேண்டும் மற்றும் விளக்கமான வெளியீட்டை வழங்க வேண்டும், Azure அங்கீகாரத் மற்றும் பிழை கையாளல் சிறந்த நடைமுறைகளை பின்பற்ற வேண்டும், DefaultAzureCredential அங்கீகாரத்தின் செயல்பாட்டை விளக்கும் கருத்துக்களை உள்ளடக்க வேண்டும் மற்றும் ஸ்கிரிப்ட்டை சீரிய வகையில் செயல்பாடுகள் மற்றும் ஆவணப்பதிவுகளுடன் உருவாக்க வேண்டும்."

Azure MCP சர்வர் முழுமையான, உற்பத்தி தயாரான Python ஸ்கிரிப்ட்டை உருவாக்கும்:
- சமீபத்திய Azure Blob Storage SDK-வை சரியான அசிங்க் நடைமுறைகளுடன் பயன்படுத்துகிறது
- DefaultAzureCredential ஐ முழுமையான மறுபிரவேச சங்கிலி விளக்கத்துடன் செயல்படுத்துகிறது
- குறிப்பிட்ட Azure இடர்பாடுகள் வகைகளை உட்பட வலுவான பிழை கையாளலை கொண்டுள்ளது
- Azure SDK சிறந்த நடைமுறைகளை வள மேலாண்மை மற்றும் இணைப்பு கையாளலில் பின்பற்றுகிறது
- விரிவான பதிவு மற்றும் விளக்கமான கான்சோல் வெளியீட்டை வழங்குகிறது
- செயல்பாடுகள், ஆவணங்கள் மற்றும் வகை குறித்த குறிப்புகளுடன் முறையாக கட்டமைக்கப்பட்ட ஸ்கிரிப்ட்டை உருவாக்குகிறது

இதன் சிறப்பு என்னவெனில் Azure MCP இல்லாமல், நீங்கள் இயல்பான blob storage குறியீட்டையே பெறுவீர்கள், இது தற்போதைய Azure மாதிரிகளுக்கு பொருந்தாததாக இருக்க கூடும். Azure MCP உடன், நீங்கள் சமீபத்திய அங்கீகார முறைகளை பயன்படுத்தி, Azure-சிறப்பு பிழை சூழ்நிலைகளை கையாளும் மற்றும் Microsoft பரிந்துரை செய்த உற்பத்தி பயன்பாட்டு நடைமுறைகளை பின்பற்றும் குறியீட்டை பெறுவீர்கள்.

**உதாரணம்**: நான் `az` மற்றும் `azd` CLI-களின் குறிப்பிட்ட கட்டளைகளை நினைவில் வைக்க கஷ்டப்பட்டேன். எனக்கு எப்போதும் இரண்டு படி செயல்முறை உள்ளது: முதலில் உருவத்திற்கு பாருங்கள், பின்னர் கட்டளையை இயக்குங்கள். எனக்கு CLI பதிவு வசதி நினைவில் இல்லாததால் பெரும்பாலும் போர்டலை திறந்து கிளிக் செய்வதையே நான் தேர்ந்தெடுக்கிறேன். நான் என்னை நினைவில் கொள்ள முடியவில்லை என நினைத்துக் காட்ட விரும்பவில்லை! நான் என்ன வேண்டுமென்று சொல்வது அதிசயம், மேலும் அதை IDE-வைக் எடுக்காமல் செய்தல் கூட சிறப்பு.

தொடங்க Azure MCP சேமிப்பகத்தில் ([Azure MCP repository](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server)) கையாள எளிய பயன்பாடுகள் பட்டியலை காணலாம். விரிவான நிறுவல் வழிகாட்டிகள் மற்றும் மேம்பட்ட மாற்ற மீதான விருப்பங்களுக்கு அதிகாரப்பூர்வ Azure MCP ஆவணங்களை ([official Azure MCP documentation](https://learn.microsoft.com/azure/developer/azure-mcp-server/)) பார்வையிடவும்.

> GitHub MCP சர்வரை GitHub Coding Agent-ன் (தானியங்கி குறியீட்டு பணிகளுக்காக பிரச்சினைகள் ஒதுக்கப்படும் AI ஏஜென்ட்)混淆ப்பட வேண்டாம். GitHub MCP சர்வர் VS Code-இன் Agent முறையில் GitHub API இணைப்பை வழங்குகிறது; ஆனால் GitHub Coding Agent என்பது தனி அம்சமாக, GitHub பிரச்சினைகளுக்கு ஒதுக்கப்படும் போது பூல் கோரிக்கைகளை உருவாக்குகிறது.

**முக்கிய திறன்கள்**:
- **⚙️ GitHub செயல்கள்**: முழுமையான CI/CD குழாய் மேலாண்மை, பணிசெயல் கண்காணிப்பு, மற்றும் இயக்கப் பிறப்புகள் கையாளல்
- **🔀 பூல் கோரிக்கைகள்**: உருவாக்கு, மதிப்பாய்வு செய், இணைக்கவும், மற்றும் விரிவான நிலை கண்காணிப்புடன் PRகளை நிர்வகிக்கவும்
- **🐛 பிரச்சினைகள்**: முழுமையான பிரச்சினை வாழ்க்கைச்சுழற்சி மேலாண்மை, கருத்திடல், லேபிளிடல், மற்றும் நியமனங்கள்
- **🔒 பாதுகாப்பு**: குறியீடு ஸ்கேனிங் எச்சரிக்கைகள், ரகசிய கண்டறிதல், மற்றும் Dependabot ஒருங்கிணைப்பு
- **🔔 அறிவிப்புகள்**: புத்திசாலி அறிவிப்பு மேலாண்மை மற்றும் சேமிப்பகம் சந்தா கட்டுப்பாடு
- **📁 சேமிப்பகம் மேலாண்மை**: கோப்பு செயல்பாடுகள், கிளை மேலாண்மை, மற்றும் சேமிப்பக நிர்வாகம்
- **👥 ஒத்துழைப்பு**: பயனர் மற்றும் நிறுவன தேடல், குழு மேலாள்மை மற்றும் அணுகல் கட்டுப்பாடு

**உயிரணுக்கான பயன்பாடு**: "என் பண்புக் கிளையிலிருந்து பூல் கோரிக்கை உருவாக்கு", "இந்த வாரம் தோல்வி கண்ட அனைத்து CI ஓட்டங்களையும் காட்டு", "என் சேமிப்பகங்களுக்கு திறந்திருக்கும் பாதுகாப்பு எச்சரிக்கைகளை பட்டியலிடு" அல்லது "என் நிறுவனங்கள் முழுவதிலும் என்னிடம் ஒதுக்கப்பட்ட அனைத்து பிரச்சினைகளையும் கண்டுபிடி"

**முழு டெமோ காட்சிநிலை**: GitHub MCP சர்வர் திறன்களை காட்டும் சக்திவாய்ந்த பணிசெயல்:

> "எங்கள் ஸ்பிரிண்ட் மதிப்பாய்வுக்கு தயாராக வேண்டும். நான் இந்த வாரம் உருவாக்கிய அனைத்து பூல் கோரிக்கைகளையும் காட்டவும், CI/CD குழாய் நிலையை சரிபார்க்கவும், நாம் சமாளிக்க வேண்டிய எந்த பாதுகாப்பு எச்சரிக்கைகளின் சுருக்கத்தை உருவாக்கவும், 'feature' லேபிளுடன் இணைக்கப்பட்ட PRகளின் அடிப்படையில் வெளியீட்டு குறிப்புகளை தயார் செய்ய எனக்கு உதவவும்."

GitHub MCP சர்வர்:
- விரிவான நிலைத் தகவலுடன் உங்கள் சமீபத்திய பூல் கோரிக்கைகளை கேள்விப்படுக
- பணிசெயல் ஓட்டங்களை பகுப்பாய்வு செய்து எந்த தோல்விகள் அல்லது செயல்திறன் சிக்கல்களை வெளிப்படுத்துக
- பாதுகாப்பு ஸ்கேனிங் முடிவுகளை தொகுத்து முக்கிய எச்சரிக்கைகள் முன்னுரிமையிடுக
- இணைக்கப்பட்ட PR-களிலிருந்து தகவலை எடுத்து முழுமையான வெளியீட்டு குறிப்புகளை உருவாக்குக
- ஸ்பிரிண்ட் திட்டமிடல் மற்றும் வெளியீட்டு தயாரிப்புக்கு செயல்விளைவான அடுத்த படிகள் வழங்குக

**உதாரணம்**: நான் இதை குறியீடு மதிப்பாய்வு பணிகளுக்கு விரும்புகிறேன். VS Code, GitHub அறிவிப்புகள் மற்றும் பூல் கோரிக்கை பக்கங்களுக்கு இடையில் கிளம்பாமல், "என் மதிப்பாய்வுக்கு காத்திருக்கும் அனைத்து PRகளையும் காட்டு" மற்றும் பிறகு "PR #123 இல் உள்ள அங்கீகார முறையின் பிழை கையாளல் பற்றி ஒரு கருத்தைச் சேர்க்கவும்" என்று கூறி முடியும். சர்வர் GitHub API அழைப்புகளை கையாளுகிறது, உரையாடல் எண்ணங்களை வைத்திருக்கிறது மற்றும் மேலும் பொருத்தமான மதிப்பாய்வுக் கருத்துக்கள் உருவாக்கத்திலும் உதவுகிறது.

**அங்கீகார விருப்பங்கள்**: சர்வர் OAuth (VS Code-இல் சிறந்த இன்டிக்ரேஷன்) மற்றும் வியாபாரி அணுகல் குறிச்சொற்களை ஆதரிக்கிறது, தேவையான GitHub செயல்பாட்டை மட்டுமே இயக்க கூடிய கருவி தொகுப்புகளுடன். உடனடி அமைப்புக்காக தொலைபார்வை சேவையாக அல்லது முழுமையான கட்டுப்பாட்டுக்காக உள்ளக Docker மூலம் இயக்கலாம்.

> **💡 சிறந்த குறிப்புரை**
> 
> உங்கள் MCP சர்வர் அமைப்புகளில் `--toolsets` அளவுருவை கட்டமைத்து தேவையான கருவி தொகுப்புகளை மட்டுமே இயக்கி, விவர சைகையை குறைத்து AI கருவிகளின் தேர்வை மேம்படுத்துங்கள். உதாரணமாக, முக்கிய மேம்பாட்டு பணிசெயல்களுக்கு `"--toolsets", "repos,issues,pull_requests,actions"` சேர்க்கவும் அல்லது முக்கியமாக GitHub கண்காணிப்பு திறன்களுக்கு `"--toolsets", "notifications, security"` பயன்படுத்துங்கள்.

MarkItDown முக்கிய ஆவண அமைப்புகளை (தலைப்புகள், பட்டியல்கள், அட்டவணைகள் மற்றும் இணைப்புகள் போன்றவை) பாதுகாக்கும் பதிலுக்கு, பல்வேறு கோப்பு வடிவங்களையும் கையாள்கிறது. எளிய உரை எடுக்கல் கருவிகள் போல இல்லாமல், இது AI செயலாக்கத்துக்கும் மனித வாசனைக்குமான அர்த்தப்பூர்வமான பொருளை மற்றும் வடிவமைப்பை பேணுவதில் கவனம் செலுத்துகிறது.

**ஆதரிக்கப்படும் கோப்பு வடிவுகள்**:
- **அலுவலக ஆவணங்கள்**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)

- **தரவு வடிவங்கள்**: CSV, JSON, XML, ZIP கோப்புகள் (உள்ளடக்கங்களை முறையாக செயலாக்குகிறது)

**மேம்பட்ட திறன்கள்**: MarkItDown LLM-ஆல் இயக்கப்படும் பட விவரணைகளை (OpenAI கிளையண்டுடன் வழங்கியிருந்தால்), மேம்பட்ட PDF செயலாக்கத்துக்கான Azure ஆவண நுண்ணறிவு, உரை உள்ளடக்கம் ஒலி மாற்றத்தைக் கொடுக்கும் மற்றும் கூடுதல் கோப்பு வடிவங்களை кеңட்ட உதவும் பிளக்-இன் அமைப்பையும் ஆதரிக்கிறது.

**உயிரூட்டும் பயன்பாடு**: "இந்த PowerPoint வழங்கலை நமது ஆவண தளத்திற்கான மார்க்டவுனாக மாற்று", "இந்த PDF இல் சரியான தலைப்பு கட்டமைப்புடன் உரையை எடு", அல்லது "இந்த Excel ஸ்பிரெட்ஷீட்டை வாசிக்கக்கூடிய அட்டவணை வடிவமாக மாற்று"

**காணொலி எடுத்துக்காட்டு**: [MarkItDown ஆவணங்கள்](https://github.com/microsoft/markitdown#why-markdown) இல் கூறப்பட்டதுபோல்:

> மார்க்டவுன் மிகவும் சுத்தமான உரையைப் போல உள்ளது, குறைந்த மார்க்அப் அல்லது வடிவமைப்புடன், ஆனால் முக்கிய ஆவண அமைப்பை பிரதிநிதித்துவம் செய்ய வழியைக் கொடுக்கும். OpenAI இன் GPT-4 போன்ற பிரதான LLM கள் மார்க்டவுனில் "தொடர்ந்து பேசுகின்றன", மற்றும் பெரும்பாலும் பங்கீடு செய்யாமல் மார்க்டவுனை பதில்களில் சேர்க்கின்றன. இதன் பொருள், அவை பரந்த அளவிலான மார்க்டவுன் வடிவமைக்கப்பட்ட உரையில் பயிற்சி பெற்றிருக்கின்றன மற்றும் அதை நன்கு புரிந்து கொண்டுள்ளன. கூடுதலாக, மார்க்டவுன் விதிகள் மிகவும் குறைவான டோக்கன் பயன்பாட்டைக் கொண்டவை.

MarkItDown ஆவண அமைப்பை பாதுகாப்பதில் சிறந்தது, இது AI வேலைபாடுகளுக்கு முக்கியம். உதாரணமாக, PowerPoint வழங்கலை மாற்றும் பொழுது, இது சரியான தலைப்புக்களுடன் ஸ்லைடு ஒழுங்கை காக்கிறது, அட்டவணைகளை மார்க்டவுன் அட்டவணைகளாக எடுத்து வைக்கிறது, படங்களுக்கான மாற்று உரையை சேர்க்கிறது, மற்றும் பேச்சாளர் குறிப்பு களையும் செயலாக்குகிறது. வரைபடங்கள் வாசிக்கக்கூடிய தரவு அட்டவணைகளாக மாற்றப்படுகின்றன, மற்றும் இறுதியான மார்க்டவுன் அசல் வழங்கலின் தர்க்க முறைப்பாட்டை பேணுகிறது. இது AI அமைப்ப்களில் வழங்கல் உள்ளடக்கத்தை உள்ளிடுவதைச் சிறக்கிறது அல்லது ஏற்கனவே உள்ள ஸ்லைட்களில் இருந்து ஆவணங்களை உருவாக்குவதற்கே சிறந்தது.

**எதை செய்கிறது**: Microsoft 365 மற்றும் Microsoft 365 Copilot உடன் ஒருங்கிணைக்கும் AI முகவர்கள் மற்றும் செயலிகளை உருவாக்க அவர்களுக்கு தேவையான கருவிகளை, க_SCHEMA சரிபார்ப்பு, மாதிரி குறியிடல் பெற்றல், மற்றும் பிழைதிருத்த உதவியுடன் வழங்குகிறது.

**ஏன் இது பயனுள்ளதாக உள்ளது**: Microsoft 365 மற்றும் Copilot க்கான கட்டுமானம் சிக்கலான மானிபெஸ்ட் தரவமைப்புகளையும் குறிப்பிட்ட அபிவிருத்தி முறைகளையும் உட்படுத்துகிறது. இந்த MCP சர்வர் முக்கியமான அபிவிருத்தி வளங்களை நேரடியாக உங்கள் குறியிடும் சுற்றுச்சூழலில் கொண்டு வருகிறது, நீங்கள் சீர்மானங்களை சரிபார்க்க, மாதிரி குறியிடலை கண்டறிய, வழக்கமான பிரச்சனைகளை புதுப்பிக்க ஆவணங்களை தொடர்ந்து பார்க்காமல் உதவுகிறது.

**உண்மை உலக பயன்பாடு**: "என் அறிவிக்க விபரக்குறிப்பை சரிபார்க்கவும், எவ்வித சீர்மான பிழைகளையும் சரி செய்யவும்", "Microsoft Graph API பிளக்கின் செயல்படுத்த மாதிரி குறியிடலை காண்பி", அல்லது "என் Teams செயலி அங்கீகார பிரச்சனைகளை புதுப்பிக்க உதவி செய்"

**நிகழ்ச்சி உதாரணம்**: Build நிகழ்ச்சியில் M365 முகவர்களைப் பற்றி நண்பர் John Miller உடன் பேசிய பிறகு நான் அவரிடம் அணுகியபோது, அவர் இந்த MCP ஐ பரிந்துரைத்தார். இது ஆவணங்களில் மூழ்காமல் துவங்க வசதியாக் கருவிகள், மாதிரி குறியிடல்கள் மற்றும் கட்டமைப்புகளை வழங்கி புதிய M365 முகவர் அபிவிருத்தியாளர்களுக்கு சிறந்தது. சீர்மான சரிபார்ப்பு அம்சங்கள், மானிபெஸ்ட் கட்டடத்தின் பிழைகளை தவிர்க்க உதவுவதில் சிறப்பு.

## 📋 முடிவுரை

மாதிரி பரிமாற்ற ஒப்பந்தம் (MCP) அபிவிருத்தியாளர்கள் AI உதவியாளர்கள் மற்றும் வெளி கருவிகளுடன் எப்படி தொடர்பு கொள்கிறார்கள் என்பதைக் மாற்றி உள்ளது. இந்த 10 Microsoft MCP சர்வர்கள் ஒருங்கிணைந்த AI ஒருங்கிணைப்பின் சக்தியை விளக்குகின்றன, அதனால் அபிவிருத்தியாளர்கள் சக்திவாய்ந்த வெளி திறன்களை அணுகும் போது தங்களது உருவாக்கு நிலையை கைவிடாமல் தொடர்வதற்கான வழிமுறைகளை வழங்குகின்றன.

முழுமையான Azure சூழல் ஒருங்கிணைப்பு முதல், Playwright போன்ற உலாவி இயக்கு கருவிகள் மற்றும் MarkItDown போன்ற ஆவண செயலாக்க தனிச்சிறப்புக் கருவிகள் வரை, இச்சர்வர்கள் பல்வேறு அபிவிருத்தி சூழல்களில் MCP எப்படி உற்பத்தித்திறனைக் உயர்த்த முடியும் என்பதைக் காட்டுகின்றன. ஒருங்கிணைந்த ஒப்பந்தம் இந்தக் கருவிகள் ஒன்றிணைந்து செயல்படுவதற்கான ஒரு ஒற்றுமையான அபிவிருத்தி அனுபவத்தை உருவாக்க காப்பாற்றுகிறது.

MCP சூழல் தொடர்ந்தும் மேம்படும்போது, சமூகத்துடன் பங்குபெற்றல், புதிய சர்வர்களை ஆராய்ச்சி செய்தல், மற்றும் தனிப்பயன் தீர்வுகளை உருவாக்கல் உங்கள் அபிவிருத்தி உற்பத்தித்திறனை அதிகரிக்க முக்கியமாக இருக்கும். MCP இன் திறந்த நிலை பாத்திரம், நீங்கள் பல்வேறு விற்பனையாளர்களின் கருவிகளை கலப்பதையும் ஒருங்கிணைப்பதையும், உங்கள் தேவைக்கேற்ப சிறந்த வேலைமுறையை உருவாக்குவதையும் அனுமதிக்கும்.
