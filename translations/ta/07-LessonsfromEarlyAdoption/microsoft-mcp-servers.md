## 🎯 இந்த வழிகாட்டலில் நீங்கள் என்ன கற்றுக்கொள்ளப்போகிறீர்கள்

இந்த நடைமுறையாளி வழிகாட்டல் புதியவையாக செயல்படும் பத்து மைக்ரோசாப்ட் MCP சர்வர்களை காண்பிக்கிறது, அவை உருவாக்குநர்கள் AI உதவியாளர்களுடன் எப்படி வேலை செய்கிறார்கள் என்பதை மாற்றி வருகிறன. MCP சர்வர்கள் *என்ன செய்யக்கூடியவை* என்பதை விளக்கும் பதிலுக்கு பதிலாக, நாம் பிற நிறுவனங்களுக்கும் மைக்ரோசாப்ட்டின் தினசரி உருவாக்க பணிகளுக்கு உண்மையான மாற்றத்தை முன்னெடுத்து வருகின்ற சர்வர்களைக் காண்பிப்போம்.

இந்த வழிகாட்டலில் உள்ள ஒவ்வொரு சர்வரும் உண்மை உலகில் பயன்பாடு மற்றும் உருவாக்குநர் கருத்துக்களை அடிப்படையாகக் கொண்டு தேர்ந்தெடுக்கப்பட்டுள்ளன. நீங்கள் ஒவ்வொரு சர்வரும் என்ன செய்கிறது என்பதைக் காண்பீர்கள் மட்டுமல்லாமல், அது ஏன் முக்கியம் மற்றும் உங்களுடைய திட்டங்களில் அதனை முழுமையாக எப்படி பயன்படுத்துவது என்பதையும் புரிந்துகொள்ளப்போகிறீர்கள். நீங்கள் MCP இல் புதியவராயினும் அல்லது உங்களுடைய நிலவிருத்தியை விரிவாக்க விரும்பினாலும், இத்தகைய சர்வர்கள் மைக்ரோசாப்ட் சூழலில் கிடைக்கும் மிகவும் நடைமுறையான மற்றும் தாக்கம் வாய்ந்த கருவிகளாக உள்ளன.

## கண்ணோட்டம்

இந்த விரிவான வழிகாட்டல் பத்து மைக்ரோசாப்ட் MCP சர்வர்களைப் பற்றியது, அவை உருவாக்குநர்கள் AI உதவியாளர்களுடன் மற்றும் வெளிப்புற கருவிகளுடன் எவ்வாறு பணியாற்றுகிறார்கள் என்பதை மாற்றுகின்றன. Azure வள மேலாண்மை முதல் ஆவண செயலாக்கம் வரை இந்த சர்வர்கள் Model Context Protocol இன் சக்தியைக் காட்டுகின்றன, சரியான, பயனுள்ள உருவாக்க பணிமுறைகளை உருவாக்குகின்றன.

## கற்றல் குறிக்கோள்கள்

இந்த வழிகாட்டலின் முடிவில், நீங்கள்:
- MCP சர்வர்கள் உருவாக்குநர் உற்பத்தித் திறனை எவ்வாறு மேம்படுத்துகின்றன என்பதை புரிந்துகொள்வீர்கள்
- மைக்ரோசாப்ட் மிக முக்கியமான MCP சர்வர் நடைமுறைகளை கற்றுக்கொள்ளவும்
- ஒவ்வொரு சர்வருக்குமான நடைமுறை பயன்பாடுகளை அறிக
- VS Code மற்றும் Visual Studio இல் இந்த சர்வர்களை அமைத்து கட்டமைப்பதை அறிக
- MCP சூழல் மற்றும் எதிர்கால தொலைவுகளைக் கோருங்கள்

## 🔧 MCP சர்வர்களை புரிந்துகொள்வது: ஆரம்பநிலை வழிகாட்டி

### MCP சர்வர்களென்ன?

Model Context Protocol (MCP) இல் நீங்கள் புதியவராக இருப்பீர்கள், "MCP சர்வர் என்றால் என்ன? நான் ஏன் கவனிக்க வேண்டும்?" என்று கேட்கலாம். சாதாரண ஒப்புமையால் தொடங்குவோம்.

MCP சர்வர்கள் உங்கள் AI கோடிங் தோழி (GitHub Copilot போன்ற) பிற கருவிகளுக்கும் சேவைகளுக்கும் இணைவதற்கு உதவுகிற சிறப்பு உதவியாளர்கள் போன்று நினைத்துக் கொள்ளுங்கள். உங்கள் கைபேசியில் வெவ்வேறு செயலிகளை உருவாக்கும் போல் – ஒரு செயலி வானிலை, மற்றொன்று வழிசெலுத்தல், மற்றொன்று வங்கிப் பணிகள் – MCP சர்வர்கள் உங்கள் AI உதவியாளர்களுக்கு வெவ்வேறு உருவாக்க கருவிகள் மற்றும் சேவைகளுடன் தொடர்பு கொள்ள உதவுகின்றன.

### MCP சர்வர்கள் விளக்கிக்கொள்ளும் பிரச்சினை

MCP சர்வர்களுக்கு முன்பு, நீங்கள்:
- Azure வளங்களை சரிபார்க்கலாம்
- GitHub பிரச்சனைகளை உருவாக்கலாம்
- தரவுத்தளத்தை கேள்வி செய்யலாம்
- ஆவணங்களை தேடலாம்

நீங்கள் கோடிங் நிறுத்தி, உலாவியைத் திறந்து, தொடர்புடைய இணையதளத்திற்கு செல்ல பிறிந்துவிட்டு, இச்செயல்களை கைமுறை செய்யவேண்டும். இந்த தொடர்ச்சியான சூழல் மாற்றம் உங்கள் ஓட்டத்தை முறித்துவிடும் மற்றும் உற்பத்தித் திறனை குறைக்கும்.

### MCP சர்வர்கள் உங்கள் உருவாக்க அனுபவத்தை எப்படி மாற்றுகின்றன

MCP சர்வர்களுடன், நீங்கள் உங்கள் உருவாக்க சூழலில் (VS Code, Visual Studio போன்றவை) இருக்கும்போது உங்கள் AI உதவியாளரிடம் இச்செயல்களைச் செய்ய கேட்டுக்கொள்ளலாம். உதாரணமாக:

**பாரம்பரிய பணிமுறை பதிலாக:**
1. கோடிங் நிறுத்துதல்
2. உலாவி திறக்குதல்
3. Azure போர்டலை நோக்கி செல்லுதல்
4. சேமிப்பகம் கணக்கு விவரங்களைத் தேடுதல்
5. VS Code க்கு திரும்புதல்
6. கோடிங் தொடக்கம்

**நீங்கள் இப்போது இது செய்யலாம்:**
1. AI ஐ கேட்டுக்கொள்ளுங்கள்: "என் Azure சேமிப்பகம் கணக்குகளின் நிலை என்ன?"
2. வழங்கப்பட்ட தகவலுடன் கோடிங் தொடருங்கள்

### புதுமுகர்கள் க்கு முக்கிய நன்மைகள்

#### 1. 🔄 **உங்கள் ஓட்ட நிலையை பாதிக்காமல் இருக்கவும்**
- பல செயலிகளுக்கிடையில் மாறுவதில்லை
- நீங்கள் எழுதும் குறியீட்டில் கவனம் சேமிக்கவும்
- வெவ்வேறு கருவிகளை மேலாண்மை செய்வதில் மன அழுத்தம் குறைக்கவும்

#### 2. 🤖 **சிக்கலான கட்டளைகள் பதிலாக இயல்புநிலை மொழியைப் பயன்படுத்தவும்**
- SQL சொற்றொடர் நினைவில் வைக்க வேண்டியதற்கு பதிலாக தேவையான தரவுகளை விவரிக்கவும்
- Azure CLI கட்டளைகள் நினைவில் வைக்கவேண்டியதற்கு பதிலாக எதனை சாதிக்கவேண்டும் என்று விளக்கவும்
- தொழில்நுட்ப விவரங்களை AI கையால் கையாளுங்கள் நீங்கள் தர்க்கத்தில் கவனம் செலுத்துங்கள்

#### 3. 🔗 **பல கருவிகளை இணைக்கவும்**
- வெவ்வேறு சேவைகளை இணைத்து சக்திவாய்ந்த பணிமுறைகளை உருவாக்கவும்
- உதாரணம்: "அனைத்து சமீபத்திய GitHub பிரச்சனைகளைப் பெறவும், தொடர்புடைய Azure DevOps வேலைப் பொருட்களை உருவாக்கவும்"
- கைவிடும் குறியீடு இல்லாமல் தானாக செயல் படுத்தல் உருவாக்கவும்

#### 4. 🌐 **விரிவடையும் சூழலை அணுகவும்**
- மைக்ரோசாப்ட், GitHub மற்றும் பிற நிறுவனங்கள் கட்டிய சர்வர்களில் இருந்து பலனை பெறுங்கள்
- வெவ்வேறு விற்பனையாளர்களின் கருவிகளை கலக்கவும்
- பல AI உதவியாளர்களின் கீழ் வேலை செய்யும் ஒற்றுமையான சூழல் சேருங்கள்

#### 5. 🛠️ **செய்துகொண்டே கற்றுக்கொள்ளவும்**
- முன்பதிவேற்றப்பட்ட சர்வர்களின் உதவியுடன் கருத்துக்களைப் புரிந்துகொள்ளவும்
- அசைவற்றவாறு உங்கள் சொந்த சர்வர்களை கட்டமைக்க தொடரவும்
- கிடைக்கும் SDK கள் மற்றும் ஆவணங்களை பயன்படுத்தி கற்றலை வழிநடத்தவும்

### புதுமுகர்களுக்கான உண்மையான உலக எடுத்துக்காட்டு

உங்களின் முதல் வலை உருவாக்கத் திட்டத்தில் புதியவரென நினைத்துக் கொள்ளுங்கள். MCP சர்வர்கள் உதவுவது எப்படி என்பதை காண்போம்:

**பாரம்பரிய அணுகுமுறை:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP சர்வர்களுடன்:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### ஏற்ற உயர்நிலை நம்பிக்கை

MCP ஒரு துறையில் பரவலாக ஏற்றுக்கொள்ளப்பட்ட நிலைமை ஆகி வரும், அதனால்:
- **ஒற்றுமை**: வெவ்வேறு கருவிகள் மற்றும் நிறுவனங்களில் ஒத்த அனுபவம்
- **இணக்குமுறை**: வெவ்வேறு விற்பனையாளர்களின் சர்வர்கள் ஒன்றாக வேலை செய்கின்றன
- **எதிர்கால பாதுகாப்பு**: திறமைகள் மற்றும் அமைப்புகள் வெவ்வேறு AI உதவியாளர்களுக்கு மாற்றப்படும்
- **சហஜனம்**: பகிர்ந்த அறிவும் வளங்களும் கொண்ட பெரிய சூழல்

## VS Code மற்றும் Visual Studio இல் MCP உடன் தொடங்குதல் 🚀

### VS Code அமைப்பு

VS Code க்கான அடிப்படைக் செயல்முறை:

1. **ஏஜென்ட் முறை இயக்கவும்**: VS Code இல் Copilot Chat சாளரத்தில் ஏஜென்ட் முறைக்கு மாறவும்
2. **MCP சர்வர்கள் அமைக்கவும்**: உங்கள் VS Code settings.json கோப்பில் சர்வர் அமைப்புகளை சேர்க்கவும்
3. **சர்வர்களைத் தொடங்கவும்**: பயன்படுத்த நினைக்கும் ஒவ்வொரு சர்வருக்கும் "தொடங்கு" பொத்தானை கிளிக் செய்யவும்
4. **கருவிகளை தேர்ந்தெடுக்கவும்**: தற்போதைய அமர்வுக்கு எந்த MCP சர்வர்களை இயக்கவேண்டும் என்று தேர்வு செய்யவும்

விரிவான அமைப்பு வழிகாட்டிகளுக்கு [VS Code MCP ஆவணங்களை](https://code.visualstudio.com/docs/copilot/copilot-mcp) பார்க்கவும்.

> **💡 நிபுணர் குறிப்புகள்: MCP சர்வர்களை திறமையாக நிர்வகிக்கவும்!**
> 
> VS Code நீட்டிப்புக்களில் இனி [நிறுவப்பட்ட MCP சர்வர்கள் நிர்வகிப்பதற்கான நவீன UI](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode) உள்ளது! எளிமையான இடைமுகத்தில் எந்த MCP சர்வர் தொடங்க, நிறுத்த, நிர்வகிக்க விரைவாக அணுகல் கிடைக்கும். முயற்சி செய்யுங்கள்!

### Visual Studio 2022 அமைப்பு

Visual Studio 2022 (பதிப்பு 17.14 அல்லது பின்னர்) க்கான அமைப்பு:

1. **ஏஜென்ட் முறை இயக்கவும்**: GitHub Copilot Chat சாளரத்தில் "Ask" பட்டியை கிளிக் செய்து "Agent" தேர்ந்தெடுக்கவும்

Visual Studio அமைப்புக்கான விரிவான வழிகாட்டி [Visual Studio MCP ஆவணங்களில்](https://learn.microsoft.com/visualstudio/ide/mcp-servers) உள்ளது.

ஒவ்வொரு MCP சர்வருக்கும் தனித்தனியான அமைப்பு தேவைகள் (இணைப்பு தொடர்கள், அங்கீகாரம்) இருப்பினும், இரண்டு IDE களிலும் அமைப்பு முறை ஒன்றே.

### 1. 📚 மைக்ரோசாப்ட் லெர்ன் ஆவணங்கள் MCP சர்வர்

[![VS Code இல் நிறுவுக](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![VS Code இன்சைடர்சில் நிறுவுக](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**என்ன செய்கிறது**: மைக்ரோசாப்ட் லெர்ன் ஆவணங்கள் MCP சர்வர் என்பது மேகத்தில் ஹோஸ்ட் செய்யப்பட்ட சேவை ஆகும், இது AI உதவியாளர்களுக்கு மாபெரும் நேரத்தில் அதிகாரபூர்வ மைக்ரோசாப்ட் ஆவணங்களுக்கு அணுகலை வழங்க Model Context Protocol ஐப் பயன்படுத்துகிறது. இது `https://learn.microsoft.com/api/mcp` உடன் இணைந்து Microsoft Learn, Azure ஆவணங்கள், Microsoft 365 ஆவணங்கள் மற்றும் பிற அதிகாரபூர்வ மைக்ரோசாப்ட் மூலங்களின் அர்த்தமாக்கப்பட்ட தேடலை எளிதாக்குகிறது.

**ஏன் இது பயனுள்ளது**: இது "மட்டுமல்ல ஆவணங்கள்" என்பது போல தோன்றினாலும், மைக்ரோசாப்ட் தொழில்நுட்பங்களை பயன்படுத்தும் ஒவ்வொரு உருவாக்குநருக்கும் மிக முக்கியமானது. .NET உருவாக்குநர்கள் AI குறியீடு உதவியாளர்களைப் பற்றி பெரிதும் புகாரளிக்கிறார்கள் அவை சமீபத்திய .NET மற்றும் C# வெளியீடுகளை அறியவில்லை என்று. மைக்ரோசாப்ட் லெர்ன் ஆவணங்கள் MCP சர்வர் இந்த பிரச்சினையை தீர்க்கிறது – சூழல் நேரத்தில் அருகிலுள்ள ஆவணங்களை, API குறிப்புகளையும் சிறந்த நடைமுறைகளையும் வழங்குகிறது. நீங்கள் சமீபத்திய Azure SDK களோடு பணியாற்றினாலும், புதிய C# 13 அம்சங்களை ஆராய்ந்தாலும், Aspire முறைகளை செயல்படுத்தினாலும், இந்த சர்வர் உங்கள் AI உதவியாளரின் துல்லியமான, நவீன குறியீட்டை உருவாக்க அதிகாரபூர்வ, சமீபத்திய தகவல்களை வழங்கும் என்பதில் உறுதி அளிக்கிறது.

**உண்மை உலக பயன்பாடு**: "அகர அகிலத்தில் Azure கொண்டெய்னர் செயலி உருவாக்க az cli கட்டளைகள் என்ன?" அல்லது "ASP.NET Core இல் Entity Framework ஐ dependency injection உடன் எப்படி அமைக்கிறேன்?" அல்லது "இந்த குறியீடு Microsoft Learn ஆவணங்களில் வாய்ப்பு பரிந்துரைகளுக்கு ஏற்ப இருக்கிறதா எனப் பார்க்கவும்." சர்வர் Microsoft Learn, Azure ஆவணங்கள் மற்றும் Microsoft 365 ஆவணங்களை விரிவாக semantic தேடல் மூலம் சம்பந்தப்பட்ட தெளிவான தகவல்களை கண்டு பிடிக்கிறது. இது குறைந்தபட்சம் 10 உயர்தர உள்ளடக்க பொருட்களை தலைப்புத் தலைப்பும் URL களுடன் வழங்குகிறது, வெளியிடப்பட்ட சமீபத்திய ஆவணங்களுக்கே எப்போதும் அணுகுகிறது.

**நிர்வாக எடுத்துக்காட்டு**: சர்வர் Microsoft ஐயியின் அதிகாரப்பூர்வ தொழில்நுட்ப ஆவணங்களை semantic தேடல் செய்யும் `microsoft_docs_search` கருவியை வெளிப்படுத்துகிறது. ஒருமுறை அமைப்பின் பிறகு, நீங்கள் "ASP.NET Core இல் JWT authentication ஐ எப்படி செயல்படுத்துவது?" போன்ற கேள்விகள் கேட்கலாம் மற்றும் விரிவான, அதிகாரப்பூர்வ பதில்களுடன் மூல இணைப்புகளைக் பெறலாம். தேடும் தரம் மிகவும் சிறந்தது, மையத்தை புரிந்து கொள்கிறது – உதாரணமாக Azure சூழலில் "கொண்டெய்னர்கள்" பற்றி கேட்கும் போது Azure Container Instances ஆவணங்களைத் தரும், C# சூழலில் இதே சொல் குறிப்பிடும் போது சம்பந்தப்பட்ட C# தொகுப்பு தகவல்களை தரும்.

குறிப்பாக விரைவில் மாறும் அல்லது சமீபத்தில் புதுப்பிக்கப்பட்ட நூலகங்கள் மற்றும் பயன்பாடுகளுக்கு இது மிகவும் உதவியாக உள்ளது. சில சமீபத்திய குறியீட்டு திட்டங்களில் Aspire மற்றும் Microsoft.Extensions.AI இன் புதிய வெளியீடுகளில் உள்ள அம்சங்களை பயன்படுத்தவிருந்தேன். மைக்ரோசாப்ட் லெர்ன் ஆவணங்கள் MCP சர்வரை சேர்ப்பதன் மூலம், நான் API ஆவணங்கள் மட்டுமல்ல வாக்களிப்பு மற்றும் வழிகாட்டல்களையும் பயன்படுத்தினேன்.

**என்ன செய்கிறது**: Azure MCP Server 15+ சிறப்பான Azure சேவை இணைப்புகளைக் கொண்ட முழுமையான தொகுப்பு ஆகும், இது முழு Azure சூழலை உங்கள் AI பணிமுறைக்கு கொண்டு வருகிறது. இது ஒரு தனியொரு சர்வர் இல்லை – இது வள மேலாண்மை, தரவுத்தள இணைப்பு (PostgreSQL, SQL Server), Azure Monitor லாக் பகுப்பாய்வு KQL உடன், Cosmos DB இன்டிக்ரேஷன் மற்றும் பல சேவைகள் அடங்கிய சக்திவாய்ந்த தொகுப்பு.

**ஏன் இது பயனுள்ளது**: Azure வளங்களை நிர்வகிப்பதற்கும் மிஞ்சி, இந்த சர்வர் Azure SDK களுடன் பணியாற்றும் போது குறியீட்டு தரத்தை மிகவும் மேம்படுத்துகிறது. Azure MCP ஐ ஏஜென்ட் முறையில் பயன்படுத்தும்போது, இது உங்களுக்கு குறியீடு எழுத உதவுவதல்ல – இச்செயலில் தற்போதைய அங்கீகாரம் கோடுகள், பிழை கையாளுதல் சிறந்த நடைமுறைகளை பின்பற்றும் மற்றும் சமீபத்திய SDK அம்சங்களை பயன்படுத்தும் *சிறந்த* Azure குறியீட்டையும் உருவாக்க உதவுகிறது. சாதாரண வேலை செய்யக்கூடிய குறியீடு கிடைப்பது பதிலாக, உற்பத்தித் தேவை விதிகளுக்கு ஏற்ப Azure பரிந்துரைகள் படி குறியீடு கிடைக்கும்.

**முக்கிய தொகுதிகள்:**
- **🗄️ தரவுத்தள இணைப்புகள்**: Azure Database for PostgreSQL மற்றும் SQL Server க்கு நேரடிமொழி அணுகல்
- **📊 Azure கண்காணிப்பு**: KQL மூலம் லாக் பகுப்பாய்வு மற்றும் செயல்பாட்டு பார்வைகள்
- **🌐 வள மேலாண்மை**: முழுமையான Azure வள இயக்கம்
- **🔐 அங்கீகாரம்**: DefaultAzureCredential மற்றும் மேலாண்மை அடையாள முறைகள்
- **📦 சேமிப்பக சேவைகள்**: Blob சேமிப்பு, Queue சேமிப்பு மற்றும் Table சேமிப்பு செயல்பாடுகள்
- **🚀 கொண்டெய்னர் சேவைகள்**: Azure Container Apps, Container Instances மற்றும் AKS மேலாண்மை
- **மற்ற பல சிறப்பு இணைப்புகள்**

**உண்மை உலக பயன்பாடு**: "எனது Azure சேமிப்பகம் கணக்குகளை பட்டியலிடு", "கடந்த நேரத்தில் ஏற்பட்ட பிழைகளுக்கு என் Log Analytics பணித் பூங்காவில் கேள்வி செய்", அல்லது "சூழல் சரியான அங்கீகாரம் உடன் Node.js பயன்படுத்தி Azure செயலியை உருவாக்க உதவி செய்"

**முழு காட்சி காட்சி**: Azure MCP ஐ GitHub Copilot Azure நீட்டிப்புடன் VS Code இல் இணைத்து கொண்ட போது அதற்கான முழு நடைமுறையை உங்கள் கண்ணுக்கு காட்டுகிறது. இரண்டும் நிறுவப்பட்டதும் கேட்கிறீர்கள்:

> "DefaultAzureCredential அங்கீகாரத்தைப் பயன்படுத்தி Azure Blob Storage-க்கு ஒரு கோப்பை பதிவேற்ற ஒரு Python ஸ்கிரிப்ட்டை உருவாக்கவும். ஸ்கிரிப்ட் என் Azure சேமிப்பு கணக்கு 'mycompanystorage' என்பதற்கு இணைக்க வேண்டும், 'documents' என்ற ஒருங்கிணைப்பு தொகுதியிற்கு பதிவேற்ற வேண்டும், தற்போதைய காலக்கெடு கொண்ட ஒரு டெஸ்ட் கோப்பை உருவாக்கி அதனை பதிவேற்ற வேண்டும், பிழைகளை நன்றாக கையாள வேண்டும் மற்றும் தகவல் வழங்கும் வெளியீட்டை வழங்க வேண்டும், அங்கீகார மற்றும் பிழை கையாளுதலுக்கான Azure சிறந்த நடைமுறைகளை பின்பற்ற வேண்டும், DefaultAzureCredential அங்கீகாரம் எப்படி செயல்படுகிறது என்பதை விளக்கும் கருத்துக்களை உள்ளடக்க வேண்டும், மற்றும் ஸ்கிரிப்ட்டை சரியான செயல்பாடுகள் மற்றும் ஆவணங்களுடன் நன்றாக அமைக்க வேண்டும்."

Azure MCP சர்வர் முழுமையான, தயாரிப்பு தயாரிக்கக்கூடிய Python ஸ்கிரிப்ட்டினை உருவாக்கும், அது:
- உரிய async முறைகளுடன் சமீபத்திய Azure Blob Storage SDK-யை பயன்படுத்துகிறது
- விரிவான fallback சங்கிலி விளக்கத்துடன் DefaultAzureCredential-ஐ அமலாக்குகிறது
- குறிப்பிட்ட Azure தவறு வகைகளுடன் வலுவான பிழை கையாளுதலைச் சேர்க்கிறது
- வள மேலாண்மை மற்றும் இணைப்பு கையாளுதலுக்கான Azure SDK சிறந்த நடைமுறைகளை பின்பற்றுகிறது
- விரிவான பதிவு மற்றும் தகவல் சுருக்க வெளியீட்டை வழங்குகிறது
- செயல்பாடுகள், ஆவணங்கள் மற்றும் வகை கண்ணோட்டங்களுடன் நன்றாக அமைக்கப்பட்ட ஸ்கிரிப்ட்டை உருவாக்குகிறது

இது குறிப்பிடத்தக்கது என்று கூறுவது, Azure MCP இல்லாமல், நீங்கள் இயங்கும் ஆனால் தற்போதைய Azure நடைமுறைகளை பின்பற்றாத பொதுவான Blob Storage குறியீட்டை பெறலாம். Azure MCP உடன், நீங்கள் சமீபத்திய அங்கீகார முறைகளை பயன்படுத்தும், Azure-க்கு ஏற்ற PARTICULAR பிழைச் சூழ்நிலைகளை கையாளும் மற்றும் Microsoft பரிந்துரைக்கும் தயாரிப்பு பயன்பாடுகளுக்கான நடைமுறைகளை பின்பற்றி குறியீடு பெறுகிறீர்கள்.

**குறிப்பிடத்தக்க எடுத்துக்காட்டு**: எனக்கு ad-hoc பயன்படுத்துவதற்கு `az` மற்றும் `azd` CLI களுக்கான குறிப்பிட்ட கட்டளைகளை நினைவில் வைத்திருக்க சிரமப்பட்டு வந்தேன். இது எப்போதும் இரண்டு படிகள்: முதலில் உள்ளடக்கத்தை தேடல், பிறகு கட்டளை இயக்கல். நான் பொதுவாக போர்டலில் சென்று கிளிக் செய்து வேலை செய்துவிடுகிறேன், CLI நடைமுறையை நினைவில் வைத்திருக்க முடியவில்லை என்று ஒப்புக் கொள்ளமாட்டேன். நான் என்ன வேண்டும் என்பதைப் பேசித் தெரிந்துகொள்ள முடிந்தால் அதுவே அர்ச்சணை, மேலும் என் IDE விட்டு வெளியே செல்லாமல் செய்ய முடிந்தால் கூடுதல் நன்றாக உள்ளது!

தொடங்குவதற்கு பெரிய பயன்பாட்டு பட்டியலுக்கு [Azure MCP சேமிப்பகம்](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) என்பதில் உள்ளது. முழுமையான அமைப்பு வழிகாட்டல்கள் மற்றும் மேம்பட்ட கட்டமைப்பு விருப்பங்களுக்கு, [அதிகாரப்பூர்வ Azure MCP ஆவணங்கள்](https://learn.microsoft.com/azure/developer/azure-mcp-server/) பார்க்கவும்.

### 3. 🐙 GitHub MCP சர்வர்

**என் செயல்**: அதிகாரபூர்வ GitHub MCP சர்வர் GitHub முழு சூழலுடன் இனிமையான ஒருங்கிணைப்பை வழங்குகிறது, ஹோஸ்ட் செய்யப்பட்ட ரிமோட் அணுகல் மற்றும் உள்ளூர் Docker அங்கீகாரம் விருப்பங்களுடன். இது அடிப்படை சேமிப்பக செயல்பாடுகளை மட்டும் அல்ல – GitHub செயல்பாடுகள் மேலாண்மை, புல் கோரிக்கை வேலைப்பாடுகள், பிரச்சினை கண்காணிப்பு, பாதுகாப்பு ஸ்கேன், அறிவிப்புகள் மற்றும் மேம்பட்ட தானியங்கிகள் போன்ற முழுமையான கருவிப் பெட்டி ஆகும்.

**எ왜 유用**: இந்த சர்வர் GitHub ஐ நீங்கள் தொடர்பு கொள்வது முறையில் மாற்றம் கொண்டுவருகிறது, முழு தளம் அனுபவத்தை நேரடியாக உங்கள் வளர்ச்சி சூழலில் கொண்டு வருகிறது. திட்ட மேலாண்மை, குறியீடு மதிப்பீடு மற்றும் CI/CD கண்காணிப்புக்கு VS Code மற்றும் GitHub.com இடையே எப்போதும் மாற வேண்டியதற்கு பதிலாக, இயற்கை மொழி கட்டளைகளில் அனைத்தும் செய்யலாம் மற்றும் உங்கள் குறியீடில் கவனம் வைக்கலாம்.

> **ℹ️ குறிப்பு: 'ஏஜெண்டுகள்' வகைகள் வேறுபாடு**
> 
> இந்த GitHub MCP சர்வரை GitHub-இன் Coding Agent (அந்த AI ஏஜென்ட், பிரச்சினைகளை ஒதுக்கி தானாக கோடிங் பணிகளை செய்யக்கூடியது) க்கு குழப்ப வேண்டாம். GitHub MCP சர்வர் VS Code-இன் ஏஜெண்ட் முறையில் GitHub API ஒருங்கிணைப்பை வழங்குகிறது, ஆனால் GitHub Coding Agent தனித்துவ அம்சமாக GitHub பிரச்சினைகளுக்கு ஒதுக்கப்பட்டால் புல் கோரிக்கைகளை உருவாக்குகிறது.

**முக்கிய திறன்கள்**:
- **⚙️ GitHub செயல்பாடுகள்**: முழுமையான CI/CD குழாய் மேலாண்மை, வேலைப்பாடு கண்காணிப்பு மற்றும் ஆய்வகம் கையாளுதல்
- **🔀 புல் கோரிக்கைகள்**: உருவாக்கல், மதிப்பாய்வு, ஒருங்கிணைப்பு மற்றும் விரிவான நிலை கண்காணிப்பு
- **🐛 பிரச்சினைகள்**: முழுமையான பிரச்சினை ஆயுள் மேலாண்மை, கருத்திடல், லேபிள் மற்றும் ஒதுக்கீடு
- **🔒 பாதுகாப்பு**: குறியீட்டு ஸ்கானிங் எச்சரிக்கைகள், ரகசிய கண்டறிதல் மற்றும் Dependabot ஒருங்கிணைப்பு
- **🔔 அறிவிப்புகள்**: விவேகமான அறிவிப்பு மேலாண்மை மற்றும் சேமிப்பக சந்தா கட்டுப்பாடு
- **📁 சேமிப்பக மேலாண்மை**: கோப்பு செயல்பாடுகள், கிளையில் மேலாண்மை மற்றும் சேமிப்பக நிர்வாகம்
- **👥 ஒத்துழைப்பு**: பயனர் மற்றும் நிறுவனர் தேடல், குழு மேலாண்மை மற்றும் அணுகல் கட்டுப்பாடு

**நிகழ்கால பயன்பாடு**: "என் வசதி கிளையிலிருந்து புல் கோரிக்கை உருவாக்கு", "இந்த வாரம் தோல்வியாகிய CI ஓட்டங்களைக் காண்க", "என் சேமிப்பகங்களுக்கு திறந்த பாதுகாப்பு எச்சரிக்கைகள் பட்டியலிடு", அல்லது "என் நிறுவனங்களுக்கு ஒதுக்கியுள்ள அனைத்து பிரச்சினைகளையும் கண்டெடு"

**முழு டெமோ நிலைமை**: GitHub MCP சர்வரின் திறன்களை காட்டும் சக்திவாய்ந்த வேலைப்பாடு:

> "எமது sprint பரிசீலனைக்கு நான் தயாராக வேண்டும். இந்த வாரம் நான் உருவாக்கிய அனைத்து புல் கோரிக்கைகளையும் காட்டவும், எங்கள் CI/CD குழாய்களின் நிலையை சரிபார்க்கவும், எதையாவது பாதுகாப்பு எச்சரிக்கைகளை சுருக்கிய அறிக்கை உருவாக்கவும், மற்றும் 'feature' லேபிளுடன் இணைந்த புல் கோரிக்கைகளின் அடிப்படையில் வெளியீடு குறிப்புகள் தணிக்கை செய்ய உதவவும்."

GitHub MCP சர்வர்:
- உங்கள் சமீபத்திய புல் கோரிக்கைகளை விரிவான நிலை தகவலுடன் கேள்வி செய்வார்
- வேலைப்பாடு ஓட்டங்களை பகுப்பாய்வு செய்து தோல்விகள் அல்லது செயல்திறன் பிரச்சனைகளைக் குறிப்பிடுவார்
- பாதுகாப்பு ஸ்கானிங் முடிவுகளை தொகுத்து முக்கியமான எச்சரிக்கைகளை முன்னுரிமையுடன் செய்வார்
- இணைந்த புல் கோரிக்கைகளிலிருந்து தகவலை எடுத்து விரிவான வெளியீடு குறிப்புகளை உருவாக்குவார்
- sprint திட்டமிடல் மற்றும் வெளியீடு தயாரிப்புக்கு செயற்கார next steps வழங்குவார்

**குறிப்பிடத்தக்க எடுத்துக்காட்டு**: நான் இதனை குறியீடு மதிப்பாய்வு வேலைப்பாடுகளில் மிகவும் விரும்புகிறேன். VS Code, GitHub அறிவிப்புகள் மற்றும் புல் கோரிக்கை பக்கங்களுக்கு இடையே ஓடாமல், நான் "என் மதிப்பாய்வுக்கு காத்திருக்கும் அனைத்து புல் கோரிக்கைகளையும் காட்டவும்" என்று கூறி பிறகு "PR #123 இல் உள்ள authentication முறையில் பிழை கையாளுதலை பற்றி கேள்வி கேட்க இடுகை சேர்க்கவும்" என்று கூறுகிறேன். சர்வர் GitHub API அழைப்புகளை கையாள்கிறது, விவாத சூழலை பராமரிக்கிறது மற்றும் மேலதிக கட்டுமான மதிப்பாய்வு கருத்துக்களை உருவாக்க உதவுகிறது.

**அங்கீகாரம் விருப்பங்கள்**: சர்வர் OAuth (VS Code இல் இனிமையான) மற்றும் Personal Access Tokens இரண்டையும் ஆதரிக்கிறது, தேவையான GitHub செயல்பாடுகளை மட்டும் இயக்கும் கட்டமைப்புகளை வழங்குகிறது. வேகமான அமைப்புக்கு அது ஹோஸ்ட் செய்யப்பட்ட சேவையாக இயக்கலாம் அல்லது முழுமையான கட்டுப்பாட்டிற்காக உள்ளூரில் Docker வழியாக இயக்கலாம்.

> **💡 தொழிற்நுட்ப குறிப்பு**
> 
> உங்கள் MCP சர்வர் அமைப்புகளில் `--toolsets` பராமரிப்பை மாற்றுவதன் மூலம் தேவையான கருவித்தொகுதிகளை மட்டும் இயக்கி சூழல் அளவை குறைத்து AI கருவி தேர்வை மேம்படுத்தலாம். உதாரணமாக, பிணைத்துறை மேம்பாட்டு வேலைப்பாடுகளுக்காக உங்கள் MCP கட்டமைவு வாதங்களில் `"--toolsets", "repos,issues,pull_requests,actions"` சேர்க்கவும் அல்லது நீங்கள் பெரும்பாலும் GitHub கண்காணிப்பு திறன்களை விரும்பினால் `"--toolsets", "notifications, security"` பயன்படுத்தவும்.

### 5. 📝 MarkItDown MCP சர்வர்

[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_MarkItDown_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_MarkItDown_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/markitdown)

**என் செயல்**: MarkItDown என்பது பல கோப்பு வடிவங்களை உயர்தர Markdown ஆக மாற்றும் முழுமையான ஆவண மாற்று சர்வர், LLM பயன்பாடு மற்றும் உரை பகுப்பாய்வு வேலைப்பாடுகளுக்காக சிறப்பாக வடிமையானது.

**எ왜 유用**: நவீன ஆவண பண்படுத்தல் வேலைப்பாடுகளுக்கு அவசியமானது! MarkItDown அத்தியாவசிய ஆவண அமைப்புகளை (தலைப்புகள், பட்டியல்கள், அட்டவணைகள் மற்றும் இணைப்புகள் போன்றவை) காப்பாற்றும் பல கோப்பு வடிவத்தை கையாள்கிறது. எளிய உரை எடுக்குமான கருவிகள் அல்லாமல், அது ஸெமாண்டிக் அர்த்தம் மற்றும் வடிவமைப்பை காக்கிறது, இது AI செயலாக்கத்திற்கும் மனித வாசிப்பிற்கும் மதிப்புடையது.

**ஆதரிக்கப்பட்ட கோப்பு வடிவங்கள்**:
- **அலுவலக ஆவணங்கள்**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **ஊடக கோப்புகள்**: படங்கள் (EXIF தரவுடன் மற்றும் OCR), ஒலிகள் (EXIF தரவுடன் மற்றும் விழிவிளக்கம்)
- **இணைய உள்ளடக்கம்**: HTML, RSS ஊட்டங்கள், YouTube URL-கள், விக்கிப்பீடியா பக்கங்கள்
- **தரவு வடிவங்கள்**: CSV, JSON, XML, ZIP கோப்புகள் (உள்ளடக்கங்களைக் மறுவட்டாரமாக செயலாக்குதல்)
- **பதிப்பிடுதல் வடிவங்கள்**: EPub, Jupyter நோட்புக் கள் (.ipynb)
- **மின்னஞ்சல்**: Outlook செய்திகள் (.msg)
- **மேம்பட்டவை**: மேம்பட்ட PDF செயலாக்கத்திற்கு Azure ஆவண நுண்ணறிவு ஒருங்கிணைப்பு

**மேம்பட்ட திறன்கள்**: MarkItDown LLM இயக்கப்படும் பட விவரணைகளை (OpenAI கிளையன்ட் கொடுக்கப்பட்டால்), Azure ஆவண நுண்ணறிவு மூலம் மேம்பட்ட PDF செயலாக்க, உதவி உரை மாற்றம் மற்றும் மேம்படுத்தி மேலதிக கோப்பு வடிவங்களை இணைக்க plugins-ஐ ஆதரிக்கிறது.

**நிகழ்கால பயன்பாடு**: "இந்த PowerPoint முன்பதிவு Markdown ஆக மாற்று எங்கள் ஆவணத்தளத்திற்கு", "இந்த PDF இல் இருந்து உரையை தேவையான தலைப்பு அமைப்புடன் எடு", அல்லது "இந்த Excel spreadsheet-ஐ வாசிக்கக்கூடிய அட்டவணை வடிவமாக மாற்று"

**சிறப்பாக எடுத்துக்காட்டு (மறுபடி சொல்வது)**: 
[MarkItDown ஆவணங்கள்](https://github.com/microsoft/markitdown#why-markdown) விளக்குகிறது
Markdown குறைவான வடிவமைப்பு ஓவர்ஹெடுடன் ஆவணத்தின் அமைப்பை பாதுகாக்கிறது என்று.
மொழி மாதிரிகள் பொதுவாக Markdown உருவாக்குகின்றன, இது ஆவண செயலாக்க பணிகளுக்கு பயனுள்ள, குறைந்த டோக்கன் பயனுள்ள
வடிவமாக இருக்கிறது.

MarkItDown ஆவண அமைப்பை பாதுகாப்பதில் மிகவும் சிறந்தது, இது AI பணிகளுக்கு முக்கியமானது. உதாரணமாக, ஒரு PowerPoint பிரசண்டேஷனை மாற்றும்போது, அது ஸ்லைடு அமைப்பை சரியான தலைப்புகளுடன் காக்கிறது, அட்டவணைகளை Markdown அட்டவணைகளாக எடுக்கிறது, படங்களுக்கு மாற்று உரையைச் சேர்க்கிறது, மற்றும் பேச்சாளர் குறிப்பு கூட செயலாக்குகிறது. கட்டவணைகள் படிக்கக்கூடிய தரவு அட்டவணைகளாக மாறுகின்றன, மற்றும் முடிவாக உருவாக்கப்படும் Markdown அசல் பிரசண்டேஷனின் தர்க்கமான பெருக்கை பராமரிக்கிறது. இது பிரசண்டேஷன் உள்ளடக்கத்தை AI அமைப்புகளில் அனுப்ப அல்லது உள்ள ஸ்லைட்களில் இருந்து ஆவணமாக்க மிகுந்த பொருத்தமானதாகும்.

**உலகச் சூழலில் பயன்பாடு**: "என் деклараட்டிவ் முகவர் கட்டமைப்பை சரிபார்த்து எந்த கட்டமைப்பு பிழைகள் varsa சரி செய்", "Microsoft Graph API பிளக்-இன் செயலாக்க மாதிரி குறியீடு காண்பி", அல்லது "என் Teams செயலி அங்கீகார பிரச்சனைகளை தீர்க்க உதவி செய்"

**விளக்கக் கொடுப்பு**: நான் என் நண்பர் ஜான் மில்லரிடம் Build விழாவில் Microsoft 365 முகவர்கள் பற்றி பேசினபோது இந்த MCP ஐ பரிந்துரைத்தார். இது M365 முகவர்களுடன் புதிதாக பணியாற்றும் டெவலப்பர்களுக்கு சிறந்தது, ஏனெனில் இதனால் டெம்ப்ளேட்டுகள், மாதிரி குறியீடுகள் மற்றும் scaffolding பெற்றுக் கொள்ளலாம், ஆவணத்தில் டேங்கி இல்லாமல் தொடங்க முடியும். கட்டமைப்பு சரிபார்ப்பு அம்சங்கள் குறிப்பாக பிழைகள் ஏற்படுத்தும் கட்டமைப்புக் கோளாறுகளைக் கண்டு பிடிக்க உதவும்.

## 📋 முடிவு

மாதிரி சூழல் நெறிமுறை (MCP) AI உதவியாளர்கள் மற்றும் புற கருவிகளுடன் டெவலப்பர்கள் தொடர்பை மாற்றி அமைக்கிறது. இந்த 10 Microsoft MCP சர்வர்கள் நிலையான AI ஒருங்கிணைப்பின் சக்தியை வெளிப்படுத்துகின்றன, சக்திவாய்ந்த புற திறன்களை அணுகும்போது டெவலப்பர்கள் தங்கள் செயல்முறைகளில் தொடர்ச்சியாக இருக்க உதவுகின்றன.

விரிவான Azure சூழல் ஒருங்கிணைப்பு முதல் Playwright போன்ற உலாவி தானியங்கி கருவிகள் மற்றும் MarkItDown போன்ற ஆவண செயலாக்கம் வரை, இச்சர்வர்கள் பல்வேறு வளர்ச்சி சூழல்களில் MCP எப்படி உற்பத்தித்திறனை மேம்படுத்தும் என்பதை காட்டுகின்றன. நிலையான நெறிமுறை இந்த கருவிகள் சீராக இணைந்து ஒருங்கிணைந்த வளர்ச்சி அனுபவத்தை உருவாக்க உறுதிசெய்கிறது.

MCP சூழல் வளர்ச்சியடைவதற்காக சமூகவியலுடன் இணைந்து, புதிய சர்வர்களை ஆராய்ந்து, தனிப்பயன் தீர்வுகளை கட்டியமைத்தல் உங்கள் வளர்ச்சி உற்பத்தித்திறனை மிகுதியாக்க முக்கியம். MCP இன் திறந்த நிலையான தன்மை வேறு விற்பனையாளர் கருவிகளை கலக்கவிட்டு உங்கள் தேவைகளுக்கு சரியான வேலைப்பாட்டை உருவாக்க அனுமதிக்கும்.
