# AGENTS.md

## திட்ட அறிமுகம்

**ஆரம்பத்திற்கான MCP** என்பது மாடல் சூழல் நெறிமுறை (MCP) கற்கும் திறந்த மூல கல்வித் திட்டமாகும் - இது செயற்கை நுண்ணறிவு மாடல்களுக்கும் கிளையண்ட் பயன்பாடுகளுக்கும் இடையேயான தொடர்புகளுக்கான முறைமை கொண்ட கட்டமைப்பு. இந்த தொகுப்பகம் பல நிரல்பாசறை மொழிகளில் நேரடி குறியீடு உதாரணங்களுடன் விரிவான கற்றல் பொருட்களை வழங்குகிறது.

### முக்கிய சాంకేతிகளான தொழில்நுட்பங்கள்

- **நிரல்பாசறை மொழிகள்**: C#, Java, JavaScript, TypeScript, Python, Rust
- **கட்டமைப்புகள் மற்றும் SDKகள்**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - ஸ்பிரிங் பூட் (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **தரவுத்தளங்கள்**: pgvector நீட்சியுடன் PostgreSQL
- **மேக தளங்கள்**: Azure (கண்டெய்னர் பயன்பாடுகள், OpenAI, உள்ளடக்க பாதுகாப்பு, பயன்பாட்டு ஆய்வு)
- **கட்டுமான கருவிகள்**: npm, Maven, pip, Cargo
- **ஆவணமிடல்**: பதிமுறை மொழிபெயர்ப்புடன் கூடிய மார்க்டவுன் (48+ மொழிகள்)

- **நடைமுறை ஆய்வுக் கூடங்கள்**: பல மொழிகளில் முழுமையான தீர்வு குறியீடு உடன் நடைமுறை பயிற்சிகள்
- **மாதிரி திட்டங்கள்**: செயல்படும் MCP சேவையகம் மற்றும் கிளையண்ட் அமலாக்கங்கள்

## அமைப்பு கட்டளைகள்

இது ஆவணமிடல் கவனிக்கப்பட்ட தொகுப்பகம். பெரும்பாலும் அமைப்பு தனித்தனிக் மாதிரி திட்டங்கள் மற்றும் ஆய்வுக்கூடங்களில் நடைபெறும்.

### தொகுப்பகம் அமைத்தல்

```bash
# பாரியத்தை நகல் எடுக்கவும்
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### மாதிரி திட்டங்களுடன் பணியாற்றுதல்

மாதிரி திட்டங்கள் இங்கு உள்ளன:
- `03-GettingStarted/samples/` - மொழி சார்ந்த உதாரணங்கள்
- `03-GettingStarted/01-first-server/solution/` - முதல் சேவையக அமலாக்கங்கள்
- `03-GettingStarted/02-client/solution/` - கிளையண்ட் அமலாக்கங்கள்
- `11-MCPServerHandsOnLabs/` - விரிவான தரவுத்தள இணைப்பு ஆய்வுக்கூடங்கள்

ஒவ்வொரு மாதிரி திட்டமும் தனது அமைப்பு வழிகாட்டுதல்களை கொண்டுள்ளது:

#### TypeScript/JavaScript திட்டங்கள்
```bash
cd <project-directory>
npm install
npm start
```

#### Python திட்டங்கள்
```bash
cd <project-directory>
pip install -r requirements.txt
# அல்லது
pip install -e .
python main.py
```

#### Java திட்டங்கள்
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

##### குறிக்கோள்

பாடத்திட்ட ஆவண மாற்றங்களைக்.validate மற்றும் பிரதிநிதித்துவ மாதிரி குறியீடு

##### உள்ளீடுகள்

- `changed_paths: string[]` (தேவை) - PRயில் மாற்றப்பட்ட உறையியல் பாதைகள்.

- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (இயல்புநிலை அனைத்தும் `false`)

##### வெளியீடுகள்

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### அனுமதிகள்

- வேலை இடம் கோப்புகளைப் படித்து கருவி உருவாக்கிய புகைப்படங்களை எழுத அனுமதி (எ.கா., லிண்ட்
  அறிக்கைகள், சோதனை பதிவுகள்) மட்டுமே; `translations/` அல்லது
  `translated_images/`-க்கு எழுத அனுமதி இல்லை.
- உள்ளூர் ஷெல் கட்டளைகளை நடைமுறைப்படுத்த அனுமதி.
- தேர்வுக்குரிய நெட்வொர்க் அணுகல் மட்டுமே தொகுப்பு மீட்டெடுப்புக்கு (`npm ci`,
  `python -m pip install`, `mvn` சார்பு தீர்வு).
- `translations/` அல்லது
  `translated_images/`-க்கு தள்ளுதல், சேர்க்குதல், அல்லது மாற்ற அனுமதி இல்லை.

##### தோல்வி முறைகள்

- `E_NO_INPUT_PATHS`: `changed_paths` காலியானது.
- `E_INVALID_PATH`: உள்ளீடு பாதை முற்றிலும் சேமிப்பகத் திறவை விட்டு வெளியேறியது.
- `E_LINT_FAILED`: மார்க் டவுன் லிண்ட் சராசரி நிராகரிக்கப்பட்டது.
- `E_LINK_AUDIT_FAILED`: இணைப்பு ஒப்பந்த கட்டளை சராசரி நிராகரிக்கப்பட்டது.
- `E_SAMPLE_TEST_FAILED`: மாதிரி சோதனை/கட்டற்றுவிடல் சராசரி நிராகரிக்கப்பட்டது.
- `E_TIMEOUT`: கட்டளை அமைக்கப்பட்ட நேர வரம்பை மீறியது.
