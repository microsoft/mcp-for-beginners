# AGENTS.md

## திட்டத்தின் மேலோட்டம்

**MCP தொடக்கக்காரர்களுக்கான** என்பது மாடல் சூழல் புரொட்டோகால் (MCP) - ஏஐ மாதிரிகள் மற்றும் கிளையன்ட் பயன்பாடுகளுக்கு இடையேயான தொடர்புக்கான ஒரு முறைமையான枠架ந்துறை மற்றும் திறந்த மூல கல்வி பாடத்திட்டம் ஆகும். இந்த சேமிப்பகத்தில் பல தொகுப்புக் மொழிகளில் செயல்பாட்டு குறியீட்டு உதாரணங்களுடன் விரிவான கற்றல் பொருட்கள் உள்ளன.

### முக்கிய தொழில்நுட்பங்கள்

- **தொகுப்புக் மொழிகள்**: C#, ஜாவா, ஜாவாஸ்கிரிப்ட், டைப்ப்ஸ்கிரிப்ட், பைதான், ரஸ்ட்
- **枠架மையங்கள் மற்றும் SDKகள்**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - ஸ்பிரிங் பூட் (ஜாவா)
  - ஃபாஸ்ட்MCP (பைதான்)
  - லாங்க்செயின்4j (ஜாவா)
- **தரவுத்தளங்கள்**: pgvector நீட்டிப்புடன் PostgreSQL
- **மேघ தளங்கள்**: அஜூர் (காண்டைனர் செயலிகள், OpenAI, உள்ளடக்கம் பாதுகாப்பு, பயன்பாட்டுத் தகவல்)
- **அமைப்பு கருவிகள்**: npm, மேவன், பிப், கார்கோ
- **ஆவணப்படுத்தல்**: தானாக மொழிபெயர்க்கப்படும் பல மொழிகள் கொண்ட மார்க்டவுன் (48+ மொழிகள்)

### கட்டமைப்பு

- **11 முக்கிய தொகுதிகள் (00-11)**: அடிப்படைகளிலிருந்து முன்னேறிய தலைப்புகளுக்கு தொடர்வழக்கக் கற்றல் பாதை

- **மாதிரிப் திட்டங்கள்**: செயல்படும் MCP சேவையகம் மற்றும் கிளையன்ட் செயல்பாடுகள்
- **மொழிபெயர்ப்பு முறைமை**: பல மொழி ஆதரவுக்கான தானாக இயங்கும் GitHub செயல்பாடுகள் வேலைமுறை

## அமைப்பு கட்டளைகள்

இது ஒரு ஆவணமயமாக்கப்பட்ட சேமிப்பகம். பெரும்பான்மையான அமைப்பு தனித்தனியான மாதிரித் திட்டங்கள் மற்றும் ஆய்வுக்கூடங்களில் நிகழ்கிறது.

### சேமிப்பக அமைப்பு

```bash
# சேமிப்பகத்தை நகலெடு
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### மாதிரித் திட்டங்களுடன் வேலை செய்தல்

மாதிரித் திட்டங்கள் உள்ளன:
- `03-GettingStarted/samples/` - மொழி-சார்ந்த உதாரணங்கள்
- `03-GettingStarted/01-first-server/solution/` - முதல் சேவையக செயல்பாடுகள்
- `03-GettingStarted/02-client/solution/` - கிளையன்ட் செயல்பாடுகள்
- `11-MCPServerHandsOnLabs/` - விரிவான தரவுத்தள ஒருமைமை ஆய்வுக்கூடங்கள்

ஒவ்வொரு மாதிரித் திட்டத்திற்கும் தனித்தனியான அமைப்புச் செவ்வியல் உள்ளன:

#### டைப்ப்ஸ்கிரிப்ட்/ஜாவாஸ்கிரிப்ட் திட்டங்கள்
```bash
cd <project-directory>
npm install
npm start
```

#### பைதான் திட்டங்கள்
```bash
cd <project-directory>
pip install -r requirements.txt
# அல்லது
pip install -e .
python main.py
```

#### ஜாவா திட்டங்கள்
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

##### குறிக்கோள்

பாடத்திட்ட ஆவண மாற்றங்கள் மற்றும் பிரதிநிதி மாதிரி குறியீடு
ஒன்றிணையத்திற்கு முன்னர் நிலையை சரிபார்க்கவும்.

##### உள்ளீடுகள்

- `changed_paths: string[]` (தேவை) - PRஇல் மாற்றியுள்ள தொடர்பான பாதைகள்.
- `run_docs_lint: boolean` (இயல்புநிலை `true`)
- `run_links_audit: boolean` (இயல்புநிலை `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (இயல்புநிலை எல்லாம் `false`)

##### வெளியீடுகள்

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### அனுமதிகள்

- பணியிட கோப்புகளை படி மற்றும் கருவி உருவாக்கிய சான்றுமறைகள் (எ.கா., மொழியாற்றல்
  அறிக்கைகள், சோதனை பதிவுகள்) மட்டுமே எழுத அனுமதி; `translations/` அல்லது
  `translated_images/` இல் எழுத அனுமதி இல்லை.
- உள்ளூர் ஷெல் கட்டளைகளை இயக்க அனுமதி.
- தொகுப்பு மீட்பு (`npm ci`, `python -m pip install`, `mvn` சார்புகள் தீர்க்கை)
  மாதிரியான கட்டாயமான உயர் நெட்வொர்க் அணுகல் மட்டுமே.
- `translations/` அல்லது `translated_images/` என்பவற்றில் புஷ், இணைப்பு அல்லது
  மாற்றம் செய்வதற்கான அனுமதி இல்லை.

##### தோல்வி முறைகள்

- `E_NO_INPUT_PATHS`: `changed_paths` காலியானவை.
- `E_INVALID_PATH`: உள்ளீடு பாதை சேமிப்பக ரூட் வழியை மீறியது.
- `E_LINT_FAILED`: மார்க்டவுன் மொழியாற்றல் 0 அல்லாத வெளியீடு.
- `E_LINK_AUDIT_FAILED`: இணைப்பு ஆய்வு கட்டளை 0 அல்லாத வெளியீடு.
- `E_SAMPLE_TEST_FAILED`: மாதிரி சோதனை/செய்தல் 0 அல்லாத வெளியீடு.
- `E_TIMEOUT`: கட்டளை நிர்ணயிக்கப்பட்ட கால வரம்பை மீறியது.
