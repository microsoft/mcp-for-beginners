## மேலோட்டம்

**Model Context Protocol (MCP)** AI உதவியாளர்கள் வெளிப்புற தரவு ஆதாரங்களை நேரடியாக பாதுகாப்புடன் அணுகி தொடர்புகொள்ள முடியும். தரவுத்தள ஒருங்கிணைப்புடன் சேர்க்கும்போது, MCP தரவினை உள்வாங்கி இயங்கும் AI பயன்பாடுகளுக்கு சக்தி வாய்ந்த செயல்திறன்களை திறக்கிறது.

இந்த கற்றல் பாதை உங்களுக்கு AI உதவியாளர்களை PostgreSQL வழியாக சில்லறை விற்பனை தரவுடன் இணைக்கும் தயாரிப்புத் தயார MCP சர்வர்களை கட்டுவதற்கான வழிகாட்டுதலை வழங்குகிறது, இதில் வரிசை நிலை பாதுகாப்பு, பொருள் பொருத்தப்பட்ட தேடல், மற்றும் பன்மையாளர் தரவு அணுகல் போன்ற நிறுவன முறைமைகள் இடம்பெற்றுள்ளன.

### MCP தீர்வு

Model Context Protocol இவை சவால்களை பின்வருமாறு முகம்கொடுக்கிறது:

- **நேரடி தரவு அணுகல்**: AI உதவியாளர்கள் நேரடி தரவுத்தளங்களையும் APIகளையும் கேள்வி செய்கின்றனர்
- **பாதுகாப்பான ஒருங்கிணைவு**: அங்கீகாரம் மற்றும் அனுமதிகளுடன் கட்டுப்படுத்தப்பட்ட அணுகல்
- **இயற்கை மொழி இடைமுகம்**: வணிக பயனாளர்கள் தெளிவான ஆங்கிலத்தில் கேட்கிறார்கள்
- **தரநிலைபடுத்தப்பட்டது நெறிமுறைகள்**: பலவித AI தளங்களிலும் கருவிகளிலும் வேலை செய்கிறது

### முக்கிய கூறுகள்

#### **1. MCP சர்வர் அடுக்கு**
- **FastMCP கட்டமைப்பு**: நவீன பைதான் MCP சர்வர் நடைமுறை
- **கருவி பதிவு**: வகை பாதுகாப்புடன் க்கூற்று கருவி வரையறைகள்
- **கோரிக்கை சூழல்**: பயனர் அடையாளம் மற்றும் அமர்வு மேலாண்மை
- **பிழை கையாளல்**: வலுவான பிழை மேலாண்மை மற்றும் பதிவேற்று

#### **2. தரவுத்தள ஒருங்கிணைப்பு அடுக்கு**
- **இணைப்பு முற்சி**: திறமையான asyncpg இணைப்பு மேலாண்மை
- **வாரிய வழங்குனர்**: இயக்கக்கூடிய அட்டவணை வாரிய கண்டறிதல்
- **கேள்வி செயல்படுத்துபவர்**: பாதுகாப்பான SQL செயல் RLS சூழலில்
- **பரிவர்த்தனை மேலாண்மை**: ACID நினைவு தக்க வைத்தல் மற்றும் திரும்பப்பெறல்

#### **3. பாதுகாப்பு அடுக்கு**
- **வரிசை நிலை பாதுகாப்பு**: பலபயனர் தரவு தனிமைப்படுத்தலுக்கான PostgreSQL RLS
- **பயனர் அடையாளம்**: கடை மேலாளர் அங்கீகாரம் மற்றும் அத்தியாயம்
- **அணுகல் கட்டுப்பாடு**: நுணுக்கமான அனுமதிகள் மற்றும் கணக்கெடுப்பு
- **உள்ளீட்டு சரிபார்ப்பு**: SQL ஊடுரொடுப்பு தடுப்பு மற்றும் கேள்வி சரிபார்ப்பு

#### **4. AI மேம்படுத்தல் அடுக்கு**
- **பொருள் பொருத்தப்பட்ட தேடல்**: தயாரிப்பு கண்டுபிடிப்புக்கு வெக்டர் நுழைவுகள்
- **Azure OpenAI ஒருங்கிணைப்பு**: உரை நுழைவுகள் உருவாக்கம்

- **தேடல் மேம்படுத்துதல்**: குறிச்சொல் மற்றும் செயல்திறன் மேம்பாடு

## 🎬 உண்மையான பயன்பாட்டு சூழல்கள்

எவ்வாறு பல்வேறு பயனாளர்கள் எங்கள் MCP சர்வருடன் தொடர்பு கொள்ளுகிறார்கள் என்பதை ஆராய்வோம்:

### காட்சி 1: கடை மேலாளரின் செயல்திறன் மதிப்பாய்வு

**பயனர்**: சாரா, சியாட்டில் கடை மேலாளர்  
**நோக்கம்**: கடந்த கால மூன்று மாத விற்பனை செயல்திறனை பகுப்பாய்வு

**இயற்கை மொழி கேள்வி**:
> "என் கடையின் Q4 2024 இன் வருமான அடிப்படையிலான மேல்தர 10 தயாரிப்புகளை காட்டவும்"

**என்ன நடக்கும்**:
1. VS Code AI உரையாடல் MCP சர்வருக்கு கேள்வி அனுப்புகிறது
2. MCP சர்வர் சாராவின் கடை சூழலை (சியாட்டில்) அடையாளம் காண்கிறது
3. RLS கொள்கைகள் சிறப்புக்கான தரவுகளை சியாட்டில் கடைக்காக தடுக்கின்றன
4. SQL கேள்வி உருவாக்கி செயல்படுத்தப்படுகிறது
5. முடிவுகள் வடிவமைக்கப்பட்டு AI உரையாடலுக்கு அனுப்பப்படுகிறது
6. AI பகுப்பாய்வு மற்றும்洞察 வழங்குகிறது

### காட்சி 2: பொருள் கண்டறிதல் பொருள் பொருத்தப்பட்ட தேடல் மூலம்

**பயனர்**: மைக், சரக்குப் பணியாளன்  
**நோக்கம்**: வாடிக்கையாளர் கோரிக்கைக்கு ஒத்துப்போகும் பொருட்களை கண்டறிதல்

**இயற்கை மொழி கேள்வி**:
> "வெள்ளை நீர்ப்புகாமல் வெளிப்புற பயன்பாட்டிற்கான மின்சாரம் இணைப்புகள் போன்ற எந்த தயாரிப்புகளைக் நாங்கள் விற்பனை செய்கிறோம்?"

4. சம்பந்தப்பட்ட தயாரிப்புகள் பொருத்தமாக வரிசைப்படுத்தப்பட்டுள்ளன
5. முடிவுகள் தயாரிப்பு விவரங்கள் மற்றும் கிடைக்கக்கூடிய தன்மைகள் உள்ளன
6. AI மாற்று மற்றும் கூட்டு வாய்ப்புகளை பரிந்துரைக்கிறது

**நோக்கம்**: அனைத்து கடைகளிலும் செயல்திறன் ஒப்பிடல்

**இயற்கை மொழி கேள்வி**:
> "கடந்த 6 மாதங்களுக்கு அனைத்து கடைகளிலும் வகைப்படுத்தப்பட்ட விற்பனையை ஒப்பிடுக"

5. AI洞察 மற்றும் பரிந்துரைகளை வழங்குகிறது

## 🔒 பாதுகாப்பும் பன்மையாளர் ஆற்றலும் விரிவாக

எங்கள் நடைமுறை நிறுவன தரப் பாதுகாப்புக்கு முன்னுரிமை தருகிறது:

### வரிசை நிலை பாதுகாப்பு (RLS)

PostgreSQL RLS தரவு தனிமைப்படுத்தலை உறுதி செய்கிறது:

```sql
-- Store managers see only their store's data
CREATE POLICY store_manager_policy ON retail.orders
  FOR ALL TO store_managers
  USING (store_id = get_current_user_store());

-- Regional managers see multiple stores
CREATE POLICY regional_manager_policy ON retail.orders
  FOR ALL TO regional_managers
  USING (store_id = ANY(get_user_store_list()));
```

### பயனர் அடையாள மேலாண்மை

ஒவ்வொரு MCP இணைப்பும் குறித்தவையாக கொண்டது:
- **கடை மேலாளர் ஐடி**: RLS சூழலுக்கான தனிச்சிறப்பு அடையாளம்
- **பங்கு ஒதுக்கீடு**: அனுமதிகள் மற்றும் அணுகல் மட்டங்கள்
- **அமர்வு மேலாண்மை**: பாதுகாப்பான அங்கீகார டோக்கன்கள்
- **கணக்கெடுப்பு பதிவு**: முழுமையான அணுகல் வரலாறு

### தரவு பாதுகாப்பு

பல அடுக்குகள் பாதுகாப்பு:
- **இணைப்பு குறியாக்சல்**: அனைத்து தரவுத்தள இணைப்புகளுக்கும் TLS
- **SQL ஊடுரொடுப்பு தடுப்பு**: காரணத்துடனான கேள்விகள் மட்டும்
- **உள்ளீட்டு சரிபார்ப்பு**: விரிவான கோரிக்கை செருகல்
- **பிழை கையாளல்**: பிழை செய்திகளில் எந்தவொரு உணர்வு தரவும் இல்லை
