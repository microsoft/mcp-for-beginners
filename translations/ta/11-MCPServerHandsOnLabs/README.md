# 🚀 MCP சர்வர் மற்றும் PostgreSQL - முழுமையான கற்றல் வழிகாட்டி

## 🧠 MCP தரவுத்தள ஒருங்கிணைப்பு கற்றல் பாதையின் முன்னோட்டு

இந்த விரிவான கற்றல் வழிகாட்டி உங்களுக்கு தயாரிப்பு-தயாரான **Model Context Protocol (MCP) சர்வர்கள்** எவ்வாறு தரவுத்தளங்களுடன் ஒருங்கிணைக்கப்படுகின்றன என்பதை வாழ்க்கைப் பயன்பாட்டு சில்லறை பகுப்பாய்வு செயல்பாட்டின் மூலம் கற்றுக்கொள்ள உதவும். இதில் நீங்கள் கற்றுக்கொள்ளப் பொருந்திய நிறுவன தரம் மாதிரிகள் **Row Level Security (RLS)**, **semantic search**, **Azure AI ஒருங்கிணைப்பு**, மற்றும் **பன்முக கிரகாளிகளுக்கான தரவுகளின் அணுகல்** போன்றவை உள்ளன.

நீங்கள் பின்புற மேம்படுத்துபவர், AI பொறியாளர் அல்லது தரவு வடிவ செயல்படையாளராக இருந்தாலும், இந்த வழிகாட்டி கட்டமைக்கப்பட்ட கற்றல் மற்றும் நடைமுறை எடுத்துக்காட்டுகள் மற்றும் செயலில் பயிற்சிகளுடன் கீழ்காணும் MCP சர்வரை https://github.com/microsoft/MCP-Server-and-PostgreSQL-Sample-Retail வழி நடத்துகிறது.

2. தரவுத்தள ஒருங்கிணைப்புக்கு 04-09 லேபுகளுக்கு கவனம் செலுத்துக
3. தயாரிப்பு வெளியீட்டிற்கு 10-12 லேபுகளில் கவனம் செலுத்துங்கள்

## 🛠️ இந்த கற்றல் பாதையை பயனுள்ளதாக எப்படி பயன்படுத்துவது

### தொடர் கற்றல் (பரிந்துரைக்கப்படுகிறது)

விரிவான புரிதலுக்காக லேபுகளை வரிசையாக கடைபிடிக்கவும்:

1. **முன்னோட்டத்தைப் படியுங்கள்** - நீங்கள் என்ன கற்றுக்கொள்ளப்போகிறீர்கள் என்பதை புரிந்துகொள்ளவும்
2. **முன் அறிவைச் சரிபார்க்கவும்** - தேவையான அறிவு உண்டா என்பதை உறுதி செய்க
3. **கடந்துவரும் வழிகாட்டிகளை பின்பற்றவும்** - கற்றுக்கொண்டதை நடைமுறைபடுத்தவும்
4. **பயிற்சிகளை முடிக்கவும்** - உங்கள் புரிதலை வலுப்படுத்தவும்
5. **முக்கிய எடுத்துக்காட்டுக்களை மதிப்பாய்வு செய்க** - கற்றல் முடிவுகளை உறுதி செய்க

### குறியான கற்றல்

நீங்கள் குறிப்பிட்ட திறன்கள் தேவைப்பட்டால்:

- **தரவுத்தள ஒருங்கிணைப்பு**: 04-06 லேபுகளுக்கு கவனம் செலுத்துக
- **பாதுகாப்பு செயலாக்கம்**: 02, 08, 12 லேபுகளில் கவனம் செலுத்துக
- **AI/அர்த்தப்படுத்தப்பட்ட தேடல்**: 07 லேபில் ஆழ்ந்து செல்
- **தயாரிப்பு வெளியீடு**: 10-12 லேபுகளை படிங்க

### கை-மேடை பயிற்சி

ஒவ்வொரு லேபுக்கும் உள்ளது:
- **நடப்புத் குறியீட்டு எடுத்துக்காட்டுகள்** - நகலெடுக்கவும், மாற்றவும், பரிசோதிக்கவும்
- **உண்மையான உலகளாவிய சூழல்கள்** - நடைமுறை சில்லறை பகுப்பாய்வு பயன்பாடுகள்
- **முன்னேற்ற திருநிலை** - எளிமையில் இருந்து மேம்பட்ட நிலைக்கு கட்டமைத்தல்
- **சரிபார்ப்பு படிகள்** - உங்கள் செயல்பாடு வேலை செய்வதென உறுதி செய்க
