# 🚀 ஆரம்பக்காரர்களுக்கான Model Context Protocol (MCP) பாடத்திட்டம்

## **C#, Java, JavaScript, Rust, Python மற்றும் TypeScript இல் கைமுறை குறியீட்டு உதாரணங்களுடன் MCP கற்றுக்கொள்ளவும்**

## 🧠 Model Context Protocol பாடத்திட்டத்தின் அவலோகம்
Model Context Protocol பயணத்திற்கு உங்கள் வரவேற்பு! செயற்கை நுண்ணறிவு பயன்பாடுகள் வெவ்வேறு கருவிகள் மற்றும் சேவைகளுடன் எப்படி தொடர்பு கொள்கிறார்கள் என்று நீங்கள் எப்போதாவது யோசித்திருந்தால், உங்கள் முன்னிலையில் இந்த பொறியியல் தீர்வு உள்ளது, இது மென்பொருள் உருவாக்குநர்களை நுண்ணறிவுத் தளங்கள் உருவாக்க புதிய முறையில் மாற்றுகிறது.

MCPயை செயற்கை நுண்ணறிவு பயன்பாடுகளுக்கான உலகளாவிய மொழிபெயர்ப்பாளர் என்று நினைத்துக் கொள்ளுங்கள் - கணினியில் எந்த சாதனத்தையும் இணைக்க USB போர்டுகள் உதவுவது போல, MCP செயற்கை நுண்ணறிவு மாதிரிகளை எந்த கருவி அல்லது சேவையுடன் நியமிக்கப்பட்ட முறையில் இணைக்க உதவுகிறது. உங்கள் முதல் உரையாடல் ரோபோவை உருவாக்குகிறீர்களா அல்லது சிக்கலான AI வேலைநிரல்கள் மீது பணியாற்றுகிறீர்களா എന്നாலும், MCP-ஐப் புரிந்து கொள்வது உங்களுக்கு அதிக திறன் வாய்ந்த மற்றும் வளைந்த செயலிகளைக் கட்டமைப்பதற்கான சக்தியைத் தரும்.

இந்த பாடத்திட்டம் உங்கள் கற்றல் பயணத்திற்கு பொறுமையும் கவனமும் கொண்டு வடிவமைக்கப்பட்டுள்ளது. நீங்கள் ஏற்கனவே புரிந்துகொண்ட எளிய கருத்துக்களிலிருந்து தொடங்கி, உங்கள் விரும்பிய நிரலாக்க மொழியில் கைமுறை பயிற்சியுடன் உங்கள் திறமையை மெதுவாக வளர்க்கிறோம். ஒவ்வொரு படியும் தெளிவான விளக்கங்களும், நடைமுறை உதாரணங்களும், மற்றும் நிறைய ஊக்கத்துடனும் வருகிறது.

இந்த பயணத்தை நீங்கள் முடித்த பிறகு, நீங்கள் உங்கள் சொந்த MCP சேவையகங்களை உருவாக்கும் திறன், பிரபலமான AI தளங்களுடன் ஒருங்கிணைக்கும் திறன், மற்றும் இந்த தொழில்நுட்பம் AI மேம்பாட்டின் எதிர்காலத்தையும் எப்படி மாற்றுகிறது என்பதை புரிந்து கொள்வதற்கான நம்பிக்கை கொண்டிருப்பீர்கள். இந்த அதிரடியான சாகசத்தை நாம் ஒன்றாகத் தொடங்குவோம்!

### அதிகாரப்பூர்வக் ஆவணங்களும் விவரங்களும்

## கற்றல் இலக்குகள்

இந்த பாடத்திட்டம் முடிந்தபோல், உங்கள் புதிய திறமைகளுக்கு நம்பிக்கை மற்றும் உற்சாகம் கொண்டிருப்பீர்கள். இவை நீங்கள் அடையப்போகும் திறன்கள்:

• **MCP அடிப்படைகளைப் புரிதல்**: Model Context Protocol என்றால் என்ன மற்றும் இது செயற்கை நுண்ணறிவு பயன்பாடுகளை எப்படி மாற்றுகிறது என்பதை ஒப்பந்தங்களும் உதாரணங்களும் கொண்டு விளக்கமாக உணர்வீர்கள்.

• **உங்கள் முதல் MCP சேவையகத்தை உருவாக்குதல்**: உங்கள் விருப்ப நிரலாக்க மொழியில் எளிமையான உதாரணங்களுடன் செயல்படுத்தி, படி படியாக திறமைகளை வளர்த்து ஒரு MCP சேவையகம் உருவாக்குவீர்கள்.

• **AI மாதிரிகளைக் குறியீட்டு கருவிகளுடன் இணைத்தல்**: AI மாதிரிகளையும் உண்மையான சேவைகளையும் தொடர்புபடுத்துவது எப்படி என கற்பீர்கள், உங்கள் செயலிகளில் சக்தியான புதிய திறன்களை வழங்க.

• **பாதுகாப்பு சிறந்த நடைமுறைகளை செயல்படுத்துதல்**: உங்கள் MCP செயலாக்கங்களை பாதுகாப்பாக வைத்துக் கொள்ளும் வழிமுறைகளைப் புரிந்து கொள்ளுங்கள், இது உங்கள் செயலிகள் மற்றும் பயனர்களை பாதுகாக்க உதவும்.

• **நம்பிக்கையுடன் பிரசுரிப்பது**: உங்கள் MCP திட்டங்களை வளர்ப்பிலிருந்து உற்பத்திக்கு எடுத்து செல்லும் நடைமுறை முறைகளை தெரிந்து கொள்ளுங்கள்.

• **MCP சமூகத்தில் சேருதல்**: AI பயன்பாடுகளின் எதிர்காலத்தை வடிவமைக்கும் வளர்ந்து வரும் வளர்பிறப்புக் குழுவின் ஒரு பகுதியாய் மாறுவீர்கள்.

## அவசியமான பின்னணி

MCP உட்படித்தலுக்கு முன், சில அடிப்படைக் கருத்துக்களில் நீங்கள் ஓய்வாக இருப்பீர்கள் என்பதை உறுதிசெய்ய்வோம். நீங்கள் இத்துறையில் நிபுணர் இல்லாவிட்டாலும் கவலை வேண்டாம் - நாங்கள் தேவையான அனைத்தையும் விளக்குவோம்!

### நெறிமுறைகளைப் புரிதல் (அடித்தளம்)

நெறிமுறையை உரையாடலில் உள்ள விதிகளாக நினைத்துக் கொள்ளுங்கள். நீங்கள் தோழரை அழைக்கும் போது, இருவரும் "வணக்கம்" என்பதற்குத் தயாராக இருக்கிறீர்கள், மாற்மாறாக உரையாடுகிறீர்கள், மற்றும் முடிந்தவுடன் "பிரியாவிடை" சொல்கிறீர்கள். கணினி நிகழ்திரைகள் உள்ளிட்ட நெறிமுறைகள் இத்தகைய நிலையில் செயல் படுத்தப்படுகின்றன.

MCP என்பது ஒரு நெறிமுறை - AI மாதிரிகள் மற்றும் செயலிகள் கருவிகளுடன் மற்றும் சேவைகளுடன் பயனுள்ள "உரையாடலை" நடத்த ஒப்புக் கொண்ட விதிமுறைகளின் தொகுப்பு. மனிதர்களுக்கு உரையாடல் விதிகள் தொடர்பை எளிதாக்குவது போல, MCP செயற்கை நுண்ணறிவு செயலிகளுக்கான தொடர்பை நம்பகமானதாக்கவும் சக்திவாய்ந்ததாக்கவும் செய்கிறது.

### கிளையன்ட்-சேவையக உறவுகள் (நிகழ்திரைகள் எளிதாக இணைவது எப்படி)

நீங்கள் ஏற்கனவே தினசரி கிளையன்ட்-சேவையக உறவுகளைப் பயன்படுத்துகிறீர்கள்! நீங்கள் வலை உலாவியில் (கிளையன்ட்) ஒரு வலைத்தளத்தைப் பார்வையிடும்போது, நீங்கள் பக்க உள்ளடக்கத்தை அனுப்பும் வலை சேவையகத்துடன் இணைக்கின்றீர்கள். உலாவி தகவல் கேட்க அறிவு கொண்டது, சேவையகம் பதில் அளிக்கிறது.

MCP-இல், இதே மாதிரி உறவு உள்ளது: AI மாதிரிகள் கிளையன்ட்களாக செயல்பட்டு தகவல் அல்லது செயல்முறை கோரிகைகளை வழங்குகின்றன, MCP சேவையகங்கள் அவற்றைக் கொடுக்கும். இது AI கேட்கும் குறிப்பிட்ட பணிகளைச் செய்ய உதவும் உதவியாளரைப் போல்.

### தரநிலை கோரிக்கை (ஒத்துழைப்பு உருவாக்குதல்)

ஒவ்வொரு வாகன உற்பத்தியாளரும் வேறுபட்ட வடிவுள்ள எரிபொருள் குழாயைக் பயன்படுத்தினால் எப்படியும் - ஒவ்வொரு வாகனத்திற்கும் வேறு தொடர்பான் தேவைப்படும்! தரநிலைப்படுத்தல் பொருட்கள் எளிதில் ஒன்றாக வேலை செய்யும் விதத்தில் ஒப்புக்கொள்ளுதல்.

MCP செயற்கை நுண்ணறிவு செயலிகளுக்கான தரநிலைப்படுத்தலை வழங்குகிறது. ஒவ்வொரு AI மாதிரியும் ஒவ்வொரு கருவிக்கும் தனிப்பட்ட குறியீடு தேவைப்படாமல், MCP உலகளாவிய தொடர்பு வழிமுறையை உருவாக்குகிறது. இதனால் மென்பொருள் உருவாக்குநர்கள் ஒருமுறை மட்டுமே கருவிகளை உருவாக்கி பல விதமான AI அமைப்புகளுடன் வேலை செய்யப் பெற முடியும்.

## 🧭 உங்கள் கற்றல் பாதை அவலோகம்

உங்கள் MCP பயணம் நம்பிக்கையுடன் திறன்களைச் சீராக வளர்க்க suunnettu. ஒவ்வொரு கட்டமும் புதிய கருத்துக்களை அறிமுகம் செய்து, நீங்கள் கற்றையின் வலிமையை நிலைநிறுத்தும்.

### 🌱 அடித்தளம் கட்டம்: அடிப்படைகளைப் புரிதல் (துணுக்குகள் 0-2)

இங்கே உங்கள் சாகசம் தொடங்குகிறது! அறிமுகங்களுக்கான எளிய உதாரணங்களும் күнசெய்திகளைப் பயன்படுத்தி MCP கருத்துக்களை அறிமுகப்படுத்துவோம். MCP என்றால் என்ன, ஏன் உள்ளது மற்றும் AI உலகத்தில் எவ்வாறு பொருந்துகின்றது ஆகியன புரிந்துகொள்ளுவீர்கள்.


• **Module 0 - MCP அறிமுகம்**: MCP என்பது என்ன மற்றும் அதனால் why it is so important இன்றைய AI செயலிகளில் எப்படி பயன்படுகிறது என்பதை ஆராய்வோம். நீங்கள் MCP யின் செயலில் உள்ள உண்மையான உலக நடைமுறை உதாரணங்களைப் பார்ப்பீர்கள் மற்றும் இது பொதுவான பிரச்சினைகளை எப்படி தீர்க்கிறது என்பதை புரிந்துகொள்ளுவீர்கள்.

• **Module 1 - முக்கியக் கருத்துக்களை விளக்குகிறது**: இங்கே நீங்கள் MCP இன் முக்கிய கட்டமைப்புகளை கற்றுக்கொள்வீர்கள். இந்த கருத்துக்கள் இயல்பானதாகவும் புரிந்து கொள்ளக்கூடியதாகவும் இருப்பதற்காக நாங்கள் நிறைந்தஉடன் மாதிரிகளையும் காட்சி உதாரணங்களையும் பயன்படுத்துவோம்.

• **Module 2 - MCP இல் பாதுகாப்பு**: பாதுகாப்பு என்பதை எனக்கு அச்சுறுத்தலாம், ஆனால் MCP இல் உள்ள உருவாக்கப்பட்ட பாதுகாப்பு அம்சங்களை மற்றும் உங்கள் செயலிகள் தொடக்கத்தில் இருந்து பாதுகாக்க சிறந்த நடைமுறைகளை நாம் கற்பிப்போம்.

### 🔨 கட்டுமான நிலை: உங்கள் முதல் நிலைகளை உருவாக்குதல் (Module 3)

இப்போது உண்மையான மகிழ்ச்சி துவங்குகிறது! நீங்கள் கையாளும் MCP சர்வர்கள் மற்றும் கிளையண்டுகளை கட்டுவதில் நேரடி அனுபவம் பெறுவீர்கள். கவலைப்பட வேண்டாம் - நாங்கள் எளிமையான வேலைகளுடன் துவங்கி ஒவ்வொரு படியையும் வழிகாட்டுவோம்.

இந்த பகுதி நிறைய கைமுறை வழிகாட்டுதல்களை கொண்டுள்ளது, இது உங்கள் விருப்ப மென்பொருள் மொழியில் பயிற்சி பெற உதவுகிறது. நீங்கள் உங்கள் முதலாவது சர்வரை உருவாக்கி அதற்கு இணைக்கும் கிளையண்டை உருவாக்குவீர்கள், மேலும் பிரபலமான அபிவிருத்தி கருவிகள் போல VS Code உடன் ஒருங்கிணைக்கவும் செய்யலாம்.

ஒவ்வொரு வழிகாட்டலும் முழுமையான குறியீட்டு எடுத்துக்காட்டுகள், சிக்கல் தீர்க்கும் குறிப்புகள் மற்றும் ஏன் குறிப்பிட்ட வடிவமைப்பு தேர்வுகள் செய்யப்படுகின்றன என்பதற்கான விளக்கங்களைக் கொண்டுள்ளது. இந்த நிலையின் முடிவில், நீங்கள் பெருமையுடன் நிலைநிறுத்தக்கூடிய MCP செயலாக்கங்களை பெற்றிருப்பீர்கள்!

### 🚀 வளர்ப்பு நிலை: மேம்பட்ட கருத்துகள் மற்றும் உண்மையான பயன்பாடு (Modules 4-5)

அடிப்படைகளை கற்றுக்கொண்ட பிறகு, நீங்கள் உன்னதமான MCP அம்சங்களை ஆராய தயாராகிறீர்கள். நாங்கள் நடைமுறையில் செயலாக்க முறைகள், பிழைதிருத்து நுட்பங்கள் மற்றும் பல்முக AI ஒருங்கிணைப்பு போன்ற மேம்பட்ட தலைப்புகளை விரிவாகச்.cover செய்யப்போகிறோம்.

மேலும் MCP செயலாக்கங்களை உற்பத்திக்கு ஏற்ப விருத்தி செய்ய நிரல்பாகம் வகுப்பது மற்றும் Azure போன்ற மேக தளங்களுடன் ஒருங்கிணைக்கப்படுவது கருதப்படுகிறது. இந்த பாடங்கள் உண்மையான உலகக் கேள்விகளுக்கு முகாமான MCP தீர்வுகளை அமைக்கும் நிலையில் உங்களைத் தயாராக்கும்.

### 🌟 திறமையுற்ற நிலை: சமூகமும் துறையில் விஷேஷமாகவும் (Modules 6-11)

கடைசி நிலை MCP சமூகத்தில் சேர்வதையும் உங்கள் ஆர்வமுள்ள பகுதிகளில் திறமை மையமாக்குதலையும் கவனிக்கும். நீங்கள் திறந்த மூல MCP திட்டங்களுக்கு பங்களிக்க போதுமான முறைகளை கற்றுக்கொள்வீர்கள், மேம்பட்ட அங்கீகார முறைகள் செயல்படுத்துவீர்கள் மற்றும் முழுமையான தரவுத்தளம் ஒருங்கிணைந்த தீர்வுகளை உருவாக்குவீர்கள்.

Module 11 சிறப்பு குறிப்பிடக்கூடியது - இது ஒரு முழுமையான 13-லேபின் கைமுறை கற்றல் பாதை ஆகும், இது PostgreSQL ஒருங்கிணைப்புடன் உற்பத்தி-தயார MCP சர்வர்களை கட்டுவதற்கு கற்றுக்கொடுக்கும். இது நீங்கள் கற்ற எல்லாமே ஒன்றிணைக்கும் ஒரு முத்திரை திட்டமாகும்!

## 📚 படிப்பு வழிகாட்டி & வளங்கள்

இந்த சேமிப்பகத்தில், நீங்கள் திறம்பட கற்றுக்கொள்ள பல வளங்கள் உள்ளன:

### படிப்பு வழிகாட்டி

இந்த சேமிப்பகத்தைக் திறம்பட ஆய்வு செய்யவும் உங்களுக்கு உதவும் விரிவான [படிப்பு வழிகாட்டி](./study_guide.md) கிடைக்கிறது. இந்த காணொளி பாடத் திட்ட வரைபடம் அனைத்து தலைப்புகளையும் இணைக்கும் விதமும், மாதிரியான திட்டங்களை சிறப்பாக பயன்படுத்தும் வழிகாட்டுதலையும் வழங்குகிறது. இது பெரும்பாலும் காட்சிப் பாடமாக கற்றுக்கொள்ள விரும்புவோருக்கு சிறந்தது.

வழிகாட்டி கொண்டுள்ளது:
- அனைத்து கருத்துக்களையும் காட்சியளிக்கும் பாடத் திட்ட வரைபடம்
- ஒவ்வொரு சேமிப்பகப் பகுதியின் விரிவான விளக்கம்
- மாதிரிப் பணிகளை எப்படி பயன்படுத்துவது குறித்து வழிகாட்டுதல்
- வெவ்வேறு திறனால் கற்றல் பாதைகள் பரிந்துரைகள்
- உங்கள் கற்றல் பயணத்திற்கு கூடுதல் வளங்கள்

### மாற்றப்பட்ட காலப்புள்ளி

பாடத் திட்டப் பொருட்களில் முக்கியமான அனைத்து புதுப்பிப்புகளையும் கண்காணிக்கும் விரிவான [மாற்றப்பட்ட காலப்புள்ளி](./changelog.md) எங்களிடம் உள்ளது. இதனால் நீங்கள் சமீபத்திய மேம்படுத்தல்கள் மற்றும் சேர்க்கைகளைப் பெற்றுக்கொள்ளலாம்.
- புதிய உள்ளடக்கம் சேர்க்கைகள்
- கட்டமைப்பு மாற்றங்கள்
- அம்ச மேம்பாடுகள்
- ஆவணப்பதிவுகள் புதுப்பிப்புகள்

## 🛠️ இந்த பாடத் திட்டத்தை திறம்பட பயன்படுத்துவது எப்படி

இந்த வழிகாட்டியில் ஒவ்வொரு பாடமும் கொண்டுள்ளது:

## 🎓 உங்கள் MCP பயணம் தொடங்குகிறது

வாழ்த்துக்கள்! உங்கள் நிகழ்காலக்கட்டமைப்பை விரிவாக்கும் மற்றும் AI அபிவிருத்தியின் முன்னணி நிலை தொடர்புபடுத்தும் ஒரு சுவாரஸ்யமான பயணத்தின் முதல் படி நீங்கள் எடுத்துள்ளீர்கள்.

### நீங்கள் ஏற்கனவே செய்ததை

இந்த அறிமுகத்தைப் படித்ததன் மூலம், நீங்கள் ஏற்கனவே உங்கள் MCP அறிவு அடித்தளத்தை கட்டியதாகத் தொடங்கியுள்ளீர்கள். MCP என்ன, அது ஏன் முக்கியம், மற்றும் இந்த பாடத்திட்டம் உங்கள் கல்வி பயணத்தை எவ்வாறு ஆதரிக்கும் என்பதை நீங்கள் புரிந்துகொண்டுள்ளீர்கள். இது ஒரு முக்கியமான சாதனை மற்றும் இந்த முக்கிய தொழில்நுட்பத்தில் உங்கள் நிபுணத்துவத்தின் தொடக்கம்.

### எதிர்கால சாகசம்

உங்கள் தொகுதிகளை முன்னேற்றும்போது, அனைத்து நிபுணர்களும் முன்பு தொடக்கக் கட்டத்தில் இருந்தனர் என்பதை நினைவில் வைக்கவும். இப்போது கடினமாக தோன்றும் கருத்துக்கள், நீங்கள் பயிற்சி செய்து பயன்படுத்தும்போது இயல்பாயிருக்கும். ஒவ்வொரு சிறிய படியும், உங்கள் அபிவிருத்தி வாழ்க்கைக்கு மிக முக்கியமான சக்திவாய்ந்த திறன்களை கட்டமைக்கும்.

### உங்கள் ஆதரவு வலையமைப்பு

நீங்கள் MCP பற்றிய ஆர்வமுள்ள கற்றலாளர்கள் மற்றும் நிபுணர்களின் ஒரு சமுதாயத்தில் சேர்கிறீர்கள், அவர்கள் வல்லுநர்களாக வளரும் உங்கள் பயணத்தைக் கைகோர்க்க முனைந்துள்ளனர். நீங்கள் எந்த கோடியிங் சவாலை சந்தித்தாலும் அல்லது ஒரு வளர்ச்சியை பகிர விரும்பினாலும், சமுதாயம் உங்கள் பயணத்துக்கு ஆதரவாக இருக்கிறது.
