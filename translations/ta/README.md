# 🚀 ஆரம்பநிலை பயனாளிகளுக்கான மாடல் சான்று (MCP) பாடத்திட்டம்

## **C#, Java, JavaScript, Rust, Python மற்றும் TypeScript ஆகிய மொழிகளில் சாதனத்துடன் MCP கற்றல்**

## 🧠 மாடல் சான்று பாடத்திட்டத்தின் மேலோட்டம்
மாடல் சான்று பயணத்தில் உங்களை வரவேற்கிறது! ஏதேனும் AI செயலிகள் எப்படி பல்வேறு கருவிகள் மற்றும் சேவைகளுடன் தொடர்பு கொள்கிறன என்று நீங்கள் ஆச்சரியப்பட்டிருப்பின், இங்கு வடிவமைக்கப்படும் உத்தி உங்கள் புரிதலை மாற்றிவிடும்.

MCP ஐ ஒரு அண்டரிடப்பட்ட மொழிபெயர்ப்பாளராக கருதுங்கள் - உங்கள் கணினியில் ஏதேனும் சாதனத்தை USB போர்ட்கள் மூலம் இணைக்க கூடிய செயல்பாட்டின் போன்று, MCP AI மாடல்களை எந்த கருவி அல்லது சேவையோடு ஒரு ஒருங்கிணைந்த முறையில் இணைக்க அனுமதிக்கிறது. முதல் chatbot உருவாக்குவதாக இருந்தாலும், சிக்கலான AI பணிச்சூழல்களில் இருந்தாலும், MCP ஐ புரிந்து கொண்டு நீங்கள் அதிக திறமையான மற்றும் வகுப்பான செயலிகளை உருவாக்க முடியும்.

இந்த பாடத்திட்டம் உங்கள் கற்றல் பயணத்தை பொறுமையாகவும் கவனமாகவும் வடிவமைக்கப்பட்டுள்ளது. நீங்கள் ஏற்கனவே புரிந்துகொள்ளும் எளிய கருத்துக்களிலிருந்து துவங்கி, உங்கள் விருப்ப மென்பொருள் மொழியில் நடைமுறை மூலம் உங்கள் திறமைகளை வளர்ப்போம். ஒவ்வொரு படியும் தெளிவான விளக்கங்களையும், பயன்பாட்டு உதாரணங்களையும், உற்சாகத்தையும் கொண்டிருக்கும்.

இந்த பயணத்தை முடித்தபோது, நீங்கள் உங்கள் சொந்த MCP சேவைகளை உருவாக்கும், பிரபல AI தளங்களுடன் இணைக்கும் மற்றும் இந்த தொழில்நுட்பம் AI வடிவமைப்பை எதிர்காலத்தில் எவ்வாறு மாற்றியுள்ளது என்பது பற்றி முழுமையாக புரிந்துகொள்ளும் திறன் பெறுவீர்கள். இந்த சுவாரசியமான பயணத்தை ஒன்றாக தொடங்குவோம்!

## கல்வி இலக்குகள்

இந்த பாடத்திட்டத்தை முடிக்கும் பொழுது, நீங்கள் புதிய திறமைகள் குறித்து நம்பிக்கையுடன் மகிழ்ச்சியுடன் இருப்பீர்கள். இதோ நீங்கள் பெறப்போகும் வாய்முறை:

• **MCP அடிப்படைகளை புரிந்து கொள்வது**: மாடல் சான்று என்ன என்பது மற்றும் அது AI செயலிகள் ஒருங்கிணைவதை எவ்வாறு புரட்சி செய்கிறது என்பதை, விளக்கக்காட்சி மற்றும் எடுத்துக்காட்டுகளுடன் புரிந்து கொள்வீர்கள்.

• **உங்கள் முதல் MCP சேவையகத்தை உருவாக்குங்கள்**: நீங்கள் விரும்பும் மென்பொருள் மொழியில் ஒரு செயல்படும் MCP சேவையகத்தை உருவாக்குவீர்கள், எளிய எடுத்துக்காட்டுகளுடன் இருந்து படிப்படியாக திறமைகளை மேம்படுத்துவீர்கள்.

• **AI மாடல்களை உண்மையான கருவிகளுடன் இணைக்கவும்**: AI மாடல்கள் மற்றும் உண்மையான சேவைகளுக்கு இடையேயான இடைவெளியை சிறப்பாக நிரப்புவதைக் கற்றுக்கொள்ளுவீர்கள், உங்கள் செயலிகளுக்கு புதிய சக்திகளை அளிக்கும்.

• **பாதுகாப்பு சிறந்த நடைமுறைகளை செயல்படுத்துங்கள்**: உங்கள் MCP அமல்படுத்தல்களை பாதுகாப்பாக வைத்திருக்கும் திறனை பெறுவீர்கள், உங்கள் செயலிகளையும் பயனர்களையும் பாதுகாக்க.

• **நம்பிக்கையுடன் பயன்பாட்டிற்கு வெளியிடுங்கள்**: உங்கள் MCP திட்டங்களை அபிவிருத்தியிலிருந்து உற்பத்திக்கு மாற்றுவதற்கான நடைமுறை உத்திகளைப் பற்றிய அறிவு பெறுவீர்கள்.

• **MCP சமூையில் இணைந்து செயல்படுங்கள்**: AI செயலி வளர்ச்சிக்கான எதிர்காலத்தை உருவாக்கும் வளர்க்கப்பட்ட அபிவிருத்தியாளர்களின் கூட்டத்தில் நீங்கள் உறுப்பினராக இருப்பீர்கள்.

## அடிப்படையான பின்னணி

MCP சிறப்பம்சங்களில் மூழ்குவதற்கு முன், சில அடிப்படையான கருத்துக்களில் நீங்கள் அமைதியாக இருக்க வேண்டும். இதில் தேர்ச்சி இல்லாவிட்டாலும் கவலைப்படாதீர்கள் - நாங்கள் தேவையான அனைத்தையும் விளக்கிக் கொடுப்போம்!

### சான்றுகளைக் காண்பது (அடித்தளம்)

சான்று என்பது உரையாடலுக்கான விதிகள் போல. நீங்கள் நண்பரை அழைக்கும் போது, இருவரும் "வணக்கம்" என்று சொல்வீர்கள், உரையாடல் முறை ஒன்றை பின்பற்றுவீர்கள், முடிவில் "பிரியா" கூறுவீர்கள். கணினி நிரல்களும் இதே விதமாக உரையாடக்கூடிய விதிகளை தேவைப்படுத்துகின்றன.

MCP என்பது ஒரு சான்று - இது ஒத்துக்கொண்ட விதிகள் தொகுப்பு ஆகும், இது AI மாடல்கள் மற்றும் செயலிகள் கருவிகள் மற்றும் சேவைகளுடன் பயனுள்ள "உரையாடல்களை" செய்ய உதவுகிறது. மனிதர்கள் உரையாடும் விதிகளால் உரையாடல் மேலும் நன்றாக நடைபெறும் போல, MCP உடன் AI செயலிகள் இடையேயான தொடர்பு நம்பகமாகவும் சக்தியுடனும்கூடுகிறது.

### கிளையன்ட்-சேவையகம் உறவுகள் (நிரல்களுக்கான ஒத்துழைப்பு)

நீங்கள் தினமும் கிளையன்ட்-சேவையகம் உறவுகளைப் பயன்படுத்துகிறீர்கள்! இணைய உலாவி (கிளையன்ட்) ஒரு வலைத்தளத்தை அணுகும் போது, ஒரு வலை சேவையகம் உங்களுக்கு பக்கம் உள்ளடக்கத்தை அனுப்புகிறது. உலாவி தகவலை கேட்க முறையாக செயல்படுகிறது, சேவையகம் பதிலளிக்க தெரியும்.

MCP இல் இதே விதியான உறவு உள்ளது: AI மாடல்கள் தகவல் அல்லது நடவடிக்கை கோருவதாக கிளையன்ட்கள் ஆக செயல்படுகின்றன, MCP சேவையகங்கள் அவற்றுக்கு திறன்களை வழங்குகின்றனர். இது AI கேட்கக்கூடிய உதவியாளராக செயல்படும் சேவையகத்தைப் போன்றது.

### ஒற்றுமையமைப்பு ஏன் முக்கியம்? (ஒன்றிணைந்த செயல்பாடு)

ஒவ்வொரு கார்கள் உருவாக்குநரு வேறுபட்ட வடிவின் எரிபொருள் பணியைப் பயன்படுத்தினால் எப்படி இருக்கிறதென நீங்கள் கற்பனை செய்யுங்கள் - ஒவ்வொரு கார் வகைக்கும் வேறான இணைப்பான் தேவைப்படும்! ஒற்றுமையமைப்பு பொதுவான முறைகளை ஒப்புக்கொள்வதை குறிக்கும், அதனால் அனைத்தும் ஒருங்கிணைந்தவையாக செயல்படும்.

MCP AI செயலிகளுக்கு இந்த ஒற்றுமையமைப்பை வழங்குகிறது. ஒவ்வொரு AI மாடலும் வெவ்வேறு கருவிகளுடன் தனிப்பட்ட குறியீடு எழுத வேண்டியதில்லை, MCP அவர்களை ஒருங்கிணைந்த முறையில் தொடர்பு கொள்ள உதவுகிறது. இதன் மூலம் அபிவிருத்தியாளர்கள் ஒரு கருவியை ஒருமுறை உருவாக்கி பல AI அமைப்புகளுடன் பயன்படுத்தலாம்.

## 🧭 உங்கள் கற்றல் பாதை மேலோட்டம்

உங்கள் MCP பயணம் கவனமாக கட்டமைக்கப்பட்டுள்ளது, அதனால் நீங்கள் இடையே இடையே புதிய கருத்துக்களை அறிந்து, பழையவற்றை உறுதிசெய்வீர்கள்.

### 🌱 அடித்தளம் நிலை: அடிப்படைகளை புரிந்துகொள்ளுதல் (Moduleகள் 0-2)

உங்கள் சாகசம் இங்கே துவங்குகிறது! MCP தொடர்பான கருத்துக்களை பரிச்சயமான ஒப்புமைகள் மற்றும் எளிய எடுத்துக்காட்டுகளுடன் அறிமுகப்படுத்துவோம். MCP என்றால் என்ன, அது ஏன் உருவாக்கப்பட்டது, மற்றும் இது AI வளர்ச்சியின் பெரிய படத்தில் எவ்வாறு பொருந்துகிறது என்பதை புரிந்துகொள்ளுவீர்கள்.


• **Module 0 - MCP அறிமுகம்**: MCP என்றால் என்ன மற்றும் அது நவீன AI பயன்பாடுகளுக்கு ஏன் முக்கியமானது என்பதை நாம் ஆராய போகிறோம். MCP செயல்படுவதின் உண்மையான உலக உதாரணங்களை நீங்கள் காண்பீர்கள் மற்றும் அது டெவலப்பர்களுக்கு ஏற்படும் பொதுவான பிரச்சனைகளை எப்படி தீர்க்கிறது என்பதைக் கற்றுக்கொள்வீர்கள்.

• **Module 1 - முக்கியக் கருத்துக்களை விளக்குதல்**: இங்கே MCP இன் அடிப்படை கட்டுமானங்களை நீங்கள் கற்றுக்கொள்ளப்போகிறீர்கள். இந்தக் கருத்துக்களை இயல்பானவையாகவும் புரிந்துகொள்ளத்தக்கதாகவும் செய்ய பல போலிநாட்கைகள் மற்றும் காட்சிப் பட உதாரணங்கள் பயன்படுத்துவோம்.

• **Module 2 - MCP இல் பாதுகாப்பு**: பாதுகாப்பு என்பதில் பதற்றம் அக்கறை ஏற்படலாம், ஆனால் MCP இல் உள்ள உட்புகு பாதுகாப்பு அம்சங்களை எவ்வாறு கொண்டுள்ளது, மற்றும் உங்கள் பயன்பாடுகளை தொடக்கத்திலிருந்தே பாதுகாக்க சிறந்த நடைமுறைகளை நாம் கற்பிப்போம்.

### 🔨 கட்டுமானப் பகுதி: உங்கள் முதல் செயலாக்கங்களை உருவாக்குதல் (Module 3)

இப்போது உண்மையான சந்தோஷம் தொடங்குகிறது! நீங்கள் நேரடியாக MCP சர்வர்கள் மற்றும் கிளையண்ட்களை கட்டியமைக்கும் அனுபவம் பெறுவீர்கள். கவலைப்படாதீர்கள் - நாம் எளிதாக தொடங்கி ஒவ்வொரு படியையும் வழிகாட்டுவோம்.

இந்த மோடுலில் உங்கள் விருப்பமான ப்ரோகிராம்மிங் மொழியில் பயிற்சி பெறவும் பல கைமுறை வழிகாட்டல்கள் உள்ளன. நீங்கள் உங்கள் முதல் சர்வரை உருவாக்கி, அதனைச் சேர்ந்த கிளையண்டை உருவாக்கி, VS கோடு போன்ற பிரபலமான டெவலப்மென்ட் கருவிகளுடன் சேர்க்கலாம்.

ஒவ்வொரு வழிகாட்டலிலும் முழுமையான குறியீட்டு உதாரணங்கள், பிழைதிருத்துக் குறிப்புகள், மற்றும் குறிப்பிட்ட வடிவமைப்பு தேர்வுகளை எதற்கு எடுக்கிறோம் என்பதற்கான விளக்கங்கள் உள்ளன. இந்தப் பகுதியின் இறுதிக்குள், நீங்கள் பெருமைபடத்தக்க செயல்படும் MCP செயலாக்கங்களை கொண்டிருப்பீர்கள்!

### 🚀 வளர்ச்சி பகுதி: மேம்பட்ட கருத்துக்கள் மற்றும் நடைமுறை விண்ணப்பம் (Modules 4-5)

அடிப்படைகளை சமாளித்தபின், நீங்கள் மேலும் நுணுக்கமான MCP அம்சங்களை ஆராயத் தயாராக இருக்கிறீர்கள். நடைமுறை செயலாக்கத் தந்திரங்கள், பிழைதிருத்தி நுட்பங்கள், மற்றும் பன்முக AI ஒருங்கிணைப்பு போன்ற மேம்பட்ட தலைப்புகளை நாங்கள் உள்ளடக்கியுள்ளோம்.

உங்கள் MCP செயலாக்கங்களை தயாரிப்பு பயன்பாட்டிற்கு அளவிடுவது மற்றும் Azure போன்ற மேக வலைத்தளங்களுடன் ஒருங்கிணைக்குவது பற்றியும் நீங்கள் கற்பீர்கள். இந்த மோடுல்கள் உண்மையான உலக தேவைகளை கையாளக்கூடிய MCP தீர்வுகளை உருவாக்க உங்களைத் தயாராக்கும்.

### 🌟 திறமையாக்கு பகுதி: சமூகமும் விசேஷங்கட்சியும் (Modules 6-11)

இறுதி நிலை MCP சமூகத்தில் இணைவதும், உங்கள் ஆர்வத்திற்கு ஏற்ப குறிப்பிட்ட பகுதிகளில் சிறப்பாக தியானிப்பதும் என்பதைக் குறிக்கிறது. திறந்த மூல MCP திட்டங்களுக்கு பங்களிப்பது, மேம்பட்ட அங்கீகார நடைமுறைகள் செயல்படுத்துவது, மற்றும் முழுமையான தரவுத்தள ஒருங்கிணைக்கப்பட்ட தீர்வுகளை உருவாக்குவது ஆகியவையும் கற்றுக்கொள்ளப்படும்.

Module 11 சிறப்பு குறிப்பிடத்தக்கது – இது பதின்மூன்று ஆய்வுகூடங்களில் (labs) முழுமையான கைமுறை கற்றல் பாதை ஆகும், PostgreSQL ஒருங்கிணைப்புடன் தயாரிப்பு-தயார் MCP சர்வர்களை உருவாக்க கற்றுக்கொடுக்கிறது. இது நீங்கள் கற்ற அனைத்தையும் ஒருங்கிணைக்கும் ஒரு முடிவுக் கேப்பாகும்!

## 🎯 MCP கற்றதற்கான முன்னறிவுறைகள்

இந்த பாடத்திட்டத்தில் மிகச்சிறந்த முறையில் பயனடைய, கீழ்காணும் பற்றறிவுகளைக் கொண்டிருக்க வேண்டும்:

- குறைந்தது ஒரு மொழியில் அடிப்படை நிரலாக்க அறிவு: C#, Java, JavaScript, Python அல்லது TypeScript
- கிளையண்ட்-சேவையகம் மாதிரி மற்றும் APIகளின் புரிதல்
- REST மற்றும் HTTPக் கருத்துக்களின் அறிவு
- (அரையறிவு) AI/ML கருத்துக்களின் பின்னணி அறிவு

- ஆதரவிற்கு ჩვენი சமூக கலந்துரையாடல்களில் சேர்ந்தல்

## 📚 படிப்பு வழிகாட்டி மற்றும் ஆதாரங்கள்

இந்த சேமிப்பகத்தில் பல ஆதாரங்கள் உள்ளன உங்கள் பயணத்தையும் கற்றலையும் எளிமைப்படுத்த உதவ:

### படிப்பு வழிகாட்டி

ஒரு விரிவான [படிப்பு வழிகாட்டி](./study_guide.md) உள்ளது இது இந்த சேமிப்பகத்தை திறம்பட பயன்படுத்த வழிகாட்டுகிறது. இந்த பார்வை பாடத்திட்ட வரைபடம் அனைத்து தலைப்புகளும் எப்படி இணைகின்றன என்பதையும் மாதிரிப் பணி உதவித் தகவல்களையும் காட்டுகிறது. பெரிய படத்தை பார்க்க விரும்பும் காணொலி கற்றாளர்களுக்கு இது சிறந்த வழிகாட்டியாகும்.

வழிகாட்டியில் உள்ளவை:
- அனைத்து தலைப்புகளையும் காண்பிக்கும் பார்வை பாடத்திட்ட வரைபடம்
- ஒவ்வொரு சேமிப்பக பகுதியின் விரிவான விளக்கம்
- மாதிரிப் பணிகளை பயன்படுத்த வழிகாட்டி
- விருப்பமான திறன் நிலை கற்றல் பாதைகள்
- உங்கள் கற்றல் பயணத்தை ஆதரிக்கும் கூடுதல் ஆதாரங்கள்

### மாற்றப்படல் பதிவு

நமது விரிவான [மாற்றப்படல் பதிவு](./changelog.md) கற்கைத் தளப் பொருட்களின் முக்கிய மேம்படுத்தல்களை தொடர்கிறது, அதனால் நீங்கள் எப்போதும் சமீபத்திய புதுப்பிப்புகளை அறியலாம்.
- புதிய உள்ளடக்க சேர்க்கைகள்
- கட்டமைப்புப் மாற்றங்கள்
- அம்ச மேம்படுத்தல்கள்
- ஆவண புதுப்பிப்புகள்

## 🛠️ இந்த பாடத்திட்டத்தை திறம்பட பயன்படுத்துவதற்கான வழிகள்

இந்த வழிகாட்டியில் ஒவ்வொரு பாடமும் அடங்கும்:

1. MCP கருத்துக்களின் தெளிவான விளக்கங்கள்

3. உண்மையான MCP பயன்பாடுகளை உருவாக்க பயிற்சிகள்  
4. மேம்பட்ட கற்றாளர்களுக்கான கூடுதல் ஆதாரங்கள்

## 🎓 உங்கள் MCP பயணம் துவங்குகிறது

வாழ்த்துக்கள்! நீங்கள் நிரலாக்க திறன்களை விரிவுபடுத்த நவீனமான AI வளர்ச்சியின் முன்பக்கம் தொடர்புக்கு செல்லும் ஒரு அற்புதமான பயணத்தை துவங்கியுள்ளீர்கள்.

### நீங்களொரு நிலை எட்டித்தீர்கள்

இந்த அறிமுகத்தை வாசிப்பதன் மூலம், நீங்கள் ஏற்கனவே உங்கள் MCP அறிவுத் தளத்தைக் கட்டியெடுத்துள்ளீர்கள். MCP என்றால் என்ன, அது ஏன் முக்கியம், இந்த பாடத்திட்டம் உங்கள் கற்றல் பயணத்தில் எவ்வாறு உதவும் என்பதையும் நீங்கள் புரிந்துகொண்டுள்ளீர்கள். இது ஒரு பெரிய சாதனை மற்றும் இந்த முக்கிய தொழில்நுட்பத்தில் உங்கள் நிபுணத்துவத்தின் முதல் படியாகும்.

### எதிர்கால சவால்கள்

நீங்கள் படிகளை முன்னோக்கி சென்றால், கவனத்தில் கொள்ளுங்கள் ஆரம்ப நிகழ்வுகள் பொதுவாகவே மெதுவாக படிப்படியாக புரிந்துகொள்ளப்படுகின்றன. இப்போது சிக்கலாக தோன்றும் கருத்துக்கள் பயிற்சி மற்றும் செயல்பாட்டால் இயல்பானதாக மாறும். ஒவ்வொரு சிறிய படியும் உங்கள் விரிவான திறன்களை உருவாக்கும், இது உங்கள் வளர்ச்சி வாழ்கைப் பகுதியில் பயன்படும்.

### உங்களுக்கு ஆதரவு வழங்கும் நெட்வொர்க்

நீங்கள் MCPயை ஆர்வமுடன் கற்றுக் கொண்டும் மற்றவர்களுக்கு உதவ ஆர்வமுள்ள கற்றாளர்கள் மற்றும் நிபுணர்கள் குழுவுடன் சேர்ந்துள்ளீர்கள். குறியீட்டுப் பிரச்சனையில் சிக்கினாலும் அல்லது ஒரு சாதனையை பகிர்ந்துகொள்ளவேண்டுமானாலும், சமூக ஒன்று உங்கள் பயணத்தை ஆதரிக்கிறது.

நீங்கள் சிக்கினால் அல்லது AI செயலிகள் உருவாக்கம் பற்றிய கேள்விகள் இருந்தால், MCP பற்றி கற்றாளர்கள் மற்றும் அனுபவசாலிகள் உரையாடல்களில் கலந்துகொள்ளுங்கள். இது கேள்விகளுக்கு எதிர்பார்ப்பும் அறிவு தானாக பகிரப்படும் உதவிப் பிரதேசமாகும்.

### துவங்கத் தயாரா?

உங்கள் MCP பயணம் இப்போது துவங்குகிறது! உங்கள் முதல் MCP அனுபவங்களை அறிந்துகொள்ள Module 0 துவங்கி, அல்லது நீங்கள் உருவாக்கப்போகும் மாதிரிப் பணிகளை ஆராயவும். ஒவ்வொரு நிபுணரும் இப்போலவே துவங்கினர்; பொறுமையும் பயிற்சியும்விட்டு நீங்கள் எதை அடையும் என்பதைப் பாருங்கள்.
