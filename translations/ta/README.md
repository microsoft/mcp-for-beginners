# 🚀 ஆரம்பதர மாணவர்களுக்கு மாதிரி சூழல் நடைமுறை (MCP) பாடத்திட்டம்

## **C#, Java, JavaScript, Rust, Python மற்றும் TypeScript மூலம் MCP-ஐ கைகோர்ந்த குறியீட்டு உதாரணங்களுடன் கற்றுக்கொள்ளுங்கள்**

## 🧠 மாதிரி சூழல் நடைமுறை பாடத்திட்டத்தின் மேற்பார்வை
மாதிரி சூழல் நடைமுறை (Model Context Protocol) பயணத்திற்கு உங்கள் வரவேற்பு! AI பயன்பாடுகள் வெவ்வேறு கருவிகள் மற்றும் சேவைகளுடன் எவ்வாறு தொடர்பு கொள்கின்றன என்று நீங்கள் எப்போதாவது ஆர்வமாயிருக்கின்றீர்களானால், அதன் நடிகைப் புரிதலை மாற்றி அமைக்கும் சோமார்த்தமான தீர்வை தற்போது கண்டுபிடிக்கப் போகிறீர்கள்.

MCP-ஐ AI பயன்பாடுகளுக்கான ஒரு உலகளாவிய மொழிபெயர்ப்பாளராக நினைக்கவும் — USB போர்ட்டுகள் எந்த சாதனத்தையும் உங்கள் கணினியில் இணைக்க உதவுவது போல, MCP AI மாதிரிகளுக்கு எந்த கருவி அல்லது சேவைக்கும் ஒரே விதமான முறையில் இணைக்க உதவுகிறது. நீங்கள் உங்கள் முதல் chatbot-ஐ உருவாக்குகிறீர்களா அல்லது சிக்கலான AI வேலைப்பாடுகளில் ஈடுபடுகிறீர்களா, MCP-ஐப் புரிந்துகொள்ளுதல் முழுமையான மற்றும் விரிவான பயன்பாடுகளை உருவாக்கும் சக்தியைக் கொடுக்கும்.

இந்த பாடத்திட்டம் உங்கள் கற்றல் பயணத்திற்கு பொறுமையும் கவனத்துடனும் வடிவமைக்கப்பட்டது. நீங்கள் முன்பே புரிந்து கொண்ட எளிய கருத்துக்களிலிருந்து ஆரம்பித்து, உங்கள் விருப்பமான நிரலாக்க மொழியில் கைகோர்ந்த பயிற்சியின் மூலம் உங்கள் திறமையை படிப்படியாக உருவாக்குவோம். ஒவ்வொரு படியும் தெளிவான விளக்கங்கள், நடைமுறை உதாரணங்கள் மற்றும் அதிக ஊக்கத்துடன் இருக்கும்.

இந்தப் பயணத்தை முடித்தபோது, நீங்கள் உங்கள் சொந்த MCP சேவையகங்களை உருவாக்குவதற்கும், பிரபலமான AI தளங்களுடன் இணைக்குவதற்கும், இந்த தொழில்நுட்பம் AI மேம்பாட்டின் எதிர்காலத்தை எப்படி மாற்றுகிறது என்பதைப் புரிந்துகொள்ள மிகவும் நம்பிக்கை கொண்டிருப்பீர்கள். இந்த அதிசயமான பயணத்தை ஒன்றாகத் துவங்குவோம்!

### அதிகாரப்பூர்வ ஆவணங்கள் மற்றும் தொழிற்பட்டிகள்

இந்த பாடத்திட்டம் **MCP தொழிற்பட்டி 2025-11-25** (சமீபத்திய நிலையான வெளியீடு) உடன் இணக்கமாக உள்ளது. MCP தொழிற்பட்டி தேதிப்பா் பதிப்பீடு (YYYY-MM-DD வடிவில்) பயன்படுத்தி தெளிவான நடைமுறை பதிப்பு கண்காணிப்பை உறுதிசெய்கிறது.

> **எதிர்கால நோக்கு:** அடுத்த தொழிற்பட்டி பதிப்பு **2026-07-28**-க்கான வெளியீட்டு வேட்பாளரை, ஜூலை 28, 2026 அன்று வெளியிட திட்டமிடப்பட்டுள்ளது. இது பரிமாற்ற அடுக்கில் நிலைத்தன்மையில்லாததாக(protocol stateless) அமைக்கிறது, விரிவாக்கங்கள்(Extensions) கட்டமைப்பை( MCT Apps, பணிகள்) அதிகாரமாக்குகிறது, அங்கீகாரத்தை உறுதி செய்கிறது மற்றும் ரூட்ஸ், சாம்பிளிங் மற்றும் பதிவு செய்வதை(Logging) சுருக்குகிறது. முழுமையான உடைப்புக்காக [MCP-இல் மாற்றங்கள்: 2026-07-28 வெளியீட்டு வேட்பாளர்](./01-CoreConcepts/mcp-2026-07-28-release-candidate.md) பக்கத்தைப் பார்க்கவும்.

இந்த வளங்கள் உங்கள் புரிதல் வளரும்போதே அதிக மதிப்புடனாக மாறும், ஆனால் உடனடி படிப்பதற்குப் பதற வேண்டாம். முதலில் உங்களுக்கு அதிக ஆர்வமான பகுதிகளிலிருந்து தொடங்குங்கள்!
- 📘 [MCP ஆவணங்கள்](https://modelcontextprotocol.io/) – படிப்பதற்கான படிகள் மற்றும் பயனர் வழிகாட்டிகள் கொண்ட உங்கள் முதன்மை வளமாக இது உள்ளது. ஆவணங்கள் துவக்கத்தரங்கள் கவனத்தில் கொண்டு எழுதப்பட்டு, தெளிவான உதாரணங்களுடன் உங்களை வழிநடத்தும்.
- 📜 [MCP தொழிற்பட்டி](https://modelcontextprotocol.io/specification/2025-11-25) – இதனை உங்கள் விரிவான குறிப்பு மய்யமாக எண்ணிக்கொள்ளலாம். பாடத்திட்டத்தில் வேலை செய்யும் போது, நீங்கள் குறிப்பிட்ட விவரங்களைப் பார்க்கவும், மேம்பட்ட சிறப்பம்சங்களை ஆராயவும் இங்கே திரும்பி வருவீர்கள்.
- 📜 [MCP தொழிற்பட்டி பதிப்பு](https://modelcontextprotocol.io/specification/versioning) – இதில் நடைமுறை பதிப்பு வரலாறு மற்றும் எவ்வாறு MCP தேதிப்பா் பதிப்பீட்டை பயன்படுத்துகிறதனின் தகவல்கள் உள்ளன (YYYY-MM-DD வடிவம்).

## கற்றல் நோக்கங்கள்

இந்த பாடத்திட்டத்தை முடிப்பதற்குப் பின்னர், நீங்கள் புதிய திறமைகளால் நம்பிக்கை மற்றும் உற்சாகம் கொண்டிருப்பீர்கள். நீங்கள் பெறப்போகும் திறன்கள்:

• **MCP அடிப்படைகளை புரிந்து கொள்**: மாதிரி சூழல் நடைமுறை என்ன மற்றும் அது AI பயன்பாடுகள் எப்படி இணைந்து செயல்படுவதை மாற்றுகிறது என்பதை விளக்கங்களும் வழக்குகளும் கொண்டு புரிந்து கொள்வீர்கள்.

• **உங்கள் முதல் MCP சர்வரை கட்டமைக்கு**: உங்கள் விருப்ப நிரலாக்க மொழியில் ஒரு வேலை செய்யும் MCP சர்வரை உருவாக்க, எளிய உதாரணங்களுடன் தொடங்கி படி படியாக உங்கள் திறனை மேம்படுத்துவீர்கள்.

• **AI மாதிரிகளை உண்மையான கருவிகளுக்கு இணைப்பு**: AI மாதிரிகளுக்கும் உண்மையான சேவைகளுக்கும் இடையே பாலம் அமைப்பது எப்படி என்பதை கற்றுக் கொண்டு, உங்கள் பயன்பாடுகளுக்கு பல்துறை திறன்களை கொடுப்பீர்கள்.

• **பாதுகாப்பு சிறந்த நடைமுறைகளை செயல்படுத்தவும்**: உங்கள் MCP செயலாக்கங்களை எப்படி பாதுகாப்பாக வைக்க வேண்டும் என்பதை புரிந்து கொண்டு, உங்கள் பயன்பாடுகளையும் பயனர்களையும் பாதுகாப்பீர்கள்.

• **நம்பிக்கையுடன் வெளியிடவும்**: வளர்ச்சி நிலை முதல் உற்பத்தி நிலை வரை உங்கள் MCP திட்டங்களை எவ்வாறு தள்ளுவதற்கு நடைமுறை ரீதியான திட்டங்களை சூழ்ச்சி செய்து செயல்படுத்துவது கற்றுக்கொள்வீர்கள்.

• **MCP சமுதாயத்தில் சேர்ந்துகொள்ளவும்**: AI பயன்பாடுகளை உருவாக்கும் எதிர்காலத்தை வடிவமைக்கும் வளர்ந்துவரும் உருவாக்குநர்களின் சமூகத்தின் ஒரு பகுதியாக மாறுவீர்கள்.

## அடிப்படைக் பின்னணி

MCP-க்கு நுழையாமல் முன் சில அடிப்படைக் கருத்துக்களை மீறல் செய்யலாம். இந்த விடயங்களில் நீங்கள் நிபுணர் இல்லாவிட்டாலும் கவலைப்பட வேண்டாம் - நாம் தேவையான எல்லாவற்றையும் உங்களுக்கு விளக்கிப் போகிறோம்!

### நடைமுறைகள் (Protocols) புரிதல் (அடித்தளம்)

நடைமுறை(protocol) என்பது உரையாடலுக்கான விதிகள் போன்று. நண்பரை அழைக்கும் போது, இருவரும் "வணக்கம்" என்று சொல்வது, உரையாடலில் முறைகேடா மாற்றமென உரிமையுடன் பேசும், முடிந்தபோது "பிரியாதிருங்கள்" என்பதுபோன்ற செய்கள் நாம் ஒப்புக்கொள்கிறோம். கணினி ப்ரோகிராம்களும் ஒவ்வொருவரும் விளக்கம் செய்கின்ற விதிகள் வேண்டும்.

MCP என்பது ஒரு நடைமுறை(protocol) – AI மாதிரிகள் மற்றும் பயன்பாடுகள் கருவிகள் மற்றும் சேவைகளுடன் விளைவாக "உரையாட அனுமதிக்கும் ஒப்புக்கொண்ட விதிகள் தொகுப்பு". மனித உரையாடல் நீடிக்க விதிகள் உதவும் முறையைப் போல, MCP AI பயன்பாடுகளுக்கான தொடர்பை நம்பகமாகவும் சக்திவாய்ந்த முறையாக்கிறது.

### கிளையன்ட்-சர்வர் உறவுகள் (ப்ரோகிராம்கள் எப்படி இணைக்கின்றன)

நீங்கள் தினமும் கிளையன்ட்-சர்வர் உறவுகளைப் பயன்படுத்திக்கொண்டிருக்கிறீர்கள்! வலை உலாவி (கிளையன்ட்) மூலம் ஒரு இணையதளத்தை பார்ப்பது என்பது, இணைய சர்வர் மூலம் பக்க உள்ளடக்கம் அனுப்பப்படவேண்டும் என்று கோருவது போன்றது. உலாவி எப்படி கேட்பது அறிந்திருக்கும், சர்வர் எப்படி பதிலளிக்கிறது என்பதும் தெரியும்.

MCP-இல் இதேபோல் AI மாதிரிகள் தகவல் அல்லது செயலைக் கேட்கும் கிளையன்ட் என்று நடந்து கொள்ளும், MCP சர்வர்கள் அந்த திறன்களை வழங்கும். இது AI வின் உதவியாளர் (சர்வர்) போல் செயல்படுகிறது.

### தரநிலைப்படுத்தல் ஏன் முக்கியம் (ஒருங்கிணைப்புக்கு உதவும்)

ஒவ்வொரு கார் உற்பத்தியாளரும் விதவிதமான எரிவாயு பம்புகளை பயன்படுத்தினால் எப்படி இருக்கும்? ஒவ்வொரு காத்துக்கு வேறொரு அடாப்டர் தேவைப்படும்! தரநிலைப்படுத்தல்(common standard) ஒற்றுமையான அணுகுமுறைகளை ஒப்புக்கொள்வது, காரியங்கள் இணைந்து செயல்பட உதவுகிறது.

MCP AI பயன்பாடுகளுக்கு இந்த தரநிலையை வழங்குகிறது. ஒவ்வொரு AI மாதிரியும் தனித்தனி குறியீடு எழுதாமல், MCP ஐ பயன்படுத்தி அனைத்து கருவிகளுடனும் எளிதாக தொடர்பு கொள்கிறது. இதனால் மென்பொருள் உருவாக்குவோர் ஒருமுறை கருவிகளை உருவாக்கி பல AI அமைப்புகளுடன் செயல்படுத்தக் கூடியதாக மாறுகிறார்கள்.

## 🧭 உங்கள் கற்றல் பாதை மேற்பார்வை

உங்கள் MCP பயணம் படிப்படியாக உங்கள் நம்பிக்கை மற்றும் திறன்களை வளர்க்க கவனமாக வடிவமைக்கப்பட்டுள்ளது. ஒவ்வொரு கட்டத்தாலும் புதிய கருத்துக்களையும் கடந்ததை ஊக்குவிக்கும் முறையையும் பரிமாறுகிறது.

### 🌱 அடித்தளம் கட்டம்: அடிப்படைகளைப் புரிந்துகொள் (கட்டங்கள் 0-2)

இது உங்கள் சாகசம் துவங்கும் இடம்! MCP கருத்துக்களை உங்களுக்குபரிச்சலான ஒப்புக்களுடன் மற்றும் எளிய உதாரணங்களுடன் அறிமுகப்படுத்துகிறோம். MCP என்றால் என்ன, அது ஏன் வேண்டும், AI வளர்ச்சியுடன் எப்படி பொருந்துகிறது என்பதை நீங்கள் புரிந்துகொள்வீர்கள்.

• **கட்ட 0 - MCP அறிமுகம்**: MCP என்பது என்ன என்பது மற்றும் இது நவீன AI பயன்பாடுகளுக்கு எவ்வாறு மிக முக்கியமானது என்பதை ஆராய்ந்து தொடங்குவோம். MCP செயல்படுத்து உண்மையான உலகுக்கான உதாரணங்களுடன் காண்பிப்போம் மேலும் உருவாக்குநர்களைக் கடந்து வரும் பொதுவான சிக்கல்களை எவ்வாறு அது தீர்க்கிறது என்பதை புரிந்துகொள்வீர்கள்.
• **மொட்யூல் 1 - முக்கிய கருத்துக்கள் விளக்கம்**: இங்கே நீங்கள் MCP இன் அடிப்படை கட்டுமானத் தளங்களை கற்றுக்கொள்வீர்கள். இந்த கருத்துக்கள் இயல்பானதும் புரிந்துகொள்ளக் கூடியதும் ஆக இருக்க பல அனலைஜிகள் மற்றும் காட்சிப்படுத்தும் உதாரணங்களைப் பயன்படுத்துகிறோம்.

• **மொட்யூல் 2 - MCP இல் பாதுகாப்பு**: பாதுகாப்பு உள்மயமாக இருக்கக் கூடும், ஆனால் MCP உடன் உள்ள காப்பாற்றும் அம்சங்களை நாம் உங்களுக்கு காட்டி, உங்கள் பயன்பாடுகளை தொடக்கமே பாதுகாக்கும் சிறந்த நடைமுறைகளை கற்றுக்கொடுக்கிறோம்.

### 🔨 கட்டுமான நிலை: உங்கள் முதல் நடைமுறைகளை உருவாக்குதல் (மொட்யூல் 3)

இப்பொழுது உண்மையான சுவை ஆரம்பமாகிறது! நீங்கள் நேரடியாக MCP சேவையகங்கள் மற்றும் கிளையன்ட்களை கட்டியமைக்கும் அனுபவத்தைப் பெறுவீர்கள். கவலைப்பட வேண்டாம் - எளிமையாகத் தொடங்கி, ஒவ்வொரு படியையும் வழிகாட்டுவோம்.

இந்த மோட்யூலில் பல நேரடி வழிகாட்டிகள் உள்ளன, அவை நீங்கள் விரும்பும் நிரல்முறை மொழியில் பிரயாசிப்பதற்கு உதவுகின்றன. உங்கள் முதல் சேவையகத்தை உருவாக்கி, அதை இணைக்க ஒரு கிளையன்ட்டையும் கட்டுவீர்கள், மேலும் VS Code போன்ற பிரபல மேம்பாட்டு கருவிகளோடு ஒருங்கிணைப்பீர்கள்.

ஒவ்வொரு வழிகாட்டியும் முழுமையான குறியீட்டு உதாரணங்கள், சிக்கல் தீர்க்கும் குறிப்புகள் மற்றும் குறிப்பிட்ட வடிவமைப்பு தேர்வுகளின் விளக்கங்களைக் கொண்டுள்ளது. இந்த கட்டுமான நிலையின் முடிவில், நீங்கள் பெருமையுடன் பயன்படுத்தக்கூடிய MCP நடைமுறைகளைப் பெற்றிருக்கலாம்!

### 🚀 வளர்ச்சி நிலை: மேம்பட்ட கருத்துக்கள் மற்றும் நிஜ உலக பயன்பாடு (மொட்யூல்கள் 4-5)

அடிப்படைகளை கையாள்ந்த பின், MCP இன் மேம்பட்ட அம்சங்களை ஆராய தயாராகுங்கள். நடைமுறை செயன்முறை திட்டங்கள், பிழைதிருத்த குறிப்பு முறைகள் மற்றும் பலவகை AI ஒருங்கிணைப்பு போன்ற மேம்பட்ட தலைப்புகளை நாம் எடுத்துக்கொள்வோம்.

MCP நடைமுறைகளைப் பெருக்கி உற்பத்தி பயன்பாட்டிற்காக பரிமாற்றுவது மற்றும் Azure போன்ற மேகவலைப்பாசரிகளில் ஒருங்கிணைப்பது ஆகியவற்றையும் கற்றுக்கொள்வீர்கள். இந்த மோட்யூல்கள் உண்மையான உலக தேவைகளை கையாளக்கூடிய MCP தீர்வுகளை உருவாக்க உங்களைத் தயாராக்குகின்றன.

### 🌟 கவிஞர் நிலை: சமூகமும் துறைகளிலும் சிறப்பு (மொட்யூல்கள் 6-11)

இறுதிப் படி MCP சமூகத்தில் சேர்ந்திடும் மற்றும் உங்களுக்கு மிகவும் ஆர்வமுள்ள துறைகளில் சிறப்பு படைக்கும் சூழலை கவனிக்கிறது. நீங்கள் திறந்த மூல MCP திட்டங்களுக்கு செய்யும் பங்களிப்பு முறைகள், மேம்பட்ட அங்கீகார மாதிரிகள் மற்றும் முழுமையான தரவுத்தள ஒருங்கிணைப்புச் சாதனங்களை கட்டமைத்தல் ஆகியவை கற்றுக்கொள்வீர்கள்.

- உங்கள் கற்றல் பயணத்தை பூர்த்தி செய்ய கூடுதல் வளங்கள்

நீங்கள் MCP குறித்து ஆர்வமுள்ள கற்றல் மற்றும் நிபுணர்களின் சமுதாயத்தில் சேர்கிறீர்கள், மற்றவர்களின் வெற்றிக்காக உதவி செய்ய ஆர்வமாக உள்ளவர்கள். நீங்கள் குறியீடு சவால்களில் சிக்கினால் அல்லது ஒரு முன்னேற்றத்தைப் பகிர விரும்பினாலும், இந்த சமுதாயம் உங்கள் பயணத்திற்கு உதவ தயாராக உள்ளது.

AI செயலிகள் கட்டொடுக்கும் போது சிக்கல் அல்லது கேள்விகள் இருந்தால், MCP குறித்து பேசும் உங்கள் சக கற்றல் குழுவினருடன் இணைவதற்கான இடம் இது. இது கேள்விகள் வரவேற்கப்படும் மற்றும் அறிவு சுதந்திரமாக பகிரப்படும் ஊட்டச்சத்திரமான சமுதாயம்.

### ஆரம்பிக்க தயாரா?

உங்கள் MCP பயணம் இப்போது துவங்குகிறது! உங்கள் முதல் MCP அனுபவங்களுக்காக Module 0யுடன் தொடங்கவும், அல்லது நீங்கள் என்ன கட்டுமென மாதிரி திட்டங்களை ஆராயவும். நினைவில் வையுங்கள் - எல்லா நிபுணர்களும் இப்போது நீங்கள் இருக்கிற அந்த நிலையிலிருந்து துவங்கினர், பொறுமையும் பயிற்சியுடன் நீங்கள் எட்டக்கூடியதை பகிர்வதற்கு பெரிதும் அடையாளமிடுவீர்கள்.

மாடல் கான்டெக்ஸ் புரோட்டோக்கால் மேம்பாட்டின் உலகிற்கு வரவேற்பு. ஒன்றாக அற்புதமான ஒன்றை கட்டுவோம்!

## 🤝 கற்றல் சமூகத்திற்கு பங்களிப்பு

இந்த பாடத்திட்டம் உங்கள் போன்ற கற்றல் ஆர்வலர்களின் பங்களிப்பால் வலுவடைகிறது! உங்கள் பிழைக்குத்திருத்தம், தெளிவான விளக்கம்சொற்சொற்கள், அல்லது புதிய உதாரணச் சேர்க்கைகளாக இருக்கலாம், உங்கள் பங்களிப்புகள் மற்ற ஆரம்பநிலை பயனாளர்களின் வெற்றிக்காக உதவும்.
