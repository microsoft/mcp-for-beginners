# MCP இல் முன்னேற்றமான தலைப்புகள்

[![முன்னேற்றமான MCP: பாதுகாப்பான, விரிவாக்கக்கூடிய மற்றும் பன்முக AI முகவரிகள்](../../../translated_images/ta/06.42259eaf91fccfc6.webp)](https://youtu.be/4yjmGvJzYdY)

இந்த அத்தியாயம் Model Context Protocol (MCP) செயலாக்கத்தில் பன்முக ஒருங்கிணைப்பு, விரிவாக்கம், பாதுகாப்பு சிறந்த நடைமுறைகள் மற்றும் நிறுவன ஒருங்கிணைப்பு உள்ளிட்ட முன்னேற்றமான தலைப்புகளைக் குறித்து கையாள்கிறது. இத்தலைப்புகள் நவீன AI அமைப்புகளின் தேவைகளை பூர்த்தி செய்யக்கூடிய வலுவான மற்றும் உற்பத்தி-தயார் MCP பயன்பாடுகளை உருவாக்குவதற்காக முக்கியமாகும்.

## கண்ணோட்டம்

இந்த பாடம் Model Context Protocol செயலாக்கத்தில் முன்னேற்றக் கருத்துக்களை ஆராய்கிறது, இதில் பன்முக ஒருங்கிணைப்பு, விரிவாக்கம், பாதுகாப்பு சிறந்த நடைமுறைகள் மற்றும் நிறுவன ஒருங்கிணைப்பு முக்கியமாக கவனம் செலுத்தப்படுகிறது. இத்தலைப்புகள் நிறுவன சூழல்களில் சிக்கலான தேவைகளை கையாளக்கூடிய உற்பத்தி-தர MCP பயன்பாடுகளை உருவாக்க மிக அவசியம்.

> **தற்போதைய விவரக்குறிப்பு குறிப்பு:** MCP `2026-07-28` புண்கள் மற்றும்
> பாடங்கள் 5.4 மற்றும் 5.6-இல் உள்ள எடுத்துக்காட்டு அடிப்படைகளை தவிர்க்கிறது. மேலும்
> பரிசோதனை Tasks செயல்பாடு Protocol Features (5.16)ல் குறிப்பிடப்பட்டுள்ளதை
> தனித்துவமான Tasks நீட்டிப்புக்கு நகர்த்துகிறது. அந்த பாடங்கள்
> பழைய `2025-11-25` செயலாக்கங்களுக்கு பராமரிக்கப்பட்டு மாற்ற வழிகாட்டுதலை
> கொண்டுள்ளன. பார்க்க: [MCP-இல் மாற்றங்கள்: 2026-07-28 விவரக்குறிப்பு](../01-CoreConcepts/mcp-2026-07-28.md).

## கற்றல் குறிக்கோள்கள்

இந்த பாடம் முடிவளிக்கும் போது, நீங்கள் செய்யக்கூடியவை:

- MCP கட்டமைப்புகளில் பன்முக திறன்களை செயல்படுத்துதல்
- உயர் கோரிக்கைக்குரிய சூழல்களுக்கு விரிவாக்கக்கூடிய MCP வடிவமைப்புகளை வடிவமைத்தல்
- MCP பாதுகாப்பு கொள்கைகளுக்கு ஏற்ப பாதுகாப்பு சிறந்த நடைமுறைகளைப் பயன்படுத்துதல்
- MCP ஐ நிறுவன AI அமைப்புகள் மற்றும் கட்டமைப்புகளுடன் ஒருங்கிணைத்தல்
- உற்பத்தி சூழல்களில் செயல்திறன் மற்றும் நம்பகத்தன்மையை மேம்படுத்தல்

- பன்முக MCP செயலாக்கங்கள் உரை செயலாக்கத்தை தாண்டி AI திறன்களை விரிவாக்குகின்றன

- முழுமையான பாதுகாப்பு நடவடிக்கைகள் தரவை பாதுகாக்கின்றன மற்றும் சரியான அணுகல் கட்டுப்பாட்டை உறுதி செய்கின்றன
- Azure OpenAI மற்றும் Microsoft AI Foundry போன்ற இயங்குமுறைகளுடன் நிறுவன ஒருங்கிணைப்பு MCP திறன்களை மேம்படுத்துகிறது
- முன்னேற்றமான MCP செயலாக்கங்கள் மேம்படுத்திய கட்டமைப்புகள் மற்றும் கவனமாக வள மேலாண்மையைக் கொண்டு நன்மைகள் பெறுகின்றன

## பயிற்சி

குறிப்பிட்ட பயன்படுத்தும் நிகழ்வுக்காக ஒரு நிறுவன தர MCP செயலாக்கத்தை வடிவமைக்கவும்:

1. உங்கள் பயன்படுத்தும் நிகழ்வுக்கான பன்முக தேவைகளை அடையாளம் காண்க
2. உணர்ச்சி தரவு பாதுகாப்புக்கு தேவையான பாதுகாப்பு கட்டுப்பாடுகளை வரையறுக்கவும்
3. மாறுபடும் சுமையை கையாளக்கூடிய விரிவாக்கக்கூடிய கட்டமைப்பை உருவாக்கவும்
4. நிறுவன AI அமைப்புகளுடன் ஒருங்கிணைப்பு புள்ளிகளை வகைப்படுத்தவும்
5. இச்செயல்திறன் குறைபாடுகளுக்கும் சரி செய்யும் நடைமுறைகளுக்கும் ஆவணம் தயாரிக்கவும்
