# MCP ரூட்கள் (பழைய அம்சம்)

> [!WARNING]
> MCP `2026-07-28` முதல் ரூட்கள் பழையதாக அறிவிக்கப்பட்டுள்ளன. பொருந்துதலுக்காக இவைகள் இந்த திருத்தத்தில் தங்கியுள்ளன 
> மற்றும் 2027 ஜூலை 28 அல்லது அதற்குப்பிறகு வெளியிடப்படும் முதல் குறிப்பிட்ட திருத்தத்தில் நீக்கப்படக்கூடியவை.
> புதிய செயலாக்கங்கள் டூல் பராமரிப்புகள், வள URIகள், அல்லது சேவை பொறுத்தியமைப்புகளை 
> ஊர்வளங்கள் அல்லது கோப்புகளை வழியாக அனுப்ப வேண்டும்.


## மேம்பார்வை

ரூட்கள் ஒரு MCP கிளையண்ட் ஒரு சேவையகம் எந்த கோப்பு அமைப்பு இடங்கள் தொடர்புடையவை என்பதைக் கூற வசதியாக செய்கிறது
தற்போதைய கோரிக்கைக்கு. ஒரு ரூட் ஒரு தேவையான `file://` URI மற்றும் ஒரு விருப்பமான
மனிதப்பாகக் காட்சியிடக்கூடிய பெயரை கொண்டிருக்கும்.

ரூட்கள் தகவல் அடிப்படையிலான குறிப்பு. அவை உரையாடல்-பாடல வரலாறான கொண்டெய்னர்கள் அல்ல,
நெறிமுறை அமர்வுகள் அல்லது அணுகல்-கட்டுப்பாட்டு யந்திரம் அல்ல. நெறிமுறை
ஒரு சேவையகம் பட்டியலிடப்பட்ட ரூட்களில் தங்குவதை கட்டாயப்படுத்தவில்லை.

## கற்றல் குறிக்கோள்கள்

இந்த பாடத்தை முடிக்கும் போது நீங்கள் திறன் பெறுவீர்கள்:

- MCP ரூட்கள் என்ன தெரிவிக்கின்றன மற்றும் என்ன தெரிவிக்கவே இல்லை என்பதைக் விளக்கவும்.
- தற்போதைய `roots/list` பல-சுற்று இயக்கத்தை அடையாளம் காணவும்.
- ரூட்களிலிருந்து தனித்தனியாக பாதுகாப்பு கட்டுப்பாடுகளை பொருத்தவும்.
- புதிய செயல்பாடுகளை ஆதரிக்கப்பட்ட மாற்றுகளுக்கு மாற்றவும்.

## ரூட் தரவு

ஒரு கிளையன்ட் ஒவ்வொரு ரூட்டையும் ஒரு `file://` URI ஆகும் மற்றும் விருப்பமான காட்சிப் பெயரை வழங்குகின்றது:

```json
{
  "roots": [
    {
      "uri": "file:///home/user/projects/weather-service",
      "name": "Weather Service"
    }
  ]
}
```

கிளையன்ட்கள் பயனரால் அனுமதிக்கப்பட்ட இடங்களையே காட்ட வேண்டும். சேவையகங்கள் முடிவைக்
தொடர்புடைய கோப்புகள் குறித்து வழிகாட்டுதலாக கருத வேண்டும், அங்கீகாரத்தின் ஆதாரமாக அல்ல.

## MCP 2026-07-28 ஓட்டு

ரூட்களை ஆதரிக்கும் கிளையன்ட் ஒவ்வொரு கோரிக்கையிலும் திறனை அறிவிக்கின்றது:

```json
{
  "_meta": {
    "io.modelcontextprotocol/clientCapabilities": {
      "roots": {}
    }
  }
}
```

ஒரு கிளையன்ட் கோரிக்கையை செயல்படுத்தும் போது, ஒரு சேவையகம்
`InputRequiredResult` உடைய `roots/list` உள்ளீட்டு கோரிக்கையைத் திருப்பி அனுப்பலாம்:

```json
{
  "resultType": "input_required",
  "inputRequests": {
    "workspaceRoots": {
      "method": "roots/list"
    }
  },
  "requestState": "opaque-state-from-server"
}
```

கிளையன்ட் அங்கீகாரம் பெற்ற ருட்களை சேர்த்து, உள்ளூரான கோரிக்கையை மீண்டும் முயல்கிறது
பொருந்தும் `inputResponses` மற்றும் மாறாத `requestState` உடன். இந்த பல-சுற்று பயணம்
முறை பரிமாற்றத்தை நிலையற்றதாக வைத்திருக்கிறது; எந்த `initialize` கைமுறைச் சந்திப்பு அல்லது
பரிமாற்ற நிலை அமர்வு இருக்காது.

## பழைய 2025-11-25 நடத்துக்கூறு

MCP `2025-11-25` இல், கிளையன்ட்கள் துவக்கப்படுகிற பொழுது ருட்களை விளம்பரப்படுத்தினர். ஒரு சேவையகம்
நேரடி `roots/list` கோரிக்கையை விட கூடும், மற்றும் ஒரு கிளையன்ட்
அதன் ருட்கள் மாற்றப்படும்போது `notifications/roots/list_changed` ஐ அனுப்ப முடியும்.

அந்த வாழ்க்கைச் சுழற்சி பழைய நடத்துக்கூறு ஆகும். அதன் துவக்கப்படுத்தல் மற்றும்
அறிவிப்பு எடுத்துக்காட்டுகளை `2026-07-28` செயலாக்கத்துடன் சேர்க்க வேண்டாம்.

## பரிந்துரைக்கப்படும் மாற்றுகள்

### கருவி அளவுருக்கள்

கருவி உருவமைப்பில் தேவையான கோப்புறை அல்லது கோப்பை தெளிவாக குறிப்பிடுக:

```json
{
  "name": "analyze_project",
  "inputSchema": {
    "type": "object",
    "properties": {
      "projectDirectory": {
        "type": "string",
        "description": "Approved project directory to analyze"
      }
    },
    "required": ["projectDirectory"]
  }
}
```

### வள URIகள்

சேவையகம் தொடர்புடைய கோப்புகளை நிலையான URIகளின் மூலம் வெளிப்படுத்த முடிந்தால் MCP வளங்களைப் பயன்படுத்தவும்.
இது கண்டறிதல் மற்றும் மீட்டெடுப்பை தெளிவாக்குகிறது.

### சர்வர் அமைப்பு

நிலைத்துள்ள அமைப்புகளுக்காக, சர்வர் துவங்கும்போது அனுமதிக்கப்பட்ட அடைவரிசைகளை அமைக்கவும்.
இது பொதுவாக ஒரு உபகரண அழைப்பின் போது அவற்றை கண்டுபிடிப்பதைவிட தெளிவாக உள்ளது.

## பாதுகாப்பு தேவைகள்

நீங்கள் தேர்ந்தெடுக்கக்கூடிய மாற்று எதுவாக இருந்தாலும்:

- கோப்பு அமைப்பு இடங்களை வெளிப்படுத்த முன் பயனர் சம்மதத்தை பெறவும்.
- பயணம் தடுப்பதற்காக பாதைகளை கண்காணித்து சரிபார்க்கவும்.
- அங்கீகாரம் மற்றும் சந்தைப் பாதுகாப்பை ருட் மதிப்புகளிலிருந்து தனித்தனி விலக்கிடவும்.
- கோப்பு அணுகப்படும் பொழுது மட்டுமே உரிமைகளை மீண்டும் சரிபார்க்கவும், தெரிவிக்கப்பட்ட பொழுதல்ல.
- பதிவு அல்லது பிழை செய்திகளில் நுண்ணறிவான பாதைகளை திருப்பி அனுப்பாமல் இருக்கவும்.

## முக்கியக் குறிப்புகள்

- ரூட்கள் தொடர்புடைய கோப்பு அமைப்பு இடங்களை விவரிக்கின்றன; அவை உரையாடல் நிலையை
  சேமிக்கவில்லை.
- ரூட்கள் வழிகாட்டுதலாகும், அணுகல் கட்டுப்பாட்டு எல்லையாக அல்ல.
- MCP `2026-07-28` ஒவ்வொரு கோரிக்கைக்கும் திறன்களை கொண்டுள்ளது மற்றும்
  `InputRequiredResult` ஐ `roots/list` க்காகப் பயன்படுத்துகிறது.
- புதிய அமலாக்கங்கள் பொறிமுறை அளவுருக்கள், வள URI கள் அல்லது சர்வர் அமைப்புகளை பயன்படுத்த வேண்டும்.
