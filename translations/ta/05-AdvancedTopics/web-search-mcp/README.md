# பாடம்: வலைத் தேடல் MCP சர்வரை உருவாக்குதல்

இந்த அத்தியாயம் வெளி API களுடன் ஒருங்கிணைந்து, பல தரவுத்தகுதிகளை கையாள்கிறது, பிழைகளை நிர்வகிக்கிறது மற்றும் பல கருவிகளைக் ஒருங்கிணைக்கிறது — அனைத்தையும் ஒரு தயாரிப்பு-தயார் வடிவில் உருவாக்குவதை கற்றுக் கொடுக்கும். நீங்கள் பார்க்கப்போவது:

- **அங்கீகாரத்தை தேவையாக்கும் வெளி API களுடன் ஒருங்கிணைப்பு**
- **பல முகவரிகள் மூலம் பல்வேறு தரவுத் төрங்களை கையாளுதல்**
- **திடமான பிழை கையாளல் மற்றும் பதிவு நடைமுறைகள்**
- **ஒரே சர்வரில் பல கருவிகளை ஒருங்கிணைத்தல்**

இறுதியில், மேம்பட்ட AI மற்றும் LLM சக்திவாய்ந்த பயன்பாடுகளுக்குத் தேவையான முறைபாடுகள் மற்றும் சிறந்த நடைமுறைகளுடன் நீங்கள் நடைமுறை அனுபவம் பெறுவீர்கள்.

## அறிமுகம்

இந்த பாடத்தில், நீங்கள் SerpAPI பயன்படுத்தி நேரடி இணைய தரவுடன் LLM திறன்களை விரிவுப்படுத்தும் மேம்பட்ட MCP சர்வர் மற்றும் கிளையன்ட் உருவாக்கும் முறையை கற்றுக் கொள்வீர்கள். இது வலைத்தளத்திலிருந்து சமீபத்திய தகவல்களை அணுகக் கூடிய 动적 AI முகவர்களை உருவாக்குவதற்கான முக்கியத் திறனாகும்.

## கற்றல் குறிக்கோள்கள்

இந்த பாடத்தின் இறுதியில், நீங்கள் செய்யக்கூடியவை:

- வெளியீட்டு API களை (SerpAPI போன்றவை) MCP சர்வரில் பாதுகாப்புடன் ஒருங்கிணைத்தல்
- வலை, செய்திகள், தயாரிப்பு தேடல் மற்றும் கேள்வி-பதில் செயலிகளுக்கு பல கருவிகளை அமல் படுத்துதல்
- LLM பயன்பாட்டிற்கு கட்டமைக்கப்பட்ட தரவுகளை பார்ஸ் செய்து வடிவமைத்தல்
- பிழைகளை கையாள்வதும் API வேகக் கட்டுப்பாடுகளை பயிற்சிவசமாக நிர்வகிப்பதும்
- தானியங்கி மற்றும் தொடர்பு வாயிலான MCP கிளையன்ட்களை உருவாக்கி சோதனை செய்தல்

## வலைத் தேடல் MCP சர்வர்

இந்த பகுதி வலைத் தேடல் MCP சர்வரின் கட்டமைப்பு மற்றும் அம்சங்களை அறிமுகப்படுத்துகிறது. FastMCP மற்றும் SerpAPI ஆகியவை ஒன்றாக பயன்படுத்தி LLM திறன்களை நேரடி இணையத் தரவுடன் விரிவுபடுத்துவதை காண்பீர்கள்.

### மேற்பார்வை

இந்த அமலாக்கம் MCP-ன் பலவிதமான, வெளி API-ஆல் இயக்கப்படும் பணிகளை பாதுகாப்பாக மற்றும் திறம்பட கையாளும் திறனைக் காட்டும் நான்கு கருவிகளை கொண்டுள்ளது:

- **general_search**: பொதுவான இணையத் தேடலுக்கு
- **news_search**: சமீபத்திய தலைப்புகளுக்காக
- **product_search**: மின்னாண் வர்த்தகத் தரவுகளுக்காக
- **qna**: கேள்வி-பதில் துணுக்குகளுக்காக

### அம்சங்கள்
- **குறியீடு உதாரணங்கள்**: Python உடன் கூடிய மொழி-செயலரீதிகள் அடங்கிய குறியீடு கிள்ளைகள் (மேலும் மொழிகளுக்கு எளிதில் விரிவாக்கக்கூடியவை) தெளிவான குறியீடு பிம்பங்களுடன்

### Python

```python
# general_search கருவியின் எடுத்துக்காட்டு பயன்பாடு
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def run_search():
    server_params = StdioServerParameters(
        command="python",
        args=["server.py"],
    )
    async with stdio_client(server_params) as (reader, writer):
        async with ClientSession(reader, writer) as session:
            await session.initialize()
            result = await session.call_tool("general_search", arguments={"query": "open source LLMs"})
            print(result)
```

[`server.py`](../../../../05-AdvancedTopics/web-search-mcp/server.py) கோப்பு MCP சர்வரை செயல்படுத்துகிறது, SerpAPI உடன் ஒருங்கிணைந்து வலை, செய்திகள், தயாரிப்பு தேடல் மற்றும் கேள்வி-பதில் கருவிகளை வெளிப்படுத்துகிறது. இது வரும் கோரிக்கைகளை கையாள்கிறது, API அழைப்புகளை நிர்வகிக்கிறது, பதில்களை பார்ஸ் செய்கிறது, மற்றும் கட்டமைக்கப்பட்ட முடிவுகளை கிளையண்டுக்கு திருப்பி விடுகிறது.

முழு அமலாக்கத்தை [`server.py`](../../../../05-AdvancedTopics/web-search-mcp/server.py) இல் பரிசீலிக்கலாம்.

இதோ சர்வர் ஒரு கருவியை எப்படி வரையறுத்து பதிவு செய்கிறது என்பதற்கு சுருக்கமான உதாரணம்:

### Python சர்வர்

```python

    # ...நடைமுறை...
```

- **வெளி API ஒருங்கிணைப்பு**: API விசைகள் மற்றும் வெளி கோரிக்கைகளை பாதுகாப்புடன் கையாளும் முறையை காட்டுகிறது
- **கட்டமைக்கப்பட்ட தரவு பார்சிங்**: API பதில்களை LLM நட்பான வடிவங்களுக்கு மாற்றுவது எப்படி என்பதைக் காட்டுகிறது
- **பிழை கையாளல்**: பயனுள்ள பதிவுகளுடன் திடமான பிழை கையாளல்
- **தொடர்பு வாயிலான கிளையன்ட்**: தானியங்கி சோதனைகள் மற்றும் தொடர்பு வாயிலான பயன்முறை இரண்டும் உள்ளடக்கம்
- **சூழல் நிர்வாகம்**: கோரிக்கைகளை பதிவு செய்வதுக்கும் அஞ்சுவதுக்கும் MCP சூழலை பயன்படுத்துகிறது

## முன் தேவைகள்

தொடங்குமுன், உங்கள் சூழல் சரியாக அமைக்கப்பட்டதா என பின்வரும் அடிப்படைகளை பின்பற்றி உறுதி செய்யவும். இது அனைத்து சார்பு தொகுதிகளும் நிறுவப்பட்டு உங்கள் API விசைகள் கோரிக்கை மற்றும் சோதனைக்கு சரியாக அமைக்கப்பட்டிருக்கும் என்பதனை உறுதி செய்யும்.

- Python 3.8 அல்லது அதற்கு மேல்
- SerpAPI API விசை ([SerpAPI](https://serpapi.com/) இல் பதிவுசெய்து இலவசத் தொகுதி கிடைக்கும்)

## நிறுவல்

தொடங்க, உங்கள் சூழலை அமைக்க பின்வரும் படிகளை பின்பற்செய்யவும்:

1. uv (பிதற்றல் செய்ய பரிந்துரைக்கப்படுகிறது) அல்லது pip பயன்படுத்தி சார்புகளை நிறுவுக:

```bash
# uv பயன்படுத்துதல் (பரிந்துரைக்கப்பட்டது)
uv pip install -r requirements.txt

# pip பயன்படுத்துதல்
pip install -r requirements.txt
```

2. திட்டம் மூலத்தில் `.env` கோப்பை உருவாக்கி உங்கள் SerpAPI விசையை சேர்க்கவும்:

```
SERPAPI_KEY=your_serpapi_key_here
```

## பயன்பாடு

வலைத் தேடல் MCP சர்வர் வலை, செய்திகள், தயாரிப்பு தேடல் மற்றும் கேள்வி-பதில் கருவிகளை SerpAPI உடன் ஒருங்கிணைய வைத்து வெளிப்படுத்தும் முக்கிய கூறு ஆகும். இது வரும் கோரிக்கைகளை கையாள்கிறது, API அழைப்புகளை நிர்வகிக்கிறது, பதில்களை பார்ஸ் செய்து கட்டமைக்கப்பட்ட முடிவுகளை கிளையண்டுக்கு வழங்குகிறது.

MCP சர்வரை இயக்க, பின்வரும் கட்டளை பயன்படுத்தவும்:


சர்வர் stdio அடிப்படையிலான MCP சர்வராக இயங்கும், கிளையன்ட் நேரடியாக அதனுடன் இணைக்க முடியும்.

### கிளையன்ட் முறைகள்

கிளையன்ட் (`client.py`) MCP சர்வருடன் தொடர்பு கொள்ள கீழ்க்காணும் இரண்டு முறைகளை ஆதரிக்கிறது:

- **சாதாரண முறை**: அனைத்து கருவிகளையும் சோதித்து அவற்றின் பதில்களை உறுதிப்படுத்தும் தானியங்கி சோதனைகளை இயக்குகிறது. இது சர்வர் மற்றும் கருவிகள் எதிர்பார்ப்பின்படி வேலை செய்கிறதா என்பதை விரைவாகத் தணிக்க உதவும்.
- **தொடர்பு வாயிலான முறை**: உங்கள் கையேடு தகவல்களை தேர்ந்தெடுத்து கொள்கிறது, ஒவ்வொரு கருவியையும் அழைக்கலாம், தனிப்பயன் வினாக்களை உள்ளிடலாம் மற்றும் நேரடி முடிவுகளை காணலாம். சர்வரினது திறன்களை ஆராய்ந்து வித்தியாசமான உள்ளீடுகளுடன் முயற்சி செய்ய இது சிறந்தது.

முழு அமலாக்கத்தை [`client.py`](../../../../05-AdvancedTopics/web-search-mcp/client.py) இல் பரிசீலிக்கலாம்.

#### MCP Python SDK உடன் தனிப்பயன் சோதனை ஸ்கிரிப்ட்களை எழுதுதல்
MCP Python SDK பயன்படுத்தி உங்கள் சொந்த சோதனை ஸ்கிரிப்ட்களை உருவாக்க முடியும்:

```python

            result = await session.call_tool("general_search", 
                                           arguments={"query": "your custom query"})
```

இந்த சூழலில் "சோதனை ஸ்கிரிப்ட்" என்பது MCP சர்வருக்காக கிளையன்டாக நடக்கும் நீங்கள் எழுதும் தனிப்பயன் Python செயலி ஆகும். இது ஒரு அதிகாரப்பூர்வ அலகு சோதனை அல்ல, உங்கள் தேர்ந்த முடிவுகள் கொண்டு சர்வர் எந்த கருவியையும் அழைக்கவோ, முடிவுகளை விசாரிக்கவோ பயன்படுகிறது. இந்த முறையை பயன்படுத்துவது:
- கருவி அழைப்புகளை முன்மாதிரியிடல் மற்றும் ஆய்வு செய்தல்
- சர்வர் வேறு உள்ளீடுகளுக்கு எப்படி பதிலளிக்கிறது என்பதை சரிபார்த்தல்
- கருவி மீண்டும் மீண்டும் அழைப்புகளை தானியக்கமாக செய்யல்
- MCP சர்வரின் மேல் உங்கள் சொந்த பணிவழிகளை அல்லது ஒருங்கிணைப்புகளை உருவாக்குதல்

புதுமையான வினாக்களை விரைவாக முயற்சி செய்ய, கருவி நடத்தை பிழைத்திருத்தம் செய்ய அல்லது மேம்பட்ட தானியக்கத்தின் தொடக்கமாக இந்த ஸ்கிரிப்ட்களை பயன்படுத்தலாம். கீழே MCP Python SDK பயன்படுத்தி எவ்வாறு ஸ்கிரிப்ட்டை உருவாக்குவது என்பதை எடுத்துக்காட்டு கொடுக்கப்பட்டுள்ளது:

## இந்த பாடத்தில் உள்ள மேம்பட்ட கருத்துக்கள்

உருவாக்கும் முன், இந்த அத்தியாயத்தில் தொடர்ச்சியாக வரும் சில முக்கிய மேம்பட்ட கருத்துக்களைப் பார்ப்போம். இவற்றை புரிந்துகொள்வது, புதியவராக இருந்தாலும் உங்களுக்குத் தொடர உதவும்:

- **பல கருவி ஒருங்கிணைத்தல்**: இது ஒரே MCP சர்வரில் வெவ்வேறு கருவிகள் (வலை தேடல், செய்தி தேடல், தயாரிப்பு தேடல் மற்றும் கேள்வி-பதில்) நிறைவேற்றப்படுவதை குறிப்பிடுகிறது. இது சர்வர் பல பணிகளை ஒருங்கிணைக்க உதவுகிறது.
- **API வேகக் கட்டுப்பாடு கையாள்தல்**: பல வெளி API கள் குறிப்பிட்ட நேரத்தில் செய்யக்கூடிய கோரிக்கைகளின் எண்ணிக்கையை வரையறுக்கின்றன. நல்ல குறியீடு அவற்றை சரிபார்த்து கட்டுப்பாடுகளை அறிவித்து, பயன்பாடு தடுமாற்றமின்றி இயங்க உதவுகிறது.
- **கட்டமைக்கப்பட்ட தரவு பார்சிங்**: API பதில்கள் சிக்கலாகவும் அடுக்குமடங்காகவும் இருப்பார்கள். இதைக் குறைத்து, LLM களை அல்லது பிற செயலிகளுக்கு நட்பான தெளிவான வடிவங்களில் மாற்றுவது.
- **பிழை மீட்பு**: சில சமயம் வலைப்பின்னல் தோல்வியடையும், API எதிர்பார்த்ததை வழங்காமல் போகும். பிழை மீட்பு குறியீடு இந்த சிக்கல்களை கையாள்ந்து பயனுள்ள கருத்துக்களை வழங்குகிறது, செயலியில் முற்றிலும் தோல்வியடையும் பேரின்மையை தவிர்க்கிறது.
- **பரிமாண சரிபார்ப்பு**: அனைத்து கருவிகளுக்கும் உள்ளீடுகள் சரியானதும் பாதுகாப்பானதும் என்பதை உறுதி செய்வது. இயல்புநிலை மதிப்புகள் அமைத்தல் மற்றும் வகைகள் சரியென்றதை சோதனை செய்தல் தவறுகளைத் தடுக்கும் மற்றும் குழப்பத்தைத் தவிர்க்க உதவும்.

இந்த பகுதியில், நீங்கள் Web Search MCP சர்வரை இயக்கும் போது பயரிடக்கூடிய பொதுவான சிக்கல்களை கண்டறிந்து சரி செய்ய உதவும்.

## பிழைத்திருத்தம்

Web Search MCP சர்வருடன் பணியாற்றுகையில், சில சமயங்களில் சிக்கல்கள் வரும் — வெளியீட்டு API களோ, புதிய கருவிகளோ பணியில் இருந்தால்இது இயல்பு. இந்த பகுதி பொதுவான சிக்கல்களுக்கு நடைமுறை தீர்வுகளை வழங்குகிறது, அதனால் விரைவாக வழிப்போக்கலாம். பிழை ஒன்று ஏற்பட்டால், இந்த குறிப்புகள் எந்தப் பிரச்சனைகளை நீங்கள் எதிர்கொள்ள முடியும் என்பதையும் அவற்றை எவ்வாறு சரிசெய்வது என்பதையும் விளக்குகிறது. கூடுதல் உதவி தேவைப்படுமுன் இந்த தீர்வுகளைச் சோதிக்கவும் — பெரும்பாலும் பிரச்சனைகள் இவை மூலம் விரைவில் தீரும்.

பயனர்கள் அடிக்கடி எதிர்கொள்ளும் முக்கிய பிரச்சனைகள் மற்றும் அவற்றுக்கு விளக்கங்கள் மற்றும் தீர்வு படிகள்:

1. **.env கோப்பில் SERPAPI_KEY காணப்படவில்லை**
   - `SERPAPI_KEY environment variable not found` என்ற பிழை வந்தால், உங்கள் பயன்பாட்டிற்கு SerpAPI அணுக API விசை கிடைக்கவில்லை என பொருள்படும். இதற்கு முன் உங்கள் திட்ட மூலப்புப் பகுதியில் `.env` என்ற கோப்பை உருவாக்கி, அதில் `SERPAPI_KEY=your_serpapi_key_here` போன்ற வரி சேருங்கள். `your_serpapi_key_here` இடத்தில் உங்கள் SerpAPI இணையதளத்திலிருந்து பெற்ற உண்மையான விசையை பதிப்பிக்கவும்.

2. **மொடியூல் காணப்பட்ட பிழைகள்**
   - `ModuleNotFoundError: No module named 'httpx'` போன்ற பிழைகள், தேவையான Python தொகுப்பு நிறுவப்படவில்லை என்பதைக் குறிக்கின்றன. இதற்கு `pip install -r requirements.txt` என்ற கட்டளையை உங்கள் டெர்மினலில் இயக்கி எல்லா சார்புகளையும் நிறுவி பிழையை சரி செய்யவும்.

3. **தொடர்பு பிரச்சனைகள்**
   - `Error during client execution` போன்ற பிழைகள் ஏற்பட்டால், அதற்கான காரணம் கிளையன்ட் சர்வருடன் இணைக்க முடியாதது அல்லது சர்வர் எதிர்பார்த்தபடி இயங்கவில்லை ஆக இருக்கலாம். கிளையன்ட் மற்றும் சர்வர் பதிப்புகள் இணக்கமானவையாக இருக்கிறதா, `server.py` சரியான அடைவில் இயங்குகிறதா என்பதை சரிபார்க்கவும். சர்வர் மற்றும் கிளையன்டை மறுதொடக்கம் செய்தாலும் உதவும்.

4. **SerpAPI பிழைகள்**
   - `Search API returned error status: 401` என்றால் உங்கள் SerpAPI விசை காணாமல் போவதாக, தவறாக உள்ளது அல்லது காலாவதியானதாக இருக்கலாம். உங்கள் SerpAPI டாஷ்போர்ட்ல் சென்று விசையை சரிபார்த்து `.env` கோப்பில் புதுப்பிக்கவும். விசை சரியான நிலைபாட்டிலும் இது தொடர்ந்திருந்தால் இலவசத் தொகுதி வரம்பு கடந்துவிட்டதா என பரிசோதிக்கவும்.

### பிழைத்திருத்த முறை (DEBUG Mode)

இயல்புநிலையால், செயலி முக்கியமான தகவல்களை மட்டுமே பதிவுசெய்கிறது. நீங்கள் அதிகதரமான விவரங்கள் (உதாரணமாக, சிக்கல்களை விசாரணை செய்வதற்கு) காண விரும்பினால் DEBUG நிலையை இயக்கலாம். இப்போது செயலியின் ஒவ்வொரு படியையும் விரிவாக காணலாம்.

**உதாரணம்: சாதாரண வெளியீடு**
```plaintext
2025-06-01 10:15:23,456 - __main__ - INFO - Calling general_search with params: {'query': 'open source LLMs'}
2025-06-01 10:15:24,123 - __main__ - INFO - Successfully called general_search

GENERAL_SEARCH RESULTS:
... (search results here) ...
```

**உதாரணம்: DEBUG வெளியீடு**
```plaintext
2025-06-01 10:15:23,456 - __main__ - INFO - Calling general_search with params: {'query': 'open source LLMs'}
2025-06-01 10:15:23,457 - httpx - DEBUG - HTTP Request: GET https://serpapi.com/search ...
2025-06-01 10:15:23,458 - httpx - DEBUG - HTTP Response: 200 OK ...
2025-06-01 10:15:24,123 - __main__ - INFO - Successfully called general_search

GENERAL_SEARCH RESULTS:
... (search results here) ...
```

DEBUG முறையில் HTTP கோரிக்கைகள், பதில்கள் மற்றும் பிற உட்கட்டமைப்பு விவரங்கள் கூடவே பதிவாகின்றன. இது பிழைத்திருத்தத்திற்கு மிகவும் உதவுகிறது.

DEBUG முறையை இயக்க `client.py` அல்லது `server.py` மேலே லாஜிங் நிலையை DEBUG ஆக அமைக்கவும்:

# [Python](#tab/python-debug)
```python
# உங்கள் client.py அல்லது server.py இன் மேல்
import logging
logging.basicConfig(
    level=logging.DEBUG,  # INFO-இல் இருந்து DEBUG-க்கு மாற்றவும்
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s"
)
```
