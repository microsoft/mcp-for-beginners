# ஆரம்பக்காரர்களுக்கான மாதிரி வரையறை நெறிமுறை (MCP) - படிப்புக் கையேடு

"ஆரம்பக்காரர்களுக்கான மாதிரி வரையறை நெறிமுறை (MCP)" பாடத்திட்டத்தின் தொகுப்புக் கட்டமைப்பினும் உள்ளடக்கத்தினும் ஒரு கண்ணோட்டத்தை இந்த படிப்புக் கையேடு வழங்குகிறது. தொகுப்பை திறம்பட எளிதாக்கவும் கிடைக்கக் கூடிய வளங்களை முழுமையாக பயன்படுத்தவும் இந்த கையேட்டை பயன்படுத்துங்கள்.

## தொகுப்பு கண்ணோட்டம்

மாதிரி வரையறை நெறிமுறை (MCP) என்பது AI மாதிரிகளுக்கும் வாடிக்கையாளர் பயன்பாடுகளுக்குமான மோதுச்சிக்கான ஒரு நிலையான படிமுறை ஆகும். ஆரம்பத்தில் Anthropic உருவாக்கியது இது இனிமேல் அதிகாரப்பூர்வ GitHub அமைப்பின் மூலமாக MCP சமுதாயத்தின் பராமரிப்பில் உள்ளது. இந்த தொகுப்பில் C#, Java, JavaScript, Python மற்றும் TypeScript மொழிகளின் செயல்படுத்தும் குறியீடு எடுத்துக்காட்டுகளுடனான விரிவான பாடத்திட்டம் உள்ளது, இது AI வடிவமைப்பாளர்கள், கணினி அமைப்பாளர்கள், மென்பொருள் பொறியாளர்களுக்காக வடிவமைக்கப்பட்டுள்ளது.

## தொகுப்பு கட்டமைப்பு

MCP-இன் வெவ்வேறு அம்சங்களின் மீது கவனம் செலுத்தி, தொகுப்பு பன்னிரண்டு முக்கிய பிரிவுகளாக கட்டமைக்கப்பட்டுள்ளது:

1. **இறுதிச் சுருக்கம் (00-Introduction/)**
   - மாதிரி வரையறை நெறிமுறையின் கண்ணோட்டம்
   - AI வழித்தடங்களில் நிலைப்படுத்தல் ஏன் முக்கியம்
   - நடைமுறை பயன்பாடுகள் மற்றும் நன்மைகள்

2. **மூலம் கருத்துக்கள் (01-CoreConcepts/)**
   - வாடிக்கையாளர்-சேவையாளர் கட்டமைப்பு
   - முக்கிய நெறிமுறை கூறுகள்
   - MCP-இல் செய்தி பரிமாற்ற வழிகள்
   - தற்போதைய விவரிப்பு: [MCP-இல் என்ன மாற்றம் : 2026-07-28 விவரிப்பு](./01-CoreConcepts/mcp-2026-07-28.md) — நிலையற்ற நெறிமுறை மூலக்கூறு, நீட்டிப்பு கட்டமைப்பு மற்றும் இருட்டும்/மாதிரிப்பிடல்/பதிவிடல் நீக்கம்

3. **பாதுகாப்பு (02-Security/)**
   - MCP அடிப்படையிலான அமைப்புகளில் நிகழக்கூடிய பாதுகாப்பு மிரட்டல்கள்
   - செயலாக்கங்களுக்கான சிறந்த நடைமுறைகள்
   - அங்கீகாரம் மற்றும் அங்கீகாராண்மை திட்டங்கள்
   - செயல்பாட்டிற்கான [CIMD மற்றும் DCR அங்கீகார மாதிரி](./02-Security/samples/cimd-dcr-auth/README.md)
   - **விரிவான பாதுகாப்பு ஆவணங்கள்**:
     - MCP பாதுகாப்பு சிறந்த நடைமுறைகள்
     - Azure உள்ளடக்க பாதுகாப்பு செயலாக்கக் கையேடு
     - MCP பாதுகாப்பு கட்டுப்பாடுகள் மற்றும் தொழில்நுட்பங்கள்
     - MCP சிறந்த நடைமுறைகள் விரைவான குறிப்புகள்
   - **முக்கிய பாதுகாப்பு தலைப்புகள்**:
     - குறைகோள் ஊட்டுதல் மற்றும் கருவி நச்சுத்தன்மை தாக்குதல்கள்
     - அமர்வு ஒடுக்குதல் மற்றும் குழப்பமடைந்த அங்கத்தில் பிரச்சினைகள்
     - டோக்கன் வழியாக நுழைவு பாதுகாப்பற்றவை
     - அதிகமான அனுமதிகள் மற்றும் அணுகல் கட்டுப்பாடு
     - AI கூறுகளுக்கான வழங்கல் சங்கிலி பாதுகாப்பு
     - Microsoft குறைகோள் காவலர்கள் ஒருங்கிணைப்பு

4. **துவக்கம் (03-GettingStarted/)**
   - சுற்றுப்புற அமைப்பு மற்றும் அமைப்பு
   - அடிப்படையான MCP சேவையகங்கள் மற்றும் வாடிக்கையாளர்களின் உருவாக்கம்
   - ஏற்கனவே உள்ள பயன்பாடுகளோடு ஒருங்கிணைப்பு
   - பின்வரும் பிரிவுகளைக் கொண்டுள்ளது:
     - முதற் சேவையக நடைமுறை
     - வாடிக்கையாளர் வளர்ச்சி
     - LLM வாடிக்கையாளர் ஒருங்கிணைப்பு
     - VS குறியீட்டு ஒருங்கிணைப்பு
     - சேவையக அனுப்பப்பட்ட நிகழ்வுகள் (SSE) சேவையகம்
     - மேம்பட்ட சேவையக பயன்பாடு
     - HTTP மாற்றல்
    - Microsoft Foundry கருவி ஒருங்கிணைப்பு
     - சோதனை நெறிமுறைகள்
     - பகிர்வு வழிகாட்டிகள்

5. **நடைமுறை செயலாக்கம் (04-PracticalImplementation/)**
   - பல்வேறு நிரல் மொழிகளில் SDK-களை பயன்படுத்துதல்
   - பிழைதிருத்துதல், சோதனை மற்றும் சரிபார்ப்பு தொழில்நுட்பங்கள்
   - மறுபயன்பாடான குறைகோள் மாதிரிகள் மற்றும் பணியாற்று முறைகள் உருவாக்குதல்
   - செயல்படுத்தல் எடுத்துக்காட்டுக்களுடன் மாதிரி திட்டங்கள்

6. **மேம்பட்ட தலைப்புகள் (05-AdvancedTopics/)**
   - சூழல் பொறியியல் தொழில்நுட்பங்கள்
   - Foundry முகவர் ஒருங்கிணைப்பு
   - பன்முறை AI பணியாற்று முறைகள்
   - OAuth2 அங்கீகாரம் முன்னிலைப்படுத்தல்கள்
   - நேரடி தேடல் திறன்கள்
   - நேரடி மாற்றல்
   - கடைசிக் குறிப்புகள் செயலாக்கம்
   - வழிசெலுத்தல் திட்டங்கள்
   - மாதிரிப்பு தொழில்நுட்பங்கள்
   - அளவீடு அணுகுமுறைகள்
   - பாதுகாப்பு கவனிக்கைகள்
   - Entra ID பாதுகாப்பு ஒருங்கிணைப்பு
   - வலை தேடல் ஒருங்கிணைப்பு
   - எதிர்ப்பு பல்கலை முகவர் காரணித்தல் (பாதுகாப்பு வடிவமைப்புகள்)

7. **சமூக பங்களிப்புகள் (06-CommunityContributions/)**
   - குறியீடு மற்றும் ஆவணமிடல் பங்களிப்பது எப்படி
   - GitHub மூலமாக ஒத்துழைப்பு
   - சமூக இயக்கத்தில் முன்னேற்றங்கள் மற்றும் கருத்துக்களைப் பெறுதல்
   - பல MCP வாடிக்கையாளர்களைப் பயன்படுத்துதல் (Claude Desktop, Cline, VSCode)
   - புகழ்பெற்ற MCP சேவையகங்களுடன் வேலை செய்வது, படங்களின் உற்பத்தி உட்பட

8. **ஆரம்பப் பயன்பாட்டின் பாடங்கள் (07-LessonsfromEarlyAdoption/)**
   - நேரடி பயன்பாடுகள் மற்றும் வெற்றிக் கதைகள்
   - MCP அடிப்படையிலான தீர்வுகளை உருவாக்கி வெளியிட்டல்
   - நுட்பம் மற்றும் எதிர்கால திட்டம்
   - **Microsoft MCP சேவையக வழிகாட்டி**: 10 தயாராக்கத்துக்கான Microsoft MCP சேவையகங்களுக்கான முழுமையான வழிகாட்டி, அதில்:

9. **சிறந்த நடைமுறைகள் (08-BestPractices/)**
   - செயல்திறன் மேம்பாடுகள் மற்றும் கதவுகள்

10. **வழங்கும் ஆய்வுகள் (09-CaseStudy/)**
    - MCP பலமுகத்தன்மையை வெளிப்படுத்தும் **ஏழு விரிவான வழக்குக் கேஸ்கள்**:
    - **Azure AI பயண முகவர்கள்**: Azure OpenAI மற்றும் AI தேடலின் பன்முக முகவர் ஒழுங்கமைப்பு
    - **Azure DevOps ஒருங்கிணைப்பு**: YouTube தரவுப் புதுப்பிப்புகளுடன் பணிமுறை தானியங்கி செய்யல்
    - **நேரடி ஆவணங்கள் மீட்டெடுக்கும்**: Python தனியார் வாடிக்கையாளர், Web ஏற்று HTTP மாற்றல் உடன்
    - **உரையாடல் படிப்புத்திட்ட ஜெனரேட்டர்**: Chainlit வலை பயன்பாடு உரையாடல் AI உடன்
    - **எடிட்டரில் உள்ள ஆவணங்கள்**: VS குறியீடு ஒருங்கிணைப்பு GitHub Copilot பணியாற்றுகளுடன்
    - **Azure API மேலாண்மை**: நிறுவனம் API ஒருங்கிணைப்புடன் MCP சேவையகம் உருவாக்குதல்
    - **GitHub MCP பங்கு பதிவேடு**: சூழல் மேம்பாடு மற்றும் முகவர் ஒருங்கிணைப்பு மேடை
    - நிறுவனம் ஒருங்கிணைப்பு, டெவலப்பர் உற்பத்தித்திறன் மற்றும் சூழல் மேம்பாட்டுடன் செயல்படுத்தல் எடுத்துக்காட்டுகள்

11. **கையடக்க பணிமனை (10-StreamliningAIWorkflowsBuildingAnMCPServerWithAIToolkit/)**
