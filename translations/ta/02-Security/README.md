# MCP பாதுகாப்பு: AI அமைப்புகளுக்கான விரிவான பாதுகாப்பு

[![MCP Security Best Practices](../../../translated_images/ta/03.175aed6dedae133f.webp)](https://youtu.be/88No8pw706o)

_(இந்த பாடத்தின் வீடியோவை பார்க்க மேலேயுள்ள படத்தை கிளிக் செய்யவும்)_

பாதுகாப்பு AI அமைப்பு வடிவமைப்பின் அடிப்படையாகும், அதனால் இதை நாங்கள் இரண்டாவது பிரிவாக முன்னுரிமை கொடுப்போம். இது Microsoft இன் **Secure by Design** கொள்கையுடன் பொருந்துகிறது, இது [Secure Future Initiative](https://www.microsoft.com/security/blog/2025/04/17/microsofts-secure-by-design-journey-one-year-of-success/) மூலம் உள்ளது.

Model Context Protocol (MCP) AI-ஐ இயக்கும் பயன்பாடுகளுக்கு சக்திவாய்ந்த புதிய திறன்களை கொண்டு வருவதோடு, பாரம்பரிய மென்பொருள் அபாயங்களை மேல் சென்ற தனித்துவமான பாதுகாப்பு சவால்களையும் அறிமுகப்படுத்துகிறது. MCP அமைப்புகள் பரம்பரிய பாதுகாப்பு கவலைகள் (பாதுகாப்பான குறியீடு, குறைந்த உரிமைகள், வழங்கல் விரைவு பாதுகாப்பு) மற்றும் AI-ஐ சார்ந்த புதிய மிரட்டல்கள் ஆகியவற்றை எதிர்கொள்கின்றன, இதில் விண்ணப்பம் ஊசி சிதைவு, கருவி பூச்சிக்கொல்லல், அமர்வுக் கபம், குழப்பப்பட்ட ஆணையாளர் தாக்கங்கள், டோக்கன் வழிநடத்தல் பாதிப்பு, மற்றும் டைனமிக் திறன் மாற்றம் அடங்கும்.

இந்த பாடம் MCP செயலாக்கங்களில் முக்கியமான பாதுகாப்பு ஆபத்துக்களை ஆராய்கின்றது—அங்கீகாரம், அனுமதி, அதிக உரிமைகள், மறைவர் விண்ணப்ப ஊசி சிதைவு, அமர்வு பாதுகாப்பு, குழப்பமான ஆணையாளர் பிரச்சனைகள், டோக்கன் மேலாண்மை மற்றும் வழங்கல் சுழற்சி அபாயங்களை உள்ளடக்குகிறது. நீங்கள் Microsoft தீர்வுகள் Prompt Shields, Azure Content Safety மற்றும் GitHub Advanced Security போன்றவற்றை பயன்படுத்தி எவ்வாறு இந்த அபாயங்களை குறைக்கவும் MCP பயன்பாட்டை வலுப்படுத்தவும் செயற்பான கட்டுப்பாடுகள் மற்றும் சிறந்த நடைமுறைகளை கற்றுக் கொள்வீர்கள்.

## கற்றல் நோக்குகள்

இந்த பாடத்தின் முடிவில், நீங்கள்:

- **MCP-சார்ந்த மிரட்டல்கள் அடையாளம் காண்பது**: விண்ணப்ப ஊசி சிதைவு, கருவி பூச்சிக்கொல்லல், அதிக உரிமைகள், அமர்வு கபம், குழப்பமான ஆணையாளர் பிரச்சனைகள், டோக்கன் வழிநடத்தல் பாதிப்பு மற்றும் வழங்கல் சுழற்சி அபாயங்கள் போன்ற MCP அமைப்புகளில் உள்ள தனித்துவமான பாதுகாப்பு ஆபத்துகள் அறிதல்
- **பாதுகாப்பு கட்டுப்பாடுகளை பயன்படுத்துவது**: வலுவான அங்கீகாரம், குறைந்த உரிமை அணுகல், பாதுகாப்பான டோக்கன் மேலாண்மை, அமர்வு பாதுகாப்பு கட்டுப்பாடுகள் மற்றும் வழங்கல் சுழற்சி சரிபார்ப்பு போன்ற சக்திவாய்ந்த தடுப்புகளை நடைமுறைப்படுத்தல்
- **Microsoft பாதுகாப்பு தீர்வுகளை பயன்படுத்துவது**: MCP தொழில்நுட்ப பாதுகாப்புக்கு Microsoft Prompt Shields, Azure Content Safety மற்றும் GitHub Advanced Security ஐப் புரிந்து கொண்டு அமல்படுத்தல்
- **கருவி பாதுகாப்பை சரிபார்த்தல்**: கருவி மெட்டாடேட்டா சரிபார்ப்பு, டைனமிக் மாற்றங்களைக் கண்காணித்தல் மற்றும் மறைவர் விண்ணப்ப ஊசி தாக்குதல்களில் இருந்து பாதுகாப்பு மிக முக்கியம் என்பதை அறிதல்
- **சிறந்த நடைமுறைகளை ஒருங்கிணைத்தல்**: பரம்பரிய பாதுகாப்பு அடிப்படைகள் (பாதுகாப்பான குறியீடு, சேவையகம் கடுமையாக்கல், பூஜ்ய நம்பிக்கை) மற்றும் MCP-சார்ந்த கட்டுப்பாடுகளை ஒருங்கிணைத்து விரிவான பாதுகாப்பை உருவாக்குதல்

# MCP பாதுகாப்பு கட்டமைப்பு & கட்டுப்பாடுகள்

நவீன MCP செயலாக்கங்கள் பாரம்பரிய மென்பொருள் பாதுகாப்பும் AI-சார்ந்த மிரட்டல்களையும் கையாளும் படிகள் அடிப்படையிலான பாதுகாப்பு அணுகுமுறைகளை தேவைப்படுத்துகின்றன. விரைவாக மாறும் MCP விவரக்குறிப்பு தனது பாதுகாப்பு கட்டுப்பாடுகளை மேம்படுத்தி வரும்போது, நிறுவன பாதுகாப்பு கட்டமைப்புகளுடன் மற்றும் சிறந்த நடைமுறைகளுடன் சிறந்த ஒருங்கிணைப்பை வழங்குகிறது.

[Microsoft Digital Defense Report](https://aka.ms/mddr) இல் உள்ள ஆய்வு **அறிக்கையிடப்பட்ட மீறும் 98% வலுவான பாதுகாப்பு பராமரிப்பால் தடையிடப்படும்** என்பதை காட்டுகிறது. மிகச் சிறந்த பாதுகாப்பு திட்டம் அடிப்படை பாதுகாப்பு நடைமுறைகள் மற்றும் MCP-சார்ந்த கட்டுப்பாடுகளின் கூட்டுக் கொள்கையை இணைக்கிறது — நிரூபிக்கப்பட்ட அடிப்படைக் பாதுகாப்பு நடவடிக்கைகள் மொத்த பாதுகாப்பு ஆபத்துக்களை குறைக்க மிக முக்கியமானவை.

## 🏔️ MCP பாதுகாப்பு சிமிட் பணிமனை (ஷெர்பா)

**கைமுறை பாதுகாப்பு பயிற்சிக்காக**, நாங்கள் மிக அதிகமாக பரிந்துரைக்கிறோம் **MCP பாதுகாப்பு சிமிட் பணிமனை** (ஷெர்பா) - Microsoft Azure இல் MCP சேவையகங்களை பாதுகாப்பதற்கான விரிவான வழிகாட்டப்பட்ட பயணம்.

### பணிமனைக் கண்ணோட்டம்

[MCP பாதுகாப்பு சிமிட் பணிமனை](https://azure-samples.github.io/sherpa/) "தவறு → விரிவாக்கம் → சரி → சரிபார்ப்பு" முறையை பயன்படுத்தி நடைமுறை, செயற்பான பாதுகாப்பு பயிற்சியை வழங்குகிறது. நீங்கள்:

- **தவறுகளை உடைத்து கற்றல்**: குற்றச்செயல்களை வெளிப்படையாக அனுபவித்து தவறுகள் உள்ள செயலிகளை முற்றிலும் பயன்படுத்தவும்
- **Azure-சார்ந்த பாதுகாப்பு பயன்படுத்தல்**: Azure Entra ID, Key Vault, API குறைவு மேலாண்மை மற்றும் AI உள்ளடக்கம் பாதுகாப்பைப் பயன்படுத்தவும்
- **உடைந்த தடுப்பு பாதுகாப்பை பின்பற்றுதல்**: பாதுகாப்பு அடுக்குகளை கட்டும் முகாம்கள மூலம் முன்னேற்றம்
- **OWASP தரநிலைகளை அமல்படுத்துதல்**: ஒவ்வொரு முறையும் [OWASP MCP Azure பாதுகாப்பு வழிகாட்டி](https://microsoft.github.io/mcp-azure-security-guide/)ற்கேற்ப வரைபடப்படுகின்றது
- **உற்பத்தி குறியீடு பெறுதல்**: செயல்திறனுடன் பணிபுரியும் பரிசோதிக்கப்பட்ட செயல்படுத்தல்களை பெற்றுகொள்ளுங்கள்

### MCP அங்கீகாரத்தின் வளர்ச்சி

அங்கீகாரம் மற்றும் அங்கீகாரத்தின் அணுகுமுறையில் MCP குறிப்பெச்சம் முக்கியமாக வளர்ந்துள்ளது:

- **அசல் அணுகுமுறை**: ஆரம்ப குறிப்பெச்சங்கள் மேம்பாட்டாளர்களை தனிப்பயன் அங்கீகார சேவையகங்களை உருவாக்க வேண்டியது, MCP சேவையகங்கள் ஒவ்வாக OAuth 2.0 அங்கீகார சேவையகங்களாக செயல்பட்டு பயனர் அங்கீகாரத்தை நேரடியாக நிர்வகிக்க வேண்டும்
- **தற்போதைய தரநிலை (`2026-07-28`)**: MCP சேவையகங்கள் அங்கீகாரத்தை வெளிப்புற அடையாள வழங்குநர்களுக்கு பணியாற்றலாம்
  Microsoft Entra ID போன்ற. கிளையண்டுகள் தற்போதைய வெளியீட்டு-சரிபார்ப்பு மற்றும் அங்கீகார-பிணைப்புத் தேவைகளை கடைப்பிடிக்க வேண்டும்.

- **படித்தள பாதுகாப்பு**: உள்ளூர் (STDIO) மற்றும் தொலைவிலுள்ள (Streamable HTTP) இணைப்புகளுக்கான சரியான அங்கீகார மாதிரிகளுடன் பாதுகாப்பான போக்குவரத்து முறைகளுக்கு மேம்பட்ட ஆதரவு

## அங்கீகாரம் மற்றும் அங்கீகார பாதுகாப்பு

### தற்போதைய பாதுகாப்பு சவால்கள்

சமகால MCP அமலாக்கங்கள் பல அங்கீகார மற்றும் அங்கீகார சவால்களை எதிர்கொள்கின்றன:

### அபாயங்கள் மற்றும் மோதல் வழிகள்

- **தவறான அங்கீகார منطிக்கை**: MCP சேவையகங்களில் தவறான அங்கீகார அமல் நுட்பங்கள் முக்கிய தரவை வெளிப்படுத்தும் மற்றும் தவறான அணுகல் கட்டுப்பாடுகளை பயன்படுத்தும்
- **OAuth குறியீட்டின் குறைபாடு**: உள்ளூர் MCP சேவையக குறியீட்டின் திருட்டு தாக்குதலாளர்களுக்கு சேவையகங்களை முன்னிலைப்படுத்துவதற்கும் கீழ்நோக்கி சேவைகளை அணுகுவதற்கும் அனுமதிக்கிறது
- **குறியீடு கடத்தல் பாதுக்காப்பு குறைகள்**: தவறான குறியீடு கையாளுதல் பாதுகாப்பு கட்டுப்பாட்டு முறைகள் மீறல் மற்றும் பொறுப்புணர்வு அகலம் உருவாக்கும்
- **அதிகமாக அனுமதிகள்**: அதிக உரிமைகள் பெற்ற MCP சேவையகங்கள் குறைந்த உரிமை 원則களை மீறி தாக்குதல் பரப்பளவை விரிவாக்குகின்றன

#### குறியீடு கடத்தல்: ஒரு முக்கிய எதிர்முறையாக

**குறியீடு கடத்தல் தற்போது MCP அங்கீகார குறிப்பெச்சத்தில் தடைசெய்யப்பட்டுள்ளது** தீவிர பாதுகாப்பு விளைவுகளுக்காக:

##### பாதுகாப்பு கட்டுப்பாடு மீறல்
- MCP சேவையகங்கள் மற்றும் கீழ்நோக்கி API-கள் முக்கிய பாதுகாப்பு கட்டுப்பாடுகளை (அளவு கட்டுப்பாடு, கோரிக்கை சரிபார்ப்பு, போக்குவரத்து கண்காணிப்பு) தற்போது குறியீடு சரிபார்ப்பை பொருந்துகின்றன
- நேரடி கிளையண்ட்-இல் API குறியீட் பயன்படுத்தல் இந்த அவசியமான பாதுகாப்புகளை தவிர்க்கிறது, பாதுகாப்பு கட்டமைப்பை பாதிக்கிறது

##### பொறுப்புணர்வு மற்றும் கண்காணிப்பு சவால்கள்  
- MCP சேவையகங்கள் மேல்நிலை வழங்கிய குறியீடுகளை பயன்படுத்தும் கிளையண்டுகளை வேறுபடுத்த முடியாது, கண்காணிப்பு டிரெய்ல்களை உடைக்கிறது
- கீழ்நிலை வள சேவையக பதிவுகள் தவறான கோரிக்கை தோற்றங்களை காட்டுகிறது, உண்மையான MCP சேவையக இடைக்காலசெயல்பாட்டாளர்களை அல்ல
- சம்பவ விசாரணை மற்றும் ஒழுங்குமுறை கண்காணிப்புகள் மிகவும் கடுமையாகிறது

##### தரவு திருட்டு அபாயங்கள்
- சரிபார்க்கப்படாத குறியீடு உரிமைகள் திருடப்பட்ட குறியீடுகளை கொண்ட தீவிர தூண்டுவோரை MCP சேவையகங்களை தரவு திருட்டுக்கு பிரதிநிதிகளாக பயன்படுத்த அனுமதிக்கும்
- நம்பிக்கை எல்லை மீறல்கள் முன்மொழியப்பட்ட பாதுகாப்பு கட்டுப்பாடுகளை தவிர்க்கும் அனுமதிக்காத அணுகல் முறைகளை அனுமதிக்கிறது

##### பன்முக சேவை தாக்குதல் வழிகள்
- பல சேவைகள் ஏற்றுக்கொள்ளும் கட்டுப்படுத்தப்பட்ட குறியீடுகள் இணைக்கப்பட்ட அமைப்புகளுக்கு இடையே பக்கவழி நகர்வை குணப்படுத்துகிறது
- குறியீடு தோற்றங்களை சரிபார்க்க முடியாவிட்டால், சேவைகள் இடையேயான நம்பிக்கை ஆக்கங்கள் மீறப்படலாம்

### பாதுகாப்பு கட்டுப்பாடுகள் மற்றும் சமாளிப்புகள்

**முக்கிய பாதுகாப்பு தேவைகள்:**

> **கட்டாயம்**: MCP சேவையகங்கள் **ஒட்டுமொத்தமாக** MCP சேவையகத்திற்கு தெளிவாக வழங்கப்படாத எந்த குறியீடுகளையும் ஏற்றுக்கொள்ளக்கூடாது

#### அங்கீகாரம் மற்றும் அங்கீகார கட்டுப்பாடுகள்

- **கடுமையான அங்கீகார ஆய்வுகள்**: MCP சேவையக அங்கீகார منطிக்கை விரிவான கணக்கெடுப்புகளை மேற்கொள்ளவும், தேவையான பயனாளர்கள் மற்றும் கிளையண்டுகள் மட்டுமே முக்கிய வளங்களை அணுகுகின்றனர் என்பதை உறுதிப்படுத்தவும்
  - **முறையீட்டு வழிகாட்டி**: [Azure API Management as Authentication Gateway for MCP Servers](https://techcommunity.microsoft.com/blog/integrationsonazureblog/azure-api-management-your-auth-gateway-for-mcp-servers/4402690)
  - **அடையாள ஒருங்கிணைப்பு**: [Using Microsoft Entra ID for MCP Server Authentication](https://den.dev/blog/mcp-server-auth-entra-id-session/)

  - குறியீடு பார்வையாளர் உரிமைகள் MCP சேவையக அடையாளத்துடன் பொருந்துவதை சரிபார்க்கவும்
  - சரியான குறியீடு சுழற்சி மற்றும் காலாவதிய கொள்கைகளை செயல்படுத்தவும்
  - குறியீடு மீட்டமைப்பு தாக்குக்களை மற்றும் அனுமதியில்லாத பயன்பாட்டை தடுப்பது

  - **சிறந்த நடைமுறைகள்**: [Secure Token Storage and Encryption Guidelines](https://youtu.be/uRdX37EcCwg?si=6fSChs1G4glwXRy2)

#### அணுகல் கட்டுப்பாடு செயல்படுத்தல்

- **குறைந்த உரிமை 원則ம்**: MCP சேவையகங்களுக்கு திட்டமிட்ட செயல்பாட்டிற்குத் தேவையான குறைந்தபட்ச அனுமதிகளை மட்டுமே வழங்கவும்
  - அனுமதி ஆய்வுகள் மற்றும் புதுப்பிப்புகள் கட்டாயமாக(privilege creep தடுக்கும்)
  - **Microsoft ஆவணம்**: [குறைந்த உரிமை கொண்ட அணுகல் பாதுகாப்பு](https://learn.microsoft.com/entra/identity-platform/secure-least-privileged-access)

- **பங்கு அடிப்படையிலான அணுகல் கட்டுப்பாடு (RBAC)**: நுணுக்கமான பங்கு நியமனங்களை செயல்படுத்தவும்
  - பங்குகளை குறிப்பிட்ட வளங்கள் மற்றும் நடவடிக்கைகளுக்கு கட்டுப்படுத்தவும்
  - பரந்த அல்லது தேவையற்ற அனுமதிகளைத் தவிர்க்கவும், இது தாக்குதல் பரப்பளவை அதிகரிக்கும்

- **தொடர் அனுமதி கண்காணிப்பு**: தொடர்ச்சியான அணுகல் கணக்கெடுப்பு மற்றும் கண்காணிப்பை செயல்படுத்தவும்
  - அனுமதி பயன்பாட்டின் முறைகள் அதிர்ச்சிக்கான ஆய்வுடன் கண்காணிக்கவும்
  - அதிகமாகவோ பயன்படாதவையாகவோ உள்ள அனுமதிகளை உடனடியாக சரி செய்யவும்

### முன்வைக்கும் சூத்திர நுழைவிதி மற்றும் கருவி மர்மச்செயல்கள்

சமகால MCP நடைமுறைகள் AI-க்கு தனித்துவமான தாக்குதல் வழிகளையும் எதிர்கொள்கின்றன, பரம்பரையில் உள்ள பாதுகாப்பு செயல்முறைகள் முழுமையாக கையாள முடியாதவையாகும்:

#### **துப்பறியும் முன்வைக்கும் சூத்திர நுழைவிதி (கிராஸ்-டொமைன் முன்வைக்கும் நுழைவு)**

**துப்பறிந்து முன்வைக்கும் நுழைவிதி** MCP-இன் AI அமைப்புகளில் உள்ள மிக முக்கியமான பாதிப்புகளை பிரதிநிதிக்கிறது. தாக்குதலாளர்கள் தீங்கான வழிமுறைகளை வெளிப்புற உள்ளடக்கங்களில்—ஆவணங்கள், வலைப்பக்கங்கள், மின்னஞ்சல்கள் அல்லது தரவு மூலங்கள்—அமைத்து, AI முறைகள் அவற்றை செல்லுபடியாகக் கொள்ளும் கட்டளைகள் என்று செயல்படுத்துகின்றன.

**தாக்குதல் நிலைகள்:**
- **ஆவண அடிப்படையிலான நுழைவு**: செயல்படுத்தப்படும் ஆவணங்களில் மறைவு தீங்கு விளைவிக்கும் வழிமுறைகள் AI எதிர்பாராத செயல்பாடுகளை தூண்டும்
- **வலை உள்ளடக்க சாப்பிடல்**: இலக்கப்பட்ட வலைப்பக்கங்களில் இணைக்கப்பட்ட முன்வைக்கும் சூத்திரங்கள் AI நடத்தை மாற்றுவதற்கான காரணமாக இருக்கும்
- **மின்னஞ்சல் தாக்குதல்கள்**: மின்னஞ்சல்களில் தீங்கு விளைவிக்கும் முன்வைக்கும் சூத்திரங்கள் AI உதவியாளர்களை தகவல் வெளியீடு அல்லது அனுமதியில்லாத செயல்பாடுகளைச் செய்யட்டும்
- **தரவு மூல பாலூட்டல்**: ஆபாசமான தரவுத்தளங்கள் அல்லது API-கள் மாசுபட்ட உள்ளடக்கங்களை AI முறைகளுக்கு வழங்குகின்றன

**உண்மையான உலக தாக்கம்**: இத்தாக்குதல்கள் தரவு திருட்டு, தனியுரிமை மீறல், தீங்கான உள்ளடக்கம் உருவாக்கம் மற்றும் பயனர் தொடர்புகளை விளையாட்டுப்படுத்தல் ஆகியவற்றை ஏற்படுத்தும். விரிவான பகுப்பாய்விற்கு பார்க்கவும் [Prompt Injection in MCP (Simon Willison)](https://simonwillison.net/2025/Apr/9/mcp-prompt-injection/).

#### **கருவி விஷப்பாய்ச்சி தாக்குதல்கள்**

**கருவி விஷப்பாய்ச்சி** MCP கருவிகளை வரையறுக்கும் மெட்டாடேட்டாவைக் குறிவைத்து தாக்குதலாளர்கள் LLM கள் கருவி விளக்கங்கள் மற்றும் அளவுகோல் விளக்கங்களை அணுகி செயலிழப்பு முடிக்கின்றனர்.

**தாக்குதல் முறைமைகள்:**
- **மெட்டாடேட்டா மாற்றம்**: தாக்குதலாளர்கள் கருவி விளக்கங்கள், அளவுகோல் வரையறைகள் அல்லது பயன்பாட்டு உதாரணங்களில் தீங்கு விளைவிக்கும் வழிமுறைகளை சேர்க்கின்றனர்
- **மறைவு வழிமுறைகள்**: AI மாதிரிகள் செயல்படுத்தும், ஆனால் மனித பயனர்களுக்கு தெரியாத முன்வைக்கும் சூத்திரங்கள் கருவி மெட்டாடேட்டாவில் மறைக்கப்படுகின்றன
- **நடத்தைமாற்ற கருவி மாற்றங்கள் ("ரக் புல்ஸ்")**: பயனர்கள் ஒப்புக்கொண்ட கருவிகள் பின்னர் பயனர் அறிவில்லாமல் தீங்கான செயல்களை செய்கின்றன
- **அளவுகோல் நுழைவு**: கருவி அளவுகோல் வரைபடங்களில் அவர்களது நடத்தைப் பாதிக்கும் தீங்கு விளைவிக்கும் உள்ளடக்கம் இணைக்கப்படுகின்றது


**பதிவேற்றப்பட்ட சர்வர் ஆபத்துக்கள்**: தொலைதூர MCP சர்வர்கள் உயர்ந்த ஆபத்துக்களை வெளிப்படுத்துகின்றன ஏனெனில் கருவி வரையறைகள் ஆரம்ப பயனர் அனுமதிக்கு பிறகு புதுப்பிக்கப்படலாம், இதனால் முன்பிருந்துதான் பாதுகாப்பான கருவிகள் தீங்கிடும் கருவிகளாக மாறும் சூழ்நிலைகள் உருவாகின்றன. விரிவான பகுப்பாய்வுக்கு, [கருவி விஷப்பாய்ச்சல் தாக்குதல்கள் (Invariant Labs)](https://invariantlabs.ai/blog/mcp-security-notification-tool-poisoning-attacks) பார்க்கவும்.

![Tool Injection Attack Diagram](../../../translated_images/ta/tool-injection.3b0b4a6b24de6bef.webp)

#### **தொடர்புள்ள AI தாக்குதல் வழிகள்**

- **குறுக்குவாரம் பதிலடி ஊட்டுதல் (XPIA)**: பல துறைகளில் உள்ள உள்ளடக்கத்தை பயன்படுத்தி பாதுகாப்பு கட்டுப்பாடுகளை தாண்டும் மேம்பட்ட தாக்குதல்கள்
- **இயங்கும் திறன் மாற்றம்**: கருவி திறன்களில் நேரடி மாற்றங்கள் ஆரம்ப பாதுகாப்பு மதிப்பீடுகளை தவிர்க்கும்
- **பொருத்தமான சாளர விஷப்பாய்ச்சல்**: பெரிய பொருத்த சாளரங்களை கையாள்வதன் மூலம் தீங்கான அறிவுரைகளைக் மறைக்கும் தாக்குதல்கள்
- **மாதிரி குழப்பத் தாக்குதல்கள்**: மாதிரி வரையறைகள் மூலம் எதிர்பார்க்கமுடியாத அல்லது பாதுகாப்பற்ற நடத்தை உருவாக்குதல்


### AI பாதுகாப்பு ஆபத்துக் தாக்கம்

**உயர் தாக்கங்களான விளைவுகள்:**
- **தகவல் திருட்டு**: அனுமதியின்றி தனிப்பட்ட அல்லது நிறுவன தரவுகளை அணுகி திருடல்
- **தனியுரிமை மீறல்**: தனிப்பட்ட அடையாளத் தகவல் (PII) மற்றும் ரகசிய வர்த்தக தரவின் வெளியீடு  
- **கணினி இயக்கம் மாற்றங்கள்**: முக்கியமான கணினி அமைப்புகள் மற்றும் வேலைநடத்தல்களில் எதிர்பாராத மாற்றங்கள்
- **அங்கீகாரத் திருட்டு**: ஒத்துழைப்பு குறியீட்டுகள் மற்றும் சேவை அங்கீகாரத் தகவல்களின் முறைகேடு
- **பக்கவாட்டுச் செயல்பாடு**: பாதிக்கப்பட்ட AI அமைப்புகள் மூலம் பெரும்பான்மையான நெட்வொர்க் தாக்குதலுக்கு வழிவகுத்தல்

### மைக்ரோசாஃப்ட் AI பாதுகாப்பு தீர்வுகள்

#### **AI பதிலடி щீல்டுகள்: ஊட்டுதல் தாக்குதல்களுக்கு முன்னணி பாதுகாப்பு**

மைக்ரோசாஃப்ட் **AI பதிலடி щீல்டுகள்** நேரடி மற்றும் மறைமுக ஊட்டுதல் தாக்குதல்களுக்கு பல பாதுகாப்பு அடுக்குகள் மூலம் முழுமையான பாதுகாப்பை வழங்குகின்றன:

##### **முக்கிய பாதுகாப்பு செயல்முறைகள்:**

1. **மேம்பட்ட கண்டறிதல் மற்றும் வடிகட்டி நீக்கம்**
   - இயந்திர கற்றல் அல்காரிதம்கள் மற்றும் NLP தொழில்நுட்பங்கள் வெளிப்புற உள்ளடக்கம் உள்ள தீங்கான உத்தரவுகளை கண்டறியும்
   - ஆவணங்கள், வலைப்பக்கங்கள், மின்னஞ்சல்கள், மற்றும் தரவுத்தளங்களில் உள்ள அச்சுறுத்தல்களை நேரடி ஆய்வு
   - சட்டபூர்வமான மற்றும் தீங்கான பதிலடி மாதிரிகளுக்கு பொருத்தமான புரிதல்

2. **சிறப்பு செயல்முறைகள்**  
   - நம்பகமான கணினி உத்தரவுகளும், சாத்தியமான பாதிக்கப்பட்ட வெளிப்புற உள்ளீடுகளும் வேறுபடுத்தல்
   - கருவிக்கு பொருத்தமான மாற்று முறைகள் ஊட்டப்பட்ட உள்ளடக்கத்தைக் தனிமைப்படுத்தலும் முன்னிறுத்தலும் செய்கின்றன
   - AI அமைப்புகளுக்கு சரியான உத்தரவுக் கட்டமைப்பை பராமரிக்கவும், ஊட்டப்பட்ட உத்தரவேற்புகளை புறக்கணிக்கவும் உதவுகிறது

3. **பாகுபடுத்தல் மற்றும் தரவுச் குறிப்பியல் அமைப்புகள்**
   - நம்பகமான கணினி செய்திகள் மற்றும் வெளிப்புற உள்ளீட்டு உரையில் தெளிவான எல்லைகள்
   - சிறப்பு குறிகள் நம்பகமான மற்றும் நம்பாத தரவு ஆதாரங்களுக்கிடையையுள்ள எல்லைகளை வெளிப்படுத்துகிறது
   - தெளிவான பிரிவினை உத்தரவுக் குழப்பம் மற்றும் அனுமதிக்கப்படாத உத்தரவு நடைமுறைதிறனை தடுக்கும்

4. **தொடர்ச்சியான அச்சுறுத்தல் நுண்ணறிவு**
   - மைக்ரோசாஃப்ட் வளர்ந்து வரும் தாக்குதல் மாதிரிகளை மீண்டும் கட்டுப்படுத்தி பாதுகாப்பை அப்டேட் செய்கிறது
   - புதிய ஊட்டுதல் தொழில்நுட்பங்கள் மற்றும் தாக்குதல் வழிகளை முன்னதாக தேடும்
   - வளர்ந்துவரும் அச்சுறுத்தல்கள் எதிர்ப்பிற்காக பாதுகாப்பு மாதிரிகள் இடப்பெயர்ப்பு

5. **ஆசூர் உள்ளடக்கம் பாதுகாப்பு ஒருங்கிணைப்பு**
   - முழுமையான ஆசூர் AI உள்ளடக்கம் பாதுகாப்பு தொகுப்பின் ஒரு பகுதி
   - கைவிடுத்தல் முயற்சிகள், தீங்கான உள்ளடக்கம் மற்றும் பாதுகாப்பு கொள்கை மீறல் கண்டறிதல் கூடுதல்
   - AI பயன்பாட்டின் அனைத்து கூறுகளிலும் ஒருமித்த பாதுகாப்பு கட்டுப்பாடுகள்

## மேம்பட்ட MCP பாதுகாப்பு அச்சுறுத்தல்கள்

### அமர்வு கைப்பற்றல் பலவீனங்கள்

**அமர்வு கைப்பற்றல்** என்பது நிலையான MCP அமல்களில் முக்கியமான தாக்குதல் வழியாகும், அங்கு அங்கீகரிக்கப்படாத தரப்புகள் உண்மையான அமர்வு அடையாளங்களைப் பெற்று தவறான செயல்களுக்காக உடன்படுகின்றனர்.

#### **தாக்குதல் சூழ்நிலைகள் மற்றும் அபாயங்கள்**

- **அமர்வு ஊட்டல் ஊட்டுதல் தாக்குதல்**: திருடப்பட்ட அமர்வு அடையாளங்கள் உடன் தாக்குதலாளர்கள் அமர்வு நிலையை பகிரும் சர்வர்களுக்கு தீங்கான நிகழ்வுகளை ஊட்டியமைத்து தீங்கு விளைவிக்கலாம் அல்லது நுட்பத் தரவுகளை அணுகலாம்
- **நேரடி மாறுபட்ட குறித்தல்**: திருடப்பட்ட அமர்வு அடையாளங்கள் MCP சர்வர் அழைப்புகளை நேரடியாக அனுமதிப்பதால் தாக்குதலாளர்களை உணவளிப்பாளர்களாக கருதுகிறது
- **பாதிக்கப்பட்ட மீண்டும் தொடக்கக்கூடிய ஓட்டைகள்**: தாக்குதலாளர்கள் கோரிக்கைகளை முன்கூட்டியே நிறுத்தி முறையான வாடிக்கையாளர்கள் தீங்கான உள்ளடக்கத்தோடு மீண்டும் தொடங்க வாய்ப்பு

#### **அமர்வு நிர்வாக பாதுகாப்பு கட்டுப்பாடுகள்**

**முக்கிய தேவைகள்:**
- **அங்கீகரிப்பு சரிபார்ப்பு**: MCP சர்வர்கள் அனைத்து புகுபதிவுகளையும் சரிபார்க்க **தேவை**, அமர்வுகளுக்கு அடிப்படையாக விசுவாசிக்க **முடியாது**
- **பாதுகாப்பான அமர்வு ID உருவாக்கம்**: பாதுகாப்பான பரந்த எண்ணியல் உருவாக்கிகளுடன் இணையற்ற, கடினமான அமர்வு அடையாளங்களை உருவாக்கவும்
- **பயனருக்கு சிறப்பாய் பிணைப்பு**: `<user_id>:<session_id>` போன்ற வடிவங்களில் அமர்வு அடையாளங்களை பயனருக்கு இணைத்தமைத்து வேறு பயனர்களிடையே தோற்றம் தடுக்கும்
- **அமர்வு ஆயுள் நிர்வாகம்**: காலாவதியானது, மாற்றம் மற்றும் செல்லாதல் ஆகியவற்றை சரியாக நடைமுறைப்படுத்தி வெறிச்செயல்களை குறைக்கவும்
- **போக்குவரத்து பாதுகாப்பு**: அனைத்து தொடர்புகளுக்கும் HTTPS தவிர வேறு வழி இல்லாமல் அமர்வு ID திருட்டை தடுக்க வேண்டும்

### குழப்பம் உள்ள டெப்பி பிரச்சனை

**குழப்பமடைந்த டெப்பி பிரச்சனை** MCP சர்வர்கள் வாடிக்கையாளர்களும் மூன்றாம் தரப்பு சேவைகளும் இடையே அங்கீகரிப்பு பூங்காக்களாக செயல்படும்போது ஏற்படும், இது நிலையான வாடிக்கையாளர் ஐடி உடைப்பினால் அங்கீகரிப்பு தவிர்ப்புக்கு வாய்ப்பு அளிக்கிறது.

#### **தாக்குதல் இயந்திரவியல் மற்றும் அபாயங்கள்**

- **குக்கி அடிப்படையிலான ஒப்புதல் தவிர்ப்பு**: பழைய பயனர் அங்கீகாரங்கள் ஒப்புதல் குக்கிகளை உருவாக்கி தாக்குதலாளர்கள் தீங்கான அனுமதி கோரிக்கைகளுடன் செயற்கை மாற்றிய மறுப்பு URI-களை பயன்படுத்தும்
- **அங்கீகரிப்பு குறியீட்டு திருட்டு**: இனி இருந்த ஒப்புதல் குக்கிகள் அங்கீகரிப்பு சேவையகங்களை ஒப்புதல் திரைகள் தவிர்க்க வழிவகுக்கும் மற்றும் குறியீடுகளை தாக்குதலாளர்களின் கட்டுப்பாட்டின் இடங்களுக்கு திருப்புவதாக இருக்கக்கூடும்  
- **அனுமதியற்ற API அணுகல்**: திருடப்பட்ட அங்கீகாரக் குறியீடுகள் மார்பு படுக்கை மற்றும் பயனரை பதிலாளியாக மாற்ற உதவுகின்றன

#### **தடுக்குதல் நுட்பங்கள்**

**கட்டாயமான கட்டுப்பாடுகள்:**
- **தெளிவான ஒப்புதல் தேவை**: மின்மாற்றுக் கணினி உபயோகப்பட்ட MCP பிராக்சி சர்வர்கள் ஒவ்வொரு பதிவு செய்யப்பட்ட வாடிக்கையாளரிடமிருந்தும் பயனர் ஒப்புதலை பெற **தேவை**
- **OAuth 2.1 பாதுகாப்பு நடைமுறைப்படுத்தல்**: அனைத்து அங்கீகரிப்பு கோரிக்கைகளும் தற்போதைய OAuth பாதுகாப்பு பிரதான செயல்முறைகளை பின்பற்ற வேண்டும், இதில் PKCE (Code பரிமாற்றத்திற்கு கீ ஆதாரம்) அடக்கப்பட்டுள்ளது
- **கடுமையான வாடிக்கையாளர் சரிபார்ப்பு**: மறுப்பு URI-களை மற்றும் வாடிக்கையாளர் அடையாளங்களை தீங்கு தவிர்க்கக் காத்துக்கொள்ளும் முறையாக நுணுக்கமாகச் சோதனை செய்ய வேண்டும்

### குறியீட்டு கடத்தல் பலவீனங்கள்  

**குறியீட்டு கடத்தல்** என்பது MCP சர்வர்கள் வாடிக்கையாளர் குறியீடுகளை சரிபார்க்காமல் ஏற்றுக்கொண்டு அவைகளை கீழ்காணும் API-க்களுக்கு அனுப்பி MCP அங்கீகரிப்பு விதிமுறைகளை மீறுவது ஆகும்.

#### **பாதுகாப்பு விளைவுகள்**

- **கட்டுப்பாடு தாண்டல்**: நேர்வழி வாடிக்கையாளர்-API குறியீடு பயன்பாடு கவனிப்பு மற்றும் அளவுகோல் கட்டுப்பாடுகளை தவிர்க்கும்
- **ஆடிட் பாதை பாழ்மை**: மேல்நிலை குறியீடுகள் வாடிக்கையாளர் கண்டறிதலை அசாத்தியமாக்கி சம்பவ விசாரணையை தோற்கடிக்கும்
- **பிராக்சி அடிப்படையிலான தரவு திருட்டு**: சரிபார்க்கப்படாத குறியீடுகள் தவறான தரவுக்கு அனுமதி அளிக்க சர்வர்களைப் பயன்படுத்து
- **நம்பிக்கை எல்லை மீறல்கள்**: குறியீடு தோற்றம் சரிபார்க்கப்படாதபோது கீழே உள்ள சேவைகளின் நம்பிக்கை அவதி எடுக்கலாம்
- **பலசேவை தாக்கல் விரிவாக்கம்**: பல சேவைகளில் ஏற்றுக்கொள்ளப்பட்ட பாதிக்கப்பட்ட குறியீடுகள் பக்கவாட்டுச் செயல்பாட்டுக்கு வழிவகுக்கும்

#### **தேவைப்படும் பாதுகாப்பு கட்டுப்பாடுகள்**

**தரமாக ஏற்கக்கூடிய தேவைகள்:**
- **குறியீடு சரிபார்த்து ஏற்றுதல்**: MCP சர்வர்கள் MCP சர்வருக்காக தெளிவாக வழங்கப்படாத குறியீடுகளை ஏற்கக் கூடாது
- **பரிசோதகர் சரிபார்ப்பு**: குறியீடு பரிசோதகர் கோரல்கள் MCP சர்வரின் அடையாளத்துடன் பொருந்துவதை எப்போதும் சரிபார்க்க வேண்டும்
- **சரியான குறியீடு ஆயுள்**: குறுகியகால அணுகல் குறியீடுகளுடன் பாதுகாப்பான சுழற்சி நடைமுறைகள் செயல் படுத்தப்பட வேண்டும்


## AI அமைப்புகளுக்கான சப்ளை செயின் பாதுகாப்பு

சப்ளை செயின் பாதுகாப்பு பாரம்பரிய மென்பொருள் சார்ந்த கோரிக்கைகளைத் தாண்டி முழு AI சூழலை உள்ளடக்குகிறது. நவீன MCP செயலாக்கங்கள் அனைத்து AI சார்ந்த கூறுகளையும் கடுமையாக சரிபார்க்கவும் கண்காணிக்கவும் வேண்டும், ஏனெனில் ஒவ்வொன்றும் அமைப்பு முழுமையை பாதிக்கும் அபாயத்தைக் கொண்டிருக்கிறது.

### விரிவுபடுத்தப்பட்ட AI சப்ளை செயின் கூறுகள்

**பாரம்பரிய மென்பொருள் சார்ந்தவை:**
- திறந்த மூல நூலகங்கள் மற்றும் கட்டமைப்புகள்
- கண்டெய்னர் படங்கள் மற்றும் அடிப்படை அமைப்புகள்  
- மேம்படுத்தல் கருவிகள் மற்றும் கட்டுமான குழாய்கள்
- கட்டமைப்பு கூறுகள் மற்றும் சேவைகள்

**AI-குறித்த சப்ளை செயின் கூறுகள்:**
- **அடிப்படை மாதிரிகள்**: பல வழங்குநர்களிடமிருந்து முன்பயிற்று மாதிரிகள், உண்மைத்தன்மை ஆராய்ச்சி தேவையானவை
- **உள்ளீடு சேவைகள்**: வெளிப்புற வேக்டர் மற்றும் பொருள் தேடல் சேவைகள்
- **பொருத்தக் கொடுப்பனவாளர்கள்**: தரவுத் தரவுகள், அறிவுக் கொள்கைகள் மற்றும் ஆவணம் களஞ்சியங்கள்  
- **மூன்றாம் தரப்பு API-கள்**: வெளிப்புற AI சேவைகள், மெஷின் லெர்ணிங் குழாய்கள் மற்றும் தரவு செயலாக்க முடிச்சுகள்
- **மாதிரி பொருட்கள்**: எடைகள், அமைப்புகள் மற்றும் சிறப்பாக படிப்பித்த மாதிரி வகைகள்
- **பயிற்சி தரவு ஆதாரங்கள்**: மாதிரி பயிற்சிக்கும் மற்றும் சிறப்பாக மாற்றத்துக்கும் பயன்படுத்தப்பட்ட தரவுத்தொகுப்புகள்

### முழுவாரியான சப்ளை செயின் பாதுகாப்பு யோசனை

#### **கூட்டு உறுதி மற்றும் நம்பிக்கை**
- **உண்மைத்தன்மை சரிபார்ப்பு**: ஒருங்கிணைப்புக்கு முன் அனைத்து AI கூறுகளின் மூலம், உரிமம் மற்றும் முழுமையை சரிபார்க்கவும்
- **பாதுகாப்பு மதிப்பீடு**: மாதிரிகள், தரவுத்தொகுப்புகள் மற்றும் AI சேவைகளுக்கான அபாயப் பரிசோதனைகள் மற்றும் பாதுகாப்பு மதிப்பாய்வுகள் மேற்கொள்ளப்பட வேண்டும்
- **புகழ் பகுப்பாய்வு**: AI சேவை வழங்குநர்களின் பாதுகாப்பு சாதனைகள் மற்றும் நடைமுறைகளை மதிப்பீடு செய்ய வேண்டும்
- **கோப்புரிமை சரிபார்ப்பு**: அனைத்து கூறுகளும் நிறுவனம் பாதுகாப்பு மற்றும் ஒழுங்குவிதி தேவைகளைக் கடைப்பிடிக்க வேண்டும்

#### **பாதுகாப்பான சூழல் கட்டமைப்பு குழாய்கள்**  
- **தானாக இயங்கும் CI/CD பாதுகாப்பு**: தானியங்கி பொருத்தல் குழாய்களில் பாதுகாப்பு ஆய்வை ஒருங்கிணை
- **பொருள் முழுமை**: அனைத்து பொருட்களின் (கோடு, மாதிரிகள், அமைப்புகள்) குறியாக்க சரிபார்ப்பை நடைமுறைப்படுத்தல்
- **முன்மொழியப்பட்ட இயக்கம்**: ஒவ்வொரு கட்டத்திலும் பாதுகாப்பு சரிபார்ப்புடன் மெதுவாக கட்டமைக்க செயல்படுத்தல்
- **நம்பகமான பொருள் களஞ்சியங்கள்**: சரிபார்க்கப்பட்ட மற்றும் பாதுகாப்பான களஞ்சியங்களில் மட்டுமே விநியோகம் செய்தல்

#### **தொடர்ச்சியான கண்காணிப்பு மற்றும் பதிலளிப்பு**
- **அனுகூறு ஆய்வுகள்**: அனைத்து மென்பொருள் மற்றும் AI கூறுகளின் தவறுகள் மற்றும் அபாயங்கள் பற்றிய கண்காணிப்பு
- **மாதிரி கண்காணிப்பு**: மாதிரியின் நடத்தை, செயல்திறன் மாறுதல்கள் மற்றும் பாதுகாப்பு விசேஷங்களை தொடர்ச்சி ஆய்வு செய்தல்
- **சேவை ஆரோக்கியக் கண்காணிப்பு**: வெளிப்புற AI சேவைகள் கிடைக்கும் தகுதி, பாதுகாப்பு சம்பவங்கள் மற்றும் கொள்கை மாற்றங்களை கண்காணித்தல்
- **அச்சுறுத்தல் நுண்ணறிவு ஒருங்கிணைப்பு**: AI மற்றும் ML பாதுகாப்பு அபாயங்களுக்கு சார்ந்த அச்சுறுத்தல் ஊட்டங்களை இணைத்தல்

#### **அணுகல் கட்டுப்பாடு மற்றும் குறைந்த அனுமதி**
- **கூற்று அடிப்படையிலான அனுமதிகள்**: வணிக தேவைக்கு ஏற்ப மாதிரி, தரவு மற்றும் சேவைகளுக்கு அணுகலை கட்டுப்படுத்தல்
- **சேவை கணக்கு மேலாண்மை**: குறைந்த அனுமதிகளுடன் தனிப்பயன் சேவை கணக்குகளை நடைமுறைப்படுத்தல்
- **நெட்வொர்க் பிரிவாக்கம்**: AI கூறுகளை தனிமைப்படுத்தி சேவைகளுக்கு இடையேயான நெட்வொர்க் அணுகலைக் கட்டுப்படுத்தல்
- **API கேட்வே கட்டுப்பாடுகள்**: வெளிப்புற AI சேவைகளுக்கு அணுகலை கட்டுப்படுத்தும் மற்றும் கண்காணிக்கும் மைய API கேட்வேகளை பயன்படுத்து

#### **சம்பவப் பதிலளிப்பு மற்றும் மீட்பு**
- **கிடக்கும் பதிலளிப்பு நடைமுறைகள்**: பாதிக்கப்பட்ட AI கூறுகளை உடனடி புதுப்பித்தல் அல்லது மாற்றத்துக்கான செயல்முறைகள்
- **அங்கீகாரத் சுழற்சி**: ரகசியங்கள், API விசைகள் மற்றும் சேவை அங்கீகாரங்களை தானாக மாற்றும் அமைப்புகள்
- **மீள்பார்வைக் கையாளுதல்**: AI கூறுகளின் முன்னேற்பாடு தருநிலை பதிப்புக்கும் விரைவான மாற்றம் செய்யும் திறன்
- **சப்ளை செயின் மீறல் மீட்பு**: மேல் நிலை AI சேவை பாதிப்புகளுக்கான குறிப்பிட்ட பதிலளிப்பு செயல்முறைகள்

## அடிப்படை பாதுகாப்பு சிறந்த நடைமுறைகள்

MCP செயலாக்கங்கள் உங்கள் நிறுவனத்தின் தற்போதைய பாதுகாப்பு நிலையை பெற்றதும் மேம்படுத்திவிடுவதும் ஆகும். அடிப்படை பாதுகாப்பு நடைமுறைகளை வலுப்படுத்துவது AI அமைப்புகளின் மற்றும் MCP அமலாக்கங்களின் அனைத்து தரப்பிலும் பாதுகாப்பை பெரிதும் மேம்படுத்தும்.

### முக்கிய பாதுகாப்பு அடிப்படைகள்

#### **பாதுகாப்பான மேம்பாட்டு நடைமுறைகள்**
- **OWASP இணக்கம்**: [OWASP டாப் 10](https://owasp.org/www-project-top-ten/) வலை பயன்பாட்டு குறைகளுக்கு எதிராக பாதுகாப்பு
- **AI-குறித்த பாதுகாப்பு**: [LLMs க்கான OWASP டாப் 10](https://genai.owasp.org/download/43299/?tmstv=1731900559) பாதுகாப்பு கட்டுப்பாடுகள் செயல்படுத்தல்
- **பாதுகாப்பான ரகசிய மேலாண்மை**: குறியீடுகள், API விசைகள் மற்றும் செம்மை அமைப்பு தரவுகளுக்கு தனித்துவமான பாதுகாப்புத் தளங்களைப் பயன்படுத்துதல்
- **முழுமையான குறியாக்கம்**: அனைத்து பயன்பாட்டு கூறுகளிலும் மற்றும் தரவு ஓட்டங்களில் பாதுகாப்பான தொடர்பு நடைமுறைப்படுத்தல்
- **உள்ளீடு மதிப்பீடு**: அனைத்து பயனர் உள்ளீடுகள், API அளவுருக்களும் மற்றும் தரவு ஆதாரங்களையும் கடுமையாக மதிப்பாய்வு செய்தல்

#### **அமைப்புறையினை வலுப்படுத்தல்**
- **பலசாதன அங்கீகாரம்**: அனைத்து நிர்வாக மற்றும் சேவை கணக்குகளுக்கும் கட்டாயமான MFA
- **திடீரெதிர் விரைவான புதுப்பிப்புகள்**: செயல்பாட்டு அமைப்புகள், கட்டமைப்புக்கள் மற்றும் சார்புகளுக்கு தானியங்கி முழுமையான புதுப்பித்தல்  
- **அடையாள சேவை ஒருங்கிணைப்பு**: மையப்படுத்தப்பட்ட அடையாள நிர்வாகம் நிறுவன அடையாள சேவைகளால் (Microsoft Entra ID, Active Directory)
- **நெட்வொர்க் பிரிவாக்கம்**: MCP கூறுகளை தரைமட்டமாக தனிமைப்படுத்தி பக்கவாட்டுச் செயல்பாட்டை கட்டுப்படுத்தல்
- **குறைந்தபட்ச அனுமதி கொள்கை**: அனைத்து கூறுகளுக்கும் மற்றும் கணக்குகளுக்கும் மிகக் குறைந்த தேவையான அனுமதிகளை வழங்கல்

#### **பாதுகாப்பு கண்காணிப்பு மற்றும் கண்டறிதல்**
- **முழுமையான பதிவு**: MCP வாடிக்கையாளர்-சர்வர் தொடர்புகளை உள்ளடக்கி AI பயன்பாட்டு செயல்பாடுகளின் விரிவான பதிவு
- **SIEM ஒருங்கிணைப்பு**: மையப்படுத்தப்பட்ட பாதுகாப்பு தகவல் மற்றும் சம்பவ மேலாண்மைக்கு நோயறிதலை எளிதாக்குதல்
- **நடத்தை பகுப்பாய்வு**: அமைப்பு மற்றும் பயனர் நடத்தைவில் வெவ்வேறு மாதிரிகளை கண்டறித AI ஆல் இயக்கப்படும் கண்காணிப்பு
- **அச்சுறுத்தல் நுண்ணறிவு**: வெளிப்புற அச்சுறுத்தல் ஊட்டங்களும் மற்றும் உடன்படல் குறியீடுகளும் இணையல்
- **சம்பவப் பதிலளிப்பு**: பாதுகாப்பு சம்பவ கண்டறிதல், பதிலளிப்பு மற்றும் மீட்பு நடைமுறைகள்

#### **சூன்ய நம்பிக்கை கட்டமைப்பு**
- **நம்பாமல் தொடங்குங்கள், எப்போதும் உறுதிப்படுத்துங்கள்**: பயனர்கள், சாதனங்கள் மற்றும் நெட்வொர்க் இணைப்புக்கள் தொடர்ந்து உறுதிப்படுத்தப்பட வேண்டும்
- **சிறு பிரிவு நெட்வொர்க் கட்டுப்பாடுகள்**: தனித்த துறைப்பணிகள் மற்றும் சேவைகளைக் தனியாக தனிமைப்படுத்த சக்தி வாய்ந்த கட்டுப்பாடுகள்
- **அடையாளமொழி சார்ந்த பாதுகாப்பு**: நெட்வொர்க் இருப்பிடத்துக்கு பதிலாக உறுதிசெய்யப்பட்ட அடையாளத்தின் அடிப்படையில் பாதுகாப்பு கொள்கைகள்
- **தொடர்ச்சி ஆபத்து மதிப்பீடு**: தற்போதைய சூழல் மற்றும் நடத்தை அடிப்படையில் வேகமாக மாற்றக்கூடிய பாதுகாப்பு நிலை மதிப்பாய்வு
- **கூடுதல் அணுகல் கட்டுப்பாடு**: ஆபத்து காரணிகள், இடம் மற்றும் சாதன நம்பிக்கையை பொறுத்து மாற்றக்கூடிய அணுகல் கட்டுப்பாடுகள்

### நிறுவன ஒருங்கிணைப்பு மாதிரிகள்

#### **Microsoft பாதுகாப்பு சூழல் ஒருங்கிணைப்பு**
- **Microsoft Defender for Cloud**: முழுமையான மேகம் பாதுகாப்பு நிலை நிர்வாகம்
- **Azure Sentinel**: AI பணிகளை பாதுகாக்க மேகம் சார்ந்த SIEM மற்றும் SOAR செயல்பாடுகள்
- **Microsoft Entra ID**: குறைநிலை அணுகல் கொள்கைகளுடன் நிறுவன அடையாள மற்றும் அணுகல் மேலாண்மை
- **Azure Key Vault**: ஹார்ட்வேர் பாதுகாப்பு அலகுடன் மையப்படுத்தப்பட்ட ரகசிய மேலாண்மை
- **Microsoft Purview**: AI தரவு ஆதாரங்கள் மற்றும் வேலைநடத்தலுக்கான தரவு ஆளுமை மற்றும் ஒழுங்குமுறை இணக்கம்

#### **ஒழுங்குமுறை மற்றும் ஆளுமை**
- **ஒழுங்குமுறை இணக்கம்**: MCP செயல்பாடுகள் தொழில்துறை தனிப்பட்ட ஒழுங்குமுறை தேவைகள் (GDPR, HIPAA, SOC 2) பூர்த்திசெய்யும் என்பதை உறுதிசெய்க

- **தரவு வகைப்படுத்தல்**: AI அமைப்புகள் செயல்படுத்தும் நுண்ணறிவு தரவின் சரியான வகைப்பாடு மற்றும் கையாள்தல்
- **ஆடிட் துவாரங்கள்**: ஒழுங்குமுறை இணக்கமானதற்கும் விசாரணை ஆய்வுக்குமான விரிவான பதிவு மருத்துவம்
- **தனியுரிமை கட்டுப்பாடுகள்**: AI அமைப்பு வடிவமைப்பில் தனியுரிமை-நியமனக் கொள்கைகளின் நிறைவேற்பு
- **மாற்ற மேலாண்மை**: AI அமைப்பு மாற்றங்களுக்கான பாதுகாப்பு ஆய்வுகளுக்கான திட்டமிட்ட செயல்முறை

இந்த அடிப்படை நடைமுறைகள் MCP-சார்ந்த பாதுகாப்பு கட்டுப்பாடுகளின் திறனை மேம்படுத்தும் வலுவான பாதுகாப்பு அடித்தளத்தை உருவாக்கி, AI இயக்கும் செயலிகளை முழுமையாக பாதுகாப்பதாக வழங்குகின்றன.

## முக்கிய பாதுகாப்பு எடுத்துக் கொள்ளுதல்கள்

- ** அடுக்குப்பொருந்திய பாதுகாப்பு அணுகுமுறை **: அடிப்படையான பாதுகாப்பு நடைமுறைகளை (பாதுகாப்பான குறியாக்கம், குறைந்த அனுமதி, கொள்முதல் சங்கிலி சான்றிதழ், தொடர்ச்சியான கண்காணிப்பு) AI-க்கு தனிப்படுத்தப்பட்ட கட்டுப்பாடுகளுடன் இணைத்தல் மூலம் முழுமையான பாதுகாப்பு

- **AI-க்கு தனிப்பட்ட ஆபத்து சூழல்**: MCP அமைப்புகள் வெவ்வேறு ஆபத்துக்களை சமாளிக்கின்றன - முன்னுரிமை ஊசியொட்டு, கருவி விஷமம், அமர்வு கவர்ச்சி, குழப்பான தட்டுப்படி பிரச்சினைகள், டோக்கன் கடந்துச்செலுத்தும் பாதிப்புகள், மிகுந்த அனுமதிகள் - இவை எல்லாவற்றையும் சிறப்பு தடைகள் தேவைப்படுகின்றன

- **அங்கீகாரம் மற்றும் அங்கீகார சிறப்புத்தன்மை**: வெளி அடையாள வழங்குநர்களைக் (Microsoft Entra ID) கொண்டு வலுவான அங்கீகாரத்தை நடைமுறைப்படுத்தி, சரியான டோக்கன் செல்லுபடுதலை ஏற்றுக்கொண்டு, உங்கள் MCP சேவையகத்திற்கே வெளியிடப்படாத டோக்கன்களை ஐயமாய் ஏற்காதீர்கள்

- **AI தாக்க தடுப்பு**: நேரடி முன்பதிவு ஊசியொட்டு மற்றும் கருவி விஷமத் தாக்குதல் எதிர்ப்பு நோக்குடன் Microsoft Prompt Shields மற்றும் Azure Content Safety-ஐ பயன்படுத்தி, கருவி சொருக்களை சரிபார்த்து, பண்பாற்ற மட்டுப்பாடுகளை கண்காணித்தல்

- **அமர்வு மற்றும் ஞாபக பாதுகாப்பு**: உபயோகப்படுத்துநர்களின் அடையாளங்களுடன் பிணைக்கப்பட்ட கிரிப்டோ கருதுகோள்படுத்தப்பட்ட, தீர்மானமற்ற அமர்வு ஐடிங்கள் பயன்படுத்தி சரியான அமர்வு ஆயுள் கையாள்வை நடைமுறைப்படுத்தி, அமர்வுகளை அங்கீகாரத்திற்கு பயன்படுத்த வேண்டாம்

- **OAuth பாதுகாப்பு சிறந்த நடைமுறைகள்**: தானாக பதிவு செய்யப்பட்ட கிளையண்டுக்களுக்கு பயனர் தெளிவான ஒப்புதலை பெறியே குழப்பான தட்டுப்படி தாக்குதல்களைத் தடுப்பது, PKCE உடன் OAuth 2.1-ஆன நடைமுறைப்படுத்தல் மற்றும் கட்டுப்படுத்தப்பட்ட redirect URI சரிபார்ப்பு

- **டோக்கன் பாதுகாப்பு கொள்கைகள்**: டோக்கன் கடந்துச்செல்லும் வழக்குகளை தவிர்த்து, டோக்கன் பார்வையாளர் உரிமைகள் சரிபார்த்து, குறுகிய ஆயுஷ்கால டோக்கன்கள் மற்றும் பாதுகாப்பான மீட்பை செயல்படுத்தி, தெளிவான நம்பிக்கை எல்லைகள் பராமரிப்பு

- **விரிவான கொள்முதல் சங்கிலி பாதுகாப்பு**: அனைத்து AI சூழல் கூறுகளையும் (மாதிரிகள், இணைப்புகள், சூழல் வழங்குநர்கள், வெளியே API-கள்) பாரம்பரிய மென்பொருள் சார்புகள் போன்று கடுமையான பாதுகாப்புடன் கையாளுதல்

- **தொடர்ந்த முன்னேற்றம்**: விரைவாக மாறும் MCP விளக்கப்படங்களுடன் ஒருங்கிணைந்து, பாதுகாப்பு சமூகம் நடைமுறைகளுக்கு பங்களித்து, செயல்முறைகள் வளரும் பொழுது பாதுகாப்பு நிலையில் மீளமைவு

- **Microsoft பாதுகாப்பு ஒருங்கிணைப்பு**: Microsoft-ன் விரிவான பாதுகாப்பு சூழலை (Prompt Shields, Azure Content Safety, GitHub Advanced Security, Entra ID) பயன்படுத்தி MCP பதிப்புவாக்கத்திற்கு மேம்பட்ட பாதுகாப்பு

- **[MCP சிறந்த நடைமுறைகள் விரைவான குறிப்பு](./mcp-best-practices.md)** - அவசியமான MCP பாதுகாப்பு நடைமுறைகளுக்கான விரைவான வழிகாட்டி
- **[BlueHat 2026: AI இன் எதிர்காலத்தை பாதுகாத்தல்: ஆழ்ந்த பாதுகாப்பு முறைமைகளுடன் MCP பாதுகாப்பு](https://www.youtube.com/watch?v=cVWB58kEt-Y)** - Microsoft Security Response Center (MSRC) வழங்கும் ஆழ்ந்த பாதுகாப்பு முறைமைகள்

### **கைகளின்கும் பாதுகாப்பு பயிற்சி**

- **[MCP பாதுகாப்பு மாநாடு பட்டறை (Sherpa)](https://azure-samples.github.io/sherpa/)** - Azure-இல் MCP சேவையகங்களை பாதுகாப்பதற்கான விரிவான கைகளின்கும் பட்டறை, தொடக்க முகாம் முதல் மாநாடு வரை படிப்படிக்கான முகாம்கள்
- **[OWASP MCP Azure பாதுகாப்பு வழிகாட்டி](https://microsoft.github.io/mcp-azure-security-guide/)** - அனைத்து OWASP MCP Top 10 ஆபத்துகளுக்கான குறிப்பிதழ் தொடக்கப்பகுதி மற்றும் நிறுவல் வழி
