## MCP அமலாக்கங்களுக்கான அவசியமான பாதுகாப்பு நடைமுறைகள்

Model Context Protocol தனித்துவமான பாதுகாப்பு சவால்களை அறிமுகப்படுத்துகிறது, அவை பாரம்பரிய மென்பொருள் பாதுகாப்பைத் தாண்டுகின்றன. இந்த நடைமுறைகள் அடிப்படை தேவைகள் மற்றும் prompt injection, tool poisoning, state-handle ஹைஜேக்கிங், confused deputy பிரச்சினைகள் மற்றும் token passthrough பாதிப்புகள் போன்ற MCP-சார்ந்த அபாயங்களை முகாம்படுத்துகின்றன.

## 1. **டோக்கன் பாதுகாப்பு மற்றும் அங்கீகாரம்**

**அங்கீகாரம் மற்றும் அனுமதிப்படுத்தல் கட்டுப்பாடுகள்:**
   - **கடுமையான அனுமதி ஆய்வு**: MCP சர்வர் அனுமதி நியமனத்தை முழுமையாக ஆய்வு செய்து, மூலங்களை அணுகக்கூடியவர்கள் நியமிக்கப்பட்ட பயனர்களுக்கும் கிளையன்டுகளுக்கும்தான் என்பதை உறுதிசெய்யுங்கள்
   - **வெளிப்புற அடையாள வழங்குநர் ஒருங்கிணைப்பு**: தனிப்பயன் அங்கீகாரத்தை உருவாக்குவதற்குப் பதிலாக Microsoft Entra ID போன்ற நிறுவன அடையாள வழங்குநர்களைப் பயன்படுத்துங்கள்
   - **டோக்கன் நேர் பார்வை (Audience) சரிபார்ப்பு**: டோக்கன்கள் உங்கள் MCP சர்வருக்காக தெளிவாக விடுக்கப்பட்டதா என்பதை எப்போதும் சரிபார்க்கவும் — மேல்நிலைய டோக்கன்களை ஒருபோதும் ஏற்காதீர்கள்
   - **சரியான டோக்கன் வாழ்க்கைசுற்று நிர்வாகம்**: பாதுகாப்பான டோக்கன் மாற்றம், காலாவதி கொள்கைகள் மற்றும் டோக்கன் மீட்பு தாக்குதல்களைத் தடுக்கும் நடைமுறைகளை செயல்படுத்துங்கள்

**பாதுகாக்கப்பட்ட டோக்கன் சேமிப்பு:**
   - அனைத்து ரகசியங்களுக்கும் Azure Key Vault அல்லது இதே போன்ற பாதுகாப்பான அடையாளச் சேமிப்பகங்களைப் பயன்படுத்துங்கள்
   - இடத்தில் மற்றும் பரிமாற்றத்தில் இரண்டிலும் டோக்கன்களுக்கு குறியீடீடு (encryption) அமல்படுத்துங்கள்
   - அங்கீகாரத் தன்மை உரிமைகளை முறையாக மாற்றுதல் மற்றும் அநுமதியற்ற அணுகல்களுக்கு கண்காணிப்பு நடத்தியுங்கள்

## 2. **State Handle மற்றும் போக்குவரத்து பாதுகாப்பு**

**பயன்பாட்டின் பாதுகாப்பான நிலை நடைமுறைகள்:**

- **Opaque State Handles**: கோரிக்கைகளை கடந்தும் பயன்பாட்டு நிலையை பிரதிபலிக்கும் பாதுகாப்பான, கணிக்க முடியாத ஹேண்டில்களைப் பயன்படுத்துங்கள்
   application state that spans requests
- **User-Specific Binding**: ஹேண்டில்களை சர்வர் பக்கத்தில் அங்கீகரிக்கப்பட்ட பிரதிநிதிக்கு பிணைக்கவும் மற்றும் பயனர்கள் இடையே மீண்டும் பயன்படுத்துவதை நிராகரிக்கவும்
   principal and reject cross-user reuse
- **Lifecycle Management**: ஹேண்டில்களின் காலாவதிக் காலம் மற்றும் ரத்து நடைமுறைகளை அமல்படுத்தி ஆபத்துகளைக் குறைக்கவும்
   windows
- **Per-request Authorization**: சிலநேரத்தில் ஒரு state handle-ஐ அங்கீகாரமாக கருதக்கூடாது; அதை வழங்கும் ஒவ்வொரு கோரிக்கையையும் அங்கீகரிக்கவும்
   authorize every request that presents one

**போக்குவரத்து அடுக்கு பாதுகாப்பு:**

- உற்பத்தி சூழலில் தொலை HTTP பரிவர்த்தனைகளுக்கு HTTPS-ஐ தேவைப்படுத்துங்கள்
- உள்ளூரி stdio சர்வர்களுக்கு செயல்முறை தனிமை மற்றும் சூழ்நிலைக் குருஞ்சானங்களுக்கு (environment credentials) பயன்படுத்துங்கள்
- சரியான சான்றிதழ் மாற்றம் மற்றும் சான்று சரிபார்ப்புக்களுடன் நவீன TLS ஐ கட்டமைக்கவும்

## 3. **AI-சார்ந்த அச்சு பாதுகாப்பு** 🤖

**Prompt Injection பாதுகாப்பு:**
   - **Microsoft Prompt Shields**: தீய உள்ளகங்களை கண்டறியும் மற்றும் வடிகட்டும் மேம்பட்ட கண்டறிதலுக்காக AI Prompt Shields ஐ செயல்படுத்துங்கள்
   - **உள்ளீடு சுத்தம் செய்வது**: எல்லா உள்ளீடுகளையும் சரிபார்த்து சுத்தப்படுத்தவும், injection தாக்குதல்களையும் confused deputy பிரச்சினைகளையும் தவிர்க்கவும்
   - **உள்ளடக்க எல்லைகள்**: நம்பகமான அறிவுரைகளும் வெளிப்புற உள்ளடக்கமும் வேறுபடச் செய்ய delimiter மற்றும் data-marking சிஸ்டம்களைப் பயன்படுத்து

**கருவி நச்சுபடுத்தல் தடுப்பு:**
   - **கருவி மெட்டாடேட்டா சரிபார்ப்பு**: கருவி வரையறைகளுக்கு ஒருமைத்தன்மை (integrity) சோதனைகளைப் பிரதிபலிக்கவும் மற்றும் எதிர்பாராத மாற்றங்களுக்கு கண்காணிப்பு அமைக்கவும்
   - **ஊடுருவி கருவி கண்காணிப்பு**: ரன்டைம் நடத்தை கண்காணித்து எதிர்பாராத உத்தியோக செயல்பாடுகளுக்காக அலெர்டிங் அமைக்கவும்
   - **அனுமதி வேலைவாய்ப்புகள்**: கருவி மாற்றங்கள் மற்றும் திறன்களில் தெளிவான பயனர் ஒப்புதலைக் கோரும் வேலைவாய்ப்புகளை அமல்படுத்துங்கள்

## 4. **அனுமதி கட்டுப்பாடு & அனுமதிகள்**

**குறைந்தபட்ச உரிமை கொள்கை:**
   - MCP சர்வர்களுக்கு தேவையான குறைந்தபட்ச அனுமதிகளையே மட்டுமே வழங்குங்கள்
   - சிறிது விதப்படுத்தப்பட்ட அனுமதிகளுடன் role-based access control (RBAC) ஐ அமல்படுத்துங்கள்
   - அனுமதி மதிப்பீடுகளை அடிக்கடி நடத்தவும் மற்றும் உரிமை உயர்வு சம்பவங்களுக்கு தொடர்ச்சியாக கண்காணிக்கவும்

**ரன்டைம் அனுமதி கட்டுப்பாடுகள்:**
   - வளச்செலவு தாக்குதல்களைத் தடுக்கும் வகையில் வள எல்லைகளை (resource limits) பொருந்துங்கள்
   - கருவி செயலாக்கச் சூழலுக்கு container தனிமையைப் பயன்படுத்துங்கள்  
   - நிர்வாகப் பணிகளுக்கு just-in-time அணுகலை செயல்படுத்துங்கள்

## 5. **உள்ளடக்க பாதுகாப்பு & கண்காணிப்பு**

**உள்ளடக்க பாதுகாப்பு அமலாக்கம்:**
   - **Azure Content Safety ஒருங்கிணைப்பு**: Azure Content Safety ஐப் பயன்படுத்தி தீய உள்ளடக்கம், jailbreak முயற்சிகள் மற்றும் கொள்கை மீறல்களை கண்டறியவும்
   - **நடத்தை பகுப்பாய்வு**: MCP சர்வர் மற்றும் கருவி செயலாக்கத்தில் விசித்திரமான நடத்தை கண்டறியும் வகையில் ரன்டைம் நடத்தை கண்காணிப்பை செயல்படுத்தவும்
   - **விரிவுமிக்க பதிவேட்டம்**: அனைத்து அங்கீகார முயற்சிகளையும், கருவி அழைப்புக்களையும் மற்றும் பாதுகாப்பு நிகழ்வுகளையும் பாதுகாப்பான, சஞ்சலமற்ற சேமிப்பில் பதிவு செய்யுங்கள்

**தொடர்ச்சியான கண்காணிப்பு:**
   - சந்தேகத்துக்குரிய மாதிரிகளுக்கும் அநுமதியற்ற அணுகல் முயற்சிகளுக்கும் நேரடி அலெர்டிங்
   - மையமாக்கப்பட்ட பாதுகாப்பு நிகழ்வு மேலாண்மைக்காக SIEM அமைப்புகளுடன் ஒருங்கிணைவு
   - MCP அமலாக்கங்களின் மீதான வழக்கமான பாதுகாப்பு ஆய்வுகள் மற்றும் penetration சோதனைகள்

## 6. **விநியோக சங்கிலி பாதுகாப்பு**

**குழு உறுப்புகள் சரிபார்ப்பு:**
   - **இணைக்க dependency ஸ்கேனிங்**: அனைத்து மென்பொருள் சார்புகளுக்கும் மற்றும் AI கூறுகளுக்கும் தானாக இயங்கும் குறுகியபகுதி நுணுக்க சோதனைகளைப் பயன்படுத்துங்கள்
   - **மூலத்தொடர்பு சரிபார்ப்பு**: மாதிரிகள், தரவுத்தொடர்கள் மற்றும் வெளிப்புற சேவைகளின் தோற்றம், உரிமம் மற்றும் ஒருமைத்தன்மையை சரிபார்க்கவும்
   - **கையொப்பமிடப்பட்ட தொகுதிகள்**: குறியாக்கமான கையொப்பமிடப்பட்ட தொகுதிகளைப் பயன்படுத்தி, பத்திரங்களை deployment-க்கு முன் சரிபார்க்கவும்

**பாதுகாப்பான மேம்பாட்டு பைப்லைன்:**
   - **GitHub Advanced Security**: ரகசியம் ஸ்கேன், சார்பு பகுப்பாய்வு மற்றும் CodeQL நிலைத்தன்மை பகுப்பாய்வை செயல்படுத்துங்கள்
   - **CI/CD பாதுகாப்பு**: தானியங்கி deployment பைப்லைன்களில் பாதுகாப்பு சரிபார்ப்புகளை ஒருங்கிணைக்கவும்
   - **ஆர்டிபாக்ட் ஒருமைத்தன்மை**: deployed ஆர்டிபாக்ட்கள் மற்றும் கட்டமைப்புகளுக்கு குறியாக்கஉறுதிசெய்யல்களை (cryptographic verification) அமல்படுத்துங்கள்

## 7. **OAuth பாதுகாப்பு & Confused Deputy தடுப்பு**

**OAuth 2.1 அமலாக்கம்:**
   - **PKCE அமலாக்கம்**: அனைத்து அங்கீகார கோரிக்கைகளுக்கும் Proof Key for Code Exchange (PKCE) ஐப் பயன்படுத்துங்கள்
    - **கிளையன்ட் பதிவு**: Client ID மெட்டாடேட்டா ஆவணங்கள் அல்லது
       முன்பதிவை முன்னுரிமை அளிக்கவும்; பழமையான Dynamic Client Registration-ஐ மட்டும் compatibility fallback ஆகப் பயன்படுத்துங்கள்
       compatibility fallback
    - **தெளிவான அனுமதி**: நிலையான மூன்றாம் பக்கம் கிளையன்ட் ID-ஐ பயன்படுத்தும் MCP ப்ராக்ஸிகள் ஒப்புதலைப் பெற வேண்டும்
       ஒவ்வொரு MCP கிளையன்டிற்கும் அங்கீகாரத்தை முன்னெப்போ செல்லும் முன்
   - **Redirect URI சரிபார்த்தல்**: redirect URI-களும் கிளையன்ட் ஐடென்டிஃபையர்களும் கடுமையான சரிபார்ப்புக்குட்படுத்தப்பட வேண்டும்

**ப்ராக்சி பாதுகாப்பு:**
   - நிலையான கிளையன்ட் ID-ஐ மோசடியால் பயன்படுத்தி அங்கீகாரத்தை தவிர்ப்பதை தடுப்பதாக நடவடிக்கை எடுக்கவும்
   - மூன்றாம் பக்கம் API அணுகலுக்கு சரியான ஒப்புதல் வேலைவாய்ப்புகளை அமல்படுத்தவும்
   - அங்கீகாரக் குறியீட்டு திருட்டு மற்றும் அநுமதியற்ற API அணுகலுக்காக கண்காணிக்கவும்

## 8. **சம்பவ பதில் மற்றும் மீட்பு**

**விரைவான பதில் திறன்கள்:**
   - **தானியங்கி பதில்**: அங்கீகார மாற்றம் மற்றும் அச்சு containment க்கு தானியக்க முறைகளை அமல்படுத்துங்கள்
   - **மறுசீரமைப்பு செயல்முறைகள்**: அறிந்த நல்லமைவுகளில் দ্রুত திரும்ப மறுசீரமைத்தல் திறன்
   - **காலைசிக்கல் திறன்கள்**: சம்பவ விசாரணைக்காக விரிவான ஆடிட் ட்ரெயில்கள் மற்றும் பதிவேட்டங்கள்

**தொடர்பு & ஒத்திசைவு:**
   - பாதுகாப்பு சம்பவங்களுக்கு தெளிவான உயர்த்தும் செயல்முறைகள்
   - நிறுவன சம்பவ பதில் குழுக்கள் உடன் ஒருங்கிணைவு
   - வழக்கமான பாதுகாப்பு சம்பவ மயக்கப் பயிற்சிகள் மற்றும் டேபிள்டாப் பயிற்சிகள்

## 9. **கட்டுப்பாடு மற்றும் ஆட்சி**

**ஒழுங்கு இணக்கம்:**
   - MCP அமலாக்கங்கள் தொழில்-சார்ந்த தேவைகளை (GDPR, HIPAA, SOC 2) பூர்த்தி செய்வதைக் உறுதிசெய்யுங்கள்
   - AI தரவு செயலாக்கத்திற்கு தரவுத்தர வகைப்பாடு மற்றும் தனியுரிமை கட்டுப்பாடுகளை அமல்படுத்துங்கள்
   - ஒழுங்கு ஆய்வுக்கான விரிவான ஆவணப்படுத்தலை பராமரிக்கவும்

**மாற்ற மேலாண்மை:**
   - அனைத்து MCP அமைப்பு மாற்றங்களுக்கும் அதிகாரப்பூர்வ பாதுகாப்பு மதிப்பாய்வு செயல்முறைகள்
   - கட்டமைப்பு மாற்றங்களுக்கு பதிப்பு கட்டுப்பாடு மற்றும் அங்கீகார வேலைவாய்ப்புகள்
   - வழக்கமான ஒழுங்கு மதிப்பீடுகள் மற்றும் இடைவெளி பகுப்பாய்வு

## 10. **முன்னேற்றப்பட்ட பாதுகாப்பு கட்டுப்பாடுகள்**

**ஜீரோ டிரஸ்ட் கட்டமைப்பு:**
   - **Never Trust, Always Verify**: பயனர்கள், சாதனங்கள் மற்றும் இணைப்புகளை தொடர்ச்சியாக சரிபார்க்கவும்
   - **மைக்ரோ-செக்மெண்டேஷன்**: தனித்தனியான MCP கூறுகளை தனித்தனியாக தனிமைப்படுத்தும் துல்லியமான நெட்வொர்க் கட்டுப்பாடுகள்
   - **நிபந்தனை அடிப்படையிலான அணுகல்**: தற்போதைய சூழல் மற்றும் நடத்தை அடிப்படையில் ஆபத்து-அமைப்புச் சுற்றுச்சூழலுக்கு ஏற்ப அணுகலைச் சரிசெய்யும் கட்டுப்பாடுகள்

**ரன்டைம் பயன்பாடு பாதுகாப்பு:**
   - **Runtime Application Self-Protection (RASP)**: நேரடி ஆபத்து கண்டறிதலிற்காக RASP தொழில்நுட்பங்களை அமைக்கவும்
   - **பயன்பாடு செயல்திறன் கண்காணிப்பு**: தாக்குதல்கள் குறித்த சக்கிரவெளிக்கான செயல்திறன் விசித்திரங்களை கண்காணிக்கவும்
   - **உடனடி பாதுகாப்பு கொள்கைகள்**: தற்போதைய ஆபத் சூழல்படி தன்னிச்சையான பாதுகாப்பு கொள்கைகளை அமல்படுத்துங்கள்

## 11. **Microsoft பாதுகாப்பு சூழல் ஒருங்கிணைப்பு**

**தொகுப்பான Microsoft பாதுகாப்பு:**
   - **Microsoft Defender for Cloud**: MCP பணி பொறுப்புகளுக்கான கிளவுட் பாதுகாப்பு நிலை மேலாண்மை
   - **Azure Sentinel**: மேம்பட்ட ஆபத் கண்டறிதலுக்கான கிளவுட்-இலக்க SIEM மற்றும் SOAR திறன்கள்
   - **Microsoft Purview**: AI வேலைநிரல்களுக்கும் தரவுத்தொடர்களுக்கும் தரவு நிர்வாகம் மற்றும் ஒழுங்கு இணக்கம்

**அடையாளம் & அணுகல் மேலாண்மை:**
   - **Microsoft Entra ID**: நிபந்தனை அடிப்படையிலான அணுகல் கொள்கைகளுடன் நிறுவன அடையாள மேலாண்மை
   - **Privileged Identity Management (PIM)**: நிர்வாகக் காரியங்களுக்கு Just-in-time அணுகல் மற்றும் அங்கீகார வேலைவாய்ப்புகள்
   - **Identity Protection**: ஆபத்து-அடிப்படையிலான நிபந்தனை அணுகலும் தானியங்கி ஆபத் பதில்களும்

## 12. **தொடர்ச்சியான பாதுகாப்பு முன்னேற்றம்**

**தற்போதைய நிலை வைத்திருத்தல்:**
   - **விபரக்குறிப்பு கண்காணிப்பு**: MCP விவரக்குறிப்பு புதுப்பிப்புகள் மற்றும் பாதுகாப்பு வழிகாட்டல் மாற்றங்களைப் pravidவுரையாக பரிசீலனை செய்யுங்கள்
   - **ஆபத் நுண்ணறிவு**: AI-சார்ந்த ஆபத் உணவுகளையும் ஒழுங்கு குறியீட்டுக்களையும் ஒருங்கிணைக்கவும்
   - **பாதுகாப்பு சமூக ஈடுபாடு**: MCP பாதுகாப்பு சமூகத்திலும் களவியல் வெளிப்படுத்தல் திட்டங்களிலும் செயல்பட்டுக் கொள்ளுங்கள்

**ஒழுங்குமாற்ற பாதுகாப்பு:**
   - **Machine Learning பாதுகாப்பு**: புதுமையான தாக்குதல் மாதிரிகளை கண்டுபிடிக்க ML-அடிப்படையிலான விசித்திர கண்டறிதலைப் பயன்படுத்துங்கள்
   - **புரொடெக்டிவ் பாதுகாப்பு பகுப்பாய்வு**: முன்கூட்டியே ஆபத்துக்களை அடையாளம் காண முன்னறிவியல் மாதிரிகளை செயல்படுத்துங்கள்
   - **பாதுகாப்பு தானியக்கமூலம்**: ஆபத் நுண்ணறிவுக்கும் விவரக்குறிப்பு மாற்றங்களுக்கும் ஏற்ப தானியங்கி பாதுகாப்பு கொள்கை புதுப்பிப்புகளை செயல்படுத்துங்கள்
