# MCP பாதுகாப்பு சிறந்த நடைமுறைகள் - செப்டம்பர் 2026 புதுப்பிப்பு

இந்த விரிவான வழிகாட்டி முக்கியமான பாதுகாப்பு சிறந்த நடைமுறைகளை விளக்குகிறது
Model Context Protocol (MCP) அமைப்புகளை செயல்படுத்துவதற்கான
**MCP விவரக்குறிப்பு 2026-07-28** மற்றும் தற்போதைய தொழிற்சாலை தரங்கள் அடிப்படையில். இவை
நடைமுறைப்பாடுகள் பாரம்பரிய பாதுகாப்பு கவலைகளையும் MCP நியமனங்களுக்கு தனிப்பட்ட
AI-தனிச்சமையின தீமைகளையும் கையாள்கின்றன.

## முக்கியமான பாதுகாப்பு தேவைகள்

### கட்டாயமான பாதுகாப்பு கட்டுப்பாடுகள் (அவசியமான தேவைகள்)

1. **டோக்கன் சரிபார்ப்பு**: MCP சேவையகங்கள் தங்கள் சொந்தமாகத் தெளிவாக வழங்கப்படாத எந்த டோக்கன்களையும் **எடுப்பதா கூடாது**
2. **அங்கீகார சரிபார்ப்பு**: அங்கீகாரம் செயல்படுத்தும் MCP சேவையகங்கள் **எல்லா உள்நுழைவு கோரிக்கைகளையும்** சரிபார்க்க வேண்டும் மற்றும் அடையாளத்தின் தரவரிசைகளுக்கு செஷன் பயன்பாட்டை **பயன்படுத்தக் கூடாது**  
3. **பயனர் ஒப்புதல்**: நிலையான மூன்றாம் தரப்பு கிளையன்ட் ஐடிகள் பயன்படுத்தும் MCP பிரதிநிதி சேவையகங்கள் ஒவ்வொரு MCP கிளையன்டுக்கும் அங்கீகர ஓட்டலை முன்னதாக பெற்றிருக்க வேண்டும்
4. **நிலை கைப்பற்றி பாதுகாப்பு**: MCP சேவையகங்கள் விண்ணப்ப நிலை கைப்பற்றலை அங்கீகாரமாகக் கவனிக்கக் கூடாது மற்றும்
	ஒரு பயன்பாட்டில் எந்தவொரு கோரிக்கையையும் **அங்கீகரிக்க வேண்டும்**


## முக்கிய பாதுகாப்பு நடைமுறைகள்

### 1. உள்ளீடு சரிபார்ப்பு மற்றும் சுத்திகரிப்பு
- **விரிவான உள்ளீடு சரிபார்ப்பு**: ஊடுருவல் தாக்குதல்கள், குழப்பமான பிரதிநிதித் தீமைகள் மற்றும் கொடூரமான ஊக்க ஊட்டல் பாதிப்புகளைத் தடுப்பத 위해 அனைத்து உள்ளீடுகளையும் சரிபார்த்து சுத்திகரிக்கவும்
- **பரிமாண ஸ்கீமா அமல்படுத்தல்**: அனைத்து கருவி சூத்திர மற்றும் API உள்ளீடுகளுக்குமான JSON ஸ்கீமா கடுமையான சரிபார்ப்பை செயல்படுத்தவும்
- **உள்ளடக்க வடிகட்டி**: Microsoft Prompt Shields மற்றும் Azure Content Safety ஆகியவற்றை பயன்படுத்தி ஊக்க ஊட்டல்களில் மற்றும் பதில்களில் தீங்கு விளைவிக்கும் உள்ளடக்கத்தை வடிகட்டவும்
- **வெளியீடு சுத்திகரிப்பு**: பயனர்களுக்கு அல்லது கீழ்மட்ட அமைப்புகளுக்கு வழங்குவதற்கு முன் அனைத்து மாதிரி வெளியீடுகளையும் சரிபார்த்து சுத்திகரிக்கவும்

### 2. அங்கீகாரம் மற்றும் அங்கீகார உயர்தரம்  
- **வெளியிலுள்ள அடையாள வழங்குநர்கள்**: தனிப்பயன்பாட்டு அங்கீகாரத்தை செயல்படுத்துவதற்குப் பதிலாக நிறுவப்பட்ட அடையாள வழங்குநர்களுக்கு (Microsoft Entra ID, OAuth 2.1 வழங்குநர்கள்) அங்கீகாரத்தை ஒப்படைக்கவும்
- **கிளையன்ட் பதிவு**: கிளையன்ட் ஐடி மெட்டாடேட்டா ஆவணங்கள் அல்லது முன்பதிவு முன்னுரிமையுடன்; பழைய டைனமிக் கிளையன்ட் பதிவேட்டையை மட்டும் பொருத்தத்திற்கு பயன்படுத்தவும்
- **நுண்ணறிவு அனுமதிகள்**: குறைந்தபட்ச உரிமை கொள்கை படி கருவி நுண்ணறிவு அனுமதிகளை செயல்படுத்தவும்
- **டோக்கன் வாழ்நாள் மேலாண்மை**: பாதுகாப்பான மாற்றத்துடன் குறுகிய கால ஆக்சஸ் டோக்கன்களை பயன்படுத்தவும் மற்றும் சரியான பார்வையாளர் சரிபார்ப்பை செய்யவும்
- **பல காரணி அங்கீகாரம்**: அனைத்து நிர்வாக அணுகல் மற்றும் உணர்ச்சிப்பூர்வமான செயல்பாடுகளுக்கும் MFA ஆதாரத்தை அவசியமாக்கவும்

### 3. பாதுகாப்பான தொடர்பு நெறிமுறைகள்
- **டிரான்ஸ்போர்ட் லேயர் பாதுகாப்பு**: தொலைதூர HTTP MCP தொடர்புகளுக்கான சரியான சான்று உறுதிப்படுத்தலுடன் HTTPS ஐ பயன்படுத்தவும்
	உள்ளூர் stdio சேவையகங்களுக்கு செயல்முறை தனிமைப்படுத்தலும் சுற்றுச்சூழல் உள்நுழைவுக் குறிப்புகளும் பயன்படுத்தவும்

- **முழுமையான குறியாக்கம்**: பயணிக்கும் மற்றும் ஓய்ந்திருக்கும் மிகக் கடுமையான தரவுகளுக்கு கூடுதல் குறியாக்க அடுக்குகளை கணினி செய்யவும்
- **சான்றிதழ் மேலாண்மை**: தானியங்கி புதுப்பிப்பு செயல்முறைகளுடன் சரியான சான்றிதழ் வாழ்க்கைச் சுற்று மேலாண்மை பாதுகாக்கவும்
- **நெறிமுறை பதிப்பு அமல்படுத்தல்**: MCP `2026-07-28` ஐ பயன்படுத்தி, ஒவ்வொரு கோரிக்கையிலும் அவசியமான பதிப்பு மெட்டாடேட்டாவை இணைத்து ஆதரிக்காத பதிப்புகளைத் நிராகரிக்கவும்


### 4. மேம்பட்ட வீதம் வரம்பீடு மற்றும் வள பாதுகாப்பு
- **பல அடுக்கு வீதம் வரம்பீடு**:  தவறான பயன்பாட்டை தடுப்பதற்கு பயனர், அடையாள குறி, செயல்பாடு, கருவி மற்றும் வள அடிப்படையில் வீதம் வரம்பீடுகளை அமல்படுத்தவும்

- **அனுசரணை வீதம் வரம்பீடு**: பயன்பாட்டு சோழங்கள் மற்றும் மிரட்டல் குறியீடுகளை ஆராயும் இயந்திரக் கற்றல் அடிப்படையிலான வீதம் வரம்பீடு அமல்படுத்தவும்
- **வள அளவுகோல் மேலாண்மை**: கணினி வளங்கள், நினைவக பயன்பாடு மற்றும் செயலாக்க நேரத்திற்கு சரியான வரம்புகளை அமைக்கவும்
- **DDoS பாதுகாப்பு**: விரிவான DDoS பாதுகாப்பு மற்றும் போக்குவரத்து பகுப்பாய்வு அமைப்புகளை நாடவும்

### 5. விரிவான பதிவு மற்றும் கண்காணிப்பு
- **கட்டமைக்கப்பட்ட ஆய்வு பதிவு**: அனைத்து MCP செயல்பாடுகளுக்கான, கருவி இயக்கங்களுக்கான மற்றும் பாதுகாப்பு நிகழ்வுகளுக்கான விரிவான, தேடக்கூடிய பதிவுகளை செயல்படுத்தவும்
- **உண்மை நேர பாதுகாப்பு கண்காணிப்பு**: MCP பணிவைகளுக்கு AI இயக்கும் வேதிப்பாதை கண்டறிதல் SIEM அமைப்புகளை வழமை செய்யவும்
- **தனியுரிமை-தகுதிசெய்யப்பட்ட பதிவுகள்**: தரவு தனியுரிமை தேவைகள் மற்றும் ஒழுங்குமுறைகளை மதிக்கும்படி பாதுகாப்பு நிகழ்வுகளை பதிவு செய்யவும்
- **நிலவும் சம்பவ பதிலளிப்பு ஒருங்கிணைப்பு**: பதிவேட்டுக் கட்டமைப்புகளை தானியங்கி சம்பவ பதிலளிப்பு பணிகளுடன் இணைக்கவும்

### 6. மேம்படுத்திய பாதுகாப்பான சேமிப்பு நடைமுறைகள்
- **ஹார்டுவேர் பாதுகாப்பு தொகுதிகள்**: முக்கிய குறியாக்க செயல்பாடுகளுக்கு HSM ஆதாரமான விசை சேமிப்பை (Azure Key Vault, AWS CloudHSM) பயன்படுத்தவும்
- **குறியாக்க விசை மேலாண்மை**: விசை மாற்றம், வேறுபாடு மற்றும் அணுகல் கட்டுப்பாடுகளுடன் சரியான விசை மேலாண்மையை செயற்படுத்தவும்
- **ரகசிய மேலாண்மை**: அனைத்து API விசைகள், டோக்கன்கள் மற்றும் அடையாளக் குறிப்புகளை தனித்துவமான ரகசிய மேலாண்மை அமைப்புகளில் சேமிக்கவும்
- **தரவு வகைப்படுத்தல்**: தரவை உணர்ச்சித்தன்மை அடிப்படையில் வகைப்படுத்தி ஏற்ற பாதுகாப்பு நடவடிக்கைகள் எடுக்கவும்

### 7. மேம்பட்ட டோக்கன் மேலாண்மை
- **டோக்கன் பாத்துரூ தடுப்பு**: பாதுகாப்பு கட்டுப்பாடுகளைக் கடக்கும் டோக்கன் பாத்துரூ மாதிரிகளை தெளிவாகத் தடை செய்யவும்
- **பார்வையாளர் சரிபார்ப்பு**: டோக்கன் பார்வையாளர் உரிமைகள் குறிக்கப்பட்ட MCP சேவை அடையாளம் பொருந்துகிறதா என்றும் எப்பொழுதும் சரிபார்க்கவும்
- **குறிப்புகள் அடிப்படையிலான அங்கீகாரம்**: டோக்கன் குறிப்புகள் மற்றும் பயனர் பண்புகளின் அடிப்படையில் நுண்ணறிவு அங்கீகாரத்தை செயல்படுத்தவும்
- **டோக்கன் பிணைத்தல்**: டோக்கன்கள் நோக்கிய MCP வளத்துடன் பொருந்துகிறதா என்றும் சரிபார்த்து, பயன்பாட்டின் நிலை கைப்பற்றலை சேவையகத்தில் அங்கீகரிக்கப்பட்ட பிரதிநிதியை பிணைக்கவும்


### 8. பாதுகாப்பான பயன்பாட்டு நிலை

- **குறியாக்க நிலை கைப்பற்றல்கள்**: கோரிக்கைகள் கடக்கும் நிலைக்கான பாரதப்பட்ட, தீர்மானிக்க முடியாத கைப்பற்றல்களை உருவாக்கவும்

- **பயனருக்கு தனித்துவமான பிணைப்பு**: ஒவ்வொரு கைப்பற்றலையும் சேவையகத்தில் அங்கீகரிக்கப்பட்ட பிரதிநிதிக்கு பிணைக்கவும்; கிளையன்ட் வழங்கிய பயனர் ஐடியை நம்ப வேண்டாம்

- **வாழ்நாள் கட்டுப்பாடுகள்**: கைப்பற்றல்களை காலாவதியாக்கவும் நீக்கவும், அம்பரவாத நிலையை மீட்டு எடுக்கும் முறையை வரையறுக்கவும்

- **ஒவ்வொரு கோரிக்கை அங்கீகாரம்**: கைப்பற்றல் முன்வைக்கப்பட்டாலும் அங்கீகாரம் மீண்டும் சரிபார்க்கப்பட வேண்டும்; கைப்பற்றல் என்பது பெயர், கடவுச்சீட்டு அல்ல


### 9. AI-தனிச்சமையுடைய பாதுகாப்பு கட்டுப்பாடுகள்
- **ஊக்க ஊட்டல் தாக்குதல் பாதுகாப்பு**: Microsoft Prompt Shields ஐ ஒளிர்ச்சி, வரையறுக்குகைகள் மற்றும் தரவு குறியீட்டு தொழில்நுட்பங்களுடன் செயல்படுத்தவும்
- **கருவி நசப்பு தடுப்பு**: கருவி மெட்டாடேட்டாவை சரிபார்க்கவும், நடைமாற்ற மாற்றங்களை கண்காணிக்கவும், கருவி முழுமையை உறுதிசெய்கவும்
- **மாதிரி வெளியீடு சரிபார்ப்பு**: மாதிரி வெளியீடுகளை தரவுத் திருட்டு, தீங்கு விளைவிக்கும் உள்ளடக்கம் அல்லது பாதுகாப்பு கொள்கை விரோதங்களுக்காக ஸ்கேன் செய்யவும்
- **சூழல் சாளர பாதுகாப்பு**: சூழல் சாளர நசப்பு மற்றும் மனையமிழை தாக்குதல்களைத் தடுக்க கட்டுப்பாடுகளை அமல்படுத்தவும்

### 10. கருவி செயலாக்க பாதுகாப்பு
- **செயலாக்க சந்து பெட்டி**: கருவி செயல்பாடுகளை கட்டான்கிளைகளிலுள்ள தனிமைப்படுத்தப்பட்ட சூழல்களில் உபரி வள வரம்புகளுடன் இயக்கவும்
- **அங்கீகாரம் பிரிப்பித்தல்**: குறைந்தபட்ச தேவையான உரிமைகளுடன் கருவிகளை இயக்கவும் மற்றும் சேவை கணக்குகளை பிரித்து வைத்திருங்கள்
- **நெட்வொர்க் தனிமைப்படுத்தல்**: கருவி செயல்பாட்டு சூழலுக்கான நெட்வொர்க் பிரிவினையை அமல்படுத்தவும்
- **செயலாக்க கண்காணிப்பு**: கருவி செயல்பாட்டின் வழிதவிர்ப்புகளை, வளப் பயன்பாடு மற்றும் பாதுகாப்பு மீறல்கள் பற்றிய கண்காணிப்பு செய்யவும்

### 11. தொடர்ச்சியான பாதுகாப்பு சரிபார்ப்பு
- **தானியங்கி பாதுகாப்பு சோதனை**: GitHub Advanced Security போன்ற கருவிகளுடன் CI/CD குழாய்களில் பாதுகாப்பு சோதனைகளை ஒருங்கிணைக்கவும்
- **பிழைதீற்ற மேலாண்மை**: AI மாதிரிகளும் வெளிப்புற சேவைகளும் உட்பட அனைத்து சார்புகளை முறையாக ஸ்கேன் செய்யவும்
- **நுழைவாயில் சோதனை**: MCP அமல்படுத்தல்களுக்கு விசேஷமாக பாதுகாப்பு மதிப்பீடுகளை முறையாக நடத்தவும்
- **பாதுகாப்பு குறியீட்டுப் பரிசீலனை**: MCP தொடர்புடைய அனைத்து குறியீடு மாற்றங்களுக்கும் கட்டாயமான பாதுகாப்பு பரிசீலனைகளை அமல்படுத்தவும்

### 12. AI வழங்கல் சங்கிலி பாதுகாப்பு
- **கூறாண்மை சரிபார்ப்பு**: அனைத்து AI கூறுகளின் (மாதிரிகள், இணைத்திகள், APIs) தோற்றம், முழுமை மற்றும் பாதுகாப்பை சரிபார்க்கவும்
- **சார்பு மேலாண்மை**: இன்றைய மென்பொருள் மற்றும் AI சார்புகளின் பட்டியலை பாதிப்பு கண்காணிப்புடன் பராமரிக்கவும்
- **நம்பகமான சேமிப்பகங்கள்**: அனைத்து AI மாதிரிகள், நூலகங்கள் மற்றும் கருவிகளுக்குமான பரிசோதிக்கப்பட்ட, நம்பகமான மூலங்களைக் பயன்படுத்தவும்
- **வழங்கல் சங்கிலி கண்காணிப்பு**: AI சேவை வழங்குநர்களிலும் மாதிரி சேமிப்பகங்களிலும் குழப்பங்களை தொடர்ந்து கண்காணிக்கவும்


## மேம்பட்ட பாதுகாப்பு வடிவக்கழுவல்கள்

### MCPக்கான ஜீரோ டிரஸ்ட் கட்டமைப்பு
- **நம்பாதே, எப்போதும் சரிபார்க்கவும்**: அனைத்து MCP பங்காளிகளுக்கும் தொடர்ச்சியான சரிபார்ப்பை বাস্তவாக்கவும்
- **மைக்ரோ-பிரிவு**: MCP கூறுகளை நுண்ணிய நெட்வொர்க் மற்றும் அடையாள கட்டுப்பாடுகளுடன் தனித்திருத்துக
- **நிபந்தனையுடைய அணுகல்**: சூழ்நிலையுடனும் நடத்தையுடனும் ஒத்துப்போகும் ஆபத்து அடிப்படையிலான அணுகல் கட்டுப்பாடுகளை செயலாக்குக
- **தொடர்ச்சியான ஆபத்து மதிப்பீடு**: தற்போதைய அச்சுறுத்தல் குறிப்புகளின் அடிப்படையில் பாதுகாப்பு நிலையை இலக்கிலா மதிப்பிடவும்

### தனியுரிமை பாதுகாக்கும் AI செயலாக்கம்
- **தரவு குறைப்பாண்மை**: ஒவ்வொரு MCP செயல்பாட்டிற்கும் தேவையான குறைந்தபட்ச தரவோடு மட்டுமே வெளிப்படுத்துக
- **வேறுபட்ட தனியுரிமை**: உணர்வுபூர்வ தரவு செயலாக்கத்திற்கான தனியுரிமை பாதுகாக்கும் ತಂತ್ರங்களை நடைமுறைபடுத்துக
- **ஹோமோமார்ஃபிக் குறியாக்கம்**: குறியாக்கமான தரவின் பாதுகாப்பான கணக்கீட்டிற்காக மேம்பட்ட குறியாக்க தொழில்நுட்பங்களை பயன் படுத்துக
- **ஃபெடரேட்டட் லெர்னிங்**: தரவு உள்ளூர் மற்றும் தனியுரிமையை பாதுகாக்கும் பகிர்ந்துள்ளக் கற்றல் முறைகளை நடைமுறைப்படுத்துக

### AI அமைப்புகளுக்கான சம்பவ எதிர்வினை
- **AI-சொல்லிய சம்பவ செயல்முறைகள்**: AI மற்றும் MCP-சொல்லிய அச்சுறுத்தல்களுக்கு ஏற்ப சம்பவ எதிர்வினை செயல்முறைகளை உருவாக்குக
- **தானியங்கி எதிர்வினை**: பொதுவான AI பாதுகாப்பு சம்பவங்களுக்கான தானியங்கி கட்டுப்பாடு மற்றும் சீரமைப்பை செயல்படுத்துக  
- **மரநோத திறன்கள்**: AI அமைப்பு தாக்குதல்கள் மற்றும் தரவு மீறல்களுக்கு மரநோத தயார் நிலையை பராமரிக்கவும்
- **மீட்புச் செயல்முறைகள்**: AI உருவகச் சாசனம் மாசுபாடு, உரையாடல் ஊடுருவல் தாக்குதல்கள் மற்றும் சேவை மீறல்கள் போன்றவற்றிலிருந்து மீள செயல்முறைகளை நிறுவுக

## 🔄 தொடர்ச்சியான மேம்பாடு

### மாறும் தரநிலைகளுடன் தற்போதைய நிலையை நிலைத்திருக்கவும்
- **MCP குறிப்புரை மேம்பாடுகள்**: அதிகாரப்பூர்வ MCP குறிப்புரை மாற்றங்கள் மற்றும் பாதுகாப்பு அறிவிப்புகளை கண்காணிக்கவும்
- **குண்டான நுண்ணறிவு**: AI பாதுகாப்பு குண்டான உணவுகள் மற்றும் தளர்வுத் தரவுத்தளங்களுக்கு சந்தா செய்யவும்  
- **சமூக பங்கு**: MCP பாதுகாப்பு சமூக விவாதங்கள் மற்றும் பணிக் குழுக்களில் பங்கேற்கவும்
- **தினசரி மதிப்பீடு**: காலாண்டு பாதுகாப்பு நிலை மதிப்பீடுகளை நடத்தவும் மற்றும் நடைமுறைகளை புதுப்பிக்கவும்

### MCP பாதுகாப்புக்கு பங்களிப்பு
- **பாதுகாப்பு ஆராய்ச்சி**: MCP பாதுகாப்பு ஆராய்ச்சி மற்றும் தளர்வு அறிவிப்பு நிகழ்ச்சிகளுக்கு பங்களிக்கவும்
- **நல்ல நடைமுறை பகிர்வு**: பாதுகாப்பு நடைமுறைகள் மற்றும் கற்றுக் கொண்ட பாடங்களை சமூகத்துடன் பகிரவும்
- **தரநிலை மேம்பாடு**: MCP குறிப்புரை மேம்பாடு மற்றும் பாதுகாப்பு தரநிலை உருவாக்கத்தில் பங்கேற்கவும்
- **கருவி மேம்பாடு**: MCP சூழல் மண்டலத்திற்கு பாதுகாப்பு கருவிகள் மற்றும் நூலகங்களை உருவாக்கி பகிரவும்
