# MCP கணக்கியைக்கூட்டும் சேவையகம் (Python)



அடிப்படையான கணக்கீட்டு செயல்திறன் வழங்கும் ஒரு எளிய Model Context Protocol (MCP) சேவையக அமல்படுத்தல் Python இல்.


## நிறுவல்

தேவையான சாராபகரங்களை நிறுவுக:

```bash
pip install -r requirements.txt
```

அல்லது MCP Python SDK ஐ நேரடியாக நிறுவுக:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## பயன்பாடு

### சேவையகத்தை இயக்குதல்

இந்த சேவையகம் MCP கிளையண்டுகள் (போல் Claude Desktop) பயன்படுத்தவும் வடிவமைக்கப்பட்டுள்ளது. சேவையகத்தை தொடங்க:

```bash
python mcp_calculator_server.py
```

**குறிப்பு**: நேரடியாக டெர்மினலில் இயக்கும்போது, JSON-RPC சரிபார்ப்பு பிழைகள் தோன்றும். இது சாதாரண நிகழ்வு - சேவையகம் சரியான வடிவத்தில் உள்ள MCP கிளையண்ட் செய்திகளுக்காக காத்திருக்கிறது.

### செயல்பாடுகளை சோதனை செய்தல்

கணக்குப்பொறி செயல்பாடுகள் சரியாக வேலை செய்கின்றனவா என்று சோதிப்பதற்கு:

```bash
python test_calculator.py
```

## குறைபாடுகள் தீர்க்குதல்

### இறக்குமதி பிழைகள்

`ModuleNotFoundError: No module named 'mcp'` எனப் பிழை தோன்றினால், MCP Python SDK ஐ நிறுவுக:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### நேரடியாக இயக்கும் போது JSON-RPC பிழைகள்

சேவையகத்தை நேரடியாக இயக்கும்போது "Invalid JSON: EOF while parsing a value" போன்ற பிழைகள் எதிர்பார்க்கப்படும். சேவையகம் MCP கிளையண்ட் செய்திகளைவே தேவைப்படுத்துகிறது, நேரடி டெர்மினல் உள்ளீடு இல்லாமல்.
