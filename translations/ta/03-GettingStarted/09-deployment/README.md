# MCP சேவையகங்களை разployment செய்தல்

> [!NOTE]
> `/sse` என்ட்பாயின்டை பயன்படுத்தும் கட்டமைப்பு உதாரணங்கள் பழைய HTTP+SSE 
> பரிமாற்றத்தை குறிக்கின்றன. MCP `2026-07-28` தொலைபேசி சேவையகங்கள் பொதுவாக 
> `/mcp` போன்ற சேவையக வரையறுக்கப்பட்ட என்ட்பாயின்டில் Streamable HTTP பயன்படுத்துகின்றன.

உங்கள் MCP சேவையகத்தை நிர்வகிப்பதால், பிறர் உங்கள் உள்ளூர் சூழலை அப்பால் அதன் கருவிகள் மற்றும் வளங்களை அணுக முடியும். உங்கள் அளவீடு, நம்பகத்தன்மை, மற்றும் மேலாண்மை எளிமை போன்ற தேவைகளுக்கு ஏற்ப பல விண்ணப்பங்கள் உள்ளன. கீழே நீங்கள் MCP சேவையகங்களை உள்ளூர், கண்டெய்னர்களில் மற்றும் கிளவுடில் deployment செய்ய வழிகாட்டுதல் காணலாம்.

## ஒளிப்படம்

இந்த பாடம் உங்கள் MCP சேவையக செயலியை எப்படி deployment செய்வது என்பதைக் கொண்டுள்ளது.

## கற்றல் இலக்குகள்

இந்த பாடத்தின் முடிவில், நீங்கள் செய்யக்கூடியவை:

- வெவ்வேறு deployment செயல்முறைகளை மதிப்பாய்வு செய்ய.
- உங்கள் செயலியை deployment செய்ய.

## உள்ளூர் மேம்பாடு மற்றும் deployment

உங்கள் சேவையகம் பயனர்களின் இயந்திரத்தில் இயங்குவதற்காக இருந்தால், நீங்கள் பின்வரும் படிகளை பின்பற்றலாம்:

1. **சேவையகத்தை பதிவிறக்கு**. நீங்கள் சேவையகத்தைக் எழுதவில்லை என்றால், முதலில் அதை உங்கள் இயந்திரத்தில் பதிவிறக்கவும்.
1. **சேவையக செயலியை துவக்கம் செய்யவும்**: உங்கள் MCP சேவையக செயலியை இயக்கவும்.

SSE க்கான (stdio வகை சேவையகத்திற்கான தேவையில்லை)

1. **நெட்வொர்க்கை கட்டமைக்கவும்**: சேவையகம் எதிர்பார்க்கப்படும் போர்டு மூலம் அணுகக்கூடியதாக இருக்க வேண்டும்.
1. **கிளையன்ட்களை இணைக்கவும்**: `http://localhost:3000` போன்ற உள்ளூர் URLகளைப் பயன்படுத்தவும்.

## கிளவுட் deployment

MCP சேவையகங்களை பல கிளவுட் தளங்களுக்கு deployment செய்யலாம்:

- **சேவையகமில்லா செயல்பாடுகள்**: இலையுதிர் MCP சேவையகங்களை serverless செயல்பாடுகளாக deployment செய்யவும்.
- **கண்டெய்னர் சேவைகள்**: Azure Container Apps, AWS ECS அல்லது Google Cloud Run போன்ற சேவைகளைப் பயன்படுத்து.
- **கியூபர்நெட்டீஸ்**: வலுவான கிடைக்கும் தன்மைக்காக MCP சேவையகங்களை Kubernetes கிளஸ்டர்களில் deployment செய்து நிர்வகிக்கவும்.

### உதாரணம்: Azure Container Apps

Azure Container Apps MCP சேவையகத்தின் deployment ஐ ஆதரிக்கிறது. இது இன்னும் முன்னேற்றத்தில் உள்ளது மற்றும் தற்பொழுது SSE சேவையகங்களை ஆதரிக்கின்றது.

இதைப் பற்றி நீங்கள் செய்யக்கூடியவைகள்:

1. ஒரு ரெப்போவை கிளோன் செய்யவும்:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. உள்ளூரில் சோதனை செய்வதற்கு செயல்படுத்தவும்:

  ```sh
  uv venv
  uv sync

  # லினக்ஸ்/மோசிஎஸ்எஸ்
  export API_KEYS=<AN_API_KEY>
  # விண்டோஸ்
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. உள்ளூரில் முயற்சிக்க, *.vscode* மட்கோப்பகத்தில் *mcp.json* கோப்பை உருவாக்கி கீழ்காணும் உள்ளடக்கத்தை சேர்:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  SSE சேவையகத்தை துவங்கியதும், JSON கோப்பில் உள்ள பிளே ஐகானை கிளிக் செய்யுங்கள், இப்போது GitHub Copilot சேவையகத்தில் கருவிகளைப் பிடிக்கும், கருவி ஐகான் காணலாம்.

1. Deployment செய்ய, கீழ்க்காணும் கட்டளையை இயக்கவும்:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

இதோ, இவற்றை பின்பற்றி உள்ளூரிலும் Azure லிலும் deployment செய்யலாம்.
