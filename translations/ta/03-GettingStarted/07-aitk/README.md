# Visual Studio Code-க்கான AI Toolkit விரிவாக்கத்திலிருந்து ஒரு சர்வரை பயன்படுத்துதல்

நீங்கள் ஒரு AI முகவரியை உருவாக்கும் போது, அது வெறும் புத்திசாலி பதில்களை உருவாக்குவதுதான் அல்ல; உங்கள் முகவரிக்கு செயல்படக்கூடிய திறனும் வழங்கப்பட வேண்டும். இதற்காக தான் Model Context Protocol (MCP) இருக்கிறது. MCP, முகவர்களுக்கு வெளிப்புற கருவிகள் மற்றும் சேவைகளை ஒரு ஒரே மாதிரியில் அணுக எளிமையாக உள்ளது. இது உங்கள் முகவரியை ஒரு கருவிமுழக்கத்தில் *உண்மையில்* பயன்படுத்தக்கூடியபடி இணைப்பதுபோல்.

எடுத்துக்காட்டில், நீங்கள் ஒரு முகவரியை உங்கள் கணினி MCP சர்வருடன் இணைத்தால், “47-ஐ 89-ஆல் பெருக்கி என்ன?” என்ற மாதிரி ஒரு கேள்வி மூலம் உங்கள் முகவர் கணிதச் செயல்பாடுகளை முடிக்க முடியும் — லாஜிக் கையெழுத்து செய்வதோ அல்லது தனிப்பயன் API-கள் உருவாக்குவதோ தேவையில்லை.

## மேலோட்டம்

இந்த பாடத்தில், Visual Studio Code-ல் உள்ள [AI Toolkit](https://aka.ms/AIToolkit) விரிவாக்கத்துடன் ஒரு கணினி MCP சர்வரை முகவரியுடன் எவ்வாறு இணைக்க வேண்டும் என்பதைப் பற்றி கற்கலாம். இதனால் உங்கள் முகவர் கூட்டல், கழித்தல், பெருக்கல், வகுத்தல் போன்ற கணித செயல்பாடுகளை இயற்கை மொழியுடன் செயல்படுத்த முடியும்.

AI Toolkit என்பது Visual Studio Code-க்கான சக்திவாய்ந்த விரிவாக்கம், இது முகவர் மேம்பாட்டை எளிதாக்குகிறது. AI பொறியாளர்கள் உடனடி அல்லது மேகத்தில் உருவாக்கி சோதித்து வலைப்போகும் AI செயலிகளைக் கட்டமைக்கலாம். இந்த விரிவாக்கம் இன்றைய பல முக்கியமாக உள்ள உருவாக்கும் AI மாதிரிகளுக்கு ஆதரவாகும்.

*Notes*: AI Toolkit தற்போது Python மற்றும் TypeScript க்கு ஆதரவு அளிக்கிறது.

### -2- முகவரிக்கான சிஸ்டம் ப்ராம்ப்டை உருவாக்குதல்

முகவரியை உருவாக்கியவுடன், அதன் தன்மை மற்றும் நோக்கத்தை நிர்ணயிக்க வேண்டும். இதில், **Generate system prompt** அம்சத்தை பயன்படுத்தி, கணினி முகவரியென்பது எப்படி நடந்து கொள்ளும் என்பதைக் கூறி, மாதிரியைச் சிஸ்டம் ப்ராம்ப்டை எழுதவிடுவீர்கள்.

![Visual Studio Code இன் AI Toolkit இல் "Calculator Agent" இடைமுகத்தினை காட்டும் திரைபடம், "Generate a prompt" எனும் தலைப்புடன் ஒரு வலை கூற்றுப் பெட்டி திறந்துள்ளது. இக்கூற்று பெட்டியில்: "நீங்கள் உதவிகரமாகவும் திறமையாகவும் நடக்கும் கணித உதவியாளர். அடிப்படை கணக்கு தொடர்பான பிரச்சனையில் நீங்கள் சரியான முடிவை கொடுப்பீர்கள்." என்பதைக் கொண்ட உரை உள்ளது. கீழே "Close" மற்றும் "Generate" பொத்தான்கள் காணப்படுகின்றன. பின்னணி பகுதியில், ஏற்கனவே தேர்ந்தெடுக்கப்பட்ட மாதிரி மற்றும் சிஸ்டம்/பயனர் ப்ராம்ப்டுகளைக் காண முடிகிறது.](../../../../translated_images/ta/aitk-generate-prompt.ba9e69d3d2bbe2a2.webp)

1. **Prompts** பகுதியில், **Generate system prompt** பொத்தானை அழுத்தவும். இது AI-ஐ பயன்படுத்தி சிஸ்டம் ப்ராம்ப்டை உருவாக்கும் தொகுப்பைத் திறக்கும்.
1. **Generate a prompt** வினாகூட்டத்தில், கீழ்காணும் உரையை உள்ளிடவும்: `நீங்கள் உதவிகரமாகவும் திறமையாகவும் நடக்கும் கணித உதவியாளர். அடிப்படை கணக்கு தொடர்பான பிரச்சனையில் நீங்கள் சரியான முடிவை கொடுப்பீர்கள்.`
1. **Generate** பொத்தானை அழுத்தவும். ஒரு அறிவிப்பு உள்நிலை கீழ்பக்க வலது மூலையில் தோன்றும் மேலும் ப்ராம்ப்ட் உருவாக்கப்படுகிறது. முடிந்தவுடன் ப்ராம்ப்ட் **Agent (Prompt) Builder**-இன் **System prompt** புலத்தில் தோன்றும்.
1. **System prompt** -ஐ ஆய்வுசெய்து தேவையானபட்சம் மாற்றவும்.

### -3- MCP சர்வரை உருவாக்குதல்

இப்போது உங்கள் முகவரிக்கு தேவையான நடத்தை மற்றும் பதில்களை வழிநடத்தும் சிஸ்டம் ப்ராம்ப்ட் உள்ளது; முகவரிக்கான பயனுள்ள திறன்களை வழங்குவதற்காக நீங்கள் ஒரு கணினி MCP சர்வரை உருவாக்கப் போகிறீர்கள். இது கூட்டல், கழித்தல், பெருக்கல், வகுத்தல் கணக்கீடுகளை செய்யக் கூடிய கருவிகளுடன் இருக்கும். இயற்கை மொழிப் ப்ராம்ப்ட்களுக்கு முகவர் நேரடி கணித செயல்பாடுகளை செய்ய முடியும்.

![Visual Studio Code-ல் AI Toolkit விரிவாக்கத்தில் Calculator Agent இடைமுகத்தின் கீழ் பகுதி திரைபடம். இடைக்குறி விரிவாக்கங்கள்: “Tools” மற்றும் “Structure output.” ஒரு கீழிறங்கும் பட்டியில் “Choose output format” “text” எனத் தேர்வு செய்யப்பட்டு உள்ளது. வலது பகுதியில் **+ MCP Server** என்ற பொத்தான் உள்ளது. மேலே உள்ள கருவி பகுதி அருகில் படம் இயக்க அதிமுக காட்சியளிக்கும் இடம் உள்ளது.](../../../../translated_images/ta/aitk-add-mcp-server.9742cfddfe808353.webp)

AI Toolkit உங்கள் சொந்த MCP சர்வர் உருவாக்கதற்கு மாதிரிகளை அடங்கிக்கொண்டுள்ளது. கணினி MCP சர்வர் உருவாக்க Python மாதிரியை பயன்படுத்துகிறோம்.

*Note*: AI Toolkit Python மற்றும் TypeScript க்கு ஆதரவு அளிக்கிறது.

1. **Agent (Prompt) Builder**-இன் **Tools** பகுதியில், **+ MCP Server** பொத்தானை அழுத்தவும். விரிவாக்கம் **Command Palette** மூலம் அமைப்பு உதவியாளரைத் திறக்கும்.
1. **+ Add Server**-ஐத் தேர்ந்தெடுக்கவும்.
1. **Create a New MCP Server**-ஐ தேர்ந்தெடுக்கவும்.
1. **python-weather** மாதிரியைத் தேர்ந்தெடுக்கவும்.
1. MCP சர்வர் மாதிரியை சேமிக்க **Default folder**-ஐ தேர்ந்தெடுக்கவும்.
1. சர்வருக்கான பெயராக **Calculator** என்று உள்ளிடவும்.
1. புதிய Visual Studio Code சாளரம் திறக்கும். **Yes, I trust the authors** என்பதை தேர்ந்தெடுக்கவும்.
1. டெர்மினலை (Terminal > New Terminal) பயன்படுத்தி ஒரு கல்குலேட்டர் சூழலை உருவாக்கவும்: `python -m venv .venv`
1. டெர்மினலில், கல்குலேட்டர் சூழலை செயல்படுத்தவும்:
    1. Windows - `.venv\Scripts\activate`
    1. macOS/Linux - `source .venv/bin/activate`
1. டெர்மினலை பயன்படுத்தி சார்புகளை நிறுவவும்: `pip install -e .[dev]`
1. **Activity Bar**-இல் **Explorer** கருத்திலும் **src** கோப்புறையை விரிவாக்கி **server.py** -ஐத் திறக்கவும்.
1. **server.py** கோப்பின் உள்ளடக்கத்தை அடுத்ததாக கொடுக்கப்பட்டதை மாற்றி சேமிக்கவும்:

    ```python
    """
    Sample MCP Calculator Server implementation in Python.

    
    This module demonstrates how to create a simple MCP server with calculator tools
    that can perform basic arithmetic operations (add, subtract, multiply, divide).
    """
    
    from mcp.server.fastmcp import FastMCP
    
    server = FastMCP("calculator")
    
    @server.tool()
    def add(a: float, b: float) -> float:
        """Add two numbers together and return the result."""
        return a + b
    
    @server.tool()
    def subtract(a: float, b: float) -> float:
        """Subtract b from a and return the result."""
        return a - b
    
    @server.tool()
    def multiply(a: float, b: float) -> float:
        """Multiply two numbers together and return the result."""
        return a * b
    
    @server.tool()
    def divide(a: float, b: float) -> float:
        """
        Divide a by b and return the result.
        
        Raises:
            ValueError: If b is zero
        """
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    ```

### -4- கணினி MCP சர்வர் கொண்டு முகவரியை இயக்குதல்

இப்போது உங்கள் முகவரிக்கு கருவிகள் கிடைக்கின்றன, அவற்றைப் பயன்படுத்த நேரம் வந்துவிட்டது! இதில், முகவரிக்கு கேள்விகளை அனுப்பி அது கணினி MCP சர்வர் வழங்கும் சரியான கருவியை பயன்படுத்துகிறதா என்பதை சோதிப்போம்.

![Visual Studio Code இன் AI Toolkit விரிவாக்கத்தில் Calculator Agent இடைமுகம். இடது பகுதியில், “Tools” கீழ் local-server-calculator_server என்ற MCP சர்வர் இணைக்கப்பட்டுள்ளது. அங்கே நான்கு கருவிகள் உள்ளன: கூட்டல், கழித்தல், பெருக்கல், வகுத்தல். நான்கு கருவிகளும் செயலில் உள்ளன என்பதை குறிக்கும் பேட்ஜ் உள்ளது. கீழே கூரிய “Structure output” பகுதி மற்றும் நீலம் “Run” பொத்தான் உள்ளது. வலது பகுதியில், “Model Response” இல் முகவர்  multiply மற்றும் subtract கருவிகளை {"a": 3, "b": 25} மற்றும் {"a": 75, "b": 20} என்ற உள்ளீட்டுடன் அழைக்கிறது. இறுதி “Tool Response” 75.0 என உள்ளது. கீழே “View Code” பொத்தான் உள்ளது.](../../../../translated_images/ta/aitk-agent-response-with-tools.e7c781869dc8041a.webp)

உங்கள் உள்ளக மேம்பாட்டு இயந்திரத்தில் MCP சர்வரை **Agent Builder** வழியாக MCP கிளையன்ட்டாக இயக்குவீர்கள்.

1. MCP சர்வரை டெபக் செய்ய `F5` அழுத்தவும். **Agent (Prompt) Builder** புதிய எடிட்டர் தாவலில் திறக்கும். டெர்மினலில் சர்வர் நிலை காணப்படும்.
1. **Agent (Prompt) Builder**-இன் **User prompt** புலத்தில் இதை உள்ளிடவும்: `I bought 3 items priced at $25 each, and then used a $20 discount. How much did I pay?`
1. முகவரின் பதிலை பெற **Run** பொத்தானை அழுத்தவும்.
1. முகவரின் வெளியீட்டை ஆய்வு செய்யவும். மாதிரி நீங்கள் **$55** செலுத்தியதாக முடிவு செய்ய வேண்டும்.
1. இதோ என்ன நடக்கும் என்பதை விளக்கமாகப் பார்க்கலாம்:
    - முகவர் கூட்டல் மற்றும் கழித்தல் கருவிகளை கணக்கீட்டுக்கு தேர்ந்தெடுக்கிறது.
    - கூட்டல் கருவிக்கான `a` மற்றும் `b` மதிப்புகள் ஒதுக்கப்படுகின்றன.
    - கழித்தல் கருவிக்கான `a` மற்றும் `b` மதிப்புகள் ஒதுக்கப்படுகின்றன.
    - ஒவ்வொரு கருவியிடமிருந்து கிடைக்கும் பதில் **Tool Response**-இல் கொடுக்கப்படும்.
    - இறுதி முடிவான வெளியீடு **Model Response**-இல் வழங்கப்படும்.
1. முகவரியை மேலும் சோதிக்க கூடுதல் ப்ராம்ப்ட்களை அனுப்பலாம். **User prompt** புலத்தின் உள்ளே கிளிக் செய்து புதிய ப்ராம்ப்டை இடலாம்.
1. சோதனை முடித்த பின் டெர்மினலில் **CTRL/CMD+C** அழுத்தி சர்வரை நிறுத்தலாம்.
