# கால்குலேட்டர் LLM கிளையன்ட்

LangChain4j-ஐ பயன்படுத்தி MiniMax OpenAI-போன்ற API மூலம் MCP (மாதிரி சூழல் நெறிமுறை) கால்குலேட்டர் சேவையை எவ்வாறு இணைக்க வேண்டும் என்பதை Java செயலி விளக்குகிறது.

## தேவையான பொருட்கள்

- Java 21 அல்லது அதற்கும் மேல் பதிப்பு
- Maven 3.6+ (அல்லது இணைக்கப்பட்ட Maven ராபர் பயன்படுத்தவும்)
- ஒரு MiniMax API விசை
- `http://localhost:8080`-இல் இயங்கும் MCP கால்குலேட்டர் சேவை

## API விசையை பெறுதல்

இந்த செயலி MiniMax OpenAI-போன்ற API-யை பயன்படுத்துகிறது. உங்கள் விசை மற்றும் முனைப்பணி URL-ஐ பெற கீழ்காணும் படிகளை பின்பற்றவும்:

### 1. ஒரு முனைப்பணி URL-ஐ தேர்வு செய்க
1. உலகளாவிய முனைப்பணிக்கு `https://api.minimax.io/v1` பயன்படுத்தவும்
2. சீனா முனைப்பணிக்கு `https://api.minimaxi.com/v1` பயன்படுத்தவும்

### 2. API விசையை உருவாக்குக
1. உங்கள் MiniMax கணக்கில் இருந்து ஒரு MiniMax API விசையை உருவாக்குக
2. விசையை பாதுகாப்பாக வைத்திருங்கள்

### 3. சுற்றுச்சூழல் மாறிலிகளை அமைக்கவும்

#### விண்டோஸ் (கமாண்ட் ப்ராம்ப்ட்):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### விண்டோஸ் (பவர் ஷெல்):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### macOS/Linux:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## அமைப்பு மற்றும் நிறுவல்

1. **திட்ட அடைவுக்கு கிளோன் செய்க அல்லது செல்லவும்**

2. **உறுப்புகளை நிறுவுக**:
   ```cmd
   mvnw clean install
   ```
   அல்லது உங்கள் கணக்கில் Maven இருந்தால்:
   ```cmd
   mvn clean install
   ```

3. **சுற்றுச்சூழல் மாறிலிகளை அமைக்கவும்** ("API விசையை பெறுதல்" பகுதியில் உள்ளதைப் பாருங்கள்)

4. **MCP கால்குலேட்டர் சேவையை தொடங்கவும்**:
   உங்கள் கணினியில் `http://localhost:8080/sse`-இல் இருக்க Chapter 1 வளர்த்த MCP கால்குலேட்டர் சேவை இயங்குகின்றதை உறுதி செய்யவும். இது கிளையன்ட் தொடங்கும் முன் இயங்கிக் கொள்வது அவசியம்.

## செயலியை இயக்குதல்

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## செயலி செய்யும் செயல்கள்

இந்த செயலி கால்குலேட்டர் சேவையுடன் மூன்று முக்கிய தொடர்புகளை வெளிப்படுத்துகிறது:

1. **கூட்டல்**: 24.5 மற்றும் 17.3 ஆகியவற்றின் கூட்டு கணக்கிடும்
2. **வட்டார வேர்**: 144-இன் வட்டார வேர் கண்டுபிடிக்கும்
3. **உதவி**: கிடைக்கும் கால்குலேட்டர் செயல்பாடுகளை காட்டும்

## எதிர்பார்க்கபடும் வெளியீடு

வெற்றிகரமாக இயங்கும் போது, உங்களுக்கு கீழ்காணும் மாதிரியில் வெளியீடு காணப்படும்:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## பிரச்சனைகளை சரிசெய்தல்

### பொதுவான பிரச்சனைகள்

1. **"OPENAI_API_KEY சுற்றுச்சூழல் மாறிலி அமைக்கப்படவில்லை"**
   - `OPENAI_API_KEY` சுற்றுச்சூழல் மாறிலியை நீங்கள் சரியாக அமைத்துள்ளீர்களா என சரிபார்க்கவும்
   - மாற்றிய பிறகு உங்கள் டெர்மினல்/கமாண்ட் ப்ராம்ப்டை மீண்டும் தொடங்கவும்

2. **"localhost:8080-க்கு இணைப்பு மறுக்கப்பட்டது"**
   - MCP கால்குலேட்டர் சேவை 8080 போர்ட்டில் இயங்குகிறதா என உறுதிப்படுத்தவும்
   - மற்ற சேவை 8080 போர்ட்டை பயன்படுத்தி இருக்கிறதா என்று சரிபார்க்கவும்

3. **"உறுதிப்பத்திரம் தோல்வி"**
   - உங்கள் API விசை செல்லுபடியாக உள்ளதா என மதிப்பாய்வு செய்யவும்
   - `OPENAI_BASE_URL` நீங்கள் நோக்கின முனைப்பணி URL-க்கு பொருத்தமாக இருக்கிறதா என சரிபார்க்கவும்

4. **Maven கட்டுமான பிழைகள்**
   - நீங்கள் Java 21 அல்லது அதற்கு மேல் பதிப்பு பயன்படுத்துகிறீர்களா என உறுதிப்படுத்த `java -version` செய்து பார்க்கவும்
   - கட்டுமானம் சுத்தமாக செய்ய முயற்சிக்க: `mvnw clean`

### பிழை அகற்றுதல்

பிழை பதிவு செயல்பாட்டை இயக்க, செயலியை இயக்கும் போது கீழ்காணும் JVM அமைப்பைச் சேர்க்கவும்:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## கட்டமைப்பு

இந்த செயலி பின்வருமாறு கட்டமைக்கப்பட்டுள்ளது:
- இயல்பாக MiniMax-M3 பயன்படுத்துகிறது; `MINIMAX_MODEL_ID`-ஐ அமைத்து `MiniMax-M3` அல்லது `MiniMax-M2.7` யை தேர்ந்தெடுக்கலாம்
- `OPENAI_BASE_URL` அமைக்கப்பட்டிருக்கும் போது அதனை பயன்படுத்துகிறது; இல்லையெனில் `MINIMAX_REGION=cn_zh` என்றால் `https://api.minimaxi.com/v1` ஐ, இல்லையெனில் இயல்பாக `https://api.minimax.io/v1` ஐப் பயன்படுத்துகிறது
- MCP சேவையை `http://localhost:8080/sse` என்ற முகவரியில் இணைக்கிறது
- கோரிக்கைகளுக்கு 60 விநாடிகள் காலாவதியாக அமைக்கப்பட்டுள்ளது

## சார்புகள்

இந்த திட்டத்தில் பயன்படும் முக்கிய சார்புகள்:
- **LangChain4j**: AI ஒருங்கிணைப்பு மற்றும் கருவி மேலாண்மை
- **LangChain4j MCP**: மாதிரி சூழல் நெறிமுறை ஆதரவு
- **LangChain4j OpenAI அதிகாரப்பூர்வம்**: MiniMax OpenAI-போன்ற API ஒருங்கிணைப்பு
- **Spring Boot**: செயலி வடிவமைப்பு மற்றும் சார்பு நிரல் இறக்குமதி
