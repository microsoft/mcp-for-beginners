# கணினி LLM கிளையன்ட்

> [!NOTE]
> இந்த தீர்வு பாடநெறியின் பழைய HTTP+SSE கணினி சேவையுடன் இணைகிறது மற்றும்
> MCP `2025-11-25` SDK API களை இலக்காகக் கொண்டு செயல்படுகிறது. இது `2026-07-28` ஸ்ட்ரீமபிள் HTTP
> எடுத்துக்காட்டாக இல்லை.

LangChain4j ஐ பயன்படுத்தி MiniMax OpenAI-பொருந்தக்கூடிய API மூலமாக MCP (மோதிரு சூழல் ஒப்பந்தம்) கணினி சேவையுடன் எப்படி இணைப்பது என்பதை விளக்கும் ஒரு ஜாவா செயலி.

## முன் தேவைகள்

- ஜாவா 21 அல்லது அதற்கு மேல்
- மெவன் 3.6+ (அல்லது இணைக்கப்பட்ட மெவன் ராப்பர் பயன்படுத்தவும்)
- ஒரு MiniMax API விசை
- `http://localhost:8080` என்ற முகவரியில் இயக்கப்படும் MCP கணினி சேவை

## API விசையை பெறுதல்

இந்த செயலி MiniMax OpenAI-பொருந்தக்கூடிய API ஐப் பயன்படுத்துகிறது. உங்கள் விசை மற்றும் கடவுச்சொல்லை பெற பின்வரும் படிகளை பின்பற்றுங்கள்:

### 1. ஒரு கடவுச்சொல்லை தேர்வு செய்க
1. உலகளாவிய கடைவண்டி வசதிக்கு `https://api.minimax.io/v1` ஐப் பயன்படுத்தவும்
2. சீனா கடைவண்டி வசதிக்கு `https://api.minimaxi.com/v1` ஐப் பயன்படுத்தவும்

### 2. ஒரு API விசை உருவாக்கு
1. உங்கள் MiniMax கணக்கில் இருந்து MiniMax API விசையை உருவாக்கவும்
2. விசையை பாதுகாப்பாக எங்காவது வைத்திடுங்கள்

### 3. சுற்றுப்புற மாறிலிகளை அமைக்கவும்

#### விண்டோஸில் (கொமாண்ட் புராம்ப்ட்):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### விண்டோஸில் (பவர்ஷெல்):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### மேக்கோஎஸ்/லினக்ஸில்:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## அமைப்பு மற்றும் நிறுவல்

1. **திட்டப் பயன்முறையைக் கிளோன் செய்யவோ அல்லது அதில் செல்லவோ செய்யவும்**

2. **இணைப்புகளை நிறுவவும்**:
   ```cmd
   mvnw clean install
   ```
   அல்லது மெவன் உங்கள் கணினியில் பொதுவாக நிறுவப்பட்டிருந்தால்:
   ```cmd
   mvn clean install
   ```

3. **சுற்றுப்புற மாறிலிகளை அமைக்கவும்** ("API விசையை பெறுதல்" பிரிவு பார்க்கவும்)

4. **MCP கணினி சேவையைத் தொடங்கவும்**:
   `http://localhost:8080/sse` முகவரியில் அத்தியாயம் 1 இன் MCP கணினி சேவை இயங்குவதை உறுதிசெய்க. இதுவே செயலியைத் தொடங்குவதற்கு முன்னதாக இயங்கவேண்டும்.

## செயலியை இயக்குதல்

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## செயலியின் செயல்பாடு

செயலி கணினி சேவையுடன் மூன்று முக்கிய இடையூறுகளை விளக்குகிறது:

1. **கூட்டல்**: 24.5 மற்றும் 17.3 ஆகியவற்றின் கூட்டுத்தொகையை கணக்கிடுகிறது
2. **வரிசைப் பரவல்**: 144 இன் வரிசைப் பரவலை கணக்கிடுகிறது
3. **உதவி**: கிடைக்கும் கணினி செயல்பாடுகளைக் காண்பிக்கிறது

## எதிர்பார்க்கப்படும் வெளியீடு

வெற்றிகரமாக இயக்கும்போது, பின்வருமாறு வெளியீடு காணப்படும்:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## சிக்கல் தீர்வு

### பொதுவான சிக்கல்கள்

1. **"OPENAI_API_KEY சுற்றுப்புற மாறிலி அமைக்கப்படவில்லை"**
   - `OPENAI_API_KEY` சுற்றுப்புற மாறிலியை நீங்கள் அமைத்துள்ளீர்களா என்பதை உறுதிசெய்க
   - மாறிலியை அமைத்த பின் உங்கள் டெர்மினல்/கொமாண்ட் புராம்ப்டை மறுதொடக்கவும்

2. **"localhost:8080 க்கான இணைப்பு மறுக்கப்பட்டது"**
   - MCP கணினி சேவை 8080 போர்ட்டில் இயங்குகிறதா என்று பரிசோதிக்கவும்
   - வேறு எந்த சேவை 8080 போர்ட்டை பயன்படுத்துகிறதா எனவும் காணவும்

3. **"அங்கீகாரம் தோல்வியடைந்தது"**
   - உங்கள் API விசை சரியானதா என சரிபார்க்கவும்
   - `OPENAI_BASE_URL` நீங்கள் பயன்படுத்த விரும்பும் கடை முகவரியுடன் பொருந்துகிறதா என்பதையும் காணவும்

4. **மெவன் கட்டுமான பிழைகள்**
   - நீங்கள் ஜாவா 21 அல்லது அதற்கு மேல் பதிப்பு பயன்படுத்துகிறீர்களா ( `java -version` )
   - கட்டுமானத்தை சுத்தம் செய்க: `mvnw clean`

### பிழைச் சரிபார்ப்பு

பிழைச் பதிவு செயல்படுத்த, செயலி இயக்கும்போது பின்வரும் JVM வரிகளைச் சேர்க்கவும்:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## கட்டமைப்பு

செயலி பின்வருமாறு கட்டமைக்கப்பட்டுள்ளது:
- இயல்பாக MiniMax-M3 ஐப் பயன்படுத்துகிறது; `MINIMAX_MODEL_ID` மூலம் `MiniMax-M3` அல்லது `MiniMax-M2.7` ஐ தேர்ந்தெடுக்கவும்
- `OPENAI_BASE_URL` அமைக்கப்பட்டிருந்தால் அதனை இணைக்கிறது; இல்லையெனில் `MINIMAX_REGION=cn_zh` என்றால் `https://api.minimaxi.com/v1` அல்லது இயல்பாக `https://api.minimax.io/v1` ஐப் பயன்படுத்தும்
- MCP சேவையுடன் `http://localhost:8080/sse` இல் இணைக்கிறது
- கோரிக்கைகளுக்கு 60-விநாடிகள் காலாவதி நேரத்தைப் பயன்படுத்துகிறது

## சார்புகள்

இந்த திட்டத்தில் பயன்படுத்தப்படும் முக்கிய சார்புகள்:
- **LangChain4j**: செயற்கை நுண்ணறிவு ஒருங்கிணைப்பு மற்றும் கருவி மேலாண்மை க்காக
- **LangChain4j MCP**: மோதிரு சூழல் ஒப்பந்த ஆதரவு க்காக
- **LangChain4j OpenAI அதிகாரப்பூர்வம்**: MiniMax OpenAI-பொருந்தக்கூடிய API ஒருங்கிணைப்புக்காக
- **Spring Boot**: செயலி கட்டமைப்பு மற்றும் சார்பு ஊழியத்திற்காக
