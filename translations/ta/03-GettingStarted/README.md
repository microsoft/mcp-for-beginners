## துவக்கம்

இந்த பகுதி பல பாடங்களைக் கொண்டுள்ளது:

- **1 உங்கள் முதல் சேவையகம்**, இந்த முதல் பாடத்தில், நீங்கள் உங்கள் முதல்வ சேவையகத்தை உருவாக்குவது மற்றும் செருகுச்செயலி கருவி மூலம் அதை ஆய்வு செய்வது, உங்கள் சேவையகத்தை சோதனை செய்வதற்கும் பிழைத்திருத்துவதற்குமான ஒரு மதிப்புமிக்க வழி, [பாடத்திற்கு](01-first-server/README.md)

- **2 கிளையന്റ്**, இந்த பாடத்தில், நீங்கள் உங்கள் சேவையகத்துடன் இணைக்கக்கூடிய ஒரு கிளையண்ட்டை எழுதுவது, [பாடத்திற்கு](02-client/README.md)

- **3 LLM உடன் கிளையந்து**, ஒரு கிளையண்ட்டை எழுதுவதற்கான இன்னும் சிறந்த வழி அதற்கு ஒரு LLM ஐச் சேர்ப்பது, இதனால் அது உங்கள் சேவையகத்துடன் என்ன செய்ய வேண்டும் என்று "பரஸ்பர பேச்சுவார்த்தை" செய்ய முடியும், [பாடத்திற்கு](03-llm-client/README.md)

- **4 Visual Studio Code இல் GitHub Copilot முகவரியை பயன்படுத்தி சேவையகத்தை ஒவ்வொன்றாக இயக்குதல்**. இங்கு, நாங்கள் Visual Studio Code இலிருந்து எங்கள் MCP சேவையகத்தை இயக்குவதைக் காண்கிறோம், [பாடத்திற்கு](04-vscode/README.md)

- **5 stdio போக்குவரத்து சேவையகம்** stdio போக்குவரத்து என்பது உள்ளூர் MCP சேவையக-கிளையண்ட் தொடர்புக்கு பரிந்துரைக்கப்பட்ட ஸ்டாண்டர்ட், பாதுகாப்பான subprocess அடிப்படையிலான தொடர்பு மற்றும் உள்ளமைக்கப்பட்ட செயல்முறை தனிமைப்படுத்தலை வழங்குகிறது [பாடத்திற்கு](05-stdio-server/README.md)

- **6 MCP உடன் HTTP ஸ்ட்ரீமிங் (ஸ்ட்ரீமபிள் HTTP)**. தெரிந்து கொள்ளவும் ஸ்டாண்ட்
	ரிமோட் போக்குவரத்து [MCP விவரிப்பு 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http),
	மேலும் இந்த பாடத்தில் இருக்கும் பழைய அமர்வு அடிப்படையிலான நடைமுறை.
	[பாடத்திற்கு](06-http-streaming/README.md)

- **7 Visual Studio Code க்கான Microsoft Foundry கருவிமாலை பயன்படுத்துதல்** உங்கள் MCP கிளையண்ட்ஸ் மற்றும் சேவையகங்களைக் கையாளவும் சோதிக்கவும் [இந்த பாடத்தில்](07-aitk/README.md)

- **8 சோதனை செய்வது**. இங்கு நாம் குறிப்பாக எவ்வாறு வேறுவிதமாக எங்கள் சேவையகம் மற்றும் கிளையண்ட்டை சோதிக்கலாம் என்பதை கவனிப்போம், [பாடத்திற்கு](08-testing/README.md)

- **9 பிரச்சாரப்படுத்தல்**. இந்த அத்தியாயம் உங்கள் MCP தீர்வுகளை பிரச்சாரப்படுத்துவதற்கான பல்வேறு வழிகளைக் காணும், [பாடத்திற்கு](09-deployment/README.md)

- **10 மேம்பட்ட சேவையக பயன்பாடு**. இந்த அத்தியாயம் மேம்பட்ட சேவையக பயன்பாட்டை உள்ளடக்கியது, [பாடத்திற்கு](./10-advanced/README.md)

- **11 அத்தோரிடேஷன்**. இந்த அத்தியாயத்தில் எளிய அத்தோரிடேஷனைச் சேர்ப்பது, Basic Auth இருந்து JWT மற்றும் RBAC பயன்படுத்துதல் வரை விவரிக்கின்றது. நீங்கள் இங்கிருந்து துவங்கி அடுத்ததாக அத்தியாயம் 5 இல் மேம்பட்ட தலைப்புகளைப் பாருங்கள் மற்றும் அத்தியாயம் 2 இல் பரிந்துரைகளின் மூலம் கூடுதல் பாதுகாப்பு கொண்டுஒடுக்குதல் செய்யுங்கள், [பாடத்திற்கு](./11-simple-auth/README.md)

- **12 MCP ஹோஸ்ட்கள்**. பிரபலமான MCP ஹோஸ்ட் கிளையண்ட்களை மூலமாக Claude Desktop, Cursor, Cline மற்றும் Windsurf ஐ செயல்படுத்தவும். போக்குவரத்து வகைகள் மற்றும் பிழைத்திருத்தத்தை அறிவு, [பாடத்திற்கு](./12-mcp-hosts/README.md)

- **13 MCP இன்ஸ்பெக்டர்**. MCP இன்ஸ்பெக்டர் கருவி மூலம் உங்கள் MCP சேவையகங்களை இடையேயான சோதனை மற்றும் பிழைத்திருத்து செய்யவும். கருவிகள், வளங்கள் மற்றும் நெடுவழி செய்திகள் தொடர்பான சிக்கல்களைத் தீர்க்க கற்றுக்கொள்ளவும், [பாடத்திற்கு](./13-mcp-inspector/README.md)

- **14 சாம்பிள் எடுக்குதல்**. பழைய Sampling பிரிமிட்டிவை `2025-11-25` க்கும்
	புதிய வடிவமைப்புக்களை நேரடியாக LLM வழங்குநர் ஒருங்கிணைப்புக்கு மாற்றுவது எப்படி என்பதை கற்றுக்கொள்ளவும். Sampling என்பது
	MCP `2026-07-28` இல் பழையதாக உள்ளது. [பாடத்திற்கு](./14-sampling/README.md)

- **15 MCP செயலிகள்**. UI வழிகாட்டிகளுடன் பதிலளிக்கும் MCP சேவையகங்களை உருவாக்கவும், [பாடத்திற்கு](./15-mcp-apps/README.md)

மாதிரி பகுப்பு நெடுவழி (MCP) என்பது LLM க்கு பயன்பாடுகள் எவ்வாறு சூழலை வழங்குகின்றன என்பது மூலம் தெளிவுபடுத்தும் ஒரு திறந்த நெடுவழி ஆகும். MCP ஐ AI பயன்பாடுகளுக்கான USB-C போர்ட் என்று நினைக்கவும் - இது AI மாதிரிகள் பல்வேறு தரவுத் தளங்களுடன் மற்றும் கருவிகளுடன் இணைவதற்கான ஒரு நிலையான வழியை வழங்குகிறது.

## கற்றல் நோக்கங்கள்

இந்த பாட முடிந்தவுடன், நீங்கள் செய்ய முடியும்:

- C#, Java, Python, TypeScript மற்றும் JavaScript இல் MCP மேம்பாட்டு சூழலை அமைக்கவும்
- தனிப்பயன் அம்சங்களுடன் அடிப்படையான MCP சேவையகங்களை உருவாக்கி பிரச்சாரப்படுத்தவும் (வளங்கள், ஊக்கங்கள் மற்றும் கருவிகள்)
- MCP சேவையகங்களுடன் இணைக்கக்கூடிய ஹோஸ்ட் பயன்பாடுகளை உருவாக்கவும்
- MCP செயலாக்கங்களை சோதித்து பிழைத்திருத்தவும்
- பொதுவான அமைப்பு சிக்கல்களை மற்றும் அவற்றின் தீர்வுகளை புரிந்து கொள்ளவும்
- உங்கள் MCP செயல்படுத்தல்களை பிரபலமான LLM சேவைகளுடன் இணைக்கவும்

## உங்கள் MCP சூழலை அமைத்தல்

MCP உடன் வேலைதொடங்குவதற்கு முன், உங்கள் மேம்பாட்டு சூழலைத் தயார் பண்ணிக் கொண்டு அடிப்படையான வேலைநடத்தை பற்றி புரிந்து கொள்வது முக்கியம். இந்த பகுதி MCP உடன் சரியான துவக்கத்தைக் கொடுக்க முதன்மை அமைப்புப் படிகளுக்கு வழிகாட்டும்.

### தேவைப்படும் முன்னிலை

MCP மேம்பாட்டில் இறங்குவதற்கு முன், நீங்கள் கொண்டிருக்க வேண்டியது:

- **மேம்பாட்டு சூழல்**: உங்கள் தேர்ந்த மொழிக்காக (C#, Java, Python, TypeScript அல்லது JavaScript)
- **IDE/எடிட்டர்**: Visual Studio, Visual Studio Code, IntelliJ, Eclipse, PyCharm அல்லது எந்த சமகால குறியீட்டு தொகுப்பும்
- **பேக்கேஜ் மேலாளர்கள்**: NuGet, Maven/Gradle, pip அல்லது npm/yarn
- **API விசைகள்**: உங்கள் ஹோஸ்ட் பயன்பாடுகளில் பயன்படுத்தவிரும்பும் ஏதேனும் AI சேவைகளுக்கான


### அதிகாரப்பூர்வ SDK கள்

வரவிருக்கும் அத்தியாயங்களில் Python, TypeScript,
Java மற்றும் .NET பயன்படுத்தி உருவாக்கப்பட்ட தீர்வுகளை நீங்கள் காண உள்ளீர்கள். இவை அதிகாரப்பூர்வ SDK கள்.

MCP `2026-07-28` க்கான SDK ஆதரவு மொழி தனித்தன்மையில் தானாகவே வழங்கப்படுகின்றது.
உதாரணம் ஓட்டுவதற்கு முன், அதன் பேக்கேஜ் பதிப்பையும் SDK வெளியீட்டு குறிப்புக்களையும்
ஆதரவு நெடுவழி திருத்தங்களுக்காக சரிபார்க்கவும். பாருங்கள்
[அதிகாரப்பூர்வ SDK பட்டியல்](https://modelcontextprotocol.io/docs/sdk):
- [C# SDK](https://github.com/modelcontextprotocol/csharp-sdk) - Microsoft உடன் கூட்டாக பராமரிக்கப்படும்
- [Java SDK](https://github.com/modelcontextprotocol/java-sdk) - Spring AI உடன் கூட்டாக பராமரிக்கப்படும்
- [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) - அதிகாரப்பூர்வ TypeScript செயலாக்கம்
- [Python SDK](https://github.com/modelcontextprotocol/python-sdk) - அதிகாரப்பூர்வ Python செயலாக்கம் (FastMCP)
- [Kotlin SDK](https://github.com/modelcontextprotocol/kotlin-sdk) - அதிகாரப்பூர்வ Kotlin செயலாக்கம்
- [Swift SDK](https://github.com/modelcontextprotocol/swift-sdk) - Loopwork AI உடன் கூட்டாக பராமரிக்கப்படும்
- [Rust SDK](https://github.com/modelcontextprotocol/rust-sdk) - அதிகாரப்பூர்வ Rust செயலாக்கம்
- [Go SDK](https://github.com/modelcontextprotocol/go-sdk) - அதிகாரப்பூர்வ Go செயலாக்கம்

## முக்கியமான முடிவுகள்

- பிரச்சாரப்படுத்தல் பரிமாணங்கள் உள்ளூர் மேம்பாட்டு சூழல் முதல் மேக அடிப்படையிலான தீர்வுகள் வரை உள்ளன
