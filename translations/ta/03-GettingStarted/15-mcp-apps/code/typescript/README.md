இது MCP App-ஐ விளக்கும் ஒரு உதாரணம்.

## நிறுவல் 

1. *mcp-app* கோப்பகத்திற்கு செல்லவும்
1. `npm install` இயக்கவும், இது முன்னணி மற்றும் பின்னணி சார்புகளை நிறுவும்

பின்னணி தொகுக்கப்படுகிறதா என்பதை சரிபார்க்க இயக்கவும்:

```sh
npx tsc --noEmit
```

எல்லாம் சரியாக இருந்தால் எந்தவொரு வெளியீடும் இல்லாமலிருக்க வேண்டும்.

## பின்னணியை இயக்கவும்

> நீங்கள் Windows இயந்திரத்தில் இருந்தால் இது சில கூடுதல் வேலைகளை தேவைப்படுத்தும், ஏனெனில் MCP Apps தீர்வு ஓட `concurrently` நூலகத்தை பயன்படுத்துகிறது, அதற்கு மாற்று கண்டுபிடிக்க வேண்டும். இதோ MCP App-இல் பிரச்சனைசெய்யும் வரி *package.json*:

```json
"start": "concurrently \"cross-env NODE_ENV=development INPUT=mcp-app.html vite build --watch\" \"tsx watch main.ts\""
```

இந்த செயலியில் இரண்டு பகுதிகள் உள்ளன: ஒரு பின்னணி பகுதி மற்றும் ஒரு ஹோஸ்ட் பகுதி.

பின்னணியை தொடங்க கீழ்க்காணும் கட்டளையை அழைக்கவும்:

```sh
npm start
```

இது `http://localhost:3001/mcp` இல் பின்னணியைத் தொடங்கும்.

> குறிப்பு: நீங்கள் Codespace-இல் இருந்தால், போர்ட் காட்சித்திறனை public ஆக அமைக்க வேண்டும். உலாவியில் https://<name வழியாக Codespace>.app.github.dev/mcp இலக்கை அணுக முடிகிறதா என்பதை சரிபார்க்கவும்
