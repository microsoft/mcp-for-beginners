# 🚀 MCP கருவி

## 🧠 MCP தரவுத்தள ஒருங்கிணைப்பு கற்றல் பாதையின் கண்ணோட்டம்

இங்கு நீங்கள் MCP பயன்படுத்தும் கருவிகளை எவ்வாறு பயன்படுத்துவது என்பது குறித்து கற்றுக்கொள்ளப்போகின்றீர்கள். MCP சர்வர்களை அவற்றுடன் இணைக்கும் போது நீங்கள் இந்த கருவிகளை பயன்படுத்தும் அனுபவம் மேம்படும்.

## 🔗 அதிகாரபூர்வ MCP வளங்கள்

- 📘 [MCP ஆவணம்](https://modelcontextprotocol.io/) – விரிவான பயிற்சிகள் மற்றும் பயனர் வழிகாட்டிகள்
- 📜 [MCP குறிப்புரை (2026-07-28)](https://modelcontextprotocol.io/specification/2026-07-28/) – புரோட்டோக்கால் கட்டமைப்பு மற்றும் தொழில்நுட்ப குறிப்புகள்
- 🧑‍💻 [MCP GitHub தொகுதி](https://github.com/modelcontextprotocol) – திறந்த மூல SDKகள், கருவிகள் மற்றும் குறியீட்டு மாதிரிகள்
- 🌐 [MCP சமூகம்](https://github.com/orgs/modelcontextprotocol/discussions) – விவாதங்களில் சேரவும் மற்றும் சமூகத்தில் பங்களிக்கவும்
- 🔒 [OWASP MCP டாப் 10](https://microsoft.github.io/mcp-azure-security-guide/mcp/) – பாதுகாப்பு சிறந்த நடைமுறைகள் மற்றும் அபாயம் குறைப்புகள்
