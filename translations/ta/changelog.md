# மாற்றங்கள் பதிவு: MCP தொடக்கத்துறையினருக்கான படிப்புத்தொகுப்பு

இந்த ஆவணம் மாடல் சூழல் புரோட்டோக்கோல் (MCP) தொடக்கத்துறையினருக்கான படிப்புத்தொகுப்பில் செய்யப்பட்ட அனைத்து முக்கிய மாற்றங்களையும் பதிவு செய்யும் கருவியாக செயல்படுகிறது. மாற்றங்கள் எதிர் கால வரிசையில் பதிவு செய்யப்படுகின்றன (புதிய மாற்றங்கள் முதலில்).

  வெளிப்படையான விளைவுகளுக்குப் பிறகு நிகழும் என்பதை எடுத்துக்காட்டுகிறது. ஆறு தீர்மானமான சோதனைகள் எளிய
  இரட்டிப்பு, பாதுகாப்பான மறுதொடக்கம் மீட்பு, உள்ளடக்கிய மோதல்கள், சேமிக்கப்பட்ட முடிவுகள்,
  செயலில் உள்ள கோரிக்கை மற்றும் ஒருங்கிணைந்த இரட்டிப்பு அனுமதி ஆகியவற்றைக் கையாள்கின்றன.

  - சர்வர் அடிப்படைகள்: வளங்கள் (தரவு ஆதாரங்கள்), ப்ராம்ட்கள் (வடிவமைப்புகள்), கருவிகள் (செயல்படுத்தக்கூடிய செயல்பாடுகள்) விரிவான விளக்கங்களுடன் மற்றும் எடுத்துக்காட்டுகள்

- **தரநிலை ஒத்திசைவு**: MCP Specification 2025-06-18 பாதுகாப்பு தேவைகளுடன் முழுமையான ஒத்திசைவு
- **அங்கீகாரம் மேம்பாடு**: தனிப்பட்ட OAuth சர்வர்களிலிருந்து வெளிப்புற அடையாள வழங்குநர் மாற்றத்துக்கான ஆவணப்படுத்துதல் (Microsoft Entra ID)
- **AI சார்ந்த அச்சுறுத்தல் பகுப்பு**: நவீன AI தாக்குதல் வழிகளுக்கான விரிவான செயல்பாட்டினை மேம்படுத்தல்
  - விரிவான ப்ராம்ட் ஊக்கு தாக்குதல் காட்சிகள் உண்மையான எடுத்துக்காட்டுகளோடு
  - கருவி விஷ விஷயாக்கம் மற்றும் "ரக் புல்" தாக்குதல் வடிவங்கள்
  - உரையாடல் விண்டோ விஷ விஷயாக்கம் மற்றும் மாதிரி குழப்ப தாக்குதல்கள்
- **Microsoft AI பாதுகாப்பு தீர்வுகள்**: Microsoft பாதுகாப்பு சூழல் முழுவதும் விரிவான கவுன்
  - AI Prompt Shields மேம்பட்ட கண்டறிதல், விளக்கு மற்றும் விநியோக கலைகளோடு
  - Azure Content Safety ஒருங்கிணைப்பு மாதிரிகள்
  - GitHub Advanced Security சப்ளை சங்கிலி பாதுகாப்பாக
- **மேம்பட்ட அச்சுறுத்தல் குறைப்பு**: பாதுகாப்பு கட்டுப்பாடுகள் விரிவாக
  - MCP-சார்ந்த அமர்வு கைபற்றல் தாக்குதல்கள் மற்றும் குறியாக்க அமர்வு ID தேவைகளோடு
  - MCP பிரதிநிதி சூழலில் குழப்பப்பட்ட டியூட்டி பிரச்சினைகள் தெளிவான அனுமதி தேவைகளுடன்
  - கட்டாய சரிபார்ப்புடன் டோக்கன் பாஸ்த்ரூ மாற்ற வெளிவீ்பு
- **சப்ளை சங்கிலி பாதுகாப்பு**: அடிப்படை மாதிரிகள், எம்பெட்டிங் சேவைகள், உரையாடல் வழங்குநர்கள் மற்றும் மூன்றாம் தரப்பு API-களை உள்ளடக்கிய AI சப்ளை சங்கிலி விரிவாக்கம்
- **அடிப்படை பாதுகாப்பு**: பூஜ்ய நம்பிக்கை கட்டமைப்பு மற்றும் Microsoft பாதுகாப்பு சூழல் உட்பட எண்டர்பிரைஸ் பாதுகாப்பு நடைமுறைகளுடன் விரிவான ஒருங்கிணைப்பு
- **வள ஒழுங்குபெயர்ப்பு**: வகை வாரியாக விரிவான வள இணைப்புகள் வகைப்படுத்தல் (அதிகாரப்பூர்வ ஆவணங்கள், தரநிலைகள், ஆராய்ச்சி, Microsoft தீர்வுகள், நிறுவல் வழிகாட்டிகள்)

### ஆவண தர மற்றும் தரநிலை மேம்பாடுகள்
- **கட்டமைக்கப்பட்ட கல்வி நோக்கங்கள்**: குறிப்பிட்ட, நடைமுறை பொருட்களுடன் கல்வி நோக்கங்களை மேம்படுத்தியது 
- **இடைமுகச்செய்திகள்**: சம்பந்தப்பட்ட பாதுகாப்பு மற்றும் மையக் கருத்துக்களுக்கிடையே இணைப்புகள் சேர்க்கப்பட்டது
- **தற்போதைய தகவல்**: அனைத்து தேதிக் குறிப்புகளும் மற்றும் விவரக்குறிப்பு இணைப்புகளும் தற்போதைய நிலைகளுக்கு புதுப்பிக்கப்பட்டன
- **நிறுவல் வழிகாட்டி**: இரு பிரிவுகளிலும் குறிப்பிட்ட, நடைமுறை நிறுவல் வழிகாட்டல்கள் சேர்க்கப்பட்டது
