# மாற்றம் பதிவு: MCP தொடக்கக் கற்கைக்கூட பாடத்திட்டம்

Model Context Protocol (MCP) தொடக்கக் கற்கைக்கூட பாடத்திட்டத்தில் செய்யப்பட்ட முக்கிய மாற்றங்களை பதிவு செய்வதற்கான ஆவணம் இது. மாற்றங்கள் காலவரிசை முறையில் (புதிய மாற்றங்கள் முதலில்) பதிவு செய்யப்பட்டுள்ளன.

#### தற்போதைய SDK களுடன் மாதிரி சரிபார்ப்பு

- **TypeScript (03-GettingStarted/01-first-server/solution/typescript)**: `npm install` மூலம் `@modelcontextprotocol/sdk@1.29.0` தீர்வு; `tsc --noEmit` எந்த வகை பிழைகளும் இல்லாமல் வெற்றி — நிலுவையில் உள்ள `McpServer` / `StdioServerTransport` APIs செல்லுபடியாகும்

- அனைத்து மாதிரிகளும் `@modelcontextprotocol/sdk` பதிப்புக்கள் (`>=1.26.0` / `^1.26.0` / `^1.27.0`) தற்போதைய `1.29.0` ஆகத் தெளிவாக முடிந்தது, API உட்பிரேதங்கள் இல்லை என உறுதிப்படுத்தப்பட்டது

  - **அங்கீகாரம் கொள்கைகள்**: அங்கீகாரம் மற்றும் அங்கீகாரம் வேறுபாடு மற்றும் நம்பகத்தன்மை கையாள்பு தெளிவான விளக்கம்

  - MCP பிரதிநிதி சூழ்நிலைகளில் குழப்பப்பட்ட துணை பிரச்சினைகள் மற்றும் தெளிவான ஒப்புதல் தேவைகள்  
  - கட்டாய சரிபார்ப்புக் கட்டுப்பாடுகளுடன் டோக்கன் பாஸ்த்ரோை வழிவிட்ட குறைபாடுகள்

- **அடிப்படை பாதுகாப்பு**: ஜீரோ நம்பிக்கை கட்டமைப்பு மற்றும் Microsoft பாதுகாப்பு சூழல் உட்பட நிறுவன பாதுகாப்பு வரைபடங்களுடன் மேம்பாடு
