# 🚀 10 माइक्रोसॉफ्ट MCP सर्वर जो डेवलपर उत्पादकता को बदल रहे हैं

## 🎯 इस गाइड में आप क्या सीखेंगे

यह व्यावहारिक गाइड दस माइक्रोसॉफ्ट MCP सर्वर्स को प्रस्तुत करता है जो सक्रिय रूप से यह बदल रहे हैं कि डेवलपर्स AI असिस्टेंट्स के साथ कैसे काम करते हैं। सिर्फ यह बताने के बजाय कि MCP सर्वर *क्या* कर सकते हैं, हम ऐसे सर्वर्स दिखाएंगे जो पहले से ही माइक्रोसॉफ्ट और उससे परे दैनिक विकास वर्कफ़्लो में वास्तविक अंतर ला रहे हैं।

इस गाइड में प्रत्येक सर्वर को वास्तविक उपयोग और डेवलपर प्रतिक्रिया के आधार पर चुना गया है। आप न केवल जानेंगे कि हर सर्वर क्या करता है, बल्कि यह भी कि यह क्यों महत्वपूर्ण है और अपने खुद के प्रोजेक्ट्स में इसका अधिकतम कैसे उपयोग करें। चाहे आप MCP में बिल्कुल नए हों या अपनी मौजूदा सेटअप को विस्तारित करना चाहते हों, ये सर्वर्स माइक्रोसॉफ्ट इकोसिस्टम में उपलब्ध कुछ सबसे व्यावहारिक और प्रभावी टूल्स का प्रतिनिधित्व करते हैं।

> **💡 त्वरित प्रारंभ टिप**
> 
> MCP में नए हैं? चिंता मत करें! यह गाइड शैक्षिक और शुरुआती के लिए उपयुक्त है। हम अवधारणाओं को विस्तार से समझाएंगे, और आप हमेशा हमारे [MCP परिचय](../00-Introduction/README.md) और [कोर अवधारणाएं](../01-CoreConcepts/README.md) मॉड्यूल से गहरी जानकारी प्राप्त कर सकते हैं।

## अवलोकन

यह व्यापक गाइड दस माइक्रोसॉफ्ट MCP सर्वरों की खोज करता है जो यह क्रांति ला रहे हैं कि डेवलपर AI असिस्टेंट्स और बाहरी टूल्स के साथ कैसे इंटरैक्ट करते हैं। Azure संसाधन प्रबंधन से लेकर दस्तावेज़ प्रसंस्करण तक, ये सर्वर मॉडल कंटेक्स्ट प्रोटोकॉल की शक्ति को दिखाते हैं जो सहज, उत्पादक विकास वर्कफ़्लोज़ बनाते हैं।

## सीखने के उद्देश्य

इस गाइड के अंत तक, आप:

- माइक्रोसॉफ्ट के प्रभावशाली MCP सर्वर कार्यान्वयन के बारे में जानेंगे
- प्रत्येक सर्वर के व्यावहारिक उपयोग मामलों का पता लगाएंगे
- VS Code और Visual Studio में इन सर्वरों को सेटअप और कॉन्फ़िगर करना सीखेंगे
- व्यापक MCP इकोसिस्टम और भविष्य की दिशा का अन्वेषण करेंगे

## 🔧 MCP सर्वरों को समझना: एक शुरुआती मार्गदर्शिका

### MCP सर्वर क्या हैं?

मॉडल कंटेक्स्ट प्रोटोकॉल (MCP) के शुरुआती के रूप में, आप सोच सकते हैं: "MCP सर्वर वास्तव में क्या है, और मुझे इसकी परवाह क्यों करनी चाहिए?" चलिए एक सरल उपमा से शुरू करते हैं।

MCP सर्वर्स को विशेष सहायक के रूप में सोचें जो आपके AI कोडिंग साथी (जैसे GitHub Copilot) को बाहरी टूल्स और सेवाओं से जोड़ने में मदद करते हैं। जैसे आप अपने फोन पर अलग-अलग कार्यों के लिए अलग-अलग एप्लिकेशन का उपयोग करते हैं—एक मौसम के लिए, एक नेविगेशन के लिए, एक बैंकिंग के लिए—वैसे ही MCP सर्वर आपके AI सहायक को विभिन्न विकास टूल्स और सेवाओं के साथ इंटरैक्ट करने की क्षमता देते हैं।

### MCP सर्वर जो समस्या हल करते हैं

MCP सर्वर से पहले, यदि आप चाहते थे:
- अपने Azure संसाधनों की जाँच करें
- GitHub इश्यू बनाएं
- अपने डेटाबेस से प्रश्न पूछें
- दस्तावेज़ की खोज करें

तो आपको कोडिंग रोकनी पड़ती थी, ब्राउज़र खोलना पड़ता था, संबंधित वेबसाइट पर जाना पड़ता था, और ये काम मैन्युअल रूप से करने पड़ते थे। यह बार-बार संदर्भ बदलना आपके प्रवाह को तोड़ देता था और उत्पादकता को कम करता था।

### MCP सर्वर आपके विकास अनुभव को कैसे बदलते हैं

MCP सर्वरों के साथ, आप अपने विकास पर्यावरण (VS Code, Visual Studio, आदि) में रह सकते हैं और बस अपने AI सहायक से इन कार्यों को संभालने के लिए कह सकते हैं। उदाहरण के लिए:

**इस पारंपरिक कार्य प्रवाह के बजाय:**
1. कोडिंग रोकें
2. ब्राउज़र खोलें
3. Azure पोर्टल पर जाएं
4. स्टोरेज अकाउंट विवरण देखें
5. VS Code पर वापस आएं
6. कोडिंग पुनः प्रारंभ करें

**आप अब ये कर सकते हैं:**
1. AI से पूछें: "मेरे Azure स्टोरेज अकाउंट्स की स्थिति क्या है?"
2. प्रदान की गई जानकारी के साथ कोडिंग जारी रखें

### शुरुआती के लिए मुख्य फायदे

#### 1. 🔄 **अपने प्रवाह की स्थिति में बने रहें**
- कई एप्लिकेशन के बीच स्विचिंग बंद करें
- जिस कोड को आप लिख रहे हैं उस पर अपना ध्यान बनाए रखें
- विभिन्न टूल्स का प्रबंधन करने की मानसिक थकान कम करें

#### 2. 🤖 **जटिल कमांड के बजाय प्राकृतिक भाषा का उपयोग करें**
- SQL सिंटैक्स याद रखने के बजाय बताएं आपको कौन सा डेटा चाहिए
- Azure CLI कमांड याद रखने के बजाय बताएं आप क्या हासिल करना चाहते हैं
- AI को तकनीकी विवरण सँभालने दें जबकि आप लॉजिक पर ध्यान केंद्रित करें

#### 3. 🔗 **कई टूल्स को जोड़ें**
- विभिन्न सेवाओं को मिलाकर शक्तिशाली वर्कफ़्लोग बनाएं
- उदाहरण: "सभी हाल के GitHub इश्यू प्राप्त करें और उनके अनुरूप Azure DevOps कार्य आइटम बनाएं"
- जटिल स्क्रिप्ट लिखे बिना ऑटोमेशन बनाएं

#### 4. 🌐 **एक बढ़ते हुए इकोसिस्टम तक पहुंचें**
- माइक्रोसॉफ्ट, GitHub और अन्य कंपनियों द्वारा निर्मित सर्वरों से लाभ उठाएं
- विभिन्न विक्रेताओं के टूल्स को आसानी से मिलाएं
- एक मानकीकृत इकोसिस्टम में शामिल हों जो विभिन्न AI असिस्टेंट्स में काम करता है

#### 5. 🛠️ **करते हुए सीखें**
- अवधारणाओं को समझने के लिए पहले से बने सर्वरों के साथ शुरुआत करें
- जैसे-जैसे आप सहज हों, अपने खुद के सर्वर्स बनाएं
- उपलब्ध SDKs और दस्तावेज़ों का उपयोग करके सीखने में मदद लें

### शुरुआती के लिए वास्तविक दुनिया का उदाहरण

मान लीजिए आप वेब डेवलपमेंट में नए हैं और अपना पहला प्रोजेक्ट कर रहे हैं। यहां MCP सर्वर आपकी कैसे मदद कर सकते हैं:

**पारंपरिक दृष्टिकोण:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP सर्वरों के साथ:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### एंटरप्राइज स्टैंडर्ड का लाभ

MCP एक उद्योग-व्यापी मानक बन रहा है, जिसका मतलब है:
- **संगति**: विभिन्न टूल्स और कंपनियों में समान अनुभव
- **अंतर-संचालन**: विभिन्न विक्रेताओं के सर्वर एक साथ काम करते हैं
- **भविष्य-साक्षरता**: कौशल और सेटअप विभिन्न AI असिस्टेंट्स में स्थानांतरित हो सकते हैं
- **समुदाय**: साझा ज्ञान और संसाधनों का बड़ा इकोसिस्टम

## VS Code और Visual Studio में MCP के साथ शुरुआत 🚀

यदि आप Visual Studio Code या Visual Studio 2022 गिटहब कोपाइलट के साथ उपयोग कर रहे हैं तो इन MCP सर्वरों को सेटअप करना सरल है।

### VS Code सेटअप

VS Code के लिए मूल प्रक्रिया इस प्रकार है:

1. **एजेंट मोड सक्षम करें**: VS Code में, Copilot Chat विंडो में एजेंट मोड में स्विच करें
2. **MCP सर्वर कॉन्फ़िगर करें**: अपने VS Code settings.json फ़ाइल में सर्वर कॉन्फ़िगरेशन जोड़ें
3. **सर्वर्स शुरू करें**: उन सर्वरों के लिए "स्टार्ट" बटन पर क्लिक करें जिन्हें आप उपयोग करना चाहते हैं
4. **टूल्स चुनें**: अपनी वर्तमान सत्र के लिए कौन से MCP सर्वर्स सक्षम करना है, चुनें

विस्तृत सेटअप निर्देशों के लिए, देखें [VS Code MCP दस्तावेज़](https://code.visualstudio.com/docs/copilot/copilot-mcp)।

> **💡 प्रो टिप: MCP सर्वरों का प्रबंधन एक विशेषज्ञ की तरह करें!**
> 
> VS Code विस्तार दृश्य में अब एक [सुविधाजनक नया UI शामिल है जो स्थापित MCP सर्वरों का प्रबंधन करता है](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! आपके पास किसी भी इंस्टॉल किए गए MCP सर्वर को शुरू, रोकने और प्रबंधित करने के लिए एक स्पष्ट, सरल इंटरफ़ेस से त्वरित पहुंच है। इसे आजमाएं!

### Visual Studio 2022 सेटअप

Visual Studio 2022 (संस्करण 17.14 या बाद का) के लिए:

1. **एजेंट मोड सक्षम करें**: GitHub Copilot Chat विंडो में "Ask" ड्रॉपडाउन पर क्लिक करें और "Agent" चुनें
2. **कॉन्फ़िगरेशन फ़ाइल बनाएँ**: अपने सॉल्यूशन डायरेक्टरी में `.mcp.json` फ़ाइल बनाएँ (सुझाए गए स्थान: `<SOLUTIONDIR>\.mcp.json`)
3. **सर्वर कॉन्फ़िगर करें**: मानक MCP फॉर्मेट का उपयोग करके अपने MCP सर्वर कॉन्फ़िगरेशन जोड़ें
4. **टूल अनुमोदन**: जब संकेत मिले, तब उपयुक्त अनुमतियों के साथ उपयोग करने वाले टूलों को अनुमोदित करें

विस्तृत Visual Studio सेटअप निर्देशों के लिए देखें [Visual Studio MCP दस्तावेज़](https://learn.microsoft.com/visualstudio/ide/mcp-servers)।

प्रत्येक MCP सर्वर के अपने कॉन्फ़िगरेशन आवश्यकताएं होती हैं (कनेक्शन स्ट्रिंग्स, प्रमाणीकरण, आदि), लेकिन दोनों IDE में सेटअप पैटर्न समान है।

**यह क्यों उपयोगी है**: यह सिर्फ "दस्तावेज़ीकरण" लग सकता है, लेकिन यह सर्वर प्रत्येक माइक्रोसॉफ्ट तकनीक उपयोग करने वाले डेवलपर के लिए बेहद महत्वपूर्ण है। AI कोडिंग असिस्टेंट्स के बारे में .NET डेवलपर्स की सबसे बड़ी शिकायत यह है कि वे नवीनतम .NET और C# रिलीज़ के साथ अपडेट नहीं होते। माइक्रोसॉफ्ट लर्न डॉक MCP सर्वर इसे हल करता है यह सुनिश्चित करके कि आपका AI सहायक वास्तविक समय में नवीनतम दस्तावेज़, API संदर्भ और सर्वोत्तम प्रथाओं तक पहुँच रखता है। चाहे आप नवीनतम Azure SDKs के साथ काम कर रहे हों, नए C# 13 फीचर्स का अन्वेषण कर रहे हों, या उन्नत Aspire पैटर्न लागू कर रहे हों, यह सर्वर यह सुनिश्चित करता है कि आपका AI सहायक सटीक, आधुनिक कोड उत्पन्न करने के लिए आधिकारिक, अद्यतन जानकारी तक पहुँच रखता है।

**वास्तविक दुनिया में उपयोग**: "आधिकारिक माइक्रोसॉफ्ट लर्न दस्तावेज़ीकरण के अनुसार Azure कंटेनर ऐप बनाने के लिए az cli कमांड क्या हैं?" या "ASP.NET Core में डिपेंडेंसी इंजेक्शन के साथ Entity Framework को कैसे कॉन्फ़िगर किया जाए?" या "इस कोड की समीक्षा करें कि क्या यह माइक्रोसॉफ्ट लर्न दस्तावेज़ीकरण में प्रदर्शन सिफारिशों से मेल खाता है।" यह सर्वर माइक्रोसॉफ्ट लर्न, Azure डॉक्स और Microsoft 365 दस्तावेज़ों में व्यापक कवरेज प्रदान करता है, उन्नत सैमांटिक खोज का उपयोग करके सबसे प्रासंगिक जानकारी खोजता है। यह उच्च गुणवत्ता वाली सामग्री के 10 तक टुकड़े, लेख शीर्षक और URLs के साथ वापस करता है, हमेशा नवीनतम माइक्रोसॉफ्ट दस्तावेज़ को प्रकाशित होते ही एक्सेस करता है।

**विशेष उदाहरण**: यह सर्वर `microsoft_docs_search` टूल प्रदान करता है जो माइक्रोसॉफ्ट की आधिकारिक तकनीकी दस्तावेज़ीकरण पर सैमांटिक खोज करता है। एक बार कॉन्फ़िगर करने के बाद, आप प्रश्न पूछ सकते हैं जैसे "ASP.NET Core में JWT प्रमाणीकरण कैसे लागू करें?" और विस्तृत, आधिकारिक उत्तर स्रोत लिंक के साथ प्राप्त कर सकते हैं। खोज की गुणवत्ता उत्कृष्ट है क्योंकि यह संदर्भ समझता है – Azure संदर्भ में "containers" पूछने पर Azure Container Instances दस्तावेज़ लौटाएगा, जबकि .NET संदर्भ में यही शब्द प्रासंगिक C# संग्रह जानकारी वापस करता है।

यह विशेष रूप से तेजी से बदलते या हाल ही में अपडेट हुए लाइब्रेरी और उपयोग मामलों के लिए उपयोगी है। उदाहरण के लिए, कुछ हाल के कोडिंग प्रोजेक्ट में मैंने Aspire और Microsoft.Extensions.AI के नवीनतम रिलीज़ के फीचर्स का उपयोग करना चाहा। माइक्रोसॉफ्ट लर्न डॉक MCP सर्वर शामिल करके, मैंने न केवल API दस्तावेज़ों का लाभ उठाया, बल्कि अभी-अभी प्रकाशित वाकथ्रू और मार्गदर्शन का भी लाभ उठाया।

### 2. ☁️ Azure MCP Server


[![VS Code में इंस्टॉल करें](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![VS Code Insiders में इंस्टॉल करें](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**यह क्या करता है**: Azure MCP Server 15+ विशेषीकृत Azure सेवा कनेक्टर्स का एक समग्र सूट है जो पूरे Azure पारिस्थितिकी तंत्र को आपके AI वर्कफ़्लो में लाता है। यह सिर्फ एक सिंगल सर्वर नहीं है – यह एक शक्तिशाली संग्रह है जिसमें रिसोर्स मैनेजमेंट, डेटाबेस कनेक्टिविटी (PostgreSQL, SQL Server), KQL के साथ Azure Monitor लॉग विश्लेषण, Cosmos DB इंटीग्रेशन और बहुत कुछ शामिल है।

**यह उपयोगी क्यों है**: Azure संसाधनों का प्रबंधन करने के अलावा, यह सर्वर Azure SDKs के साथ काम करते समय कोड गुणवत्ता को नाटकीय रूप से सुधारता है। जब आप Agent मोड में Azure MCP का उपयोग करते हैं, तो यह सिर्फ आपको कोड लिखने में मदद नहीं करता – बल्कि आपको *बेहतर* Azure कोड लिखने में मदद करता है जो वर्तमान प्रमाणीकरण पैटर्न, त्रुटि हैंडलिंग सर्वोत्तम प्रथाओं का पालन करता है, और नवीनतम SDK फीचर्स का लाभ उठाता है। आपको ऐसा सामान्य कोड नहीं मिलता जो शायद काम करे, बल्कि ऐसा कोड मिलता है जो Azure की प्रोडक्शन वर्कलोड्स के लिए अनुशंसित पैटर्न का पालन करता है।

**मुख्य मॉड्यूल शामिल हैं**:
- **🗄️ डेटाबेस कनेक्टर्स**: Azure Database for PostgreSQL और SQL Server के लिए प्रत्यक्ष प्राकृतिक भाषा पहुँच
- **📊 Azure Monitor**: KQL संचालित लॉग विश्लेषण और परिचालन अंतर्दृष्टि
- **🌐 रिसोर्स मैनेजमेंट**: पूर्ण Azure संसाधन जीवनचक्र प्रबंधन
- **🔐 प्रमाणीकरण**: DefaultAzureCredential और प्रबंधित पहचान पैटर्न
- **📦 स्टोरेज सेवाएं**: ब्लॉब स्टोरेज, क्यू स्टोरेज, और टेबल स्टोरेज ऑपरेशन
- **🚀 कंटेनर सेवाएं**: Azure Container Apps, Container Instances, और AKS प्रबंधन
- **और भी कई विशेषीकृत कनेक्टर्स**

**वास्तविक उपयोग**: "मेरे Azure स्टोरेज खातों की सूची बनाएं", "पिछले घंटे में त्रुटियों के लिए मेरे Log Analytics वर्कस्पेस से क्वेरी करें", या "सही प्रमाणीकरण के साथ Node.js का उपयोग कर Azure एप्लिकेशन बनाने में मेरी मदद करें"

**पूर्ण डेमो परिदृश्य**: यहां एक संपूर्ण वॉकथ्रू है जो दिखाता है कि Azure MCP को VS Code में GitHub Copilot for Azure एक्सटेंशन के साथ जोड़ने में कितनी शक्ति है। जब आपके पास दोनों इंस्टॉल हों और आप निर्देश दें:

> "एक Python स्क्रिप्ट बनाएं जो DefaultAzureCredential प्रमाणीकरण का उपयोग करके Azure Blob Storage में एक फ़ाइल अपलोड करे। स्क्रिप्ट को मेरे Azure स्टोरेज खाते 'mycompanystorage' से कनेक्ट करना चाहिए, 'documents' नामक कंटेनर में अपलोड करना चाहिए, अपलोड के लिए मौजूदा टाइमस्टैम्प के साथ एक टेस्ट फ़ाइल बनानी चाहिए, त्रुटियों को प्रभावी ढंग से संभालना चाहिए और सूचनात्मक आउटपुट प्रदान करना चाहिए, Azure की प्रमाणीकरण और त्रुटि हैंडलिंग के सर्वोत्तम प्रथाओं का पालन करना चाहिए, इस बात की स्पष्टता के लिए टिप्पणियाँ शामिल होनी चाहिए कि DefaultAzureCredential प्रमाणीकरण कैसे काम करता है, और स्क्रिप्ट को उचित फंक्शंस और दस्तावेजीकरण के साथ अच्छी तरह से संरचित बनाना चाहिए।"

Azure MCP Server एक पूर्ण, प्रोडक्शन-तैयार Python स्क्रिप्ट उत्पन्न करेगा जो:
- नवीनतम Azure Blob Storage SDK का उपयोग सही async पैटर्न के साथ करता है
- व्यापक fallback चेन व्याख्या के साथ DefaultAzureCredential लागू करता है
- विशिष्ट Azure अपवाद प्रकारों के साथ मजबूत त्रुटि हैंडलिंग शामिल करता है
- रिसोर्स मैनेजमेंट और कनेक्शन हैंडलिंग के लिए Azure SDK सर्वोत्तम प्रथाओं का पालन करता है
- विस्तृत लॉगिंग और सूचनात्मक कंसोल आउटपुट प्रदान करता है
- फंक्शन्स, दस्तावेजीकरण, और टाइप हिंट्स के साथ उचित रूप से संरचित स्क्रिप्ट बनाता है

इसे खास बनाता है कि Azure MCP के बिना आपको सामान्य ब्लॉब स्टोरेज कोड मिल सकता है जो काम कर सकता है लेकिन वर्तमान Azure पैटर्न का पालन नहीं करता। Azure MCP के साथ, आपको कोड मिलता है जो नवीनतम प्रमाणीकरण विधियों का लाभ उठाता है, Azure-विशिष्ट त्रुटि परिदृश्यों को संभालता है, और प्रोडक्शन एप्लिकेशन के लिए Microsoft की अनुशंसित प्रथाओं का पालन करता है।

**विशिष्ट उदाहरण**: मुझे adhoc उपयोग के लिए `az` और `azd` CLI के विशिष्ट कमांड याद रखने में कठिनाई होती है। यह मेरे लिए हमेशा दो-चरण की प्रक्रिया होती है: पहले सिंटैक्स देखना, फिर कमांड चलाना। अक्सर मैं पोर्टल में जाकर काम करता हूं क्योंकि मुझे स्वीकार नहीं करना चाहता कि मैं CLI सिंटैक्स याद नहीं रख सकता। जो मैं चाहता हूं उसे बस वर्णित करना अद्भुत है, और इससे भी बेहतर है कि मैं यह अपने IDE को छोड़े बिना कर सकता हूं!

शुरुआत के लिए, [Azure MCP रिपोजिटरी](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) में उपयोग मामलों की एक बेहतरीन सूची है। व्यापक सेटअप गाइड और उन्नत कॉन्फ़िगरेशन विकल्पों के लिए, [आधिकारिक Azure MCP दस्तावेज़](https://learn.microsoft.com/azure/developer/azure-mcp-server/) देखें।

**यह क्या करता है**: आधिकारिक GitHub MCP Server GitHub के पूरे इकोसिस्टम के साथ सहज एकीकरण प्रदान करता है, जिसमें होस्ट किए गए दूरस्थ एक्सेस और स्थानीय Docker डिप्लॉयमेंट विकल्प दोनों शामिल हैं। यह सिर्फ मूल रिपोजिटरी ऑपरेशंस के बारे में नहीं है – यह एक व्यापक टूलकिट है जिसमें GitHub Actions प्रबंधन, पुल रिक्वेस्ट वर्कफ़्लो, इशू ट्रैकिंग, सुरक्षा स्कैनिंग, सूचनाएं और उन्नत ऑटोमेशन क्षमताएँ शामिल हैं।

**यह उपयोगी क्यों है**: यह सर्वर GitHub के साथ आपकी बातचीत के तरीके को बदल देता है और पूर्ण प्लेटफ़ॉर्म अनुभव को सीधे आपके विकास वातावरण में लाता है। परियोजना प्रबंधन, कोड समीक्षा, और CI/CD मॉनिटरिंग के लिए VS Code और GitHub.com के बीच निरंतर स्विच करने के बजाय, आप प्राकृतिक भाषा कमांड के माध्यम से सब कुछ संभाल सकते हैं जबकि आप अपने कोड पर ध्यान केंद्रित करते हैं।

> **ℹ️ नोट: 'एजेंट्स' के विभिन्न प्रकार**
> 
> इस GitHub MCP Server को GitHub के Coding Agent (AI एजेंट जिसे आप कोडिंग कार्यों के लिए इशू असाइन कर सकते हैं) से मत भ्रमित करें। GitHub MCP Server VS Code के Agent मोड के भीतर GitHub API इंटीग्रेशन प्रदान करता है, जबकि GitHub का Coding Agent एक अलग फीचर है जो GitHub इशूज़ को असाइन किए जाने पर पुल रिक्वेस्ट बनाता है।

**मुख्य क्षमताएँ शामिल हैं**:
- **⚙️ GitHub Actions**: पूर्ण CI/CD पाइपलाइन प्रबंधन, वर्कफ़्लो मॉनिटरिंग, और आर्टिफैक्ट हैंडलिंग
- **🔀 पुल रिक्वेस्ट्स**: PR बनाना, समीक्षा करना, मर्ज करना, और पूर्ण स्थिति ट्रैकिंग के साथ प्रबंधन
- **🐛 इशूज़**: पूर्ण इशू जीवनचक्र प्रबंधन, टिप्पणियां, लेबलिंग, और असाइनमेंट
- **🔒 सुरक्षा**: कोड स्कैनिंग अलर्ट, गुप्त पहचान, और Dependabot इंटीग्रेशन
- **🔔 सूचनाएं**: स्मार्ट नोटिफिकेशन प्रबंधन और रिपोजिटरी सदस्यता नियंत्रण
- **📁 रिपोजिटरी प्रबंधन**: फ़ाइल ऑपरेशन, ब्रांच प्रबंधन, और रिपोजिटरी प्रशासन
- **👥 सहयोग**: उपयोगकर्ता और संगठन खोज, टीम प्रबंधन, और एक्सेस नियंत्रण

**वास्तविक उपयोग**: "मेरी फीचर ब्रांच से एक पुल रिक्वेस्ट बनाएं", "मुझे इस सप्ताह सभी असफल CI रन दिखाएं", "मेरे रिपोजिटरी के लिए खुले सुरक्षा अलर्ट की सूची बनाएं", या "मेरे संगठन में मुझे असाइन किए गए सभी इशू खोजें"

**पूर्ण डेमो परिदृश्य**: यहां एक शक्तिशाली वर्कफ़्लो है जो GitHub MCP Server की क्षमताओं को प्रदर्शित करता है:

> "मुझे हमारे स्प्रिंट समीक्षा के लिए तैयारी करनी है। इस सप्ताह मैंने जो भी पुल रिक्वेस्ट बनाए हैं उन्हें दिखाएं, हमारे CI/CD पाइपलाइनों की स्थिति जांचें, हमारे द्वारा संबोधित किए जाने वाले किसी भी सुरक्षा अलर्ट का सारांश बनाएं, और मर्ज हुए PRs के 'feature' लेबल के आधार पर रिलीज नोट्स ड्राफ्ट करने में मेरी मदद करें।"

GitHub MCP Server:
- आपके हाल के पुल रिक्वेस्ट्स को विस्तृत स्थिति जानकारी के साथ क्वेरी करेगा
- वर्कफ़्लो रन का विश्लेषण करेगा और किसी भी असफलता या प्रदर्शन मुद्दों को हाइलाइट करेगा
- सुरक्षा स्कैनिंग परिणाम संकलित करेगा और महत्वपूर्ण अलर्ट को प्राथमिकता देगा
- मर्ज हुए PRs से जानकारी निकालकर व्यापक रिलीज नोट्स तैयार करेगा
- स्प्रिंट योजना और रिलीज तैयारी के लिए व्यावहारिक अगले कदम प्रदान करेगा

**विशिष्ट उदाहरण**: मुझे यह कोड समीक्षा वर्कफ़्लो के लिए बहुत पसंद है। VS Code, GitHub सूचनाओं और पुल रिक्वेस्ट पेजों के बीच कूदने के बजाय, मैं कह सकता हूं "मुझे मेरे समीक्षा के लिए प्रतीक्षारत सभी PR दिखाओ" और फिर "PR #123 में प्रमाणीकरण विधि में त्रुटि हैंडलिंग के बारे में एक टिप्पणी जोड़ो।" सर्वर GitHub API कॉल्स संभालता है, चर्चा का संदर्भ बनाए रखता है, और मुझे अधिक रचनात्मक समीक्षा टिप्पणियाँ तैयार करने में भी मदद करता है।

**प्रमाणीकरण विकल्प**: सर्वर OAuth (VS Code में सहज) और Personal Access Tokens दोनों का समर्थन करता है, साथ ही कॉन्फ़िगर करने योग्य टूलसेट्स केवल आवश्यक GitHub कार्यक्षमता सक्षम करने के लिए। आप इसे त्वरित सेटअप के लिए दूरस्थ होस्टेड सेवा के रूप में या पूर्ण नियंत्रण के लिए स्थानीय रूप से Docker द्वारा चला सकते हैं।

> **💡 प्रो टिप**
> 
> अपनी MCP सर्वर सेटिंग्स में `--toolsets` पैरामीटर कॉन्फ़िगर करके केवल आवश्यक टूलसेट्स सक्षम करें ताकि संदर्भ आकार कम हो और AI टूल चयन बेहतर हो सके। उदाहरण के लिए, कोर विकास वर्कफ़्लो के लिए अपने MCP कॉन्फ़िगरेशन आर्ग्स में `"--toolsets", "repos,issues,pull_requests,actions"` जोड़ें, या यदि आप मुख्य रूप से GitHub मॉनिटरिंग क्षमताओं की इच्छा रखते हैं तो `"--toolsets", "notifications, security"` का उपयोग करें।

### 5. 📝 MarkItDown MCP Server


[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_MarkItDown_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_MarkItDown_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/markitdown)

**यह क्या करता है**: MarkItDown एक व्यापक दस्तावेज़ रूपांतरण सर्वर है जो विभिन्न फ़ाइल स्वरूपों को उच्च-गुणवत्ता वाले Markdown में परिवर्तित करता है, जो LLM खपत और पाठ विश्लेषण कार्यप्रवाह के लिए अनुकूलित है।

**यह क्यों उपयोगी है**: आधुनिक दस्तावेज़ीकरण कार्यप्रवाह के लिए आवश्यक! MarkItDown कई फ़ाइल प्रारूपों को संभालता है जबकि शीर्षक, सूचियाँ, तालिकाएँ और लिंक जैसी महत्वपूर्ण दस्तावेज़ संरचना को संरक्षित करता है। सरल पाठ निष्कर्षण उपकरणों के विपरीत, यह सार्थक अर्थ और स्वरूपण बनाए रखने पर केंद्रित है, जो AI प्रोसेसिंग और मानव पठनीयता दोनों के लिए मूल्यवान है।

**समर्थित फ़ाइल प्रारूप**:
- **ऑफिस दस्तावेज़**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **मीडिया फ़ाइलें**: छवियाँ (EXIF मेटाडाटा और OCR के साथ), ऑडियो (EXIF मेटाडाटा और भाषण लिप्यंतरण के साथ)
- **वेब सामग्री**: HTML, RSS फ़ीड, YouTube URL, विकिपीडिया पृष्ठ
- **डेटा प्रारूप**: CSV, JSON, XML, ZIP फ़ाइलें (सामग्री को पुनरावृत्ति के साथ संसाधित करता है)
- **प्रकाशन प्रारूप**: EPub, Jupyter नोटबुक (.ipynb)
- **ईमेल**: Outlook संदेश (.msg)
- **उन्नत**: बेहतर PDF प्रसंस्करण के लिए Azure Document Intelligence एकीकरण

**उन्नत क्षमताएँ**: MarkItDown LLM-संचालित छवि विवरणों का समर्थन करता है (जब OpenAI क्लाइंट प्रदान किया जाए), बेहतर PDF प्रसंस्करण के लिए Azure Document Intelligence, भाषण सामग्री के लिए ऑडियो लिप्यंतरण, और अतिरिक्त फ़ाइल स्वरूपों के लिए प्लगइन सिस्टम।

**वास्तविक दुनिया उपयोग**: "हमारी दस्तावेज़ीकरण साइट के लिए इस PowerPoint प्रस्तुति को Markdown में परिवर्तित करें", "इस PDF से उचित शीर्षक संरचना के साथ पाठ निकालें", या "इस Excel स्प्रेडशीट को पठनीय तालिका प्रारूप में बदलें"

**विशेष उदाहरण**: [MarkItDown docs](https://github.com/microsoft/markitdown#why-markdown) से उद्धृत करने के लिए:

> Markdown लगभग सामान्य पाठ के समान है, जिसमें न्यूनतम मार्कअप या स्वरूपण होता है, लेकिन फिर भी महत्वपूर्ण दस्तावेज़ संरचना को दर्शाने का एक तरीका प्रदान करता है। मुख्यधारा के LLM, जैसे OpenAI का GPT-4o, मूल रूप से Markdown "बोलते हैं", और अक्सर अनुरोध न किए भी Markdown को उनकी प्रतिक्रियाओं में शामिल करते हैं। यह सुझाव देता है कि उन्हें बड़ी मात्रा में Markdown-स्वरूपित पाठ पर प्रशिक्षित किया गया है, और वे इसे अच्छी तरह से समझते हैं। एक अतिरिक्त लाभ के रूप में, Markdown सम्मेलन भी अत्यधिक टोकन-कुशल हैं।

MarkItDown दस्तावेज़ संरचना को संरक्षित करने में बहुत अच्छा है, जो AI कार्यप्रवाहों के लिए महत्वपूर्ण है। उदाहरण के लिए, PowerPoint प्रस्तुति को परिवर्तित करते समय, यह स्लाइड संगठन को उचित शीर्षकों के साथ रखता है, तालिकाओं को Markdown तालिकाओं के रूप में निकालता है, छवियों के लिए वैकल्पिक पाठ शामिल करता है, और यहां तक कि वक्ता नोट्स को भी संसाधित करता है। चार्ट पढ़ने योग्य डेटा तालिकाओं में परिवर्तित हो जाते हैं, और परिणामी Markdown मूल प्रस्तुति के तार्किक प्रवाह को बनाए रखता है। यह प्रस्तुति सामग्री को AI सिस्टम में फीड करने या मौजूदा स्लाइड से दस्तावेज़ बनाने के लिए इसे परफेक्ट बनाता है।

- **📊 मूल्यांकन फ्रेमवर्क**: व्यापक टेक्स्ट और एजेंट मूल्यांकन चलाएं, मार्कडाउन रिपोर्ट बनाएं, और AI अनुप्रयोगों के लिए गुणवत्ता आश्वासन लागू करें
- **🚀 प्रोटोटाइपिंग टूल**: GitHub-आधारित प्रोटोटाइपिंग के लिए सेटअप निर्देश प्राप्त करें और Microsoft Foundry Labs से अत्याधुनिक अनुसंधान मॉडल एक्सेस करें

**वास्तविक दुनिया में डेवलपर उपयोग**: "मेरे एप्लिकेशन के लिए Phi-4 मॉडल को Azure AI सेवाओं पर डिप्लॉय करें", "मेरे दस्तावेज़ीकरण RAG सिस्टम के लिए एक नया खोज इंडेक्स बनाएं", "मेरे एजेंट के उत्तरों का गुणवत्ता मानकों के खिलाफ मूल्यांकन करें", या "मेरे जटिल विश्लेषण कार्यों के लिए सर्वश्रेष्ठ तर्क मॉडल खोजें"

**पूर्ण डेमो परिदृश्य**: यहाँ एक शक्तिशाली AI विकास कार्यप्रवाह है:

> "मैं एक कस्टमर सपोर्ट एजेंट बना रहा हूँ। मेरी मदद करें कि कैटलॉग से एक अच्छा तर्क मॉडल खोजें, उसे Azure AI सेवाओं पर डिप्लॉय करें, हमारे दस्तावेज़ीकरण से एक नॉलेज बेस बनाएं, प्रतिक्रिया गुणवत्ता परीक्षण के लिए एक मूल्यांकन फ्रेमवर्क सेट करें, और फिर GitHub टोकन के साथ परीक्षण के लिए इंटीग्रेशन का प्रोटोटाइप बनाएं।"

Microsoft Foundry MCP Server निम्न करेगा:
- आपके आवश्यकताओं के आधार पर सर्वोत्तम तर्क मॉडल की सिफारिश के लिए मॉडल कैटलॉग से प्रश्न करेगा
- आपके पसंदीदा Azure क्षेत्र के लिए डिप्लॉयमेंट कमांड और कोटा जानकारी प्रदान करेगा
- आपके दस्तावेज़ीकरण के लिए उचित स्कीमा के साथ Azure AI Search इंडेक्स सेटअप करेगा
- गुणवत्ता मानकों और सुरक्षा जांचों के साथ मूल्यांकन पाइपलाइनों को कॉन्फ़िगर करेगा
- त्वरित परीक्षण के लिए GitHub प्रमाणीकरण के साथ प्रोटोटाइपिंग कोड उत्पन्न करेगा
- आपके विशिष्ट तकनीकी स्टैक के अनुसार व्यापक सेटअप गाइड प्रदान करेगा

**विशेष उदाहरण**: एक डेवलपर के रूप में, मैं विभिन्न LLM मॉडल्स के साथ तालमेल बनाए रखने में कठिनाई महसूस कर रहा था। मैं कुछ मुख्य मॉडल जानता हूँ, लेकिन ऐसा लगता था कि मैं कुछ उत्पादकता और दक्षता लाभ खो रहा हूँ। और टोकन और कोटा प्रबंधन तनावपूर्ण और मुश्किल है – मुझे कभी पता नहीं चलता कि मैं सही कार्य के लिए सही मॉडल चुन रहा हूँ या मेरे बजट को अनुचित तरीके से खर्च कर रहा हूँ। मैंने James Montemagno से इस MCP सर्वर के बारे में सुना जब मैं MCP सर्वर सिफारिशों के लिए टीम के साथ बात कर रहा था, और मैं इसे उपयोग करने के लिए उत्साहित हूँ! मॉडल खोज क्षमताएँ विशेष रूप से प्रभावशाली लगती हैं उन लोगों के लिए जो सामान्य मॉडल्स से परे जाकर विशिष्ट कार्यों के लिए अनुकूलित मॉडल खोजना चाहते हैं। मूल्यांकन फ्रेमवर्क मुझे यह सत्यापित करने में मदद करेगा कि मैं वास्तव में बेहतर परिणाम पा रहा हूँ, न कि केवल कुछ नया आज़माने के लिए।

> **ℹ️ प्रायोगिक स्थिति**
> 
> यह MCP सर्वर प्रायोगिक है और सक्रिय विकासाधीन है। फीचर्स और APIs में परिवर्तन हो सकते हैं। Azure AI क्षमताओं का अन्वेषण करने और प्रोटोटाइप बनाने के लिए उपयुक्त, लेकिन उत्पादन उपयोग के लिए स्थिरता आवश्यकताओं को सत्यापित करें।
### 10. 🏢 Microsoft 365 एजेंट्स टूलकिट MCP सर्वर

**यह क्या करता है**: Microsoft 365 और Microsoft 365 Copilot के साथ एकीकृत AI एजेंट्स और अनुप्रयोगों का निर्माण करने के लिए आवश्यक उपकरण डेवलपर्स को प्रदान करता है, जिसमें स्कीमा सत्यापन, नमूना कोड पुनःप्राप्ति, और समस्या निवारण सहायता शामिल है।

**यह क्यों उपयोगी है**: Microsoft 365 और Copilot के लिए निर्माण में जटिल manifesto स्कीमा और विशिष्ट विकास पैटर्न शामिल हैं। यह MCP सर्वर आवश्यक विकास संसाधनों को सीधे आपके कोडिंग वातावरण में लाता है, जिससे आप स्कीमा सत्यापित कर सकते हैं, नमूना कोड खोज सकते हैं, और दस्तावेज़ों का लगातार संदर्भ लिए बिना सामान्य समस्याओं का निवारण कर सकते हैं।

**वास्तविक दुनिया उपयोग**: "मेरे डिक्लेरेटिव एजेंट मैनिफेस्ट को सत्यापित करें और किसी भी स्कीमा त्रुटियों को ठीक करें", "माइक्रोसॉफ्ट ग्राफ API प्लगइन लागू करने के लिए नमूना कोड दिखाएं", या "मेरे Teams ऐप प्रमाणीकरण मुद्दों का निवारण करने में मेरी मदद करें"

**विशेष उदाहरण**: मैंने Build में M365 एजेंट्स पर John Miller से बात की, और उन्होंने यह MCP सुझाया। यह नए M365 एजेंट डेवलपर्स के लिए उपयोगी हो सकता है क्योंकि यह टेम्पलेट्स, नमूना कोड, और स्थापित करने के लिए स्कैफोल्डिंग प्रदान करता है ताकि वे दस्तावेज़ों में खोए बिना शुरू कर सकें। स्कीमा सत्यापन सुविधाएँ विशेष रूप से उपयोगी लगती हैं ताकि मैनिफेस्ट संरचना त्रुटियां टाल सकें जो घंटों की डीबगिंग करवा सकती हैं।

## अगला क्या? 🔮

## 📋 निष्कर्ष

मॉडल कॉन्टेक्स्ट प्रोटोकॉल (MCP) डेवलपर्स के AI सहायक और बाहरी उपकरणों के साथ इंटरैक्शन के तरीके को बदल रहा है। ये 10 Microsoft MCP सर्वर मानकीकृत AI इंटीग्रेशन की शक्ति का प्रदर्शन करते हैं, जो सहज वर्कफ़्लोज़ सक्षम करते हैं जो डेवलपर्स को उनकी फ्लो स्टेट में रखते हैं और शक्तिशाली बाहरी क्षमताओं तक पहुँच प्रदान करते हैं।

व्यापक Azure इकोसिस्टम एकीकरण से लेकर Playwright जैसे ब्राउज़र ऑटोमेशन और MarkItDown जैसे दस्तावेज़ प्रॉसेसिंग के लिए विशिष्ट टूल्स तक, ये सर्वर दिखाते हैं कि MCP कैसे विभिन्न विकास परिदृश्यों में उत्पादकता बढ़ा सकता है। मानकीकृत प्रोटोकॉल सुनिश्चित करता है कि ये टूल सहजता से एक साथ काम करें, एक सम्मिलित विकास अनुभव बनाएं।

जैसे-जैसे MCP इकोसिस्टम विकसित होता रहेगा, समुदाय के साथ जुड़े रहना, नए सर्वर का अन्वेषण करना, और कस्टम समाधान बनाना आपकी विकास उत्पादकता को अधिकतम करने की कुंजी होगी। MCP के खुले मानक होने का अर्थ है कि आप विभिन्न विक्रेताओं के टूल्स को मिलाकर अपनी विशिष्ट आवश्यकताओं के लिए परफेक्ट वर्कफ़्लो बना सकते हैं।

1. **इंस्टॉल और कॉन्फ़िगर करें**: अपने VS Code वातावरण में किसी एक MCP सर्वर की सेटअप करें और बुनियादी कार्यक्षमता का परीक्षण करें।
2. **वर्कफ़्लो इंटीग्रेशन**: एक विकास कार्यप्रवाह डिज़ाइन करें जो कम से कम तीन अलग-अलग MCP सर्वर को संयोजित करता हो।
3. **कस्टम सर्वर योजना**: अपनी दैनिक विकास दिनचर्या में ऐसी एक क्रिया पहचानें जिसे एक कस्टम MCP सर्वर द्वारा लाभ पहुंचाया जा सके और इसके लिए एक विनिर्देशन बनाएँ।
4. **प्रदर्शन विश्लेषण**: सामान्य विकास कार्यों के लिए MCP सर्वरों के उपयोग की दक्षता की तुलना पारंपरिक तरीकों से करें।
5. **सुरक्षा मूल्यांकन**: अपने विकास वातावरण में MCP सर्वर के उपयोग के सुरक्षा प्रभावों का मूल्यांकन करें और सर्वश्रेष्ठ प्रथाओं का प्रस्ताव करें।
