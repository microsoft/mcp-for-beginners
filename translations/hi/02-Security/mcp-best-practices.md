# MCP सुरक्षा सर्वोत्तम प्रथाएँ - सितंबर 2026 अपडेट

यह व्यापक मार्गदर्शिका मॉडल संदर्भ प्रोटोकॉल (MCP) सिस्टम लागू करने के लिए आवश्यक सुरक्षा सर्वोत्तम प्रथाओं को रेखांकित करती है, जो
**MCP विनिर्देशन 2026-07-28** और वर्तमान उद्योग मानकों पर आधारित है। ये
प्रथाएँ पारंपरिक सुरक्षा चिंताओं और MCP तैनाती के लिए अनन्य AI-विशिष्ट खतरों दोनों को संबोधित करती हैं।



## महत्वपूर्ण सुरक्षा आवश्यकताएँ

### अनिवार्य सुरक्षा नियंत्रण (MUST आवश्यकताएँ)

1. **टोकन सत्यापन**: MCP सर्वर **कभी भी स्वीकार नहीं करेगा** ऐसे टोकन जिन्हें स्पष्ट रूप से MCP सर्वर के लिए जारी नहीं किया गया हो
2. **अधिकार पुष्टि**: MCP सर्वर जो प्राधिकरण लागू करते हैं **सभी** इनबाउंड अनुरोधों को सत्यापित करना **चाहिए** और प्रमाणीकृत के लिए सत्रों का उपयोग **नहीं करना चाहिए**  
3. **उपयोगकर्ता सहमति**: स्थिर तृतीय-पक्ष क्लाइंट आईडी का उपयोग करने वाले MCP प्रॉक्सी सर्वर को प्रत्येक MCP क्लाइंट के लिए स्पष्ट सहमति प्राप्त करनी **चाहिए** इससे पहले कि वे प्राधिकरण प्रवाह अग्रेषित करें
4. **स्टेट हैंडल सुरक्षा**: MCP सर्वर एक एप्लिकेशन स्टेट हैंडल के
	स्वामित्व को प्रमाणीकृत के रूप में नहीं मानना चाहिए और
	हर अनुरोध को प्राधिकृत करना चाहिए जो इसे उपयोग करता है

## मुख्य सुरक्षा प्रथाएँ

### 1. इनपुट सत्यापन और शोधन
- **व्यापक इनपुट सत्यापन**: सभी इनपुट को सत्यापित और शुद्ध करें ताकि इंजेक्शन हमलों, कंफ्यूज्ड डिप्टी समस्याओं, और प्रांप्ट इंजेक्शन कमजोरियों से बचा जा सके
- **पैरामीटर स्कीमा प्रवर्तन**: सभी उपकरण पैरामीटर और API इनपुट के लिए सख्त JSON स्कीमा सत्यापन लागू करें
- **सामग्री फ़िल्टरिंग**: दुर्भावनापूर्ण सामग्री को फ़िल्टर करने के लिए Microsoft प्रांप्ट शील्ड्स और Azure कंटेंट सेफ़्टी का उपयोग करें
- **आउटपुट शोधन**: उपयोगकर्ताओं या नीचे के सिस्टम को प्रस्तुत करने से पहले सभी मॉडल आउटपुट को सत्यापित और शुद्ध करें

### 2. प्रमाणीकरण और प्राधिकरण उत्कृष्टता  
- **बाहरी पहचान प्रदाता**: कस्टम प्रमाणीकरण लागू करने के बजाय स्थापित पहचान प्रदाताओं (Microsoft Entra ID, OAuth 2.1 प्रदाता) को प्रमाणीकरण सौंपें
- **क्लाइंट पंजीकरण**: क्लाइंट आईडी मेटाडेटा दस्तावेज़ या पूर्व-पंजीकरण को प्राथमिकता दें; संगतता के लिए मात्र डिप्रिकेटेड डायनैमिक क्लाइंट पंजीकरण का उपयोग करें
- **सूक्ष्म अनुमति**: न्यूनतम विशेषाधिकार सिद्धांत का पालन करते हुए उपकरण-विशिष्ट सूक्ष्म अनुमतियाँ लागू करें
- **टोकन जीवनचक्र प्रबंधन**: सुरक्षित रोटेशन और सही ऑडियंस सत्यापन के साथ अल्पकालिक एक्सेस टोकन का उपयोग करें
- **मल्टी-कारक प्रमाणीकरण**: सभी प्रशासनिक पहुंच और संवेदनशील संचालन के लिए MFA आवश्यक करें

### 3. सुरक्षित संचार प्रोटोकॉल
- **ट्रांसपोर्ट लेयर सिक्योरिटी**: रिमोट HTTP MCP संचार के लिए उचित प्रमाणपत्र सत्यापन के साथ HTTPS का उपयोग करें
	; स्थानीय stdio सर्वर के लिए प्रक्रिया पृथक्करण और पर्यावरण
	प्रामाणिकता का उपयोग करें
- **एंड-टू-एंड एन्क्रिप्शन**: संवेदनशील डेटा के लिए यात्रा में और संग्रहीत डेटा के लिए अतिरिक्त एन्क्रिप्शन परतें लागू करें
- **प्रमाणपत्र प्रबंधन**: स्वचालित नवीकरण प्रक्रियाओं के साथ उचित प्रमाणपत्र जीवनचक्र प्रबंधन बनाए रखें
- **प्रोटोकॉल संस्करण प्रवर्तन**: MCP `2026-07-28` का प्रयोग करें, हर अनुरोध पर आवश्यक
	संस्करण मेटाडेटा शामिल करें, और असमर्थित संस्करणों को अस्वीकार करें

### 4. उन्नत दर सीमांकन और संसाधन संरक्षण
- **बहु-स्तरीय दर सीमांकन**: दुरुपयोग को रोकने के लिए उपयोगकर्ता, प्रमाणपत्र,
  संचालन, उपकरण, और संसाधन के अनुसार दर सीमांकन लागू करें
- **अनुकूली दर सीमांकन**: उपयोग पैटर्न और खतरा संकेतकों के अनुसार अनुकूल मशीन लर्निंग-आधारित दर सीमांकन का उपयोग करें
- **संसाधन कोटा प्रबंधन**: संगणन संसाधन, मेमोरी उपयोग, और निष्पादन समय के लिए उपयुक्त सीमाएँ निर्धारित करें
- **DDoS संरक्षण**: व्यापक DDoS संरक्षण और ट्रैफ़िक विश्लेषण प्रणाली तैनात करें

### 5. व्यापक लॉगिंग और निगरानी
- **संरचित ऑडिट लॉगिंग**: सभी MCP संचालन, उपकरण निष्पादन, और सुरक्षा घटनाओं के लिए विस्तृत, खोजने योग्य लॉग लागू करें
- **रीयल-टाइम सुरक्षा निगरानी**: MCP कार्यभार के लिए AI-संचालित विसंगति डिटेक्शन के साथ SIEM सिस्टम तैनात करें
- **गोपनीयता-अनुपालन लॉगिंग**: डेटा गोपनीयता आवश्यकताओं और नियमों का सम्मान करते हुए सुरक्षा घटनाओं को लॉग करें
- **घटना प्रतिक्रिया एकीकरण**: लॉगिंग सिस्टम को स्वचालित घटना प्रतिक्रिया वर्कफ़्लो से कनेक्ट करें

### 6. उन्नत सुरक्षित भंडारण प्रथाएँ
- **हार्डवेयर सुरक्षा मॉड्यूल**: महत्वपूर्ण क्रिप्टोग्राफिक संचालन के लिए HSM-समर्थित कुंजी भंडारण (Azure Key Vault, AWS CloudHSM) का उपयोग करें
- **एन्क्रिप्शन कुंजी प्रबंधन**: कुंजी घुमाव, पृथक्करण, और एन्क्रिप्शन कुंजी के लिए पहुँच नियंत्रण लागू करें
- **सीक्रेट्स प्रबंधन**: सभी API कुंजियाँ, टोकन, और प्रमाणपत्र समर्पित गुप्त प्रबंधन प्रणालियों में संग्रहीत करें
- **डेटा वर्गीकरण**: संवेदनशीलता स्तरों के आधार पर डेटा को वर्गीकृत करें और उचित सुरक्षा उपाय लागू करें

### 7. उन्नत टोकन प्रबंधन
- **टोकन पासथ्रू रोकथाम**: स्पष्ट रूप से ऐसे टोकन पासथ्रू पैटर्न को प्रतिबंधित करें जो सुरक्षा नियंत्रणों को बायपास करते हैं
- **ऑडियंस सत्यापन**: हमेशा टोकन ऑडियंस दावों का सत्यापन करें कि वे लक्षित MCP सर्वर पहचान से मेल खाते हैं
- **दावों-आधारित प्राधिकरण**: टोकन दावों और उपयोगकर्ता विशेषताओं के आधार पर सूक्ष्म प्राधिकरण लागू करें
- **टोकन बाइंडिंग**: सत्यापित करें कि टोकन लक्षित MCP संसाधन के लिए हैं और
	एप्लिकेशन स्टेट हैंडल को सर्वर-साइड पर प्रमाणीकृत प्रिंसिपल से बाँधते हैं

### 8. सुरक्षित एप्लिकेशन स्टेट

- **क्रिप्टोग्राफिक स्टेट हैंडल**: अनुरोधों को पार करने वाले स्टेट के लिए अस्पष्ट, गैर-निर्धारित हैंडल उत्पन्न करें

- **उपयोगकर्ता-विशिष्ट बाइंडिंग**: प्रत्येक हैंडल को सर्वर-साइड पर प्रमाणीकृत
	प्रिंसिपल के साथ बाँधें; क्लाइंट द्वारा प्रदान किए गए उपयोगकर्ता आईडी पर भरोसा न करें
- **जीवनचक्र नियंत्रण**: हैंडल को समाप्त करें और रद्द करें, तथा कॉलर्स के लिए परिभाषित करें
	कि वे स्थिर स्टेट से कैसे पुनर्प्राप्त करें
- **प्रति-आवेदन प्राधिकरण**: जब भी एक हैंडल प्रस्तुत किया जाता है तो प्राधिकरण पुनः जाँचें; एक हैंडल नाम है, प्रमाण-पत्र नहीं


### 9. AI-विशिष्ट सुरक्षा नियंत्रण
- **प्रांप्ट इंजेक्शन रक्षा**: Microsoft प्रांप्ट शील्ड्स को स्पॉटलाइटिंग, सीमा निर्धारण, और डेटामार्किंग तकनीकों के साथ लागू करें
- **उपकरण विषाक्तता रोकथाम**: उपकरण मेटाडेटा का सत्यापन करें, गतिशील परिवर्तन देखें, और उपकरण की अखंडता सत्यापित करें
- **मॉडल आउटपुट सत्यापन**: संभावित डेटा रिसाव, हानिकारक सामग्री, या सुरक्षा नीति उल्लंघनों के लिए मॉडल आउटपुट स्कैन करें
- **संदर्भ विंडो संरक्षण**: संदर्भ विंडो जहरीलीकरण और हेरफेर हमलों को रोकने के लिए नियंत्रण लागू करें

### 10. उपकरण निष्पादन सुरक्षा
- **निष्पादन सैंडबॉक्सिंग**: संसाधन सीमाओं के साथ कंटेनरीकृत, पृथक वातावरण में उपकरण निष्पादन चलाएँ
- **विशेषाधिकार पृथक्करण**: न्यूनतम आवश्यक विशेषाधिकारों के साथ उपकरण निष्पादित करें और सेवा खाते अलग रखें
- **नेटवर्क पृथक्करण**: उपकरण निष्पादन वातावरण के लिए नेटवर्क विभाजन लागू करें
- **निष्पादन निगरानी**: उपकरण निष्पादन के लिए विसंगत व्यवहार, संसाधन उपयोग, और सुरक्षा उल्लंघनों की निगरानी करें

### 11. सतत सुरक्षा सत्यापन
- **स्वचालित सुरक्षा परीक्षण**: GitHub Advanced Security जैसे उपकरणों के साथ CI/CD पाइपलाइनों में सुरक्षा परीक्षण एकीकृत करें
- **भेद्यता प्रबंधन**: सभी निर्भरताओं सहित AI मॉडल और बाहरी सेवाओं को नियमित रूप से स्कैन करें
- **पैठ परीक्षण**: विशेष रूप से MCP कार्यान्वयन को लक्षित करते हुए नियमित सुरक्षा मूल्यांकन करें
- **सुरक्षा कोड समीक्षा**: सभी MCP-संबंधित कोड परिवर्तनों के लिए अनिवार्य सुरक्षा समीक्षाएँ लागू करें

### 12. AI के लिए आपूर्ति श्रृंखला सुरक्षा
- **घटक सत्यापन**: सभी AI घटकों (मॉडल, एम्बेडिंग्स, API) की उत्पत्ति, अखंडता, और सुरक्षा सत्यापित करें
- **निर्भरता प्रबंधन**: सभी सॉफ़्टवेयर और AI निर्भरताओं की वर्तमान सूची और भेद्यता ट्रैकिंग बनाए रखें
- **विश्वसनीय रिपॉजिटरी**: सभी AI मॉडलों, लाइब्रेरी, और उपकरणों के लिए सत्यापित, विश्वसनीय स्रोतों का उपयोग करें
- **आपूर्ति श्रृंखला निगरानी**: AI सेवा प्रदाताओं और मॉडल रिपॉजिटरी में समझौते के लिए निरंतर निगरानी करें

## उन्नत सुरक्षा पैटर्न

### MCP के लिए ज़ीरो ट्रस्ट आर्किटेक्चर
- **कभी विश्वास न करें, हमेशा सत्यापित करें**: सभी MCP प्रतिभागियों के लिए निरंतर सत्यापन लागू करें
- **माइक्रो-सेगमेंटेशन**: सूक्ष्म नेटवर्क और पहचान नियंत्रणों के साथ MCP घटकों को अलग करें
- **सशर्त पहुँच**: संदर्भ और व्यवहार के अनुसार अनुकूलित जोखिम-आधारित पहुँच नियंत्रण लागू करें
- **निरंतर जोखिम मूल्यांकन**: वर्तमान खतरा संकेतकों के आधार पर सुरक्षा स्थिति का गतिशील मूल्यांकन करें

### गोपनीयता-संरक्षित AI कार्यान्वयन
- **डेटा न्यूनीकरण**: प्रत्येक MCP ऑपरेशन के लिए केवल न्यूनतम आवश्यक डेटा उजागर करें
- **विभेदक गोपनीयता**: संवेदनशील डेटा प्रोसेसिंग के लिए गोपनीयता-संरक्षण तकनीक लागू करें
- **होमॉमॉर्फिक एन्क्रिप्शन**: एन्क्रिप्टेड डेटा पर सुरक्षित गणना के लिए उन्नत एन्क्रिप्शन तकनीकों का उपयोग करें
- **फ़ेडरेटेड लर्निंग**: डेटा स्थानीयता और गोपनीयता को संरक्षित करते हुए वितरित शिक्षण दृष्टिकोण लागू करें

### AI सिस्टम के लिए घटना प्रतिक्रिया
- **AI-विशिष्ट घटना प्रक्रियाएँ**: AI और MCP-विशिष्ट खतरों के लिए अनुकूलित घटना प्रतिक्रिया प्रक्रियाएँ विकसित करें
- **स्वचालित प्रतिक्रिया**: सामान्य AI सुरक्षा घटनाओं के लिए स्वचालित विच्छेदन और सुधार लागू करें  
- **फोरेंसिक क्षमताएँ**: AI सिस्टम समझौतों और डेटा उल्लंघनों के लिए फोरेंसिक तत्परता बनाए रखें
- **पुनर्प्राप्ति प्रक्रियाएँ**: AI मॉडल विषाक्तता, प्रांप्ट इंजेक्शन हमलों, और सेवा समझौतों से पुनर्प्राप्ति के लिए प्रक्रियाएँ स्थापित करें

### विकसित हो रहे मानकों के साथ अपडेट रहें

- **सुरक्षा अनुसंधान**: MCP सुरक्षा अनुसंधान और कमजोरियों विवरण कार्यक्रमों में योगदान दें
- **सर्वोत्तम प्रथा साझा करना**: सुरक्षा कार्यान्वयन और सीखे गए सबक समुदाय के साथ साझा करें
- **मानक विकास**: MCP विनिर्देश विकास और सुरक्षा मानक निर्माण में भाग लें
- **उपकरण विकास**: MCP पारिस्थितिकी तंत्र के लिए सुरक्षा उपकरण और पुस्तकालय विकसित करें और साझा करें
