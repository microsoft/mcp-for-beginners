# कैलकुलेटर LLM क्लाइंट

> [!NOTE]
> यह समाधान कोर्स की पुराने HTTP+SSE कैलकुलेटर सेवा से जुड़ता है और
> MCP `2025-11-25` SDK API लक्षित करता है। यह `2026-07-28` Streamable HTTP
> उदाहरण नहीं है।

एक जावा एप्लिकेशन जो दिखाता है कि LangChain4j का उपयोग करके MiniMax OpenAI-आधारित API के माध्यम से MCP (मॉडल कंटेक्स्ट प्रोटोकॉल) कैलकुलेटर सेवा से कैसे कनेक्ट किया जाए।

## पूर्वापेक्षाएँ

- जावा 21 या उससे ऊपर
- Maven 3.6+ (या शामिल Maven रैपर का उपयोग करें)
- एक MiniMax API कुंजी
- एक MCP कैलकुलेटर सेवा जो `http://localhost:8080` पर चल रही हो

## API कुंजी प्राप्त करना

यह एप्लिकेशन MiniMax OpenAI-आधारित API का उपयोग करता है। अपनी कुंजी और एंडपॉइंट पाने के लिए ये कदम उठाएं:

### 1. एक एंडपॉइंट चुनें
1. वैश्विक एंडपॉइंट के लिए `https://api.minimax.io/v1` का उपयोग करें
2. चीन एंडपॉइंट के लिए `https://api.minimaxi.com/v1` का उपयोग करें

### 2. API कुंजी बनाएं
1. अपनी MiniMax खाते से एक MiniMax API कुंजी बनाएं
2. कुंजी को कहीं सुरक्षित रखें

### 3. पर्यावरण चर सेट करें

#### विंडोज़ (कमांड प्रॉम्प्ट) पर:
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### विंडोज़ (PowerShell) पर:
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### मैकओएस/लिनक्स पर:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## सेटअप और इंस्टॉलेशन

1. **प्रोजेक्ट डायरेक्टरी क्लोन या नेविगेट करें**

2. **डिपेंडेंसियां इंस्टॉल करें**:
   ```cmd
   mvnw clean install
   ```
   या यदि आपके पास ग्लोबली Maven इंस्टॉल है:
   ```cmd
   mvn clean install
   ```

3. **पर्यावरण चर सेट करें** (ऊपर "API कुंजी प्राप्त करना" अनुभाग देखें)

4. **MCP कैलकुलेटर सेवा शुरू करें**:
   सुनिश्चित करें कि अध्याय 1 की MCP कैलकुलेटर सेवा `http://localhost:8080/sse` पर चल रही है। यह क्लाइंट शुरू करने से पहले चल रही होनी चाहिए।

## एप्लिकेशन चलाना

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## एप्लिकेशन क्या करता है

एप्लिकेशन कैलकुलेटर सेवा के साथ तीन मुख्य इंटरैक्शन दिखाता है:

1. **जोड़**: 24.5 और 17.3 का योग निकालता है
2. **वर्गमूल**: 144 का वर्गमूल निकालता है
3. **सहायता**: उपलब्ध कैलकुलेटर फ़ंक्शंस दिखाता है

## अपेक्षित आउटपुट

जब सफलतापूर्वक चलाएँ तो आपको इस तरह का आउटपुट दिखेगा:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## समस्या निवारण

### सामान्य समस्याएँ

1. **"OPENAI_API_KEY पर्यावरण चर सेट नहीं है"**
   - सुनिश्चित करें कि आपने `OPENAI_API_KEY` पर्यावरण चर सेट किया है
   - चर सेट करने के बाद टर्मिनल/कमांड प्रॉम्प्ट पुनः प्रारंभ करें

2. **"localhost:8080 से कनेक्शन अस्वीकृत"**
   - जाँचें कि MCP कैलकुलेटर सेवा पोर्ट 8080 पर चल रही हो
   - देखे कि कोई अन्य सेवा पोर्ट 8080 उपयोग तो नहीं कर रही

3. **"प्रमाणीकरण विफल"**
   - सुनिश्चित करें आपकी API कुंजी वैध है
   - जांचें कि `OPENAI_BASE_URL` उस एंडपॉइंट से मेल खाता है जिसे आप उपयोग करना चाहते थे

4. **Maven बिल्ड त्रुटियाँ**
   - सुनिश्चित करें कि आप जावा 21 या उससे ऊपर का उपयोग कर रहे हैं: `java -version`
   - बिल्ड साफ़ करने की कोशिश करें: `mvnw clean`

### डिबगिंग

डिबग लॉगिंग सक्षम करने के लिए, रन करते समय निम्न JVM तर्क जोड़ें:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## कॉन्फ़िगरेशन

एप्लिकेशन को इस प्रकार कॉन्फ़िगर किया गया है:
- डिफ़ॉल्ट रूप से MiniMax-M3 का उपयोग करें; `MINIMAX_MODEL_ID` सेट करके `MiniMax-M3` या `MiniMax-M2.7` चुनें
- जब `OPENAI_BASE_URL` सेट हो तो उससे कनेक्ट करें; अन्यथा `MINIMAX_REGION=cn_zh` होने पर `https://api.minimaxi.com/v1` या डिफ़ॉल्ट रूप से `https://api.minimax.io/v1` का उपयोग करें
- MCP सेवा के लिए `http://localhost:8080/sse` से कनेक्ट करें
- अनुरोधों के लिए 60 सेकंड का टाइमआउट सेट करें

## डिपेंडेंसियाँ

इस प्रोजेक्ट में उपयोग की गई मुख्य डिपेंडेंसियाँ:
- **LangChain4j**: AI इंटीग्रेशन और टूल प्रबंधन के लिए
- **LangChain4j MCP**: मॉडल कंटेक्स्ट प्रोटोकॉल समर्थन के लिए
- **LangChain4j OpenAI official**: MiniMax OpenAI सक्षम API इंटीग्रेशन के लिए
- **Spring Boot**: एप्लिकेशन फ्रेमवर्क और डिपेंडेंसी इंजेक्शन के लिए
