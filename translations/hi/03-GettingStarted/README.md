इस अनुभाग में कई पाठ शामिल हैं:

- **1 आपका पहला सर्वर**, इस पहले पाठ में, आप अपने पहले सर्वर को कैसे बनाएँ और इसे निरीक्षण उपकरण के साथ कैसे सत्यापित करें, यह सीखेंगे, जो आपके सर्वर का परीक्षण और डिबग करने का एक मूल्यवान तरीका है, [पाठ पर जाएँ](01-first-server/README.md)

- **2 क्लाइंट**, इस पाठ में, आप यह सीखेंगे कि एक ऐसा क्लाइंट कैसे लिखा जाए जो आपके सर्वर से कनेक्ट हो सके, [पाठ पर जाएँ](02-client/README.md)

- **3 LLM के साथ क्लाइंट**, क्लाइंट लिखने का एक और भी बेहतर तरीका है कि इसमें एक LLM जोड़ें ताकि यह आपके सर्वर के साथ "समझौता" कर सके कि क्या करना है, [पाठ पर जाएँ](03-llm-client/README.md)

- **4 Visual Studio Code में GitHub Copilot एजेंट मोड के साथ सर्वर का उपयोग करना**। यहाँ, हम Visual Studio Code के अंदर से अपने MCP सर्वर को चलाने पर ध्यान दे रहे हैं, [पाठ पर जाएँ](04-vscode/README.md)

- **5 stdio ट्रांसपोर्ट सर्वर** stdio ट्रांसपोर्ट स्थानीय MCP सर्वर-से-क्लाइंट संचार के लिए अनुशंसित मानक है, जो अंतर्निहित प्रक्रिया पृथक्करण के साथ सुरक्षित उप प्रक्रिया आधारित संचार प्रदान करता है [पाठ पर जाएँ](05-stdio-server/README.md)

- **6 MCP के साथ HTTP स्ट्रीमिंग (Streamable HTTP)**। मानक दूरसंचार ट्रांसपोर्ट के बारे में जानें
	[MCP विनिर्देश 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http) में,
	साथ ही पाठ में संरक्षित विरासत आधारित सेशन कार्यान्वयन।
	[पाठ पर जाएँ](06-http-streaming/README.md)

- **7 VSCode के लिए AI टूलकिट उपयोग करना** ताकि आप अपने MCP क्लाइंट और सर्वर का उपभोग और परीक्षण कर सकें [पाठ पर जाएँ](07-aitk/README.md)

- **8 परीक्षण**। यहाँ हम विशेष रूप से देखेंगे कि हम अपने सर्वर और क्लाइंट को विभिन्न तरीकों से कैसे परीक्षण कर सकते हैं, [पाठ पर जाएँ](08-testing/README.md)

- **9 तैनाती**। यह अध्याय आपके MCP समाधानों को तैनात करने के विभिन्न तरीकों को देखेगा, [पाठ पर जाएँ](09-deployment/README.md)

- **10 उन्नत सर्वर उपयोग**। यह अध्याय उन्नत सर्वर उपयोग को कवर करता है, [पाठ पर जाएँ](./10-advanced/README.md)

- **11 प्रमाणीकरण**। यह अध्याय सरल प्रमाणीकरण जोड़ना सिखाता है, बेसिक ऑथ से लेकर JWT और RBAC का उपयोग तक। आपको यहां शुरू करने और फिर अध्याय 5 में उन्नत विषयों को देखने और अध्याय 2 में अनुशंसित अतिरिक्त सुरक्षा कड़े करने के लिए प्रोत्साहित किया जाता है, [पाठ पर जाएँ](./11-simple-auth/README.md)

- **12 MCP होस्ट**। लोकप्रिय MCP होस्ट क्लाइंट जैसे Claude Desktop, Cursor, Cline, और Windsurf को कॉन्फ़िगर और उपयोग करें। ट्रांसपोर्ट प्रकार और समस्या निवारण सीखें, [पाठ पर जाएँ](./12-mcp-hosts/README.md)

- **13 MCP निरीक्षक**। MCP निरीक्षक उपकरण का उपयोग करते हुए अपने MCP सर्वरों को इंटरैक्टिव रूप से डिबग और परीक्षण करें। उपकरण, संसाधन, और प्रोटोकॉल संदेशों को समस्या निवारण करना सीखें, [पाठ पर जाएँ](./13-mcp-inspector/README.md)

- **14 सैम्पलिंग**। `2025-11-25` के लिए विरासत सैम्पलिंग प्रिमिटिव और
	नए डिज़ाइनों को सीधे LLM प्रदाता एकीकरण में कैसे माइग्रेट करें, सीखें। सैम्पलिंग
	MCP `2026-07-28` में अप्रचलित है। [पाठ पर जाएँ](./14-sampling/README.md)

- **15 MCP ऐप्स**। ऐसे MCP सर्वर बनाएं जो UI निर्देशों के साथ भी उत्तर देते हैं, [पाठ पर जाएँ](./15-mcp-apps/README.md)

मॉडल कॉन्टेक्स्ट प्रोटोकॉल (MCP) एक खुला प्रोटोकॉल है जो यह मानकीकृत करता है कि एप्लिकेशन LLMs को संदर्भ कैसे प्रदान करते हैं। MCP को AI एप्लिकेशन के लिए एक USB-C पोर्ट के रूप में सोचें - यह AI मॉडलों को विभिन्न डेटा स्रोतों और टूल्स से जोड़ने का मानकीकृत तरीका प्रदान करता है।

## सीखने के उद्देश्य

इस पाठ के अंत तक, आप सक्षम होंगे:

- C#, Java, Python, TypeScript, और JavaScript में MCP के लिए विकास पर्यावरण सेट अप करें
- कस्टम सुविधाओं (संसाधन, प्रॉम्प्ट, और टूल्स) के साथ मूल MCP सर्वर बनाएं और तैनात करें
- होस्ट एप्लिकेशन बनाएं जो MCP सर्वर से कनेक्ट हो सकें
- MCP कार्यान्वयन का परीक्षण और डिबग करें
- सामान्य सेटअप चुनौतियों और उनके समाधान को समझें
- अपने MCP कार्यान्वयन को लोकप्रिय LLM सेवाओं से कनेक्ट करें

## अपना MCP पर्यावरण सेट करना

MCP के साथ काम शुरू करने से पहले, आपके लिए यह आवश्यक है कि आप अपना विकास पर्यावरण तैयार करें और मूल कार्यप्रवाह को समझें। यह अनुभाग आपको MCP के साथ सुचारू शुरुआत के लिए प्रारंभिक सेटअप चरणों से मार्गदर्शन करेगा।

### आवश्यकताएँ

MCP विकास में कूदने से पहले, सुनिश्चित करें कि आपके पास है:

- **विकास पर्यावरण**: आपकी चुनी हुई भाषा (C#, Java, Python, TypeScript, या JavaScript) के लिए
- **IDE/एडिटर**: Visual Studio, Visual Studio Code, IntelliJ, Eclipse, PyCharm, या कोई आधुनिक कोड एडिटर
- **पैकेज मैनेजर्स**: NuGet, Maven/Gradle, pip, या npm/yarn
- **API कुंजियाँ**: उन किसी भी AI सेवाओं के लिए जो आप अपने होस्ट एप्लिकेशन में उपयोग करने की योजना बनाते हैं


### आधिकारिक SDKs

अगले अध्यायों में आप Python, TypeScript,
Java और .NET का उपयोग करके बने समाधान देखेंगे। यहाँ आधिकारिक SDKs हैं।

MCP `2026-07-28` के लिए SDK समर्थन स्वतंत्र रूप से भाषा द्वारा रोल आउट हो रहा है।
उदाहरण चलाने से पहले, इसके पैकेज संस्करण और SDK के रिलीज नोट्स जांचें
समर्थित प्रोटोकॉल संशोधनों के लिए। देखें
[आधिकारिक SDK सूची](https://modelcontextprotocol.io/docs/sdk):
- [C# SDK](https://github.com/modelcontextprotocol/csharp-sdk) - Microsoft के साथ सहयोग में बनाए रखा गया
- [Java SDK](https://github.com/modelcontextprotocol/java-sdk) - Spring AI के साथ सहयोग में बनाए रखा गया
- [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) - आधिकारिक TypeScript कार्यान्वयन
- [Python SDK](https://github.com/modelcontextprotocol/python-sdk) - आधिकारिक Python कार्यान्वयन (FastMCP)
- [Kotlin SDK](https://github.com/modelcontextprotocol/kotlin-sdk) - आधिकारिक Kotlin कार्यान्वयन
- [Swift SDK](https://github.com/modelcontextprotocol/swift-sdk) - Loopwork AI के साथ सहयोग में बनाए रखा गया
- [Rust SDK](https://github.com/modelcontextprotocol/rust-sdk) - आधिकारिक Rust कार्यान्वयन
- [Go SDK](https://github.com/modelcontextprotocol/go-sdk) - आधिकारिक Go कार्यान्वयन

## मुख्य निष्कर्ष

- भाषा-विशिष्ट SDK के साथ एक MCP विकास पर्यावरण सेट करना आसान है
- MCP सर्वर बनाना, स्पष्ट स्कीमाओं के साथ उपकरण बनाना और पंजीकृत करना शामिल है
- MCP क्लाइंट सर्वर और मॉडल से जुड़े होते हैं ताकि विस्तारित क्षमताओं का लाभ उठाया जा सके
- परीक्षण और डिबगिंग विश्वसनीय MCP कार्यान्वयन के लिए आवश्यक है
- तैनाती विकल्प स्थानीय विकास से क्लाउड आधारित समाधानों तक होते हैं
