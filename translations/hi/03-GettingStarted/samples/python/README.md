# MCP कैलकुलेटर सर्वर (पायथन)



पायथन में एक साधारण मॉडल संदर्भ प्रोटोकॉल (MCP) सर्वर कार्यान्वयन जो बुनियादी कैलकुलेटर कार्यक्षमता प्रदान करता है।


## स्थापना

आवश्यक निर्भरताएँ स्थापित करें:

```bash
pip install -r requirements.txt
```

या MCP पायथन SDK सीधे स्थापित करें:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## उपयोग

### सर्वर चलाना

सर्वर को MCP क्लाइंट्स (जैसे Claude Desktop) द्वारा उपयोग के लिए डिज़ाइन किया गया है। सर्वर शुरू करने के लिए:

```bash
python mcp_calculator_server.py
```

**नोट**: जब इसे सीधे टर्मिनल में चलाया जाता है, तो आप JSON-RPC सत्यापन त्रुटियाँ देखेंगे। यह सामान्य व्यवहार है - सर्वर सही ढंग से फॉर्मेट किए गए MCP क्लाइंट संदेशों की प्रतीक्षा कर रहा है।

### फ़ंक्शन का परीक्षण करना

यह सुनिश्चित करने के लिए कि कैलकुलेटर फ़ंक्शन सही काम करते हैं:

```bash
python test_calculator.py
```

## समस्या निवारण

### आयात त्रुटियाँ

यदि आप `ModuleNotFoundError: No module named 'mcp'` देखते हैं, तो MCP पायथन SDK स्थापित करें:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### सीधे चलाने पर JSON-RPC त्रुटियाँ

"Invalid JSON: EOF while parsing a value" जैसी त्रुटियाँ जब सर्वर सीधे चलाया जाता है, अपेक्षित हैं। सर्वर को MCP क्लाइंट संदेशों की आवश्यकता होती है, सीधे टर्मिनल इनपुट की नहीं।
