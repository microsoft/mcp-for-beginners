# MCP सर्वर तैनात करना

> [!NOTE]
> जो कॉन्फ़िगरेशन उदाहरण `/sse` एंडपॉइंट का उपयोग करते हैं, वे लेगेसी HTTP+SSE ट्रांसपोर्ट को लक्षित करते हैं। MCP `2026-07-28` रिमोट सर्वर सामान्यतः एक सर्वर-निर्धारित एंडपॉइंट जैसे `/mcp` पर स्ट्रीमएबल HTTP का उपयोग करते हैं।
> 
> 

अपने MCP सर्वर को तैनात करने से अन्य लोग आपके स्थानीय वातावरण से बाहर इसके टूल और संसाधनों तक पहुँच सकते हैं। आपकी आवश्यकताओं जैसे स्केलेबिलिटी, विश्वसनीयता, और प्रबंधन की सरलता के आधार पर कई तैनाती रणनीतियाँ हैं जिन पर विचार किया जाना चाहिए। नीचे आपको स्थानीय, कंटेनरों में, और क्लाउड पर MCP सर्वरों को तैनात करने के लिए मार्गदर्शन मिलेगा।

## अवलोकन

यह पाठ यह कवर करता है कि आप अपने MCP Server ऐप को कैसे तैनात कर सकते हैं।

## सीखने के उद्देश्य

इस पाठ के अंत तक, आप सक्षम होंगे कि:

- विभिन्न तैनाती दृष्टिकोणों का मूल्यांकन करें।
- अपने ऐप को तैनात करें।

## स्थानीय विकास और तैनाती

यदि आपका सर्वर उपयोगकर्ता की मशीन में चलाकर उपयोग किया जाना है, तो आप निम्नलिखित चरणों का पालन कर सकते हैं:

1. **सर्वर डाउनलोड करें**। यदि आपने सर्वर नहीं लिखा है, तो इसे सबसे पहले अपनी मशीन पर डाउनलोड करें। 
1. **सर्वर प्रक्रिया शुरू करें**: अपना MCP सर्वर एप्लिकेशन चलाएँ 

SSE के लिए (stdio प्रकार के सर्वर के लिए आवश्यक नहीं)

1. **नेटवर्किंग कॉन्फ़िगर करें**: सुनिश्चित करें कि सर्वर अपेक्षित पोर्ट पर सुलभ है 
1. **क्लाइंट्स से कनेक्ट करें**: स्थानीय कनेक्शन URL जैसे `http://localhost:3000` का उपयोग करें

## क्लाउड तैनाती

MCP सर्वर विभिन्न क्लाउड प्लेटफॉर्म पर तैनात किए जा सकते हैं:

- **सर्वरलेस फ़ंक्शन**: हल्के MCP सर्वर को सर्वरलेस फ़ंक्शन के रूप में तैनात करें
- **कंटेनर सेवाएं**: Azure Container Apps, AWS ECS, या Google Cloud Run जैसी सेवाओं का उपयोग करें
- **कुबेरनेट्स**: उच्च उपलब्धता के लिए MCP सर्वरों को कुबेरनेट्स क्लस्टर्स में तैनात और प्रबंधित करें

### उदाहरण: Azure Container Apps

Azure Container Apps MCP सर्वर की तैनाती का समर्थन करता है। यह अभी प्रगति में है और वर्तमान में SSE सर्वरों का समर्थन करता है।

आप इसे इस प्रकार कर सकते हैं:

1. एक रिपॉजिटरी क्लोन करें:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. इसे स्थानीय रूप से चलाकर परीक्षण करें:

  ```sh
  uv venv
  uv sync

  # लिनक्स/मैकओएस
  export API_KEYS=<AN_API_KEY>
  # विंडोज़
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. इसे स्थानीय रूप से आज़माने के लिए, *.vscode* डायरेक्टरी में *mcp.json* फ़ाइल बनाएं और निम्नलिखित सामग्री जोड़ें:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  एक बार SSE सर्वर चालू हो जाने पर, आप JSON फ़ाइल में प्ले आइकन पर क्लिक कर सकते हैं, अब आपको GitHub Copilot द्वारा सर्वर पर टूल पकड़े जाने दिखाई देंगे, टूल आइकन देखें। 

1. तैनात करने के लिए, निम्न कमांड चलाएं:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

बस, इसे स्थानीय रूप से तैनात करें, इन चरणों के माध्यम से इसे Azure पर तैनात करें।
