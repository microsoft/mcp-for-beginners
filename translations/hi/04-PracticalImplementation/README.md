# व्यावहारिक कार्यान्वयन

[![कैसे वास्तविक टूल्स और वर्कफ़्लोज़ के साथ MCP ऐप्स बनाएं, परीक्षण करें और तैनात करें](../../../translated_images/hi/05.64bea204e25ca891.webp)](https://youtu.be/vCN9-mKBDfQ)

_(इस पाठ का वीडियो देखने के लिए ऊपर दी गई छवि पर क्लिक करें)_

व्यावहारिक कार्यान्वयन वह जगह है जहाँ Model Context Protocol (MCP) की शक्ति अनुभव की जा सकती है। जबकि MCP के पीछे के सिद्धांत और वास्तुकला को समझना महत्वपूर्ण है, वास्तविक मूल्य तब निकलता है जब आप इन अवधारणाओं को वास्तविक दुनिया की समस्याओं को हल करने वाले समाधान बनाने, परीक्षण करने और तैनात करने के लिए लागू करते हैं। यह अध्याय वैचारिक ज्ञान और हाथों-हाथ विकास के बीच पुल का काम करता है, और आपको MCP-आधारित एप्लिकेशन को जीवन में लाने की प्रक्रिया के माध्यम से मार्गदर्शन करता है।

चाहे आप बुद्धिमान सहायक विकसित कर रहे हों, व्यावसायिक वर्कफ़्लोज़ में AI को एकीकृत कर रहे हों, या डेटा प्रसंस्करण के लिए कस्टम उपकरण बना रहे हों, MCP एक लचीला आधार प्रदान करता है। इसकी भाषा-निर्पेक्ष डिज़ाइन और लोकप्रिय प्रोग्रामिंग भाषाओं के लिए आधिकारिक SDK इसे व्यापक डेवलपर्स तक पहुँच योग्य बनाते हैं। इन SDKs का उपयोग करके, आप जल्दी से प्रोटोटाइप बना सकते हैं, पुनरावृत्ति कर सकते हैं, और विभिन्न प्लेटफॉर्म और वातावरण में अपने समाधानों को स्केल कर सकते हैं।

अगले अनुभागों में, आपको व्यावहारिक उदाहरण, नमूना कोड, और तैनाती रणनीतियाँ मिलेंगी जो दर्शाती हैं कि C#, Java with Spring, TypeScript, JavaScript, और Python में MCP को कैसे लागू किया जाए। आप यह भी सीखेंगे कि MCP सर्वरों को कैसे डीबग और परीक्षण करें, API प्रबंधित करें, और Azure का उपयोग करके क्लाउड में समाधान तैनात करें। ये हाथों-हाथ संसाधन आपकी सीखने की गति बढ़ाने और आपको भरोसेमंद, उत्पादन-तैयार MCP एप्लिकेशन बनाने में मदद करने के लिए डिज़ाइन किए गए हैं।

## अवलोकन

यह पाठ कई प्रोग्रामिंग भाषाओं में MCP कार्यान्वयन के व्यावहारिक पहलुओं पर केंद्रित है। हम C#, Java with Spring, TypeScript, JavaScript, और Python में MCP SDKs का उपयोग करके मजबूत एप्लिकेशन कैसे बनाएँ, MCP सर्वर को डीबग और परीक्षण करें, और पुन: उपयोग योग्य संसाधन, प्रॉम्प्ट्स, और टूल्स बनाएं, इसका पता लगाएंगे।

## सीखने के उद्देश्य

इस पाठ के अंत तक, आप सक्षम होंगे:

- विभिन्न प्रोग्रामिंग भाषाओं में आधिकारिक SDKs का उपयोग करके MCP समाधान लागू करें
- व्यवस्थित रूप से MCP सर्वरों का डीबग और परीक्षण करें
- सर्वर सुविधाएँ (संसाधन, प्रॉम्प्ट्स, और टूल्स) बनाएं और उपयोग करें
- जटिल कार्यों के लिए प्रभावी MCP वर्कफ़्लोज़ डिज़ाइन करें
- प्रदर्शन और विश्वसनीयता के लिए MCP कार्यान्वयन का अनुकूलन करें

## कोर सर्वर सुविधाएँ

MCP सर्वर निम्नलिखित सुविधाओं का संयोजन लागू कर सकते हैं:

### संसाधन

संसाधन उपयोगकर्ता या AI मॉडल के लिए संदर्भ और डेटा प्रदान करते हैं:

- दस्तावेज भंडार
- ज्ञान आधार
- संरचित डेटा स्रोत
- फ़ाइल सिस्टम

### प्रॉम्प्ट्स

प्रॉम्प्ट उपयोगकर्ताओं के लिए टेम्प्लेटेड संदेश और वर्कफ़्लोज़ होते हैं:

- पूर्व-निर्धारित बातचीत टेम्प्लेट
- मार्गदर्शित इंटरैक्शन पैटर्न
- विशिष्ट संवाद संरचनाएँ

### टूल्स

टूल AI मॉडल के लिए निष्पादित करने वाले फ़ंक्शंस होते हैं:

- डेटा प्रसंस्करण उपयोगिताएँ
- बाह्य API एकीकरण
- गणनात्मक क्षमताएँ
- खोज कार्यक्षमता

## नमूना कार्यान्वयन: C# कार्यान्वयन

आधिकारिक C# SDK रिपॉजिटरी में कई नमूना कार्यान्वयन शामिल हैं जो MCP के विभिन्न पहलुओं को प्रदर्शित करते हैं:

- **बुनियादी MCP क्लाइंट**: MCP क्लाइंट बनाने और टूल्स को कॉल करने का सरल उदाहरण
- **बुनियादी MCP सर्वर**: टूल पंजीकरण के साथ न्यूनतम सर्वर कार्यान्वयन
- **उन्नत MCP सर्वर**: टूल पंजीकरण, प्रमाणीकरण, और त्रुटि हैंडलिंग सहित पूर्ण फीचर्ड सर्वर
- **ASP.NET एकीकरण**: ASP.NET कोर के साथ एकीकरण दिखाने वाले उदाहरण
- **टूल कार्यान्वयन पैटर्न**: विभिन्न जटिलता स्तरों के साथ टूल कार्यान्वयन के विभिन्न पैटर्न

MCP C# SDK पूर्वावलोकन में है और API बदल सकते हैं। हम SDK के विकास के साथ इस ब्लॉग को लगातार अपडेट करेंगे।

## रिमोट MCP सर्वर को Azure पर तैनात करें

चलिए देखते हैं कि क्या हम पहले बताए गए नमूने को तैनात कर सकते हैं:

1. रिपॉजिटरी क्लोन करें

    ```bash
    git clone https://github.com/Azure-Samples/remote-mcp-apim-functions-python.git
    cd remote-mcp-apim-functions-python
    ```

1. `Microsoft.App` संसाधन प्रदाता पंजीकृत करें।

   - यदि आप Azure CLI का उपयोग कर रहे हैं, तो `az provider register --namespace Microsoft.App --wait` चलाएं।
   - यदि आप Azure PowerShell का उपयोग कर रहे हैं, तो `Register-AzResourceProvider -ProviderNamespace Microsoft.App` चलाएं। फिर कुछ समय बाद यह जांचने के लिए `(Get-AzResourceProvider -ProviderNamespace Microsoft.App).RegistrationState` चलाएं कि पंजीकरण पूरा हुआ या नहीं।

1. इस [azd](https://aka.ms/azd) कमांड को चलाएं ताकि API प्रबंधन सेवा, फंक्शन ऐप (कोड के साथ), और अन्य आवश्यक Azure संसाधनों को प्रावधानित किया जा सके

    ```shell
    azd up
    ```

    इस कमांड से Azure पर सभी क्लाउड संसाधन तैनात हो जाएंगे

### MCP इंस्पेक्टर के साथ अपने सर्वर का परीक्षण करें

1. एक **नई टर्मिनल विंडो** में MCP इंस्पेक्टर इंस्टॉल करें और चलाएं

    ```shell
    npx @modelcontextprotocol/inspector
    ```

    आपको इस प्रकार का इंटरफ़ेस दिखाई देना चाहिए:

    ![Node inspector से कनेक्ट करें](../../../translated_images/hi/connect.141db0b2bd05f096.webp)

1. ऐप द्वारा प्रदर्शित URL (जैसे [http://127.0.0.1:6274/#resources](http://127.0.0.1:6274/#resources)) से MCP इंस्पेक्टर वेब ऐप को लोड करने के लिए CTRL क्लिक करें
1. ट्रांसपोर्ट प्रकार को `SSE` सेट करें
1. URL को अपने चल रहे API प्रबंधन SSE एंडपॉइंट पर सेट करें जो `azd up` के बाद प्रदर्शित होता है, और **Connect** करें:

    ```shell
    https://<apim-servicename-from-azd-output>.azure-api.net/mcp/sse
    ```

1. **List Tools**। किसी टूल पर क्लिक करें और **Run Tool** करें।  

यदि सभी चरण सफलतापूर्वक पूरे हो गए हैं, तो आप अब MCP सर्वर से जुड़ गए हैं और आपने एक टूल कॉल किया है।

## Azure के लिए MCP सर्वर

[Remote-mcp-functions](https://github.com/Azure-Samples/remote-mcp-functions-dotnet): यह रिपॉजिटरी सेट Azure Functions का उपयोग करते हुए Python, C# .NET, या Node/TypeScript के साथ कस्टम रिमोट MCP (Model Context Protocol) सर्वर बनाने और तैनात करने के लिए एक क्विकस्टार्ट टेम्पलेट है।

नमूना एक पूर्ण समाधान प्रदान करता है जो डेवलपर्स को सक्षम बनाता है:

- लोकल पर बनाएं और चलाएं: लोकल मशीन पर MCP सर्वर विकसित और डीबग करें
- Azure पर तैनात करें: सरल azd up कमांड के साथ क्लाउड पर आसानी से तैनात करें
- क्लाइंट्स से कनेक्ट करें: VS Code के Copilot एजेंट मोड और MCP इंस्पेक्टर टूल सहित विभिन्न क्लाइंट्स से MCP सर्वर से कनेक्ट करें

### प्रमुख विशेषताएं

- डिज़ाइन द्वारा सुरक्षा: MCP सर्वर कुंजी और HTTPS का उपयोग करके सुरक्षित है
- प्रमाणीकरण विकल्प: बिल्ट-इन ऑथ और/या API प्रबंधन के साथ OAuth का समर्थन करता है
- नेटवर्क पृथक्करण: Azure वर्चुअल नेटवर्क (VNET) का उपयोग करके नेटवर्क पृथक्करण की अनुमति देता है
- सर्वरलेस आर्किटेक्चर: Azure Functions का उपयोग करते हुए स्केलेबल, इवेंट-चालित निष्पादन
- लोकल विकास: व्यापक स्थानीय विकास और डीबगिंग समर्थन
- सरल तैनाती: Azure के लिए सुव्यवस्थित तैनाती प्रक्रिया

रिपॉजिटरी में सभी आवश्यक विन्यास फ़ाइलें, स्रोत कोड, और अधोसंरचना परिभाषाएँ शामिल हैं ताकि जल्दी से उत्पादन-तैयार MCP सर्वर कार्यान्वयन शुरू किया जा सके।

- [Azure Remote MCP Functions Python](https://github.com/Azure-Samples/remote-mcp-functions-python) - Python के साथ Azure Functions का उपयोग करके MCP का नमूना कार्यान्वयन

- [Azure Remote MCP Functions .NET](https://github.com/Azure-Samples/remote-mcp-functions-dotnet) - C# .NET के साथ Azure Functions का उपयोग करके MCP का नमूना कार्यान्वयन

- [Azure Remote MCP Functions Node/Typescript](https://github.com/Azure-Samples/remote-mcp-functions-typescript) - Node/TypeScript के साथ Azure Functions का उपयोग करके MCP का नमूना कार्यान्वयन।

## प्रमुख निष्कर्ष

- MCP SDKs भाषा-विशिष्ट टूल्स प्रदान करते हैं जो मजबूत MCP समाधान लागू करने के लिए हैं
- डीबगिंग और परीक्षण प्रक्रिया विश्वसनीय MCP एप्लिकेशन के लिए महत्वपूर्ण है
- पुन: उपयोग योग्य प्रॉम्प्ट टेम्प्लेट लगातार AI इंटरैक्शन सक्षम करते हैं
- अच्छी तरह से डिज़ाइन किए गए वर्कफ़्लोज़ कई टूल्स का उपयोग करके जटिल कार्यों को आयोजित कर सकते हैं
- MCP समाधान लागू करते समय सुरक्षा, प्रदर्शन, और त्रुटि हैंडलिंग को ध्यान में रखना आवश्यक है

## अभ्यास

अपने डोमेन की एक वास्तविक समस्या को संबोधित करने वाला व्यावहारिक MCP वर्कफ़्लो डिज़ाइन करें:

1. 3-4 टूल्स की पहचान करें जो इस समस्या के समाधान में उपयोगी होंगे
2. एक वर्कफ़्लो आरेख बनाएं जिसमें दिखाएं कि ये टूल्स कैसे इंटरैक्ट करते हैं
3. अपनी पसंदीदा भाषा का उपयोग करके इनमें से किसी एक टूल का एक बुनियादी संस्करण लागू करें
4. एक प्रॉम्प्ट टेम्प्लेट बनाएं जो मॉडल को आपके टूल का प्रभावी उपयोग करने में मदद करेगा
