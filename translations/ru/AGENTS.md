# AGENTS.md

## Обзор проекта

**MCP для начинающих** — это образовательная открытая учебная программа по изучению Model Context Protocol (MCP) — стандартизированного фреймворка для взаимодействия между моделями ИИ и клиентскими приложениями. Этот репозиторий предоставляет комплексные учебные материалы с практическими примерами кода на нескольких языках программирования.

### Ключевые технологии

- **Языки программирования**: C#, Java, JavaScript, TypeScript, Python, Rust
- **Фреймворки и SDK**:
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **Базы данных**: PostgreSQL с расширением pgvector
- **Облачные платформы**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **Инструменты сборки**: npm, Maven, pip, Cargo
- **Документация**: Markdown с автоматическим мультиязычным переводом (более 48 языков)

### Архитектура

- **11 основных модулей (00-11)**: Поэтапное обучение от основ до продвинутых тем
- **Практические лаборатории**: Практические задания с полным кодом решений на нескольких языках
- **Пример проектов**: Рабочие реализации MCP сервера и клиентов
- **Система перевода**: Автоматизированный рабочий процесс GitHub Actions для поддержки нескольких языков
- **Изображения**: Централизованная директория с изображениями и их переведёнными версиями

#### Кандидат на MCP инструмент: рабочий процесс `validate_curriculum_change`

##### Цель

Проверить состояние изменений документации учебного плана и репрезентативного примерного кода
перед слиянием.

##### Входные данные

- `changed_paths: string[]` (обязательно) — изменённые относительные пути в PR.
- `run_docs_lint: boolean` (по умолчанию `true`)
- `run_links_audit: boolean` (по умолчанию `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (по умолчанию все `false`)

##### Выходные данные

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### Права доступа

- Чтение файлов рабочей области и запись артефактов, сгенерированных инструментом (например, отчёты линтинга,
  логи тестов) — только эти операции; запись в директории `translations/` или
  `translated_images/` запрещена.
- Выполнение локальных shell-команд.
- Опциональный сетевой доступ только для восстановления пакетов (`npm ci`,
  `python -m pip install`, разрешение зависимостей `mvn`).
- Нет прав на push, merge или изменения в `translations/` или
  `translated_images/`.

##### Режимы сбоев

- `E_NO_INPUT_PATHS`: `changed_paths` пуст.
- `E_INVALID_PATH`: путь ввода выходит за пределы корня репозитория.
- `E_LINT_FAILED`: линтер markdown завершился с ненулевым кодом.
- `E_LINK_AUDIT_FAILED`: команда аудита ссылок завершилась с ошибкой.
- `E_SAMPLE_TEST_FAILED`: тест/сборка примера завершилась с ненулевым кодом.
- `E_TIMEOUT`: команда превысила установленное время ожидания.

##### Рекомендуемый контракт CI

Для автоматизации проверки настройте CI-задачу, которая:

- Триггерится на pull request с изменениями в `*.md`, примерах кода или этом файле.
- Выполняет указанные выше команды точно.
- Сохраняет логи как артефакты.
- Завершает задачу с ошибкой при любом ненулевом коде выхода.

### Внесение изменений в документацию

1. Редактируйте только английские markdown файлы в корневых папках модулей (00-11)
2. При необходимости обновите изображения в директории `images/`
3. GitHub Action co-op-translator автоматически создаст переводы
4. Переводы пересоздаются при пуше в основную ветку

### Работа с переводами

- **Автоматический перевод**: рабочий процесс GitHub Actions обрабатывает все переводы
- НЕ редактируйте вручную файлы в директории `translations/`
- Метаданные перевода встроены в каждый переводимый файл
- Поддерживаемые языки: более 48 языков, включая арабский, китайский, французский, немецкий, хинди, японский, корейский, португальский, русский, испанский и многие другие

### Частые проблемы и решения

**В: Мой PR не проходит проверку перевода**
О: Убедитесь, что вы редактировали только английские markdown файлы в корневых папках модулей, а не переведённые версии.

**В: Как добавить новый язык?**
О: Поддержка языков управляется через рабочий процесс co-op-translator. Откройте issue для обсуждения добавления новых языков.

**В: Примеры кода не работают**
О: Убедитесь, что вы следовали инструкциям по установке в README конкретного примера. Проверьте, что установлены правильные версии зависимостей.

**В: Изображения не отображаются**

A: Убедитесь, что пути к изображениям относительные и используют прямые слэши. Изображения должны находиться в каталоге `images/` или `translated_images/` для локализованных версий.
