# AGENTS.md

## Обзор проекта

**MCP для начинающих** — это открытый учебный курс для изучения Model Context Protocol (MCP) — стандартизированного фреймворка для взаимодействия между AI-моделями и клиентскими приложениями. Этот репозиторий предоставляет комплексные обучающие материалы с практическими примерами кода на нескольких языках программирования.

### Ключевые технологии

- **Языки программирования**: C#, Java, JavaScript, TypeScript, Python, Rust
- **Фреймворки и SDK**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **Базы данных**: PostgreSQL с расширением pgvector
- **Облачные платформы**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **Инструменты сборки**: npm, Maven, pip, Cargo
- **Документация**: Markdown с автоматическим многоязычным переводом (48+ языков)

### Архитектура

- **11 основных модулей (00-11)**: Последовательный учебный путь от основ к продвинутым темам
- **Практические лаборатории**: Практические упражнения с полным решением на нескольких языках
- **Примерные проекты**: Рабочие MCP-серверы и клиентские реализации
- **Система перевода**: Автоматизированный рабочий процесс GitHub Actions для поддержки многоязычности
- **Изображения**: Централизованный каталог с переводами изображений

#### Рабочий процесс кандидата в инструменты MCP: `validate_curriculum_change`

##### Цель

Проверить изменения в документации учебного плана и работоспособность представительного образца кода
перед слиянием.

##### Входы

- `changed_paths: string[]` (обязательно) - относительные пути, изменённые в PR.
- `run_docs_lint: boolean` (по умолчанию `true`)
- `run_links_audit: boolean` (по умолчанию `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (по умолчанию все `false`)

##### Выходы

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### Разрешения

- Чтение файлов рабочей области и запись артефактов, созданных инструментом (например, отчётов линтинга,
  журналов тестов) только; записи в `translations/` или
  `translated_images/` запрещены.
- Выполнение локальных shell-команд.
- Опциональный доступ к сети только для восстановления пакетов (`npm ci`,
  `python -m pip install`, разрешение зависимостей `mvn`).
- Нет разрешений на push, merge или изменение `translations/` или
  `translated_images/`.

##### Режимы сбоев

- `E_NO_INPUT_PATHS`: `changed_paths` пуст.
- `E_INVALID_PATH`: входящий путь выходит за пределы корня репозитория.
- `E_LINT_FAILED`: линтер Markdown завершился с ошибкой.
- `E_LINK_AUDIT_FAILED`: команда аудита ссылок завершилась с ошибкой.
- `E_SAMPLE_TEST_FAILED`: тест/сборка образца завершилась с ошибкой.
- `E_TIMEOUT`: команда превысила установленное время ожидания.

##### Рекомендуемый контракт CI

Для автоматизации проверки настройте CI-задачу, которая:

- Запускается на pull request, затрагивающие `*.md`, пример кода или этот файл.
- Выполняет точно перечисленные выше команды.
- Сохраняет логи как артефакты.
- Фиксирует сбой задачи при любом ненулевом коде выхода.

### Частые проблемы и решения

**В: Мой PR не проходит проверку перевода**
О: Убедитесь, что вы редактировали только английские markdown-файлы в корневых папках модулей, а не переведённые версии.

**В: Как добавить новый язык?**
О: Поддержка языков управляется через workflow co-op-translator. Откройте issue для обсуждения добавления новых языков.

**В: Примеры кода не работают**

A: Убедитесь, что вы выполнили инструкции по настройке в README конкретного примера. Проверьте, что у вас установлены правильные версии зависимостей.

**Q: Изображения не отображаются**
A: Проверьте, что пути к изображениям относительные и используют прямые слэши. Изображения должны находиться в каталоге `images/` или `translated_images/` для локализованных версий.

### Вопросы производительности

- Работа перевода может занять несколько минут

- Держите отдельные markdown-файлы сосредоточенными и разумного размера
- Используйте относительные ссылки для лучшей переносимости
