# 🚀 MCP сервер с PostgreSQL — Полное руководство по обучению

## 🧠 Обзор учебного пути по интеграции MCP с базами данных

Это комплексное руководство по обучению научит вас создавать готовые к эксплуатации **серверы Model Context Protocol (MCP)** с интеграцией баз данных через практическую реализацию розничной аналитики. Вы изучите корпоративные шаблоны, включая **Row Level Security (RLS)**, **семантический поиск**, **интеграцию с Azure AI** и **многоарендный доступ к данным**.

Независимо от того, являетесь ли вы backend-разработчиком, AI-инженером или архитектором данных, это руководство предоставляет структурированное обучение с реальными примерами и практическими упражнениями, которые проводят вас через следующий MCP сервер https://github.com/microsoft/MCP-Server-and-PostgreSQL-Sample-Retail.

### 💻 Что вы создадите

К концу этого учебного пути вы создадите полный **MCP сервер Zava Retail Analytics**, включающий:

- **Многотабличную розничную базу данных** с заказами клиентов, товарами и запасами
- **Row Level Security** для изоляции данных по магазинам
- **Семантический поиск продуктов** с использованием Azure OpenAI эмбеддингов
- **Интеграцию AI чата в VS Code** для запросов на естественном языке
- **Готовое к эксплуатации развертывание** с Docker и Azure
- **Всеобъемлющий мониторинг** с помощью Application Insights

## 🎯 Требования для обучения

Чтобы максимально эффективно пройти этот учебный путь, рекомендуется иметь:

- **Знания баз данных**: Базовое понимание SQL и реляционных баз данных
- **Понимание API**: Знание REST API и HTTP концепций
- **Инструменты разработки**: Опыт работы с командной строкой, Git и редакторами кода
- **Основы облака**: (Опционально) Базовые знания Azure или аналогичных облачных платформ
- **Знакомство с Docker**: (Опционально) Понимание концепций контейнеризации

### Необходимые инструменты

- **Docker Desktop** — для запуска PostgreSQL и MCP сервера
- **Azure CLI** — для развертывания облачных ресурсов
- **VS Code** — для разработки и интеграции MCP
- **Git** — для контроля версий
- **Python 3.8+** — для разработки MCP сервера
