# Использование сервера из расширения AI Toolkit для Visual Studio Code

Когда вы создаёте ИИ-агента, дело не только в генерации умных ответов; важно также дать агенту возможность предпринимать действия. Вот где на помощь приходит Протокол Контекста Модели (Model Context Protocol, MCP). MCP упрощает доступ агентов к внешним инструментам и сервисам единообразным способом. Можно представить это как подключение агента к набору инструментов, которыми он действительно может пользоваться.

Допустим, вы подключаете агента к вашему серверу MCP калькулятора. Внезапно ваш агент может выполнять математические операции, просто получая запрос вроде «Сколько будет 47 умножить на 89?» — нет необходимости писать логику вручную или создавать пользовательские API.

## Обзор

В этом уроке мы рассмотрим, как подключить сервер MCP калькулятора к агенту с помощью расширения [AI Toolkit](https://aka.ms/AIToolkit) в Visual Studio Code, что позволит вашему агенту выполнять арифметические операции, такие как сложение, вычитание, умножение и деление, используя естественный язык.

AI Toolkit — это мощное расширение для Visual Studio Code, которое упрощает разработку агентов. Инженеры ИИ могут легко создавать ИИ-приложения, разрабатывая и тестируя генеративные модели ИИ — локально или в облаке. Расширение поддерживает большинство популярных сегодня генеративных моделей.

*Примечание*: в настоящее время AI Toolkit поддерживает Python и TypeScript.

## Цели обучения

К концу этого урока вы сможете:

- Использовать сервер MCP через AI Toolkit.
- Настроить конфигурацию агента для обнаружения и использования инструментов, предоставляемых сервером MCP.
- Взаимодействовать с инструментами MCP с помощью естественного языка.

## Подход

Вот общий порядок действий:

- Создать агента и определить его системный запрос.
- Создать сервер MCP с инструментами калькулятора.
- Подключить конструктор агента к серверу MCP.
- Протестировать вызов инструментов агента с помощью естественного языка.

Отлично, теперь, когда мы понимаем общий процесс, настроим ИИ-агента для использования внешних инструментов через MCP, расширяя его возможности!

### -3- Создание сервера MCP

Теперь, когда вы определили системный запрос агента — который направляет его поведение и ответы — пришло время наделить агента практическими возможностями. В этом разделе вы создадите сервер MCP калькулятора с инструментами для выполнения операций сложения, вычитания, умножения и деления. Этот сервер позволит вашему агенту выполнять математические операции в реальном времени в ответ на запросы на естественном языке.

![Снимок экрана нижней части интерфейса Calculator Agent в расширении AI Toolkit для Visual Studio Code. Видны раскрывающиеся меню «Инструменты» и «Структурированный вывод», а также выпадающее меню с надписью «Выбор формата вывода», установленное в «текст». Справа кнопка под названием «+ MCP Server» для добавления сервера протокола контекста модели. Над секцией Инструменты показан заполнитель с иконкой изображения.](../../../../translated_images/ru/aitk-add-mcp-server.9742cfddfe808353.webp)

AI Toolkit оснащён шаблонами для удобства создания собственного сервера MCP. Мы используем шаблон на Python для создания сервера MCP калькулятора.

*Примечание*: в настоящее время AI Toolkit поддерживает Python и TypeScript.

1. В разделе **Инструменты** **Конструктора агента (Prompt Builder)** нажмите кнопку **+ MCP Server**. Расширение запустит мастер настройки через **Палитру команд**.
1. Выберите **+ Добавить сервер**.
1. Выберите **Создать новый сервер MCP**.
1. Выберите шаблон **python-weather**.
1. Выберите **Папка по умолчанию** для сохранения шаблона сервера MCP.
1. Введите следующее имя для сервера: **Calculator**
1. Откроется новое окно Visual Studio Code. Выберите **Да, я доверяю авторам**.
1. Используя терминал (**Терминал** > **Новый терминал**), создайте виртуальное окружение: `python -m venv .venv`
1. В терминале активируйте виртуальное окружение:
    1. Windows — `.venv\Scripts\activate`
    1. macOS/Linux — `source .venv/bin/activate`
1. В терминале установите зависимости: `pip install -e .[dev]`
1. В представлении **Проводник** на **Панели активности** разверните каталог **src** и откройте файл **server.py** в редакторе.
1. Замените код в файле **server.py** следующем содержимым и сохраните:

    ```python
    """
    Sample MCP Calculator Server implementation in Python.

    
    This module demonstrates how to create a simple MCP server with calculator tools
    that can perform basic arithmetic operations (add, subtract, multiply, divide).
    """
    
    from mcp.server.fastmcp import FastMCP
    
    server = FastMCP("calculator")
    
    @server.tool()
    def add(a: float, b: float) -> float:
        """Add two numbers together and return the result."""
        return a + b
    
    @server.tool()
    def subtract(a: float, b: float) -> float:
        """Subtract b from a and return the result."""
        return a - b
    
    @server.tool()
    def multiply(a: float, b: float) -> float:
        """Multiply two numbers together and return the result."""
        return a * b
    
    @server.tool()
    def divide(a: float, b: float) -> float:
        """
        Divide a by b and return the result.
        
        Raises:
            ValueError: If b is zero
        """
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    ```

### -4- Запуск агента с сервером MCP калькулятора

Теперь, когда у вашего агента есть инструменты, пора их использовать! В этом разделе вы будете отправлять запросы агенту, чтобы проверить и убедиться, что агент использует соответствующие инструменты сервера MCP калькулятора.

![Снимок экрана интерфейса Calculator Agent в расширении AI Toolkit для Visual Studio Code. На левой панели, в разделе «Инструменты», добавлен сервер MCP под названием local-server-calculator_server, отображаются четыре доступных инструмента: сложение, вычитание, умножение и деление. Значок показывает, что четыре инструмента активны. Ниже свернута секция «Структурированный вывод», а снизу синяя кнопка «Запустить». На правой панели, в разделе «Ответ модели», агент вызывает инструменты умножения и вычитания с входными данными {"a": 3, "b": 25} и {"a": 75, "b": 20} соответственно. Итоговый ответ инструмента показан как 75,0. Внизу появилась кнопка «Посмотреть код».](../../../../translated_images/ru/aitk-agent-response-with-tools.e7c781869dc8041a.webp)

Вы будете запускать сервер MCP калькулятора на вашем локальном компьютере разработчика через **Конструктор агента** в качестве клиента MCP.

1. Нажмите `F5`, чтобы начать отладку сервера MCP. **Конструктор агента (Prompt Builder)** откроется в новой вкладке редактора. Статус сервера будет отображаться в терминале.
1. В поле **Пользовательский запрос** **Конструктора агента (Prompt Builder)** введите следующий запрос: `Я купил 3 товара по цене 25 долларов каждый, а затем применил скидку в 20 долларов. Сколько я заплатил?`
1. Нажмите кнопку **Запустить** для генерации ответа агента.
1. Проверьте вывод агента. Модель должна сделать вывод, что вы заплатили **55 долларов**.
1. Вот что должно произойти:
    - Агент выберет инструменты **умножение** и **вычитание** для помощи в вычислении.
    - Для инструмента **умножение** будут заданы соответствующие значения `a` и `b`.
    - Для инструмента **вычитание** будут заданы соответствующие значения `a` и `b`.
    - Ответ от каждого инструмента будет предоставлен в соответствующем поле **Ответ инструмента**.
    - Итоговый вывод модели будет показан в поле **Ответ модели**.
1. Отправляйте дополнительные запросы для дальнейшего тестирования агента. Вы можете изменить существующий запрос в поле **Пользовательский запрос**, кликнув в поле и заменив текст.
1. По окончании тестирования агента вы можете остановить сервер, введя в терминале **CTRL/CMD+C** для выхода.

## Задание
