# Клиент калькулятора LLM

Java-приложение, демонстрирующее, как использовать LangChain4j для подключения к сервису калькулятора MCP (Model Context Protocol) через API, совместимый с MiniMax OpenAI.

## Необходимые условия

- Java 21 или выше
- Maven 3.6+ (или используйте включённый Maven wrapper)
- Ключ API MiniMax
- Сервис калькулятора MCP, работающий по адресу `http://localhost:8080`

## Получение ключа API

Это приложение использует совместимый с OpenAI API MiniMax. Выполните следующие шаги, чтобы получить ключ и конечную точку:

### 1. Выберите конечную точку
1. Используйте `https://api.minimax.io/v1` для глобальной конечной точки
2. Используйте `https://api.minimaxi.com/v1` для конечной точки в Китае

### 2. Создайте ключ API
1. Создайте ключ API MiniMax в своем аккаунте MiniMax
2. Храните ключ в надежном месте

### 3. Установите переменные окружения

#### В Windows (Командная строка):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### В Windows (PowerShell):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### В macOS/Linux:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## Настройка и установка

1. **Клонируйте репозиторий или перейдите в каталог проекта**

2. **Установите зависимости**:
   ```cmd
   mvnw clean install
   ```
   Или если Maven установлен глобально:
   ```cmd
   mvn clean install
   ```

3. **Настройте переменные окружения** (см. раздел "Получение ключа API" выше)

4. **Запустите сервис калькулятора MCP**:
   Убедитесь, что сервис калькулятора MCP из главы 1 работает по адресу `http://localhost:8080/sse`. Он должен быть запущен перед запуском клиента.

## Запуск приложения

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## Что делает приложение

Приложение демонстрирует три основных взаимодействия с сервисом калькулятора:

1. **Сложение**: вычисляет сумму 24.5 и 17.3
2. **Квадратный корень**: вычисляет квадратный корень из 144
3. **Помощь**: отображает доступные функции калькулятора

## Ожидаемый результат

При успешном запуске вы должны увидеть результат, похожий на:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## Устранение неполадок

### Распространённые проблемы

1. **Переменная окружения OPENAI_API_KEY не установлена**
   - Убедитесь, что переменная окружения `OPENAI_API_KEY` установлена
   - Перезапустите терминал или командную строку после установки переменной

2. **"Connection refused to localhost:8080"**
   - Убедитесь, что сервис калькулятора MCP запущен на порту 8080
   - Проверьте, не занят ли порт 8080 другим сервисом

3. **"Authentication failed"**
   - Проверьте корректность вашего ключа API
   - Убедитесь, что `OPENAI_BASE_URL` совпадает с вашей выбранной конечной точкой

4. **Ошибки сборки Maven**
   - Убедитесь, что используете Java 21 или выше: `java -version`
   - Попробуйте очистить сборку: `mvnw clean`

### Отладка

Чтобы включить логирование отладки, добавьте следующий аргумент JVM при запуске:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## Конфигурация

Приложение настроено следующим образом:
- По умолчанию используется MiniMax-M3; установите `MINIMAX_MODEL_ID` для выбора `MiniMax-M3` или `MiniMax-M2.7`
- Подключается к `OPENAI_BASE_URL`, если он задан; иначе использует `https://api.minimaxi.com/v1` при `MINIMAX_REGION=cn_zh` или по умолчанию — `https://api.minimax.io/v1`
- Подключается к сервису MCP по адресу `http://localhost:8080/sse`
- Использует таймаут 60 секунд для запросов

## Зависимости

Основные зависимости в этом проекте:
- **LangChain4j**: Для интеграции с ИИ и управления инструментами
- **LangChain4j MCP**: Для поддержки протокола Model Context
- **LangChain4j OpenAI official**: Для интеграции с MiniMax OpenAI-совместимым API
- **Spring Boot**: Для фреймворка приложения и внедрения зависимостей
