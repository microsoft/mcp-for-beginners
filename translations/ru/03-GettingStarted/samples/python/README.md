# MCP Calculator Server (Python)



Простая реализация сервера Model Context Protocol (MCP) на Python, обеспечивающая базовую функциональность калькулятора.


## Установка

Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

Или установите MCP Python SDK напрямую:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## Использование

### Запуск сервера

Сервер предназначен для использования клиентами MCP (например, Claude Desktop). Чтобы запустить сервер:

```bash
python mcp_calculator_server.py
```

**Примечание**: При запуске напрямую в терминале вы увидите ошибки валидации JSON-RPC. Это нормальное поведение — сервер ожидает сообщения от корректно сформатированных клиентов MCP.

### Тестирование функций

Чтобы проверить правильную работу функций калькулятора:

```bash
python test_calculator.py
```

## Устранение неполадок

### Ошибки импорта

Если вы видите `ModuleNotFoundError: No module named 'mcp'`, установите MCP Python SDK:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### Ошибки JSON-RPC при запуске напрямую

Ошибки типа "Invalid JSON: EOF while parsing a value" при запуске сервера напрямую ожидаемы. Серверу нужны сообщения клиентов MCP, а не прямой ввод в терминал.
