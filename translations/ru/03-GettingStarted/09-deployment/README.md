# Развертывание серверов MCP

> [!NOTE]
> Примеры конфигураций, использующие конечную точку `/sse`, нацелены на устаревший HTTP+SSE транспорт. Удалённые серверы MCP версии `2026-07-28` используют Streamable HTTP, обычно на определённой сервером конечной точке, такой как `/mcp`.
> 
> 

Развертывание вашего MCP сервера позволяет другим получить доступ к его инструментам и ресурсам за пределами вашей локальной среды. Существует несколько стратегий развертывания, которые стоит рассмотреть в зависимости от ваших требований к масштабируемости, надежности и простоте управления. Ниже вы найдете рекомендации по развертыванию серверов MCP локально, в контейнерах и в облаке.

## Локальная разработка и развертывание

Если ваш сервер предназначен для использования на машине пользователя, вы можете выполнить следующие шаги:

1. **Скачать сервер**. Если вы не писали сервер, сначала скачайте его на вашу машину.
1. **Запустить процесс сервера**: Запустите ваше приложение MCP сервера

Для SSE (не требуется для сервера типа stdio)

1. **Настроить сеть**: Убедитесь, что сервер доступен на ожидаемом порту
1. **Подключить клиентов**: Используйте локальные URL-адреса подключения, такие как `http://localhost:3000`

## Облачное развертывание

Серверы MCP можно развертывать на различных облачных платформах:

- **Безсерверные функции**: Разворачивайте легкие MCP серверы как безсерверные функции
- **Контейнерные сервисы**: Используйте сервисы, такие как Azure Container Apps, AWS ECS или Google Cloud Run
- **Kubernetes**: Разворачивайте и управляйте MCP серверами в кластерах Kubernetes для высокой доступности

### Пример: Azure Container Apps

Azure Container Apps поддерживают развертывание MCP серверов. Это ещё в работе, и пока поддерживаются SSE серверы.

Вот как вы можете это сделать:

1. Клонируйте репозиторий:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. Запустите локально, чтобы проверить:

  ```sh
  uv venv
  uv sync

  # linux/macOS
  export API_KEYS=<AN_API_KEY>
  # windows
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. Чтобы попробовать локально, создайте файл *mcp.json* в директории *.vscode* и добавьте следующее содержимое:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  Как только SSE сервер запущен, вы можете нажать на иконку воспроизведения в JSON файле, теперь вы должны увидеть, что инструменты на сервере подхвачены GitHub Copilot, посмотрите на иконку Инструментов.

1. Для развертывания выполните следующую команду:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

Вот и всё, разверните локально или на Azure, выполнив эти шаги.
