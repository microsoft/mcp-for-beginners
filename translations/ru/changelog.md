### Усиление безопасности и устранение уязвимостей зависимостей

Проведён комплексный аудит безопасности всех манифестов зависимостей и исходного кода примеров, затем устранены все выявленные npm предупреждения и одна проблема на уровне кода. После исправлений `npm audit` сообщает об **отсутствии уязвимостей** во всех проверенных каталогах.

#### Уязвимости зависимостей npm (транзитивные) — исправлены

Проаудированы все 15 закоммиченных файлов `package-lock.json`. Уязвимости были только в транзитивных зависимостях, приносившихся инструментом MCP Inspector для разработчиков, клиентом OpenAI и SDK MCP; они все теперь устранены без разрушения примеров:
- **10-StreamliningAIWorkflows.../lab4/code/github_mcp_server/inspector** и **lab3/code/weather_mcp/inspector**: обновлён `@modelcontextprotocol/inspector` с версии `0.16.6` / `0.14.1` до `0.22.0`, что устранило предупреждения, связанные с `ajv`, `brace-expansion`, `diff`, `path-to-regexp` и `ws`. Добавлен npm `overrides` для форсирования патч-версии `shell-quote@1.8.4` для устранения критического предупреждения, вызванного `concurrently`; оба lock-файла регенерированы (теперь 0 уязвимостей)
- **03-GettingStarted/samples/typescript**: команда `npm audit fix` обновила транзитивную зависимость `qs` (средняя серьёзность) до патч-версии
- **03-GettingStarted/samples/javascript**: `npm audit fix` обновила транзитивный `hono` (средняя серьёзность) до патч-версии
- **03-GettingStarted/03-llm-client/solution/typescript**: `npm audit fix` обновила транзитивный `form-data` (высокая серьёзность) до патч-версии
- **03-GettingStarted/11-simple-auth/solution/typescript**: сгенерирован отсутствующий `package-lock.json` для обеспечения воспроизводимости и аудита (0 уязвимостей)

#### Исправление уровня кода безопасности (OWASP A03: Injection)

- **10-StreamliningAIWorkflows.../lab4/code/github_mcp_server/src/server.py**: удалён параметр `shell=True` из инструмента `open_in_vscode`. Предыдущий вызов `subprocess.run(["start", "", vscode_path, folder_path], shell=True)` позволял мета-символам оболочки в пути к папке интерпретироваться `cmd.exe` (вектор командной инъекции). Теперь запускается напрямую разрешённый `Code.exe` с папкой в качестве аргумента — без оболочки — что функционально эквивалентно и безопасно.

#### Аудит зависимостей Python

- Проведен аудит всех наборов зависимостей Python с помощью `pip-audit`. Модули `05-AdvancedTopics` и `03-GettingStarted/samples/python` сообщили об **отсутствии известных уязвимостей** (их диапазоны `mcp` / `httpx` / `pydantic` / `python-dotenv` разрешаются в текущие патч-релизы)
- **09-CaseStudy/docs-mcp/solution/python/requirements.txt**: `pip-audit` выявил транзитивную зависимость **`werkzeug` 3.1.1** с тремя предупреждениями о DoS в Windows из-за `safe_join` — `CVE-2025-66221`, `CVE-2026-21860` и `CVE-2026-27199` (все исправлены в 3.1.6). Добавлена явная фиксация безопасности `werkzeug>=3.1.6`, чтобы разрешилась патч-версия; проверена чистая резолюция ограничения с использованием стека `chainlit` / `mcp` / `semantic-kernel`.
