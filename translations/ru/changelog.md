# Журнал изменений: Учебная программа MCP для начинающих

Этот документ служит записью всех значительных изменений, внесённых в учебную программу Model Context Protocol (MCP) для начинающих. Изменения документируются в обратном хронологическом порядке (сначала новые изменения).

## 29 июля 2026 года

### Новый модуль 08 Сопроводительный материал: надёжные сайдкары и безопасные повторные попытки

Добавлен вендорно-нейтральный сопроводительный урок для инструментов MCP, создающих реальные
эффекты, согласованный с окончательной спецификацией `2026-07-28`.

- **Новый**: [сопроводительный урок по надёжным сайдкарам][reliability-sidecar]
  использует одну историю со службой поддержки, две диаграммы Mermaid и поток принятия решений о повторных попытках,
  чтобы разъяснить ключи стабильной работы, атомарное дублирование допуска,
  согласование, доказательства и границу расширения Задач.
- **Новый**: Упражнение по внедрению сбоев с использованием стандартной библиотеки Python и SQLite
  использует отдельные хранилища операций и тикетов для демонстрации утери ответа
  после фиксации внешнего эффекта. Шесть детерминированных тестов покрывают наивное
  дублирование, восстановление при перезапуске с защитой, конфликты полезной нагрузки, кешированные результаты,
  активные требования и параллельный допуск дубликатов.
- **Обновлено**: Модуль 08 теперь ссылается на сопроводительный урок, идентифицирует
  окончательную модель бесcессионного запроса `2026-07-28`, различает наблюдаемость OpenTelemetry
  и устаревшую функцию ведения журналов MCP, а также ограничивает
  общий пример повторной попытки операциями только для чтения.
- **Опционально**: Урок сопоставляет свои переносимые концепции с одной отмеченной реализации сообщества,
  не делая размещённый сервис или сетевой вызов частью
  упражнения.

[reliability-sidecar]: ./08-BestPractices/reliability-sidecars/README.md
