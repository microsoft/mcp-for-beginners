# 🚀 初學者的模型上下文協議 (MCP) 課程

## **用 C#、Java、JavaScript、Rust、Python 和 TypeScript 的實作範例學習 MCP**

## 🧠 模型上下文協議課程概覽
歡迎展開模型上下文協議的學習之旅！如果你曾好奇 AI 應用程序如何與不同的工具和服務溝通，你即將發現改變開發者建立智能系統方式的優雅解決方案。

將 MCP 想像成 AI 應用的通用翻譯器——就像 USB 埠讓你能連接任何裝置到電腦，MCP 讓 AI 模型以標準化方式連接任何工具或服務。無論你是在建立第一個聊天機械人或處理複雜的 AI 工作流程，了解 MCP 都能給你建立更強大且靈活應用程序的能力。

這個課程以耐心和關懷設計，陪伴你的學習旅程。我們將從你已熟悉的簡單概念開始，並透過實作練習逐步建立你的專業知識，每一步都包含清楚的說明、實用範例，以及滿滿的鼓勵。

完成此課程後，你將充滿信心地建構自己的 MCP 伺服器，整合流行的 AI 平台，並理解這項技術如何重塑 AI 開發的未來。讓我們一起展開這激動人心的冒險吧！

### 官方文件與規範

本課程與 **MCP 規格 2025-11-25**（最新穩定版本）保持一致。MCP 規格使用基於日期的版本號（YYYY-MM-DD 格式），以確保協議版本的明確追蹤。

> **展望未來：** 下一個規格版本 **2026-07-28** 的釋出候選版預計於 2026 年 7 月 28 日推出。該版本使協議在傳輸層無狀態化，正式化擴展框架（MCP 應用、任務）、加強授權安全，並廢止 Roots、Sampling 及 Logging。詳情請參閱 [MCP 2026-07-28 發布候選版變更內容](./01-CoreConcepts/mcp-2026-07-28-release-candidate.md)。

這些資源隨著你的理解提升會越來越寶貴，但不用急著全部閱讀，先從你最感興趣的部分開始吧！
- 📘 [MCP 文件](https://modelcontextprotocol.io/) – 這是你一步步學習的指南和用戶手冊。文件以初學者為對象，提供清晰範例，讓你能跟著練習。
- 📜 [MCP 規格](https://modelcontextprotocol.io/specification/2025-11-25) – 把它當作你的全方位參考手冊。隨課程進度，你會常回來查閱細節與探索進階功能。
- 📜 [MCP 規格版本控制](https://modelcontextprotocol.io/specification/versioning) – 介紹協議的版本歷史及 MCP 如何使用基於日期的版本號（YYYY-MM-DD 格式）。
- 🧑‍💻 [MCP GitHub 倉庫](https://github.com/modelcontextprotocol) – 這裡有多種程式語言的 SDK、工具與程式碼範例，猶如實用範例與即用元件的寶庫。
- 🌐 [MCP 社群](https://github.com/orgs/modelcontextprotocol/discussions) – 加入學習者與經驗豐富的開發者討論 MCP，這是一個支持性的社群，歡迎提問並自由分享知識。
  
## 學習目標

完成本課程後，你會對你的新技能感到自信與興奮。以下是你將達成的目標：

• **理解 MCP 基礎**：你將掌握模型上下文協議是什麼，及它如何革新 AI 應用的協同運作，透過類比和範例讓你輕鬆理解。

• **建構你的第一個 MCP 伺服器**：你將使用你偏好的程式語言，從簡單範例開始，一步步提升技能，完成一個可運作的 MCP 伺服器。

• **連接 AI 模型與實際工具**：你將學會如何橋接 AI 模型與真實服務，賦予你的應用強大新功能。

• <strong>實施最佳安全實務</strong>：你將了解如何保持 MCP 實作安全，保護你的應用與使用者。

• <strong>自信部署</strong>：你將學會如何將 MCP 專案從開發帶入生產環境，並掌握實務部署策略。

• **加入 MCP 社群**：你將成為日益壯大的開發社群一份子，共同塑造 AI 應用開發的未來。

## 基礎背景知識

在深入 MCP 具體內容前，先確保你對一些基礎概念感到自在。如果你對這些領域不是專家也不用擔心——我們會逐步解說你需要知道的所有內容！

### 理解協議（基礎）

可以把協議想像成對話的規則。當你打電話給朋友，雙方都知道接聽時要說「哈囉」、輪流說話，以及結束時說「再見」。電腦程式同樣需要類似的規則來有效通訊。

MCP 是一種協議——一套約定的規則，幫助 AI 模型與工具及服務間進行有效「對話」。就像會話規則讓人際交流更流暢，MCP 讓 AI 應用的通訊更加可靠強大。

### 客戶端與伺服器關係（程式如何協同工作）

你每天都在使用客戶端與伺服器關係！例如你用網頁瀏覽器（客戶端）訪問網站，連接到提供頁面內容的網頁伺服器。瀏覽器知道如何請求資訊，伺服器知道如何回應。

在 MCP 中，我們有類似的關係：AI 模型擔任請求資訊或操作的客戶端，MCP 伺服器提供這些能力。就像 AI 有一位會幫忙執行特定任務的助手（伺服器）。

### 為何標準化很重要（讓事物協同運作）

想像如果每家車廠用不同形狀的油槍——你要每台車都準備不同轉接頭！標準化就是大家同意共用方案，讓事物無縫協同。

MCP 為 AI 應用提供這種標準化。不是每個 AI 模型都需要編寫客製代碼與每種工具對接，MCP 建立通用溝通方式。這讓開發者能一次打造工具，並讓它兼容多種 AI 系統。

## 🧭 你的學習路徑概覽

你的 MCP 旅程經過精心設計，逐步建立信心與技能。每階段引入新概念，同時鞏固已學知識。

### 🌱 基礎階段：理解基本概念（模組 0-2）

冒險由此開始！我們將用熟悉的類比和簡單範例介紹 MCP 概念。你會了解 MCP 是什麼、存在的意義，以及它在更大 AI 開發世界的角色。


• **模組 0 - MCP 簡介**: 我們將從探索 MCP 是什麼以及它為何對現代 AI 應用如此重要開始。你將看到 MCP 在實際中的範例，並了解它如何解決開發人員面臨的常見問題。

• **模組 1 - 核心概念解析**: 在這裡你會學習 MCP 的基本構建區塊。我們將使用大量類比和視覺範例，確保這些概念感覺自然且易於理解。

• **模組 2 - MCP 的安全性**: 安全性聽起來可能令人畏懼，但我們會向你展示 MCP 如何內建安全功能，並教你從一開始就保護應用程式的最佳做法。

### 🔨 建置階段：創建你的第一個實作（模組 3）

現在真正的樂趣開始了！你將獲得實作 MCP 伺服器和客戶端的實際操作經驗。別擔心 - 我們會從簡單開始，並引導你完成每個步驟。

本模組包含多個實作指南，讓你以偏好的程式語言練習。你將創建你的第一個伺服器，建構一個用於連接的客戶端，甚至整合熱門開發工具如 VS Code。

每個指南皆包含完整的程式碼範例、故障排除提示，以及我們選擇特定設計的原因說明。此階段結束時，你將擁有可自豪運作的 MCP 實作！

### 🚀 成長階段：進階概念與實務應用（模組 4-5）

掌握基礎後，你已經準備好探索更精妙的 MCP 功能。我們將涵蓋實務實作策略、除錯技術，以及多模態 AI 整合等進階主題。

你還將學習如何擴展 MCP 實作以供生產使用，並與如 Azure 等雲端平台整合。這些模組讓你準備好打造能夠應對現實需求的 MCP 解決方案。

### 🌟 精通階段：社群與專精（模組 6-11）

最後階段聚焦於加入 MCP 社群並專精於你最感興趣的領域。你將學習如何為開源 MCP 項目做出貢獻、實作進階身份驗證模式，以及打造完整的資料庫整合解決方案。

模組 11 值得特別一提 - 它是完整的 13 個實作實驗室學習路徑，教授你搭建帶有 PostgreSQL 整合的生產準備 MCP 伺服器。這就像一個總結專案，將你所學全部整合起來！
