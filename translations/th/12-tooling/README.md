# 🚀 เครื่องมือ MCP

## 🧠 ภาพรวมของเส้นทางการเรียนรู้การผสานฐานข้อมูล MCP

ที่นี่คุณจะได้เรียนรู้วิธีใช้เครื่องมือที่ใช้ MCP ประสบการณ์ของคุณในการใช้เครื่องมือเหล่านี้จะดีขึ้นเมื่อคุณเชื่อมต่อเซิร์ฟเวอร์ MCP กับเครื่องมือเหล่านั้น

## 🔗 แหล่งข้อมูลอย่างเป็นทางการของ MCP

- 📘 [เอกสาร MCP](https://modelcontextprotocol.io/) – บทเรียนและคู่มือผู้ใช้อย่างละเอียด
- 📜 [ข้อกำหนด MCP (2026-07-28)](https://modelcontextprotocol.io/specification/2026-07-28/) – สถาปัตยกรรมโปรโตคอลและเอกสารอ้างอิงทางเทคนิค
- 🧑‍💻 [ที่เก็บ GitHub ของ MCP](https://github.com/modelcontextprotocol) – SDKs โอเพ่นซอร์ส เครื่องมือ และตัวอย่างโค้ด
- 🌐 [ชุมชน MCP](https://github.com/orgs/modelcontextprotocol/discussions) – เข้าร่วมการอภิปรายและมีส่วนร่วมในชุมชน
- 🔒 [OWASP MCP Top 10](https://microsoft.github.io/mcp-azure-security-guide/mcp/) – แนวทางปฏิบัติที่ดีที่สุดด้านความปลอดภัยและการลดความเสี่ยง
