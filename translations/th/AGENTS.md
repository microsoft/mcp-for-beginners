# AGENTS.md

## ภาพรวมโครงการ

**MCP สำหรับผู้เริ่มต้น** คือหลักสูตรการศึกษาระบบเปิดสำหรับการเรียนรู้ Model Context Protocol (MCP) - กรอบงานมาตรฐานสำหรับการโต้ตอบระหว่างโมเดล AI กับแอปพลิเคชันลูกค้า รีโพสิทอรีนี้ให้วัสดุการเรียนรู้ครบถ้วนพร้อมตัวอย่างโค้ดที่ลงมือทำได้ในหลายภาษาโปรแกรม

### เทคโนโลยีสำคัญ

- **ภาษาโปรแกรม**: C#, Java, JavaScript, TypeScript, Python, Rust
- **เฟรมเวิร์ก & SDK**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **ฐานข้อมูล**: PostgreSQL พร้อมส่วนขยาย pgvector
- **แพลตฟอร์มคลาวด์**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **เครื่องมือบิลด์**: npm, Maven, pip, Cargo
- **เอกสาร**: Markdown พร้อมการแปลภาษาอัตโนมัติหลายภาษา (มากกว่า 48 ภาษา)

### สถาปัตยกรรม

- **โมดูลหลัก 11 โมดูล (00-11)**: เส้นทางการเรียนรู้ลำดับขั้นจากพื้นฐานไปยังหัวข้อขั้นสูง
- **ห้องปฏิบัติการลงมือทำ**: แบบฝึกหัดปฏิบัติกับโค้ดตัวอย่างครบถ้วนในหลายภาษา
- **โครงการตัวอย่าง**: การใช้งาน MCP เซิร์ฟเวอร์และไคลเอนต์ที่ทำงานได้
- **ระบบแปลภาษา**: ระบบทำงานอัตโนมัติผ่าน GitHub Actions สำหรับรองรับหลายภาษา
- **แหล่งภาพ**: ไดเรกทอรีภาพศูนย์กลางพร้อมเวอร์ชันแปลแล้ว

## คำสั่งตั้งค่า

รีโพสิทอรีนี้เน้นเอกสารหลักเป็นหลัก การติดตั้งส่วนใหญ่เกิดขึ้นภายในโครงการตัวอย่างและห้องปฏิบัติการแต่ละชุด

### การตั้งค่ารีโพสิทอรี

```bash
# โคลนที่เก็บข้อมูล
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### การทำงานกับโครงการตัวอย่าง

โครงการตัวอย่างตั้งอยู่ใน:
- `03-GettingStarted/samples/` - ตัวอย่างเฉพาะภาษา
- `03-GettingStarted/01-first-server/solution/` - การใช้งานเซิร์ฟเวอร์แรก
- `03-GettingStarted/02-client/solution/` - การใช้งานไคลเอนต์
- `11-MCPServerHandsOnLabs/` - ห้องปฏิบัติการผสานฐานข้อมูลครบถ้วน

ในแต่ละโครงการตัวอย่างมีคำแนะนำการตั้งค่าเฉพาะ:

#### โครงการ TypeScript/JavaScript
```bash
cd <project-directory>
npm install
npm start
```

#### โครงการ Python
```bash
cd <project-directory>
pip install -r requirements.txt
# หรือ
pip install -e .
python main.py
```

#### โครงการ Java
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

##### อินพุต

- `changed_paths: string[]` (จำเป็น) - เส้นทางสัมพัทธ์ที่เปลี่ยนใน PR
- `run_docs_lint: boolean` (ค่าเริ่มต้น `true`)
- `run_links_audit: boolean` (ค่าเริ่มต้น `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (ค่าเริ่มต้นทั้งหมด `false`)

##### เอาต์พุต

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,`
  `summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### สิทธิ์

- อ่านไฟล์ในพื้นที่ทำงานและเขียนผลผลิตเครื่องมือที่สร้างเอง (เช่น รายงาน lint,
  บันทึกการทดสอบ) เท่านั้น; ไม่มีการเขียนใน `translations/` หรือ
  `translated_images/`
- รันคำสั่ง shell ท้องถิ่นได้
- เข้าถึงเครือข่ายโดยสมัครใจเฉพาะเพื่อคืนค่าชุดแพ็กเกจ (`npm ci`,
  `python -m pip install`, การแก้ไขขึ้นอยู่กับ `mvn`)
- ไม่มีสิทธิ์ push, merge หรือแก้ไข `translations/` หรือ
  `translated_images/`

##### โหมดความล้มเหลว

- `E_NO_INPUT_PATHS`: `changed_paths` ว่างเปล่า
- `E_INVALID_PATH`: เส้นทางอินพุตออกนอกโฟลเดอร์รีโพสิทอรี
- `E_LINT_FAILED`: markdown lint ออกจากสถานะไม่เป็นศูนย์
- `E_LINK_AUDIT_FAILED`: คำสั่งตรวจสอบลิงก์ออกสถานะไม่เป็นศูนย์
- `E_SAMPLE_TEST_FAILED`: การทดสอบ/สร้างตัวอย่างออกสถานะไม่เป็นศูนย์
- `E_TIMEOUT`: คำสั่งเกินเวลาที่กำหนด

### โครงสร้างเอกสาร

- **Modules 00-11**: เนื้อหาหลักสูตรหลักในลำดับต่อเนื่อง
- **translations/**: เวอร์ชันภาษาต่างๆ (สร้างอัตโนมัติ, ห้ามแก้ไขโดยตรง)
- **translated_images/**: รูปภาพเวอร์ชันแปลท้องถิ่น (สร้างอัตโนมัติ)
- **images/**: รูปภาพต้นฉบับและไดอะแกรม

### การเปลี่ยนแปลงเอกสาร

1. แก้ไขเฉพาะไฟล์ markdown ภาษาอังกฤษในไดเรกทอรีโมดูลราก (00-11)
2. อัปเดตรูปภาพในไดเรกทอรี `images/` หากจำเป็น
3. การทำงานของ co-op-translator GitHub Action จะสร้างการแปลโดยอัตโนมัติ
4. การแปลจะถูกสร้างใหม่เมื่อมีการ push สู่ main branch

### การทำงานกับการแปล

- **การแปลอัตโนมัติ**: กระบวนการ GitHub Actions ดูแลการแปลทั้งหมด
- **ห้ามแก้ไขด้วยตนเอง** ไฟล์ในไดเรกทอรี `translations/`
- ข้อมูลเมตาการแปลถูกฝังในแต่ละไฟล์แปล
- รองรับภาษา 48+ ภาษา รวมทั้ง อาหรับ, จีน, ฝรั่งเศส, เยอรมัน, ฮินดี, ญี่ปุ่น, เกาหลี, โปรตุเกส, รัสเซีย, สเปน, และอีกมากมาย

## แนวทางการร่วมพัฒนา

### ขั้นตอนการ Pull Request

1. **Fork และ Clone**: Fork ที่เก็บและ clone fork ของคุณมาไว้ที่เครื่อง
2. **สร้าง Branch**: ใช้ชื่อ branch ที่อธิบายได้ (เช่น `fix/typo-module-3`, `add/python-example`)
3. **ทำการเปลี่ยนแปลง**: แก้ไขไฟล์ markdown ภาษาอังกฤษเท่านั้น (ไม่แก้ไขไฟล์แปล)
4. **ทดสอบในเครื่อง**: ตรวจสอบว่า markdown แสดงผลถูกต้อง
5. **ส่ง PR**: ใช้หัวข้อ PR และคำอธิบายที่ชัดเจน
6. **CLA**: เซ็นสัญญา Microsoft Contributor License Agreement เมื่อมีการแจ้งเตือน
