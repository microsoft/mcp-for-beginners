# การใช้งานเซิร์ฟเวอร์จากส่วนขยาย AI Toolkit สำหรับ Visual Studio Code

เมื่อคุณกำลังสร้างตัวแทน AI มันไม่ใช่แค่การสร้างคำตอบอัจฉริยะเท่านั้น แต่ยังเกี่ยวกับการให้ตัวแทนของคุณมีความสามารถในการดำเนินการด้วย นั่นคือที่มาของ Model Context Protocol (MCP) MCP ทำให้ง่ายสำหรับตัวแทนในการเข้าถึงเครื่องมือและบริการภายนอกในรูปแบบที่สอดคล้องกัน คิดเหมือนกับการเสียบตัวแทนของคุณเข้ากับชุดเครื่องมือที่มันสามารถ *ใช้งาน* ได้จริง

สมมติว่าคุณเชื่อมต่อตัวแทนกับเครื่องคิดเลข MCP เซิร์ฟเวอร์ ทันใดนั้น ตัวแทนของคุณสามารถดำเนินการคณิตศาสตร์ได้เพียงแค่รับคำสั่งเช่น “47 คูณ 89 เท่ากับเท่าไหร่?” — โดยไม่จำเป็นต้องเขียนตรรกะแบบตายตัวหรือสร้าง API ที่กำหนดเอง

## ภาพรวม

บทเรียนนี้ครอบคลุมวิธีเชื่อมต่อ MCP เซิร์ฟเวอร์เครื่องคิดเลขกับตัวแทนโดยใช้ส่วนขยาย [AI Toolkit](https://aka.ms/AIToolkit) ใน Visual Studio Code ทำให้ตัวแทนของคุณสามารถดำเนินการทางคณิตศาสตร์ เช่น การบวก การลบ การคูณ และการหาร ผ่านภาษาธรรมชาติ

AI Toolkit เป็นส่วนขยายที่ทรงพลังสำหรับ Visual Studio Code ที่ช่วยให้การพัฒนาตัวแทนเป็นไปอย่างราบรื่น วิศวกร AI สามารถสร้างแอปพลิเคชัน AI ได้อย่างง่ายดายโดยพัฒนาและทดสอบโมเดล generative AI — ทั้งในเครื่องหรือบนคลาวด์ ส่วนขยายรองรับโมเดล generative ส่วนใหญ่ที่มีอยู่ในปัจจุบัน

*หมายเหตุ*: AI Toolkit รองรับ Python และ TypeScript ในขณะนี้

## เป้าหมายการเรียนรู้

เมื่อจบบทเรียนนี้ คุณจะสามารถ:

- ใช้ MCP เซิร์ฟเวอร์ผ่าน AI Toolkit
- กำหนดค่าการตั้งค่าตัวแทนเพื่อให้สามารถค้นพบและใช้งานเครื่องมือที่มีอยู่ใน MCP เซิร์ฟเวอร์ได้
- ใช้เครื่องมือ MCP ผ่านภาษาธรรมชาติ

## วิธีดำเนินการ

นี่คือวิธีที่เราต้องดำเนินการในระดับสูง:

- สร้างตัวแทนและกำหนด prompt ระบบ
- สร้าง MCP เซิร์ฟเวอร์ที่มีเครื่องคิดเลข
- เชื่อมต่อ Agent Builder กับ MCP เซิร์ฟเวอร์
- ทดสอบการเรียกใช้งานเครื่องมือของตัวแทนผ่านภาษาธรรมชาติ

ดีมาก ตอนนี้ที่เราเข้าใจขั้นตอนแล้ว ให้เรากำหนดค่าตัวแทน AI เพื่อใช้ประโยชน์จากเครื่องมือภายนอกผ่าน MCP เพื่อเพิ่มขีดความสามารถของมัน!

### -2- สร้าง prompt ระบบสำหรับตัวแทน

เมื่อโครงสร้างตัวแทนถูกตั้งค่าแล้ว ถึงเวลาที่จะกำหนดบุคลิกภาพและจุดประสงค์ของมัน ในส่วนนี้ คุณจะใช้ฟีเจอร์ **Generate system prompt** เพื่ออธิบายพฤติกรรมที่ตั้งใจของตัวแทน—ในกรณีนี้คือตัวแทนเครื่องคิดเลข—และให้โมเดลเขียน prompt ระบบให้คุณ

![ภาพหน้าจออินเทอร์เฟซ "Calculator Agent" ใน AI Toolkit สำหรับ Visual Studio Code มีหน้าต่างโมดัลเปิดชื่อว่า "Generate a prompt" โมดัลอธิบายว่าสามารถสร้าง prompt เทมเพลตโดยการแชร์รายละเอียดพื้นฐานและมีช่องข้อความพร้อมตัวอย่าง prompt ระบบ: "คุณเป็นผู้ช่วยคณิตศาสตร์ที่ช่วยเหลือและมีประสิทธิภาพ เมื่อได้รับปัญหาที่เกี่ยวข้องกับเลขคณิตขั้นพื้นฐาน คุณจะตอบด้วยผลลัพธ์ที่ถูกต้อง" ด้านล่างช่องข้อความมีปุ่ม "Close" และ "Generate" มีส่วนหนึ่งของการตั้งค่าตัวแทนที่เห็นในพื้นหลัง รวมถึงโมเดลที่เลือก "OpenAI GPT-4o (ผ่าน GitHub)" และช่องระบบและ prompt ผู้ใช้](../../../../translated_images/th/aitk-generate-prompt.ba9e69d3d2bbe2a2.webp)

1. ในส่วน **Prompts** คลิกปุ่ม **Generate system prompt** ปุ่มนี้จะเปิดใน prompt builder ที่ใช้ AI เพื่อสร้าง prompt ระบบสำหรับตัวแทน
1. ในหน้าต่าง **Generate a prompt** ให้ใส่ข้อความต่อไปนี้: `คุณเป็นผู้ช่วยคณิตศาสตร์ที่ช่วยเหลือและมีประสิทธิภาพ เมื่อได้รับปัญหาที่เกี่ยวข้องกับเลขคณิตขั้นพื้นฐาน คุณจะตอบด้วยผลลัพธ์ที่ถูกต้อง`
1. คลิกปุ่ม **Generate** การแจ้งเตือนจะปรากฏที่มุมล่างขวายืนยันว่ากำลังสร้าง prompt ระบบ เมื่อการสร้าง prompt เสร็จสมบูรณ์ prompt จะปรากฏในช่อง **System prompt** ของ **Agent (Prompt) Builder**
1. ตรวจสอบ **System prompt** และแก้ไขหากจำเป็น

### -3- สร้าง MCP เซิร์ฟเวอร์

เมื่อคุณกำหนด prompt ระบบของตัวแทนเรียบร้อยแล้ว — เพื่อชี้นำพฤติกรรมและการตอบกลับ — ถึงเวลาติดตั้งความสามารถใช้งานจริงให้ตัวแทน ในส่วนนี้ คุณจะสร้าง MCP เซิร์ฟเวอร์เครื่องคิดเลขพร้อมเครื่องมือในการคำนวณการบวก ลบ คูณ และหาร เซิร์ฟเวอร์นี้จะช่วยให้ตัวแทนของคุณทำการคำนวณตามคำสั่งภาษาธรรมชาติได้แบบเรียลไทม์

![ภาพหน้าจอส่วนล่างของอินเทอร์เฟซ Calculator Agent ใน AI Toolkit สำหรับ Visual Studio Code แสดงเมนูขยายได้สำหรับ “Tools” และ “Structure output” พร้อมเมนูแบบเลื่อนลงที่ระบุ “Choose output format” ตั้งค่าเป็น “text” ด้านขวาเป็นปุ่ม “+ MCP Server” สำหรับเพิ่ม Model Context Protocol เซิร์ฟเวอร์ ไอคอนรูปภาพเป็นที่ว่างเหนือส่วน Tools](../../../../translated_images/th/aitk-add-mcp-server.9742cfddfe808353.webp)

AI Toolkit มีเทมเพลตสำหรับความสะดวกในการสร้าง MCP เซิร์ฟเวอร์ของคุณเอง เราจะใช้เทมเพลต Python สำหรับการสร้าง MCP เซิร์ฟเวอร์เครื่องคิดเลข

*หมายเหตุ*: AI Toolkit รองรับ Python และ TypeScript ในขณะนี้

1. ในส่วน **Tools** ของ **Agent (Prompt) Builder** คลิกปุ่ม **+ MCP Server** ส่วนขยายจะเปิดตัวช่วยตั้งค่าผ่าน **Command Palette**
1. เลือก **+ Add Server**
1. เลือก **Create a New MCP Server**
1. เลือกเทมเพลต **python-weather**
1. เลือก **Default folder** เพื่อบันทึกเทมเพลต MCP เซิร์ฟเวอร์
1. ใส่ชื่อเซิร์ฟเวอร์ดังนี้: **Calculator**
1. หน้าต่าง Visual Studio Code ใหม่จะเปิดขึ้น เลือก **Yes, I trust the authors**
1. ใช้เทอร์มินัล (**Terminal** > **New Terminal**) สร้างสภาพแวดล้อมเสมือน: `python -m venv .venv`
1. ใช้เทอร์มินัล เปิดใช้งานสภาพแวดล้อมเสมือน:
    1. Windows - `.venv\Scripts\activate`
    1. macOS/Linux - `source .venv/bin/activate`
1. ใช้เทอร์มินัล ติดตั้ง dependencies: `pip install -e .[dev]`
1. ในมุมมอง **Explorer** ของ **Activity Bar** ขยายไดเรกทอรี **src** และเลือก **server.py** เพื่อเปิดไฟล์ในแก้ไข
1. แทนที่โค้ดในไฟล์ **server.py** ด้วยสิ่งต่อไปนี้แล้วบันทึก

    ```python
    """
    Sample MCP Calculator Server implementation in Python.

    
    This module demonstrates how to create a simple MCP server with calculator tools
    that can perform basic arithmetic operations (add, subtract, multiply, divide).
    """
    
    from mcp.server.fastmcp import FastMCP
    
    server = FastMCP("calculator")
    
    @server.tool()
    def add(a: float, b: float) -> float:
        """Add two numbers together and return the result."""
        return a + b
    
    @server.tool()
    def subtract(a: float, b: float) -> float:
        """Subtract b from a and return the result."""
        return a - b
    
    @server.tool()
    def multiply(a: float, b: float) -> float:
        """Multiply two numbers together and return the result."""
        return a * b
    
    @server.tool()
    def divide(a: float, b: float) -> float:
        """
        Divide a by b and return the result.
        
        Raises:
            ValueError: If b is zero
        """
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    ```

### -4- รันตัวแทนด้วย MCP เซิร์ฟเวอร์เครื่องคิดเลข

คุณจะรัน MCP เซิร์ฟเวอร์เครื่องคิดเลขบนเครื่องพัฒนา local ของคุณผ่าน **Agent Builder** ในฐานะไคลเอนต์ MCP

1. กด `F5` เพื่อเริ่มการดีบัก MCP เซิร์ฟเวอร์ **Agent (Prompt) Builder** จะเปิดในแท็บแก้ไขใหม่ สถานะเซิร์ฟเวอร์แสดงในเทอร์มินัล
1. ในช่อง **User prompt** ของ **Agent (Prompt) Builder** ใส่ prompt ต่อไปนี้: `ฉันซื้อของ 3 ชิ้น ราคาชิ้นละ $25 แล้วใช้ส่วนลด $20 ฉันจ่ายเท่าไหร่?`
1. คลิกปุ่ม **Run** เพื่อสร้างคำตอบจากตัวแทน
1. ตรวจสอบผลลัพธ์ที่ตัวแทนส่งออก โมเดลควรสรุปว่าคุณจ่าย **$55**
1. นี่คือการสรุปว่าจะเกิดอะไรขึ้น:
    - ตัวแทนเลือกเครื่องมือ **multiply** และ **subtract** เพื่อช่วยในการคำนวณ
    - ค่าของ `a` และ `b` ถูกกำหนดสำหรับเครื่องมือ **multiply**
    - ค่าของ `a` และ `b` ถูกกำหนดสำหรับเครื่องมือ **subtract**
    - คำตอบจากแต่ละเครื่องมือถูกส่งผ่านใน **Tool Response**
    - ผลลัพธ์สุดท้ายจากโมเดลแสดงใน **Model Response**
1. ส่ง prompt เพิ่มเติมเพื่อทดสอบตัวแทนต่อไป คุณสามารถแก้ไข prompt ที่มีอยู่ในช่อง **User prompt** โดยคลิกแล้วแทนที่ข้อความเดิม
1. เมื่อคุณทดสอบตัวแทนเสร็จสิ้น คุณสามารถหยุดเซิร์ฟเวอร์ผ่าน **เทอร์มินัล** โดยกด **CTRL/CMD+C** เพื่อออก

## การบ้าน

ลองเพิ่มรายการเครื่องมือเพิ่มเติมลงในไฟล์ **server.py** ของคุณ (เช่น: คืนค่ารากที่สองของตัวเลข) ส่ง prompt เพิ่มเติมที่ต้องการให้ตัวแทนใช้เครื่องมือใหม่ของคุณ (หรือเครื่องมือที่มีอยู่) อย่าลืมรีสตาร์ทเซิร์ฟเวอร์เพื่อโหลดเครื่องมือใหม่ที่เพิ่มเข้ามา

## ข้อคิดสำคัญ

ข้อคิดสำคัญจากบทนี้คือ:

- ส่วนขยาย AI Toolkit เป็นไคลเอนต์ที่ยอดเยี่ยมที่ช่วยให้คุณใช้งาน MCP เซิร์ฟเวอร์และเครื่องมือของพวกเขาได้
- คุณสามารถเพิ่มเครื่องมือใหม่ให้กับ MCP เซิร์ฟเวอร์ เพื่อขยายความสามารถของตัวแทนให้รองรับความต้องการที่เปลี่ยนแปลง
- AI Toolkit มีเทมเพลต (เช่น เทมเพลต MCP เซิร์ฟเวอร์ Python) เพื่อช่วยให้ง่ายต่อการสร้างเครื่องมือที่กำหนดเอง
