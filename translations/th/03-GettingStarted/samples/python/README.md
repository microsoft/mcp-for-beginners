# MCP Calculator Server (Python)



การใช้งานเซิร์ฟเวอร์ Model Context Protocol (MCP) ที่เรียบง่ายในภาษา Python ซึ่งมีฟังก์ชันเครื่องคิดเลขพื้นฐาน


## การติดตั้ง

ติดตั้ง dependencies ที่จำเป็น:

```bash
pip install -r requirements.txt
```

หรือติดตั้ง MCP Python SDK โดยตรง:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## วิธีใช้งาน

### การรันเซิร์ฟเวอร์

เซิร์ฟเวอร์นี้ออกแบบมาให้ใช้งานด้วย MCP clients (เช่น Claude Desktop) เพื่อเริ่มเซิร์ฟเวอร์:

```bash
python mcp_calculator_server.py
```

**หมายเหตุ**: เมื่อรันโดยตรงในเทอร์มินัล คุณจะเห็นข้อผิดพลาดการตรวจสอบ JSON-RPC ซึ่งเป็นพฤติกรรมปกติ - เซิร์ฟเวอร์ตั้งรอข้อความ MCP client ที่มีรูปแบบถูกต้อง

### การทดสอบฟังก์ชัน

เพื่อทดสอบให้แน่ใจว่าฟังก์ชันเครื่องคิดเลขทำงานถูกต้อง:

```bash
python test_calculator.py
```

## การแก้ไขปัญหา

### ข้อผิดพลาดการนำเข้าโมดูล

หากคุณเห็น `ModuleNotFoundError: No module named 'mcp'` ให้ติดตั้ง MCP Python SDK:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### ข้อผิดพลาด JSON-RPC เมื่อรันโดยตรง

ข้อผิดพลาดเช่น "Invalid JSON: EOF while parsing a value" เมื่อรันเซิร์ฟเวอร์โดยตรงเป็นสิ่งที่คาดไว้ เซิร์ฟเวอร์ต้องการข้อความจาก MCP client ไม่ใช่ข้อมูลจากเทอร์มินัลโดยตรง
