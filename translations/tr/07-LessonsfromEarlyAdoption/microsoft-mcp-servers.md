## 🔧 MCP Sunucularını Anlama: Yeni Başlayanlar İçin Kılavuz

### MCP Sunucuları Nedir?

Model Context Protocol'e (MCP) yeni başladıysanız, "MCP sunucusu tam olarak nedir ve neden önemsemeliyim?" diye sorabilirsiniz. Basit bir benzetme ile başlayalım.

MCP sunucularını, AI kodlama yardımcınızın (örneğin GitHub Copilot) harici araçlar ve hizmetlere bağlanmasına yardımcı olan özelleşmiş asistanlar olarak düşünün. Tıpkı telefonda farklı görevler için farklı uygulamalar kullanmanız gibi — biri hava durumu için, biri navigasyon için, biri bankacılık için — MCP sunucuları AI asistanınıza farklı geliştirme araçları ve hizmetleriyle etkileşim kurma becerisi sağlar.

### MCP Sunucularının Çözdüğü Sorun

MCP sunucuları olmadan, eğer:
- Azure kaynaklarınızı kontrol etmek isteseydiniz
- Bir GitHub problemi oluşturmak isteseydiniz 
- Veritabanınıza sorgu göndermek isteseydiniz
- Belgelerde arama yapmak isteseydiniz

Kodlamayı durdurup, bir tarayıcı açıp, ilgili web sitesine gitmeniz ve bu görevleri manuel olarak yapmanız gerekirdi. Bu sürekli bağlam değiştirme, akışınızı böler ve verimliliği düşürür.

### MCP Sunucuları Geliştirme Deneyiminizi Nasıl Dönüştürür

MCP sunucuları sayesinde geliştirme ortamınızda (VS Code, Visual Studio, vb.) kalabilir ve AI asistanınızdan bu görevleri yapmasını basitçe isteyebilirsiniz. Örneğin:

**Bu geleneksel iş akışını düşünün:**
1. Kodlamayı durdur
2. Tarayıcıyı aç
3. Azure portalına git
4. Depolama hesabı detaylarını kontrol et
5. VS Code'a geri dön
6. Kodlamaya devam et

**Şimdi ise şunu yapabilirsiniz:**
1. AI'a sor: "Azure depolama hesaplarımın durumu nedir?"
2. Sağlanan bilgilerle kodlamaya devam et

### Yeni Başlayanlar İçin Temel Faydalar

#### 1. 🔄 **Akış Halinde Kalın**
- Birden çok uygulama arasında geçiş yapmaya son

#### 3. 🔗 **Birden Çok Aracı Birbirine Bağlayın**
- Farklı servisleri birleştirerek güçlü iş akışları oluşturun
- Örnek: "Son GitHub problemlerini al ve karşılık gelen Azure DevOps iş öğeleri oluştur"

#### 4. 🌐 **Büyüyen Bir Ekosisteme Erişin**

### Yeni Başlayanlar İçin Gerçek Dünya Örneği

Diyelim ki web geliştirmeye yeni başladınız ve ilk projeniz üzerinde çalışıyorsunuz. MCP sunucuları şöyle yardımcı olabilir:

**Geleneksel yaklaşım:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP sunucularıyla:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

## VS Code ve Visual Studio'da MCP ile Başlamak 🚀

GitHub Copilot ile Visual Studio Code veya Visual Studio 2022 kullanıyorsanız, bu MCP sunucularını kurmak oldukça basittir.

### VS Code Kurulumu

VS Code için temel süreç şöyle:

1. **Ajan Modunu Etkinleştirin**: VS Code'da Copilot Sohbet penceresinde Ajan moduna geçin
2. **MCP Sunucularını Yapılandırın**: VS Code settings.json dosyanıza sunucu yapılandırmaları ekleyin
3. **Sunucuları Başlatın**: Kullanmak istediğiniz her sunucu için "Başlat" düğmesine tıklayın
4. **Araçları Seçin**: Geçerli oturumunuz için hangi MCP sunucularını etkinleştireceğinizi seçin

Ayrıntılı kurulum talimatları için [VS Code MCP dokümantasyonuna](https://code.visualstudio.com/docs/copilot/copilot-mcp) bakın.

> **💡 Uzman İpucu: MCP Sunucularını profesyonelce yönetin!**
> 
> VS Code Uzantılar görünümüne artık [kurulu MCP Sunucularını yönetmek için kullanışlı yeni bir arayüz dahil oldu](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Yüklediğiniz MCP Sunucularını başlatmak, durdurmak ve yönetmek için hızlıca erişiminiz var. Deneyin!

### Visual Studio 2022 Kurulumu

Visual Studio 2022 (sürüm 17.14 veya sonrası) için:

1. **Ajan Modunu Etkinleştirin**: GitHub Copilot Sohbet penceresinde "Sor" açılır menüsüne tıklayın ve "Ajan" seçeneğini seçin
2. **Yapılandırma Dosyası Oluşturun**: Çözüm dizininizde bir `.mcp.json` dosyası oluşturun (önerilen konum: `<SOLUTIONDIR>\.mcp.json`)
3. **Sunucuları Yapılandırın**: MCP sunucu yapılandırmalarınızı standart MCP formatını kullanarak ekleyin
4. **Araç Onayı**: İstendiğinde, uygun kapsam izinleriyle kullanmak istediğiniz araçları onaylayın

Ayrıntılı Visual Studio kurulum talimatları için [Visual Studio MCP dokümantasyonuna](https://learn.microsoft.com/visualstudio/ide/mcp-servers) bakın.

Her MCP sunucusunun kendi yapılandırma gereksinimleri vardır (bağlantı dizeleri, kimlik doğrulama, vb.), ancak her iki IDE'de de kurulum deseni tutarlıdır.

**Ne yapar**: Microsoft Learn Docs MCP Sunucusu, AI asistanlarına Model Context Protocol aracılığıyla resmi Microsoft dokümantasyonuna gerçek zamanlı erişim sağlayan bulut tabanlı bir hizmettir. `https://learn.microsoft.com/api/mcp` adresine bağlanır ve Microsoft Learn, Azure dokümantasyonu, Microsoft 365 dokümantasyonu ve diğer resmi Microsoft kaynakları üzerinde semantik arama yapmayı mümkün kılar.

**Neden faydalı**: "Sadece dokümantasyon" gibi görünse de, bu sunucu Microsoft teknolojilerini kullanan her geliştirici için kritik önemdedir. AI kodlama asistanları hakkında en büyük şikayetlerden biri, en yeni .NET ve C# sürümleri hakkında güncel olmamalarıdır. Microsoft Learn Docs MCP Sunucusu, en güncel dokümantasyon, API referansları ve en iyi uygulamalara gerçek zamanlı erişim sağlayarak bu sorunu çözer. En son Azure SDK'larıyla çalışıyor, yeni C# 13 özelliklerini keşfediyor veya son trend Aspire desenlerini uyguluyor olun, bu sunucu AI asistanınızın doğru ve modern kod üretmesi için gerekli yetkin ve güncel bilgiye erişmesini sağlar.

**Gerçek dünya kullanımı**: "Resmi Microsoft Learn dokümantasyonuna göre Azure container uygulaması oluşturmak için az cli komutları nelerdir?" veya "ASP.NET Core'da Entity Framework'u dependency injection ile nasıl yapılandırırım?" Ya da "Bu kodu Microsoft Learn Dokümantasyonundaki performans önerileri ile eşleştiğinden emin olmak için incele." Sunucu, Microsoft Learn, Azure belgeleri ve Microsoft 365 dokümantasyonu genelinde gelişmiş semantik arama kullanarak en bağlamsal olarak alakalı bilgileri bulur. En güncel Microsoft dokümantasyonuna erişerek makale başlıkları ve URL'lerle birlikte en fazla 10 yüksek kaliteli içerik parçası döner.

**Öne çıkan örnek**: Sunucu, Microsoft'un resmi teknik dokümantasyonu üzerinde semantik arama yapan `microsoft_docs_search` aracını sunar. Yapılandırıldıktan sonra, "ASP.NET Core'da JWT kimlik doğrulamasını nasıl uygularım?" gibi sorular sorabilir ve kaynak bağlantılarıyla detaylı resmi yanıtlar alabilirsiniz. Arama kalitesi olağanüstüdür çünkü bağlamı anlar – Azure bağlamında "container" hakkında sorulduğunda Azure Container Instances dokümantasyonu dönerken, aynı terim .NET bağlamında ilgili C# koleksiyon bilgileri döner.

Bu, özellikle hızla değişen veya yeni güncellenen kütüphaneler ve kullanım senaryoları için çok kullanışlıdır. Örneğin, yakın zamanda bazı kodlama projelerinde Aspire ve Microsoft.Extensions.AI'nin en son sürümlerindeki özellikleri kullanmak istedim. Microsoft Learn Docs MCP sunucusunu dahil ederek sadece API dokümanlarını değil, yeni yayımlanmış kılavuzları ve rehberlikleri de kullanabildim.

### 2. ☁️ Azure MCP Sunucusu


[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Ne yapar**: Azure MCP Server, Azure ekosistemini AI iş akışınıza getiren 15'ten fazla özel Azure servis konektöründen oluşan kapsamlı bir pakettir. Bu sadece tek bir sunucu değildir – kaynak yönetimi, veritabanı bağlantısı (PostgreSQL, SQL Server), KQL ile Azure Monitor log analizi, Cosmos DB entegrasyonu ve çok daha fazlasını içeren güçlü bir koleksiyondur.

**Neden faydalı**: Sadece Azure kaynaklarını yönetmenin ötesinde, bu sunucu Azure SDK’ları ile çalışırken kod kalitesini önemli ölçüde artırır. Azure MCP’yi Agent modunda kullandığınızda, sadece kod yazmanıza yardımcı olmakla kalmaz – aynı zamanda mevcut kimlik doğrulama kalıplarına, hata işleme en iyi uygulamalarına uyan ve en yeni SDK özelliklerinden yararlanan *daha iyi* Azure kodu yazmanıza yardımcı olur. Çalışabilecek genel kod almak yerine, Azure tarafından önerilen üretim iş yükleri için kalıplara uyan kod elde edersiniz.

**Ana modüller şunlardır**:
- **🗄️ Veritabanı Konektörleri**: Azure Database for PostgreSQL ve SQL Server için doğrudan doğal dil erişimi
- **📊 Azure Monitor**: KQL destekli log analizi ve operasyonel içgörüler
- **🌐 Kaynak Yönetimi**: Tam Azure kaynak yaşam döngüsü yönetimi
- **🔐 Kimlik Doğrulama**: DefaultAzureCredential ve yönetilen kimlik kalıpları
- **📦 Depolama Servisleri**: Blob Depolama, Kuyruk Depolama ve Tablo Depolama işlemleri
- **🚀 Konteyner Servisleri**: Azure Container Apps, Container Instances ve AKS yönetimi
- **Ve daha birçok özel konektör**

**Gerçek dünya kullanımı**: "Azure depolama hesaplarımı listele", "Son saat içindeki hatalar için Log Analytics çalışma alanımı sorgula" veya "Node.js kullanarak uygun kimlik doğrulama ile bir Azure uygulaması oluşturmama yardım et"

**Tam demo senaryosu**: Azure MCP’yi GitHub Copilot for Azure eklentisi ile VS Code’da birleştirmenin gücünü gösteren tam bir rehber:

> "DefaultAzureCredential kimlik doğrulaması kullanarak bir dosyayı Azure Blob Storage’a yükleyen bir Python betiği oluştur. Betik, 'mycompanystorage' adlı Azure depolama hesabıma bağlanmalı, 'documents' adlı bir konteynıra yüklemeli, yüklemek için geçerli zaman damgası ile bir test dosyası oluşturmalı, hataları zarifçe ele almalı ve bilgilendirici çıktı sağlamalı, kimlik doğrulama ve hata işleme için Azure en iyi uygulamalarını takip etmeli, DefaultAzureCredential kimlik doğrulamasının nasıl çalıştığını açıklayan yorumlar içermeli ve betiği uygun işlevler ve dokümantasyon ile iyi yapılandırmalı."

Azure MCP Server, aşağıdakileri içeren tam, üretime hazır bir Python betiği üretecektir:
- En son Azure Blob Storage SDK’sını uygun async kalıpları ile kullanır
- Kapsamlı yedekleme zinciri açıklaması ile DefaultAzureCredential uygular
- Özel Azure istisna türleriyle sağlam hata işleme içerir
- Kaynak yönetimi ve bağlantı işlemleri için Azure SDK en iyi uygulamalarını takip eder
- Ayrıntılı loglama ve bilgilendirici konsol çıktısı sağlar
- İşlevler, dokümantasyon ve tür ipuçları ile uygun yapılandırılmış bir betik oluşturur

Bu durumu olağanüstü kılan şey, Azure MCP olmadan, çalışabilecek ancak geçerli Azure kalıplarını takip etmeyen genel blob depolama kodu almanızdır. Azure MCP ile en yeni kimlik doğrulama yöntemlerinden yararlanan, Azure'ya özgü hata senaryolarını işleyen ve Microsoft’un üretim uygulamaları için önerdiği uygulamaları takip eden kod alırsınız.

**Örnek**: `az` ve `azd` CLI'deki komutları hatırlamakta zorlandım. Benim için her zaman iki aşamalı bir süreç: önce sözdizimini ararım, sonra komutu çalıştırırım. Çoğunlukla portal'a gidip oradan ilerlemeyi tercih ederim çünkü CLI sözdizimini hatırlayamadığımı kabul etmek istemem. Sadece istediğimi tarif edebilmek harika, dahası bunu IDE’den ayrılmadan yapabilmek müthiş!

Başlamak için [Azure MCP deposundaki](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) mükemmel kullanım durumu listesine göz atabilirsiniz. Kapsamlı kurulum rehberleri ve gelişmiş yapılandırma seçenekleri için resmi [Azure MCP belgelerine](https://learn.microsoft.com/azure/developer/azure-mcp-server/) bakınız.

Bu, sadece temel depo işlemleri değil – GitHub Actions yönetimi, pull request iş akışları, sorun takibi, güvenlik taraması, bildirimler ve gelişmiş otomasyon yeteneklerini içeren kapsamlı bir araç setidir.

**Neden faydalı**: Bu sunucu, GitHub ile olan etkileşiminizi geliştirerek tam platform deneyimini doğrudan geliştirme ortamınıza getiren bir dönüşüm sağlar. Proje yönetimi, kod incelemeleri ve CI/CD takibi için sürekli VS Code ile GitHub.com arasında geçiş yapmak yerine, kodunuza odaklanırken her şeyi doğal dil komutlarıyla yapabilirsiniz.

> **ℹ️ Not: Farklı 'Agent' Türleri**
> 
> Bu GitHub MCP Server'ı, GitHub'un Kodlama Agentı (otomatik kodlama görevleri için sorunlara atayabileceğiniz AI ajanı) ile karıştırmayın. GitHub MCP Server, VS Code'un Agent modunda çalışarak GitHub API entegrasyonu sağlarken, GitHub Kodlama Agentı atanan GitHub sorunları için pull requestler oluşturan ayrı bir özelliktir.

**Ana yetenekler şunlardır**:
- **⚙️ GitHub Actions**: Tam CI/CD boru hattı yönetimi, iş akışı takibi ve eser yönetimi
- **🔀 Pull Requestler**: PR oluşturma, inceleme, birleştirme ve kapsamlı durum takibi
- **🐛 Sorunlar (Issues)**: Tam sorun yaşam döngüsü yönetimi, yorumlama, etiketleme ve atama
- **🔒 Güvenlik**: Kod tarama uyarıları, gizli anahtar tespiti ve Dependabot entegrasyonu
- **🔔 Bildirimler**: Akıllı bildirim yönetimi ve depo abonelik kontrolü
- **📁 Depo Yönetimi**: Dosya işlemleri, dal yönetimi ve depo yönetimi
- **👥 İşbirliği**: Kullanıcı ve organizasyon araması, takım yönetimi ve erişim kontrolü

**Gerçek dünya kullanımı**: "Feature dalımdan bir pull request oluştur", "Bu haftaki başarısız tüm CI çalıştırmalarını göster", "Depolarımdaki açık güvenlik uyarılarını listele" veya "Organizasyonlarımdaki bana atanmış tüm sorunları bul"

**Tam demo senaryosu**: GitHub MCP Server’ın yeteneklerini gösteren güçlü bir iş akışı:

> "Sprint değerlendirmesine hazırlanmalıyım. Bu hafta oluşturduğum tüm pull requestleri göster, CI/CD boru hattımızın durumunu kontrol et, ele almamız gereken güvenlik uyarılarının özetini çıkar ve 'feature' etiketiyle birleştirilen PR’lere dayanarak sürüm notları taslağı oluşturmama yardım et."

GitHub MCP Server şunları yapar:
- Detaylı durum bilgisiyle son pull requestlerinizi sorgular
- İş akışı çalıştırmalarını analiz eder ve başarısızlıklar veya performans sorunlarını vurgular
- Güvenlik tarama sonuçlarını derler ve kritik uyarılara öncelik verir
- Birleştirilen PR’lerden bilgi çıkararak kapsamlı sürüm notları oluşturur
- Sprint planlama ve sürüm hazırlığı için uygulanabilir sonraki adımları sağlar

**Örnek**: Kod inceleme iş akışları için kullanmayı çok seviyorum. VS Code, GitHub bildirimleri ve pull request sayfaları arasında geçiş yapmak yerine "İncelememi bekleyen tüm PR’leri göster" diyebiliyorum, ardından "PR #123’e kimlik doğrulamadaki hata işleme hakkında bir yorum ekle" komutunu verebiliyorum. Sunucu GitHub API çağrılarını yönetiyor, tartışma bağlamını koruyor ve daha yapıcı inceleme yorumları hazırlamama bile yardım ediyor.

**Kimlik doğrulama seçenekleri**: Sunucu hem OAuth (VS Code’da sorunsuz) hem de Kişisel Erişim Tokenlarını destekler; ihtiyacınız olan yalnızca GitHub işlevselliğini etkinleştirmek için yapılandırılabilir araç setleri sağlar. Anında kurulum için uzak barındırılan hizmet olarak veya tam kontrol için yerelde Docker ile çalıştırabilirsiniz.

> **💡 İpucu**
> 
> MCP sunucu ayarlarınızdaki `--toolsets` parametresini yapılandırarak yalnızca ihtiyacınız olan araç setlerini etkinleştirin; bu, bağlam boyutunu küçültür ve AI araç seçimini iyileştirir. Örneğin, temel geliştirme iş akışları için MCP yapılandırma argümanlarınıza `"--toolsets", "repos,issues,pull_requests,actions"` ekleyin veya çoğunlukla GitHub izleme yetenekleri için `"--toolsets", "notifications, security"` kullanın.

[![VS Code'a Kur](https://img.shields.io/badge/VS_Code-Install_MarkItDown_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D) [![VS Code Insiders'a Kur](https://img.shields.io/badge/VS_Code_Insiders-Install_MarkItDown_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/markitdown)

**Neden faydalı**: Modern dokümantasyon iş akışları için vazgeçilmez! MarkItDown, başlıklar, listeler, tablolar ve bağlantılar gibi kritik belge yapılarını koruyarak etkileyici bir dosya formatı yelpazesini işliyor. Basit metin çıkarma araçlarının aksine, hem yapay zeka işleme hem de insan tarafından okunabilirlik açısından değerli anlamsal anlam ve biçimlendirmeye odaklanıyor.

**Desteklenen dosya formatları**:
- **Ofis Belgeleri**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Medya Dosyaları**: Görseller (EXIF meta verisi ve OCR ile), Ses (EXIF meta verisi ve konuşma transkripsiyonu ile)
- **Web İçeriği**: HTML, RSS beslemeleri, YouTube URL'leri, Wikipedia sayfaları
- **Veri Formatları**: CSV, JSON, XML, ZIP dosyaları (içeriği yinelemeli olarak işler)
- **Yayınlama Formatları**: EPub, Jupyter not defterleri (.ipynb)
- **E-posta**: Outlook mesajları (.msg)
- **Gelişmiş**: Gelişmiş PDF işleme için Azure Document Intelligence entegrasyonu

**Gelişmiş yetenekler**: MarkItDown, LLM destekli görüntü açıklamaları (bir OpenAI istemcisi sağlandığında), gelişmiş PDF işlemesi için Azure Document Intelligence, konuşma içeriği için ses transkripsiyonu ve ek dosya formatlarına genişletme için eklenti sistemi destekler.

**Gerçek dünya kullanımı**: "Bu PowerPoint sunumunu dokümantasyon sitemiz için Markdown'a dönüştür", "Bu PDF'den doğru başlık yapısıyla metni çıkar" veya "Bu Excel tablosunu okunabilir tablo formatına dönüştür"

**Öne çıkan örnek**: [MarkItDown belgelerinden](https://github.com/microsoft/markitdown#why-markdown) alıntı yapmak gerekirse:

> Markdown, minimal işaretleme veya biçimlendirme ile düz metne çok yakındır, ancak yine de önemli belge yapısını temsil etmenin bir yolunu sağlar. OpenAI'in GPT-4o gibi ana akım LLM'ler doğal olarak Markdown "konuşur" ve yanıtlarına sıklıkla Markdown'u istemeden dahil eder. Bu, onların büyük miktarda Markdown biçimlendirilmiş metinle eğitildiğini ve onu iyi anladığını gösterir. Yan fayda olarak, Markdown konvansiyonları aynı zamanda yüksek oranda token verimlidir.

MarkItDown, belge yapısını korumada gerçekten iyidir ki bu yapay zeka iş akışları için önemlidir. Örneğin, bir PowerPoint sunumu dönüştürürken, slayt organizasyonunu doğru başlıklarla korur, tabloları Markdown tabloları olarak çıkarır, görseller için alternatif metin ekler ve hatta konuşmacı notlarını işler. Grafikler okunabilir veri tablolarına dönüştürülür ve ortaya çıkan Markdown, orijinal sunumun mantıksal akışını korur. Bu, sunum içeriğini yapay zeka sistemlerine beslemek veya mevcut slaytlardan dokümantasyon oluşturmak için mükemmeldir.

**Ne yapar**: Microsoft Foundry MCP Sunucusu, geliştiricilere model katalogları, dağıtım yönetimi, Azure AI Search ile bilgi indeksleme ve değerlendirme araçları dahil olmak üzere Azure’un yapay zeka ekosistemine kapsamlı erişim sağlar. Bu deneysel sunucu, yapay zeka geliştirme ile Azure’un güçlü yapay zeka altyapısı arasındaki boşluğu kapatarak yapay zeka uygulamalarını oluşturmayı, dağıtmayı ve değerlendirmeyi kolaylaştırır.

**Neden faydalı**: Bu sunucu, kurumsal düzeyde AI yeteneklerini doğrudan geliştirme iş akışınıza getirerek Azure AI hizmetleri ile çalışma şeklinizi dönüştürür. Azure portalı, dokümantasyon ve IDE arasında geçiş yapmak yerine, doğal dil komutlarıyla modelleri keşfedebilir, hizmetleri dağıtabilir, bilgi tabanlarını yönetebilir ve AI performansını değerlendirebilirsiniz. Özellikle RAG (Retrieval-Augmented Generation) uygulamaları geliştiren geliştiriciler, çoklu model dağıtımlarını yönetenler veya kapsamlı AI değerlendirme süreçleri uygulayanlar için güçlüdür.

**Temel geliştirici yetenekleri**:
- **🔍 Model Keşfi ve Dağıtım**: Microsoft Foundry'nin model kataloğunu keşfedin, detaylı model bilgisi ve kod örnekleri alın, modelleri Azure AI Hizmetlerine dağıtın
- **📚 Bilgi Yönetimi**: Azure AI Search indeksleri oluşturun ve yönetin, belgeler ekleyin, indeksleyicileri yapılandırın ve gelişmiş RAG sistemleri kurun
- **⚡ AI Ajan Entegrasyonu**: Azure AI Ajanları ile bağlantı kurun, mevcut ajanları sorgulayın ve üretim senaryolarında ajan performansını değerlendirin
- **📊 Değerlendirme Çerçevesi**: Kapsamlı metin ve ajan değerlendirmeleri yapın, markdown raporları oluşturun ve AI uygulamaları için kalite güvencesi uygulayın
- **🚀 Prototip Oluşturma Araçları**: GitHub tabanlı prototip oluşturma talimatlarını alın ve en son araştırma modelleri içeren Microsoft Foundry Labs’a erişim sağlayın

**Gerçek dünya geliştirici kullanımı**: "Uygulamam için Azure AI Hizmetlerine Phi-4 modeli dağıt", "Dokümantasyon RAG sistemim için yeni bir arama indeksi oluştur", "Ajanımın yanıtlarını kalite metriklerine göre değerlendir" veya "Karmaşık analiz görevlerim için en iyi akıl yürütme modelini bul"

**Tam demo senaryosu**: İşte güçlü bir yapay zeka geliştirme iş akışı:

> "Müşteri destek ajanı oluşturuyorum. Katalogdan iyi bir akıl yürütme modeli bulmama, bunu Azure AI Hizmetlerine dağıtmama, dokümantasyonumuzdan bir bilgi tabanı oluşturmama, yanıt kalitesini test etmek için bir değerlendirme çerçevesi kurmama ve ardından test için GitHub token ile entegrasyonu prototip haline getirmeme yardım et."

Microsoft Foundry MCP Sunucusu şunları yapacak:
- Gereksinimlerinize göre optimal akıl yürütme modellerini önermek için model kataloğunu sorgulama
- Tercih ettiğiniz Azure bölgesi için dağıtım komutları ve kota bilgisi sağlama
- Dokümantasyonunuz için uygun şemaya sahip Azure AI Search indeksleri kurma
- Kalite metrikleri ve güvenlik kontrolleri ile değerlendirme hatları yapılandırma
- Hemen test için GitHub kimlik doğrulamalı prototip kodu oluşturma
- Belirli teknoloji yığınınıza göre kapsamlı kurulum rehberleri sağlama

**Öne çıkan örnek**: Geliştirici olarak mevcut farklı LLM modelleriyle güncel kalmakta zorlanıyorum. Bazı ana modelleri biliyorum ama bazı verimlilik ve performans artışlarını kaçırıyormuşum gibi hissediyorum. Token ve kotayı yönetmek zor – doğru görev için doğru modeli seçip seçmediğimden ya da bütçemi verimsiz harcıyorum diye asla emin olamıyorum. Bu MCP Sunucusu’nu, ekip arkadaşlarımla MCP Sunucu önerileri üzerine konuşurken James Montemagno’dan duydum ve kullanmak için heyecanlıyım! Model keşif yetenekleri, sıradan modellerin ötesine geçmek ve belirli görevler için optimize edilmiş modelleri bulmak isteyen benim gibi biri için oldukça etkileyici görünüyor. Değerlendirme çerçevesi ise aslında daha iyi sonuçlar alıp almadığımı doğrulamama yardımcı olacak, sadece yenilik olsun diye bir şey denemiyorum.

> **ℹ️ Deneysel Durum**
> 
> Bu MCP sunucusu deneysel olup aktif geliştirme aşamasındadır. Özellikler ve API’ler değişebilir. Azure AI yeteneklerini keşfetmek ve prototipler oluşturmak için mükemmeldir, ancak üretim kullanımı için kararlılık gereksinimlerini doğrulayın.

Şema doğrulama özellikleri, saatler süren hata ayıklamalara neden olabilecek bildirim yapısı hatalarını önlemek için özellikle faydalı görünüyor.

## 📋 Sonuç

Model Context Protocol (MCP), geliştiricilerin AI asistanları ve dış araçlarla etkileşimini dönüştürüyor. Bu 10 Microsoft MCP sunucusu, standartlaştırılmış AI entegrasyonunun gücünü göstererek geliştiricilerin akış halinde kalırken güçlü dış yeteneklere sorunsuz erişim sağladığı iş akışlarını mümkün kılıyor.

Kapsamlı Azure ekosistemi entegrasyonundan Playwright gibi tarayıcı otomasyonu veya MarkItDown gibi belge işleme için özel araçlara kadar bu sunucular, MCP’nin farklı geliştirme senaryolarında verimliliği artırabileceğini gösteriyor. Standart protokol, bu araçların sorunsuz birlikte çalışmasını sağlayarak tutarlı bir geliştirme deneyimi sunuyor.

MCP ekosistemi gelişmeye devam ederken, toplulukla etkileşimde kalmak, yeni sunucuları keşfetmek ve özel çözümler geliştirmek geliştirme verimliliğinizi maksimize etmek için anahtar olacaktır. MCP’nin açık standart yapısı, farklı satıcılardan araçları karıştırıp eşleştirerek özel ihtiyaçlarınıza uygun ideal iş akışını oluşturmanızı sağlar.
