# 🚀 Servers 10 za Microsoft MCP Zinazo Badilisha Ufanisi wa Waendelezaji

## 🎯 Uta Jifunza Nini Katika Mwongozo Huu

Mwongozo huu wa vitendo unaonyesha seva kumi za Microsoft MCP ambazo zinabadilisha jinsi waendelezaji wanavyofanya kazi na wasaidizi wa AI. Badala ya kuelezea tu kile seva za MCP zinazoweza *kufanya*, tutajionyesha seva ambazo tayari zinafanya tofauti halisi katika mwendo wa kazi wa kila siku wa maendeleo huko Microsoft na kwingineko.

Kila seva katika mwongozo huu imechaguliwa kwa kutumia matumizi halisi na maoni ya waendelezaji. Utagundua si tu kile kila seva hufanya, lakini kwa nini ni muhimu na jinsi ya kuitumia vyema katika miradi yako mwenyewe. Iwe wewe ni mgeni kabisa kwa MCP au unatafuta kupanua usanidi uliopo, seva hizi zinaonyesha baadhi ya zana za vitendo na zenye athari kubwa zinazopatikana katika mfumo wa Microsoft.

> **💡 Kidokezo cha Kuanzia Haraka**
>
> Mpya kwa MCP? Usijali! Mwongozo huu umeundwa kuwa rafiki kwa wanaoanza. Tutafafanua dhana tunapoendelea, na unaweza kila wakati kurejea kwenye moduli zetu za [Utangulizi wa MCP](../00-Introduction/README.md) na [Dhana za Msingi](../01-CoreConcepts/README.md) kwa taarifa za kina zaidi.

## Muhtasari

Mwongozo huu kamili unachunguza seva kumi za Microsoft MCP ambazo zinageuza jinsi waendelezaji wanavyoshirikiana na wasaidizi wa AI na zana za nje. Kuanzia usimamizi wa rasilimali za Azure hadi usindikaji wa nyaraka, seva hizi zinaonyesha nguvu za Itifaki ya Muktadha wa Mfano (Model Context Protocol) katika kuunda mid流kazi ya maendeleo yenye ufanisi.

## 🔧 Kuelewa Seva za MCP: Mwongozo kwa Waanzilishi

### Seva za MCP ni Nini?

Kama mgeni kwa Itifaki ya Muktadha wa Mfano (MCP), unaweza kuuliza: "Seva ya MCP ni nini hasa, na kwa nini ni muhimu kwangu?" Hebu tuanze na mfano rahisi.

Fikiria seva za MCP kama wasaidizi maalum wanaosaidia msaidizi wako wa AI wa kuandika msimbo (kama GitHub Copilot) kuunganishwa na zana na huduma za nje. Kama vile unavyotumia programu tofauti kwenye simu yako kwa kazi tofauti — moja kwa hali ya hewa, moja kwa urambazaji, moja kwa benki — seva za MCP zinampa msaidizi wako wa AI uwezo wa kushirikiana na zana na huduma mbalimbali za maendeleo.

### Tatizo Ambalo Seva za MCP Zinatatua

Kabla ya seva za MCP, ikiwa ungetaka:
- Kagua rasilimali zako za Azure
- Tengeneza suala la GitHub
- Uliza katika hifadhidata yako
- Tafuta ndani ya nyaraka

Ilibidi ukome kuandika, ufungue kivinjari, uende kwenye tovuti husika, na ufanye kazi hizo kwa mkono. Kubadilisha muktadha mara kwa mara kwa njia hii huvunja mtiririko wako na kupunguza ufanisi.

### Jinsi Seva za MCP Zinabadilisha Uzoefu Wako wa Maendeleo

Kwa seva za MCP, unaweza kubaki katika mazingira yako ya maendeleo (VS Code, Visual Studio, n.k) na kuomba tu msaidizi wako wa AI kushughulikia kazi hizi. Kwa mfano:

**Badala ya mchakato huu wa jadi:**
1. Koma kuandika msimbo
2. Fungua kivinjari
3. Nenda kwenye lango la Azure
4. Angalia maelezo ya akaunti ya uhifadhi
5. Rudi VS Code
6. Endelea kuandika msimbo

**Sasa unaweza kufanya hivi:**
1. Muulize AI: "Hali ya akaunti zangu za uhifadhi Azure ni ipi?"
2. Endelea kuandika msimbo ukitumia taarifa ulizopata

### Faida Muhimu kwa Waanzilishi

#### 1. 🔄 **Kaa Katika Hali Yako ya Mtiririko**
- Haufanyi marejeleo kati ya programu nyingi tena
- Linda umakini wako kwenye msimbo unaouandika
- Punguza mzigo wa akili wa kusimamia zana tofauti

#### 2. 🤖 **Tumia Lugha Asilia Badala ya Amri Ngumu**
- Badala ya kukumbuka sarufi ya SQL, elezea data unayotaka
- Badala ya kukumbuka amri za Azure CLI, fafanua kile unachotaka kufanikisha
- Acha AI ishughulikie maelezo ya kitaalamu huku ukizingatia mantiki

#### 3. 🔗 **Unganisha Zana Nyingi Pamoja**
- Tengeneza mwendo wa kazi wenye nguvu kwa kuunganisha huduma tofauti
- Mfano: "Pata masuala yote ya hivi majuzi kwenye GitHub na tengeneza vitu vinavyolingana vya kazi vya Azure DevOps"
- Jenga otomatiki bila kuandika skiripti ngumu

#### 4. 🌐 **Pata Ufikiaji wa Mfumo Unaokua**
- Faida kutoka kwa seva zilizotengenezwa na Microsoft, GitHub, na kampuni nyingine
- Changanya na linganisha zana kutoka kwa wauzaji tofauti kwa urahisi
- Jiunge na mfumo ulio sawa unaofanya kazi kwa wasaidizi mbalimbali wa AI

#### 5. 🛠️ **Jifunze Kwa Kufanya**
- Anza na seva zilizojengwa ili kuelewa dhana
- Polepole jenga seva zako mwenyewe unapozoea
- Tumia SDK zilizopo na nyaraka kwa mwongozo wa kujifunza

### Mfano Halisi kwa Waanzilishi

Tuseme wewe ni mgeni kwenye maendeleo ya wavuti na unafanya kazi kwenye mradi wako wa kwanza. Hapa ni jinsi seva za MCP zinavyoweza kusaidia:

**Mbinu ya jadi:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**Kwa seva za MCP:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

- **Kulinda baadaye**: Ujuzi na usanidi hupitishwa kati ya wasaidizi tofauti wa AI

## Kuanzisha MCP katika VS Code na Visual Studio 🚀

Kusanidi seva hizi za MCP ni rahisi ikiwa unatumia Visual Studio Code au Visual Studio 2022 pamoja na GitHub Copilot.

### Usanidi wa VS Code

Hapa ni mchakato wa msingi kwa VS Code:

1. **Washa Hali ya Mwakilishi**: Katika VS Code, badilisha hadi hali ya Mwakilishi kwenye dirisha la Copilot Chat
2. **Sakinisha Seva za MCP**: Ongeza usanidi wa seva kwenye faili la settings.json la VS Code
3. **Anza Seva**: Bonyeza kitufe cha "Anza" kwa kila seva unayotaka kutumia
4. **Chagua Zana**: Chagua seva za MCP unazotaka kufungua kwa kikao chako cha sasa

Kwa maelezo ya kina ya usanidi, angalia [nyaraka za MCP za VS Code](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Kidokezo cha Mtaalamu: Simamia Seva za MCP kama mtaalamu!**
>
> Mwonekano wa Viendelezi wa VS Code sasa unajumuisha [kiolesura kipya cha kusimamia Seva za MCP zilizowekwa](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Una ufikiaji wa haraka wa kuanza, kusitisha, na kusimamia Seva za MCP yoyote iliyowekwa kwa kiolesura safi na rahisi. Jaribu sasa!

### Usanidi wa Visual Studio 2022

Kwa Visual Studio 2022 (toleo 17.14 au baadaye):

1. **Washa Hali ya Mwakilishi**: Bonyeza kidirisha cha "Muulize" kwenye GitHub Copilot Chat kisha chagua "Mwakilishi"
2. **Tengeneza Faili la Usanidi**: Tengeneza faili `.mcp.json` kwenye saraka ya suluhisho lako (mahali kupendekezwa: `<SOLUTIONDIR>\.mcp.json`)
3. **Sanidi Seva**: Ongeza usanidi wa seva zako za MCP kwa kutumia muundo wa MCP uliowekwa
4. **Idhini ya Zana**: Ukipata ombi, ruhusu zana unazotaka kutumia kwa idhini sahihi za upeo

Kwa maelezo ya kina ya usanidi wa Visual Studio, angalia [nyaraka za MCP za Visual Studio](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Kila seva ya MCP ina mahitaji yake ya usanidi (mistringi ya muunganisho, uthibitishaji, n.k), lakini mtindo wa usanidi ni sawa katika IDE zote mbili.

**Inafanya nini**: Seva ya Microsoft Learn Docs MCP ni huduma inayotolewa kwa wingu inayompa msaidizi wa AI ufikiaji wa wakati halisi kwenye nyaraka rasmi za Microsoft kupitia Itifaki ya Muktadha wa Mfano. Inaunganishwa na `https://learn.microsoft.com/api/mcp` na kuwezesha utaftaji wa maana katika Microsoft Learn, nyaraka za Azure, nyaraka za Microsoft 365, na vyanzo vingine rasmi vya Microsoft.

**Kwa nini ni muhimu**: Ingawa inaweza kuonekana kama "nyaraka tu," seva hii ni muhimu sana kwa kila mendelezaji anayetumia teknolojia za Microsoft. Malalamiko makubwa kutoka kwa waendelezaji wa .NET kuhusu wasaidizi wa kuandika msimbo wa AI ni kwamba hawajui tena za sasisho za hivi karibuni za .NET na C#. Seva ya Microsoft Learn Docs MCP inatatua hili kwa kutoa ufikiaji wa wakati halisi wa nyaraka za hivi karibuni, rejea za API, na mbinu bora. Iwe unafanya kazi na SDK mpya za Azure, ukichunguza vipengele vipya vya C# 13, au kutekeleza mbinu za Aspire za kisasa, seva hii inahakikisha msaidizi wako wa AI ana ufikiaji wa taarifa rasmi, za kisasa zinazohitajika kuunda msimbo sahihi na wa kisasa.

**Matumizi halisi**: "Ni amri gani za az cli za kuunda programu ya kontena ya Azure kulingana na nyaraka rasmi za Microsoft Learn?" au "Najeshi gani Entity Framework kwa kutumia utegemezi wa injekshini katika ASP.NET Core?" Au labda "Kagua msimbo huu kuhakikisha unafuata mapendekezo ya utendaji katika Nyaraka za Microsoft Learn." Seva hutoa habari pana kutoka Microsoft Learn, nyaraka za Azure, na nyaraka za Microsoft 365 kwa kutumia utaftaji wa maana wa hali ya juu kupata taarifa zinazohusiana zaidi na muktadha. Inarudisha hadi vipande 10 vya maudhui ya ubora wa juu pamoja na vichwa vya makala na URL, kila mara ikipata nyaraka za hivi karibuni za Microsoft wakati zinachapishwa.

**Mfano ulioangaziwa**: Seva inaonyesha zana ya `microsoft_docs_search` inayofanya utaftaji wa maana dhidi ya nyaraka rasmi za kiufundi za Microsoft. Mara baada ya kusanidiwa, unaweza kuuliza maswali kama "Jinsi gani ya kutekeleza uthibitishaji wa JWT katika ASP.NET Core?" na kupata majibu ya kina, rasmi yenye viungo vya vyanzo. Ubora wa utaftaji ni wa kipekee kwa sababu unaelewa muktadha – kuuliza kuhusu "kontena" katika muktadha wa Azure kutaonyesha nyaraka za Azure Container Instances, wakati neno lile lile katika muktadha wa .NET litatoa taarifa zinazohusiana na mkusanyiko wa C#.

Hii ni muhimu hasa kwa maktaba na matumizi yanayobadilika haraka au ambayo yamebadilishwa hivi karibuni. Kwa mfano, katika baadhi ya miradi ya hivi karibuni ya kuandika msimbo nilitaka kutumia vipengele katika matoleo ya hivi karibuni ya Aspire na Microsoft.Extensions.AI. Kwa kujumuisha seva ya Microsoft Learn Docs MCP, niliweza kutumia si tu nyaraka za API, bali pia maelekezo na mwongozo uliotangazwa hivi karibuni.

### 2. ☁️ Seva ya Azure MCP


[![Install in VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Install in VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Kinachofanya**: Azure MCP Server ni seti kamili ya viunganishaji maalum 15+ vya huduma za Azure vinavyoleta mfumo mzima wa Azure katika mtiririko wako wa kazi wa AI. Hii siyo server moja tu – ni mkusanyiko wenye nguvu unaojumuisha usimamizi wa rasilimali, uunganishaji wa hifadhidata (PostgreSQL, SQL Server), uchambuzi wa kumbukumbu za Azure Monitor kwa kutumia KQL, ujumuishaji wa Cosmos DB, na zaidi.

**Kwa nini ni muhimu**: Zaidi ya kusimamia rasilimali za Azure tu, server hii inaboresha sana ubora wa msimbo wakati wa kufanya kazi na SDK za Azure. Unapotumia Azure MCP katika hali ya Agent, haitasaidia tu kuandika msimbo – inakusaidia kuandika *msimbo bora zaidi* wa Azure unaoifuata mifumo ya uthibitishaji ya sasa, mbinu bora za kushughulikia makosa, na kutumia vipengele vya hivi karibuni vya SDK. Badala ya kupata msimbo wa jumla ambao unaweza kufanya kazi, unapata msimbo unaofuata mifumo inayopendekezwa na Azure kwa mizigo ya uzalishaji.

**Moduli kuu ni pamoja na**:
- **🗄️ Viunganishaji vya Hifadhidata**: Ufikiaji wa lugha asilia moja kwa moja kwa Azure Database kwa PostgreSQL na SQL Server
- **📊 Azure Monitor**: Uchambuzi wa kumbukumbu unaotumia KQL na maarifa ya uendeshaji
- **🌐 Usimamizi wa Rasilimali**: Usimamizi kamili wa mzunguko wa maisha wa rasilimali za Azure
- **🔐 Uthibitishaji**: Mifano ya DefaultAzureCredential na utambulisho unaosimamiwa
- **📦 Huduma za Uhifadhi**: Uendeshaji wa Blob Storage, Queue Storage, na Table Storage
- **🚀 Huduma za Kontena**: Azure Container Apps, Container Instances, na usimamizi wa AKS
- **Na viunganishaji maalum vingi zaidi**

**Matumizi halisi**: "Orodhesha akaunti zangu za uhifadhi za Azure", "Fanya uchunguzi wa Log Analytics workspace kwa makosa katika saa iliyopita", au "Nisaidie kujenga programu ya Azure kwa kutumia Node.js na uthibitishaji sahihi"

**Hali kamili ya maonyesho**: Hapa kuna maelezo kamili yanayoonyesha nguvu ya kuunganisha Azure MCP na ugani wa GitHub Copilot kwa Azure katika VS Code. Unapokuwa na vyote vimewekwa na kuandika:

> "Tengeneza script ya Python inayopakua faili kwenye Azure Blob Storage kwa kutumia uthibitishaji wa DefaultAzureCredential. Script hiyo inapaswa kuunganishwa na akaunti yangu ya uhifadhi ya Azure inayoitwa 'mycompanystorage', ipakishe kwenye kontena linaloitwa 'documents', tengeneza faili ya majaribio yenye alama ya muda wa sasa ya kupakia, shughulikia makosa kwa tahadhari na toa taarifa ya maana, ifuate mbinu bora za Azure kwa uthibitishaji na utatuzi wa makosa, jumuisha maelezo yanayobainisha jinsi uthibitishaji wa DefaultAzureCredential unavyofanya kazi, na fanya script iwe na muundo mzuri na kazi sahihi pamoja na nyaraka."

Azure MCP Server itazalisha script kamili ya Python tayari kwa uzalishaji ambayo:
- Inatumia SDK ya hivi karibuni ya Azure Blob Storage kwa mifumo sahihi ya async
- Inatekeleza DefaultAzureCredential pamoja na maelezo ya mnyororo kamili wa mbadala
- Inajumuisha utatuzi madhubuti wa makosa kwa aina maalum za makosa ya Azure
- Inafuata mbinu bora za SDK za Azure kwa usimamizi wa rasilimali na usimamizi wa muunganisho
- Inatoa kumbukumbu za kina na taarifa za maana kwenye consola
- Inaunda script yenye muundo mzuri na kazi, nyaraka, na vidokezo vya aina

Kinachofanya hili kuwa cha kushangaza ni kwamba bila Azure MCP, unaweza kupata msimbo wa kawaida wa kuhifadhi blob ambao unaweza kufanya kazi lakini haufuati mifumo ya sasa ya Azure. Kwa Azure MCP, unapata msimbo unaotumia mbinu mpya za uthibitishaji, unashughulikia hali maalum za makosa za Azure, na unafuata mbinu iliyopendekezwa na Microsoft kwa programu za uzalishaji.

**Mfano wa kuangazia**: Nimeshindwa kukumbuka amri maalum za `az` na `azd` kwa matumizi ya mara moja. Daima ni mchakato wa hatua mbili kwangu: kwanza angalia muundo wa amri, kisha endesha amri. Mara nyingi mimi huingia tu kwenye portal na kubofya sehemu za kufanya kazi kwa sababu sitaki kukiri kuwa siwezi kukumbuka muundo wa amri wa CLI. Kuwa na uwezo wa kuelezea tu ninachotaka ni ajabu, na bora zaidi ni kuwa na uwezo wa kufanya hivyo bila kuondoka kwenye IDE yangu!

Kuna orodha nzuri ya matumizi katika [Azure MCP repository](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) kuanzia sasa. Kwa miongozo kamili ya usanidi na chaguzi za usanidi wa hali ya juu, angalia [nyaraka rasmi za Azure MCP](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

**Kinachofanya**: Server rasmi ya GitHub MCP hutoa muunganiko wa moja kwa moja na mfumo mzima wa GitHub, ikitoa ufikiaji wa mbali unao hifadhiwa pamoja na chaguzi za usambazaji wa ndani kwa kutumia Docker. Hii siyo tu kuhusu shughuli za msingi za hazina – ni zana kamili inayojumuisha usimamizi wa GitHub Actions, mtiririko wa kazi za pull request, ufuatiliaji wa masuala, uchunguzi wa usalama, arifa, na uwezo wa automatiska wa hali ya juu.

**Kwa nini ni muhimu**: Server hii inabadilisha jinsi unavyoshirikiana na GitHub kwa kuleta uzoefu kamili wa jukwaa moja kwa moja katika mazingira yako ya maendeleo. Badala ya kubadilisha mara kwa mara kati ya VS Code na GitHub.com kwa usimamizi wa miradi, ukaguzi wa msimbo, na ufuatiliaji wa CI/CD, unaweza kushughulikia kila kitu kupitia amri za lugha asilia huku ukiwa umejitahidi kwenye msimbo wako.

> **ℹ️ Kumbuka: Aina Mbili za 'Wakili'**
>
> Usichanganye GitHub MCP Server hii na GitHub Coding Agent (wakili wa AI unayeweza kuteuliwa kwa masuala kwa kazi za automatiska za uandishi wa msimbo). GitHub MCP Server hufanya kazi ndani ya hali ya Agent ya VS Code kutoa muunganisho wa GitHub API, wakati GitHub Coding Agent ni kipengele kingine kinachounda pull requests wakati kinapopewa masuala ya GitHub.

**Uwezo kuu ni pamoja na**:
- **⚙️ GitHub Actions**: Usimamizi kamili wa mizunguko ya CI/CD, ufuatiliaji wa mtiririko wa kazi, na uendeshaji wa artifacts
- **🔀 Pull Requests**: Tengeneza, hakiki, muungano, na usimamizi wa PRs pamoja na ufuatiliaji kamili wa hali
- **🐛 Masuala**: Usimamizi kamili wa mzunguko wa maisha wa masuala, maoni, uwekaji lebo, na uteuzi
- **🔒 Usalama**: Tahadhari za skanning ya msimbo, ugunduzi wa siri, na ujumuishaji wa Dependabot
- **🔔 Arifa**: Usimamizi wa arifa za akili na udhibiti wa usajili wa hazina
- **📁 Usimamizi wa Hazina**: Shughuli za faili, usimamizi wa matawi, na usimamizi wa hazina
- **👥 Ushirikiano**: Utafutaji wa watumiaji na mashirika, usimamizi wa timu, na udhibiti wa ufikiaji

**Matumizi halisi**: "Tengeneza pull request kutoka tawi langu la kipengele", "Nionyeshe mbio zote za CI zilizoshindwa wiki hii", "Orodhesha tahadhari zote za usalama kwa hazina zangu", au "Tafuta masuala yote yaliyoniambatisha katika mashirika yangu"

**Hali kamili ya maonyesho**: Hapa kuna mtiririko mwenye nguvu unaoonyesha uwezo wa GitHub MCP Server:

> "Nahitaji kujiandaa kwa ukaguzi wetu wa sprint. Nionyeshe pull requests zote nilizotengeneza wiki hii, angalia hali ya mizunguko ya CI/CD, tengeneza muhtasari wa tahadhari zozote za usalama tunazohitaji kushughulikia, na nisaidie kuandika vidokezo vya toleo kulingana na PR zilizounganishwa zenye lebo ya 'feature'."

GitHub MCP Server itafanya:
- Kufanya uchunguzi wa pull requests zako za hivi karibuni zikiwa na taarifa za kina za hali
- Kuchambua mbio za mtiririko wa kazi na kuangazia kushindwa au matatizo ya utendaji yoyote
- Kukusanya matokeo ya uchunguzi wa usalama na kuipa kipaumbele tahadhari muhimu
- Kutengeneza vidokezo kamili vya toleo kwa kutoa taarifa kutoka kwa PR zilizounganishwa

**Mfano wa kuangazia**: Napenda kutumia hii kwa mtiririko wa kazi za ukaguzi wa msimbo. Badala ya kuruka kati ya VS Code, arifa za GitHub, na kurasa za pull request, naweza kusema "Nionyeshe PR zote zinazosubiri ukaguzi wangu" kisha "Ongeza maoni kwa PR #123 kuuliza kuhusu utatuzi wa makosa katika njia ya uthibitishaji." **Chaguzi za Uthibitishaji**: Server inaunga mkono OAuth (mwenye mwendo mzuri ndani ya VS Code) na Personal Access Tokens, na seti za zana zinazoweza kusanidiwa kuwezesha tu kazi za GitHub unazohitaji. Unaweza kuendesha kama huduma iliyo hifadhiwa kwa mbali kwa usanidi wa papo hapo au ndani ya Docker kwa udhibiti kamili.

> **💡 Ushauri wa Mtaalamu**

**Matumizi halisi ya mvamizi**: "Telekeza modeli ya Phi-4 kwa Huduma za Azure AI kwa ajili ya programu yangu", "Tengeneza orodha mpya ya utafutaji kwa mfumo wangu wa RAG wa nyaraka", "Tathmini majibu ya wakilangu kupima ubora", au "Tafuta modeli bora ya kufikiri kwa kazi zangu ngumu za uchambuzi"

**Mzunguko kamili wa onyesho**: Hapa kuna mtiririko wenye nguvu wa maendeleo ya AI:

> "Ninajenga wakala wa msaada kwa wateja. Nisaidie kutafuta modeli nzuri ya kufikiri kutoka katalogi, telekeza kwa Huduma za Azure AI, tengeneza msingi wa maarifa kutoka kwa nyaraka zetu, weka mfumo wa tathmini kupima ubora wa majibu, kisha nisaidie kuanzisha uingizaji na tokeni ya GitHub kwa majaribio."

Server ya Microsoft Foundry MCP itafanya:
- Uliza katalogi ya modeli kupendekeza modeli bora za kufikiri kulingana na mahitaji yako
- Toa amri za utekelezaji na taarifa za ukubwa wa matumizi kwa eneo lako unalotaka la Azure
- Panga viorodheshaji vya Azure AI Search na muundo sahihi kwa nyaraka zako
- Panga njia za tathmini kwa kutumia vipimo vya ubora na ukaguzi wa usalama
- Tengeneza msimbo wa uingizaji pamoja na uhakiki wa GitHub kwa majaribio ya haraka
- Toa miongozo kamili ya usanidi inayolingana na teknolojia yako maalum

**Mfano wa kujitokeza**: Kama mvumbuzi, nimekuwa nikiteseka kufuatilia modeli tofauti za LLM zinazopatikana. Najua chache kuu, lakini nimekuwa nikihisi kama nampoteza faida fulani za uzalishaji na ufanisi. Na tokeni na ukubwa wa matumizi ni changamoto na ni vigumu kusimamia – sioni kama ninachagua modeli sahihi kwa kazi sahihi au kuchoma bajeti yangu kwa ufanisi mdogo. Nilisikia kuhusu MCP Server hii kutoka kwa James Montemagno wakati nilikuwa nikizungumza na wenzangu kuhusu mapendekezo ya MCP Server kwa chapisho hili, na nina hamu ya kuitumia! Uwezo wa kugundua modeli unaonekana wa kushangaza kwa mtu kama mimi anayetaka kuchunguza zaidi ya zinazojulikana kiasi na kupata modeli zilizo optimized kwa kazi maalum. Mfumo wa tathmini unapaswa kunisaidia kuthibitisha kwamba ninapata matokeo bora kweli, siyo tu kujaribu kitu kipya kwa sababu tu.

> **ℹ️ Hali ya Majaribio**

> Server hii ya MCP ni ya majaribio na inazidi kuendelezwa. Vipengele na API zinaweza kubadilika. Ni bora kwa kuchunguza uwezo wa Azure AI na kujenga prototypes, lakini hakikisha unathibitisha uthabiti kwa matumizi ya uzalishaji.

## 📋 Hitimisho

Itifaki ya Muktadha wa Modeli (MCP) inabadilisha jinsi wavamizi wanavyoshirikiana na wasaidizi wa AI na zana za nje. Server hizi 10 za Microsoft MCP zinaonyesha nguvu ya ushirikiano uliosawazishwa wa AI, kuwezesha mitiririko ya kazi isiyo na mshono inayowaweka wavamizi katika hali ya mtiririko wao wakati wakipata uwezo mkubwa wa nje.

Kuanzia ushirikiano wa kina wa mazingira ya Azure hadi zana maalum kama Playwright kwa uendeshaji wa vivinjari na MarkItDown kwa usindikaji wa nyaraka, server hizi zinaonyesha jinsi MCP inavyoweza kuongeza uzalishaji katika hali mbalimbali za maendeleo. Itifaki iliyo sanifu inahakikisha kuwa zana hizi zinas working pamoja kwa urahisi, kuunda uzoefu wa maendeleo wa mshikamano.

Wakati mazingira ya MCP yanaendelea kubadilika, kuendelea kushiriki na jamii, kuchunguza server mpya, na kujenga suluhisho za desturi kutakuwa kazi kuu ya kuongeza uzalishaji wako wa maendeleo. Asili ya wazi ya MCP ina maana unaweza kuchanganya na kuoanisha zana kutoka wauzaji tofauti kuunda mtiririko mzuri wa kazi kulingana na mahitaji yako maalum.
