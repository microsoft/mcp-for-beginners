## 🔧 Entendiendo los servidores MCP: guía para principiantes

### ¿Qué son los servidores MCP?

Como principiante en el Protocolo de Contexto de Modelos (MCP), podrías preguntarte: "¿Qué es exactamente un servidor MCP y por qué debería importarme?" Comencemos con una analogía simple.

Piensa en los servidores MCP como asistentes especializados que ayudan a tu compañero de codificación con IA (como GitHub Copilot) a conectarse con herramientas y servicios externos. Al igual que usas diferentes aplicaciones en tu teléfono para distintas tareas —una para el clima, otra para navegación, otra para banca— los servidores MCP permiten que tu asistente de IA interactúe con diferentes herramientas y servicios de desarrollo.

### El problema que resuelven los servidores MCP

Antes de los servidores MCP, si querías:
- Consultar tus recursos de Azure
- Crear un issue en GitHub
- Consultar tu base de datos
- Buscar en la documentación

Tenías que dejar de programar, abrir un navegador, ir al sitio web correcto y hacer estas tareas manualmente. Este cambio constante de contexto rompe tu flujo y reduce la productividad.

### Cómo los servidores MCP transforman tu experiencia de desarrollo

Con los servidores MCP, puedes permanecer en tu entorno de desarrollo (VS Code, Visual Studio, etc.) y simplemente pedirle a tu asistente de IA que maneje estas tareas. Por ejemplo:

**En lugar de este flujo de trabajo tradicional:**
1. Dejar de programar
2. Abrir el navegador
3. Navegar al portal de Azure
4. Buscar detalles de la cuenta de almacenamiento
5. Volver a VS Code
6. Reanudar la programación

**Ahora puedes hacer esto:**
1. Preguntar a la IA: "¿Cuál es el estado de mis cuentas de almacenamiento en Azure?"
2. Continuar programando con la información proporcionada

### Beneficios clave para principiantes

#### 1. 🔄 **Permanece en tu estado de flujo**
- No más cambios entre múltiples aplicaciones
- Mantén tu enfoque en el código que escribes
- Reduce la carga mental de manejar diferentes herramientas

#### 2. 🤖 **Usa lenguaje natural en lugar de comandos complejos**
- En lugar de memorizar sintaxis SQL, describe qué datos necesitas
- En lugar de recordar comandos de Azure CLI, explica lo que quieres lograr
- Deja que la IA maneje los detalles técnicos mientras tú te concentras en la lógica

#### 3. 🔗 **Conecta múltiples herramientas juntas**
- Crea flujos de trabajo poderosos combinando diferentes servicios
- Ejemplo: "Obtén todos los issues recientes de GitHub y crea elementos de trabajo correspondientes en Azure DevOps"
- Construye automatizaciones sin escribir scripts complejos

#### 4. 🌐 **Accede a un ecosistema en crecimiento**
- Benefíciate de servidores creados por Microsoft, GitHub y otras compañías
- Mezcla y combina herramientas de diferentes proveedores sin problema
- Únete a un ecosistema estandarizado que funciona con diferentes asistentes de IA

#### 5. 🛠️ **Aprende haciendo**
- Comienza con servidores preconstruidos para entender los conceptos
- Construye gradualmente tus propios servidores a medida que te sientes más cómodo
- Usa los SDKs disponibles y la documentación para guiar tu aprendizaje

### Ejemplo real para principiantes

Supongamos que eres nuevo en el desarrollo web y estás trabajando en tu primer proyecto. Así es como los servidores MCP pueden ayudar:

**Enfoque tradicional:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**Con servidores MCP:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

## Comenzando con MCP en VS Code y Visual Studio 🚀

Configurar estos servidores MCP es sencillo si usas Visual Studio Code o Visual Studio 2022 con GitHub Copilot.

### Configuración en VS Code

Este es el proceso básico para VS Code:

1. **Habilita el modo Agente**: En VS Code, cambia al modo Agente en la ventana de Copilot Chat
2. **Configura los servidores MCP**: Añade configuraciones de servidor en tu archivo settings.json de VS Code
3. **Inicia los servidores**: Haz clic en el botón "Start" para cada servidor que quieras usar
4. **Selecciona herramientas**: Elige qué servidores MCP habilitar para tu sesión actual

Para instrucciones detalladas de configuración, consulta la [documentación MCP para VS Code](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Consejo profesional: ¡Gestiona servidores MCP como un experto!**
> 
> La vista de Extensiones en VS Code ahora incluye una [nueva y útil interfaz para gestionar servidores MCP instalados](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode). Tienes acceso rápido para iniciar, detener y gestionar cualquier servidor MCP instalado con una interfaz clara y sencilla. ¡Pruébalo!

### Configuración en Visual Studio 2022

Para Visual Studio 2022 (versión 17.14 o superior):

1. **Habilita el modo Agente**: Haz clic en el menú desplegable "Ask" en la ventana de GitHub Copilot Chat y selecciona "Agent"
2. **Crea el archivo de configuración**: Crea un archivo `.mcp.json` en el directorio de tu solución (ubicación recomendada: `<SOLUTIONDIR>\.mcp.json`)
3. **Configura los servidores**: Añade configuraciones de tus servidores MCP usando el formato estándar MCP
4. **Aprobación de herramientas**: Cuando se solicite, aprueba las herramientas que deseas usar con los permisos de alcance apropiados

Para instrucciones detalladas de configuración en Visual Studio, consulta la [documentación MCP para Visual Studio](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Cada servidor MCP tiene sus propios requisitos de configuración (cadenas de conexión, autenticación, etc.), pero el patrón de configuración es consistente en ambos IDEs.

### 1. 📚 Servidor Microsoft Learn Docs MCP

[![Instalar en VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![Instalar en VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**Qué hace**: El servidor Microsoft Learn Docs MCP es un servicio alojado en la nube que proporciona a los asistentes de IA acceso en tiempo real a la documentación oficial de Microsoft a través del Protocolo de Contexto de Modelos. Se conecta a `https://learn.microsoft.com/api/mcp` y permite búsqueda semántica a lo largo de Microsoft Learn, documentación de Azure, documentación de Microsoft 365 y otras fuentes oficiales de Microsoft.

**Por qué es útil**: Aunque parezca "solo documentación", este servidor es crucial para cada desarrollador que usa tecnologías Microsoft. Una de las quejas más comunes de los desarrolladores .NET sobre los asistentes de codificación con IA es que no están actualizados con las últimas versiones de .NET y C#. El servidor Microsoft Learn Docs MCP resuelve esto al proporcionar acceso en tiempo real a la documentación más actual, referencias de API y mejores prácticas. Ya sea que trabajes con los SDKs más recientes de Azure, explores nuevas características de C# 13 o implementes patrones avanzados Aspire, este servidor asegura que tu asistente de IA tenga acceso a la información autorizada y actualizada necesaria para generar código preciso y moderno.

**Uso en el mundo real**: "¿Cuáles son los comandos az cli para crear una aplicación contenedor de Azure según la documentación oficial de Microsoft Learn?" o "¿Cómo configuro Entity Framework con inyección de dependencias en ASP.NET Core?" O qué tal "Revisa este código para asegurarte de que cumple con las recomendaciones de rendimiento de la documentación Microsoft Learn." El servidor ofrece cobertura completa a través de Microsoft Learn, docs de Azure y documentación Microsoft 365 usando búsqueda semántica avanzada para encontrar la información más relevante contextualmente. Devuelve hasta 10 fragmentos de contenido de alta calidad con títulos de artículos y URLs, siempre accediendo a la documentación Microsoft más reciente al momento de publicar.

**Ejemplo destacado**: El servidor expone la herramienta `microsoft_docs_search` que realiza búsquedas semánticas contra la documentación técnica oficial de Microsoft. Una vez configurado, puedes hacer preguntas como "¿Cómo implemento autenticación JWT en ASP.NET Core?" y obtener respuestas detalladas y oficiales con enlaces a la fuente. La calidad de búsqueda es excepcional porque entiende el contexto: preguntar por "contenedores" en un contexto de Azure devuelve documentación de Azure Container Instances, mientras el mismo término en contexto .NET devuelve información relevante de colecciones en C#.

Esto es especialmente útil para bibliotecas y casos de uso que cambian rápidamente o que han sido actualizados recientemente. Por ejemplo, en proyectos recientes quería aprovechar características en las últimas versiones de Aspire y Microsoft.Extensions.AI. Incluyendo el servidor Microsoft Learn Docs MCP, pude aprovechar no solo la documentación de API, sino también guías y tutoriales que se habían publicado justo entonces.

> **💡 Consejo profesional**

Considera añadir un prompt de sistema o [copilot-instructions.md](https://docs.github.com/copilot/how-tos/custom-instructions/adding-repository-custom-instructions-for-github-copilot) como: "Tienes acceso a `microsoft.docs.mcp` – usa esta herramienta para buscar la documentación oficial Microsoft más reciente cuando manejes preguntas sobre tecnologías Microsoft como C#, Azure, ASP.NET Core o Entity Framework."
>

### 2. ☁️ Servidor Azure MCP


[![Instalar en VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Instalar en VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Qué hace**: El Azure MCP Server es un conjunto integral de más de 15 conectores especializados para servicios de Azure que trae todo el ecosistema de Azure a tu flujo de trabajo de IA. No es solo un servidor único: es una colección poderosa que incluye gestión de recursos, conectividad de bases de datos (PostgreSQL, SQL Server), análisis de registros de Azure Monitor con KQL, integración con Cosmos DB, y mucho más.

**Por qué es útil**: Más allá de simplemente administrar recursos de Azure, este servidor mejora dramáticamente la calidad del código cuando trabajas con los SDKs de Azure. Cuando usas Azure MCP en modo Agente, no solo te ayuda a escribir código, sino que te ayuda a escribir *mejor* código para Azure que sigue los patrones actuales de autenticación, las mejores prácticas de manejo de errores y aprovecha las últimas funcionalidades del SDK. En lugar de obtener código genérico que podría funcionar, obtienes código que sigue los patrones recomendados por Azure para cargas de trabajo en producción.

**Los módulos clave incluyen**:
- **🗄️ Conectores de Bases de Datos**: Acceso directo en lenguaje natural a Azure Database para PostgreSQL y SQL Server
- **📊 Azure Monitor**: Análisis de registros potenciado por KQL e información operativa
- **🌐 Gestión de Recursos**: Gestión completa del ciclo de vida de recursos de Azure
- **🔐 Autenticación**: DefaultAzureCredential y patrones de identidad gestionada
- **📦 Servicios de Almacenamiento**: Operaciones en Blob Storage, Queue Storage y Table Storage
- **🚀 Servicios de Contenedores**: Azure Container Apps, Container Instances y gestión de AKS
- **Y muchos más conectores especializados**

**Uso en el mundo real**: "Lista mis cuentas de almacenamiento de Azure", "Consulta mi espacio de trabajo de Log Analytics para errores en la última hora", o "Ayúdame a construir una aplicación Azure usando Node.js con autenticación apropiada"

**Escenario de demostración completo**: Aquí tienes un recorrido completo que muestra el poder de combinar Azure MCP con la extensión GitHub Copilot for Azure en VS Code. Cuando tienes ambos instalados y solicitas:

> "Crea un script en Python que suba un archivo a Azure Blob Storage usando la autenticación DefaultAzureCredential. El script debe conectarse a mi cuenta de almacenamiento Azure llamada 'mycompanystorage', subir a un contenedor llamado 'documents', crear un archivo de prueba con la marca de tiempo actual para subirlo, manejar errores de manera elegante y proporcionar salida informativa, seguir las mejores prácticas de Azure para autenticación y manejo de errores, incluir comentarios explicando cómo funciona la autenticación DefaultAzureCredential, y hacer que el script esté bien estructurado con funciones adecuadas y documentación."

El Azure MCP Server generará un script completo en Python listo para producción que:
- Usa el SDK más reciente de Azure Blob Storage con patrones async apropiados
- Implementa DefaultAzureCredential con una explicación completa de la cadena de respaldo
- Incluye manejo robusto de errores con tipos específicos de excepciones de Azure
- Sigue las mejores prácticas del SDK de Azure para gestión de recursos y manejo de conexiones
- Proporciona registros detallados y salida informativa en consola
- Crea un script correctamente estructurado con funciones, documentación y sugerencias de tipos

Lo que hace esto notable es que sin Azure MCP, podrías obtener código genérico para almacenamiento de blobs que funciona pero no sigue los patrones actuales de Azure. Con Azure MCP, obtienes código que aprovecha los métodos de autenticación más recientes, maneja escenarios específicos de errores de Azure y sigue las prácticas recomendadas por Microsoft para aplicaciones en producción.

**Ejemplo destacado**: He tenido dificultades para recordar los comandos específicos de las CLI `az` y `azd` para uso ad-hoc. Siempre es un proceso de dos pasos para mí: primero buscar la sintaxis y luego ejecutar el comando. A menudo solo entro al portal y hago clic para completar el trabajo porque no quiero admitir que no recuerdo la sintaxis de la CLI. Poder describir simplemente lo que quiero es increíble, y aún mejor poder hacerlo sin salir de mi IDE.

Hay una gran lista de casos de uso en el [repositorio de Azure MCP](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) para ayudarte a comenzar. Para guías de configuración completas y opciones avanzadas de configuración, consulta la [documentación oficial de Azure MCP](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

### 3. 🐙 GitHub MCP Server

[![Instalar en VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Instalar en VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**Qué hace**: El GitHub MCP Server oficial ofrece integración perfecta con todo el ecosistema de GitHub, ofreciendo tanto acceso remoto alojado como opciones de despliegue local con Docker. No se trata solo de operaciones básicas de repositorios, sino de un conjunto completo de herramientas que incluye gestión de GitHub Actions, flujos de trabajo de pull request, seguimiento de issues, escaneo de seguridad, notificaciones y capacidades avanzadas de automatización.

**Por qué es útil**: Este servidor transforma la manera en que interactúas con GitHub al traer toda la experiencia de la plataforma directamente a tu entorno de desarrollo. En lugar de cambiar constantemente entre VS Code y GitHub.com para gestión de proyectos, revisiones de código y monitoreo de CI/CD, puedes manejar todo mediante comandos en lenguaje natural manteniendo el enfoque en tu código.

> **ℹ️ Nota: Diferentes Tipos de 'Agentes'**
> 
> No confundas este GitHub MCP Server con el Agente de Codificación de GitHub (el agente de IA al que puedes asignar issues para tareas codificadas automáticas). El GitHub MCP Server funciona dentro del modo Agente de VS Code para proporcionar integración con la API de GitHub, mientras que el Agente de Codificación de GitHub es una función separada que crea pull requests cuando se le asignan issues de GitHub.

**Capacidades clave incluyen**:
- **⚙️ GitHub Actions**: Gestión completa de pipelines CI/CD, monitoreo de flujos de trabajo y manejo de artefactos
- **🔀 Pull Requests**: Crear, revisar, fusionar y gestionar PRs con seguimiento completo de estados
- **🐛 Issues**: Gestión completa del ciclo de vida de issues, comentarios, etiquetado y asignaciones
- **🔒 Seguridad**: Alertas de escaneo de código, detección de secretos e integración con Dependabot
- **🔔 Notificaciones**: Gestión inteligente de notificaciones y control de suscripción de repositorios
- **📁 Gestión de Repositorios**: Operaciones de archivos, gestión de ramas y administración de repositorios
- **👥 Colaboración**: Búsqueda de usuarios y organizaciones, gestión de equipos y control de acceso

**Uso en el mundo real**: "Crear un pull request desde mi rama de características", "Muéstrame todas las ejecuciones CI fallidas esta semana", "Lista las alertas de seguridad abiertas para mis repositorios", o "Encuentra todos los issues asignados a mí en mis organizaciones"

**Escenario de demostración completo**: Aquí tienes un flujo poderoso que demuestra las capacidades del GitHub MCP Server:

> "Necesito prepararme para nuestra revisión de sprint. Muéstrame todos los pull requests que he creado esta semana, verifica el estado de nuestras pipelines CI/CD, crea un resumen de cualquier alerta de seguridad que necesitemos abordar, y ayúdame a redactar las notas de la versión basadas en PRs fusionados con la etiqueta 'feature'."

El GitHub MCP Server:
- Consulta tus pull requests recientes con información detallada de estado
- Analiza las ejecuciones de flujo de trabajo y destaca fallos o problemas de rendimiento
- Compila resultados de escaneo de seguridad y prioriza alertas críticas
- Genera notas de la versión completas extrayendo información de PRs fusionados
- Proporciona próximos pasos accionables para planificación de sprint y preparación de lanzamientos

**Ejemplo destacado**: Me encanta usar esto para flujos de trabajo de revisión de código. En lugar de saltar entre VS Code, notificaciones de GitHub y páginas de pull request, puedo decir "Muéstrame todos los PRs esperando mi revisión" y luego "Agrega un comentario al PR #123 preguntando sobre el manejo de errores en el método de autenticación." El servidor maneja las llamadas a la API de GitHub, mantiene el contexto sobre la discusión e incluso me ayuda a redactar comentarios de revisión más constructivos.

**Opciones de autenticación**: El servidor soporta tanto OAuth (de manera transparente en VS Code) como Personal Access Tokens, con conjuntos de herramientas configurables para habilitar solo la funcionalidad de GitHub que necesitas. Puedes ejecutarlo como un servicio remoto alojado para una configuración instantánea o localmente vía Docker para control completo.

> **💡 Consejo profesional**
> 
> Habilita solo los conjuntos de herramientas que necesitas configurando el parámetro `--toolsets` en la configuración de tu servidor MCP para reducir el tamaño del contexto y mejorar la selección de herramientas de IA. Por ejemplo, añade `"--toolsets", "repos,issues,pull_requests,actions"` a los argumentos de configuración de tu MCP para flujos de trabajo de desarrollo principales, o usa `"--toolsets", "notifications, security"` si principalmente deseas capacidades de monitoreo de GitHub.

**Qué hace**: MarkItDown es un servidor completo de conversión de documentos que transforma varios formatos de archivo en Markdown de alta calidad, optimizado para el consumo por LLM y flujos de trabajo de análisis de texto.

**Por qué es útil**: ¡Esencial para flujos de trabajo modernos de documentación! MarkItDown maneja una impresionante variedad de formatos de archivo mientras preserva la estructura crítica del documento como encabezados, listas, tablas y enlaces. A diferencia de las herramientas simples de extracción de texto, se enfoca en mantener el significado semántico y el formato que son valiosos tanto para el procesamiento por IA como para la legibilidad humana.

**Formatos de archivo compatibles**:
- **Documentos Office**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Archivos multimedia**: Imágenes (con metadatos EXIF y OCR), Audio (con metadatos EXIF y transcripción de voz)
- **Contenido web**: HTML, feeds RSS, URLs de YouTube, páginas de Wikipedia
- **Formatos de datos**: CSV, JSON, XML, archivos ZIP (procesa recursivamente el contenido)
- **Formatos para publicación**: EPub, notebooks Jupyter (.ipynb)
- **Correo electrónico**: Mensajes de Outlook (.msg)
- **Avanzado**: Integración con Azure Document Intelligence para procesamiento mejorado de PDF

**Capacidades avanzadas**: MarkItDown soporta descripciones de imágenes impulsadas por LLM (cuando se proporciona un cliente OpenAI), Azure Document Intelligence para un procesamiento mejorado de PDFs, transcripción de audio para contenido de voz y un sistema de plugins para extenderse a formatos adicionales.

**Uso real**: "Convertir esta presentación de PowerPoint a Markdown para nuestro sitio de documentación", "Extraer texto de este PDF con la estructura correcta de encabezados" o "Transformar esta hoja de Excel en un formato de tabla legible"

**Ejemplo destacado**: Para citar la [documentación de MarkItDown](https://github.com/microsoft/markitdown#why-markdown):

> Markdown está extremadamente cerca del texto plano, con una mínima marca o formato, pero aún proporciona una manera de representar estructuras importantes del documento. Los LLMs principales, como GPT-4o de OpenAI, "hablan" Markdown nativamente, y a menudo incorporan Markdown en sus respuestas sin que se lo pidan. Esto sugiere que han sido entrenados con grandes cantidades de texto formateado en Markdown y lo entienden bien. Como beneficio adicional, las convenciones Markdown también son altamente eficientes en tokens.

MarkItDown es muy bueno preservando la estructura del documento, lo cual es importante para flujos de trabajo con IA. Por ejemplo, al convertir una presentación de PowerPoint, mantiene la organización de diapositivas con los encabezados adecuados, extrae tablas como tablas Markdown, incluye texto alternativo para imágenes e incluso procesa las notas del presentador. Los gráficos se convierten en tablas de datos legibles, y el Markdown resultante mantiene el flujo lógico de la presentación original. Esto lo hace perfecto para alimentar contenido de presentaciones a sistemas de IA o crear documentación a partir de diapositivas existentes.
