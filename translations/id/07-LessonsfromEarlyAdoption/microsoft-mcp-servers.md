## 🔧 Memahami Server MCP: Panduan untuk Pemula

### Apa Itu Server MCP?

Sebagai pemula di Model Context Protocol (MCP), Anda mungkin bertanya-tanya: "Apa sebenarnya server MCP itu, dan mengapa saya harus peduli?" Mari mulai dengan analogi sederhana.

Pikirkan server MCP sebagai asisten khusus yang membantu pendamping kode AI Anda (seperti GitHub Copilot) terhubung ke alat dan layanan eksternal. Sama seperti Anda mungkin menggunakan aplikasi berbeda di ponsel Anda untuk tugas berbeda — satu untuk cuaca, satu untuk navigasi, satu untuk perbankan — server MCP memberikan kemampuan asisten AI Anda untuk berinteraksi dengan alat dan layanan pengembangan berbeda.

### Masalah yang Diselesaikan Server MCP

Sebelum ada server MCP, jika Anda ingin:
- Memeriksa sumber daya Azure Anda
- Membuat masalah GitHub
- Menanyakan basis data Anda
- Mencari dokumentasi

Anda harus berhenti mengoding, membuka browser, mengunjungi website yang sesuai, dan melakukan tugas tersebut secara manual. Pergantian konteks yang terus menerus ini memutus alur Anda dan mengurangi produktivitas.

### Bagaimana Server MCP Mengubah Pengalaman Pengembangan Anda

Dengan server MCP, Anda bisa tetap di lingkungan pengembangan Anda (VS Code, Visual Studio, dll.) dan cukup minta asisten AI Anda mengerjakan tugas-tugas ini. Misalnya:

**Alih-alih alur kerja tradisional ini:**
1. Berhenti mengoding
2. Buka browser
3. Buka portal Azure
4. Cari detail akun penyimpanan
5. Kembali ke VS Code
6. Lanjutkan mengoding

**Anda sekarang bisa melakukan ini:**
1. Tanyakan ke AI: "Apa status akun penyimpanan Azure saya?"
2. Lanjut mengoding dengan informasi yang diberikan

### Manfaat Utama untuk Pemula

#### 1. 🔄 **Tetap Dalam Alur Kerja Anda**
- Tidak perlu berganti antar aplikasi
- Fokus tetap pada kode yang Anda tulis
- Kurangi beban mental dalam mengelola berbagai alat

#### 2. 🤖 **Gunakan Bahasa Alami daripada Perintah Rumit**
- Daripada menghapal sintaks SQL, jelaskan data apa yang Anda butuhkan
- Daripada mengingat perintah Azure CLI, jelaskan apa yang ingin Anda capai
- Biarkan AI mengurus detail teknis sementara Anda fokus pada logika

#### 3. 🔗 **Hubungkan Beberapa Alat Secara Bersama**
- Buat alur kerja yang kuat dengan menggabungkan layanan berbeda
- Contoh: "Ambil semua masalah GitHub terbaru dan buat item kerja Azure DevOps yang sesuai"
- Bangun otomatisasi tanpa membuat skrip rumit

#### 4. 🌐 **Akses Ekosistem yang Berkembang**
- Manfaatkan server yang dibuat oleh Microsoft, GitHub, dan perusahaan lain
- Gabungkan alat dari berbagai vendor secara mulus
- Bergabung dengan ekosistem standar yang bekerja di banyak asisten AI

#### 5. 🛠️ **Belajar dengan Praktik**
- Mulai dengan server yang sudah jadi untuk memahami konsep
- Secara bertahap buat server Anda sendiri saat semakin nyaman
- Gunakan SDK dan dokumentasi yang tersedia untuk memandu pembelajaran Anda


### Keunggulan Standar Perusahaan

MCP menjadi standar industri, yang berarti:
- **Konsistensi**: Pengalaman seragam di berbagai alat dan perusahaan

- **Daya Tahan Masa Depan**: Keahlian dan pengaturan dapat dipindahkan antar asisten AI
- **Komunitas**: Ekosistem besar dengan pengetahuan dan sumber daya bersama

## Memulai dengan MCP di VS Code dan Visual Studio 🚀

Pengaturan server MCP ini mudah jika Anda menggunakan Visual Studio Code atau Visual Studio 2022 dengan GitHub Copilot.

### Pengaturan VS Code

Berikut proses dasar untuk VS Code:

1. **Aktifkan Mode Agen**: Di VS Code, pindah ke mode Agen di jendela Copilot Chat
2. **Konfigurasi Server MCP**: Tambahkan konfigurasi server ke file settings.json VS Code Anda
3. **Mulai Server**: Klik tombol "Mulai" untuk setiap server yang ingin Anda gunakan
4. **Pilih Alat**: Pilih server MCP mana yang diaktifkan untuk sesi saat ini

Untuk instruksi pengaturan yang rinci, lihat dokumentasi [VS Code MCP](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Tips Pro: Kelola Server MCP seperti profesional!**
>
> Tampilan Extensions VS Code kini mencakup [UI baru yang praktis untuk mengelola Server MCP yang terpasang](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Anda memiliki akses cepat untuk memulai, menghentikan, dan mengelola Server MCP apa pun melalui antarmuka yang jelas dan sederhana. Coba sekarang!

### Pengaturan Visual Studio 2022

Untuk Visual Studio 2022 (versi 17.14 atau lebih baru):

1. **Aktifkan Mode Agen**: Klik dropdown "Ask" di jendela GitHub Copilot Chat dan pilih "Agent"
2. **Buat File Konfigurasi**: Buat file `.mcp.json` di direktori solusi Anda (lokasi yang direkomendasikan: `<SOLUTIONDIR>\.mcp.json`)
3. **Konfigurasikan Server**: Tambahkan konfigurasi server MCP Anda menggunakan format MCP standar
4. **Persetujuan Alat**: Saat diminta, setujui alat yang ingin Anda gunakan dengan izin lingkup yang sesuai

Untuk instruksi pengaturan Visual Studio yang rinci, lihat dokumentasi [Visual Studio MCP](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Setiap server MCP memiliki persyaratan konfigurasi sendiri (seperti connection string, otentikasi, dll.), tetapi pola pengaturannya konsisten di kedua IDE.

Server ini terhubung ke `https://learn.microsoft.com/api/mcp` dan memungkinkan pencarian semantik di Microsoft Learn, dokumentasi Azure, dokumentasi Microsoft 365, dan sumber resmi Microsoft lainnya.

**Mengapa berguna**: Walaupun terdengar seperti "hanya dokumentasi," server ini sebenarnya krusial bagi setiap pengembang yang menggunakan teknologi Microsoft. Salah satu keluhan terbesar dari pengembang .NET tentang asisten AI pengkodean adalah mereka tidak selalu up to date dengan rilis .NET dan C# terbaru. Microsoft Learn Docs MCP Server mengatasi ini dengan memberikan akses real-time ke dokumentasi terbaru, referensi API, dan praktik terbaik. Baik Anda bekerja dengan SDK Azure terbaru, menjelajah fitur baru C# 13, atau mengimplementasikan pola Aspire terbaru, server ini memastikan asisten AI memiliki akses ke informasi otoritatif dan terkini yang dibutuhkan untuk menghasilkan kode akurat dan modern.

**Penggunaan nyata**: "Apa perintah az cli untuk membuat aplikasi kontainer Azure sesuai dokumentasi resmi Microsoft Learn?" atau "Bagaimana cara mengonfigurasi Entity Framework dengan dependency injection di ASP.NET Core?" Atau bagaimana dengan "Tinjau kode ini untuk memastikan sesuai dengan rekomendasi performa di Dokumentasi Microsoft Learn." Ia mengembalikan hingga 10 potongan konten berkualitas tinggi dengan judul artikel dan URL, selalu mengakses dokumentasi Microsoft terbaru saat diterbitkan.

**Contoh unggulan**: Server ini menyediakan alat `microsoft_docs_search` yang melakukan pencarian semantik terhadap dokumentasi teknis resmi Microsoft. Setelah dikonfigurasi, Anda bisa bertanya seperti "Bagaimana cara mengimplementasikan otentikasi JWT di ASP.NET Core?" dan mendapatkan jawaban rinci, resmi, lengkap dengan tautan sumber. Kualitas pencariannya luar biasa karena memahami konteks – bertanya tentang "containers" dalam konteks Azure akan mengembalikan dokumentasi Azure Container Instances, sedangkan istilah sama dalam konteks .NET mengembalikan informasi koleksi C# yang relevan.

Ini sangat berguna untuk pustaka dan kasus penggunaan yang cepat berubah atau baru diperbarui. Misalnya, dalam beberapa proyek pengkodean terakhir saya ingin memanfaatkan fitur dalam rilis terbaru Aspire dan Microsoft.Extensions.AI. Dengan menyertakan Microsoft Learn Docs MCP server, saya dapat memanfaatkan bukan hanya dokumentasi API, tapi juga panduan dan walkthrough yang baru diterbitkan.

### 2. ☁️ Azure MCP Server


[![Instal di VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Instal di VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Apa yang dilakukan**: Azure MCP Server adalah rangkaian lengkap lebih dari 15 konektor layanan Azure khusus yang membawa seluruh ekosistem Azure ke dalam alur kerja AI Anda. Ini bukan hanya satu server saja – ini adalah koleksi kuat yang mencakup manajemen sumber daya, konektivitas basis data (PostgreSQL, SQL Server), analisis log Azure Monitor dengan KQL, integrasi Cosmos DB, dan banyak lagi.

**Mengapa ini berguna**: Selain hanya mengelola sumber daya Azure, server ini secara dramatis meningkatkan kualitas kode saat bekerja dengan SDK Azure. Saat Anda menggunakan Azure MCP dalam mode Agen, ia tidak hanya membantu Anda menulis kode – ia membantu Anda menulis kode Azure yang *lebih baik* yang mengikuti pola autentikasi terkini, praktik terbaik penanganan kesalahan, dan memanfaatkan fitur SDK terbaru. Daripada mendapatkan kode generik yang mungkin bekerja, Anda mendapatkan kode yang mengikuti pola rekomendasi Azure untuk beban kerja produksi.

**Modul utama meliputi**:
- **🗄️ Konektor Basis Data**: Akses bahasa alami langsung ke Azure Database untuk PostgreSQL dan SQL Server
- **📊 Azure Monitor**: Analisis log bertenaga KQL dan wawasan operasional
- **🌐 Manajemen Sumber Daya**: Manajemen siklus hidup lengkap sumber daya Azure
- **🔐 Autentikasi**: Pola DefaultAzureCredential dan managed identity
- **📦 Layanan Penyimpanan**: Operasi Blob Storage, Queue Storage, dan Table Storage
- **🚀 Layanan Kontainer**: Azure Container Apps, Container Instances, dan manajemen AKS
- **Dan banyak konektor khusus lainnya**

**Penggunaan nyata**: "Daftar akun penyimpanan Azure saya", "Kueri workspace Log Analytics saya untuk kesalahan dalam satu jam terakhir", atau "Bantu saya membuat aplikasi Azure menggunakan Node.js dengan autentikasi yang tepat"

**Skenario demo lengkap**: Berikut adalah panduan lengkap yang menunjukkan kekuatan menggabungkan Azure MCP dengan ekstensi GitHub Copilot untuk Azure di VS Code. Ketika Anda telah menginstal keduanya dan memberikan perintah:

> "Buat skrip Python yang mengunggah file ke Azure Blob Storage menggunakan autentikasi DefaultAzureCredential. Skrip harus terhubung ke akun penyimpanan Azure saya bernama 'mycompanystorage', mengunggah ke kontainer bernama 'documents', membuat file uji dengan stempel waktu saat ini untuk diunggah, menangani kesalahan dengan baik dan memberikan output informatif, mengikuti praktik terbaik Azure untuk autentikasi dan penanganan kesalahan, menyertakan komentar yang menjelaskan cara kerja autentikasi DefaultAzureCredential, dan membuat skrip terstruktur dengan baik dengan fungsi dan dokumentasi yang tepat."

Azure MCP Server akan menghasilkan skrip Python lengkap siap produksi yang:
- Menggunakan SDK Azure Blob Storage terbaru dengan pola async yang tepat
- Mengimplementasikan DefaultAzureCredential dengan penjelasan rantai fallback yang komprehensif
- Menyertakan penanganan kesalahan yang kuat dengan tipe pengecualian Azure spesifik
- Mengikuti praktik terbaik SDK Azure untuk manajemen sumber daya dan penanganan koneksi
- Menyediakan logging rinci dan output konsol yang informatif
- Membuat skrip terstruktur dengan fungsi, dokumentasi, dan petunjuk tipe

Yang membuat ini luar biasa adalah tanpa Azure MCP, Anda mungkin mendapatkan kode blob storage generik yang bekerja tapi tidak mengikuti pola Azure terkini. Dengan Azure MCP, Anda mendapatkan kode yang memanfaatkan metode autentikasi terbaru, menangani skenario kesalahan spesifik Azure, dan mengikuti praktik yang direkomendasikan Microsoft untuk aplikasi produksi.

**Contoh unggulan**: Saya kesulitan mengingat perintah spesifik untuk CLI `az` dan `azd` untuk penggunaan ad-hoc. Untuk saya, selalu proses dua langkah: pertama mencari sintaks, lalu menjalankan perintah. Saya sering hanya masuk ke portal dan klik sana-sini untuk menyelesaikan pekerjaan karena saya tidak mau mengakui saya tidak ingat sintaks CLI. Bisa hanya dengan mendeskripsikan apa yang saya inginkan sangat menakjubkan, dan lebih baik lagi bisa melakukannya tanpa meninggalkan IDE saya!

Ada daftar kasus penggunaan yang bagus di [repositori Azure MCP](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) untuk memulai Anda. Untuk panduan pengaturan lengkap dan opsi konfigurasi lanjutan, lihat [dokumentasi resmi Azure MCP](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

### 3. 🐙 GitHub MCP Server

[![Instal di VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Instal di VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**Apa yang dilakukan**: GitHub MCP Server resmi menyediakan integrasi mulus dengan seluruh ekosistem GitHub, menawarkan opsi akses jarak jauh yang dihosting dan juga penyebaran Docker lokal. Ini bukan hanya tentang operasi repositori dasar – ini adalah toolkit lengkap yang mencakup manajemen GitHub Actions, alur kerja pull request, pelacakan isu, pemindaian keamanan, notifikasi, dan kemampuan otomasi lanjutan.

**Mengapa ini berguna**: Server ini mengubah cara Anda berinteraksi dengan GitHub dengan membawa pengalaman platform penuh langsung ke lingkungan pengembangan Anda. Alih-alih terus-menerus beralih antara VS Code dan GitHub.com untuk manajemen proyek, review kode, dan pemantauan CI/CD, Anda dapat menangani semuanya melalui perintah bahasa alami sambil tetap fokus pada kode Anda.

> **ℹ️ Catatan: Jenis 'Agen' Berbeda**
> 
> Jangan bingung antara GitHub MCP Server ini dengan GitHub Coding Agent (agen AI yang dapat Anda tugaskan untuk tugas pengkodean otomatis pada isu tertentu). GitHub MCP Server bekerja dalam mode Agen VS Code untuk menyediakan integrasi API GitHub, sementara GitHub Coding Agent adalah fitur terpisah yang membuat pull request saat ditugaskan ke isu GitHub.

**Kemampuan utama meliputi**:
- **⚙️ GitHub Actions**: Manajemen pipeline CI/CD lengkap, pemantauan alur kerja, dan penanganan artefak
- **🔀 Pull Requests**: Membuat, meninjau, menggabungkan, dan mengelola PR dengan pelacakan status komprehensif
- **🐛 Isu**: Manajemen siklus hidup isu lengkap, komentar, pelabelan, dan penugasan
- **🔒 Keamanan**: Peringatan pemindaian kode, deteksi rahasia, dan integrasi Dependabot
- **🔔 Notifikasi**: Manajemen notifikasi pintar dan kontrol langganan repositori
- **📁 Manajemen Repositori**: Operasi file, manajemen cabang, dan administrasi repositori
- **👥 Kolaborasi**: Pencarian pengguna dan organisasi, manajemen tim, dan kontrol akses

**Penggunaan nyata**: "Buat pull request dari cabang fitur saya", "Tunjukkan semua CI yang gagal minggu ini", "Daftar semua peringatan keamanan terbuka untuk repositori saya", atau "Cari semua isu yang ditugaskan kepada saya di seluruh organisasi saya"

**Skenario demo lengkap**: Berikut adalah alur kerja kuat yang menunjukkan kemampuan GitHub MCP Server:

> "Saya perlu mempersiapkan untuk tinjauan sprint kami. Tunjukkan semua pull request yang saya buat minggu ini, periksa status pipeline CI/CD kami, buat ringkasan peringatan keamanan yang perlu kami atasi, dan bantu saya menyusun catatan rilis berdasarkan PR yang sudah digabung dengan label 'feature'."

GitHub MCP Server akan:
- Mengkueri pull request terbaru Anda dengan informasi status detail
- Menganalisis jalannya workflow dan menyoroti kegagalan atau masalah performa
- Mengumpulkan hasil pemindaian keamanan dan memprioritaskan peringatan kritis
- Menghasilkan catatan rilis komprehensif dengan mengekstrak informasi dari PR yang digabung

Sebagai manfaat sampingan, konvensi Markdown juga sangat efisien dalam penggunaan token.

MarkItDown sangat baik dalam mempertahankan struktur dokumen, yang penting untuk alur kerja AI. Misalnya, saat mengonversi presentasi PowerPoint, ia mempertahankan organisasi slide dengan judul yang benar, mengekstrak tabel sebagai tabel Markdown, menyertakan teks alt untuk gambar, bahkan memproses catatan pembicara. Grafik dikonversi menjadi tabel data yang dapat dibaca, dan Markdown yang dihasilkan menjaga alur logis presentasi asli. Ini membuatnya sempurna untuk memasukkan konten presentasi ke dalam sistem AI atau membuat dokumentasi dari slide yang ada.

Ini bisa sangat membantu bagi pengembang baru di M365 Agents karena menyediakan template, contoh kode, dan kerangka kerja untuk memulai tanpa tenggelam dalam dokumentasi. Fitur validasi skema tampak sangat berguna untuk menghindari kesalahan struktur manifest yang bisa menyebabkan berjam-jam debugging.

## 📋 Kesimpulan

Model Context Protocol (MCP) mengubah cara pengembang berinteraksi dengan asisten AI dan alat eksternal. 10 server MCP Microsoft ini menunjukkan kekuatan integrasi AI yang distandarisasi, memungkinkan alur kerja mulus yang menjaga pengembang dalam kondisi fokus sambil mengakses kemampuan eksternal yang kuat.

Dari integrasi ekosistem Azure yang komprehensif hingga alat khusus seperti Playwright untuk otomatisasi browser dan MarkItDown untuk pemrosesan dokumen, server-server ini menunjukkan bagaimana MCP dapat meningkatkan produktivitas di berbagai skenario pengembangan. Protokol standar memastikan alat-alat ini bekerja bersama secara mulus, menciptakan pengalaman pengembangan yang terpadu.

Seiring ekosistem MCP terus berkembang, tetap terlibat dengan komunitas, menjelajah server baru, dan membangun solusi kustom akan menjadi kunci untuk memaksimalkan produktivitas pengembangan Anda. Sifat standar terbuka MCP berarti Anda dapat mencampur dan mencocokkan alat dari vendor berbeda untuk menciptakan alur kerja sempurna sesuai kebutuhan spesifik Anda.
