## 🔧 Memahami Server MCP: Panduan untuk Pemula

### Apa Itu Server MCP?

Sebagai pemula dalam Model Context Protocol (MCP), Anda mungkin bertanya: "Apa sebenarnya server MCP, dan mengapa saya harus peduli?" Mari kita mulai dengan sebuah analogi sederhana.

Anggap server MCP sebagai asisten khusus yang membantu pendamping pengkodean AI Anda (seperti GitHub Copilot) terhubung ke alat dan layanan eksternal. Sama seperti Anda mungkin menggunakan berbagai aplikasi di ponsel untuk tugas berbeda—satu untuk cuaca, satu untuk navigasi, satu untuk perbankan—server MCP memberi asisten AI Anda kemampuan untuk berinteraksi dengan berbagai alat dan layanan pengembangan.

### Masalah yang Diselesaikan Server MCP

Sebelum ada server MCP, jika Anda ingin:
- Memeriksa sumber daya Azure Anda
- Membuat masalah GitHub
- Mengkueri basis data Anda
- Mencari dokumentasi

Anda harus berhenti coding, membuka browser, menavigasi ke situs yang tepat, dan secara manual melakukan tugas-tugas ini. Pergantian konteks yang konstan ini memecah alur kerja Anda dan mengurangi produktivitas.

### Bagaimana Server MCP Mengubah Pengalaman Pengembangan Anda

Dengan server MCP, Anda dapat tetap di lingkungan pengembangan Anda (VS Code, Visual Studio, dll.) dan cukup meminta asisten AI Anda untuk menangani tugas-tugas ini. Contohnya:

**Daripada alur kerja tradisional ini:**
1. Berhenti coding
2. Buka browser
3. Navigasi ke portal Azure
4. Cari detail akun penyimpanan
5. Kembali ke VS Code
6. Melanjutkan coding

**Sekarang Anda bisa melakukan ini:**
1. Tanyakan ke AI: "Apa status akun penyimpanan Azure saya?"
2. Lanjutkan coding dengan informasi yang diberikan

### Manfaat Utama untuk Pemula

#### 1. 🔄 **Tetap dalam Keadaan Alur Anda**
- Tidak perlu lagi berpindah antara banyak aplikasi
- Fokus tetap pada kode yang Anda tulis
- Mengurangi beban mental dalam mengelola berbagai alat

#### 2. 🤖 **Gunakan Bahasa Alami Daripada Perintah Kompleks**
- Daripada menghafal sintaks SQL, jelaskan data yang Anda butuhkan
- Daripada mengingat perintah Azure CLI, jelaskan apa yang ingin Anda capai
- Biarkan AI menangani detail teknis sementara Anda fokus pada logika

#### 3. 🔗 **Hubungkan Berbagai Alat Bersama-sama**
- Ciptakan alur kerja yang kuat dengan menggabungkan berbagai layanan
- Contoh: "Dapatkan semua isu GitHub terbaru dan buat item kerja Azure DevOps yang sesuai"
- Bangun otomatisasi tanpa menulis skrip rumit

#### 4. 🌐 **Akses Ekosistem yang Berkembang**
- Manfaatkan server yang dibuat oleh Microsoft, GitHub, dan perusahaan lainnya
- Campur dan padukan alat dari vendor berbeda dengan mulus
- Bergabunglah dengan ekosistem standar yang bekerja lintas asisten AI

#### 5. 🛠️ **Belajar dengan Melakukan**
- Mulai dengan server yang sudah dibuat untuk memahami konsep
- Secara bertahap bangun server Anda sendiri seiring peningkatan kenyamanan
- Gunakan SDK dan dokumentasi yang tersedia untuk panduan belajar

## Memulai dengan MCP di VS Code dan Visual Studio 🚀

Mengatur server MCP ini cukup mudah jika Anda menggunakan Visual Studio Code atau Visual Studio 2022 dengan GitHub Copilot.

### Pengaturan VS Code

Berikut proses dasar untuk VS Code:

1. **Aktifkan Mode Agent**: Di VS Code, alihkan ke mode Agent di jendela Copilot Chat
2. **Konfigurasi Server MCP**: Tambahkan konfigurasi server ke file settings.json VS Code Anda
3. **Mulai Server**: Klik tombol "Start" untuk setiap server yang ingin Anda gunakan
4. **Pilih Alat**: Pilih server MCP mana yang akan diaktifkan untuk sesi Anda saat ini

Untuk instruksi pengaturan terperinci, lihat [dokumentasi MCP VS Code](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Tip Pro: Kelola Server MCP seperti profesional!**
>
> Tampilan Ekstensi VS Code sekarang menyertakan [UI baru yang berguna untuk mengelola Server MCP yang terpasang](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Anda memiliki akses cepat untuk memulai, menghentikan, dan mengelola Server MCP apa pun yang terpasang menggunakan antarmuka yang jelas dan sederhana. Coba sekarang!

### Pengaturan Visual Studio 2022

Untuk Visual Studio 2022 (versi 17.14 atau lebih baru):

1. **Aktifkan Mode Agent**: Klik dropdown "Ask" di jendela GitHub Copilot Chat dan pilih "Agent"
2. **Buat File Konfigurasi**: Buat file `.mcp.json` di direktori solusi Anda (lokasi yang direkomendasikan: `<SOLUTIONDIR>\.mcp.json`)
3. **Konfigurasi Server**: Tambahkan konfigurasi server MCP Anda menggunakan format MCP standar
4. **Persetujuan Alat**: Saat diminta, setujui alat yang ingin Anda gunakan dengan izin lingkup yang sesuai

Untuk instruksi pengaturan Visual Studio terperinci, lihat [dokumentasi MCP Visual Studio](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Setiap server MCP memiliki persyaratan konfigurasi sendiri (string koneksi, otentikasi, dll.), tetapi pola pengaturannya konsisten di kedua IDE.

**Apa yang dilakukan**: Server Microsoft Learn Docs MCP adalah layanan yang dihosting di cloud yang menyediakan akses waktu nyata kepada asisten AI ke dokumentasi resmi Microsoft melalui Model Context Protocol. Server ini terhubung ke `https://learn.microsoft.com/api/mcp` dan memungkinkan pencarian semantik di Microsoft Learn, dokumentasi Azure, dokumentasi Microsoft 365, dan sumber resmi Microsoft lainnya.

**Mengapa berguna**: Meskipun terlihat hanya sebagai "dokumentasi," server ini sangat penting bagi setiap pengembang yang menggunakan teknologi Microsoft. Salah satu keluhan terbesar dari pengembang .NET tentang asisten pengkodean AI adalah bahwa mereka tidak mengikuti rilis .NET dan C# terbaru. Server Microsoft Learn Docs MCP mengatasi ini dengan menyediakan akses waktu nyata ke dokumentasi, referensi API, dan praktik terbaik terbaru. Baik Anda bekerja dengan SDK Azure terbaru, menjelajahi fitur baru C# 13, atau mengimplementasikan pola Aspire mutakhir, server ini memastikan asisten AI Anda memiliki akses ke informasi otoritatif dan terkini yang diperlukan untuk menghasilkan kode yang akurat dan modern.

**Penggunaan dunia nyata**: "Apa perintah az cli untuk membuat aplikasi kontainer Azure menurut dokumentasi resmi Microsoft Learn?" atau "Bagaimana saya mengonfigurasi Entity Framework dengan dependency injection di ASP.NET Core?" Atau bagaimana dengan "Tinjau kode ini untuk memastikan sesuai dengan rekomendasi performa dalam Dokumentasi Microsoft Learn." Server ini menyediakan cakupan komprehensif di Microsoft Learn, dokumen Azure, dan dokumentasi Microsoft 365 menggunakan pencarian semantik canggih untuk menemukan informasi paling relevan secara kontekstual. Server mengembalikan hingga 10 potongan konten berkualitas tinggi dengan judul artikel dan URL, selalu mengakses dokumentasi Microsoft terbaru saat dipublikasikan.

**Contoh unggulan**: Server ini mengekspose alat `microsoft_docs_search` yang melakukan pencarian semantik terhadap dokumentasi teknis resmi Microsoft. Setelah dikonfigurasi, Anda dapat mengajukan pertanyaan seperti "Bagaimana cara mengimplementasikan otentikasi JWT di ASP.NET Core?" dan mendapatkan jawaban resmi yang rinci beserta tautan sumber. Kualitas pencarian sangat baik karena memahami konteks – bertanya tentang "kontainer" dalam konteks Azure akan mengembalikan dokumentasi Azure Container Instances, sementara istilah yang sama dalam konteks .NET mengembalikan informasi koleksi C# yang relevan.

Ini sangat berguna untuk perpustakaan dan kasus penggunaan yang berubah cepat atau baru diperbarui. Misalnya, dalam beberapa proyek coding terbaru saya ingin memanfaatkan fitur di rilis terbaru Aspire dan Microsoft.Extensions.AI. Dengan menyertakan server Microsoft Learn Docs MCP, saya dapat memanfaatkan tidak hanya dokumentasi API, tetapi juga panduan dan tutorial yang baru saja dipublikasikan.

### 2. ☁️ Server Azure MCP

[![Pasang di VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Pasang di VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Apa yang dilakukan**: Server Azure MCP adalah suite lengkap dengan lebih dari 15 konektor layanan Azure khusus yang membawa seluruh ekosistem Azure ke dalam alur kerja AI Anda. Ini bukan hanya satu server – ini adalah koleksi kuat yang mencakup manajemen sumber daya, konektivitas basis data (PostgreSQL, SQL Server), analisis log Azure Monitor dengan KQL, integrasi Cosmos DB, dan banyak lagi.

**Mengapa berguna**: Selain hanya mengelola sumber daya Azure, server ini secara dramatis meningkatkan kualitas kode saat bekerja dengan SDK Azure. Ketika menggunakan Azure MCP dalam mode Agent, ia tidak hanya membantu menulis kode – ia membantu menulis kode Azure yang *lebih baik* yang mengikuti pola otentikasi saat ini, praktik terbaik penanganan kesalahan, dan memanfaatkan fitur SDK terbaru. Daripada mendapatkan kode generik yang mungkin berfungsi, Anda mendapatkan kode yang mengikuti pola yang direkomendasikan Azure untuk beban kerja produksi.

**Modul kunci meliputi**:
- **🗄️ Konektor Basis Data**: Akses bahasa alami langsung ke Azure Database untuk PostgreSQL dan SQL Server
- **📊 Azure Monitor**: Analisis log berbasis KQL dan wawasan operasional
- **🌐 Manajemen Sumber Daya**: Manajemen siklus hidup sumber daya Azure penuh
- **🔐 Otentikasi**: Pola DefaultAzureCredential dan managed identity
- **📦 Layanan Penyimpanan**: Operasi Blob Storage, Queue Storage, dan Table Storage
- **🚀 Layanan Kontainer**: Azure Container Apps, Container Instances, dan manajemen AKS
- **Dan banyak konektor khusus lainnya**

**Penggunaan dunia nyata**: "Daftar akun penyimpanan Azure saya", "Kueri workspace Log Analytics saya untuk kesalahan dalam satu jam terakhir", atau "Bantu saya membangun aplikasi Azure menggunakan Node.js dengan otentikasi yang tepat"

**Skenario demo lengkap**: Berikut walkthrough lengkap yang menunjukkan kekuatan menggabungkan Azure MCP dengan ekstensi GitHub Copilot untuk Azure di VS Code. Ketika Anda memiliki keduanya terpasang dan memberi prompt:

> "Buat skrip Python yang mengunggah file ke Azure Blob Storage menggunakan autentikasi DefaultAzureCredential. Skrip harus terhubung ke akun penyimpanan Azure saya yang bernama 'mycompanystorage', mengunggah ke container bernama 'documents', membuat file uji dengan timestamp saat ini untuk diunggah, menangani kesalahan dengan baik dan memberikan output yang informatif, mengikuti praktik terbaik Azure untuk autentikasi dan penanganan kesalahan, menyertakan komentar yang menjelaskan cara kerja autentikasi DefaultAzureCredential, dan membuat skrip yang terstruktur dengan baik dengan fungsi dan dokumentasi yang tepat."

Server Azure MCP akan menghasilkan skrip Python lengkap, siap produksi yang:
- Menggunakan SDK Azure Blob Storage terbaru dengan pola async yang tepat
- Menerapkan DefaultAzureCredential dengan penjelasan rantai fallback yang komprehensif
- Menyertakan penanganan kesalahan yang kuat dengan tipe pengecualian Azure spesifik
- Mengikuti praktik terbaik SDK Azure untuk manajemen sumber daya dan penanganan koneksi
- Menyediakan logging terperinci dan output konsol yang informatif
- Membuat skrip yang terstruktur dengan benar dengan fungsi, dokumentasi, dan petunjuk tipe

Yang membuat ini luar biasa adalah bahwa tanpa Azure MCP, Anda mungkin mendapatkan kode penyimpanan blob generik yang berjalan tetapi tidak mengikuti pola Azure saat ini. Dengan Azure MCP, Anda mendapatkan kode yang memanfaatkan metode autentikasi terbaru, menangani skenario kesalahan khusus Azure, dan mengikuti praktik yang disarankan Microsoft untuk aplikasi produksi.

**Contoh unggulan**: Saya pernah kesulitan mengingat perintah spesifik untuk CLI `az` dan `azd` untuk penggunaan ad-hoc. Selalu merupakan proses dua langkah bagi saya: pertama mencari sintaks, kemudian menjalankan perintah. Saya sering masuk ke portal dan mengklik sekeliling untuk menyelesaikan pekerjaan karena saya tidak mau mengakui saya tidak bisa mengingat sintaks CLI. Bisa hanya menggambarkan apa yang saya mau itu luar biasa, dan lebih baik lagi bisa melakukannya tanpa meninggalkan IDE saya!

Ada daftar kasus penggunaan hebat di [repositori Azure MCP](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) untuk memulai Anda. Untuk panduan pengaturan komprehensif dan opsi konfigurasi lanjutan, lihat [dokumentasi resmi Azure MCP](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

### 3. 🐙 Server GitHub MCP

[![Pasang di VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Pasang di VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**Apa yang dilakukannya**: Server GitHub MCP resmi menyediakan integrasi mulus dengan seluruh ekosistem GitHub, menawarkan opsi akses jarak jauh terhosting dan deployment Docker lokal. Ini bukan hanya tentang operasi repositori dasar – melainkan toolkit komprehensif yang mencakup manajemen GitHub Actions, alur kerja pull request, pelacakan isu, pemindaian keamanan, notifikasi, dan kapabilitas otomatisasi tingkat lanjut.

**Mengapa berguna**: Server ini mengubah cara Anda berinteraksi dengan GitHub dengan membawa pengalaman platform penuh langsung ke lingkungan pengembangan Anda. Alih-alih terus-menerus beralih antara VS Code dan GitHub.com untuk manajemen proyek, review kode, dan pemantauan CI/CD, Anda dapat menangani semuanya melalui perintah bahasa alami sambil tetap fokus pada kode Anda.

> **ℹ️ Catatan: Jenis 'Agen' yang Berbeda**
> 
> Jangan bingung antara Server GitHub MCP ini dengan GitHub's Coding Agent (agen AI yang bisa Anda tugaskan untuk isu agar melakukan tugas pengkodean otomatis). Server GitHub MCP bekerja dalam mode Agen VS Code untuk menyediakan integrasi API GitHub, sementara Coding Agent GitHub adalah fitur terpisah yang membuat pull request saat ditugaskan ke isu GitHub.

**Kemampuan utama meliputi**:
- **⚙️ GitHub Actions**: Manajemen pipeline CI/CD lengkap, pemantauan workflow, dan penanganan artifak
- **🔀 Pull Requests**: Membuat, meninjau, menggabungkan, dan mengelola PR dengan pelacakan status komprehensif
- **🐛 Issues**: Manajemen siklus hidup isu penuh, commenting, pelabelan, dan penugasan
- **🔒 Keamanan**: Peringatan pemindaian kode, deteksi rahasia, dan integrasi Dependabot
- **🔔 Notifikasi**: Manajemen notifikasi pintar dan kontrol langganan repositori
- **📁 Manajemen Repositori**: Operasi file, manajemen cabang, dan administrasi repositori
- **👥 Kolaborasi**: Pencarian pengguna dan organisasi, manajemen tim, dan kontrol akses

**Penggunaan nyata**: "Buat pull request dari branch fitur saya", "Tampilkan semua CI run yang gagal minggu ini", "Daftar semua peringatan keamanan terbuka untuk repositori saya", atau "Temukan semua isu yang ditugaskan ke saya di seluruh organisasi saya"

**Skenario demo lengkap**: Berikut ini alur kerja kuat yang menampilkan kemampuan Server GitHub MCP:

> "Saya perlu mempersiapkan review sprint kami. Tunjukkan semua pull request yang saya buat minggu ini, periksa status pipeline CI/CD kami, buat ringkasan peringatan keamanan yang perlu kami tangani, dan bantu saya menyusun catatan rilis berdasarkan PR yang sudah digabung dengan label 'feature'."

Server GitHub MCP akan:
- Menanyakan pull request terbaru Anda dengan informasi status yang detail
- Menganalisis run workflow dan menyoroti kegagalan atau masalah performa
- Mengompilasi hasil pemindaian keamanan dan memprioritaskan peringatan kritis
- Menghasilkan catatan rilis komprehensif dengan mengekstrak informasi dari PR yang digabung
- Menyediakan langkah-langkah aksi berikutnya untuk perencanaan sprint dan persiapan rilis

## 📋 Kesimpulan

Model Context Protocol (MCP) sedang mengubah cara pengembang berinteraksi dengan asisten AI dan alat eksternal. Sepuluh server MCP Microsoft ini menunjukkan kekuatan integrasi AI yang distandarisasi, memungkinkan alur kerja tanpa hambatan yang menjaga pengembang tetap fokus sambil mengakses kemampuan eksternal yang kuat.

Dari integrasi ekosistem Azure yang komprehensif hingga alat khusus seperti Playwright untuk otomatisasi browser dan MarkItDown untuk pemrosesan dokumen, server-server ini memperlihatkan bagaimana MCP dapat meningkatkan produktivitas dalam berbagai skenario pengembangan. Protokol yang distandarisasi memastikan alat-alat ini bekerja bersama secara mulus, menciptakan pengalaman pengembangan yang kohesif.

Seiring ekosistem MCP terus berkembang, tetap terlibat dengan komunitas, menjelajah server baru, dan membangun solusi kustom akan menjadi kunci untuk memaksimalkan produktivitas pengembangan Anda. Sifat standar terbuka MCP berarti Anda dapat menggabungkan alat dari vendor berbeda untuk menciptakan alur kerja yang sempurna sesuai kebutuhan spesifik Anda.

## 🎯 Latihan

1. **Pasang dan Konfigurasikan**: Pasang salah satu server MCP di lingkungan VS Code Anda dan uji fungsi dasar.
2. **Integrasi Alur Kerja**: Rancang alur kerja pengembangan yang menggabungkan setidaknya tiga server MCP berbeda.
3. **Perencanaan Server Kustom**: Identifikasi tugas dalam rutinitas pengembangan harian Anda yang dapat diuntungkan dari server MCP kustom dan buat spesifikasinya.
4. **Analisis Kinerja**: Bandingkan efisiensi penggunaan server MCP dengan pendekatan tradisional untuk tugas pengembangan umum.
5. **Penilaian Keamanan**: Evaluasi implikasi keamanan penggunaan server MCP di lingkungan pengembangan Anda dan usulkan praktik terbaik.
