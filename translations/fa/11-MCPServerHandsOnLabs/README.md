# 🚀 سرور MCP با PostgreSQL - راهنمای کامل یادگیری

## 🧠 مرور مسیر یادگیری ادغام پایگاه داده MCP

این راهنمای جامع به شما آموزش می‌دهد چگونه سرورهای **پروتکل مدل کانتکست (MCP)** آماده تولید بسازید که از طریق یک پیاده‌سازی عملی تحلیل خرده‌فروشی با پایگاه داده‌ها ادغام می‌شوند. شما الگوهای سازمانی شامل **امنیت در سطح ردیف (RLS)**، **جستجوی معنایی**، **ادغام هوش مصنوعی Azure** و **دسترسی داده چند مستاجری** را یاد خواهید گرفت.

چه شما توسعه‌دهنده بک‌اند، مهندس هوش مصنوعی یا معمار داده باشید، این راهنما یادگیری ساختاریافته با مثال‌های واقعی و تمرین‌های عملی را ارائه می‌دهد که شما را از طریق سرور MCP در https://github.com/microsoft/MCP-Server-and-PostgreSQL-Sample-Retail راهنمایی می‌کند.

### 💻 آنچه خواهید ساخت

تا پایان این مسیر یادگیری، شما یک **سرور MCP تحلیل خرده‌فروشی زَوا** کامل خواهید ساخت که شامل:

- **پایگاه داده چندجدولی خرده‌فروشی** با سفارش‌های مشتریان، محصولات و موجودی
- **امنیت در سطح ردیف** برای جداسازی داده‌های مبتنی بر فروشگاه
- **جستجوی معنایی محصول** با استفاده از embeddingهای Azure OpenAI
- **ادغام چت هوش مصنوعی VS Code** برای کوئری‌های زبان طبیعی
- **استقرار آماده تولید** با داکر و Azure
- **پایش جامع** با Application Insights

## 🎯 ملزومات پیش‌نیاز یادگیری

برای بهره‌وری بیشتر از این مسیر یادگیری، باید داشته باشید:

- **تجربه برنامه‌نویسی**: آشنایی با Python (ترجیحاً) یا زبان‌های مشابه
- **دانش پایگاه داده**: درک پایه‌ای از SQL و پایگاه‌های داده رابطه‌ای
- **مفاهیم API**: آشنایی با REST APIها و مفاهیم HTTP
- **ابزارهای توسعه**: تجربه کار با خط فرمان، Git و ویرایشگرهای کد
- **مبانی ابر**: (اختیاری) دانش پایه از Azure یا پلتفرم‌های ابری مشابه
- **آشنایی با Docker**: (اختیاری) درک مفاهیم کانتینرسازی

### ابزارهای مورد نیاز

- **Docker Desktop** - برای اجرای PostgreSQL و سرور MCP
- **Azure CLI** - برای استقرار منابع ابری
- **VS Code** - برای توسعه و ادغام MCP
- **Git** - برای کنترل نسخه
- **Python 3.8+** - برای توسعه سرور MCP
