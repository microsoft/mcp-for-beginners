# سرور ماشین‌حساب MCP (پایتون)



یک پیاده‌سازی ساده از پروتکل متن مدل (MCP) در پایتون که قابلیت‌های پایه ماشین‌حساب را فراهم می‌کند.


## نصب

وابستگی‌های مورد نیاز را نصب کنید:

```bash
pip install -r requirements.txt
```

یا SDK پایتون MCP را مستقیماً نصب کنید:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## استفاده

### راه‌اندازی سرور

این سرور برای استفاده توسط کلاینت‌های MCP (مانند Claude Desktop) طراحی شده است. برای شروع سرور:

```bash
python mcp_calculator_server.py
```

**توجه**: هنگام اجرای مستقیم در ترمینال، خطاهای اعتبارسنجی JSON-RPC را مشاهده خواهید کرد. این رفتار طبیعی است - سرور در انتظار پیام‌های کلاینت MCP با فرمت صحیح است.

### تست عملکردها

برای اطمینان از عملکرد صحیح تابع‌های ماشین‌حساب:

```bash
python test_calculator.py
```

## رفع اشکال

### خطاهای واردکردن ماژول

اگر خطا `ModuleNotFoundError: No module named 'mcp'` را مشاهده کردید، SDK پایتون MCP را نصب کنید:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### خطاهای JSON-RPC هنگام اجرای مستقیم

خطاهایی مثل "Invalid JSON: EOF while parsing a value" هنگام اجرای مستقیم سرور طبیعی است. سرور به پیام‌های کلاینت MCP نیاز دارد، نه ورودی مستقیم از ترمینال.
