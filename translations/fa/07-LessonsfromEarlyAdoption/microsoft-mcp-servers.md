## 🔧 آشنایی با سرورهای MCP: راهنمای مبتدیان

### سرورهای MCP چه هستند؟

اگر تازه‌کار در پروتکل مدل کانتکست (MCP) هستید، ممکن است بپرسید: «سرور MCP دقیقاً چیست و چرا باید برایم اهمیت داشته باشد؟» بیا با یک مثال ساده شروع کنیم.

سرورهای MCP مانند دستیاران تخصصی هستند که به همراه کدزنی هوش مصنوعی شما (مثلاً GitHub Copilot) کمک می‌کنند تا به ابزارها و خدمات خارجی متصل شود. درست همانطور که شما ممکن است برای کارهای مختلف در تلفن هوشمندتان از اپ‌های مختلف استفاده کنید — یکی برای هواشناسی، یکی برای نقشه، یکی برای بانکداری — سرورهای MCP به دستیار هوش مصنوعی شما امکان تعامل با ابزارها و خدمات گوناگون توسعه را می‌دهند.

### مشکلی که سرورهای MCP حل می‌کنند

پیش از سرورهای MCP، اگر می‌خواستید:
- منابع Azure خود را بررسی کنید
- یک issue در GitHub ایجاد کنید
- از پایگاه داده‌تان پرس‌وجو کنید
- در اسناد جستجو کنید

باید کدنویسی را متوقف می‌کردید، مرورگر باز می‌کردید، به سایت مربوط می‌رفتید و این کارها را دستی انجام می‌دادید. این جابجایی مداوم زمینه، جریان کار شما را می‌شکند و بهره‌وری را کاهش می‌دهد.

### چگونه سرورهای MCP تجربه توسعه شما را متحول می‌کنند

با سرورهای MCP می‌توانید در محیط توسعه خود (VS Code، Visual Studio و غیره) بمانید و تنها از دستیار هوش مصنوعی خود بخواهید این کارها را انجام دهد. به عنوان مثال:

**به جای این جریان کاری سنتی:**
۱. کدنویسی را متوقف کنید
۲. مرورگر را باز کنید
۳. به پورتال Azure بروید
۴. جزئیات حساب ذخیره‌سازی را جستجو کنید
۵. به VS Code برگردید
۶. به کدنویسی ادامه دهید

**حالا می‌توانید این کار را انجام دهید:**
۱. از هوش مصنوعی بپرسید: «وضعیت حساب‌های ذخیره‌سازی Azure من چطور است؟»
۲. با اطلاعات ارائه شده به کدنویسی ادامه دهید

### مزایای کلیدی برای مبتدیان

#### ۱. 🔄 **در وضعیت جریان کاری‌تان بمانید**
- دیگر بین چند برنامه جابجا نشوید
- تمرکز روی کدی که می‌نویسید حفظ شود
- بار ذهنی مدیریت ابزارهای مختلف کاهش یابد

#### ۲. 🤖 **استفاده از زبان طبیعی به جای دستورات پیچیده**
- به جای حفظ سینتکس SQL، شرح دهید چه داده‌ای نیاز دارید
- به جای به خاطر سپردن دستورات Azure CLI، توضیح دهید چه می‌خواهید انجام دهید
- بگذارید هوش مصنوعی جزئیات فنی را انجام دهد و شما روی منطق تمرکز کنید

#### ۳. 🔗 **اتصال ابزارهای متعدد به هم**
- با ترکیب سرویس‌های مختلف جریان‌های کاری قدرتمندی بسازید
- مثال: «تمام issueهای اخیر GitHub را بگیر و موارد کاری مربوط به Azure DevOps ایجاد کن»
- بدون نوشتن اسکریپت‌های پیچیده خودکارسازی بسازید

#### ۴. 🌐 **دسترسی به اکوسیستم رو به رشد**
- از سرورهای ساخته شده توسط مایکروسافت، GitHub و دیگر شرکت‌ها بهره‌مند شوید
- به طور یکپارچه ابزارهای مختلف را از تامین‌کنندگان گوناگون ترکیب کنید
- به اکوسیستم استانداردی بپیوندید که در میان دستیاران هوش مصنوعی مختلف کار می‌کند

#### ۵. 🛠️ **یادگیری با انجام دادن**
- با سرورهای از پیش ساخته شده شروع کنید تا مفاهیم را درک کنید
- به تدریج سرورهای خود را بسازید وقتی بیشتر راحت شدید
- از SDKها و مستندات موجود برای راهنمایی یادگیری استفاده کنید

### مثال دنیای واقعی برای مبتدیان

فرض کنید شما تازه وارد توسعه وب هستید و روی اولین پروژه خود کار می‌کنید. اینجا چگونگی کمک سرورهای MCP آمده است:

**رویکرد سنتی:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**با سرورهای MCP:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### مزیت استاندارد سازمانی

MCP به استانداردی گسترده در صنعت تبدیل می‌شود، به این معنی که:

- **تعاملی بودن**: سرورها از تامین‌کنندگان مختلف با هم کار می‌کنند
- **آمادگی برای آینده**: مهارت‌ها و راه‌اندازی‌ها بین دستیاران هوش مصنوعی مختلف منتقل می‌شود
- **جامعه**: اکوسیستم بزرگی از دانش و منابع مشترک

## شروع به کار با MCP در VS Code و Visual Studio 🚀

راه‌اندازی این سرورهای MCP اگر از Visual Studio Code یا Visual Studio 2022 با GitHub Copilot استفاده می‌کنید، ساده است.

### راه‌اندازی VS Code

روند پایه در VS Code به شرح زیر است:

۱. **فعالسازی حالت Agent**: در VS Code در پنجره چت Copilot به حالت Agent بروید
۲. **پیکربندی سرورهای MCP**: تنظیمات سرور را به فایل settings.json اضافه کنید
۳. **شروع سرورها**: دکمه «شروع» را برای هر سروری که می‌خواهید استفاده کنید بزنید
۴. **انتخاب ابزارها**: سرورهای MCP را برای جلسه فعلی فعال کنید

برای دستورالعمل‌های دقیق‌تر، مستندات [MCP در VS Code](https://code.visualstudio.com/docs/copilot/copilot-mcp) را ببینید.

> **💡 نکته حرفه‌ای: سرورهای MCP را مانند یک حرفه‌ای مدیریت کنید!**
> 
> نمای Extensions در VS Code اکنون شامل [رابط کاربری جدیدی برای مدیریت سرورهای MCP نصب شده](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode) است! دسترسی سریع برای شروع، توقف و مدیریت هر سرور MCP نصب شده را با رابطی ساده و واضح دارید. حتما امتحانش کنید!

### راه‌اندازی Visual Studio 2022

برای Visual Studio 2022 (نسخه ۱۷.۱۴ یا بالاتر):

۱. **فعالسازی حالت Agent**: در پنجره چت GitHub Copilot روی منوی کشویی «بپرس» کلیک کرده و «Agent» را انتخاب کنید
۲. **ایجاد فایل پیکربندی**: فایل `.mcp.json` را در دایرکتوری راه‌حل خود بسازید (مکان پیشنهادی: `<SOLUTIONDIR>\.mcp.json`)
۳. **پیکربندی سرورها**: تنظیمات سرورهای MCP را با فرمت استاندارد MCP اضافه کنید
۴. **تأیید ابزارها**: هنگام درخواست، اجازهٔ استفاده از ابزارها را با مجوزهای مناسب تایید کنید

برای دستورالعمل‌های دقیق راه‌اندازی Visual Studio، مستندات [MCP در Visual Studio](https://learn.microsoft.com/visualstudio/ide/mcp-servers) را ببینید.

هر سرور MCP نیازمندی‌های پیکربندی خاص خود را دارد (رشته‌های اتصال، احراز هویت و غیره) اما الگوی راه‌اندازی در هر دو IDE یکسان است.

### ۱. 📚 سرور MCP مستندات Microsoft Learn

[![نصب در VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![نصب در VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**وظیفه آن**: سرور MCP مستندات Microsoft Learn سرویسی ابری است که به دستیاران هوش مصنوعی دسترسی لحظه‌ای به مستندات رسمی مایکروسافت از طریق پروتکل مدل کانتکست می‌دهد. این سرور به `https://learn.microsoft.com/api/mcp` متصل شده و جستجوی معنایی در Microsoft Learn، مستندات Azure، مستندات Microsoft 365 و منابع رسمی دیگر مایکروسافت را ممکن می‌کند.

**چرا مفید است**: در حالی که ممکن است فقط «مستندات» به نظر برسد، این سرور برای هر توسعه‌دهنده‌ای که از فناوری‌های مایکروسافت استفاده می‌کند بسیار حیاتی است. یکی از بزرگترین شکایت‌های توسعه‌دهندگان .NET درباره دستیاران کدنویسی هوش مصنوعی این است که اطلاعاتشان بروز نیست. سرور MCP مستندات Microsoft Learn این مشکل را با ارائه دسترسی لحظه‌ای به مستندات جدیدترین، مراجع API و بهترین روش‌ها حل می‌کند. چه در حال کار با آخرین SDKهای Azure باشید، چه ویژگی‌های جدید C# ۱۳ را بررسی کنید یا الگوهای پیشرفته Aspire را پیاده کنید، این سرور اطمینان می‌دهد دستیار هوش مصنوعی شما به اطلاعات رسمی، به‌روز و دقیق دسترسی دارد تا کد صحیح و مدرنی تولید کند.

**استفاده واقعی**: «دستورات az cli برای ایجاد یک Azure container app مطابق مستندات رسمی Microsoft Learn چیست؟» یا «چگونه Entity Framework را با وابستگی تزریق در ASP.NET Core پیکربندی کنم؟» یا «این کد را بررسی کن تا مطمئن شوی با توصیه‌های عملکردی مستندات Microsoft Learn مطابقت دارد.» این سرور پوشش کاملی روی Microsoft Learn، مستندات Azure و مستندات Microsoft 365 با جستجوی معنایی پیشرفته دارد تا مرتبط‌ترین اطلاعات زمینه‌ای را بیابد. حداکثر ۱۰ قطعه محتوا با عناوین مقاله و URLها بازمی‌گرداند و همیشه به جدیدترین مستندات مایکروسافت که منتشر می‌شود دسترسی دارد.

**مثال شاخص**: این سرور ابزار `microsoft_docs_search` را ارائه می‌دهد که جستجوی معنایی روی مستندات فنی رسمی مایکروسافت انجام می‌دهد. پس از پیکربندی، می‌توانید سوالاتی مانند «چگونه احراز هویت JWT را در ASP.NET Core پیاده کنم؟» بپرسید و پاسخ‌های رسمی و دقیق همراه با لینک منابع دریافت کنید. کیفیت جستجو عالی است چون زمینه را درک می‌کند – پرسیدن درباره «containers» در زمینه Azure مستندات Azure Container Instances را بازمی‌گرداند، در حالی که در زمینه .NET اطلاعات مرتبط با collectionهای C# را نشان می‌دهد.

این خصوصاً برای کتابخانه‌ها و موارد استفاده‌ای که سریع تغییر می‌کنند یا تازه به‌روزرسانی شده‌اند مفید است. مثلاً در بعضی پروژه‌های کدنویسی اخیر می‌خواستم ویژگی‌های انتشارهای جدید Aspire و Microsoft.Extensions.AI را استفاده کنم. با افزودن سرور MCP مستندات Microsoft Learn، توانستم نه تنها مستندات API بلکه راهنماها و راه‌حل‌های تازه منتشر شده را هم بهره ببرم.

### ۲. ☁️ سرور MCP Azure


[![نصب در VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![نصب در VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**چه کاری انجام می‌دهد**: سرور Azure MCP مجموعه‌ای جامع از بیش از ۱۵ کانکتور تخصصی سرویس Azure است که کل اکوسیستم Azure را وارد گردش کار هوش مصنوعی شما می‌کند. این فقط یک سرور ساده نیست – بلکه مجموعه‌ای قدرتمند است که شامل مدیریت منابع، اتصال به پایگاه داده (PostgreSQL، SQL Server)، تحلیل لاگ‌های Azure Monitor با KQL، ادغام Cosmos DB و بسیار موارد دیگر می‌شود.

**چرا مفید است**: فراتر از مدیریت منابع Azure، این سرور کیفیت کد را هنگامی که با SDKهای Azure کار می‌کنید به طور چشمگیری بهبود می‌بخشد. وقتی از Azure MCP در حالت Agent استفاده می‌کنید، فقط به شما در نوشتن کد کمک نمی‌کند – بلکه به شما کمک می‌کند کد *بهتری* برای Azure بنویسید که الگوهای احراز هویت فعلی، بهترین روش‌های مدیریت خطا، و استفاده از جدیدترین ویژگی‌های SDK را دنبال می‌کند. به جای گرفتن کدی عمومی که ممکن است کار کند، کدی دریافت می‌کنید که الگوهای توصیه شده Azure برای بارکاری‌های تولیدی را رعایت می‌کند.

**ماژول‌های کلیدی شامل**:
- **🗄️ کانکتورهای پایگاه داده**: دسترسی مستقیم زبان طبیعی به پایگاه داده Azure برای PostgreSQL و SQL Server
- **📊 Azure Monitor**: تحلیل لاگ بر پایه KQL و بینش‌های عملیاتی
- **🌐 مدیریت منابع**: مدیریت چرخه عمر کامل منابع Azure
- **🔐 احراز هویت**: الگوهای DefaultAzureCredential و managed identity
- **📦 سرویس‌های ذخیره‌سازی**: عملیات روی Blob Storage، Queue Storage و Table Storage
- **🚀 سرویس‌های کانتینر**: مدیریت Azure Container Apps، Container Instances و AKS
- **و بسیاری کانکتورهای تخصصی دیگر**

**کاربرد واقعی**: "فهرست حساب‌های ذخیره‌سازی Azure من"، "پرس و جو در فضای کاری Log Analytics برای خطاهای یک ساعت گذشته"، یا "کمکم کن یک اپلیکیشن Azure با Node.js و احراز هویت مناسب بسازم"

**سناریوی کامل دمو**: در اینجا یک مرور کامل است که قدرت ترکیب Azure MCP با افزونه GitHub Copilot برای Azure در VS Code را نشان می‌دهد. وقتی هر دو نصب شده باشند و فرمان دهید:

> "یک اسکریپت پایتون ایجاد کن که فایلی را با استفاده از احراز هویت DefaultAzureCredential به Azure Blob Storage آپلود کند. اسکریپت باید به حساب ذخیره‌سازی Azure من به نام 'mycompanystorage' متصل شود، به کانتینری به نام 'documents' آپلود کند، یک فایل تست با زمان حال تولید کند، خطاها را به طور مناسب مدیریت و خروجی آموزنده ارائه دهد، بهترین روش‌های Azure برای احراز هویت و مدیریت خطا را دنبال کند، شامل توضیحاتی درباره نحوه کار احراز هویت DefaultAzureCredential باشد، و اسکریپت به خوبی ساختاربندی شده با توابع مناسب و مستندسازی باشد."

سرور Azure MCP اسکریپتی کامل و آماده تولید به زبان پایتون ایجاد خواهد کرد که:
- از جدیدترین SDK Azure Blob Storage با الگوهای async مناسب استفاده می‌کند
- احراز هویت DefaultAzureCredential را با توضیح کامل زنجیره جایگزینی پیاده‌سازی می‌کند
- مدیریت خطای قوی با نوع استثناهای خاص Azure دارد
- بهترین روش‌های SDK Azure برای مدیریت منابع و اتصالات را دنبال می‌کند
- لاگ‌گیری دقیق و خروجی کنسول آموزنده ارائه می‌دهد
- اسکریپتی ساختاربندی شده، با توابع، مستندات و اشاره به تایپ‌ها ایجاد می‌کند

نکته قابل توجه این است که بدون Azure MCP، ممکن است کد بلاگ ذخیره‌سازی عمومی دریافت کنید که کار می‌کند اما الگوهای فعلی Azure را دنبال نمی‌کند. با Azure MCP، کدی دریافت می‌کنید که جدیدترین روش‌های احراز هویت را بهره می‌برد، سناریوهای خطای خاص Azure را مدیریت می‌کند و بهترین شیوه‌های مایکروسافت برای برنامه‌های تولیدی را رعایت می‌کند.

**مثال برجسته**: من برای به خاطر سپردن دستورات خاص CLI های `az` و `azd` مخصوصاً استفاده فوری مشکل داشتم. همیشه برای من یک فرآیند دو مرحله‌ای است: ابتدا نحو را جست‌وجو می‌کنم و سپس دستور را اجرا می‌کنم. اغلب فقط به پورتال می‌روم و کلیک می‌کنم تا کارم را انجام دهم زیرا نمی‌خواهم اعتراف کنم نمی‌توانم نحو CLI را به خاطر بیاورم. توانایی فقط توصیف آنچه می‌خواهم فوق‌العاده است، و چه بهتر که بتوانم این کار را بدون ترک IDE خود انجام دهم!

در [مخزن Azure MCP](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) فهرستی عالی از موارد استفاده وجود دارد تا شروع کنید. برای راهنماهای جامع راه‌اندازی و گزینه‌های پیکربندی پیشرفته، مستندات رسمی [Azure MCP](https://learn.microsoft.com/azure/developer/azure-mcp-server/) را بررسی کنید.

### ۳. 🐙 سرور GitHub MCP

[![نصب در VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![نصب در VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**چه کاری انجام می‌دهد**: سرور رسمی GitHub MCP یکپارچگی بی‌دردسر با کل اکوسیستم GitHub ارائه می‌دهد، شامل دسترسی از راه دور میزبانی شده و گزینه‌های استقرار محلی در Docker. این فقط عملیات پایه مخزن نیست – بلکه یک جعبه ابزار جامع است که شامل مدیریت GitHub Actions، گردش‌کار درخواست کشش، پیگیری مشکلات، اسکن امنیتی، اعلان‌ها و قابلیت‌های پیشرفته اتوماسیون است.

**چرا مفید است**: این سرور نحوه تعامل شما با GitHub را تحول می‌بخشد و تجربه کامل پلتفرم را مستقیماً به محیط توسعه شما می‌آورد. به جای جابجایی مداوم بین VS Code و GitHub.com برای مدیریت پروژه، بررسی کد و نظارت بر CI/CD، می‌توانید همه چیز را از طریق دستورات زبان طبیعی در حالی که روی کدتان متمرکز هستید انجام دهید.

> **ℹ️ نکته: انواع مختلف 'Agent' ها**
> 
> سرور GitHub MCP را با GitHub Coding Agent (عامل هوش مصنوعی که می‌توانید به آن مسائل را برای وظایف کدگذاری خودکار واگذار کنید) اشتباه نگیرید. سرور GitHub MCP در حالت Agent VS Code کار می‌کند تا ادغام API GitHub را ارائه دهد، در حالی که GitHub Coding Agent یک ویژگی جداگانه است که هنگام اختصاص دادن به مسائل GitHub، درخواست کشش ایجاد می‌کند.

**قابلیت‌های کلیدی شامل**:
- **⚙️ GitHub Actions**: مدیریت کامل خط لوله CI/CD، نظارت بر گردش‌کار و مدیریت مصنوعات
- **🔀 درخواست‌های کشش**: ایجاد، بررسی، ادغام و مدیریت درخواست‌ها با پیگیری جامع وضعیت
- **🐛 مسائل**: مدیریت کامل چرخه عمر مسائل، نظرگذاری، برچسب‌گذاری و تخصیص
- **🔒 امنیت**: هشدارهای اسکن کد، کشف رازها و ادغام Dependabot
- **🔔 اعلان‌ها**: مدیریت هوشمند اعلان‌ها و کنترل اشتراک مخزن
- **📁 مدیریت مخزن**: عملیات فایل، مدیریت شاخه و مدیریت مخزن
- **👥 همکاری**: جستجوی کاربران و سازمان‌ها، مدیریت تیم و کنترل دسترسی

**کاربرد واقعی**: "یک درخواست کشش از شاخه ویژگی من ایجاد کن"، "تمام اجرای‌های CI ناموفق این هفته را نشان بده"، "هشدارهای امنیتی باز برای مخازن من را فهرست کن" یا "همه مسائل اختصاص‌داده شده به من در سازمان‌هایم را پیدا کن"

**سناریوی کامل دمو**: در اینجا یک گردش کار قدرتمند است که قابلیت‌های سرور GitHub MCP را نشان می‌دهد:

> "من باید برای بازبینی اسپرینت آماده شوم. تمام درخواست‌های کششی که این هفته ایجاد کرده‌ام را نشان بده، وضعیت خطوط لوله CI/CD ما را بررسی کن، خلاصه‌ای از هر هشدار امنیتی که باید به آن رسیدگی کنیم بساز، و به من کمک کن یادداشت‌های انتشار را بر اساس درخواست‌های کشش ادغام‌شده با برچسب 'feature' تهیه کنم."

سرور GitHub MCP این موارد را انجام خواهد داد:
- پرس‌وجوی درخواست‌های کشش اخیر شما با اطلاعات دقیق وضعیت
- تحلیل اجرای گردش‌کار و برجسته کردن هرگونه شکست یا مشکلات عملکرد
- جمع‌بندی نتایج اسکن امنیتی و اولویت‌بندی هشدارهای بحرانی
- ایجاد یادداشت‌های انتشار جامع با استخراج اطلاعات از درخواست‌های کشش ادغام‌شده
- ارائه گام‌های عملی بعدی برای برنامه‌ریزی اسپرینت و آماده‌سازی انتشار

**مثال برجسته**: من عاشق استفاده از این برای گردش کار بررسی کد هستم. به جای رفت‌وآمد بین VS Code، اعلان‌های GitHub و صفحات درخواست کشش، می‌توانم بگویم "تمام PR هایی که منتظر بازبینی من هستند را نشان بده" و سپس "یک نظر به PR شماره ۱۲۳ اضافه کن و درباره مدیریت خطا در روش احراز هویت سؤال بپرس." این سرور تماس‌های API GitHub را مدیریت می‌کند، زمینه بحث را حفظ می‌کند و حتی در نوشتن نظرات بازبینی سازنده‌تر کمک می‌کند.

**گزینه‌های احراز هویت**: سرور از OAuth (یکپارچه در VS Code) و توکن‌های دسترسی شخصی پشتیبانی می‌کند، با مجموعه ابزارهای پیکربندی‌شده تا فقط قابلیت‌های GitHub مورد نیاز شما را فعال کند. می‌توانید آن را به‌عنوان سرویس میزبانی شده از راه دور برای راه‌اندازی فوری اجرا کنید یا به‌صورت محلی با Docker برای کنترل کامل.

> **💡 نکته حرفه‌ای**
> 
> فقط مجموعه ابزارهایی را که نیاز دارید با پارامتر `--toolsets` در تنظیمات سرور MCP خود فعال کنید تا اندازه زمینه کاهش یابد و انتخاب ابزار هوش مصنوعی بهبود یابد. به عنوان مثال، برای جریان‌های کاری توسعه اصلی، `"--toolsets", "repos,issues,pull_requests,actions"` را به آرگومان‌های پیکربندی MCP اضافه کنید، یا اگر عمدتاً به قابلیت‌های نظارت GitHub نیاز دارید، `"--toolsets", "notifications, security"` را استفاده کنید.

**چرا مفید است**: ضروری برای جریان‌های کاری مستندسازی مدرن! MarkItDown طیف گسترده‌ای از فرمت‌های فایل را پشتیبانی می‌کند در حالی که ساختار بحرانی سند مانند عناوین، فهرست‌ها، جدول‌ها و لینک‌ها را حفظ می‌کند. بر خلاف ابزارهای استخراج متن ساده، تمرکز آن بر حفظ معنی مفهومی و قالب‌بندی‌ای است که برای هر دو پردازش هوش مصنوعی و خوانایی انسان ارزشمند است.

- **فایل‌های رسانه‌ای**: تصاویر (با متادیتای EXIF و OCR)، صوت (با متادیتای EXIF و رونویسی گفتار)
- **محتوای وب**: HTML، خوراک‌های RSS، آدرس‌های یوتیوب، صفحات ویکی‌پدیا
- **فرمت‌های داده‌ای**: CSV، JSON، XML، فایل‌های ZIP (محتویات را به صورت بازگشتی پردازش می‌کند)
- **فرمت‌های انتشاراتی**: EPub، دفترچه‌های یادداشت Jupyter (.ipynb)
- **ایمیل**: پیام‌های Outlook (.msg)
- **پیشرفته**: ادغام Azure Document Intelligence برای پردازش پیشرفته PDF

**قابلیت‌های پیشرفته**: MarkItDown پشتیبانی از توصیف تصاویر با قدرت LLM (هنگام ارائه با کلاینت OpenAI)، ادغام Azure Document Intelligence برای پردازش پیشرفته PDF، رونویسی صوتی برای محتوای گفتار، و یک سیستم افزونه برای افزودن فرمت‌های فایل اضافی را دارد.

**استفاده در دنیای واقعی**: «این ارائه پاورپوینت را به Markdown تبدیل کن برای سایت مستندسازی ما»، «متن این PDF را با ساختار صحیح عناوین استخراج کن»، یا «این صفحه گسترده اکسل را به فرمت جدول قابل خواندن تبدیل کن»

**مثال برجسته**: نقل قول از [مستندات MarkItDown](https://github.com/microsoft/markitdown#why-markdown):

> Markdown بسیار نزدیک به متن ساده است، با حداقل نشانه‌گذاری یا قالب‌بندی، اما هنوز روشی برای نشان دادن ساختار مهم سند فراهم می‌کند. مدل‌های قدرتمند LLM، مانند GPT-4o از OpenAI، به طور بومی "به زبان" Markdown صحبت می‌کنند و اغلب بدون درخواست قبلی Markdown را در پاسخ‌های خود وارد می‌کنند. این نشان می‌دهد که آنها روی حجم زیادی از متن قالب‌بندی شده به Markdown آموزش دیده‌اند و آن را به خوبی درک می‌کنند. به عنوان مزیت جانبی، قراردادهای Markdown همچنین بسیار بهینه از نظر توکن‌ها هستند.

MarkItDown واقعاً در حفظ ساختار سند خوب عمل می‌کند، که برای جریان‌های کاری هوش مصنوعی اهمیت دارد. برای مثال، هنگام تبدیل یک ارائه پاورپوینت، سازماندهی اسلایدها با عناوین مناسب را حفظ می‌کند، جدول‌ها را به جدول‌های Markdown استخراج می‌کند، متن جایگزین تصاویر را وارد می‌کند، و حتی یادداشت‌های سخنران را پردازش می‌کند. نمودارها به جدول‌های داده قابل خواندن تبدیل می‌شوند، و Markdown نهایی جریان منطقی ارائه اصلی را حفظ می‌کند. این باعث می‌شود برای وارد کردن محتوای ارائه به سیستم‌های هوش مصنوعی یا ایجاد مستندات از اسلایدهای موجود عالی باشد.

**مثال برجسته**: به عنوان یک توسعه‌دهنده، من در دنبال کردن مدل‌های LLM مختلف کمی مشکل داشتم. چند مدل اصلی را می‌شناسم، اما احساس می‌کردم فرصت‌های بهره‌وری و کارایی را از دست می‌دهم. همچنین توکن‌ها و سهمیه‌ها استرس‌زا و سخت مدیریت می‌شدند – هرگز مطمئن نبودم که مدل مناسب برای هر کار را انتخاب کرده‌ام یا بودجه‌ام را به طور ناکارآمد مصرف می‌کنم. همین امروز درباره این سرور MCP از جیمز مونتمگنو شنیدم وقتی با هم‌تیمی‌ها در مورد توصیه‌های سرور MCP صحبت می‌کردم و هیجان‌زده‌ام که از آن استفاده کنم! قابلیت‌های کشف مدل به خصوص برای کسی مثل من که می‌خواهد فراتر از مدل‌های معمولی اکتشاف کند و مدل‌های بهینه‌شده برای وظایف خاص را پیدا کند، بسیار چشمگیر است. چارچوب ارزیابی هم باید به من کمک کند اطمینان حاصل کنم که واقعاً نتایج بهتری می‌گیرم، نه صرفاً چیزی جدید را برای تنوع امتحان می‌کنم.

> **ℹ️ وضعیت آزمایشی**
>
> این سرور MCP آزمایشی است و در حال توسعه فعال می‌باشد. ویژگی‌ها و APIها ممکن است تغییر کنند. عالی برای کشف قابلیت‌های هوش مصنوعی Azure و ساخت نمونه‌های اولیه، اما برای استفاده در تولید پایداری آن را بررسی کنید.
### 10. 🏢 سرور ابزارک عامل‌های Microsoft 365 MCP

[![نصب در VS Code](https://img.shields.io/badge/VS_Code-Install_M365_Agents_Toolkit-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=M365AgentsToolkit%20Server&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22@microsoft%2Fm365agentstoolkit-mcp%40latest%22%2C%22server%22%2C%22start%22%5D%7D) [![نصب در VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_M365_Agents_Toolkit-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=M365AgentsToolkit%20Server&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22@microsoft%2Fm365agentstoolkit-mcp%40latest%22%2C%22server%22%2C%22start%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/OfficeDev/microsoft-365-agents-toolkit)

**چه کاری انجام می‌دهد**: ابزارهای ضروری برای ساخت عامل‌ها و برنامه‌های هوش مصنوعی که با Microsoft 365 و Microsoft 365 Copilot ادغام می‌شوند را فراهم می‌کند، شامل اعتبارسنجی ساختار، بازیابی کد نمونه، و کمک به رفع اشکال.

**چرا مفید است**: ساخت برای Microsoft 365 و Copilot شامل ساختارهای پیچیده مانفیست و الگوهای توسعه خاص است. این سرور MCP منابع ضروری توسعه را مستقیماً به محیط کدنویسی شما می‌آورد، به شما کمک می‌کند ساختارها را اعتبارسنجی کنید، کد نمونه پیدا کنید و مشکلات رایج را بدون نیاز مکرر به مراجعه به مستندات رفع کنید.

**استفاده عملی**: "مانفیست اعلامی عاملم را اعتبارسنجی کن و هر خطای ساختاری را برطرف کن"، "کد نمونه برای پیاده‌سازی افزونه Microsoft Graph API را نشان بده"، یا "کمکم کن مشکلات احراز هویت اپ Teams را رفع کنم"

**مثال برجسته**: بعد از گفت‌وگو با جان میلر در بیلد درباره عامل‌های M365، به او مراجعه کردم و او این MCP را پیشنهاد داد. این برای توسعه‌دهندگانی که تازه با M365 Agents آشنا شده‌اند عالی است چون قالب‌ها، کد نمونه و چارچوب‌های ابتدایی برای شروع فراهم می‌کند بدون این که در مستندات غرق شوند. قابلیت‌های اعتبارسنجی ساختار به خصوص برای جلوگیری از خطاهای ساختار مانفیست که ممکن است ساعت‌ها اشکال‌زدایی بخواهد، بسیار مفید به نظر می‌رسد.

> **💡 نکته حرفه‌ای**
>
> این سرور را همراه با سرور MCP مستندات Microsoft Learn استفاده کنید تا پشتیبانی جامع توسعه M365 داشته باشید – یکی مستندات رسمی را ارائه می‌دهد و دیگری ابزارهای عملی توسعه و کمک به رفع اشکال را فراهم می‌کند.

## 📋 نتیجه‌گیری

پروتکل مدل کانتکست (MCP) نحوه تعامل توسعه‌دهندگان با دستیارهای هوش مصنوعی و ابزارهای خارجی را متحول می‌کند. این 10 سرور Microsoft MCP قدرت یکپارچه‌سازی استاندارد شده هوش مصنوعی را نشان می‌دهند که جریان کاری بی‌وقفه و متمرکز را برای توسعه‌دهندگان فراهم می‌آورد در حالی که به قابلیت‌های قدرتمند خارجی دسترسی دارند.

از ادغام جامع اکوسیستم Azure گرفته تا ابزارهای تخصصی مانند Playwright برای خودکارسازی مرورگر و MarkItDown برای پردازش اسناد، این سرورها نشان می‌دهند چگونه MCP می‌تواند بهره‌وری در سناریوهای مختلف توسعه را افزایش دهد. پروتکل استاندارد شده تضمین می‌کند که این ابزارها به طور یکپارچه با هم کار کنند و تجربه توسعه همگن ایجاد کنند.

با ادامه تکامل اکوسیستم MCP، درگیر بودن با جامعه، اکتشاف سرورهای جدید و ساخت راه‌حل‌های سفارشی کلید افزایش بهره‌وری توسعه شما خواهد بود. ماهیت استاندارد باز MCP به شما امکان می‌دهد ابزارها را از فروشندگان مختلف ترکیب کنید تا جریان کاری ایده‌آل برای نیازهای خاص خود بسازید.

## 🎯 تمرین‌ها

1. **نصب و پیکربندی**: یکی از سرورهای MCP را در محیط VS Code خود راه‌اندازی کنید و عملکرد پایه‌ای آن را تست کنید.
2. **ادغام جریان کاری**: یک جریان کاری توسعه طراحی کنید که حداقل سه سرور MCP مختلف را با هم ترکیب کند.
3. **برنامه‌ریزی سرور سفارشی**: یک وظیفه در روند روزانه توسعه خود شناسایی کنید که می‌تواند از سرور MCP سفارشی بهره‌مند شود و مشخصات آن را ایجاد کنید.
4. **تحلیل عملکرد**: کارایی استفاده از سرورهای MCP را در مقایسه با روش‌های سنتی برای وظایف رایج توسعه مقایسه کنید.
5. **ارزیابی امنیتی**: پیامدهای امنیتی استفاده از سرورهای MCP در محیط توسعه خود را ارزیابی کنید و بهترین شیوه‌ها را پیشنهاد دهید.
