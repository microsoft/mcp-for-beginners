# AGENTS.md

## ప్రాజెక్టు అవగాహన

**కొత్తవారికి MCP** అనేది Model Context Protocol (MCP) నేర్చుకోవడానికి ఓపెన్-సోర్స్ విద్యా పరీక్షాంశం - ఇది AI మోడల్స్ మరియు క్లయింట్ అప్లికేషన్స్ మధ్య పరస్పర చర్యలకు ఒక ప్రమాణీకృత నేపథ్యం. ఈ రిపాజిటరీలో వివిధ ప్రోగ్రామింగ్ భాషలలో హ్యాండ్స్-ఆన్ కోడ్ ఉదాహరణలతో సమగ్ర అధ్యయన పదార్థాలు అందుబాటులో ఉన్నాయి.

### ప్రధాన సాంకేతికతలు

- **ప్రోగ్రామింగ్ భాషలు**: C#, జావా, జావాస్క్రిప్ట్, టైప్స్ క్రిప్ట్, పైథాన్, రస్ట్
- **ఫ్రేమ్‌వర్క్‌లు & SDKలు**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - స్ప్రింగ్ బూట్ (జావా)
  - ఫాస్ట్ MCP (పైథాన్)
  - లాంగ్ చైన్4జె (జావా)
- **డేటాబేస్‌లు**: pgvector ఎక్స్‌టెన్షన్‌తో పోస్ట్గ్రెSQL
- **క్లౌడ్ ప్లాట్‌ఫారమ్‌లు**: ఆజ్యూర్ (కంటైనర్ యాప్‌లు, ఓపెన్‌ఎఏఐ, కంటెంట్ సేఫ్టీ, అప్లికేషన్ ఇన్సైట్స్)
- **బిల్డ్ టూల్స్**: npm, మేవెన్, పిప్, కార్గో
- **డాక్యుమెంటేషన్**: స్వయం-చలిత బహుభాషా అనువాదంతో మార్క్‌డౌన్ (48+ భాషలు)

### నిర్మాణం

- **11 కోర్ మోడ్యూల్స్ (00-11)**: ప్రాథమికం నుండి అధునాతన విషయాల వరుస క్రమం విద్య
- **హ్యాండ్స్-ఆన్ ల్యాబ్స్**: బహుభాషా పూర్తి పరిష్కార కోడ్‌తో ప్రాక్టికల్ వ్యాయామాలు
- **నమూనా ప్రాజెక్టులు**: పనిచేసే MCP సర్వర్ మరియు క్లయింట్ అమలు
- **అనువాద వ్యవస్థ**: బహుభాషా మద్దతు కోసం ఆటోమేటెడ్ గిట్‌హబ్ చర్యలు వర్క్‌ఫ్లో
- **జాడ చిత్రాలు**: అనువాద రూపాలతో కేంద్రీకృత చిత్రాల డైరెక్టరీ

## సెటప్ ఆజ్ఞలు

ఇది డాక్యుమెంటేషన్-ఆధారిత రిపాజిటరీ. ఎక్కువ సెటప్ ప్రత్యేక నమూనా ప్రాజెక్టులు మరియు ల్యాబ్స్‌లో జరుగుతుంది.

### రిపాజిటరీ సెటప్

```bash
# రిపాజిటరీని క్లోన్ చేయండి
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### నమూనా ప్రాజెక్టులతో పని

నమూనా ప్రాజెక్టులు ఈ చోట్ల ఉంటాయి:
- `03-GettingStarted/samples/` - భాషకు ప్రత్యేక ఉదాహరణలు
- `03-GettingStarted/01-first-server/solution/` - మొదటి సర్వర్ అమలు
- `03-GettingStarted/02-client/solution/` - క్లయింట్ అమలు
- `11-MCPServerHandsOnLabs/` - సమగ్ర డేటాబేస్ ఏకీకరణ ల్యాబ్స్

ప్రతి నమూనా ప్రాజెక్టుకు ప్రత్యేక సెటప్ సూచనలు ఉంటాయి:

#### టైప్స్క్రిప్ట్/జావాస్క్రిప్ట్ ప్రాజెక్టులు
```bash
cd <project-directory>
npm install
npm start
```

#### పైథాన్ ప్రాజెక్టులు
```bash
cd <project-directory>
pip install -r requirements.txt
# లేదా
pip install -e .
python main.py
```

#### జావా ప్రాజెక్టులు
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

#### అభ్యర్ధిత MCP టూల్ వర్క్‌ఫ్లో: `validate_curriculum_change`

##### లక్ష్యం

సిలబస్ డాక్యుమెంటేషన్ మార్పులు మరియు ప్రతినిధి నమూనా కోడ్
ఆరోగ్యాన్ని విలీనం ముందు నిర్ధారించండి.

##### ఇన్‌పుట్‌లు

- `changed_paths: string[]` (అవసరం) - PRలో మార్చబడిన సంబంధిత మార్గాలు.
- `run_docs_lint: boolean` (డిఫాల్ట్ `true`)
- `run_links_audit: boolean` (డిఫాల్ట్ `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (డిఫాల్ట్ అంతా `false`)

##### అవుట్పుట్‌లు

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### అనుమతులు

- వర్క్‌స్పేస్ ఫైళ్లను చదవండి మరియు సాధన-సృష్టించిన ఆర్టిఫాక్ట్‌లను మాత్రమే వ్రాయండి (ఉదా: లింట్
  నివేదికలు, పరీక్షా లాగ్‌లు); `translations/` లేదా
  `translated_images/`లో వ్రాయవద్దు.
- స్థానిక షెల్ ఆదేశాలను అమలు చేయండి.
- ప్యాకేజీ రీస్టోర్ (`npm ci`,
  `python -m pip install`, `mvn` ఆధారపడి నెట్‌వర్క్ యాక్సెస్ మాత్రమే ఐచ్ఛికం).
- `translations/` లేదా
  `translated_images/`లో పుష్, మерж్ లేదా మార్పులు చేయడం అనుమతించదు.

##### విఫలమయ్యే పరిస్థితులు

- `E_NO_INPUT_PATHS`: `changed_paths` ఖాళీగా ఉంది.
- `E_INVALID_PATH`: ఇన్‌పుట్ మార్గం రిపాజిటరీ రూట్ నుండి తప్పిపోయింది.
- `E_LINT_FAILED`: మార్క్‌డౌన్ లింట్ తప్పుగా ముగిసింది.
- `E_LINK_AUDIT_FAILED`: లింక్ ఆడిట్ ఆదేశం తప్పుగా ముగిసింది.
- `E_SAMPLE_TEST_FAILED`: నమూనా పరీక్ష/బిల్డ్ తప్పుగా ముగిసింది.
- `E_TIMEOUT`: ఆదేశం నిర్దేశిత సమయ పరిమితిని దాటి ఉంది.

##### సిఫార్సు చేసిన CI ఒప్పందం

నిర్ధారణ ఆటోమేషన్ కోసం CI పని ఏర్పాటుచేయండి:

- `*.md`, నమూనా కోడ్, లేదా ఈ ఫైల్‌ను టచ్ చేసే పుల్ రిక్వెస్ట్‌లపై ట్రిగ్గర్ అవుతుంది.
- మించి పేర్కొన్న ఖచ్చితమైన ఆదేశాలను నడుపుతుంది.
- లాగ్‌లను ఆర్టిఫాక్ట్‌లుగా నిల్వచేస్తుంది.
- ఏదైనా నాన్-జీరో ఎగ్జిట్ కోడ్‌పై పని విఫలమవుతుంది.

## బిల్డ్ మరియు డిప్లాయ్‌మెంట్

### డాక్యుమెంటేషన్ డిప్లాయ్‌మెంట్

రిపాజిటరీ GitHub పేజెస్ లేదా సమాన సేవలను డాక్యుమెంటేషన్ హోస్టింగ్ కోసం ఉపయోగిస్తుంటుంది (అన్వయిస్తే). మెయిన్ బ్రాంచ్‌కు మార్పులు ట్రిగ్గర్ చేస్తాయి:
