# 🚀  డెవలపర్ ఉత్పాదకతను పరివర్తనం చేస్తున్న 10 Microsoft MCP సర్వర్లు

## 🎯 ఈ మార్గదర్శకంలో మీరు నేర్చుకోబోతున్న విషయం

ఈ ప్రాయోగిక మార్గదర్శకంలో డెవలపర్లు AI సహాయకులతో ఎలా పనిచేస్తున్నారో మార్చేస్తున్న దశాబ్దం Microsoft MCP సర్వర్లను చూపిస్తారు. MCP సర్వర్లు *ఏం* చేయగలవో మాత్రమే వివరిస్తూ కాక, ఇప్పటికే Microsoft మరియు ఇతర చోట్ల రోజువారీ అభివృద్ధి వర్క్‌ఫ్లోల్లో రియల్ ప్రభావం చూపుతున్న సర్వర్లను మేము చూపిస్తాము.

ఈ మార్గదర్శకంలో ప్రతి సర్వర్ వాస్తవ జీవిత వినియోగం మరియు డెవలపర్ అభిప్రాయాల ఆధారంగా ఎంచుకోబడింది. మీరు ప్రతి సర్వర్ ఏమి చేస్తుందో మాత్రమే కాకుండా దాని ముఖ్య్యత ఏంటి, మీ స్వంత ప్రాజెక్టుల్లో ఎక్కువ ప్రయోజనం ఎలా పొందవచ్చో తెలుసుకుంటారు. మీరు MCP కి పూర్తిగా కొత్తవారైనా లేదా ఉన్న సెటప్ ని విస్తరించుకోవాలనుకునే వారు అయినా, ఈ సర్వర్లు Microsoft పర్యావరణంలో అందుబాటులో ఉన్న కొన్ని అత్యంత ప్రాయోగిక మరియు ప్రభావవంతమైన పరికరాలను సూచిస్తాయి.

> **💡 త్వరిత ప్రారంభ సూచన**
>
> MCP కొత్తవారా? కోవ్వద్దు! ఈ మార్గదర్శకం ఆరంభదశ కోసం రూపొందించబడింది. మేము ఆలోచనలను వివరించబోతున్నాము, మరియు మీరు ఎప్పుడైనా మా [MCP పరిచయం](../00-Introduction/README.md) మరియు [ప్రధాన భావనల](../01-CoreConcepts/README.md) మాడ్యూల్స్ కి వెనుకబడవచ్చు.

## అవలోకనం

ఈ సమగ్ర మార్గదర్శకం డెవలపర్లు AI సహాయకులు మరియు బాహ్య పరికరాలతో ఎలా సంభాషిస్తున్నారో మారుస్తున్న 10 Microsoft MCP సర్వర్లను పరిశీలిస్తుంది. Azure వనరుల నిర్వహణ నుండి డాక్యుమెంట్ ప్రాసెసింగ్ వరకు, ఈ సర్వర్లు మోడల్ కాంటెక్ట్స్ ప్రోటోకాల్ శక్తిని నిరూపిస్తాయి, సమగ్ర, ఉత్పాదక అభివృద్ధి వర్క్‌ఫ్లోలను సృష్టిస్తున్నాయి.

## నేర్చుకునే లక్ష్యాలు

ఈ మార్గదర్శకం చివరికి, మీరు:
- MCP సర్వర్లు డెవలపర్ ఉత్పాదకతను ఎలా పెంచుతాయో అర్థం చేసుకోండి
- Microsoft యొక్క అత్యంత ప్రభావవంతమైన MCP సర్వర్ అమలులను తెలుసుకోండి
- ప్రతి సర్వర్ కోసం ప్రాయోగిక ఉపయోగాల విషయాలు తెలుసుకోండి
- VS Code మరియు Visual Studio లో ఈ సర్వర్లను ఎలా సెటప్ చేసుకోవచ్చో తెలుసుకోండి
- MCP విస్తృత పర్యావరణం మరియు భవిష్య దిశలను అన్వేషించండి

## 🔧 MCP సర్వర్ల అర్థం చేసుకోటం: ఒక ఆరంభిక మార్గదర్శకం

### MCP సర్వర్లు అంటే ఏమిటి?

మోడల్ కాంటెక్ట్స్ ప్రోటోకాల్ (MCP) లో కొత్తవారి కోసం, మీరు అనుకున్నవారు: "MCP సర్వర్ అనేది ఏమిటి, మరియు నేను దాని గురించి ఎందుకు శ్రద్ధ చూపాలి?" సులభమైన ఉదాహరణతో ప్రారంభిద్దాం.

MCP సర్వర్లను ప్రత్యేక సహాయకులుగా భావించండి, ఇవి మీ AI కోడింగ్ సహాయకుడు (GitHub Copilot వంటి) బాహ్య పరికరాలు మరియు సేవలతో కనెక్ట్ అవ్వడానికి సహాయపడతాయి. మీరు మీ ఫోన్ లో వేరే వేరే పనుల కోసం వేరే వేరే యాప్స్ ఉపయోగించే విధంగా—ఒకటి వాతావరణం కోసం, ఒకటి నావిగేషన్ కోసం, మరోటి బ్యాంకింగ్ కోసం—MCP సర్వర్లు మీ AI సహాయకుడికి వేరే వేరే అభివృద్ధి పరికరాలు మరియు సేవలతో సంభాషించడానికి సామర్ధ్యాన్ని ఇస్తాయి.

### MCP సర్వర్లు ఎదుటి సమస్య ఏమిటి?

MCP సర్వర్లు వచ్చెప్పటికీ, మీరు ఇలా చేయాలని అనుకుంటే:
- మీ Azure వనరులను తనిఖీ చేయండి
- GitHub ఇష్యూ సృష్టించండి
- మీ డేటాబేస్ ను ప్రశ్నించండి
- డాక్యుమెంటేషన్ లో శోధించండి

మీరు కోడింగ్ ఆపి, బ్రౌజర్ తెరవాలి, సరైన వెబ్‌సైట్‌కు వెళ్లి, ఈ పనులను చేయాలి. ఈ నిరంతర సందర్భ మార్పు మీ ఫ్లో మూలంగా productivity తగ్గిస్తుంది.

### MCP సర్వర్లు మీ అభివృద్ధి అనుభవాన్ని ఎలా మార్చుతాయో

MCP సర్వర్లతో, మీరు మీ అభివృద్ధి వాతావరణంలోనే (VS Code, Visual Studio వంటివి) ఉండి, ఈ పనులను AI సహాయకుడికి చేయమని చెప్పవచ్చు. ఉదాహరణకి:

**సాంప్రదాయ వర్క్‌ఫ్లో ఇలాగే ఉంటుంది:**
1. కోడింగ్ ఆపు
2. బ్రౌజర్ తెట్టు
3. Azure పోర్టల్ కి వెళ్ళు
4. స్టోరేజ్ అకౌంట్ల వివరాలు చూడండి
5. VS Code కి తిరిగి వచ్చి
6. కోడింగ్ కొనసాగించు

**ఇప్పుడు మీరు ఈ విధంగా చేయవచ్చు:**
1. AI ని అడగండి: "నా Azure స్టోరేజ్ అకౌంట్ల స్థితి ఏమిటి?"
2. అందిన సమాచారంతో కోడింగ్ కొనసాగించండి

### కొత్తవారికి ముఖ్యమైన లాభాలు

#### 1. 🔄 **మీ ఫ్లో స్థితిలోనే ఉండండి**
- పలు అప్లికేషన్ల మధ్య మార్పిడి చేయాల్సిన అవసరం లేదు
- మీరు రాస్తున్న కోడింగ్ పై మీ దృష్టి ఉంచుకోండి
- వేరే పరికరాలు నిర్వహించడం వల్లమెంత మానసిక ఒత్తిడి తగ్గిస్తుంది

#### 2. 🤖 **జటిల ఆజ్ఞల బదులు సహజ భాష ఉపయోగించండి**
- SQL సింటాక్స్ మర్చిపోకుండా మీరు కావలసిన డేటాను వివరించండి
- Azure CLI ఆజ్ఞలను జ్ఞాపకం పెట్టుకోవద్దు, మీరు ఏం సాధించాలనుకుంటున్నారో చెప్పండి
- AI కి సాంకేతిక విషయాలు నిర్వహించడానికి అవకాశం ఇవ్వండి, మీరు లాజిక్ మీద దృష్టి పెట్టండి

#### 3. 🔗 **వెండర్ల వేర్వేరు పరికరాలను కలపండి**
- వేరే సేవలను కలుపుకుని శక్తివంతమైన వర్క్‌ఫ్లోలను సృష్టించండి
- ఉదాహరణకి: "అంతిమ GitHub ఇష్యూలను పొందండి మరియు సంబంధిత Azure DevOps వర్క్ ఐటంలను సృష్టించండి"
- కష్టమైన స్క్రిప్టులు రాయకుండా ఆటోమేషన్ ఉపయోగించండి

#### 4. 🌐 **వృద్ధిపొందుతున్న పర్యావరణానికి ప్రాప్తి**
- Microsoft, GitHub మరియు ఇతర కంపెనీలు అందించిన సర్వర్ల లాభం పొందండి
- విభిన్న వెండర్ల పరికరాలను సులువుగా కలయండి
- వివిధ AI సహాయకులతో పనిచేసే ప్రమాణీకృత పర్యావరణంలో పాల్గొనండి

#### 5. 🛠️ **చేయడం ద్వారా నేర్చుకోండి**
- భావనలను అర్థం చేసుకోవటానికి ప్రీ-బిల్ట్ సర్వర్లతో మొదలుపెట్టు
- మరింత సౌకర్యంగా ఉన్నప్పుడు మీ సొంత సర్వర్లను నిర్మించండి
- అందుబాటులో ఉన్న SDKలు మరియు డాక్యుమెంటేషన్ ను ఉపయోగించి నేర్చుకోండి

### కొత్తవారికి వాస్తవ ప్రపంచ ఉదాహరణ

మీరు వెబ్ అభివృద్ధిలో కొత్తవారుగా ఒక మొదటి ప్రాజెక్ట్ పై పనిచేస్తున్నారని అనుకుందాం. MCP సర్వర్లు ఎలా సహాయపడతాయో ఇలా ఉంది:

**సాంప్రదాయ దృష్టికోణం:**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**MCP సర్వర్లతో:**
```
1. Code a feature
2. Ask AI: "Create a GitHub issue for testing this login feature"
3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

### సంస్థ స్థాయి ప్రమాణ ప్రయోజనం

MCP పరిశ్రమవ్యాప్తంగా ప్రమాణంగా మారుతోంది, అందువల్ల:
- **సామాన్యత**: వివిధ పరికరాల మరియు కంపెనీలలో సారూప్య అనుభవం
- **ఇంటర్‌ఓపరబిలిటీ**: వేర్వేరు వెండర్ల సర్వర్లు కలిసి పనిచేస్తాయి
- **భవిష్యత్ రక్షణ**: నైపుణ్యాలు మరియు సెటప్ లు వివిధ AI సహాయకులకు మారవచ్చు
- **కమ్యూనిటీ**: పెద్ద పర్యావరణం, పంచుకునే జ్ఞానం మరియు వనరులు

## VS Code మరియు Visual Studio లో MCP తో ప్రారంభించండి 🚀

మీరు Visual Studio Code లేదా Visual Studio 2022 ని GitHub Copilot తో వాడుతున్నట్లయితే ఈ MCP సర్వర్ల సెటప్ సులభం.

### VS Code సెటప్

VS Code కోసం ప్రాథమిక ప్రక్రియ ఇలాంటిది:

1. **ఏజెంట్ మోడ్ ని ఆన్ చేయండి**: VS Code లో Copilot చాట్ విండో లో ఏజెంట్ మోడ్ కి మార్చండి
2. **MCP సర్వర్లను కాన్ఫిగర్ చేయండి**: మీ VS Code settings.json ఫైల్ లో సర్వర్ కాన్ఫిగరేషన్లు జత చేయండి
3. **సర్వర్లను ప్రారంభించండి**: మీరు వాడదలచిన ప్రతి సర్వర్ కోసం "స్టార్ట్" బటన్‌ను నొక్కండి
4. **పరికరాలను ఎంచుకోండి**: ప్రస్తుతం సెషన్ కోసం ఏ MCP సర్వర్లను ఆన్ చేయాలో ఎంచుకోండి

పూర్తి సెటప్ సూచనల కోసం [VS Code MCP డాక్యుమెంటేషన్](https://code.visualstudio.com/docs/copilot/copilot-mcp) చూడండి.

> **💡 ప్రొ టిప్: MCP సర్వర్లను ప్రొఫెషనల్ లా నిర్వహించండి!**
>
> VS Code ఎక్స్‌టెన్షన్స్ వ్యూ ఇప్పుడు [సులభమైన ఇంటర్‌ఫేస్ తో MCP సర్వర్లను నిర్వహించడానికి కొత్త UI](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode) కలిగి ఉంది! మీరు ఇన్‌స్టాల్ చేసిన MCP సర్వర్స్ మీథో స్టార్ట్, స్టాప్ మరియు మేనేజ్ చేయటానికి తేలికైన UI ఉపయోగించవచ్చు. ప్రయత్నించండి!

### Visual Studio 2022 సెటప్

Visual Studio 2022 (వర్షన్ 17.14 లేదా తర్వాత) కోసం:

1. **ఏజెంట్ మోడ్ ఆన్ చేయండి**: GitHub Copilot చాట్ విండోలో "Ask" డ్రాప్‌డౌన్ నొక్కి "Agent" ని ఎంచుకోండి
2. **కాన్ఫిగరేషన్ ఫైల్ సృష్టించండి**: మీ సొల్యూషన్ డైరెక్టరీలో `.mcp.json` ఫైల్ సృష్టించండి (సిఫార్సు చేయబడిన ప్రదేశం: `<SOLUTIONDIR>\.mcp.json`)
3. **సర్వర్లను కాన్ఫిగర్ చేయండి**: స్టాండర్డ్ MCP ఫార్మాట్ ను ఉపయోగించి MCP సర్వర్ కాన్ఫిగరేషన్లు జత చేయండి
4. **పరికరాల అనుమతి**: మీరు వాడదలచిన పరికరాలకు సరైన స్కోప్ అనుమతులు ఇచ్చి ఆమోదించండి

పూర్తి Visual Studio సెటప్ సూచనల కోసం [Visual Studio MCP డాక్యుమెంటేషన్](https://learn.microsoft.com/visualstudio/ide/mcp-servers) చూడండి.

ప్రతి MCP సర్వర్ జత సంబంధించిన కాన్ఫిగరేషన్ అవసరాలు (కనెక్షన్ స్ట్రింగ్స్, ధృవీకరణ మొదలైనవి) ఉంటాయి, కానీ సెటప్ నమూనా ఇరు IDEలలో సారూప్యం.

**ఎందుకు ఉపయోగకరం**: ఇది కేవలం "డాక్యుమెంటేషన్" లా కనిపించినప్పటికీ, Microsoft సాంకేతికతలను ఉపయోగించే ప్రతి డెవలపర్‌కు ఇది అత్యంత కీలకం. .NET డెవలపర్లు AI కోడింగ్ సహాయకులు తాజా .NET మరియు C# విడుదలలపై అప్‌డేట్ కాకపోవటం గురించి ఎక్కువ ఫిర్యాదులు ఉంటాయి. Microsoft Learn Docs MCP సర్వర్ తాజా డాక్యుమెంటేషన్, API సూచనలు, ఉత్తమ పద్ధతులపై రియల్-టైమ్ ప్రాప్తిని అందించడం ద్వారా దీన్ని పరిష్కరిస్తుంది. మీరు తాజా Azure SDKలను ఉపయోగిస్తున్నా, కొత్త C# 13 ఫీచర్లను అన్వేషిస్తున్నా లేదా కటింగ్-ఎడ్జ్ Aspire నమూనాలు అమలు చేస్తున్నా, ఈ సర్వర్ మీ AI సహాయకుడు సరిగా, ఆధునిక కోడ్ సృష్టించేందుకు అధికారిక, తాజా సమాచారాన్ని అందించడానికి సహాయపడుతుంది.

**వాస్తవ జీవిత వినియోగం**: "ఆధికారిక Microsoft Learn డాక్యుమెంటేషన్ ప్రకారం Azure కంటైనర్ యాప్ సృష్టించడానికి az cli ఆజ్ఞలు ఏమిటి?" లేదా "ASP.NET Core లో Entity Framework ని డిపెండెన్సీ ఇన్జెక్షన్ తో ఎలా లెక్కించాలి?" లేదా "ఈ కోడ్ Microsoft Learn డాక్యుమెంటేషన్ లోని పనితీరు సిఫార్సులను సరైనదిగా అనుసరిస్తుందో పరిశీలించండి." సర్వర్ Microsoft Learn, Azure డాక్స్, Microsoft 365 డాక్యుమెంటేషన్ పై సమగ్ర కవరేజి ఇస్తుంది, అడ్వాన్స్డ్ సేమాంటిక్ శోధనను ఉపయోగించి అత్యంత సార్వత్రిక సంబంధిత సమాచారం కనుగొంటుంది. ఇది10 వరకు ఉన్న ఆర్టికల్ శీర్షికలు మరియు URLs తో నాణ్యమైన కంటెంట్ చంక్స్ ను అందిస్తుంది, ఎప్పుడైనా తాజా Microsoft డాక్యుమెంటేషన్ ను పొందుతుంది.

**ప్రదర్శించబడిన ఉదాహరణ**: ఈ సర్వర్ `microsoft_docs_search` టూల్ ను అందిస్తుంది, ఇది Microsoft అధికారిక సాంకేతిక డాక్యుమెంటేషన్ తో సేమాంటిక్ శోధన చేస్తుంది. ఒకసారి కాన్ఫిగర్ చేసిన తర్వాత, మీరు "ASP.NET Core లో JWT ఆథెంటికేషన్ ఎలాగు అమలు చేయాలి?" అని అడిగి, వాస్తవిక, అధికారిక సమాధానాలు మూల లింకులతో పొందవచ్చు. శోధన నాణ్యత అత్యుత్తమం ఎందుకంటే ఇది సందర్భాన్ని అర్థం చేసుకుంటుంది – ఉదాహరణకు Azure సందర్భంలో "కంటైనర్లు" గురించి అడిగితే Azure కంటైనర్ ఇన్స్టెంట్స్ డాక్యుమెంటేషన్ వస్తుంది, అదే పదం .NET సందర్భంలో అడిగితే సంబంధిత C# కలెక్షన్ సమాచారం వస్తుంది.

ఇది త్వరగా మారే లేదా ఇటీవల నవీకరించబడిన లైబ్రరీలు మరియు వినియోగానికి ఎంతో ఉపయోగకరం. ఉదాహరణకి, ఇటీవల కొన్ని కోడింగ్ ప్రాజెక్టుల్లో నేను Aspire మరియు Microsoft.Extensions.AI తాజా విడుదలల ఫీచర్లు ఉపయోగించాలనుకున్నప్పుడు, Microsoft Learn Docs MCP సర్వర్ కలుపుకోవడం వలన నేను కేవలం API డాక్స్ మాత్రమే కాకుండా, తాజాగా ప్రచురించబడిన వాక్‌త్రూ మరియు మార్గదర్శకాలను వాడుకోవచ్చు.

**ఏమి చేస్తుంది**: Azure MCP సర్వర్ అనేది 15+ ప్రత్యేక Azure సేవ కनेक్టర్లు కలిగిన సమగ్ర సూట్, ఇది మొత్తం Azure ఎకోసిస్టమ్‌ను మీ AI వర్క్‌ఫ్లోలోకి తీసుకువస్తుంది. ఇది కేవలం ఒకే సర్వర్ కాదె – ఇది రిసోర్స్ నిర్వహణ, డేటాబేస్ కనెక్టివిటీ (PostgreSQL, SQL Server), Azure Monitor లాగ్ విశ్లేషణ KQLతో, Cosmos DB ఇంటిగ్రేషన్, మరియు ఇంకెన్నో వాటిని కలిగిన శక్తివంతమైన సేకరణ.

**దీన్ని ఉపయోగించడం ఎందుకు ముఖ్యమైంది**: కేవలం Azure వనరులను నిర్వహించడమే కాకుండా, ఈ సర్వర్ Azure SDKsతో పని చేస్తున్నప్పుడు కోడ్ నాణ్యతను క్షణికంగా మెరుగుపరుస్తుంది. మీరు Azure MCPని Agent మోడ్‌లో ఉపయోగిస్తే, ఇది కేవలం కోడ్ రాయడం మాత్రమే కాకుండా, *మంచి* Azure కోడ్ రాయటానికి సహాయపడుతుంది, ఇది ప్రస్తుత ధృవీకరణ నమూనాలను, దోష నిర్వహణ ఉత్తమ ప్రవర్తనలను అనుసరిస్తుంది మరియు తాజా SDK ఫీచర్లను వినియోగిస్తుంది. సాధారణంగా పని చేసే కోడ్ పొందడానికి బದಲು, మీరు ఉత్పత్తి వర్క్లోడ్లకు అనుగుణంగా Azure సిఫార్సు చేసిన నమూనాలను అనుసరించే కోడ్ పొందుతారు.

**ప్రధాన మాడ్యూల్స్‌లో ఉన్నాయి**:
- **🗄️ డేటాబేస్ కనెక్టర్లు**: Azure డేటాబేస్ కోసం PostgreSQL మరియు SQL Serverకి ప్రత్యక్ష సహజ భాషా యాక్సెస్
- **📊 Azure మానిటర్**: KQL ఆధారిత లాగ్ విశ్లేషణ మరియు ఆపరేషనల్ ఇన్సైట్స్
- **🌐 వనరు నిర్వహణ**: సంపూర్ణ Azure వనరు జీవనచక్ర నిర్వహణ
- **🔐 ధృవీకరణ**: DefaultAzureCredential మరియు నిర్వహిత గుర్తింపు నమూనాలు
- **📦 స్టోరేజ్ సర్వీసులు**: బ్లోబ్ స్టోరేజ్, క్యూయ్ స్టోరేజ్, మరియు టేబుల్ స్టోరేజ్ ఆపరేషన్లు
- **🚀 కంటైనర్ సర్వీసులు**: Azure కంటైనర్ యాప్స్, కంటైనర్ ఇన్స్‌టాన్సెస్, మరియు AKS నిర్వహణ
- **మరెన్నో ప్రత్యేక కनेक్టర్లు**

**వాస్తవ వినియోగం**: "నాకు Azure స్టోరేజ్ ఖాతాలను జాబితా చేయండి", "నా లాగ్ అనలిటిక్స్ వర్క్‌స్పేస్‌లో గత గంటలో తప్పుల కోసం క్వెరీ చేయండి", లేదా "నాకు Node.js ఉపయోగించి సరైన ధృవీకరణతో Azure అప్లికేషన్‌ని నిర్మించడంలో సహాయం చేయండి"

**పూర్తి డెమో సన్నివేశం**: ఇక్కడ Azure MCPని VS కోడ్‌లో GitHub Copilot for Azure ఎక్స్ఫెన్షన్‌తో కలిపి శక్తిని చూపించే పూర్తి వాక్‌త్రూ ఉంది. మీరు రెండింటినీ ఇన్‌స్టాల్ చేసి, ఈ విధంగా అడిగితే:

> "Python స్క్రిప్ట్ రాయండి, ఇది DefaultAzureCredential ధృవీకరణ ఉపయోగించి Azure Blob Storageకి ఫైల్ అప్‌లోడ్ చేస్తుంది. స్క్రిప్ట్ నేను ఉపయోగించే Azure స్టోరేజ్ ఖాతా 'mycompanystorage'కి కనెక్ట్ అవ్వాలి, 'documents' అనే కంటైనర్‌కు అప్‌లోడ్ చేయాలి, ప్రస్తుత టైమ్‌స్టాంప్‌తో ఒక టెస్ట్ ఫైల్ తయారు చేసి అప్‌లోడ్ చేయాలి, లోపాలను మెరుగ్గా నిర్వహించాలి మరియు స్పష్టమైన అవుట్పుట్ అందించాలి, Azure ధృవీకరణ మరియు లోప నిర్వహణ ఉత్తమ ప్రవర్తనలను అనుసరించాలి, DefaultAzureCredential ధృవీకరణ ఎలా పనిచేస్తుందో వ్యాఖ్యలతో వివరించాలి, మరియు స్క్రిప్ట్‌ను సరైన ఫంక్షన్లు మరియు డాక్యుమెంటేషన్‌తో బాగా నిర్మించాలి."

Azure MCP సర్వర్ పూర్తి ఉత్పన్న-సిద్ధ Python స్క్రిప్ట్‌ను ఉత్పత్తి చేస్తుంది:
- తాజా Azure Blob Storage SDKని సరైన అసింక్ నమూనాల్లో ఉపయోగిస్తుంది
- DefaultAzureCredentialని సమగ్ర పరివర్తన శ్రేణి వివరాలతో అమలు చేస్తుంది
- విశిష్ట Azure ఎక్సెప్షన్ రకాలతో దృఢమైన లోప నిర్వహణ కలిగి ఉంటుంది
- వనరు నిర్వహణ మరియు కనెక్షన్ హ్యాండ్లింగ్ కోసం Azure SDK ఉత్తమ ప్రవర్తనలు అనుసరిస్తుంది
- సుస్పష్ట లాగ్ మరియు సమాచారాత్మక కన్సోల్ అవుట్పుట్ అందిస్తుంది
- సరైన నిర్మాణంతో ఉన్న స్క్రిప్ట్‌ను ఫంక్షన్లు, డాక్యుమెంటేషన్, మరియు టైప్ సూచనలతో సృష్టిస్తుంది

ఈ విషయం ప్రత్యేకమైంది ఎందుకంటే Azure MCP లేకుండా, మీరు సాధారణ బ్లోబ్ స్టోరేజ్ కోడ్ పొందవచ్చు, అది పని చేసే కొంతవరకు ప్రస్తుత Azure నమూనాలను అనుసరించదు. Azure MCPతో, మీరు తాజా ధృవీకరణ పద్ధతులు, Azure-స్పెసిఫిక్ లోప పరిస్థితులను నిర్వహించే, మరియు ఉత్పన్న అప్లికేషన్లకు Microsoft సిఫార్సు చేసిన పద్ధతులను అనుసరించే కోడ్ పొందుతారు.

**ప్రదర్శన ఉదాహరణ**: నేను `az` మరియు `azd` CLIలకు సంబంధించిన నిర్దిష్ట ఆదేశాలను మర్చిపోకూడదనే బాధపడతాను. ఇది నాకు ఎప్పుడూ రెండు దశల ప్రక్రియ: మొదట సింటాక్స్ చూడాలి, ఆపై ఆదేశాన్ని 실행 చేయాలి. ఎక్కువసార్లు నేను పోర్టల్‌లోకి వెళ్లి పని చేస్తాను ఎందుకంటే CLI సింటాక్స్ నన్ను గుర్తు పెట్టుకోలేదని ఒప్పుకోవడం నాకిష్టంకాదు. నేను కావలసినదాన్ని కేవలం వివరించగలగటం అద్భుతం, ఇంకా నా IDEని వదిలించాలని లేకుండా చేయగలగటం మరింత బాగుంది!

మీరు మొదలు పెట్టడానికి ఉత్తమ ఉపయోగాల జాబితా [Azure MCP రిపాజిటరీ](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server)లో ఉంది. సమగ్ర సెటప్ గైడ్‌లు మరియు అధునాతన కాన్ఫిగరేషన్ ఎంపికల కోసం, [అధికారిక Azure MCP డాక్యుమెంటేషన్](https://learn.microsoft.com/azure/developer/azure-mcp-server/)ను చూడండి.

**ఏమి చేయగలదు**: అధికార GitHub MCP సర్వర్ GitHub యొక్క మొత్తం ఎకోసిస్టమ్‌తో సజావుగా ఇంటిగ్రేట్ అవుతుంది, హోస్టింగ్ రిమోట్ యాక్సెస్ మరియు లోకల్ డాకర్ డిప్లాయ్‌మెంట్ ఎంపికలను అందిస్తుంది. ఇది మౌలిక రిపాజిటరీ ఆపరేషన్లు కాకుండా, GitHub Actions నిర్వహణ, పుల్ రిక్వెస్ట్ వర్క్‌ఫ్లో, ఇష్యూ ట్రాకింగ్, భద్రతా స్కానింగ్, నోటిఫికేషన్లు మరియు అధునాతన ఆటోమేషన్ సామర్థ్యాలను కలిగిన సమగ్ర టూల్‌కిట్.

**దీన్ని ఉపయోగించడం ఏమిటంటే**: ఈ సర్వర్ GitHubతో మీరు ఎలా సంభాషిస్తారో మార్చేస్తుంది, పూర్తి ప్లాట్‌ఫారమ్ అనుభవాన్ని మీ డెవలప్‌మెంట్ వాతావరణంలో నేరుగా తీసుకువస్తుంది. ప్రాజెక్ట్ నిర్వహణ, కోడ్ సమీక్షలు, మరియు CI/CD గమనింపు కోసం VS కోడ్ మరియు GitHub.com మధ్య ఎప్పటికప్పుడు మారిపోవాలంటే బదులు, మీరు సహజ భాషా ఆదేశాల ద్వారా అన్ని పనులు నిర్వహించవచ్చు మరియు మీ కోడ్ మీద దృష్టి పెడతారు.

> **ℹ️ గమనిక: వివిధ రకాల 'ఏజెంట్లు'**
>
> ఈ GitHub MCP సర్వర్‌ను GitHub యొక్క కోడింగ్ ఏజెంట్ (స్వయంచాలక కోడింగ్ పనుల కోసం సమస్యలకు నియమించగల AI ఏజెంట్)తో ముడిపడకండి. GitHub MCP సర్వర్ VS కోడ్ యొక్క ఏజెంట్ మోడ్‌లో GitHub API ఇంటిగ్రేషన్ అందిస్తుంది, మరొకవైపు GitHub కోడింగ్ ఏజెంట్ GitHub ఇష్యూలకు నియమించబడినప్పుడు పుల్ రిక్వెస్ట్‌లను సృష్టిస్తుంది.

- **🔀 పుల్ రిక్వెస్ట్‌లు**: సృష్టి, సమీక్ష, విలీనం, మరియు సమగ్ర స్థితి ట్రాకింగ్‌తో PRల నిర్వహణ

- **🔒 భద్రత**: కోడ్ స్కానింగ్ అలర్ట్లు, రహస్య గుర్తింపు, మరియు Dependabot ఇంటిగ్రేషన్
- **🔔 నోటిఫికేషన్లు**: స్మార్ట్ నోటిఫికేషన్ నిర్వహణ మరియు రిపాజిటరీ సబ్‌స్క్రిప్షన్ నియంత్రణ
- **📁 రిపాజిటరీ నిర్వహణ**: ఫైల్ ఆపరేషన్లు, బ్రాంచ్ నిర్వహణ, మరియు రిపాజిటరీ అడ్మినిస్ట్రేషన్
- **👥 సహకారం**: యూజర్ మరియు సంస్థ శోధన, టీం నిర్వహణ, మరియు యాక్సెస్ నియంత్రణ

**వాస్తవ వినియోగం**: "నా ఫీచర్ బ్రాంచ్ నుంచి పుల్ రిక్వెస్ట్ సృష్టించు", "ఈ వారంలో విఫలమైన CI రన్స్ అన్ని చూపించు", "నా రిపాజిటరీలకు సంబంధించిన ఓపెన్ భద్రతా అలర్ట్లు తెలియజేయి", లేదా "నా సంస్థల దిగువన నాకు అసైన్ చేసిన అన్ని ఇష్యూలను చూపించు"

**పూర్తి డెమో సన్నివేశం**: GitHub MCP సర్వర్ సామర్థ్యాలను ప్రదర్శించే శక్తివంతమైన వర్క్‌ఫ్లో ఇక్కడ ఉంది:

> "మా స్ప్రింట్ సమీక్షకు నేను సిద్ధం కావాలి. ఈ వారంలో నేను సృష్టించిన అన్ని పుల్ రిక్వెస్ట్‌లను చూపించు, మా CI/CD పైప్‌లైన్‌ల స్థితిని తనిఖీ చేయి, ఎదురుచూపుల భద్రతా అలర్ట్స్ సంగ్రహించు, మరియు విలీనం అయిన PRల ఆధారంగా 'ఫీచర్' లేబులుతో విడుదల నోట్స్ డ్రాఫ్ట్ చేయడంలో సహాయం చేయు."

GitHub MCP సర్వర్:
- మీ తాజా పుల్ రిక్వెస్ట్‌లను సాంకేతిక వివరాలతో ప్రశ్నిస్తుంది
- వర్క్‌ఫ్లో పరుగుల విశ్లేషణ చేసి ఏవైనా విఫలాలు లేదా పనితీరు సమస్యలను హైలైట్ చేస్తుంది
- భద్రతా స్కానింగ్ ఫలితాలను సంకలనం చేసి కీలక అలర్ట్లను ప్రాధాన్యం ఇస్తుంది
- విలీనం అయిన PRల నుండి సమాచారాన్ని తీసుకుని సమగ్ర విడుదల నోట్స్ సృష్టిస్తుంది
- స్ప్రింట్ ప్రణాళిక మరియు విడుదల సిద్ధత కోసం చర్యాత్మక తదుపరి చర్యలను అందిస్తుంది

**ప్రదర్శన ఉదాహరణ**: నేను కోడ్ సమీక్ష వర్క్‌ఫ్లోలకు దీన్ని ఉపయోగించడం ఇష్టం. VS కోడ్, GitHub నోటిఫికేషన్లు, మరియు పుల్ రిక్వెస్ట్ పేజీల మధ్య జంప్ అవ్వకూడదు. నేను "నా సమీక్ష కోసం వేచిచున్న అన్ని PRలను చూపించు" అని చెబుతాను, తరువాత "PR #123కి కామెంట్ జోడించి ధృవీకరణ పద్ధతిలో దోష నిర్వహణ గురించి అడుగు" అని చెప్పగలను. సర్వర్ GitHub API పిలుపులను నిర్వహిస్తుంది, చర్చ యొక్క సందర్భాన్ని గుర్తుపెడుతుంది, మరియు మరింత నిర్మాణాత్మక సమీక్ష వ్యాఖ్యలు రాయడంలో సహాయపడుతుంది.

**ధృవీకరణ ఎంపికలు**: సర్వర్ OAuth (VS కోడ్‌లో సజావుగా) మరియు వ్యక్తిగత యాక్సెస్ టోకన్లను రెండింటినీ మద్దతు ఇస్తుంది, మీరు కావలసిన GitHub ఫంక్షనాలిటీ మాత్రమే ఎనేబుల్ చేసే కాన్ఫిగర్ అయ్యే టూల్‌సెట్‌లను అందిస్తుంది. మీరు దానిని తక్షణ సెటప్ కోసం రిమోట్ హోస్టెడ్ సర్వీసుగా లేదా పూర్తిగా నియంత్రణకోసం లోకల్‌ను డాకర్ ద్వారా నడపగలరు.

> మీ MCP సర్వర్ సెట్టింగుల్లో `--toolsets` పరామితిని కాన్ఫిగర్ చేసి మీరు అవసరం ఉన్న టూల్‌సెట్‌లను మాత్రమే ఎనేబుల్ చేయండి, తద్వారా కాంటెక్స్ట్ పరిమాణం తగ్గి AI టూల్ ఎంపిక మెరుగుపడుతుంది. ఉదాహరణకు, ప్రాథమిక అభివృద్ధి వర్క్‌ఫ్లోల కోసం `"--toolsets", "repos,issues,pull_requests,actions"`ని మీ MCP కాన్ఫిగరేషన్ argsకి జోడించండి, లేదా మీరు ప్రధానంగా GitHub గమనింపు సామర్థ్యాలను కోరితే `"--toolsets", "notifications, security"`ని ఉపయోగించండి.

**ఇది ఎందుకు ఉపయోగకరం**: ఆధునిక డాక్యుమెంటేషన్ వర్క్‌ఫ్లోల కోసం ముఖ్యమైనది! MarkItDown అనేది పెద్ద సంఖ్యలో ఫైల్ ఫార్మాట్లను నిర్వహిస్తుంది మరియు శీర్షికలు, జాబితాలు, పట్టికలు, మరియు లింకులు వంటి కీలకమైన డాక్యుమెంట్ నిర్మాణాన్ని సంరక్షిస్తుంది. సరళమైన టెక్స్ట్ ఎక్స్‌ట్రాక్షన్ టూల్స్‌తో పోలిస్తే, ఇది సాంకేతిక అర్థం మరియు ఫార్మాటింగ్‌ను కాపాడుకోవడమై ప్రాధాన్యత ఇస్తుంది, ఇది AI ప్రాసెసింగ్ మరియు మానవ పఠనానికి విలువైనది.

**మద్దతు పొందిన ఫైల్ ఫార్మాట్లు**:

- **వెబ్ కంటెంట్**: HTML, RSS ఫీడ్లు, YouTube URLs, వికీపీడియా పేజీలు
- **డేటా ఫార్మాట్లు**: CSV, JSON, XML, ZIP ఫైళ్ళు (అంతర్గత కంటెంట్లను పునరావృతంగా ప్రాసెస్ చేస్తాయి)

- **ఇమెయిల్**: Outlook సందేశాలు (.msg)
- **అదనపు**: మెరుగైన PDF ప్రాసెసింగ్ కోసం Azure Document Intelligence అనుసంధానం

**అదనపు సామర్థ్యాలు**: MarkItDown LLM ఆధారిత ఇమేజ్ వివరణలను (ఒపెన్‌ఎഐ క్లయింట్‌తో అందించినప్పుడు), మెరుగైన PDF ప్రాసెసింగ్ కోసం Azure Document Intelligence, స్పీచ్ కంటెంట్ కోసం ఆడియో ట్రాన్స్‌క్రిప్షన్, మరియు అదనపు ఫైల్ ఫార్మాట్లకు విస్తరణ కోసం ప్లగిన్ సిస్టమ్‌ను మద్దతు ఇస్తుంది.

**వాస్తవ ప్రపంచ ఉపయోగం**: "ఈ పవర్‌పాయింట్ ప్రెజెంటేషన్‌ను మన డాక్యుమెంటేషన్ సైట్ కోసం మార్క్డౌన్‌గా మార్చండి", "ఈ PDF నుంచి సరైన శీర్షిక నిర్మాణంతో టెక్స్ట్ ఎక్స్‌ట్రాక్ట్ చేయండి", లేదా "ఈ ఎక్సెల్ స్ప్రెడ్‌షీట్‌ను పఠనీయమైన పట్టిక ఫార్మాట్‌లో మార్చండి"

**ప్రధాన ఉదాహరణ**: [MarkItDown డాక్స్](https://github.com/microsoft/markitdown#why-markdown) నుండి اقتباس:

> మార్క్డౌన్ అనేది సాదా టెక్స్ట్‌కు చాలా దగ్గరగా ఉంటుంది, కనిష్ట మార్కప్ లేదా ఫార్మాటింగ్‌తో, కానీ ముఖ్యం డాక్యుమెంట్ నిర్మాణాన్ని ప్రదర్శించే మార్గాన్ని అందిస్తుంది. ప్రాచుర్యం పొందిన LLMలు, ఉదాహరణకు OpenAI యొక్క GPT-4o, సహజంగానే "మార్క్డౌన్" మాట్లాడుతాయి, మరియు తరచుగా ఎటువంటి ప్రాంప్ట్ లేకుండా వారి ప్రతిస్పందనల్లో మార్క్డౌన్‌ను చేర్చుతాయి. ఇది వారి భారీ మార్క్డౌన్-ఫార్మాట్ చేసిన టెక్స్ట్‌పై శిక్షణ పొందినట్టు సూచిస్తుంది, మరియు దీన్ని అర్థం చేసుకుంటారు. అదనంగా, మార్క్డౌన్ సాంప్రదాయాలు చాలా టోకెన్-ఫలప్రదంగా ఉంటాయి.

MarkItDown డాక్యుమెంట్ నిర్మాణాన్ని గట్టిగా కాపాడుకోవడం చాలా మంచిది, ఇది AI వర్క్‌ఫ్లోల కోసం ముఖ్యమైనది. ఉదాహరణకు, పవర్‌పాయింట్ ప్రెజెంటేషన్‌ను మార్చేటప్పుడు, ఇది స్లైడ్ క్రమబద్ధీకరణను సరైన శీర్షికలతో కాపాడుతుంది, పట్టికలను మార్క్డౌన్ పట్టికలాగా తీసుకుంటుంది, చిత్రాలకు ఆల్ట్ టెక్స్ట్ చేర్చుతుంది, మరియు స్పీకర్ నోట్లను కూడా ప్రాసెస్ చేస్తుంది. చార్ట్లు చదవదగిన డేటా పట్టికలుగా మారిపోతాయి, మరియు ఫలితంగా వచ్చిన మార్క్డౌన్ అసలు ప్రెజెంటేషన్ యొక్క తార్కిక ప్రవాహాన్ని ఎప్పటికప్పుడూ కాపాడుతుంది. ఇది ప్రెజెంటేషన్ కంటెంట్‌ను AI వ్యవస్థలకు అందించడానికి లేదా లభ్యమయ్యే స్లైడ్ల నుంచి డాక్యుమెంటేషన్ సృష్టించడానికి చాలా సరైనది.
### 6. 🗃️ SQL సర్వర్ MCP సర్వర్

**ఇది ఏమి చేస్తుంది**: SQL సర్వర్ డేటాబేసుల (ఆన్-ప్రెమైసెస్, Azure SQL లేదా ఫాబ్రిక్)కి సంభాషణాత్మక ప్రాప్తిని అందిస్తుంది

**ఇది ఎందుకు ఉపయోగకరం**: PostgreSQL సర్వర్ లాగా, Microsoft SQL కన్సిస్టమ్లో ఉంది. సరళమైన కనెక్షన్ స్ట్రింగ్‌తో కనెక్ట్ అవ్వండి మరియు సహజ భాషతో క్వెరీలు ప్రారంభించండి – మరింత సానుభూతి మార్పిడి అవసరం లేదు!

**వాస్తవ ప్రపంచ ఉపయోగం**: "గత 30 రోజుల్లో పూర్తి చేయని అన్ని ఆర్డర్స్ కనుగొనండి" అనేది సరైన SQL క్వెరీలుగా మార్చబడుతుంది మరియు ఫార్మాట్ చేయబడిన ఫలితాలను చూపిస్తుంది

**ప్రధాన ఉదాహరణ**: మీరు మీ డేటాబేస్ కనెక్షన్ ఏర్పాటుచేసిన వెంటనే, మీరు వెంటనే మీ డేటాతో సంభాషణలు ప్రారంభించవచ్చు. బ్లాగ్ పోస్ట్ ఈ విషయాన్ని సులభమైన ప్రశ్నతో చూపిస్తుంది: "మీరు ఏ డేటాబేస్‌కు కనెక్ట్ అయ్యారు?" MCP సర్వర్ సరైన డేటాబేస్ టూల్‌ను పిలిచి, మీ SQL సర్వర్ ఇన్స్టాన్స్కు కనెక్ట్ అవుతుంది మరియు ప్రస్తుత డేటాబేస్ కనెక్షన్ వివరాలను ఇస్తుంది – ఒక్క SQL లైన్ రాయకుండా. సర్వర్ విస్తృతమైన డేటాబేస్ ఆపరేషన్లను మద్దతు ఇస్తుంది, స్కీమా నిర్వహణ నుండి డేటా మేనిప్యులేషన్ వరకు, అందులో సహజ భాష ప్రాంప్ట్‌ల ద్వారా. పూర్తి సెటప్ సూచనలు మరియు VS Code, Claude Desktop‌తో కాన్ఫిగరేషన్ ఉదాహరణల కోసం, చూడండి: [Introducing MSSQL MCP Server (Preview)](https://devblogs.microsoft.com/azure-sql/introducing-mssql-mcp-server/).

దీనిని నిజంగా శక్తివంతం చేసే విషయం ఏమిటంటే ఇది సహజ భాష సూచనలు మరియు అమలు చేయదగిన పరీక్ష కోడ్ మధ్య అంతరాన్ని వదిలిస్తుంది. సంప్రదాయ విధానాలు మాన్యువల్ పరీక్ష రచన లేదా సందర్భానుగుణం కోసం కోడ్‌బేస్ ప్రాప్తిని అవసరం చేసేవి. కాని ప్లేఖ్యైట్ MCP తో, మీరు బాహ్య సైట్లను, క్లయింట్ అనువర్తనాలను, లేదా కోడ్ ప్రాప్తి లేని బ్లాక్‌బాక్స్ పరీక్షా సన్నివేశాలలో కూడా పరీక్షించవచ్చు.

**ఇది ఎందుకు ఉపయోగకరం**: అభివృద్ధి వాతావరణాల నిర్వహణను భారీగా సరళతరం చేస్తుంది! ప్రత్యేక కమాండ్‌లు గుర్తు పెట్టుకోకుండా అభివృద్ధి వాతావరణాలను సృష్టించండి, కాన్ఫిగర్ చేయండి, మరియు నిర్వహించండి.

**వాస్తవ ప్రపంచ ఉపయోగం**: "మా ప్రాజెక్ట్ కోసం తాజా .NET SDK తో కొత్త డెవ్ బాక్స్ సెట్ చేయండి మరియు కాన్ఫిగర్ చేయండి", "నా అన్ని అభివృద్ధి వాతావరణాల స్థితిని తనిఖీ చేయండి", లేదా "మన టీమ్ ప్రెజంటేషన్ల కోసం ఒక ప్రమాణీకృత డెమో వాతావరణం సృష్టించండి"

**ప్రధాన ఉదాహరణ**: వ్యక్తిగత అభివృద్ధికి డెవ్ బాక్స్ ఉపయోగించాలని నేను చాలా ఇష్టపడతాను. జేమ్స్ మాంటెమాగ్నో డెవ్ బాక్స్ యొక్క గొప్పతనం గురించి తెలుపుతుండగా నాకు ఈ విషయం తెలిసింది, ఎందుకంటే కాన్ఫరెన్స్ / హోటల్ / ఏరోప్లేన్ వైఫైను చూసుకునకుండా అక్కడ కూడా వేగంగా ఈథర్నెట్ కనెక్షన్ కలిగి ఉంటుంది. వాస్తవానికి, నేను ఇటీవల బ్రగ్స్ నుండి ఆంట్వర్ప్ బస్సు ప్రయాణిస్తుండగా నా ల్యాప్‌టాప్‌ను నా ఫోన్ హాట్‌స్పాట్‌కు జోడించి కొన్ని కాన్ఫరెన్స్ డెమో అభ్యాసం చేసాను! నా తదుపరి దశలో, బహుళ అభివృద్ధి వాతావరణాలను మరియు ప్రమాణీకృత డెమో వాతావరణాలను నిర్వహించడంపై ఎక్కువగా దృష్టి పెట్టబోతున్నాను. మరియు వినియోగదారులు మరియు సహచరుల నుండి పెద్ద ఉపయోగ కేస్‌ ఒకటి, డెవ్ బాక్స్‌ను ముందుగా కాన్ఫిగర్ చేసిన అభివృద్ధి వాతావరణాల కోసం ఉపయోగించడం. ఇరువురు సందర్భాలలో, MCP ఉపయోగించి Dev Boxలను కాన్ఫిగర్ చేసి నిర్వహించడంవల్ల సహజ భాషా పరస్పర చర్యను వినియోగించవచ్చు, అఖిల అభివృద్ధి వాతావరణంలోనే ఉండి.

### 9. 🤖 Microsoft ఫౌండ్రి MCP సర్వర్

**ఇది ఏమిటి**: మైక్రోసాఫ్ట్ ఫౌండ్రి MCP సర్వర్ అభివృద్ధి దారులకు ఆజ్యూర్ యొక్క AI ఎకోసిస్టమ్‌కి సమగ్ర ప్రాప్తి అందిస్తుంది, ఇందులో మోడల్ క్యాటలాగ్స్, డిప్లాయ్‌మెంట్ నిర్వహణ, ఆజ్యూర్ AI సెర్చ్‌తో జ్ఞాన సూచికీకరణ మరియు మూల్యాంకన సాధనాలు ఉన్నాయి. ఈ ప్రయోగాత్మక సర్వర్ AI అభివృద్ధి మరియు ఆజ్యూర్ యొక్క శక్తివంతమైన AI మౌలిక సదుపాయాల మధ్య సెతగా పనిచేస్తుంది, AI అప్లికేషన్లను నిర్మించడం, డిప్లాయ్ చేయడం మరియు మూల్యాంకనం చేయడం సులభతరం చేస్తుంది.

**ఏందుకు ఉపయోగకరం**: ఈ సర్వర్ మీరు ఆజ్యూర్ AI సేవలతో పనిచేసే విధానాన్ని మార్చేస్తుంది, ఇది సంస్థ స్థాయి AI సామర్ధ్యాలను మీ అభివృద్ధి వర్క్‌ఫ్లోలో నేరుగా తీసుకువస్తుంది. మీరు ఆజ్యూర్ పోర్టల్, డాక్యుమెంటేషన్, మరియు మీ IDE మధ్య మార్పిడి చేయాల్సిన అవసరం లేకుండా, మోడల్స్ కనుగొనడం, సేవలను డిప్లాయ్ చేయడం, జ్ఞాన పునాది నిర్వహించడం, మరియు సహజ భాషా ఆదేశాల ద్వారా AI పనితీరును అంచనా వేయవచ్చు. RAG (రిట్రీవల్-ఆగ్మెంటెడ్ జనరేషన్) అప్లికేషన్‌లను నిర్మించే అభివృద్ధిదారులకు, బహుముఖ మోడల్ డిప్లాయ్‌మెంట్‌లను నిర్వహించేందుకు లేదా సమగ్ర AI మూల్యాంకన పద్ధతులను అమలు చేయేందుకు ఇది ముఖ్యంగా శక్తివంతమైనది.

- **📚 జ్ఞాన నిర్వహణ**: ఆజ్యూర్ AI సెర్చ్ సూచికలను సృష్టించి నిర్వహించండి, డాక్‌మెంట్లను జోడించండి, సూచికలను అమర్చండి, మరియు ప్రత్యేక RAG వ్యవస్థలను నిర్మించండి

**ప్రదర్శన ఉదాహరణ**: ఒక అభివృద్ధిదారుగా, అందుబాటులో ఉన్న వివిధ LLM మోడల్స్‌తో కుదుర్చుకోవడంలో నేను చిక్కుకున్నాను. కొన్ని ప్రధానమైనవన్నీ నాకు తెలుసు, కాని నేను కొంత ఉత్పాదకత మరియు సామర్ధ్య వికాసాలను తక్కువగా పొందుతున్నట్లుగా అనిపిస్తోంది. టోకెన్లు మరియు కోటాలు సమస్యగా మారి, సరైన పనికి సరైన మోడల్ ఎంచుకుంటున్నానా లేదా నా బడ్జెట్ అనర్ధకంగా ఖర్చు అవుతోందా అనేదీ తెలియదు. ఈ పోస్ట్ కోసం MCP సర్వర్ సిఫార్సుల కోసం నా సహచరులతో సంభాషించినప్పుడు James Montemagno నుండి ఈ MCP సర్వర్ గురించి వినిపించియర్, మరియు దీనిని ఉపయోగించేందుకు నేను ఉత్సాహంగా ఉన్నాను! మోడల్ కనుగొను సామర్ధ్యాలు, ఎక్స్‌ప్లోర్ చేయాలనుకుంటున్న వారికి చాలా ఆకర్షణీయంగా ఉన్నాయి, అందులో ప్రత్యేక పనులకు ఆప్టిమైజ్ చేయబడిన మోడల్స్ కనుగొనవచ్చు. మూల్యాంకన ఫ్రేమ్‌వర్క్ నాకు నిజంగా మెరుగైన ఫలితాలు వచ్చాయా అని నిర్ధారించడంలో సహాయం చేయడం ఇష్టం.

### 10. 🏢 మైక్రోసాఫ్ట్ 365 ఏజెంట్లు టూల్‌కిట్ MCP సర్వర్

**ఇది ఏమిటి**: మైక్రోసాఫ్ట్ 365 మరియు మైక్రోసాఫ్ట్ 365 కోపైలట్‌తో సంబంధించిన AI ఏజెంట్లు మరియు అప్లికేషన్లు నిర్మించడానికి అవసరమైన పరికరాలను అందిస్తుంది, వీటిలో స్కీమా ధృవీకరణ, నమూనా కోడ్ పొందడం మరియు సమస్య పరిష్కారం సహాయం లాంటి వాటి ఉన్నాయి.

**ఏందుకు ఉపయోగకరం**: మైక్రోసాఫ్ట్ 365 మరియు కోపైలట్ కోసం నిర్మాణం చేస్తే, కాంప్లెక్స్ మానిఫెస్ట్ స్కీమాలు మరియు నిర్దిష్ట అభివృద్ధి పద్ధతులు అవసరం. ఈ MCP సర్వర్ అవసరమైన అభివృద్ధి వనరులను నేరుగా మీ కోడింగ్ వాతావరణంలోకి తీసుకువస్తుంది, స్కీమాలు ధృవీకరించడంలో, నమూనా కోడ్ కనుగొనడంలో, మరియు స్థిరమైన డాక్యుమెంటేషన్‌ను స ఆయంను తగ్గించకుండా సాధారణ సమస్యల పరిష్కారంలో సహాయపడుతుంది.

**యథార్థ వాడుక**: "నా ప్రకటన ఏజెంట్ మానిఫెస్ట్‌ను ధృవీకరించండి మరియు ఎటువంటి స్కీమా తప్పులను సరిచేయండి", "మైక్రోసాఫ్ట్ గ్రాఫ్ API ప్లగిన్ అమలుకు నమూనా కోడ్ చూపించండి", లేదా "నా Teams యాప్ ధృవీకరణ సమస్యలను పరిష్కరించడంలో నాకు సహాయం చేయండి"

**ప్రదర్శన ఉదాహరణ**: Buildలో M365 ఏజెంట్ల గురించి నా స్నేహితుడు John Miller తో మాట్లాడిన తర్వాత, అతను ఈ MCPని సూచించారు. కొత్త M365 ఏజెంట్స్ అభివృద్ధిదారులకు ఇది మంచిది కావచ్చు, ఎందుకంటే ఇది టెంప్లేట్లు, నమూనా కోడ్, మరియు స్టార్టప్ కోసం అవసరమైన నిర్మాణాలను అందిస్తుంది, డాక్యుమెంటేషన్‌లో ఒడిదుడుకుల వద్దు. స్కీమా ధృవీకరణ ఫీచర్లు ప్రత్యేకించి మానిఫెస్ట్ నిర్మాణ తప్పుల నుండి ఎదురు నిల్వ డీబగ్గింగ్ గంటలను నివారించడంలో ఉపయోగకరంగా కనిపిస్తున్నాయి.

## 📋 ముగింపు

మోడల్ కాంటెక్స్ట్ ప్రోటోకాల్ (MCP) అభివృద్ధిదారులు AI సహాయకులు మరియు బాహ్య సాధనాలతో ఎలా పరస్పర చర్య చేస్తున్నారో మార్చేస్తోంది. ఈ 10 మైక్రోసాఫ్ట్ MCP సర్వర్లు ప్రామాణీకృత AI ఇంటిగ్రేషన్ శక్తిని చూపిస్తూ, అభివృద్ధిదారులు తమ ఫ్లో మధ్యలో ఉండి శక్తివంతమైన బాహ్య సామర్థ్యాలను యాక్సెస్ చేసుకునే కనెక్టు వర్క్‌ఫ్లోలను సృష్టిస్తున్నాయి.

సమగ్ర Azure ఎకోసిస్టమ్ ఇంటిగ్రేషన్ నుండి బ్రౌజర్ ఆటోమేషన్ కోసం Playwright మరియు డాక్యుమెంట్ ప్రాసెసింగ్ కోసం MarkItDown వంటి ప్రత్యేక పరికరాల వరకు, ఈ సర్వర్లు వివిధ అభివృద్ధి పరిసరాల్లో MCP ఎలా ఉత్పాదకతను మెరుగుపరుస్తుందో ప్రదర్శిస్తున్నాయి. ప్రామాణీకృత ప్రోటోకాల్ ఈ పరికరాలు కలిసి పని చేయడానికి సహాయపడుతుంది, సమగ్రమైన అభివృద్ధి అనుభవాన్ని సృష్టిస్తుంది.

MCP ఎకోసిస్టమ్ అభివృద్ధి చెందుతూనే ఉండగా, కమ్యూనిటీలో పాల్గొనడం, కొత్త సర్వర్లను అన్వేషించడం, మరియు ప్రత్యేక అవసరాలకు అనుగుణంగా అనుకూల పరిష్కారాలను నిర్మించడం మీ అభివృద్ధి ఉత్పాదకతను గరిష్ట పరచడానికి కీలకం అవుతుంది. MCP యొక్క ఓపెన్ స్టాండర్డ్ స్వభావం వల్ల మీరు వివిధ విక్రेतల పరికరాలను కలిపి మీ సొంత వర్క్‌ఫ్లోని సృష్టించుకోవచ్చు.
