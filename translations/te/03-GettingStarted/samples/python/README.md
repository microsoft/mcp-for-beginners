# MCP క్యాల్క్యులేటర్ సర్వర్ (Python)



పైన్లో ఒక సాధారణ మోడల్ కంటెక్స్ట్ ప్రోటోకాల్ (MCP) సర్వర్ అమలు, ఇది ప్రాథమిక క్యాల్క్యులేటర్ ఫంక్షనాలిటీని అందిస్తుంది.


## ఇన్‌స్టాలేషన్

అవసరమైన డిపెండెన్సీలను ఇన్స్టాల్ చేయండి:

```bash
pip install -r requirements.txt
```

లేదా MCP Python SDK ను నేరుగా ఇన్స్టాల్ చేయండి:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## ఉపయోగం

### సర్వర్‌ను నడపడం

సర్వర్‌ను MCP 클యింట్లు (క్లాడ్ డెస్క్‌టాప్ వంటి) ఉపయోగించడానికి రూపొందಿಸಲಾಗಿದೆ. సర్వర్ ప్రారంభించడానికి:

```bash
python mcp_calculator_server.py
```

**గమనిక**: నేరుగా టెర్మినల్‌లో నడపినప్పుడు, మీరు JSON-RPC ధృవీకరణ లోపాలను చూడవచ్చు. ఇది సాధారణ ప్రవర్తన - సర్వర్ సరైన రూపంలో ఉన్న MCP క్లయింట్ సందేశాలను కోరుకుంటోంది.

### ఫంక్షన్‌లను పరీక్షించడం

క్యాల్క్యులేటర్ ఫంక్షన్‌లు సరిగా పని చేస్తున్నాయని పరీక్షించడానికి:

```bash
python test_calculator.py
```

## సమస్యలు పరిష్కారం

### ఇంపోర్ట్ లోపాలు

మీరు `ModuleNotFoundError: No module named 'mcp'` అనే లోపాన్ని చూస్తే, MCP Python SDKని ఇన్స్టాల్ చేయండి:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### నేరుగా నడిపేటప్పుడు JSON-RPC లోపాలు

సర్వర్‌ను నేరుగా నడిపేటప్పుడు "Invalid JSON: EOF while parsing a value" లాంటి లోపాలు ఎదురవ్వడం సాధారణం. సర్వర్‌కు MCP క్లయింట్ సందేశాలు అవసరం, నేరైన టెర్మినల్ ఇన్‌పుట్ కాదు.
