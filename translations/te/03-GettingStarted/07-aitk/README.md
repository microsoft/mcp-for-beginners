# విజువల్ స్టూడియో కోడ్ కోసం AI టూల్‌కిట్ విస్తరణ నుండి ఒక సర్వర్‌ను వినియోగించడం  

మీరు ఒక AI ఏజెంట్‌ను నిర్మిస్తున్నప్పుడు, ఇది కేవలం తెలివైన ప్రతిస్పందనలు సృష్టించడం గురించి మాత్రమే కాదు; మీ ఏజెంట్‌కు చర్య తీసుకునే సామర్థ్యం కూడా ఇవ్వడం ముఖ్యం. ఇక్కడే Model Context Protocol (MCP) అవసరం వస్తుంది. MCP ఏజెంట్‌లు బాహ్య సాధనాలు మరియు సేవలను నిరంతరంగా యాక్సెస్ చేయడాన్ని సులభతరం చేస్తుంది. దీన్ని మీరు మీ ఏజెంట్‌ను ఒక టూల్‌బాక్స్‌లో జతచేసినట్లుగా ఆలోచించండి, దీనిని అది వాస్తవంగా ఉపయోగించగలుగుతుంది.  

మీరు ఒక ఏజెంట్‌ను మీ క్యాల్క్యులేటర్ MCP సర్వర్‌కు కనెక్ట్ చేస్తే నమ్మండి, ఆ ఏజెంట్ కి “47 రెట్లు 89 ఎంత?” వంటి ప్రాంప్ట్‌ను అందించడం ద్వారా గణిత చర్యలు నిర్వహించగలదు—లోజిక్‌ను హార్డ్‌కోడ్ చేయడం లేదా కస్టమ్ API లను సృష్టించడం అవసరం లేదు.  

## అవలోకనం  

ఈ పాఠం ద్వారా మీరు Visual Studio Codeలో [AI Toolkit](https://aka.ms/AIToolkit) విస్తరణను ఉపయోగించి ఒక క్యాలిక్యులేటర్ MCP సర్వర్‌ని ఏజెంట్‌కు ఎలా కనెక్ట్ చేయాలో తెలుసుకుంటారు. దీని ద్వారా మీ ఏజెంట్ సహజ భాష ద్వారా జోడింపు, విడివిడిగా, గుణాకారం మరియు భాగాకారం వంటి గణిత ఆపరేషన్లు నిర్వహించగలుగుతుంది.  

AI Toolkit అనేది Visual Studio Code కోసం శక్తివంతమైన విస్తరణ, ఇది ఏజెంట్ అభివృద్ధిని సులభతరం చేస్తుంది. AI ఇంజనీర్లు తమ సొంత జనరేటివ్ AI మోడల్‌లను—లోకల్‌లో గానీ క్లౌడ్‌లో గానీ—పరీక్షించి అభివృద్ధి చేయవచ్చు. ఈ విస్తరణ ప్రస్తుతం అందుబాటులో ఉన్న అతిపెద్ద జనరేటివ్ మోడల్స్‌కు మద్దతు ఇస్తుంది.  

*గమనిక*: AI Toolkit ప్రస్తుతం Python మరియు TypeScript ను మద్దతు ఇస్తుంది.  

## నేర్చుకునే లక్ష్యాలు  

ఈ పాఠం ముగింపులో మీకు వీలవుతుంది:  

- AI Toolkit ద్వారా MCP సర్వర్‌ను వినియోగించటం.  
- ఏజెంట్ కాన్ఫిగరేషన్‌ను సర్దుబాటు చేసి MCP సర్వర్ ద్వారా అందించే పరికరాలను కనుగొని ఉపయోగించటం.  
- సహజ భాష ద్వారా MCP పరికరాలను వినియోగించటం.  

## విధానం  

మేము దీన్ని ఎలా సమగ్రంగా చేయాలో చూద్దాం:  

- ఒక ఏజెంట్ సృష్టించి, దాని సిస్టమ్ ప్రాంప్ట్‌ను నిర్వచించండి.  
- క్యాలిక్యులేటర్ టూల్స్‌ను కలిగిన MCP సర్వర్‌ను సృష్టించండి.  
- ఏజెంట్ బిల్డర్‌ను MCP సర్వర్‌కు కనెక్ట్ చేయండి.  
- సహజ భాష ద్వారా ఏజెంట్ టూల్ కాలింగ్‌ను పరీక్షించండి.  

బాగుంది, ఇప్పుడు ఫ్లో ని అర్థం చేసుకున్న తర్వాత, MCP ద్వారా బాహ్య పరికరాలను వినియోగించగల AI ఏజెంట్‌ను సెట్ చేయండి, దాని సామర్థ్యాలను పెంపొందించండి!

### -1- ఒక ఏజెంట్ సృష్టించండి

![AI Toolkit విస్తరణలో "Calculator Agent" బిల్డర్ ఇంటర్ఫేస్ స్క్రీన్‌షాట్. ఎడమ ప్యానెల్‌లో "OpenAI GPT-4o (via GitHub)" మోడల్ ఎంచుకోబడింది. సిస్టమ్ ప్రాంప్ట్ "మీరు విశ్వవిద్యాలయంలో గణితం బోధించే ప్రొఫెసర్" అని ఉంది. వినియోగదారు ప్రాంప్ట్ "ఫూరియర్ సమీకరణాన్ని సులభ పదజాలంలో వివరించండి" అని ఉంది. అదనంగా టూల్స్ జోడించడానికి, MCP సర్వర్ యాక్టివేట్ చేయడానికి, మరియు స్ట్రక్చర్డ్ అవుట్పుట్ ఎంచుకునే బటన్లు ఉన్నాయి. క్రింద ఒక బ్లూ “Run” బటన్ ఉంది. కుడి ప్యానెల్‌లో షురూ చేసేందుకు ఉదాహరణ ఏజెంట్లు ఉన్నవిగా చూపబడుతున్నాయి.](../../../../translated_images/te/aitk-agent-builder.901e3a2960c3e477.webp)

3. **+ New Agent** బటన్‌పై క్లిక్ చేయండి. **Command Palette** ద్వారా సెటప్ విజార్డు ప్రారంభమవుతుంది.  
4. పేరు **Calculator Agent** ఎంటర్ చేసి **Enter** నొక్కండి.  
5. **Agent (Prompt) Builder**లో **Model** ఫీల్డ్‌ కోసం **OpenAI GPT-4o (via GitHub)** మోడల్‌ను ఎంచుకోండి.  

### -2- ఏజెంట్ కోసం సిస్టమ్ ప్రాంప్ట్ సృష్టించండి  

ఏజెంట్ రూపొందించిన తర్వాత, దాని వ్యక్తిత్వం మరియు లక్ష్యాన్ని నిర్వచించడానికి స‌మయం. ఈ సెక్షన్లో మీరు **Generate system prompt** ఫీచర్ ఉపయోగించి ఏజెంట్ ఉద్దేశించిన ప్రవర్తనను, ఈ సందర్భంలో క్యాలిక్యులేటర్ ఏజెంట్ ను వివరించి, మోడల్ ద్వారా సిస్టమ్ ప్రాంప్ట్ రాయించుకుంటారు.  

![AI Toolkitలో "Calculator Agent" ఇంటర్ఫేస్ స్క్రీన్‌షాట్, “Generate a prompt” అనే మోడల్ విండో తెరువు. ప్రాంప్ట్ మూడెల్ ను సృష్టించేందుకు ప్రాథమిక వివరాలను పంచుకోవడం ద్వారా, "మీరు సహాయకరమైన మరియు సమర్థవంతమైన గణిత సహాయకులుగా ఉంటారు. ప్రాథమిక ఆరిథమెటిక్కు సంబంధించిన సమస్యలు వస్తే మీరు సరైన ఫలితాన్ని ఇస్తారు." అని ఉదాహరణ టెక్స్ట్ బాక్స్‌లో ఉంది. దిగువన "Close" మరియు "Generate" బటన్లు ఉన్నాయి.](../../../../translated_images/te/aitk-generate-prompt.ba9e69d3d2bbe2a2.webp)  

1. **Prompts** సెక్షన్‌లో **Generate system prompt** బటన్‌పై క్లిక్ చేయండి. ఇది ప్రాంప్ట్ బిల్డర్ తెరుస్తుంది, ఇక్కడ AI సాయంతో ఏజెంట్ కోసం సిస్టమ్ ప్రాంప్ట్ సృష్టించబడుతుంది.  
2. **Generate a prompt** విండోలో క్రింది వాక్యం నమోదు చేయండి: `You are a helpful and efficient math assistant. When given a problem involving basic arithmetic, you respond with the correct result.`  
3. **Generate** బటన్‌పై క్లిక్ చేయండి. ప్రాంప్ట్ తయారవుతుందన్న నోటిఫికేషన్ టెర్మినల్ దిగువ-కుడి మూలలో ఉంటుంది. ప్రాంప్ట్ తయారీ పూర్తయిన తరువాత, అది **Agent (Prompt) Builder**లోని **System prompt** ఫీల్డ్‌లో కనిపిస్తుంది.  
4. **System prompt** సమీక్షించి అవసరమైతే మార్చండి.  

### -3- MCP సర్వర్ సృష్టించండి  

మీరు ఏజెంట్ సిస్టమ్ ప్రాంప్ట్‌ను నిర్వచించిన తర్వాత దాన్ని ప్రాక్టికల్ సామర్థ్యాలతో భర్తీ చేయడానికి సమయం వచ్చింది. ఈ భాగంలో మీరు జోడింపు, విడివిడిగా, గుణాకారం మరియు భాగాకారం గణనలను నిర్వహించే టూల్స్ ఉన్న క్యాలిక్యులేటర్ MCP సర్వర్‌ను తయారుచేస్తారు. ఈ సర్వర్ సహజ భాష ప్రాంప్ట్‌లకు స్పందించి ఏజెంట్‌కు రియల్ టైంలో గణిత చర్యలు చేయడానికి అనుమతిస్తుంది.  

![AI Toolkit విస్తరణలో Calculator Agent ఇంటర్‌ఫేస్ దిగువ భాగం స్క్రీన్‌షాట్. "Tools" మరియు "Structure output" విస్తరించదగిన మెనూలు, "Choose output format" అనే డ్రాప్‌డౌన్ "text"కి సెట్ చేయబడింది. కుడి పక్కన "+ MCP Server" అనే బటన్ ఉంది. టూల్స్ విభాగం పై భాగంలో ఒక చిత్రం ఐకాన్ ప్లేస్‌హోల్డర్ ఉంది.](../../../../translated_images/te/aitk-add-mcp-server.9742cfddfe808353.webp)  

AI Toolkit లో మీ స్వంత MCP సర్వర్ సృష్టించడానికి సులభతరమైన టెంప్లేట్లు ఉన్నాయి. క్యాలిక్యులేటర్ MCP సర్వర్ సృష్టించడానికి Python టెంప్లేట్‌ను ఉపయోగిస్తాము.  

*గమనిక*: AI Toolkit ప్రస్తుతం Python మరియు TypeScript మద్దతు ఇస్తుంది.  

1. **Agent (Prompt) Builder**లో **Tools** విభాగంలో **+ MCP Server** బటన్‌పై క్లిక్ చేయండి. **Command Palette** ద్వారా సెటప్ విజార్డు ప్రారంభమవుతుంది.  
2. **+ Add Server** ఎంచుకోండి.  
3. **Create a New MCP Server** ఎంచుకోండి.  
4. టెంప్లేట్‌గా **python-weather** ఎంచుకోండి.  
5. MCP సర్వర్ టెంప్లేట్ సేవ్‌చేయడానికి **Default folder** ఎంచుకోండి.  
6. సర్వర్ పేరు గా క్రింది పేరు ఇవ్వండి: **Calculator**  
7. ఒక కొత్త Visual Studio Code విండో ఓపెన్ అవుతుంది. **Yes, I trust the authors** ఎంచుకోండి.  
8. టెర్మినల్‌లో (Terminal > New Terminal) వర్చువల్ ఎన్విరాన్మెంటు సృష్టించండి: `python -m venv .venv`  
9. టెర్మినల్‌లో వర్చువల్ ఎన్విరాన్మెంట్ను యాక్టివేట్ చేయండి:  
    1. విండోస్ - `.venv\Scripts\activate`  
    2. macOS/Linux - `source .venv/bin/activate`  
10. టెర్మినల్‌లో డిపెండెన్సీలను ఇన్స్టాల్ చేయండి: `pip install -e .[dev]`  
11. **Activity Bar**లో **Explorer** వ్యూలో **src** డైరెక్టరీని విస్తరించి **server.py** ఫైల్ ను ఎడిటర్‌లో తెరవండి.  
12. **server.py** కోడ్‌ని క్రింద ఇవ్వబడినదిగా మార్చి సేవ్ చేయండి:  

    ```python
    """
    Sample MCP Calculator Server implementation in Python.

    
    This module demonstrates how to create a simple MCP server with calculator tools
    that can perform basic arithmetic operations (add, subtract, multiply, divide).
    """
    
    from mcp.server.fastmcp import FastMCP
    
    server = FastMCP("calculator")
    
    @server.tool()
    def add(a: float, b: float) -> float:
        """Add two numbers together and return the result."""
        return a + b
    
    @server.tool()
    def subtract(a: float, b: float) -> float:
        """Subtract b from a and return the result."""
        return a - b
    
    @server.tool()
    def multiply(a: float, b: float) -> float:
        """Multiply two numbers together and return the result."""
        return a * b
    
    @server.tool()
    def divide(a: float, b: float) -> float:
        """
        Divide a by b and return the result.
        
        Raises:
            ValueError: If b is zero
        """
        if b == 0:
            raise ValueError("Cannot divide by zero")
        return a / b
    ```
  
### -4- క్యాలిక్యులేటర్ MCP సర్వర్‌తో ఏజెంట్‌ను నడపండి  

ఇప్పటినుంచి మీ ఏజెంట్‌కు టూల్స్ ఉన్నాయని అనుకుంటే, వాటిని ఉపయోగించే సమయం వచ్చింది! ఈ భాగంలో, మీరు ఏజენტ్కి ప్రాంప్ట్‌లు అందించి క్యాలిక్యులేటర్ MCP సర్వర్‌లో సరైన టూల్‌ని ఏజెంట్ ఉపయోగిస్తున్నదా అంటే పరీక్షిస్తారు.  

![AI Toolkit విస్తరణలో Calculator Agent ఇంటర్‌ఫేస్ స్క్రీన్‌షాట్. ఎడమ ప్యానెల్లో "Tools" కింద లొకల్-సర్వర్-calculator_server MCP సర్వర్ జోడించబడింది, ఇందులో నాలుగు టూల్స్: జోడించు, తీసివెయ్యి, గుణించు, భాగించు. నాలుగు టూల్స్ యాక్టివ్ అని బ్యాడ్జ్ చూపిస్తోంది. కింది భాగంలో కూర్చున్న “Structure output” సెక్షన్ మరియు ఒక బ్లూ “Run” బటన్ ఉన్నాయి. కుడి ప్యానెల్లో "Model Response" లో ఏజెంట్ multiply మరియు subtract టూల్స్‌ను వరుసగా {"a": 3, "b": 25} మరియు {"a": 75, "b": 20} ఇన్‌పుట్‌లతో పిలుస్తుంది. తుది "Tool Response" 75.0 అని చూపిస్తుంది. క్రింద "View Code" బటన్ ఉంది.](../../../../translated_images/te/aitk-agent-response-with-tools.e7c781869dc8041a.webp)  

మీరు క్యాలిక్యులేటర్ MCP సర్వర్‌ను మీ లోకల్ డెవ్ మెషిన్‌లో **Agent Builder** ద్వారా MCP క్లయింట్‌గా నడపతారు.  

1. MCP సర్వర్‌ను డిబగ్ చేయడానికి `F5` నొక్కండి. **Agent (Prompt) Builder** కొత్త ఎడిటర్ ట్యాబ్లో ఓపెన్ అవుతుంది. టెర్మినల్‌లో సర్వర్ స్థితి కనిపిస్తుంది.  
2. **Agent (Prompt) Builder**లో **User prompt** ఫీల్డ్‌లో ఈ ప్రాంప్ట్‌ను ఎంటర్ చేయండి: `I bought 3 items priced at $25 each, and then used a $20 discount. How much did I pay?`  
3. ఏజెంట్ ప్రతిస్పందన సృష్టించడానికి **Run** బటన్ పై క్లిక్ చేయండి.  
4. ఏజెంట్ అవుట్‌పుట్ పై సమీక్షించండి. తగినది అంటే, మీరు **$55** చెల్లించారని మోడల్ తేల్చే అవకాశం ఉంది.  
5. క్రింది ప్రక్రియలవుతాయి:  
    - ఏజెంట్ గణనకు సహాయంగా **multiply** మరియు **subtract** టూల్స్ ఎంచుకుంటుంది.  
    - **multiply** టూల్ కోసం `a` మరియు `b` విలువలు కేటాయించబడతాయి.  
    - **subtract** టూల్‌కి `a` మరియు `b` విలువలు కేటాయించబడతాయి.  
    - ప్రతి టూల్ నుండి వచ్చిన ప్రతిస్పందన **Tool Response**లో అందించబడుతుంది.  
    - తుది అవుట్‌పుట్ **Model Response**లో ఇవ్వబడుతుంది.  
6. ఏజెంట్‌ను మరింత పరీక్షించేందుకు అదనపు ప్రాంప్ట్‌లు పంపండి. **User prompt** ఫీల్డ్‌లో ప్రాథమిక ప్రాంప్ట్‌ను మార్చవచ్చు.  
7. ఏజెంట్‌ను పరీక్షించడం ముగిస్తే, టెర్మినల్ లో **CTRL/CMD+C** నొక్కి సర్వర్‌ను ఆపండి.  

## అసైన్‌మెంట్  

మీ **server.py** ఫైల్‌లో అదనపు టూల్ ఎంట్రీని చేర్చడానికి ప్రయత్నించండి (ఉదాహరణకు: ఒక సంఖ్య యొక్క చదరపు వేరియును కళ్ళకు). కొత్త లేదా ఉన్న టూల్స్‌ను ఏజెంట్ వినియోగించాల్సిన దానిని పరీక్షించడానికి ప్రాంప్ట్‌లు పంపండి. కొత్త టూల్స్‌లోడ్ కావడానికి సర్వర్‌ను రీస్టార్ట్ చేయడం మర్చిపోవద్దు.
