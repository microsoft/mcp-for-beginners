# MCP సర్వర్ల నిబంధన

> [!NOTE]
> కాన్ఫిగరేషన్ ఉదాహరణలు `/sse` ఎండ్‌పాయింట్‌ను ఉపయోగిస్తాయి, అవి పాత HTTP+SSE
> ట్రాన్స్‌పోర్ట్‌ను లక్ష్యంగా చేసుకుంటాయి. MCP `2026-07-28` రిమోట్ సర్వర్లు సాధారణంగా
> `/mcp` వంటి సర్వర్-นิ निश्चित ఎండ్‌పాయింట్‌ వద్ద స్ట్రీమేబుల్ HTTP‌ను ఉపయోగిస్తాయి.

మీ MCP సర్వర్‌ను నియమించడం ద్వారా ఇతరులు మీ స్థానిక వాతావరణం దాటి దాని టూల్స్ మరియు వనరుల్ని ఉపయోగించగలరు. స్కేలబిలిటీ, నమ్మకత్వం మరియు నిర్వహణ సౌలభ్యం కోసం మీ అవసరాల ఆధారంగా అనేక నియామక వ్యూహాలు ఉన్నాయి. కింద మీరు స్థానికంగా, కంటైనర్లలో మరియు క్లౌడ్‌కు MCP సర్వర్ల నియామకానికి దిశానిర్దేశాలను కనుగొనగలరు.

## అవలోకనం

ఈ పాఠం మీ MCP సర్వర్ యాప్‌ను ఎలా నిబంధించాలో చెబుతుంది.

## అభ్యాస లక్ష్యాలు

ఈ పాఠం ముగిసే సమయంలో, మీరు చేయగలరు:

- వివిధ నియామక విధానాలను అంచనా వేయండి.
- మీ యాప్‌ను నియమించండి.

## లోకల్ అభివృద్ధి మరియు నియామకం

మీరు సర్వర్‌ను వినియోగదారుల యంత్రంలో నడుపదలిచినట్లయితే, మీరు క్రింది దశలను అనుసరించవచ్చు:

1. **సర్వర్‌ను డౌన్లోడ్ చేసుకోండి**. మీరు సర్వర్‌ను రాయకపోతే, ముందుగా మీ యంత్రానికి డౌన్లోడ్ చేసుకోండి.
1. **సర్వర్ ప్రక్రియను ప్రారంభించండి**: మీ MCP సర్వర్ అప్లికేషన్‌ను నడపండి

SSE కోసం (stdio రకానికి అవసరం లేదు)

1. **నెట్‌వర్కింగ్ కాన్ఫిగర్ చేయండి**: సర్వర్ అనుకున్న పోర్ట్‌లో చేరదగినదిగా ఉందని ఖచ్చితంగా చేసుకోండి
1. **క్లయింట్లను కనెక్ట్ చేయండి**: `http://localhost:3000` వంటి స్థానిక కనెక్షన్ URLలను ఉపయోగించండి

## క్లౌడ్ నియామకం

MCP సర్వర్లను వివిధ క్లౌడ్ వేదికలకు నియమించవచ్చు:

- **సర్వర్‌లెస్ ఫంక్షన్ల**: తేలికపాటి MCP సర్వర్లను సర్వర్‌లెస్ ఫంక్షన్లుగా నియమించండి
- **కంటైనర్ సర్వీసెస్**: Azure Container Apps, AWS ECS, లేదా Google Cloud Run వంటి సేవలను ఉపయోగించండి
- **కుబెర్నెటిస్**: MCP సర్వర్లను కుబెర్నెటిస్ క్లస్టర్లలో అధిక లభ్యత కోసం నియమించి నిర్వహించండి

### ఉదాహరణ: Azure Container Apps

Azure Container Apps MCP సర్వర్ల నియామకాన్ని మద్దతు ఇస్తాయి. ఇది ఇంకా అభివృద్దిలో ఉంది మరియు ప్రస్తుతం SSE సర్వర్లను మాత్రమే మద్దతు ఇస్తుంది.

మీరు ఇలా చేయవచ్చు:

1. ఒక రిపోను క్లోన్ చేయండి:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. ఇప్పటికే స్థానికంగా పరీక్షించండి:

  ```sh
  uv venv
  uv sync

  # లినక్స్/మ్యాక్OS
  export API_KEYS=<AN_API_KEY>
  # విండోస్
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. స్థానికంగా ప్రయోగించేందుకు, *.vscode* డైరెక్టరీలో *mcp.json* ఫైలు సృష్టించి క్రింది విషయాలను జత చేయండి:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  SSE సర్వర్ ప్రారంభమైన వెంటనే, JSON ఫైల్‌లో ప్లే ఐకాన్‌పై క్లిక్ చేయండి, ఇప్పుడు GitHub Copilot ద్వారా సర్వర్ నుండి టూల్స్ ఎంచుకోబడటం కనిపిస్తుంది, టూల్ ఐకాన్ చూడండి.

1. నియమించడానికి, క్రింది కమాండ్‌ను నడపండి:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

అదే ఇది, ఈ దశల ద్వారా స్థానికంగా లేదా Azureకు నియమించండి.
