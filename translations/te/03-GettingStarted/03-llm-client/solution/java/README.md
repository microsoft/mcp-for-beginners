# క్యాల్క్యులేటర్ LLM క్లయింట్

> [!NOTE]
> ఈ పరిష్కారం కోర్సు యొక్క లెగేసీ HTTP+SSE క్యాల్క్యులేటర్ సేవకు కనెక్ట్ అవుతుంది మరియు
> MCP `2025-11-25` SDK APIs లక్ష్యంగా పెట్టుకుంది. ఇది `2026-07-28` స్ట్రీమబుల్ HTTP
> ఉదాహరణ కాదు.

MCP (మోడెల్ కాంటెక్ట్స్ ప్రోటోకాల్) క్యాల్క్యులేటర్ సర్వీస్‌తో MiniMax OpenAI-పరస్పర అనుకూల API ద్వారా కనెక్ట్ కావడానికి LangChain4j ఎలా ఉపయోగించాలో చూపించే జావా అప్లికేషన్.

## ముందస్తు అవసరాలు

- జావా 21 లేదా అంపైక
- Maven 3.6+ (లేదా అర్థం చేసిన Maven ర్యాప్పర్ ఉపయోగించండి)
- MiniMax API కీ ఒకటి
- `http://localhost:8080` వద్ద ఒక MCP క్యాల్క్యులేటర్ సర్వీస్

## API కీ పొందడం

ఈ అప్లికేషన్ MiniMax OpenAI-పరస్పర అనుకూల API ని ఉపయోగిస్తుంది. మీ కీ మరియు ఎండ్కాయింట్ పొందేందుకు ఈ దశలను అనుసరించండి:

### 1. ఒక ఎండ్కాయింట్ ఎంచుకోండి
1. గ్లోబల్ ఎండ్కాయింట్ కోసం `https://api.minimax.io/v1` ఉపయోగించండి
2. చైనా ఎండ్కాయింట్ కోసం `https://api.minimaxi.com/v1` ఉపయోగించండి

### 2. API కీ సృష్టించండి
1. మీ MiniMax ఖాతా నుండి MiniMax API కీ సృష్టించండి
2. కీని సురక్షిత స్థలంలో ఉంచండి

### 3. محیط వేరియబిల్స్ సెట్ చేయండి

#### విండోస్ (కమాండ్ ప్రాంప్ట్) లో:
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### విండోస్ (పవర్‌షెల్) లో:
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### MacOS/Linux లో:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## సెట్ అప్ మరియు ఇన్‌స్టాలేషన్

1. **ప్రాజెక్ట్ డైరెక్టరీని క్లోన్ చేయండి లేదా వెళ్ళండి**

2. **డిపెండెన్సీలను ఇన్‌స్టాల్ చేయండి**:
   ```cmd
   mvnw clean install
   ```
   లేదా మీరు Maven గ్లోబలీ ఇన్‌స్టాల్ చేసి ఉంటే:
   ```cmd
   mvn clean install
   ```

3. **పరిస్థితి వేరియబిల్స్ సెట్ చేయండి** (పైన "API కీ పొందడం" విభాగం చూడండి)

4. **MCP క్యాల్క్యులేటర్ సర్వీస్ ప్రారంభించండి**:
   చాప్టర్ 1 లోని MCP క్యాల్క్యులేటర్ సర్వీస్ `http://localhost:8080/sse`పై నడుస్తుందని నిర్ధారించండి. మీరు క్లయింట్ ప్రారంభించే ముందు ఇది నడుస్తుండాలి.

## అప్లికేషన్ నడిపించడం

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## అప్లికేషన్ చేసే పని

అప్లికేషన్ క్యాల్క్యులేటర్ సర్వీస్‌తో మూడు ప్రధాన పరస్పర చర్యలను చూపుతుంది:

1. **జోడింపు**: 24.5 మరియు 17.3 యొక్క మొత్తం లెక్కించబడుతుంది
2. **వర్గమూలం**: 144 యొక్క వర్గమూలం లెక్కించబడుతుంది
3. **సహాయం**: అందుబాటులో ఉన్న క్యాల్క్యులేటర్ ఫంక్షన్లను చూపిస్తుంది

## ఆశించిన అవుట్‌పుట్

విజయవంతంగా నడువబడినప్పుడు, మీరు క్రింది పద్ధతిలో అవుట్‌పుట్ చూడవచ్చు:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## సమస్య పరిష్కారం

### సాధారణ సమస్యలు

1. **"OPENAI_API_KEY పరిసరివేరియబుల్ సెట్ చేయబడలేదు"**
   - మీరు `OPENAI_API_KEY` పరిసరివేరియబుల్ సెట్ చేశారని నిర్ధారించుకోండి
   - వేరియబుల్ సెట్ చేసిన తర్వాత మీ టెర్మినల్/కమాండ్ ప్రాంప్ట్‌ను రీస్టార్ట్ చేయండి

2. **"localhost:8080 కి కనెక్షన్ తిరస్కరించబడింది"**
   - MCP క్యాల్క్యులేటర్ సర్వీస్ 8080 పోర్ట్‌పై నడుస్తున్నదని నిర్ధారించుకోండి
   - మర్చిపోకుండా మరో సర్వీస్ 8080 పోర్ట్ ఉపయోగిస్తోందో చూడండి

3. **"ఆధారపడావు విఫలము"**
   - మీ API కీ చెల్లుబాటు అయ్యిందా లేదని తనిఖీ చేయండి
   - మీరు ఉద్దేశించిన ఎండ్కాయింట్‌కు `OPENAI_BASE_URL` సరిపోతుందో కూడా తనిఖీ చేయండి

4. **Maven బిల్డ్ లో లోపాలు**
   - మీరు జావా 21 లేదా ఎక్కువ వర్షన్ ఉపయోగిస్తున్నారని నిర్ధారించుకోండి: `java -version`
   - బిల్డ్ శుభ్రం చేయాలని ప్రయత్నించండి: `mvnw clean`

### డీబగ్గింగ్

డీబగ్ లాగింగ్ నియంత్రించడానికి, నడిపే సమయంలో క్రింది JVM ఆర్గుమెంట్ని జోడించండి:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## కాన్ఫిగరేషన్

అప్లికేషన్ క్వీ ఈ విధంగా కాన్ఫిగర్ చేయబడి ఉంటుంది:
- మూల్యంగా MiniMax-M3 వాడుతుంది; `MINIMAX_MODEL_ID` ని సెట్ చేస్తే `MiniMax-M3` లేదా `MiniMax-M2.7` ఎంచుకోగలరు
- `OPENAI_BASE_URL` సెట్ ఉంటే దానికి కనెక్ట్ అవుతుంది; లేదంటే `MINIMAX_REGION=cn_zh` ఉన్నప్పుడు `https://api.minimaxi.com/v1` లేదా సాధారణంగా `https://api.minimax.io/v1` ను ఉపయోగిస్తుంది
- MCP సర్వీస్ కు `http://localhost:8080/sse` ద్వారా కనెక్ట్ అవుతుంది
- అభ్యర్థనలకు 60-సెకన్ల టైమ్ అవుట్ ఉపయోగిస్తుంది

## డిపెండెన్సీలు

ఈ ప్రాజెక్ట్ ఉపయోగించే ముఖ్యమైన డిపెండెన్సీలు:
- **LangChain4j**: AI ఇంటిగ్రేషన్ మరియు టూల్ నిర్వహణ కోసం
- **LangChain4j MCP**: మోడెల్ కాంటెక్ట్ ప్రోటోకాల్ మద్దతు కోసం
- **LangChain4j OpenAI అధికారిక**: MiniMax OpenAI-పరస్పర అనుకూల API ఇంటిగ్రేషన్ కోసం
- **Spring Boot**: అప్లికేషన్ ఫ్రేమ్‌వర్క్ మరియు డిపెండెన్సీ ఇంజెక్షన్ కోసం
