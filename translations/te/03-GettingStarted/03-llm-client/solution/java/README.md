# క్యాల్క్యులేటర్ LLM క్లయింట్

LangChain4j ను ఉపయోగించి MiniMax OpenAI-అనుకూల API ద్వారా MCP (మోడల్ కాంటెక్స్ట్ ప్రోటోకాల్అ) క్యాల్క్యులేటర్ సేవకు ఎలా కనెక్ట్ కావాలో చూపించే జావా అప్లికేషన్.

## ముందస్తు అవసరాలు

- జావా 21 లేక అందుకు పైగా
- మావెన్ 3.6+ (లేదా సహా ఇచ్చిన మావెన్ రాపర్ ఉపయోగించండి)
- ఒక MiniMax API కీ
- `http://localhost:8080` వద్ద నడుస్తున్న MCP క్యాల్క్యులేటర్ సేవ

## API కీ పొందడం

ఈ అప్లికేషన్ MiniMax OpenAI-అనుకూల API ను ఉపయోగిస్తుంది. మీ కీ మరియు ఎండ్‌పాయింట్‌ను పొందడానికి ఈ దశలను అనుసరించండి:

### 1. ఎండ్‌పాయింట్ ఎంచుకొనండి
1. గ్లోబల్ ఎండ్‌పాయింట్ కోసం `https://api.minimax.io/v1` ఉపయోగించండి
2. చైనా ఎండ్‌పాయింట్ కోసం `https://api.minimaxi.com/v1` ఉపయోగించండి

### 2. API కీ సృష్టించండి
1. మీ MiniMax ఖాతా నుండి MiniMax API కీ సృష్టించండి
2. కీని ఏదైనా భద్ర స్థలంలో పెట్టుకోండి

### 3. ఎన్విరాన్మెంట్ వేరియబుల్స్ సెట్ చేయండి

#### విండోస్ (కమాండ్ ప్రాంప్ట్) లో:
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### విండోస్ (పవర్‌షెల్) లో:
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### మాక్OS/Linux లో:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## సెటప్ మరియు ఇన్‌స్టాలేషన్

1. **ప్రాజెక్ట్ డైరెక్టరీని క్లోన్ చేయండి లేదా అందులోకి వెళ్లండి**

2. **డిపెండెన్సీలను ఇన్‌స్టాల్ చేయండి**:
   ```cmd
   mvnw clean install
   ```
   లేక మీరు మావెన్ గ్లోబల్గా ఇన్‌స్టాల్ చేసి ఉంటే:
   ```cmd
   mvn clean install
   ```

3. **ఎన్విరాన్మెంట్ వేరియబుల్స్ సెట్ చేయండి** ("API కీ పొందడం" విభాగాన్ని చూడండి)

4. **MCP క్యాల్క్యులేటర్ సేవను ప్రారంభించండి**:
   మీరు చాప్టర్ 1 లోని MCP క్యాల్క్యులేటర్ సేవను `http://localhost:8080/sse` వద్ద నడుస్తున్నట్లు ఖాతరు చేసుకోండి. ఇది క్లయింట్ ని ప్రారంభించే ముందు నడుస్తుండాలి.

## అప్లికేషన్ ని నడిపించడం

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## అప్లికేషన్ ఏం చేస్తుంది

అప్లికేషన్ క్యాల్క్యులేటర్ సేవతో మూడు ప్రధాన ఇంటరాక్షన్లను చూపిస్తుంది:

1. **యొకసం**: 24.5 మరియు 17.3 యొక్క మొత్తం లెక్కిస్తుంది
2. **స్క్వేర్ రూట్**: 144 యొక్క వర్గమూలం లెక్కిస్తుంది
3. **సహాయం**: అందుబాటులో ఉన్న క్యాల్క్యులేటర్ ఫంక్షన్లను చూపిస్తుంది

## అనుకోబడిన ఫలితం

విజయవంతంగా నడిపినప్పుడు, మీరు క్రింద చూపినట్లుగానీ అవుట్‌పుట్ చూడాలి:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## సమస్యలు పరిష్కరించడం

### సాధారణ సమస్యలు

1. **"OPENAI_API_KEY ఎన్విరాన్మెంట్ వేరియబుల్ సెట్ కాలేదు"**
   - మీరు `OPENAI_API_KEY` ఎన్విరాన్మెంట్ వేరియబుల్ సెట్ చేసినట్లయినట్లు ఖాతరు చేసుకోండి
   - వేరియబుల్ సెట్ చేసిన తర్వాత టెర్మినల్/కమాండ్ ప్రాంప్ట్ ని రీస్టార్ట్ చేయండి

2. **"localhost:8080 కి కనెక్షన్ తిరస్కరించబడింది"**
   - MCP క్యాల్క్యులేటర్ సేవ 8080 పోర్టులో నడుస్తున్నదని నిర్ధారించుకోండి
   - ఇంకొక సేవ 8080 పోర్టును వాడుతుందా అని పరిశీలించండి

3. **"ఆథెంటికేషన్ విఫలమైంది"**
   - మీ API కీ సరైనదో పరిశీలించండి
   - మీరు ఉపయోగించదలచుకున్న ఎండ్‌పాయింట్‌తో `OPENAI_BASE_URL` సరిపోలుతున్నదో చూడండి

4. **మావెన్ బిల్డ్ తప్పిదాలు**
   - మీరు జావా 21 లేదా అంతకంటే పైగా వర్షన్ ఉపయోగిస్తున్నారని నిర్ధారించుకోండి: `java -version`
   - బిల్డ్ క్లీన్ చేయడానికి ప్రయత్నించండి: `mvnw clean`

### డీబగ్గింగ్

డీబగ్ లాగింగ్ ప్రారంభించడానికి, నడపేప్పుడు ఈ JVM ఆర్గ్యుమెంట్ జోడించండి:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## కాన్ఫిగరేషన్

అప్లికేషన్ ఈ విధంగా కాన్ఫిగర్ చేయబడింది:
- డిఫాల్ట్‌గా MiniMax-M3 ఉపయోగిస్తుంది లేదా `MINIMAX_MODEL_ID` సెట్ చేసినప్పుడు MiniMax-M2.7 ఉపయోగిస్తుంది
- `OPENAI_BASE_URL` సెట్ చేసినప్పుడు దానితో అనుసంధానం చేస్తుంది; లేకపోతే `MINIMAX_REGION=cn_zh` అయితే `https://api.minimaxi.com/v1` లేదా డిఫాల్ట్‌గా `https://api.minimax.io/v1` ఉపయోగిస్తుంది
- MCP సేవకు `http://localhost:8080/sse` వద్ద కనెక్ట్ అవుతుంది
- అభ్యర్థనలకు 60-సెకన్ల టైమ్‌ఔట్ ఉపయోగిస్తుంది

## డిపెండెన్సీలు

ఈ ప్రాజెక్టులో ఉపయోగించే ముఖ్య డిపెండెన్సీలు:
- **LangChain4j**: AI ఇంటిగ్రేషన్ మరియు టూల్ నిర్వహణ కోసం
- **LangChain4j MCP**: మోడల్ కాంటెక్స్ట్ ప్రోటోకాల్ మద్దతుకు
- **LangChain4j OpenAI అధికారిక**: MiniMax OpenAI-అనుకూల API ఇంటిగ్రేషన్ కోసం
- **Spring Boot**: అప్లికేషన్ ఫ్రేమ్‌వర్క్ మరియు డిపెండెన్సీ ఇంజెక్షన్ కోసం
