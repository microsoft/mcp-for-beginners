# కాలిక్యులేటర్ LLM క్లయింట్

ఎలా LangChain4j ను ఉపయోగించి MiniMax OpenAI-అనుకూల API ద్వారా MCP (మోడల్ కాంటెక్ట్స్ ప్రోటోకాల్) కాలిక్యులేటర్ సేవకు కనెక్ట్ అవ్వాలో చూపించే జావా అప్లికేషన్.

## ముందస్తు అవసరాలు

- జావా 21 లేదా పైగా
- Maven 3.6+ (లేదా అందులో ఉన్న Maven రాపర్ ఉపయోగించండి)
- MiniMax API కీ
- `http://localhost:8080` వద్ద నడుస్తున్న MCP కాలిక్యులేటర్ సర్వీస్

## API కీ పొందడం

ఈ అప్లికేషన్ MiniMax OpenAI-అనుకూల API ను ఉపయోగిస్తుంది. మీ కీ మరియు ఎండ్పాయింట్ పొందడానికి ఈ దశలను అనుసరించండి:

### 1. ఒక ఎండ్పాయింట్ ఎంచుకోండి
1. గ్లోబల్ ఎండ్పాయింట్ కోసం `https://api.minimax.io/v1` ఉపయోగించండి
2. చైనా ఎండ్పాయింట్ కోసం `https://api.minimaxi.com/v1` ఉపయోగించండి

### 2. API కీ సృష్టించండి
1. మీ MiniMax ఖాతా నుండి MiniMax API కీ సృష్టించండి
2. కీని ఒక సురక్షిత స్థలంలో ఉంచండి

### 3. ఎన్విరాన్‌మెంట్ వేరియబుల్స్ సెట్ చేయండి

#### విండోలు (కమాండ్ ప్రాంప్ట్):
```cmd
set OPENAI_API_KEY=your_minimax_api_key_here
set OPENAI_BASE_URL=https://api.minimax.io/v1
set MINIMAX_MODEL_ID=MiniMax-M3
```

#### విండోలు (పవర్‌షెల్):
```powershell
$env:OPENAI_API_KEY="your_minimax_api_key_here"
$env:OPENAI_BASE_URL="https://api.minimax.io/v1"
$env:MINIMAX_MODEL_ID="MiniMax-M3"
```

#### macOS/Linux:
```bash
export OPENAI_API_KEY=your_minimax_api_key_here
export OPENAI_BASE_URL=https://api.minimax.io/v1
export MINIMAX_MODEL_ID=MiniMax-M3
```

## సెటప్ మరియు ఇన్‌స్టాలేషన్

1. **ప్రాజెక్ట్ డైరెక్టరీని క్లోన్ చేయండి లేదా వెళ్లండి**

2. **డిపెండెన్సీలు ఇన్‌స్టాల్ చేయండి**:
   ```cmd
   mvnw clean install
   ```
   లేదా మీరు Maven గ్లోబల్‌గా ఇన్‌స్టాల్ చేసినట్లయితే:
   ```cmd
   mvn clean install
   ```

3. **ఎన్విరాన్‌మెంట్ వేరియబుల్స్ సెట్ చేయండి** ("API కీ పొందడం" సెక్షన్ చూడండి)

4. **MCP కాలిక్యులేటర్ సర్వీస్ ప్రారంభించండి**:
   చాప్టర్ 1 లోని MCP కాలిక్యులేటర్ సర్వీస్ `http://localhost:8080/sse` వద్ద నడుస్తుందో నిర్ధారించండి. ఇది క్లయింట్ ప్రారంభించే ముందు నడవాలి.

## అప్లికేషన్ నడుపుట

```cmd
mvnw clean package
java -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## అప్లికేషన్ ఏమి చేస్తుంది

అప్లికేషన్ కాలిక్యులేటర్ సర్వీస్‌తో మూడు ప్రధాన పరస్పర చర్యలను ప్రదర్శిస్తుంది:

1. **జోడింపు**: 24.5 మరియు 17.3 మొత్తాన్ని లెక్కిస్తుంది
2. **స్క్వేర్ రూట్**: 144 యొక్క చదరపు మูล్యాన్ని లెక్కిస్తుంది
3. **సహాయం**: అందుబాటులో ఉన్న కాలిక్యులేటర్ ఫంక్షన్లను చూపిస్తుంది

## ఆశిత అవుట్పుట్

విజయవంతంగా నడిచేటప్పుడు, మీరు క్రింది వంటి అవుట్పుట్ చూడవచ్చు:

```
The sum of 24.5 and 17.3 is 41.8.
The square root of 144 is 12.
The calculator service provides the following functions: add, subtract, multiply, divide, sqrt, power...
```

## సమస్య పరిష్కారం

### సాధారణ సమస్యలు

1. **"OPENAI_API_KEY ఎన్విరాన్‌మెంట్ వేరియబుల్ సెట్ కాలేదు"**
   - మీరు `OPENAI_API_KEY` ఎన్విరాన్‌మెంట్ వేరియబుల్ సెట్ చేసినట్లు నిర్ధారించుకోండి
   - వేరియబుల్ సెట్ చేసిన తర్వాత టెర్మినల్/కమాండ్ ప్రాంప్ట్ రీస్టార్ట్ చేయండి

2. **"localhost:8080 కు కనెక్షన్ తిరస్కరించబడింది"**
   - MCP కాలిక్యులేటర్ సర్వీస్ 8080 పోర్ట్‌లో నడుస్తున్నదని నిర్ధారించండి
   - ఇంకొక సర్వీస్ పోర్ట్ 8080 ఉపయోగిస్తున్నదా అని తనిఖీ చేయండి

3. **"ఆథెంటికేషన్ విఫలం"**
   - మీ API కీ చెల్లుబాటు అయ్యేది అని నిర్ధారించుకోండి
   - మీరు ఉపయోగించదలచుకున్న ఎండ్పాయింట్‌కు `OPENAI_BASE_URL` సరిపోయేదని తనిఖీ చేయండి

4. **Maven బిల్డ్ లో తప్పులు**
   - మీరు జావా 21 లేదా త_MARKOWN పైన వాడుతున్నారని నిర్ధారించుకోండి: `java -version`
   - బిల్డ్ క్లీన్ చెయ్యండి: `mvnw clean`

### డీబగ్గింగ్

డీబగ్గింగ్ లాగింగ్‌ను ఎనేబుల్ చేయడానికి, రన్ చేసినప్పుడు ఈ JVM ఆర్గ్యుమెంట్‌ను జోడించండి:
```cmd
java -Dlogging.level.dev.langchain4j=DEBUG -jar target\calculator-llm-client-0.0.1-SNAPSHOT.jar
```

## కాన్ఫిగరేషన్

అప్లికేషన్ కింది విధంగా కాన్ఫిగర్ చేయబడింది:
- డిఫాల్ట్‌గా MiniMax-M3 ఉపయోగిస్తుంది; `MINIMAX_MODEL_ID` సెటింగ్ ద్వారా `MiniMax-M3` లేదా `MiniMax-M2.7` ఎంచుకోండి
- `OPENAI_BASE_URL` సెట్ అయితే దానికి కనెక్ట్ అవుతుంది; లేకపోతే `MINIMAX_REGION=cn_zh` ఉన్నప్పుడు `https://api.minimaxi.com/v1` లేదా డిఫాల్ట్‌గా `https://api.minimax.io/v1` ఉపయోగిస్తుంది
- MCP సర్వీస్‌కు `http://localhost:8080/sse` వద్ద కనెక్ట్ అవుతుంది
- రిక్వెస్ట్‌లకు 60 సెకన్ల టైమ్‌ఆઉట్ ఉపయోగిస్తుంది

## డిపెండెన్సీలు

ఈ ప్రాజెక్టులో ఉపయోగించే ప్రధాన డిపెండెన్సీలు:
- **LangChain4j**: AI ఇంటిగ్రేషన్ మరియు టూల్ మేనేజ్‌మెంట్ కోసం
- **LangChain4j MCP**: మోడల్ కాంటెక్స్ట్ ప్రోటోకాల్ మద్దతు కోసం
- **LangChain4j OpenAI అధికారిక**: MiniMax OpenAI-అనుకూల API ఇంటిగ్రేషన్ కోసం
- **Spring Boot**: అప్లికేషన్ ఫ్రేమ్‌వర్క్ మరియు డిపెండెన్సీ ఇంజెక్షన్ కోసం
