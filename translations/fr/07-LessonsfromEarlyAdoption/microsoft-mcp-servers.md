## 🔧 Comprendre les serveurs MCP : guide pour débutants

### Qu’est-ce qu’un serveur MCP ?

En tant que débutant dans le Model Context Protocol (MCP), vous vous demandez peut-être : « Qu’est-ce qu’un serveur MCP exactement, et pourquoi devrais-je m’en soucier ? » Commençons par une analogie simple.

Pensez aux serveurs MCP comme à des assistants spécialisés qui aident votre compagnon de codage IA (comme GitHub Copilot) à se connecter à des outils et services externes. Tout comme vous pouvez utiliser différentes applis sur votre téléphone pour différentes tâches — une pour la météo, une pour la navigation, une pour la banque — les serveurs MCP permettent à votre assistant IA d’interagir avec différents outils et services de développement.

### Le problème que les serveurs MCP résolvent

Avant les serveurs MCP, si vous vouliez :
- Vérifier vos ressources Azure
- Créer un issu GitHub
- Interroger votre base de données
- Chercher dans la documentation

Vous deviez arrêter de coder, ouvrir un navigateur, naviguer vers le site approprié, et effectuer ces tâches manuellement. Ce changement constant de contexte brise votre rythme et réduit votre productivité.

### Comment les serveurs MCP transforment votre expérience de développement

Avec les serveurs MCP, vous pouvez rester dans votre environnement de développement (VS Code, Visual Studio, etc.) et simplement demander à votre assistant IA de gérer ces tâches. Par exemple :

**Au lieu de ce flux de travail traditionnel :**
1. Arrêter de coder
2. Ouvrir le navigateur
3. Aller sur le portail Azure
4. Chercher les détails du compte de stockage
5. Revenir à VS Code
6. Reprendre le codage

**Vous pouvez désormais faire ceci :**
1. Demander à l’IA : « Quel est le statut de mes comptes de stockage Azure ? »
2. Continuer à coder avec les informations fournies

### Avantages clés pour les débutants

#### 1. 🔄 **Rester dans votre état de flow**
- Plus besoin de passer d’une application à une autre
- Gardez votre concentration sur le code que vous écrivez
- Réduisez la charge mentale de gestion de différents outils

#### 2. 🤖 **Utilisez le langage naturel plutôt que des commandes complexes**

- Au lieu de retenir les commandes Azure CLI, expliquez ce que vous voulez accomplir
- Laissez l’IA gérer les détails techniques pendant que vous vous concentrez sur la logique

#### 3. 🔗 **Connecter plusieurs outils ensemble**
- Créez des flux de travail puissants en combinant différents services
- Exemple : « Récupère toutes les issues GitHub récentes et crée les éléments de travail correspondants dans Azure DevOps »
- Construisez de l’automatisation sans écrire de scripts complexes

#### 4. 🌐 **Accéder à un écosystème en pleine expansion**
- Profitez des serveurs développés par Microsoft, GitHub et d’autres sociétés
- Mélangez et assortissez des outils de différents fournisseurs de façon transparente
- Rejoignez un écosystème standardisé qui fonctionne avec différents assistants IA

#### 5. 🛠️ **Apprendre en pratiquant**
- Commencez avec des serveurs préconstruits pour comprendre les concepts
- Construisez progressivement vos propres serveurs à mesure que vous gagnez en confiance
- Utilisez les SDKs et la documentation disponibles pour guider votre apprentissage

### Exemple concret pour les débutants

Imaginons que vous débutiez en développement web et travaillez sur votre premier projet. Voici comment les serveurs MCP peuvent vous aider :

**Approche traditionnelle :**
```
1. Code a feature
2. Open browser → Navigate to GitHub
3. Create an issue for testing
4. Open another tab → Check Azure docs for deployment
5. Open third tab → Look up database connection examples
6. Return to VS Code
7. Try to remember what you were doing
```

**Avec les serveurs MCP :**
```
1. Code a feature

3. Ask AI: "How do I deploy this to Azure according to the docs?"
4. Ask AI: "Show me the best way to connect to my database"
5. Continue coding with all the information you need
```

## Démarrage avec MCP dans VS Code et Visual Studio 🚀

La configuration des serveurs MCP est simple si vous utilisez Visual Studio Code ou Visual Studio 2022 avec GitHub Copilot.

### Configuration VS Code

Voici le processus de base pour VS Code :

1. **Activer le mode Agent** : dans VS Code, passez en mode Agent dans la fenêtre Copilot Chat
2. **Configurer les serveurs MCP** : ajoutez les configurations serveurs dans votre fichier settings.json de VS Code
3. **Démarrer les serveurs** : cliquez sur le bouton "Start" pour chaque serveur que vous souhaitez utiliser
4. **Sélectionner les outils** : choisissez quels serveurs MCP activer pour la session en cours

Pour des instructions de configuration détaillées, consultez la [documentation MCP pour VS Code](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Astuce pro : gérez les serveurs MCP comme un expert !**
> 
> La vue Extensions de VS Code inclut désormais une [interface pratique pour gérer les serveurs MCP installés](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode) ! Vous avez un accès rapide pour démarrer, arrêter et gérer n’importe quel serveur MCP installé avec une interface claire et simple. Essayez !

### Configuration Visual Studio 2022

Pour Visual Studio 2022 (version 17.14 ou ultérieure) :

1. **Activer le mode Agent** : cliquez sur le menu déroulant "Ask" dans la fenêtre GitHub Copilot Chat et sélectionnez "Agent"
2. **Créer fichier de configuration** : créez un fichier `.mcp.json` dans le répertoire de votre solution (emplacement recommandé : `<SOLUTIONDIR>\.mcp.json`)
3. **Configurer les serveurs** : ajoutez vos configurations serveur MCP au format standard MCP
4. **Validation des outils** : lorsque demandé, approuvez les outils que vous souhaitez utiliser avec les permissions d’accès appropriées

Pour des instructions détaillées sur la configuration dans Visual Studio, consultez la [documentation MCP Visual Studio](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Chaque serveur MCP a ses propres exigences de configuration (chaînes de connexion, authentification, etc.), mais le schéma de configuration est cohérent entre les deux IDEs.

### 1. 📚 Serveur MCP Microsoft Learn Docs

[![Installer dans VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![Installer dans VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**Ce qu’il fait** : Le serveur MCP Microsoft Learn Docs est un service cloud qui fournit aux assistants IA un accès en temps réel à la documentation officielle Microsoft via le Model Context Protocol. Il se connecte à `https://learn.microsoft.com/api/mcp` et permet une recherche sémantique à travers Microsoft Learn, la documentation Azure, la documentation Microsoft 365, et d’autres sources officielles Microsoft.

**Pourquoi c’est utile** : Bien que cela puisse sembler être "juste de la documentation," ce serveur est en fait crucial pour chaque développeur utilisant les technologies Microsoft. Une des principales plaintes des développeurs .NET concernant les assistants IA de code est qu’ils ne sont pas à jour sur les dernières versions de .NET et C#. Le serveur MCP Microsoft Learn Docs résout ce problème en fournissant un accès en temps réel à la documentation la plus récente, aux références API, et aux meilleures pratiques. Que vous travaillez avec les derniers SDK Azure, exploriez les nouvelles fonctionnalités C# 13, ou implémentiez les derniers patterns Aspire, ce serveur garantit que votre assistant IA a accès à l’information autoritaire et actuelle dont il a besoin pour générer un code précis et moderne.

**Utilisation concrète** : « Quelles sont les commandes az cli pour créer une application conteneur Azure selon la documentation officielle Microsoft Learn ? » ou « Comment configurer Entity Framework avec l'injection de dépendances dans ASP.NET Core ? » Ou bien « Peux-tu revoir ce code pour vérifier s’il correspond aux recommandations de performance dans la documentation Microsoft Learn. » Le serveur offre une couverture complète de Microsoft Learn, des docs Azure, et de la documentation Microsoft 365 en utilisant une recherche sémantique avancée pour trouver l’information la plus pertinente. Il retourne jusqu’à 10 extraits de contenu de haute qualité avec titres d’articles et URLs, accédant toujours à la documentation Microsoft la plus récente dès sa publication.

**Exemple phare** : Le serveur expose l’outil `microsoft_docs_search` qui effectue une recherche sémantique dans la documentation technique officielle de Microsoft. Une fois configuré, vous pouvez poser des questions comme « Comment implémenter l’authentification JWT dans ASP.NET Core ? » et obtenir des réponses détaillées, officielles, avec liens sources. La qualité de recherche est exceptionnelle car elle comprend le contexte – demander « containers » dans un contexte Azure renvoie à la documentation Azure Container Instances, tandis que dans un contexte .NET, les informations pertinentes sur les collections C# sont retournées.

Ceci est particulièrement utile pour des bibliothèques ou cas d'utilisation récemment mis à jour ou en évolution rapide. Par exemple, lors de projets de codage récents, je souhaitais exploiter des fonctionnalités des dernières versions d’Aspire et Microsoft.Extensions.AI. En incluant le serveur MCP Microsoft Learn Docs, j’ai pu bénéficier non seulement des docs API, mais aussi des guides pratiques fraîchement publiés.

### 2. ☁️ Serveur MCP Azure


[![Installer dans VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Installer dans VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Ce que cela fait** : Le serveur Azure MCP est une suite complète de plus de 15 connecteurs spécialisés pour les services Azure qui intègre tout l'écosystème Azure dans votre flux de travail IA. Ce n'est pas juste un serveur unique – c'est une collection puissante qui inclut la gestion des ressources, la connectivité aux bases de données (PostgreSQL, SQL Server), l'analyse de journaux Azure Monitor avec KQL, l'intégration Cosmos DB, et bien plus encore.

**Pourquoi c'est utile** : Au-delà de la simple gestion des ressources Azure, ce serveur améliore considérablement la qualité du code lorsque vous travaillez avec les SDK Azure. Lorsque vous utilisez Azure MCP en mode Agent, il ne vous aide pas seulement à écrire du code – il vous aide à écrire du *meilleur* code Azure qui respecte les dernières méthodes d'authentification, les meilleures pratiques de gestion des erreurs, et exploite les dernières fonctionnalités du SDK. Au lieu d'obtenir un code générique qui pourrait fonctionner, vous obtenez un code qui suit les schémas recommandés par Azure pour les charges de travail en production.

**Modules clés incluent** :
- **🗄️ Connecteurs de bases de données** : Accès en langage naturel direct à Azure Database pour PostgreSQL et SQL Server
- **📊 Azure Monitor** : Analyse de journaux par KQL et informations opérationnelles
- **🌐 Gestion des ressources** : Gestion complète du cycle de vie des ressources Azure
- **🔐 Authentification** : Patterns DefaultAzureCredential et identité managée
- **📦 Services de stockage** : Opérations sur Blob Storage, Queue Storage, et Table Storage
- **🚀 Services de conteneurs** : Gestion des Azure Container Apps, Container Instances, et AKS
- **Et bien d'autres connecteurs spécialisés**

**Utilisation réelle** : "Liste mes comptes de stockage Azure", "Interroge mon espace Log Analytics pour les erreurs de la dernière heure", ou "Aide-moi à construire une application Azure en Node.js avec une authentification appropriée"

**Scénario de démonstration complet** : Voici une présentation complète qui montre la puissance de la combinaison Azure MCP avec l'extension GitHub Copilot for Azure dans VS Code. Lorsque vous avez les deux installés et que vous saisissez :

> "Crée un script Python qui télécharge un fichier sur Azure Blob Storage en utilisant l'authentification DefaultAzureCredential. Le script doit se connecter à mon compte de stockage Azure nommé 'mycompanystorage', télécharger dans un conteneur nommé 'documents', créer un fichier test avec la date et heure actuelles à télécharger, gérer les erreurs de façon élégante avec une sortie informative, suivre les meilleures pratiques Azure pour l'authentification et la gestion des erreurs, inclure des commentaires expliquant comment fonctionne l'authentification DefaultAzureCredential, et rendre le script bien structuré avec des fonctions appropriées et une documentation."

Le serveur Azure MCP générera un script Python complet prêt pour la production qui :
- Utilise le dernier SDK Azure Blob Storage avec les patterns async appropriés
- Implémente DefaultAzureCredential avec une explication complète de la chaîne de secours
- Inclut une gestion robuste des erreurs avec des types spécifiques d'exceptions Azure
- Suit les meilleures pratiques du SDK Azure pour la gestion des ressources et des connexions
- Fournit une journalisation détaillée et une sortie console informative
- Crée un script bien structuré avec fonctions, documentation et annotations de types

Ce qui rend cela remarquable, c'est que sans Azure MCP, vous pourriez obtenir un code générique pour le stockage des blobs qui fonctionne mais ne suit pas les schémas Azure actuels. Avec Azure MCP, vous obtenez un code qui exploite les méthodes d'authentification les plus récentes, gère les scénarios d'erreurs spécifiques à Azure, et suit les pratiques recommandées par Microsoft pour les applications en production.

**Exemple mis en avant** : J'ai eu du mal à me souvenir des commandes spécifiques des CLI `az` et `azd` pour une utilisation ponctuelle. C'est toujours un processus en deux étapes pour moi : d'abord chercher la syntaxe, puis exécuter la commande. Souvent, je finis par aller dans le portail et naviguer pour accomplir mon travail parce que je n'aime pas admettre que je ne me souviens pas de la syntaxe CLI. Pouvoir simplement décrire ce que je veux est incroyable, et encore mieux de pouvoir le faire sans quitter mon IDE !

Il existe une excellente liste de cas d'utilisation dans le [dépôt Azure MCP](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) pour bien démarrer. Pour des guides d'installation complets et des options de configuration avancées, consultez la [documentation officielle d'Azure MCP](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

### 3. 🐙 Serveur GitHub MCP

[![Installer dans VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Installer dans VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**Ce que cela fait** : Le Serveur GitHub MCP officiel offre une intégration transparente avec l'ensemble de l'écosystème GitHub, proposant à la fois un accès distant hébergé et des options de déploiement local via Docker. Ce n'est pas seulement pour les opérations de base sur les dépôts – c'est un ensemble d'outils complet qui inclut la gestion des GitHub Actions, les flux de travail des pull requests, le suivi des issues, l'analyse de sécurité, les notifications et des capacités d'automatisation avancées.

**Pourquoi c'est utile** : Ce serveur transforme la façon dont vous interagissez avec GitHub en apportant une expérience complète de la plateforme directement dans votre environnement de développement. Au lieu de devoir constamment basculer entre VS Code et GitHub.com pour la gestion de projet, les revues de code et la surveillance CI/CD, vous pouvez tout gérer par des commandes en langage naturel tout en restant concentré sur votre code.

> **ℹ️ Note : Différents types d'« agents »**
> 
> Ne confondez pas ce Serveur GitHub MCP avec le Coding Agent de GitHub (l'agent IA que vous pouvez assigner aux issues pour des tâches de codage automatisées). Le Serveur GitHub MCP fonctionne dans le mode Agent de VS Code pour fournir l'intégration API GitHub, tandis que le Coding Agent de GitHub est une fonctionnalité distincte qui crée des pull requests lorsqu'il est assigné aux issues GitHub.

**Fonctionnalités clés incluent** :
- **⚙️ GitHub Actions** : Gestion complète des pipelines CI/CD, surveillance des workflows, et gestion des artefacts
- **🔀 Pull Requests** : Création, revue, fusion, et gestion des PR avec suivi complet du statut
- **🐛 Issues** : Gestion complète du cycle de vie des issues, commentaires, étiquetage, et assignation
- **🔒 Sécurité** : Alertes de scan de code, détection de secrets, et intégration Dependabot
- **🔔 Notifications** : Gestion intelligente des notifications et contrôle des abonnements aux dépôts
- **📁 Gestion de dépôts** : Opérations sur les fichiers, gestion des branches, et administration des dépôts
- **👥 Collaboration** : Recherche utilisateur et organisation, gestion des équipes, et contrôle des accès

**Utilisation réelle** : "Crée une pull request depuis ma branche feature", "Montre-moi tous les runs CI échoués cette semaine", "Liste les alertes de sécurité ouvertes pour mes dépôts", ou "Trouve toutes les issues assignées à moi dans mes organisations"

**Scénario de démonstration complet** : Voici un flux de travail puissant qui démontre les capacités du Serveur GitHub MCP :

> "Je dois préparer notre revue de sprint. Montre-moi toutes les pull requests que j'ai créées cette semaine, vérifie le statut de nos pipelines CI/CD, crée un résumé des alertes de sécurité à traiter, et aide-moi à rédiger les notes de version basées sur les PR fusionnées avec l'étiquette 'feature'."

Le serveur GitHub MCP :
- Interrogera vos pull requests récentes avec des informations de statut détaillées
- Analysera les runs de workflow et mettra en lumière les échecs ou problèmes de performance
- Compiler les résultats du scan de sécurité et priorisera les alertes critiques
- Générera des notes de version complètes en extrayant les informations des PR fusionnées
- Fournira des prochaines étapes concrètes pour la planification du sprint et la préparation de la release

**Exemple mis en avant** : J'adore utiliser cela pour les workflows de revue de code. Au lieu de passer d'un côté VS Code, notifications GitHub, et pages de pull request, je peux dire "Montre-moi toutes les PR en attente de ma revue" puis "Ajoute un commentaire sur la PR #123 pour demander au sujet de la gestion des erreurs dans la méthode d'authentification." Le serveur gère les appels API GitHub, maintient le contexte de la discussion, et m'aide même à rédiger des commentaires de revue plus constructifs.

**Options d'authentification** : Le serveur prend en charge à la fois OAuth (intégré dans VS Code) et les jetons d'accès personnels, avec des jeux d'outils configurables pour n'activer que les fonctionnalités GitHub dont vous avez besoin. Vous pouvez l'exécuter comme service distant hébergé pour une installation instantanée ou localement via Docker pour un contrôle total.

> **💡 Astuce de pro**
> 
> Activez uniquement les jeux d'outils dont vous avez besoin en configurant le paramètre `--toolsets` dans vos paramètres du serveur MCP pour réduire la taille du contexte et améliorer la sélection des outils IA. Par exemple, ajoutez `"--toolsets", "repos,issues,pull_requests,actions"` à vos arguments de configuration MCP pour les workflows de développement principaux, ou utilisez `"--toolsets", "notifications, security"` si vous souhaitez principalement les capacités de surveillance GitHub.

### 5. 📝 Serveur MarkItDown MCP

**Ce que cela fait** : MarkItDown est un serveur de conversion de documents complet qui transforme divers formats de fichiers en Markdown de haute qualité, optimisé pour la consommation par des LLM et les flux de travail d'analyse de texte.

**Pourquoi c'est utile** : Essentiel pour les flux de travail de documentation modernes ! MarkItDown gère une large gamme de formats de fichiers tout en préservant la structure critique des documents comme les titres, listes, tableaux et liens. Contrairement aux simples outils d'extraction de texte, il se concentre sur le maintien de la signification sémantique et du formatage, précieux à la fois pour le traitement par IA et la lecture humaine.

**Formats de fichiers pris en charge** :
- **Documents Office** : PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Fichiers multimédias** : Images (avec métadonnées EXIF et OCR), Audio (avec métadonnées EXIF et transcription vocale)
- **Contenu Web** : HTML, flux RSS, URLs YouTube, pages Wikipédia
- **Formats de données** : CSV, JSON, XML, fichiers ZIP (traitement récursif du contenu)
- **Formats de publication** : EPub, carnets Jupyter (.ipynb)
- **Email** : messages Outlook (.msg)
- **Avancé** : intégration Azure Document Intelligence pour un traitement amélioré des PDF

**Capacités avancées** : MarkItDown prend en charge les descriptions d'images alimentées par LLM (lorsqu'un client OpenAI est fourni), Azure Document Intelligence pour un traitement étendu des PDF, la transcription audio des contenus vocaux, ainsi qu'un système de plugins pour étendre à d'autres formats de fichiers.

**Usage concret** : « Convertir cette présentation PowerPoint en Markdown pour notre site de documentation », « Extraire le texte de ce PDF avec une structure correcte des titres » ou « Transformer ce tableau Excel en un format lisible »

**Exemple présenté** : Pour citer la [documentation de MarkItDown](https://github.com/microsoft/markitdown#why-markdown) :

> Le Markdown est extrêmement proche du texte brut, avec une mise en forme minimale, mais offre toujours un moyen de représenter une structure de document importante. Les LLM grand public, comme GPT-4o d'OpenAI, "parlent" nativement Markdown et l'intègrent souvent spontanément dans leurs réponses. Cela suggère qu'ils ont été entraînés sur d'importantes quantités de texte formaté en Markdown, et le comprennent bien. En bonus, les conventions Markdown sont aussi très efficientes en tokens.

MarkItDown excelle vraiment dans la préservation de la structure du document, ce qui est important pour les flux de travail IA. Par exemple, lors de la conversion d'une présentation PowerPoint, il conserve l'organisation des diapositives avec les bons titres, extrait les tableaux sous forme de tableaux Markdown, inclut le texte alternatif des images, et traite même les notes du présentateur. Les graphiques sont convertis en tableaux de données lisibles, et le Markdown résultant maintient le flux logique de la présentation originale. Cela le rend parfait pour alimenter les systèmes IA avec le contenu des présentations ou créer de la documentation à partir de diapositives existantes.
