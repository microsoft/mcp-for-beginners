## 🔧 Förstå MCP-servrar: En nybörjarguide

### Vad är MCP-servrar?

Som nybörjare inom Model Context Protocol (MCP) kanske du undrar: "Vad är egentligen en MCP-server och varför ska jag bry mig?" Låt oss börja med en enkel liknelse.

Tänk på MCP-servrar som specialiserade assistenter som hjälper din AI-kodningskompis (som GitHub Copilot) att koppla upp sig mot externa verktyg och tjänster. Precis som du kanske använder olika appar på din telefon för olika uppgifter—en för väder, en för navigation, en för bank—ger MCP-servrar din AI-assistent möjligheten att interagera med olika utvecklingsverktyg och tjänster.

### Problemet som MCP-servrar löser

Före MCP-servrar, om du ville:
- Kontrollera dina Azure-resurser
- Skapa en GitHub-issue 
- Fråga din databas
- Söka igenom dokumentation

Var du tvungen att sluta koda, öppna en webbläsare, navigera till rätt webbplats och manuellt utföra dessa uppgifter. Denna ständiga kontextväxling bryter ditt flow och minskar produktiviteten.

### Hur MCP-servrar förändrar din utvecklingsupplevelse

Med MCP-servrar kan du stanna kvar i din utvecklingsmiljö (VS Code, Visual Studio osv.) och helt enkelt be din AI-assistent att hantera dessa uppgifter. Till exempel:

**Istället för detta traditionella arbetsflöde:**
1. Sluta koda
2. Öppna webbläsare
3. Navigera till Azure-portalen
4. Söka upp detaljer om lagringskonto
5. Återvänd till VS Code
6. Fortsätt koda

**Kan du nu göra detta:**
1. Fråga AI: "Vad är statusen på mina Azure-lagringskonton?"
2. Fortsätt koda med den information som ges

## Kom igång med MCP i VS Code och Visual Studio 🚀

Att ställa in dessa MCP-servrar är enkelt om du använder Visual Studio Code eller Visual Studio 2022 med GitHub Copilot.

### VS Code-uppsättning

Här är den grundläggande processen för VS Code:

1. **Aktivera agentläge**: I VS Code, byt till agentläge i Copilot Chat-fönstret
2. **Konfigurera MCP-servrar**: Lägg till serverkonfigurationer i din VS Code settings.json-fil
3. **Starta servrar**: Klicka på "Starta" för varje server du vill använda
4. **Välj verktyg**: Välj vilka MCP-servrar som ska aktiveras för din aktuella session

För detaljerade installationsanvisningar, se [VS Code MCP-dokumentationen](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Profftips: Hantera MCP-servrar som ett proffs!**
> 
> VS Code Extensions-vyn inkluderar nu ett [praktiskt nytt gränssnitt för att hantera installerade MCP-servrar](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Du har snabb tillgång för att starta, stoppa och hantera alla installerade MCP-servrar via ett tydligt och enkelt gränssnitt. Prova det!

### Visual Studio 2022-uppsättning

För Visual Studio 2022 (version 17.14 eller senare):

1. **Aktivera agentläge**: Klicka på "Fråga"-rullgardinsmenyn i GitHub Copilot Chat-fönstret och välj "Agent"
2. **Skapa konfigurationsfil**: Skapa en `.mcp.json`-fil i din lösningsmapp (rekommenderad plats: `<SOLUTIONDIR>\.mcp.json`)
3. **Konfigurera servrar**: Lägg till dina MCP-serverkonfigurationer med standard-MCP-format
4. **Verktygs-godkännande**: När du uppmanas, godkänn de verktyg du vill använda med lämpliga åtkomstbehörigheter

För detaljerade Visual Studio-installationsinstruktioner, se [Visual Studio MCP-dokumentationen](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Varje MCP-server har sina egna konfigurationskrav (anslutningssträngar, autentisering osv.), men installationsmönstret är konsekvent i båda IDE:erna.

### 1. 📚 Microsoft Learn Docs MCP Server

[![Installera i VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![Installera i VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**Vad den gör**: Microsoft Learn Docs MCP Server är en molnbaserad tjänst som ger AI-assistenter realtidsåtkomst till officiell Microsoft-dokumentation via Model Context Protocol. Den ansluter till `https://learn.microsoft.com/api/mcp` och möjliggör semantisk sökning över Microsoft Learn, Azure-dokumentation, Microsoft 365-dokumentation och andra officiella Microsoft-källor.

**Varför den är användbar**: Även om det kan verka som "bara dokumentation" är denna server faktiskt avgörande för varje utvecklare som använder Microsoft-teknologier. En av de största klagomålen från .NET-utvecklare om AI-kodningsassistenter är att de inte är uppdaterade med de senaste .NET- och C#-versionerna. Microsoft Learn Docs MCP Server löser detta genom att erbjuda realtidsåtkomst till den mest aktuella dokumentationen, API-referenser och bästa praxis. Oavsett om du arbetar med de senaste Azure SDK:erna, utforskar nya C# 13-funktioner eller implementerar banbrytande Aspire-mönster, säkerställer denna server att din AI-assistent har tillgång till auktoritativ, uppdaterad information för att generera korrekt, modern kod.

**Verklig användning**: "Vilka är az cli-kommandona för att skapa en Azure containerapp enligt den officiella Microsoft Learn-dokumentationen?" eller "Hur konfigurerar jag Entity Framework med dependency injection i ASP.NET Core?" Eller vad sägs om "Granska denna kod för att säkerställa att den följer prestationsrekommendationerna i Microsoft Learn-dokumentationen." Servern erbjuder omfattande täckning över Microsoft Learn, Azure-dokument och Microsoft 365-dokumentation med avancerad semantisk sökning för att hitta den mest kontextuellt relevanta informationen. Den returnerar upp till 10 högkvalitativa innehållsbitar med artikeltitlar och URL:er, och får alltid tillgång till den senaste Microsoft-dokumentationen i takt med att den publiceras.

**Exempel som visas**: Servern exponerar verktyget `microsoft_docs_search` som utför semantisk sökning mot Microsofts officiella tekniska dokumentation. När den är konfigurerad kan du ställa frågor som "Hur implementerar jag JWT-autentisering i ASP.NET Core?" och få detaljerade, officiella svar med källor. Sökningens kvalitet är exceptionell eftersom den förstår kontext – att fråga om "containers" i en Azure-kontext ger resultat från Azure Container Instances-dokumentationen, medan samma term i en .NET-kontext ger relevant C#-samlingsinformation.

Detta är särskilt användbart för snabbt föränderliga eller nyligen uppdaterade bibliotek och användningsfall. Till exempel, i några nyliga kodningsprojekt ville jag utnyttja funktioner i de senaste versionerna av Aspire och Microsoft.Extensions.AI. Genom att inkludera Microsoft Learn Docs MCP-servern kunde jag använda inte bara API-dokumentationen utan även genomgångar och vägledning som just publicerats.

> **💡 Profftips**
> 
> Även modellverktyg som är vänliga mot verktyg behöver uppmuntran att använda MCP-verktyg! Överväg att lägga till en system-prompt eller [copilot-instructions.md](https://docs.github.com/copilot/how-tos/custom-instructions/adding-repository-custom-instructions-for-github-copilot) som: "Du har tillgång till `microsoft.docs.mcp` – använd detta verktyg för att söka i Microsofts senaste officiella dokumentation när du hanterar frågor om Microsoft-teknologier som C#, Azure, ASP.NET Core eller Entity Framework."
>
> För ett utmärkt exempel på detta i praktiken, kolla in [C# .NET Janitor chat-läget](https://github.com/awesome-copilot/chatmodes/blob/main/csharp-dotnet-janitor.chatmode.md) från Awesome GitHub Copilot-repositoriet. Detta läge använder specifikt Microsoft Learn Docs MCP-servern för att hjälpa till att städa upp och modernisera C#-kod med de senaste mönstren och bästa praxis.
### 2. ☁️ Azure MCP Server


[![Installera i VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Installera i VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Vad den gör**: Azure MCP Server är en omfattande svit med över 15 specialiserade Azure-tjänstekopplingar som för in hela Azure-ekosystemet i ditt AI-arbetsflöde. Det här är inte bara en enskild server – det är en kraftfull samling som inkluderar resurshantering, databasanslutning (PostgreSQL, SQL Server), Azure Monitor logganalys med KQL, Cosmos DB-integration och mycket mer.

**Varför den är användbar**: Utöver att bara hantera Azure-resurser förbättrar denna server dramatiskt kodkvaliteten när du arbetar med Azure SDK:er. När du använder Azure MCP i Agent-läge hjälper den dig inte bara att skriva kod – den hjälper dig att skriva *bättre* Azure-kod som följer aktuella autentiseringsmönster, bästa praxis för felhantering och använder de senaste SDK-funktionerna. Istället för att få generisk kod som kanske fungerar får du kod som följer Azures rekommenderade mönster för produktionsarbetsbelastningar.

**Nyckelmoduler inkluderar**:
- **🗄️ Databaskopplingar**: Direkt naturligt språklig åtkomst till Azure Database för PostgreSQL och SQL Server
- **📊 Azure Monitor**: KQL-drivna logganalyser och driftinsikter
- **🌐 Resurshantering**: Fullständig livscykelhantering av Azure-resurser
- **🔐 Autentisering**: DefaultAzureCredential och hanterade identitetsmönster
- **📦 Lagringstjänster**: Blob Storage, Queue Storage och Table Storage-operationer
- **🚀 Containertjänster**: Azure Container Apps, Container Instances och AKS-hantering
- **Och många fler specialiserade kopplingar**

**Praktisk användning**: "Lista mina Azure-lagringskonton", "Fråga mitt Log Analytics-arbetsområde efter fel under den senaste timmen", eller "Hjälp mig bygga en Azure-applikation med Node.js med korrekt autentisering"

**Fullständig demoscenario**: Här är en komplett genomgång som visar kraften i att kombinera Azure MCP med GitHub Copilot för Azure-extension i VS Code. När du har båda installerade och skriver:

> "Skapa ett Python-skript som laddar upp en fil till Azure Blob Storage med DefaultAzureCredential-autentisering. Skriptet ska ansluta till mitt Azure-lagringskonto med namnet 'mycompanystorage', ladda upp till en container som heter 'documents', skapa en testfil med aktuell tidsstämpel att ladda upp, hantera fel på ett elegant sätt och ge informativ output, följa Azures bästa praxis för autentisering och felhantering, inkludera kommentarer som förklarar hur DefaultAzureCredential-autentiseringen fungerar och göra skriptet välstrukturerat med korrekta funktioner och dokumentation."

Azure MCP Server genererar ett komplett, produktionsklart Python-skript som:
- Använder den senaste Azure Blob Storage SDK med korrekta asynkrona mönster
- Implementerar DefaultAzureCredential med omfattande förklaring av fallback-kedjan
- Inkluderar robust felhantering med specifika Azure-undantagstyper
- Följer Azure SDK:s bästa praxis för resurshantering och anslutningshantering
- Ger detaljerad loggning och informativ konsolutskrift
- Skapar ett korrekt strukturerat skript med funktioner, dokumentation och typer

Det som gör detta anmärkningsvärt är att utan Azure MCP kan du få generisk blob storage-kod som fungerar men inte följer nuvarande Azure-mönster. Med Azure MCP får du kod som använder de senaste autentiseringsmetoderna, hanterar Azure-specifika felscenarier och följer Microsofts rekommenderade praxis för produktionsapplikationer.

**Exempel**: Jag har haft svårt att komma ihåg de specifika kommandona för `az` och `azd` CLI:er för ad-hoc-användning. Det är alltid en tvåstegsprocess för mig: först leta upp syntaxen, sen köra kommandot. Jag hoppar ofta bara in i portalen och klickar runt för att få jobbet gjort eftersom jag inte vill erkänna att jag inte minns CLI-syntaxen. Att kunna bara beskriva vad jag vill är fantastiskt, och ännu bättre att kunna göra det utan att lämna min IDE!

Det finns en bra lista med användningsfall i [Azure MCP-repositoriet](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) för att komma igång. För omfattande installationsguider och avancerade konfigurationsalternativ, kolla in den [officiella Azure MCP-dokumentationen](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

### 3. 🐙 GitHub MCP Server

[![Installera i VS Code](https://img.shields.io/badge/VS_Code-Install_Server-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D) [![Installera i VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Server-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=github&config=%7B%22type%22%3A%20%22http%22%2C%22url%22%3A%20%22https%3A%2F%2Fapi.githubcopilot.com%2Fmcp%2F%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/github/github-mcp-server)

**Vad den gör**: Den officiella GitHub MCP Server erbjuder sömlös integration med GitHubs hela ekosystem och erbjuder både hostad fjärråtkomst och lokala Docker-distributionsalternativ. Det handlar inte bara om grundläggande repositories-operationer – det är en komplett verktygslåda som inkluderar hantering av GitHub Actions, pull request-arbetsflöden, ärendehantering, säkerhetsskanning, aviseringar och avancerade automatiseringsmöjligheter.

**Varför den är användbar**: Denna server förändrar hur du interagerar med GitHub genom att föra in hela plattformsupplevelsen direkt i din utvecklingsmiljö. Istället för att hela tiden växla mellan VS Code och GitHub.com för projektledning, kodgranskningar och CI/CD-övervakning kan du hantera allt via naturliga språkkonton medan du håller fokus på din kod.

> **ℹ️ Notera: Olika typer av 'agenter'**
> 
> Blanda inte ihop denna GitHub MCP Server med GitHubs Coding Agent (den AI-agent som du kan tilldela ärenden för automatiserade kodningsuppgifter). GitHub MCP Server fungerar inom VS Codes Agent-läge för att ge GitHub API-integration, medan GitHubs Coding Agent är en separat funktion som skapar pull requests när den tilldelas GitHub-ärenden.

**Nyckelfunktioner inkluderar**:
- **⚙️ GitHub Actions**: Fullständig hantering av CI/CD-pipelines, övervakning av arbetsflöden och hantering av artefakter
- **🔀 Pull Requests**: Skapa, granska, slå ihop och hantera PR:er med omfattande statusuppföljning
- **🐛 Ärenden**: Full hantering av ärendelivscykel, kommentarer, märkning och tilldelning
- **🔒 Säkerhet**: Kodsökvarningar, sekretessdetektion och Dependabot-integration
- **🔔 Aviseringar**: Smart aviseringhantering och kontroll av repositories-prenumerationer
- **📁 Repository-hantering**: Filoperationer, grenhantering och repository-administration
- **👥 Samarbete**: Sökning av användare och organisationer, teamhantering och åtkomstkontroll

**Praktisk användning**: "Skapa en pull request från min feature-branch", "Visa alla misslyckade CI-körningar denna vecka", "Lista öppna säkerhetsvarningar för mina repositories" eller "Hitta alla ärenden tilldelade mig över mina organisationer"

**Fullständig demoscenario**: Här är ett kraftfullt arbetsflöde som visar GitHub MCP Servers kapabiliteter:

> "Jag behöver förbereda inför vår sprintgranskning. Visa alla pull requests jag skapat denna vecka, kontrollera status för våra CI/CD-pipelines, skapa en sammanfattning av eventuella säkerhetsvarningar vi behöver hantera, och hjälp mig att skapa utgivningsanteckningar baserade på sammanslagna PR:er med etiketten 'feature'."

GitHub MCP Server kommer att:
- Fråga dina senaste pull requests med detaljerad statusinformation
- Analysera arbetsflödeskörningar och markera eventuella fel eller prestandaproblem
- Sammanställa resultat från säkerhetsskanning och prioritera kritiska varningar
- Generera omfattande utgivningsanteckningar genom att extrahera information från sammanslagna PR:er
- Ge handlingsbara nästa steg för sprintplanering och förberedelse av release

**Exempel**: Jag älskar att använda detta för kodgranskningsarbetsflöden. Istället för att hoppa mellan VS Code, GitHub-aviseringar och PR-sidor kan jag säga "Visa alla PR:er som väntar på min granskning" och sedan "Lägg till en kommentar på PR #123 och fråga om felhanteringen i autentiseringsmetoden." Servern hanterar GitHub API-anropen, bibehåller kontext om diskussionen och hjälper mig till och med att formulera mer konstruktiva granskningskommentarer.

**Autentiseringsalternativ**: Servern stöder både OAuth (sömlöst i VS Code) och personliga åtkomsttoken, med konfigurerbara verktygsuppsättningar för att aktivera endast den GitHub-funktionalitet du behöver. Du kan köra den som en hostad fjärrtjänst för omedelbar installation eller lokalt via Docker för fullständig kontroll.

> **💡 Tips**

- **Webbinnehåll**: HTML, RSS-flöden, YouTube-URL:er, Wikipedia-sidor
- **Dataformat**: CSV, JSON, XML, ZIP-filer (bearbetar innehållet rekursivt)
- **Publiceringsformat**: EPub, Jupyter-notebookar (.ipynb)
- **E-post**: Outlook-meddelanden (.msg)
- **Avancerat**: Azure Document Intelligence-integration för förbättrad PDF-bearbetning

**Avancerade funktioner**: MarkItDown stöder LLM-drivna bildbeskrivningar (när en OpenAI-klient tillhandahålls), Azure Document Intelligence för förbättrad PDF-bearbetning, ljudtranskription för talinnehåll och ett pluginsystem för utökning till fler filformat.

**Verklig användning**: "Konvertera denna PowerPoint-presentation till Markdown för vår dokumentationssajt", "Extrahera text från denna PDF med korrekt rubrikstruktur" eller "Omvandla detta Excel-kalkylblad till ett läsbart tabellformat"

**Exempel**: För att citera [MarkItDown-dokumentationen](https://github.com/microsoft/markitdown#why-markdown):

> Markdown ligger mycket nära vanlig text, med minimal markup eller formatering, men ger ändå ett sätt att representera viktigt dokumentstruktur. Storskaliga LLM, som OpenAI:s GPT-4o, "talar" inbyggt Markdown och inkorporerar ofta Markdown i sina svar utan att bli uppmanade till det. Detta antyder att de har tränats på stora mängder Markdown-formaterad text och förstår det väl. Som en bonus är Markdown-konventioner också mycket token-effektiva.

MarkItDown är mycket duktigt på att bevara dokumentstruktur, vilket är viktigt för AI-arbetsflöden. Till exempel, när en PowerPoint-presentation konverteras, behåller den bildorganisation med rätt rubriker, extraherar tabeller som Markdown-tabeller, inkluderar alt-text för bilder och bearbetar till och med talarmanus. Diagram konverteras till läsbara datatabeller och den resulterande Markdown behåller det logiska flödet i originalpresentationen. Detta gör den perfekt för att mata presentationsinnehåll till AI-system eller skapa dokumentation utifrån befintliga bilder.

## 📋 Slutsats

Model Context Protocol (MCP) förändrar hur utvecklare interagerar med AI-assistenter och externa verktyg. Dessa 10 Microsoft MCP-servrar visar kraften i standardiserad AI-integration, vilket möjliggör sömlösa arbetsflöden som håller utvecklare i sitt flow samtidigt som de får tillgång till kraftfulla externa funktioner.

Från den omfattande integreringen med Azure-ekosystemet till specialverktyg som Playwright för webbläsarautomation och MarkItDown för dokumentbearbetning, visar dessa servrar hur MCP kan öka produktiviteten i olika utvecklingsscenarier. Den standardiserade protokollet säkerställer att dessa verktyg fungerar smidigt tillsammans och skapar en sammanhängande utvecklingsupplevelse.

När MCP-ekosystemet fortsätter att utvecklas blir det viktigt att engagera sig i communityn, utforska nya servrar och bygga egna lösningar för att maximera din utvecklingsproduktivitet. MCP:s öppna standard gör att du kan kombinera verktyg från olika leverantörer för att skapa det perfekta arbetsflödet för dina specifika behov.

## 🎯 Övningar

1. **Installera och konfigurera**: Sätt upp en av MCP-servrarna i din VS Code-miljö och testa grundläggande funktionalitet.
2. **Arbetsflödesintegration**: Designa ett utvecklingsarbetsflöde som kombinerar minst tre olika MCP-servrar.
3. **Planering av egen server**: Identifiera en uppgift i din dagliga utvecklingsrutin som kan dra nytta av en anpassad MCP-server och skapa en specifikation för den.
4. **Prestandaanalys**: Jämför effektiviteten med att använda MCP-servrar kontra traditionella metoder för vanliga utvecklingsuppgifter.
5. **Säkerhetsbedömning**: Utvärdera säkerhetsimplikationerna av att använda MCP-servrar i din utvecklingsmiljö och föreslå bästa praxis.
