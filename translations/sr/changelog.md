# Дневник измена: MCP за почетнике курикулум

Овај документ служи као запис свих значајних измена направљених у курикулуму Model Context Protocol (MCP) за почетнике. Измене се документују у обрнутом хронолошком редоследу (најновије измене прве).

## 9. септембар 2026.

### MCP 2026-07-28 коначна усклађеност спецификације

Ажурирана енглеска верзија курикулума са препорука за верзију за издање и `2025-11-25`
основним смерницама на коначну MCP `2026-07-28` спецификацију.

- **Ажурирано**: Референце за текућу верзију, линкови спецификације, смернице за бездржавне
  захтеве, `server/discover`, Streamable HTTP заглавља и животни циклус Tasks
  екстензије у 38 енглеских докумената.
- **Исправљено**: Елиситација сада користи `elicitation/create`, Sampling користи
  `sampling/createMessage`, а `InputRequiredResult.resultType` користи
  `"input_required"`.
- **Замењено**: Нетачна лекција о Root Context стању разговора замењена је
  лекцијом која прецизно одговара протоколу, покривајући информативне смернице за фајл систем,
  тренутни мулти-повратни ток, безбедносне границе и опције миграције.
- **Појашњено**: Roots, Sampling, Logging и Dynamic Client Registration су
  деприкативни у `2026-07-28`, са документованим препорученим заменама и најранијим
  датумом уклањања.
- **Означено**: Примери који и даље зависе од MCP `2025-11-25`, HTTP+SSE,
  иницијализационих руковања или сесија протокола задржани су као примери старе
  компатибилности, а не приказани као тренутне имплементације.
- **Смернице за безбедност**: Ажурирани самостални безбедносни приручници да користе
  ауторизацију по захтеву и експлицитне примарне хендлове апликацијског стања уместо
  уклоњених ID сесија протокола. Client ID Metadata документи су сада
  препоручени пут за регистрацију, а DCR је документација само за компатибилност.
- **Подршка материјала**: Ажурирани студијски водич, листа доприносиоца,
  случај студије Publora и случај студије APIM. APIM водич сада препоручује
  свој тренутни Streamable HTTP `/mcp` крајњу тачку уместо застарелог `/sse`.
- **Канонични линкови**: Замена пензионисаних и нацрт спецификацијских URL-ова у енглеском
  изворном Markdown-у са верзионираним `2026-07-28` линковима, уз очување експлицитних
  линкова ка старим верзијама где пример остаје закључан на старијој алатки.
- **Стабилни имена фајлова**: Преименовани су водич за коначну спецификацију и два безбедносна
  водича да се уклоне суфикси верзија кандидат за издање и године, а затим су сви енглески
  хипервезе ажуриране на стабилне путање.
- **Нови пример ауторизације**: Додат тестиран
  [TypeScript MCP `2026-07-28` resource server](./02-Security/samples/cimd-dcr-auth/README.md)
  који упоређује препоручене Client ID Metadata документе са застарелом Dynamic
  Client Registration резервном опцијом. Пример укључује RFC 9728 дискавери, JWKS
  валидaцију, скопове по алатима, дванаест тестова и корак-по-корак ауторизацију у Auth0.
- **Опсег превода**: Уређени су само енглески изворни фајлови; аутоматски преводи и преведене слике
  остају непромењени.

### Ојачавање безбедности и санација рањивости зависности

Извршен је потпун безбедносни преглед свих манифеста зависности и примера кода, а затим поправљене све пријављене npm упозорења и један проналазак на нивоу кода. Након санације, `npm audit` извештава о **0 рањивости** у сваком директоријуму који је проверан.

#### npm рањивости зависности (прелазне) — Поправљене

Проверавано је свих 15 објављених `package-lock.json` фајлова. Ранивости су биле ограничене на прелазне зависности које вуче MCP инспектор дев алат, OpenAI клијент и MCP SDK; све су сада решене без прекидања примера:

- **10-StreamliningAIWorkflows.../lab4/code/github_mcp_server/inspector** и **lab3/code/weather_mcp/inspector**: Подигнуто `@modelcontextprotocol/inspector` (`0.16.6` / `0.14.1` → `0.22.0`), што је очистило упозорења из пакета `ajv`, `brace-expansion`, `diff`, `path-to-regexp` и `ws`. Додат npm унос `overrides` који приморава исправљени `shell-quote@1.8.4` да елиминише преостало критично упозорење које носи `concurrently`; регенерисани оба lockfile-а (сада 0 рањивости)
- **03-GettingStarted/samples/typescript**: `npm audit fix` ажурирао транзитивни `qs` (умерено) на исправљену верзију
- **03-GettingStarted/samples/javascript**: `npm audit fix` ажурирао транзитивни `hono` (умерено) на исправљену верзију
- **03-GettingStarted/03-llm-client/solution/typescript**: `npm audit fix` ажурирао транзитивни `form-data` (високо) на исправљену верзију
- **03-GettingStarted/11-simple-auth/solution/typescript**: Генерисан недостајући `package-lock.json` тако да је пројекат репродуктиван и подложан ревизији (0 рањивости)

#### Безбедносна поправка на нивоу кода (OWASP A03: Injection)

- **10-StreamliningAIWorkflows.../lab4/code/github_mcp_server/src/server.py**: Уклоњено `shell=True` из алата `open_in_vscode`. Претходни `subprocess.run(["start", "", vscode_path, folder_path], shell=True)` је дозвољавао да се специјални знакови љуске у путањи фасцикле тумаче од стране `cmd.exe` (вектор инјекције команде). Сада директно покреће решени `Code.exe` са фасциклом као аргументом — без љуске — што је функционално еквивалентно и безбедно

#### Ревизија Python зависности

- Ревидирани сви сетови Python захтева са `pip-audit`. `05-AdvancedTopics` и `03-GettingStarted/samples/python` су пријавили **никакве познате рањивости** (њихови опсези `mcp` / `httpx` / `pydantic` / `python-dotenv` воде до тренутних поправљених издања)
- **09-CaseStudy/docs-mcp/solution/python/requirements.txt**: `pip-audit` је означио транзитивну зависност **`werkzeug` 3.1.1** са три упозорења о отказу услуге (`safe_join` Windows имена уређаја) — `CVE-2025-66221`, `CVE-2026-21860` и `CVE-2026-27199` (сва три исправљена у 3.1.6). Додата експлицитна безбедносна верзија `werkzeug>=3.1.6` тако да се исправљена верзија реши; верификовано да ограничење чисто решава са стеком `chainlit` / `mcp` / `semantic-kernel`
