# 🚀 MCP сервер са PostgreSQL - Комплетан водич за учење

## 🧠 Преглед пута учења за интеграцију MCP базе података

Овај обједињени водич за учење вас учи како да изградите производно спремне **сервере протокола модела контекста (MCP)** који се интегришу са базама података кроз практичну примену малопродајне аналитике. Научићете образац корпоративног нивоа укључујући **безбедност на нивоу реда (RLS)**, **семантичко претраживање**, **интеграцију Azure AI**, и **приступ подацима више закупаца**.

Било да сте програмер позадине, инжењер вештачке интелигенције или архитекта података, овај водич пружа структуриран процес учења са примерима из стварног света и практичним вежбама које вас воде кроз следећи MCP сервер https://github.com/microsoft/MCP-Server-and-PostgreSQL-Sample-Retail.

- **Семантичко претраживање производа** коришћењем Azure OpenAI уграђивања

- **Производно спремно постављање** са Docker и Azure услугама
- **Свеобухватно праћење** помоћу Application Insights

## 🎯 Захтеви за учење

Да бисте извукли највише из овог пута учења, требало би да имате:

- **Искуство у програмирању**: Познавање Питхона (по могућству) или сличних језика
- **Знање о базама података**: Основно разумевање SQL и релационих база података
- **Концепти API-ја**: Разумевање REST API-ја и HTTP концепата
- **Алатке за развој**: Искусво са командном линијом, Git-ом и уредницима кода
- **Основе облака**: (опционо) Основно знање о Azure или сличним облачним платформама
- **Познавање Docker-а**: (опционо) Разумевање концепата контейнеризације

### Потребни алати

- **Docker Desktop** - За покретање PostgreSQL и MCP сервера
- **Azure CLI** - За постављање облачних ресурса
- **VS Code** - За развој и интеграцију MCP-а
- **Git** - За контролу верзија
- **Python 3.8+** - За развој MCP сервера
