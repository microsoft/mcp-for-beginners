# AGENTS.md

## Преглед пројекта

**MCP за почетнике** је отворени образовни курикулум за учење Model Context Protocol (MCP) - стандардирани оквир за интеракције између AI модела и клиентских апликација. Ово складиште пружа свеобухватне материјале за учење са примерима кода у више програмских језика.

### Кључне технологије

- **Програмски језици**: C#, Java, JavaScript, TypeScript, Python, Rust
- **Фрејмворци и SDK-ови**:
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **Базе података**: PostgreSQL са pgvector проширењем
- **Облачно окружење**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **Алати за изградњу**: npm, Maven, pip, Cargo
- **Документација**: Markdown са аутоматизованим преводом на више језика (48+ језика)

### Архитектура

- **11 језгровских модула (00-11)**: Секвенцијални пут учења од основа до напредних тема
- **Практичне радионице**: Практичне вежбе са комплетним решењем у више језика
- **Пример пројекти**: Радне имплементације MCP сервера и клијената
- **Систем превођења**: Аутоматизовани GitHub Actions радни ток за подршку више језика
- **Слике и ресурси**: Централизовани директоријум слика са преведеним верзијама

##### Циљ

Вaлидација промена у документацији курикулума и здравља репрезентативног пример кода
пре спајања.

##### Уноси

- `changed_paths: string[]` (обавезно) - релаивне путање које су промене у PR-у.
- `run_docs_lint: boolean` (подразумевано `true`)
- `run_links_audit: boolean` (подразумевано `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (подразумевано све `false`)

##### Излази

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### Дозволе

- Читање фајлова радне површине и писање артефаката генерисаних од стране алата (нпр. линт
  извештаје, тест логове) само; без писања у `translations/` или
  `translated_images/`.
- Извршавање локалних shell команди.
- Опциони приступ мрежи само за обнављање пакета (`npm ci`,
  `python -m pip install`, резолуција зависности `mvn`).
- Није дозвољено пушовање, спајање или измена у `translations/` или
  `translated_images/`.

##### Начини неуспеха

- `E_NO_INPUT_PATHS`: `changed_paths` је празан.
- `E_INVALID_PATH`: улазна путања излази из корена складишта.
- `E_LINT_FAILED`: markdown линт излази са ненултим кодом.
- `E_LINK_AUDIT_FAILED`: команда за проверу линкова излази са ненултим кодом.
- `E_SAMPLE_TEST_FAILED`: тест/изградња примера излази са ненултим кодом.
- `E_TIMEOUT`: команда је прешла подесно време извршења.

##### Рекомндовани CI уговор

За аутоматизацију валидације, конфигуришите CI задатак који:

- Покреће се на pull захтеве који дотичу `*.md`, пример код, или ову датотеку.
- Извршава тачно наведене команде горе.
- Чува логове као артефакте.
- Непосредно пропада задатак при било ком ненултом коду излаза.

### Структура документације

- **Модули 00-11**: Садржај основног курикулума у секвенцијалном редоследу
- **translations/**: Језички специфичне верзије (ауто-генерисане, не уређујте директно)
- **translated_images/**: Локализоване верзије слика (ауто-генерисане)
- **images/**: Изворне слике и дијаграми

### Прављење измена у документацији

1. Уређујте само енглеске markdown фајлове у директоријумима коренских модула (00-11)
2. По потреби ажурирајте слике у директоријуму `images/`
3. GitHub Action co-op-translator ће аутоматски генерисати преводе
4. Преводи се регенеришу при пушању у main грана

### Рад са преводима

- **Аутоматски превод**: GitHub Actions процес обрађује све преводе
- НЕ уређујте ручно фајлове у директоријуму `translations/`
- Мета-подаци о преводу су уграђени у сваки преведени фајл
- Подржани језици: преко 48 језика укључујући арапски, кинески, француски, немачки, хинди, јапански, корејски, португалски, руски, шпански и многе друге

## Упутства за стил кода

### Стил документације

- Користите јасан, пријатељски језик за почетнике
- Укључујте примере кода на више језика где је применљиво
- Пратите најбоље праксе за markdown:
  - Користите ATX стил заглавља (`#` синтакса)
  - Користите ограђене блокове кода са идентификаторима језика
  - Укључите описни алтернативни текст за слике
  - Држите дужину редова разумном (нема оштрог ограничења, али будите разумни)

### Стил примера кода

#### TypeScript/JavaScript
- Користите ES модуле (`import`/`export`)
- Пратите TypeScript строги режим
- Укључите анотације типова
- Циљно ES2022

#### Python
- Пратите PEP 8 стилске смернице
- Користите типске назнаке где је потребно
- Укључите docstring-ове за функције и класе
- Користите модерне Python функције (3.8+)

#### Java
- Пратите Spring Boot конвенције
- Користите Java 21 функције
- Пратите стандардну структуру Maven пројекта
- Укључите Javadoc коментаре

### Честа решавања проблема

**П: Мој PR не пролази проверу превода**
О: Проверите да ли сте уређивали само енглеске markdown фајлове у коренским модулима, а не преведене верзије.

**П: Како да додам нови језик?**
О: Подршка за језик се управља кроз co-op-translator процес. Отворите issue за дискусију о додавању нових језика.

**П: Примери кода не раде**

О: Уверите се да сте следили упутства за подешавање у README конкретног примера. Проверите да ли имате исправне верзије зависности.

**П: Слике се не приказују**
О: Потврдите да су путеви до слика релативни и да користе косе црте. Слике треба да буду у директоријуму `images/` или у `translated_images/` за локализоване верзије.
