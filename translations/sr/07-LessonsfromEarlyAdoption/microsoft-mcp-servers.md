## 🔧 Разумевање MCP сервера: Водич за почетнике

### Шта су MCP сервери?

Као почетник у Протоколу контекста модела (MCP), можда се питате: „Шта је тачно MCP сервер и зашто ми је то важно?“ Почнимо једноставном аналогом.

Размислите о MCP серверима као о специјализованим асистентима који помажу вашем AI пратиоцу (као што је GitHub Copilot) да се повеже са спољним алатима и сервисима. Баш као што на телефону користите различите апликације за различите задатке – једну за време, једну за навигацију, једну за банкарство – MCP сервери дају вашем AI асистенту могућност да комуницира са различитим развојним алатима и услугама.

### Проблем који MCP сервери решавају

Пре MCP сервера, ако сте желели да:
- Провeрите своје Azure ресурсе
- Креирате GitHub issue
- Извршите упит у бази података
- Претражите документацију

Морали сте да прекинете кодирање, отворите прегледач, идете на одговарајући сајт и ручно извршите ове задатке. Ова стална промена контекста прекида ваш ток рада и смањује продуктивност.

### Како MCP сервери трансформишу ваше искуство развоја

Са MCP серверима можете остати у вашем развојном окружењу (VS Code, Visual Studio, итд.) и једноставно замолити свог AI асистента да обради те задатке. На пример:

**Уместо овог традиционалног процеса:**
1. Престаните да кодирајете
2. Отворите прегледач
3. Идите на Azure портал
4. Потражите детаље о складишном рачуну
5. Вратите се у VS Code
6. Наставите са кодирањем

**Сада то можете урадити овако:**
1. Питајте AI: „Који је статус мојих Azure складишних рачуна?“
2. Наставите да кодирајете са добијеним информацијама

## Почетак рада са MCP у VS Code и Visual Studio 🚀

Постављање ових MCP сервера је једноставно ако користите Visual Studio Code или Visual Studio 2022 са GitHub Copilot.

### Подешавање за VS Code

Ево основног процеса за VS Code:

1. **Омогућите Agent Mode**: У VS Code пребаците се на Agent режим у прозору Copilot Chat
2. **Конфигуришите MCP сервере**: Додајте конфигурације сервера у датотеку settings.json у вашем VS Code
3. **Покрените сервере**: Кликните на дугме „Start“ за сваки сервер који желите да користите
4. **Изаберите алате**: Одаберите које MCP сервере ћете омогућити за ваш тренутни сесију

За детаљна упутства о подешавању, погледајте [VS Code MCP документацију](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Про савет: Управљајте MCP серверима као професионалац!**
> 
> View Extensions у VS Code сада укључује [практичан нови кориснички интерфејс за управљање инсталираним MCP серверима](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Имаш брз приступ за покретање, заустављање и управљање MCP серверима кроз јасан и једноставан интерфејс. Испробајте!

### Подешавање за Visual Studio 2022

За Visual Studio 2022 (верзија 17.14 или новија):

1. **Омогућите Agent Mode**: Кликните на падајући мени „Ask“ у прозору GitHub Copilot Chat и изаберите „Agent“
2. **Креирајте датотеку конфигурације**: Направите `.mcp.json` фајл у директоријуму вашег решења (препоручена локација: `<SOLUTIONDIR>\.mcp.json`)
3. **Конфигуришите сервере**: Додајте конфигурације ваших MCP сервера користећи стандардни MCP формат
4. **Одобрење алата**: Када вам буде затражено, одобрите алате које желите да користите уз одговарајуће дозволе

За детаљна упутства о подешавању Visual Studio, погледајте [Visual Studio MCP документацију](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Сваки MCP сервер има своје захтеве за конфигурацију (подаци за повезивање, аутентификација, итд.), али шаблон подешавања је исти у оба IDE-а.

### 1. 📚 Microsoft Learn Docs MCP сервер

[![Инсталирај у VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![Инсталирај у VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**Шта ради**: Microsoft Learn Docs MCP сервер је сервис у облаку који пружа AI асистентима приступ званичној Microsoft документацији у реалном времену преко Протокола контекста модела. Повезује се на `https://learn.microsoft.com/api/mcp` и омогућава семантичко претраживање кроз Microsoft Learn, Azure документацију, Microsoft 365 документацију и друге званичне изворе из Microsoft-а.

**Зашто је користан**: Иако може деловати као „само документација“, овај сервер је пресудан за сваког програмера који користи Microsoft технологије. Једна од највећих замерки .NET програмера на AI асистенте за кодирање је што нису ажурирани са најновијим издањима .NET-а и C#-а. Microsoft Learn Docs MCP сервер то решава тако што даје приступ најновијој документацији, API референцама и најбољим праксама у реалном времену. Без обзира да ли радите са најновијим Azure SDK-овима, истражујете нове функције C# 13 или примењујете напредне Aspire обрасце, овај сервер обезбеђује да ваш AI асистент има приступ ауторитетним, актуелним информацијама неопходним за генерише прецизан и модеран код.

**Примена у стварном свету**: „Које су az cli команде за креирање Azure container апликације према званичној Microsoft Learn документацији?“ или „Како конфигурисати Entity Framework са dependency injection у ASP.NET Core?“ Или шта кажете на „Прегледај овај код да се увериш да одговара препорукама за перформансе у Microsoft Learn документацији.“ Сервер пружа свеобухватну покривеност преко Microsoft Learn, Azure докумената и Microsoft 365 документације користећи напредно семантичко претраживање за проналажење најрелевантнијих информација. Враћа до 10 висококвалитетних делова садржаја са насловима чланака и URL адресама, увек приступајући најновијој Microsoft документацији чим је објављена.

**Истоимени пример**: Сервер излаже tool `microsoft_docs_search` који извршава семантичко претраживање у званичној техничкој документацији Microsoft-а. Када је конфигурисан, можете поставити питања попут „Како имплементирати JWT аутентификацију у ASP.NET Core?“ и добити детаљне, званичне одговоре са изворним линковима. Квалитет претраге је изванредан јер разуме контекст – питање о „контејнерима“ у Azure контексту враћа документацију о Azure Container Instances, док исти термин у .NET контексту враћа релевантне информације о C# колекцијама.

Ово је посебно корисно за брзо мењајуће или недавно ажуриране библиотеке и употребе. На пример, у неким недавним пројектима кодирања желео сам да искористим функције најновијих издања Aspire и Microsoft.Extensions.AI. Укључивањем Microsoft Learn Docs MCP сервера, могао сам да користим не само API документацију, већ и практичне водиче и инструкције које су тек објављене.

### 2. ☁️ Azure MCP сервер


[![Инсталирајте у VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Инсталирајте у VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Шта ради**: Azure MCP Server је свеобухватни скуп од преко 15 специјализованих Azure конектора који целокупни Azure екосистем уносе у ваш AI радни ток. Ово није само један сервер – то је моћна колекција која укључује управљање ресурсима, повезивање са базама података (PostgreSQL, SQL Server), анализу Azure Monitor логова са KQL, интеграцију Cosmos DB и још много тога.

**Зашто је користан**: Осим што управља Azure ресурсима, овај сервер значајно побољшава квалитет кода при раду са Azure SDK-овима. Када користите Azure MCP у Agent режиму, он не само да вам помаже да пишете код – помаже вам да пишете *бољи* Azure код који прати актуелне обрасце аутентификације, најбоље праксе за руковање грешкама и користи најновије могућности SDK-а. Уместо да добијете општи код који можда ради, добијате код који следи препоручене Azure обрасце за продукционе радне задатке.

**Кључни модули укључују**:
- **🗄️ Конектори за базе података**: директан приступ на природном језику Azure Database за PostgreSQL и SQL Server
- **📊 Azure Monitor**: анализа логова уз помоћ KQL и оперативни увиди
- **🌐 Управљање ресурсима**: целокупно управљање животним циклусом Azure ресурса
- **🔐 Аутентификација**: DefaultAzureCredential и обрасци управљаног идентитета
- **📦 Сервис складиштења**: операције са Blob Storage, Queue Storage и Table Storage
- **🚀 Контейнерски сервиси**: управљање Azure Container Apps, Container Instances и AKS-ом
- **И још много других специјализованих конектора**

**Примена у пракси**: "Прикажи моје Azure налоге за складиштење", "Постави упит у Log Analytics радни простор за грешке у последњем часу" или "Помози ми да направим Azure апликацију користећи Node.js са правилном аутентификацијом"

**Цео демо сценарио**: Ево потпуног водича који показује моћ комбиновања Azure MCP са GitHub Copilot за Azure екстензију у VS Code-у. Када имате оба инсталирана и унесете:

> "Направи Python скрипту која отпрема фајл у Azure Blob Storage користећи DefaultAzureCredential аутентификацију. Скрипта треба да се повеже са мојим Azure налогом за складиштење који се зове 'mycompanystorage', отпреми у контејнер 'documents', креира тест фајл са тренутним датума и времена за отпремање, лепо руковати грешкама и обезбеди информативан излаз, следи најбоље праксе Azure за аутентификацију и руковање грешкама, укључи коментаре који објашњавају како DefaultAzureCredential аутентификација функционише и направи скрипту добро структуирану са одговарајућим функцијама и документацијом."

Azure MCP Server ће генерисати потпуну, продукционо спремну Python скрипту која:
- Користи најновији Azure Blob Storage SDK са правилним async обрасцима
- Имплементира DefaultAzureCredential са свеобухватним објашњењем fallback ланца
- Укључује робусно руковање грешкама са специфичним типовима Azure изузетака
- Следи најбоље праксе Azure SDK за управљање ресурсима и везама
- Обезбеђује детаљно бележење и информативан излаз на конзоли
- Креира правилно структуирану скрипту са функцијама, документацијом и типским наговештајима

Оно што је изузетно је да без Azure MCP-а можете добити општи код за blob storage који ради, али не прати тренутне Azure обрасце. Са Azure MCP-ом добијате код који користи најновије методе аутентификације, рукује Azure-специфичним сценаријима грешака и прати препоручене праксе Microsoft-а за продукционе апликације.

**Истакнути пример**: Имао сам потешкоћа са памћењем специфичних команди за `az` и `azd` CLI алате за ад-хок употребу. Увек ми је то двостепени процес: прво потражим синтаксу, па онда изведем команду. Често улазим у портал и кликам како бих обавио посао јер не желим да признам да не могу да запамтим CLI синтаксу. Могућност да само опишем шта желим је невероватна, а још боље што могу то да урадим без напуштања мог IDE-а!

### 5. 📝 MarkItDown MCP Server


[![Инсталирај у VS Code](https://img.shields.io/badge/VS_Code-Install_MarkItDown_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D) [![Инсталирај у VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_MarkItDown_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/markitdown)

**Шта ради**: MarkItDown је свеобухватан сервер за конверзију докумената који претвара различите формате фајлова у висококвалитетни Markdown, оптимизован за коришћење са LLM-овима и радним токовима за анализу текста.

**Зашто је користан**: Неопходан за модерне радне токове документације! MarkItDown обрађује импресиван опсег формата фајлова док чува кључну структуру документа као што су наслови, листе, табеле и линкови. За разлику од алата за једноставно издвајање текста, фокусира се на одржавање семантичког значења и форматирања које је вредно и за AI обраду и за људску читљивост.

**Подржани формати фајлова**:
- **Офис документи**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Медијски фајлови**: Слике (са EXIF метаподацима и OCR), Аудио (са EXIF метаподацима и транскрипцијом говора)
- **Веб садржај**: HTML, RSS феедови, YouTube URL-ови, Wikipedia странице
- **Датски формати**: CSV, JSON, XML, ZIP фајлови (рекурзивно процесира садржај)
- **Формати за публиковање**: EPub, Jupyter нотебоокови (.ipynb)
- **Е-пошта**: Outlook поруке (.msg)
- **Напредно**: Интеграција Azure Document Intelligence за унапређену обраду PDF-ова

**Напредне могућности**: MarkItDown подржава описе слика покретане LLM-ом (када је обезбеђен OpenAI клијент), Azure Document Intelligence за унапређену обраду PDF-ова, транскрипцију аудио садржаја, као и плагин систем за проширење подршке другим форматима фајлова.

**Реална употреба**: "Конвертуј ову PowerPoint презентацију у Markdown за наш сајт за документацију", "Извуци текст из овог PDF-а са правилном структуром наслова", или "Трансформиши ову Excel табелу у читљиви табеларни формат"

**Истакнути пример**: Да цитирамо [MarkItDown документацију](https://github.com/microsoft/markitdown#why-markdown):

> Markdown је изузетно близу обичном тексту, са минималним означавањем или форматирањем, али и даље пружа начин да представи важну структуру документа. Главни LLM-ови, као што је OpenAI GPT-4o, изворно "говоре" Markdown и често несвесно укључују Markdown у своје одговоре. Ово сугерише да су тренирани на огромним количинама текста у Markdown формату и да га добро разумеју. Као споредан бонус, Markdown конвенције су такође веома ефикасне у потрошњи токена.

MarkItDown одлично чува структуру докумената што је важно за AI радне токове. На пример, при конверзији PowerPoint презентације, задржава организацију слајдова са правим насловима, извлачи табеле као Markdown табеле, укључује алтернативни текст за слике, па чак и обрађује белешке говорника. Графикони се претварају у читљиве табеле података, а результирајући Markdown задржава логички ток оригиналне презентације. Ово га чини савршеним за уношење презентационих садржаја у AI системе или за креирање документације из постојећих слајдова.
