## 🔧 Разумевање MCP сервера: Водич за почетнике

### Шта су MCP сервери?

Као почетник у Model Context Protocol (MCP), можда се питате: "Шта је тачно MCP сервер и зашто ми је то важно?" Почнимо са једноставном аналогијом.

Замислите MCP сервере као специјализоване асистенте који помажу вашем AI пратиоцу за програмирање (као што је GitHub Copilot) да се повеже са спољашњим алаткама и услугама. Баш као што користите различите апликације на свом телефону за различите задатке — једну за временску прогнозу, другу за навигацију, трећу за банкарство — MCP сервери дају вашем AI асистенту могућност да комуницира са разним развојним алаткама и услугама.

### Проблем који MCP сервери решавају

Пре MCP сервера, ако сте желели да:
- Проверите ваше Azure ресурсе
- Креирате GitHub issue
- Извршите упит у базу података
- Претражите документацију

Морали сте да прекинете програмирање, отворите прегледач, одете на одговарајући сајт и ручно извршите те задатке. Ова стална промена контекста прекида ваш радни ток и смањује продуктивност.

### Како MCP сервери трансформишу ваше развојно искуство

Са MCP серверима, можете остати у свом развојном окружењу (VS Code, Visual Studio и др.) и једноставно замолити свог AI асистента да обави те задатке. На пример:

**Уместо овог традиционалног тока:**
1. Прекини програмирање
2. Отвори прегледач
3. Иди на Azure портал
4. Потражи детаље о складишним налогима
5. Врати се у VS Code
6. Настави програмирање

**Сада то можете овако:**
1. Питај AI: "Који је статус мојих Azure складишних налога?"
2. Настави да пишеш код са добијеним информацијама

### Кључне предности за почетнике

#### 1. 🔄 **Останите у свом радном току**
- Нема више пребацивања између више апликација
- Останите фокусирани на код који пишете
- Смањите ментални напор управљања различитим алатима

#### 2. 🤖 **Користите природни језик уместо сложених команди**
- Уместо памћења SQL синтаксе, опишите које податке желите
- Уместо да памтите Azure CLI команде, објасните шта желите да постигнете
- Пустите AI да обради техничке детаље док ви радите на логици

#### 3. 🔗 **Повежите више алата заједно**
- Креирајте јаке токове рада комбиновањем различитих услуга
- Пример: "Добиј све нове GitHub issue-ове и направи одговарајуће Azure DevOps радне ставке"
- Направите аутоматизацију без писања сложених скрипти

#### 4. 🌐 **Приступајући све већем екосистему**
- Искористите сервере које праве Microsoft, GitHub и друге компаније
- Лако комбинујте алате од различитих продавница
- Прикључите се на стандардан екосистем који ради са различитим AI асистентима

#### 5. 🛠️ **Учите кроз рад**
- Почните са предефинисаним серверима да бисте разумели концепте
- Постепено правите своје сервере како будете стицали више самопоуздања
- Користите доступне SDK-ове и документацију у процесу учења

## Започињање рада са MCP у VS Code и Visual Studio 🚀

Подешавање ових MCP сервера је једноставно ако користите Visual Studio Code или Visual Studio 2022 са GitHub Copilot-ом.

### Подешавање у VS Code

Ево основног процеса за VS Code:

1. **Омогући Agent Mode**: У VS Code-у укључите Agent mode у прозору Copilot Chat
2. **Конфигуриши MCP сервере**: Додајте конфигурације сервера у ваш settings.json фајл за VS Code
3. **Покрени сервере**: Кликните на дугме "Start" за сваки сервер који желите да користите
4. **Изаберите алате**: Одаберите које MCP сервере желите да омогућите за текућу сесију

За детаљна упутства о подешавању погледајте [документацију за VS Code MCP](https://code.visualstudio.com/docs/copilot/copilot-mcp).

> **💡 Професионални савет: Управљајте MCP серверима као стручњак!**
> 
> У прегледу екстензија за VS Code сада имате [згодан нови интерфејс за управљање инсталираним MCP серверима](https://code.visualstudio.com/docs/copilot/chat/mcp-servers#_use-mcp-tools-in-agent-mode)! Брзо приступајте покретању, заустављању и управљању сваким MCP сервером преко јасног и једноставног интерфејса. Испробајте!

### Подешавање у Visual Studio 2022

За Visual Studio 2022 (верзија 17.14 или новија):

1. **Омогући Agent Mode**: Кликните на "Ask" падајући мени у GitHub Copilot Chat прозору и изаберите "Agent"
2. **Креирај конфигурациону датотеку**: Направите `.mcp.json` фајл у директоријуму вашег решења (препоручена локација: `<SOLUTIONDIR>\.mcp.json`)
3. **Конфигуришите сервере**: Додајте MCP конфигурације сервера користећи стандардни MCP формат
4. **Одобрење алата**: Када се затражи, одобрите алате које желите да користите са одговарајућим дозвољеним опсегом

За детаљна упутства за Visual Studio погледајте [Visual Studio MCP документацију](https://learn.microsoft.com/visualstudio/ide/mcp-servers).

Сваки MCP сервер има своје захтеве за конфигурацију (линије за повезивање, аутентификација итд.), али образац подешавања је уједначен у оба IDE-а.

### 1. 📚 Microsoft Learn Docs MCP Server

[![Инсталирај у VS Code](https://img.shields.io/badge/VS_Code-Install_Microsoft_Docs_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D) [![Инсталирај у VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Microsoft_Docs_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=microsoft.docs.mcp&config=%7B%22type%22%3A%22http%22%2C%22url%22%3A%22https%3A%2F%2Flearn.microsoft.com%2Fapi%2Fmcp%22%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/mcp)

**Шта ради**: Microsoft Learn Docs MCP сервер је сервис хостован у облаку који обезбеђује AI асистентима приступ званичној Microsoft документацији у реалном времену преко Model Context Protocol. Повезује се са `https://learn.microsoft.com/api/mcp` и омогућава семантичку претрагу кроз Microsoft Learn, Azure документацију, Microsoft 365 документацију и друге званичне Microsoft изворе.

**Зашто је користан**: Иако може изгледати као "само документација", овај сервер је пресудан за сваког програмера који користи Microsoft технологије. Једна од највећих примедби .NET програмера о AI асистентима је што нису у току са најновијим .NET и C# верзијама. Microsoft Learn Docs MCP сервер решава овај проблем обезбеђујући приступ најсвежијој документацији, API референцама и најбољим праксама у реалном времену. Без обзира да ли радите са најновијим Azure SDK-овима, истражујете нове C# 13 могућности или имплементирате најмодерније Aspire шаблоне, овај сервер осигурава да ваш AI асистент има приступ ауторитетним и ажурираним информацијама потребним за генерисање тачног, савременог кода.

**Пример из стварног света**: "Које су az cli команде за креирање Azure container апликације према званичној Microsoft Learn документацији?" или "Како конфигурисати Entity Framework са dependency injection у ASP.NET Core?" Или: "Прегледај овај код да видиш да ли одговара препорукама за перформансе из Microsoft Learn документације." Сервер пружа свеобухватну покривеност Microsoft Learn, Azure и Microsoft 365 документације користећи напредну семантичку претрагу да би пронашао најрелевантније информације. Враћа до 10 висококвалитетних делова садржаја са насловима и URL-овима, увек приступајући најновијој Microsoft документацији чим буде објављена.

**Издвојени пример**: Сервер излаже `microsoft_docs_search` алат који обавља семантичку претрагу званичне Microsoft техничке документације. Када је конфигурисан, можете поставити питања као што су "Како да имплементирам JWT аутентификацију у ASP.NET Core?" и добити детаљне, службене одговоре са линковима на изворе. Квалитет претраге је изузетан јер разуме контекст – питање о "контејнерима" у Azure контексту ће вратити документацију Azure Container Instances, док исти термин у .NET контексту враћа релевантне информације о C# колекцијама.

Ово је нарочито корисно за брзо променљиве или недавно ажуриране библиотеке и корисничке случајеве. На пример, у неким недавним пројектима желео сам да искористим могућности из најновијих верзија Aspire и Microsoft.Extensions.AI. Укључивањем Microsoft Learn Docs MCP сервера, могао сам да искористим не само API документацију, већ и упутства и смернице које су тек објављене.

### 2. ☁️ Azure MCP сервер

[![Инсталирај у VS Code](https://img.shields.io/badge/VS_Code-Install_Azure_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D) [![Инсталирај у VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_Azure_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=Azure%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40azure%2Fazure-mcp%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Azure/azure-mcp)

**Шта ради**: Azure MCP сервер је свеобухватан скуп од преко 15 специјализованих конектора Azure услуга који уносе целом Azure екосистем у ваш AI радни ток. Ово није само један сервер – то је моћна колекција која укључује управљање ресурсима, повезивање са базама података (PostgreSQL, SQL Server), анализу логова Azure Monitora са KQL, интеграцију Cosmos DB и много више.

**Зашто је користан**: Поред управљања Azure ресурсима, овај сервер драматично побољшава квалитет кода када радите са Azure SDK-овима. Када користите Azure MCP у Agent режиму, он вам не помаже само да пишете код – помаже вам да пишете *бољи* Azure код који поштује тренутне шаблоне аутентификације, најбоље праксе обраде грешака и користи најновије функције SDK-а. Уместо да добијете генерички код који можда ради, добијате код који прати препоручене Azure шаблоне за продукцијске радне задатке.

**Кључни модули укључују**:
- **🗄️ Конектори за базе података**: Природан језик приступ Azure Database for PostgreSQL и SQL Server
- **📊 Azure Monitor**: KQL-подржана анализа логова и оперативне информације
- **🌐 Управљање ресурсима**: Потпуно управљање животним циклусом Azure ресурса
- **🔐 Аутентификација**: DefaultAzureCredential и шаблони managed identity
- **📦 Услуге за складиштење**: Радње са Blob Storage, Queue Storage и Table Storage
- **🚀 Услуге контејнера**: Azure Container Apps, Container Instances и AKS управљање
- **И многи други специјализовани конектори**

**Пример из стварног света**: "Почини моје Azure складишне налоге", "Изврши упит у мом Log Analytics радном простору за грешке у последњем часу", или "Помози ми да направим Azure апликацију користећи Node.js са правилном аутентификацијом"

**Потпуни демонстрациони сценарио**: Ево потпуног корак-по-корак приказа који показује моћ комбинације Azure MCP-а са GitHub Copilot за Azure екстензију у VS Code-у. Када имате оба инсталирана и упишете упит:

> "Креирајте Python скрипт који отпрема фајл у Azure Blob Storage користећи аутентификацију DefaultAzureCredential. Скрипт треба да се повеже на мој Azure налог за складиштење под називом 'mycompanystorage', отпрема у контејнер под називом 'documents', направи тест фајл са тренутним временским печатом за отпремање, љубазно рукује грешкама и пружа информативан излаз, прати најбоље Azure праксе за аутентификацију и руковање грешкама, укључује коментаре који објашњавају како DefaultAzureCredential аутентификација ради и учини скрипт добро организованим са одговарајућим функцијама и документацијом."

Azure MCP Server ће генерисати комплетан, продукцијски спреман Python скрипт који:
- Користи најновији Azure Blob Storage SDK са одговарајућим async моделима
- Имплементира DefaultAzureCredential са детаљним објашњењем ланца резервних планова
- Укључује јаку обраду грешака са специфичним Azure изузецима
- Прати најбоље праксе Azure SDK за управљање ресурсима и везама
- Пружа детаљно логовање и информативан приказ на конзоли
- Креира исправно структуиран скрипт са функцијама, документацијом и типским појашњењима

Оно што је изванредно јесте да без Azure MCP-а можете добити генераички код за blob storage који ради али не прати актуелне Azure обрасце. Са Azure MCP-ом добијате код који користи најновије методе аутентификације, рукује специјалним Azure сценаријима грешака и следи Мицрософт препоруке за продукцијске апликације.

**Илустративни пример**: Мучио сам се са памћењем специфичних команди за `az` и `azd` CLI-је за повремену употребу. За мене је то увек двостепени процес: прво гледам синтаксу, затим покренем команду. Често само одем у портал и кликћем да обавим посао јер не желим да признам да не могу да се сетим CLI синтаксе. Могућност да само опишем шта желим је невероватна, а још боље је то учинити без изласка из IDE-а!

Постоји добра листа примера употребе у [Azure MCP репозиторијуму](https://github.com/Azure/azure-mcp?tab=readme-ov-file#-what-can-you-do-with-the-azure-mcp-server) да бисте почели. За детаљне упуте за подешавање и напредне опције конфигурације, погледајте [службену Azure MCP документацију](https://learn.microsoft.com/azure/developer/azure-mcp-server/).

- Саставити резултате безбедносног скенирања и дати приоритет критичним упозорењима
- Генерисати свеобухватне белешке о издању извлачењем информација из спојених PR-ова

### 5. 📝 MarkItDown MCP Server

[![Инсталирај у VS Code](https://img.shields.io/badge/VS_Code-Install_MarkItDown_MCP-0098FF?style=flat-square&logo=visualstudiocode&logoColor=white)](https://vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D) [![Инсталирај у VS Code Insiders](https://img.shields.io/badge/VS_Code_Insiders-Install_MarkItDown_MCP-24bfa5?style=flat-square&logo=visualstudiocode&logoColor=white)](https://insiders.vscode.dev/redirect/mcp/install?name=MarkItDown%20MCP&config=%7B%22command%22%3A%22npx%22%2C%22args%22%3A%5B%22-y%22%2C%22%40microsoft%2Fmcp-markitdown%40latest%22%5D%7D&quality=insiders) [![GitHub](https://img.shields.io/badge/GitHub-View_Repository-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/microsoft/markitdown)

**Шта ради**: MarkItDown је свеобухватан сервер за конверзију докумената који претвара разне формате фајлова у висококвалитетан Markdown, оптимизован за LLM конзумацију и радне токове анализе текста.

**Зашто је корисно**: Неопходан за савремене радне токове документације! MarkItDown подржава импресиван избор формата фајлова уз очување критичне структуре документа као што су наслови, спискови, табеле и линкови. За разлику од једноставних алата за извлачење текста, фокусира се на одржавање семантичког значења и форматирања које је вредно како за обраду од стране AI, тако и за људску читљивост.

**Подржани формати фајлова**:
- **Office документи**: PDF, PowerPoint (PPTX), Word (DOCX), Excel (XLSX/XLS)
- **Медијски фајлови**: Слике (са EXIF метаподацима и OCR), Аудио (са EXIF метаподацима и транскрипцијом говора)
- **Веб садржај**: HTML, RSS фидови, YouTube URL-ови, Wikipedia странице
- **Формати података**: CSV, JSON, XML, ZIP фајлови (рекурзивна обрада садржаја)
- **Формати за публиковање**: EPub, Jupyter notebook-ови (.ipynb)
- **Е-пошта**: Outlook поруке (.msg)
- **Напредно**: Azure Document Intelligence интеграција за унапређену обраду PDF-ова

**Напредне могућности**: MarkItDown подржава описе слика покретане LLM-ом (када се користи OpenAI клијент), Azure Document Intelligence за унапређену обраду PDF-ова, транскрипцију аудија за говорне садржаје и систем плагина за проширење подршке на додатне формате фајлова.

**Примена у стварном свету**: "Конвертуј ову PowerPoint презентацију у Markdown за наш сајт документације", "Извучи текст из овог PDF-а са исправном структуром наслова" или "Претвори ову Excel табелу у читљив формат табеле"

**Истакнути пример (парафразирано)**: The
[MarkItDown документација](https://github.com/microsoft/markitdown#why-markdown) објашњава
да Markdown очувава структуру документа уз мало форматирања.
Језички модели обично производе Markdown, чинећи га корисним, ефикасним
форматом за радне токове обраде докумената.

MarkItDown је заиста добар у очувању структуре документа, што је важно за AI радне токове. На пример, при конвертовању PowerPoint презентације, он задржава организацију слајдова са правим насловима, извлачи табеле као Markdown табеле, укључује алт текст за слике и чак обрађује белешке говорника. Графикони се конвертују у читљиве табеле података, а добијени Markdown одржава логички ток оригиналне презентације. Ово га чини савршеним за уношење садржаја презентације у AI системе или за креирање документације из постојећих слајдова.

Оно што ово чини заиста моћним је да превазилази јаз између упутстава у природном језику и извршног тест кода. Традиционални приступи захтевају или ручно писање тестова или приступ кодној бази ради контекста. Али са Playwright MCP, можете тестирати екстерне сајтове, корисничке апликације или радити у сценаријима црне кутије где приступ коду није доступан.

**Зашто је корисно**: Овај сервер мења начин на који радите са Azure AI сервисима тиме што уноси AI могућности на нивоу предузећа директно у ваш развојни ток. Уместо да пребацујете између Azure портала, документације и IDE-а, можете откривати моделе, имплементирати сервисе, управљати базама знања и процењивати учинак AI кроз команде на природном језику. Посебно је моћан за програмере који развијају RAG (Retrieval-Augmented Generation) апликације, управљају мултимоделским имплементацијама или спроводе свеобухватне AI евалуационе процесе.

**Кључне могућности за програмере**:

- **📚 Управљање знањем**: Креирајте и управљајте Azure AI Search индексима, додајте документе, конфигуришите индексере и изградите софистициране RAG системе
- **⚡ Интеграција AI агената**: Повежите се са Azure AI агентима, извршите упите постојећих агената и процените рад агената у продукционим сценаријима
- **📊 Оцјењивачки оквир**: Покрените свеобухватне текстуалне и агентске евалуације, генеришите извештаје у Markdown формату и имплементирајте контролу квалитета AI апликација
- **🚀 Алати за прототипизацију**: Добијте упутства за постављање GitHub-базиране прототипизације и приступите Microsoft Foundry Labs за најсавременије истраживачке моделе

**Примена у стварном свету**: „Имплементирај Phi-4 модел у Azure AI Services за моју апликацију“, „Креирај нови претраживачки индекс за мој документациони RAG систем“, „Оцени одговоре мог агента према мерилима квалитета“ или „Пронађи најбољи модел за резоновање за моје комплексне анализе“

**Цео демонстрациони сценарио**: Ево моћног AI развојног тока:

> „Правим агента за корисничку подршку. Помози ми да пронађем добар модел резоновања у каталогу, имплементирам га у Azure AI Services, направим базу знања од наше документације, поставим оквир за евалуацију да тестирам квалитет одговора, а затим ми помогни да прототипујем интеграцију са GitHub токеном за тестирање.“

Microsoft Foundry MCP Server ће:
- Извршити упит у каталогу модела да препоручи оптималне моделе резоновања на основу ваших захтева
- Пружити команде за имплементацију и информације о квотама за ваш омиљени Azure регион
- Поставити Azure AI Search индексе са одговарајућом шемом за вашу документацију
- Конфигурисати евалуационе цевоводе са мерилима квалитета и проверама безбедности
- Генерисати код за прототипизацију са GitHub аутентификацијом за одмах тестирање
- Пружити комплетне водиче за постављање прилагођене вашем технолошком скупу

**Пример из праксе**: Као програмер, имао сам потешкоћа да пратим различите LLM моделе који су доступни. Познајем неке главне, али имао сам осећај да пропуштам неке добитке у продуктивности и ефикасности. Токени и квоте су стресни и тешки за управљање – никад не знам да ли узимам прави модел за задатак или трошим буџет неефикасно. Управо сам чуо за овај MCP Server од James Montemagno док сам распитивао колеге за препоруке MCP сервера за овај пост, и узбуђен сам да га испробам! Могућности откривања модела изгледају посебно импресивно за неког као што сам ја ко жели да истражи изван уобичајених опција и пронађе моделе оптимизоване за специфичне задатке. ## 📋 Закључак

Model Context Protocol (MCP) мења начин на који програмери комуницирају са AI асистентима и екстерним алатима. Ових 10 Microsoft MCP сервера показују снагу стандаризоване AI интеграције омогућавајући беспрекорне токове рада који држе програмере у стању фокуса док користе моћне екстерне могућности.

Од свеобухватне интеграције Azure екосистема до специјализованих алата као што су Playwright за аутоматизацију прегледача и MarkItDown за обраду докумената, ови сервери показују како MCP може повећати продуктивност у различитим развојним сценаријима. Стандаризовани протокол осигурава да ови алати функционишу беспрекорно заједно, стварајући кохерентно развојно искуство.

Како екосистем MCP наставља да се развија, одржавање контакта са заједницом, истраживање нових сервера и изградња прилагођених решења биће кључ за максимизирање ваше продуктивности у развоју. Отворена природа стандарда MCP значи да можете комбиновати алате различитих произвођача да бисте створили савршен ток рада за ваше специфичне потребе.
