# Деплој MCP сервера

> [!NOTE]
> Примери конфигурација који користе `/sse` ендпоинт циљају на стари HTTP+SSE пренос. MCP `2026-07-28` удаљени сервери користе Streamable HTTP, обично на ендпоинту који дефинише сервер као што је `/mcp`.
> транспорт. MCP `2026-07-28` удаљени сервери користе Streamable HTTP, обично на
> сервер дефинисаном ендпоинту попут `/mcp`.

Постављањем свог MCP сервера омогућавате другима приступ његовим алатима и ресурсима ван вашег локалног окружења. Постоји неколико стратегија деплојања које треба размотрити, у зависности од ваших захтева за скалабилношћу, поузданошћу и лакоћом управљања. Испод ћете пронаћи смернице за постављање MCP сервера локално, у контејнерима и на облаку.

## Преглед

Ова лекција покрива како да поставите вашу MCP Server апликацију.

## Циљеви учења

На крају ове лекције моћи ћете да:

- Процените различите приступе деплојању.
- Поставите своју апликацију.

## Локални развој и деплој

Ако је ваш сервер намењен за коришћење на рачунару корисника, можете пратити следеће кораке:

1. **Преузмите сервер**. Ако нисте написали сервер, прво га преузмите на своју машину.
1. **Покрените процес сервера**: Покрените вашу MCP сервер апликацију

За SSE (није потребно за stdio тип сервера)

1. **Конфигуришите мрежу**: Осигурајте да је сервер доступан на очекиваном порту
1. **Повежите клијенте**: Користите локалне URL-ове за конекције као што је `http://localhost:3000`

## Деплој на облак

MCP сервери могу бити постављени на различите облачне платформе:

- **Безсерверске функције**: Поставите лагане MCP сервере као безсерверске функције
- **Услуге контејнера**: Користите услуге као што су Azure Container Apps, AWS ECS или Google Cloud Run
- **Kubernetes**: Деплојујте и управљајте MCP серверима у Kubernetes кластерима за високу доступност

### Пример: Azure Container Apps

Azure Container Apps подржавају деплој MCP сервера. Још увек је у развоју и тренутно подржава SSE сервере.

Ево како то можете урадити:

1. Клонирајте репо:

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. Покрените га локално да тестирате:

  ```sh
  uv venv
  uv sync

  # линукс/macOS
  export API_KEYS=<AN_API_KEY>
  # виндоус
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. Да бисте покушали локално, направите *mcp.json* фајл у *.vscode* директоријуму и додајте следећи садржај:

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  Када се SSE сервер покрене, можете кликнути на иконицу за покретање у JSON фајлу, сада би требало да видите алате на серверу које хвата GitHub Copilot, видите икону алата.

1. За деплој, покрените следећу команду:

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

Ето, поставите га локално, деплујте га на Azure пратећи ове кораке.
