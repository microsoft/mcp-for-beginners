# Основна услуга калкулатора MCP

Ова услуга пружа основне операције калкулатора преко Model Context Protocol (MCP). Дизајнирана је као једноставан пример за почетнике који уче о имплементацијама MCP.

За више информација, погледајте [C# SDK](https://github.com/modelcontextprotocol/csharp-sdk)

## Карактеристике

Ова услуга калкулатора нуди следеће могућности:

1. **Основне аритметичке операције**:
   - Сабирање два броја
   - Одузаимање једног броја од другог
   - Множење два броја
   - Дељење једног броја другим (са провером делјења са нулом)

## Коришћење типа `stdio`
  
## Конфигурација

1. **Конфигуришите MCP сервере**:
   - Отворите ваш радни простор у VS Code.
   - Креирајте датотеку `.vscode/mcp.json` у вашем фолдеру радног простора за конфигурисање MCP сервера. Пример конфигурације:

     ```jsonc
     {
       "inputs": [
         {
           "type": "promptString",
           "id": "repository-root",
           "description": "The absolute path to the repository root"
         }
       ],
       "servers": {
         "calculator-mcp-dotnet": {
           "type": "stdio",
           "command": "dotnet",
           "args": [
             "run",
             "--project",
             "${input:repository-root}/03-GettingStarted/samples/csharp/src/calculator.csproj"
           ]
         }
       }
     }
     ```

   - Биће вам тражено да унесете корен GitHub репозиторијума, који се може добити из команде `git rev-parse --show-toplevel`.

## Коришћење услуге

Услуга пружа следеће API крајње тачке преко MCP протокола:

- `add(a, b)`: Саберите два броја
- `subtract(a, b)`: Одузмите други број од првог
- `multiply(a, b)`: Помножите два броја
- `divide(a, b)`: Поделите први број другим (са провером да није нула)
- isPrime(n): Проверите да ли је број прост

## Тестирање са Github Copilot Chat у VS Code

1. Покушајте да пошаљете захтев услузи користећи MCP протокол. На пример, можете питати:
   - "Сабери 5 и 3"
   - "Одузми 10 од 4"
   - "Помножи 6 и 7"
   - "Подели 8 са 2"
   - "Да ли је 37854 прост?"
   - "Који су 3 проста броја пре и после 4242?"
2. Да бисте били сигурни да користи алате, додајте #MyCalculator у упит. На пример:
   - "Сабери 5 и 3 #MyCalculator"
   - "Одузми 10 од 4 #MyCalculator


## Верзија у контејнеру

Претходно решење је сјајно када имате инсталиран .NET SDK и све зависности су постављене. Међутим, ако желите да делите решење или га покренете у другом окружењу, можете користити верзију у контејнеру.

1. Покрените Docker и уверите се да ради.
1. Из терминала се преместите у фолдер `03-GettingStarted\samples\csharp\src` 
1. Да бисте изградили Docker слику за услугу калкулатора, извршите следећу команду (замените `<YOUR-DOCKER-USERNAME>` својим Docker Hub корисничким именом):
   ```bash
   docker build -t <YOUR-DOCKER-USERNAME>/mcp-calculator .
   ``` 
1. Након што је слика изграђена, отпремите је на Docker Hub. Покрените следећу команду:
   ```bash
   docker push <YOUR-DOCKER-USERNAME>/mcp-calculator
   ```

## Коришћење Docker верзије

1. У датотеци `.vscode/mcp.json` замените конфигурацију сервера следећим:
   ```json
    "mcp-calculator": {
      "command": "docker",
      "args": [
        "run",
        "--rm",
        "-i",
        "<YOUR-DOCKER-USERNAME>/mcp-calculator"
      ],
      "envFile": "",
      "env": {}
    }
   ```
   Гледајући конфигурацију, можете видети да је команда `docker` а аргументи су `run --rm -i <YOUR-DOCKER-USERNAME>/mcp-calculator`. Заставица `--rm` обезбеђује да се контејнер уклони након што се заустави, а заставица `-i` вам омогућава интеракцију са стандардним улазом контејнера. Последњи аргумент је име слике коју смо управо изградили и отпремили на Docker Hub.

## Тестирање Docker верзије

Покрените MCP сервер кликом на дугме Старт изнад `"mcp-calculator": {`, и као и раније, можете тражити од услуге калкулатора да изврши неке математичке операције за вас.
