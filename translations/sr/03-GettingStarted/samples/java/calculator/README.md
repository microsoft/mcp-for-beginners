# Основна калкулатор MCP услуга

> [!NOTE]
> Овај пример користи наследни HTTP+SSE транспорт и циља SDK компатибилан
> са MCP `2025-11-25`. Нови удаљени сервери треба да користе `2026-07-28` Streamable
> HTTP подршку.

Ова услуга пружа основне калкулаторске операције преко Model Context Protocol (MCP) користећи Spring Boot са WebFlux транспортом. Дизајнирана је као једноставан пример за почетнике који уче о имплементацијама MCP-а.

За више информација, погледајте [MCP Server Boot Starter](https://docs.spring.io/spring-ai/reference/api/mcp/mcp-server-boot-starter-docs.html) референтну документацију.

## Преглед

Услуга приказује:
- Подршку за SSE (Server-Sent Events)
- Аутоматску регистрацију алата користећи Spring AI `@Tool` анотацију
- Основне калкулаторске функције:
  - Сабирање, одузимање, множење, дељење
  - Израчунавање степена и квадратног корена
  - Модул (остатак) и апсолутна вредност
  - Помоћна функција за опис операција

## Карактеристике

Овај калкулатор пружа следеће могућности:

1. **Основне аритметичке операције**:
   - Сабирање два броја
   - Одузимање једног броја од другог
   - Множење два броја
   - Делјење једног броја са другим (са провером дељења са нулом)

2. **Напредне операције**:
   - Израчунавање степена (подизање базе на експоненту)
   - Израчунавање квадратног корена (са провером за негативне бројеве)
   - Израчунавање модула (остатак при дељењу)
   - Израчунавање апсолутне вредности

3. **Помоћни систем**:
   - Уграђена помоћна функција која објашњава све доступне операције

## Коришћење услуге

Услуга пружа следеће API ентпојнт-ове преко MCP протокола:

- `add(a, b)`: Сабира два броја
- `subtract(a, b)`: Одзи има други број од првог
- `multiply(a, b)`: Множи два броја
- `divide(a, b)`: Делји први број са другим (са провером нуле)
- `power(base, exponent)`: Израчунава степен броја
- `squareRoot(number)`: Израчунава квадратни корен (са провером за негативни број)
- `modulus(a, b)`: Израчунава остатак при дељењу
- `absolute(number)`: Израчунава апсолутну вредност
- `help()`: Прима информације о доступним операцијама

## Коришћење LangChain4j клијента

Пројекат укључује LangChain4j пример клијента у `com.microsoft.mcp.sample.client.LangChain4jClient` који показује како интегрисати калкулаторску услугу са LangChain4j и GitHub моделима:

### Претходни услови

1. **Подешавање GitHub токена**:
   
   За коришћење GitHub AI модела (као што је phi-4), потребан вам је лични приступни токен:

   а. Идите у подешавања вашег GitHub налога: https://github.com/settings/tokens
   
   б. Кликните "Generate new token" → "Generate new token (classic)"
   
   в. Дајте свом токену описно име
   
   г. Изаберите следеће опсеге:
      - `repo` (Пуна контрола над приватним репозиторијумима)
      - `read:org` (Читање организације и чланства у тимовима, читање пројеката организације)
      - `gist` (Креирање гистова)
      - `user:email` (Приступ емаил адресама корисника (само за читање))
   
   д. Кликните "Generate token" и копирајте нови токен
   
   е. Подесите га као променљиву окружења:
      
      На Windows-у:
      ```
      set GITHUB_TOKEN=your-github-token
      ```
      
      На macOS/Linux-у:
      ```bash
      export GITHUB_TOKEN=your-github-token
      ```

   ж. За трајно подешавање, додајте га у променљиве окружења преко системских подешавања

2. Додајте LangChain4j GitHub зависност у ваш пројекат (већ укључено у pom.xml):
   ```xml
   <dependency>
       <groupId>dev.langchain4j</groupId>
       <artifactId>langchain4j-github</artifactId>
       <version>${langchain4j.version}</version>
   </dependency>
   ```

3. Осигурајте да калкулатор сервер ради на `localhost:8080`

### Покретање LangChain4j клијента

Овај пример показује:
- Повезивање са калкулатор MCP сервером преко SSE транспорта
- Коришћење LangChain4j за прављење chat бота који користи калкулаторске операције
- Интеграцију са GitHub AI моделима (сада користећи phi-4 модел)

Клијент шаље следеће пример упите ради демонстрације функционалности:
1. Израчунавање збира два броја
2. Пронаћи квадратни корен броја
3. Добијати информације о доступним калкулаторским операцијама

Покрените пример и проверите излаз у конзоли да видите како AI модел користи калкулаторске алате да одговори на упите.

### Конфигурација GitHub модела

LangChain4j клијент је конфигурисан да користи GitHub phi-4 модел са следећим подешавањима:

```java
ChatLanguageModel model = GitHubChatModel.builder()
    .apiKey(System.getenv("GITHUB_TOKEN"))
    .timeout(Duration.ofSeconds(60))
    .modelName("phi-4")
    .logRequests(true)
    .logResponses(true)
    .build();
```

За коришћење других GitHub модела, једноставно промените параметар `modelName` на други подржани модел (нпр. "claude-3-haiku-20240307", "llama-3-70b-8192" и др.).

## Зависности

Пројекат захтева следеће кључне зависности:

```xml
<!-- For MCP Server -->
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-starter-mcp-server-webflux</artifactId>
</dependency>

<!-- For LangChain4j integration -->
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-mcp</artifactId>
    <version>${langchain4j.version}</version>
</dependency>

<!-- For GitHub models support -->
<dependency>
    <groupId>dev.langchain4j</groupId>
    <artifactId>langchain4j-github</artifactId>
    <version>${langchain4j.version}</version>
</dependency>
```

## Покретање сервера

### Коришћење Java

```bash
java -jar target/calculator-server-0.0.1-SNAPSHOT.jar
```

### Коришћење MCP инспектора

MCP инспектор је користан алат за интеракцију са MCP услугама. Да бисте га користили са овом калкулаторском услугом:

1. **Инсталирајте и покрените MCP инспектор** у новом терминал прозору:
   ```bash
   npx @modelcontextprotocol/inspector
   ```

2. **Приступите веб корисничком интерфејсу** кликом на URL који апликација приказује (обично http://localhost:6274)

3. **Конфигуришите везу**:
   - Поставите тип транспорта на "SSE"
   - Поставите URL на SSE ентпојнт вашег сервера: `http://localhost:8080/sse`
   - Кликните "Connect"

4. **Користите алате**:
   - Кликните "List Tools" да видите доступне калкулаторске операције
   - Изаберите алат и кликните "Run Tool" да извршите операцију

### Коришћење Docker-а

Пројекат укључује Dockerfile за контејнеризовано постављање:

1. **Изградите Docker слику**:
   ```bash
   docker build -t calculator-mcp-service .
   ```

2. **Покрените Docker контејнер**:
   ```bash
   docker run -p 8080:8080 calculator-mcp-service
   ```

Ово ће:
- Изградити мултистепени Docker слику са Maven 3.9.9 и Eclipse Temurin 24 JDK
- Креирати оптимизовану контејнер слику
- Изложити услугу на порт 8080
- Покренути MCP калкулатор услугу унутар контејнера

Доступни сте услугу на `http://localhost:8080` након покретања контејнера.

## Решавање проблема

### Уобичајени проблеми са GitHub токеном

1. **Проблеми са дозволама токена**: Ако добијете 403 Forbidden грешку, проверите да ли ваш токен има исправне дозволе као што је наведено у претходним условима.

2. **Токен није пронађен**: Ако добијете грешку "No API key found", уверите се да је GITHUB_TOKEN променљива окружења исправно подешена.

3. **Ограничење учесталости захтева**: GitHub API има ограничења брзине. Ако наиђете на грешку ограничења (статусни код 429), сачекајте неколико минута пре покушаја поново.

4. **Истек токена**: GitHub токени могу истећи. Ако после неког времена добијете грешке при аутентификацији, генеришите нови токен и ажурирајте променљиву окружења.

Ако вам треба додатна помоћ, проверите [LangChain4j документацију](https://github.com/langchain4j/langchain4j) или [GitHub API документацију](https://docs.github.com/en/rest).
