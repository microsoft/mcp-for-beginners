## 🎯 ဒီ Module က ဘာတွေ ပါဝင်သလဲ

ဒီ module က အမှန်တကယ် အဖွဲ့အစည်းတွေ နဲ့ ဖန်တီးသူတွေ ဘယ်လို Model Context Protocol (MCP) ကို အသုံးချပြီး အခက်အခဲတွေကို ဖြေရှင်းကာ ဆန်းသစ်တီထွင်မှု အား ပေးနေသလဲဆိုတာကို လေ့လာပါမယ်။ အသေးစိတ် ကေ့စ်စာတမ်းတွေနဲ့ လက်တွေ့ စီမံကိန်းတွေ၊ ပြုလုပ်နိုင်တဲ့ ဥပမာတွေလည်း ပါတယ်၊ MCP က ဘယ်လို လုံခြုံပြီး၊ တိုးချဲ့နိုင်ပြီး၊ ချိတ်ဆက်ထားတဲ့ စကားပြောပုံစံ မော်ဒယ်တွေ၊ ကိရိယာတွေ နဲ့ စီးပွားရေး အချက်အလက် တွေကို ဆက်သွယ်ပေးနိုင်တာကို ရှာဖွေတွေ့ရှိပါလိမ့်မယ်။

### 📚 MCP ကို လက်တွေ့ တွေ့ရစေပါ

ဒီ စည်းကမ်းချက်တွေကို ထုတ်လုပ်မှုအဆင့် အတွက် အကောင်အထည်ဖော်ထားတဲ့ ကိရိယာတွေပေါ်မှာ ကြည့်ချင်ပါသလား? ကျွန်ုပ်တို့ရဲ့ [**မိုက်ခရိုဆော့ဖ် MCP ဆာဗာ ၁၀ ခု - ဖန်တီးသူ အလုပ်တိုးတက်မှုကို ပြောင်းလဲနေသူများ**](microsoft-mcp-servers.md) ကို ကြည့်ပါ၊ အဲဒီမှာ သင်အသုံးပြုနိုင်တဲ့ တကယ့် မိုက်ခရိုဆော့ဖ် MCP ဆာဗာတွေပါဝင်ပါတယ်။

## အမျိုးအစား

ဒီသင်ခန်းစာက အစောပိုင်း အသုံးပြုသူတွေ ဘယ်လို Model Context Protocol (MCP) ကို အသုံးချပြီး အမှန်တကယ် ဖြစ်ပေါ်နေတဲ့ အခက်အခဲတွေနဲ့ ဆန့်ကျင်ကာ စက်မှုလုပ်ငန်းတွေမှာ ဆန်းသစ်တီထွင်မှု ကို ကျင့်သုံးနေကြတာကို စူးစမ်းလေ့လာပါတယ်။ အသေးစိတ် ကေ့စ်စတက်ဒီးတွေ၊ လက်တွေ့လုပ်ဆောင်မှုစီမံကိန်းတွေနဲ့ MCP က ဘယ်လို စံသတ်မှတ်လိုက်တဲ့၊ လုံခြုံပြီး တိုးချဲ့နိုင်တဲ့ AI ပေါင်းစပ်မှုကို ဖန်တီးပေးလုပ်တဲဲ့ လမ်းကြောင်းတကျ ချိတ်ဆက်ပေးခြင်းဖြင့် အကြီးစား စကားမော်ဒယ်များ၊ ကိရိယာများနဲ့ စီးပွားရေး ဒေတာများကို တစ်ခုတည်းသော အစီအစဉ်တကျ ချိတ်ဆက်ပေးတယ်ဆိုသည်ကို ရှာဖွေတွေ့ရှိမှာဖြစ်ပါတယ်။ MCP အခြေပြု ဖြေရှင်းချက်များကို ဒီဇိုင်းဆွဲတည်ဆောက်ရာတွင် လက်တွေ့ အတွေ့အကြုံ ရရှိမည်၊ များစွာသုံးစွဲပုံစနစ်များမှ သင်ယူမည်၊ ထုတ်လုပ်မှု ပတ်ဝန်းကျင်များတွင် MCP ကို အသုံးချရာတွင် အကောင်းဆုံး နည်းလမ်းများကို ရှာဖွေတွေ့ရှိမည် ဖြစ်ပြီး MCP နည်းပညာနဲ့ ဒီလောက ဖွံ့ဖြိုးတိုးတက်မှုတို့ အလျောက်လမ်းကြောင်းများ၊ နောက်တော့ဘက် ကြောင့်ရှိသော ဖောက်သည်များကို လေ့လာလိမ့်မည်။

## သင်ယူရမည့် ရည်မှန်းချက်များ

- စက်မှုလုပ်ငန်းကွာဟချက် များအတွင်း MCP ကို တကယ့်ဘဝတွင် အကောင်အထည်ဖော်ကြည့်ရှုခြင်း။
- MCP အခြေပြု လုပ်ငန်းများကို ဒီဇိုင်းဆွဲပြီး တည်ဆောက်ခြင်း။
- MCP နည်းပညာတွင် ဖြစ်ပေါ်နေသော လမ်းကြောင်းများနဲ့ နောင်တွင် ဘယ်လိုတိုးတက်မလဲ စူးစမ်းခြင်း။
- လက်တွေ့ ဖန်တီးမှု အခြေအနေများတွင် အကောင်းဆုံး နည်းလမ်းများကို လက်တွေ့ အသုံးချခြင်း။

## တကယ့်ဘဝ MCP အကောင်အထည်ဖော်မှုများ

### ကေ့စ်စတက်ဒီ ၁: စီးပွားရေး လူကြိုက်များသော ဖောက်သည်ဝန်ဆောင်မှု အလိုအလျောက် စနစ်

လုပ်ငန်းကြီးတစ်ခုက MCP အခြေပြု ဖြေရှင်းချက်ကို ဖောက်သည်ဝန်ဆောင်မှု စနစ်များပေါ်တွင် စံချိန်တင် AI ဆက်သွယ်မှုများ ဖန်တီးရန် ဝယ်ယူအသုံးပြုခဲ့သည်။ ဒီကိစ္စသည် အောက်ပါအတိုင်း စီမံခန့်ခွဲနိုင်ခဲ့သည်။

- အများစုသော LLM ပံ့ပိုးသူများအတွက် အထူးသင့်တော်ရာ ချိတ်ဆက်ရပ်တည်ရာ စနစ်တစ်ခု ဖန်တီးခြင်း။
- ဌာနများအတွင်း စဉ်ဆက်မပြတ် သဘောတူညီမှုရှိသော prompt စီမံခန့်ခွဲမှုကို ထိန်းသိမ်းခြင်း။
- ခိုင်မာသော လုံခြုံမှုနဲ့ အညီအရောက် စီမံခန့်ခွဲမှု လုပ်ဆောင်ခြင်း။
- လိုအပ်ချက်အရ အမျိုးမျိုးသော AI မော်ဒယ်များအကြား လွယ်ကူစွာ နှုတ်ပြောင်းနိုင်ခြင်း။

**နည်းပညာဆိုင်ရာ အကောင်အထည်ဖော်မှု:**

```python
# ဖောက်သည်ထောက်ခံရေးအတွက် Python MCP ဆာဗာအကောင်အထည်ဖော်ခြင်း
import logging
import asyncio
from modelcontextprotocol import create_server, ServerConfig
from modelcontextprotocol.server import MCPServer
from modelcontextprotocol.transports import create_http_transport
from modelcontextprotocol.resources import ResourceDefinition
from modelcontextprotocol.prompts import PromptDefinition
from modelcontextprotocol.tool import ToolDefinition

# မှတ်တမ်းတင်ခြင်းကို ဖွင့်တပ်ဆင်ပါ
logging.basicConfig(level=logging.INFO)

async def main():
    # ဆာဗာ ဖွဲ့စည်းမှုကို ဖန်တီးပါ
    config = ServerConfig(
        name="Enterprise Customer Support Server",
        version="1.0.0",
        description="MCP server for handling customer support inquiries"
    )
    
    # MCP ဆာဗာကို စတင်လုပ်ဆောင်ပါ
    server = create_server(config)
    
    # အသိပညာအခြေခံ ရင်းမြစ်များကို မှတ်ပုံတင်ပါ
    server.resources.register(
        ResourceDefinition(
            name="customer_kb",
            description="Customer knowledge base documentation"
        ),
        lambda params: get_customer_documentation(params)
    )
    
    # prompt စနစ်ပုံစံများကို မှတ်ပုံတင်ပါ
    server.prompts.register(
        PromptDefinition(
            name="support_template",
            description="Templates for customer support responses"
        ),
        lambda params: get_support_templates(params)
    )
    
    # ထောက်ခံရေးကိရိယာများကို မှတ်ပုံတင်ပါ
    server.tools.register(
        ToolDefinition(
            name="ticketing",
            description="Create and update support tickets"
        ),
        handle_ticketing_operations
    )
    
    # HTTP ကန့်သတ်ချက်နှင့် ဆာဗာကို စတင်ပါ
    transport = create_http_transport(port=8080)
    await server.run(transport)

if __name__ == "__main__":
    asyncio.run(main())
```

**ရလဒ်များ:** မော်ဒယ်ကုန်ကျစရိတ် ၃၀% လျော့ချခြင်း၊ တုံ့ပြန်မှု တစ်စဉ်တစ်ရာ တည်ငြိမ်မှု ၄၅% တိုးတက်ခြင်း၊ ကမ္ဘာလုံးဆိုင်ရာ လည်ပတ်မှုများအတွက် အညီအနာခံမှု တိုးတက်ခြင်း။

### ကေ့စ်စတက်ဒီ ၂: ကျန်းမာရေး ကုသမှု အသံပုက္ခ

ကျန်းမာရေး လက်ခံရရှိသူတစ်ဦးက အသုံးပြုထားသော အထူးပြုမှု ထိန်းသိမ်းပြီးသော မော်ဒယ်များနှင့် စိတ်ချရသော လူနာဒေတာ စောင့်ရှောက်မှုဖြင့် MCP အဆောက်အအုံတည်ဆောက်ခဲ့သည်။

- အများပြည်သူနှင့် အထူးပြု ဆရာဝန် မော်ဒယ်များ အကြား ချောမွေ့စွာ ပြောင်းလဲ ဖလှယ်နိုင်ခြင်း။
- တင်းကြပ်သော ကိုယ်ရေးကာကွယ်မှု ထိန်းချုပ်မှုများနှင့် စစ်ဆေးစာရင်းများ။
- ရှိပြီးသား အီလက်ထရွန်းနစ် ကျန်းမာရေးမှတ်တမ်း (EHR) စနစ်များနှင့် ပေါင်းစည်းခြင်း။
- ဆေးဘက်ဆိုင်ရာ ဝေါဟာရများအတွက် တစ်ပြိုင်နက်တည်း prompt အင်ဂျင်နီယာ လုပ်ငန်းဆောင်တာ။

**နည်းပညာဆိုင်ရာ အကောင်အထည်ဖော်မှု:**

```csharp
// C# MCP host application implementation in healthcare application
using Microsoft.Extensions.DependencyInjection;
using ModelContextProtocol.SDK.Client;
using ModelContextProtocol.SDK.Security;
using ModelContextProtocol.SDK.Resources;

public class DiagnosticAssistant
{
    private readonly MCPHostClient _mcpClient;
    private readonly PatientContext _patientContext;
    
    public DiagnosticAssistant(PatientContext patientContext)
    {
        _patientContext = patientContext;
        
        // Configure MCP client with healthcare-specific settings
        var clientOptions = new ClientOptions
        {
            Name = "Healthcare Diagnostic Assistant",
            Version = "1.0.0",
            Security = new SecurityOptions
            {
                Encryption = EncryptionLevel.Medical,
                AuditEnabled = true
            }
        };
        
        _mcpClient = new MCPHostClientBuilder()
            .WithOptions(clientOptions)
            .WithTransport(new HttpTransport("https://healthcare-mcp.example.org"))
            .WithAuthentication(new HIPAACompliantAuthProvider())
            .Build();
    }
    
    public async Task<DiagnosticSuggestion> GetDiagnosticAssistance(
        string symptoms, string patientHistory)
    {
        // Create request with appropriate resources and tool access
        var resourceRequest = new ResourceRequest
        {
            Name = "patient_records",
            Parameters = new Dictionary<string, object>
            {
                ["patientId"] = _patientContext.PatientId,
                ["requestingProvider"] = _patientContext.ProviderId
            }
        };
        
        // Request diagnostic assistance using appropriate prompt
        var response = await _mcpClient.SendPromptRequestAsync(
            promptName: "diagnostic_assistance",
            parameters: new Dictionary<string, object>
            {
                ["symptoms"] = symptoms,
                patientHistory = patientHistory,
                relevantGuidelines = _patientContext.GetRelevantGuidelines()
            });
            
        return DiagnosticSuggestion.FromMCPResponse(response);
    }
}
```

**ရလဒ်များ:** ဆရာဝန်များအတွက် တိကျမြန်ဆန်သော ရောဂါ သုံးသပ်မှု အကြံပြုချက်များ တိုးတက်ကာ HIPAA သတ်မှတ်ချက် အပြည့်အဝ လိုက်နာမှုနှင့် စနစ်များအကြား context-switching များ လျော့နည်း စေသည်။

### ကေ့စ်စတက်ဒီ ၃: ဘဏ္ဍာရေး ဝန်ဆောင်မှု စွမ်းရည် စိစစ်ခြင်း

ဘဏ္ဍာရေး အဖွဲ့အစည်းက MCP ကို သုံးပြီး သူတို့၏ စွမ်းရည်စိစစ်မှု လုပ်ငန်းစဉ်များကို ဌာနအနည်းငယ်ကွာခြားမှုရှိပြီး သတ်မှတ်သုံးစွဲစေနိုင်ခဲ့သည်။

- ခရက်ဒစ် စွမ်းရည်၊ လိမ်လည်မှု ရှာဖွေရေး နှင့် ရင်းနှီးမြှုပ်နှံမှု စွမ်းရည် မော်ဒယ်များအတွက် တစ်ခုတည်းသော အင်တာဖေ့စ် တည်ဆောက်ခြင်း။
- တင်းကြပ်သော အထောက်အထား ထိန်းချုပ်မှုနှင့် မော်ဒယ် ဗားရှင်း များ ပြုလုပ်ခြင်း။
- AI အကြံပြုချက် များအားလုံးကို စစ်ဆေးနိုင်မှု သေချာစေရန်။
- ကွာခြားသော စနစ် များတွင် ဒေတာ ဖော်မက် ရန် အမျိုးမျိုးကို ထိန်းသိမ်းခြင်း။

**နည်းပညာဆိုင်ရာ အကောင်အထည်ဖော်မှု:**

```java
// ငွေကြေးဖောက်ထွင်းမှုခြိမ်းခြောက်မှုဆန်းစစ်ရန် Java MCP ဆာଭာ
import org.mcp.server.*;
import org.mcp.security.*;

public class FinancialRiskMCPServer {
    public static void main(String[] args) {
        // ငွေကြေးလိုက်နာမှုလက္ခဏာများပါသော MCP ဆာဗာ တည်ဆောက်ရန်
        MCPServer server = new MCPServerBuilder()
            .withModelProviders(
                new ModelProvider("risk-assessment-primary", new AzureOpenAIProvider()),
                new ModelProvider("risk-assessment-audit", new LocalLlamaProvider())
            )
            .withPromptTemplateDirectory("./compliance/templates")
            .withAccessControls(new SOCCompliantAccessControl())
            .withDataEncryption(EncryptionStandard.FINANCIAL_GRADE)
            .withVersionControl(true)
            .withAuditLogging(new DatabaseAuditLogger())
            .build();
            
        server.addRequestValidator(new FinancialDataValidator());
        server.addResponseFilter(new PII_RedactionFilter());
        
        server.start(9000);
        
        System.out.println("Financial Risk MCP Server running on port 9000");
    }
}
```

### ကေ့စ်စတက်ဒီ ၄: Microsoft Playwright MCP ဆာဗာ(browser automation)

Microsoft က [Playwright MCP ဆာဗာ](https://github.com/microsoft/playwright-mcp) ကို ဖန်တီးခဲ့ပြီး Model Context Protocol မှတဆင့် လုံခြုံ စံပြန်သော browser automation ကို ခွင့်ပြုသည့် ခုတည်ဆောက်မှုဖြစ်သည်။ ဒီ production-ready ဆာဗာက AI ပရိုဂရမ်များနဲ့ LLMs တွေကို ဝဘ်ဘရောက်ဇာများမှာ ထိန်းချုပ်နိုင်စေပြီး စစ်ဆေးနိုင်စွမ်းရှိ၊ လွှဲပြောင်းတိုးရှင်းနိုင်ပြီး automated web testing, data extraction နဲ့ end-to-end workflow များအတွက် အသုံးပြုနိုင်စေသည်။

> **🎯 ထုတ်လုပ်မှုအဆင့် အသုံးပြုနိုင်သော ကိရိယာ**
> 
> ဒီကေ့စ်စတက်ဒီမှာ သင် ယနေ့ အသုံးပြုနိုင်သော တကယ့် MCP ဆာဗာကို ပြသထားပါသည်။ Playwright MCP Server နဲ့ အခြား Microsoft MCP ဆာဗာ ၉ ခုကို လေ့လာရန် ကျွန်ုပ်တို့ရဲ့ [**Microsoft MCP Servers Guide**](microsoft-mcp-servers.md#8--playwright-mcp-server) ကို ကြည့်ပါ။

**အဓိက လက္ခဏာများ:**
- MCP ကိရိယာများအဖြစ် ဝဘ်ဘရောက်ဇာ ထိန်းချုပ်မှု လုပ်ဆောင်နိုင်ခြင်း (Navigation, form filling, screenshot ဖမ်းယူခြင်း စသည်ဖြင့်)
- ခွင့်ပြုချက်မရ အမိန့်များကို တားမြစ်ရန် တင်းကြပ်သော လက်လှမ်းမီမှု ထိန်းချုပ်မှုနှင့် sandboxing ကို အသုံးပြုခြင်း။
- ဘရောက်ဇာ အတုံ့ပြန်မှုအားလုံးအတွက် အသေးစိတ် စစ်ဆေးမှတ်တမ်းများ ပေးခြင်း။
- Azure OpenAI နဲ့ အခြား LLM ပံ့ပိုးသူများနဲ့ ပေါင်းစည်း၍ agent-driven automation ကို ထောက်ပံ့ခြင်း။
- GitHub Copilot ၏ Coding Agent ကို web browsing အတတ်ပညာဖြင့် ဝှက်ပေးခြင်း။

**နည်းပညာဆိုင်ရာ အကောင်အထည်ဖော်မှု:**

```typescript
// TypeScript: MCP ဆာဗာတွင် Playwright ဘရောက်ဇာအလိုအလျောက်လုပ်ဆောင်မှုကိရိယာများမှတ်ပုံတင်ခြင်း
import { createServer, ToolDefinition } from 'modelcontextprotocol';
import { launch } from 'playwright';

const server = createServer({
  name: 'Playwright MCP Server',
  version: '1.0.0',
  description: 'MCP server for browser automation using Playwright'
});

// URL သို့သွားရန်နှင့် screenshot ရယူရန်ကိရိယာတစ်ခုမှတ်ပုံတင်ပါ
server.tools.register(
  new ToolDefinition({
    name: 'navigate_and_screenshot',
    description: 'Navigate to a URL and capture a screenshot',
    parameters: {
      url: { type: 'string', description: 'The URL to visit' }
    }
  }),
  async ({ url }) => {
    const browser = await launch();
    const page = await browser.newPage();
    await page.goto(url);
    const screenshot = await page.screenshot();
    await browser.close();
    return { screenshot };
  }
);

// MCP ဆာဗာကို စတင်ပါ
server.listen(8080);
```

**ရလဒ်များ:**

- AI ပရိုဂရမ်များနဲ့ LLMs များအတွက် လုံခြုံစိတ်ချရသော programmatic browser automation ကို ခွင့်ပြုခြင်း။
- ဝဘ်အက်ပ်များအတွက် manual စမ်းသပ်မှု လုပ်အား လျော့နည်းပြီး စမ်းသပ်မှု coverage တိုးတက်ခြင်း။
- စီးပွားရေး ပတ်ဝန်းကျင်တွင်း browser-based tool ပေါင်းစည်းမှုအတွက် ထပ်မံအသုံးပြုနိုင်၊ တိုးချဲ့နိုင်သော တည်ဆောက်မှု Framework ကို ဖန်တီးခြင်း။
- GitHub Copilot ၏ web browsing စွမ်းရည်များကို အားပေး ခဲ့သည်။

### ကေ့စ်စတက်ဒီ ၅: Azure MCP – အစိုးရအဆင့် Model Context Protocol အဖြစ်ဝန်ဆောင်မှု

Azure MCP Server ([https://aka.ms/azmcp](https://aka.ms/azmcp)) သည် Microsoft ၏ စီမံခန့်ခွဲပြီးသော အစိုးရအဆင့် Model Context Protocol အကောင်အထည်ဖော်မှုဖြစ်ပြီး MCP ဆာဗာ လုပ်ဆောင်မှုများကို မိုးလုံလေလုံဝန်ဆောင်မှုအနေဖြင့် သတ်မှတ်ထားသည်။ Azure MCP သည် အဖွဲ့အစည်းများအား မြန်ဆန်စွာ MCP ဆာဗာများကို တည်ဆောက်၊ စီမံခန့်ခွဲကာ Azure AI၊ ဒေတာ၊ လုံခြုံရေး ဝန်ဆောင်မှုများနှင့် ပေါင်းစည်းနိုင်စေပြီး လုပ်ငန်းဆောင်တာဆုံးရှုံးမှု သက်သာစေခြင်းနှင့် AI အသုံးချမှု မြန်ဆန်စေသည်။

> **🎯 ထုတ်လုပ်မှုအဆင့် အသုံးပြုနိုင်သော ကိရိယာ**
> 
> ယနေ့ သုံးစွဲနိုင်သော တကယ့် MCP ဆာဗာဖြစ်သည်! Microsoft Foundry MCP Server အကြောင်းကို ကျွန်ုပ်တို့ရဲ့ [**Microsoft MCP Servers Guide**](microsoft-mcp-servers.md) မှာ ဖတ်ရှုနိုင်ပါသည်။


- သွင်းထားပြီး အစီအစဉ်, စောင့်ကြည့်မှုနှင့် လုံခြုံရေး ပါသည့် MCP ဆာဗာ စုံလင်စွာ စီမံခန့်ခွဲမှု ထောက်ပံ့မှု။
- Azure OpenAI, Azure AI Search နှင့် အခြား Azure ဝန်ဆောင်မှုများနှင့် ဒေသစံတော်ချိန် ပေါင်းစည်းမှု။
- Microsoft Entra ID ဖြင့် အဖွဲ့အစည်း အတည်ပြုမှုနှင့် ခွင့်ပြုခွင့်စနစ်။
- ကိုယ်ပိုင် ကိရိယာများ၊ prompt templates နှင့် resource connectors များ အတွက် ထောက်ပံ့မှု။
- စီးပွားရေး လုံခြုံရေးနှင့် စည်းမျဉ်းစက်မှု လိုအပ်ချက်များကို လိုက်နာခြင်း။

**နည်းပညာဆိုင်ရာ အကောင်အထည်ဖော်မှု:**

```yaml
# Example: Azure MCP server deployment configuration (YAML)
apiVersion: mcp.microsoft.com/v1
kind: McpServer
metadata:
  name: enterprise-mcp-server
spec:
  modelProviders:
    - name: azure-openai
      type: AzureOpenAI
      endpoint: https://<your-openai-resource>.openai.azure.com/
      apiKeySecret: <your-azure-keyvault-secret>
  tools:
    - name: document_search
      type: AzureAISearch
      endpoint: https://<your-search-resource>.search.windows.net/
      apiKeySecret: <your-azure-keyvault-secret>
  authentication:
    type: EntraID
    tenantId: <your-tenant-id>
  monitoring:
    enabled: true
    logAnalyticsWorkspace: <your-log-analytics-id>
```

**ရလဒ်များ:**  
- စီးပွားရေး AI စီမံကိန်းများအတွက် အသုံးပြုနိုင်ပြီး စည်းကမ်းလိုက်နာမှုရှိသော MCP ဆာဗာ ပလက်ဖောင်းကို ဖြန့်ချီပေးခြင်း၊ သက်သာစေခြင်း။
- LLM များ၊ ကိရိယာများနဲ့ စီးပွားရေး ဒေတာရင်းမြစ်များ ပေါင်းစည်းမှုကို လွယ်ကူစွာ ပြုလုပ်နိုင်ခြင်း။
- MCP အလုပ် ဘက်များအတွက် လုံခြုံမှု၊ စုံစမ်းကြည့်ခြင်းနှင့် လည်ပတ်မှု ထိရောက်မှု တိုးတက်စေခြင်း။
- Azure SDK ထိပ်တိုက် သုံးစွဲမှုအကောင်းဆုံးနည်းလမ်းများနဲ့ လက်ရှိ အတည်ပြုခြင်း ပုံစံအတိုင်း ကိုဒ်အရည်အသွေး မြှင့်တင်ခြင်း။

## ကိစ္စလေ့လာမှု ၆: NLWeb
MCP (Model Context Protocol) သည် Chatbots နှင့် AI အကူအညီပေးသူများအား ကိရိယာများနှင့် ဆက်သွယ်ရန် အသုံးပြုသော ပေါ်ပြူလာ ကန့်သတ်နည်းလမ်းတစ်ခုဖြစ်သည်။ NLWeb ၏ အခန်းကဏ္ဍတိုင်းသည် MCP ဆာဗာတစ်ခုဖြစ်ပြီး၊ အချက်အလက်မေးခွန်းတစ်ခုကို သဘာဝဘာသာဖြင့် မေးမြန်းရန် အသုံးပြုသော ask ဆိုသော အဓိကနည်းလမ်းတစ်ခုကို ထောက်ပံ့ပေးသည်။ ပြန်လည် အသုံးပြုသည့် တုံ့ပြန်မှုသည် ဝက်ဘ်ဒေတာဖော်ပြရန် အများပြည့်ပြည့်အသုံးပြုသော အသုံးအနှုန်း schema.org ကို အထောက်အပံ့ပြုသည်။ အလွယ်တကူပြောရရင် MCP သည် Http နှင့် HTML တို့အကြားရှိ အဓိကသဘောတူညီချက်အတိုင်း NLWeb ဖြစ်သည်။ NLWeb သည် နည်းလမ်းများ၊ Schema.org ပုံစံများနှင့် နမူနာကုဒ်များကို ပေါင်းစပ်၍ ဆိုက်များအား အရှိန်မြန်စွာ ဤအပေါ်စနစ်များကို ဖန်တီးရန် ကူညီပေးသည်၊ ၎င်းသည် လူများကို စကားပြော ဆက်သွယ်ချက်များမှတဆင့်နှင့် စက်များအား သဘာဝအေးဂျင့်အကြား ဆက်သွယ်မှုမှတဆင့် အကျိုးဖြစ်ထွန်းစေသည်။

NLWeb သည် နှစ်ခုခွဲထားသော တစ်စိတ်တစ်ပိုင်းများရှိသည်။
- စောစီးစွာ စတင်အသုံးပြုနိုင်သော နည်းလမ်းတစ်ခုဖြစ်ပြီး ဝက်ဘ်ဆိုက်ကို သဘာဝဘာသာဖြင့် ဆက်သွယ်ရန်နှင့် ပြန်လည်တုံ့ပြန်မှုအတွက် json နှင့် schema.org ကို အထောက်အပံ့ပြု Format တစ်ခုဖြစ်သည်။ အသေးစိတ်အချက်အလက်များအတွက် REST API ကို ညွှန်ကြားချက်စာတမ်းကြည့်ပါ။
- (1) သည်ရှိသော markup ကို အသုံးပြုပြီး (1) ကို ရိုးရှင်းစွာ အကောင်အထည်ဖော်ထားသည်၊ ထိုဆိုက်များသည် ပစ္စည်းများ၊ မှုန့်ချက်များ၊ သွားရောက်လည်ပတ်ရန်နေရာများ၊ သုံးသပ်ချက်များ စသည့် အထုပ်များအဖြစ် မှတ်တမ်းတင်နိုင်သည်။ အသုံးပြုသူ အင်တာဖေ့စ် ဝစ်ဂျက်များနှင့်အတူဆိုက်များသည် သိမ်းဆည်းထားသော အကြောင်းအရာများအတွက် စကားပြောဆက်သွယ်ချက်များကို လွယ်ကူစွာ ဖော်ပြနိင်သည်။ ယခုလုပ်ဆောင်ပုံအကြောင်းပိုပြီးလေ့လာရန် Life of a chat query အတွက် စာရွက်စာတမ်းများကို ကြည့်ပါ။

## လက်တွေ့လုပ်ငန်းစဉ်များ

### ပရောဂျက် ၁: မော်ဒယ် ပံ့ပိုးသူခွဲများ စုပေါင်း MCP ဆာဗာ တည်ဆောက်ခြင်း

**ရည်မှန်းချက်:** သတ်မှတ်ချက်တစ်ခုအပေါ်တွင် အခြေခံပြီး မော်ဒယ်ပံ့ပိုးသူများထံ မေးခွန်းများကို လမ်းညွှန်ပေးနိုင်သော MCP ဆာဗာတစ်ခု ဖန်တီးပါ။

**လိုအပ်ချက်များ:**

- မော်ဒယ်ပံ့ပိုးသူ များစွာ (ဥပမာ - OpenAI, Anthropic, ဒေသတွင်း မော်ဒယ်များ) အနည်းဆုံး သုံးခုထောက်ပံ့ပါ။
- မေးပွဲအချက်အလက်များကို အခြေခံ၍ လမ်းညွှန်ပေးသော စနစ်တစ်ခု တပ်ဆင်ပါ။
- ပံ့ပိုးသူ လက်မှတ်များ စီမံခန့်ခွဲမှုအတွက် ဖွဲ့စည်းတည်ဆောက်မှုရေးဆွဲပါ။
- စွမ်းဆောင်ရည် နှင့် ကုန်ကျစရိတ် တိုးတက်စေရန် များစွာအသုံးပြုသော မေးခွန်းများအတွက် cache ထည့်ပါ။
- အသုံးပြုမှု ကို ကြည့်ရှုရန် ရိုးရှင်းသော ဒက်ရှ်ဘုတ် တစ်ခု တည်ဆောက်ပါ။

**အကောင်အထည်ဖော်ဆောင်ရွက်ခြင်း အဆင့်များ:**

1. အခြေခံ MCP ဆာဗာ အခြေခံအဆောက်အအုံ ပြင်ဆင်ပါ။
2. AI မော်ဒယ် ဝန်ဆောင်မှုပို့ဆောင်သူ တစ်ခုချင်းစီအတွက် adapter များ ထိုးထွင်းဆောက်လုပ်ပါ။
3. မေးပွဲ attribute အပေါ် မူတည်၍ လမ်းညွှန်မှုတန်းတူရေးဆွဲပါ။
4. မေးခွန်းများ မကြာခဏ ထပ်မံမေးသော စနစ်များအတွက် cache ကြောင့် performance မြှင့်တင်ပါ။
5. မျှဝေမှု ဒက်ရှ်ဘုတ် တိုးတက်အောင် ဖန်တီးပါ။
6. မေးခွန်းပုံစံ အမျိုးမျိုးဖြင့် စမ်းသပ်ပါ။

**နည်းပညာများ:** Python (.NET/Java/Python မှ သင့်တင့်ရာရွေးချယ်၍)၊ cache အတွက် Redis နှင့် ဒက်ရှ်ဘုတ်အတွက် ရိုးရှင်းသော ဝက်ဘ်ဖရိမ်ဝတ် အမျိုးအစား တခုကို ရွေးချယ်ပါ။

### ပရောဂျက် ၂: စီးပွားရေး အသုံးပြု ပရောဂျက် မှတ်တမ်း စီမံခန့်ခွဲမှု စနစ်


**ရည်မှန်းချက်။** အဖွဲ့အစည်းတစ်ခုလုံးအတွင်း prompt templates များကို စီမံခန့်ခွဲခြင်း၊ ဗားရှင်းထုတ်ခြင်းနှင့် ဖြန့်ချိခြင်းအတွက် MCP အခြေပြု စနစ်တစ်ခု ဖန်တီးပါ။

**လိုအပ်ချက်များ။**


- prompt template များအတွက် စင်ထရယ်ပြုစုသော ဆော့ဖ်ဝဲစင်တာ တည်ဆောက်ရန်
- ဗားရှင်းနှင့် အတည်ပြုလုပ်ငန်းစဉ်များ တပ်ဆင်ရန်
- နမူနာထည့်သွင်းချက်များနှင့် template စမ်းသပ်မှုစွမ်းဆောင်မှုများ တည်ဆောက်ရန်
- စီမံခန့်ခွဲမှုအတွက် အခန်းကဏ္ဍအခြေခံ ဝင်ရောက်ခွင့် ထိန်းချုပ်မှုများ ပုံဖော်ရန်
- template ရယူခြင်းနှင့် ထုတ်လွှင့်ခြင်းအတွက် API တစ်ခု ဖန်တီးရန်

**အကောင်အထည်ဖော်ခြင်း အဆင့်များ။**

1. template သိမ်းဆည်းရန် အချက်အလက်ဒေတာစနစ် ဒီဇိုင်းဆွဲရန်
2. template CRUD လုပ်ဆောင်ချက်အတွက် အခြေခံ API ဖန်တီးရန်
3. ဗားရှင်းစနစ် တပ်ဆင်ရန်
4. အတည်ပြုလုပ်ငန်းစဉ် ဖန်တီးရန်
5. စမ်းသပ်မှုဖဲင်းမှု ဖန်တီးရန်
6. စီမံခန့်ခွဲမှုအတွက် ရိုးရှင်းသော ဝက်ဘ်အင်တာဖေ့စ် တည်ဆောက်ရန်
7. MCP ဆာဗာနှင့် ပေါင်းစပ်ရန်

**နည်းပညာများ:** သင့်နှစ်သက်ရာ backend framework, SQL သို့မဟုတ် NoSQL ဒေတာဘေ့စ်၊ နှင့် စီမံခန့်ခွဲမှုအင်တာဖေ့စ်အတွက် frontend framework တစ်ခု။

### Project 3: MCP အခြေခံ ပါဝင်သော အကြောင်းအရာ ဖန်တီးရေးပလက်ဖောင်း

**ရည်မှန်းချက်:** MCP ကို အသုံးပြု၍ အကြောင်းအရာပုံစံအမျိုးမျိုးတွင် တိကျ တစ်ပြိုင်နက်တည်းရှိသော ရလဒ်များ ပေးနိုင်သော အကြောင်းအရာ ဖန်တီးရေးပလက်ဖောင်း တည်ဆောက်ရန်။

**လိုအပ်ချက်များ:**

- အကြောင်းအရာပုံစံ အမျိုးမျိုးအား (ဘလော့ခ်ပို့စ်များ၊ လူမှုမီဒီယာ၊ ကြော်ငြာစာများ) ထောက်ပံ့ရန်
- စိတ်ကြိုက် ပြင်ဆင်နိုင်သည့် template အခြေခံ ဖန်တီးမှု ကို တပ်ဆင်ရန်
- အကြောင်းအရာ သုံးသပ်ခြင်းနှင့် တုံ့ပြန်ချက်စနစ် ဖန်တီးရန်
- အကြောင်းအရာ စွမ်းဆောင်ရည် ကို တိုင်းတာသည့် မီတရီက်များ မှတ်တမ်းတင်ရန်
- အကြောင်းအရာ ဗားရှင်းနှင့် ပြန်လည်တိုးတက်မှုကို ထောက်ပံ့ရန်

**အကောင်အထည်ဖော်ခြင်း အဆင့်များ**

1. MCP client အခြေခံဝင်းယာကျင်း ပြင်ဆင်ရန်
2. အကြောင်းအရာပုံစံအမျိုးမျိုးအတွက် template များ ဖန်တီးရန်
3. အကြောင်းအရာ ဖန်တီးရေး လုပ်ငန်းစဉ် တည်ဆောက်ရန်
4. သုံးသပ်ချက်စနစ် တပ်ဆင်ရန်
5. မီတရီက် 추적မှု စနစ် ဖန်တီးရန်
6. template စီမံခန့်ခွဲမှုနှင့် အကြောင်းအရာ ဖန်တီးရေးအတွက် အသုံးပြုသူ အင်တာဖေ့စ် တည်ဆောက်ရန်

**နည်းပညာများ:** သင့်နှစ်သက်ရာ ပရိုဂရမ်းမင်းဘာသာစကား၊ ဝက်ဘ် framework နှင့် တည်ဆောက်ထားသည့် ဒေတာဘေ့စ်စနစ်။

## MCP နည်းပညာအတွက် အနာဂတ်လမ်းညွှန်ချက်များ

### ဖြစ်ပေါ်လာနေသော ထုံးစံများ

1. **စုံလင်ပုံစံ MCP**
   - ပုံရိပ်၊ အသံနှင့် ဗွီဒီယို မော်ဒယ်များနှင့် အပြန်အလှန်ဆက်သွယ်မှုများ စံနှုန်းချထားရန် MCP ဖြန့်ချိခြင်း
   - cross-modal ဆင်ခြေဆိုင်ရာစွမ်းရည်များ ဖွံ့ဖြိုးတိုးတက်မှု
   - မော်ဒယ်အမျိုးမျိုးအတွက် စံပြ prompt ပုံစံများ

2. **ဖက်ဒရေးတက် MCP အခြေခံအင်ဖရာစတက္ချား**
   - အဖွဲ့အစည်းများအကြား သယံဇာတများမျှဝေနိုင်သည့် ပြန်လည်ဖြန့်ဝေ MCP ကွန်ယက်များ
   - စံသတ်မှတ်ထားသည့် လုံခြုံသော မော်ဒယ်မျှဝေခြင်း ပရိုတိုကောများ
   - ကိုယ်ပိုင် အချက်အလက် ကာကွယ်မှု ရေတွက်ခြင်း နည်းပညာများ

3. **MCP ဈေးကွက်များ**
   - MCP template များနှင့် plugin များ မျှဝေခြင်းနှင့် ငွေကြေးရရှိရေးစနစ်များ
   - အရည်အသွေး သာမန် သင်တန်းနှင့် လက်မှတ်ရရှိရေးလုပ်ငန်းစဉ်များ
   - မော်ဒယ် ဈေးကွက်များနှင့် ပေါင်းစပ်ခြင်း

4. **Edge Computing အတွက် MCP**
   - သိုလှောင်မှုကန့်သတ်ထားသည့် edge စက်ပစ္စည်းများအတွက် MCP စံများကို သင့်လျော်စွာ ပြင်ဆင်ခြင်း
   - နိမ့်မြှောက် သတင်းအချက်အလက်နှုန်းတွင် အကောင်းဆုံးသုံးနိုင်ရန် ပရိုတိုကောများ
   - IoT စနစ်အတွက် အထူးပြု MCP အကောင်အထည်ဖော်မှုများ

5. **စည်းကမ်းနှင့် စီမံခန့်ခွဲမှုဖွဲ့စည်းမှုများ**
   - စည်းကမ်းလိုက်နာမှုအတွက် MCP ဝါလ်လီအသစ်များ ဖွံ့ဖြိုးတိုးတက်မှု
   - စံသတ်မှတ်ထားသော စစ်ဆေးမှု လမ်းကြောင်းများနှင့် ဖော်ပြချက် များအတွက်အင်တာဖေ့စ်များ
   - နောက်ဆုံးပေါ် AI အုပ်ချုပ်မှု စနစ်များနှင့် ပေါင်းစည်းမှု

### Microsoft မှ MCP အတွက် ဖြေရှင်းချက်များ

Microsoft နှင့် Azure တို့သည် MCP ကို အမျိုးမျိုးသော သရုပ်ပြမှုများတွင် တပ်ဆင်အသုံးပြုနိုင်ရန် အထောက်အကူပြု open-source repository များ စတင်ဖန်တီးထားပါသည်။

#### Microsoft အဖွဲ့အစည်း

1. [playwright-mcp](https://github.com/microsoft/playwright-mcp) - Browser automation နှင့် စမ်းသပ်မှုအတွက် Playwright MCP ဆာဗာတစ်ခု
2. [files-mcp-server](https://github.com/microsoft/files-mcp-server) - OneDrive MCP ဆာဗာကို ဒေသတွင်း စမ်းသပ်မှုနှင့် အသိုက်အဝန်း ဝေဝါးမှုအတွက် အကောင်အထည်ဖော်မှု
3. [NLWeb](https://github.com/microsoft/NlWeb) - open protocols နှင့် အဖွဲ့အစည်း open source tools များစုစည်းမှုဖြစ်ပြီး AI Web အတွက် အခြေခံအလွှာ တည်ဆောက်ခြင်းကို အဓိကထားသည်။

#### Azure-Samples အဖွဲ့အစည်း

1. [mcp](https://github.com/Azure-Samples/mcp) - Azure ပေါ်တွင် MCP ဆာဗာများ တည်ဆောက်အသုံးပြုရန် နမူနာများ၊ ကိရိယာများနှင့် အရင်းအမြစ်များ
2. [mcp-auth-servers](https://github.com/Azure-Samples/mcp-auth-servers) - ဒီနေ့ Model Context Protocol အသုံးပြု၍ အတည်ပြုချက် MCP ဆာဗာများ
3. [remote-mcp-functions](https://github.com/Azure-Samples/remote-mcp-functions) - Azure Functions တွင် Remote MCP ဆာဗာ အကောင်အထည်ဖော်မှုအတွက် လမ်းညွှန်စာမျက်နှာ နှင့် ဘာသာစကား အလိုက် မျှဝေခြင်း
4. [remote-mcp-functions-python](https://github.com/Azure-Samples/remote-mcp-functions-python) - Python အသုံးပြု၍ Azure Functions တွင် Remote MCP ဆာဗာ များ ဖန်တီး ထုတ်လွှင့်ရန် Quickstart template
5. [remote-mcp-functions-dotnet](https://github.com/Azure-Samples/remote-mcp-functions-dotnet) - .NET/C# အသုံးပြု၍ Azure Functions တွင် Remote MCP ဆာဗာ များ ဖန်တီး ထုတ်လွှင့်ရန် Quickstart template
6. [remote-mcp-functions-typescript](https://github.com/Azure-Samples/remote-mcp-functions-typescript) - TypeScript အသုံးပြု၍ Azure Functions တွင် Remote MCP ဆာဗာ များ ဖန်တီး ထုတ်လွှင့်ရန် Quickstart template
7. [remote-mcp-apim-functions-python](https://github.com/Azure-Samples/remote-mcp-apim-functions-python) - Python အသုံးပြု၍ Remote MCP ဆာဗာများသို့ Azure API Management ကို AI Gateway အနေနှင့် အသုံးပြုခြင်း
8. [AI-Gateway](https://github.com/Azure-Samples/AI-Gateway) - APIM နှင့် AI သုတေသနများ၊ MCP စွမ်းဆောင်ရည်များဖြင့် Azure OpenAI နှင့် AI Foundry ပေါင်းစပ်ခြင်း

ဤ repositories များသည် Model Context Protocol အတွက် အမျိုးမျိုးသော ပရိုဂရမ်မင်းဘာသာစကားများနှင့် Azure ဝန်ဆောင်မှုများတွင် အသုံးပြုရန် အကောင်အထည်ဖော်မှုများ၊ template များ၊ အရင်းအမြစ်များ ရှိသည်။ ဤသည်သည် မူလဆာဗာကိုယ်တိုင် အကောင်အထည်ဖော်မှုပြီး authentication, cloud deployment နှင့် စီးပွားရေး ပေါင်းစည်းမှု အခြေအနေများကို ဖုံးလွှမ်းသည်။

#### MCP အရင်းအမြစ် စုစည်းမှုဖိုင်ထည့်ဖိုဒါ

Microsoft MCP repository တရားဝင် [MCP Resources directory](https://github.com/microsoft/mcp/tree/main/Resources) တွင် Model Context Protocol ဆာဗာများနှင့် အသုံးပြုရန် အပလီကေးရှင်း များ၊ prompt templates များ နှင့် tool ပုံသဏ္ဍာန်များ စုစည်းထားသည်။ ဤဖိုင်ထည့်ဖိုဒါမှာ MCP တို့သုံးလူများအတွက် အလျင်အမြန်စတင်အသုံးပြုနိုင်ရန် အဘို့ အသုံးပြုပြီးနောက် ထပ်မံအသုံးပြုနိုင်သော အခြေခံပစ္စည်းများနှင့် အကောင်းဆုံးကျင့်သုံးမှု ဥပမာများကို ပံ့ပိုးပေးသည်။

- **Prompt Templates:** ယေဘုယျ AI လုပ်ငန်းများနှင့် အခြေအနေများအတွက် အသင့်အသုံးပြုနိုင်သော prompt templates များ၊ သင့်ရဲ့ MCP ဆာဗာအကောင်အထည်ဖော်မှုများအတွက် ကိုက်ညီစေရန်ပြင်ဆင်နိုင်သည်။
- **Tool Definitions:** tool တွေကို MCP ဆာဗာလိုက်အသုံးပြုမှုများအတွက် စံပြ သဘာဝပုံစံ များနှင့် မီတာဒေတာများ။
- **Resource Samples:** MCP ဖောင်မြူလာထဲတွင် ဒေတာရင်းမြစ်များ၊ API များ နှင့် ပြင်ပဝန်ဆောင်မှုများ ဆက်သွယ်မည့် နမူနာအရင်းအမြစ် သတ်မှတ်ချက်များ။
- **Reference Implementations:** အမှန်တကယ် MCP project များတွင် resource များ၊ prompt များနှင့် tool များကို ဘယ်လို ရှိတည်ဆောက်စီမံရမယ်ဆိုတာ ပြသထားသော လက်တွေ့ နမူနာများ။

ဤအရင်းအမြစ်များသည် ဖွံ့ဖြိုးတိုးတက်မှု မြန်ဆန်စေခြင်း၊ စံနှုန်းများ ထိန်းသိမ်းခြင်းနှင့် MCP-based ဖြေရှင်းချက်များ တည်ဆောက်ရာတွင် အကောင်းဆုံး ကျင့်သုံးရေးလမ်းညွှန်ချက်များ ထောက်ပံ့သည်။

- [MCP Resources (Sample Prompts, Tools, and Resource Definitions)](https://github.com/microsoft/mcp/tree/main/Resources)

### သုတေသန အခွင့်အလမ်းများ

- MCP ဖွဲ့စည်းမှုများအတွင်း ထိရောက်သော prompt အဆင့်မြှင့် နည်းပညာများ
- မွမ်းမံ စနစ်များအတွက် လုံခြုံမှု မော်ဒယ်များ
- MCP အကောင်အထည်ဖော်မှုများအပေါ် စွမ်းဆောင်ရည် ဆိုင်ရာ တိုင်းတာမှုများ
- MCP ဆာဗာများအတွက် တရားဝင် အတည်ပြုမှုနည်းပညာများ

## စာရွက်အနှစ္ချုပ်

Model Context Protocol (MCP) သည် စံနှုန်းချထားပြီး လုံခြုံ ဖြည့်စွက်နိုင်သော AI ပေါင်းစည်းမှုကို လုပ်ငန်းခွဲများအဖြစ် အမြန်ဆုံး ရရှိစေသည်။ ဒီသင်ခန်းစာရှိ နမူနာနှင့် လက်တွေ့ပြဿနာများမှတဆင့် Microsoft နှင့် Azure အပါအဝင် ဦးဆောင်အသုံးပြုသူများက MCP ကို လက်တွေ့ ကွပ်ကဲ ရှုထောင့်ဖြင့်အသုံးချကာ AI ခေတ်မီစနစ် ဖွံ့ဖြိုးတိုးတက်ရေးနှင့် လုံခြုံရေး၊ စံထောက်ခံမှု၊ သွားလာမှု အမြဲတမ်းသေချာစေလိုသည်။ MCP ၏ module များဖြင့် အဖွဲ့အစည်းများသည် မဟာဗျူဟာစေ့စပ်သည့် စီးပွားရေးဒေတာ၊ tool များနှင့် ကွန်ယက်နှင့် ပေါင်းစပ်၍ audit လုပ်နိုင်သည့် framework တစ်ခုရှိစေသည်။ MCP ရှိ တိုးတက်မှု ဖော်ပြီ စွန့်စားမှုအဖွဲ့နှင့် open-source အရင်းအမြစ်များနှင့် ဆက်နွယ်ပြီး အကောင်းဆုံးကျင့်သုံးမှုများကို အသုံးချခြင်းဖြင့် ခိုင်မာပြီး အနာဂတ်သင့်လျော်သော AI ဖြေရှင်းချက်များ တည်ဆောက်နိုင်မည်ဖြစ်သည်။

## လေ့ကျင့်မှုများ

1. သင်တစ်ခုတည်းသော နမူနာ အတက်ကို ဂရုစိုက် လေ့လာပြီး နည်းလမ်းတစ်ခုအသစ် အတွက် အကောင်အထည်ဖော်ချက်ကို အကြံပြုပါ။
2. စီမံကိန်းတစ်ခုကို ရွေးချယ်ပြီး အသေးစိတ် နည်းပညာဖော်ပြချက် တစ်ခု ဖန်တီးပါ။
3. နမူနာအတက်များတွင် ဖုံးကွယ်ထားသော စက်မှုလုပ်ငန်းကို သုတေသနပြု၊ MCP ဖော်ပြချက်များဖြင့် ထိတွေ့အခက်အခဲများကို အကျဉ်းချုပ်ရေးဆွဲပါ။
4. အနာဂတ်လမ်းညွှန်ချက်များထဲမှ တစ်ခုကို လေ့လာ၍ ထိုလမ်းညွှန်ချက်အား ပံ့ပိုးရန် MCP extension အသစ်တစ်ခု အတွက် အတွေးအခေါ်တစ်ခု ဖန်တီးပါ။
