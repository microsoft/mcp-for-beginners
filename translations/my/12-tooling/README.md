# 🚀 MCP ကိရိယာများ

## 🧠 MCP ဒေတာဘေ့စ်ပေါင်းစည်းခြင်း သင်ကြားမှု လမ်းကြောင်းအကြောင်းအကျဥ်း

ဤနေရာတွင် သင်သည် MCP ကို အသုံးပြုသော ကိရိယာများကို ဘယ်လိုအသုံးပြုရမည်ကို လေ့လာမည်ဖြစ်သည်။ MCP ဆာဗာများကို ထိုကိရိယာများနှင့် ချိတ်ဆက်သည့်အခါ သင့်အတွေ့အကြုံပိုမိုကောင်းမွန်လာမည်ဖြစ်သည်။

## 🔗 တရားဝင် MCP အရင်းအမြစ်များ

- 📘 [MCP စာရွက်စာတမ်းများ](https://modelcontextprotocol.io/) – အသေးစိတ် သင်ခန်းစာများနှင့် အသုံးပြုသူလမ်းညွှန်များ
- 📜 [MCP သတ်မှတ်ချက် (2026-07-28)](https://modelcontextprotocol.io/specification/2026-07-28/) – ပရိုတိုကော အဆောက်အအုံနှင့် နည်းပညာဆိုင်ရာအညွှန်းများ
- 🧑‍💻 [MCP GitHub ဂိုဒေါင်း](https://github.com/modelcontextprotocol) – အဖွင့်မူလတန်း SDK များ၊ ကိရိယာများနှင့် ကုဒ်နမူနာများ
- 🌐 [MCP အသိုင်းအဝိုင်း](https://github.com/orgs/modelcontextprotocol/discussions) – ဆွေးနွေးချက်များ ပူးပေါင်းဝင်ရောက်ပြီး အသိုင်းအဝိုင်းအား ထောက်ပံ့ပါ
- 🔒 [OWASP MCP ထိပ်တန်း ၁၀](https://microsoft.github.io/mcp-azure-security-guide/mcp/) – လုံခြုံရေးအကောင်းဆုံး လေ့ကျင့်မှုများနှင့် စိုးရိမ်ချက်များသက်သာရေး
