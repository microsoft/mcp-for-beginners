# MCP ကိရိယာတွက်စက် ဆာဗာ (Python)



Python ကို အသုံးပြု၍ ရေးသားထားသော ရိုးရှင်းသော Model Context Protocol (MCP) ဆာဗာတစ်ခုဖြစ်ပြီး မူလကိရိယာတွက်စက်လုပ်ဆောင်ချက်များကို ပေးဆောင်ပါသည်။


## တပ်ဆင်ခြင်း

လိုအပ်သော အခြေခံပစ္စည်းများကို တပ်ဆင်ပါ။

```bash
pip install -r requirements.txt
```

သို့မဟုတ် MCP Python SDK ကို တိုက်ရိုက် တပ်ဆင်နိုင်ပါသည်။

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## အသုံးပြုနည်း

### ဆာဗာကို ဖွင့်ခြင်း

ဆာဗာကို MCP client များ (ဥပမာ Claude Desktop) အသုံးပြုရန်ဒီဇိုင်းဆွဲထားသည်။ ဆာဗာကို စတင်ဖို့ -

```bash
python mcp_calculator_server.py
```

**မှတ်ချက်**: တိုက်ရိုက် terminal ထဲတွင် အလုပ်လုပ်၏၊ JSON-RPC စစ်ဆေးခြင်းတောင်းဆိုမှု မှားယွင်းမှု ပေါ်လာမှာ ဖြစ်နိုင်သည်။ ၎င်းသည် ပုံမှန် လုပ်ဆောင်ချက်ဖြစ်ပြီး ဆာဗာသည် စနစ်တကျ ဖော်ပြထားသော MCP client မက်ဆေ့ချက်များအတွက် စောင့်ဆိုင်းနေပါသည်။

### လုပ်ဆောင်ချက်များ စမ်းသပ်ခြင်း

ကိရိယာတွက်စက်လုပ်ဆောင်ချက်များ မှန်ကန်စွာ လုပ်ဆောင်နေနိုင်ကြောင်း စမ်းသပ်ရန် -

```bash
python test_calculator.py
```

## ပြဿနာဖြေရှင်းခြင်း

### Import အမှားများ

`ModuleNotFoundError: No module named 'mcp'` ဆိုသည့် အမှားလာပါက MCP Python SDK ကို တပ်ဆင်ပါ။

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### တိုက်ရိုက် အလုပ်လုပ်စဉ် JSON-RPC အမှားများ

ဆာဗာကို တိုက်ရိုက် စတင်လည်ပွဲတွင် "Invalid JSON: EOF while parsing a value" များကဲ့သို့သော အမှား လာမယ်ဆိုရင် မျှော်လင့်ရပါသည်။ ဆာဗာသည် MCP client မက်ဆေ့ချ်များ လိုအပ်ပါသည်၊ တိုက်ရိုက် terminal input မလိုအပ်ပါ။
