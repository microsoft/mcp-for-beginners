# MCP ဆာဗာများ တပ်ဆင်ခြင်း

> [!NOTE]
> `/sse` endpoint ကို အသုံးပြုသည့် တပ်ဆင်မှု နမူနာများသည် အဖိုးကြီး HTTP+SSE
> သယ်ယူပို့ဆောင်မှု ကို ရည်ညွှန်းသည်။ MCP `2026-07-28` အဝေးမှ ဆာဗာများသည် ပုံမှန်အားဖြင့်
> ဆာဗာသတ်မှတ်ထားသော endpoint တစ်ခုဖြစ်သည့် `/mcp` တွင် Streamable HTTP ကို အသုံးပြုသည်။

သင့် MCP ဆာဗာကို တပ်ဆင်ခြင်းဖြင့် သင့်ဒေသတွင်မဟုတ်ဘဲ အခြားသူများက ၎င်း၏ကိရိယာများနှင့် အရင်းအမြစ်များကို ဝင်ရောက်အသုံးပြုနိုင်သည်။ ကြီးထွားတိုးတက်မှု၊ ယုံကြည်စိတ်ချရမှုနှင့် စီမံခန့်ခွဲမှုလွယ်ကူမှုတွင် မူတည်ပြီး တပ်ဆင်ရေး မျိုးစုံကို ရွေးချယ်နိုင်သည်။ အောက်တွင် MCP ဆာဗာများကို မိမိဒေသတွင်၊ ကွန်တိန်နာများတွင်နှင့် လေထု(service) တွင် တပ်ဆင်ခြင်းအတွက် လမ်းညွှန်ချက်များကို တွေ့နိုင်ပါသည်။

## အကြောင်းအကျဉ်း

ဤသင်ခန်းစာတွင် MCP ဆာဗာ အက်ပ်ကို မည်သို့ တပ်ဆင်ရမည်ကို ဖော်ပြထားသည်။

## သင်ယူရမည့် ရည်မှန်းချက်များ

ဤသင်ခန်းစာ၏ အဆုံးသတ်မှ စတင်၍ လုပ်ဆောင်နိုင်မည့်အချက်များမှာ-

- တပ်ဆင်ပုံများ အမျိုးမျိုးကို သုံးသပ်နိုင်ခြင်း။
- မိမိ၏ အက်ပ်ကို တပ်ဆင်နိုင်ခြင်း။

## ဒေသခံ ဖွံ့ဖြိုးတိုးတက်မှု နှင့် တပ်ဆင်ခြင်း

သင့်ဆာဗာကို အသုံးပြုသူများ မိမိကွန်ပျူတာပေါ်တွင် စနိုင်မည်ဆိုပါက အောက်ပါအဆင့်များကို လိုက်နာနိုင်သည်-

1. **ဆာဗာကို ဒေါင်းလုပ်လုပ်ပါ။** ဆာဗာကို မရေးဆွဲရသေးလျှင် မိမိကွန်ပျူတာသို့ ပထမဦးစွာ ဒေါင်းလုပ်လုပ်ပါ။ 
1. **ဆာဗာလုပ်ငန်းစဉ်ကို စတင်ပါ။** မိမိ၏ MCP ဆာဗာ အက်ပ်ကို စတင်ဆော့ပါ။

SSE အတွက် (stdio စတိုင်ပုံ ဆာဗာ မလိုအပ်ပါ)

1. **ကွန်ယက်ဖွင့်ချိတ်ဆက်ခြင်း**: ဆာဗာသည် မျှော်လင့်ထားသော ဘားတ်မှာ ဝင်ရောက်နိုင်ရမည်။
1. **ဖောက်သည်များ ဆက်သွယ်ခြင်း**: `http://localhost:3000` ကဲ့သို့ ဒေသခံ ချိတ်ဆက်ရန် URL များကို အသုံးပြုပါ။

## လေထု (Cloud) တပ်ဆင်ခြင်း

MCP ဆာဗာများကို လေထု ပလက်ဖောင်းမျိုးစုံတွင် တပ်ဆင်နိုင်သည်။

- **Serverless Functions**: အလင်းအပေါ် MCP ဆာဗာများကို serverless function များအဖြစ် တပ်ဆင်ခြင်း။
- **Container Services**: Azure Container Apps, AWS ECS, သို့မဟုတ် Google Cloud Run ကဲ့သို့ ဝန်ဆောင်မှုများ အသုံးပြုခြင်း။
- **Kubernetes**: MCP ဆာဗာများကို Kubernetes ကလပ်စတာများတွင် တပ်ဆင်စီမံရန်။

### ဥပမာ - Azure Container Apps

Azure Container Apps သည် MCP ဆာဗာ တပ်ဆင်ခြင်းကို ထောက်ပံ့သည်။ ယင်းသည် လက်ရှိတွင် တိုက်ရိုက် SSE ဆာဗာများကိုသာ ထောက်ပံ့နေသေးသည်။

ပြုလုပ်ပုံမှာ အောက်ပါအတိုင်းဖြစ်သည်။

1. GitHub တို့မှ repo ကို Clone လုပ်ပါ။

  ```sh
  git clone https://github.com/anthonychu/azure-container-apps-mcp-sample.git
  ```

1. ဒေသခံတွင် စမ်းသပ်ရန် run လုပ်ပါ။

  ```sh
  uv venv
  uv sync

  # linux/macOS
  export API_KEYS=<AN_API_KEY>
  # windows
  set API_KEYS=<AN_API_KEY>

  uv run fastapi dev main.py
  ```

1. ဒေသခံတွင်စမ်းသပ်ရန် *mcp.json* ဖိုင်ကို *.vscode* ဖိုလ်ဒါတွင် ဖန်တီးပြီး အောက်ပါ အကြောင်းအရာကို ထည့်ပါ။

  ```json
  {
      "inputs": [
          {
              "type": "promptString",
              "id": "weather-api-key",
              "description": "Weather API Key",
              "password": true
          }
      ],
      "servers": {
          "weather-sse": {
              "type": "sse",
              "url": "http://localhost:8000/sse",
              "headers": {
                  "x-api-key": "${input:weather-api-key}"
              }
          }
      }
  }
  ```

  SSE ဆာဗာ စတင်ပြီးနောက် JSON ဖိုင်ရှိ play အိုင်ကွန်ကို နှိပ်နိုင်ပြီး GitHub Copilot မှ ဆာဗာတွင်ရှိသည့် ကိရိယာများကို တွေ့ရမည်။

1. တပ်ဆင်ရန် အောက်ပါ ကွန်မန်းကို Run ပါ။

  ```sh
  az containerapp up -g <RESOURCE_GROUP_NAME> -n weather-mcp --environment mcp -l westus --env-vars API_KEYS=<AN_API_KEY> --source .
  ```

၎င်းဖြင့် ဒေသခံတွင် တပ်ဆင်ခြင်း၊ Azure သို့ တပ်ဆင်ခြင်းကို အဆင့်လိုက် လုပ်ဆောင်နိုင်ပါပြီ။
