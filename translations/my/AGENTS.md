# AGENTS.md

## စီမံကိန်းအကြောင်းအရာ

**MCP for Beginners** သည် Model Context Protocol (MCP) ကိုလေ့လာရန်အတွက် open-source ပညာပေးသင်ရိုးညွှန်းတမ်းဖြစ်ပြီး၊ AI မော်ဒယ်များနှင့် client အက်ပ်များအကြား အပြန်အလှန်ဆက်သွယ်မှုအတွက် စံပြသော structure ဖြစ်သည်။ ဤ repository သည် programming ဘာသာစကားများစွာဖြင့် လက်တွေ့ code ဥပမာအပါအဝင် ကျွမ်းကျင်စွာ လေ့လာနိုင်ရန် စုံလင်သော သင်ကြားမှုအရာဝတ္ထုများကို ပေးအပ်သည်။

### အဓိကနည်းပညာများ

- **Programming Languages**: C#, Java, JavaScript, TypeScript, Python, Rust
- **Frameworks & SDKs**: 
  - MCP SDK (`@modelcontextprotocol/sdk`)
  - Spring Boot (Java)
  - FastMCP (Python)
  - LangChain4j (Java)
- **Databases**: PostgreSQL with pgvector extension
- **Cloud Platforms**: Azure (Container Apps, OpenAI, Content Safety, Application Insights)
- **Build Tools**: npm, Maven, pip, Cargo
- **Documentation**: Markdown with automated multi-language translation (48+ languages)

### နည်းပညာဖွဲ့စည်းတည်ဆောက်မှု

- **11 Core Modules (00-11)**: အခြေခံအရာများမှ အဆင့်မြင့်အကြောင်းအရာများထိ တစဉ်တကြောင်း လေ့လာသင်ယူမှုလမ်းကြောင်း
- **Hands-on Labs**: ဘာသာစကားများစွာဖြင့် လက်တွေ့လုပ်ဆောင်နိုင်သော လေ့ကျင့်ခန်းများနှင့် ပြီးစီးသော ဖြေရှင်းချက်ကုဒ်များ
- **Sample Projects**: MCP ဆာဗာနှင့် client အကောင်အထည်ဖော်ချက်များ
- **Translation System**: ဘာသာစကားများစွာကို အလိုအလျောက် ထောက်ပံ့ပေးသော GitHub Actions workflow
- **Image Assets**: ဘာသာပြန်ထားသော ဓာတ်ပုံများ သိမ်းဆည်းထားသော စုစည်းဧရိယာ

## တပ်ဆင်ချက် များ

ဤသည်မှာ စာတမ်းများအာရုံစိုက်ထားသော repository ဖြစ်ပြီး ခုခံအများစုကို စမ်းသပ်ပရောဂျက်များနှင့် လေ့ကျင့်ခန်းများထဲတွင် အလုပ်လုပ်သည်။

### Repository တပ်ဆင်ခြင်း

```bash
# စာကြည့်တိုက်ကို ကလုန်လုပ်ပါ။
git clone https://github.com/microsoft/mcp-for-beginners.git
cd mcp-for-beginners
```

### စမ်းသပ်ပရောဂျက်များနှင့်အလုပ်လုပ်ခြင်း

စမ်းသပ်ပရောဂျက်များကို အောက်ပါနေရာများတွင်တွေ့ရှိနိုင်သည်။
- `03-GettingStarted/samples/` - ဘာသာစကားအလိုက် ဥပမာများ
- `03-GettingStarted/01-first-server/solution/` - ပထမဆုံးဆာဗာ အကောင်အထည်ဖော်မှုများ
- `03-GettingStarted/02-client/solution/` - Client အကောင်အထည်ဖော်မှုများ
- `11-MCPServerHandsOnLabs/` - သည်အကြောင်း အတွင်း တင့်တင်းစွာ डेटाबेस ထည့်သွင်းထားသည့် လေ့ကျင့်ခန်းများ

စမ်းသပ်ပရောဂျက်တိုင်းတွင် ကိုယ်ပိုင်တပ်ဆင်ခြင်းညွှန်ကြားချက်များ ပါရှိသည်။

#### TypeScript/JavaScript Projects
```bash
cd <project-directory>
npm install
npm start
```

#### Python Projects
```bash
cd <project-directory>
pip install -r requirements.txt
# သို့မဟုတ်
pip install -e .
python main.py
```

#### Java Projects
```bash
cd <project-directory>
mvn clean install
mvn spring-boot:run
```

##### ရည်ရွယ်ချက်

သင်၏ ပညာရေးအစီအစဉ်စာရွက်စာတမ်းများ ပြောင်းလဲမှုများနှင့် ကိုယ်စားပြုနမူနာ ကုဒ်များ
မာ့ခ်အချိန်မတိုင်ခင် ကောင်းမွန်မှုကို စစ်ဆေးသည်။

##### ထည့်သွင်းစာရင်းများ

- `changed_paths: string[]` (လိုအပ်သည်) - PR တွင် ပြောင်းလဲထားသော ဆက်စပ်လမ်းကြောင်းများ။
- `run_docs_lint: boolean` (ပုံမှန် `true`)
- `run_links_audit: boolean` (ပုံမှန် `true`)
- `run_samples: { typescript?: boolean, python?: boolean, java?: boolean }`
  (ပုံမှန်အားလုံး `false`)

##### ထွက်စာရင်းများ

- `status: "ok" | "failed"`
- `checks: Array<{ name: string, command: string, exit_code: number,
  summary: string }>`
- `artifacts: Array<{ type: "log" | "report", path: string }>`
- `failed_checks: string[]`

##### ခွင့်ပြုချက်များ

- အလုပ်ရုံစာရွက်စာတမ်းများအား ဖတ်ရှုနိုင်ခြင်းနှင့် ကိရိယာဖန်တီးထားသော အရာများအား (ဥပမာ - lint
  အစီရင်ခံစာများ၊ စမ်းသပ်မှုလော့ဂ်များ)သာ ရေးခြင်း၊ `translations/` သို့မဟုတ်
  `translated_images/` တွင် မရေးခြင်း။
- ဒေသစပ် shell command များကို အကောင်အထည်ဖော်ခြင်း။
- အနည်းငယ်ကွန်ယက်အသုံးပြုခွင့် (package ပြန်သိမ်းရန်သာ)၊ (`npm ci`,
  `python -m pip install`, `mvn` မှာ တိုင်ပင်မှုဖြေရှင်းခြင်း)။
- `translations/` သို့မဟုတ် `translated_images/` ဖိုင်များကို
  ပွတ် pushing, merging သို့မဟုတ် ပြင်ဆင်ခြင်း မခွင့်ပြု။

##### အခက်အခဲဖြစ်စဉ်များ

- `E_NO_INPUT_PATHS`: `changed_paths` မရှိ။
- `E_INVALID_PATH`: ထည့်သွင်းလမ်းကြောင်းသည် repository ရဲ့ အခြေခံအပြင်ထွက်တယ်။
- `E_LINT_FAILED`: markdown lint သည် ၀င်ခွင့် code မတူညီ ပြီးနောက်ထွက်သည်။
- `E_LINK_AUDIT_FAILED`: link audit command သည် ၀င်ခွင့် code မတူညီ ပြီးနောက်ထွက်သည်။
- `E_SAMPLE_TEST_FAILED`: နမူနာ စမ်းသပ်မှု/ဖွဲ့စည်းမှု သည် ၀င်ခွင့် code မတူညီ ပြီးနောက်ထွက်သည်။
- `E_TIMEOUT`: command သည် သတ်မှတ်ထားသော အချိန်ကန့်သတ် ကျော်လွန်သွားသည်။

##### အကြံပြု CI စာချုပ်

အတည်ပြုလက်မလုပ်ရင်၊ အောက်ပါ CI task တစ်ခု ပုံစံတစ်မျိုး မှတ်သားပါ။

- `*.md`, နမူနာကုဒ်များ သို့မဟုတ် ဒီ ဖိုင်ကို ထိခိုက်သည့် pull request တွေကို မြှောက်တင်သည်။
- အထက်ဖော်ပြထားသော command များကို တိတိကျကျ လုပ်ဆောင်သည်။
- သော့မှတ်များကို artifacts အဖြစ် သိမ်းဆည်းသည်။
- အချို့ non-zero exit code တွေဖြစ်ရင် task ကို မအောင်မြင်အောင် ထားသည်။

## စမ်းသပ်ခြင်း လမ်းညွှန်များ

### စာတမ်းဆက်တင် အတည်ပြုခြင်း

၎င်းသည် အဓိကအားဖြင့် စာတမ်းဆက်တင် အထားအပေါ် အထူးပြုထားသော အချက်ဖြစ်သည်၊ စမ်းသပ်ခြင်းကို အောက်ပါအတိုင်း အာရုံစိုက်သည်။

1. **link ပုံစံ စစ်ဆေးခြင်း**: ပြန်လည်သုံးသပ်ရန် Markdown links များစာရင်းပြုစုခြင်း

   ```bash
   # Markdown လင့်ခ်များကို စစ်ဆေးပါ (ပုံစံ စစ်ဆေးခြင်း)
   find . -name "*.md" -not -path "*/node_modules/*" -not -path "./translations/*" -not -path "./translated_images/*" -print0 | xargs -0 grep -En "\[.*\]\(.*\)"
   ```

2. **ကုဒ်နမူနာ စမ်းသပ်ခြင်း**: ကုဒ်နမူနာများကို ကုဒ်စမ်းသပ်ခြင်း/ပြေးမှုကို စစ်ဆေးခြင်း

   ```bash
   # သတ်မှတ်ထားသည့်နမူနာကိုသွားပါ၊ ၎င်း၏စမ်းသပ်မှုများကိုလည်းပြေးပါ။
   cd 03-GettingStarted/samples/typescript
   npm install && npm test
   ```

3. **Markdown Linting**: ဖော်ပြထားသော ဖော်မက်တင်း တိကျမှုစစ်ဆေးခြင်း

   ```bash
   # လိုအပ်ပါက markdownlint ကို သုံးပါ
   npx --yes markdownlint-cli2 "**/*.md" "#node_modules" "#translations" "#translated_images"
   ```

## ပါဝင်ဆောင်ရွက်ခြင်း လမ်းညွှန်များ

### Pull Request လုပ်ငန်းစဥ်

1. **Fork နဲ့ Clone**: repository ကို fork ပြုလုပ်ပြီး သီးခြားနေရာတွင် clone လုပ်ပါ
2. **Branch တစ်ခု ဖန်တီးပါ**: အဓိပ္ပာယ်ရှိသော branch နာမည်များ အသုံးပြုပါ (ဥပမာ၊ `fix/typo-module-3`, `add/python-example`)
3. **ပြောင်းလဲမှုများ ဆောင်ရွက်ပါ**: English markdown ဖိုင်များကိုသာ တည်းဖြတ်ပါ (ဘာသာပြန်ထားသောများ မဟုတ်ပါ)
4. **သင့်နယ်တွင် စမ်းသပ်ပါ**: Markdown rendering မှန်ကန်မှုစစ်ဆေးပါ
5. **PR တင်ပါ**: ရှင်းလင်းသော PR ခေါင်းစဉ်များနှင့် ဖော်ပြချက်များ အသုံးပြုပါ
6. **CLA**: Microsoft Contributor License Agreement ကို လိုအပ်သလို လက်မှတ်ရေးထိုးပါ

**Q: ပုံများ မပြသကြပါက**
