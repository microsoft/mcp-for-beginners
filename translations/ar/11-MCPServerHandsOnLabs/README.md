# 🚀 خادم MCP مع PostgreSQL - دليل تعلم كامل

## 🧠 لمحة عامة عن مسار تعلم دمج قاعدة بيانات MCP

يعلّمك هذا الدليل الشامل كيفية بناء **خوادم بروتوكول سياق النموذج (MCP)** جاهزة للإنتاج تتكامل مع قواعد البيانات من خلال تنفيذ عملي لتحليلات التجزئة. ستتعلم أنماط على مستوى المؤسسة بما في ذلك **أمان مستوى الصف (RLS)**، **البحث الدلالي**، **تكامل Azure AI**، و**الوصول متعدد المستأجرين للبيانات**.

سواء كنت مطور backend أو مهندس ذكاء اصطناعي أو مهندس بيانات، يوفر هذا الدليل تعلّمًا منظمًا مع أمثلة حقيقية وتمارين عملية يرافقك خلالها عبر خادم MCP التالي https://github.com/microsoft/MCP-Server-and-PostgreSQL-Sample-Retail.

### 💻 ما الذي ستبنيه

بنهاية هذا المسار التعليمي، ستكون قد بنيت **خادم MCP لتحليلات التجزئة من Zava** كاملاً يتميز بـ:

- **قاعدة بيانات تجزئة متعددة الجداول** مع طلبات العملاء، المنتجات، والمخزون
- **أمان مستوى الصف** لعزل البيانات بناءً على المتجر
- **بحث دلالي للمنتجات** باستخدام تضمينات Azure OpenAI
- **تكامل محادثة AI في VS Code** لاستعلامات اللغة الطبيعية
- **نشر جاهز للإنتاج** باستخدام Docker و Azure
- **مراقبة شاملة** مع Application Insights

## 🎯 المتطلبات الأساسية للتعلم

لتحقيق أقصى استفادة من هذا المسار التعليمي، يجب أن تكون لديك:

- **خبرة في البرمجة**: إلمام بـ Python (يفضل) أو لغات مشابهة
- **معرفة قواعد البيانات**: فهم أساسي لـ SQL وقواعد البيانات العلائقية
- **مفاهيم API**: فهم REST APIs ومفاهيم HTTP
- **أدوات التطوير**: خبرة في سطر الأوامر، Git، ومحررات الكود
- **أساسيات الحوسبة السحابية**: (اختياري) معرفة أساسية بـ Azure أو منصات سحابية مماثلة
- **الإلمام بـ Docker**: (اختياري) فهم مفاهيم الحاويات

### الأدوات المطلوبة

- **Docker Desktop** - لتشغيل PostgreSQL وخادم MCP
- **Azure CLI** - لنشر الموارد السحابية
- **VS Code** - للتطوير وتكامل MCP
- **Git** - لمراقبة الإصدارات
- **Python 3.8+** - لتطوير خادم MCP

## 📚 دليل الدراسة والموارد

يتضمن هذا المسار التعليمي موارد شاملة لمساعدتك على التنقل بفعالية:

### دليل الدراسة

يتضمن كل مختبر:
- **أهداف تعلم واضحة** - ما ستحققه
- **تعليمات خطوة بخطوة** - أدلة تنفيذ مفصلة
- **أمثلة كود** - عينات عمل مع شروحات
- **تمارين** - فرص ممارسة عملية
- **أدلة استكشاف الأخطاء** - المشكلات الشائعة وحلولها
- **موارد إضافية** - قراءات واستكشافات أخرى

### التحقق من المتطلبات الأساسية

قبل بدء كل مختبر، ستجد:
- **المعرفة المطلوبة** - ما يجب أن تعرفه مسبقاً
- **التحقق من الإعداد** - كيفية التأكد من بيئتك
- **تقديرات الوقت** - الوقت المتوقع لإكماله
- **نتائج التعلم** - ما ستعرفه بعد الانتهاء

### مسارات التعلم الموصى بها

اختر مسارك بناءً على مستوى خبرتك:

#### 🟢 **مسار المبتدئين** (جديد على MCP)
1. تأكد من إكمال 0-10 من [MCP للمبتدئين](https://aka.ms/mcp-for-beginners) أولاً
2. أكمل المختبرات 00-03 لتعزيز فهمك للأساسيات
3. اتبع المختبرات 04-06 للبناء العملي
4. جرب المختبرات 07-09 للاستخدام العملي

#### 🟡 **مسار متوسط** (لديك بعض خبرة MCP)
1. راجع المختبرات 00-01 لمفاهيم محددة في قواعد البيانات
2. ركز على المختبرات 02-06 للتنفيذ
3. اغمر نفسك في المختبرات 07-12 للميزات المتقدمة

#### 🔴 **مسار متقدم** (لديك خبرة مع MCP)
1. تصفح المختبرات 00-03 للسياق
2. ركز على المختبرات 04-09 لدمج قاعدة البيانات
3. ركز على المختبرات 10-12 للنشر في الإنتاج

## 🛠️ كيف تستخدم هذا المسار التعليمي بفعالية

### التعلم المتسلسل (موصى به)

اعمل عبر المختبرات بالترتيب لفهم شامل:

1. **اقرأ النظرة العامة** - فهم ما ستتعلمه
2. **تحقق من المتطلبات الأساسية** - تأكد من امتلاك المعرفة المطلوبة
3. **اتبع الأدلة خطوة بخطوة** - نفذ أثناء التعلم
4. **أكمل التمارين** - عزز فهمك
5. **راجع النقاط الرئيسية** - ثبت نتائج التعلم

### التعلم المستهدف

إذا كنت بحاجة إلى مهارات محددة:

- **دمج قاعدة البيانات**: ركز على المختبرات 04-06
- **تنفيذ الأمان**: ركز على المختبرات 02، 08، 12
- **البحث الدلالي/الذكاء الاصطناعي**: اغمر في المختبر 07
- **النشر في الإنتاج**: ادرس المختبرات 10-12

### الممارسة العملية

يتضمن كل مختبر:
- **أمثلة كود عملية** - انسخ، عدل، وجرب
- **سيناريوهات واقعية** - حالات استخدام تحليل تجزئة عملية
- **تعقيد تدريجي** - بناء من البسيط إلى المتقدم
- **خطوات التحقق** - تأكد من عمل التنفيذ لديك
