# خادم MCP Calculator (بايثون)



تنفيذ بسيط لخادم بروتوكول سياق النموذج (MCP) بلغة بايثون يوفر وظائف آلة حاسبة أساسية.


## التثبيت

قم بتثبيت التبعيات المطلوبة:

```bash
pip install -r requirements.txt
```

أو قم بتثبيت SDK الخاص بـ MCP بايثون مباشرةً:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

## الاستخدام

### تشغيل الخادم

تم تصميم الخادم ليُستخدم بواسطة عملاء MCP (مثل Claude Desktop). لبدء الخادم:

```bash
python mcp_calculator_server.py
```

**ملاحظة**: عند التشغيل مباشرة في الطرفية، سترى أخطاء تحقق JSON-RPC. هذا سلوك طبيعي - الخادم ينتظر رسائل عملاء MCP بتنسيق صحيح.

### اختبار الوظائف

لاختبار عمل وظائف الآلة الحاسبة بشكل صحيح:

```bash
python test_calculator.py
```

## استكشاف الأخطاء وإصلاحها

### أخطاء الاستيراد

إذا رأيت `ModuleNotFoundError: No module named 'mcp'`، قم بتثبيت SDK الخاص بـ MCP بايثون:

```bash
pip install "mcp>=2.1.1,<3.0.0"
```

### أخطاء JSON-RPC عند التشغيل مباشرة

الأخطاء مثل "JSON غير صالح: EOF أثناء تحليل قيمة" عند تشغيل الخادم مباشرة متوقعة. الخادم يحتاج لرسائل عملاء MCP، وليس إدخال طرفي مباشر.
